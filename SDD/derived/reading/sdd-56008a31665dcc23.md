<a id="s033-sh004"></a>
## s033\-sh004 — ppt/slides/slide33\.xml/spTree/\*\[4\]

```text
Requirement: “We want to build our carts by container type.  We want our labels for parcel shipments to be grouped by container type while printing and we need to know how many of each container type will be used.  The users will be handed a stack of labels, starting with the break label, which will tell them how many of a specific container type are needed.  Then, they find the container types and then put them on a cart for picking.  We also need the Container ID barcoded.”
Resolution: We can configure our Label Master criteria to order our labels by Container Type, and can stamp the Container Type and count on Break Labels.  We can have a Break Label print for every Container Type. We will add a barcode to the top of the container contents label for the Container ID.

```
