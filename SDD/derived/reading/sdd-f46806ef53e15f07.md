## b00016 — word/document\.xml/body/\*\[16\]

```text
The process of building the SCALE configuration can be divided into different functional areas. The following are the main functional areas: Items, Locations, Inventory Management, Receiving, Work, Outbound Flow, Allocation, Wave, Cycle Counting, Work Orders, Replenishment, Container Creation (sometimes called Cubing) and Quality Check (also known as QC). Not all functional areas are required, for example, some warehouses do not have replenishment flows and would not require configuration in this functional area.
```

<a id="b00017"></a>
## b00017 — word/document\.xml/body/\*\[17\]

```text
These functional areas are sometimes interconnected. Therefore, it is advised to follow a certain order when creating the configuration, as some steps require the definition of certain parameters beforehand. It is not compulsory to follow the order defined in this document although it is recommended. This document serves as a reference for how to use the configuration tool and how the functional areas communicate with one another.
```
