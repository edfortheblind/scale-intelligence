Activating/Deactivating a customized Insight screen
 
The Activate and Deactivate buttons enable users to activate and deactivate custom screens.
 
Activating a custom screen will automatically disable the corresponding base insight screen. For instance, the base
Receipt Insight screen will be disabled if you activate a custom Receipt Insight screen. Similarly deactivating will function
