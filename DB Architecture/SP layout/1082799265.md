### Purpose

Build work\-group chart plus monitor summary counts\.

### Inputs defaults

- filterCriteria nvarchar\(MAX\), culture nvarchar\(10\); no defaults\.

### Null and invalid input behavior

- Absent warehouse leaves the local variable NULL, so warehouse comparisons match no rows\. Duplicate matching filter names are assigned without ordering\.
- Empty matching work produces an empty chart; outer SUM values for work units, instructions and condition counts can be NULL, while estimated\-time ISNULL gives zero and the closed COUNT gives zero\. COUNT\(DISTINCT WORK\_UNIT\) excludes NULL work\-unit values\.
- A work unit in two conditions contributes to both per\-condition distinct counts; the summed unit total is not a warehouse\-wide distinct count\. A NULL group gets localized category text but NULL description\.

### Output shape

- Seven result sets: chart rows with binding/category/data/description/axis/drilldown/title fields, followed by six one\-row scalar result sets for units, instructions, estimated time, open, in\-process and recently closed instructions\.
