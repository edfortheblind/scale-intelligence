PowerShell > SCALE SaaS PowerShell

SCALE provides integration with Windows PowerShell to automate environment, single sign on configuration processes. This section briefly explains SCALE SaaS PowerShell module command.

Steps to follow to execute PowerShell commands

Open PowerShell as administrator. 

Run commands from below table. Optional parameter can be left blank. 

Commands we offer as part of SCALE SaaS PowerShell are :

Command Purpose Parameters Notes
Install-SCALEIISCertificate Install IIS certificate                

 

 
Install-SCALELicenseCertificate Install license certificate
Publish-SCALEDesktop Publish desktop for all environments
Get-SCALEStandaloneConnectionStrings Return database and azure connection strings
Set-SCALEStandaloneConnectionStrings Set database and azure connection strings

DatabaseConnectionString

AzureStorageConnectionString
Clear-SCALECache Clear cache entries

Key: Clears the given key within the specified region(region and key values are separated by ':').

Region: Clears the entire region.

Region concept is applicable for Redis cache only.

Examples:

Clear-ScaleCache -Key "tenant1_AUTH_CONFIG:TokenEndpoint"

Clear-ScaleCache -Region "tenant1_AUTH_CONFIG"

Set-ScaleComposerClientConfig

Sets the configuration parameters for SCALE Assist to communicate with composer endpoints.

AuthenticationServer

UserName

ComposerPassword

AuthenticationServerToken

ComposerEndPointServer

SCALEChatbotId

Example:

Set-ScaleComposerClientConfig `

-AuthenticationServer "auth.scale.local" `

-UserName "admin" `

-ComposerPassword "MySecurePassword!" `

-AuthenticationServerToken "abc123xyz" `

-ComposerEndPointServer "composer.scale.local" `

-SCALEChatbotId "bot-456"
