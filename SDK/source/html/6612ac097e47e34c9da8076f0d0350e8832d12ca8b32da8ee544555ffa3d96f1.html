Supported Screen Control Events
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > Supported Screen Control Events

Any JavaScript function can be called from the eventing infrastructure on the metadata screens. This page describes the functions that are provided by base SCALE as default or "common" functions. They should be used whenever possible to avoid rewriting code and reinventing logic.

JS File JS Function Description Expected Parameters
_webUi.detailsScreenActions menuActionOpenUrlInCurrentTab Opens a new page in the current browser tab. URL + page specific parameters
menuActionOpenUrlInModalDialog Opens a new page in a modal dialog. URL + page specific parameters
_webUi.detailsScreenBinding cancel
invokePOSTWebService Invokes a POST web service call. POSTServiceURL + specific web service parameters
invokePUTWebService Invokes a PUT web service call. PUTServiceURL + specific web service parameters
save Saves data on a Details screen, which could be either an insert or an update.
  • POSTServiceURL or PUTServiceURL + specific web service parameters
  • POSTServiceErrorCallbackInsert or PUTServiceErrorCallbackUpdate
_webUi.dialog hideModalDialogByEvent Hides a visible modal dialog. ModalDialogName
showModalDialogByEvent Shows a modal dialog. ModalDialogName
_webUi.insightListPaneActions menuActionOpenUrlInCurrentTab Opens a new page in the current browser tab. URL
menuActionOpenUrlInCurrentTabWithPost Opens a new page in the current browser tab where the html is obtained by a POST call. POSTServiceURL + specific web service parameters
menuActionOpenUrlInModalDialog Opens a new page in a modal dialog. URL + page specific parameters
menuActionPerformDelete
  • DELETEServiceURL + specific web service parameters
  • Delete_SuccessCallback
  • ConfirmationMessageCode
  • ConfirmationTitleCode
menuActionPerformGet Invokes a GET web service call. GETServiceURL + specific web service parameters
menuActionPerformPost Invokes a POST web service call with optional prompt beforehand.
  • POSTServiceURL + specific web service parameters
  • Post_SuccessCallback
  • Post_ErrorCallback
  • ConfirmationMessageCode
  • ConfirmationTitleCode
menuActionPerformPostForSelection Invokes a POST web service call with optional prompt beforehand for multiple rows.
  • POSTServiceURL + specific web service parameters
  • Post_SuccessCallback
  • Post_ErrorCallback
  • ConfirmationMessageCode
  • ConfirmationTitleCode
modalDialogPerformGetWithConfirmation Invokes a GET web service call that returns a confirmation message displayed to the user in a modal. If the user confirms positively, a POST web service call is made.
  • GETServiceURL + specific web service parameters
  • POSTServiceURL + specific web service parameters
  • ModalDialogName
  • Post_SuccessCallback
  • Post_ErrorCallback
  • ConfirmationMessageCode
  • ConfirmationTitleCode
modalDialogPerformPost Invokes a POST web service call from a modal dialog and then hides the modal dialog.
  • POSTServiceURL + specific web service parameters
  • Post_SuccessCallback
  • Post_ErrorCallback
  • ConfirmationMessageCode
  • ConfirmationTitleCode
  • ModalDialogName
modalDialogPerformPostWithConfirmation Invokes a POST web service call that returns a confirmation message displayed to the user in a modal. If the user confirms positively, another call POST web service call is made to the same web service (without confirmation).
  • POSTServiceURL + specific web service parameters
  • ModalDialogName
  • Post_SuccessCallback
  • Post_ErrorCallback
  • ConfirmationMessageCode
  • ConfirmationTitleCode
_webUi.metadataActions menuActionPerformPost Invokes a POST web service.
  • POSTServiceURL + specific web service parameters
  • Post_SuccessCallback
