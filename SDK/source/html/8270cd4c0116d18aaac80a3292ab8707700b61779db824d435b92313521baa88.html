How to: Configure Cascading Combo Boxes

This topic will walk you through changing metadata to define two cascading combo boxes. When the user selects a value from the parent combo box the list of results in the child combo box will be narrowed down to only the values that are associated with the selected parent.

 Step 1: Identify the parent and child combo boxes

These could be controls that are shipped with the system or custom controls that were added. For this example, let's look at the Carrier and Service fields from the Shipment detail screen. Find the OBJECT_ID of the corresponding SCREEN_CONTROL records for the combo boxes. The below SQL will return the entire list of controls for a screen and the correct control should be chosen from the list. The form id for the Shipment detail screen is 2735. The Carrier combo box control name is CarrierCarrierNameValue and the Carrier Service combo box control name is CarrierCarrierServiceValue. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find Object Id of control
Copy Code 
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))
 Step 2: Identify the drop down list to show from the combo box

A SCREEN_CONTROL_ATTRIBUTE record for the parent (carrier) and child (carrier service) combo box should be found in the SCREEN_CONTROL_ATTRIBUTES table. The records are defined as listed in the table below. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

When configuring your own parent and child cascading combo boxes they should have similar records defined in the SCREEN_CONTROL_ATTRIBUTE table as the carrier and service example.

 

Field Value
SCREEN_CONTROL_ID The Object of the grid screen control the attribute is tied to.
ATTRIBUTE_NAME The name of the attribute. For the parent combo box this value should be childCombo. For the child combo box this value should be parentCombo.
ATTRIBUTE_VALUE The value associated with the attribute. For the parent this should be the name of the child combo box. This value can be found in the SCREEN_CONTROL record found in step 1. For the child combo box this value should be the name of the parent combo box.
ACTIVE Used to define if the attribute is active. This should be Y.
IS_CONTROL_PROPERTY Defines if this is a property of the control. This should be N.
