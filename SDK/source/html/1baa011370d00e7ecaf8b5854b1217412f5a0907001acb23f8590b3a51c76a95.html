Location Inventory Attributes Web services
View with Navigation Tools

The following web services are available to get and insert/update Location Inventory Attributes.

 Step 1: Retrieve an Inventory Resource representation

First perform an HTTP GET to retrieve a Inventory resource representation.

How to: Inventory Web Service

 Step 2: Get the Location Inventory Attributes

The Inventory resource representation will include the link to the Location Inventory Attributes resource. The link (rel="getInventoryAttributes") has a href that is a URI template with the {attributeId} token. To fetch the Location Inventory Attributes representation, substitute the token and perform an HTTP GET:

Request:

  • URI: From Inventory's link (rel="getInventoryAttributes") href
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by the LocationInventoryAttributes representation conforming to one of the media types: application/vnd.manh.ils.inventory.locationInventoryAttributes+json, XML 

 Step 3: Save the Location Inventory Attributes

The Inventory resource representation will include the link to the Location Inventory Attributes resource. The link (rel="putInventoryAttributes") has a href that is a URI template with the {attributeId} token. Perform a HTTP PUT with the following:

Request:

  • URI: From Inventory's link (rel="putInventoryAttributes") href
  • Method: PUT
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Roles: SCALEUSER,Confidential
  • Entity: The LocationInventoryAttributes representation with AttributeId (to update) and without AttributeId (to insert new). Also, it's InternalLocationInv number can be set to link it to a Location Inventory after save. The entity should conform to one of the media types: application/vnd.manh.ils.inventory.locationInventoryAttributes+json, XML

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by the updated LocationInventoryAttributes with the attributeId field representing the inserted Id. The Response conforms to one of the media types: application/vnd.manh.ils.inventory.locationInventoryAttributes+json, XML
400

The following ErrorTypes can be expected: Location
