VAS Confirmation Web Service
View with Navigation Tools

The VAS Confirmation web service allows a consumer to complete Value Added services for a list of Shipping containers.  This is achieved by executing the following steps:

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Retrieve the ShippingContainerVasActivities

The Shipping resource representation will include the link to the Shipping Container Vas Activities resource. The link (rel="shippingContainerVasActivities") has a href that is a URL to the ShippingContainerVasActivities Resource.  To fetch the Shipping Container Vas Activity representations perform an HTTP GET:

Request:

  • URI: <link href>?<queryString>

    Note that the <queryString> can consist of any fields found in the request entity (XML).  For example, if requesting for the VAS activities (Coupons and Manual) for all containers in the shipment "SHIP01", the query string would be 'ShipmentId=SHIP01&VasActivities=Coupons&VasActivities=Manual'

    • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential                   

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.shipping.shippingContainerVasActivities+json, application/vnd.manh.ils.shipping.shippingContainerVasActivities+xml

 Step 3: Post the ShippingContainerVasActivities using the completed link

The Shipping Container Vas Activities collection resource representation will include a completed link. To do a Vas Confirmation, set the "completed" field on each shippingContainerVasActivity representation and perform an HTTP POST with the following:

Request:

  • URI: From ShippingContainerVasActivities' link (rel="complete") href
  • Method: POST
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: The updated ShippingContainerVasActivities from Step 2

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by the updated entity conforming to one of the requested media types: application/vnd.manh.ils.shipping.shippingContainerVasActivities+json, application/vnd.manh.ils.shipping.shippingContainerVasActivities+xml
