How to: Retrieve Parameter Values from the Insight Grid
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Actions > How to: Retrieve Parameter Values from the Insight Grid

Columns from a selected grid row can be dynamically retrieved and passed as parameters to the web services that dynamic actions call. The parameter naming conventions spelled out in the Screen Control Event Parameter Naming Conventions must be followed for the values to be retrieved and passed correctly. Use the How to: Perform a GET Service Call from Metadata Action, How to: Perform a POST Service Call from Metadata Action, or How to: Perform a DELETE Service Call from Metadata Action topics to create the proper metadata records to call the web service. Then, for each parameter value that needs to be pulled from a grid, add a SCREEN_CONTROL_EVENT_PARAMETERS record. The format of this record depends on the type of service being called.

 GET and DELETE services

GET and DELETE services use query string parameters and the SCREEN_CONTROL_EVENT_PARAMETERS record should be created as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
PARAMETER_NAME queryParameter_Grid_<ControlName>_<InputParameterName> (e.g. queryParameter_Grid_DetailPaneDetailsContainers_internalNum)
PARAMETER_VALUE The name of the column to pull the value from (e.g. HIDDEN_INTERNALCONTAINERNUM)
SCREEN_CONTROL_ID_EVENT_ID The Object Id of the screen control event
 POST services

POST services pass a single json entity that is deserialized and the SCREEN_CONTROL_EVENT_PARAMETERS record should be created as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
PARAMETER_NAME PostData_Grid_<ControlName>_<InputParameterName> (e.g. PostData_Grid_DetailPaneDetailsContainers_internalNum)
PARAMETER_VALUE The name of the column to pull the value from (e.g. HIDDEN_INTERNALCONTAINERNUM)
SCREEN_CONTROL_ID_EVENT_ID The Object Id of the screen control event
