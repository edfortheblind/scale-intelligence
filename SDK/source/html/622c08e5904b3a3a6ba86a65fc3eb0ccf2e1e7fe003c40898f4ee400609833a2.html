How to: Display a Column Value as a Link in a Grid
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Display a Column Value as a Link in a Grid

A column value inside a grid on the detail pane can be displayed as a hyperlink by setting the template property of the IgniteUI grid column header. This allows for flexible conditional formatting (i.e. a column value can be displayed as a hyperlink or plain text based on a specified condition). This is achieved by setting the column template attribute value for an IgniteUI grid column header object. The system processes the given template value using either the IgniteUI or Handlebars template engine. An example column template value with the Handlebars template engine is shown below.

Handlebards Column Template
Copy Code 
{{#ifCond INTERNALNUMTYPE "==" "Shipment"}}
    <a href="/SCALE/Insights/2735?filters=BasicCriteriaShipmentId:{{encodeURIComponent REFERENCEID}}">{{REFERENCEID}}</a>
{{else}}
    {{#ifCond INTERNALNUMTYPE "==" "Dock Management"}}
        <a href="/SCALE/Insights/2735?filters=BasicCriteriaShipmentId:{{encodeURIComponent REFERENCEID}}">{{REFERENCEID}}</a>            {{else}}
        {{REFERENCEID}}
    {{/ifCond}}
{{/ifCond}}

 

For specific information on handlebars refer the following article: http://handlebarsjs.com/.

 

NOTE: %20 must be used for spaces for example CARRIER === UPS%20GROUND

 Set the template in the stored procedure for the detail pane

The detail pane data is generally filled via a stored procedure. See the How to: Create a Detail Pane Stored Procedure topic for more details on creating this stored procedure. This stored procedure can have a special table returned named "AdditionalInfo".  To make a column in a grid be a hyperlink, you will need to insert a record into the "AdditionalInfo" table inside the detail pane stored procedure to set the template property value for a column. If the "AdditionalInfo" table does not exist in the stored procedure, then create one using the following as an example.

AdditionalInfo table in detail pane stored procedure
Copy Code 
SELECT  *
FROM
    (   
        --        Table Name,                      Column Name,     IG grid column header property,     Property Value   
        VALUES('DetailPaneDetailsReference', 'REFERENCEID', 'template', '
        {{#ifCond INTERNALNUMTYPE "==" "Shipment"}}
        <a href="/SCALE/Insights/2735?filters=BasicCriteriaShipmentId:{{encodeURIComponent REFERENCEID}}">{{REFERENCEID}}</a>{{else}}
        {{#ifCond INTERNALNUMTYPE "==" "Dock Management"}}<a href="/SCALE/Insights/2735?filters=BasicCriteriaShipmentId:{{encodeURIComponent REFERENCEID}}">{{REFERENCEID}}</a>{{else}}{{REFERENCEID}}{{/ifCond}}
        {{/ifCond}}'),
        ('DetailPaneDetailsReference', 'INTERNALNUMTYPE', 'hidden', 'true')
    )
    AS  AdditionalInfo (ADDITIONALINFO_TABLENAME, ColumnName, Property, Value)
