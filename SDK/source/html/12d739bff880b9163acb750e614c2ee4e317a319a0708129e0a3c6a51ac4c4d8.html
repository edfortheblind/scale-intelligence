Transfer Shipping Containers Web Service
View with Navigation Tools

The TransferShippingContainers operation belongs to the Dock Management Web Service. It takes a list of top-level shipping containers (a.k.a. tree units) and either assigns new work, reassigns existing work, or preassigns future moves to the given destination location(s).

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Post the TransferShippingContainersRequest using the transferShippingContainers link

The Shipping resource representation will include a transferShippingContainers link. To invoke transferShippingContainers for a list of shipping Containers, create the relevant TransferShippingContainersRequest data structure and perform an HTTP POST with the following:

Request:

  • URI: From Shipping representation's link (rel="transferShippingContainers") href
  • Method: POST
  • Content-Type: application/json or application/xml
  • Roles: SCALEUSER,Confidential
  • Entity: application/vnd.manh.ils.shipping.transferShippingContainers+json, xml

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity that contains either an error or is empty, which signifies a successful transfer. Note that if an error is found, check the ErrorType to see if location collisions were encountered, in case special recovery logic is desired. If so, the list of containers that experienced location collisions is also provided:application/vnd.manh.ils.shipping.transferShippingContainersResponse+json, xml
