How to: Bind Detail Pane Controls
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Detail Pane > How to: Bind Detail Pane Controls

The detail pane is filled when a grid record in the list pane is selected. This fires an event that will call the configured web service and bind the detail pane controls with the json returned.

 Step 1: Configure the grid record selected event

The main list pane grid of an insight screen needs to have an event created in metadata when the user selects a new row in the grid.

 Create a screen control event record tied to the main list pane grid

Add a SCREEN_CONTROL_EVENT record as follows for the main list pane grid. This defines what gets called when a record is selected in the grid. This action will call the configured web service and bind the detail pane controls to the data returned. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_ID The Screen Control Id of the main list page grid
EVENT_ID iggridselectionactiverowchanged
EVENT_NAME _webUi.Grid.gridActiveRowChanged
 Create screen control event parameters tied to the event

Now add a SCREEN_CONTROL_EVENT_PARAMETERS record as follows for the grid control event. This defines what web service will get called when the user selects a row in the grid. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_EVENT_ID The Screen Control Event Id of the event for the grid
PARAMETER_NAME GETServiceURL if a stored procedure will be used or POSTServiceURL if a custom web service will be used
PARAMETER_VALUE /general/scaleapi/GenericDataBindApi if a stored procedure will be used or the URL of a custom web service


Now create one SCREEN_CONTROL_EVENT_PARAMETERS record for each parameter that will be passed to the web service. Please referece the How to: Perform GET Service Call from Metadata Action and How to: Perform POST Service Call from Metadata Action topics for instructions.

 Step 2: Ensure the detail pane control names align with returned data
The data returned by the web service call will be automatically bound to the proper controls as long as the json is returned in the proper format, and the control names match the json return values created by either the stored procedure or custom web service.
