How to: Set Label Orientation
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Set Label Orientation

Labels can be applied both individually as well as in conjunction with another control. If a label will be inserted by itself as a standalone control, it must be created through metadata using the Label control. Labels that will be tied to another control are NOT entered in metadata, but are created automatically based on the "Label Orientation" specified for the main control (as well as the "Resource Key" specified on the control). Please see the "Label Orientation" configuration for an enumeration of the available label orientations.

 Setting label orientation on a new control when metadata is created
In order to set the label orientation on a control as it is being created from metadata, simply set the LABEL_ORIENTATION and the RESOURCE_KEY on the control that the label should be tied to. Please reference the How to: Create Screen Controls topic for more details. Also see the "Label Orientation" configuration for an enumeration of the available label orientations.

 Modifying the label orientation for an existing control

In order to change an existing control to have a different label orientation, first find the Object Id of the control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find Object Id of controls
Copy Code 
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))


Then update the LABEL_ORIENTATION field accordingly. Please see the "Label Orientation" configuration for an enumeration of the available label orientations.

Modifying label orientation
Copy Code 
update SCREEN_CONTROL set LABEL_ORIENTATION = '30' where OBJECT_ID = <object id>
