How to: Create the Search Pane
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Search Pane > How to: Create the Search Pane

The "Search Pane" on an insight screen represents the left side of the screen where search criteria are entered and used to filter the grid results. As an example, you can find all of the metadata records for an existing search pane using the following script.

Shipment insight search pane example
Copy Code 
declare @formId numeric(9,0);
declare @paneName nvarchar(25);
set @formId = 2735;
set @paneName = 'SearchPane';
select * from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId);
select * from SCREEN_GROUP where SCREEN_PART_ID in (
    select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId));
select * from SCREEN_GROUP_COLUMN where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
        select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId)));
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
        select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId)));
select * from SCREEN_CONTROL_ATTRIBUTES where SCREEN_CONTROL_ID in (
    select OBJECT_ID from SCREEN_CONTROL where SCREEN_GROUP_ID in (
        select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
            select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId))));
select * from SCREEN_CONTROL_EVENT where SCREEN_CONTROL_ID in (
    select OBJECT_ID from SCREEN_CONTROL where SCREEN_GROUP_ID in (
        select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
            select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId))));
select * from SCREEN_CONTROL_EVENT_PARAMETERS where SCREEN_CONTROL_EVENT_ID in (
    select OBJECT_ID from SCREEN_CONTROL_EVENT where SCREEN_CONTROL_ID in (
        select OBJECT_ID from SCREEN_CONTROL where SCREEN_GROUP_ID in (
            select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
                select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId)))));


Creating the search pane on an insight screen can be processed as follows.

 Step 1: Create a screen part record for the search pane

Add a SCREEN_PART record as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_ID The Screen Id of the current insight screen
PART_NAME SearchPane
RESOURCE_KEY NULL
PART_TYPE 10 (Div Container)
DIV_CSS_CLASS col-md-4 col-lg-4 searchpanepart
DEFAULT_ACTION SearchPaneMenuSearch
 Step 2: Add basic criteria
Please reference the How to: Add Basic Criteria to Search Pane topic for instructions.
 Step 3: Add other criteria
Add subsequent criteria sections with input controls, or sections with checked list boxes. Please reference How to: Add Checked List Box to Search Pane for more details.
 Step 4: Add advanced criteria
Please reference the How to: Add Advanced Criteria to Search Pane topic for instructions.
