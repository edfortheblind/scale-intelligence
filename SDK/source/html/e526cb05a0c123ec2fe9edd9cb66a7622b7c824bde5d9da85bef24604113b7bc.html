How to: Create a New Monitor Page
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Monitor Pages > How to: Create a New Monitor Page

Insight Architect supports creating a basic Monitor page. Follow the below instructions for creating a new Monitor page.

 Step 1: Open the Insight Architect Monitor Builder

Browse to the URL https://<servername>/scale/trans/monitoringbuilder?internalFormId=0 - this must be done manually as this page is not accessible via the main menu.

 Step 2: Fill the Required Data in Insight Architect for the New Monitor Page

Fill in the required fields on the screen:

  • Form id: Will default to the next available Form Id. Either leave as is or change to desired Form Id.
  • Form key name: Format as MNU_<monitoringscreenname>_MONITORING (i.e. if my Monitor will be named "Custom", then use MNU_Custom_Monitoring.
  • Functional area: Choose the functional area that the new Monitor screen should be under in the menu.

Expand the Summary Tiles section and add a record for each summary tile you want at the top of the Monitor page:

  • Sequence: Numeric value that controls the order in which the tiles will show up.
  • Data binding: The column name that must be returned from the stored procedure for the Monitor page.
  • Resource key: The resource key that will be translated for the summary tile.

Expand the Actions bar section and fill the required fields:

  • Insight: Represents the parameters passed when the user clicks the Insight button in the Actions bar of the new Monitor page. Either enter the proper value if you are familiar with the formatting, or just enter "FORM_ID=2723,SearchPaneWhs=FROM_WHS;" for now and we will come back and update it later. This default value will just make the Insight button on the Actions bar go to the Inventory Insight screen filtered by the users current warehouse.
  • Breadcrumb resource keys: Enter a resource key that will be translated in the breadcrumb trail for each level drill-down the chart will have.

Expand the Chart area section and fill the required fields:

  • Stored procedure: Specify the name of the stored procedure that will be used to return the chart data and summary tile data.
  • Data binding: Specify the column name in the stored procedure that will represent the chart data.
  • Insight URL: Represents the parameters passed when the user drills down to the last level of the chart and therefore into an Insight page with filters. Either enter the proper value if you are familiar with the formatting, or just enter "FORM_ID=2723,SearchPaneWhs=FROM_WHS;" for now and we will come back and update it later. This default value will just make the drill down in the chart go to the Inventory Insight screen filtered by the users current warehouse.
  • Insight criteria: Represents the common parameters passed when moving from a Monitor page to an Insight page. Either enter the proper value if you are familiar with the formatting, or just enter "from_whs=@warehouse;" for now and we will come back and update it later. 
  • Drill down levels: Enter a drill down level (0, 1, 2 where 0 is chronologically first) and criteria for each drill down level you want in the chart. Each subsequent drill down level should have the criteria from the previous level plus one extra criteria. For example, level 0 might just be "from_whs=@warehouse;", level 1 be "from_whs=@warehouse,locating_zone=@locatingZone;", and level 2 be "from_whs=@warehouse,locating_zone=@locatingZone,location_type=@locationType;".

Expand the Indicator tiles section and fill the required fields:

  • Stored procedure: Specify the name of the stored procedure that will be used to return the indicator tile data.
  • Indicator tiles: Create records for each indicator tile you want on the Monitor page:
    • Resource key: The resource key that will be translated for the indicator tile.
    • Data binding: Specify the column name in the stored procedure that will represent the indicator tile data. 
    • Tile criteria: Represents the parameters passed when moving from a Monitor page to an Insight page by clicking on an indicator tile. Either enter the proper value if you are familiar with the formatting, or just enter "from_whs=@warehouse;" for now and we will come back and update it later. 
    • Go to Insight URL: Represents the URL that will be generated to go to an Insight page when an indicator tile is clicked. Either enter the proper value if you are familiar with the formatting, or just enter "FORM_ID=2723,SearchPaneWhs=@warehouse" for now and we will come back and update it later.
    • Caution criteria: Leave blank for now, we will come back later.
    • Warning criteria: Leave blank for now, we will come back later. 

Click the Save button. The beginning of your new Monitor page will appear.

 Step 3: Modify the Required Stored Procedures

Up until now we have used the Insight Architect tool to create the beginning of a Monitor page. Many of the values may still be the default values mentioned above just so that we could get a working base and now we can modify the more complex portions of the Monitor screen via the metadata portion of Insight Architect (How to: Use Insight Architect to Customize a Metadata Page ).

As a part of the previous step, the Insight Architect tool generated stored procedures based on the names you gave in the stored procedures fields above. It also put random number generation in for the chart, summary tiles, and indicator tiles, which is why your new screen is showing values when you have not told it what values to actually show. Since it has created a stored procedure skeleton for us, it is now easy to go modify the stored procedure(s) with the proper SQL to return the values we want to return in the columns that are now returning random numbers.

Use the following topics to modify the stored procedures with the exact information you need to fill the data on the Monitor screen:

  • How to: Create Monitor Page Stored Procedure
  • How to: Bind Controls on a Monitor Page
 Step 4: Ensure Chart Drilldown is Working Properly

Ensure that you can drill down into the different chart levels. If not, then update the stored procedures and metadata as required by following the instructions in the following topics:

  • How to: Add a Drilldown Level to a Chart on a Monitor Page
  • How to: Drilldown to Insight Screen from a Chart on a Monitor Page
 Step 5: Ensure Breadcrumb is Working Properly

Ensure that the breadcrumb is properly reflecting the drilldown levels of the chart. If not, then update the stored procedures and metadata as required by following the instructions in the following topics:

  • How to: Create a Breadcrumb on a Monitor Page
 Step 6: Ensure Summary Tiles are Working Properly

Ensure that the summary tiles are being updated properly as you drill down into the different chart levels. If not, then update the stored procedures and metadata as required by following the instructions in the following topics:

  • How to: Create Monitor Page Stored Procedure
 Step 7: Ensure Indicator Tiles are Working Properly
Ensure that the indicator tiles are have proper data and that you can drill down into the appropriate Insight screen with correct filters. If not, then update the stored procedures and metadata as required by following the instructions in the following topics:
  • How to: Create an Indicator Tile on a Monitor Page
  • How to: Go to Insight from Indicator Tile
  • How to: Configure Critical Level on Indicator Tile
