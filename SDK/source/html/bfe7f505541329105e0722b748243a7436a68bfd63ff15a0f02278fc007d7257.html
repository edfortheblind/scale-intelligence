How to: Change an Editor Control to a Combo Box
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Change an Editor Control to a Combo Box

This topic will walk you through changing a metadata text editor to a combo box with a drop down list.

 Step 1: Identify an editor to modify

This could be a control that is shipped with the system or a custom field that is currently an editor. For this example, let's assume that there is an Insight screen that has User Defined Field 1 as a basic search criteria field. Find the OBJECT_ID of the corresponding SCREEN_CONTROL record for the text editor control. The below SQL will return the entire list of controls for a screen and the correct control should be chosen from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find Object Id of control
Copy Code 
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))
 Step 2: Identify the drop down list to show from the combo box
See the How to: Define Lists tied to Controls topic for details on the available lists for combo boxes. For our example we will be creating a drop down of countries for the User Defined Field 1 control.
 Step 3: Update the control type and tie the control to a list
 Determine the control type
Find the control type for a combo box. Reference the "Screen Control Type" configuration for an enumeration of screen control types. The enumeration key for ComboBox is "80".
 Determine the data source type
Find the data source type for a generic config list. Reference the "Metadata Data Source Type" configuration for the full list of supported data source type enumerations. The enumeration key for generic configuration is "30".
 Determine the data source
Find the data source for the Country configuration. Reference the How to: Define Lists tied to Controls topic for more information. The enumeration key for this example is "COUNTRY".
 Update control type, data source type, and data source

Update the CONTROL_TYPE for the text editor control in the SCREEN_CONTROL table so that it becomes a combo box. Also update the DATA_SOURCE_TYPE and DATA_SOURCE values so that the combo box points to the correct list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Update editor to be combo box
Copy Code 
update screen_control set CONTROL_TYPE = '80', DATA_SOURCE_TYPE = '30', DATA_SOURCE = 'COUNTRY'
where OBJECT_ID = <insert object id of user defined 1 control>
