How to: Customize the Background Image on the Dashboard Screen
View with Navigation Tools

This topic will walk you through customizing the background image found on the Dashboard page.

 Step 1: Add the _custom folder
  1. Browse to the %SCALE_HOME% \web directory on the SCALE server. 
  2. Add a folder called _custom.
  3. Add a subfolder called images.
 Step 2: Copy the image to _custom
  1. Copy the new background image to the _custom\images folder created in Step 1. Landscape images are recommended (if portrait image is used, custom css will need to be applied).
 Step 3: Add custom css for the new image

The background image is defined in css. This section will walk through creating custom css to load the new image. In order to do this: 

 

  1. Create or edit a file named _custom.css in the _custom folder referenced in step 1. 
  2. Add custom css to the file pointing to the new image as seen below.
_custom.css
Copy Code 
body.dashboardbody {
    background: url(/SCALE/_custom/images/CustomDashboardImage.png) no-repeat center center fixed !important;
}
NOTE: !important is required for the css to be applied properly. Use it for all css that you apply to the image. Additional css may be required depending on the image that is applied.
 Step 4: Verify the background image loads properly
  1. Open the dashboard page in a web browser: https://servername/scale/trans/dashboard.
  2. Verify the new background image loads.
