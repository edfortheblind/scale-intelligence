Multi Order Pallet Immediate Dock Transfer Web Service
View with Navigation Tools

The multi order pallet immediate dock transfer web service allows for the immediate transfer of a multi order pallet between dock locations. This is achieved by executing the following steps:

 Step 1: Retrieve multi order pallet resource

To initiate the immediate transfer of a multi order pallet, one must perform a 'get' operation to retrieve a multi order pallet resource using the following operation

 Request
  • URI: http://ServerName/ILSIntegrationServices/MultiOrderPallets?mopId={mopId}
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.shipping.multiOrderPallet+json, application/vnd.manh.ils.shipping.multiOrderPallet+xml
400 The following ErrorTypes can be expected: MultiOrderPallet, Warehouse

 

 Step 2: Transfer multi order pallet using the transfer link

The multi order pallet resource retrieved in Step 1 will contain a link to transfer the multi order pallet (rel="transferMultiOrderPalletUri"). To perform the transfer replace token {location} with the desired location and perform the following 'post' operation:

 Request
  • URI: From multi order pallet resource retrieved in Step 1
  • Method: POST
  • Accept: application/json or application/xml
  • Entity: Entity retrieved in Step 1
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by the updated ShippingContainer: application/vnd.manh.ils.shipping.shippingContainer+json, application/vnd.manh.ils.shipping.shippingContainer+xml
400

The following ErrorTypes can be expected: MultiOrderPallet, Container, FromLocation, ToLocation, Warehouse
