How to: Jump to an Insight Screen from a Monitor Page
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Monitor Pages > How to: Jump to an Insight Screen from a Monitor Page

Click on Insight menu button on Monitor screen open Insight screen. Insight screen Search Pane filter criteria populate drilled down Chart value. To achive this below steps need to follow.

 Step 1: Add an event for the insight menu button

The Insight menu button needs to be added. A "Click" event needs to be created for Insight menu button on Monitor Page. Please refer to the  How to: Create Screen Control Events topic for more detailed information.        

 Step 2: Add an event parameter for the insight menu button

The "Click" event should have URL parameter.   The value for this parameter should be in the following format. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

 

Use the ALT+219 █ character for the separator characters in the path as shown below.

 

{{FORM_ID=<Form Id>}}?filters=<Control Name> █{{{Chart Field Name}}}

Field Description

Form Id

Defines the Insight screen Form Id.

Control Name

Defines the name of the control on the Insight screen search pane that this criteria applies to.

Chart Field Name

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

 

For example, the "URL" event parameter value set to following

{{FORM_ID=2757}}?filters=SearchPaneWhs █{{{FROM_WHS}}},SearchPaneAdvCrit_Field █{{{WORK_GROUP}}},SearchPaneWrkTyp █{{{WORK_TYPE}}},BasicCriteriaUserAssigned █{{{USER_ASSIGNED}}}

Field Description

2757

Defines the Work Insight screen Form Id.

SearchPaneWhs

Defines the name of the control on the Insight screen search pane that FROM_WHS criteria applies to.

FROM_WHS

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

SearchPaneAdvCrit_Field

Defines the name of the control on the Insight screen search pane that WORK_GROUP criteria applies to.

WORK_GROUP

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

SearchPaneWrkTyp

Defines the name of the control on the Insight screen search pane that WORK_TYPE criteria applies to.

WORK_TYPE

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.
