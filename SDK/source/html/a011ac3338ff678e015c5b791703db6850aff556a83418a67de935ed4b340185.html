User Interface Extensibility > Metadata Web Pages > Detail Pages > Detail Routing

There is a single Detail controller and single view that interpret metadata and render controls dynamically at runtime for Detail screens. Please see the Metadata Page Architecture topic for more details. The following routes are currently defined for the Detail pages.

Name Template Example Description
Detail Details/{id}/{internalNum} localhost/scale/details/workinstruction/10000 Calls index method of "Detail" controller passing the specified entity name and entity Id for "edit" or "display" mode.
Detail Details/{id} localhost/scale/details/shipmentheader Calls index method of "Detail" controller passing the specified entity name for "insert" mode with no parent.
DetailWithParent Details/{parentid}/{internalNum}/{id} localhost/scale/details/shipmentheader/5/shipmentdetail Calls index method of "Detail" controller passing the specified parent entity name and Id, along with the child entity name for "insert" mode with an already existing parent.
