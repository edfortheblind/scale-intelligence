How to: Create a Dynamic Modal Dialog
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Create a Dynamic Modal Dialog

A modal dialog control allows for an overlay screen that prompts for user input in order to continue an action. An example of this is when a user chooses to save a search from an insight page and the system prompts them for a name for the search. Modal dialogs are configured via metadata and are made up of several screen parts, groups, and controls in a similar fashion to the overall page. In order to add a new modal dialog control, follow these steps.

 Step 1: Create ModalDialog screen part
Create a screen part of type ModalDialog. This part should be configured with PARTIAL_VIEW = Y. See the How to: Create Screen Parts topic for more details. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
 Step 2: Create Form screen group
Create a Form screen group that is tied to the screen part. This will be the top level screen group. See the How to: Create Screen Groups topic for more details. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
 Step 3: Create ModalDialogHeader screen group
Create a ModalDialogHeader group as a child group of the form group. The RESOURCE_KEY will be used as the title for the modal dialog. No other controls are required in this group as the close button and title comes for free. See the How to: Create Screen Groups topic for more details. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
 Step 4: Create ModalDialogBody screen group
Create a ModalDialogBody group as a child group of the form group. See the How to: Create Screen Groups topic for more details. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
 Step 5: Add input controls to the ModalDialogBody
Any dynamic input controls desired to the body of the dialog. All input controls are supported within the dialog control. See the How to: Create Screen Controls topic for more details. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
 Step 6: Create ModalDialogFooter screen group
Create a ModalDialogFooter group as a child group of the form group. See the How to: Create Screen Groups topic for more details. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
 Step 7: Add button controls to the ModalDialogFooter
Any dynamic button controls desired to the footer of the dialog and tie events to them. See the How to: Create Screen Controls topic and How to: Create Screen Control Events topic for more details. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
