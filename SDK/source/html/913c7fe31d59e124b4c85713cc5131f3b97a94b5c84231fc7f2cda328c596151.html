How to: Author SQL Server Reporting Services Reports

Reporting > How to: Author SQL Server Reporting Services Reports

SQL Server Reporting Services (SSRS) reports are created and modified in the Report Designer of SQL Server Business Intelligence Development Studio (BIDS), which installs as part of the SQL Server client tools.  See Designing and Implementing Reports Using Report Designer (Reporting Services) for general report authoring techniques.

The SSRS reports are shipped as .rdl files with the application.  The Database Installation Guide's "Appendix: Microsoft SQL Server Reporting Services Configuration" topic has a section called "Uploading Reporting Services Reports", which explains the typical process of deploying SSRS reports for the application.

When customizing base SSRS reports, make sure to actually modify and deploy a copy of the actual base report.  This protects against the loss of customization during upgrades.
