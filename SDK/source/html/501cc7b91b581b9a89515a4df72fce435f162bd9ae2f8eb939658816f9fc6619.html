How to: Customize the Calendar Event Preview
View with Navigation Tools

This topic will walk through an example of customizing the calendar event preview that appears when tapping on an event.

 

Before customizing the calendar it is recommended that a copy of the screen is created using the Insight Architect in the toolbox to ensure changes are saved for future upgrades. During upgrades the metadata changed below will be overwritten and changes may be lost.

 

 Customizing the Calendar Event Preview

Full Calendar event previews can be customized to display more/less information about the selected event. 

 

The below example will show how to add a new field to be displayed in the preview.

 Step 1: Find the SCREEN_CONTROL record for the calendar in the transaction screen

Use the following SQL statement to locate the calendar using the corresponding Form Id. Insight Architect can also be used for this How to: Use Insight Architect to Customize a Metadata Page.

Find calendar control record
Copy Code 
select * from SCREEN_CONTROL where CONTROL_TYPE = '370' and SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))

 Step 2: Update the eventDetailFields attribute to include the new field for the preview

Fields displayed in the preview are controlled by the eventDetailFields attribute. The fields here are separated by the | symbol. Each field has 2 parts: The resource key for the header and field name from the Api call result. These are further separated by colon : symbol.

 

For example in DOCKDOOR:Dock, DOCKDOOR is the resource key for the text displayed as header and Dock is the field in JSON returned from the API call.

Use the following SQL statement to modify the header attribute to add new view. Insight Architect can also be used for this How to: Use Insight Architect to Customize a Metadata Page.

Modify eventDetailFields attribute
Copy Code 
update SCREEN_CONTROL_ATTRIBUTES set ATTRIBUTE_VALUE = <new value>
where SCREEN_CONTROL_ID = <control id of calendar> and ATTRIBUTE_NAME = 'eventDetailFields'

 Step 3: Modify the URL for API which fetches event data

The URL for the API call which fetches the data to be displayed is specified in the screen control attribute eventsApiURL This API needs to be modified to return the newly added field. At this time it is required to change the eventsApiURL to point to a new custom service. Insight Architect can also be used for this How to: Use Insight Architect to Customize a Metadata Page.

Modify header attribute
Copy Code 
update SCREEN_CONTROL_ATTRIBUTES set ATTRIBUTE_VALUE = <new service URL>
where SCREEN_CONTROL_ID = <control id of calendar> and ATTRIBUTE_NAME = 'eventsApiURL'
 

After all steps run the reset.bat found in the <Install dir>\Utility folder. Then use CTRL+F5 to refresh the page. The new field should appear on the event preview.
