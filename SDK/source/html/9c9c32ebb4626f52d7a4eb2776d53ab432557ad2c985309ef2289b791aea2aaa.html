How to: Perform a GET Service Call from Metadata Action
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Actions > How to: Perform a GET Service Call from Metadata Action

Follow the steps below to make an action call a simple GET service.

 Step 1: Create a new web service
If a new web service call is required, create it. Reference the various web service sections of the SDK for more information.

 Step 2: Create a screen control or find an existing screen control
Please reference the How to: Create Screen Controls for instructions.
 Step 3: Create the screen control event and parameters for the action to perform a GET request
       

Create a new SCREEN_CONTROL_EVENT record as follows. This defines what gets called when the event is fired. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_ID The Screen Control Id of the the control that fires the action
EVENT_ID click or another event to be fired depending on the type of the control
EVENT_NAME _webUi.insightListPaneActions.menuActionPerformGet


Now create a SCREEN_CONTROL_EVENT_PARAMETERS record to define the URL that will be called. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
PARAMETER_NAME GETServiceURL
PARAMETER_VALUE The URL for web service minus query string parameters (i.e. /general/scaleapi/PrintApi?)
SCREEN_CONTROL_ID_EVENT_ID The Object Id of the screen control event


Now create SCREEN_CONTROL_EVENT_PARAMETERS records to define the query parameters that will be passed to the GET service call. Please reference the How to: Retrieve Parameter Values from the Insight Grid, How to: Retrieve Parameter Values from the Insight Detail Pane Model, How to: Retrieve Parameter Values from an Input Control, and How to: Retrieve Parameter Values from a JavaScript Function Call topics for more information on creating these records.
