Multi Order Pallet Nesting Web Service
View with Navigation Tools

The Nest Shipping Container On Multi Order Pallet Web Service allows a user to nest a shipping container onto a multi order pallet. The nest operation will associate the parent and all the children with the multi order pallet. To achieve the nest operation follow these steps:

 Step1: Retrieve multi order pallet

Perform a 'get' operation to retrieve the multi order pallet you want to nest on.

 Request
  • URI: http://ServerName/ILSIntegrationServices/multiOrderPallets/{mopId}
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.shipping.multiOrderPallet+json, application/vnd.manh.ils.shipping.multiOrderPallet+xml
400 The following ErrorTypes can be expected: MultiOrderPallet, Warehouse

 

 Step 2: Create multi order pallet if it doesn't exist

If you didn't find a multi order pallet in Step 1. Perform a 'post' operation to add the desired multi order pallet to the system

 Request
  • URI: http://ServerName/ILSIntegrationServices/multiOrderPallets
  • Method: POST
  • Content-Type: application/json or application/xml
  • Entity: application/vnd.manh.ils.shipping.multiOrderPallet+json, application/vnd.manh.ils.shipping.multiOrderPallet+xml
NOTE: If a multiOrderPalletId is not supplied in the request the system checks the packing preferences for the user. If Container Assignment Method is set to 'System' a new id is generated by the application. If Container Assignment is set to 'Manual' an error is returned.
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity that represents the new created multi order pallet: application/vnd.manh.ils.shipping.multiOrderPallet+json, application/vnd.manh.ils.shipping.multiOrderPallet+xml
400 The following ErrorTypes can be expected: MultiOrderPallet, Warehouse
409 The following ErrorTypes can be expected: MultiOrderPallet

 Step 3: Retrieve shipping container to nest

Perform a 'get' operation to retrieve the shipping container

How to: Shipping Container Web Service

 Step 4: Nest shipping container on multi order pallet

To nest a shipping container on a multi order pallet use the link on the shipping container and replace token {mopId} with the actual multi order pallet id.

 Request
  • URI: Use the shipping container entity retrieved in Step 3 to get the link to nest onto a multi order pallet (rel="nestShippingContainerOnMultiOrderPallet")
  • Method: POST
  • Content-Type: application/json or application/xml
  • Entity: Use the shipping container entity retrieved in Step 3

 

Tip: You can send a request with only the warehouse and container id instead of sending a full blown shipping container entity.
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity that represents the nested shipping container: JSON, XML
400 The following ErrorTypes can be expected: MultiOrderPallet, Warehouse, Container
