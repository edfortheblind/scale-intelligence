Close Container Web Service
View with Navigation Tools

The Close Container Web Service invokes the Close Container function of the application when performing a POST to the ShippingContainers-Closed resource.

 Request
  • URI: http://ServerName/outbound/ShippingContainers/ShippingContainers-Closed
  • Method: POST
  • Content-Type: application/json or application/xml
  • Entity: application/vnd.manh.ils.shipping.ShippingContainerClosedRequest+json, xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200

OK will be accompanied by an entity that represents the successfully closed shipping container: application/vnd.manh.ils.shipping.shippingContainer+json, xml

Note that certain soft warning/information messages may be returned in the response (message, messageCode fields), even when the shipping container is closed successfully.
400

The following ErrorTypes can be expected: Container, Warehouse, Weight

The following ErrorCodes can be suppressed upon resubmit:

  • MSG_WEIGHTOLERANCE: Returned when a change in weight now exceeds the container type's tolerance.  Suppress using SuppressWeightToleranceValidation.
  • MSG_CHGTRACKINGNUM: Returned when a previously manifested FedEx container should be re-manifested, but the user's Packing Preferences are not configured to Auto Manifest At Close.  Suppress using SuppressRemanifestFedExContainerValidation, which will also force the re-manifest.
  • MSG_ZEROWEIGHTVER: Returned when a weight of zero is specified.  Suppress using SuppressZeroWeightValidation.
  • MSG_OVERRIDEVAS01: Returned when VAS activity is pending for a container and user's Packing Preference allows overriding the warning.  Suppress using SuppressVasConfirmationValidation.
