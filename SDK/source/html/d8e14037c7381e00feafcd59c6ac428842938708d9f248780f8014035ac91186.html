How to: Bind Detail Controls
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Detail Pages > How to: Bind Detail Controls

Individual controls on a Detail page are bound to properties on the returned NHibernate entity by specifying the NHibernate property in the DATA_SOURCE column of the SCREEN_CONTROL table along with the appropriate DATA_SOURCE_TYPE.

 Step 1: Find the SCREEN_CONTROL record for the control

Select the SCREEN_CONTROL record for the control you are working with. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find SCREEN_CONTROL record
Copy Code 
select * from SCREEN_CONTROL where CONTROL_NAME = <control name>

 Step 2: Update the DATA_SOURCE and DATA_SOURCE_TYPE fields

To add a binding or change the binding on the control, simply update the DATA_SOURCE and DATA_SOURCE_TYPE fields accordingly. The DATA_SOURCE field must be filled with an NHibernate property, which is generally the database field name minus the underscores, with the first letter and each letter after the underscores capitalized and all other letters lower case (it is case sensitive). For example, the SHIPMENT_ID database column would be ShipmentId on an NHibernate entity. The DATA_SOURCE_TYPE is filled with one of the identifiers from the "Metadata data source type" configuration. For example, to bind an editor on a Detail page to the SHIPMENT_ID column, set the control to have DATA_SOURCE = 'ShipmentId' and DATA_SOURCE_TYPE = 20 (Data-bind attribute). Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Modify DATA_SOURCE and DATA_SOURCE_TYPE columns
Copy Code 
update SCREEN_CONTROL set DATA_SOURCE = '<new NHibernate property name>', DATA_SOURCE_TYPE = 'new data source type>'
where CONTROL_NAME = <control name>
