Notifications > Extensibility

The base product comes with notification capability from certain fixed functionality like Personal alerts. However, there might be a need to support more real time notifications from other parts of the system. The framework is capable of processing and delivering notifications as long as some custom code (possibly exit point programs), database triggers or stored procedures are able to insert the Notification_Message record, properly linked to relevant Notification configurations.
