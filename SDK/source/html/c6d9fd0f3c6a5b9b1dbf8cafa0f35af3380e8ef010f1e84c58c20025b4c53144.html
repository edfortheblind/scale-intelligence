All new SCALE screens are written as web pages that are fully extensible via metadata. This page serves as a general starting point for metadata screen extensibility.

 Architecture

Please reference the Metadata Page Architecture and Complex Page Architecture topics for page architecture, metadata structure, and a glossary of terms.

 Frameworks/Patterns

There are 5 different frameworks (or patterns) available in SCALE currently:

 

  • Insight: Insight screens provide the ability to filter and display data and then take action agains the resulting records. These screens are generally equivalent to Viewers or Explorers in the desktop application. Insight screens consist of a Search Pane (used for specifying filters), a List Pane (displays resulting records based on filters), and a Detail Pane (displays additional information for a record selected in the grid in the List Pane).

  • Monitor: Monitor screens provide the ability to display drill-down charts and tiles for high level information. The drill-down on these screens always have an ultimate destination of some other Insight screen that will show the data filtered by the Monitor screen.

  • Details: Details screens provide standard CRUD (create, read, update, delete) operations for various tables in the application.

  • Transaction: Transaction screens are more dynamic and generally represent some function in the system (i.e. Close Container, Transfer Container, etc.).

  • Complex screen: Complex screens are more dynamic, transactional, and generally represent complex functions in the system (i.e. Packing, QC, etc.). The list of complex screens can be found under <install directory>/web/dist.
