Shipping Web Services
View with Navigation Tools

The following web services are all related to the Shipping functional area of the application:

Web Service Description
Address Validation Invokes Address Validation for a single address or a list of addresses.
Close Container Invokes Close Container for a single shipping container.
Force QC Allows a consumer to pass QC for a Shipping container without actually verifying the item contents.
Immediate Dock Transfer Immediately transfers a shipping container between shipping dock locations without creating dock management work.
Multi Order Pallet Immediate Dock Transfer Allows for the immediate transfer of a multi order pallet between shipping dock locations.
Multi Order Pallet Nesting Provides the ability to nest a shipping container on a multi order pallet.
Multi Order Pallet Unnesting Provides the ability to unnest a shipping container from a multi order pallet.
Pallet Building Builds Pallets for a wave or a list of Shipping Containers.
QC Assignment Invokes QC assignment on a list of Shipping Containers.
QC Confirmation Invokes QC confirmation for contents of a Shipping Container.
Rating Calculates freight rates for a shipment
Rate Shopping Invokes Rate Shopping.
Shipping Allows access to links (URL or URI template) to web services related to shipping.
Shipping Container Allows access to a Shipping Container.
VAS Confirmation Invokes VAS confirmation of a list of activities for a list of Shipping Containers.
