How to: Create Screen Parts
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Create Screen Parts

Screen parts simply represent a portion of an overall web page. Screen parts are represented by the SCREEN_PART database table. There can be 1-N screen parts (ordered by SEQUENCE field) for a particular page. Screen parts are tied to screens through the MAIN_UI_SCREEN table (SCREEN_PART.SCREEN_ID = MAIN_UI_SCREEN.OBJECT_ID).

 Step 1: Determine the Object Id for the screen

Use the following SQL to determine the Object Id for the screen if you know the Form Id. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find the Object Id for screen
Copy Code 
select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>
 Step 2: Create screen part record

Create a new record in the SCREEN_PART table tied to the corresponding MAIN_UI_SCREEN record for the page. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Description/Notes
PART_NAME The name of the screen part. For insight screens, the search pane must be named "SearchPane", the list pane must be named "ListPane", the detail pane must be named "DetailPane".
RESOURCE_KEY The resource key of the text to show for the screen part, if any.
PART_TYPE The type of the part. Please see the "Screen Part Type" configuration for an enumeration of all screen part types.
SEQUENCE Screen parts are rendered in sequence order.
DEFAULT_ACTION The button or link that should be triggered when the Enter key is pressed and focus is in a control within this screen part. Please see the How to: Set Default Action for Enter Key topic for more details.
DIV_CSS_CLASS Used to configure the layout of the screen part. Please see the How to: Configure Layout of Metadata Pages topic for more details.
PARTIAL_VIEW Whether the screen part should be rendered as a partial view. Currently only Modal Dialogs support partial views.
       
Please note that the dbc_IScreenPart stored procedure can be used to create screen parts.
