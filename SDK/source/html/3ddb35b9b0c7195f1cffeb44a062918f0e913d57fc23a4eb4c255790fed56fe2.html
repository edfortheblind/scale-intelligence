How to: Configure Critical Level on Indicator Tile
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Monitor Pages > How to: Configure Critical Level on Indicator Tile

If Action Tile data meets Caution criteria or Warning criteria  then tiles change the color to indicate the critical level for that Action Tile.

Follow the below steps to enable Critical level on an Action Tile.

 Step 1: Create required screen control attribute for Action Tile
Create the below Action Tile attributes to enable critical level. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
Critical Level Attribute Name Attribute Value

Caution

data-actionTileCautionCriteria

For example, the "data-actionTileCautionCriteria" attribute for the At Risk Work  Action Tile is set to ">=30"

Warning

data-actionTileWarningCriteria

For example, the "data-actionTileCautionCriteria" attribute for the At Risk Work  Action Tile is set to ">40"

   

 Step 2: Modify Action Tile stored procedure

Update the configured Action Tile  stored procedure to return value for Caution and Warning for each Action Tile.

To achieve this function fn_GetCriticalLevel should be called from stored procedure.

For example, stored procedure WRK_MonitorWorkGroupActionTile that returns data for the At Risk Work Action Tile returns values for Caution and Warning critical level.

IF(@actionTileName = N'ActionTileAtRiskWork')
BEGIN

SELECT TOP 1 N'ACTIONTILE_ATRISKWORK' AS N'ACTIONTILE_ATRISKWORK', COUNT(DISTINCT WORK_UNIT) AS N'AT_RISK_WORK' ,
'CAUTION' = (SELECT dbo.fn_GetCriticalLevel(@cautionCriteria, COUNT(DISTINCT WORK_UNIT))),
'WARNING' = (SELECT dbo.fn_GetCriticalLevel(@warningCriteria, COUNT(DISTINCT WORK_UNIT))) 
FROM WORK_INSTRUCTION WHERE (FROM_WHS =@warehouse) AND CONDITION IN (N'OPEN', N'IN PROCESS') AND AGING_DATE_TIME > DateAdd(DAY, -1, GETDATE())

END
