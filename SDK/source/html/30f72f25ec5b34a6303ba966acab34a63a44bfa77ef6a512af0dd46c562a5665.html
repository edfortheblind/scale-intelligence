How to: Extract values from Xml through SQL
View with Navigation Tools

The following utility SQL function and stored procedure have been provided with the product to help extract values from Xml parameters in SQL Stored procedures. Typically these xml parameters represent viewer action endpoint data and complex data passed to exit points.

 Sql Function : GetActionEndPointXMLValues

This function can be used to extract row data for viewer/personal views gadget Action endpoints, and expects input XML (@endpointData) conforming to GenericViewerEndPointData.xsd format only.

Internally, it takes the values of child elements under the xpath 'GenericViewerEndpointData/GenericViewerDataRows/GenericViewerDataRow/GenericViewerDataColumns/GenericViewerDataColumn' from the xml and returns it in a table format so that it can be easily processed in raw SQL. The returned table contains the following columns:- 

       'ID' - the generated primary key,
       'Name' - the column name from the viewer/personal views grid,
       'Value' - the cell value,
       'ViewerRowID' - the index of the rows (selected on the grid).

 

Here is an example of a stored procedure invoked from action endpoint which uses GetActionEndPointXMLValues sql function. Functionally, its job is to reset status of DIF Outgoing message and log Process history for the action.

DIF - Reset Outgoing Message : Viewer action
Copy Code 
CREATE PROCEDURE AEP_DIFResetOutgoingMessage
(
@session XML,
@endpointData XML
)
AS
BEGIN
  DECLARE @tmp table
  (
  Name NVARCHAR(max),
  Value NVARCHAR(max),
  ViewerRowID INT
  )

  DECLARE @userStamp NVARCHAR(MAX)
  EXEC GetXMLAttributeValueByAttributeName @session,'Session/User',@userStamp OUTPUT

  INSERT INTO @tmp
      SELECT Name,value,ViewerRowID FROM GetActionEndPointXMLValues(@endpointData)

  UPDATE DIF_OUTGOING_MESSAGE
    SET STATUS='Ready', DATE_TIME_STAMP=GETDATE()
    WHERE MSG_ID IN (SELECT value FROM @tmp WHERE NAME='MSG_ID')

  DECLARE @Warehouse NVARCHAR(max)
  EXEC GetXMLAttributeValueByAttributeName @session,'Session/CurrentWarehouse',@Warehouse OUTPUT
　
  EXEC HIST_SaveProcHist 'Action End Point','DIF Outgoing Message',null,null,null,null,
                     'Manually Reset','Action End Point',@userStamp,@Warehouse,'Y'
END

 

 

 Sql Stored Procedure :GetXMLAttributeValueByAttributeName

This stored procedure can be used to extract specific element values from the action endpoint data and exitpoint xml parameters.

It expects the following parameters:-

       @xml            - XML - indicates the xml data
       @nodeXpath  - NVARCHAR(MAX) - indicates the path of the element whose value is desired

       @nodeValue  - NVARCHAR(MAX) OUTPUT - returns the attribute value.  

       @xmlnsDeclarations NVARCHAR(MAX) - The full list of xml namespace declarations (if any). This is an optional parameter. See msdn.microsoft.com/en-us/library/ms177400.aspx for syntax for @xmlnsDeclarations. See below for an example.

Here is an example of a simple stored procedure representing an exitpoint which leverages the GetXMLAttributeValueByAttributeName utility stored procedure. It also shows how to use raw sql to extract warehouse data from Session xml.

Shipment Creation - Before : Exit point program
Copy Code 
CREATE PROCEDURE EXP_ShipmentCreationBefore
(
  @SESSIONVALUE xml,
  @SHIPMENTHEADERDO XML,
  @RETURNVALUE NVARCHAR(max) OUTPUT
)
AS
BEGIN 
 DECLARE @shipmentId NVARCHAR(MAX)
 EXEC GetXMLAttributeValueByAttributeName @SHIPMENTHEADERDO,'ShipmentHeaderDO/shipmentId',
       @shipmentId OUTPUT

 DECLARE @country NVARCHAR(MAX)
 EXEC GetXMLAttributeValueByAttributeName @SHIPMENTHEADERDO,'ShipmentHeaderDO/customerCountry',
       @country OUTPUT

 DECLARE @postalCode NVARCHAR(max)
 SELECT @postalCode = C.value('(customerPostalCode)[1] ', 'nvarchar(MAX)')
 FROM @SHIPMENTHEADERDO.nodes('ShipmentHeaderDO') AS T(C);

 IF (@shipmentId IS NOT NULL AND @country <> 'US' AND @postalCode IS NOT NULL)
     BEGIN
       SET @RETURNVALUE='MSG_GEN016' -- ERROR:Postal code should not be specified
     END
END

Sample Stored Procedure for extracting attributes using the optional @xmlnsDeclarations parameter 
Copy Code 
CREATE PROCEDURE [dbo].[EXP_ShipConfirmationBefore] (
    @SESSIONVALUE xml,
    @SHIPCONFIRMATIONBEFOREXML xml,
    @RETURNVALUE nvarchar(max) output
)
AS 
  SET NOCOUNT ON; 
  declare @internalShipmentNum nvarchar(100)
  declare @userName nvarchar(100)
 
  EXEC GetXMLAttributeValueByAttributeName @SHIPCONFIRMATIONBEFOREXML, 'IntegrationPointData/Body/InternalShipmentNum', @internalShipmentNum OUTPUT , 
    'default ''http://www.manh.com/ILSNET/ExitPoints/ShipConfirmationBeforeRequest'' , ''http://www.manh.com/ILSNET/General/Session'' as session'
  EXEC GetXMLAttributeValueByAttributeName @SHIPCONFIRMATIONBEFOREXML, 'IntegrationPointData/Header/Session/session:UserName', @userName OUTPUT , 
    'default ''http://www.manh.com/ILSNET/ExitPoints/ShipConfirmationBeforeRequest'' , ''http://www.manh.com/ILSNET/General/Session'' as session'
  update SHIPMENT_HEADER
    set USER_DEF1 = 'Confirmed', USER_STAMP = @userName
    where INTERNAL_SHIPMENT_NUM = @internalShipmentNum
