How to Change the Days Viewed for a Calendar
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to Change the Days Viewed for a Calendar

The views in the calendar can be customized to show a particular number of days. This is controlled by a set of screen control attributes linked to the calendar control.

This attribute should be created or modifed in the metadata for the calendar control within the SCREEN_CONTROL_ATTRIBUTES table.

Before customizing the calendar it is recommended that a copy of the screen is created using the Insight Architect to ensure changes are saved for future upgrades. During upgrades the metadata changed below will be overwritten and changes may be lost.

 

 Modify the calendar control to include three days view

SCALE is shipped with default day view and seven days view. The below steps will show how to add a three days view to the calendar

 Step 1: Find the SCREEN_CONTROL record for the calendar in the transaction screen

Use the following SQL statement to locate the calendar using the corresponding Form Id. Insight Architect can also be used for this How to: Use Insight Architect to Customize a Metadata Page.

Find calendar control record
Copy Code 
select * from SCREEN_CONTROL where CONTROL_TYPE = '370' and SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))
 Step 2: Add three day view to the calendar header

The header attribute in the controls what buttons appear in the header of the calendar along with their location. Use the following SQL statement to modify the header attribute to add a new three days button to the right side of the header. Insight Architect can also be used for this How to: Use Insight Architect to Customize a Metadata Page.

Modify header attribute
Copy Code 
update SCREEN_CONTROL_ATTRIBUTES set ATTRIBUTE_VALUE = '{left: ''today prev,next'',center: ''title'',right: ''timelineDay,timelineSevenDays,timelineThreeDays''}'
where SCREEN_CONTROL_ID = <control id of calendar> and ATTRIBUTE_NAME = 'header'
 Step 3: Add the number of days that should be displayed when selecting the new button

The views attribute specifies the number of days to be used for the view (button defined above). Use the following SQL statement to modify the view attribute to include the three days view. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Modify views attribute
Copy Code 
update SCREEN_CONTROL_ATTRIBUTES set ATTRIBUTE_VALUE = '{timelineThreeDays:{type: ''timeline'',duration: { days: 3 }}, timelineSevenDays:{type: ''timeline'',duration: { days: 7 }}}'
where SCREEN_CONTROL_ID = <control id of calendar> and ATTRIBUTE_NAME = 'views'
 Step 4: Add a resource key for the button text

The text displayed on the new view should be specified through buttonTextForViews attribute. Use below SQL to include a resource key for the three days button. Insight Architect can also be used for this How to: Use Insight Architect to Customize a Metadata Page.

Modify buttonTextForViews attribute
Copy Code 
update SCREEN_CONTROL_ATTRIBUTES set ATTRIBUTE_VALUE = 'timelineSevenDays: ''SEVENDAYS'',timelineThreeDays: ''THREEDAYS'''
where SCREEN_CONTROL_ID = <control id of calendar> and ATTRIBUTE_NAME = 'buttonTextForViews'

Also, make sure this new resource exists in the system using the system text editor.

 

After all steps run the reset.bat found in the <Install dir>\Utility folder. Then use CTRL+F5 to refresh the page. The new button should appear in the calendar header.
