How to: Default the Group By Column in a Grid

 Defaulting group by columns within a grid

Grids store column grouping information on a user/browser/device basis and remember these settings. However, grids can also be configured to have default group by columns which apply until the first time a user groups by a column from within the grid itself.

 Find the appropriate screen control grid column record for the default grid group by column

Use the following SQL to determine the Object Id for the screen control grid columns that are stored in the grid if you know the Form Id. This will return all screen control grid columns and you will need to find the appropriate column from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find existing screen control grid columns
Copy Code 
select * from SCREEN_CONTROL_GRID_COLUMNS where SCREEN_CONTROL_ID IN (
    select OBJECT_ID from SCREEN_CONTROL where SCREEN_GROUP_ID in (
        select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
            select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
                select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>))))

If there are any records that have a SQL_CLAUSE_TYPE = 50 (Group By - Within Control), then there are already default group by columns on the grid. Once these records are found, you can either update those records or create new ones to get the correct group by columns.

 Update or insert screen control grid columns for the default group by order

If records already exist, the default group by can be changed by simply changing the FIELD to a new value. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Updating sort order
Copy Code 
update SCREEN_CONTROL_GRID_COLUMNS set FIELD = '<new group by column>' where OBJECT_ID = <object id>

If no records exist, or you need to add new columns to the existing group by columns, then create a new SCREEN_CONTROL_GRID_COLUMNS record. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_ID The Object Id of the grid control
FIELD The column name to group by
FIELD_NAME NULL
FIELD_WIDTH NULL
FIELD_TYPE NULL
SQL_CLAUSE_TYPE 50 (Group By - Within Control)
SEQUENCE Use this field to determine the order of the default group by columns
RESOURCE_KEY NULL
HIDDEN N
DECIMAL_POSITIONS NULL
 Defaulting group by columns within a query

The search queries that are executed from insight screens can also be defaulted to "group by" a column. In this scenario, the resulting records are grouped within the query itself, before the data is ever sent to the grid (and therefore there is no resulting "grouping" in the grid itself).

 Find the appropriate screen control grid column record for the default query group by column

Use the following SQL to determine the Object Id for the screen control grid columns that are stored in the grid if you know the Form Id. This will return all screen control grid columns and you will need to find the appropriate column from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
