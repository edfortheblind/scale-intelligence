How to: Add a Grid to a Detail/Transaction Screen
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Detail Pages > How to: Add a Grid to a Detail/Transaction Screen

The grid on detail or transaction screen is a screen control along with some other special metadata records defining the grid contents. Follow the below mentioned steps to add a grid to a detail or transaction screen.

 Step 1: Create a screen group to house the grid 

Add a SCREEN_GROUP record as follows in order to create a to hold the grid. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the Data Pane
GROUP_NAME Provide Group Name
RESOURCE_KEY NULL
GROUP_TYPE 60(Panel)
PARENT_GROUP_ID Set this to the Object Id of this screen group record once it is created
NESTED_GROUP_UNIT Set this to the Object Id of this screen group record once it is created
DIV_CSS_CLASS row ScreenGroupPanel
ROW_CSS_CLASS cruddetaildatapanel
 Step 2: Create a screen group column 

Add a SCREEN_GROUP_COLUMN record as follows in order to create a column in screen group which intern hold the grid. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID Set this to the Object Id of this screen group record
COLUMN_NAME Provide Column Name
COLUMN_CSS_CLASS col-lg-12 col-md-12 col-sm-12 col-12 cruddatapaneheaderrowcolumn
 Step 3: Create grid screen control

Now add a SCREEN_CONTROL record as follows for the grid. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the panel that will hold the grid
CONTROL_NAME Provide Control Name
RESOURCE_KEY NULL
CONTROL_TYPE 20(Grid)
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE 90(Details Grid)
DATA_SOURCE NULL
DIV_CSS_CLASS listpanedatagrid
CONTROL_CSS_CLASS NULL
SCREEN_GROUP_COLUMN_ID Set this to the Object Id of this screen group column record
 Step 4: Create model class for grid

Please reference the How to: Create the Grid Model for instructions.

 Step 5: Create required screen control attributes for grid

One SCREEN_CONTROL_ATTRIBUTES record needs to be created in order to tie the grid to a database table or view. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
ATTRIBUTE_NAME data-dbtable
ATTRIBUTE_VALUE The name of the database table or view for the grid
SCREEN_CONTROL_ID The Screen Control Id of the grid
IS_CONTROL_PROPERTY N


Another SCREEN_CONTROL_ATTRIBUTES record needs to be created in order to tie the grid to the model class. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
ATTRIBUTE_NAME data-modelclass
ATTRIBUTE_VALUE The namespace and class for model (i.e. General.Mvc.Models.Detail.ShipmentDetailsCrudGridModel)
SCREEN_CONTROL_ID The Screen Control Id of the grid
IS_CONTROL_PROPERTY N
 Step 6: Create screen control grid columns
Please reference the How to: Create Screen Control Grid Columns topic for instructions.
