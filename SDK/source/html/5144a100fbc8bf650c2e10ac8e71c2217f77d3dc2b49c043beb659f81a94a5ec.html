Outbound Work Workflow
View with Navigation Tools
Integration Services > REST-Based Web Services > Work Web Services > Outbound Work Workflow

When using Web services for outbound work execution, an order needs to be maintained in the custom code. This order is significant to have the behavior similar to RF or full screen work execution.

To start with, assign the work unit to the user using the Assign Work Web Service. Then this work will not be accessible to any other user till it is unassigned. On Success, it will give the list of open work instructions and by default each instruction with have Links for Confirm and Pick work execution.

Execute the work. From the response of the Assign Work Web Service you could build the request object to execute the work

If the current user needs to be unassigned or work needs to be passed for some reason use Unassign Web Service. This web service could be invoked in case of any exceptions during the entire flow as well.
