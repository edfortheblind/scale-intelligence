How to: Add List Pane Menu Options
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > List Pane > How to: Add List Pane Menu Options

Follow these steps to add the menu options that are standard for the list pane of insight screens, as well as new custom menu options.

 Step 1: Create required modal dialogs
If any actions on the insight screen will require input via modal dialogs, create them. Please reference the How to: Create a Dynamic Modal Dialog topic for more information.
 Step 2: Create new menu screen groups
       

Add a SCREEN_GROUP record as follows in order to create an actions menu for the list pane. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the Insight Menu pane
GROUP_NAME ListPaneMenu
RESOURCE_KEY NULL
GROUP_TYPE 70 (Menu)
PARENT_GROUP_ID NULL
NESTED_GROUP_UNIT Set this to the Object Id of this screen group record once it is created
DIV_CSS_CLASS nav nav-pills
ROW_CSS_CLASS row rowmenupanel


Add a SCREEN_GROUP record as follows in order to create a menu drop down for the list pane actions. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the list pane
GROUP_NAME ListPaneMenuActionDropdown
RESOURCE_KEY ACTIONS
GROUP_TYPE 80 (Menu Dropdown)
PARENT_GROUP_ID The Screen Group Id of the menu SCREEN_GROUP in the list pane
NESTED_GROUP_UNIT The Screen Group Id of the menu SCREEN_GROUP in the list pane
DIV_CSS_CLASS dropdown pull-right
ROW_CSS_CLASS NULL
 Step 3: Create screen control related records for each action

Please reference the following topics in the User Inteface Extensibility | Metadata Web Pages | Actions folder for more information on creating individual actions.

 Step 4: Create a new panel screen group to house export to excel action
   

Add a SCREEN_GROUP record as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

 

Field Value
SCREEN_PART_ID The Screen Part Id of the search pane
GROUP_NAME ListPaneMenuExportToExcelPanel
RESOURCE_KEY NULL
GROUP_TYPE 60 (Panel)
PARENT_GROUP_ID The Screen Group Id of the menu SCREEN_GROUP in the list pane
NESTED_GROUP_UNIT The Screen Group Id of the menu SCREEN_GROUP in the list pane
DIV_CSS_CLASS NULL
ROW_CSS_CLASS NULL
 Step 5: Create screen control related records for the "export to excel" action
        
 Create menu button screen control

Now add a SCREEN_CONTROL record as follows for the Menu Button control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the menu dropdown on the list pane
CONTROL_NAME ListPaneMenuExportToExcel
RESOURCE_KEY EXPORTTOEXCEL
CONTROL_TYPE 150 (Menu Button)
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE NULL
DATA_SOURCE NULL
DIV_CSS_CLASS pull-right menubutton
CONTROL_CSS_CLASS pull-right menubutton fa fa-file-excel-o excelIcon
TOOL_TIP_RESOURCE_KEY EXPORTTOEXCEL
 Create a screen control event record tied to the menu button control

Now add a SCREEN_CONTROL_EVENT record as follows for the Menu Button control. This defines what gets called when the button is clicked by the user. This action will call a pre-created JavaScript function that process the "export to excel" action on an insight screen. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_ID The Screen Control Id of the menu button
EVENT_ID click
EVENT_NAME _webUi.insightListPaneActions.exportButtonClicked
