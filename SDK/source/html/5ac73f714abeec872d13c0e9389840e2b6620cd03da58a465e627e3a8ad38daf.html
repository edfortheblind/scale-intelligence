How to: Manually Configure the Drilldown for a Dashboard Tile
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Transaction Pages > How to: Manually Configure the Drilldown for a Dashboard Tile

The drilldown for most Dashboard tiles can be configured directly from the Basic and Advanced grids located in the Gadget query calculation configuration. It is recommended to use the grids in the configuration if at all possible. However, at times it may be necessary to manually enter the parameters yourself by choosing the Customize parameter string option. This allows the parameters to be manually entered, which enables fields to be included multiple times (i.e. to form a "range") as well as other more advanced capabilities. This topic outlines the format of the parameters for drilldown on Dashboard tiles.

 

 Basic criteria

The basic criteria portion of the parameters has the following format:

filters=<Control Id> █<Value>

 

Use the ALT+219 █ character for the separator characters in the path as shown below.

 

Field Description
<Control Id> The id of the corresponding control in metadata on the Insight screen for the tile.
<Value> The value that the control should be filtered by on the Insight screen.

 

 Advanced criteria format

The advanced criteria portion of the parameters has the following format:

advancedFilters=<Database Column> █<Translated Text> █<Operand Identifier> █<Operand Text> █<Identifier> █<Description> █<Data Type>     

Field Description
<Database Column> The database column that should be filtered.
<Translated Text> The translated text for the database column name.
<Operand Identifier> The identifier for the operand as defined in the Metadata filter operand configuration.
<Operand Text> Optional. Only needs to be passed if the translated text for the operand needs to be different than the operand identifier.
<Identifier> The identifier for actual filtering (i.e. a description of "Yes" has an identifier of "Y").
<Description> The description for the identifier.
<Data Type> The data type for the column. Valid values are A (Alpha), N (Number), and D (Date and DateTime).

 

 Example

Below is an example of a parameter string for a tile that is tied to the Inventory Insight screen.

filters=SearchPaneWhs:MN,BasicCriteria-PermanentLocs:TRUE&advancedFilters=ALLOCATED_QTY █Allocated qty █50 █ █5 █5 █N

 

This example is translated to the following filters on the Inventory Insight screen:

  • Warehouse = MN
  • Only permanent locations = toggled ON
  • Allocated qty > 5
