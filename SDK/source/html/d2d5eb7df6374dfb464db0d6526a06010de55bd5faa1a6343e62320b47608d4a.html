How to: Go to Insight from Indicator Tile
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Monitor Pages > How to: Go to Insight from Indicator Tile

Clicking on an Action Tile will open the Insight screen in a new tab. Follow the below steps to enable clicking or tapping on an Action Tile.

 To enable clicking or tapping on an Action Tile, the "data-actionTileGoToInsight" attribute needs to be created for the action tile control. The value for this attribute should be in the following format. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

 Use the ALT+219 █ character for the separator characters in the path as shown below.

{{FORM_ID=<Form Id>}}?filters=<Control Name>█{{{Chart Field Name}}}

Field Description

Form Id

Defines the Insight screen Form Id.

Control Name

Defines the name of the control on the Insight screen search pane that this criteria applies to.

Chart Field Name

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

For example, the "data-actionTileGoToInsight" attribute for the Priority Work action tile is set to the following.

{{FORM_ID=2757}}?filters=SearchPaneWhs█{{{{FROM_WHS}}},SearchPaneAdvCrit_Field█{{{{WORK_GROUP}}},SearchPaneWrkTyp█{{{{WORK_TYPE}}},SearchPaneAdvCrit_Field█{{{{WORK_INSTRUCTION_PRIORITY}}}

Field Description

2757

Defines the Work Insight screen Form Id.

SearchPaneWhs

Defines the name of the control on the Insight screen search pane that FROM_WHS criteria applies to.

FROM_WHS

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

SearchPaneAdvCrit_Field

Defines the name of the control on the Insight screen search pane that WORK_GROUP criteria applies to.

WORK_GROUP

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

SearchPaneWrkTyp

Defines the name of the control on the Insight screen search pane that WORK_TYPE criteria applies to.

WORK_TYPE

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

The Insight screen search pane values populate based on both the action tile criteria and the current chart drill down level criteria.

For example, if the action tile criteria is FROM_WHS ='MN' and WORK_INSTRUCTION_PRIORITY<= 10, and the chart drill down level criteria is FROM_WHS ='MN' and WORK_GROUP='Picking', then when the user clicks or taps an action tile the system will open a new tab for Work Insight screen passing the search pane filters as: From Whs (FROM_WHS)='MN', Priority (WORK_INSTRUCTION_PRIORITY) <= 10, and Work Group (WORK_GROUP) = 'Picking'. 

For this the "data-actionTileGoToInsight" attribute value should be:

{{FORM_ID=2757}}?filters=SearchPaneWhs█{{{{FROM_WHS}}},SearchPaneAdvCrit_Field█{{{{WORK_GROUP}}}SearchPaneAdvCrit_Field█{{{{WORK_INSTRUCTION_PRIORITY}}}

Note: please refer to the  How to: Create Screen Control Attributes topic for more detailed information on screen control attributes.
