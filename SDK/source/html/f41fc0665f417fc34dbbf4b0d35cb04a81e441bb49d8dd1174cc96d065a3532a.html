How to: Create Screen Control Event Parameters
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Create Screen Control Event Parameters

Event parameters provide the ability to pass parameters to a function called by an event. These are represented by the SCREEN_CONTROL_EVENT_PARAMETERS database table. There can be 1-N event parameters for a particular control event. Event parameters are tied to events by the SCREEN_CONTROL_EVENT_ID field (SCREEN_CONTROL_EVENT_PARAMETERS.SCREEN_CONTROL_EVENT_ID = SCREEN_CONTROL_EVENT.OBJECT_ID).

Screen control event parameters are rendered via JQuery binding along with the actual event itself. In the example below, an event parameter called "ModalDialogName" is getting passed with a value of "SaveSearchModalDialog".

Event Parameters in HTML
Copy Code 
<script type="text/javascript">
    $(function () { if (typeof _webUi.dialog.showModalDialogByEvent === 'function') 
    {  $(document).delegate('#SearchPaneMenuActionSaveSearch', 'click',
    {'ModalDialogName' : 'SaveSearchModalDialog'} ,
    _webUi.dialog.showModalDialogByEvent)} })
</script>

 Step 1: Determine the Object Id for the screen control event

Use the following SQL to determine the Object Id for the screen control event if you know the Form Id. This will return all screen controls events on the page and you will need to find the appropriate screen control event from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

 

Find the Object Id for screen control event
Copy Code 
select * from SCREEN_CONTROL_EVENT where SCREEN_CONTROL_ID in (
    select OBJECT_ID from SCREEN_CONTROL where SCREEN_GROUP_ID in (
        select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
            select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
                select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>))))
 Step 2: Create screen control event parameters record

Create a new record in the SCREEN_CONTROL_EVENT_PARAMETERS table tied to the corresponding SCREEN_CONTROL_EVENT record. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Description/Notes
PARAMETER_NAME The name of the parameter to pass.
PARAMETER_VALUE The value for the parameter.

 

Please note that the dbc_IScreenControlEventParameters stored procedure can be used to create screen control event parameters.
