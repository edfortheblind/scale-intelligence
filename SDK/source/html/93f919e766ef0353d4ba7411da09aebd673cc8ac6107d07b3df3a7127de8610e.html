How to: Configure Item Images for Metadata screens
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Configure Item Images for Metadata screens

This topic will describe how to configure an item image and display it on a metadata screen.

The file paths in this topic refer to the default installation directory of SCALE on the application server. The files may be found in a different path on servers where the path was customized during installation.
 Step 1: Deploy the Image

The image first needs to be deployed to the Metadata Screen virtual directory  %SCALE_HOME%\web\content.

It is recommended that custom images are placed in a new location %SCALE_HOME%\web\content\manhcustom\images to ensure that custom images are not lost when SCALE is upgraded.

To deploy the image, copy to the %SCALE_HOME%\web\content\manhcustom\images directory. If the directory does not exist it will have to be created.

For example, if we were deploying an image named example.png, after the above step you would find it at this path: %SCALE_HOME%\web\content\manhcustom\images\example.png. 

See File Sharing Guide for further deployment options.
 Step 2: Configure the Web Thumbnail Image of the Item

In SCALE go the Item Configuration and open the record for the item.

On the Internet Information tab specify a Web Thumbnail Image

The Web Thumbnail Image value on the item configuration would then need to be set to /SCALE/Content/manhcustom/images/<image name>. Using our above image the item configuration would have a web thumbnail image value of /SCALE/Content/manhcustom/images/example.png.

Absolute URLs can be configured for the image paths.
 Step 3: Bind the Image to a Screen Control

Once the image is tied to the item configuration it can then be displayed on the metadata screens through metadata binding.

Add a SCREEN_CONTROL record as indicated below to add metadata for displaying an image on a metadata screen. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
CONTROL_NAME The name of the screen control.
RESOURCE_KEY NULL
CONTROL_TYPE 170 (image)
SEQUENCE Screen controls are rendered in a sequence order. This should be the next available sequence number.
DEFAULT_ACTION NULL
DIV_CSS_CLASS NULL
CONTROL_CSS_CLASS img-responsive
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE 20 (Data-bind attribute)
DATA_SOURCE WebThumbnailImage (Field from the item table to bind to)
DEFAULT_STATE NULL
TOOL_TIP_RESOURCE_KEY NULL

Please note the dbc_IScreenControl stored procedure can be used to create screen controls.

Please reference the How to: Create Screen Controls topic for more information on adding the screen control. Also reference the How to: Bind Detail Pane Controls topic for instructions on how to bind these controls with the values returned from the stored procedure or web service.
