How to: Customize the Single Signon Page
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Single Signon Page > How to: Customize the Single Signon Page

This topic will walk you through customizing the single signon page for Azure Active Directory or Active Directory Federation Services (ADFS).

 Customize Microsoft Entra ID Signon Page
  • Sign in to the Azure portal with an account that's a global admin for the directory.
  • Select More services, enter Users and groups in the text box, and then select Enter.
  • On the Users and groups blade, select Company branding.
  • Customize screens as required.
Note- Visit https://docs.microsoft.com/en-us/azure/active-directory/active-directory-branding-custom-signon-azure-portal for more info.
 Customize ADFS Signon Page
  • Logon to the ADFS server (must be Windows Server 2016).
  • Open Powershell as an administrator.
  • Customize the screens as required with Powershell commands as outlined at https://docs.microsoft.com/en-us/windows-server/identity/ad-fs/operations/ad-fs-user-sign-in-customization
