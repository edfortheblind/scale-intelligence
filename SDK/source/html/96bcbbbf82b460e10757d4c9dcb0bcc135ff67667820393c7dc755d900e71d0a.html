How to: Customize the Bill of Lading
View with Navigation Tools
Printing > SQL Server Reporting Service > How to: Customize the Bill of Lading

This topic will give information about how to control the number of Customer Order Information and Carrier Information rows displayed on the first and supplementary pages of the Bill of Lading.

 Modify the defaults on the first page of the Bill of Lading
The default number of records for the customer order information and carrier information sections on first page of the Bill of Lading should be modified. Currently the first page of the Bill of Lading has a maximum of 5 records for both the carrier information and the customer order information. To change this value, modify the TransformPageLevelData method in the BillOfLadingDataTransformationForSSRS class.
 Modify the defaults on supplemental pages of the Bill of Lading

The default number of records for the customer order information and carrier information sections on supplement pages of the Bill of Lading should also be modified. Currently supplement pages of the Bill of Lading has a maximum of 35 records for both the carrier information and the customer order information. There are two ways to change this value:


 Option 1: Use Visual Studio SQL Data Tools
  1. Open the report on a machine that has Visual Studio with SQL Data Tools installed.
  2. Open the project Reporting.rptproj.
  3. Open the design view of BillOfLadingSupplementPageSubReport report.
  4. Select the CarrierParent Tablix in the properties dropdown.
  5. At the bottom of the report you will see row groups and columns groups. In row group right click on details2 and select group property.
  6. This expression is dividing by 35 right now to get 35 records per supplement page.
  7. Modify this number value with the new max record count for the supplemental page.
  8. Save the report and upload to the SSRS server.See database install guide in help for how to upload report to SSRS server.
 Option 2: Use Notepad
  1. Open the BillOfLadingSupplementPageSubReport report in notepad.
  2. Find the expression Ceiling((RowNumber(Nothing)).
  3. This expression is dividing by 35 right now to get 35 records per supplement page.
  4. Modify this number value with the new max record count for the supplemental page.
  5. Save the report and upload to the SSRS server.See database install guide in help for how to upload report to SSRS server.
 How to customize Reports
BOL reports can be customized by passing the custom stored procedure name in data source query parameters in the reports. This allows to display the required elements in SSRS Reports.
The custom stored procedure can be called by a report during print preview, print selected, print default, and auto print.

To customize the reports, follow the below mentioned steps:

  1. Make sure custom stored procedure is available in database.
  2. Custom stored procedure can be passed into data source query parameters in the report (*.rdl file) as:

               <Parameter Name="storedProcedure">
                        <DefaultValue>CustomStoredProcedureForReports</DefaultValue>
                </Parameter>

  3. Dataset needs to be modified appropriately to match the results of stored procedure.
  4. The result of stored procedure execution will be used for displaying specific properties in the generated SSRS Reports.
