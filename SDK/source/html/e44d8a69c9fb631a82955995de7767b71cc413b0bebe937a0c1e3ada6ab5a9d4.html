Compression in REST-Based Web API Web Services
View with Navigation Tools

When building systems on top of web APIs, performance is critical. Compression is an easy and effective way to reduce the size and increase the speed of communication between a client and remote resource.

Two common compression algorithms used on the web are GZip and Deflate. The Accept-Encoding header is used by a client to restrict the encoding types that are acceptable in the response.

public class ApiCompressionMessageHandler : DelegatingHandler
    {
        public Collection<IApiCompressor> Compressors { get; private set; }
        #region ..ctor
        public ApiCompressionMessageHandler(
            GZipCompressor gZipCompressor,
            DeflateCompressor deflateCompressor)
        {
            Compressors = new Collection<IApiCompressor>();
            Compressors.Add(gZipCompressor);
            Compressors.Add(deflateCompressor);
        }
        #endregion
        /// <summary>
        /// Checks the Acccept Encoding and compresses the response based on the first supported encoding type
        /// </summary>
        /// <param name="request"></param>
        /// <param name="cancellationToken"></param>
        /// <returns></returns>
        protected async override Task<HttpResponseMessage> SendAsync
(HttpRequestMessage request, CancellationToken cancellationToken)
        {
            var response = await base.SendAsync(request, cancellationToken);
            if (request.Headers.AcceptEncoding.Count > 0 && response.Content != null)
            {
                var encoding = request.Headers.AcceptEncoding.First();
                var compressor = Compressors.FirstOrDefault
(c => c.EncodingType.Equals(encoding.Value, StringComparison.InvariantCultureIgnoreCase));
                if (compressor != null)
                {
                    response.Content = new ApiCompressedContent(response.Content, compressor);
                }
            }
            return response;
        }
    }

The ApiCompressionMessageHandler takes care of compressing responses based on the Accept-Encoding header supplied by the client.

The ApiCompressionMessageHandler has a collection of compressors that can be used to compress responses into different formats. By default it contains compressors for GZip and Deflate formats.

In the SendAsync method we get the response and check if the client accepts any of the encoding types supported by our Compressors. If so, we replace the response.Content with CompressedContent.

public class ApiCompressedContent : HttpContent
    {
        private readonly HttpContent content;
        private readonly IApiCompressor compressor;
        /// <summary>
        /// Compresses the content and adds the content encoding to the header
        /// </summary>
        /// <param name="content"></param>
        /// <param name="compressor"></param>
        public ApiCompressedContent(HttpContent content, IApiCompressor compressor)
        {
            this.content = content;
            this.compressor = compressor;
            AddHeaders();
        }
        /// <summary>
        /// Determines whether the HTTP content has a valid length in bytes
        /// </summary>
        /// <param name="length"></param>
        /// <returns></returns>
        protected override bool TryComputeLength(out long length)
        {
            length = -1;
            return false;
        }
        /// <summary>
        /// Serialize the HTTP content to a stream as an asynchronous operation
        /// </summary>
        /// <param name="stream"></param>
        /// <param name="context"></param>
        /// <returns></returns>
        protected async override Task SerializeToStreamAsync(Stream stream, TransportContext context)
        {
            using (content)
            {
                var contentStream = await content.ReadAsStreamAsync();
                await compressor.Compress(contentStream, stream);
            }
        }
        /// <summary>
        /// Adds the encoding type to the respone header.
        /// </summary>
        private void AddHeaders()
        {
            foreach (var header in content.Headers)
            {
                Headers.TryAddWithoutValidation(header.Key, header.Value);
            }
            Headers.ContentEncoding.Add(compressor.EncodingType);
        }
    }

The ApiCompressedContent class takes care of compressing the original content stream using the provided IApiCompressor instance. It also ensures that the correct Content-Encoding header is added to the response so that the client knows how to perform decompression.
