How to: Add a Summary Tile to an Insight List Pane
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > List Pane > How to: Add a Summary Tile to an Insight List Pane

Summary tiles provide a simple means to provide a description and a summary for a particular value. Summary tiles are bound with a data source type = 20 (DataBindAttribute) and a data source set to the returned json attribute that the tile should be bound to. For the summary tiles located in the list pane of an insight screen, the data source needs to be set to the actual column name the summary tile is for – this enables the insight screen to dynamically retrieve and bind these values when executing the filter statement. Any aggregate SQL function (sum, count, average, min, max, etc.) can be used to calculate a tile value. This can be configured by tying a screen control attributes record to the summary tile control with an attribute name = "data-aggregateClause". If no screen control attributes record is tied to a summary tile control, the system will default to a "count distinct" function for the field specified in the data source.

 Step 1: Create a panel screen group to house the summary tiles

Add a SCREEN_GROUP record as follows in order to create a panel to hold the summary tiles. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the list pane
GROUP_NAME ListPaneSummary
RESOURCE_KEY NULL
GROUP_TYPE 60 (Panel)
PARENT_GROUP_ID NULL
NESTED_GROUP_UNIT Set this to the Object Id of this screen group record once it is created
DIV_CSS_CLASS listpanesummarypanelgroup equalize
ROW_CSS_CLASS row listpanesummarypanel
 Step 2: Create summary tile screen control

Now add a SCREEN_CONTROL record as follows for the summary tile. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the panel that will hold the summary tile
CONTROL_NAME The name of this summary tile control
RESOURCE_KEY The resource key for the top label in the summary tile
CONTROL_TYPE 50 (Summary Tile)
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE 20 (DataBindAttribute)
DATA_SOURCE The column name from the database table or view that value will be calculated from. This ties to the FIELD_NAME column in the SCREEN_CONTROL_GRID_COLUMNS table for the corresponding grid in the list pane.
DIV_CSS_CLASS panesummarytile col-3 col-sm-3 col-md-3 col-lg-3 (please note this can change based on the number of summary tiles that will be shown together, but 4 tiles are recommended for optimal spacing)
CONTROL_CSS_CLASS NULL
 Step 3: Create required screen control attributes for summary tile

One SCREEN_CONTROL_ATTRIBUTES record needs to be created if an aggregate function other than "count distinct" will be used. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
ATTRIBUTE_NAME data-aggregateClause
ATTRIBUTE_VALUE Aggregate clause other than the default "count distinct" (e.g. sum(TOTAL_LINES))
SCREEN_CONTROL_ID The Screen Control Id of the grid
IS_CONTROL_PROPERTY N
