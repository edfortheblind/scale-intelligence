How to: Add a New Section to an Accordion
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Add a New Section to an Accordion

An accordion control is defined by multiple levels of screen groups. The top level screen group represents the overall accordion control. The level directly below that represents the individual accordion sections (sub-accordions). In order to add a new sub-accordion to an existing accordion, follow these steps.

 Step 1: Find the Object Id for the parent accordion screen group

Use the following SQL to find the accordion where the sub-accordion will be added. This SQL will find all accordions on the page - pick the correct group from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find the Object Id for parent accordion
Copy Code 
select * from SCREEN_GROUP where GROUP_TYPE = '40' and SCREEN_PART_ID IN (
    select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
        select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>))
 Step 2: Create sub-accordion screen group record
Create a new child record in the SCREEN_GROUP table tied to the corresponding header SCREEN_GROUP. Please see the How to: Create Screen Groups topic for details on creating screen groups. Make sure to set the GROUP_TYPE = "50" (sub-accordion) and the PARENT_GROUP_ID = <object id of parent accordion group>. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
