How to: Bind Controls on a Monitor Page

To bind a chart control on a Monitor Page, a stored procedure needs to be called via a built in web service. This web service returns the JSON which has the required data to bind the chart control on a Monitor page. Please follow the below steps to bind a chart control on a Monitor page.  Please follow the below steps to bind a chart control on monitor page.

 Step 1: Create Stored Procedure for Chart
A stored procedure must be created that will retrieve the chart data. The stored procedure should be named in the format <functional area>_Monitor<Description of what will be retrieved>. For example, if a Monitor page was going to be created for retrieving work related data based on work group, the stored procedure should be named WRK_MonitorWorkGroupChartData. Please refer to the How to: Create Monitor Page Stored Procedure topic for more detailed information.        
 Step 2: Create required screen control attributes for Chart
Create the below Screen Control Attributes to bind a chart control on monitor page. Please refer to the How to: Create Screen Control Attributes topic for more detailed information on screen control attributes. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Description

data-monitorWebService

Defines the web service which returns the required information to a Monitor page for binding data to a chart control. This attribute value is "/general/scaleapi/GenericMonitorDataRetrievalApi/Post" and can be used for all charts.

data-chartType

 Defines the type of a chart. Currently supported value is "Column".

data-chartCategoryMaxCount

Defines the maximum value of the axis. This is an optional attribute and the default value is 10.

data-drilldownLevel0criteria

Defines filter criteria to retrieve data from the stored procedure. Each level can have one filter criteria with a list of comma delimited values with an ending semicolon.

data-drilldownLevel0storedprocedure

This attribute defines the stored procedure to call for the chart data. The stored procedure has two parameters: filterCriteria  and culture. Each drill down level in the chart has one stored procedure.
