Pallet Building Web Service
View with Navigation Tools

The Pallet building web services support the following operations. However, the application only invokes the "Pallet Building for Wave" operation during the Pallet Building Wave Step.

 Pallet Building for Wave

It takes a wave number and nests all applicable top-level containers into pallets, as directed by the Pallet Building Master linked to the Wave Master. This is achieved by the following steps:

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Build Pallets

The Shipping resource representation will include the link to the "Waved Shipping Containers-Palletized" collection resource. The link (rel="palletBuildingForWave") has a href with a URI template that has the {waveNumber} token. To build pallets for wave substitute the token and perform an HTTP POST using the following:

Request:

  • URI: From Shipping resource link (rel="palletBuildingForWave") href
  • Method: POST
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: none
  • Roles: SCALEUSER,Confidential

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200

OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.shipping.palletBuildingResponse+json, xml

Note that for performance reasons neither of the ContainerReferenceList fields are returned when requesting pallets using the wave number.
400

The following ErrorTypes can be expected: Container, Unknown

 Pallet Building for Container list

It takes a Pallet Building Master and a list of Shipping Containers and nests all applicable top-level containers into pallets, as directed by the Pallet Building Master. This is achieved by the following steps:

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Build Pallets

The Shipping resource representation will include the link to the "Shipping Containers-Palletized" collection resource. The link (rel="palletBuildingForContainerList") has a href with a URI template that has the {palletBuildingMaster} token. To palletize the given containers substitute the token and perform an HTTP POST using the following:

Request:

  • URI: From Shipping resource link (rel="palletBuildingForContainerList") href
  • Method: POST
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: application/vnd.manh.ils.shipping.ContainerReferenceList+json, XML
  • Roles: SCALEUSER,Confidential

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200

OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.shipping.palletBuildingResponse+json, xml

Contains a ContainerReferenceList tree structure showing the new pallets and which containers are nested in each, and a ContainerReferenceList of any containers that did not get nested.
400

The following ErrorTypes can be expected: Container, Unknown
