Force QC Web Service
View with Navigation Tools

The Force QC web service allows a consumer to pass QC for a Shipping container without actually verifying the item contents.  This is achieved by executing the following steps:

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Retrieve the ShippingContainer using its link

The Shipping resource representation will include the link to the Shipping Containers Resource. The link (rel="shippingContainer") has a href that is a URI template with the {warehouse} and {containerId} tokens.  To fetch the Shipping Container representation, substitute the tokens and perform an HTTP GET:

How to: Shipping Container Web service

 Step 3: Update the ShippingContainer using its self link

The Shipping Container representation will include a self link. To do a Force QC Confirmation set the QcStatus field to 3 (Complete) on the shipping container representation and perform an HTTP PUT with the following:

Request:

  • URI: From ShippingContainer's link (rel="self") href
  • Method: PUT
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: The updated ShippingContainer from Step 2
  • Roles: SCALEUSER,Confidential

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
