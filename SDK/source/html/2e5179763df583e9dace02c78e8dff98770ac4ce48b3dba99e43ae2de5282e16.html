How to: Change Displayed Language
View with Navigation Tools

There seems to be some confusion in regards to how our product retrieves the culture settings from Windows in order to configure numbers, dates, and resources. This article is a refresher which explains how each different aspect of our product retrieves the culture information.

 Main Application
The Main Application uses the Windows Regional Settings to decide what culture the application should be run in. The steps for configuring this are below:

  1. Access the Windows Control Panel (Start | Control Panel).
  2. Access the Regional and Language Options screen.
  3. On the Regional Options Tab, select a language and press OK.
 Trading Partner Management
TPM does not use the Regional Settings from Windows to determine what culture should be displayed. It instead uses a language configured on the web user configuration of the application. The steps for configuring this are below:

  1. Open the Configurations Explorer, and access the Web User Window.
  2. Open the web user profile record that you want to select a language for, and select the General Tab.
  3. Use the Language Selection Field to indicate which language you want the system to use when displaying text on the web windows.
  4. Press OK. The system will save the record.
 RF
RF does not use the Regional Settings from Windows to determine what culture should be displayed. Instead it uses the language settings of Web Browser (Internet Explorer) to determine which culture to use. The steps for configuring this are below:

  1. Open Internet Explorer.
  2. Go to Tools/Internet Options
  3. Click on the Languages button. The window should look like this:



  4. Click on the add button and then choose the language you would like to add:
