How to: Set Template Name for a Screen Control
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Set Template Name for a Screen Control

Templates are used to move complex and recurring html out of metadata and into a partial view.

 Setting template name on a new control when metadata is created

In order to set the template name on a control as it is being created from metadata, simply set the TEMPLATE_NAME on the control.

 

 Modifying the template name for an existing control

In order to change an existing control to have a different template name , first find the Object Id of the control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find Object Id of control
Copy Code 
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (select * from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))

 

Then update the TEMPLATE_NAME field accordingly. Please see below for the "template naming convention" for how to set this value. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Modifying template name on control
Copy Code 
update SCREEN_CONTROL set TEMPLATE_NAME = 'XYZ-2' where OBJECT_ID = <object id>
 Template naming convention

Templates should be named in the format template_name-{number of controls in template} = partial view name . For example: _MetaControlRow-2 is a template with 2 controls in it.The partial views should be saved in  ~Views\Shared\Template.

Example of _MetaControlRow-2
Copy Code 
<div class='row ScreenGroupPanel'>
    <div class='col-lg-4 col-md-4 col-sm-4 col-4 cruddatapanedetailrowcolumn'>{{Control1}}</div>
    <div class='col-lg-8 col-md-8 col-sm-8 col-8 cruddatapanedetailrowcolumn'>{{Control2}}</div>
</div>
