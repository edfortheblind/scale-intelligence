Inventory Transactions Web Service
View with Navigation Tools

The Inventory Transactions operation performs inventory adjustments or transfers. Work is created based on WorkCreationMode flag set on the InventoryTransactionRequest

 Request
  • URI: http://ServerName/Inventory/InventoryTransactions/inventoryTransactions
  • Method: POST
  • Content-Type: application/json or application/xml
  • Entity: JSON, XML
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity that contains a result message, the list of failed and/or successful transactions, and possibly an error message: JSON, XML
400

The following ErrorCodes can be expected and can be suppressed upon resubmit:

  • MSG_INVVAL40: Returned when the unit of measure overrides differ between the from location and the destination location. Suppress using SuppressUMOverrides.
  • MSG_INVVAL41: Returned when the unit of measure overrides at the destination location will be created from the overrides existing at the transfer location. Suppress using SuppressUMOverrides.
