How to: Add a Grid to an Insight List Pane
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > List Pane > How to: Add a Grid to an Insight List Pane

The main grid on an insight list pane is a screen control along with some other special metadata records defining the grid contents. Follow the below steps to add a main grid to an insight page list pane.

 Step 1: Create a panel screen group to house the grid 

Add a SCREEN_GROUP record as follows in order to create a panel to hold the grid. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the list pane
GROUP_NAME ListPanePanel
RESOURCE_KEY NULL
GROUP_TYPE 60 (Panel)
PARENT_GROUP_ID NULL
NESTED_GROUP_UNIT Set this to the Object Id of this screen group record once it is created
DIV_CSS_CLASS NULL
ROW_CSS_CLASS row listpanepanel
 Step 2: Create grid screen control

Now add a SCREEN_CONTROL record as follows for the grid. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the panel that will hold the grid
CONTROL_NAME ListPaneDataGrid
RESOURCE_KEY NULL
CONTROL_TYPE 20 (Grid)
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE NULL
DATA_SOURCE NULL
DIV_CSS_CLASS listpanedatagrid
CONTROL_CSS_CLASS NULL
 Step 3: Create required screen control attributes for grid

One SCREEN_CONTROL_ATTRIBUTES record needs to be created in order to tie the grid to a database table or view. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
ATTRIBUTE_NAME data-dbtable
ATTRIBUTE_VALUE The name of the database table or view for the grid
SCREEN_CONTROL_ID The Screen Control Id of the grid
IS_CONTROL_PROPERTY N


Another SCREEN_CONTROL_ATTRIBUTES record needs to be created in order to tie the grid to the model class. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
ATTRIBUTE_NAME data-modelclass
ATTRIBUTE_VALUE The namespace and class for model (i.e. General.Mvc.Models.Insight.InventoryGridModel)
SCREEN_CONTROL_ID The Screen Control Id of the grid
IS_CONTROL_PROPERTY N
 Step 4: Create screen control grid columns
Please reference the How to: Create Screen Control Grid Columns topic for instructions.
