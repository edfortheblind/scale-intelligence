Links in REST-Based Web Service Entities
View with Navigation Tools

Entities returned from REST-Based web services may contain links to additional information or operations on the resource or related resources.  This gives the client the ability to discover what information/operations are available and execute the desired link in a consistent fashion, all while reducing the client's knowledge of specific URIs. 

The following table describes the structure of a link.  See here for JSON and XML examples/schema.

Property Description
rel

The relationship of the link to the current resource.
type The media type associated with the link.  When retrieving information, this type describes the Content-Type of the response.  For operations, this describes the Content-Type of the request.
href

The URI to the linked resource.

This may also be a URI template, where tokens have the form {tokenName}.
