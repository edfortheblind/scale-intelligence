How to: Set Field Defaults through Exit Point Programs
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Detail Pages > How to: Set Field Defaults through Exit Point Programs

System can set default values to detail screens through configured exit point. Default values can be set in create mode. System provides the exit point Field Defaults – Modify, this should be used to pass default values to detail screen. Sql function ConvertKeyValueTableToXML can be utilized to provide default values in required XML format to system. User defined Table Type KeyValueTableType is used to pass values to the ConvertKeyValueTableToXML function.

The following example represents a sample implementation of the Field Defaults – Modify exit point program using a stored procedure. 

Sample exit point program for Field Defaults - Modify exit point
Copy Code 
CREATE PROCEDURE EXP_FieldDefaultsModify (
    @SESSIONVALUE xml,
    @FORMID numeric,
    @SCREENNAME nvarchar(max),
    @ENTITY xml,
    @RETURNVALUE nvarchar(max) output
)
AS
    SET NOCOUNT ON;
    Declare @DataTable as KeyValueTableType;
    if(@FORMID = 2760) -- Shipment
    BEGIN
        Insert into @DataTable([Key],VALUE)
        values ('UserDef7','9.000') 
        Insert into @DataTable([Key],VALUE)   
        values ('Company','04-"Electronic" Avenue')
    END
    --Returns Key Value XML for provided defaults.
    select @RETURNVALUE = dbo.ConvertKeyValueTableToXML(@DataTable)
