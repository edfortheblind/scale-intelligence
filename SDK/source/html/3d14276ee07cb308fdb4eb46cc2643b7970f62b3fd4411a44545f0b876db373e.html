Cycle Count Quick Plan Web Service
View with Navigation Tools

The Cycle Count Quick Plan Web Service gives the ability to submit a list of cycle count quick plans for processing, as well as a resource that will calculate the number of cycle count requests a quick plan would create once submitted.

 Requests

CycleCountQuickPlans resource:

  • URI: http://ServerName/ILSIntegrationServices/CycleCountQuickPlans
  • Method: POST
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: JSON, XML
  • Roles: SCALEUSER,Confidential

 

CalculatedRequestCount resource:

  • URI: http://ServerName/ILSIntegrationServices/CycleCounting/CalculatedRequestCount?<queryString>
    • Note that the <queryString> can consist of any fields found in the above request entity to the CycleCountQuickPlans resource.  For example, if requesting the count for all items that start with 'NOR' in warehouse '001', the query string would be 'Description=description&Item=NOR%25&Warehouse=001', where '%25' is the URL-encoding for the '%' wildcard character.
  • Method: GET
  • Accept: application/json or application/xml
 Responses

Aside from standard responses, note the following specifics for this service:

CycleCountQuickPlans resource:

Status Code Notes
202

Accepted will be the typical response when the quick plans are successfully queued for processing.  It will be accompanied by a human readable message entity in the requested media type: JSON, XML

The Location header of the response will contain a URI to the Cycle Count Plan Web Service that can be used to access the cycle count plan once created.
400 Bad Request may be accompanied by the Criteria or Description ErrorTypes.

CalculatedRequestCount resource:

Status Code Notes
200

OK will be accompanied by an entity in the requested media type: JSON, XML
400 Bad Request may be accompanied by the Criteria or Description ErrorTypes.
