How to: Add Detail/Transaction Screen Menu Options
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Detail Pages > How to: Add Detail/Transaction Screen Menu Options

Follow these steps to add the menu options that are standard for all the detail and transaction screens.

 Step 1: Create new menu screen groups
       

Add a SCREEN_GROUP record as follows in order to create a section for the menu option. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the screen
GROUP_NAME [ScreenName]Menu
RESOURCE_KEY NULL
GROUP_TYPE 70 (Menu)
PARENT_GROUP_ID NULL
NESTED_GROUP_UNIT Set this to the Object Id of this screen group record once it is created
DIV_CSS_CLASS nav nav-pills
ROW_CSS_CLASS row rowmenupanel
FIXED_TO_TOP Y
ACTIVE Y
SEQUENCE Set this field to be relative to the other members of the parent screen part to control ordering on the web page


Add a SCREEN_GROUP record as follows in order to create a menu panel for the menu option. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the screen
GROUP_NAME [ScreenName]MenuPanel
RESOURCE_KEY NULL
GROUP_TYPE 60 (Panel)
PARENT_GROUP_ID Set this to the object id of group created above
DIV_CSS_CLASS pull-right menubuttonpanel
ROW_CSS_CLASS NULL
FIXED_TO_TOP Y
ACTIVE Y
SEQUENCE Set this field to be same as the sequence of the group created above
 Step 2: Create screen control related records for the menu action
 Create menu button screen control

Now add a SCREEN_CONTROL record as follows for the Menu Button control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the Menu Panel
CONTROL_NAME [ScreenName] MenuAction [Action]
RESOURCE_KEY Resource key for the button
CONTROL_TYPE 150 (Menu Button)
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE NULL
DATA_SOURCE NULL
DIV_CSS_CLASS pull-right menubutton
CONTROL_CSS_CLASS dropdownaction pull-right menubutton menubuttonsave
TOOL_TIP_RESOURCE_KEY Resource key for the button
 Add security for the menu button
Please refer How to: Configure Security for a Dynamic Action topic in order to add security for the new action.
 Create a screen control event record tied to the menu button control
Please refer How to: Create Screen Control Events topic in order to add event for the new control.
 Create screen control event parameters record tied to the event
Please refer How to: Create Screen Control Event Parameters topic in order to add event parameters for the new event.
