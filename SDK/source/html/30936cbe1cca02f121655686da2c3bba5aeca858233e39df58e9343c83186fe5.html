Image capture - Link internal reference number
View with Navigation Tools
Integration Endpoints > Exit points > Image capture - Link internal reference number

The system provides an exit point Image capture - Link internal reference number , that should be used to let the system know if it should override the system's internal number mapping logic for all image capture reference types.

The exit point should return a numeric value if it finds internal mapping number for the given reference id and reference type, else it should return NULL.

 

The following example represents a sample implementation of the Image capture - Link internal reference number> exit point program using a stored procedure. 

  • Sample exit point program for Image capture - Link internal reference number exit point
/*
 Mod     | Programmer    | Date       | Modification Description
 --------------------------------------------------------------------
         | srajesh       | 3/29/2024  | Stored Procedure for exit point:Image capture - Link internal reference number
*/
CREATE PROCEDURE [EXP_ImageCaptureLinkInternalReferenceNumber] (
    @SESSIONVALUE xml,
    @REFERENCECATEGORY NVARCHAR(50),
    @REFERENCETYPE NVARCHAR(50),
    @REFERENCEID NVARCHAR(50),
    @RETURNVALUE NUMERIC(9,0) output
)
AS
BEGIN
    SET NOCOUNT ON; 
    SET @RETURNVALUE = NULL; --SETTING DEFAULT VALUE
    IF(@REFERENCECATEGORY = 'RECEIVING')
        BEGIN
            IF(@REFERENCETYPE = 'RECEIPTID')
                BEGIN
                    SET @RETURNVALUE = (SELECT TOP 1 INTERNAL_RECEIPT_NUM FROM RECEIPT_HEADER 
                                        WHERE RECEIPT_ID = @REFERENCEID 
                                        AND LEADING_STS BETWEEN 100 AND 900); 
                END
            IF(@REFERENCETYPE = 'LICENSEPLATE')
                BEGIN
                    SET @RETURNVALUE = (SELECT TOP 1 INTERNAL_REC_CONT_NUM FROM RECEIPT_CONTAINER
                                        WHERE CONTAINER_ID = @REFERENCEID); 
                END
        END
        RETURN @RETURNVALUE;
END
