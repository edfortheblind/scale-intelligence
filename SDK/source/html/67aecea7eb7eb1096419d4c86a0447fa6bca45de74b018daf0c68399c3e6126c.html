Compression in REST-Based WCF Web Services
View with Navigation Tools

REST-based web services offer the ability to compress entities attached to both requests and responses.  In certain scenarios, the size of the entity as it travels across the network can be reduced by over 90%.

To send the application a compressed entity, apply one of the supported compression encodings to the entity data and place the name of that encoding in the Content-Encoding header.  The following C# example illustrates how deflate encoding can be achieved using the System.IO.Compression.DeflateStream class:

 

C# - Compressing a Request Entity
Copy Code 
private System.Net.HttpWebRequest GetDeflatePostRequest(
    string uri,
    string entityXml)
{
    HttpWebRequest request = WebRequest.Create(uri) as HttpWebRequest;
    request.Method = "POST";
    request.ContentType = "application/xml";
    request.Headers[HttpRequestHeader.ContentEncoding] = "deflate";

    StreamWriter requestStreamWriter = null;
    try
    {
        Stream stream = new System.IO.Compression.DeflateStream(
            request.GetRequestStream(), CompressionMode.Compress);
        requestStreamWriter = new StreamWriter(stream);
        requestStreamWriter.Write(entityXml);
        requestStreamWriter.Flush();
    }
    finally
    {
        if (requestStreamWriter != null)
            requestStreamWriter.Close();
    }

    return request;
}

 

To request that the application respond with a compressed entity, set the Accept-Encoding header on the request to the desired compression format, and then be prepared to decompress the response entity once it returns.  It is a good idea to check the Content-Encoding on the response to make sure decompression is required, as there may be situations where the application could not compress the response (e.g. error situations).  The following C# example illustrates how a .NET consumer can request that the response entity is compressed using the gzip encoding.  Note that the HttpWebRequest class will handle much of the work for you when using the AutomaticDecompression property.

 

C# - Accepting a Compressed Response Entity
Copy Code 
private System.Net.HttpWebRequest GetRequestThatAcceptsGZip(
    string uri)
{
    HttpWebRequest request = WebRequest.Create(uri) as HttpWebRequest;
    request.Method = "GET";
    request.AutomaticDecompression = DecompressionMethods.GZip;
    return request;
}
