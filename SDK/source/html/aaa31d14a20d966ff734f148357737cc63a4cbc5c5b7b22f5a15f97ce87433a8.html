The following web services are all related to the Work functional area of the application:

Web Service Description
Assign Work Unit Assign the entire work unit to the user
Confirm into Shipping Container Outbound Work Instruction Executes the Confirm work for Shipment and Dock Management
Confirm into Tote Outbound Work Instruction Executes the Confirm into Tote work for Shipment and Dock Management
Confirm Outbound Work Instruction Executes the Confirm work for Shipment and Dock Management
Get Work Unit Gets the different work units found at the location that are ‘like’ the work unit specified.
Pick into Shipping Container Outbound Work Instruction Executes the Pick into Shipping Container work for Shipment and Dock Management
Pick into Tote Outbound Work Instruction Executes the Pick into Tote work for Shipment and Dock Management
Pick Outbound Work Instruction Executes the Pick work into None for Shipment and Dock Management
Putaway into Shipping Container Outbound Work Instruction Executes the Put away into Shipping Container for Shipment and Dock Management.
Putaway Outbound Work Instruction Executes the Put away work for Shipment and Dock Management
Remove Container From Group Unassigns the specified container from its current group
Remove Container Group Removes entire group of the specified container
Unassign Or Pass Work Unit Unassign or Pass the entire work unit from the user assigned
