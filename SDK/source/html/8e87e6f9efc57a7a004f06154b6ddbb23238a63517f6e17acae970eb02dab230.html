How to: Tie Advanced Criteria Fields to Operand Lists and Field Types
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Search Pane > How to: Tie Advanced Criteria Fields to Operand Lists and Field Types

The Advanced Criteria control is tied to a single database table or view. This is accomplished by setting the DATA_SOURCE_TYPE = 40 (TableFields - loads columns from database table) and DATA_SOURCE = <table or view name>. See the How to: Create Screen Controls topic for more details. The Advanced criteria control will fill the "Field" drop down with all of the available fields in the database table or view. The "Operand" drop down and "Value" controls will be updated based on the "Field" chosen. In order to tie a specific field with the correct operands and field types, the FILTER_ATTRIBUTES table needs to have the proper record created. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).


Field Description
ATTRIBUTE Field name with underscores stripped out (i.e. INTERNAL_SHIPMENT_NUM database field should be created with ATTRIBUTE of INTERNALSHIPMENTNUM)
VALIDATION_LIST The type of list that should be tied to the "Value" control when referencing the associated ATTRIBUTE. Please see the How to: Define Lists tied to Controls topic for more details.
FIELD_TYPE The type of the field. The valid types are ALPHA, DATE, DATETIME, DECIMAL, and NUMBER. This value also defines the operand list tied to the ATTRIBUTE through the "Metadata Filter Operand" configuration.
RECORD_TYPE For lists that require a parameter value, pass it here. For example, to display a list of countries, specify a VALIDATION_LIST of "Generic" and a RECORD_TYPE of "COUNTRY".

Please note that the default is ALPHA with no list tied to the control. This means that if no record with a matching ATTRIBUTE is found, the resulting "Value" control will be treated as an ALPHA control with no drop down.

Please note that the dbc_IFilterAttributes stored procedure can be used to create filter attributes.
