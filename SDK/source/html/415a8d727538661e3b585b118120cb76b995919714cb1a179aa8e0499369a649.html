How to Add Custom Detail Pane Tile With Multiple Selection on InsightPage
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > How to Add Custom Detail Pane Tile With Multiple Selection on InsightPage

The tooling provided for creating a new custom detail pane tile on the insight page with multiple selection on the grid and displaying the value on screen passed from stored procedure

 Step 1: Copy an Existing Insight Page Script

Browse to the directory that SCALE is installed to and then go to the sub folder Database | ILS | DBChange | _Metadata | Insight. Pick a script for the screen on which you want to add the custom action. Copy the script to another location, rename it, and open it.

 Step 2: Add the event on row selection of the grid
Reference the How to: Create Screen Control Events topic in order to add event for the new control.
Field Value
EventId iggridselectionrowselectionchanged
EventName _webUi.Grid.gridRowSelectionChangedWithMultiSelect
 Step 3: Add the new column to the grid.
Reference the How to: Create Screen Control Events topic in order to add event for the new control.

Add the new column to the grid which needs to be passed to the stored procedure

Make sure the fieldName is set to "INTERNAL_NUM" for the new column

Field Value
Field Internal_Shipment_Num
FieldName INTERNAL_NUM
ResourceKey INTERNAL_NUM
Hidden Y
 Step 4: Create screen control event parameters record tied to the event
Reference the How to: Create Screen Control Event Parameters topic in order to add event parameters for the new event.
Field Value
ParameterName PostData_internalNums
ParameterValue INTERNAL_NUM
 Step 5: Add the internalNums parameter to the stored procedure for Tile Data
Add the internalNums parameter to the stored procedure which fetches the detail pane tile data e.g., SHP_InsighInPoolDetailPaneData for Planned shipment insight screen.
 Step 6: Add the custom detail indicator tile on Insight screen
Reference the How to: Create Indicator Tile on an Insight Detail Pane topic in order to add event for the new control.
 Step 7: Run the script on the corresponding datatbase environment.
