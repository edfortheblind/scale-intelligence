How to: Enable/Disable Metadata Actions Based on Screen Data
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Actions > How to: Enable/Disable Metadata Actions Based on Screen Data

Metadata actions can also be enabled and disabled based on data on the screen. For example, when a new record is selected in the list pane grid, certain actions may need to be enabled or disabled based on the data in that row. Records can be added to the SCREEN_CONTROL_EVENT_PARAMETERS table to configure the data that determines whether an action is enabled or disabled when a new record in the grid is selected. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Please note that security checkpoints in the system override the metadata configurations for enabling or disabling an action.

Field Value
PARAMETER_NAME EnableAction_<ControlName> (e.g. EnableAction_ListPaneMenuActionUnassignWork)
PARAMETER_VALUE Literal value (true or false) or JavaScript conditional (e.g. INSTRUCTION_TYPE === Header && USER_ASSIGNED !== NULL && WORK_INSTRUCTION_CONDITION !== Closed)
SCREEN_CONTROL_ID The Object Id of the screen control event

 

The parameter value must be in the handlebars format. For specific information on handlebars refer the following article: http://handlebarsjs.com/.

 

NOTE: %20 must be used for spaces for example CARRIER === UPS%20GROUND

Insight actions can also be enabled/ disabled based on controls on insight screens except Listpane grid data.

Field Value
PARAMETER_NAME EnableAction_<ControlName>_<ControlId> (e.g. EnableAction_ListPaneMenuActionAddFilteredShipmentsToWave_filterBadge, Here filterBadge is Id of control, used to determine whether to enable or disable action based on its value.)
PARAMETER_VALUE Literal value (true or false) or JavaScript conditional (e.g. filterBadge > 0)
SCREEN_CONTROL_ID The Object Id of the screen control event
