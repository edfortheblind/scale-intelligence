Adjustment Type Authorization Retrieval Exit Point
View with Navigation Tools
Integration Endpoints > Exit points > Adjustment Type Authorization Retrieval Exit Point

The system provides an exit point Adjustment Type Authorization Retrieval , that should be used to override the list of adjustment types that can be viewed in various screens. The sql utility function ModifyCharacterSeparatedStringList can be used to modify adjustment types in stored procedure exit point programs.

 

The following example represents a sample implementation of the Adjustment Type Authorization Retrieval exit point program using a stored procedure. 

Sample exit point program for Adjustment Type Authorization Retrieval exit point
Copy Code 
CREATE PROCEDURE [EXP_AdjustmentTypeAuthorizationRetrieval] (
    @SESSIONVALUE xml,
    @ADJUSTMENTTYPELIST nvarchar(max),
    @RETURNVALUE nvarchar(max) output
)
AS
    SET NOCOUNT ON;
    DECLARE @adjustmentTypesToAdd nvarchar(max), @adjustmentTypesToRemove nvarchar(max);
    SET @adjustmentTypesToAdd = '';
    SET @adjustmentTypesToRemove = '';

        -- Update the list using Pipe character as the separator
        SELECT @RETURNVALUE = dbo.ModifyCharacterSeparatedStringList(@ADJUSTMENTTYPELIST, @adjustmentTypesToAdd, @adjustmentTypesToRemove, '|')
