Screen groups represent a grouping of controls within a single screen part. Screen groups are represented by the SCREEN_GROUP database table. There can be 1-N screen groups (ordered by the SEQUENCE field) for a particular screen part. Screen groups are tied to screen parts by the SCREEN_PART_ID field (SCREEN_GROUP.SCREEN_PART_ID = SCREEN_PART.OBJECT_ID). Screen groups can also be nested within each other (i.e. an accordion control has sub-accordions or an accordion control can be placed inside a panel control). This nesting is controlled by the PARENT_GROUP_ID and NESTED_GROUP_UNIT fields. All records in a particular "tree" (other than the top level record) will have a PARENT_GROUP_ID. All records in a "tree" will have the top level OBJECT_ID as their NESTED_GROUP_UNIT (including the top level record). Please reference the "Screen Group Type" configuration for an enumeration of the available screen groups. Also, the table below gives more information on screen groups.

 SavedSearchesMenu

The saved searches menu control is a drop down menu that lists the users favorite searches for an insight screen. It is actually entered in metadata as a screen group and combines several other controls so that metadata is minimized (since this will go on every insight screen). It uses Knockout.js to dynamically bind the drop down to the list of the users favorites.

Saved Searches Menu HTML
Copy Code 
<div id="ScreenGroupSavedSearchesMenu39690" class="dropdown pull-right" data-name="SearchPaneMenuFavoritesDropdown" data-internalid="39690">
    <li class="dropdown pull-right" >
        <a class="dropdown-toggle" data-bs-toggle="dropdown" id="SearchPaneMenuFavoritesDropdown" href=""><span class="glyphicon glyphicon-star"></span></a>
            <ul class="dropdown-menu" data-bind="foreach:savedSearches">
                <li class="dropdownaction" data-controlType="SavedSearchesMenu">
                    <a id="SearchPaneMenuFavoritesChooseSearch" href="javascript:;"><span data-bind="text:$data"> </span></a>
                </li>
            </ul>
<script type="text/javascript">
    $(function () {$(document).on('click', "[data-controlType='SavedSearchesMenu']",
        function(e) { _webUi.insightSearchPaneActions.applySavedSearchClicked(e);})})
    var savedSearches = ko.observableArray([]);
    ko.applyBindings(savedSearches);
    function setSavedSearchesList(newSearchName) {
        if (savedSearches._latestValue.toString().toLowerCase().indexOf(newSearchName.toLowerCase()) < 0) {
            savedSearches.push(newSearchName);
            savedSearches.sort(function(a, b) { if (a.toLowerCase() < b.toLowerCase()) return -1; if (a.toLowerCase() > b.toLowerCase()) return 1; return 0; });
        }
    }
</script>
</div>
 ModalDialogHeader, ModalDialogBody, and ModalDialogFooter

The ModalDialog screen part should always consist of a Form group with nested header, body, and footer groups. Each of these groups can then have controls tied to them to allow for a dynamic ModalDialog with input from a user.

ModalDialog Groups HTML
Copy Code 
<div class="modal-header"  data-controlType="modalDialogHeader" data-controlId="39684" >
    <button type="button" class="close" data-bs-dismiss="modal" aria-hidden="true">&times;</button>
    <h4 class="modal-title" id="modalLabel">Save Search Criteria</h4>
</div>
<div class="modal-body"  data-controlType="modalDialogBody" data-controlId="39685" >
    <p>modal dialog body content here</p>
</div>
<div class="modal-footer"  data-controlType="modalDialogFooter" data-controlId="39686" >
    <button id="SaveButton" class=" btn btn-default">Save</button>
    <button id="SaveSearchCancelButton" class=" btn btn-default">Cancel</button>
</div>

 Accordion With Sidebar

The Accordian with Sidebar creates a sidebar with navigation to the accordion sections of the page. The sidebar is automatically built with no need for extra metadata. It has a feature to collapse all sections of the accordion.

Copy Code 
<div class="accordionsidebar" id="wrapper" style="padding-top: 60px;">
   <div id="sidebar-wrapper">
      <ul class="sidebar-name">
         <li><a onclick="_webUi.accordion.collapseAllSubAccordions('MainAccordion')">Collapse all</a></li>
         <li class="divider"></li>
         <li><a onclick="_webUi.accordion.activateSubAccordion('MainAccordion','SubAccordion','0');">Accordion Header</a></li>
