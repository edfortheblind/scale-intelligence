A column chart can be drilled down to N levels and further drilled down to open an Insight screen. For example, the "data-drilldownToInsight" attribute value could be set to the following.

 Create required screen control attribute for Action Tile

To enable drilldown to insight , the "data-drilldownToInsight" attribute needs to be created for the Chart control. The value for this attribute should be in the following format. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

 

Use the ALT+219 █ character for the separator characters in the path as shown below.

 

{{FORM_ID=<Form Id>}}?filters=<Control Name>█{{{Chart Field Name}}}

Field Description

Form Id

Defines the Insight screen Form Id.

Control Name

Defines the name of the control on the Insight screen search pane that this criteria applies to.

Chart Field Name

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

For example, the "data-drilldownToInsight" attribute value  set to the following.

{{FORM_ID=2757}}?filters=SearchPaneWhs█{{{FROM_WHS}}},SearchPaneAdvCrit_Field█{{{WORK_GROUP}}},SearchPaneWrkTyp█{{{WORK_TYPE}}},BasicCriteriaUserAssigned█{{{USER_ASSIGNED}}}

Field Description

2757

Defines the Work Insight screen Form Id.

SearchPaneWhs

Defines the name of the control on the Insight screen search pane that FROM_WHS criteria applies to.

FROM_WHS

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

SearchPaneAdvCrit_Field

Defines the name of the control on the Insight screen search pane that WORK_GROUP criteria applies to.

WORK_GROUP

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

SearchPaneWrkTyp

Defines the name of the control on the Insight screen search pane that WORK_TYPE criteria applies to.

WORK_TYPE

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

BasicCriteriaUserAssigned

Defines the name of the control on the Insight screen search pane that USER_ASSIGNED criteria applies to.

USER_ASSIGNED

Defines the field name from the chart that should be used to filter the Insight screen for this criteria.

Note: please refer to the  How to: Create Screen Control Attributes topic for more detailed information on screen control attributes.
