How to: Tie a Detail Page to a Table or View
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Detail Pages > How to: Tie a Detail Page to a Table or View

A detail screen can currently only be driven from a single database entity (either table or view) and must have an NHibernate entity generated for it. This entity is defined by the TABLE_NAME column on the FORM table tied to the screen. It should be filled with the NHibernate entity name that the screen will be tied to (for example "WorkInstruction").

 Modify an existing detail screen to point to a different table or view

In order to change an existing detail screen to point to a different table or view, follow the steps below.

 Step 1: Find the FORM record for the detail page

Select the FORM record that this screen is tied to. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find FORM record
Copy Code 
select * from FORM where FORM_ID = <form id>

 Step 2: Update the TABLE_NAME field with new table or view
 Use the following SQL statement to modify the table or view NHibernate entity name that the detail screen is using. For example, if the screen will be based on the WORK_INSTRUCTION table, the entity name provided should be "WorkInstruction". Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Modify TABLE_NAME column
Copy Code 
update FORM set TABLE_NAME = '<new table or view NHibernate entity name>'
where FORM_ID = <form id>
               
Please note that changing the table or view on an detail screen only changes the table or view that the detail page binds with. Specific controls may reference column names or properties that do not exist in the table or view and in this case errors will occur on the screen. The individual properties that other controls on the page point to will need to be updated as well. Please reference the XXX page for more details.
 Create a new detail page tied to a table or view
Tying a new detail page to a table or view NHibernate entity is as simple as specifying the TABLE_NAME column on the corresponding FORM record and then binding each individual control on the page in metadata. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
