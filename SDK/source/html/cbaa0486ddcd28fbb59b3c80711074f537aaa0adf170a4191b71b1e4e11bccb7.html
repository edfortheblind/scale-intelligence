Azure function is a serverless compute service that enables us to run code on-demand without having to explicitly provision or manage infrastructure. This can be utilized as an exit point program and will provide extensibility to the customers to add their custom code in it. For configuring azure function as an exit point program, please refer Exit point program(Web service type)

 Usage of the key vault in azure functions

Azure Key vault is used to store secrets. To invoke SCALE web services from azure functions, bearer token is required. Please refer topic Generating bearer token(Client Credentials Grant with SCALEUser role token) to know how to generate bearer token. This logic requires API Confidential client secret key. As the key cannot be shared, this can be stored in azure key vault as a secret and can be retrieved in azure function by its URI(DNS name) and secret name.

Creating new key vault

  1. Log on to the azure AAD portal.
  2. From the dashboard, select Create a resource > Security> Key Vault.
  3. Create key vault pane, assign a name for vault.
  4. Choose a subscription from the list of available subscriptions.
  5. Select a resource group.

Using the key vault in azure functions

  1. Once the key vault app is created, please note down the DNS name from overview.
  2. Then add secrets from the settings and store secret key, please note down the secret name.
  3. Secret name and DNS name are required while retrieving the secret key from the key vault in azure function.
  4. In the access polices, choose the azure function app from where we are accessing the key vault.
  5. Also enable Managed service identity for the selected azure function app. This can be found in the platform features.
