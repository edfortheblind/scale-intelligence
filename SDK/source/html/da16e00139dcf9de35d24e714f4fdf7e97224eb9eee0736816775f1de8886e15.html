How to: Add Complex Filters to the Search Pane
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Search Pane > How to: Add Complex Filters to the Search Pane

Filter configurations can be applied as pre-configured complex filters on an Insight screen. An example of this that is shipped with the system is the Planned Shipment Filters on the Planned Shipment Insight screen. Use the following instructions to add these types of filters to any insight screen.

 Step 1: Create a new filter configuration for the screen

A new filter configuration needs to be created so that the filters can be properly configured. This involves creating a new Form Id and filter config header. It is recommended that Insight filters be placed under Personalization/extensibility | User Interface | Insight Filters folder in the Configuration Explorer (but this is not a requirement). Below is an example script that can be run with the SCALE installers to create a similar filter configuration (needs to be updated based on the Filter config you want to add).

Filter configuration SQL script
Copy Code 
DELETE FROM RESOURCE_FILE_BASE WHERE RESOURCE_KEY in ('UI_FLTPLANSHIPFLTRS', 'PLANSHIPFLTRS', 'UI_CFGFILPLANSHIPFLTRS');
DELETE FROM SECURITY_CHECKPOINT WHERE FORM_ID in (4033);
DELETE FROM FORM WHERE FORM_ID in (4033);
DELETE FROM FILTER_STATEMENT WHERE RECORD_TYPE = 'PLANSHIPFLTRS';
DELETE FROM FILTER_CONFIG_DETAIL WHERE RECORD_TYPE = 'PLANSHIPFLTRS';
DELETE FROM FILTER_CONFIG_HEADER WHERE RECORD_TYPE = 'PLANSHIPFLTRS';
   
#SP dbc_IGenericConfigForm
    formId = 4033,
    formKeyName = 'UI_FLTPLANSHIPFLTRS',
    helpResourceKey = 'UI_CFGFILPLANSHIPFLTRS',
    helpText = 'plannedShipmentFilters.htm',
    parentkeyname = 'UI_CFGNODEINSIGHTFLTRS',
    tableName = 'FILTER_CONFIG_DETAIL',
    text = 'Planned shipment filters',
    usedByGenerator = 'Y',
    processStamp = 'dbChange194099.sql';

#SP dbc_IFilterConfigHeader
    allowOrderBy = 'N',
    description = 'Planned shipment filters',
    doPath = 'com.pronto.dbutility.process.ShipmentDetailDO,com.pronto.dbutility.process.ShipmentHeaderDO',
    joinClause = NULL,
    recordType = 'PLANSHIPFLTRS',
    tableDoName = 'Metadata_Insight_Shipment_Pool_View',
    processStamp = 'dbChange194099.sql';
 Step 2: Add a combo box tied to your filter configuration to the appropriate Insight screen

Now add a SCREEN_CONTROL record as follows to the appropriate Insight screen. It is recommended to add this combo box to the top of the Basic Criteria section. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the sub-accordion that will hold the combo box.
CONTROL_NAME The name of the control.
RESOURCE_KEY The resource key used when creating the filter configuration. In the example above, it would be UI_FLTPLANSHIPFLTRS.
CONTROL_TYPE 80 (ComboBox)
LABEL_ORIENTATION 20 (Inline)
DATA_SOURCE_TYPE 10 (ConfigType)
DATA_SOURCE Filter|<record type of the filter configuration> (in the example above, it would be PLANSHIPFLTRS.
DIV_CSS_CLASS basiccriteriarow
CONTROL_CSS_CLASS NULL
