How to: Set Default State for a Control
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Set Default State for a Control

Some controls can be defaulted in different states. Currently the only controls that support default states are toggle switches, checked list boxes, and hierarchical checked list boxes. Please reference the "Metadata Default State" configuration for an enumeration of the available default states.

 Setting default state of new control when metadata is created
In order to set the default state on a control as it is being created from metadata, simply set the DEFAULT_STATE on the control. Please reference the How to: Create Screen Controls topic for more details. Also see the "Metadata Default State" configuration for an enumeration of the available default states.

 Modifying the default state for an existing control

In order to change an existing control to have a different default state, first find the Object Id of the control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find Object Id of controls
Copy Code 
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))
       

 

Then update the DEFAULT_STATE field accordingly. Please see the "Metadata Default State" configuration for an enumeration of the available default states. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page). Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page). 

Modifying default state on control
Copy Code 
update SCREEN_CONTROL set DEFAULT_STATE = '30' where OBJECT_ID = <object id>
