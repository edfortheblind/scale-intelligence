Extensibility > Movement Class Analysis > Movement Class Analysis Overview

The Movement Class Analysis scheduled job collects data from the transaction and archive transaction history tables. This job calculates the total hits and total quantity in base unit of measure per unique item/company/location/warehouse. The Movement Class Analysis system stores the calculated records in the new Movement Class Analysis table with the help of the Movement Class Analysis scheduled job.

Movement Class Analysis considers only the transactions of inventory locations having the direction "From" for the below mentioned list of transaction types.

  • Inventory Adjustments
  • Inventory Transfers
  • Warehouse Transfers
  • Over Pick Adjustments
  • Pick and Put Confirmation
  • Pick Confirmation
  • Short Pick Adjustment

 

This functionality is made up of a new Scheduled Job, Stored Procedure, Functions and Views in the database. Below is the brief description of these.

 Scheduled Job

Added the scheduled job Movement Class Analysis. It has four configurable parameters shown below.

  • Warehouse: Warehouse defines the warehouse to collect data for. When not specified all warehouses will be evaluated.
  • Number of Days to Collect: Time Duration for which Item/Location movement needs to be collected. Default shipped value is 90 days. Value should be positive integer greater than 0.
  • Collect Data for Permanent Locations Only: Collects data for permanent locations only when selected. Shipped value is not selected.
  • Include Archived Data: Scheduler collects data from AR_TRANSACTION_HISTORY table in addition to TRANSACTION_HISTORY table when selected. By default archive transaction history will not be collected.

 

 Stored Procedure MOVECLS_MineMovementClassAnalysisData 

Stored Procedure MOVECLS_MineMovementClassAnalysisData migrates data from the TRANSACTION_HISTORY and AR_TRANSACTION_HISTORY table to MOVEMENT_CLASS_ANALYSIS table, having four input parameter shown below.

  • @Warehouse: Stored Procedure MineMovementClassAnalysisData will mine data for passed Warehouse.
  • @Days: Defines the number of days of data to collect.
  • @Permanent: Allows only permanent inventory locations for retrieval.
  • @IncludeArchiveData: Triggers the retrieval of archived transactions in addition.

 Views

Two new views have been created for the movement class analysis viewer for passing values as the Header and Detail Data Source.

  • MOVEMENT_CLASS_ANALYSIS_VIEW: Queries the Movement Class Analysis table by using the function INVfn_RtrvItemInfoForBaseUM and INVfn_RtrvConversionInfoForItemAndLocation and provides information such as Item, Item Class, Number of Hits, Item Movement of Class, Location Movement Class, Total Volume, Total Weight, Number of Days, etc. This is used as the Header Data Source in the Movement Class Analysis Viewer.
  • MOVEMENT_CLASS_ANALYSIS_UM_VIEW : This view provides the Item Unit of Measure records linked to the movement class analysis records displayed in the viewer. This is used as the Detail Data Source in the Movement Class Analysis Viewer.

 

 Functions

Three new functions have been added to retrieve data from the Movement Class Analysis table and used by the Views mentioned above.

  • GENfn_SplitString: Splits string using the passed in separator.
  • INVfn_RtrvConversionInfoForItemAndLocation: Uses the Location Quantity UM List to return a list of Item Unit Of measure records matching the Item/Company and Location passed in. Will use Item Class if Item/Company is not found in the Item Unit of Measure table. All records are returned when a quantity um list is not specified.
  • INVfn_RtrvItemInfoForBaseUM: Returns the item’s information like cost, volume, color, size etc for base UM of passed item.
