Item Unit of Measure Web Service
View with Navigation Tools

The Item Unit Of Measure Web Service allows access to an item unit of measure in the application.

 Request
  • URI: http://ServerName/general/items/uoms?item={item}&company={company}
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200

OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.general.itemUnitOfMeasure+json, XML

Links available:-

rel Media type(s)
self application/vnd.manh.ils.general.itemUnitOfMeasure+json, XML

400 The following Error Type can be expected: Unknown
