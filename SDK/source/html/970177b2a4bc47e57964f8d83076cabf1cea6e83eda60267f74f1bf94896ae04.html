Shipping Web Service
View with Navigation Tools

The Shipping Web Service allows access to links (URL or URI template) to other web services in the shipping functional area. For example, Shipping Container, VAS Activities and QC Assignment web services.

 Request
  • URI: http://ServerName/ilsIntegrationServices/shipping
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200

OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.shipping+json, application/vnd.manh.ils.shipping+xml
