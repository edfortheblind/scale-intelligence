Rating Web Service
View with Navigation Tools

The Rating web services offer the following functionality:-

 Get Shipment Rate

It takes a shipment (real or hypothetical) and calculates the shipping charges. At this time Rating in the application will calculate the Base Freight Charge, Freight Discount, and Total Freight Charge. This is achieved by the following steps:

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Get the shipment rate 

The Shipping resource representation will include the link to the Shipment Rates collection resource. The link (rel="getShipmentRate") has a href that is a URL to the Shipment Rates Resource. To fetch the shipping rate perform an HTTP GET:

Request:

  • URI: <link href>?<queryString>

    Note that the <queryString> can consist of a set of fields found in the request entity (application/vnd.manh.ils.shipping.rateShipmentRequest+json, xml).

  • Accept: application/json or application/xml
  • Method: GET
  • Roles: SCALEUSER,Confidential                       

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.shipping.rateShipmentResponse+json, xml
400

The following ErrorTypes can be expected: Unknown

 Rate Shipment

It takes a shipment and updates it with the calculated shipping charges. This is achieved by the following steps:

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Rate the shipment

The Shipping resource representation will include the link to the Shipments-Rated collection resource. To update the Shipment with freight rates perform an HTTP POST using the following:

Request:

  • URI: From Shipping resource link (rel="rateShipment") href
  • Method: POST
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: application/vnd.manh.ils.shipping.rateShipmentRequest+json, xml

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.shipping.rateShipmentResponse+json, xml
400

The following ErrorTypes can be expected: Unknown
