How to: Add Search Pane Menu Options
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Search Pane > How to: Add Search Pane Menu Options

Follow these steps to add the menu options that are standard for the search pane of insight screens, as well as new custom menu options.

 Step 1: Create a modal dialog for the "Save Search" action
Create a modal dialog control that will be used to provide user input when the "Save Search" action is selected. Please reference the How to: Create a Dynamic Modal Dialog topic for more information.
 Step 2: Create new menu screen groups
       

Add a SCREEN_GROUP record as follows in order to create a menu for the search pane. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the Insight menu pane
GROUP_NAME SearchPaneMenu
RESOURCE_KEY NULL
GROUP_TYPE 70 (Menu)
PARENT_GROUP_ID NULL
NESTED_GROUP_UNIT Set this to the Object Id of this screen group record once it is created
DIV_CSS_CLASS nav nav-pills
ROW_CSS_CLASS row rowmenupanel
                       
 Step 3: Create screen control related records for the "Save Search" action
 Create menu button screen control

Now add a SCREEN_CONTROL record as follows for the Menu Button control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the menu dropdown on the search pane
CONTROL_NAME SearchPaneMenuActionSaveSearch
RESOURCE_KEY SAVESEARCH
CONTROL_TYPE 150 (Menu Button)
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE NULL
DATA_SOURCE NULL
DIV_CSS_CLASS pull-left menubutton
CONTROL_CSS_CLASS pull-left menubutton fa fa-floppy-o floppyDiskIcon
TOOL_TIP_RESOURCE_KEY SAVESEARCH
 Add security for the menu button
Reference the How to: Configure Security for a Dynamic Action topic in order to add security for the new action.
 Create a screen control event record tied to the menu button control

Now add a SCREEN_CONTROL_EVENT record as follows for the Menu Button control. This defines what gets called when the button is clicked by the user. This action will call a generic JavaScript function that will show a Modal Dialog control that will prompt the user to input the name of the search that they want to save. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_ID The Screen Control Id of the menu button
EVENT_ID click
EVENT_NAME _webUi.dialog.showModalDialogByEvent
 Create a screen control event parameters record tied to the event

Now add a SCREEN_CONTROL_EVENT_PARAMETERS record as follows for the Menu Button control event. This defines what Modal Dialog control should be displayed by the event. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_EVENT_ID The Screen Control Event Id of the event for the menu button
PARAMETER_NAME ModalDialogName
PARAMETER_VALUE The name of the Modal Dialog created in metadata previously (normally named "SaveSearchModalDialog")
 Step 4: Create screen control related records for the "Search" action
 Create a menu button screen control

Now add a SCREEN_CONTROL record as follows for the Menu Button control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the menu dropdown on the search pane
CONTROL_NAME SearchPaneMenuSearch
RESOURCE_KEY BTN_SEARCH
CONTROL_TYPE 150 (Menu Button)
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE NULL
DATA_SOURCE NULL
DIV_CSS_CLASS pull-left menubutton
CONTROL_CSS_CLASS pull-left menubutton
TOOL_TIP_RESOURCE_KEY BTN_SEARCH
 Create a screen control event record tied to the menu button control

Now add a SCREEN_CONTROL_EVENT record as follows for the Menu Button control. This defines what gets called when the button is clicked by the user. This action will call a pre-created JavaScript function that process the "Search" action on an insight screen. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_ID The Screen Control Id of the menu button
EVENT_ID click
EVENT_NAME _webUi.insightSearchPaneActions.searchButtonClicked
 Step 5: Create a screen group for the "Favorites" menu

Add a SCREEN_GROUP record as follows. This defines the entire "Favorites" menu and will be rendered as several different records in the HTML. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the search pane
GROUP_NAME SearchPaneMenuFavoritesDropdown
RESOURCE_KEY FAVORITES
GROUP_TYPE 100 (Saved Searches Menu)
PARENT_GROUP_ID The Screen Group Id of the menu SCREEN_GROUP in the search pane
NESTED_GROUP_UNIT The Screen Group Id of the menu SCREEN_GROUP in the search pane
DIV_CSS_CLASS dropdown pull-left pullleftfavourite
ROW_CSS_CLASS NULL
