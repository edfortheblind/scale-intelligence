Get Work Unit
View with Navigation Tools
Integration Services > REST-Based Web Services > Work Web Services > Get Work Unit

The Work Unit Web Service gets the different work units found at the location that are ‘like’ the work unit specified. The web service will retrieve all the work unit ids that match the work unit specified in the request or that are like the work unit plus the 'new work delimiter' configured in the application (e.g. like '2343534AB#')

 

Note: The location on the request is compared with the "from location", the "incoming P&D" and the "outgoing P&D" on the work instruction to find a match.
 Request
  • URI: http://ServerName/ILSIntegrationServices/WorkUnits?workUnit={workUnit}&fromLoc={fromLoc}
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity in the requested media type: JSON, XML
400 The following ErrorTypes can be expected: WorkInstruction, FromLocation
404 The following ErrorTypes can be expected: WorkInstruction
