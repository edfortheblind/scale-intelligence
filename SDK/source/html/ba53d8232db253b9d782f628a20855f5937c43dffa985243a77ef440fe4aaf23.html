How to: Set Default Action for Enter Key
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Set Default Action for Enter Key

It is often necessary to define a "default action" (button or link) when the Enter key is pressed from a specific control on a screen. This can be defined dynamically in metadata via the DEFAULT_ACTION fields in the SCREEN_PART, SCREEN_GROUP, and SCREEN_CONTROL tables. Metadata screens will process these fields in a "bottom up" approach, meaning that the lowest level (control level) takes precedence over higher levels (group, part). With this approach, the required metadata can be minimized by generally placing the default action at the part level. However, if controls require a different default action, it can be specified at the group or control level.

When a page is loaded with all of its controls, each control is assigned a custom attribute named "data-defaultAction". This attribute is filled based on priority order (the default action from control if it is specified, then the group, and then the part) and is illustrated below:

Text Editor HTML

<div id="ScreenControlTextEditor56948" class="ScreenControlTextEditorInline basiccriteriarow  " data-name="BasicCriteriaLocation" data-internalid="56948">
    <label class="LabelInline" for="BasicCriteriaLocation"> </label>
    <span data-controlId="56948" data-controlType="igEditor" data-dataType="A" data-defaultAction="SearchPaneMenuSearch" id="BasicCriteriaLocation"></span>
    <input name="BasicCriteriaLocation" type="hidden" />
    <script type="text/javascript">
        //<!--<![CDATA[$(function () {$('#BasicCriteriaLocation').igEditor({ type: 0, button: 'clear',
            disabled: false, excludeKeys: null, height: 25, hideEnterKey: false, includeKeys: null, maxLength: 25,
            nullText: 'Location', selectionOnFocus: -1, textMode: 'text', toLower: false, toUpper: false,
            inputName: 'BasicCriteriaLocation' });});//]]>-->
    </script>
</div>


 

When the page loads it also binds the "keypress" event to all controls with a matching "data-defaultAction" attribute.  It does this for all unique default actions for a screen (for the parts, groups, and controls). This is illustrated below:

Binding Default Action HTML
Copy Code 
<script type="text/javascript">
    $(function () {$(document).on('keypress', "[data-defaultAction='SearchPaneMenuSearch']",
        function(e) { return _webUi.onKeyPress(e, "SearchPaneMenuSearch");})})
</script>

Please note that the DEFAULT_ACTION field should be filled with the Id of the button/link that should be called when the user hits enter. The default action always calls the "onKeyPress" function in webui.js, passing the Id specified for the default action.


In order to modify the default action on a specific part, group, or control, a SQL statement similar to the following should be used. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Update default action on part
Copy Code 
update screen_part set DEFAULT_ACTION = '<id of custom action>' where OBJECT_ID = <object id of existing part>
Update default action on group
Copy Code 
update screen_group set DEFAULT_ACTION = '<id of custom action>' where OBJECT_ID = <object id of existing group>
Update default action on control
Copy Code 
update screen_control set DEFAULT_ACTION = '<id of custom action>' where OBJECT_ID = <object id of existing control>
