Calling a REST-Based Web Service
View with Navigation Tools

REST-based Web Services can be invoked from any type of consumer that has access to a common HTTP API.  With that said, below are two common examples: .NET and AJAX.

 .NET

.NET offers an HTTP API in its System.Net.HttpWebRequest and HttpWebResponse classes.  The following example code illustrates how to use those classes to interact synchronously with a typical service:

C#
Copy Code 
public string InvokeService(
    string userName,
    string culture,
    string httpMethod,
    string uri,
    int timeoutMillis,
    string contentType,
    string requestEntity,
    out HttpStatusCode statusCode)
{
    // build the request.
    HttpWebRequest request = HttpWebRequest.Create(uri) as HttpWebRequest;
    request.Accept = contentType;
    request.Headers.Add("Session", userName + ":::" + culture);
    request.Method = httpMethod;
    request.Timeout = timeoutMillis;

    // add request entity when applicable.
    if (requestEntity != null
        && (httpMethod == "POST" || httpMethod == "PUT"))
    {
        request.ContentType = contentType;
        StreamWriter requestStream = null;
        try
        {
            requestStream = new StreamWriter(request.GetRequestStream());
            requestStream.Write(requestEntity);
        }
        finally
        {
            if (requestStream != null)
                    requestStream.Close();
        }
    }

    // perform a synchronous request.
    // use request.BeginGetResponse() for asynchronous requests.
    HttpWebResponse response = null;
    try
    {
        try
        {
            response = request.GetResponse() as HttpWebResponse;
        }
        catch (System.Net.WebException e)
        {
            // all non-200 (OK) responses are thrown as WebExceptions by .NET.
            if (e.Response != null)
                response = e.Response as HttpWebResponse;
            else
                throw;
        }

        // make the status code available.
        statusCode = response.StatusCode;

        // return the response entity as a string.
        StreamReader responseStream = new StreamReader(response.GetResponseStream(), Encoding.UTF8);
        return responseStream.ReadToEnd();
    }
    finally
    {
        if (response != null)
            response.Close();
    }
}
 AJAX

AJAX (Asynchronous JavaScript and XML), for the sake of this SDK, simply describes HTTP requests made directly from JavaScript hosted in a web browser.  The key to AJAX is the XMLHttpRequest JavaScript object, which offers a typical HTTP API.

Though XML is implied in the acronym, the application also supports JSON (JavaScript Object Notation) media types, which can be more convenient from JavaScript.  See www.json.org for more information about JSON, especially www.json.org/js.html, which focuses on using JSON within JavaScript, with a link to an open source JSON serializer (www.json.org/json2.js).

The following example illustrates the use of XMLHttpRequest while using the application/json media type:

    function invokeService(userName, culture, method, uri, requestEntity, asynch)
    {
        // create the XMLHttpRequest object in a cross-browser safe manner.
        var xmlHttpRequest = window.XMLHttpRequest
            ? xmlHttpRequest = new XMLHttpRequest() // IE7+, Firefox, Opera, Safari, etc.
            : new ActiveXObject('MSXML2.XMLHTTP.3.0'); // pre-IE7

        // open and initialize the XMLHttpRequest.
        xmlHttpRequest.open(method, uri, async);
        xmlHttpRequest.setRequestHeader("Accept", "application/json");
        xmlHttpRequest.setRequestHeader("Session", userName + ":::" + culture);

        // add the event handler that will process the response of the request.
        var responseEntity;
        xmlHttpRequest.onreadystatechange=function()
        {
            if (xmlHttpRequest.readyState != 4)
                return;

            // parse the response entity into object form, while handling
            // the specialized date format returned by the application.
            responseEntity = JSON.parse(
                xmlHttpRequest.responseText,
                __jsonParserFilter);
            if (xmlHttpRequest.status == 200)
            {
                // Success! Possibly use response entity.
            }
            // add else-ifs for other expected response statuses.
            else
            {
                // handle error based on status and response json, if applicable.
            }
        }

        // perform the request, passing the request entity if specified.
        if (requestEntity
            && (method == "POST" || method == "PUT"))
        {
            xmlHttpRequest.setRequestHeader("Content-Type", "application/json");
            xmlHttpRequest.send(JSON.stringify(requestEntity));
        }
        else
        {
            xmlHttpRequest.send();
        }

        // if we waited for a response, send it back to the caller.
        if (!asynch)
            return responseEntity;
    }

    function __jsonParserFilter(key, value)
    {
        // The application will return Dates as strings in the form "/Date(milliseconds[+-]GMT)/"
        // The following will properly parse such strings into Date objects.

            && typeof(value) === 'string'
            && value.indexOf('/Date(') == 0)
        {
            return eval("new Date(" + value.substring(6, v.length-2) + ")");
        }
    }
