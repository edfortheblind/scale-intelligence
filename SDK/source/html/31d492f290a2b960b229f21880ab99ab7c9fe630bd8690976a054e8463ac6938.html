Multi Order Pallet Unnesting Web Service
View with Navigation Tools

The Unnest Shipping Container from Multi Order Pallet Web Service removes a shipping container from a multi order pallet. To achieve this operation follow these steps:

 Step 1: Retrieve shipping container to unnest

Perform a 'get' operation to retrieve the shipping container

How to: Shipping Container Web Service

 Step 2: Unnest shipping container from multi order pallet

To unnest a shipping container from a multi order pallet use the link on the shipping container and replace token {mopId} with the actual multi order pallet id.

 Request
  • URI: Use the shipping container entity retrieved in Step 1 to get the link to unnest from a multi order pallet (rel="unNestShippingContainerOnMultiOrderPallet")
  • Method: DELETE
  • Content-Type: application/json or application/xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
204 OK with no entity on the response
400 The following ErrorTypes can be expected: MultiOrderPallet, Warehouse, Container
