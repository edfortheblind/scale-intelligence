WM Capture Inventory Attributes
View with Navigation Tools
Integration Endpoints > Exit points > WM Capture Inventory Attributes

The system provides an exit point WM Capture Inventory Attributes , that should be used to let the system know if it should prompt for inventory attributes.

The exit point should return 'YES' to capture attirbutes, any other return value will skip the attributes entry.

 

The following example represents a sample implementation of the WM Capture Inventory Attributes/em> exit point program using a stored procedure. 

Sample exit point program for WM Capture Inventory Attributes exit point
Copy Code 
CREATE PROCEDURE [EXP_WmCaptureInventoryAttributes] (
    @SESSIONVALUE xml,
    @ITEM nvarchar(50),
    @COMPANY nvarchar(25),
    @LOCATION nvarchar(25),
    @RETURNVALUE nvarchar(max) output
)
AS 
    SET NOCOUNT ON; 
    --insert custom sql 
Set @RETURNVALUE = 'YES'
