How to: Create Monitor Page Stored Procedure
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Monitor Pages > How to: Create Monitor Page Stored Procedure

The Generic Monitor Data Retrieval web service is used to retrieve data from a stored procedure and return it to a Monitor page. Also see the How to Bind Controls on Monitor Page topic for more information on binding the data to the controls on the Monitor page.

 Stored Procedure in Detail
  • Stored Procedure Input Parameters: This stored procedure has two input parameters, FilterCriteria and culture. FilterCriteria can have multiple comma separated values and should end with a semicolon.
  • fn_GetMonitorFilterParameters Function: The Monitor stored procedure calls this SQL function to format the "FilterCriteria". This function returns a table which contains filterName and filterValue columns to represent the filter criteria name and value.
  • Return Data from Stored Procedure: The Monitor stored procedure returns data in a Table format. The table column details are outlined below.
Column Name Description
ChartData_<DataSourceName> This is the first column for the return data table. <DataSourceName> represents the data binding name for the control.
Data Defines the actual chart values.
Category Defines the data name for a chart.
XaxisTitle Defines the chart's X axis title.
YaxisTtile Defines the chart's Y axis title.
NextDrillDownLevel Defines the next level of drilldown for the chart. Use -1 for last level or no drilldown.
Example Monitor Stored Procedure
Copy Code 
Alter Procedure WRK_MonitorWorkGroupChartData
@filterCriteria nVarchar(MAX),
@culture nvarchar(10)
       
AS
    Set NoCount ON
    DECLARE @warehouse as nVarchar(50);
    DECLARE @criteriaTempTable TABLE (
   filterName nVarchar(300),
   filterValue nVarchar(300))
 /*get the where clause value*/
  INSERT INTO @criteriaTempTable SELECT * FROM fn_GetMonitorFilterParameters(@filterCriteria)
  SELECT @warehouse = filterValue from @criteriaTempTable WHERE filterName = 'FROM_WHS'
   
 
  SELECT 'CHARTDATA_MonitorWorkGroup' AS CHARTDATA_MonitorWorkGroup, CATEGORY = CASE WHEN  WORK_INSTRUCTION.WORK_GROUP IS NULL THEN 'Unassigned' ELSE WORK_INSTRUCTION.WORK_GROUP END,                                                                            
                                                                    COUNT(DISTINCT WORK_INSTRUCTION.WORK_UNIT)AS DATA,
                                                                    DESCRIPTION =CASE WHEN  WORK_INSTRUCTION.WORK_GROUP IS NULL THEN dbo.RSCMfn_RtrvResource('UNASSIGNED',N'text',@culture) ELSE GENERIC_CONFIG_DETAIL.DESCRIPTION END,   
                                                                    'WORKGROUP' AS XAXISTITLE, 'WORKUNITS' AS YAXISTITLE, 1 AS NextDrillDownLevel FROM WORK_INSTRUCTION
 LEFT OUTER JOIN GENERIC_CONFIG_DETAIL ON GENERIC_CONFIG_DETAIL.IDENTIFIER = WORK_INSTRUCTION.WORK_GROUP
 WHERE (WORK_INSTRUCTION.FROM_WHS =@warehouse OR WORK_INSTRUCTION.TO_WHS=@warehouse) AND WORK_INSTRUCTION.CONDITION != 'CLOSED'  and (GENERIC_CONFIG_DETAIL.RECORD_TYPE ='WORK GROUP' or GENERIC_CONFIG_DETAIL.RECORD_TYPE IS NULL)  GROUP BY WORK_INSTRUCTION.WORK_GROUP, GENERIC_CONFIG_DETAIL.DESCRIPTION ;

/* Summary Tiles End */                 
    If @@ERROR <> 0 GoTo ErrorHandler
    Set NoCount OFF
    Return(0)
 
ErrorHandler:
    Return(@@ERROR)
