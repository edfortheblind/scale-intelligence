How to: Set Content Loading Type
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Set Content Loading Type

The Content loading type value in metadata allows for specifying how you want to load content on a detail screen.

 Setting Content loading type on a new group or subgroup when metadata is created

In order to set the Content loading type on a group or subgroup as it is being created from metadata, simply set the CONTENT_LOADING_TYPE on the group or  subgroup.

 

 Modifying the Content loading type  for an existing group/subgroup

In order to change an existing group/subgroup to have a different content loading type, first find the Object Id of the group/subgroup. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find Object Id of group/subgroup
Copy Code 
select * from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>))

 

Then update the CONTENT_LOADING_TYPE field accordingly. Please see "Content loading type"  for an enumeration configuration of the available content loading type. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Modifying content loading type on group/subgroup
Copy Code 
update SCREEN_GROUP set CONTENT_LOADING_TYPE = '1' where OBJECT_ID = <object id>

 

Please note that the Content loading type is currently supported only for the accordion control and only on detail screens.
