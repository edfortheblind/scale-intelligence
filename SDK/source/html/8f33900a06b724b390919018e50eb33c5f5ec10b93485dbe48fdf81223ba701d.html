How to: Replace the Insight Sign On Logo
View with Navigation Tools

This topic will describe how to change the logo on the Insight Sign On screen.

The file paths in this topic refer to the default installation directory of SCALE on the application server. The files may be found in a different path on servers where the path was customized during installation.
 Step 1: Deploy the Image

The image first needs to be deployed to the Metadata Screen directory  %SCALE_HOME%\web\content.

It is recommended that custom images are placed in a new location  %SCALE_HOME%\web\content\manhcustom\images. This will ensure that the custom images are not lost when SCALE is upgraded.

To deploy the image, copy it to the  %SCALE_HOME%\web\content\manhcustom\images directory. If the directory does not exist it will have to be created.

For example, if we were deploying an image named example.png, after the above step you would find it at this path:  %SCALE_HOME%web\content\manhcustom\images\example.png.

When the replacement image is a different size than the shipped Manhattan logo, css can be added to style the image correctly.  For example, to configure the width of the image, custom css would need to be added as follows.

Change logo width
Copy Code 
.logo {width: 300px;}

See the How to: Override the Default Theme for the Metadata Screens topic for more information on editing the style in the manh.css file.

 Update the image in the Login.cshtml file

Open the Login.cshtml file in the  %SCALE_HOME%\web\views\security folder.

Replace the logo image file name ManhattanSCALE_fnl_white_384.png with the new image file name and save the changes to the file.

Below is an example of replacing the file name and path to point to the example.png file in the manhcustom\images location.

login
Copy Code 
<img class="img-responsive center-block" id="ManhLogoImage" style="visibility: visible;" src="/SCALE/Content/manhcustom/images/Example.png">
