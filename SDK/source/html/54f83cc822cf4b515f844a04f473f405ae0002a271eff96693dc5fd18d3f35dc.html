How to: Configure Security for a Dynamic Action
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Actions > How to: Configure Security for a Dynamic Action

Actions in the metadata screens use the same security concepts and configurations as the rest of the system. Follow the steps below to add security to an action on a metadata page.

 Step 1: Create a security checkpoint for the action

Create a SECURITY_CHECKPOINT record for the action that is tied to the appropriate Form Id.

Field Value
FORM_ID The Form Id for the current page that action will be added to.
CHECK_POINT Unique identifier for the checkpoint for the action. Custom checkpoints start at 21, so use the first available number after 21 for the Form Id.
RESOURCE_FILE_KEY Resource key that will be used to display the checkpoint in the "Security Permissions" screen.

 Step 2: Find the Object Id of the control that fires the action

Use the following SQL statement to find the control that fires the action you want to add security to. This will return all of the controls for the page and you will need to find the correct control from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page ).

Find the action
Copy Code 
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
        select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)));

 Step 3: Add a screen control attribute for the security checkpoint

Create a SCREEN_CONTROL_ATTRIBUTES record tied to the control for the security checkpoint. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
ATTRIBUTE_NAME data-securitycheckpoint
ATTRIBUTE_VALUE The security checkpoint configured in step 1
SCREEN_CONTROL_ID The Screen Control Id of the control that fires the action
IS_CONTROL_PROPERTY N
