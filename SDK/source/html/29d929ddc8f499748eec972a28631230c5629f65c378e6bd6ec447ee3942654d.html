RF View Picks SQL - Modify Exit Point
View with Navigation Tools
Integration Endpoints > Exit points > RF View Picks SQL - Modify Exit Point

System allows user to view all instructions associated with current work unit and select particular work instruction for execution from RF Pick Confirmation page through View Picks option. This option redirects to the Pick Instructions page which displays a list of work instructions associated with the current work unit. By default this page displays four columns i.e. Seq, Item, Loc, Qty. RF View Picks SQL – Modify exit point allows the user to customize the columns displayed on this page. In the SCALE configuration, this exit point can be found under Exit Point Controls -> Outbound -> RF View Picks SQL – Modify.

 

This exit point receives following four input parameters.

  • @SESSIONVALUE – Session(xml)
  • @WORKUNIT - Work unit
  • @WORKPROFILE - Work profile
  • @SQL  - Base SQL query which is used to fetch and display work instruction list

 

This exit point has an output parameter i.e. @RETURNVALUE. It returns the customized SQL query which overrides base SQL query to fetch and display work instruction list. Base SQL query looks as shown below

Base SQL query
Copy Code 
SELECT
    INTERNAL_INSTRUCTION_NUM AS 'HIDDEN_INTERNAL_INSTRUCTION_NUM',
    FROM_QTY AS 'HIDDEN_FROMQTY',
    CASE WHEN FROM_QTY > 0 THEN 1 ELSE 0 END AS 'HIDDEN_PICKED' ,
    dbo.IsWorkZoneAuthorized(@workProfile,FROM_WORK_ZONE) AS 'HIDDEN_IsWorkAuthorized',
    SEQUENCE AS 'SEQ',
    CASE WHEN SUBSTRING(ITEM, 13, 1) = '' THEN ITEM ELSE LEFT(ITEM, 10) + '..' END AS 'ITEM',
    CASE WHEN SUBSTRING(FROM_LOC, 13, 1) = '' THEN FROM_LOC ELSE LEFT(FROM_LOC, 10) + '..' END AS 'LOC',
    QUANTITY AS 'RF_QUANTITY' 
FROM WORK_INSTRUCTION WI
WHERE WORK_UNIT = @workUnit 
    AND INSTRUCTION_TYPE = 'DETAIL' 
ORDER BY CASE WHEN WI.FROM_QTY > 0 THEN 1 ELSE 0 END DESC,WI.SEQUENCE ASC

 Guidelines to modify the base SQL query
  • Columns with HIDDEN_ prefix indicate that this column value is not displayed in the page but it is rendered on the page. Base hidden columns should not be altered as these are used by backend processing while selecting the work instructions.
  • Alias names provided for all non-hidden columns should be valid resource keys.
