How to: Change Decimal Positions on Resources
View with Navigation Tools
Localization > How to: Change Decimal Positions on Resources

In the application you will notice that editable numeric fields may now show decimal positions where they haven’t in the past. These editable fields are tied to the resource file and not the Decimal Positions configuration at this time. To adjust the number of positions on these fields a modification via the System Text Editor is needed. This can be done by taking the following steps:

  1. Launch the System Text Editor from the Main UI
  2. When the following window appears look for keys related to the area you would like to change. If for example you want to change all Quantity fields to not show decimal positions you would probably want to search for QUANTITY and QTY in the Resource Key section.
  3. Customize the entries by right-clicking and choosing 'Open Custom Value'.
  4. Change the Decimal Position value from 5 to 0 and hit OK.
  5. Repeat for all keys you would like to change.
  6. Click Apply on the System Text Editor Window.
 Remove All Decimal Precision

If you wish to remove all decimal precision from fields across the entire system, you could run a quick query to update all of the fields at once to have a decimal position value of zero. The queries below will insert custom records for QUANTITY and QTY resources with a decimal pos value of 0. The resources will need to be regenerated after running these. You could pull out the resource key section that narrows the results down to QUANTITY if you wanted to do this over all keys.

 

SQL Server Syntax
Copy Code 
-- First update all existing custom records
UPDATE
        RESOURCE_FILE_CUSTOM
SET
        DECIMAL_POS = 0,
        USER_STAMP = 'System',
        PROCESS_STAMP = 'Decimal Pos = 0',
        DATE_TIME_STAMP = getDate()
WHERE
        (RESOURCE_KEY like '%QUANTITY%' OR RESOURCE_KEY LIKE '%QTY%')
        AND
        DECIMAL_POS = 5
        AND
        RESOURCE_GROUP = 'Text';

-- Next insert any missing custom records
INSERT INTO RESOURCE_FILE_CUSTOM
(
        RESOURCE_LANGUAGE,
        RESOURCE_GROUP,
        RESOURCE_KEY,
        TEXT,
        FIELD_LENGTH,
        DECIMAL_POS,
        USER_STAMP,
        PROCESS_STAMP,
        DATE_TIME_STAMP
)
SELECT
        RESOURCE_LANGUAGE,
        RESOURCE_GROUP,
        RESOURCE_KEY,
        TEXT,
        FIELD_LENGTH,
        0,
        'System',
        'Decimal Pos = 0',
        getDate()
FROM
        RESOURCE_FILE_BASE
WHERE
        (RESOURCE_KEY like '%QUANTITY%' OR RESOURCE_KEY LIKE '%QTY%')
        AND
        DECIMAL_POS = 5
        AND
        RESOURCE_GROUP = 'Text'
        AND
        NOT RESOURCE_KEY IN (
                SELECT
                        RESOURCE_KEY
                FROM
                        RESOURCE_FILE_CUSTOM
                WHERE
                        (RESOURCE_KEY like '%QUANTITY%' OR RESOURCE_KEY LIKE '%QTY%')
                        AND
                        RESOURCE_GROUP = 'Text');
