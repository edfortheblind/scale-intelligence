Authentication in REST-Based Web Services
View with Navigation Tools

One of the challenges to building any rest based web service/web api is having a well thought out authentication and authorization strategy. The most preferred mechanism is to authenticate client over HTTP using a signed token.

A token is a piece of data that has no meaning or use on its own, but combined with the correct tokenization system, becomes a vital player in securing your application. Token based authentication works by ensuring that each request to a server is accompanied by a signed token which the server verifies for authenticity and only then responds to the request.

In SCALE application, we use Bearer authentication (also called token authentication) which is an HTTP authentication scheme that involves security tokens called bearer tokens. The name “Bearer authentication” can be understood as “give access to the bearer of this token".

The bearer token is a cryptic string, usually generated by the server in response to a login request. The client must send this token in the Authorization header when making requests to protected resources:

 

Authorization: Bearer <token>

How to add ‘Authorization’ header?

In SCALE application, the ‘Authorization’ header can be added to the HttpRequest in below ways.

2) Client Credentials Grant with Confidential role token : This uses client credentials grant, which is for non interactive applications (a CLI, a daemon, or a Service running on your backend) where the token is issued to the application itself, instead of an end user. This will be presented with token marked as "Confidential", which can call only confidential role SCALE Api's.

Here, the ‘Authorization’ header is added to the HttpRequest, token is generated using AuthenticationHandler.AcquireToken() and is added to the Authorization header. The code for token generation is shown below:

C# - AuthenticationHandler
Copy Code 
 public static string AcquireToken()
        {
            bool retry = false; 
            int retryCount = 0; 
            do
            {
                try
                {
                    if (CacheProvider.Contains(NcacheAcquireTokenKey))
                    {
                        return CacheProvider.Get(NcacheAcquireTokenKey) as string;
                    }
                    var authContext = new AuthenticationContext(Authority);
                    ClientCredential clientCredential = new ClientCredential(ClientId, ClientSecret);
                    var authResult = authContext.AcquireTokenAsync(ClientId, clientCredential);
                    Task.WaitAll(authResult);
                    CacheProvider.Add(NcacheAcquireTokenKey, authResult.Result.AccessToken, new TimeSpan(0, 40, 0));
                    return authResult.Result.AccessToken;
                }
                catch (AdalException ex)
                {
                    if (ex.ErrorCode == "temporarily_unavailable")
                    {
                        retry = true;
                        retryCount++;
                        Thread.Sleep(3000);
                    } 
                    Logger.FatalFormat(
                        "An error occurred while acquiring a token\nTime: {0}\nError: {1}\nRetry: {2}\n", DateTime.Now, ex, retry);
                }
                catch (Exception ex)
                {
                    Logger.Fatal("ADAL Error: " + ex.Message + " call stack : " + ex.StackTrace);
                }
            } while (retry && retryCount++ < 3);
            return String.Empty;
        }

Once the token is generated it is sent through the request Authorization header.

private HttpWebRequest InitializeHttpWebRequest(string method, object httpEntity)
        {
            this.Uri = this.Uri.Trim();
            this.Uri = ConfigManager.GetUri(this.Uri);
            Validate.IsNotEmpty(this.Uri, "this.Uri");
            Validate.IsNotNegativeOrZero(this.TimeoutMillis, "this.TimeoutMillis");
            IMediaType acceptMediaType = this._mediaTypeConverter.GetMediaType(this._responseSerializer);
            Validate.IsNotNull(acceptMediaType, "acceptMediaType (" + this._responseSerializer + ")");
            HttpWebRequest httpWebRequest = HttpWebRequest.Create(this.Uri) as HttpWebRequest;
            httpWebRequest.Method = method;
            httpWebRequest.Timeout = this.TimeoutMillis;
            httpWebRequest.Accept = acceptMediaType.ToString();
            httpWebRequest.UseDefaultCredentials = true;
            this._httpRequestSession.AddCurrentSessionToRequest(httpWebRequest);
            if (!string.IsNullOrEmpty(this.AcceptEncoding))
                httpWebRequest.Headers[HttpRequestHeader.AcceptEncoding] = this.AcceptEncoding;
            if (httpEntity != null)
            {
                Stream requestStream = httpWebRequest.GetRequestStream();
                try
                {
                    if (this.RequestEncoder != null)
                    {
                        this.RequestEncoder.EncodeToStream(httpEntity, this._requestSerializer, requestStream);
                        string contentEncoding = this._encodingConverter.GetEncodingFromEncoder(this.RequestEncoder);
                        Validate.IsNotEmpty(contentEncoding, "contentEncoding");
                        httpWebRequest.Headers[HttpRequestHeader.ContentEncoding] = contentEncoding;
                    }
                    else
                    {
                        this._requestSerializer.SerializeToStream(httpEntity, requestStream);
                    }
                }
                finally
                {
                    if (requestStream != null)
                        requestStream.Close();
                }
                IMediaType contentMediaType = this._mediaTypeConverter.GetMediaType(this._requestSerializer);
                Validate.IsNotNull(contentMediaType, "contentType (" + this._requestSerializer + ")");
                httpWebRequest.ContentType = contentMediaType.ToString();
            }// end if
            else
            {
                httpWebRequest.ContentLength = 0;
            }// end else 
            httpWebRequest.Headers["Authorization"] = "Bearer " + AuthenticationHandler.AcquireToken();
            return httpWebRequest;
        }     
        #endregion InitializeHttpWebRequest

public string Post(ShippingContainersClosedRequest shippingContainersClosedRequest)
        {
            var client = new HttpClient();

            client.DefaultRequestHeaders.Accept.Clear();
            client.DefaultRequestHeaders.Accept.Add(new MediaTypeWithQualityHeaderValue("application/json"));

            HttpContent httpContent = BuildContent(shippingContainersClosedRequest);

        }

3) Client Credentials Grant with SCALEUser role token : This uses client credentials grant, which is for non interactive applications (a CLI, a daemon, or a Service running on your backend) where the token is issued to the application itself, instead of an end user. This will be presented with token marked as "SCALEUSER", which can call only SCALEUSER role SCALE Api's.

For this flow you need to create "API Confidential Application" as discussed in Single Sign on guides.

Use http request to get the token as below inputs

Method - POST

URL - Authentication instance+Tenant id/oauth2/token

Request Body for ADFS -

grant_type=client_credentials&client_id=API confidential client id&client_secret=API confidential client secret&resource=API confidential client id

Request Body for Microsoft Entra ID-

grant_type=client_credentials&client_id=API confidential client id&client_secret=API confidential client secret&resource=client id 

   
Change the highlighted values from SCALE single sign-on configuration. API confidential client secret is not part of SCALE single sign-on configuration. This value was generated when created API confidential client.Also, you need to have SCALE user profile for user SCALEAPI to use this token.
