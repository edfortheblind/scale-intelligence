Screen parts simply represent a portion of an overall web page. Screen parts are represented by the SCREEN_PART database table. There can be 1-N screen parts (ordered by the SEQUENCE field) for a particular page. Screen parts are tied to screens through the MAIN_UI_SCREEN table (SCREEN_PART.SCREEN_ID = MAIN_UI_SCREEN.OBJECT_ID). Please reference the "Screen Part Type" configuration for an enumeration of the available screen parts. Also, the table below gives more information on screen parts.

Type Value Control Name Control Type
DivContainer 10 Standard HTML Divs HTML
ModalDialog 20 Bootstrap-Modal (http://jschr.github.io/bootstrap-modal/) Bootstrap
 DivContainer

The DivContainer screen part is rendered as a simple div tag.

DivContainer HTML
Copy Code 
<div id="ScreenPartDivContainer21493" class="col-md-4 col-lg-4 searchpanepart" data-name="SearchPane" data-internalid="21493">

 ModalDialog

The modal dialog control is actually entered in metadata as a screen part so that other groups and controls can be tied to the modal dialog and rendered as "content" inside of the dialog. The modal dialog control is rendered in a partial view. Through this all metadata functionality is available within a modal dialog. 

ModalDialog HTML
Copy Code 
<div id="SaveSearchModalDialog" class="modal fade" data-bs-backdrop="static" tabindex="-1" role="dialog" aria-labelledby="modalLabel" aria-hidden="true"  data-controlType="modalDialog" data-controlId="21492" >
    <div class="modal-dialog">
        <div class="modal-content">
        </div>
    </div>
</div>


Modal dialogs have a special event parameter named “ModalDialogName” that is used to specify which modal dialog should be shown or hidden during processing. When calling an event that will show a modal dialog, create an event parameter with a name of "ModalDialogName" and a value of the name of the modal dialog control. See the How to: Create Screen Control Event Parameters topic for more information.

ModalDialogName event parameter HTML
Copy Code 
<script type="text/javascript">
    $(function () {if (typeof _webUi.dialog.showModalDialogByEvent === 'function') {  $(document).delegate('#SearchPaneMenuActionSaveSearch', 'click',{'ModalDialogName' : 'SaveSearchModalDialog'} ,_webUi.dialog.showModalDialogByEvent)} })
</script>

 Lookup

The Lookup screen part is rendered as a 2 main div tags. In the first div tag i.e ScreenSearchPartDivContainer , basic search criteria controls are rendered and in the second div tag i.e ScreenListPanePartDivContainer the grid is rendered. Both Basic search criteria and grid column controls are rendered dynamically based on recordtype
