Labor Event Web Service
View with Navigation Tools

The Labor Event Web Service allows consumers to log labor events in the application.

 Request
  • URI: http://ServerName/ILSIntegrationServices/laborEvents
  • Method: POST
  • Content-Type: application/vnd.manh.ils.labor.laborEvent+json or application/vnd.manh.ils.labor.laborEvent+xml
  • Entity: JSON, XML
  • Roles: SCALEUSER,Confidential

ActivityType, UserName and Warehouse are mandatory fields. If StartDateTime or EndDateTime are not provided, run-time timestamps will be set by default. If environment is not provided, ‘Default’ environment will be used. Status will be deemed to be ‘Ready’ if no value is provided.

 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
202

Accepted will be the typical response when the labor event is successfully logged for processing. It will be accompanied by a human readable message entity in the requested media type: application/vnd.manh.ils.labor.laborEvent+json, application/vnd.manh.ils.labor.laborEvent+xml

Link in the above response entity has the following properties
href href will point to the Query-String based Labor Search Web Service
type application/vnd.manh.ils.labor.laborEvent+json or application/vnd.manh.ils.labor.laborEvent+xml
rel laborEvent
400 Bad Request may be accompanied by the ActivityType, User or Warehouse ErrorTypes or it can indicate a generic request entity problem.
403 Forbidden response is given when Labor is turned off on the system.
412 This response will be given in scenarios where Labor module is not licensed or the LaborType used is not eligible for Labor logging.
