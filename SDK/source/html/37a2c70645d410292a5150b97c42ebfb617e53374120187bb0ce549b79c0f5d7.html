Field Restrictions
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Detail Pages > Field Restrictions

The base system is shipped with certain protected fields on a detail page as Label controls. However, since the detail pages are now being rendered via metadata, it would be simple to change some of these protected fields to be editors instead, which would allow those fields to be editable. For example, the Item field on the Work Instruction table is shipped as a label and needs to be protected. If it were editable and someone changed the item value on a work instruction, the work instruction would be corrupt at that point. To protect against this, the concept of field restrictions was created. Field restrictions are simply a list of fields on a detail page that should always be read-only, even if someone changes the metadata for that field to be an editor instead of a label. The restrictions lists are defined through a C# class that must implement the IScreenRestrictionsProcessor interface. Each detail page has its restrictions class defined via the RESTRICTIONS_ID (which represents Spring identifier) field on the corresponding MAIN_UI_SCREEN record for the screen. The base restrictions can be modified via the exit point defined in the topic How to: Customize Field Restrictions through Exit Point Programs.

public class WorkInstructionRestrictionsProcessor : IScreenRestrictionsProcessor
{
    public Dictionary<string,string> GetRestrictions(int internalNum, ScreenConstants.Mode screenMode, out bool restrictEntireScreen)     
    {
        //Dictionary containing restricted fields and error message to be displayed in case restriction is violated
        Dictionary<string, string> restrictions = new Dictionary<string,string>();
        WorkInstruction workInstruction = this._workInstructionDao.Get(internalNum);
        if (workInstruction != null)
        {
            restrictions = GetDefaultRestrictions();
            restrictEntireScreen = false;
            return restrictions;
        }
        else
        {
            //Get a message for this scenario
            restrictions.Add("All", "MSG_WORKINSTRUCTION03");
            restrictEntireScreen = true;
        }              
       
        return null;
    }
