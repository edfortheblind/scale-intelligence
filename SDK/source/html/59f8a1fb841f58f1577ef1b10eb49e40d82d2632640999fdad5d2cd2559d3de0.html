How to: Create Screen Control Events
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Create Screen Control Events

Control events represent an event that can be triggered against a web control, such as "click" or "onkeypress" or "textChanged". These are represented by the SCREEN_CONTROL_EVENT database table. There can be 1-N control events for a particular screen control. Control events are tied to screen controls by the SCREEN_CONTROL_ID field (SCREEN_CONTROL_EVENT.SCREEN_CONTROL_ID = SCREEN_CONTROL.OBJECT_ID).

Available events can be found within the external documentation for a particular control suite (i.e. IgniteUI documentation, JQueryUI documentation, etc.). Screen control events are rendered via JQuery binding as follows.

 Step 1: Determine the Object Id for the screen control

Use the following SQL to determine the Object Id for the screen control if you know the Form Id. This will return all screen controls on the page and you will need to find the appropriate screen control from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

 

Find the Object Id for screen control
Copy Code 
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))
 Step 2: Create screen control event record

Create a new record in the SCREEN_CONTROL_EVENT table tied to the corresponding SCREEN_CONTROL record for the screen control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

 

Field Description/Notes
EVENT_ID The identifier of the control specific event such as click or onkeypress.
EVENT_NAME The javascript function that could be called when event is triggered.
GRID_COLUMN Used to tie the event to a grid column. Should be filled with the FIELD_NAME value from the SCREEN_CONTROL_GRID_COLUMNS table.
       
Please note that the dbc_IScreenControlEvent stored procedure can be used to create screen control events.
Please note there is a new special event called DOMCONTENTLOADED to call anything on DOM Ready using metadata. Configure this event in metadata (follow standard event related metadata) for any control to call specific javascript function on DOM Ready event. Parameters passed to handler are control name (automatically) and all configured event parameters in metadata.
