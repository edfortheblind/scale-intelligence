REST-Based Web Services
View with Navigation Tools
In the application, REST-Based Web Services describe the set of business resources accessible through the standard HTTP protocol.
Related topics:
  • Authentication in REST-Based Web Services - Contains information and examples of how to invoke web services that require authentication.
  • Calling a REST-Based Web Service - Contains examples in C# and JavaScript that illustrate how to programmatically interact with services.
  • Compression in REST-Based Web Services - Describes how compressed entities can be supplied to and requested from REST-Based Web Services in the application, with C# examples.
  • HTTP Headers in REST-Based Web Services - Describes the common use of HTTP headers by REST-Based Web Services in the application.
  • Links in REST-Based Web Service Entities - Describes the purpose and structure and links found within REST-Based Web Service Entities.
  • Standard Responses from REST-Based Web Services - Describes standard application responses.

 

Additional Notes:

  • The Integration Service Simulator of the SCALE Toolbox (Testing group) has a tab labeled "REST" that can be used to test all of the below REST-Based Web Services with required headers.
  • Swagger can be used to view and test all webAPI REST services.       
  • If environments are configured in SCALE then subdomain of webservice hostname should match with environment name.
  • Default connecting string(Toolbox connection string) should be configured as environment if any environment is configured in SCALE.
