How to: Add Menu Options to a Details/Transaction Screen Grid
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Detail Pages > How to: Add Menu Options to a Details/Transaction Screen Grid

Follow these steps to add the menu options for the grid that are standard for the detail and transaction pages.

 Step 1: Create required modal dialogs
If any actions on the detail screen grid will require input via modal dialogs, create them. Please reference the How to: Create a Dynamic Modal Dialog topic for more information.
 Step 2: Create new menu screen groups
       

Add a SCREEN_GROUP record as follows in order to create an actions menu for the detail screen grid. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the detail Page
GROUP_NAME [GridName]Menu
RESOURCE_KEY NULL
GROUP_TYPE 70 (Menu)
PARENT_GROUP_ID NULL
NESTED_GROUP_UNIT 0
DIV_CSS_CLASS row ScreenGroupPanel cruddetailtitlepanel nav nav-pills
ROW_CSS_CLASS row transparentscreengroup


Add a SCREEN_GROUP record as follows in order to create Title Panel. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the detail Page
GROUP_NAME [GridName]TitlePanel
RESOURCE_KEY NULL
GROUP_TYPE 60 (Panel)
PARENT_GROUP_ID The Screen Group Id of the menu SCREEN_GROUP in the detail page
NESTED_GROUP_UNIT The Screen Group Id of the menu SCREEN_GROUP in the detail page
DIV_CSS_CLASS pull-left menubuttonpanel
ROW_CSS_CLASS NULL
 Step 3: Create screen control related records for each action
 Create menu button screen control

Now add a SCREEN_CONTROL record as follows for the Menu Button control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the title panel
CONTROL_NAME [GridName] MenuAction [Action]
RESOURCE_KEY Resource key for the button
CONTROL_TYPE 150 (Menu Button)
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE NULL
DATA_SOURCE NULL
DIV_CSS_CLASS pull-right menubutton
CONTROL_CSS_CLASS dropdownaction pull-right menubutton cruddetailmenubutton
 Add security for the menu button
Reference the How to: Configure Security for a Dynamic Action topic in order to add security for the new action.
 Create a screen control event record tied to the menu button control
Reference the How to: Create Screen Control Events topic in order to add event for the new control.
 Create screen control event parameters record tied to the event
Reference the How to: Create Screen Control Event Parameters topic in order to add event parameters for the new event.
