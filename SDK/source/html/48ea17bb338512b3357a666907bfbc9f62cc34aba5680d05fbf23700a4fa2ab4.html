How to: Add Basic Criteria to Search Pane
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Search Pane > How to: Add Basic Criteria to Search Pane

Adding input controls inside a "Basic Criteria" section to the search pane on an insight page simply requires adding a new sub-accordion SCREEN_GROUP and new SCREEN_CONTROL records for all input controls.

 Step 1: Create a new accordion screen group if one doesn't exist

If the outer accordion SCREEN_GROUP record does not exist, then it needs to be created as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the search pane
GROUP_NAME SearchPaneCriteria
RESOURCE_KEY NULL
GROUP_TYPE 40 (Accordion)
PARENT_GROUP_ID NULL
NESTED_GROUP_UNIT Set this equal to the Object Id for this SCREEN_GROUP record after it is created
DIV_CSS_CLASS NULL
ROW_CSS_CLASS row searchpanecriteria
 Step 2: Create a new sub-accordion screen group

When adding a new Basic Criteria section from scratch, it will be done within a new sub-accordion on the search pane. Add a SCREEN_GROUP record as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the search pane
GROUP_NAME Name of the screen group
RESOURCE_KEY Resource key that will be translated as the sub-accordion title
GROUP_TYPE 50 (Sub-accordion)
PARENT_GROUP_ID The Screen Group Id of the main accordion SCREEN_GROUP in the search pane
NESTED_GROUP_UNIT The Screen Group Id of the main accordion SCREEN_GROUP in the search pane
DIV_CSS_CLASS NULL
ROW_CSS_CLASS NULL
 Step 3: Create screen control records for each input control

Now add SCREEN_CONTROL and SCREEN_CONTROL_ATTRIBUTES records for each input control that should be inside the basic criteria section. Reference the How to: Create Screen Controls topic for more information.
