How to: Create Screen Group Columns
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Create Screen Group Columns

Screen group columns represent nested bootstrap columns within a screen group. Screen group columns are represented by the SCREEN_GROUP_COLUMN database table. There can be 0-N screen group columns (ordered by the SEQUENCE field) for a particular screen group. Ideally since bootstrap is being used there would be no more than 12 columns configured for a single screen group.  Screen group columns are tied to screen groups by the SCREEN_GROUP_ID field (SCREEN_GROUP_COLUMN.SCREEN_GROUP_ID = SCREEN_GROUP.OBJECT_ID).

 Step 1: Determine the Object Id for the screen group

Use the following SQL to determine the Object Id for the screen group if you know the Form Id. This will return all screen groups for the page and you will need to pick the appropriate group from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find the Object Id for screen group
Copy Code 
select * from SCREEN_GROUP where SCREEN_PART_ID in (
    select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
        select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>))
 Step 2: Create screen group column record

Create a new record in the SCREEN_GROUP_COLUMN table tied to the corresponding SCREEN_GROUP record for the screen group. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Description/Notes
COLUMN_NAME The name of the screen group column.
COLUMN_CSS_CLASS The css class for the given column - used by Bootstrap to define column properties and appearance.
SEQUENCE Screen group columns are rendered in sequence order.

Please note that the dbc_IScreenGroupColumn stored procedure can be used to create screen group columns.
