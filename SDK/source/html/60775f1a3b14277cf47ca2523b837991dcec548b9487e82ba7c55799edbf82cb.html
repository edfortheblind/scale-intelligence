How to: Create Screen Control Attributes
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Create Screen Control Attributes

Control attributes are name/value pairs that are stored as html attributes for a web control. This provides for an easy way to store important data tied to a particular control in a dynamic fashion. The attributes are represented by the SCREEN_CONTROL_ATTRIBUTES database table. There can be 1-N control attributes for a particular screen control. Control attributes are tied to screen controls by the SCREEN_CONTROL_ID field (SCREEN_CONTROL_ATTRIBUTES.SCREEN_CONTROL_ID = SCREEN_CONTROL.OBJECT_ID).

Screen control attributes are rendered via JQuery binding as follows.

Custom Html Attribute
Copy Code 
<script type="text/javascript">
    $(function () { $('#BasicCriteriaItem').attr({ 'data-dbcolumn': "Item" }); })
</script>

 Step 1: Determine the Object Id for the screen control

Use the following SQL to determine the Object Id for the screen control if you know the Form Id. This will return all screen controls on the page and you will need to find the appropriate screen control from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

 

Find the Object Id for screen control
Copy Code 
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))
 Step 2: Create the screen control attributes record

Create a new record in the SCREEN_CONTROL_ATTRIBUTES table tied to the corresponding SCREEN_CONTROL record for the screen control. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Description/Notes
ATTRIBUTE_NAME The name of the attribute. Can either be a control specific attribute name or a custom attribute name.
ATTRIBUTE_VALUE The value that should be created in Html for the attribute.
IS_CONTROL_PROPERTY Is this attribute a pre-defined attribute on the control itself? Please reference Supported Control Properties for more details. Properties that have this field set as "N" are used to simply store data as a custom attribute on the control and can be used for selecting fields in JQuery or any other use in JavaScript.

 

Please note that the dbc_IScreenControlAttributes stored procedure can be used to create screen control attributes.
