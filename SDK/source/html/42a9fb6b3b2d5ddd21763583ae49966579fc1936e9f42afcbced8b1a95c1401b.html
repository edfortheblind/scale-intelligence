How to: Add Advanced Criteria to Search Pane
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Search Pane > How to: Add Advanced Criteria to Search Pane

The Advanced Criteria control allows for the "advanced search" section within a metadata insight screen to be easily applied within the metadata. Adding an Advanced Criteria control to the search pane on an insight page simply requires adding a new sub-accordion SCREEN_GROUP and a new advanced criteria SCREEN_CONTROL record.

 Step 1: Create a new sub-accordion screen group

When adding a new Advanced Criteria section from scratch, it will be done within a new sub-accordion on the search pane. Add a SCREEN_GROUP record as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the search pane
GROUP_NAME SearchPaneAdvancedCriteria
RESOURCE_KEY ADVANCEDCRITERIA
GROUP_TYPE 50 (Sub-accordion)
PARENT_GROUP_ID The Screen Group Id of the main accordion SCREEN_GROUP in the search pane
NESTED_GROUP_UNIT The Screen Group Id of the main accordion SCREEN_GROUP in the search pane
DIV_CSS_CLASS NULL
ROW_CSS_CLASS NULL
 Step 2: Create a new advanced criteria screen control

Now add a SCREEN_CONTROL record as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the sub-accordion that will hold the Advanced Criteria control.
CONTROL_NAME SearchPaneAdvCrit
RESOURCE_KEY NULL
CONTROL_TYPE 70 (Advanced Criteria)
LABEL_ORIENTATION 20 (Inline)
DATA_SOURCE_TYPE 40 (TableFields)
DATA_SOURCE The name of the database table or view the control should be tied to.
DIV_CSS_CLASS advancedCriteriaInline
CONTROL_CSS_CLASS NULL
