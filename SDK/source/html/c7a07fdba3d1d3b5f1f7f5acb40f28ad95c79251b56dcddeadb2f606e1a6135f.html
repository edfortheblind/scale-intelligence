Short Pick Replenishment Web Service
View with Navigation Tools

The Short Pick Replenishment Web Service accepts details related to location, item and the shortfall quantity. The web service checks if there is any existing in-transit movement which can satisfy the current pick requirement. If none exists, the web service will try to replenish the location by running the replenishment masters configured for this type of replenishment. After replenishing, in-transit is checked again. The service then reports the status back to the caller.

 Request
  • URI: http://ServerName/ILSIntegrationServices/ShortPickReplenishment
  • Method: POST
  • Content-Type: application/vnd.manh.ils.inventory.shortPickReplenishment+json or application/vnd.manh.ils.inventory.shortPickReplenishment+xml
  • Entity: JSON
  • Roles: SCALEUSER
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200

OK will be accompanied by an entity in the requested media type: JSON
400 Bad Request may be accompanied by the Item, Location or Warehouse ErrorTypes or it can indicate a generic request entity problem.
