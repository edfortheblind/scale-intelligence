How to: Add Validation to Modal Dialog Controls
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Add Validation to Modal Dialog Controls

The input controls within a modal dialog control use JQuery validation and must be inside a form tag for the validation to function properly. Validation can be configured for an input control via the standard JQuery validation Html attributes.

 Step 1: Create ModalDialog
Please reference the How to: Create a Dynamic Modal Dialog topic for details on creating a modal dialog control.
 Step 2: Add validation attributes

In order to add validation to an input control, create a SCREEN_CONTROL_ATTRIBUTES record with ATTRIBUTE_NAME of the appropriate JQuery Validation attribute (http://jqueryvalidation.org/documentation/) and ATTRIBUTE_VALUE of "true". Also create another SCREEN_CONTROL_ATTRIBUTES record with ATTRIBUTE_NAME of the appropriate JQuery Validation Message attribute and ATTRIBUTE_VALUE of the correct error resource key. For example, to make an input control be required, add an attribute for "data-rule-required = true" and "data-msg-required = <error msg key>". These message keys in metadata are rendered in HTML as the translated resource text (see below). Please reference the How to: Create Screen Control Attributes topic for more details. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
