QC Confirmation Web Service
View with Navigation Tools

The QC Confirmation web service allows a consumer to perform QC counts for the item contents of a Shipping container.  This is achieved by executing the following steps:

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Retrieve the ShippingContainer using its link

The Shipping resource representation will include the link to the Shipping Containers Resource. The link (rel="shippingContainer") has a href that is a URI template with the {warehouse} and {containerId} tokens.  To fetch the Shipping Container representation, substitute the tokens and perform an HTTP GET:

How to: Shipping Container Web service

 Step 3: Retrieve the ShippingContainerQcCounts using its qcCounts link

The Shipping Container resource representation will include the link to its QC Counts collection resource. The link has a href that is a URI template with the {intContNum} token.  To fetch the QC Counts, substitute the token with the Shipping Container's InternalContainerNum and perform an HTTP GET:

Request:

  • URI: From ShippingContainer's link (rel="qcCounts") href
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by the updated ShippingContainer conforming to one of the media types: application/vnd.manh.ils.shipping.shippingContainerQcCounts+json, XML 

 Step 4: Post the ShippingContainerQcCounts using its completed link

The Shipping Container QC Counts collection resource representation will include a completed link. To do a QC Confirmation for the shipping container, fill the relevant QC data into each ShippingContainerQCCount representation and perform an HTTP POST with the following:

Request:

  • URI: From ShippingContainerQcCounts' link (rel="completed") href
  • Method: POST
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: The updated ShippingContainerQcCounts from Step 3

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by the updated ShippingContainerQcCounts with the QcStatus field representing a Success or failure. The Response conforms to one of the media types: application/vnd.manh.ils.shipping.shippingContainerQcCounts+json, XML 
400

The following ErrorTypes can be expected: Container, Item, Quantity
