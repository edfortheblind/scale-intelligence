How to: Tie an Insight Page to a Table or View
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > How to: Tie an Insight Page to a Table or View

An insight screen can currently only be driven from a single database entity (either table or view). This entity is defined by the "data-dbtable" Html attribute on the list pane grid control. 

data-dbtable attribute
Copy Code 
<script type="text/javascript">
    $(function () { $('#ListPaneDataGrid').attr({
    'data-dbtable': "Metadata_Insight_Shipment_View" });})
</script>

This attribute should be created or modifed in the metadata for the grid control on an insight screen within the SCREEN_CONTROL_ATTRIBUTES table.

 Modify an existing insight screen to point to a different table or view

In order to change an existing Insight screen to point to a different table or view, follow the steps below.

 Step 1: Find the SCREEN_CONTROL record for the insight grid

Use the following SQL statement to locate the grid using the corresponding Form Id. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find grid control record
Copy Code 
select * from SCREEN_CONTROL where CONTROL_TYPE = '20' and SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))

 Step 2: Update the data-dbtable attribute with new table or view

Use the following SQL statement to modify the table or view that the insight screen is using. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Modify data-dbtable attribute
Copy Code 
update SCREEN_CONTROL_ATTRIBUTES set ATTRIBUTE_VALUE = '<new table or view>'
where SCREEN_CONTROL_ID = <control id of grid> and ATTRIBUTE_NAME = 'data-dbtable'

Please note that changing the table or view on an insight screen only changes the table or view that the insight page selects from. If specific controls reference column names that do not exist in the table or view, errors will occur on the screen. The individual columns that other controls point to will need to be updated as well. Please reference the How to: Create Insight Search Pane for more details.

 Create a new insight page tied to a table or view
Tying a new insight page to a table or view is as simple as creating a new SCREEN_CONTROL_ATTRIBUTES record with ATTRIBUTE_NAME = "data-dbtable" and ATTRIBUTE_VALUE = "<table or view name>" that is linked to the SCREEN_CONTROL record for the grid on the page. Please reference the How to: Create Insight List Pane topic for more details on creating a grid on an insight screen. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
