How to: Default the Order By Column in a Grid
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Default the Order By Column in a Grid

Grids store column sorting information on a user/browser/device basis and remember these settings. However, grids can also be configured to have default sort columns which apply until the first time a user sorts by a column from within the grid itself. Follow the steps below to set a default sort column for a grid.

 Find the appropriate screen control grid column record for the default sort column

Use the following SQL to determine the Object Id for the screen control grid columns that are stored in the grid if you know the Form Id. This will return all screen control grid columns and you will need to find the appropriate column from the list. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find existing screen control grid columns
Copy Code 
select * from SCREEN_CONTROL_GRID_COLUMNS where SCREEN_CONTROL_ID IN (
    select OBJECT_ID from SCREEN_CONTROL where SCREEN_GROUP_ID in (
        select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
            select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
                select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>))))

If there are any records that have a SQL_CLAUSE_TYPE = 30 (Order By), then there are already default sort columns on the grid. Once these records are found, you can either update those records or create new ones to get the correct sort columns.

 Update or insert screen control grid columns for the default sort order

If records already exist, the default sort order can be changed by simply changing the FIELD to a new value. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Updating sort order
Copy Code 
update SCREEN_CONTROL_GRID_COLUMNS set FIELD = '<new sort column>' where OBJECT_ID = <object id>

If no records exist, or you need to add new columns to the existing sort order, then create a new SCREEN_CONTROL_GRID_COLUMNS record. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_ID The Object Id of the grid control
FIELD The column name to sort by
FIELD_NAME NULL
FIELD_WIDTH NULL
FIELD_TYPE NULL
SQL_CLAUSE_TYPE 30 (Order By)
SEQUENCE Use this field to determine the order of the default sort columns
RESOURCE_KEY NULL
HIDDEN N
DECIMAL_POSITIONS NULL
