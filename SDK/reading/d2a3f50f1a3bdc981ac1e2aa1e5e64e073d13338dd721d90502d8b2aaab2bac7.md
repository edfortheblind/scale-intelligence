    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">The Advanced Criteria control is tied to a single database table or view. This is accomplished by setting the DATA_SOURCE_TYPE = 40 (TableFields - loads columns from database table) and DATA_SOURCE = &lt;table or view name&gt;. See the <a href="bb522128265dc8e032acf43909a28cdb0383a4c646d9bddef63fdc9e27ce292e.html" data-source-node="n48">How to: Create Screen Controls</a> topic for more details. The Advanced criteria control will fill the "Field" drop down with all of the available fields in the database table or view. The "Operand" drop down and "Value" controls will be updated based on the "Field" chosen. In order to tie a specific field with the correct operands and field types, the FILTER_ATTRIBUTES table needs to have the proper record created. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n49"><u data-source-node="n50"><font color="navy" data-source-node="n51">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>

<p data-source-node="n52"><br data-source-node="n53"></p>

<table data-source-node="n54">
    <tbody data-source-node="n55">
        <tr data-source-node="n56">
            <td data-source-node="n57"><strong data-source-node="n58">Field</strong></td>

            <td data-source-node="n59"><strong data-source-node="n60">Description</strong></td>
        </tr>

        <tr data-source-node="n61">
            <td data-source-node="n62">ATTRIBUTE</td>

            <td data-source-node="n63">Field name with underscores stripped out (i.e. INTERNAL_SHIPMENT_NUM database field should be created with ATTRIBUTE of INTERNALSHIPMENTNUM)</td>
        </tr>

        <tr data-source-node="n64">
            <td data-source-node="n65">VALIDATION_LIST</td>

            <td data-source-node="n66">The type of list that should be tied to the "Value" control when referencing the associated ATTRIBUTE. Please see the <a href="214eb77fcca668e6d3d5cd9070338718eb6ee7521adef16d8be75751c6a0e94f.html" data-source-node="n67">How to: Define Lists tied to Controls</a> topic for more details.</td>
        </tr>

        <tr data-source-node="n68">
            <td data-source-node="n69">FIELD_TYPE</td>

            <td data-source-node="n70">The type of the field. The valid types are ALPHA, DATE, DATETIME, DECIMAL, and NUMBER. This value also defines the operand list tied to the ATTRIBUTE through the "Metadata Filter Operand" configuration.</td>
        </tr>

        <tr data-source-node="n71">
            <td data-source-node="n72">RECORD_TYPE</td>

            <td data-source-node="n73">For lists that require a parameter value, pass it here. For example, to display a list of countries, specify a VALIDATION_LIST of "Generic" and a RECORD_TYPE of "COUNTRY".</td>
        </tr>
    </tbody>
</table>

<p data-source-node="n74"></p>

<div class="i-box i-box-note" data-source-node="n75">
    Please note that the default is ALPHA with no list tied to the control. This means that if no record with a matching ATTRIBUTE is found, the resulting "Value" control will be treated as an ALPHA control with no drop down.
</div>
