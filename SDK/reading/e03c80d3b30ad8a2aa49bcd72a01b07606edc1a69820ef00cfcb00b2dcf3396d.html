Labor Update Web Service
View with Navigation Tools

The Labor Update Web Service allows consumers to update the fields of an identified resource.

 Request
  • URI:http://ServerName/ILSIntegrationServices/laborEvents?internalDetailNum={internalDetailNum}
  • Method: PUT
  • Content-Type: application/vnd.manh.ils.labor.laborDetail+json or application/vnd.manh.ils.labor.laborDetail+xml
  • Entity: JSON, XML
  • Roles: SCALEUSER,Confidential

The InternalDetailNum of the request entity should match the internalDetailNum provided in the URL. DateTimeStamp of the request entity will be ignored and run-time timestamp will be used. When StartDateTime or EndDateTime is not provided, previous values will be retained.

 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200

This is the success response. It will be accompanied by a human readable message entity in the requested media type: application/vnd.manh.ils.labor.laborEvent+json, application/vnd.manh.ils.labor.laborEvent+xml

Link in the above response entity has the following properties
href href will point to the Internal Detail Number based Labor Search Web Service
type application/vnd.manh.ils.labor.laborEvent+json or application/vnd.manh.ils.labor.laborEvent+xml
rel self
400 When internalDetailNums of the url and request entity do not match, it is deemed to be a bad request.
