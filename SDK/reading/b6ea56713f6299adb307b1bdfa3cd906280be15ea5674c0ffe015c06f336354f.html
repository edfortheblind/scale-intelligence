How to: Create an Indicator Tile on an Insight Detail Pane
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Detail Pane > How to: Create an Indicator Tile on an Insight Detail Pane

Tiles can be added to the Detail pane of an Insight screens. These tiles are clickable and will open another Insight screen with applied filters.

 Step 1: Modify or create the Detail pane stored procedure

Tiles on the Detail pane are bound with data in the same fashion as all other data on the detail pane. Please reference the topic How to: Bind Detail Pane Controls for instructions on binding a tile on the Detail pane.   

 Step 2: Create a panel screen group to house the Indicator Tile

Add a SCREEN_GROUP record as follows in order to create a panel to hold the Indicator tile. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the Monitor Pane
GROUP_NAME The name of the group
RESOURCE_KEY NULL
GROUP_TYPE 60 (Panel)
PARENT_GROUP_ID NULL
NESTED_GROUP_UNIT 0
DIV_CSS_CLASS listpanesummarypanelgroup equalize
ROW_CSS_CLASS row indicatortilepanel
 Step 3: Create a Screen Control for the Indicator Tile

Add a SCREEN_CONTROL record as follows for the tile. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of the panel that will hold the tile
CONTROL_NAME The name of this tile control
RESOURCE_KEY The resource key of the label to show for the tile control
CONTROL_TYPE 360 (Insight Indicator tile)
DATA_SOURCE_TYPE 20 (Data-bind attribute - sets data from the ajax response)
DATA_SOURCE The data source that will be used to fill the control.
DIV_CSS_CLASS col-3 col-sm-3 col-md-12 col-lg-12
CONTROL_CSS_CLASS indicatortile
 Step 4: Create Screen Control Attributes for the Indicator Tile

Add a SCREEN_CONTROL_ATTRIBUTES record as follows for the tile. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Description

data-indicatorTileGoToInsight

URL template and the parameters to be redirected to the insight page are defined here.

e.g.

Use the ALT+219 █ character for the separator characters in the path as shown below.

 

{{FORM_ID=2757}}?filters=SearchPaneWhs █ {{{Warehouse}}},BasicCriteriaItem █ {{{Item}}},SearchPaneComp █ {{{Company}}},BasicCriteriaFromLoc █ {{{Location}}},BasicCriteriaInstrType █ {{{InstructionType}}}

FORM_ID=<form id>: This indicates that when the tile is clicked the insight page corresponding to the <form id> is displayed.
SearchPaneWhs, etc.: The token values defined here will bind to the Basic Criteria search on the Insight page. Currently only basic criteria filters are supported when clicking/tapping on a tile from an Insight Detail pane.
