Labor Search Web Service
View with Navigation Tools

The Labor Search Web Service allows consumers to search for already logged labor events.

This web service can be invoked in 2 ways.

1. Internal Detail Number based
 Request
  • URI:http://ServerName/ILSIntegrationServices/laborEvents/{InternalDetailNum}
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.labor.laborEvent+json , application/vnd.manh.ils.labor.laborEvent+xml.

Response will contain the single entity which was requested.
Link in the above response entity has the following properties
href href will point to the Internal Detail Number based Labor Search Web Service
type application/vnd.manh.ils.labor.laborEvent+json or application/vnd.manh.ils.labor.laborEvent+xml
rel self
204 A no content response is issued when the requested resource is not found in the system.

2. Query-String based
 Request
  • URI:http://ServerName/ILSIntegrationServices/laborEvents?{Query-String}
  • Method: GET
  • Accept: application/json or application/xml

The {Query-String} can contain any of the field values of the resource as key-value pairs. DateTimes should be in the standard string representation (ex 12/1/2009 3:16:09 PM).

A sample query string will look like
http://ServerName/ILSIntegrationServices/LaborEvents?ActivityScreen=SomeScreen&ActivityType=SomeType&EndDateTime=12/1/2009 3:16:09 PM&StartDateTime=12/1/2009 3:16:09 PM&UserName=SomeUser

 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.labor.laborEvents+json , application/vnd.manh.ils.labor.laborEvents+xml.

Response will contain a list of entities matching the request.
Links in each of the entities in the list above has the following properties
href href will point to the Internal Detail Number based Labor Search Web Service
type application/vnd.manh.ils.labor.laborEvent+json or application/vnd.manh.ils.labor.laborEvent+xml
rel self
204 A no content response is issued when the requested resource is not found in the system.
