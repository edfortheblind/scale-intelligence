    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Labels can be applied both individually as well as in conjunction with another control. If a label will be inserted by itself as a standalone control, it must be created through metadata using the Label control. Labels that will be tied to another control are NOT entered in metadata, but are created automatically based on the "Label Orientation" specified for the main control (as well as the "Resource Key" specified on the control). Please see the "Label Orientation" configuration for an enumeration of the available label orientations.</p>

<p data-source-node="n48"></p>

<div id="i-f272dbe8-d120-4941-a3f5-3778a64e850b-section-heading" class="i-section-heading" data-source-node="n49">
    <span class="i-section-heading-icon" data-source-node="n50"><span class="i-hidden" data-source-node="n51"> </span></span><span class="i-section-heading-text" data-source-node="n52">Setting label orientation on a new control when metadata is created</span>
</div>

<div id="i-f272dbe8-d120-4941-a3f5-3778a64e850b-section-content" class="i-section-content" data-source-node="n53">
    In order to set the label orientation on a control as it is being created from metadata, simply set the LABEL_ORIENTATION and the RESOURCE_KEY on the control that the label should be tied to. Please reference the <a href="bb522128265dc8e032acf43909a28cdb0383a4c646d9bddef63fdc9e27ce292e.html" data-source-node="n54">How to: Create Screen Controls</a> topic for more details. Also see the "Label Orientation" configuration for an enumeration of the available label orientations.
</div>
