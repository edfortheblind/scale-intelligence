Work Profile Warehouse Authorization Exit Point
View with Navigation Tools

The system provides an exit point Work Profile Warehouse Authorization, that should be used to override the list of work profiles that can be viewed in various screens. The sql utility function ModifyCharacterSeparatedStringList can be used to modify work profiles in stored procedure exit point programs.

 

The following example represents a sample implementation of the Work Profile Warehouse Authorization exit point program using a stored procedure. 

Sample exit point program for Work Profile Warehouse Authorization exit point
Copy Code 
CREATE PROCEDURE [EXP_WorkProfileWarehouseAuthorization] (
    @SESSIONVALUE xml,
    @WORKPROFILELIST nvarchar(max),
    @RETURNVALUE nvarchar(max) output
)
AS
    SET NOCOUNT ON;
    DECLARE @workProfilesToAdd nvarchar(max), @workProfilesToRemove nvarchar(max);
    SET @workProfilesToAdd = '';
    SET @workProfilesToRemove = '';

        -- Update the list using Pipe character as the separator
        SELECT @RETURNVALUE = dbo.ModifyCharacterSeparatedStringList(@WORKPROFILELIST, @workProfilesToAdd, @workProfilesToRemove, '|')
