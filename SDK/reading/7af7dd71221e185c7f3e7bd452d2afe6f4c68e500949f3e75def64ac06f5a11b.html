The complex screen architecture exists to create complex transaction screens using a mixture of metadata and Knockout components. The code for these screens is under <installDirectory>/web/dist and also served from there. The technologies used in this architecture are as follows:

  • Knockout
  • Typescript
  • Syntactically Awesome Style Sheets (SASS)

The complex screens are written with Knockout component binding (http://knockoutjs.com/documentation/component-binding.html). Each component uses extensive Knockout binding (http://knockoutjs.com/documentation/introduction.html).

The complex screens still use the Infragistics IgniteUI controls with their Knockout support. There are also other custom bindings created by Manhattan Associates such as “EnterKey” and “Modal” bindings. Each Knockout component has Typescript files, HTML files and a SASS file. There are also other Typescript files which are referenced by the main Component.ts file.
