    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">This allows XML download of Item Master data into the application. For more specifics and examples on Interfacing in the application, consult the help.</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Request</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <ul data-source-node="n47">
        <li data-source-node="n48"><strong data-source-node="n49">URI:</strong> http://<i data-source-node="n50">ServerName</i>/general/interfaces/items-Downloaded</li>

        <li data-source-node="n51"><strong data-source-node="n52">Method:</strong> POST</li>

        <li data-source-node="n53"><strong data-source-node="n54">Content-Type:</strong> application/json or application/xml</li>

        <li data-source-node="n55"><strong data-source-node="n56">Entity:</strong> <a href="../source/downloads/18abcedd1ec34ceeda37653cc96316ca9e67414488d6b4d92a5520aa9cc2ba3a.json" data-source-node="n57">application/vnd.manh.ils.interfaces.interfaceRequest+json</a>, <a href="../source/downloads/4351673f9fa2a3c2659b42ee9f4b15cae228bb24f512d4da4b77b6bf307dc78a.xsd" data-source-node="n58">xml</a></li>

        <li data-source-node="n59"><strong data-source-node="n60">Roles:</strong> SCALEUSER,Confidential</li>
    </ul>

    <p data-source-node="n61">    Note that the xmlData field in the request must conform to <a href="../source/downloads/9c4337dbc90559cd133743c91468dcee3b998d6f08f2a951ac7432f464d65828.xsd" data-source-node="n62">ItemDownload.xsd</a> schema. Also, if a XML content-type is used then the xmlData element must have a string value that is encoded to ensure a well-formed xml interfaceRequest.</p>
</div>
