Screen control attributes have an IS_CONTROL_PROPERTY that is used to determine whether the attribute is tied to a specific property of the control or if it is just a custom html attribute that should be tied to the control. The following table shows the control specific properties that can currently be set through the SCREEN_CONTROL_ATTRIBUTES table (with an IS_CONTROL_PROPERTY = Y).

Control Type Property Default Value Description
Button disabled false Default the button to a disabled state.
ComboBox allowCustomValue false Provides the ability to enter and keep custom value in field.
caseSensitive false Control whether the combo box is case sensitive.
childCombo none Ties a parent ComboBox to a child ComboBox by name.
data-caseInsensitiveBinding false Apply this attribute if you want the data binding for the ComboBox to be case insensitive.
defaultValue none Default the combo box to one of the values (default is none).
disabled false Default the combo box to a disabled state.
mode editable Sets the mode for the ComboBox (see IgniteUI help for members).
parentCombo none Ties a child ComboBox to a parent ComboBox by name.
Jquery validation attributes (i.e. data-rule-required or data-msg-required) n/a Performs input validation using jquery.validate. Currently only supported inside a form tag.
DatePicker data-dateOnly false Control whether the date picker uses both date and time or just date.
disabled false Default the date picker to a disabled state.
maxValue Jan 1, 9999 Control max date that can be entered.
minValue Jan 1, 1753 Control min date that can be entered.
Jquery validation attributes n/a Performs input validation using jquery.validate. Currently only supported inside a form tag.
DateRange data-dateOnly false Control whether the date pickers use both date and time or just date.
DateTimeEditor disabled false Default the date time editor to a disabled state.
maxValue Jan 1, 9999 23:59:59 Control max date/time that can be entered.
minValue Jan 1, 1753 00:00:00 Control min date/time that can be entered.
Jquery validation attributes n/a Performs input validation using jquery.validate. Currently only supported inside a form tag.
DateTimeRange allowTodayOnlySelection none Indicates that the date/time range control should add a "today only" toggle switch and allow users to either indicate "today" or enter an actual date/time range.
FullCalendar buttonTextForViews 'timelineSevenDays: ''SEVENDAYS''' Specifies the resource key to be used for the custom view added using views attribute.
dateRangeSelectable false Indicates whether the date ranges on the calendar are selectable.
dateRangeUnselectCancel n/a

The value supported for this attribute is a jquery selector and it specifes the region on the page which can be clicked without firing the unselect event.

An example for this looks like '#divId' where divId is the Id for a div, and if one clicks anywhere inside this div, the selection will not be cleared.
defaultView timelineDay Indicates the default calendar view. Other available calendar views are timelineDay, timelineWeek, timelineMonth, and timelineYear.
displayNowIndicator true

Displays a line on the calendar to indicate the current time.

 

See the How to: Customize the Color of the Full Calendar Now Indicator topic for more information on customization.
eventDetailFields n/a

Represents the list of fields to be displayed on the event detail popover. Each field is separated by '|' character and each field information contains value for resource key and name of the field.

An example looks like "DOCKDOOR:Dock|CARRIER:Carrier|TRAILERID:TrailerId|START:ApptDateTime|END:EndDateTime", field name is used to fetch the value from event data JSON object.
eventDetailViewButtonResourceKey VIEWAPPOINTMENT Represents the resource key of the view button text displayed on the event detail preview.
eventDetailEditButtonResourceKey EDITAPPOINTMENT Represents the resource key of the edit button text displayed on the event detail preview.
eventDetailScreenFormId 0 Represents the form id of the screen to navigate to on clicking the View/Edit button on the event detail preview.
eventDetailScreenURL n/a

Represents the URL of the screen to navigate to on clicking the View/Edit button on the event detail preview.

An example looks like "{{#if InternalReceiptNum}}/scale/trans/recappschedule?InternalNum={{InternalReceiptNum}}{{/if}}", the query string parameter value is populated from event data JSON object.
eventStartField n/a Represents the name of the field in event data JSON object which holds the event start time.
eventEndField n/a Represents the name of the field in event data JSON object which holds the event end time.
eventIdField n/a Represents the name of the field in event data JSON object which indicates unique identifier for the event.
eventTitleField n/a Represents the name of the field in event data JSON object which will be shown as title to identify an event on calendar and used to display the event title on event detail popover.
header {left: ''today prev,next'',center: ''title'',right: ''timelineDay,timelineSevenDays''} Specifies the buttons on the header of the calendar.
heightPercentage 0.88 Indicates the height of calendar control on the parent screen. Value should be in the range of 0 to 1.
minTime 00:00:00 Indicates the minimum time displayed on the calendar. Default value is set to 12:00 AM.
maxTime 24:00:00 Indicates the maximum time displayed on the calendar. Default value is set to end at 12:00 AM.
onDateRangeSelect n/a

Specifies the javascript method to be called when Select event is fired.

For example, if you have a javascript method defined like below, you would set the value for this attribute as 'dateRangeSelected'

This event supports parameters startDate, endDate, jsEvent, view and resource.

Copy Code 
var dateRangeSelected = function (startDate, endDate, jsEvent, view, resource){};

onDateRangeUnselect n/a

Specifies the javascript method to be called when Unselect event is fired.

For example, if you have a javascript method defined like below, you would set the value for this attribute as 'dateRangeUnselected'

This event supports parameters jsEvent and view.

Copy Code 
var dateRangeUnselected = function (jsEvent, view) {};

resourceIdField n/a Represents the name of the field in event data JSON object which holds the resource id value. This is used to link resources with their corresponding events on calendar view. 
resourceLabelResourceKey DOCKDOORS Represents the resource key of the resources title text.
resourceAreaWidth 15% Indicates the width of reosurce display column in percentage.
scrollTimeOffsetForToday 1

Indicates the offset for setting the scroll time on the calendar for current date. The scroll time will be set to the current time minus the offset in hours.

Default value is set to 1 hour.
scrollTime 6:00:00

Indicates the setting for scroll time on the calendar for all other dates except current date. The scroll time will be set to this for all days except today.

Default value is set to 6AM.
views {timelineSevenDays:{type: ''timeline'',duration: { days: 7 }}} Specifies the views supported in the calendar. By default, the calendar will display 1 and 7 day views. See this topic for more information on customization: How to change the Days viewed for a Calendar.
viewRendered _webUi.apptScheduleTransaction.viewRendered

Specifies the javascript method to be called when the viewRendered event is fired.

For example, if you have a javascript method defined like below, you would set the value for this attribute as 'calendarViewRendered'

This event supports parameters view and element.

Copy Code 
var calendarViewRendered = function (view, element) {};

Grid alternateRowStyles false Control whether alternating rows in grid should be styled differently.
data-addRowRequired true Control whether adding a new row should be allowed in an editable grid.
data-defaultsProcessor none The "defaults" class that should be used to default values in the grid when the user adds a new row in an editable grid..
data-duplicateRowMsg none Error message to be shown if a duplicate row is entered in an editable grid.
data-editValueRequired none Define the columns that require a value in an editable grid.
data-groupBy true Control whether the grid allows grouping by columns.
data-loadDefaults true Whether or not default processing should occur on the grid when it is loaded (things like selecting a row, etc.).
data-local false Controls whether the grid paging, grouping, etc. is done locally in the grid (true) or remote on the server (false).
data-readonlyColumn none Define the read only columns in an editable grid.
data-restCreate none Web service URL that will be called when adding a record from an editable grid.
data-restDelete none Web service URL that will be called when deleting a record from an editable grid.
data-restFormId -1 Defines the Form Id for the corresponding Details screen that an editable grid is replacing; used for security purposes.
data-restrictionsProcessor none The "restrictions" class that should be used to restrict columns for an editable grid.
data-restUpdate none Web service URL that will be called when editing a record from an editable grid.
data-securityCheckpoint none The security checkpoint that should be checked for editable grids.
multipleSelection false Control whether multiple rows can be selected or not.
pageSize 100 Provides ability to override the number of the rows shown per page in the main grid. On Insight screens, the maximum pageSize is 500 for performance reasons. This is not yet supported through metadata on the hierarchical and mini grid controls.
rowSelectors false Control whether row selectors can be selected or not. Using row selectors we can select single or multiple rows in the grid. This will also provide selection using checkboxes.
MenuButton disabled false Default the menu button to a disabled state.
href n/a The URL for the MenuButton hyperlink.
NumericEditor AllowNullValue false Whether or not the editor accepts a blank value.
data-ClearValue Y Control whether there is an option to clear the value in the editor.
dataMode calculated based on decimal positions Data mode for the editor (see IgniteUI help for members).
disabled false Default the numeric editor to a disabled state.
groupSeparator No separator Set the separator value (i.e. comma for thousands separator). Pass empty for no separator. (defaults to no separator).
maxDecimals Decimal length from the resource file Control the max number of decimals that can be entered.
maxValue Calculated value based on max length and decimal length from the resource file Control the max value that can be entered.
minDecimals 0 Control the min number of decimals that can be entered.
minValue none Control the min value that can be entered.
TextAlignment Left Textalign for the editor (see IgniteUI help for members).
Jquery validation attributes n/a Performs input validation using jquery.validate. Currently only supported inside a form tag.
SummaryTile data-aggregateClause none Defines the aggregate clause used by the tile when the backend query is generated.
data-percentage false Displays percentage(%) symbol with tile data.
TextEditor disabled false Default the text editor to a disabled state.
excludeKeys none Control the characters that user should not be able to enter.
includeKeys none Control the characters that user should be able to enter.
maxLength Max Length from the resource file Control the max length of value that can be entered.
textMode text text = regular text mode, multiline = multiline editor (see IgniteUI help for members).
toLower false Set "Lower" encasing on control.
toUpper false Set "Upper" encasing on control.
Jquery validation attributes n/a Performs input validation using jquery.validate. Currently only supported inside a form tag.
TimePicker hoursSpinDelta 1 Time picker spinner increment. Defaults to 1 hour unless specified in metadata.
minutesSpinDelta 1 Time picker spinner increment. Defaults to 1 minute unless specified in metadata.

 

Other screen control attributes do not have IS_CONTROL_PROPERTY set to Y, but still play an important role in defining how a control is rendered and functions. The following table shows the other properties that can currently be set through the SCREEN_CONTROL_ATTRIBUTES table (with an IS_CONTROL_PROPERTY = N).

Control Type Property Default Value Description
Combobox data-customValueConfig n/a Allows custom values based on Generic Config Detail configuration.
Grid data-dbObjectType none Defines that the data source for the grid is a SQL stored procedure ( by passing a value of "SP").
data-dbTable none Defines the data source for the grid. If a stored procedure will be used, specify the stored procedure name.
data-gridEditMode none Used to set the edit mode in an editable grid. Supported values are Grid, Cell and None.
data-headerkey none In a Details screen, defines the Model field that contains the "key" that should be used to fill grids on the page (i.e. on the Shipment screen, the Shipment Detail grid will be driven by the Internal_Shipment_Num field in the model to show the proper records in the grid).
data-hideColumnFiltering false Used to hide the filtering feature on a grid column
data-hideColumnSorting false Used to hide the sorting feature on a grid column
data-hideColumnSummaries false Used to hide the summaries feature on a grid column
data-modelClass none Defines the class that will be used as the "model" for the grid.
data-queryEngineId Default query engine Spring Id for the query engine that should be used for the grid.
data-removeGroupSeparatorFromNumericColumns none Removes the group seperator character from a specified list of comma separated numeric columns.
data-restrictNegativeValues none Restricts entering negative values in numeric fields on an editable grid. Value should be a comma separated string containing field data sources.
ImageButton data-controlHtml n/a Allows for the html of an embedded image to be set on the button.
Label data-format none Allows a label to display Date only (date) or date time (datetime).
MenuButton data-allowOnMultiSelect false Determines whether the menu button should be enabled if multiple rows are selected in the corresponding grid.
data-divider n/a Allows an entry in a menu to have a divider line after it.
data-formId n/a Specifies the Form Id of the screen that will be called by the action, which is used in security checks.
data-useCheckbox false Allows checkbox to be associated with menu item. JavaScript coding is still required to show/hide the checkbox (add class "showcheckbox" to the control to show the checkbox; remove the same class to hide it).
MultiSelectionComboBox data-childdbcolumn n/a Defies the child column for the combo box.
data-parentdbcolumn n/a Defines the parent column for the combo box.
TextEditor data-dbcolumn none The binding database column for an Insight Search Pane editor.
Lookup none The Lookup record type for the editor.
ToggleSwitch data-btn-false-resourceKey TOGGLESWITCH_OFF Allows the "negative" condition text on the toggle to be set via resource key.
data-btn-true-resourceKey TOGGLESWITCH_ON Allows the "positive" condition text on the toggle to be set via resource key.
data-negativeCondition n/a Defines the condition applied to the generated query when the toggle is set to the "negative" position (off, no, or false). A special type of toggle condition is outlined at How to: Use a Toggle to Dynamically tie an Insight Page to an Alternate Table or View.
data-positiveCondition n/a Defines the condition applied to the generated query when the toggle is set to the "positive" position (on, yes, or true). A special type of toggle condition is outlined at How to: Use a Toggle to Dynamically tie an Insight Page to an Alternate Table or View.
data-togglegroup none Allows for multiple toggle switches to be grouped together, so that only one of them can be toggled to the positive condition at once.
