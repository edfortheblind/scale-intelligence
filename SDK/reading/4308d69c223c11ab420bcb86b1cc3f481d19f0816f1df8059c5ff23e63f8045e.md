    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">This topic will walk you through customizing the single signon page for Azure Active Directory or Active Directory Federation Services (ADFS).</p>

<div id="i-a2c7aaa9-7cd7-42b8-a6d1-3705e49b3c78-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Customize Microsoft Entra ID Signon Page</span>
</div>

<div id="i-a2c7aaa9-7cd7-42b8-a6d1-3705e49b3c78-section-content" class="i-section-content" data-source-node="n52">
    <ul data-source-node="n53">
        <li data-source-node="n54">Sign in to the Azure portal with an account that's a global admin for the directory.</li>

        <li data-source-node="n55">Select <strong data-source-node="n56">More services</strong>, enter <strong data-source-node="n57">Users and groups</strong> in the text box, and then select <strong data-source-node="n58">Enter</strong>.</li>

        <li data-source-node="n59">On the Users and groups blade, select <strong data-source-node="n60">Company branding.</strong></li>

        <li data-source-node="n61">Customize screens as required.</li>
    </ul>

    <div class="i-box i-box-note" data-source-node="n62">
        Note- Visit <a href="https://docs.microsoft.com/en-us/azure/active-directory/active-directory-branding-custom-signon-azure-portal" data-source-node="n63">https://docs.microsoft.com/en-us/azure/active-directory/active-directory-branding-custom-signon-azure-portal</a> for more info.
    </div>
</div>

<div id="i-1ae1e410-2075-4323-9334-823cdb53877a-section-content" class="i-section-content" data-source-node="n68">
    <ul data-source-node="n69">
        <li data-source-node="n70">Logon to the ADFS server (must be Windows Server 2016).</li>

        <li data-source-node="n71">Open Powershell as an administrator.</li>

        <li data-source-node="n72">Customize the screens as required with Powershell commands as outlined at <a href="https://docs.microsoft.com/en-us/windows-server/identity/ad-fs/operations/ad-fs-user-sign-in-customization" data-source-node="n73">https://docs.microsoft.com/en-us/windows-server/identity/ad-fs/operations/ad-fs-user-sign-in-customization</a></li>
