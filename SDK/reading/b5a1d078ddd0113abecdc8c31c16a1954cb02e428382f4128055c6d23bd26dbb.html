How to: Use a Toggle to Dynamically tie an Insight Page to an Alternate Table or View
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > How to: Use a Toggle to Dynamically tie an Insight Page to an Alternate Table or View

Insight screens generally work of a single SQL table or view that is tied to the Advanced criteria and Grid controls. At times, however, it may be useful to dynamically switch between two different SQL tables or views on a single Insight screen. This can be accomplished with special attributes on a Toggle control placed on the Insight screen. The following rules apply however:

  • Both SQL tables or views MUST return the exact same set of columns.
  • The detail pane stored procedure may need to be modified as well since it would normally have a hard-coded SQL table or view that it uses.
  • Action enabling/disabling may need to be modified as well based on the differences in the two SQL tables or views.

Use the following steps to add a toggle to an Insight screen to dynamically switch between two different SQL views or tables.

 Step 1: Add a Toggle control to the Insight page

Use the How to: Add Basic Criteria to Search Pane page to add a Toggle control to the Insight page. The following screen control attributes are required for this Toggle control.

Attribute Value
data-dbcolumn TableOrView
data-positiveCondition If the "positive" state should use the default table or view, then empty string. Otherwise, the name of the SQL table or view that should be used when the toggle is in the "positive" state.
data-negativeCondition If the "negative" state should use the default table or view, then empty string. Otherwise, the name of the SQL table or view that should be used when the toggle is in the "negative" state.
 Step 2: Create a new SQL table or view
Create the alternate SQL table or view that will be used by the Insight screen. It must return the exact same set of columns as the default SQL table or view used by the Insight screen.
 Step 3: Modify Detail Pane Stored Procedure
If required, modify the detail pane stored procedure. Please reference the How to: Create a Detail Pane Stored Procedure page for more details.
 Step 4: Modify how Actions are Enabled/Disabled
If required, modify the conditions when the Insight screen actions are enabled or disabled. Please reference the How to: Enable/Disable Metadata Actions Based on Screen Data page for more details.
