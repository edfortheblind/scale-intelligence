        <p data-source-node="n47">It is often necessary to define a "default action" (button or link) when the Enter key is pressed from a specific control on a screen. This can be defined dynamically in metadata via the DEFAULT_ACTION fields in the SCREEN_PART, SCREEN_GROUP, and SCREEN_CONTROL tables. Metadata screens will process these fields in a "bottom up" approach, meaning that the lowest level (control level) takes precedence over higher levels (group, part). With this approach, the required metadata can be minimized by generally placing the default action at the part level. However, if controls require a different default action, it can be specified at the group or control level.</p>

<p data-source-node="n48">When a page is loaded with all of its controls, each control is assigned a custom attribute named "data-defaultAction". This attribute is filled based on priority order (the default action from control if it is specified, then the group, and then the part) and is illustrated below:</p>

<div class="i-box i-box-note" data-source-node="n140">
    Please note that the DEFAULT_ACTION field should be filled with the Id of the button/link that should be called when the user hits enter. The default action always calls the "onKeyPress" function in webui.js, passing the Id specified for the default action.
</div>
