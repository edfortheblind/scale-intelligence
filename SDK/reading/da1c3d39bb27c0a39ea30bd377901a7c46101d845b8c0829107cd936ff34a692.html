Define Custom Endpoint Handlers
View with Navigation Tools

An endpoint handler is a module that contains logic to keep an endpoint running. The system hosts all configured endpoints under service "DIFCommunicationService". When the service starts it looks for all configured endpoint handlers to start the appropriate endpoints.

 

The following endpoint handlers are provided by the system:

 

IncomingTCPServerEndpointHandler This endpoint handler is used to send data to the system when the system serves as a server and the MHE as a client. This handler should be used when the system waits for connections and the MHE connects to the system to send data.
IncomingTCPClientEndpointHandler This endpoint handler is used to send data to the system when the system acts as a client and the MHE as a server. This handler connects to the MHE but waits for the MHE to send data
IncomingFileEndpointHandler This endpoint handler is used to move file from one location to another location using simple file operation.
OutgoingTCPClientEndpointHandler

This endpoint handler is used to send data from the system to the MHE. This handler connects to the MHE and sends it data. 
OutgoingHTTPClientEndpointHandler

This endpoint handler is used to send data from the system to the configured DIF outgoing endpoint web service(Azure function). 

 

In addition to the four endpoint handlers provided by the system. You can create your own endpoint handler, the following steps provide direction to create a custom endpoint handler:

 

1. Your endpoint handler must implement interface IEndpointHandler. The interface is located in assembly DeviceIntegrationFramework.Interfaces under the Common folder.

 

Your endpoint handler should have logic to keep processing until the endpoint handler is issued the stop command

 

2. You will need to defined your endpoint handler in the Spring.NET objects definition files. Put your object definition in a custom file and add an import directive in file  Objects.DeviceIntegrationFramework.BL.xml

Custom file with endpoint Handler Entry
Copy Code

<object id="IncomingTCPServerEndpointHandler" type="DeviceIntegrationFramework.BL.IncomingTCPServerEndpointHandler, DeviceIntegrationFramework.BL, Version=8.0.0.0, Culture=neutral, PublicKeyToken=a978a715ccadf176" singleton="false" autowire="constructor"/>
Add import directive to file Objects.DeviceIntegrationFramework.BL.xml
Copy Code

<objects xmlns="http://www.springframework.net">

<import resource=file:/%SCALE_HOME%/Settings/Custom.xml />

</objects>

3. Update your endpoint configuration. You will need to specify the object id (e.g "IncomingTCPServerEndpointHandler") of your spring entry in column ENDPOINT_HANDLER of table DIF_ENDPOINT
