    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">In the application you will notice that editable numeric fields may now show decimal positions where they haven’t in the past. These editable fields are tied to the resource file and not the Decimal Positions configuration at this time. To adjust the number of positions on these fields a modification via the System Text Editor is needed. This can be done by taking the following steps:<br data-source-node="n48"></p>

<ol data-source-node="n49">
    <li data-source-node="n50">Launch the System Text Editor from the Main UI<br data-source-node="n51"></li>

    <li data-source-node="n52">When the following window appears look for keys related to the area you would like to change. If for example you want to change all Quantity fields to not show decimal positions you would probably want to search for QUANTITY and QTY in the Resource Key section.<br data-source-node="n53"></li>

    <li data-source-node="n54">Customize the entries by right-clicking and choosing 'Open Custom Value'.<br data-source-node="n55"></li>

    <li data-source-node="n56">Change the Decimal Position value from 5 to 0 and hit OK.<br data-source-node="n57"></li>

    <li data-source-node="n58">Repeat for all keys you would like to change.<br data-source-node="n59"></li>

    <li data-source-node="n60">Click Apply on the System Text Editor Window.</li>
</ol>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n65">
    <p data-source-node="n66">If you wish to remove all decimal precision from fields across the entire system, you could run a quick query to update all of the fields at once to have a decimal position value of zero. The queries below will insert custom records for QUANTITY and QTY resources with a decimal pos value of 0. The resources will need to be regenerated after running these. You could pull out the resource key section that narrows the results down to QUANTITY if you wanted to do this over all keys.</p>
