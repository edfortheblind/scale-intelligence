Receiving Web Service
View with Navigation Tools

The Receiving Web Service allows access to links (URL or URI template) to other web services in the Receiving functional area. For example, Receipts web service.

 Request
  • URI: http://ServerName/ilsIntegrationServices/Receiving
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200

OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.receiving+json, application/vnd.manh.ils.receiving+xml

Links available:-

receivingPreCheckInContainersLinkBuilder application/vnd.manh.ils.Receipts.PreCheckInContainerCreation+json, XML
