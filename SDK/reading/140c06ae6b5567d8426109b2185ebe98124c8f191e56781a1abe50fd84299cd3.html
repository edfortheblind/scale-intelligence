Item Download
View with Navigation Tools

This allows XML download of Item Master data into the application. For more specifics and examples on Interfacing in the application, consult the help.

 Request
  • URI: http://ServerName/general/interfaces/items-Downloaded
  • Method: POST
  • Content-Type: application/json or application/xml
  • Entity: application/vnd.manh.ils.interfaces.interfaceRequest+json, xml
  • Roles: SCALEUSER,Confidential

    Note that the xmlData field in the request must conform to ItemDownload.xsd schema. Also, if a XML content-type is used then the xmlData element must have a string value that is encoded to ensure a well-formed xml interfaceRequest.

 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200

OK will be accompanied by an entity conforming to one of the requested media types: application/vnd.manh.ils.interfaces.interfaceResponse+json, xml
