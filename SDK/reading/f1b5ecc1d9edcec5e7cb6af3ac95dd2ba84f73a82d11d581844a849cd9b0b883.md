        <p data-source-node="n48">The system provides an exit point <em data-source-node="n49">WM Capture Inventory Attributes</em> , that should be used to let the system know if it should prompt for inventory attributes.</p>

<p data-source-node="n50">The exit point should return 'YES' to capture attirbutes, any other return value will skip the attributes entry.</p>

<p data-source-node="n51"> </p>
