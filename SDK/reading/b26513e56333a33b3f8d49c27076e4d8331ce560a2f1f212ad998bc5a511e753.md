    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">A modal dialog control allows for an overlay screen that prompts for user input in order to continue an action. An example of this is when a user chooses to save a search from an insight page and the system prompts them for a name for the search. Modal dialogs are configured via metadata and are made up of several screen parts, groups, and controls in a similar fashion to the overall page. In order to add a new modal dialog control, follow these steps.</p>

<div id="i-344d5559-87a6-4381-937a-205a63f4c4a3-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Step 1: Create ModalDialog screen part</span>
</div>

<div id="i-344d5559-87a6-4381-937a-205a63f4c4a3-section-content" class="i-section-content" data-source-node="n52">
    Create a screen part of type ModalDialog. This part should be configured with PARTIAL_VIEW = Y. See the <a href="6782568ac24669083b06b11cd8a7a49a257405092ee921de8c1e82be2ce21020.html" data-source-node="n53"><font color="navy" data-source-node="n54">How to: Create Screen Parts</font></a> topic for more details. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n55"><u data-source-node="n56"><font color="navy" data-source-node="n57">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).
</div>

<div id="i-e4d65240-8762-49d2-ba70-02ce022efff0-section-heading" class="i-section-heading" data-source-node="n58">
    <span class="i-section-heading-icon" data-source-node="n59"><span class="i-hidden" data-source-node="n60"> </span></span><span class="i-section-heading-text" data-source-node="n61">Step 2: Create Form screen group</span>
</div>

<div id="i-e4d65240-8762-49d2-ba70-02ce022efff0-section-content" class="i-section-content" data-source-node="n62">
    Create a Form screen group that is tied to the screen part. This will be the top level screen group. See the <a href="d56eab375c6856ee498740b181674d34f75a61df99c10b442cf5a66ae9f2cef6.html" data-source-node="n63">How to: Create Screen Groups</a> topic for more details. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n64"><u data-source-node="n65"><font color="navy" data-source-node="n66">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).
</div>

<div id="i-1c1e2b6b-8a77-4584-8a5a-7b6626d34b71-section-heading" class="i-section-heading" data-source-node="n67">
    <span class="i-section-heading-icon" data-source-node="n68"><span class="i-hidden" data-source-node="n69"> </span></span><span class="i-section-heading-text" data-source-node="n70">Step 3: Create ModalDialogHeader screen group</span>
</div>

<div id="i-1c1e2b6b-8a77-4584-8a5a-7b6626d34b71-section-content" class="i-section-content" data-source-node="n71">
    Create a ModalDialogHeader group as a child group of the form group. The RESOURCE_KEY will be used as the title for the modal dialog. No other controls are required in this group as the close button and title comes for free. See the <a href="d56eab375c6856ee498740b181674d34f75a61df99c10b442cf5a66ae9f2cef6.html" data-source-node="n72"><font color="navy" data-source-node="n73">How to: Create Screen Groups</font></a> topic for more details. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n74"><u data-source-node="n75"><font color="navy" data-source-node="n76">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).
</div>

<div id="i-b9254106-4832-4113-bf74-f350071e45be-section-heading" class="i-section-heading" data-source-node="n77">
    <span class="i-section-heading-icon" data-source-node="n78"><span class="i-hidden" data-source-node="n79"> </span></span><span class="i-section-heading-text" data-source-node="n80">Step 4: Create ModalDialogBody screen group</span>
</div>

<div id="i-b9254106-4832-4113-bf74-f350071e45be-section-content" class="i-section-content" data-source-node="n81">
    Create a ModalDialogBody group as a child group of the form group. See the <a href="d56eab375c6856ee498740b181674d34f75a61df99c10b442cf5a66ae9f2cef6.html" data-source-node="n82"><font color="navy" data-source-node="n83">How to: Create Screen Groups</font></a> topic for more details. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n84"><u data-source-node="n85"><font color="navy" data-source-node="n86">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).
</div>

<div id="i-c23749cc-547f-42c9-8b98-a6494ff0a711-section-heading" class="i-section-heading" data-source-node="n87">
    <span class="i-section-heading-icon" data-source-node="n88"><span class="i-hidden" data-source-node="n89"> </span></span><span class="i-section-heading-text" data-source-node="n90">Step 5: Add input controls to the ModalDialogBody</span>
</div>

<div id="i-c23749cc-547f-42c9-8b98-a6494ff0a711-section-content" class="i-section-content" data-source-node="n91">
    Any dynamic input controls desired to the body of the dialog. All input controls are supported within the dialog control. See the <a href="bb522128265dc8e032acf43909a28cdb0383a4c646d9bddef63fdc9e27ce292e.html" data-source-node="n92">How to: Create Screen Controls</a> topic for more details. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n93"><u data-source-node="n94"><font color="navy" data-source-node="n95">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).
</div>

<div id="i-013bb07a-136a-4cc4-b4be-a1667befd611-section-heading" class="i-section-heading" data-source-node="n96">
    <span class="i-section-heading-icon" data-source-node="n97"><span class="i-hidden" data-source-node="n98"> </span></span><span class="i-section-heading-text" data-source-node="n99">Step 6: Create ModalDialogFooter screen group</span>
</div>

<div id="i-013bb07a-136a-4cc4-b4be-a1667befd611-section-content" class="i-section-content" data-source-node="n100">
    Create a ModalDialogFooter group as a child group of the form group. See the <a href="d56eab375c6856ee498740b181674d34f75a61df99c10b442cf5a66ae9f2cef6.html" data-source-node="n101"><font color="navy" data-source-node="n102">How to: Create Screen Groups</font></a> topic for more details. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n103"><u data-source-node="n104"><font color="navy" data-source-node="n105">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).
</div>

<div id="i-258e712a-fdba-4c1a-965e-7eeb7da7a7a6-section-heading" class="i-section-heading" data-source-node="n106">
    <span class="i-section-heading-icon" data-source-node="n107"><span class="i-hidden" data-source-node="n108"> </span></span><span class="i-section-heading-text" data-source-node="n109">Step 7: Add button controls to the ModalDialogFooter</span>
</div>

<div id="i-258e712a-fdba-4c1a-965e-7eeb7da7a7a6-section-content" class="i-section-content" data-source-node="n110">
    Any dynamic button controls desired to the footer of the dialog and tie events to them. See the <a href="bb522128265dc8e032acf43909a28cdb0383a4c646d9bddef63fdc9e27ce292e.html" data-source-node="n111"><font color="navy" data-source-node="n112">How to: Create Screen Controls</font></a> topic and <a href="eca9fc53f0fb038bdfb1d5f215e7b5f31082e710554ecde05af2dd256e790233.html" data-source-node="n113">How to: Create Screen Control Events</a> topic for more details. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n114"><u data-source-node="n115"><font color="navy" data-source-node="n116">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).
