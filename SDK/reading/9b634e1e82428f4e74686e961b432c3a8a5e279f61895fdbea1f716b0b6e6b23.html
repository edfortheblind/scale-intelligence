Remove Container Group
View with Navigation Tools
Integration Services > REST-Based Web Services > Work Web Services > Remove Container Group

The Remove Container Group function of Outbound Work Execution Web Service removes the entire group of a specified container.

 Request
  • URI: http://ServerName/outbound/outboundWorkInstructions/outboundWorkInstructions-Grouped?containerId={containerId}&warehouse={warehouse}
  • Method: DELETE
  • Content-Type: application/json or application/xml
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK
400 The following ErrorTypes can be expected: Container, Warehouse
