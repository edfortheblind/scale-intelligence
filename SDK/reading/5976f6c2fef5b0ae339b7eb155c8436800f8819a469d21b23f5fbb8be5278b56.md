    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Screen groups represent a grouping of controls within a single screen part. Screen groups are represented by the SCREEN_GROUP database table. There can be 1-N screen groups (ordered by the SEQUENCE field) for a particular screen part. Screen groups are tied to screen parts by the SCREEN_PART_ID field (SCREEN_GROUP.SCREEN_PART_ID = SCREEN_PART.OBJECT_ID). Screen groups can also be nested within each other (i.e. an accordion control has sub-accordions or an accordion control can be placed inside a panel control). This nesting is controlled by the PARENT_GROUP_ID and NESTED_GROUP_UNIT fields. All records in a particular "tree" (other than the top level record) will have a PARENT_GROUP_ID. All records in a "tree" will have the top level OBJECT_ID as their NESTED_GROUP_UNIT (including the top level record). Please reference the "Screen Group Type" configuration for an enumeration of the available screen groups. Also, the table below gives more information on screen groups.</p>
