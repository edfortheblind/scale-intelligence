    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Columns from a selected grid row can be dynamically retrieved and passed as parameters to the web services that dynamic actions call. The parameter naming conventions spelled out in the <a href="578b8b51893ce94bd97ac7229cfa2747e32948724bbcd4b08a5f0253a8730226.html" data-source-node="n48">Screen Control Event Parameter Naming Conventions</a> must be followed for the values to be retrieved and passed correctly. Use the <a href="349b79b031b88e988c45527ef77a447ebcc9b4e1f12c300ad7bfb286fe2cd905.html" data-source-node="n49">How to: Perform a GET Service Call from Metadata Action</a>, <a href="86e589806734e407eaba41ca9571b0b3bcb21d7020eac089f5d58f20c8237ad6.html" data-source-node="n50">How to: Perform a POST Service Call from Metadata Action</a>, or <a href="2d9f9ac140e772d1ded706bc360fb7c39ae5cd978a4d476a7510cf8fe1deb5a3.html" data-source-node="n51">How to: Perform a DELETE Service Call from Metadata Action</a> topics to create the proper metadata records to call the web service. Then, for each parameter value that needs to be pulled from a grid, add a SCREEN_CONTROL_EVENT_PARAMETERS record. The format of this record depends on the type of service being called.</p>
