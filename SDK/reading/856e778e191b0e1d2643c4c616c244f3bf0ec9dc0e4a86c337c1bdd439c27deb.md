        <div class="i-box i-box-note" data-source-node="n158">
            Please note that changing the table or view on an insight screen only changes the table or view that the insight page selects from. If specific controls reference column names that do not exist in the table or view, errors will occur on the screen. The individual columns that other controls point to will need to be updated as well. Please reference the <a href="7cf47da0d418debe3bec7ab244abe2ff74ef12b621108fc7d8bbde0f9fc7f797.html" data-source-node="n159">How to: Create Insight Search Pane</a> for more details.

    <span class="i-section-heading-icon" data-source-node="n162"><span class="i-hidden" data-source-node="n163"> </span></span><span class="i-section-heading-text" data-source-node="n164">Create a new insight page tied to a table or view</span>
</div>

<div id="i-1a1613ad-d96b-456c-a792-7c5a33fd4e9d-section-content" class="i-section-content" data-source-node="n165">
    Tying a new insight page to a table or view is as simple as creating a new SCREEN_CONTROL_ATTRIBUTES record with ATTRIBUTE_NAME = "data-dbtable" and ATTRIBUTE_VALUE = "&lt;table or view name&gt;" that is linked to the SCREEN_CONTROL record for the grid on the page. Please reference the <a href="5942a56b700da391844709a2365a8f75521486c96ded9bd531252e13ef0b3ae1.html" data-source-node="n166">How to: Create Insight List Pane</a> topic for more details on creating a grid on an insight screen. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n167"><u data-source-node="n168"><font color="navy" data-source-node="n169">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).
