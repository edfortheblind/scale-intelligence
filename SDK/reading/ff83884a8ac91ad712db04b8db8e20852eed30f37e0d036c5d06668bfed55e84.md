    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Every web service call triggered by an action goes through a single default success callback JavaScript function. This function is named defaultSuccessCallback and is in the webclient.js file. It simply displays a success message to the user. You can override the default success callback dynamically for POST and GET methods through metadata. Use the <a href="86e589806734e407eaba41ca9571b0b3bcb21d7020eac089f5d58f20c8237ad6.html" data-source-node="n48">How to: Perform a POST Service Call from Metadata Action</a> or <a href="2d9f9ac140e772d1ded706bc360fb7c39ae5cd978a4d476a7510cf8fe1deb5a3.html" data-source-node="n49">How to: Perform a DELETE Service Call from Metadata Action</a> topics to create the proper metadata records to call the web service. Then, add a SCREEN_CONTROL_EVENT_PARAMETERS record to override the default success callback. The format of this record depends on the type of service being called. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n50"><u data-source-node="n51"><font color="navy" data-source-node="n52">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>
