    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">This topic will walk you through changing metadata to define two cascading combo boxes. When the user selects a value from the parent combo box the list of results in the child combo box will be narrowed down to only the values that are associated with the selected parent.</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n48">

</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n53">
    <p data-source-node="n54">These could be controls that are shipped with the system or custom controls that were added. For this example, let's look at the Carrier and Service fields from the Shipment detail screen. Find the OBJECT_ID of the corresponding SCREEN_CONTROL records for the combo boxes. The below SQL will return the entire list of controls for a screen and the correct control should be chosen from the list. The form id for the Shipment detail screen is <em data-source-node="n55">2735</em>. The Carrier combo box control name is <em data-source-node="n56">CarrierCarrierNameValue</em> and the Carrier Service combo box control name is <em data-source-node="n57">CarrierCarrierServiceValue</em>. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n58"><u data-source-node="n59"><font color="navy" data-source-node="n60">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n98">
    <p data-source-node="n99"><span class="SectionHeadingText" data-source-node="n100">A SCREEN_CONTROL_ATTRIBUTE record for the parent (carrier) and child (carrier service) combo box should be found in the SCREEN_CONTROL_ATTRIBUTES table. The records are defined as listed in the table below. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n101"><u data-source-node="n102"><font color="navy" data-source-node="n103">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</span></p>

    <p data-source-node="n104"><span class="SectionHeadingText" data-source-node="n105">When configuring your own parent and child cascading combo boxes they should have similar records defined in the SCREEN_CONTROL_ATTRIBUTE table as the carrier and service example.</span></p>
