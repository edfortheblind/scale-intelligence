    <div id="i-body-content" class="i-body-content" data-source-node="n47">
        <p data-source-node="n48">The system provides an exit point <em data-source-node="n49">Image capture - Link internal reference number</em> , that should be used to let the system know if it should override the system's internal number mapping logic for all image capture reference types.</p>

<p data-source-node="n50">The exit point should return a numeric value if it finds internal mapping number for the given reference id and reference type, else it should return NULL.</p>

<p data-source-node="n51"> </p>

<p data-source-node="n52">The following example represents a sample implementation of the <em data-source-node="n53">Image capture - Link internal reference number&gt; exit point program using a stored procedure. </em></p>
