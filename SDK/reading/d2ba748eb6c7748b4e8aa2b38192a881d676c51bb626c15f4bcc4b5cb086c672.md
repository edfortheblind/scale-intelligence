    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The following web services are available to get and insert/update Location Inventory Attributes.</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Step 1: Retrieve an Inventory Resource representation</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <p data-source-node="n47">First perform an HTTP GET to retrieve a Inventory resource representation.</p>

    <p data-source-node="n48">How to: <a href="22624a15f9f9ccef14a3639e6bd7e76202b906b338354a7787f060853dedf0fe.html" data-source-node="n49">Inventory Web Service</a></p>
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n50">
    <span class="i-section-heading-icon" data-source-node="n51"><span class="i-hidden" data-source-node="n52"> </span></span><span class="i-section-heading-text" data-source-node="n53">Step 2: Get the Location Inventory Attributes</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n54">
    <p align="left" data-source-node="n55">The Inventory resource representation will include the link to the Location Inventory Attributes resource. The link (rel="getInventoryAttributes") has a href<em data-source-node="n56"> </em>that is a URI template with the <strong data-source-node="n57">{attributeId}</strong> token. To fetch the Location Inventory Attributes representation, substitute the token and perform an HTTP GET:</p>

    <p data-source-node="n58"><strong data-source-node="n59">Request:</strong></p>

    <ul data-source-node="n60">
        <li data-source-node="n61"><strong data-source-node="n62">URI:</strong> From Inventory's link (rel="getInventoryAttributes") href</li>

        <li data-source-node="n63"><strong data-source-node="n64">Method:</strong> GET</li>

        <li data-source-node="n65"><strong data-source-node="n66">Accept:</strong> application/json or application/xml</li>

        <li data-source-node="n67"><strong data-source-node="n68">Roles:</strong> SCALEUSER,Confidential</li>
    </ul>

    <p data-source-node="n69"> </p>

    <p data-source-node="n70"><strong data-source-node="n71">Response:</strong></p>

    <p data-source-node="n72">Aside from <a href="330a68671fd01d31e69b8634088ee603d769cc8b8d2c45b49f4a3d068a6f9bdb.html" data-source-node="n73">standard responses</a>, note the following specifics for this service:</p>

    <p data-source-node="n74"></p>

    <table class="members" data-source-node="n75">
        <tbody data-source-node="n76">
            <tr data-source-node="n77">
                <th class="nameColumn" data-source-node="n78">Status Code</th>

                <th class="descriptionColumn" data-source-node="n79">Notes</th>
            </tr>

            <tr data-source-node="n80">
                <td data-source-node="n81">200</td>

                <td data-source-node="n82">OK will be accompanied by the LocationInventoryAttributes representation conforming to one of the media types: <a href="../source/downloads/85d3b087edfb46763b977e44b9da6bb62d2543809980823fd8f9bf8073146a30.json" data-source-node="n83">application/vnd.manh.ils.inventory.locationInventoryAttributes+json</a>, <a href="../source/downloads/c50c7ea5d87281ddea31ad136df2ad92f255fb28a7964104c0f76d2e8153afc6.xsd" data-source-node="n84">XML</a> </td>
            </tr>

</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n86">
    <span class="i-section-heading-icon" data-source-node="n87"><span class="i-hidden" data-source-node="n88"> </span></span><span class="i-section-heading-text" data-source-node="n89">Step 3: Save the Location Inventory Attributes</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n90">
    <p align="left" data-source-node="n91">The Inventory resource representation will include the link to the Location Inventory Attributes resource. The link (rel="putInventoryAttributes") has a href<em data-source-node="n92"> </em>that is a URI template with the <strong data-source-node="n93">{attributeId}</strong> token. Perform a HTTP PUT with the following:</p>

    <p data-source-node="n94"><strong data-source-node="n95">Request:</strong></p>

    <ul data-source-node="n96">
        <li data-source-node="n97"><strong data-source-node="n98">URI:</strong> From Inventory's link (rel="putInventoryAttributes") href</li>

        <li data-source-node="n99"><strong data-source-node="n100">Method:</strong> PUT</li>

        <li data-source-node="n101"><strong data-source-node="n102">Accept:</strong> application/json or application/xml</li>

        <li data-source-node="n103"><strong data-source-node="n104">Content-Type:</strong> application/json or application/xml</li>

        <li data-source-node="n105"><strong data-source-node="n106">Roles:</strong> SCALEUSER,Confidential</li>

        <li data-source-node="n107"><strong data-source-node="n108">Entity:</strong> The LocationInventoryAttributes representation with AttributeId (to update) and without AttributeId (to insert new). Also, it's InternalLocationInv number can be set to link it to a Location Inventory after save. The entity should conform to one of the media types: <a href="../source/downloads/85d3b087edfb46763b977e44b9da6bb62d2543809980823fd8f9bf8073146a30.json" data-source-node="n109">application/vnd.manh.ils.inventory.locationInventoryAttributes+json</a>, <a href="../source/downloads/c50c7ea5d87281ddea31ad136df2ad92f255fb28a7964104c0f76d2e8153afc6.xsd" data-source-node="n110">XML</a></li>
    </ul>

    <p data-source-node="n111"><strong data-source-node="n112">Response:</strong></p>

    <p data-source-node="n113">Aside from <a href="330a68671fd01d31e69b8634088ee603d769cc8b8d2c45b49f4a3d068a6f9bdb.html" data-source-node="n114">standard responses</a>, note the following specifics for this service:</p>

                <td data-source-node="n122">200</td>
