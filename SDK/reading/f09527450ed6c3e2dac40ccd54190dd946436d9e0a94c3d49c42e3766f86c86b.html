QC Assignment Web Service
View with Navigation Tools

The QC Confirmation web service allows a consumer to perform QC counts for the item contents of a Shipping container.  This is achieved by executing the following steps:

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Post the ContainerReferenceList using the qcAssignment link

The Shipping resource representation will include a qcAssignment link. The link (rel="qcAssignment") has a href with a URI template that has the {QCAssignmentEvaluationMethod} token. To invoke a QC Assignment for a list of shipping containers, create the relevant ContainerReference data structures substituting the token and perform an HTTP POST with the following:

Request:

  • URI: From Shipping representation's link (rel="qcAssignment") href
  • Method: POST
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: application/vnd.manh.ils.shipping.containerReferenceList+json, xml
  • Roles: SCALEUSER,Confidential

 

Response:

Aside from standard responses, note the following specifics for this service:
