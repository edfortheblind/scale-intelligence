    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">This topic will walk through an example of customizing the calendar event preview that appears when tapping on an event.</p>

<p data-source-node="n42"> </p>

<div class="i-box i-box-caution" data-source-node="n43">
    <p data-source-node="n44">Before customizing the calendar it is recommended that a copy of the screen is created using the Insight Architect in the toolbox to ensure changes are saved for future upgrades. During upgrades the metadata changed below will be overwritten and changes may be lost.</p>
</div>

<p data-source-node="n45"> </p>

        <span class="i-section-heading-icon" data-source-node="n103"><span class="i-hidden" data-source-node="n104"> </span></span><span class="i-section-heading-text" data-source-node="n105">Step 2: Update the eventDetailFields attribute to include the new field for the preview</span>
    </div>

    <div id="i-95f65508-a588-4cf4-b336-3ba647b0ce4a-section-content" class="i-section-content" data-source-node="n106">
        <p data-source-node="n107">Fields displayed in the preview are controlled by the eventDetailFields attribute. The fields here are separated by the <b data-source-node="n108">|</b> symbol. Each field has 2 parts: The resource key for the header and field name from the Api call result. These are further separated by <b data-source-node="n109">colon :</b> symbol.</p>

        <p data-source-node="n110"> </p>

        <p data-source-node="n111">For example in DOCKDOOR:Dock, DOCKDOOR is the resource key for the text displayed as header and Dock is the field in JSON returned from the API call.</p>Use the following SQL statement to modify the header attribute to add new view. Insight Architect can also be used for this <a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n112"><u data-source-node="n113"><font color="navy" data-source-node="n114">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>.
