    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">SQL Server Reporting Services (SSRS) reports are created and modified in the Report Designer of SQL Server Business Intelligence Development Studio (BIDS), which installs as part of the SQL Server client tools.  See <a href="https://docs.microsoft.com/en-us/previous-versions/sql/sql-server-2008-r2/ms159253(v=sql.105)" data-source-node="n48">Designing and Implementing Reports Using Report Designer (Reporting Services)</a> for general report authoring techniques.</p>

<p data-source-node="n49">The SSRS reports are shipped as .rdl files with the application.  The Database Installation Guide's "Appendix: Microsoft SQL Server Reporting Services Configuration" topic has a section called "Uploading Reporting Services Reports", which explains the typical process of deploying SSRS reports for the application.</p>

<p data-source-node="n50">When customizing base SSRS reports, make sure to actually modify and deploy a copy of the actual base report.  This protects against the loss of customization during upgrades.<br data-source-node="n51"></p>
