    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The Short Pick Replenishment Web Service accepts details related to location, item and the shortfall quantity. The web service checks if there is any existing in-transit movement which can satisfy the current pick requirement. If none exists, the web service will try to replenish the location by running the replenishment masters configured for this type of replenishment. After replenishing, in-transit is checked again. The service then reports the status back to the caller.</p>
