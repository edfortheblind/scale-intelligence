Assign Work

Integration Services > REST-Based Web Services > Work Web Services > Assign Work

The Work Unit Assign Web Service assigns the entire work unit to the user. Use this web service to assign the work unit before a user starts executing outbound work using Work Web Services

 

Note: The web service has a optional fields called "Confirm"(this will decide user confirmation requirement, if work is already assigned to some other user.) and "user".
 Request
  • URI: http://serverName/ilsIntegrationServices/workUnits/assign/{WorkUnit}
  • Method: POST
  • Accept: application/json or application/xml
  • Entity: JSON, XML
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 200 OK will be accompanied by an entity that represents the successfully executed work instruction: JSON, XML
400 Bad request can be expected if any exception occurred during processing or validation error.
