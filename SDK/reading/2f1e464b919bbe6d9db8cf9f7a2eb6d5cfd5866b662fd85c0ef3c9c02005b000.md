    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">The Generic Monitor Data Retrieval web service is used to retrieve data from a stored procedure and return it to a Monitor page. Also see the <a href="87805cd9111e0fa780af41745eecaec6f7c342121195d2ac78cb63c28ef7c81d.html" data-source-node="n48"><font color="navy" data-source-node="n49">How to Bind Controls on Monitor Page</font></a> topic for more information on binding the data to the controls on the Monitor page.</p>

<div id="i-78ca4f69-beb4-42cc-89dc-4799de93602b-section-heading" class="i-section-heading" data-source-node="n50">
    <span class="i-section-heading-icon" data-source-node="n51"><span class="i-hidden" data-source-node="n52"> </span></span><span class="i-section-heading-text" data-source-node="n53">Stored Procedure in Detail</span>
</div>

<div id="i-78ca4f69-beb4-42cc-89dc-4799de93602b-section-content" class="i-section-content" data-source-node="n54">
    <ul data-source-node="n55">
        <li data-source-node="n56"><strong data-source-node="n57">Stored Procedure Input Parameters: </strong>This stored procedure has two input parameters, FilterCriteria and culture. FilterCriteria can have multiple comma separated values and should end with a semicolon.</li>

        <li data-source-node="n58"><strong data-source-node="n59">fn_GetMonitorFilterParameters Function:</strong> The Monitor stored procedure calls this SQL function to format the "FilterCriteria". This function returns a table which contains filterName and filterValue columns to represent the filter criteria name and value.</li>

        <li data-source-node="n60"><strong data-source-node="n61">Return Data from Stored Procedure: </strong>The Monitor stored procedure returns data in a Table format. The table column details are outlined below.</li>
    </ul>

    <table data-source-node="n62">
        <tbody data-source-node="n63">
            <tr data-source-node="n64">
                <td data-source-node="n65"><strong data-source-node="n66">Column Name</strong></td>

                <td data-source-node="n67"><strong data-source-node="n68">Description</strong></td>
            </tr>

            <tr data-source-node="n69">
                <td data-source-node="n70">ChartData_&lt;DataSourceName&gt;</td>

                <td data-source-node="n71">This is the first column for the return data table. &lt;DataSourceName&gt; represents the data binding name for the control.</td>
            </tr>

            <tr data-source-node="n72">
                <td data-source-node="n73">Data</td>

                <td data-source-node="n74">Defines the actual chart values.</td>
            </tr>

            <tr data-source-node="n75">
                <td data-source-node="n76">Category</td>

                <td data-source-node="n77">Defines the data name for a chart.</td>
            </tr>

            <tr data-source-node="n78">
                <td data-source-node="n79">XaxisTitle</td>

                <td data-source-node="n80">Defines the chart's X axis title.</td>
            </tr>

            <tr data-source-node="n81">
                <td data-source-node="n82">YaxisTtile</td>

                <td data-source-node="n83">Defines the chart's Y axis title.</td>
            </tr>

            <tr data-source-node="n84">
                <td data-source-node="n85">NextDrillDownLevel</td>

                <td data-source-node="n86">Defines the next level of drilldown for the chart. Use -1 for last level or no drilldown.</td>
            </tr>
        </tbody>
    </table>
