    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">The tooling provided for creating a new custom Details page is not complete. For now, follow the instructions below in order to create a new Details page.</p>

<div id="i-4e3ebfee-fda6-4c77-bf05-a12df9ed1da5-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Step 1: Copy an Existing Details Page Script</span>
</div>

<div id="i-4e3ebfee-fda6-4c77-bf05-a12df9ed1da5-section-content" class="i-section-content" data-source-node="n52">
    <p data-source-node="n53">Browse to the directory that SCALE is installed to and then go to the sub folder Database | ILS | Scripts | _Metadata | Detail. Pick a script for a screen that is the most similar to the page you want to create. Copy the script to another location, rename it, and open it.</p>
</div>

<div id="i-9f4eb37a-4158-45fc-9d8e-13bdf1934d95-section-heading" class="i-section-heading" data-source-node="n54">
    <span class="i-section-heading-icon" data-source-node="n55"><span class="i-hidden" data-source-node="n56"> </span></span><span class="i-section-heading-text" data-source-node="n57">Step 2: Update Script with Page Level information</span>
</div>

<div id="i-9f4eb37a-4158-45fc-9d8e-13bdf1934d95-section-content" class="i-section-content" data-source-node="n58">
    <p data-source-node="n59">Update the script for all page level information as follows:</p>

    <p data-source-node="n60"> </p>

    <ul data-source-node="n61">
        <li data-source-node="n62"><strong data-source-node="n63"><em data-source-node="n64">Form Id</em></strong>: Use a different Form Id for your new screen. At the top of the script you will see the Form Id being set similar to this: <strong data-source-node="n65">set @formId = 2767</strong>. Search and replace the actual Form Id value in the script with your new Form Id. The new Form Id value you use should be the next available Form Id &gt;= 60,000. So in the example given above, the Form Id 2767 should be replaced by 60000 everywhere in the script.</li>

        <li data-source-node="n66">
            <strong data-source-node="n67"><em data-source-node="n68">Form record</em></strong>: Update the call to <strong data-source-node="n69">DBC_IFORM</strong> as follows:

            <ul data-source-node="n70">
                <li data-source-node="n71">@formKeyName = MNU_&lt;customScreenName&gt;Details (i.e. MNU_CustomDetails)</li>

                <li data-source-node="n72"><a data-source-node="n73">@tableName</a> = the name of the NHibernateEntity that represents the SQL table that should be used for the Details screen data</li>

                <li data-source-node="n74"><a data-source-node="n75">@associatedFormKey</a> = null</li>
            </ul>
        </li>

        <li data-source-node="n76"><strong data-source-node="n77"><em data-source-node="n78">Security</em></strong>: Remove all calls to <strong data-source-node="n79">dbc_ISecurityCheckpoint</strong> except for security_checkpoint 1, 3, and 6 ("run", "change", "display").</li>

        <li data-source-node="n80">
            <strong data-source-node="n81"><em data-source-node="n82">Screen record</em></strong>: Update the call to <strong data-source-node="n83">DBC_IMAINUISCREEN</strong> as follows:

            <ul data-source-node="n84">
                <li data-source-node="n85"><a data-source-node="n86">@functionalArea</a> = the identifier of the functional area you want the screen to show up under in the menu</li>

                <li data-source-node="n87"><a data-source-node="n88">@menuResourceKey</a> = the Resource Key to be used for the page title</li>

                <li data-source-node="n89"><a data-source-node="n90">@path</a> = Update based on the NHibernate entity that will be used for the page (i.e. /scale/details/&lt;NHibernateEntityName&gt;</li>

                <li data-source-node="n91"><a data-source-node="n92">@restrictionsId</a> = set this to the configured Spring Id for the .NET class that will house the "restrictions" list for the screen, if any (see the <a href="e52c7b80f83f0d4e4bbbb36c16b33ce83c60b0e350ec27e07b71b7afb03aa569.html" data-source-node="n93"><u data-source-node="n94"><font color="navy" data-source-node="n95">Field Restrictions</font></u></a> topic for more information)</li>

                <li data-source-node="n96"><a data-source-node="n97">@defaultsId</a> = set this to the configured Spring Id for the .NET class that will house the "defaults" list for the screen, if any (see the <a href="7c8b58daf66f8a0844aa65677824c56e02d9005b50dccd167330dbcffc93fb11.html" data-source-node="n98">Detail Defaults</a> topic for more information)</li>
            </ul>
        </li>

        <li data-source-node="n99"><strong data-source-node="n100"><em data-source-node="n101">Licensing</em></strong>: Remove all calls to <strong data-source-node="n102">dbc_IMainUiWmLicenseXrefOriginal</strong>.</li>
    </ul>
</div>

<div id="i-bc469d8a-86f9-48f5-9405-8b0f5c6ad79e-section-heading" class="i-section-heading" data-source-node="n103">
    <span class="i-section-heading-icon" data-source-node="n104"><span class="i-hidden" data-source-node="n105"> </span></span><span class="i-section-heading-text" data-source-node="n106">Step 3: Run the Modified Script</span>
</div>

<div id="i-bc469d8a-86f9-48f5-9405-8b0f5c6ad79e-section-content" class="i-section-content" data-source-node="n107">
    <p data-source-node="n108">Open SQL Server Management Studio and run the modified script ensuring there are no errors. Run an IISRESET and then try to browse to the new page. The URL will be in the format https://&lt;serverName&gt;/scale/details/&lt;NHibernateEntityName&gt;/&lt;internalId&gt;. The new Details page may not be shown properly, since the controls on the screen do not bind with teh proper NHibernateEntity yet.</p>
</div>
