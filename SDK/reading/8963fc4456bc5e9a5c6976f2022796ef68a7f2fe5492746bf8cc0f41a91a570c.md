    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">This topic will walk you through customizing the background image found on the Dashboard page.</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Step 1: <span class="SectionHeadingText" data-source-node="n46">Add the _custom folder</span></span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n47">
    <ol class="i-last-child" data-source-node="n48">
        <li data-source-node="n49">Browse to the %SCALE_HOME% \web directory on the SCALE server. </li>

        <li data-source-node="n50">Add a folder called _custom.</li>

        <li data-source-node="n51">Add a subfolder called images.</li>
    </ol>
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n52">
    <span class="i-section-heading-icon" data-source-node="n53"><span class="i-hidden" data-source-node="n54"> </span></span><span class="i-section-heading-text" data-source-node="n55">Step 2: Copy the image to _custom</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n56">
    <ol class="i-last-child" data-source-node="n57">
        <li data-source-node="n58">Copy the new background image to the _custom\images folder created in Step 1. Landscape images are recommended (if portrait image is used, custom css will need to be applied).</li>
    </ol>
</div>

<div id="i-6e3729bd-f917-430c-a08d-28a087f294d3-section-heading" class="i-section-heading" data-source-node="n59">
    <span class="i-section-heading-icon" data-source-node="n60"><span class="i-hidden" data-source-node="n61"> </span></span><span class="i-section-heading-text" data-source-node="n62">Step 3: Add custom css for the new image</span>
</div>

<div id="i-6e3729bd-f917-430c-a08d-28a087f294d3-section-content" class="i-section-content" data-source-node="n63">
    <p data-source-node="n64">The background image is defined in css. This section will walk through creating custom css to load the new image. In order to do this: </p>

    <p class="i-adjacent-paragraph" data-source-node="n65"> </p>

    <ol data-source-node="n66">
        <li data-source-node="n67">Create or edit a file named _custom.css in the _custom folder referenced in step 1. </li>

        <li data-source-node="n68">Add custom css to the file pointing to the new image as seen below.</li>
    </ol>

    <div class="i-filtered-content-CSS" data-title="CSS" data-itemid="CSS" data-source-node="n69">
        <table class="i-syntax-table" data-source-node="n70">
            <tbody data-source-node="n71">
                <tr data-source-node="n72">
                    <th data-source-node="n73">_custom.css</th>

                    <th data-source-node="n74">
                        <div class="i-copy-code-wrapper" data-source-node="n75">
                            <span class="i-copy-code" data-source-node="n76">Copy Code</span>
                        </div>
                    </th>
                </tr>

                <tr data-source-node="n77">
                    <td class="i-code" colspan="2" data-source-node="n78">
                        <pre data-source-node="n79">
<span style="COLOR: #800000" data-source-node="n80">body.dashboardbody </span>{
    <span style="COLOR: #ff0000" data-source-node="n81">background</span><span style="COLOR: #0000ff" data-source-node="n82">: url(/SCALE/_custom/images/CustomDashboardImage.png) no-repeat center center fixed !important;</span>
}
</pre>
                    </td>
                </tr>
            </tbody>
        </table>
    </div>

    <div class="i-box i-box-note" data-source-node="n83">
        NOTE: !important is required for the css to be applied properly. Use it for all css that you apply to the image. Additional css may be required depending on the image that is applied.
    </div>
</div>

</div>

<ol data-source-node="n88">
    <li data-source-node="n89">Open the dashboard page in a web browser: https://servername/scale/trans/dashboard.</li>

    <li data-source-node="n90">Verify the new background image loads.</li>
</ol>
