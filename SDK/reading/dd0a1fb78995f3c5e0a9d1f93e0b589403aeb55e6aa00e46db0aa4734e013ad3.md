    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The Immediate Dock Transfer web service allows for the immediate, non-work movement of a shipping container between shipping dock locations.  This is achieved by executing the following steps:</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Step 1: Retrieve a ShippingContainer Resource Representation</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <p data-source-node="n47">To initiate an Immediate Dock Transfer, one must first perform an HTTP GET to retrieve a ShippingContainer resource representation using the following request/response information:</p>

    <p data-source-node="n48"><strong data-source-node="n49">Request:</strong></p>

    <ul data-source-node="n50">
        <li data-source-node="n51"><strong data-source-node="n52">URI:</strong> http://<i data-source-node="n53">ServerName</i>/ILSIntegrationServices/ShippingContainers-NoOpenWork?warehouse={warehouse}&amp;containerId={containerId}</li>

        <li data-source-node="n54"><strong data-source-node="n55">Method:</strong> GET</li>

        <li data-source-node="n56"><strong data-source-node="n57">Accept:</strong> application/json or application/xml</li>

        <li data-source-node="n58"><strong data-source-node="n59">Roles:</strong> SCALEUSER,Confidential</li>
    </ul>

    <p data-source-node="n60"> </p>

    <p data-source-node="n61"><strong data-source-node="n62">Response:</strong></p>

    <p data-source-node="n63">Aside from <a href="330a68671fd01d31e69b8634088ee603d769cc8b8d2c45b49f4a3d068a6f9bdb.html" data-source-node="n64">standard responses</a>, note the following specifics for this service:</p>

    <p data-source-node="n65"></p>

    <table class="members" data-source-node="n66">
        <tbody data-source-node="n67">
            <tr data-source-node="n68">
                <th class="nameColumn" data-source-node="n69">Status Code</th>

                <th class="descriptionColumn" data-source-node="n70">Notes</th>
            </tr>

            <tr data-source-node="n71">
                <td data-source-node="n72">200</td>

                <td data-source-node="n73">OK will be accompanied by an entity in the requested media type: <a href="../source/downloads/af2c2f17c50f4f1530f5daeb9d1140f90286bd41f1f438ac78d0e433f4c1a38f.json" data-source-node="n74">JSON</a>, <a href="../source/downloads/68a46243614c196bbf806210ac9da735f0a948460a12f5d8be684c0f0b7d0de0.xsd" data-source-node="n75">XML</a></td>
            </tr>

            <tr data-source-node="n76">
                <td data-source-node="n77">400</td>

                <td data-source-node="n78">The following ErrorTypes can be expected: <strong data-source-node="n79">Container, Warehouse</strong></td>
            </tr>
        </tbody>
    </table>

    <p data-source-node="n80"></p>
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n81">
    <span class="i-section-heading-icon" data-source-node="n82"><span class="i-hidden" data-source-node="n83"> </span></span><span class="i-section-heading-text" data-source-node="n84">Step 2: Post the ShippingContainer using its ImmediateDockTransfer URI Template</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n85">
    <p data-source-node="n86">The ShippingContainer resource representation will include the <strong data-source-node="n87">ImmediateDockTransfer</strong> URI Template field that contains a single <strong data-source-node="n88">{location}</strong> token.  To execute the transfer, substitute the desired destination dock location and perform the following HTTP POST:</p>

    <p data-source-node="n89"><strong data-source-node="n90">Request:</strong></p>

    <ul data-source-node="n91">
        <li data-source-node="n92"><strong data-source-node="n93">URI:</strong> From ShippingContainer's ImmediateDockTransfer URI Template field</li>

        <li data-source-node="n94"><strong data-source-node="n95">Method:</strong> POST</li>

        <li data-source-node="n96"><strong data-source-node="n97">Accept:</strong> application/json or application/xml</li>

        <li data-source-node="n98"><strong data-source-node="n99">Content-Type:</strong> application/json or application/xml</li>

        <li data-source-node="n100"><strong data-source-node="n101">Entity:</strong> The ShippingContainer from Step 1</li>
    </ul>

    <p data-source-node="n102"> </p>

    <p data-source-node="n103"><strong data-source-node="n104">Response:</strong></p>

    <p data-source-node="n105">Aside from <a href="330a68671fd01d31e69b8634088ee603d769cc8b8d2c45b49f4a3d068a6f9bdb.html" data-source-node="n106">standard responses</a>, note the following specifics for this service:</p>
