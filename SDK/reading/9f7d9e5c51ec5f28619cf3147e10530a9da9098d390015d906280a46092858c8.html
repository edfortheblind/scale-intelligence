Address Validation Web Service
View with Navigation Tools

The Address Validation Web Service is used to invoke the Address Validation function of the application.  The addressCandidates resource represents the validation result of a single address, while the addressCandidatesList resource represents the validation results of several addresses.

For information on the configuration and use of Address Validation, please refer to the application's help.

 Request

addressCandidates resource:

  • URI: http://ServerName/ILSIntegrationServices/Shipping/addressCandidates?address1={address1}&address2={address2}&address3={address3}&city={city}&state={state}&postalCode={postalCode}&country={country}
    • address1: The first line of address information.
    • address2: Optional.  The second line of address information.
    • address3: Optional.  The third line of address information.
    • city: The city of the address to validate.
    • state: The state of the address to validate.
    • postalCode: The postal code of the address to validate.
    • country: The country of the address to validate.
  • Method: GET
  • Accept: application/xml

addressCandidatesList resource:

  • URI: http://ServerName/ILSIntegrationServices/Shipping/addressCandidatesList
  • Method: POST
  • Content-Type: application/xml
  • Roles: SCALEUSER,Confidential
  • Entity:
    • AddressCandidatesListCriteria.xsd: Contains a list of Addresses to be given as input to the Address Validation function.
      • Address.xsd: Used to express one of the addresses to validate.
 Response

Aside from standard responses, note the following specifics for this service:

addressCandidates resource:

Status Code Notes
200

OK will be accompanied by an entity conforming to the following schema:

  • AddressCandidates.xsd: Contains a list of Addresses or an error message.
    • Address.xsd: Used to express each individual address suggested by the Address Validation function.

 

addressCandidatesList resource:

Status Code Notes
200

OK will be accompanied by an entity conforming to the following schema:

  • AddressCandidatesList.xsd: Contains a list of AddressCandidates.
    • AddressCandidates.xsd: Contains a list of Addresses or an error message.
      • Address.xsd: Used to express each individual address suggested by the Address Validation function.
