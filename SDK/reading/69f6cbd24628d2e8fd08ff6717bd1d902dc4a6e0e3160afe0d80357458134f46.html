How to: Add Detail Pane Menu Options
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Detail Pane > How to: Add Detail Pane Menu Options

Follow these steps to add the menu options that are standard for the detail pane of insight screens, as well as new custom menu options.

 Step 1: Create required modal dialogs
If any actions on the insight screen will require input via modal dialogs, create them. Please reference the How to: Create a Dynamic Modal Dialog topic for more information.
 Step 2: Create new menu screen groups
       

Add a SCREEN_GROUP record as follows in order to create an actions menu for the detail pane. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the Insight menu pane
GROUP_NAME DetailPaneMenu
RESOURCE_KEY NULL
GROUP_TYPE 70 (Menu)
PARENT_GROUP_ID NULL
NESTED_GROUP_UNIT Set this to the Object Id of this screen group record once it is created
DIV_CSS_CLASS nav nav-pills
ROW_CSS_CLASS row rowmenupanel
                       
 Step 3: Create screen control related records for each action

Please reference the How to: Create Metadata Screen Actions topic for instructions.
