        <div class="summary" data-source-node="n41">
    The ProcessDockAssignmentWaveStep operation belongs to the Dock Management Web Service. It is invoked as part of the Dock Assignment Wave Step and is not intended to be called by a custom implementation. 
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Step 1: Retrieve a Shipping Resource Representation</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <p data-source-node="n47">First perform an HTTP GET to retrieve a Shipping resource representation.</p>

    <p data-source-node="n48">How to: <a href="15f4741027cfd823e26da0bc96553096c9655a5a8d497e3a92a0830eea6f1929.html" data-source-node="n49">Shipping Web Service</a></p>
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n50">
    <span class="i-section-heading-icon" data-source-node="n51"><span class="i-hidden" data-source-node="n52"> </span></span><span class="i-section-heading-text" data-source-node="n53">Step 2: Post the WaveNumber using the locateWaveContainers link</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n54">
    <p align="left" data-source-node="n55">The Shipping resource representation will include a <strong data-source-node="n56">locateWaveContainers</strong> URI Template field that contains a single {waveNumber} token. To invoke DockAssignmentWaveStep for a wave, substitute the desired wave number and perform the following HTTP POST:</p>

    <p data-source-node="n57"><strong data-source-node="n58">Request:</strong></p>

    <ul data-source-node="n59">
        <li data-source-node="n60"><strong data-source-node="n61">URI:</strong> From Shipping representation's link (rel="locateWaveContainers") href</li>

        <li data-source-node="n62"><strong data-source-node="n63">Method:</strong> POST</li>

        <li data-source-node="n64"><strong data-source-node="n65">Content-Type:</strong> application/json or application/xml</li>

        <li data-source-node="n66"><strong data-source-node="n67">Roles:</strong> SCALEUSER,Confidential</li>
    </ul>

    <p data-source-node="n68"> </p>

    <p data-source-node="n69"><strong data-source-node="n70">Response:</strong></p>
