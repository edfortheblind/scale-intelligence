    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">The detail pane is filled when a grid record in the list pane is selected. This fires an event that will call the configured web service and bind the detail pane controls with the json returned.</p>

<div id="i-454c9ef7-c84e-4eef-8737-9d33e20144ee-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Step 1: Configure the grid record selected event</span>
</div>

<div id="i-454c9ef7-c84e-4eef-8737-9d33e20144ee-section-content" class="i-section-content" data-source-node="n52">
    <p data-source-node="n53">The main list pane grid of an insight screen needs to have an event created in metadata when the user selects a new row in the grid.</p>

    <div id="i-fe942430-6a26-4138-8613-e151aa82dfa4-section-heading" class="i-section-heading" data-source-node="n54">
        <span class="i-section-heading-icon" data-source-node="n55"><span class="i-hidden" data-source-node="n56"> </span></span><span class="i-section-heading-text" data-source-node="n57">Create a screen control event record tied to the main list pane grid</span>
    </div>

    <div id="i-fe942430-6a26-4138-8613-e151aa82dfa4-section-content" class="i-section-content" data-source-node="n58">
        <p data-source-node="n59">Add a SCREEN_CONTROL_EVENT record as follows for the main list pane grid. This defines what gets called when a record is selected in the grid. This action will call the configured web service and bind the detail pane controls to the data returned. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n60"><u data-source-node="n61"><font color="navy" data-source-node="n62">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>

                <tr data-source-node="n70">

    </div>

This defines what web service will get called when the user selects a row in the grid. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n87"><u data-source-node="n88"><font color="navy" data-source-node="n89">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>
