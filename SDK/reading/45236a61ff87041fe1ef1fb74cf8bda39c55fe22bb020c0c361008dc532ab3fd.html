Integration Services > REST-Based Web Services > Work Web Services > Confirm into Tote Outbound Work Instruction

The Outbound Work Execution Web Service invokes the Execute Work function for Shipment and Dock Management of the application when performing a POST to the OutboundWorkInstructions-ConfirmTote resource.

 Request
  • URI: http://ServerName/outbound/outboundWorkInstructions/outboundWorkInstructions-ConfirmedIntoTote
  • Method: POST
  • Content-Type: application/json or application/xml
  • Entity: JSON, XML
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity that represents the successfully executed work instruction: JSON, XML
