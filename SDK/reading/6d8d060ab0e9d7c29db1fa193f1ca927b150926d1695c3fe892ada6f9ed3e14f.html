How to: Create Section Headers on a Detail/Transaction Screen
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Detail Pages > How to: Create Section Headers on a Detail/Transaction Screen

Follow these steps to add new section header on a detail or transaction screen.

 Step 1: Create new header screen group and screen group column
       

Add a SCREEN_GROUP record as follows in order to create an section header background container. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_PART_ID The Screen Part Id of the detail screen
GROUP_NAME The name of the screen group
RESOURCE_KEY NULL
GROUP_TYPE 60 (Panel)
PARENT_GROUP_ID The Screen Group Id of the parent SCREEN_GROUP
NESTED_GROUP_UNIT The Screen Group Id of the parent SCREEN_GROUP
DIV_CSS_CLASS row ScreenGroupPanel cruddetailtitlepanel
ROW_CSS_CLASS NULL
       

Add a SCREEN_GROUP_COLUMN record as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
COLUMN_NAME The name of the screen group column
COLUMN_CSS_CLASS col-lg-12 col-md-12 col-sm-12 col-12 cruddatapanedetailrowcolumn
SCREEN_GROUP_ID The Screen Group Id of Screen Group created above
 Step 2: Create a new label screen control
         

Add a label SCREEN_CONTROL record as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_GROUP_ID The Screen Group Id of Screen Group created above
SCREEN_GROUP_COLUMN_ID The Screen Group Column Id of Screen Group Column created above
CONTROL_NAME The name of the screen control
RESOURCE_KEY Resource key that should be shown on the label
CONTROL_TYPE 30 (Label)
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE NULL
DATA_SOURCE NULL
DIV_CSS_CLASS NULL
CONTROL_CSS_CLASS cruddetailtitlelabel
