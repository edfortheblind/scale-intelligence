    <p data-source-node="n49">Web API Exit Point needs to add before configuring the exit point.</p>
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n50">
    <span class="i-section-heading-icon" data-source-node="n51"><span class="i-hidden" data-source-node="n52"> </span></span><span class="i-section-heading-text" data-source-node="n53">Steps to Add Web API Exit Point</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n54">
    Needs to follow the below steps to add an Exit Point for a Web API. In below example we are adding exit point for <b data-source-node="n55">WorkInstructionsApi</b> API.

    <p data-source-node="n56">- Get the URI from SDK for this API.</p>

    <p data-source-node="n57"> <img border="0" alt="" src="../source/assets/945996b4566bf6b937b02d334d26c4f06148bf5e0a0ef5372d7df7b7cef4fc76.png" loading="eager" data-source-node="n58"></p>

    <p data-source-node="n59"></p>

    <p data-source-node="n60">-Go to SCALE  Exit Point Control configuration screen . Open Exit Point Control for <b data-source-node="n61">WebAPI</b> category.</p>

    <p data-source-node="n62"> <img border="0" alt="" src="../source/assets/8b0a57f008448b48482ff87b1e60f56527aa7b973f8b4ab0e57f98f91c286f1f.png" loading="eager" data-source-node="n63"></p>

    <p data-source-node="n64"></p>

    <p data-source-node="n65">-Click on "Actions" from above screen. On  "Add Exit Point" selection below screen will display.</p>

    <p data-source-node="n66"> <img border="0" alt="" src="../source/assets/092481e7ab10085fc3832a17a492f4c12aa58bb427c3633ebf7dcae8949795bd.png" loading="eager" data-source-node="n67"></p>

    <p data-source-node="n68"></p>

    <p data-source-node="n69">-Select "Action" and enter the "API", "Method"  as mentioned in URI .</p>

    <p data-source-node="n70">For the above API Action should be <b data-source-node="n71">POST</b>, API <b data-source-node="n72">WorkInstructionsApi</b> and Method <b data-source-node="n73">workInstructions</b></p>

    <p data-source-node="n74"> <img border="0" alt="" src="../source/assets/84aff6da00b43f0ed279d301576e7a3462c71444a0ed74e7ff74c82008d5c285.png" loading="eager" data-source-node="n75"></p>

    <p data-source-node="n76">-Execute must be selected in case of <b data-source-node="n77">POST\PUT</b> action.</p>

    <p data-source-node="n78"><strong data-source-node="n79">After</strong> must be selected in case Exit Point returns <strong data-source-node="n80">custom</strong> json along with API response.Otherwise <strong data-source-node="n81">Before</strong>  must be selected .</p>
