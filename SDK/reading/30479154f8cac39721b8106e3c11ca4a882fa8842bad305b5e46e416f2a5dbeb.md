    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">A column value inside a grid on the detail pane can be displayed as a hyperlink by setting the template property of the IgniteUI grid column header. This allows for flexible conditional formatting (i.e. a column value can be displayed as a hyperlink or plain text based on a specified condition). This is achieved by setting the column template attribute value for an IgniteUI grid column header object. The system processes the given template value using either the IgniteUI or Handlebars template engine. An example column template value with the Handlebars template engine is shown below.</p>

<div id="i-edb6ed57-dd77-42df-9119-e5adc0deb9b1-section-content" class="i-section-content" data-source-node="n88">
    <p data-source-node="n89">The detail pane data is generally filled via a stored procedure. See the <a href="35cdfcbe2823f6394fe2644f35985b4dd4c0b5f9cf4e66f1d6d0d8f7fa5b8339.html" data-source-node="n90">How to: Create a Detail Pane Stored Procedure</a> topic for more details on creating this stored procedure. This stored procedure can have a special table returned named "AdditionalInfo".  To make a column in a grid be a hyperlink, you will need to insert a record into the "AdditionalInfo" table inside the detail pane stored procedure to set the template property value for a column. If the "AdditionalInfo" table does not exist in the stored procedure, then create one using the following as an example.</p>
