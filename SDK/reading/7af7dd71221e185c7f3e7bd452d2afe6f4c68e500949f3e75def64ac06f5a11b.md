    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">The complex screen architecture exists to create complex transaction screens using a mixture of metadata and Knockout components. The code for these screens is under &lt;installDirectory&gt;/web/dist and also served from there. The technologies used in this architecture are as follows:</p>

<ul data-source-node="n48">
    <li data-source-node="n49">Knockout</li>

    <li data-source-node="n50">Typescript</li>

    <li data-source-node="n51">Syntactically Awesome Style Sheets (SASS)</li>
</ul>

<p data-source-node="n52">The complex screens are written with Knockout component binding (<a href="http://knockoutjs.com/documentation/component-binding.html" data-source-node="n53">http://knockoutjs.com/documentation/component-binding.html</a>). Each component uses extensive Knockout binding (<a href="http://knockoutjs.com/documentation/introduction.html" data-source-node="n54">http://knockoutjs.com/documentation/introduction.html</a>).</p>

<p data-source-node="n55">The complex screens still use the Infragistics IgniteUI controls with their Knockout support. There are also other custom bindings created by Manhattan Associates such as “EnterKey” and “Modal” bindings. Each Knockout component has Typescript files, HTML files and a SASS file. There are also other Typescript files which are referenced by the main Component.ts file.<br data-source-node="n56"></p>
