How to: Override the Default Success Callback
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Actions > How to: Override the Default Success Callback

Every web service call triggered by an action goes through a single default success callback JavaScript function. This function is named defaultSuccessCallback and is in the webclient.js file. It simply displays a success message to the user. You can override the default success callback dynamically for POST and GET methods through metadata. Use the How to: Perform a POST Service Call from Metadata Action or How to: Perform a DELETE Service Call from Metadata Action topics to create the proper metadata records to call the web service. Then, add a SCREEN_CONTROL_EVENT_PARAMETERS record to override the default success callback. The format of this record depends on the type of service being called. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
PARAMETER_NAME <Method>_SuccessCallback (e.g. Post_SuccessCallback or Delete_SuccessCallback)
PARAMETER_VALUE The path of the success callback function to call (e.g. _webUi.insightSearchPaneActions.saveSearchSuccessCallback)
SCREEN_CONTROL_ID_EVENT_ID The Object Id of the screen control event
