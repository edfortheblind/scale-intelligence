How to Add Custom Action With Multiple Selection On InsightPage
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > How to Add Custom Action With Multiple Selection On InsightPage

The tooling provided for creating a new custom action on the insight page with multiple selection on the grid and passing the column data(comma separated) to the stored Procedure.

 Step 1: Copy an Existing Insight Page Script

Browse to the directory that SCALE is installed to and then go to the sub folder Database | ILS | DBChange | _Metadata | Insight. Pick a script for the screen on which you want to add the custom action. Copy the script to another location, rename it, and open it.

 Step 2: Create Custom Action screen control
 Now add a SCREEN_CONTROL record as follows for the custom action. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).
Field Value
CONTROL_NAME [ListPane] MenuAction [Action]
RESOURCE_KEY Resource key for the Action
CONTROL_TYPE 150
LABEL_ORIENTATION NULL
DATA_SOURCE_TYPE NULL
DATA_SOURCE NULL
DIV_CSS_CLASS NULL
CONTROL_CSS_CLASS dropdownaction
TOOL_TIP_RESOURCE_KEY Resource key for the button
 Step 3: Create a screen control event record tied to the custom action. control
Reference the How to: Create Screen Control Events topic in order to add event for the new control.
Field Value
EventId click
EventName _webUi.insightListPaneActions.menuActionPerformPostForMultipleSelection
 Step 4: Create screen control event parameters record tied to the event
Reference the How to: Create Screen Control Event Parameters topic in order to add event parameters for the new event.
Field Value
ParameterName PostData_Grid_ListPaneDataGrid_[Column Name]
ParameterValue [Column Name]

Field Value
ParameterName PostData_storedProcedure
ParameterValue [Stored Procedure]

Field Value
ParameterName POSTServiceURL
ParameterValue [/outbound/scaleapi/GenericDataExecutionApi]

 Step 5: Run the script on the corresponding datatbase environment.
