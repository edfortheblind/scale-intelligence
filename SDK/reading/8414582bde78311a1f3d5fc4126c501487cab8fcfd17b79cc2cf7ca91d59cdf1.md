    <span class="i-section-heading-icon" data-source-node="n48"><span class="i-hidden" data-source-node="n49"> </span></span><span class="i-section-heading-text" data-source-node="n50">System level feature flags</span>
</div>

<div id="i-077faedd-56f1-40bd-ac85-30cd3937a6a4-section-content" class="i-section-content" data-source-node="n51">
    <p data-source-node="n52">System level Feature flags are defined in the “FeatureFlags.xml” file and they can be found in the “Settings” folder of the Manhattan SCALE application servers.</p>

    <ol data-source-node="n53">
        <li data-source-node="n54">Defines the list of features that the system is supporting.</li>

        <li data-source-node="n55">Features can be turned on/off using these settings.</li>
    </ol>

    <p data-source-node="n56"><b data-source-node="n57">Example:</b></p>

    <p data-source-node="n58">Transferring a Multiple Order Pallet (MOP), containing many shipping containers takes more time. This process can be submitted to batch by turning on (setting to “true”) the feature “TransferMultiOrderPalletBatchSubmission”.</p>

    <p data-source-node="n59"><img border="0" alt="" src="../source/assets/58172196304435f8e6c9695dbe9214a97a259b8465e90e6760c355c656b62c1f.png" loading="eager" data-source-node="n60"></p>
</div>

<div id="i-110c9498-8dc2-44fc-8bb1-998756054c74-section-heading" class="i-section-heading" data-source-node="n61">
    <span class="i-section-heading-icon" data-source-node="n62"><span class="i-hidden" data-source-node="n63"> </span></span><span class="i-section-heading-text" data-source-node="n64">Run time settings:</span>
</div>

<div id="i-110c9498-8dc2-44fc-8bb1-998756054c74-section-content" class="i-section-content" data-source-node="n65">
    <p data-source-node="n66">Run time settings can be defined in the “Runtime.xml” file and can be found in the “Settings” folder of the Manhattan SCALE application servers.</p>

    <ol data-source-node="n67">
        <li data-source-node="n68">Defines a list of settings that impact the changes dynamically.</li>

        <li data-source-node="n69">Changes will be impacted without being resetting the services.</li>
    </ol>

    <p data-source-node="n70"><b data-source-node="n71">Example:</b></p>

    <p data-source-node="n72">Whenever a license is added/changed, changing the value of the below highlighted key (ReloadLicense) will reload the license into the system without the need of resetting the services.</p>
