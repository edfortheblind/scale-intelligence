        <p data-source-node="n47">Individual controls on a Detail page are bound to properties on the returned NHibernate entity by specifying the NHibernate property in the DATA_SOURCE column of the SCREEN_CONTROL table along with the appropriate DATA_SOURCE_TYPE.</p>

    <span class="i-section-heading-icon" data-source-node="n77"><span class="i-hidden" data-source-node="n78"> </span></span><span class="i-section-heading-text" data-source-node="n79">Step 2: Update the DATA_SOURCE and DATA_SOURCE_TYPE fields</span>

<div id="i-6345cea4-a345-410d-a9b0-88f2853a2728-section-content" class="i-section-content" data-source-node="n80">
    <p data-source-node="n81">To add a binding or change the binding on the control, simply update the DATA_SOURCE and DATA_SOURCE_TYPE fields accordingly. The DATA_SOURCE field must be filled with an NHibernate property, which is generally the database field name minus the underscores, with the first letter and each letter after the underscores capitalized and all other letters lower case (it is case sensitive). For example, the SHIPMENT_ID database column would be ShipmentId on an NHibernate entity. The DATA_SOURCE_TYPE is filled with one of the identifiers from the "Metadata data source type" configuration. For example, to bind an editor on a Detail page to the SHIPMENT_ID column, set the control to have DATA_SOURCE = 'ShipmentId' and DATA_SOURCE_TYPE = 20 (Data-bind attribute). Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n82"><u data-source-node="n83"><font color="navy" data-source-node="n84">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>
