    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">A detail screen can currently only be driven from a single database entity (either table or view) and must have an NHibernate entity generated for it. This entity is defined by the TABLE_NAME column on the FORM table tied to the screen. It should be filled with the NHibernate entity name that the screen will be tied to (for example "WorkInstruction").</p>

        <div class="i-box i-box-note" data-source-node="n110">
            Please note that changing the table or view on an detail screen only changes the table or view that the detail page binds with. Specific controls may reference column names or properties that do not exist in the table or view and in this case errors will occur on the screen. The individual properties that other controls on the page point to will need to be updated as well. Please reference the XXX page for more details.
