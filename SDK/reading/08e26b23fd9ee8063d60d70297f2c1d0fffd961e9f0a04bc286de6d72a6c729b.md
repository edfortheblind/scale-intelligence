        <p data-source-node="n47">This topic will walk you through changing a metadata text editor to a combo box with a drop down list.</p>

</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n52">

For this example, let's assume that there is an Insight screen that has User Defined Field 1 as a basic search criteria field. Find the OBJECT_ID of the corresponding SCREEN_CONTROL record for the text editor control. The below SQL will return the entire list of controls for a screen and the correct control should be chosen from the list. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n54"><u data-source-node="n55"><font color="navy" data-source-node="n56">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n100">

        <span class="i-section-heading-icon" data-source-node="n102"><span class="i-hidden" data-source-node="n103"> </span></span><span class="i-section-heading-text" data-source-node="n104">Determine the control type</span>

    <div id="i-ff7b2078-4994-4443-a27c-66dca568ffdd-section-content" class="i-section-content" data-source-node="n105">
        Find the control type for a combo box. Reference the "Screen Control Type" configuration for an enumeration of screen control types. The enumeration key for ComboBox is "80".
    </div>

    <div id="i-8e27dace-b077-434b-b499-3eceae4e35bf-section-heading" class="i-section-heading" data-source-node="n106">
        <span class="i-section-heading-icon" data-source-node="n107"><span class="i-hidden" data-source-node="n108"> </span></span><span class="i-section-heading-text" data-source-node="n109">Determine the data source type</span>
    </div>

    <div id="i-8e27dace-b077-434b-b499-3eceae4e35bf-section-content" class="i-section-content" data-source-node="n110">
        Find the data source type for a generic config list. Reference the "Metadata Data Source Type" configuration for the full list of supported data source type enumerations. The enumeration key for generic configuration is "30".
    </div>

    <div id="i-ed3ed6be-5b31-4a09-a0b2-bd4971afcc06-section-heading" class="i-section-heading" data-source-node="n111">
        <span class="i-section-heading-icon" data-source-node="n112"><span class="i-hidden" data-source-node="n113"> </span></span><span class="i-section-heading-text" data-source-node="n114">Determine the data source</span>
    </div>

    <div id="i-ed3ed6be-5b31-4a09-a0b2-bd4971afcc06-section-content" class="i-section-content" data-source-node="n115">
        Find the data source for the Country configuration. Reference the <a href="214eb77fcca668e6d3d5cd9070338718eb6ee7521adef16d8be75751c6a0e94f.html" data-source-node="n116">How to: Define Lists tied to Controls</a> topic for more information. The enumeration key for this example is "COUNTRY".
    </div>

    <div id="i-6278fd5b-e572-48e3-8f61-727f1c0bda67-section-heading" class="i-section-heading" data-source-node="n117">
        <span class="i-section-heading-icon" data-source-node="n118"><span class="i-hidden" data-source-node="n119"> </span></span><span class="i-section-heading-text" data-source-node="n120">Update control type, data source type, and data source</span>

    <div id="i-6278fd5b-e572-48e3-8f61-727f1c0bda67-section-content" class="i-section-content" data-source-node="n121">

Also update the DATA_SOURCE_TYPE and DATA_SOURCE values so that the combo box points to the correct list. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n123"><u data-source-node="n124"><font color="navy" data-source-node="n125">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>
