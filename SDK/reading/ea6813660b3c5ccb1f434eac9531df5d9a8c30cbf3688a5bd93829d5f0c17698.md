    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Actions in the metadata screens use the same security concepts and configurations as the rest of the system. Follow the steps below to add security to an action on a metadata page.</p>

<div id="i-5a980e86-8708-4458-b2d8-ff80774b719a-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Step 1: Create a security checkpoint for the action</span>
</div>

<div id="i-5a980e86-8708-4458-b2d8-ff80774b719a-section-content" class="i-section-content" data-source-node="n52">
    <p data-source-node="n53">Create a SECURITY_CHECKPOINT record for the action that is tied to the appropriate Form Id.</p>

    <p data-source-node="n54"></p>

    <table data-source-node="n55">
        <tbody data-source-node="n56">

            </tr>

            <tr data-source-node="n62">
                <td data-source-node="n63">FORM_ID</td>

                <td data-source-node="n64">The Form Id for the current page that action will be added to.</td>
            </tr>

            <tr data-source-node="n65">
                <td data-source-node="n66">CHECK_POINT</td>

                <td data-source-node="n67">Unique identifier for the checkpoint for the action. Custom checkpoints start at 21, so use the first available number after 21 for the Form Id.</td>
            </tr>

            <tr data-source-node="n68">
                <td data-source-node="n69">RESOURCE_FILE_KEY</td>

                <td data-source-node="n70">Resource key that will be used to display the checkpoint in the "Security Permissions" screen.</td>
            </tr>
        </tbody>
    </table>
