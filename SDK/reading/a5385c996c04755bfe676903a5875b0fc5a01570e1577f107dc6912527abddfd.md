    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Metadata actions can also be enabled and disabled based on data on the screen. For example, when a new record is selected in the list pane grid, certain actions may need to be enabled or disabled based on the data in that row. Records can be added to the SCREEN_CONTROL_EVENT_PARAMETERS table to configure the data that determines whether an action is enabled or disabled when a new record in the grid is selected. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n48"><u data-source-node="n49"><font color="navy" data-source-node="n50">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>

<p data-source-node="n51"></p>

<div class="i-box i-box-note" data-source-node="n52">
    Please note that security checkpoints in the system override the metadata configurations for enabling or disabling an action.
</div>
