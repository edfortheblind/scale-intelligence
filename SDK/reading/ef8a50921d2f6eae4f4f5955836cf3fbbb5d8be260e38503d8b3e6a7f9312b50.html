How to: Customize the Signon Page Logo
View with Navigation Tools

This topic will walk you through customizing the logo found on the Signon page.

 Step 1: Add the _custom folder
  1. Browse to the %SCALE_HOME% \web directory on the SCALE server. 
  2. Add a folder called _custom.
  3. Add a subfolder called images.
 Step 2: Copy the image to _custom
  1. Copy the new logo image to the _custom\images folder created in Step 1.
  2. Rename the file to LoginLogo.png.     
  3. Perform an iisreset to see the new image on the Signon page.

     

 Step 3: Verify the logo loads properly
  1. Open the signon page in the web browser: https://<server_name>/scale/security/login.
  2. Verify the new image loads.
 Step 4: Add custom css if necessary

Images can be different shapes and sizes. If the new logo is not the same size and shape as the base SCALE logo custom css can be specified to center and re-size it. 

 

To do this perform the following steps:

  1. Create a file called _custom.css in the _custom folder created in step 1.
  2. Add custom css to the file as needed by customizing the .logo and .logonimage classes.

 

For example to change the size of the image add the following custom css to _custom.css.

_custom.css
Copy Code

.logo

{

font-size: 1.5em !important;

}
                      
NOTE: !important is required to be defined for all css to ensure the customization is applied properly.
