    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">The Content loading type value in metadata allows for specifying how you want to load content on a detail screen.</p>

<div id="i-5be16e34-6bfe-46f8-9485-8b333683986e-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Setting Content loading type on a new group or subgroup when metadata is created</span>
</div>

<div id="i-5be16e34-6bfe-46f8-9485-8b333683986e-section-content" class="i-section-content" data-source-node="n52">
    <p data-source-node="n53">In order to set the Content loading type on a group or subgroup as it is being created from metadata, simply set the CONTENT_LOADING_TYPE on the group or  subgroup.</p>

    <p data-source-node="n54"> </p>
</div>

<div id="i-5120cb95-4ef4-45fc-b83e-8ef647886de1-section-heading" class="i-section-heading" data-source-node="n55">
