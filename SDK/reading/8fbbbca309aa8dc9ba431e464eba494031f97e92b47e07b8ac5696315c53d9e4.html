How to: Show a Metadata Page Inside a Modal Dialog
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Actions > How to: Show a Metadata Page Inside a Modal Dialog

Metadata web pages often need to be shared across other pages. In these instances, a modal dialog can be used to display a completely separate web page. These modals should have very little content to prevent scrolling on tablet devices, and they should also not require multiple "stacked" levels of modals. If they do, another means of showing the page should be used. Showing another metadata web page inside a modal dialog can be configured through metadata as follows.

 Step 1: Create a screen control or find an existing screen control
Please reference the How to: Create Screen Controls topic for instructions on creating the control that will trigger the action.
 Step 2: Create the screen control event and parameters for displaying the modal dialog

Create a new SCREEN_CONTROL_EVENT record as follows. This defines what gets called when the event is fired. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_CONTROL_ID The Screen Control Id of the the control that fires the action
EVENT_ID click or another event to be fired depending on the type of the control
EVENT_NAME _webUi.insightListPaneActions.menuActionOpenUrlInModalDialog


Now create a SCREEN_CONTROL_EVENT_PARAMETERS record to define the URL that should be displayed inside the modal dialog. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
PARAMETER_NAME URL
PARAMETER_VALUE The templatized value of the URL that should be in the modal (e.g. {{#if InternalShipmentNum}}{{FORM_ID=3030}}/internalShipmentNum={{InternalShipmentNum}}{{/if}})
SCREEN_CONTROL_ID_EVENT_ID The Object Id of the screen control event
