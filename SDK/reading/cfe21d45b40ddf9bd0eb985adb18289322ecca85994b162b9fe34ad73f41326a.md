    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">The tooling provided for creating a new custom Transaction page is not complete. For now, follow the instructions below in order to create a new Transaction page.</p>

<div id="i-dce9dd6b-259d-452c-b01e-beb6c52f0c7b-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Step 1: Copy an Existing Transaction Page Script</span>
</div>

<div id="i-dce9dd6b-259d-452c-b01e-beb6c52f0c7b-section-content" class="i-section-content" data-source-node="n52">
    <p data-source-node="n53">Browse to the directory that SCALE is installed to and then go to the sub folder Database | ILS | Scripts | _Metadata | Transaction. Pick a script for a screen that is the most similar to the page you want to create. Copy the script to another location, rename it, and open it.</p>
</div>

<div id="i-7def4e78-4ec5-474b-a0ac-6022f30d84c4-section-heading" class="i-section-heading" data-source-node="n54">
    <span class="i-section-heading-icon" data-source-node="n55"><span class="i-hidden" data-source-node="n56"> </span></span><span class="i-section-heading-text" data-source-node="n57">Step 2: Update Script with Page Level information</span>
</div>

<div id="i-7def4e78-4ec5-474b-a0ac-6022f30d84c4-section-content" class="i-section-content" data-source-node="n58">
    <p data-source-node="n59">Update the script for all page level information as follows:</p>

    <p data-source-node="n60"> </p>

    <ul data-source-node="n61">
        <li data-source-node="n62"><strong data-source-node="n63"><em data-source-node="n64">Form Id</em></strong>: Use a different Form Id for your new screen. At the top of the script you will see the Form Id being set similar to this: <strong data-source-node="n65">set @formId = 2767</strong>. Search and replace the actual Form Id value in the script with your new Form Id. The new Form Id value you use should be the next available Form Id &gt;= 60,000. So in the example given above, the Form Id 2767 should be replaced by 60000 everywhere in the script.</li>

        <li data-source-node="n66">
            <strong data-source-node="n67"><em data-source-node="n68">Form record</em></strong>: Update the call to <strong data-source-node="n69">DBC_IFORM</strong> as follows:

            <ul data-source-node="n70">
                <li data-source-node="n71">@formKeyName = MNU_&lt;customScreenName&gt;Transaction (i.e. MNU_CustomTransaction)</li>

                <li data-source-node="n72"><a data-source-node="n73">@tableName</a> = the name of the SQL Stored Procedure that will provide the view model for the Transaction screen. At the beginning you can leave the existing value in this field if you want the screen to open up initially as an exact replica of the screen script that was copied.</li>

                <li data-source-node="n74"><a data-source-node="n75">@associatedFormKey</a> = null</li>
            </ul>
        </li>

        <li data-source-node="n76"><strong data-source-node="n77"><em data-source-node="n78">Security</em></strong>: Remove all calls to <strong data-source-node="n79">dbc_ISecurityCheckpoint</strong> except for security_checkpoint 1 ("run").</li>

        <li data-source-node="n80">
            <strong data-source-node="n81"><em data-source-node="n82">Screen record</em></strong>: Update the call to <strong data-source-node="n83">DBC_IMAINUISCREEN</strong> as follows:

            <ul data-source-node="n84">
                <li data-source-node="n85"><a data-source-node="n86">@functionalArea</a> = the identifier of the functional area you want the screen to show up under in the menu</li>

                <li data-source-node="n87"><a data-source-node="n88">@menuResourceKey</a> = the Resource Key to be used for the page title</li>

                <li data-source-node="n89"><a data-source-node="n90">@path</a> = Update based on the Form Key Name entered on the Form record (i.e. /scale/trans/&lt;portion of Form Key Name between the starting "MNU_" and ending "transaction")</li>

                <li data-source-node="n91"><a data-source-node="n92">@restrictionsId</a> = set this to the configured Spring Id for the .NET class that will house the "restrictions" list for the screen, if any (see the <a href="e52c7b80f83f0d4e4bbbb36c16b33ce83c60b0e350ec27e07b71b7afb03aa569.html" data-source-node="n93">Field Restrictions</a> topic for more information)</li>

                <li data-source-node="n94"><a data-source-node="n95">@defaultsId</a> = null</li>
            </ul>
        </li>

        <li data-source-node="n96"><strong data-source-node="n97"><em data-source-node="n98">Licensing</em></strong>: Remove all calls to <strong data-source-node="n99">dbc_IMainUiWmLicenseXrefOriginal</strong>.</li>
    </ul>
</div>

<div id="i-7b445a42-5e74-4881-a201-8d675eda0160-section-heading" class="i-section-heading" data-source-node="n100">
    <span class="i-section-heading-icon" data-source-node="n101"><span class="i-hidden" data-source-node="n102"> </span></span><span class="i-section-heading-text" data-source-node="n103">Step 3: Run the Modified Script</span>
</div>

<div id="i-7b445a42-5e74-4881-a201-8d675eda0160-section-content" class="i-section-content" data-source-node="n104">
    <p data-source-node="n105">Open SQL Server Management Studio and run the modified script ensuring there are no errors. Run an IISRESET and then try to browse to the new page. The URL will be in the format https://&lt;serverName&gt;/scale/trans/&lt;portion of form key name&gt;?&lt;list of query parameters&gt; (for example, if the Transfer Container script is copied, and the new form key name is listed as MNU_CUSTOMTRANSACTION, then the URL would be in the format <a href="https://travstg.manhscale.com/%3cservername%3e/scale/trans/custom?internalContainerNum=2822" data-source-node="n106">https://&lt;serverName&gt;/scale/trans/custom?internalContainerNum=2822</a>. Please note that if a new stored procedure is specified in the Table Name column of the Form record, then the screen will not function until the stored procedure exists and the controls on the script bind with it properly.</p>
</div>

<div id="i-376e22eb-ca06-429f-bcf0-b7f877b67a13-section-heading" class="i-section-heading" data-source-node="n107">
    <span class="i-section-heading-icon" data-source-node="n108"><span class="i-hidden" data-source-node="n109"> </span></span><span class="i-section-heading-text" data-source-node="n110">Step 4: Modify the General Controls on the Page</span>
</div>

<div id="i-376e22eb-ca06-429f-bcf0-b7f877b67a13-section-content" class="i-section-content" data-source-node="n111">
    <p data-source-node="n112">Now that the new page exists, we can modify the screen metadata for the general controls on the page using either Insight Architect (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n113">How to: Use Insight Architect to Customize a Metadata Page</a> ), modifying the script mentioned above, or straight SQL against the database. Transaction screens are formatted in the exact same way as Details screens, so please reference the topics <a href="7c404593faea4e5f14ce50f69ead468ed1729c06d6cb827b86e156a844b22b97.html" data-source-node="n114">How to: Modify an Existing Transaction Page</a> and <a href="6d8d060ab0e9d7c29db1fa193f1ca927b150926d1695c3fe892ada6f9ed3e14f.html" data-source-node="n115">How to: Create Section Headers on a Detail/Transaction Screen</a>  for a general overview of the Details and Transaction metadata.</p>
</div>

<div id="i-914b606a-74b8-4e1f-b8dc-b3dad30ca234-section-heading" class="i-section-heading" data-source-node="n116">
    <span class="i-section-heading-icon" data-source-node="n117"><span class="i-hidden" data-source-node="n118"> </span></span><span class="i-section-heading-text" data-source-node="n119">Step 5: Modify any Grids on the Page</span>
</div>

<div id="i-914b606a-74b8-4e1f-b8dc-b3dad30ca234-section-content" class="i-section-content" data-source-node="n120">
    <p data-source-node="n121">Now modify the screen metadata for any grids that need to be on the page using either Insight Architect (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n122">How to: Use Insight Architect to Customize a Metadata Page</a> ), modifying the script mentioned above, or straight SQL against the database. Reference the topic <a href="9ef78adfa70baccd6481ad222f0b9d219c9194cde1459736f627e007f1cb44c3.html" data-source-node="n123">How to: Add a Grid to a Detail/Transaction Screen</a> for a general overview of the metadata for grids on a Transaction page.</p>
</div>
