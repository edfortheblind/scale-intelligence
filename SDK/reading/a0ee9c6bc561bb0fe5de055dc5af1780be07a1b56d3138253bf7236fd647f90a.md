    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">The drilldown for most Dashboard tiles can be configured directly from the Basic and Advanced grids located in the Gadget query calculation configuration. It is recommended to use the grids in the configuration if at all possible. However, at times it may be necessary to manually enter the parameters yourself by choosing the Customize parameter string option. This allows the parameters to be manually entered, which enables fields to be included multiple times (i.e. to form a "range") as well as other more advanced capabilities. This topic outlines the format of the parameters for drilldown on Dashboard tiles.</p>

<p data-source-node="n48"> </p>

<div id="i-404e93d1-09cb-44de-b01a-b64f94d0662a-section-heading" class="i-section-heading" data-source-node="n49">
    <span class="i-section-heading-icon" data-source-node="n50"><span class="i-hidden" data-source-node="n51"> </span></span><span class="i-section-heading-text" data-source-node="n52">Basic criteria</span>
</div>

<div id="i-404e93d1-09cb-44de-b01a-b64f94d0662a-section-content" class="i-section-content" data-source-node="n53">
    <p data-source-node="n54">The basic criteria portion of the parameters has the following format:</p>

    <p data-source-node="n55"><strong data-source-node="n56">filters=&lt;Control Id&gt;</strong> █<strong data-source-node="n57">&lt;Value&gt;</strong></p>

    <p data-source-node="n58"> </p>

    <p data-source-node="n59">Use the ALT+219 █ character for the separator characters in the path as shown below.</p>

    <p data-source-node="n60"> </p>

    <table data-source-node="n61">
        <tbody data-source-node="n62">
            <tr data-source-node="n63">
                <td data-source-node="n64"><strong data-source-node="n65">Field</strong></td>

                <td data-source-node="n66"><strong data-source-node="n67">Description</strong></td>
            </tr>

            <tr data-source-node="n68">
                <td data-source-node="n69">&lt;Control Id&gt;</td>

                <td data-source-node="n70">The id of the corresponding control in metadata on the Insight screen for the tile.</td>
            </tr>

            <tr data-source-node="n71">
                <td data-source-node="n72">&lt;Value&gt;</td>

                <td data-source-node="n73">The value that the control should be filtered by on the Insight screen.</td>
            </tr>
        </tbody>
    </table>

    <p data-source-node="n74"> </p>
</div>

<div id="i-db4e99d6-d193-49a3-9555-5d282df61339-section-heading" class="i-section-heading" data-source-node="n75">
    <span class="i-section-heading-icon" data-source-node="n76"><span class="i-hidden" data-source-node="n77"> </span></span><span class="i-section-heading-text" data-source-node="n78">Advanced criteria format</span>
</div>

<div id="i-db4e99d6-d193-49a3-9555-5d282df61339-section-content" class="i-section-content" data-source-node="n79">
    <p data-source-node="n80">The advanced criteria portion of the parameters has the following format:</p>

    <p data-source-node="n81"><strong data-source-node="n82">advancedFilters=&lt;Database Column&gt;</strong> █<strong data-source-node="n83">&lt;Translated Text&gt;</strong> █<strong data-source-node="n84">&lt;Operand Identifier&gt;</strong> █<strong data-source-node="n85">&lt;Operand Text&gt;</strong> █<strong data-source-node="n86">&lt;Identifier&gt;</strong> █<strong data-source-node="n87">&lt;Description&gt;</strong> █<strong data-source-node="n88">&lt;Data Type&gt;    </strong> </p>

    <table data-source-node="n89">
        <tbody data-source-node="n90">
            <tr data-source-node="n91">
                <td data-source-node="n92"><strong data-source-node="n93">Field</strong></td>

                <td data-source-node="n94"><strong data-source-node="n95">Description</strong></td>
            </tr>

            <tr data-source-node="n96">
                <td data-source-node="n97">&lt;Database Column&gt;</td>

                <td data-source-node="n98">The database column that should be filtered.</td>
            </tr>

            <tr data-source-node="n99">
                <td data-source-node="n100">&lt;Translated Text&gt;</td>

                <td data-source-node="n101">The translated text for the database column name.</td>
            </tr>

            <tr data-source-node="n102">
                <td data-source-node="n103">&lt;Operand Identifier&gt;</td>

                <td data-source-node="n104">The identifier for the operand as defined in the Metadata filter operand configuration.</td>
            </tr>

            <tr data-source-node="n105">
                <td data-source-node="n106">&lt;Operand Text&gt;</td>

                <td data-source-node="n107">Optional. Only needs to be passed if the translated text for the operand needs to be different than the operand identifier.</td>
            </tr>

            <tr data-source-node="n108">
                <td data-source-node="n109">&lt;Identifier&gt;</td>

                <td data-source-node="n110">The identifier for actual filtering (i.e. a description of "Yes" has an identifier of "Y").</td>
            </tr>

            <tr data-source-node="n111">
                <td data-source-node="n112">&lt;Description&gt;</td>

                <td data-source-node="n113">The description for the identifier.</td>
            </tr>

            <tr data-source-node="n114">
                <td data-source-node="n115">&lt;Data Type&gt;</td>

                <td data-source-node="n116">The data type for the column. Valid values are A (Alpha), N (Number), and D (Date and DateTime).</td>
            </tr>
        </tbody>
    </table>

    <p data-source-node="n117"> </p>

<div id="i-5ed9cf5b-fcce-45a2-969e-c7656064d310-section-heading" class="i-section-heading" data-source-node="n118">
    <span class="i-section-heading-icon" data-source-node="n119"><span class="i-hidden" data-source-node="n120"> </span></span><span class="i-section-heading-text" data-source-node="n121">Example</span>
</div>

<div id="i-5ed9cf5b-fcce-45a2-969e-c7656064d310-section-content" class="i-section-content" data-source-node="n122">
    <p data-source-node="n123">Below is an example of a parameter string for a tile that is tied to the Inventory Insight screen.</p>

    <p data-source-node="n124"><strong data-source-node="n125">filters=SearchPaneWhs:MN,BasicCriteria-PermanentLocs:TRUE&amp;advancedFilters=ALLOCATED_QTY</strong> █<strong data-source-node="n126">Allocated qty</strong> █<strong data-source-node="n127">50</strong> █ █<strong data-source-node="n128">5</strong> █<strong data-source-node="n129">5</strong> █<strong data-source-node="n130">N</strong></p>

    <p data-source-node="n131"> </p>

    <p data-source-node="n132">This example is translated to the following filters on the Inventory Insight screen:</p>

    <ul data-source-node="n133">
        <li data-source-node="n134">Warehouse = MN</li>

        <li data-source-node="n135">Only permanent locations = toggled ON</li>

        <li data-source-node="n136">Allocated qty &gt; 5</li>
    </ul>
