 Starting Endpoints
To start endpoints simply start service "DIFCommunicationService". The service will start all configured active endpoints.
 Stoping Endpoints

To stop all endpoints simply stop service "DIFCommunicationService". When the service stops it will stop all running endpoints.

 Manually Stopping Endpoints

There is no way to stop endpoints manually. However, you can create a utility that sends commands to the administration socket to stop a specific endpoint. The default admin port is 9012. See section 'Services\DIF Communication Service' for details on how to use a different port.

 

This is an example of the code you need to write if you need to stop endpoints manually.

 

Example of client code to send stop command
Copy Code

using System;

using System.Collections.Generic;

using System.Linq;

using System.Text;

using System.Net.Sockets;

using System.Net;

namespace Manh.DeviceIntegrationFramework

{

class Test

{

public void SendStopCommand()

{

Socket socket = new Socket(AddressFamily.InterNetwork, SocketType.Stream, ProtocolType.Tcp);

try

{

string remoteAddress = "127.0.0.1"; //Put the IP addres of your server here.

int remotePort = 9012; //Change this value if you changed the default admin port

int endpoint = 0; // Find the endpoint id that you want to stop

IPAddress ipAddress = IPAddress.Parse(remoteAddress);

IPEndPoint endPoint = new IPEndPoint(ipAddress, remotePort);

socket.Connect(endPoint);

socket.ReceiveBufferSize = 4012;

socket.SendBufferSize = 4012;

string message = "StopEndpoint, " + endpoint;

byte[] data = Encoding.ASCII.GetBytes(message);

socket.Send(data);

}

finally

{

if (socket.Connected)

socket.Shutdown(SocketShutdown.Both);

 

socket.Close();

socket = null;

}

}

}

}
