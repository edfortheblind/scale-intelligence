    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The InvMgmtWithWorkCreation operation belongs to the Inventory Management Web Service. It takes information about inventory adjustments or transfers and creates work to fulfill the requests.<br data-source-node="n42">
<br data-source-node="n43">
The following schema represent the request and response messages of the InvMgmtWithWorkCreation operation.<br data-source-node="n44">
<br data-source-node="n45"></p>

<ul data-source-node="n46">
    <li data-source-node="n47"><b data-source-node="n48"><a href="../source/downloads/5ed7b0ac1b17a857b9d26ec421005c324cd4c8286e8ab0503a5efc3a1af71104.xsd" data-source-node="n49">Session.xsd</a>:</b> Holds user session information. Note that this information is located in the SOAP envelope's header and not as part of the body.<br data-source-node="n50">
    <br data-source-node="n51"></li>

    <li data-source-node="n52"><b data-source-node="n53"><a href="../source/downloads/ee393116cc8193a4f362b797a451be8ab03ff61c48d74c86f913479ea4bb6b1a.xsd" data-source-node="n54">InventoryTransactionRequest.xsd</a>:</b> Contains an unbounded list of transactions to roll back. Note that the AdjustInventory flag should be set false to match the nature of this operation.<br data-source-node="n55">
    <br data-source-node="n56"></li>

    <li data-source-node="n57"><b data-source-node="n58"><a href="../source/downloads/71cc50359167818b23ff1134231381e37edf2df541ede3fdfd0b19614be5a463.xsd" data-source-node="n59">InventoryTransactionResponse.xsd</a>:</b> Contains a result message, the list of failed and/or successful transactions, and possibly an error message.<br data-source-node="n60"></li>
</ul>
