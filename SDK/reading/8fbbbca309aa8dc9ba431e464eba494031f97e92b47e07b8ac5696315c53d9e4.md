    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Metadata web pages often need to be shared across other pages. In these instances, a modal dialog can be used to display a completely separate web page. These modals should have very little content to prevent scrolling on tablet devices, and they should also not require multiple "stacked" levels of modals. If they do, another means of showing the page should be used. Showing another metadata web page inside a modal dialog can be configured through metadata as follows.</p>
