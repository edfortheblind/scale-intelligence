How to: Add a Drilldown Level to a Chart on a Monitor Page
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Monitor Pages > How to: Add a Drilldown Level to a Chart on a Monitor Page

A column chart can be drilled down to N levels. Follow the below steps to enable drill down for a chart.

 Step 1: Create a Stored Procedure for the Chart

A stored procedure needs to be created for each drilldown level. The stored procedure name should be in the format <functional area>_Monitor<Description of what will be retrieved>.

For example if a chart is retrieving data for work type for active work then the stored procedure would be named WRK_MonitorWorkTypeChartData

Please refer to the  How to: Create Monitor Page Stored Procedure topic for more information.

 Step 2: Create Required Screen Control Attributes for the Chart

The following screen control attributes need to be created and tied to the corresponding chart. Please refer to the  How to: Create Screen Control Attributes topic for more information. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Description

data-drilldownLevel<N>criteria

This attribute defines the parameters to pass to the stored procedure for the
various drill downs the user has executed. These parameters will filter the data
in the stored procedure. The criteria consists of a comma delimited list of
criteria, ending with a semicolon.

For example if a chart has two drill down levels then the following attributes need to be created: data-drilldownLevel1criteria and data-drilldownLevel2criteria.

data-drilldownLevel<N>storedprocedure

This attribute defines the stored procedure that should be used to retrieve the
data for a drill down level in the chart. Each drill down level has one stored
procedure defined.

For example if a chart has two drill down levels then the following attributes need to be created: data-drilldownLevel1storedprocedure and data-drilldownLevel2storedprocedure.
