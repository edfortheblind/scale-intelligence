Process Dock Assignment Wave Step Web Service
View with Navigation Tools
The ProcessDockAssignmentWaveStep operation belongs to the Dock Management Web Service. It is invoked as part of the Dock Assignment Wave Step and is not intended to be called by a custom implementation. 
 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Post the WaveNumber using the locateWaveContainers link

The Shipping resource representation will include a locateWaveContainers URI Template field that contains a single {waveNumber} token. To invoke DockAssignmentWaveStep for a wave, substitute the desired wave number and perform the following HTTP POST:

Request:

  • URI: From Shipping representation's link (rel="locateWaveContainers") href
  • Method: POST
  • Content-Type: application/json or application/xml
  • Roles: SCALEUSER,Confidential

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity that contains an error or is empty:application/vnd.manh.ils.shipping.processDockAssignmentWaveStepResponse+json, xml
