Close Putaway Group Web Service
View with Navigation Tools

This web service invokes the Close Putaway Group function of the application by performing a POST to the PutawayGroup-Closed resource using {groupId} and {warehouse} tokens.

 Request
  • URI: http://ServerName/inbound/putawayGroups/PutawayGroups-Closed?groupId={groupId}&warehouse={warehouse}
  • Method: POST
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: none
  • Roles: SCALEUSER,Confidential
 Response

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity that represents the successfully closed putaway group: application/vnd.manh.ils.receiving.putawayGroup+json, xml
400

The following ErrorTypes can be expected: Unknown.
