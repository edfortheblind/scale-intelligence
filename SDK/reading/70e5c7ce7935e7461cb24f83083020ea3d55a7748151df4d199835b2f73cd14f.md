        <p data-source-node="n47">The base product comes with notification capability from certain fixed functionality like Personal alerts. However, there might be a need to support more real time notifications from other parts of the system. The framework is capable of processing and delivering notifications as long as some custom code (possibly <a href="37bf92fb5253f98c528830bc68482020fcdc2473b47852b314527d292c7c018b.html" data-source-node="n48">exit point</a> programs), database triggers or stored procedures are able to insert the Notification_Message record, properly linked to relevant <a href="5ab87f921fdc6ad917ba83ec5fae919733f3c1a9b041a97c769eba191c908f37.html" data-source-node="n49">Notification configurations</a>.</p>
