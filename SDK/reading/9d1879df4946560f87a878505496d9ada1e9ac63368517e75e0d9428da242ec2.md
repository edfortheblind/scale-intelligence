    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Insight Architect is a tool used to customize metadata. Currently Insight Architect is a simple editing of raw metadata. This means that it exactly follows the database flow and structure for metadata tables and allows for updating literal database values. For a review on the metadata architecture please reference the <a href="2947132cd4956ea18b05a31ba95ea4781245188fab631288551ad3e8094e543a.html" data-source-node="n48">Metadata Page Architecture</a> topic. Some benefits of using Insight Architect over straight SQL include:</p>

<ul data-source-node="n49">
    <li data-source-node="n50">Easier traversing of the metadata hierarchy</li>

    <li data-source-node="n51">Selection from lists where applicable</li>

    <li data-source-node="n52">Automatic clearing of cached metadata for immediate results</li>

    <li data-source-node="n53">Ability to export versioned scripts for screen metadata</li>
</ul>

<p data-source-node="n54">Follow these instructions to use Insight Architect to customize metadata.</p>

<div id="i-ba006ed1-7754-4927-a952-c003961a53ff-section-heading" class="i-section-heading" data-source-node="n55">
    <span class="i-section-heading-icon" data-source-node="n56"><span class="i-hidden" data-source-node="n57"> </span></span><span class="i-section-heading-text" data-source-node="n58">Step 1: Create a Customized Version of the Screen</span>
</div>

<div id="i-ba006ed1-7754-4927-a952-c003961a53ff-section-content" class="i-section-content" data-source-node="n59">
    <p data-source-node="n60">Make sure that there is a customized version of the desired screen by following the instructions in the Developer Hub topic.</p>
</div>

<div id="i-7b22135a-ff9f-441f-8b26-97b6c1192f8f-section-heading" class="i-section-heading" data-source-node="n61">
    <span class="i-section-heading-icon" data-source-node="n62"><span class="i-hidden" data-source-node="n63"> </span></span><span class="i-section-heading-text" data-source-node="n64">Step 2: Browse to the Appropriate Insight Architect Page</span>
</div>

<div id="i-7b22135a-ff9f-441f-8b26-97b6c1192f8f-section-content" class="i-section-content" data-source-node="n65">
    <p data-source-node="n66">Insight Architect is not available from the main menu on the metadata web pages. Therefore, to access it, you need to manually type the appropriate URL into your browser of choice. First, find the appropriate Form Id by reviewing the Desktop Layout configuration and finding the screen that you want to customize. With that Form Id, open a browser and type the following URL:</p>

    <p data-source-node="n67"> </p>

    <p data-source-node="n68"><strong data-source-node="n69">https://&lt;servername&gt;/scale/details/form/&lt;formid&gt;</strong></p>
</div>

<div id="i-8d5e3759-8d83-4934-a106-28491ded3de9-section-heading" class="i-section-heading" data-source-node="n70">
    <span class="i-section-heading-icon" data-source-node="n71"><span class="i-hidden" data-source-node="n72"> </span></span><span class="i-section-heading-text" data-source-node="n73">Step 3: Drill Down to the Customized Page</span>
</div>

<div id="i-8d5e3759-8d83-4934-a106-28491ded3de9-section-content" class="i-section-content" data-source-node="n74">
    <p data-source-node="n75">It is important to only customize the screen that is marked with system_created = N, otherwise the base installer will overwrite your customizations. Click on the hyperlink that has system_created = N (unchecked box).</p>

    <p data-source-node="n76"> </p>

    <p data-source-node="n77"><img border="0" alt="" src="../source/assets/9520dd7fd435c482756ae5ae2ef5281c9f7717af632875b38e600761271cb1b4.png" loading="eager" data-source-node="n78"></p>
</div>

<div id="i-c3ebcb78-aba9-4196-8d62-a362b03340fa-section-heading" class="i-section-heading" data-source-node="n79">
    <span class="i-section-heading-icon" data-source-node="n80"><span class="i-hidden" data-source-node="n81"> </span></span><span class="i-section-heading-text" data-source-node="n82">Step 4: Modify Metadata using Insight Architect</span>
</div>

<div id="i-c3ebcb78-aba9-4196-8d62-a362b03340fa-section-content" class="i-section-content" data-source-node="n83">
    <p data-source-node="n84">Traverse through the metadata hierarchy using Insight Architect by clicking the hyperlinks in the grids and then edit, delete, or create metadata records as required. For each metadata record, once editing or creating is complete on the page, click the Save button. This will automatically clear the metadata cache so that your changes can be immediately viewed from the actual page itself (or open the page by clicking the Preview button).</p>       
</div>

<div id="i-b83943c0-ec65-46f2-9b91-59f2334a81bc-section-heading" class="i-section-heading" data-source-node="n85">
    <span class="i-section-heading-icon" data-source-node="n86"><span class="i-hidden" data-source-node="n87"> </span></span><span class="i-section-heading-text" data-source-node="n88">Step 5: Export a Versioned Script</span>
</div>

<div id="i-b83943c0-ec65-46f2-9b91-59f2334a81bc-section-content" class="i-section-content" data-source-node="n89">
    At any point during metadata customization, you can save off a versioned script for the current screen metadata by clicking the Actions | Export button from the "Screen" Insight Architect page (URL mentioned above).
</div>
