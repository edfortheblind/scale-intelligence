    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">This topic will describe how to change the logo on the Insight Sign On screen.</p>

<div class="i-box i-box-note" data-source-node="n42">
    The file paths in this topic refer to the default installation directory of SCALE on the application server. The files may be found in a different path on servers where the path was customized during installation.
</div>

<div id="i-a0cbdd7e-e815-41b6-9b27-d4bfba68ac9a-section-heading" class="i-section-heading" data-source-node="n43">
    <span class="i-section-heading-icon" data-source-node="n44"><span class="i-hidden" data-source-node="n45"> </span></span><span class="i-section-heading-text" data-source-node="n46"><span class="SectionHeadingText" data-source-node="n47">Step 1: Deploy the Image</span></span>
</div>

<div id="i-a0cbdd7e-e815-41b6-9b27-d4bfba68ac9a-section-content" class="i-section-content" data-source-node="n48">
    <p data-source-node="n49">The image first needs to be deployed to the Metadata Screen directory  %SCALE_HOME%\web\content.</p>

    <p data-source-node="n50">It is recommended that custom images are placed in a new location  %SCALE_HOME%\web\content\manhcustom\images. This will ensure that the custom images are not lost when SCALE is upgraded.<br data-source-node="n51"></p>

    <p data-source-node="n52">To deploy the image, copy it to the  %SCALE_HOME%\web\content\manhcustom\images directory. If the directory does not exist it will have to be created.<br data-source-node="n53"></p>

    <p data-source-node="n54">For example, if we were deploying an image named example.png, after the above step you would find it at this path:  %SCALE_HOME%web\content\manhcustom\images\example.png.</p>

    <p data-source-node="n55">When the replacement image is a different size than the shipped Manhattan logo, css can be added to style the image correctly.  For example, to configure the width of the image, custom css would need to be added as follows.</p>

    <p data-source-node="n77">Replace the logo image file name <em data-source-node="n78">ManhattanSCALE_fnl_white_384.png</em> with the new image file name and save the changes to the file.</p>
