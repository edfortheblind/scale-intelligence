    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">To bind a chart control on a Monitor Page, a stored procedure needs to be called via a built in web service. This web service returns the JSON which has the required data to bind the chart control on a Monitor page. Please follow the below steps to bind a chart control on a Monitor page.  Please follow the below steps to bind a chart control on monitor page.</p>

<div id="i-b3dc839d-7779-446f-9ef2-ed8982d27c93-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Step 1: Create Stored Procedure for Chart</span>
</div>

<div id="i-b3dc839d-7779-446f-9ef2-ed8982d27c93-section-content" class="i-section-content" data-source-node="n52">
    <span style="FONT-SIZE: 10pt;FONT-FAMILY: &quot;Segoe UI&quot;,sans-serif;COLOR: rgb(30,30,30)" data-source-node="n53"><span style="FONT-SIZE: 10pt;FONT-FAMILY: &quot;Segoe UI&quot;,sans-serif;COLOR: rgb(30,30,30)" data-source-node="n54">A stored procedure must be created that will retrieve the chart data. The stored procedure should be named in the format <em data-source-node="n55">&lt;functional area&gt;_Monitor&lt;Description of what will be retrieved&gt;</em>. For example, if a Monitor page was going to be created for retrieving work related data based on work group, the stored procedure should be named <em data-source-node="n56">WRK_MonitorWorkGroupChartData.</em> Please refer to the <a data-source-node="n57"><u data-source-node="n58"><font color="#0066CC" data-source-node="n59">How to: Create Monitor Page Stored Procedure</font></u></a> topic for more detailed information. </span></span>       
</div>

<div id="i-b342ed48-97b4-4bad-947a-216626f5454c-section-heading" class="i-section-heading" data-source-node="n60">

</div>

<div id="i-b342ed48-97b4-4bad-947a-216626f5454c-section-content" class="i-section-content" data-source-node="n64">
    Create the below Screen Control Attributes to bind a chart control on monitor page. Please refer to the <a data-source-node="n65"><u data-source-node="n66"><font color="#0066CC" data-source-node="n67">How to: Create Screen Control Attributes</font></u></a> topic for more detailed information on screen control attributes. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n68"><u data-source-node="n69"><font color="navy" data-source-node="n70">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).

        <tbody data-source-node="n73">
            <tr data-source-node="n74">
                <td data-source-node="n75"><strong data-source-node="n76">Field</strong></td>

                <td data-source-node="n77"><strong data-source-node="n78">Description</strong></td>
            </tr>

            <tr data-source-node="n79">
                <td data-source-node="n80">
                    <p data-source-node="n81">data-monitorWebService</p>
                </td>

                <td data-source-node="n82">
                    <p data-source-node="n83">Defines the web service which returns the required information to a Monitor page for binding data to a chart control. This attribute value is "/general/scaleapi/GenericMonitorDataRetrievalApi/Post" and can be used for all charts.</p>
                </td>
            </tr>

            <tr data-source-node="n84">
                <td data-source-node="n85">
                    <p data-source-node="n86">data-chartType</p>
                </td>

                <td data-source-node="n87">Defines the type of a chart. Currently supported value is "Column".</td>
            </tr>

            <tr data-source-node="n88">
                <td data-source-node="n89">
                    <p data-source-node="n90">data-chartCategoryMaxCount</p>
                </td>

                <td data-source-node="n91">
                    <p data-source-node="n92">Defines the maximum value of the axis. This is an optional attribute and the default value is 10.</p>
                </td>
            </tr>

            <tr data-source-node="n93">
                <td data-source-node="n94">
                    <p data-source-node="n95">data-drilldownLevel0criteria</p>
                </td>

                <td data-source-node="n96">
                    <p data-source-node="n97">Defines filter criteria to retrieve data from the stored procedure. Each level can have one filter criteria with a list of comma delimited values with an ending semicolon.</p>
                </td>
            </tr>

            <tr data-source-node="n98">
                <td data-source-node="n99">
                    <p data-source-node="n100">data-drilldownLevel0storedprocedure</p>
                </td>

                <td data-source-node="n101">
                    <p data-source-node="n102">This attribute defines the stored procedure to call for the chart data. The stored procedure has two parameters: filterCriteria  and culture. Each drill down level in the chart has one stored procedure.</p>
                </td>
            </tr>
