Screen controls represent a single control or set of controls within a single screen group. Screen controls are represented by the SCREEN_CONTROL database table. There can be 1-N screen controls (ordered by SEQUENCE field) for a particular screen group. Screen controls are tied to screen groups by the SCREEN_GROUP_ID field (SCREEN_CONTROL.SCREEN_GROUP_ID = SCREEN_GROUP.OBJECT_ID). In addition when the screen group has screen group columns there can be 1-N screen controls (ordered by the SEQUENCE field) for a particular screen group column. Screen controls are tied to screen group columns by the SCREEN_GROUP_COLUMN_ID field (SCREEN_CONTROL.SCREEN_GROUP_COLUMN_ID = SCREEN_GROUP_COLUMN.OBJECT_ID). Please reference the "Screen Control Type" configuration for an enumeration of the available screen controls. Also, the table below gives more information on screen controls.

 AdvancedCriteria

The AdvancedCriteria control allows for the "advanced search" section within a metadata insight screen to be easily applied within the metadata. Other controls are embedded within the "value" portion of the control based on the field chosen in the "field" control (text editor, date editor, numeric editor, combo box, etc.). The control type and drop down list for the "value" control is retrieved via client event through a "FilterAttributes" web service (that reads records from the FILTER_ATTRIBUTES table). This control's data source represents the table or view that the advanced search should iterate over.

 ToggleSwitch

The toggle switch control is similar to a single checkbox – it basically has an on/off switch. The actual column the control is tied to in the database is filled by a screen control attribute record with attribute_name = "data-dbcolumn". Please see the How to: Set Default State for a Control topic for information on setting the default on/off state for the toggle switch. Toggle switches that are used as search criteria within the search pane in an insight screen must also have two other control attributes: "data-positiveCondition" and "data-negativeCondition". The values for these attributes should be set to the appropriate filter for the "positive" (on) and "negative" (off) states. For example, in a toggle switch that is for "Include Empty Locations", the following would be required:

Attribute Value
data-dbcolumn Location_Sts
data-positivecondition empty string (representing to extra search criteria)
data-negativecondition <> 'Empty' (to prevent records with "Empty" Location_Sts from being shown)
data-btn-true-resourceKey  Set Resource key for positive condition. By default if this attribute is not provided the resource of positive condition is "TOGGLESWITCH_ON".
data-btn-false-resourceKey  Set Resource key for negative condition. By default if this attribute is not provided the resource of negative condition is "TOGGLESWITCH_OFF".
data-bind Provide this attribute when binding toggle with model property. For knockout binding we use custom binding handler called scaleToggle. The default value of toggle switch is decided by the model property. It is recommended to always provide default state as positive (on) when using with data-bind.

 Image

The image control expects the data returned in the data bound json object to have the prefix of “image:”. This allows the framework to acknowledge that an image needs to be bound and not text. For example "image:/SCALE/CONTENT/MANH/IMAGES/Image.png".

 DateRange

The date range control allows for range entry of dates. The "from" side always uses ">=" as the operator and the "to" side always uses "<=" as the operator during query generation. Resource keys for these range controls should be stored as a single value in metadata for the control – behind the scenes the control will add "FROM" and "TO" to the front of the configured metadata value in order to retrieve the resource text for the label. For example, if the resource key in metadata is specified as "SCHEDULEDSHIPDATE", then the system will translate the "from" and "to" labels with the keys "FROMSCHEDULEDSHIPDATE" and "TOSCHEDULEDSHIPDATE" respectively.

 FullCalendar

FullCalendar is used to display events or appointments in calendar format. This control is derived from third party control - fullcalendar (https://fullcalendar.io/). It allows to configure and display events in different calendar views like Day, Week or Month. An example of this control is available in Appointment Calendar screen.

FullCalendar HTML
Copy Code 
<div name="ApptScheduleCalendar" class="fullCalendar" id="ApptScheduleCalendar">
</div>
$(function() {
    $('#ApptScheduleCalendar').fullCalendar({
        now: $.fullCalendar.moment('2018-12-12 12:44:27Z').format(),
        timezone: 'local',
        duration: '06:00:00',
        header: {
            left: 'today prev,next',
            center: 'title',
            right: 'timelineDay,timelineSevenDays'
        },
        defaultView: 'timelineDay',
        views: {
            timelineSevenDays: {
                type: 'timeline',
                duration: {
                    days: 7
                }
            }
        },
        resourceLabelText: 'Dock doors',
        resourceAreaWidth: '15%',
        aspectRatio: 1.35,
        height: $(window).height() * 0.85,
        buttonText: {
            today: 'Today',
            month: 'Month',
            week: 'Week',
            day: 'Day',
            list: 'List',
            timelineSevenDays: '7 days'
        },
        resources: function(callback, start, end, timezone) {
            var url = '/inbound/scaleapi/recappscheduleapi/receiving-DockLocations' + '?warehouse=' + encodeURIComponent(_webSession.CurrentWhs());
            var httpResponse = _httpRequest.performGet(url, function(resourceObjects) {
                if (resourceObjects) {
                    var resourceList = [];
                    $.each(resourceObjects, function(index, value) {
                        resourceList.push({
                            id: value,
                            title: value
                        });
                    });
                    callback(resourceList);
                }
            }, null, false, true);
        },
        events: function(start, end, timezone, callback) {
            console.log('start date time ' + start + 'end datetime ' + end);
            var url = '/inbound/scaleapi/recappscheduleapi' + '?startDateTime=' + $.fullCalendar.moment.utc(start).format('YYYY-MM-DD HH:mm:ss') + '&endDateTime=' + $.fullCalendar.moment.utc(end).format('YYYY-MM-DD HH:mm:ss') + '&warehouse=' + encodeURIComponent(_webSession.CurrentWhs());
            var httpResponse = _httpRequest.performGet(url, function(eventObjects) {
                if (eventObjects) {
                    var eventList = [];
                    $.each(eventObjects, function(index, value) {
                        value['resourceId'] = value["Dock"];
                        value['id'] = value["ObjectId"];
                        value['title'] = value["ReceiptId"];
                        value['start'] = $.fullCalendar.moment(value["ApptDateTime"] + 'Z').format();
                        value['end'] = $.fullCalendar.moment(value["EndDateTime"] + 'Z').format();
                        eventList.push(value);
                    });
                    callback(eventList);
                }
            }, null, false, true);
        },
        eventRender: function(event, element) {
            var eventDetailsPopupHtml = '<div class="popover-content">';
            var fields = ["Dock", "Carrier", "TrailerId", "ApptDateTime", "EndDateTime"];
            var fieldLabels = ["Dock door", "Carrier", "Trailer id", "Start", "End"];
            if (fields) {
                $.each(fields, function(index, value) {
                    eventDetailsPopupHtml += '<div class="row popover-content-header">' + fieldLabels[index] + '</div>';
                    eventDetailsPopupHtml += '<div class="row popover-content-value">' + (fields[index].toUpperCase().includes('DATETIME') || fields[index].toUpperCase().includes('DATE') ? $.fullCalendar.moment(event[fields[index]] + 'Z').format('YYYY/MM/DD hh:mm:ss a') : event[fields[index]]) + '</div>';
                });
                eventDetailsPopupHtml += '<div class="row"><button id="viewButton" class="btn btn-default calendarpopoverbutton"><span></span>View appointment</button></div></div>';
            }
            $(element).popover({
                title: function() {
                    return '<B>' + event.title + '</B>';
                },
                placement: 'auto',
                html: true,
                trigger: 'click',
                content: function() {
                    return eventDetailsPopupHtml;
                },
                container: 'body'
            }).popover('show');
        }
    });
    var calendar = $('#ApptScheduleCalendar');
    if (calendar) {
        $(window).resize(function() {
            var calHeight = $(window).height() * 0.85;
            $('#ApptScheduleCalendar').fullCalendar('option', 'height', calHeight);
        });
    }
})
