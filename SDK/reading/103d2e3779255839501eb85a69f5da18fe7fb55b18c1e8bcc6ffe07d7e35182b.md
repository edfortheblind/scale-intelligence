    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The VAS Confirmation web service allows a consumer to complete Value Added services for a list of Shipping containers.  This is achieved by executing the following steps:</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Step 1: Retrieve a Shipping Resource Representation</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <p data-source-node="n47">First perform an HTTP GET to retrieve a Shipping resource representation.</p>

    <p data-source-node="n48">How to: <a href="15f4741027cfd823e26da0bc96553096c9655a5a8d497e3a92a0830eea6f1929.html" data-source-node="n49">Shipping Web Service</a></p>
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n50">
    <span class="i-section-heading-icon" data-source-node="n51"><span class="i-hidden" data-source-node="n52"> </span></span><span class="i-section-heading-text" data-source-node="n53">Step 2: Retrieve the ShippingContainerVasActivities</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n54">
    <p align="left" data-source-node="n55">The Shipping resource representation will include the link to the Shipping Container Vas Activities resource. The link (rel="shippingContainerVasActivities") has a href<em data-source-node="n56"> </em>that is a URL to the ShippingContainerVasActivities Resource.  To fetch the Shipping Container Vas Activity representations perform an HTTP GET:</p>

    <p align="left" data-source-node="n57"><strong data-source-node="n58">Request:</strong></p>

    <ul data-source-node="n59">
        <li data-source-node="n60"><strong data-source-node="n61">URI: &lt;link href&gt;</strong>?&lt;queryString&gt;</li>
    </ul>

    <p data-source-node="n62">    Note that the &lt;queryString&gt; can consist of any fields found in the request entity (<a href="../source/downloads/a29fbab87caa0f54d92d541d23661060f0fa4aa5a5c880851485eb44c942d112.xsd" data-source-node="n63">XML</a>).  For example, if requesting for the VAS activities (Coupons and Manual) for all containers in the shipment "SHIP01", the query string would be 'ShipmentId=SHIP01&amp;VasActivities=Coupons&amp;VasActivities=Manual'</p>

                </div>
            </li>

            <li data-source-node="n72">

                </div>
            </li>

            <li data-source-node="n75">

        </ul>
    </div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n95">
    <span class="i-section-heading-icon" data-source-node="n96"><span class="i-hidden" data-source-node="n97"> </span></span><span class="i-section-heading-text" data-source-node="n98">Step 3: Post the ShippingContainerVasActivities using the completed link</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n99">
    <p align="left" data-source-node="n100">The Shipping Container Vas Activities collection resource representation will include a <strong data-source-node="n101">completed</strong> link. To do a Vas Confirmation, set the "completed" field on each shippingContainerVasActivity representation and perform an HTTP POST with the following:</p>

    <p data-source-node="n102"><strong data-source-node="n103">Request:</strong></p>

    <ul data-source-node="n104">
        <li data-source-node="n105"><strong data-source-node="n106">URI:</strong> From ShippingContainerVasActivities' link (rel="complete") href</li>

        <li data-source-node="n107"><strong data-source-node="n108">Method:</strong> POST</li>

        <li data-source-node="n109"><strong data-source-node="n110">Accept:</strong> application/json or application/xml</li>

        <li data-source-node="n111"><strong data-source-node="n112">Content-Type:</strong> application/json or application/xml</li>

        <li data-source-node="n113"><strong data-source-node="n114">Entity:</strong> The updated ShippingContainerVasActivities from Step 2</li>
    </ul>

    <p data-source-node="n115"> </p>
