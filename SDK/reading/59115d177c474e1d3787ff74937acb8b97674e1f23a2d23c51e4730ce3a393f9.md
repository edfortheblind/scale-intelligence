    <div id="i-body-content" class="i-body-content" data-source-node="n47">
        <p data-source-node="n48">The system provides an exit point <em data-source-node="n49">Receiving Preference Authorization Retrieval</em>, that should be used to override the list of receiving preferences that can be viewed in various screens. The sql utility function <em data-source-node="n50">ModifyCharacterSeparatedStringList</em> can be used to modify receiving preferences in stored procedure exit point programs.</p>

<p data-source-node="n51"> </p>

<p data-source-node="n52">The following example represents a sample implementation of the <em data-source-node="n53">Receiving Preference Authorization Retrieval</em> exit point program using a stored procedure. </p>
