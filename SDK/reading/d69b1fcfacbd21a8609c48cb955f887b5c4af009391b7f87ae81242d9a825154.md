    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">The input controls within a modal dialog control use JQuery validation and must be inside a form tag for the validation to function properly. Validation can be configured for an input control via the standard JQuery validation Html attributes.</p>

<div id="i-758ba84e-deeb-4622-9fe3-69044726aecb-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Step 1: Create ModalDialog</span>
</div>

<div id="i-758ba84e-deeb-4622-9fe3-69044726aecb-section-content" class="i-section-content" data-source-node="n52">
    Please reference the <a href="b26513e56333a33b3f8d49c27076e4d8331ce560a2f1f212ad998bc5a511e753.html" data-source-node="n53">How to: Create a Dynamic Modal Dialog</a> topic for details on creating a modal dialog control.
</div>

<div id="i-8276a611-caa4-4fd5-9148-96e14bf700f9-section-heading" class="i-section-heading" data-source-node="n54">
    <span class="i-section-heading-icon" data-source-node="n55"><span class="i-hidden" data-source-node="n56"> </span></span><span class="i-section-heading-text" data-source-node="n57">Step 2: Add validation attributes</span>
</div>

<div id="i-8276a611-caa4-4fd5-9148-96e14bf700f9-section-content" class="i-section-content" data-source-node="n58">
    <p data-source-node="n59">In order to add validation to an input control, create a SCREEN_CONTROL_ATTRIBUTES record with ATTRIBUTE_NAME of the appropriate JQuery Validation attribute (<a href="http://jqueryvalidation.org/documentation/" data-source-node="n60">http://jqueryvalidation.org/documentation/</a>) and ATTRIBUTE_VALUE of "true". Also create another SCREEN_CONTROL_ATTRIBUTES record with ATTRIBUTE_NAME of the appropriate JQuery Validation Message attribute and ATTRIBUTE_VALUE of the correct error resource key. For example, to make an input control be required, add an attribute for "data-rule-required = true" and "data-msg-required = &lt;error msg key&gt;". These message keys in metadata are rendered in HTML as the translated resource text (see below). Please reference the <a href="c6f2b575ac93c80d7fed0743e021c3a4410aa69f0a1277ed7d8a2a7e7a692c93.html" data-source-node="n61">How to: Create Screen Control Attributes</a> topic for more details. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n62"><u data-source-node="n63"><font color="navy" data-source-node="n64">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>
