    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The Cycle Count Quick Plan Web Service gives the ability to submit a list of cycle count quick plans for processing, as well as a resource that will calculate the number of cycle count requests a quick plan would create once submitted.</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Requests</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <p data-source-node="n47"><strong data-source-node="n48">CycleCountQuickPlans resource:</strong></p>

    <ul data-source-node="n49">
        <li data-source-node="n50"><strong data-source-node="n51">URI:</strong> http://<i data-source-node="n52">ServerName</i>/ILSIntegrationServices/CycleCountQuickPlans</li>

        <li data-source-node="n53"><strong data-source-node="n54">Method:</strong> POST</li>

        <li data-source-node="n55"><strong data-source-node="n56">Accept:</strong> application/json or application/xml</li>

        <li data-source-node="n57"><strong data-source-node="n58">Content-Type:</strong> application/json or application/xml</li>

        <li data-source-node="n59"><strong data-source-node="n60">Entity:</strong> <a href="../source/downloads/c449197884b2adebce26cd67169d6b8d3c41b651844393b74e0a99c58948d982.json" data-source-node="n61">JSON</a>, <a href="../source/downloads/48c0980f5aebe2792f5b62b4f11a6261c6fa105d9ce48daa6bd2c1ae2742c7af.xsd" data-source-node="n62">XML</a></li>

        <li data-source-node="n63"><strong data-source-node="n64">Roles:</strong> SCALEUSER,Confidential</li>
    </ul>

    <p data-source-node="n65"> </p>

    <p data-source-node="n66"><strong data-source-node="n67">CalculatedRequestCount resource:</strong></p>

    <ul data-source-node="n68">
        <li data-source-node="n69">
            <strong data-source-node="n70">URI:</strong> http://<i data-source-node="n71">ServerName</i>/ILSIntegrationServices/CycleCounting/CalculatedRequestCount?&lt;queryString&gt;

            <ul data-source-node="n72">
                <li data-source-node="n73">Note that the &lt;queryString&gt; can consist of any fields found in the above request entity to the CycleCountQuickPlans resource.  For example, if requesting the count for all items that start with 'NOR' in warehouse '001', the query string would be 'Description=<em data-source-node="n74">description</em>&amp;Item=NOR%25&amp;Warehouse=001', where '%25' is the URL-encoding for the '%' wildcard character.</li>
            </ul>
        </li>

        <li data-source-node="n75"><strong data-source-node="n76">Method:</strong> GET</li>

        <li data-source-node="n77"><strong data-source-node="n78">Accept:</strong> application/json or application/xml</li>
    </ul>
</div>
