Immediate Dock Transfer Web Service
View with Navigation Tools

The Immediate Dock Transfer web service allows for the immediate, non-work movement of a shipping container between shipping dock locations.  This is achieved by executing the following steps:

 Step 1: Retrieve a ShippingContainer Resource Representation

To initiate an Immediate Dock Transfer, one must first perform an HTTP GET to retrieve a ShippingContainer resource representation using the following request/response information:

Request:

  • URI: http://ServerName/ILSIntegrationServices/ShippingContainers-NoOpenWork?warehouse={warehouse}&containerId={containerId}
  • Method: GET
  • Accept: application/json or application/xml
  • Roles: SCALEUSER,Confidential

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity in the requested media type: JSON, XML
400 The following ErrorTypes can be expected: Container, Warehouse

 Step 2: Post the ShippingContainer using its ImmediateDockTransfer URI Template

The ShippingContainer resource representation will include the ImmediateDockTransfer URI Template field that contains a single {location} token.  To execute the transfer, substitute the desired destination dock location and perform the following HTTP POST:

Request:

  • URI: From ShippingContainer's ImmediateDockTransfer URI Template field
  • Method: POST
  • Accept: application/json or application/xml
  • Content-Type: application/json or application/xml
  • Entity: The ShippingContainer from Step 1

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by the updated ShippingContainer: JSON, XML
400

The following ErrorTypes can be expected: Container, FromLocation, ToLocation, Warehouse
