How to: Create Screen Groups
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > How to: Create Screen Groups

Screen groups represent a grouping of controls within a single screen part. Screen groups are represented by the SCREEN_GROUP database table. There can be 1-N screen groups (ordered by the SEQUENCE field) for a particular screen part. Screen groups are tied to screen parts by the SCREEN_PART_ID field (SCREEN_GROUP.SCREEN_PART_ID = SCREEN_PART.OBJECT_ID). Screen groups can also be nested within each other (i.e. an accordion control has sub-accordions or an accordion control can be placed inside a panel control). This nesting is controlled by the PARENT_GROUP_ID and NESTED_GROUP_UNIT fields. All records in a particular "tree" (other than the top level record) will have a PARENT_GROUP_ID. All records in a "tree" will have the top level OBJECT_ID as their NESTED_GROUP_UNIT (including the top level record).

 Step 1: Determine the Object Id for the screen part

Use the following SQL to determine the Object Id for the screen part if you know the Form Id. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Find the Object Id for screen part
Copy Code 
select * from SCREEN_PART where SCREEN_ID in (
    select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)
 Step 2: Create screen group record

Create a new record in the SCREEN_GROUP table tied to the corresponding SCREEN_PART record for the screen part. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Description/Notes
GROUP_NAME The name of the screen group.
RESOURCE_KEY The resource key of the label to show for the screen group, if any.
GROUP_TYPE
 The type of the group. Please see the "Screen Group Type" configuration for an enumeration of all screen group types.
SEQUENCE Screen groups are rendered in sequence order.
DEFAULT_ACTION The button or link that should be triggered when the Enter key is pressed and focus is in a control within this screen group. Please see the How to: Set Default Action for Enter Key topic for more details.
DIV_CSS_CLASS Used to configure the layout of the screen group. Please see the How to: Configure Layout of Metadata Pages topic for more details.
ROW_CSS_CLASS Used to configure the layout of the screen group. Please see the How to: Configure Layout of Metadata Pages topic for more details.
PARENT_GROUP_ID The parent group for this group (used in nested groups).
NESTED_GROUP_UNIT The top level group for this group (used in nested groups).
FIXED_TO_TOP Used to configure elements that should be fixed to the top of the page when the page is scrolled. This feature only applies to Detail screens (Create, Read, Update) at this time.
CONTENT_LOADING_TYPE Used to specify how content in the screen group should be loaded. Please see the "Content Loading Type" configuration for an enumeration of all content loading types. Also see the How to: Set Loading Content Type topic for more information.
       
Please note that the dbc_IScreenGroup stored procedure can be used to create screen groups.
