How to: Create a New Insight Page
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > How to: Create a New Insight Page

The tooling provided for creating a new custom Insight page is not complete. For now, follow the instructions below in order to create a new Insight page.

 Step 1: Copy an Existing Insight Page Script

Browse to the directory that SCALE is installed to and then go to the sub folder Database | ILS | Scripts | _Metadata | Insight. Pick a script for a screen that is the most similar to the page you want to create. Copy the script to another location, rename it, and open it.

 Step 2: Update Script with Page Level information

Update the script for all page level information as follows:

 

  • Form Id: Use a different Form Id for your new screen. At the top of the script you will see the Form Id being set similar to this: set @formId = 2767. Search and replace the actual Form Id value in the script with your new Form Id. The new Form Id value you use should be the next available Form Id >= 60,000. So in the example given above, the Form Id 2767 should be replaced by 60000 everywhere in the script.
  • Form record: Update the call to DBC_IFORM as follows:
    • @formKeyName = MNU_<customScreenName>Insight (i.e. MNU_CustomInsight)
    • @tableName = the name of the SQL table or SQL View that should be used for the Insight screen data
  • Security: Remove all calls to dbc_ISecurityCheckpoint except for security_checkpoint 1 (which is "run").
  • Screen record: Update the call to DBC_IMAINUISCREEN as follows:
    • @functionalArea = the identifier of the functional area you want the screen to show up under in the menu
    • @menuResourceKey = the Resource Key to be used for the page title
  • Licensing: Remove all calls to dbc_IMainUiWmLicenseXrefOriginal.
 Step 3: Run the Modified Script

Open SQL Server Management Studio and run the modified script ensuring there are no errors. Run an IISRESET and then try to browse to the new page. The URL will be in the format https://<serverName>/scale/insights/<newFormId>. The new Insight page should be shown, but it will look exactly like the Insight page of the script that was copied.

 Step 4: Modify the Search Pane

Now that the new page exists, we can modify the screen metadata for the Search Pane using either Insight Architect (How to: Use Insight Architect to Customize a Metadata Page ), modifying the script mentioned above, or straight SQL against the database. Reference the topic How to: Create the Search Pane for a general overview of the Search Pane metadata.

 

  • Basic Criteria: Modify, add, or delete the basic criteria controls as required. Make sure they are pointing at the proper field in the database. Reference the How to: Add Basic Criteria to Search Pane topic for instructions.
  • Advanced Criteria: Update the data_source on the Advanced Criteria control for the screen to be the SQL Table or SQL View that will be used for the table. Please note that for the fields in the Advanced Criteria control to show the proper controls (numeric editor vs. text editor vs combo box, etc.), records may need to be added to the FILTER_ATTRIBUTES table. Please reference the How to: Add Advanced Criteria to Search Pane and How to: Tie Advanced Criteria Fields to Operand Lists and Field Types topics for more information.
 Step 5: Modify the List Pane

Now modify the screen metadata for the List Pane using either Insight Architect (How to: Use Insight Architect to Customize a Metadata Page ), modifying the script mentioned above, or straight SQL against the database. Reference the topic How to: Create the List Pane for a general overview of the List Pane metadata.

 

  • Summary Tiles: Modify, add, or delete the Summary Tile controls as required. Reference the How to: Add a Summary Tile to an Insight List Pane topic for instructions.
  • Grid: Modify the main grid and also the grid columns. Make sure to properly point the grid at the correct SQL Table or SQL View via the data-dbtable screen control attribute. Please reference the How to: Add a Grid to an Insight List Pane topic for more information.
 Step 6: Modify the Detail Pane

Now modify the screen metadata for the Detail Pane using either Insight Architect (How to: Use Insight Architect to Customize a Metadata Page ), modifying the script mentioned above, or straight SQL against the database. Reference the topic How to: Create the Detail Pane for a general overview of the Detail Pane metadata.

 

  • Stored Procedure: Create a new stored procedure to fill the data for the Detail Pane. Reference the How to: Create a Detail Pane Stored Procedure topic for instructions.
  • Header section: Modify, add, or delete the controls in the header section. Please reference the How to: Bind Detail Pane Controls topic for more information.
  • Tiles: Modify, add, or delete the tiles on the Detail Pane. Please reference the How to: Create an Indicator Tile on an Insight Detail Pane topic for more information.
 Step 7: Modify the Actions

Now modify the screen metadata for the Actions on the page using either Insight Architect (How to: Use Insight Architect to Customize a Metadata Page ), modifying the script me. ntioned above, or straight SQL against the database. Reference the topic How to: Add List Pane Menu Options for a general overview of the Actions metadata.
