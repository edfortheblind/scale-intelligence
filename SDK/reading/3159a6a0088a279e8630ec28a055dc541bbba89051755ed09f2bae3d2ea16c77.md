        <p data-source-node="n47">Clicking on an Action Tile will open the Insight screen in a new tab. Follow the below steps to enable clicking or tapping on an Action Tile.</p>

<p data-source-node="n136">The Insight screen search pane values populate based on both the action tile criteria and the current chart drill down level criteria.</p>

<p data-source-node="n137">For example, if the action tile criteria is FROM_WHS ='MN' and WORK_INSTRUCTION_PRIORITY&lt;= 10, and the chart drill down level criteria is FROM_WHS ='MN' and WORK_GROUP='Picking', then when the user clicks or taps an action tile the system will open a new tab for Work Insight screen passing the search pane filters as: From Whs (FROM_WHS)='MN', Priority (WORK_INSTRUCTION_PRIORITY) &lt;= 10, and Work Group (WORK_GROUP) = 'Picking'. </p>

<p data-source-node="n138">For this the "data-actionTileGoToInsight" attribute value should be:</p>

<p data-source-node="n139">{{FORM_ID=2757}}?filters=SearchPaneWhs█{{{{FROM_WHS}}},SearchPaneAdvCrit_Field█{{{{WORK_GROUP}}}SearchPaneAdvCrit_Field█{{{{WORK_INSTRUCTION_PRIORITY}}}</p>
