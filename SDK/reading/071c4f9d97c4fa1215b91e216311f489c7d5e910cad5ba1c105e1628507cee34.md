<p data-source-node="n47">This topic will describe how to configure an item image and display it on a metadata screen.</p>

<div class="i-box i-box-note" data-source-node="n48">
    The file paths in this topic refer to the default installation directory of SCALE on the application server. The files may be found in a different path on servers where the path was customized during installation.
</div>

<div id="i-e23c92f6-92b1-45a5-8775-8fee74d084fc-section-heading" class="i-section-heading" data-source-node="n49">
    <span class="i-section-heading-icon" data-source-node="n50"><span class="i-hidden" data-source-node="n51"> </span></span><span class="i-section-heading-text" data-source-node="n52"><span class="SectionHeadingText" data-source-node="n53">Step 1: Deploy the Image</span></span>
</div>

<div id="i-e23c92f6-92b1-45a5-8775-8fee74d084fc-section-content" class="i-section-content" data-source-node="n54">
    <p data-source-node="n55">The image first needs to be deployed to the Metadata Screen virtual directory  %SCALE_HOME%\web\content.</p>

    <p data-source-node="n56">It is recommended that custom images are placed in a new location %SCALE_HOME%\web\content\manhcustom\images to ensure that custom images are not lost when SCALE is upgraded.</p>

    <p data-source-node="n57">To deploy the image, copy to the %SCALE_HOME%\web\content\manhcustom\images directory. If the directory does not exist it will have to be created.</p>

    <p class="LastChild" data-source-node="n58">For example, if we were deploying an image named example.png, after the above step you would find it at this path: %SCALE_HOME%\web\content\manhcustom\images\example.png. </p>

    <div class="i-box i-box-note" data-source-node="n59">
        See File Sharing Guide for further deployment options.
    </div>
</div>

<div id="i-a23d6bee-844c-4b1e-a29b-281b32aa5d23-section-heading" class="i-section-heading" data-source-node="n60">
    <span class="i-section-heading-icon" data-source-node="n61"><span class="i-hidden" data-source-node="n62"> </span></span><span class="i-section-heading-text" data-source-node="n63"><span class="SectionHeadingText" data-source-node="n64">Step 2: Configure the Web Thumbnail Image of the Item</span></span>
</div>

<div id="i-a23d6bee-844c-4b1e-a29b-281b32aa5d23-section-content" class="i-section-content" data-source-node="n65">
    <p data-source-node="n66">In SCALE go the Item Configuration and open the record for the item.</p>

    <p data-source-node="n67">On the Internet Information tab specify a Web Thumbnail Image</p>

    <p data-source-node="n68">The Web Thumbnail Image value on the item configuration would then need to be set to /SCALE/Content/manhcustom/images/&lt;image name&gt;. Using our above image the item configuration would have a web thumbnail image value of /SCALE/Content/manhcustom/images/example.png.</p>

    <div class="i-box i-box-note" data-source-node="n69">
        Absolute URLs can be configured for the image paths.
    </div>
</div>

<div id="i-01017c83-2f0f-48c1-ba83-6b7f209c931d-section-heading" class="i-section-heading" data-source-node="n70">
