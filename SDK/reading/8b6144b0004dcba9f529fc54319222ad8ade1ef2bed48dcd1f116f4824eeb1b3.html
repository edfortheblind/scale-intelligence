Locate Shipping Containers Web Service
View with Navigation Tools

The LocateShippingContainers operation belongs to the Dock Management Web Service. It takes a list of top-level shipping containers (a.k.a. tree units), determines where each container should be placed based on the appropriate Dock Management Flow, and then invokes the TransferShippingContainers operation.

 Step 1: Retrieve a Shipping Resource Representation

First perform an HTTP GET to retrieve a Shipping resource representation.

How to: Shipping Web Service

 Step 2: Post the LocateShippingContainersRequest using the locateShippingContainers link

The Shipping resource representation will include a locateShippingContainers link. To invoke locateShippingContainers for a list of shipping containers, create the relevant LocateShippingContainersRequest data structure and perform an HTTP POST with the following:

Request:

  • URI: From Shipping representation's link (rel="locateShippingContainers") href
  • Method: POST
  • Content-Type: application/json or application/xml
  • Roles: SCALEUSER,Confidential
  • Entity: application/vnd.manh.ils.shipping.locateShippingContainers+json, xml

 

Response:

Aside from standard responses, note the following specifics for this service:

Status Code Notes
200 OK will be accompanied by an entity that contains either an error or a list of ContainerReference and the locations to which each container was located: application/vnd.manh.ils.shipping.locateShippingContainersResponse+json, xml
