How to: Create the Detail Pane
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Insight Pages > Detail Pane > How to: Create the Detail Pane

The "Detail Pane" on an insight screen represents the right section of the screen where detailed information is displayed for the selected row in the list pane grid. As an example, you can find all of the metadata records for an existing detail pane using the following script.

Shipment insight detail pane example
Copy Code 
declare @formId numeric(9,0);
declare @paneName nvarchar(25);
set @formId = 2735;
set @paneName = 'DetailPane';
select * from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId);
select * from SCREEN_GROUP where SCREEN_PART_ID in (
    select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId));
select * from SCREEN_GROUP_COLUMN where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
        select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId)));
select * from SCREEN_CONTROL where SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
        select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId)));
select * from SCREEN_CONTROL_ATTRIBUTES where SCREEN_CONTROL_ID in (
    select OBJECT_ID from SCREEN_CONTROL where SCREEN_GROUP_ID in (
        select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
            select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId))));
select * from SCREEN_CONTROL_EVENT where SCREEN_CONTROL_ID in (
    select OBJECT_ID from SCREEN_CONTROL where SCREEN_GROUP_ID in (
        select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
            select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId))));
select * from SCREEN_CONTROL_EVENT_PARAMETERS where SCREEN_CONTROL_EVENT_ID in (
    select OBJECT_ID from SCREEN_CONTROL_EVENT where SCREEN_CONTROL_ID in (
        select OBJECT_ID from SCREEN_CONTROL where SCREEN_GROUP_ID in (
            select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID in (
                select OBJECT_ID from SCREEN_PART where PART_NAME = @paneName and SCREEN_ID in (select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = @formId)))));


Creating the detail pane on an insight screen can be processed as follows.

 Step 1: Create the screen part record for the detail pane

Add a SCREEN_PART record as follows. Insight Architect can also be used for this (How to: Use Insight Architect to Customize a Metadata Page).

Field Value
SCREEN_ID The Screen Id of the current insight screen
PART_NAME DetailPane
RESOURCE_KEY NULL
PART_TYPE 10 (Div Container)
DIV_CSS_CLASS col-md-4 col-lg-4 detailpanepart
DEFAULT_ACTION NULL
 Step 2: Create a stored procedure or web service to return the detail data

Create either a stored procedure or web service that will return the data to bind to the detail pane. Reference the How to: Create a Detail Pane Stored Procedure and How to: Create a Detail Pane Web Service topics for instructions.

Please note that the stored procedure approach is the most commonly used. A web service should only be created if complex calculations are required that are too difficult to accomplish within a stored procedure.
 Step 3: Add controls to the detail pane
Please reference the How to: Add Screen Controls topic for instructions. Also reference the How to: Bind Insight Detail Pane Controls topic for instructions on how to bind these controls with the values returned from the stored procedure or web service.
