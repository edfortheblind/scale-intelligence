    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The Nest Shipping Container On Multi Order Pallet Web Service allows a user to nest a shipping container onto a multi order pallet. The nest operation will associate the parent and all the children with the multi order pallet. To achieve the nest operation follow these steps:</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Step1: Retrieve multi order pallet</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <p data-source-node="n47">Perform a 'get' operation to retrieve the multi order pallet you want to nest on.</p>

    <div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n48">
        <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Request</span>
    </div>

    <div id="i-SectionId-section-content" class="i-section-content" data-source-node="n52">
        <ul data-source-node="n53">
            <li data-source-node="n54"><strong data-source-node="n55">URI:</strong> http://<i data-source-node="n56">ServerName</i>/ILSIntegrationServices/multiOrderPallets/{mopId}</li>

            <li data-source-node="n57"><strong data-source-node="n58">Method:</strong> GET</li>

            <li data-source-node="n59"><strong data-source-node="n60">Accept:</strong> application/json or application/xml</li>

            <li data-source-node="n61"><strong data-source-node="n62">Roles:</strong> SCALEUSER,Confidential</li>
        </ul>
    </div>

    <div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n63">
        <span class="i-section-heading-icon" data-source-node="n64"><span class="i-hidden" data-source-node="n65"> </span></span><span class="i-section-heading-text" data-source-node="n66">Response</span>

    <span class="i-section-heading-icon" data-source-node="n88"><span class="i-hidden" data-source-node="n89"> </span></span><span class="i-section-heading-text" data-source-node="n90">Step 2: Create multi order pallet if it doesn't exist</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n91">
    <p data-source-node="n92">If you didn't find a multi order pallet in Step 1. Perform a 'post' operation to add the desired multi order pallet to the system</p>

    <div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n93">
        <span class="i-section-heading-icon" data-source-node="n94"><span class="i-hidden" data-source-node="n95"> </span></span><span class="i-section-heading-text" data-source-node="n96">Request</span>
    </div>

    <div id="i-SectionId-section-content" class="i-section-content" data-source-node="n97">
        <ul data-source-node="n98">
            <li data-source-node="n99"><strong data-source-node="n100">URI:</strong> http://<i data-source-node="n101">ServerName</i>/ILSIntegrationServices/multiOrderPallets</li>

            <li data-source-node="n102"><strong data-source-node="n103">Method:</strong> POST</li>

            <li data-source-node="n104"><strong data-source-node="n105">Content-Type:</strong> application/json or application/xml</li>

            <li data-source-node="n106"><strong data-source-node="n107">Entity:</strong> <a href="../source/downloads/7f156becf42543da3670229e10d3174cef2934d8a0e9990213672b265bdb1577.json" data-source-node="n108">application/vnd.manh.ils.shipping.multiOrderPallet+json</a>, <a href="../source/downloads/00658f966abcce96b89d60913eabb619403079ba8cf8c304be333953407f49a1.xsd" data-source-node="n109">application/vnd.manh.ils.shipping.multiOrderPallet+xml</a></li>
        </ul>

        <div class="i-box i-box-note" data-source-node="n110">
            NOTE: If a multiOrderPalletId is not supplied in the request the system checks the packing preferences for the user. If Container Assignment Method is set to 'System' a new id is generated by the application. If Container Assignment is set to 'Manual' an error is returned.
        </div>
    </div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n155">
    <p data-source-node="n156">To nest a shipping container on a multi order pallet use the link on the shipping container and replace token {mopId} with the actual multi order pallet id.</p>

    <div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n157">
        <span class="i-section-heading-icon" data-source-node="n158"><span class="i-hidden" data-source-node="n159"> </span></span><span class="i-section-heading-text" data-source-node="n160">Request</span>

            <li data-source-node="n163"><strong data-source-node="n164">URI:</strong> Use the shipping container entity retrieved in Step 3 to get the link to nest onto a multi order pallet (rel="<span lang="EN" data-source-node="n165">nestShippingContainerOnMultiOrderPallet")</span></li>

            <li data-source-node="n166"><strong data-source-node="n167">Method:</strong> POST</li>

            <li data-source-node="n168"><strong data-source-node="n169">Content-Type:</strong> application/json or application/xml</li>

            <li data-source-node="n170"><strong data-source-node="n171">Entity:</strong> Use the shipping container entity retrieved in Step 3</li>
        </ul>

        <p data-source-node="n172"> </p>

        <div class="i-box i-box-tip" data-source-node="n173">
            Tip: You can send a request with only the warehouse and container id instead of sending a full blown shipping container entity.
