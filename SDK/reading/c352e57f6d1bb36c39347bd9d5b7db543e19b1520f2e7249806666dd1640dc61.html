Inventory Web Services
View with Navigation Tools

The following web services are all related to the Inventory functional area of the application:

Web Service Description
Cancel Inventory Transactions Cancels the already performed inventory transactions
Cycle Count Plan Allows access to a Cycle Count Plan.
Cycle Count Quick Plan Queues a list of Cycle Count Quick Plan for processing or calculates how many cycle count requests would be created for the quick plan.
Inventory Allows access to links (URL or URI template) to web services related to inventory.
Inventory Override Info Gets the Check Digit, Location Verification Method and inventory information associated with a Location.
Inventory Transactions Prepares inventory for work and create work. This is used for transaction inventory adjustment or transfer with work only.
Short Pick Replenishment Tries to avoid short pick by replenishing the location before short pick happens.
