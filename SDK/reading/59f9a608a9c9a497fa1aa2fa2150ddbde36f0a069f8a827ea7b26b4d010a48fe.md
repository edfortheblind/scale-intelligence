    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Templates are used to move complex and recurring html out of metadata and into a partial view.</p>

<div id="i-c6766ab2-b067-409e-ab11-a107d7058444-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Setting template name on a new control when metadata is created</span>
</div>

<div id="i-c6766ab2-b067-409e-ab11-a107d7058444-section-content" class="i-section-content" data-source-node="n52">
    <p data-source-node="n53">In order to set the template name on a control as it is being created from metadata, simply set the TEMPLATE_NAME on the control.</p>

    <p data-source-node="n54"> </p>
</div>

    <span class="i-section-heading-icon" data-source-node="n123"><span class="i-hidden" data-source-node="n124"> </span></span><span class="i-section-heading-text" data-source-node="n125">Template naming convention</span>

<div id="i-d50fd8ed-be34-4405-93bb-7b95b1eb089a-section-content" class="i-section-content" data-source-node="n126">
    <p data-source-node="n127">Templates should be named in the format template_name-{number of controls in template} = partial view name . For example: _MetaControlRow-2 is a template with 2 controls in it.The partial views should be saved in  ~Views\Shared\Template.</p>
