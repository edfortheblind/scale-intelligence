    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Control attributes are name/value pairs that are stored as html attributes for a web control. This provides for an easy way to store important data tied to a particular control in a dynamic fashion. The attributes are represented by the SCREEN_CONTROL_ATTRIBUTES database table. There can be 1-N control attributes for a particular screen control. Control attributes are tied to screen controls by the SCREEN_CONTROL_ID field (SCREEN_CONTROL_ATTRIBUTES.SCREEN_CONTROL_ID = SCREEN_CONTROL.OBJECT_ID).</p>
