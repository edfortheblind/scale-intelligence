    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">Web Api routing is composed of three steps:</p>

<ul data-source-node="n42">
    <li data-source-node="n43">Find the route and parse the route data</li>

    <li data-source-node="n44">Find the matching controller</li>

    <li data-source-node="n45">Find the matching action</li>
</ul>

<div id="i-3f7d67ed-6130-4386-8962-b4596f4d31b8-section-heading" class="i-section-heading" data-source-node="n46">
    <span class="i-section-heading-icon" data-source-node="n47"><span class="i-hidden" data-source-node="n48"> </span></span><span class="i-section-heading-text" data-source-node="n49">Find the route and parse the route data</span>
</div>

<div id="i-3f7d67ed-6130-4386-8962-b4596f4d31b8-section-content" class="i-section-content" data-source-node="n50">
    <ul data-source-node="n51">
        <li data-source-node="n52">In this step the route will be parsed in order to find the controller, action, and other data in the URL.</li>

        <li data-source-node="n53">Currently there are two routes defined in SCALE for Web Api </li>

        <li data-source-node="n54">
            <ul data-source-node="n55">
                <li data-source-node="n56">
                    <table data-source-node="n57">
                        <tbody data-source-node="n58">
                            <tr data-source-node="n59">
                                <td width="208" data-source-node="n60"><strong data-source-node="n61">Route</strong></td>

                                <td data-source-node="n62"><strong data-source-node="n63">Description</strong></td>
                            </tr>

                            <tr data-source-node="n64">
                                <td width="208" data-source-node="n65">Scaleapi/{Controller}/{Action}/{Id}</td>

                                <td data-source-node="n66">In this route you will need to specify the action also. For example, in order to call update status on the LotApi Web Api controller, the route should be: POST scaleapi/LotApi/UpdateStatus. This is the recommended route.</td>
                            </tr>

                            <tr data-source-node="n67">
                                <td width="208" data-source-node="n68">Scaleapi/ {Controller}/{Id}</td>

                                <td data-source-node="n69">In this route you will need to specify the controller only. For example, in order to call update status on the LotApi controller, the route should be POST scaleapi/LotApi.</td>
                            </tr>
                        </tbody>
                    </table>
                </li>
            </ul>
        </li>
    </ul>

    <div class="i-box i-box-note" data-source-node="n70">
        Note: Id is optional for both of these routes.
    </div>
</div>

<div id="i-2830d941-95a3-4983-8977-2bf3a5a8c208-section-heading" class="i-section-heading" data-source-node="n71">
    <span class="i-section-heading-icon" data-source-node="n72"><span class="i-hidden" data-source-node="n73"> </span></span><span class="i-section-heading-text" data-source-node="n74">Find the matching controller</span>
</div>

<div id="i-2830d941-95a3-4983-8977-2bf3a5a8c208-section-content" class="i-section-content" data-source-node="n75">
    <blockquote style="MARGIN-RIGHT: 0px" dir="ltr" data-source-node="n76">
        Controller matching is done purely based on the value of the “controller” key in the route data. If the key “controller” doesn’t exist in the route data, controller selection will fail.
    </blockquote>
</div>

<div id="i-bb97af85-e5a0-4fba-8692-2dcab18b5d85-section-heading" class="i-section-heading" data-source-node="n77">
    <span class="i-section-heading-icon" data-source-node="n78"><span class="i-hidden" data-source-node="n79"> </span></span><span class="i-section-heading-text" data-source-node="n80">Find the matching action</span>
</div>

<div id="i-bb97af85-e5a0-4fba-8692-2dcab18b5d85-section-content" class="i-section-content" data-source-node="n81">
    <ul data-source-node="n82">
        <li data-source-node="n83">If the route data contains the key "action" then the action will be searched based on the action name and the verb.</li>

        <li data-source-node="n84">If the route data doesn’t contain the key “action”, then the action will be searched based on the supported request method directly.</li>
    </ul>
</div>

<div class="i-box i-box-note" data-source-node="n85">
    Note: Every route is defined in the IntegrationServices/HTTP/App_Start/WebApiConfig.cs file.
</div>
