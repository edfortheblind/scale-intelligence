    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The TransferShippingContainers operation belongs to the Dock Management Web Service. It takes a list of top-level shipping containers (a.k.a. tree units) and either assigns new work, reassigns existing work, or preassigns future moves to the given destination location(s).<br data-source-node="n42">
<br data-source-node="n43"></p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n44">
    <span class="i-section-heading-icon" data-source-node="n45"><span class="i-hidden" data-source-node="n46"> </span></span><span class="i-section-heading-text" data-source-node="n47">Step 1: Retrieve a Shipping Resource Representation</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n48">
    <p data-source-node="n49">First perform an HTTP GET to retrieve a Shipping resource representation.</p>

    <p data-source-node="n50">How to: <a href="15f4741027cfd823e26da0bc96553096c9655a5a8d497e3a92a0830eea6f1929.html" data-source-node="n51">Shipping Web Service</a></p>
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n52">
    <span class="i-section-heading-icon" data-source-node="n53"><span class="i-hidden" data-source-node="n54"> </span></span><span class="i-section-heading-text" data-source-node="n55">Step 2: Post the TransferShippingContainersRequest using the transferShippingContainers link</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n56">
    <p align="left" data-source-node="n57">The Shipping resource representation will include a <strong data-source-node="n58">transferShippingContainers</strong> link. To invoke transferShippingContainers for a list of shipping Containers, create the relevant <a href="../source/downloads/728b07f343b3d4bbdc1d5cd482127b7e13b662c04bd060e5b84f93def06d9b98.json" data-source-node="n59">TransferShippingContainersRequest</a> data structure and perform an HTTP POST with the following:</p>

    <p data-source-node="n60"><strong data-source-node="n61">Request:</strong></p>

    <ul data-source-node="n62">
        <li data-source-node="n63"><strong data-source-node="n64">URI:</strong> From Shipping representation's link (rel="transferShippingContainers") href</li>

        <li data-source-node="n65"><strong data-source-node="n66">Method:</strong> POST</li>

        <li data-source-node="n67"><strong data-source-node="n68">Content-Type:</strong> application/json or application/xml</li>

        <li data-source-node="n69"><strong data-source-node="n70">Roles:</strong> SCALEUSER,Confidential</li>

        <li data-source-node="n71"><strong data-source-node="n72">Entity:</strong> <a href="../source/downloads/728b07f343b3d4bbdc1d5cd482127b7e13b662c04bd060e5b84f93def06d9b98.json" data-source-node="n73">application/vnd.manh.ils.shipping.transferShippingContainers+json</a>, <a href="../source/downloads/feb3ad4d84e0ea930ad56fbd26411442e2911f988684eb0e21e8b41b5286937d.xsd" data-source-node="n74">xml</a></li>
    </ul>

    <p data-source-node="n75"> </p>

    <p data-source-node="n76"><strong data-source-node="n77">Response:</strong></p>

    <p data-source-node="n78">Aside from <a href="330a68671fd01d31e69b8634088ee603d769cc8b8d2c45b49f4a3d068a6f9bdb.html" data-source-node="n79">standard responses</a>, note the following specifics for this service:</p>

    <table class="members" data-source-node="n80">
        <tbody data-source-node="n81">
            <tr data-source-node="n82">
                <th class="nameColumn" data-source-node="n83">Status Code</th>

                <th class="descriptionColumn" data-source-node="n84">Notes</th>
            </tr>

            <tr data-source-node="n85">
                <td data-source-node="n86">200</td>

                <td data-source-node="n87">OK will be accompanied by an entity that contains either an error or is empty, which signifies a successful transfer. Note that if an error is found, check the ErrorType to see if location collisions were encountered, in case special recovery logic is desired. If so, the list of containers that experienced location collisions is also provided:<a href="../source/downloads/f35e37d49ec270e2bc34a0d0d4622662cb51841f9852d30c966e5f0efc54578e.json" data-source-node="n88">application/vnd.manh.ils.shipping.transferShippingContainersResponse+json</a>, <a href="../source/downloads/e447d280ce653ae949d4576b4397a61b8ac2309a0f767e0edc6c418957ec5349.xsd" data-source-node="n89">xml</a></td>
            </tr>
