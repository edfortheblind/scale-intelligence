    <div id="i-body-content" class="i-body-content" data-source-node="n48">
        <p data-source-node="n49">When using Web services for outbound work execution, an order needs to be maintained in the custom code. This order is significant to have the behavior similar to RF or full screen work execution.</p>

<p data-source-node="n50">To start with, assign the work unit to the user using the <a href="326224053ea93a3ac5a8c43338cfe316abf690de6b1bb5536df730968a56d541.html" data-source-node="n51">Assign Work Web Service</a>. Then this work will not be accessible to any other user till it is unassigned. On Success, it will give the list of open work instructions and by default each instruction with have <a href="9953e91b11848d7ae696684395218b88955e27c21df9fa2a43895d68b284e307.html" data-source-node="n52">Links</a> for <a href="487a46610d3512ba0034407faf1e6707f78dfb8d4beb2076cb08be99c6b301da.html" data-source-node="n53">Confirm</a> and <a href="fbf36a6ae536bb6872f6cec0f37a6ce23f699954ed2ff03f8fd18c74aa887e69.html" data-source-node="n54">Pick</a> work execution.</p>

<p data-source-node="n55">Execute the work. From the response of the <a href="326224053ea93a3ac5a8c43338cfe316abf690de6b1bb5536df730968a56d541.html" data-source-node="n56">Assign Work Web Service</a> you could build the request object to execute the work</p>

<p data-source-node="n57">If the current user needs to be unassigned or work needs to be passed for some reason use <a href="110a9e0792de9a0429b8099e9b5e7fbb7df4dca688e94873df6fc1f614291574.html" data-source-node="n58">Unassign Web Service</a>. This web service could be invoked in case of any exceptions during the entire flow as well.</p>
