        <p data-source-node="n41">The Cycle Count Plan Web Service allows access to a Cycle Count Plan in the application.</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Request</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <ul data-source-node="n47">
        <li data-source-node="n48">
            <strong data-source-node="n49">URI:</strong> http://<i data-source-node="n50">ServerName</i>/ILSIntegrationServices/CycleCountPlans?requestId={requestId}

            <div style="MARGIN-LEFT: 2em" data-source-node="n51">
                <ul data-source-node="n52">
                    <li data-source-node="n53">Note that the requestId is currently only filled by the <a href="fc7e5b7fb17383ff5610c6d7ea4f66c32678157396aaab7cb3ae7415a069f243.html" data-source-node="n54">Cycle Count Quick Plan Web Service</a>, which will return the above URI when a quick plan is successfully submitted for processing.</li>
                </ul>
            </div>
        </li>

        <li data-source-node="n55"><strong data-source-node="n56">Method:</strong> GET</li>

        <li data-source-node="n57"><strong data-source-node="n58">Accept:</strong> application/json or application/xml</li>

        <li data-source-node="n59"><strong data-source-node="n60">Roles:</strong> SCALEUSER,Confidential</li>
    </ul>
</div>
