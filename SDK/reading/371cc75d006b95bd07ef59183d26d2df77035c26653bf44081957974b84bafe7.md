    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">System can set default values to detail screens through configured exit point. Default values can be set in create mode. System provides the exit point <em data-source-node="n48">Field Defaults – Modify</em>, this should be used to pass default values to detail screen. Sql function <em data-source-node="n49">ConvertKeyValueTableToXML</em> can be utilized to provide default values in required XML format to system. User defined Table Type <em data-source-node="n50">KeyValueTableType</em> is used to pass values to the <em data-source-node="n51">ConvertKeyValueTableToXML</em> function.</p>

<p data-source-node="n52">The following example represents a sample implementation of the <em data-source-node="n53">Field Defaults – Modify</em> exit point program using a stored procedure. </p>
