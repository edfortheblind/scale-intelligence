How to: Customize the Appointment Calendar Page Appointment Preview Fields
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Transaction Pages > How to: Customize the Appointment Calendar Page Appointment Preview Fields

The Appointment Calendar Events SQL – Modify exit point allows the user to customize the fields displayed on the appointment preview displayed on Appointment Calendar page. In the SCALE configuration, this exit point can be found under Exit Point Controls -> General-> Appointment Calendar Events SQL - Modify.

 

This exit point receives following two input parameters.

  • @SESSIONVALUE – Session(xml)
  • @SQL  - Base SQL query which is used to fetch and display appointments

 

This exit point has an output parameter i.e. @RETURNVALUE. It returns the customized SQL query which overrides the base SQL query to fetch and display appointments. The base SQL query looks as shown below


Base SQL query
Copy Code 
SELECT
    NULL as backgroundColor, NULL as textColor, AP.OBJECT_ID as ObjectId, AP.DOCK as Dock, AP.APPT_DATE_TIME as ApptDateTime, AP.END_DATE_TIME as EndDateTime, RH.INTERNAL_RECEIPT_NUM as InternalReceiptNum, RH.RECEIPT_ID as ReceiptId, RH.TRAILER_ID as TrailerId, RH.CARRIER as Carrier
FROM
    APPOINTMENT_SCHEDULE AP JOIN RECEIPT_HEADER RH ON AP.INTERNAL_RECEIPT_NUM = RH.INTERNAL_RECEIPT_NUM
WHERE
    RH.WAREHOUSE = @WAREHOUSE AND ((AP.APPT_DATE_TIME <= @apptendDateTime) AND (@apptstartDateTime <= AP.END_DATE_TIME))

 

 The steps below will walk through adding custom fields to appointment preview in the Appointment Calendar page.

 Configure the Appointment Calendar Events SQL – Modify exit point
 Step 1: Access the exit point
Go to Configurations | Exit point control and open the Stored procedure for the Appointment Calendar Events SQL - Modify Exit Point.               
 Step 2: Create the stored procedure
Generate the sample stored procedure.            
 Step 3: Add the additional fields to the SQL statement
Added the modified SQL query below to the stored procedure which adds the custom fields to appointment preview. The example below shows how to add two custom fields i.e. ReceiptType and SourceName to the base SQL statement.            

Custom SQL query
Copy Code 
SELECT
    NULL as backgroundColor, NULL as textColor, AP.OBJECT_ID as ObjectId, AP.DOCK as Dock, AP.APPT_DATE_TIME as ApptDateTime, AP.END_DATE_TIME as EndDateTime, RH.INTERNAL_RECEIPT_NUM as InternalReceiptNum, RH.RECEIPT_ID as ReceiptId, RH.TRAILER_ID as TrailerId, RH.CARRIER as Carrier, RH.RECEIPT_TYPE as ReceiptType, RH.SOURCE_NAME as SourceName
FROM
    APPOINTMENT_SCHEDULE AP JOIN RECEIPT_HEADER RH ON AP.INTERNAL_RECEIPT_NUM = RH.INTERNAL_RECEIPT_NUM
WHERE
    RH.WAREHOUSE = @WAREHOUSE AND ((AP.APPT_DATE_TIME <= @apptendDateTime) AND (@apptstartDateTime <= AP.END_DATE_TIME))
 Step 4: Save the stored procedure
Click OK/run script to save the stored procedure to the database.            
 Customize the Appointment Calendar page metadata
 Step 1: Find the SCREEN_CONTROL record for the calendar in the transaction screen

Use the following SQL statement to locate the calendar using the corresponding Form Id. Insight Architect can also be used for this How to: Use Insight Architect to Customize a Metadata Page. 


Find calendar control record
Copy Code 
select * from SCREEN_CONTROL where CONTROL_TYPE = '370' and SCREEN_GROUP_ID in (
    select OBJECT_ID from SCREEN_GROUP where SCREEN_PART_ID IN (
        select OBJECT_ID from SCREEN_PART where SCREEN_ID in (
            select OBJECT_ID from MAIN_UI_SCREEN where FORM_ID = <form id>)))
 Step 2: Modify the metadata to include the additional fields on the appointment preview

The next step is to update the metadata to include the additional fields on the appointment preview displayed when clicking on an appointment in appointment calendar page. These fields are added to the attribute value of the metadata. Execute the following SQL statement to add the SOURCENAME and RECEIPTTYPE fields. Insight Architect can also be used for this How to: Use Insight Architect to Customize a Metadata Page.


Modify eventDetailFields attribute
Copy Code 
update SCREEN_CONTROL_ATTRIBUTES
set ATTRIBUTE_VALUE = 'DOCKDOOR:Dock|CARRIER:Carrier|TRAILERID:TrailerId|START:ApptDateTime|END:EndDateTime|SOURCENAME:SourceName|RECEIPTTYPE:ReceiptType'
where SCREEN_CONTROL_ID = <control id of calendar> and ATTRIBUTE_NAME = 'eventDetailFields'
After all steps run the reset.bat found in the %SCALE_HOME% folder. Then use CTRL+F5 to refresh the page. The new fields should appear as shown below on the appointment preview in Appointment Calendar page.
