Screen Control Event Parameter Naming Conventions
View with Navigation Tools
User Interface Extensibility > Metadata Web Pages > Shared > Screen Control Event Parameter Naming Conventions

Event parameters have naming conventions that must be followed in order to dynamically call web services through actions. The following conventions refer to the PARAMETER_NAME column in the SCREEN_CONTROL_EVENT_PARAMETERS table.

Name Description Naming Convention
Service URL parameter Defines the URL for the web service call <Method>ServiceURL where <Method> is the Http method (GET, POST, DELETE, etc.).
Pull parameter value from detail pane model Any value from the detail pane model can be passed as an  argument to the web service call <ParameterType>_<InputParameterName> where <ParameterType> is the type of parameter (queryParameter for GET and DELETE and PostData for POST) and <InputParameterName> is the name of the parameter to pass. Please reference the How to: Retrieve Parameter Values from the Insight Detail Pane Model topic for more information.
Pull parameter value from grid column Any column from the selected grid row can be passed as an  argument to the web service call <ParameterType>_Grid_<ControlName>_<InputParameterName> where <ParameterType> is the type of parameter (queryParameter for GET and DELETE and PostData for POST), <ControlName> is the name of the grid control, and <InputParameterName> is the name of the parameter to pass. Please reference the How to: Retrieve Parameter Values from the Insight Grid topic for more information.
Pull parameter value from input prompt User input via a Modal Dialog prompt can be passed as an argument to the web service call <ParameterType>_Input_<ControlName>_<InputParameterName> where <ParameterType> is the type of parameter (queryParameter for GET and DELETE and PostData for POST), <ControlName> is the name of the input control, and <InputParameterName> is the name of the parameter to pass. Please reference the How to: Retrieve Parameter Values from an Input Control topic for more information.
Pull parameter value from javascript function The return value from a javascript function can be passed as an argument to the web service call <ParameterType>_Function_<InputParameterName> where <ParameterType> is the type of parameter (queryParameter for GET and DELETE and PostData for POST) and <InputParameterName> is the name of the parameter to pass. Please reference the How to: Retrieve Parameter Values from a JavaScript Function Call topic for more information.
Override success callback function The default success callback when the web service completes can be overridden <Method>_SuccessCallback where <Method> is the Http method (GET, POST, DELETE, etc.). Please reference the How to: Override the Default Success Callback topic for more information.
Enable/Disable actions Enable or disable an action based on the data in the selected grid record EnableAction_<ControlName> where <ControlName> is the name of the control tied to the action.
