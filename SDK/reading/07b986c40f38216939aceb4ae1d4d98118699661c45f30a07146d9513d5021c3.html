How to: Customize Style Sheet files for the RF Pages
View with Navigation Tools
Web > How to: Customize Style Sheet files for the RF Pages

The new web page design allows users to customize the presentation elements of the pages. This includes but may not be limited to the fonts, colors, page size, and alignment of elements on the pages. This topic will walk through how the system determines the style sheet that will be applied when a user logs into RF along with an example of how a user could customize the shipped style sheets to personalize their RF experience.

 

Not all pages in RF Support this at this time. See Web Page Architecture for the list of supported areas.

 

 Step 1: RF Style Sheet Deployment

The application ships 3 suggested RF Style Sheet files. These are deployed in the %SCALE_HOME%\RF folder.

 

The files that are shipped by default are:

  • RFStylesSmall.css: This file should be used for languages that require a smaller font size.
  • RFStylesMedium.css: This is the file RF will use by default.
  • RFStylesLarge.css: This file can be used if users wish to have a larger font experience.

 

 Step 2: Creating a Personalized RF Style Sheet
Users that wish to personalize their RF experience can do so by creating a copy of one of the shipped style sheets and modifying the elements within the file. It is recommended that user's create their own copy of the file to ensure that their customizations have not been lost during an upgrade.

 

 Step 3: Configuring the RF Style Sheet Technical Value
A system wide technical value called RF Style Sheet is shipped in the Technical Values configuration. Users can configure their custom style sheet to be used by all RF users by changing the shipped value. See the products help documentation for more information.

 

 Step 4: Configuring the RF Style Sheet Per User
By changing the RF Style Sheet value on the user profile configuration users can also configure the custom style sheet to only apply to a subset of RF users. See the products help documentation for more information.

 

 Step 5: Viewing the Results
After applying the configuration changes to use the custom style sheet user's can then log into RF to see the changes applied to the RF Screens listed earlier in this topic.
