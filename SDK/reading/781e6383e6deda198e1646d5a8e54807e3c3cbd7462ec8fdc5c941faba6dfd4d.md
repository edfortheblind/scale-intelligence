    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The Close Container Web Service invokes the Close Container function of the application when performing a POST to the ShippingContainers-Closed resource.</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Request</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <ul data-source-node="n47">
        <li data-source-node="n48"><strong data-source-node="n49">URI:</strong> http://<i data-source-node="n50">ServerName</i>/outbound/ShippingContainers/ShippingContainers-Closed</li>

        <li data-source-node="n51"><strong data-source-node="n52">Method:</strong> POST</li>

        <li data-source-node="n53"><strong data-source-node="n54">Content-Type:</strong> application/json or application/xml</li>

        <li data-source-node="n55"><strong data-source-node="n56">Entity:</strong> <a href="../source/downloads/31d73c98419de1394c32a2a969c0b16f99c9507609ab5f2acd69ac3fba0afa72.json" data-source-node="n57"></a><a href="../source/downloads/31d73c98419de1394c32a2a969c0b16f99c9507609ab5f2acd69ac3fba0afa72.json" data-source-node="n58">application/vnd.manh.ils.shipping.ShippingContainerClosedRequest+json</a>, <a href="../source/downloads/594b0a281d0b8d47fc26ab69c93ca2cbd5cce0e3830aeff8b291b8186be9ac28.xsd" data-source-node="n59">xml</a></li>

        <li data-source-node="n60"><strong data-source-node="n61">Roles:</strong> SCALEUSER,Confidential</li>
    </ul>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n66">
    <p data-source-node="n67">Aside from <a href="330a68671fd01d31e69b8634088ee603d769cc8b8d2c45b49f4a3d068a6f9bdb.html" data-source-node="n68">standard responses</a>, note the following specifics for this service:</p>

    <table class="members" data-source-node="n69">
        <tbody data-source-node="n70">
            <tr data-source-node="n71">
                <th class="nameColumn" data-source-node="n72">Status Code</th>

                <th class="descriptionColumn" data-source-node="n73">Notes</th>
            </tr>

            <tr data-source-node="n74">
                <td data-source-node="n75">200</td>

                <td data-source-node="n76">
                    <p data-source-node="n77">OK will be accompanied by an entity that represents the successfully closed shipping container: <a href="../source/downloads/95fb243e33440ff59695366e9ce3e3ff65efec1582b7d85197c8a3d87cb3cf4f.json" data-source-node="n78">application/vnd.manh.ils.shipping.shippingContainer+json</a>, <a href="../source/downloads/fc7040568dde23a0c4ddb8a77f40ec5918317e86fa6467db1c18e2b8686a59de.xsd" data-source-node="n79">xml</a></p>

                    <p data-source-node="n80">Note that certain soft warning/information messages may be returned in the response (message, messageCode fields), even when the shipping container is closed successfully.</p>
                </td>
            </tr>

            <tr data-source-node="n81">
                <td data-source-node="n82">400</td>

                <td data-source-node="n83">
                    <p data-source-node="n84">The following ErrorTypes can be expected: <strong data-source-node="n85">Container, Warehouse, Weight</strong></p>

                    <p data-source-node="n86">The following ErrorCodes can be suppressed upon resubmit:</p>

                    <ul data-source-node="n87">
                        <li data-source-node="n88"><strong data-source-node="n89">MSG_WEIGHTOLERANCE:</strong> Returned when a change in weight now exceeds the container type's tolerance.  Suppress using <strong data-source-node="n90">SuppressWeightToleranceValidation</strong>.</li>

                        <li data-source-node="n91"><strong data-source-node="n92">MSG_CHGTRACKINGNUM:</strong> Returned when a previously manifested FedEx container should be re-manifested, but the user's Packing Preferences are not configured to Auto Manifest At Close.  Suppress using <strong data-source-node="n93">SuppressRemanifestFedExContainerValidation</strong>, which will also force the re-manifest.</li>

                        <li data-source-node="n94"><strong data-source-node="n95">MSG_ZEROWEIGHTVER:</strong> Returned when a weight of zero is specified.  Suppress using <strong data-source-node="n96">SuppressZeroWeightValidation</strong>.</li>

                        <li data-source-node="n97"><strong data-source-node="n98">MSG_OVERRIDEVAS01:</strong> Returned when VAS activity is pending for a container and user's Packing Preference allows overriding the warning.  Suppress using <strong data-source-node="n99">SuppressVasConfirmationValidation</strong>.</li>
                    </ul>
                </td>
            </tr>
