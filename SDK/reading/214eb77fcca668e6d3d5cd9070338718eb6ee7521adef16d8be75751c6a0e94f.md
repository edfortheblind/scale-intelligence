    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Metadata based screens allow for controls such as drop downs, checked list boxes, etc. to be tied to a list of values. The list of available values is retrieved dynamically at runtime based on the metadata configured. Therefore these lists can be defined and controlled by clients at runtime.</p>

<p data-source-node="n48">The DATA_SOURCE_TYPE and DATA_SOURCE fields in the SCREEN_CONTROL table drive this dynamic list retrieval. The following are valid DATA_SOURCE_TYPE values for retrieving lists tied to controls:</p>

<p data-source-node="n49"> </p>

<p data-source-node="n50"></p>

<table data-source-node="n51">
    <tbody data-source-node="n52">
        <tr data-source-node="n53">
            <td class="NewStyle" width="231" data-source-node="n54"><strong data-source-node="n55">Data Source Type</strong></td>

            <td class="NewStyle" width="52" data-source-node="n56"><strong data-source-node="n57">Value</strong></td>

            <td class="NewStyle" data-source-node="n58"><strong data-source-node="n59">Description</strong></td>
        </tr>

        <tr data-source-node="n60">
            <td width="231" data-source-node="n61">ConfigType</td>

            <td width="52" data-source-node="n62">10</td>

            <td data-source-node="n63">Retrieves lists for normal configurations; works exactly like the "ConfigType|…" lists within generic configurations. The supported list of types is defined in a generic configuration with record type of "METADATACONFIGTYPE".</td>
        </tr>

        <tr data-source-node="n64">
            <td data-source-node="n65">Generic</td>

            <td data-source-node="n66">30</td>

            <td data-source-node="n67">Retrieves lists for generic configurations; works exactly like the generic lists within generic configurations. Any generic configuration record type is supported.</td>
        </tr>

        <tr data-source-node="n68">
            <td data-source-node="n69">TableFields</td>

            <td data-source-node="n70">40</td>

            <td data-source-node="n71">Retrieves a list of columns for a database table.</td>
        </tr>
    </tbody>
</table>

    <span class="i-section-heading-icon" data-source-node="n74"><span class="i-hidden" data-source-node="n75"> </span></span><span class="i-section-heading-text" data-source-node="n76">How to configure control lists based on ConfigType records</span>
</div>

<div id="i-40bd6e85-8e52-480d-8a84-326bec7197a9-section-content" class="i-section-content" data-source-node="n77">
    <p data-source-node="n78">This section defines how ConfigType records can be used to fill dynamic lists tied to controls in metadata screens. The valid ConfigType values can be found in the "Metadata Config Type" configuration.</p>

    <p data-source-node="n79">Specifying a DATA_SOURCE_TYPE of 10 (ConfigType) in the SCREEN_CONTROL table indicates to the system that it should use built-in retrieval logic based on the value in the DATA_SOURCE field to fill the list tied to the control. The following table contains a few samples – please reference the "Metadata Config Type" configuration for the full list of supported values.</p>

    <p data-source-node="n80"> </p>

    <table data-source-node="n81">
        <tbody data-source-node="n82">
            <tr data-source-node="n83">
                <td class="NewStyle" width="231" data-source-node="n84"><strong data-source-node="n85">Data Source</strong></td>

                <td class="NewStyle" data-source-node="n86"><strong data-source-node="n87">Example</strong></td>
            </tr>

            <tr data-source-node="n91">

            <tr data-source-node="n94">
                <td data-source-node="n95">ProNumber</td>

                <td data-source-node="n96">To retrieve the list of Pro Number records, specify data source type = 10 and data source = ProNumber.</td>
            </tr>
        </tbody>
