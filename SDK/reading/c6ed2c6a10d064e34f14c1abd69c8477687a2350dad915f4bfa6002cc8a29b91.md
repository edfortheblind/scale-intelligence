        <p data-source-node="n41">REST-based web services offer the ability to compress entities attached to both requests and responses.  In certain scenarios, the size of the entity as it travels across the network can be reduced by over 90%.</p>

<p data-source-node="n42">To send the application a compressed entity, apply one of the supported compression encodings to the entity data and place the name of that encoding in the <a href="f579bfac844b388ae25396c60597f70bfde47aba8e663ffe4ece557eb116c226.html#Content-Encoding" data-source-node="n43">Content-Encoding</a> header.  The following C# example illustrates how deflate encoding can be achieved using the <strong data-source-node="n44">System.IO.Compression.DeflateStream</strong> class:</p>

<p data-source-node="n45"> </p>

<span style="COLOR: #0000ff" data-source-node="n57">private</span> System.Net.HttpWebRequest GetDeflatePostRequest(
    <span style="COLOR: #0000ff" data-source-node="n58">string</span> uri,
    <span style="COLOR: #0000ff" data-source-node="n59">string</span> entityXml)
{
    HttpWebRequest request = WebRequest.Create(uri) <span style="COLOR: #0000ff" data-source-node="n60">as</span> HttpWebRequest;
    request.Method = <span style="COLOR: #800000" data-source-node="n61">"POST"</span>;
    request.ContentType = <span style="COLOR: #800000" data-source-node="n62">"application/xml"</span>;
    request.Headers[HttpRequestHeader.ContentEncoding] = <span style="COLOR: #800000" data-source-node="n63">"deflate"</span>;

    StreamWriter requestStreamWriter = <span style="COLOR: #0000ff" data-source-node="n64">null</span>;
    <span style="COLOR: #0000ff" data-source-node="n65">try</span>
    {
        Stream stream = <span style="COLOR: #0000ff" data-source-node="n66">new</span> System.IO.Compression.DeflateStream(
            request.GetRequestStream(), CompressionMode.Compress);
        requestStreamWriter = <span style="COLOR: #0000ff" data-source-node="n67">new</span> StreamWriter(stream);
        requestStreamWriter.Write(entityXml);
        requestStreamWriter.Flush();
    }
    <span style="COLOR: #0000ff" data-source-node="n68">finally</span>
    {
        <span style="COLOR: #0000ff" data-source-node="n69">if</span> (requestStreamWriter != <span style="COLOR: #0000ff" data-source-node="n70">null</span>)
            requestStreamWriter.Close();
    }

    <span style="COLOR: #0000ff" data-source-node="n71">return</span> request;
}

<p data-source-node="n72"> </p>

<p data-source-node="n73">To request that the application respond with a compressed entity, set the <a href="f579bfac844b388ae25396c60597f70bfde47aba8e663ffe4ece557eb116c226.html#Accept-Encoding" data-source-node="n74">Accept-Encoding</a> header on the request to the desired compression format, and then be prepared to decompress the response entity once it returns.  It is a good idea to check the <a href="f579bfac844b388ae25396c60597f70bfde47aba8e663ffe4ece557eb116c226.html#Content-Encoding" data-source-node="n75">Content-Encoding</a> on the response to make sure decompression is required, as there may be situations where the application could not compress the response (e.g. error situations).  The following C# example illustrates how a .NET consumer can request that the response entity is compressed using the gzip encoding.  Note that the <strong data-source-node="n76">HttpWebRequest</strong> class will handle much of the work for you when using the <strong data-source-node="n77">AutomaticDecompression</strong> property.</p>
