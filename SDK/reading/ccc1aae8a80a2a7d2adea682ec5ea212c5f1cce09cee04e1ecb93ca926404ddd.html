There is a single Insight controller and single view that interpret metadata and render controls dynamically at runtime. Please see the Metadata Page Architecture topic for more details. The following routes are currently defined for the Insight screens and can be used interchangeably.

Name Template Example Description
Insight Insights/{id} localhost/scale/insights/10000 Calls index method for “Insight” controller passing the specified Form Id.
Default {controller}/{action}/{id} localhost/scale/insight/index/10000 Calls index method for “Insight” controller passing the specified Form Id.
