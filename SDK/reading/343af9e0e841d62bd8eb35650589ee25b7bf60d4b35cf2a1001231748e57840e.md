    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Adding a conditional statement in the COLUMN_TEMPLATE column of the SCREEN_CONTROL_GRID_COLUMNS table will provide a conditional color displayed on the grid when the conditions are met.</p>

<p data-source-node="n48">To setup a color on a grid, we first need to add a conditional statement into the COLUMN_TEMPLATE column. This conditional statement will be defined using the handlebar format and  will be stored in SCREEN_CONTROL_GRID_COLUMNS table. The condition will be checked when the datagrid is rendered. When the condition is satisfied, the color defined in the conditional statement will be displayed for each row meeting the condition.</p>

<p data-source-node="n49"><br data-source-node="n50">
Below is the screenshot showing the contents of SCREEN_CONTROL_GRID_COLUMNS table in which a conditional statement is added. The conditional statement in this screenshot is defined as: If the warehouse column of the grid is 'MN', then the background color of that grid row will be blue while the foreground color will be white.</p>

<p data-source-node="n51"> </p>

<p data-source-node="n52"><img border="0" alt="" src="../source/assets/ca74ad3a3fa1a1db3b83abc987f7710fb6d852dcaf194ea65f989306cae645b2.png" loading="eager" data-source-node="n53"></p>

<p data-source-node="n54"> </p>

<p data-source-node="n55">The colors can be defined in hexadecimal format as well.  The above conditional statement can also be written as : If the warehouse column of the grid is 'MN', then the background color of that grid row will be <a style="WHITE-SPACE: normal;COLOR: rgb(64,64,64);BACKGROUND-COLOR: rgb(241,241,241)" href="http://www.w3schools.com/tags/ref_color_tryit.asp?hex=0000FF" data-source-node="n56">#0000FF</a> while the foreground color will be <a style="WHITE-SPACE: normal;COLOR: rgb(64,64,64);BACKGROUND-COLOR: rgb(255,255,255)" href="http://www.w3schools.com/tags/ref_color_tryit.asp?hex=FFFFFF" data-source-node="n57">#FFFFFF</a>. </p>

<div class="i-box i-box-note" data-source-node="n58">
    <strong data-source-node="n59">NOTE:</strong> The Color column must be visible on the grid. Use the column chooser to verify the column is visible to ensure the colors are properly applied to the rows.
</div>
