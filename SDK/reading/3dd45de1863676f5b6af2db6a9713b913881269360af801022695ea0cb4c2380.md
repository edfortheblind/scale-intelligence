    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">At times a POST, DELETE, or GET service call may need to be made with input from the user. This can be accomplished by adding a modal dialog control with input controls, showing the modal dialog when an action is triggered, and then calling a web service with the results of the user input. This scenario can be configured through metadata as follows.</p>

<div id="i-dc58dde2-3558-48f9-b093-128cf8156ce9-section-heading" class="i-section-heading" data-source-node="n48">
    <span class="i-section-heading-icon" data-source-node="n49"><span class="i-hidden" data-source-node="n50"> </span></span><span class="i-section-heading-text" data-source-node="n51">Step 1: Create a new web service</span>
</div>

<div id="i-dc58dde2-3558-48f9-b093-128cf8156ce9-section-content" class="i-section-content" data-source-node="n52">
    If a new web service call is required, create it. Reference the various web service sections of the SDK for more information.
</div>

<div id="i-f9fc29e1-c650-4ad1-b98b-3208e80c4bed-section-content" class="i-section-content" data-source-node="n124">
    In the footer section of the modal dialog control, one of the buttons should be configured as the "positive" action. This action will be triggered when the user inputs the proper data and chooses the affirmative action such as "OK" or "Save". This action is tied to an event through the same SCREEN_CONTROL_EVENT and SCREEN_CONTROL_EVENT_PARAMETERS records as other actions. More information on tying an action to an event that performs a web service call can be found in the <a href="349b79b031b88e988c45527ef77a447ebcc9b4e1f12c300ad7bfb286fe2cd905.html" data-source-node="n125">How to: Perform a GET Service Call from Metadata Action</a>, <a href="86e589806734e407eaba41ca9571b0b3bcb21d7020eac089f5d58f20c8237ad6.html" data-source-node="n126">How to: Perform a POST Service Call from Metadata Action</a>, <a href="2d9f9ac140e772d1ded706bc360fb7c39ae5cd978a4d476a7510cf8fe1deb5a3.html" data-source-node="n127">How to: Perform a DELETE Service Call from Metadata Action</a>, and <a href="7c130070b4881563ebd3b9574d4e87928786de1563bbdb5f0a1fcab5a64da1b2.html" data-source-node="n128">How to: Retrieve Parameter Values from an Input Control</a> topics. There are also special functions to perform service calls from a modal dialog window. The SCREEN_CONTROL_EVENT created should be as follows. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n129"><u data-source-node="n130"><font color="navy" data-source-node="n131">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).
