    <div id="i-body-content" class="i-body-content" data-source-node="n40">
        <p data-source-node="n41">The QC Confirmation web service allows a consumer to perform QC counts for the item contents of a Shipping container.  This is achieved by executing the following steps:</p>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n42">
    <span class="i-section-heading-icon" data-source-node="n43"><span class="i-hidden" data-source-node="n44"> </span></span><span class="i-section-heading-text" data-source-node="n45">Step 1: Retrieve a Shipping Resource Representation</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n46">
    <p data-source-node="n47">First perform an HTTP GET to retrieve a Shipping resource representation.</p>

    <p data-source-node="n48">How to: <a href="15f4741027cfd823e26da0bc96553096c9655a5a8d497e3a92a0830eea6f1929.html" data-source-node="n49">Shipping Web Service</a></p>
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n50">
    <span class="i-section-heading-icon" data-source-node="n51"><span class="i-hidden" data-source-node="n52"> </span></span><span class="i-section-heading-text" data-source-node="n53">Step 2: Retrieve the ShippingContainer using its link</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n54">
    <p align="left" data-source-node="n55">The Shipping resource representation will include the link to the Shipping Containers Resource. The link (rel="shippingContainer") has a href<em data-source-node="n56"> </em>that is a URI template with the <strong data-source-node="n57">{warehouse}</strong> and <strong data-source-node="n58">{containerId}</strong> tokens.  To fetch the Shipping Container representation, substitute the tokens and perform an HTTP GET:</p>

    <p align="left" data-source-node="n59">How to: <a href="2e3af3dc7ca1dabe3792d04c19fbf77fee984e8e250ba64b6b314f3a3dca2a21.html" data-source-node="n60">Shipping Container Web service</a></p>
</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n61">
    <span class="i-section-heading-icon" data-source-node="n62"><span class="i-hidden" data-source-node="n63"> </span></span><span class="i-section-heading-text" data-source-node="n64">Step 3: Retrieve the ShippingContainerQcCounts using its qcCounts link</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n65">
    <p align="left" data-source-node="n66">The Shipping Container resource representation will include the link to its QC Counts collection resource. The link has a href<em data-source-node="n67"> </em>that is a URI template with the <strong data-source-node="n68">{intContNum}</strong> token.  To fetch the QC Counts, substitute the token with the Shipping Container's InternalContainerNum and perform an HTTP GET:</p>

    <p data-source-node="n69"><strong data-source-node="n70">Request:</strong></p>

    <ul data-source-node="n71">
        <li data-source-node="n72"><strong data-source-node="n73">URI:</strong> From ShippingContainer's link (rel="qcCounts") href</li>

        <li data-source-node="n74"><strong data-source-node="n75">Method:</strong> GET</li>

        <li data-source-node="n76"><strong data-source-node="n77">Accept:</strong> application/json or application/xml</li>

        <li data-source-node="n78"><strong data-source-node="n79">Roles:</strong> SCALEUSER,Confidential</li>
    </ul>

    <p data-source-node="n80"> </p>

    <p data-source-node="n81"><strong data-source-node="n82">Response:</strong></p>

    <p data-source-node="n83">Aside from <a href="330a68671fd01d31e69b8634088ee603d769cc8b8d2c45b49f4a3d068a6f9bdb.html" data-source-node="n84">standard responses</a>, note the following specifics for this service:</p>

    <p data-source-node="n85"></p>

                <td data-source-node="n92">200</td>

</div>

<div id="i-SectionId-section-heading" class="i-section-heading" data-source-node="n97">
    <span class="i-section-heading-icon" data-source-node="n98"><span class="i-hidden" data-source-node="n99"> </span></span><span class="i-section-heading-text" data-source-node="n100">Step 4: Post the ShippingContainerQcCounts using its completed link</span>
</div>

<div id="i-SectionId-section-content" class="i-section-content" data-source-node="n101">
    <p align="left" data-source-node="n102">The Shipping Container QC Counts collection resource representation will include a <strong data-source-node="n103">completed</strong> link. To do a QC Confirmation for the shipping container, fill the relevant QC data into each ShippingContainerQCCount representation and perform an HTTP POST with the following:</p>

    <p data-source-node="n104"><strong data-source-node="n105">Request:</strong></p>

    <ul data-source-node="n106">
        <li data-source-node="n107"><strong data-source-node="n108">URI:</strong> From ShippingContainerQcCounts' link (rel="completed") href</li>

        <li data-source-node="n109"><strong data-source-node="n110">Method:</strong> POST</li>

        <li data-source-node="n111"><strong data-source-node="n112">Accept:</strong> application/json or application/xml</li>

        <li data-source-node="n113"><strong data-source-node="n114">Content-Type:</strong> application/json or application/xml</li>

        <li data-source-node="n115"><strong data-source-node="n116">Entity:</strong> The updated ShippingContainerQcCounts from Step 3</li>
    </ul>

    <p data-source-node="n117"> </p>

    <p data-source-node="n118"><strong data-source-node="n119">Response:</strong></p>

    <p data-source-node="n120">Aside from <a href="330a68671fd01d31e69b8634088ee603d769cc8b8d2c45b49f4a3d068a6f9bdb.html" data-source-node="n121">standard responses</a>, note the following specifics for this service:</p>
