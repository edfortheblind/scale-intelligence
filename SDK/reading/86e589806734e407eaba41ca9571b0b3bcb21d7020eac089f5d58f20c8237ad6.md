    <div id="i-body-content" class="i-body-content" data-source-node="n46">
        <p data-source-node="n47">Follow the steps below to make an action call a simple POST service.</p>

<p data-source-node="n48"></p>

<div id="i-dd5574d8-4bb2-45f5-80d2-e31371bee128-section-heading" class="i-section-heading" data-source-node="n49">
    <span class="i-section-heading-icon" data-source-node="n50"><span class="i-hidden" data-source-node="n51"> </span></span><span class="i-section-heading-text" data-source-node="n52">Step 1: Create a new web service</span>
</div>

<div id="i-dd5574d8-4bb2-45f5-80d2-e31371bee128-section-content" class="i-section-content" data-source-node="n53">
    If a new web service call is required, create it. Reference the various web service sections of the SDK for more information.
</div>

<p data-source-node="n54"></p>

<div id="i-3fd6de3a-c22b-46b7-b2cc-de13b4ff1d70-section-heading" class="i-section-heading" data-source-node="n55">
    <span class="i-section-heading-icon" data-source-node="n56"><span class="i-hidden" data-source-node="n57"> </span></span><span class="i-section-heading-text" data-source-node="n58">Step 2: Create a screen control or find an existing screen control</span>
</div>

<div id="i-3fd6de3a-c22b-46b7-b2cc-de13b4ff1d70-section-content" class="i-section-content" data-source-node="n59">
    Please reference the <a href="bb522128265dc8e032acf43909a28cdb0383a4c646d9bddef63fdc9e27ce292e.html" data-source-node="n60">How to: Create Screen Controls</a> for instructions.
</div>

<div id="i-8d878ab9-aff9-4ac5-be1d-360f35786e93-section-heading" class="i-section-heading" data-source-node="n61">
    <span class="i-section-heading-icon" data-source-node="n62"><span class="i-hidden" data-source-node="n63"> </span></span><span class="i-section-heading-text" data-source-node="n64">Step 3: Create the screen control event and parameters for the action to perform a POST request</span>
</div>

<div id="i-8d878ab9-aff9-4ac5-be1d-360f35786e93-section-content" class="i-section-content" data-source-node="n65">
           

    <p data-source-node="n66">Create a new SCREEN_CONTROL_EVENT record as follows. This defines what gets called when the event is fired. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n67"><u data-source-node="n68"><font color="navy" data-source-node="n69">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>

    <table data-source-node="n70">
        <tbody data-source-node="n71">
            <tr data-source-node="n72">
                <td data-source-node="n73"><strong data-source-node="n74">Field</strong></td>

                <td data-source-node="n75"><strong data-source-node="n76">Value</strong></td>
            </tr>

            <tr data-source-node="n77">
                <td data-source-node="n78">SCREEN_CONTROL_ID</td>

                <td data-source-node="n79">The Screen Control Id of the the control that fires the action</td>
            </tr>

            <tr data-source-node="n80">
                <td data-source-node="n81"><font style="COLOR: rgb(0,0,0);BACKGROUND-COLOR: rgb(255,255,255)" color="white" data-source-node="n82">EVENT_ID</font></td>

                <td data-source-node="n83"><em data-source-node="n84">click</em> or another event to be fired depending on the type of the control</td>
            </tr>

            <tr data-source-node="n85">
                <td data-source-node="n86">EVENT_NAME</td>

                <td data-source-node="n87"><em data-source-node="n88"><font style="BACKGROUND-COLOR: rgb(247,247,255)" data-source-node="n89">_webUi.insightListPaneActions.menuActionPerformPost</font></em></td>
            </tr>
        </tbody>
    </table>

    <p data-source-node="n90"><br data-source-node="n91"></p>

    <p data-source-node="n92">Now create a SCREEN_CONTROL_EVENT_PARAMETERS record to define the URL that will be called. Insight Architect can also be used for this (<a href="9d1879df4946560f87a878505496d9ada1e9ac63368517e75e0d9428da242ec2.html" data-source-node="n93"><u data-source-node="n94"><font color="navy" data-source-node="n95">How to: Use Insight Architect to Customize a Metadata Page</font></u></a>).</p>

        <tbody data-source-node="n97">

            </tr>

            <tr data-source-node="n103">
                <td data-source-node="n104">PARAMETER_NAME</td>

                <td data-source-node="n105"><em data-source-node="n106">POSTServiceURL</em></td>
            </tr>

            <tr data-source-node="n107">
                <td data-source-node="n108"><font style="COLOR: rgb(0,0,0);BACKGROUND-COLOR: rgb(255,255,255)" color="white" data-source-node="n109">PARAMETER_VALUE</font></td>

                <td data-source-node="n110">The URL for web service (i.e. <em data-source-node="n111">/general/scaleapi/ScreenPartSearchApi</em>)</td>
            </tr>

            <tr data-source-node="n112">
                <td data-source-node="n113">SCREEN_CONTROL_ID_EVENT_ID</td>
