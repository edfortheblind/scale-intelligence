REST-Based Web Service Configuration
View with Navigation Tools

Web service configuration settings, such as URIs, client timeouts, Cache-Control headers, etc., are defined in the Service.properties file deployed to the Settings folder of the Manhattan SCALE application servers and clients.  The settings of this file are used to fill Spring.NET property placeholders.  Consult that help topic to learn how to override settings at the process level, how to define settings at a more centralized location, etc.
