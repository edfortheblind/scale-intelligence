Technical Process Summary

** Functionality **

 

 

Summary...

The system includes several technical tools/modules that help SCALE run efficiently. Below are descriptions of these components:

 

 

 

Process Queue...

The application includes a service called the Process Queuing Service. This service writes requests to the Process Queue Request table in real-time for all batch processes. Then, the service will process these requests in the background, according to the priority that you have given a certain thread. You can view the statuses of these processes in the Background Job Queue Insight Screen. For more detailed information about these queues, see the topic Using the Process Queue.

 

 

 

Web Services...

Web Services provide an integration point into the system for third-party developers. The web services provide a specific system function (such as ship confirmation), and the data is returned as XML. Web Services allow customers to interact with the system directly from their custom code using these defined integration points. These services can be invoked from anywhere that has access to the web server they are hosted on. If you have a web server that is only used internally, these services can be used within the company only. If, however, you have a web server that is exposed to the Internet, a web service could potentially be called from anywhere in the world.

 

 

 

Scheduled Jobs...

The system's scheduled jobs allow you to plan the executing of repetitive processes that you want the system to run on a regular basis. You can schedule certain system processes (such as data archiving, interfacing, scan and weigh, replenishment, etc.) to run automatically on a certain time/day. When the system starts a job, it will send the processing thread for that job to the batch submission queue, where the system manages the priority of the execution of this thread. The thread will stay in the queue until it is processed.

 

 

 

Decimal Point Formatting...

The application supports the common formats for representing decimal values: a period separator or a comma separator. SCALE will use the separator that is defined on your current Windows language setting.

 

 

 

Fully-Customizable Viewer Windows...

SCALE features a customizable viewer window paradigm that is used for such processing windows as the Close Container Window, data archive viewers, and the Replenishment Insight. The system also allows users to create their own viewer windows, and have them appear in SCALE along with the system-supplied windows. These custom viewers feature two tabs: one that allows the user to enter search criteria, and the other that displays the results of a search query. The fields that display on a custom viewer are completely configurable, as well as the actions, colors, and icons that appear on the viewer. You can also choose to associate one database table or two (in a header-detail relationship) with a custom viewer window.
