Using Gadgets

In general, gadgets are defined as small specialized applications that are designed to do simple tasks (such as clocks, calendars, RSS readers, or search tools). On the SCALE Desktop, gadgets also allow you to run small pieces of functionality, whether it originates from SCALE or an external application. You can have any number of gadgets displaying at any time on the Desktop. When you exit and re-enter the application, the gadgets will be in the same position and be the same size as they were when you exited the application.

 

There are two types of gadgets, Single User Gadgets and Global Gadgets. Note that gadgets are sorted by type in the gadget library window.

  • Single User Gadgets: When you create a single user gadget on your Desktop, they are not viewable by any user other than yourself. Note that gadgets are created by default as single user gadgets. Single user gadgets are listed under the "My Gadgets" section of the gadget library.

  • Global Gadgets: These gadgets can be viewed by more than one user (i.e. all users, a subset of users, or a security group). Global gadgets are listed under the "Global Gadgets" section of the gadget library.

Creating/Managing Global Gadgets...

 

Creating a Global Gadget

 

1. After adding a gadget to the desktop, you can choose to designate it as a global gadget.

 

2. Open the settings window of your gadget.

 

 

 

3. Select the Global Gadget Checkbox to indicate that you want users other than yourself to have access to this gadget.

 

 

 

4. Press the Apply Button. The system will designate this gadget a global gadget, and the Configure Security Permissions link will activate.

 

5. Select the Configure Security Permissions link to grant permission to the user(s) that you want to grant access to this gadget (all users, a subset of users, or a security group). The system will open the Security Permissions Window.

 

 

 

6. After you have created the appropriate security records and have exited the Security Permissions Window, press the OK Button. The system will then save your global gadget settings.

 

 

Global and Local Gadgets With the Same Name

There is a scenario where a user can have a single user gadget and global gadget that have the same name. In this scenario, if the user wished to make their single user gadget a global gadget, they would have to rename it. The scenario is the following: Suppose you create a single user gadget called My Gadget. Also, suppose another user creates a single user gadget with the same name (My Gadget). Then, if the first user decides to make their gadget a global gadget, the system allows this. The second user now has a global gadget and a single user gadget with the same name. When the second user attempts to make their single user gadget a global gadget, the system gives them an error indicating the name must be unique.

 

 

 

 

 

Gadget Security...

When you create a gadget, the system creates the a security permissions record for this gadget. This allows you to manage the security for users/groups in the same way as other SCALE windows. You can choose to add security records for users/groups at the time of global gadget creation, or at a later time. In addition, a user with the proper security authority can change a gadget from being a global gadget to a single user gadget (or vice versa). When you do this, the system will remove/add the proper security records so that the various Desktops this change affects can manage this change. Also note that if a user has permission to access a global gadget, but that permission is taken away, the next time they open SCALE, the system will not display that gadget.

 

 

Below are descriptions of the available gadget security checkpoints:

  • Add Gadget to Desktop: Determines if you can add a gadget to the Desktop from the gadget library.

  • Add New Gadget: Determines if you can add a gadget into the gadget library.

  • Administer Gadget Settings: Determines if you can access the Gadget Settings screen.

  • Administer Global Gadgets: This setting determines the following:

    - Whether you can make a single user gadget into a global gadget.

    - Whether you can configure settings on global gadgets.

    - Whether you can uninstall global gadgets.

    - Whether you can copy global gadgets (if you do not have this security, then you can copy a global gadget, but it will become a single user gadget).

  • Copy Gadget: Determines if you can copy a gadget, whether it is a single user or global gadget.

  • Remove Gadget from Desktop: Determines if you can close a gadget that is being displayed on the Desktop.

  • Uninstall Gadget: Determines if you can remove a gadget from the gadget library.

Copying Gadgets...

You can copy an existing gadget and save a new version of this gadget with a different name. Note that you need to have the appropriate security permissions in order to perform this action.

 

 

The following steps describe how to copy a gadget:

 

1. Open the Desktop Gadget - Library Window.

 

2. Right-click the gadget you want to copy, and select the Copy action:

 

 

 

3. The system will open the Desktop Gadget - Copy window:

 

 

 

4. Enter a new name for this gadget, and press OK. This name must be unique among gadgets.

 

5. The system will save your new gadget, and display it in the Desktop Gadget - Library. You can now add this gadget to the Desktop and configure its settings.

 

 

 

 

 

Removing Gadgets from the Desktop...

When you press the "X" button on a gadget's Toolbar, the system will remove the gadget from the Desktop. Note that this gadget will still remain present in the library, so you can add it again to the Desktop later if you choose. Note that there is a security checkpoint that governs whether or not a user will be able to remove gadgets from the Desktop.

 

 

 

 

 

Uninstalling Gadgets...

This option allows the user to remove a gadget from being listed in the gadget library. This will prevent users from viewing this gadget on the Desktop, unless it is first reloaded into the library. There is a security checkpoint that governs whether or not a user will be able to uninstall gadgets from the library. Note that if a global gadget is uninstalled, then that gadget will not be available to any users the next time that they log into the application.

 

1. Access the Desktop's gadget library.

 

2. Right-click the gadget that you want to remove and choose the Uninstall option:

 

 

 

3. The system will remove the listing from the gadget library, as well as the gadget itself from the Desktop (if the gadget was currently being displayed there).

 

 

 

 

Shipped Gadget Descriptions...

The following gadgets are shipped with the system, and are available to add to the Desktop. See the SCALE SDK for information on how to create your own custom gadgets.

 

COUNTER GADGET

This gadget identifies the number of records that have met specific data criteria. For example, you might want to define this gadget to identify how many shipments have been confirmed. The counter number would then tick upwards by one digit each time a shipment is confirmed (see the example below). Note that the data displayed by the Counter gadget is defined using either a custom SQL statement or stored procedure. This query/stored procedure should return a single count value that will be bound to the gadget.

 


 

 

DOCUMENT GADGET

This gadget displays a list of the file contents of a particular local or network directory. You will need to provide the directory whose contents you want the gadget to display (it must be a valid local or UNC path). 

 

 

 

FEED GADGET

This gadget allows you to set up and display an RSS feed inside a gadget. When the gadget is displayed on the Desktop, it will display headlines from the RSS feed that was configured. Note that feeds that require a username/password (other than your Windows login) are not supported with this gadget.

 

 

 

GAUGE GADGET

This gadget communicates the percent of records that have met a specific data criteria. For example, you could use a gauge gadget to show the percentage of today’s shipments that have been ship confirmed; or, the percent of permanent locations that are currently empty. Gauge data is defined using either a custom SQL statement or stored procedure, and the gauge will provide reliable percents based on the data returned from the database. This query/stored procedure should return a single percentage value that will be bound to the gadget.

 

 

  

WAREHOUSE ALERTS GADGET

This gadget displays alert(s) that meet the data criteria of a warehouse alert record. A warehouse alert is an immediate update or warning on a situation the warehouse manager needs to address. The alert gadget can display this information directly on the Desktop. You can also export the grid data to an Excel spreadsheet by pressing the Excel button on the gadget's toolbar. Note that this gadget only includes those alerts that are defined to generate history. Therefore, alerts that only generate emails cannot be displayed using this gadget. .
