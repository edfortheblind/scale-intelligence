Packing a Container

This topic includes the basic procedures required to pack an item into a container from the Packing screen. Note that you cannot pack a shipment that is currently on a wave that has not been released.

Reference Messages...

The system displays one or more of the following reference messages, depending on the condition of the container that you are currently packing. These messages appear in the Status Info accordion of the Packing Screen.

  • Not Completely Picked: This message indicates that there are line(s) on this shipment that have yet to be picked. Any line(s) that have not been picked cannot be packed.

  • Completely Picked: This message indicates that all line(s) for this shipment have been picked, and are available to be packed.

  • VAS Required: This message indicates that the container you are packing into requires value added services.

  • QC Required: This message indicates that the container you are packing into requires QC.

  • Awaiting Immediate Needs: This message indicates that the shipment has been completely picked, but has immediate needs pending.

 

 

 

Packing a Container...

  1. Access the Packing Screen.

    2.  

  2. Identify the shipment in the Shipment ID field. Note that the default value for this field is the shipment number. You can configure the system to prompt for a different field when initiating a packing action using the "Initiation Field" setting on the Packing Preferences configuration.

    3.  

  3. Select a value in the Team field to indicate that you want to sign onto a packing team. If you are associated with a work team, the system will track your activity on the Labor Activity Insight Screen. Note that this field is optional.

  4. Press the initiation (arrow) button. The Packing Screen will then display all of the open lines for the initiated entity (e.g., a shipment). Note that if you enter an initiation criteria that does not have any items left to pack, the system will display an error message indicating that there are no lines available to pack.
     
  5. Use the Container ID Field to select a container ID to assign to this package:

    - Use an Existing Container: By pressing the Existing container button, you can pack items into an existing container. The system will populate the drop-down field with all the container(s) that are associated with this entity. If you have not yet packed any containers for this entity, the system will not display any container IDs in this field.

    - Use a New Container: By pressing the New container button, you can pack items into a new container. The container will become a free-entry field where you can indicate the new container ID (if container assignment is defined as manual in your packing preferences). Note that if you are using system container assignment, the system will disable this field and contain a value that says "System created".

  6. Use the Container Type Field to identify what type of container you are packing into. If you assigned an existing container ID, you cannot change this value since the container type has previously been defined. The container types available for packing can be authorized by company and warehouse. See the Defining Container Types for more details.

  7. Next, identify the item that you want to pack:

      8.  

    • If item validation is active (via packing preferences), you will need to scan/enter the item/item cross reference that you want to pack.

       

    • If item validation is not active (via packing preferences), you can select a grid row of the item you want to pack. The system will then auto-populate the ID into the Item field.

     

    Packing Instructions - On selecting an item,

    • if packing instructions are defined at shipment header level, then it will be displayed in the Packing Instruction accordion.

    • If packing instruction are defined at shipment line level, then a pop-up notification will be displayed.


  8. Enter the quantity you want to pack using the plus and minus buttons on the quantity ticker. You may also enter the number value directly into the quantity text box. Note that if item verify is off, the system defaults the total packed quantity into the quantity ticker when you select an item's grid row.

    9.  

  9. Select the Pack Button. The system will pack the shipment line into the container. If you have packed the full quantity of the line into the container, then the item's grid row will disappear from the grid. The system will also update the Total Quantity and Total Weight values in the Container Summary accordion.

    Note that you could also press the Pack All Button, which would pack ALL of the remaining item quantities into the container. Also, packing will prompt for serial number entry when the item has been set up to track serial numbers in the outbound or inventory flows.

     

    Note: You will need to provide catch weight for catch weight-tracked items.


    10.  

  10. When you pack an item and item validation mode is on, the system will display the following in the "Last Item Packed" section on the right pane of the screen: the item's ID, description, quantity packed.

  11. You can now pack additional items into this existing container, or into a brand new container. Or, you could close the container by pressing the Close button (the system will display the Close Container Screen loaded with the container that you just packed).

 

Packing Error Note:

- If the system encounters an error when packing an item, the system will display a checkbox in the "Error" grid column. You can then press the row's checkbox to view the specific error that occurred.

 

 

 

 

Overpacking a Container...

When you pack a container in the system, you typically cannot pack an amount that is greater than the quantity available on the shipment line. However, the system does allow overpacking if your packing preferences are defined accordingly.

  1. Indicate the quantity of the item you want to over pack.

  2. Select the Pack Action. The system will then display the Over Packing Verification Screen.

     

  3. Use the Reason Code Field to enter an explanation for the overpacking action.

  4. Press Save when finished. The system will pack the item into the container.

 

 

 

Printing Container Documents...

You can print documents and labels from the Packing Screen by pressing the Print Button. The system will display a dialog that allows you to choose the documents/labels you want to print.

 

 

 

 

Closing a Packed Container...

  1. After a container is completely packed, the system will activate the Close button.

  2. Press the Close button.

  3. The system will open the Close Container Screen. See the topic Closing a Container for more information on this action.
