Using the VAS Insight: Container Screen

The VAS Container: Insight Screen displays the value-added activities (such as putting hangars on clothes, or including a catalog with an order) that are assigned to a shipment's containers. You can use this screen to confirm these activities. When you confirm an activity, you are simply indicating to the system that an activity has actually been performed on the container's contents.

Searching For VAS Activities...

Access the VAS Container: Insight Screen.

  1. Indicate the container(s) whose activities you want the system to display in the grid. You can do this by using any combination of the following criteria:

    - Container ID: You can enter a container ID, and the system will display all VAS activity(s) that are associated with that container.

    - Shipment ID: You can enter a shipment ID, and the system will display all VAS activity(s) that are associated with any container(s) on that shipment.

    - VAS Activity: You can choose one or several activities, and the system will display all container(s) that have those VAS activity(s) associated with them.

  2. Use the Include Confirmed Activities setting to indicate if you want the system to display activities in the grid that have been finished (confirmed) by a user.

  3. Press the Apply Button. The system will display the results in the grid. The system will represent each container/activity as a separate row in the grid.

 

 

 

Viewing VAS Activities...

The VAS activities grid includes several reference fields, which are described below:

  • Container ID: This represents the container that has an activity assigned to it.

  • Shipment ID: This represents the shipment that is associated with the VAS-assigned container.

  • VAS Activity: This represents the activity that is assigned to a container.

  • Instructions: This represents an activity's instructions text, which provides the user directions on how to perform the activity.

  • Status: This represents the status of the container that has a VAS activity associated with it. In order to confirm a VAS activity, a container needs to be in at least an "In Packing" status. The system will make activity rows inactive if they are not at least at the minimum status to confirm VAS.

  • QC Required: This indicates if QC is also required for this container, and the condition of that QC action (pending, failed, passed).

 

 

 

Confirming VAS Activities...

The act of confirming a VAS activity indicates that said activity has actually been performed to the contents of a container. For example, if you have an activity for placing a catalog into a container, then when you confirm this activity on the VAS Container: Insight Screen, that tells the system that this activity as been performed. If a container's status is not at least "In Packing", the system will not allow you to confirm any activities for that container.

 

You can confirm VAS activities by selecting the Confirmed Checkbox for an activity row, and choose Confirm button:

- Note that you can confirm activities one-by-one, or multiple activities at one time.

 

- After an activity has been confirmed, the system inactivates the row. You cannot undo a confirmation once it has been performed.

 

 

 

 

Printing VAS Paperwork...

The VAS Container: Insight Screen also features a paperwork document called the VAS Activity List, which outlines the containers of a shipment that require VAS, and the activities that need to be performed on each container. You can print this document not only from the VAS Container: Insight Screen, but also from a wave.

 

The following procedures describe how to print this document from the VAS Container: Insight Screen:

  1. Select an activity row that is associated with the shipment for which you want to print the VAS Activity List.

  2. Press the Print Selected Docs or Print Default Docs button as needed.
    • If you select Print Selected Docs option, the system will display the Print Documents Window.

    • If you select Print Default Docs option, the system prints the documents configured as "default" (with no further prompting).

      - Note that when multiple rows are selected in VAS insight, both options remain disabled. For more information, see the Printing Paperwork topic.

  3. Press the Submit Button. The system will print that shipment's VAS Activity List.
