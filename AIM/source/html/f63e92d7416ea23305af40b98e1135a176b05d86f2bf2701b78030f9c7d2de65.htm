Activating a Zone for Pick Management

You must activate picking management for a specific zones if you want the system to display work unit(s) from these zones in the picking management windows. Note that this topic discusses only the steps needed to activate picking management for specific zones. For more general information on creating zones, see the topic Defining Zones. You will activate zones on the Zone Window.

 

 

 

Using the Pick Management Active Checkbox

Access the Zone Window. Open or create a new zone record.

  1. Choose the value "Work" in the Zone Type Field. You must choose a zone type of "Work" if you want to activate picking management.

     

  2. Use the Pick Management Active Checkbox to indicate if you want work units in this zone to appear in picking management.
     

    • If this checkbox is checked, the system will display work units from this zone in picking management windows, such as the Picking Selection Window or the Picking Management Explorer.

       

    • If this checkbox is not checked, the system will not display work units from this zone in picking management windows.
