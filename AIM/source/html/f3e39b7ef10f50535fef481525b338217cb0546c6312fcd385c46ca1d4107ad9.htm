Defining Outbound QC Reason Codes

You need to configure the reason codes that you will use on the QC Workbench to indicate why an item quantity did not pass QC inspection. Note that you will need to create these reason codes with a process of Quality Control.

 

RF Shipping Container QC Screen Reason Code

The system will always assign the RF QC Failed Quantity reason code to failed quantities counted on the RF Shipping Container QC screen. This reason code is shipped with the system, and you can change the description of this reason code record to meet your business needs.
