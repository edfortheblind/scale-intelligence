Using the Receipt Monitoring Screen

You can use the Receipt Monitoring screen to research and manage receipts in a warehouse.

 

 

Notes
  • This topic discusses specific fields represented on this screen as it is shipped in the base SCALE product. If your screen has been customized, different field (s) may appear on your screen.

Navigating/Viewing the Receipt Monitoring Bar Chart

  1. Access the Receipt Monitoring screen.

  2. The system will display a chart on the first (highest) level which indicates the numbers of receipt headers in the user's default warehouse broken down by Receipt Dates as defined (Past Due, Today, Tomorrow, This Week, This Month, Future).

  3. Press on a Receipt Date data column, and the system will display the next level of the chart, Receipt Type.

  4. Press on a Receipt ID Type data column, and the system will then display the next level of the chart, Vendor Name.

  5. Press on a Vendor Name data column, and the system will then display the last level of the chart, Purchase Order.

 

NOTES:

  • On any level of the chart, pressing Insight takes you to Receipt Insight with the receipts selected that match that graph.

  • On each graph level, the totals at the top of the graph show number of receipts (headers), number of receipt lines, and total value (from receipt headers) pertaining to that graph.

  • Changing warehouse at the top of the Monitoring screen displays the open receipts from the selected warehouse.

 

 

 

Summary Data...

The following summary data totals are accessible from the Receipt Monitoring screen:

 

Total Receipts

This value indicates the number of receipts.

 

 

Total Receipt Lines

This value indicates the number of unique receipt lines associated with the receipts being shown.

 

 

Total Receipt Value

This value indicates the total value of receipts.

 

 

 

Indicator Tiles

Indicator tiles display key warehouse data totals. Tapping on a tiles will navigate you to the appropriate insight screen that will load the data. The following indicator tiles are shipped with the system:

 

 

Receipts over 24 hours old

This tile represents the summation of the number of receipts that have at least one item checked in greater than 24 hours ago and is not closed.

 

 

Pending putaways over 4 hours old

This tile represents work instructions (with a "header" Instruction type and "receipt" Internal Number Type along with the condition is not equal to closed) where the aging date time is greater than 4 hours since the current date/time. Pressing on the tile takes the you to Work Insight with the selected instructions.

 

 

Receipts with QC

This tile represents a count of the receipt headers where at least one receipt container has inbound quality control pending, and are not yet in a closed status.
