How Does the FedEx Server Work With the Application?

The FedEx PowerShip Plus Server is a shipping tool that provides rating and routing information, in addition to parcel manifest EDI uploads. The server, which is provided by Federal Express, is loaded with its own propriety software. It communicates with the system via a network LAN.

How FedEx and the System Communicate: Manifesting...

These procedures assume that the FedEx Server was installed at your site and tested to ensure accuracy:

  1. The system sends a manifesting request to the FedEx Server.

     

  2. The server manifests the parcel and sends the information back to the system.

     

  3. The system sends a request to the server each time it manifests a parcel.
Note on Dimensional Weight Rating:

Although you will define a parcel’s dimensions in the system, dimensional weight rating is handled by the FedEx Server. The server updates the parcel manifest to reflect the dimensional weight rates that it assigns.

 

 

 

How FedEx and the System Communicate: Uploading Revenue Files...

These procedures assume that an employee closed the parcel manifest:

  1. When FedEx parcel manifests are closed in the system, EDI Files are generated, and a request is sent to transmit the data to FedEx.

     

  2. The FedEx server will dial FedEx Headquarters and transmit the data. FedEx Headquarters will not send a successful transmission message; however, they will send a bill via mail.

How FedEx and the System Communicate: Downloads...

The term "downloads" refers to all information that is downloaded from FedEx Headquarters to the FedEx Server. Downloads include new rates and routing data and updated software.

  1. From the FedEx Server terminal, an employee will access the ‘Demand Download’ Window; he/she will select a download type.

     

  2. The FedEx Server dials FedEx Headquarters and transmits the download request.

     

  3. FedEx Headquarters reviews the response and transmits the appropriate data.
