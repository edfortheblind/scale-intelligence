Lookup Screen

You can use a Lookup Screen to search for a specific record in the system. This is especially helpful when you do not know what a particular field value should be. The system implements several search criteria when looking for a record. Lookup Screens are located throughout the system, whenever they are required. You can access them by pressing the small magnifying glass icon to the right of a field input box.

 

 

Lookup Screen Fields...

  • The application uses several search criteria to locate records in the system. The specific fields in each Lookup Screen will depend on the type of record you are searching for.

 

Procedures...

  1. Click on the magnifying glass icon (next to a field's input box), and the system will display a Lookup Screen.

     

  2. Enter information for the search criteria fields (the fields displayed will depend on what type of field the lookup was accessed for). When entering data in the search criteria fields, you can use this search syntax to help narrow down your search:
     

    • A% will return all records that start with a capital "A"

       

    • %A will return all records that end in a capital "A"

       

    • Search that starts with only a lower or upper case A will return all records that start with an "A".

      •  

    • %a% will return all records that include a lowercase "a" anywhere in the record name.

     

  3. Press the apply filter button. The system will display any records that have met your search criteria in the record list.

     

  4. Choose a record from the record list and press the Select button. The system will return to the original screen with the value populated into the appropriate field.

    NOTE: You can also clear the records from the Lookup Screen by pressing the Clear button (Clear filter for Insight/Transaction/Details screen). The filter button does not refresh the grid or start a search when clearing the filter criteria. You will have to press the Apply filter button to start the search.
