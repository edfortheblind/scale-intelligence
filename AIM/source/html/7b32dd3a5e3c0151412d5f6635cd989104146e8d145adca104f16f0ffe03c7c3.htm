Creating Label Masters

A label master record manages the process of printing the labels from a wave. The following labels are governed by these records: shipping labels, vendor labels, and container contents labels. Label masters are useful because they allow you to define how/when these labels will be generated and printed. There are two additional label criteria windows that can be used to help filter the labels that are generated.

  • Label Master Criteria - You use this window to define which shipments the system will generate labels for by creating label master criteria filter rules. Labels can be printed in the wave by using wave flow that includes the "Paperwork-Labels" wave step.

  • Label Selection Criteria - You can use this window to determine the eligible containers for which you want labels. Labels can be generated by specific document types, which eliminates the need to create unnecessary document routing records for unwanted labels.

 

Notes
  • You must run a wave using a wave master that has the appropriate label master and wave flow associated with it. Otherwise, the system will use the wave master in the warehouse with the highest priority (which may not be associated with your label master).
  • If a label master does not have a label master criteria configured, or has one with no "order by" rules, the system will collate the labels sent to a specific print device by document type. For example, if printing shipping labels and vendor labels, every shipping label will print first, followed by every vendor label. To collate labels by container, you need to use a system-created label master criteria record named "Collate By Container." This record is set up with trivial criteria and a single "order by" rule of Shipping_Container.INTERNAL_CONTAINER_NUM, which will properly collate by container. Note that this field must be used in the "ordering of" other label master criteria records if container collation is desired. Keep in mind that the system-created "*Default" label master will use this "Collate by Container" label master criteria record.
  • Wave label processing (using label masters) does not honor the Number of Copies value found on the Document Routing Window. You can  work around this by adding creating multiple Label Master Document Type records. Please note, however, that this will incur extra processing, as the label will be generated multiple times.  Also, this does not work for all document types (such as FedEx Shipping Labels).

  • Wave label processing does not generate labels for child containers when the "Print for Nested Containers" is selected on a label's Document Window record.

  • When adding filter criteria, the Label Generation Process uses the following steps:

    1. Label master criteria

    2. Label selection criteria

    3. Document routing

    4. Sort and possibly set break labels:

    - Print device
    - Order by label master criteria
    - Document type

Creating Label Master Criteria Records...

Access the Label Master Criteria Window. The system uses the records created on this window to determine the shipment(s) in a wave that will require a certain label to be printed. You can also activate break labels on the Order By Tab. These are used as a separator between a group of labels for a wave's shipments. For instance, suppose your wave has two shipments, and the system would need to generate three labels for each shipment. If activated, a break label would then print in between the two shipments' group of labels. The break label template provided with SCALE displays the Shipment ID and Container ID fields as samples to aid your customization efforts.

  • Select the Create Break Label Check box to indicate that you want the system to print a break label.

     
  • Use the Break Label Template Field to indicate a template that you want the system to use when generating break labels.

 

 

Creating Label Selection Criteria Records...

Access the Label Selection Criteria Window. The system uses the records created in this window to determine which container labels to print. You can use this window to define a specific document type. By using the Label Master Criteria and Label Selection Criteria Windows together, you can eliminates the need to create unnecessary document routing records. This configuration filters using the shipping container and shipment header view tables. The system will error if a container is selected and no document routing records exist.

 

Example: Using Label Master Criteria and Label Selection Criteria

Desired Labels: Vendor labels for all containers and Container Contents for PL only

  • 10 containers in wave



    • 5 PL

    • 5 CS
  • 2 Document Type Records Configured: Container Contents, Vendor Labels

Label Master Criteria Configured: defined so ALL containers are eligible ('container_num' is not null )



Label Master Selection Criteria Configured: PL containers are only chosen (Shipping_container type = PL)

 

In this example, the system will only create container and vendor labels for the 5 PL containers.

 

 

Creating Label Masters...

Access the Label Master Window.

  1. Use the Label Master Field to provide a name for your master record. Also provide a description.

     
  2. Use the Data Selection Field to select a label master criteria record, which determines the shipment(s) in a wave that will require this label to be printed. These records are defined on the Label Master Criteria Window.

     
  3. Use the Print Mode Field to determine when in the wave process you want these labels to generate/print:

    - Print During Wave: The system will generate and print the label files when executing the "Paperwork-Labels" wave step.

    - Print At Release: The system will generate and print the label files after a wave has been released (manual release only).

    - Manual: The system will generate the label files during the wave process, but will not print them. The user then can manually print these labels using the "Reprint Labels" option on the Wave Insight screen. This option is useful if you do not want the user to wait for the system to generate the labels when manually reprinting them (they will have already been generated via the wave).
     
  4. Use the Document Type Field to choose the label that you want to print during the wave.

     
  5. Use the Generating Class Field to indicate if you are printing a vendor label or shipping label.



  6. Use the Label Selection Criteria Field to indicate the which containers are eligible for label printing.



  7. If necessary, press the Add Button to create an additional detail to this master record.

     
  8. Press OK when finished. The system will save your record.
