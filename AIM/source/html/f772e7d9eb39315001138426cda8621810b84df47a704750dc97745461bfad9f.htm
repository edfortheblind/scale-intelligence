Creating a Work Order

Work orders manage how a finished item will be assembled. All work order related information, such as components and instructions, can be stored on a bill of material record or manually entered when the work order is created. You can define work orders on the Work Order Insight screen.

Notes...
  • For specific definitions of a certain field on this screen, see the "Field Links" section of this topic, or type the field name into the help index.
     
  • Note on Component Part Allocation: The system can allocate component parts automatically when you either create a new work order or release an existing one. You can use the Work Order Allocation Method Field on the Work Order Values Window. You can also manually allocate component parts from the Component area on the Work Order.

  • Note on Deleting Work Orders: You cannot delete a work order if a non-inventory item has been allocated. First, you must deallocate the non-inventory item, because non-inventory items are marked as on hand immediately upon allocation. Once this deallocation has occurred, you can then delete the work order.

  • Creating Work Orders in the Wave: In addition, the system can create work orders using the "Work Order Creation" wave step (if the finished item's BOM Action is defined to create the work orders). There will be one work order per item/per wave created. For example, suppose five shipments all need the same item. The system then would create one work order for the sum total of all five shipments, and link all five shipments to the work order.

  • Note on Bill of Material Revisions: If a bill of material has multiple revisions, then when you enter the finished item on a new work order, you will be able to select which revision you want to use for this work order.
