Defining Serial Number Templates

A serial number template determines the physical structure of a serial number. You can define if a serial will be alpha-numeric or numeric, its length in characters, and whether a serial number can be duplicated (for this template) in the system. You can associate a serial number template with an item on the Item Window. SCALE tracks two different types of serial numbers: major and minor. A major serial number is the primary serial number that the system will reference and display in SCALE. A minor serial number is a secondary serial number that the system references behind-the-scenes, but is not typically viewable in SCALE windows. Note that you are not required to define minor serial numbers when using serial number tracking. The system can validate serial numbers throughout the warehouse (the Inbound, Inventory, and Outbound processes). Serial numbers are written to their own database table, which allows the system to easily access these values for various processes.

 

NOTE: The length of the entire serial number template cannot exceed 50 characters, as that is the maximum length of the Serial Number field in the database.

Notes on the Example Used in the Procedures...

In outlining the concepts behind defining a serial number template, this topic will use the example below. Therefore, suppose that you are a warehouse that stores computer systems. Each computer houses several components, including a processor, video card, CD-ROM drive, and a modem. The warehouse tracks not only the major serial number (on the computer case itself), but also minor serial numbers on each component. The serial number templates, then, would need to have the following structure:

 

Major Serial Number: 4AD2-5452367540-2M
(four alphanumeric characters - ten numeric characters - two alphanumeric characters)

 

 

 

Minor Serial Numbers: 32163543-C9

(eight numeric characters - two alphanumeric characters)

Procedures: Defining a Serial Number...

The following procedures explain how to create a serial number template. See the graphics in the example section above to view the screen flow for defining master and minor serial numbers.

 

Using the Header Fields...

 

Access the Serial Number Template Window. Create a new record.

  1. Use the Template Name Field to indicate the general system identifier associated with this template. In our example, you would enter the value IBN Computer. This is the value you will see when you choose a serial number template to assign to an item.

  2. Use the Description Field to provide a text name for the major serial number.

  3. Use the Allow Duplicates Checkbox to determine whether the system will allow users to enter the same serial number for this particular template. Note that this checkbox will be active only if the "Allow Duplicate Serial Numbers" flag in the Inventory Control Values is set at "Y." Be sure to only use this setting if your business process is not affected by having item(s) with the same serial number.

    - If unchecked, indicates that you want to prevent duplicate serial numbers from being entered for an individual serial number template.

    - If checked, the system will allow duplicate serial numbers across serial number templates. The system will only allow duplicate serial numbers to be added to items that are associated with a serial number template.

  4. Use the Allow Range Entry Checkbox to indicate that you want the system to ask for a range of serial numbers (created using this template) during the RF picking/check in of serial number-tracked items. This option is only available when the following criteria are met:

    - Templates do not contain minor serial numbers

    - Serial numbers end with a numeric value

    Note: When range entry is active, the final segment of the serial number template must be numeric, and cannot exceed 9 digits. If for this type of serial number you need to enter a serial number range with greater than 9 digits, you will need to configure another numeric segment (before the final segment) for the additional digits required.

    GS1 Note: During the processing of GS1 scans, since the system allows the scanning of only a single serial number from a GS1 barcode, the system ignores a serial number template's "allow range entry" setting. You will, however, be able to enter serial number ranges as part of the normal check in process that occurs after the GS1 scan(s).

 

Using the Pattern Fields Tab...

 

You can use these fields to define how each segment of a serial number will be structured.

  1. Use the Type Field to indicate what type of character the system will use for this segment of the serial number:

    - Alpha: Letters only

    - AlphaNumeric: Letters and/or Numbers

    - Numeric: Numbers only

    - Constant: A specific letter, number, and/or symbol (such as a dash or a double-zero). This value will be the same for any serial number entered using this template. A constant would typically be used as a separator character.

  2. Use the Length Field to indicate the mandatory number of characters that the system will expect to be entered for this segment of the serial number.

  3. Use the Value Field to indicate the characters you want as a constant on every serial number that uses this template. For example, you could enter a dash "-" to separate two segments of characters. Note that you must select constant in the Type Field in order to enter a value into this field.

  4. Press the Advanced Button to display more options you can configure for this template:

    - Use the Pattern Field to view the code that represents the segments that you defined for this template. The system uses this string to "compute" a serial number according to the parameters in your template. You should only edit the values in this field if you are strongly familiar with the syntax that is used to code the serial number segments.

    - Use the Test Data Field to enter a sample serial number value that you believe matches the structure of this template.

    - Press the Test Button to have the system analyze your "test data" and decide if it matches the template. The system will display a message with the test results.

    - Press the Basic Button to return to the general Pattern Fields Tab. The system will save any information you have entered into the advanced fields.

  5. Press the Add Button to confirm the data you have entered for a major/minor serial number, or one of its particular segment(s). After this button is pressed, you can enter new number/segment data.
