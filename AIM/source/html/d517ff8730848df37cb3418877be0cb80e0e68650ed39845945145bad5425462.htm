Location Process Summary

** Functionality **

 

 

Summary...

A location is the unique place in the warehouse where an item or license plate can be picked, putaway, or replenished. Locations can be defined on the Location Window. To minimize setup time, you can set up location types which identify dimensions and quantity maximums for a group of locations. Later, you can associate each location with its location type. This is especially helpful if you have rows of the same storage type, such as a racking system or pallet storage area. You can also define movement classes per location. The movement class identifies what types of product can be stored in the location.

The following are key features of the location functional area:

 

Location Templates...

The system features location templates, which you can use to define the structure of a location ID. A location template includes separators. Later, employees can just enter the ID string and the system will automatically apply the correct structure.

 

 

 

Location Classes...

The system provides predefined location classes. A location class identifies the purpose of a location, such as storage or shipping dock.

 

 

 

Permanent Locations...

You can associate items with a permanent location. This allows you to allocate items that you don't track as inventory, such as promotional leaflets and other value-adds.

 

 

 

Pickup & Dropoff Locations...

You can also create Pickup and Dropoff (P&D) locations. P&D locations can be used as intermediate locations while performing inventory movement. You can then associate P&D locations with a regular inventory locations. For example, suppose you have a narrow aisle that contains several inventory locations. When items are picked from these locations, the picker could then place the items in an outgoing P&D location at the end of the aisle. A different worker would then pick up these items, and take them to their destination (which could be an incoming P&D location, packing station, or other area).
