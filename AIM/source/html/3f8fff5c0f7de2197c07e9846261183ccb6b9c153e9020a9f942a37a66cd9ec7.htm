Creating/Editing a Shipment

The system generates all necessary shipments when an order is interfaced from the ERP. However, you may need to manually create or edit a shipment to accommodate special circumstances. Shipments can be created/edited from the Shipment Insight Screen.

Creating a Shipment...

  1. Open the Shipment Insight Screen or the Planned Shipment Insight Screen.

  2. Select the New action. The system will display the Shipment Screen in new mode.

  3. Enter the required fields (Shipment ID and all of the Ship To address fields). In addition to shipment ID and the required Ship To fields, the Warehouse field must be populated when creating a shipment from the Shipment Insight screen. The warehouse will be defaulted to the user’s default warehouse when opening the screen in new mode.

  4. Press the Save button, and the system will create the shipment. If you now wish to create line(s) for this shipment, see the topic Creating/Processing a Shipment Line for further instructions.

NOTES:

  • The shipment's leading and trailing status are determined by the status action value associated with the screen that you're creating it on.

  • If you created this shipment on the Shipment Insight screen, its status is based on the value defined in the "Add From Shipping" status action.

  • If you created this shipment on the Planned Shipment Insight screen, its status is based on the value defined in the "Add From Wave" status action.

  • If you created this shipment on the Order Entry Window, its status is based on the value defined in the "Add From Order Entry" status action.

 

 

 

Editing a Shipment...

  1. Open the Shipment Insight Screen or the Planned Shipment Insight Screen.

  2. Access the shipment you want to edit.

  3. Select the Edit action.

  4. Change the values of the field(s) you wish to edit.

  5. Press the Save button The system will save your changes.
