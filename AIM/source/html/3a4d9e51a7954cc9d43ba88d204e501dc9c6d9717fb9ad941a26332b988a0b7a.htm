The following special parameters are available when using SSRS for printing:

 

Parameter

 

Description

 

DOCUMENT_TYPE

 

Filled with the Document Type of the printed Document.

 

CONNECTIONSTRIN

 

Filled with connection string that used by data source.

 

LANGUAGE

 

Filled with the Document's language in Culture Name format, e.g. "en-US" for "English (United States)"

 

 

 

 

The following internal numbers are available on the SSRS Printing Request table:

 

Internal Number

 

Description

 

INTERNAL_NUM1

 

Filled with the internal number and internal number type based on the parameters for the document type used to print the document.

 

INTERNAL_NUM_TYPE1

 

Filled with the internal number and internal number type based on the parameters for the document type used to print the document.

 

INTERNAL_NUM2

 

Filled with the internal number and internal number type based on the parameters for the document type used to print the document.

INTERNAL_NUM_TYPE2

 

Filled with the internal number and internal number type based on the parameters for the document type used to print the document.

 

INTERNAL_NUM3

 

Filled with the internal number and internal number type based on the parameters for the document type used to print the document.

 

INTERNAL_NUM_TYPE3

 

Filled with the internal number and internal number type based on the parameters for the document type used to print the document.

 

 

NOTE: Some document types use a single internal number, while others may fill two or three. Three internal number types are provided for custom document types.

 

 

 

Example:

 

1. One Internal Number: Printing an allocation pick list for a shipment with an internal shipment number equal to 12747 would have the INTERNAL_NUM1 set to 12747 and the INTERNAL_NUM_TYPE1 set to InternalShipmentNum.

 

2. Two Internal Numbers: Printing a cycle count list with a plan number equal to 502 and group number equal to 1 would have the INTERNAL_NUM1 set to 502 and the INTERNAL_NUM_TYPE1 set to InternalPlanNumber and INTERNAL_NUM2 set to 1 and the INTERNAL_NUM_TYPE2 set to GroupNumber.
