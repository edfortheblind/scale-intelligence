Shipment Consolidation Screen

The system displays this window when you select the Consolidate action for a shipment. It displays all the shipments that you can consolidate with the one that you selected. You can use it to pick which shipments should be consolidated with your initial shipment. This window can be accessed by selecting the Consolidate action on a shipment from the Shipment Insight or Planned Shipment Insight.

 

 

Notes

 

- The following are the rules regarding a shipment's eligibility for manual consolidation:

  • You can consolidate shipments that are in an In Pool status only with other shipments that are in an In Pool status.

  • You can consolidate shipments in a Wave Pending status only with other shipments assigned to that same wave.

  • You can consolidate shipments beyond a Wave Pending status if their associated wave has been released, or if they have no associated wave. They may only be consolidated with other shipments whose wave has been released, or who has no associated wave.

  • You cannot consolidate shipments that are on a wave that is either currently running or has completed running, but has not yet been released.

- Shipment(s) highlighted in yellow meet the original shipment's required criteria, but contain differences in the criteria that are not required. For the Shipment Consolidation screen, this goes into the Required Criteria accordion.
