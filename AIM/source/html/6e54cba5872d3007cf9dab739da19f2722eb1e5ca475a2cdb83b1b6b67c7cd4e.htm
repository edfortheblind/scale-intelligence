Creating Receipts From Purchase Orders

From the Purchase Order Insight screen, you can choose to create a receipt/receipt line from the information contained on a purchase order. This is helpful if your ERP interface does not download receipts into SCALE, but you want to use receipts in your inbound processing flow. Using this functionality, you are able to bypass the need for these downloaded receipts by creating them directly from purchase orders. On a purchase order with open lines, clicking the Receipt from PO action opens the Receipt From Purchase Order Screen with the header and line information from the selected purchase order. Only purchase order lines with open quantity are displayed in the grid specifying lines to be added to a receipt.

Procedures...

 

Warehouse Section
  1. Access the Receipt From Purchase Order Screen:

    - Enter a new ID in the Receipt ID Field. The system will then create a new receipt, using the ID that you provided. It will copy all the shared values from the purchase order to the new receipt (company, source address information, etc.)  

    - Enter an existing ID in the Receipt ID Field. The system will accept any receipt ID that exists, and also shares the same company and vendor information. In the case of the vendor information, the receipt and the PO must share the same vendor/company information, but they can be from different ship froms. Also, the receipt cannot be closed. If you happen to assign one receipt ID to multiple POs, the system will display the value "Multiple" in the Purchase Order ID Field on the Receipt screen.

    - If you leave the Receipt ID field blank, after a confirmation message the receipt gets created with a receipt ID equal to the purchase order ID plus a numeric next number suffix. For example, if the purchase order ID were 12345, the first receipt would be created with a receipt ID of 12345-01. The second receipt would be created with a receipt ID of 12345-02, and so on.
     
  2. The Company Field is defaulted by the system from the Purchase Order Screen.
     
  3. Select the Go Directly To Receipt Workbench Toggle to have the system to automatically open a new receipt in the Receipt Workbench for processing after you have finished using this screen.

  4. Click Save after updating the lines.

 

NOTE: If the 'Locating Rule Assignment During Receiving' system value is set to "Receipt Detail Creation", then a locating rule gets assigned to each receipt line according to the locating rule assignment criteria configured.

 

 

Item Info Section

This section identifies the detail lines and quantities to assign to this new receipt. You can choose to set all the line(s) quantities using a percent value or a specific amount; or, you can manually define the quantities separately for each receipt line. These methods are described below:

  • Use the % Toggle to set all the detail lines to a particular percent. This is selected by default; the default value is 100%. When specifying a percent, the percent is taken against the available quantity on the line and rounded to the nearest whole number. After inputting a value, press the Update All Lines Button. The system will then calculate the amount per detail line and display those numbers in the Receipt Quantity Field.
     
  • Use the Quantity Toggle to set all the detail lines to a specific quantity. If the Available Quantity for a particular line is less than the amount defined here, the system will assign the entire amount to this detail. After inputting a value, press the Update All Lines Button. The system will set all of the values in the Receipt Quantity Field to match this value.
     
  • You can also manually set the quantity for each of the lines. Using this method, you would directly enter each detail line's quantity to a specific value in the Receipt Quantity Field. If you do not change a value in this field, it remains at the "available quantity" amount.

 

 

Source Section

The Source Fields display the name and address information for the vendor responsible for this purchase order.
