Frozen Checkbox

Select this checkbox if you want to label an inventory lot as being "frozen," which typically would mean that you do not want any item quantities associated with this lot ID to be shipped from the warehouse. For a frozen lot, the system will assign this lot's inventory the status that is defined on the "Inventory Status For Frozen Lots" setting on the Inventory Control Values Window. When you mark a lot as frozen, or you unmark a lot as frozen, it changes the inventory status on all inventory for that item /company /lot in the warehouse.

 

Note: The only way to prevent shipping frozen lots is to prevent them from being allocated in the first place. The allocation location selection for the allocating rules would need to exclude inventory where the inventory status equals the frozen lot status in order to stop new shipments from allocating the frozen lot.
