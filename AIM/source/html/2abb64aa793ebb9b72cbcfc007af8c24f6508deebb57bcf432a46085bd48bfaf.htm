General System Concepts Process Summary

** Functionality **

 

 

 

Summary...

This topic introduces you to some basic concepts that not only help define your user experience, but also will help you configure SCALE with your warehouse.

 

 

 

Related Topics...

- Setup Overviews

 

 

 

The following are key features of the general system concepts functional area:

 

Warehouses...

A warehouse represents a shipping and storage destination. All transactions in the system are associated with a warehouse. You must define at least one warehouse in the system.

 

 

 

Multi-Company Processing...

SCALE supports multi-company distribution. This allows you to seamlessly manage all third-party-logistics distribution activities. Several SCALE entities can be associated with a specific company, such as item masters. To activate multi-company support, you will need to define two or more companies on the Company Window. Note that multi-company processing is not required to run the system. If you are not a third party distributor, do not define any values on the Company Window, and the system will not display the Company Field on any setup/processing window.

 

 

 

User Profiles...

A user profile identifies an employee to the system. You must have a user profile to access SCALE. The profile record contains such user-specific settings as preference defaults, passwords, and company access authorizations.

 

 

 

Window Security...

SCALE provides a flexible security system that you can apply to each window. All users by default have access to all windows and the ability to perform all actions. Therefore, if you are concerned about restricting access to the system, you will need to define user-level security in SCALE. .

 

Modifying system-level security per window limits all employees' ability to access and/or perform actions on a specific window. This is especially helpful if you want to ensure that critical records, such as status flows, are not deleted or changed. User-level security limits a specific employee's ability to access and/or perform actions on a certain window. This is especially helpful if your employees exclusively work in specific departments and should only access particular windows.

 

When the employee attempts to access a system window, the system will determine if he/she has any user-level security records:

  • If yes, the system will reference these user-level records each time the employee attempts to access a window.

     

  • If no, the system will reference the system-level security record.
Security Strategies

There are two general strategies you can use to set security:

  • Relaxed Security: This strategy allows all employees to access and perform all actions on every window. You can then restrict user permissions as needed. You can implement this strategy by creating a system-level record that allows permission to perform all actions on a window.

     

  • Highly-Restrictive: This strategy allows only select employees access to certain windows. You can then grant user permissions as needed. You can implement this strategy by creating user-level record(s) that allow the appropriate window permissions.

 

 

Interactive Desktop...

SCALE features a main menu design (called the Desktop) that not only allows you to access all the primary areas of the application, but you can also create custom link groups to important system windows. Also, you can import in mini application windows (called Gadgets), which allow you to interact with application data directly from the desktop.
