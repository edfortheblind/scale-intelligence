Searching a Wave...

You can use the Wave Insight Screen to search for wave records for the shipment(s) in your warehouse.

  1. Open the Wave Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter button. The system will display all information regarding the resulting records in the List Pane.

NOTE: You can select all the records from the first page of List Pane by checking the check box for selecting all records. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

Building a Wave...

You can use the Wave Insight Screen to build wave records for the shipment(s) in your warehouse.

  1. Open the Wave insight screen.

  2. Click on the Build action. The Build Wave screen opens.

  3. Specify the Warehouse and one or more Wave master(s) in the Build Wave screen and then click on the Build button. Only the authorized wave masters for the selected warehouse are displayed for selection. The system returns to the Wave Insight screen and displays a confirmation message stating that the build wave is successfully submitted.

Note: In some scenarios, the wave will cause bad data, when waved shipments are distributed to an existing shipment with allocate complete checked. In such scenarios, user needs to check shipment has allocation completion checked. This will ensure that no bad data is created on completion of wave.

 

 

 

About the List Pane...

The Wave Insight Screen's List Pane displays the results from a query performed in the Filter Pane. The List Pane's Grid Fields contains some hidden fields. You can find this complete list of fields by clicking on 'Select columns'.

About the Detail Pane...

  • The Wave Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

  • The indicator tiles of the Detail panes are: Planned Shipments, Waved Shipments, Lines, Containers, and Work Units. Between Planned and Waved Shipments tiles, only one will have a quantity greater than 0 at any given time.

  • For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

 

Screen Actions

The following actions are accessible from the List Pane and/or Detail Pane:

 

 

New

This action enables you to manually create a wave record from the Wave Insight screen. For more information on this topic, see the Creating a New Wave Record topic.

 

 

Edit/View

The Edit action is shown instead of the View action when you got the Edit security. The View action is displayed when you only have Display security for the screen.

 

 

Delete

This action allows you to delete any selected wave that has not been run. When you delete a wave, all the shipments are returned to the pool and can be assigned to a new wave.

 

 

Build

This action allows you to build wave(s) for a certain warehouse. During the wave building process, the system assigns pooled shipments to the appropriate wave(s).

 

 

Cancel

This action allows you to cancel any wave that has been run, as long as it has not been released. For more information on this topic, see the Canceling a Wave topic.

 

 

Reprint Labels

This action enables you to manually select the printers that the system will use to print wave paperwork (documents and/or labels). These printers will override the print devices that were previously configured in your document routing/document master configuration records. For more information on this topic, see the Manually Selecting Wave Printers/Reprinting Wave Paperwork topic.

 

 

Release

This action allows you to manually release it to the warehouse. When you release it, the work generated for this wave becomes available for processing. For more information on this topic, see the Processing a Wave topic.

 

 

Run

This action enables you to manually execute a run when the wave is manually created or operates in manual mode. For more general information on this topic, see the Processing a Wave topic.

 

 

Run (Select Printers) 

This action enables you to choose to reprint the labels, with the additional options of being able to select any label master or printer that you want to use after the completion of the wave. For more information on this topic, see the Manually Selecting Wave Printers/Reprinting Wave Paperwork topic.
