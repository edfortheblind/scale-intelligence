Using the Labor Monitoring Screen

You can use the Labor Monitoring screen to research and manage the estimated time data that the system calculated for certain labor group(s). In this screen, the graphs display the amount of open work for the various groupings in the chart. The chart indicates the estimated minutes of work by grouping as configured in the Estimated Work Rates configuration.

 

 

Notes
  • This topic discusses specific fields represented on this screen as it is shipped in the base SCALE product. If your screen has been customized, different field (s) may appear on your screen.

Navigating/Viewing the Labor Monitoring Bar Chart...

  1. Access the Labor Monitoring screen.

  2. The system will display a chart on the first (highest) level which indicates the estimated time broken down by labor groups. In each of the labor groups, the estimated time that will be displayed will be taken from the work instruction header.

  3. Press on a Labor Groups data column, and the system will display the next level of the chart, Work Types indicating the estimated time broken down by work type. If you navigate to Work Insight from the Labor group level, the system displays all the open and in process work units for the warehouse grouping by the work unit column in the list pane.

  4. Press on a Work Types data column, and the system will then display the next level of the chart, Users, indicating the estimated time broken down by unassigned users and the names of all the users who are assigned to that work type. If you navigate to Work Insight from the Work Type level, the system displays all the open and in process work for that labor group that has been clicked to come to the Work Type level.

  5. When drilling into each assigned user, the system redirects to the Work Insight screen displaying work assigned to that specific user. If you navigate to Work Insight from the Users level, the system displays all the open and in process work for the work type that is clicked to come to the Users level.

 

NOTES 
  • On any level of the chart, pressing the Insight button takes you to Work Insight with the work units selected that match that graph.

  • Changing warehouse at the top of the Labor Monitoring screen displays the open labor groups from the selected warehouse.

  • The estimated time is always displayed for open and in process work only.

 

 

 

Summary Data

The following summary data totals are accessible from the Labor Monitoring screen:

 

Total Estimated Time

This value indicates the total minutes for the work units being shown at that bar chart level.

 

 

Work Closed Last Hour

This value indicates the total work units completed or closed for that bar chart level.

 

 

Users Closing Work Last Hour

This value indicates the total number of users completing work units for that bar chart level.

 

 

 

 

Indicator Tiles

Indicator tiles display key warehouse data totals. Tapping on a tile will navigate you to the appropriate Insight screen loaded with the appropriate data. The following indicator tiles are shipped with the system:

 

 

Activities Done Last Hour

This tile represents the summation of the number of work units (activities) completed in the last hour. Pressing on this tile opens the Labor Activity Insight screen filtering by Date Time Field, Activity Type, and Warehouse.

 

 

Users Completing Activities Last Hour

This tile indicates the distinct number of users who complected labor activity in the last hour. Pressing on this tile opens the Labor Activity Insight screen filtering by From Activity Date Time Field, Username and Warehouse. Count of distinct user and labor records shown on the Insight screen can be different as one user might have performed more than one activity.

 

 

Work Units Closed Today

This tile represents the number of closed work units for today. Pressing on this tile opens the Work Insight screen filtering in the Basic Criteria by warehouse and filtering only closed work.
