Using Warehouse Mobile Menu Insight

 

You can use the Warehouse Mobile Insight screen to search and manage SRC screen flow files.

 

Related Topics

 

Field Descriptions

 

  • Menu option name - The name of the menu option is displayed.
  • Menu resource key - This used as translated resource key.
  • Form Id - This indicates the menu resource key associated with parent menu record that does not have an SRC assigned.
  • Sequence - The value which will be displayed as sequence in menu.
  • Object ID - The unique identify for the new record created by the system
  • Parent- The name of the parent menu option used for child submenu option.
  • SRC identifier- The name of the SRC associated to the menu option
  • Active- You can toggle to make the SRC menu option active or not in Warehouse Mobile
  • System created- This identifier indicates whether the menu option was system created or manually created.
  • Submenu name- The name of the submenu associated with this menu option.
  • Submenu resource key- The translated resource key.

Searching/Viewing Warehouse Mobile menu Records

 

You can use the Warehouse Mobile Menu Insight screen to search for and view SRC records.

  1. Navigate to Menu >> System Management >> Activity Architect. . Click Configure Menu to open the Warehouse Mobile Menu Insight screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search. Optionally you can use the Advanced Criteria to enhance the search criteria.

  3. Click Search and system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

About the List Pane

 

The list pane displays the list of menu records.

 

  • The Warehouse Mobile Menu Insight screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

Screen Actions...

The following actions are accessible from the Warehouse Mobile Menu Insight screen:

 

New

This action enables you to create a new warehouse mobile menu. Click New to create a new warehouse mobile menu. For more information on this topic, see Creating Warehouse Mobile menu.

 

Edit

This action allows edit the existing warehouse mobile menu record. Click Edit and view the warehouse mobile menu screen in edit mode. For more information on this topic, see Creating Warehouse Mobile menu.

 

Delete

This action allows you to delete single or multiple warehouse mobile menu records at a time.
