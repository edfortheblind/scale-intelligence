Using the Movement Class Insight Screen

You can use the Movement Class Insight Screen to research movement class data (per item/company/location/warehouse) for each unit of measure for that item combination. The screen automatically groups the results based on converted quantity unit of measure value. The system automatically calculates the converted quantity and displays that value along with the converted unit of measure movement class information. This allows the user to view picks in EA, CS, PL (or any other unit of measure they have configured). The data conversion occurs in real time when user runs the viewer query.

 

Note that the system will display a dark blue icon (displayed on the left side of the record row listing) for records that have an item location assignment configured.

Searching/Viewing Movement Class Analysis Records...

You can use the Movement Class Insight Screen to search for and view movement class analysis records in your warehouse.

  1. Open the Movement Class Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

The Movement Class Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

About the Detail Pane...

The Movement Class Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Movement Class Insight contains Indicator Tiles with counts of the other entities (i.e.locations). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Locations
    1. Displays the count of the number of locations where the selected item/company is present.

    2. Clicking on this tile takes you to Inventory Insight screen filtering on item, company, and warehouse.

For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

 

Screen Actions

The following actions are accessible from the List Pane:

 

Adjust

This action allows to perform an inventory adjustment to an item. Clicking on Adjust redirects to the Inventory Adjustment Screen and if any of the adjustment type is selected from the dropdown, system auto-populates some of the fields. For additional information on this topic, refer to Adjusting Inventory (Desktop and RF)

 

 

Transfer

This action allows you to perform an inventory transfer to an item. Clicking on Transfer redirects to the Inventory Transfer Screen and if any of the adjustment type is selected from the dropdown, system auto-populates some of the fields. For additional information on this topic, refer to Transferring Inventory (Desktop and RF).
