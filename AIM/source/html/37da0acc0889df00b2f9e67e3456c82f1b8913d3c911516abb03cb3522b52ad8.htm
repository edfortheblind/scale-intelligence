Generate Config File Checkbox

On the Scale Configurations window, when this checkbox is selected, instead of updating the user.config file on the application server with the scale communication information, the system generates a file called Scale weight service.exe.config that must be copied to the client machine where the weigh scale is connected. This file is generated on the application server C:\Program Files\Manhattan Associates\ILS\<release level>\Client\Scale weight service and needs to be copied to the client machine at C:\Program Files (X86)\Manhattan Associates\Scale weight service.

 

A message appears indicating the name and location of the file, and where it needs to be copied to. After copying the Scale weight service.exe.config file to the client machine's Program Files (x86)\Manhattan Associates\Scale weight service folder, the scale attached to the client machine communicates with the client machine, and the user can use it during Close container on that machine.

 

NOTE: After copying this to the client machine, the Scale weight service must be restarted on the client machine.
