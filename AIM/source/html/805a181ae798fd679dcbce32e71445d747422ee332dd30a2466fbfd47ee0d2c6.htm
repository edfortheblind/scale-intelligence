Insight Architect - Customize Insight Screen

Overview

Extensions of insight screens in applications enables user to shape their experience to their specific needs. This screen enables the user to create a custom version of the base screen in the application.

  • users can adjust the layout to better their workflow.

  • deactivate or delete these extend screens ensures that the application remains organized.

Customizing a Base Insight Screen

Create a custom screen from the base screen in the application. Follow the steps

  • Navigate to SCALE Extend>> Insight Architect to view the Customize Insight Screen.

  • Click Create New to select a base screen to customize.

  • Select the screen from the grid and click Create Custom.

    • Users can use the Is Customized? column to filter whether the selected base screen is customized or not.

When a base insight screen is customized, the system performs the following

  • A new custom insight screen with new form id is created.

  • This new custom screen is activated.

  • The existing base screen by default will be deactivated.

Edit a Custom Insight Screen

Follow the steps

  • Click View All, to list all the customized screens.

  • Select the custom screen and Click Edit.

  • The custom Form for the insight screen is displayed. You can modify the screen as required.

 

Activating/Deactivating a customized Insight screen

 

The Activate and Deactivate buttons enable users to activate and deactivate custom screens.

 

Activating a custom screen will automatically disable the corresponding base insight screen. For instance, the base Receipt Insight screen will be disabled if you activate a custom Receipt Insight screen. Similarly deactivating will function vice verse.

 

Delete a customized Insight Screen

Users can delete the custom screens from the application database.

 

When a customer screen is deleted, the system performs the following

  • The configuration records in the database related to the custom screen is deleted.

  • The related base insight screen is activated.

 

Publish a Customized Insight Screen

 

The customized insight screen can be published from the Stage to Production.

  • Click View All, to list all the customized screens.

  • Select the custom screen. Click Publish.

  • System will publish the custom screen to production.

Note: This is for Manhattan Active SCALE users only.
