SSRS File Name Record IDs field

The SSRS file name record ID is used in naming the SSRS pdf document. Printing with a configured record ID for the document type saves the SSRS document file name with the document type identifier, record ID based on document type, and GUID. So the SSRS document name will be saved in the format: <Document Type Identifier>_<Record ID>_<GUID>.pdf. If the record ID is not found, then the system will create the file name without it. The record ID used must be from the same table shipped with the document type. For example, the Allocation Pick List document type has ShipmentHeader.ShipmentId as the record ID. If you want to use a different column for the record ID, then you can choose another column from the Shipment Header table. This may require adding a record for the column to the SSRS File Name Record IDs configuration.

 

NOTE: 

 

1. Special characters (e.g., \ / : * " < > | ) that cannot be used as characters in file names will be removed from the record ID.

2. The record ID on the All Bills of Lading document type is shipped as blank. The All Bill of Ladings document type prints both the Master Bill of Lading and Bill of Ladings, and hence the record IDs from those documents are used when creating the file names.

 

3. All shipped record IDs are 25 characters or less. The record ID and file path length must be taken into consideration when adding a new record ID or setting a file path. A record ID that has too many characters could cause the file name to exceed the maximum file path length.
