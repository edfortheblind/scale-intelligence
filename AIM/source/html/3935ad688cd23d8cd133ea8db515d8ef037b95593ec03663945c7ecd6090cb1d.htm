Storage Template Configuration

Overview

 

Storage Template configuration defines the unit of measure hierarchy used to store inventory. You can create templates with ordered detail records that specify unit of measure values, treat-full percentages, and unitization grouping behavior for item storage.

 

Configure Storage Template

 

1. Storage Template

 

The Review Storage Templates screen displays existing records and allows record maintenance.

  • Review Storage Templates: View existing templates with Storage Template and Description columns.

  • Add New Storage Template: Create a new storage template record.

  • Edit/Delete: Update or remove the selected storage template record.

 

A. Information

 

Enter the core storage template details.

  • Storage Template: Enter the unique identifier for the storage template record.

  • Description: Enter a description for the storage template.

 

2. Details

 

The Details screen displays the ordered list of unit of measure detail records for this storage template.

  • Sequence: The order in which the detail record appears in the template hierarchy.

  • Unit of Measure: The unit of measure assigned to this detail level.

  • Treat Full %: The percentage at which the system considers this unit of measure level to be full.

  • Group During Unitization: Indicates whether inventory should be grouped during the unitization process at this level.

  • Add New Detail: Add a new detail record to the template.

  • Edit/Delete: Update or remove the selected detail record.

 

A. Detail Information

 

Define the properties for a storage template detail record.

  • Unit of Measure: Select the unit of measure for this detail level. This value is required.

  • Treat Full %: Enter the percentage threshold at which this unit of measure level is treated as full by the system.

  • Group During Unitization: Enable this option to group inventory of this unit of measure during unitization processing.

 

Use Back, Save, Continue, and Finish to manage and complete Storage Template configuration.
