Work Order Process Summary

** Functionality **

Process Flows

 

Summary...

Work Order processing manages the creation of finished items from component parts. All work order related information, such as components and instructions, can be stored on a bill of material record or manually entered when the work order is created. Component part allocation can be performed automatically when the work order is created or released. Employees can also manually allocate components. You can use work creation to support the movement of component parts to the build location and finished items to their storage locations. You can also choose not to use work creation and instead use paperwork to move items. Also, the system supports bill of material revision numbers. When you copy an existing bill of material record, the system assigns the new record a revision number. This allows you to support multiple versions of one finished item.

The following are key features of the work order functional area:

 

 

Component Part Allocation...

The system allows you to manage component part allocation based on your warehouse needs. You can set component parts to be allocated as soon as the work order is created. This is helpful if you need to reserve component parts in advance. If you prefer to allocate components after the work order is ready to be processed, you can set to allocate the components when the work order is released. Finally, you can choose to allocate component parts manually at some point after the work order is created.

 

 

 

Finished Item Breakdown...

The system supports the breakdown of finished items after they are constructed. This allows you to deassemble a finished item and introduce its component parts back as inventory. Inventory management moves the build components back to the build location, where you can either use them or transfer them back to their original storage locations.

 

 

 

Work Order Paperwork...

Work order documents can be printed manually from the Work Order Insight screen, or automatically during the work creation process. Below is a list of the documents available:

  • Work Order Pick List - This document identifies the component parts needed, their storage locations and the build location that they need to be delivered to. You can set the system to print this document as soon as the work order is released or you can print them when the components are allocated.

     

  • Work Order Instruction List - This document identifies the component parts needed and the instructions on how to assemble them. You can set the system to print this document as soon as the work order is released or you can print them when the components are allocated.

     

  • Work Order Finished Item Putaway List - This document provides putaway information for the finished item, including its putaway location. You can set the system to print this document as soon as the finished item is confirmed or you can print them manually later.

You can use these documents to manage the movement and assembly of components to the build location and the putaway of the finished item. These documents can be used with work creation, or in place of work creation.

 

 

 

Interface...

The system support the interfacing of work orders and bills of materials into the system.
