Or Checkbox

On the Action / Customize Viewers Window...

This checkbox determines if the system should display an action, color, or icon for a particular data record.

 

For example, suppose that you wanted to have the system color the data records of two companies red. You would need to set up two rules in your viewer color record:

  • Company = Company A [or checkbox selected]

  • Company = Company B

If you selected the Or Checkbox in the above example, the system will shade red either company's data record(s). If you did not select the Or Checkbox, the system would not shade any records, because there can be no data that is associated with both companies.

 

An example of not needing to check the Or Checkbox would be if you wanted the system to shade data record(s) that meet the following criteria:

  • Carrier = UPS
  • Carrier Service = Ground

Since the Or Checkbox is not selected, the system assumes that the criteria in both rules needs to be met before shading a record a certain color.
