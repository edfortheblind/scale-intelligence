Processing Work Orders

The Work Order Insight, Work Order Line Insight, and Work Order License Plate Insight Screens are used to manage work orders through the system. You can release, confirm, and close work orders, among other actions, from this screen.

Confirming a Work Order...

You will confirm a work order to identify the finished item as complete. At that time, this item is considered inventory in the warehouse. You cannot confirm a finished item when there is not enough component quantity at the build location. If this is attempted, the system will alert you of the situation. You will then need to perform some inventory adjustment(s) before you will be allowed to confirm the work order. You cannot delete a work order if a non-inventory item has been allocated. First, you must deallocate the non-inventory item, because non-inventory items are marked as on hand immediately upon allocation. Once this deallocation has occurred, you can then delete the work order.

 

Note: A new item/company/lot confirmed quantity will take on the inventory status that already exists. This happens when all the inventory is in single status. It is only if the lot exists in multiple inventory statuses or the lot does not exist at all that the inventory status gets assigned from work order preferences.

 

Access the Work Order Insight Screen:

  1. Access the work order that you want to confirm, and select the Confirm Action. The system will display the Work Order Confirmation screen.

     

  2. The system may provide a License Plate ID (based on the License Plate Assignment value selected on the Work Order Preferences screen). If this value is not provided, define a License Plate ID. The License Plate Screen prompts for a license plate when work order preferences has Create Work unchecked.

     

  3. Use the Quantity Field to identify how many finished item units you want to confirm.

  4. Use the Lot Field to indicate the lot ID that is associated with this work order's finished item. The system will inactivate this field if the finished item is not lot controlled.

    NOTE: Entering a new lot will display the Lot Screen to capture inventory status or freeze the lot. You can also change the lot and expiration date from this screen.

  5. Use the Expiration Date Field to indicate the expiration date that is associated with this work order's finished item. The system will inactivate this field if the finished item is not lot controlled. The Expiration Date is also disabled when an existing lot for the finished item is entered in the Lot field. The expiration date will be filled with the date for the existing lot. If the expiration date for an existing lot needs to be changed, then the user would need to use the Lot screen from the Lot insight to update the expiration date.

     

  6. Use the Putaway Location Field to identify the storage location for the finished item(s). If this item has previously been located to a storage location, the system will default that value in this field. For assistance in choosing a putaway location, press the Locate Button. The system will display the Locating Rule Selection Screen. Choose the locating rule that you want the system to use when calculating a location (the system displays the item's default locating rule, as defined on the Item screen), and press Locate. The system will run through the typical locating logic, and choose a location. The Putaway Location Field then will be populated with the newly-calculated location.

     

    NOTE: The Locating Rule Selection Screen also defaults the split quantity when the selected locating rule from the screen splits the quantity because the location can only fit part of the quantity being confirmed. For additional information, refer to the topic Locating Rule Selection Screen.

     

  7. Press Confirm. The system will:

    - Print the Work Order Finished Item Putaway List if the Generate Paperwork on Confirm Check box is selected on the Work Order Preferences screen.

    - Display the Work Order Serial Number Entry Screen if you are confirming the work order for a serial-tracked finished item. This screen allows you to indicate the serial number(s) for the components of this finished item or component. Press Save when finished entering these values. The system will confirm the work order.

    - Generate putaway work instructions if work is created for finished item putaway (based on work order preferences record).

 

 

 

Closing a Work Order...

You can close a work order or multiple work orders at any point in the work order process. .

  1. Open the Work Order Insight and access the work order that you want to close.

     

  2. Select the Close Action. The system will close the work order. You will not be able to complete any finished items on this work order.

 

 

 

Releasing a Work Order...

A work order cannot be processed until it is released. At that time, employees can assemble the finished item. You can manually release a work order in the Work Order Insight. You can choose to have the work order automatically released when it is created, or manually released when appropriate. The system can allocate component parts automatically when you either create a new work order or release an existing one. You can use the Work Order Allocation Method Field on the Work Order Values screen. You can also manually allocate component parts from the Component Parts Tab on the Work Order screen. Note that you can update the build location of a work order when the work order has not been released, and no components on the work order have been allocated.

  1. Access the Work Order Insight Screen.

     

  2. Access the work order that you want to release, and select the Release Action.

     

  3. The system will display a verification message. Verify that you want to release this work order. The system will release the work.

     

    • The system will allocate the component parts if you set Work Order Allocation Method to 'Release'.

       

    • If work was created for this finished item, it is removed from the hold status and can be executed.

       

    • The system will print the Work Order Component Pick List if the Generate Paperwork on Release Check box is selected on the Work Order Preferences screen.

 

 

 

Allocating/Deallocating a Work Order...

You can allocate or deallocate component(s) from a work order with Work Order Line Insight Screen. The system can perform these actions either per component or in a batch.

 

- Invoking the Allocate action will open the Work Order Component Allocation screen. You can select the allocation rule or enter the location from where the components needs to be allocated and tap on Allocate action. On allocating with both Allocation Rule and Location fields left blank, system will use the default allocation rule for allocation. Inventory is adjusted properly at both From and To locations on successful allocation.

 

NOTE: You can allocate work order line with and without work. System looks at the work order preference configuration to decide whether work needs to be created or not for the allocated quantity.

 

- Invoking the Deallocate action by selecting a line will deallocate the line. When the 'Allocated' flag is set to 'N', Inventory is adjusted properly at both From and To location on successful deallocation and system writes the deallocation history.

 

Refer to the topic Using the Work Order Line Insight Screen for additional information.

 

 

 

 

Allocating /Deallocating all Work Order Lines...

You can allocate all component lines of work order or deallocate all the work components with Work Order Insight Screen.

 

- Selecting a work order and invoking Allocate All action will allocate all the work order lines and if all the lines are allocated, 'Allocated' flag is set to 'Y'. Inventory is adjusted properly at both From and To location on successful allocation. If one or more lines fails to get allocated, a message is shown indicating that only partial allocation is successful.

 

NOTE: You can allocate a work order with and without work. System looks at the work order preference configuration to decide whether work needs to be created or not for the allocated quantity.

 

- Invoking the Deallocate All action by selecting a work order will deallocate all the work order lines. On deallocation, the 'Allocated' flag is set to 'N' on the deallocated work order lines, inventory is adjusted properly at both From and To location on successful deallocation, and the system writes deallocation history.

 

Refer to the topic Using the Work Order Insight Screen for additional information.
