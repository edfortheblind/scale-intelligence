Defining Wave Maximums

During the wave building process, the wave maximum record determines when a wave will stop accepting shipments. When the system stops accepting shipments, it generates a new wave and therefore continues accepting shipments. You will establish wave maximums on the Wave Maximums Window. Later, you will associate these maximums with the appropriate waves on the Wave Master Window.

Procedures...

  1. Identify this record in the Wave Maximum Field.

     

  2. Use the maximum fields to define how much product can be processed in a wave.
     

    • If you want to define one of the values with no maximums, leave the '0' value in the field.

       

    • If you define multiple values on this tab, the system will honor the first maximum it reaches during wave building process. For example, suppose two maximum values are defined: Maximum Shipments (100) and Maximum Weight (200 lbs). If the system reached either of these values during the wave building process, it would close the wave and start a new one.

     

  3. Press OK. The system will save the record.
