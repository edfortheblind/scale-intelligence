Using Inventory Attributes

You can add, edit, and/or delete inventory attributes from a location inventory record via the Inventory Insight Screen. After one of these actions is performed, the system will update the location inventory record, and generate a transaction history record documenting this change. If you want to read more general functional information about inventory attributes (including specifically where they are supported in SCALE), please see the topic Inventory Attributes - Introduction.

 

Pre-Defined Attribute Values

You can create your own pre-defined inventory attribute values that the user can select from on views/gadgets. See Creating Inventory Attribute Values for more details.

Adding Inventory Attributes...

  1. Access the Inventory Insight screen and select a record that does not already have attributes associated with it.

  2. Select the Edit Inventory Attributes action. The system will display the Inventory Attributes Screen in new mode.

  3. Use the Attribute 1-20 Fields to provide the new attribute value(s) that you are adding to this inventory. Note that the system requires that you save at least one attribute field value (you cannot add zero attribute values).

  4. Press Save. The system will add the attribute value(s) to the inventory.

 

 

 

Editing Inventory Attributes...

  1. Access the Inventory Insight screen and select a record.

  2. In the Actions menu, the Edit Attributes action will get enabled. Click on the Edit attributes action. The system will open the Inventory Attributes screen in a new tab in edit mode.

  3. Use the Attribute 1-20 Fields to change the attribute value(s).

  4. Prees Save. The system will save the location inventory with the updated attribute value(s). If no attributes exist yet for the record, they will be added.

 

 

 

Deleting Inventory Attributes...

  1. Access the Inventory Insight screen and search for a location inventory record which has an inventory attributes associated with it.

  2. Select that record.

  3. Click on the Delete attributes action.

  4. The system will ask you to confirm that you want to delete the attributes.

    - If you press Yes, the system will delete the link from the location inventory record and deletes the entire inventory attribute record from the database. A confirmation message appears that the record got deleted successfully.

    - If you press No, the system will not delete the attributes and will return to the Inventory Insight screen.
