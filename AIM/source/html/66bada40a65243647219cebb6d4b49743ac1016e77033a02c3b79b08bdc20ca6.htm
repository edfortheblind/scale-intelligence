Defining Location Selection Records

You will use location selection records, along with locating strategy records, to identify the characteristics that a location must have to be considered during locating. It also determines the order that the system will organize the eligible location.

Basic Procedures...

  1. Using the Filter Data Tab: You can use this tab to identify which locations should be considered for locating. If a strategy is defined on the locating rule detail, that system uses the strategy, along with the values defined on the filter data tab, to select locations eligible for locating.

  2. Using the Order By Tab: You can use this tab to organize these locations. After the locations are organized, the system selects the number required to process the order.

  3. When finished, press OK. The system will save your location selection record.

 

 

 

Locating Close to an Item's Permanent Location...

When locating, you can have the system attempt to find a location near an item’s permanent location. The location selection process creates a set of locations based on any property of the item’s permanent location, and then can be used in conjunction with any locating strategy. This can be facilitated by using the Permanent Location icon . This icon will appear next to the Value Field, only if the Location table was selected in the Table Name Field. When you press this icon, the system will display the <<PermLoc>> token in the Value Field.

 

For example, suppose your locations use an aisle/bay/level template, and an item’s permanent location is 001/05/01.You want to locate to an item’s permanent location in the bulk area first. If that area is full, then you would want to locate to an empty location that is in the same aisle and same bay as the permanent location. If there are no openings in the same aisle and bay, then you would want to locate to empty in the bulk location. The locating rule, then, would have three sequences:

  1. First, the system will try to locate to a permanent location (using the Item Location Assignment locating strategy), in a bulk location (using a location selection rule that selects from your bulk locations).

  2. If the system fails to find a suitable location: Then, the system will try to locate to an empty location near the item's permanent location. You would then use the Empty Location locating strategy, and set up a location selection record using the location template fields with the permanent location token as a value (see below). The system will use the token when processing the location selection criteria, and find the item’s permanent location with the same unit of measure:

              LOCATION.TEMPLATE_FIELD1 = N’<<PermLoc>>’
              AND LOCATION.TEMPLATE_FIELD2 = N’<<PermLoc>>’

    Also, you could specify a + (plus) or - (minus) value to locate one way either direction from a permanent location. Note that the system will ignore these + and - values if the location template is not numeric. For example, you could have the system try to locate one bay in either direction of your permanent location, assuming in the example below that you are using an aisle-bay-level location structure (with location template field 2 representing a bay):

              LOCATION.TEMPLATE_FIELD2 = N’<<PermLoc>>’+1
              AND LOCATION.TEMPLATE_FIELD2 = N’<<PermLoc>>’-1

  3. If the system fails to find a suitable location: Then, the system will try to locate to any empty location (using the Empty Location locating strategy), in a bulk location (using a location selection rule that selects from your bulk locations).
