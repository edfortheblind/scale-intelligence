Allocate All UMs to Clear Reserve Location Checkbox

This setting determines if the system will look for all the units of measure in an allocation location inventory record to "clean up" the location during the replenishment allocation process. Keep in mind that this allocation happens in the order of the highest unit of measure to the lowest unit of measure.

 

NOTE: This functionality is applicable only if the “Clear Location” (on the allocation rule detail) setting is active as well.

 

 

Example

Suppose you have the following:

  • Location A with 170 EA of Item A (units of measure are CS=50 EA, and PL=100 EA).

  • The replenishment increment is PL.

  • Both the “Clear Location” and “Allocate All UMs to Clear Reserve Location” settings are active.

The system will first allocate 1 PL (100 EA). and since the setting to clear all units of measure is active, the system will look for next unit of measure, and allocate 1 CS (50 EA), and finally 20 EA.

 

Note that if the “Allocate All UMs to Clear Reserve Location” setting had NOT been active in this example, then the allocation process would have failed because the system cannot “clear” the location.
