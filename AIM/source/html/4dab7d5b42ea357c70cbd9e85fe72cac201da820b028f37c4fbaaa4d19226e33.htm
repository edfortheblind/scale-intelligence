Creating Work Groups

A work group is a global category that describes one action required to move product through the warehouse. Common work groups could include receiving, picking, packing and shipping. Work groups are tied to work types. They allow you to group together work types that are subsets of one work group. For example, the work types order picking and batch picking could be subsets of the work group picking.
