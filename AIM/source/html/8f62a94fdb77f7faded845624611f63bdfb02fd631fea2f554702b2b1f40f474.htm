Using Warehouse Mobile - Shipping Container QC

The Warehouse Mobile- Shipping Container QC enables workers with hand held device to easily manually mark a shipping container for QC. Based on the Quality Control option selected in the Packing preference, the system can perform Shipping container QC in Grocery Store and Total Quantity modes.

 

 

Topics Discussed

  • Manually Mark a shipping container for QC

  • Perform Shipping container QC - Grocery Store mode

  • Perform Shipping container QC - Total Quantity mode

 

Manually Mark a shipping container for QC

Follow the steps to mark a shipping container QC

  1. Tap Shipping Container QC screen.
  2. Enter or scan the Container ID and Tap Go.
  3. System prompts user to mark the entered container for QC or not. Select Yes.
  4. Container is marked for QC successful message is displayed.

Perform Shipping container QC - Grocery Store mode.

Follow the steps to process the shipping container QC in Grocery Store mode.

 

Configuration Required

  • Select the Grocery Store option under Packing Preference >> Quality Control in User Profile configuration

Follow the steps

  1. Tap Shipping Container QC
  2. Enter or scan the Container IDand Tap Go
  3. Enter the item name in Item field and Tap Go. System will display a success message with Item name and quantity count value.
  4. Select Actions >> Complete. The system will validate if the item count matches with the system count. If yes, then QC successful message is displayed.

Perform Shipping container QC - Total Quantity mode.

Follow the steps to process the shipping container QC in Total Quantity mode.

 

Configuration Required

  • Select the Total Quantity option under Packing Preference >> Quality Control in User Profile configuration

Follow the steps

  1. Tap Shipping Container QC
  2. Enter or scan the Container IDand Tap Go
  3. Enter the item name in Item field and Tap Go. System will prompt user to enter the Item quantity count.
  4. Enter value in Quantity Field and Tap Go. System will display a success message with Item name and quantity count value.
  5. Select Actions >> Complete. The system will validate if the item count matches with the system count. If yes, then QC successful message is displayed.

 

Note:

  • If the count does not match, the system will display QC failed message and prompts user to rescan item when Actions >>Complete action is performed.
    • Tap Yes, and user can rescan the items to count.
    • Tap No, and system redirects to the Container ID entry screen.
