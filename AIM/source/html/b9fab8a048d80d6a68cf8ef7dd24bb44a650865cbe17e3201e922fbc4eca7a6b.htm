Warehouse Mobile Screen Flow

 

The Warehouse Mobile application uses the Screen Rendering File (SRC) file to display and control the screen user interface functionality.

 

Pre-requisites

 

The following needs to be done before we define the Warehouse Mobile Screen Flow.

 

SRC Files

The SRC files are shipped with the application. It is recommended to use these SRC file. Download and save the SRC file in the system. All SRC files are available in the screen flow folder of the application binary.

 

Define SRC file path

Navigate to Configurations>>Technical >> Technical Values. In the Technical Values page, select SRC File path (Key 440 ).

In the System Value text box enter the SRC File path stored in the system.

 

Configuration steps

Follow the steps to configure the work flow JSON file.

  • Navigate to Configurations >>Personalization/Extensibility >>Work Flow >>Warehouse Mobile Screen Flow
  • Add New configuration. Enter Identifier, Record type and Description.
  • select the Workflow file from the drop down list.
