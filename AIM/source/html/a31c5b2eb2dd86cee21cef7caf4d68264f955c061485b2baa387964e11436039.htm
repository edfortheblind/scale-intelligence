Starting the Interface

When you are ready to start an interface process, you have one more decision to consider: whether to run the interface process manually, or to have the system start it automatically at certain time(s) of the day. Below are discussions on the advantages of both options, and the procedures on how to use them.

 

 

Starting the Interface Automatically on a Regular Basis...

 

Warehouse Scenarios

Typically, most customers will want to schedule their interface to start it automatically during certain time(s) of the day. This accommodates the two most typical business flows:

  • Running the interface once at night: Suppose your ERP system sends down data throughout the day. You might then want to schedule the interface to start once at night when no one is working, so the interface job will not affect daily processing. When started, the SCALE interface will retrieve the new data, and place it into the database; therefore, when the workers arrive in the morning, there will be new data ready to be processed.
     
  • Running the interface several times during the day: Suppose your ERP system sends down data throughout the day. You might then want to schedule the interface to start several times during the work day (every two hours, for example). When started, the SCALE interface will retrieve the new data, and place it into the database; therefore, when the workers arrive in the morning, new data will be ready to be processed throughout the work day.

 

Procedures

To automatically interface data, you will need to set up a SCALE scheduled job to have the system start the interface at a certain time of day.

  1. Access the Scheduled Job Window. Follow the general procedures for creating a scheduled job.
     
  2. Additionally, you will need to enter special values on the Parameters Tab of the Scheduled Job Window:

    - Use the Area Field to indicate the interface functional area process that you want to run with this scheduled job. These values are represented by interface process records, which determine how data can be downloaded and/or uploaded between SCALE and the ERP.

    - Use the Direction Field to indicate if this scheduled job will be kicking off a system download, upload, or either direction (choose "all").

    - Use the Mode Field to indicate what method this scheduled job will use to interface data into the application: by delimited text file, directly from the interface tables, or via XML files. If this job will be used to interface in using several methods, choose "all."
     
  3. Press OK. The system will save your scheduled job.
     
  4. When the appropriate time arrives, the system will kick off the interface:

    - If the interface ran successfully, you should find your newly-interfaced data in the appropriate place in the system. For example, if you downloaded shipments, you could find them in the Planned Shipment Insight screen.

    - If the interface did not run successfully, you will need to research the problem. See the topic Troubleshooting the Interface for more details on this process.

 

 

Starting the Interface Manually...

 

Warehouse Scenarios

You can also choose to manually interface data between SCALE and your ERP if your business needs require. Reasons for needing to manually start the interface process include:

  • Variable work volume: You might choose to start the interface manually if your warehouse's actual work volume fluctuates from day-to-day, and/or you require that the interface is run several times a day (at non-scheduled times). A manually-run interface allows you to start the interface process at different times during the day when the work load is light and system performance will not be adversely affected by interface processing.

 

Procedures

To interface data between the two systems:

  1. Access the Interface Data Window.
     
  2. Use the Process Buttons to identify in which "direction" you want the system to interface data in:

    - To download data from the ERP, select the Download Button.

    - To upload data to the ERP, select the Upload Button.
     
  3. Use the Upload Output Buttons to identify what method the system should use to transmit the data (note that you will only be able to do this if you selected the Upload Button in Step 2). If you transmit using a text file, select "Delimited File." If you transmit directly to the database, select "Interface Tables." If you transmit using XML files, select "XML."
     
  4. Use the Functional Areas Field to define what type of data you want to interface.
     
  5. Press OK. The system will submit a request for the system to process any data file(s) that may exist.

    - If the interface ran successfully, you should find your newly-interfaced data in the appropriate place in SCALE. For example, if you downloaded shipments, you could find them in the Planned Shipment Insight screen.

    - If the interface did not run successfully, you will need to research the problem. See the topic Troubleshooting the Interface for more details on this process.
