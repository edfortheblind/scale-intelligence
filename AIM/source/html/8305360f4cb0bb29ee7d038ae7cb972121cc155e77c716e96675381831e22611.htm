Warehouse Mobile - Location Inquiry

The location inquiry enables you to search and view the location inventory records on warehouse mobile. This helps to validate the items actual quantity with that of the quantity physically present in a location. Also, you can access the adjust or transfer inventory actions from this screen.

Perform a search

The following details the steps you can use to search for inventory using this screen

  1. Log in to Warehouse Mobile application.
  2. Select the Location Inquiry option from the Warehouse Mobile Main Menu.
  3. Enter any combination of field characters for location, item and LP and tap Go. For example, suppose you have two LP's in your warehouse called "LP12345" and "123LP45". If you enter the value "LP" and search, the system will display the record for "LP12345" but not the record for "123LP45", because it assumes that the criteria you enter appears at the beginning of the value.
  4. The following field information is displayed.
    • Record - It displays the record number of the total records listed. For example, 5 of 1500.
    • Location and item name is displayed. Tap i to see the detailed information pop-up screen.
    • The status, On hand and Unit of measurement is displayed. The system will display all location inventory records for the current warehouse that have item quantities that are in any of the four statuses: On-Hand, In-Transit, Allocated and Suspense.
    • In case its serial number tracked item, then On Hand will have the information symbol. Tap to view all the serial numbers associated with the item.
  5. Tap Go to view the next record.
  6. Tap Actions >> Previous Record to view the record already viewed.
  7. Tap Actions >> Cancel to go back to the search screen.

Perform Inventory Management Action from Location Inquiry

Inventory transfer of adjustment and transfer can be performed in the following way.

  • Log in to Warehouse Mobile application.
  • Select the Location Inquiry option from the Warehouse Mobile Main Menu.
  • Enter search criteria value and tap Go.
  • All the records for the warehouse based on the item/location or License plate is displayed.
  • Adjustment
    • Tap Actions >> Adjust, to view the Select Adjustment class screen.
    • Tap on the Adjustment Type to view the Pop-up. Select the required option. For example Positive Adjustment and Tap Go

    • Enter the quantity that needs to be adjusted, and tap Go.

    • System will prompt to select the Inventory Status and then Tap Go
    • User Defined fields are highlighted for selection.
    • Tap Actions >> Done, to complete the adjustment for the inventory.
  • Status Change
    • Tap Actions >> Status Change, to view Select Adjustment class screen.
    • Tap on the Status Change to view the Pop-up. Select the required option and Tap Go.
    • Item and description details are displayed.
    • Select for All location Yes or No and Tap Go.
    • System will prompt for LP and Lot values if needed.
    • Tap Status field, and modify the status. Tap Go and inventory status change success message is displayed.
      • System prompts for Inventory Attributes for location (if configured).
      • Tap Go and inventory status change success message is displayed.
  • Transfer
    • Tap Actions >> Transfer, to view the Select Adjustment class screen.
    • Tap on the Adjustment Type to view the Transfer adjustment class. Select the required option. For example Transfer and Tap Go.
    • Enter the transfer quantity value and Tap Go.
    • Enter the To location value and Tap Go.
    • Select the Status to and Tap Go.
      • System prompts for Inventory Attributes for location (if configured).
    • Optionally enter User Defined fields if required.
    • Tap Actions >> Done. Inventory transfer successful message is displayed.

     

    Edit Attributes

    Edit attributes option is displayed only if the exit point ’WM Capture inventory attributes’ is turned on. If not then system will not show the Edit attributes option.

    • Tap Actions >> Edit Attributes to edit attributes for the location.

      • System will populate attributes value if already saved for the location.

    • You can add/edit Inventory Attributes 1-9.

    • Tap Actions >> Done to save the attributes.

Note:

  • When performing an adjustment for an item which is lot controlled and/or license plate tracked, the system will prompt for these values as well.

  • Transfer and Status change for location with inventory attributes cannot be performed from Warehouse Mobile >> Inventory Management screen. If you try to change the status, an error message is displayed.
