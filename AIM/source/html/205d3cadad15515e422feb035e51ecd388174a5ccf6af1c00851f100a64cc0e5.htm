System Built Cart Picking - Process

The system directed cart building process enables the application to assign containers created in a wave to a cart when the user initiates the work unit using Warehouse Mobile. This enables the system to include on carts containers that were created after the initial day’s wave(s) have been run. Also, the system tries to assign containers to the cart in an order (configured by zone) that will provide an optimum walking path when the worker picks products into the cart. This improves the picker(worker) efficiency by reducing the picking time against the manually assigned containers to the cart.

Configurations

System Build carts need the following configuration.

 

Work Profile >> Work Processing Tab

 

Work Initiation method - Select Cart Picking. The following two options are available for the selection

  • System-built carts - Select for the system to assign containers to a cart at the time of work initiation

  • Cart spots - Define the size of the cart. The value determines the number of spots present in the cart. One container per spot is allowed by the system.

Zone >> Cart Building tab

  • Zone sequence - This sequence value enables the system to optimize the walking order for various work zones in the warehouse for the picker. This improves the picking time and efficiency.

Using Warehouse Mobile - Work Execution

 

  1. Tap Work Execution to view the Select Work Profile screen.
  2. Select system build cart picking work profile from the menu.

  3. The system will analyze the eligible work units, and build the cart assigning a shipping container to each spot.

  4. The system will next display the Build Cart screen, which will display each spot and what container (ID, type) that is assigned to each cart spot. You then will physically build the cart before proceeding to the next screen.

    1. Cart Spot - Value of cart spot
    2. Container type - type of container is displayed
    3. Container ID - last four digits of the container is displayed.

  5. When you are finished placing the containers on your cart, tap Go, and the system will display the first work instruction in the Pick confirmation screen. You can then move with the cart to complete picking in the warehouse

Note:

  • If there are no eligible work units for system-built carts, the system will display the Build Cart screen with no spots assigned.

  • If you press the Back button on the Build Cart screen, the system will return to the Work Profile Selection screen. The cart that the system just built will stay built.

 

Criteria for System Cart Building

The application uses the following criteria to decide the work/containers that will be assigned to a cart during the work creation process.

 

1. Priority - The least numbered priority work units are allotted first. For example, priority with value 2 is processed first then with value 10.

 

2. Minimum and Maximum Work Zone - The work unit header record has the Minimum (lowest ) and Maximum (highest) zone sequence values. The system will take these zones the from locations of the instructions on the work unit.

 

Note:

  • The system will ignore the work units that does not have the Minimum/Maximum zone sequence configured.

  • If there is only one work instruction on a work unit, then the Minimum Work Zone and Maximum Work Zone values will be identical.

  • Zone sequence value is NULL on the work zone record, the system will ignore that zone when determining the Minimum/Maximum zone values.

3. Aging Date/Time

This value represents the date/time the work was created. The older the work unit is created; it is considered first for cart building assignment.
