Initiation Method (Workflow) Field

In the Receiving Preferences Window...

This field indicates the initiation workflow that you want the user to use during the RF receiving process. Included in each workflow are the separate activities that will occur during the pre-execution stage of RF receiving. Examples of these activities are the "initiation" field that the system will prompt for at the beginning of RF receiving (such as receipt ID, item, etc), whether QC inspection is active, or whether GS1 processing is to be used. See the SCALE SDK for more detailed information on how to use workflow with RF receiving.
