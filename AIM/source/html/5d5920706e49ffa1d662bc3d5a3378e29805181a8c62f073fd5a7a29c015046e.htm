Creating Packing Criteria Records

The system uses a packing criteria record determines which items the system will allow to be packed into the same shipping container. The system references this record during the wave's container creation process and also during the manual packing process. Using these records are helpful if you want to keep certain items from being packed with others that are going to a different destination. For example, if you are shipping to a distribution center that forwards items to a company's stores, users would not be allowed to pack items that are being shipped to different stores into the same container.

Procedures...

Access the Packing Criteria Window. Create a new record, and provide it a name and description. The Detail Records Tab lists all of the packing criteria detail records in sequence order. Double-click a record to open or create a new record. The system will open the Packing Criteria Detail Window:

 

Using the Header Fields
  1. Use the Packing Criteria Field to identify the name of the packing criteria record that this detail record is associated with.
     
  2. Use the Sequence Field to indicate the order in which the system will process through the packing criteria records.

 

Using the General Tab
  1. Use the Field Name Field to indicate the field value that a detail line must have for the system to pack it into a particular container. Note that only items whose shipment line values match ALL of the fields (as defined on the packing criteria record) will be packed together.

    For example, suppose that "Item Size" is a field defined on the packing criteria record. The detail line item being packed, however, has a different "Item Size" value than an item already in the container. The system, then, cannot pack this item into the container, because the "Item Size" values do not match up. The system will then need to look for another container to pack this item into.
     
  2. Use the Required Check box to indicate if the system will display a packing criteria-related warning message, or an error, during full-screen packing:

    - If this check box is selected, then users will not be allowed to pack items with differing values together.

    - If this check box is not selected, when the user attempts to pack these differing items, the system will display a warning message asking for confirmation to make sure they want to pack these items. Note that the container creation process and RF pick/pack functionality do not use the Required Field. All fields must match for the items to be packed together, regardless of the Required Checkbox's value.

  3. Press OK. The system will save the detail record.
