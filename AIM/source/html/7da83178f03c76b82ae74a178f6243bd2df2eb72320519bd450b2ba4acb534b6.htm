Associating Text Messages

You will use this window to associate an existing text message with an item/company or account/company: company is an optional, not required value. When the item/company or account/company is processed, the system will display the message on the RF and Warehouse Mobile devices. This is especially helpful when the account requires special handling for a specific item, such as additional labeling or handling. The actual text message must be defined on the Text Message Window before you can associate it with an item/company or account/company.

 

For example, if you want employees to insert a safety booklet into a company's item box, you can associate the text message "Insert Safety Message" with the company's item. When the employee picks the company's item, the system will display the message; it will not display the message when the employee picks an item associated with another company. The message is displayed on an RF and Warehouse Mobile devices or the Text Message Window (from the Work Insight Screen).

  2. Use the Account Field to associate a specific account with a text message. Each time someone processes a work instruction for this account, the system will display the message.
