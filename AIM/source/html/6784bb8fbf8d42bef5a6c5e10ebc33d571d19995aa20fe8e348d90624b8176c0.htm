Defining Wave Masters

A wave master record creates a wave template. This template manages the movement of specific shipments through the wave cycle.

Procedures...

Access the Wave Master Window. Name this record and provide a description.

 

Using the General Tab Fields

  1. Use the Wave Mode Button to determine how waves will be run for this record. If automatic is chosen, as soon at a wave is built, the system will run it. If you select automatic mode, determine if you want to exclude rejected shipments from being processed using this wave master record. To exclude rejected shipments, make sure that wave criteria record associated with this wave master includes the following criteria: the attribute 'rejection code' and the operand 'is null' (no value required).


  2. Use the Priority Field to identify when this wave will be executed in relation to other waves. The system initiates waves in priority order. The lower the priority, the sooner a wave is initiated. If a shipment is processed in a wave, the system will not process it again through a later wave.

  3. Use the Wave Criteria Field to select a wave filter. During the build wave, this value determines which shipments will be selected into this wave.

  4. Use the Wave Flow Field to select a wave flow. The wave flow determines what steps will be executed during the wave. The steps represent processes, such as carrier assignment.
     
  5. Use the Wave Maximums Field to select a wave maximums record. During the build wave, this value determines how much product will be processed in this wave. It allows you to manage work flow through the warehouse.


  6. Select the Auto Release Checkbox if you want to automatically release work to the warehouse. If you select this checkbox, the system will automatically release this work to the warehouse floor as soon as the run wave process is complete. If you don't select this checkbox, someone will need to manually release this work from the Wave Insight screen. You cannot cancel a wave that is released automatically.



  7. Use the Maintain Allocated Replenishments Upon Wave Cancellation Checkbox to determine if the system should "maintain" a replenishment request from the wave if it is canceled. If this checkbox is selected and the system leaves the replenishment, the system will remove the request from the wave (along with its corresponding work). Note that the only time a replenishment will stay out on the system is if some other process has allocated the inventory that is being replenished. In this case, the system will leave the replenishment out there so as not to cause problems with the subsequent activity that allocated it. The system also generates history records that indicate the replenishment request and work was left from the wave.



    8. For example:

    - Suppose you run Wave1 which creates a replenishment for 10 of an item, and Wave1 allocates 3 of those.

     

    - You then run Wave2, which allocates 5 of the same item from that same location

     

    - If you now cancel Wave1 the system will leave a replenishment for 10 out there so that it does not cause problems with Wave2.

     

Using the Selection Criteria Fields
  1. Use the Container Creation Criteria Field to define which items/shipments you want the system to create containers for during the wave. In other words, container creation criteria determines which allocation requests get assigned to which containers. These criteria records also can define the certain order in which the system will attempt to pack certain items.

  2. Use the Labor Plan Field to indicate the labor management data plan that you want to calculate estimated labor data for (when running waves using this master). A labor plan is a record that determines which labor group(s) to calculate values for in the wave, and in what sequence order to process them. Note that the labor plan execution wave step must be a part of your flow to use this value.

  3. Use the Pallet Building Master Field to define how the system will build pallets during waves that include the pallet building wave step. This master record determines such things as which shipping container(s) will be eligible to be placed on a new pallet, and which strategy the system will use to arrange the pallet's contents.

  4. Use the Pallet UM Conversion Criteria Field to indicate the filter record that you want the system to use when deciding which parent containers are eligible for the pallet UM conversion process. This process involves taking a full parent container (such as a pallet) and generating its associated containers, primarily for the purpose of printing vendor labels.

  5. Use the Picking Group Field to identify the picking group record that the system will run during the wave. If the wave flow includes the pick group creation step, this record determines where in the warehouse the picking group can be used and how many full or loose cases constitute a group.

  6. Use the Pro/BOL Number Criteria Field to indicate the filter record you want the system to use when deciding which shipments on a wave to assign pro/BOL numbers to. A Pro/BOL number is an identifier used by LTL carriers to uniquely identify a particular shipment.

  7. The Shipment Distribution Criteria Field is used by the Shipment Distribution wave step. This field represents the criteria record that indicates what shipments are eligible for the wave step's processing (creating new shipments for all details on the original order/distro header, with the ship to information coming from the detail's mark for).

  8. Use the Document Master Field to identify the document master record that the system will run during the wave. The document master determines which document types will print for particular wave records, such as work instructions. This menu is only available if paperwork is a step in the wave flow selected for this record.



  9. Use the Label Master Field to associate a label master to this wave master. A label master record manages the process of printing the labels from a wave. The following labels are governed by these records: shipping labels, vendor labels, and container contents labels.

  10. Press OK. The system will save your record.

 

Using the Replenishment Masters Fields
  1. Use the Replenishment Masters checkboxes to indicate which master(s) you want to run during the replenishment wave step. Note that this tab is only active when you have the replenishment wave step in your wave flow.

 

Using the Warehouse Access fields
  1. Use the tab to assign wave masters to warehouses. Note that when creating a wave or building a wave then only the wave masters for the selected warehouse will be available.
