Nesting Containers Onto Multiple Order Pallets (RF)

You can use this screen to nest shipping containers onto multiple order pallets. A multiple order pallet is a single shipping pallet that has different shipments (for different ship to addresses) placed on it. Also, you may remove container(s) from a multiple order pallet using this screen. Note that the only places in the application where you can view multiple order pallets is in the Multiple Order Pallet Insight Screen.

Nesting a Container Onto a Multiple Order Pallet (RF)...

 

Log onto the RF device. Access the Multiple Order Pallet Nesting RF Screen.

  1. Enter the ID of the container you want to nest.

  2. Enter the ID of the multiple order pallet that you want to nest the container onto. Whether the new multiple order pallet ID is manually or system generated is based on the user's Container Assignment Method setting in packing preferences.

    - If this multiple order pallet does not yet exist in the system, you can create it by nesting the first container onto it (as there is no other way to create a multiple order pallet in the system). The system will generate a UCC-128 ID for the multiple order pallet.

  3. Press the Nest Button. The system will nest the container onto the multiple order pallet. You can continue to nest containers, or exit the screen by pressing the Cancel button.
Nesting Validations

The system performs the following validations when it determines whether a container can be nesting onto a multiple order pallet:

  • The “from” shipping container must be at the same dock location as the shipping container(s) already nested on the multiple order pallet.

  • A new multiple pallet ID must be unique in the system; it cannot be a currently-existing shipping container or multiple order pallet.

  • A shipping container must be the “top-level” container to be eligible for nesting onto a multiple order pallet. Child shipping containers are NOT eligible for nesting.

  • A shipping container must have a status greater than In Packing and less than or equal to Ship Confirm Pending to be eligible for nesting.

  • A shipping container cannot be assigned to different carrier from the container(s) on the multiple order pallet.

  • A shipping container cannot be assigned to a load different from the container(s) on the multiple order pallet.

  • A shipping container cannot be assigned when the shipment(s) on the multiple order pallet are assigned to a closed shipping load.

  • As a result of the nesting action, the system will not change the manifest state on any of the shipping container(s) that are being nested or are already nested on the multiple order pallet.

  • A shipping container cannot already be assigned to a multiple order pallet.

  • A shipping container cannot be nested onto the multiple order pallet if its wave has not been released.

  • A shipping container cannot be nested onto the multiple order pallet if it has pending shipment work.

  • A shipping container cannot be nested onto the multiple order pallet if it has pending or active dock management work.

 

 

 

Removing a Container From a Multiple Order Pallet (RF)...

 

Log onto the RF device. Access the Multiple Order Pallet Nesting RF Screen.

  1. Enter the ID of the container you want to remove from the multiple order pallet.

  2. Enter the ID of the multiple order pallet that you want to remove the container from.

  3. Press the Remove Button. The system will remove the container from the multiple order pallet. You can continue to remove containers, or exit the screen by pressing the Cancel button.
Removal From Nesting Validations

The system performs the following validations when it determines whether a container can be removed from a multiple order pallet:

  • A shipping container must be the “top-level” container to be eligible for removing from a multiple order pallet. Child shipping containers are NOT eligible to remove from nesting.

  • A shipping container must have a status greater than In Packing and less than or equal to Ship Confirm Pending to be eligible to remove from nesting.

  • As a result of the remove from nesting action, the system will not change the manifest state on any of the shipping container(s) that are being removed or are still already nested on the multiple order pallet.
