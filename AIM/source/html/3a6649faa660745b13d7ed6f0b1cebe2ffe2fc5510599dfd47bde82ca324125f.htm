Value Key

 

Value Description

 

10

 

Check Variable Trade Item?: This value indicates if you want the system to check if the GTIN (01 or 02) is variable trade item.

  • You would set this value to Yes (the system default) when using 14 digit item cross references.

  • You would set this value to No when using less than 14 digit item cross references (e.g. 13, 12, or 8).
