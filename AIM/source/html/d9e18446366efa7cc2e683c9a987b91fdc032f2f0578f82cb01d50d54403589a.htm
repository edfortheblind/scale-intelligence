Notes on Printing with SQL Server Reporting Services

The following are some things to take into consideration when using SQL Server Reporting Services for printing:

 

 

Installation Notes...

  • Please see the installation guides regarding certified print drivers.

  • Please see the installation guides regarding necessary Windows operating system updates.

 

Functional Notes...

  • The following are the statuses for SSRS printing requests:

    - Ready = Waiting to be printed.

    - In Process = In printing.

    - Closed = Printing completed.

    - Error = An exception has occurred (such as timeout).

    - Note that these statuses indicate when a print request has been sent to the spooler. Once a request is in the print spooler, it is up to the printer to generate the physical printed document.

  • Print requests are placed in a "Ready" state, which means they are waiting to be picked up and sent to the PDF reader for printing.

  • When a print request is picked up for printing, it is marked with an "In Process" state, and the "process start date time" value is recorded.

  • When a print request is consumed by the PDF reader within the specified allowable time, then it is marked with a state of "Closed" and the "process end date time" value is recorded.

  • When a print request is not consumed by the PDF reader within the specified allowable time, then it is marked with a state of "Error" and the "process end date time" value is recorded.

  • Note that "Closed" does not mean that a record printed successfully, but that it was sent to the PDF Reader successfully.

  • The following are the date/time definitions for SSRS printing requests:

    - Render time – The time it took to render the document.

    - Inserted date time – When the print request was inserted into the database.

    - Process start date time – The time when the record was picked up and sent to the PDF reader print application.

    - Process end date time – The time when the record was finished being consumed by the PDF reader print application.
