Adding a Shipment to a Wave

If you manually create a wave, you must manually add shipments to it. You can also manually add shipments to existing waves. You can add or transfer a shipment to a wave if the wave is neither closed nor released.

Adding a Shipment to a Wave...

  1. Access the Planned Shipment Insight screen.

  2. Select a shipment that is in the pool.

  3. Open the Actions menu and tap on Add shipment to wave or Transfer to another wave. This opens the Add Shipment to Wave screen.

    NOTE: If you select the Transfer to another wave action, the Add Shipment to Wave screen opens with the list of existing waves and an option to transfer to a new wave. This action is enabled only when the leading and trailing status of the shipment is 'Wave Pending' and the shipment is on a wave.

  4. You can assign this record to either a new or existing wave.

    - To assign this shipment to a new wave, select the New Wave Button. The system will display the New Wave Window. Select this new wave record and press Save. The system will navigate back to the Planned Shipment Insight screen after displaying a success message indicating that the shipment(s) were successfully added to the wave. The wave that you have added will be highlighted; the system will generate a wave number for it.

    - To assign this shipment to an existing wave, select the appropriate record from the Existing Wave Field and press Save.

     

    This will add shipments selected from the Planned Shipment Insight to the wave.

     

 

 

 

Adding All Filtered Shipment(s) to a Wave...

  1. Access the Planned Shipment Insight screen.

  2. Select a shipment that is in the pool.

  3. Open the Actions menu and tap on Add all filtered shipments to wave. This opens the Add Shipment to Wave screen. The system will add all the shipments that are returned out of search criteria.

  4. You can assign this record to either a new or existing wave.

    - To assign this shipment to a new wave, select the New Wave Button. The system will display the New Wave Window. Select this new wave record and press Save. The system will navigate back to the Planned Shipment Insight screen after displaying a success message indicating that the shipment(s) were successfully added to the wave. The wave that you have added will be highlighted.

    - To assign this shipment to an existing wave, select the appropriate record from the Existing Wave Field and press Save.

     

    This will add shipments selected from the Planned Shipment Insight to the wave.
