Creating/Processing a Shipping Load

A shipping load represents all of the shipments assigned to a particular carrier on a particular date. You can manually create a shipping load on the Shipping Load Insight screen. Also, you can have the system automatically create shipping loads during the wave process.

Creating a Shipping Load...

 

Shipping Load Info Accordion

- You can use these fields to define various values that the system will use to process this load.

 

Dates Accordion

- You can use these fields to define this load's planned/actual ship or departure dates.

 

Status Accordion

- You can use these fields to view the leading and trailing statuses of this load.

 

Consolidator Accordion

- You can use these fields to indicate the place where the shipping load will delivered to, in lieu of its final destination (a.k.a. the "consolidator"). The consolidator then would organize the particular shipments of a load according to where they are to be delivered. The system references the information on this tab only when generating a "consolidator" master bill of lading.

 

Totals Accordion

- You can use these fields to view current summary and unit of measure data about this load.

 

Reference Info Accordion

- You can use these fields to view user/process/warehouse information.

 

When finished...

- Press Save. The system will add this new shipping load. Its leading and trailing status are determined by the status associated with the Add From Shipping Status Action.

 

 

 

Confirming a Shipping Load...

When you confirm a shipping load, the system will attempt to confirm any open shipments. You cannot confirm a shipment if it has not been released from its wave. If a load contains both released and unreleased shipments, the system will ship confirm the released shipments, if the released shipments are in the correct status. However, neither the load nor the unreleased shipments will be confirmed. The unreleased shipments will have to be transferred to an alternate load, or removed from the load altogether. In the Shipping Load Insight screen, a load that has failed confirmation will be represented by a red icon.

  1. Access either the Shipping Load Insight screen.

     

  2. Access the load that you want to confirm, and select the Confirm action. Before the system can confirm a load, each shipment on that load must be confirmed. To achieve this, the system will review the detail lines on a shipment and attempt to either confirm them or split them off to a new shipment. Once the detail lines are confirmed, the system will attempt to confirm the entire shipment.

    Confirming the Detail Lines...

    • If a shipment's detail lines are all in the leading shipping status, the system will attempt to confirm the entire shipment.

       

    • If a shipment's detail lines are within the shipping status range, you can either attempt to confirm the entire shipment, split it, or move it to a different load. Exactly what the system will do depends on the split shipment setting on your shipping preferences record. You can configure your preferences to either display the split options for you to choose from, or to have the system perform the split action (after confirming with the user that this is ok).

    • Note that as part of the load confirm process, the system will execute any pending work associated with the shipments on the load.

    • If at least one of the shipment's detail lines is not in the shipping status range, the system will let you split the shipment. You can confirm all lines within this range.

      The system will not allow you to confirm a detail line that is not in the shipping status range.

      If you decide to split the shipment, you can confirm all of the detail lines within the shipping status range or only those lines in the leading status range.

      a. If you decide to confirm all of the detail lines within the range, all of these lines will remain with the original shipment. The system will attempt to confirm this shipment. All detail lines below the range the system will be associated with a new shipment, which cannot be confirmed.

      b. If you decide to confirm only the lines in the leading shipping status, only those lines will remain with the original shipment. The system will attempt to confirm this shipment. All detail lines below the leading shipping status will be associated with a new shipment, which cannot be confirmed.

      If you decide to NOT split the shipment, the system will not confirm any of the detail lines. The entire shipment will remain open.

     

    Confirming the Shipment...

    After the detail lines are confirmed or split, the system will attempt to confirm the shipment. At this point, the system references the shipment information, such as postal code and carrier information. As long as this information is correct, the shipment is confirmed as its detail lines are already confirmed. If for some reason this information is incorrect (bad postal code, carrier does not deliver to postal code, etc), the system will not confirm the shipment and the entire load will fail confirmation. The system will display an error message identifying why the shipment failed confirmation. You will need to either rectify the problem or remove the shipment from the load. Upon shipping load confirmation, the system will remanifest any containers that are not manifested for today's date and not on a closed manifest. The system will either remanifest the containers for today's date (the true shipping date), or split them into another shipment (if chosen).


    Pending VAS Activities Note...
    There is a setting in packing preferences that allows you to configure if the system will allow the user to ignore a container's pending VAS activities if they exist at the time of load confirmation. See the Allow VAS Override At Close Container and Load Confirm Checkbox topic for more information.

    Pending/Failed QC Inspection Note...
    If a container has pending or failed QC inspection associated with it at the time of load confirmation, then the system will prompt the user indicating that they cannot confirm the load until the QC is performed/resolved.

    "ERROR" Container Note...
    If you attempt to confirm a shipment that has containers of an ERROR container type, then the system will move any of these ERROR containers (if they are in the appropriate status), to a new shipment (assuming that you have your shipping preferences configured to split shipments), and the ship confirmation action will succeed. However, if these ERROR containers are not in a status to be split, then they will stay on the shipment, and the ship confirmation action will fail.

    Serial Number Items Note...
    If a shipment has serial number tracked items that are not packed, the entire shipment will be transferred to a new load, i.e., the shipment will not be split. Also, if the "Transfer Failed Shipments" setting on shipping preferences is not active, then the system will display an error message at load confirm in this case.

  3. The system will complete this step for each open shipment on the load. Assuming that all shipments passed confirmation, the system will attempt to confirm the load.

     

  4. After the load is confirmed, the system will complete the following tasks, based on your system configurations: generate Bill of Lading, perform final rating, define Actual Ship Date and Time.

 

 

 

Print Processing a Shipping Load...

When you enable Auto Printing At Load Confirm option in your shipping preferences, the system will automatically print any/all documents and the document types should have either the Shipment or Load print procedure checked as the "default" value.

 

The "Default" value set for All Bills of Lading option when using the Print Selected Documents functions as below

  • When the Bill of lading type on the shipping load is None, then system will prints just the bills of lading for all of the shipments on the load.
  • When the Bill of lading type on the shipping load is Consolidator or Multi stop truck load, then system will print the Master bill of lading for the load as well as all bills of lading for the shipments on the load.

 

Deleting a Shipping Load...

You may need to delete a shipping load to accommodate unforeseen circumstances, such as a carrier strike. Before deleting a load, you need to transfer its shipments to a different shipping load. You cannot delete a shipping load tied to shipments. Before attempting to delete a load, move its shipments to a different shipping load.

  1. Access the Shipping Load Insight screen.

     

  2. Access the load that you want to delete, and select the Delete action.

     

  3. The system will display a confirmation window. Verify that you want to delete this shipping load.

     

  4. Press OK. The system will delete the shipping load.

 

 

 

Removing a Shipment From a Load...

If you want to remove a shipment from a load, and not assign it to a new load, complete the procedures below.

  1. Access the Shipment Insight screen.

  2. Access the shipment(s) that you want to remove from a load, and select the Transfer action. The system will display the Transfer Shipment screen. Information about the shipment and its current load (the load you are transferring from) are provided.

    • Type '0' in the Destination Load Field.

    • Press OK. The system will remove the shipment from the load.
     

    Alternatively, select Remove from Load action from the Shipment Insight screen. You can click Yes to the displayed confirmation message and the selected shipment(s) will be removed from their assigned shipping load.

 

 

Editing a Shipping Load...

You can edit and save the shipping load details using the Edit action of Shipping Load Insight screen. The edit action of Shipping Load Insight or the hyperlink in the internal load number column of the list pane of Shipping Load Insight can be used to edit and save the shipping load details. The system will redirect to the shipping load details screen on clicking the Edit action of the Shipping Load Insight screen.

 

 

 

Closing Out a Shipping Load...

When you close a shipping load, additional shipments cannot be added to it. It will only include those shipments previously assigned. This is especially helpful when it is critical that new shipments are not added on the dock floor.

  1. Access the Shipping Load Insight screen.

     

  2. Access the load that you want to close, and select the Close Out Shipping Load Action.

     

  3. If the load can be closed, the system will display a confirmation window. Press OK to close the load. The system will display the message 'Update was successful'.

NOTE: The Close action is used for closing of shipping load using the Shipping Load Insight screen.

 

 

Assigning/Transferring a Shipment To a Load...

You can transfer any non-confirmed shipment(s) to a new load unless the load is closed. When you perform this action, the system will transfer all selected shipment(s) to the same load. When transferring multiple shipments, if any shipment's carrier differs from the destination load's carrier, you will need to choose a new carrier service. The selected service will be applied to all shipments that have a carrier different from the load's carrier. If the new load is associated with a different carrier and/or service, the system will remove any accessorials that applied to the first carrier/service, but not to the new one.

  1. Access the Shipment Insight screen. 

  2. Access the shipments that you want to transfer to a different load. You can transfer single, multiple, or all filtered shipments.

    • The Transfer Shipment action will transfer only the visible shipments selected on the list pane to the load.

    • The Transfer All Filtered Shipments to a Load action transfers all the shipments to a load based on the shipments that match the Shipment insight filter criteria.

  3. The system will display the Transfer Shipment screen. Information about the shipment(s) and its current load (the load you are transferring from) are provided. If you are assigning these shipment(s) to its first load, the system will not display load data.

  4. Define the load that you want to transfer this shipment to in the Destination Load Field.

    • If this is an existing load, you can use the Lookup Search to find a particular load. 

    • If this is a new load:

      • When accessed from the Transfer Shipment Transaction screen, click on the Add button. System redirects the user to the Shipping Load screen which opens in a new tab. Define the new load and the system will create the new load number. The user needs to copy the shipping load number and paste the same in the destination load section of the Transfer Shipment screen.


  5. Press OK. The system will transfer the shipment. Any transferred containers that were manifested on the original load will be remanifested using this load's data. If necessary, you can re-route and re-rate both loads.

 

 

Unassigning a Load from a Dock Door...

The only place you can unassign a load from a dock door is on the Shipping Load screen. When you unassign the load, the system will unassign the In Transit shipping container(s) for the shipment from the dock door. Note that if the shipment includes container(s) that are On Hand at the dock door, the system will not allow the unassign action.

  1. Open a shipping load from the Shipping Load screen.

  2. Clear out the value in the Dock Door Field.

  3. Press Save. The system will unassign this load from its current dock door.
