Using Warehouse Mobile - Shipping Container Nesting

The Warehouse Mobile shipping container nesting enables workers with the mobile device to pack one small (child) container into another large (parent) container. This is used for orders that have prepacked cases and few loose items. Using nesting the case can be packed into a large container that also has the loose items.

When you performs nesting, the system associates the nested container ID and its items with the container that you have nested into.

Using this screen, shipping container can also be removed from pallets.

Note: Containers on shipment can only be nested. will be done for containers. Also, the container types available for nesting can be authorized by company and warehouse. See the Defining Container Types for more details.

Nest Container screen

 

Enables user to nest containers on the shipping dock in the warehouse.

 

  1. Tap Shipping Container Nesting to view the Select Nesting Type screen.

  2. Tap Nest.

  3. Enter or scan the Container ID and Tap Go.
  4. The entered Container ID is displayed as From Container. Click information to view the details of the container.
  5. Enter the To Container to nest. Tap Go.
  6. In case its a new container created, select the Container Type from the list.
  7. Tap Go to complete nesting the containers.

Nesting Containers Onto Multiple Order Pallets

 

User can nest shipping containers onto multiple order pallets. A multiple order pallet is a single shipping pallet that has different shipments (for different ship to addresses) placed on it. Also, you may remove container(s) from a multiple order pallet using this screen.

 

Remove Shipping Container screen

 

The Remove Shipping Container screen prompts for a Container ID. The Warehouse Mobile screen is titled Shipping Container Remove Nesting and uses the Container ID field to start the remove flow.

If you enter a nested container, the system removes a single container from the pallet. If you enter a parent container, the system prompts you to confirm whether to remove all nested containers from the pallet.

 

Remove a single container from a pallet

 

Use this flow when you want to remove one nested shipping container from a pallet.

 

  1. Select Remove from the Select Nesting Type screen.
  2. Enter or scan the nested container in the Container ID field.
  3. Confirm the removal when prompted.
  4. The system removes the container from the pallet.
  5. The system notifies the user that the container was successfully removed from the pallet.

 

Remove all containers from a pallet

 

Use this flow when you want to remove all nested shipping containers from a parent pallet.

 

  1. Select Remove from the Select Nesting Type screen.
  2. Enter or scan the parent container in the Container ID field.
  3. When the confirmation prompt appears, select Yes to remove all nested containers from the pallet.
  4. Select No to return to the Container ID screen without removing containers.

Notes

  • A new system created container or manually added container nesting will be done based on the packing reference configuration
  • The container type listed will be based on the configuration in the company and user authorization.
  • When nesting is done to an existing container, system will not prompt container type selection.
  • Nesting cannot be done for a container in different location.
  • When a wave is not in Released state, then nesting will fail.
  • Asynchronous validation is enabled, and system displays appropriate error message.
