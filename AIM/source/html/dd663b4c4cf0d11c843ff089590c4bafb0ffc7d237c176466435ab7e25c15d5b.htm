UCC/EAN Number Field

** To read more about EPC generation, see the topic How an EPC is Generated **

 

** To read more about UCC Codes, see the topic UCC Code Field **

 

The UCC/EAN identifier assigned to this shipping entity (company or warehouse). If the system generates container IDs during packing, the UCC/EAN number occupies up to positions 4 - 10 of the ID. Note that three flex positions exist for codes that are greater than 7 characters. In addition, if a vendor compliant label is produced for a container linked to this number and it includes a UCC-128 barcode, the UCC/EAN number occupies positions 4 - 10 of the barcode.
