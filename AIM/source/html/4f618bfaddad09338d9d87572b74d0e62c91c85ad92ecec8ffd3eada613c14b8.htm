Reconciling Cycle Counts (Insight Screen & RF)

Reconciling is the process that occurs after a count of a location has been performed, when someone (usually a supervisor) indicates to the system that the system's count of a location's item quantity was indeed incorrect, and what the correct item quantity actually is. For example, suppose the system says that there are 10 eaches of an item in a particular location. When executing a cycle count, however, the worker counts 14 eaches. A supervisor then would need to "reconcile" the new item quantity that is currently present in the location. You can reconcile cycle counts via an RF device or from the Cycle Count Request Insight screen.

Note About Reconciling at a Location Where Inventory Has Been Added...

When someone has added an item to a location during a cycle count, that item quantity is put into pending review status, if the quantity is outside of tolerances (for either a single or a multi item location), or it is a single item location associated with another item (such as another item on hand/in transit, or it is another item's permanent location). If there is another item associated with the location at which you are attempting to reconcile quantity, then you will not be allowed to reconcile from the Cycle Count Request Insight. Instead, you will need to use the Inventory Adjustment screen to adjust out the old item quantity from the location. Then you can return to the Cycle Count Request Insight to reconcile the new item's quantity.

 

See the topic Confirming Cycle Counts for more information on adding items during cycle counting.

 

 

 

 

Procedures: Reconciling from the Cycle Count Request Insight Screen...

  1. Access the Cycle Count Request Insight Screen.

  2. Select a cycle count request and click on the Reconcile Action. The Cycle Count Reconcile screen opens.

    1. The action is enabled for the cycle count requests which are in 'pending review' status.

    2. The action is also enabled for cycle count requests with 'open' status only if the cycle count request is created without work.

    3. Canceling the screen without making any changes will close the screen without any changes to location inventory as well as cycle count request.

    4. Canceling the screen after some modifications will show a message indicating that there is an uncommitted data and seek confirmation from the user and on confirmation the screen is cancelled without any modifications to any of the data.

  3. Enter the reconcile quantity and submit the request for reconciliation. This will update the location inventory and writes the transaction history for the adjustment that has happened.

 

NOTES:

  • The reconciling will prompt for serial number entry when the item has been set up to track serial numbers in inventory.

  • An existing serial number can be selected by entering the serial number into the text box and pressing the Add/Select button or checking the serial number in the grid.

  • A new serial number can be added by entering the serial number into the text box and pressing the Add/Select button.

 

 

 

Procedures: Reconciling Using an RF Device...

  1. Log on to your RF Device.
     
  2. Choose the "Cycle Count Reconcile" function from the RF Main Menu screen. The system will display the Cycle Count Reconciliation screen.
     
  3. Narrow down the reconcile requests that the system will display by entering values for the fields on the Cycle Count Reconciliation screen. For example, if you enter a value in the Item Field, the system will display any reconcile requests that exist for this particular item. Or, you can simply press the OK Button, and the system will display a request to reconcilate.
     
    NOTE: If the location tracks license plates, the system will have you enter or verify the License Plate ID during the reconciliation process.
     
  4. Press OK. The system will display all applicable reconcile requests, ordered in location sequence. If you want more detailed information about a request, press the Details Button.
     
  5. Review the item quantity information as needed (you can press the Details button for further information):

    - Use the Quantity Counted Field to view the item quantity that the user entered when performing the original cycle count.

    - Use the On Hand Quantity Field to indicate the item quantity (and its unit of measure) that is currently present at the location.

    - The location quantity values on the Details page reflect the quantities that are present in the location at the time of the reconcile, NOT at the time that the cycle count was performed.
     
  6. Press OK. The system will reconcile that location, and display the next request (if one exists). Note that you can press the Cancel Button to skip any request that the system displays. Skipped requests will remain in the "Pending Review" status.

    SERIAL NUMBER NOTE: If the item being reconciled is serial number tracked, the system will ask you to enter these values as well. Press OK when finished.
