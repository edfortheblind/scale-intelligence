Performing Rate Shopping

Rate shopping allows you to view potential carriers and their rate charges before assigning a carrier to a shipment. Unlike routing, rate shopping is an interactive process that is initiated by the user per shipment.  You can also rate shop against several criteria (customer address fields, carrier designation, total weight/volume, etc.) before an actual shipment is created. This allows you to give a customer the best delivery option even before an order is placed.

 

Note that the data sent to Progistics uses the theoretical volume and weight values (defined on the rating profile) when calculating the rates of shipments that have not yet been created. These values are defined on a carrier's rating profile. If the shipment exists and there are containers attached to the shipment, the system passes the actual container data to Progistics.  If no containers exist, then the system calculates theoretical containers based on the weight and volume from the rating profile. See the topic Identifying Rating Profiles for more information on theoretical containers.

 

The SCALE internal LTL rating uses the actual shipping container weight and LTL class values when calculating the rate of the shipment. Once you analyze the results of your rate search, you can assign a new carrier to your shipment, or choose to keep the existing carrier. Note that you can rate shop any shipment in any status (except shipments that are in an "in process" wave or have been ship confirmed). SCALE uses a web service to calculate the rates and display them on the Rate Shopping screen.

 

 

Rate Shopping Notes
  • You can only rate shop for carriers that SCALE currently supports. The system will only consider carriers that have system calculated rates (as defined on the Carrier Window). Carriers with manually-assigned rates or no rates are not included in rate shopping. 
     
  • LTL Rating is performed internally by the SCALE system.
 
Hundredweight Processing

Hundredweight is the rate to be charged per hundred pounds shipped. This provides a discount for shipments going to the same destination postal code based upon weight. Typically a discount is given to these shipments. If a shipment qualifies for hundredweight processing, the charges on the shipment will not reflect the hundredweight charge until the manifest is actually closed. This is to insure that the shipment qualifies for hundredweight. Therefore, the SCALE system does not update the shipment with the freight charge until after the manifest is closed. However, when rate shopping, the hundredweight freight charge will be displayed.

  • The Rate Shopping screen features two tabs: the Criteria Tab and the Results Tab.

  • Criteria: This tab allows the user to provide parameters for a rate search, (either carrier/address data for a potential shipment, or a shipment ID for an existing shipment). Note that any value changes made on this tab will not impact existing shipment data (except carrier data if you press the Assign Carrier Button). Also, keep in mind that some fields on this tab are required for some carriers, but are not for others. In general, the following fields are required for a rate search: Warehouse, Ship To Address 1, Ship To City, Ship To State, Ship To Postal Code, Ship To Country, Freight Terms, Total Weight, and Total Volume.
     
  • Results: This tab displays the eligible carriers, rate charges, and delivery days that the system returned based on your search criteria.

Procedures...

  1. Access the Rate Shopping screen.
     
  2. Use the Shipment ID Field to indicate the shipment for which you want to research rates. Note that this field is not mandatory; you can perform a general rate search that is not tied to a specific shipment by leaving this field blank.
     
  3. The Customer/Ship To and Address Fields indicate this shipment's destination.
     
  4. The Company and Warehouse Fields should match what was on the original shipment.
     
  5. Use the Carrier Information Fields to indicate which carrier you want to use to deliver this shipment, and how it will be delivered.
     
  6. The Unit of Measure Fields indicate the total weight and volume of the shipment.
     
  7. Perform the Search. The system will search for eligible carrier(s) and their appropriate rates, and display the information on the Results Tab. The carrier that has the cheapest rate will be displayed at the top of the grid, and any carriers that had errors during rating will be displayed at the bottom. Note that if the "days to deliver" value is a zero, then it was not defined; or, the carrier did not have a carrier commitments record.

    Press the Assign Carrier Button if you want to assign a new carrier/rate to this shipment.
