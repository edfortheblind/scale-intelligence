Creating a Shipping Load...

 

You can use the Add action in Shipping Load Insight to create a shipping load. When this action is invoked, the system will open to the Shipping Load Screen in new mode. The Shipping Load screen has the following sections:

 

Shipping Load Info

- You can use these fields to define various values that the system will use to process a load.

 

Dates

- You can use these fields to define a load's planned/actual ship or departure dates.

 

Status

- You can use these fields to view the leading and trailing statuses of a load.

 

Consolidator

- You can use these fields to indicate the place where the shipping load will delivered to, in lieu of its final destination (that is the "consolidator"). The consolidator then would organize the particular shipments of a load according to where they are to be delivered. The system references the information on this tab only when generating a "consolidator" master bill of lading.

 

Totals

- You can use these fields to view current summary and unit of measure data about a load.

 

Reference Info

- You can use this section to view some additional information on a load.

 

After the mandatory fields are specified and saved, system displays a success message stating that the shipping load is created and the screen automatically gets refreshed to display the shipping load number that got generated.

 

 

Invoke Shipping Load Insight from Shipment Insight...

If you want to invoke the Shipping Load Insight from the Shipment Insight, complete the following procedures:

  • Select the hyperlink on the Shipping Load column of the list pane of the Shipment Insight

    OR

  • Select the hyperlink from the Load number of the load section of the detail pane of Shipment Insight.

 

About the List Pane...

The Shipping Load Insight Screen's list pane displays the results from a query performed in the filter pane.

List Pane Icon Explanation

Certain conditions for the shipping load are represented by graphical icons on the list pane. Below are explanations of what each icon represents:


Icon Explanation

Shipping load has failed confirmation.

Shipping load is in the process of being confirmed.


For more general information about the list pane, see the topic Introduction to Insight Screens.

 

 

About the Detail Pane...

  • The Shipping Load Insight Screen's detail pane displays select field values associated with a selected record in the list pane.



  • The detail pane of the Shipping Load Insight contains Indicator Tiles which displays values relating to the information displayed in the list pane. If you press on those tiles, it will take you to the appropriate screen showing the selected data. Below are the indicator tiles displayed on the Shipping Load Insight:

    1. Shipments

      1. Displays the number of shipments on the load.

      2. Pressing on this tile takes you to Shipment Insight web screen filtering on the given load number.

    2. Lines

      1. Displays total number of shipment line records on the load.

      2. Pressing on this tile takes you to Shipment Line Insight filtering on the given load number.

    3. Containers
      1. Displays the total number of "parent" shipping containers on the load.

      2. Pressing on this tile takes you to Shipping Container Insight filtering on the given load number.


  • For more general information about the detail pane, see the topic Introduction to Insight Screens.

 

 

Screen Actions...

The following actions are accessible from the list pane:

 

New

This action enables you to manually create a new shipping load from the Shipping Load Insight screen.

 

Edit

This action allows you to change field values on the shipping load. When this action is selected, the system will open the Shipment Load Screen in edit mode.

 

Delete

This action allows you to delete a shipping load or multiple loads. Before deleting a load, you need to transfer its shipments to a different shipping load. You cannot delete a shipping load tied to shipments.

 

Close

This action enables you to close a shipping load or multiple loads. This is especially helpful when it is critical that new shipments are not added on the dock floor. When you close a shipping load, additional shipments cannot be added to it. It will only include those shipments previously assigned.

 

Confirm

This action enables you to confirm a shipping load. The system allows one or more loads to be confirmed at a time. You cannot confirm a shipment if it has not been released from its wave. If a load contains both released and unreleased shipments, the system will ship confirm the released shipments, if the released shipments are in the correct status. However, neither the load nor the unreleased shipments will be confirmed. The unreleased shipments will have to be transferred to an alternate load, or removed from the load altogether. For more information on confirming shipments, see the topic Creating/Processing a Shipping Load.

 

Print Preview

This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to Printing Paperwork.

 

Print Default Docs

This action allows you to print the default shipping load documents that have both the print procedure for "load" setting and the default setting selected on the document’s document type record.

 

Print Selected Docs

This action allows you to print all the selected documents.

 

Sign BOL

This action enables shipper and carrier to digitally sign Bills of Lading document. For more information, read Sign BOL.
