CUPS Printer Integration

Users can now integrate CUPS with the Manhattan Active SCALE application for printing documents and labels. CUPS is an open-source printing system that allows you to configure a system as a printer server. Customers can maintain their own CUPS printer servers and physical printers at their location and connect them to the SCALE application for printing purposes.

 

This integration allows customers to have control over the printers accessible to the SCALE application and manage their printing requirements independently.

 

The process of integration is as follows

 

1. Set up CUPS Printer Servers and Physical Printers

Customers have the option to install and maintain their own CUPS printer servers and physical printers. CUPS enables clients to configure and manage print queues, turning their systems into printer servers.

 

2. Integration with SCALE Application

Customers can connect their CUPS printer servers and physical printers to the SCALE application using the configuration steps given below. This integration allows users of the SCALE application to print documents and labels using the configured printers.

 

Configuration steps

  • IPP (Internet Printing Protocol) of Printer: The IPP of the printer needs to be copied from the CUPS server. This IPP will be used to identify and connect to the printer.

  • Creating a New Printer Device in SCALE

     

    • Go to Printer Devices in the configuration.

    • Choose the option to Create New printer device.

    • Provide a Qualified Device Name which should be the IPP of the printer configured on the CUPS server. This information helps the SCALE application identify and connect to the printer.

Notes

  • The printer setup, CUPS server configuration, and printer network connectivity are separate from the SCALE application.

  • Customers are responsible for managing and maintaining their printer infrastructure, which is then connected to the SCALE application for printing.
