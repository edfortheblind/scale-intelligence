User Profile Configuration

Overview

The User profiles are created for all associates using the application to be identified by the system. The system references the user profile to determine how an associate will perform tasks (such as packing, shipping, receiving, etc).

 

Configuration Hierarchy

 

 

Configure User Profile

 

1. User Profile Information

  • The Username and Email Address must be unique for each user.

  • The Default Warehouse represents the user's primary working location.

    • When the user logs into the application, this warehouse is automatically selected.

  • Assign a Supervisor to the user during profile creation.

 

2. Security Information

Configure the user security group and its Vocollect password.

 

3. Payroll Information

The payroll ID, wage rate, and hiring date are defined for the user.

 

4. Receiving Preference

The default receiving preference will be what is selected when opening the Receipt Workbench or Warehouse Mobile Receiving. The user can be authorized to one to many receiving preferences. The receiving preferences found under the Receiving Preferences Field will only be those that have been authorized for the user. Read Receiving Preference.

 
4. Packing Preference

A packing preference record allows you to manage how a user or group of users will pack shipments. These actions are primarily done in the Packing Screen or the Close Container Screen. Read Packing Preference.

 

5. Shipping Preference

A shipping preference record allows you to manage how a user or group of users will ship confirm orders. The default shipping preference record should accommodate the majority of employees. Create specific preference records for employees with unique processing needs. Read Shipping Preference

 

6. Cycle Count Preference

This preference record will determine whether activity-driven cycle count requests should be executed immediately or created as pending requests. Read Cycle Count Preference

 

7. Work Order Preferences

This preference record will determine how a user or group of users will process work orders. The default preference record should accommodate the majority of associates. Read Work Order Preference.

 

8. Printer

The default printer on the user profile overrides the document routing printer configured for the document type. Selecting a printer when printing selected documents will override the default printer. It will also override printers assigned to the workstations.

 

9. System Values

Configure the Desktop template, SCALE Theme, RF Style sheet and Excel export directory for the user.

 

10. Default Work Profile

Configure the work profile that the user will use during work processing.
