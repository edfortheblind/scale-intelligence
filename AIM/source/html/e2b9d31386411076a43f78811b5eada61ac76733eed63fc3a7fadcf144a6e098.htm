Commitments Required For Routing Checkbox

This checkbox identifies how the system will make a carrier decision during routing, when a particular carrier is part of a carrier group. The following is based on when a carrier commitment record does not exist for a certain carrier:  

  • If this checkbox is checked, commitments are required for this carrier. Therefore, the system will reject this carrier because no commitment record exists.

     
  • If this checkbox is not checked, that indicates that commitments are not required for this carrier. Therefore, the system will not reject the carrier. However, a large number of days to deliver is used (999), which makes it almost impossible for that carrier to "win" the selection process and be assigned to the shipment.
