Shipper Code

A shipper code identifies the entity responsible for shipping a product. Progistics/FSMS requires this code to generate a container manifest for each shipper.

 

Single-Company Processing:

  • If your system does not support multi-company processing, create one shipper per warehouse postal code. If multiple warehouses share a postal code, they can use the same shipper code.

Multi-Company Processing:

  • If your system does support multi-company processing, determine which companies require their own manifests. Assign a unique shipper code to each of those companies. Link all other companies to a warehouse-level shipper code. Their shipments will be included in the warehouse’s manifest.

Create a shipper code record.

  • Shipper Code - Used to identify this shipper to Progistics/FSMS. It must begin with an alpha character, but it can contain both alpha and numeric characters. It cannot contain symbols or spaces. All characters must be upper-case: MANHATTAN, etc. Also, provide a description in the Description Field.

  • Contact Name - Used to identify the contact for this shipper code. This represents the person who can be contacted if shipping concerns arise for the warehouse/company associated with this shipper code.

  • Phone Number - Enter contact's phone number.

  • Employer ID/Tax Number - Provide the employer ID number/tax number for this particular shipper code contact.

  • Haz Mat Phone Number- Used to provide the phone number of the person who needs to be called if there is an emergency dealing with hazardous materials.

 

FedEx Values

  • Meter Number - Identify a unique shipping location for a FedEx account. For example, if a company has warehouses in three different locations (i.e. three shippers), then FedEx would provide them with three different meter numbers.

  • Sign Release Auth Number Indicate the signature release authorization number that is on file with FedEx. This value releases the FedEx courier from requiring a signature upon package delivery.
