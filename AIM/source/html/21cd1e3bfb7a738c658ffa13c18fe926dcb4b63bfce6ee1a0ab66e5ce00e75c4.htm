Searching/Viewing Replenishment Request Records...

You can use the Replenishment Insight Screen to search for and view replenishment request records in your warehouse.

  1. Open the Replenishment Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

The Replenishment Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

List Pane Icon Explanation

Certain conditions for the replenishment requests are represented by graphical icons on the list pane. Below are explanations of what each icon represents:

 

Icon Explanation

Replenishment request does not have work created.

Replenishment request has been marked for work creation.



For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Replenishment Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Replenishment Insight contains Indicator Tiles with counts of the other entities (i.e. open work, and transactions). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Open Work

    1. Clicking on this tile takes you to Work Insight filtering on the warehouse, internal replenishment request number, and internal number type.

    2. The internal number type will be Replenishment.

  2. Transactions

    1. Displays the transaction history of the replenishment.

    2. Clicking on this tile takes you to Transaction History Insight filtering on the warehouse, internal replenishment request number, and transaction type. In Transaction History Insight, the internal replenishment request number gets populated in the reference Id field of Transaction history insight.

    3. The transaction type will be Replenishment allocation.


For more general information about the Detail Pane, see the topic Introduction to Insight Screens.



 

Screen Actions

The following actions are accessible from the List Pane and/or Detail Pane:

 

View/Edit

The Edit action is shown instead of the View action when you got the Edit security.

 

 

Create Work Immediately

This action allows you to create a work for replenishment requests that are waiting in queue from replenishment insight. The action is enabled for the replenishment requests which has work created marked as 'No'. Selecting the replenishment request(s) for which work is not created and invoking the action will send the request to work creation process.

 

 

Mark for Work Creation

This action allows you to mark replenishment requests for work creation. The action is enabled for the replenishment requests which has 'Work Created' and 'Marked for work creation' marked as 'No'. Selecting the replenishment request(s) which are not marked for work creation and invoking the action will label the request for work creation.
