Add and Delete Exit points (WebAPI)

 

Exit points can be added and deleted for WebAPI category only. These WebAPI exit points are primarily used for Warehouse Mobile application.

 

Add Exit Point
  • Access the Exit Point Control window. Click Actions >>Add Exit Point.
  • In the Exit Point Create new window
  • Select the actions from the drop-down list. The options for selection are get, post and put.
  • Under Execute section, select Before or After
    • Before -Will call the exit point before the API action
    • After - Will call the exit point after the API action
  • Click OK.
Delete Exit Point
  • Access the Exit Point Control window. Click Actions >>Delete Exit Point.
  • The Exit Point - Delete window is displayed.
  • Select the Exit Point from the drop-down list.
  • Click OK.
