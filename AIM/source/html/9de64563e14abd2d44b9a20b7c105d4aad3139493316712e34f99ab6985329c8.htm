Using the Document Routing Viewer

You can use the viewer to edit, copy, and delete multiple document routing records. From the Configuration Explorer window you can edit, copy, or delete a single record. The Document Routing Viewer allows the selection of multiple records to perform the same actions. You can also select multiple records with different document types and customize the document routing viewer from the Actions menu.

Searching Document Routing Records...

You can use the Document Routing Viewer to perform searches for document routing records.

 

  • Enter the criteria that you want to use to define your search.

  • Press Search. The system will display the resulting records from your search in the Results Tab.

 

 

 

Editing Single Document Routing Record...

You can edit a single record from the Configuration Explorer as well as from the Document Routing Viewer Window. This is helpful when the data on a record does not reflect the desired details.

  • Double-click to open the specific record under Document Routing window from the Configuration Explorer. The Routing criteria tab is opened by default.


  • Modify the existing record and click OK.

Alternatively, you can also open the Document Routing Viewer Window and search for the record you want to modify. Under the Results tab, the record will be displayed. You can right-click on that specific record and press Edit.

 

 

 

Editing Multiple Document Routing Records...

You can edit multiple records from the Document Routing Viewer Window.

 

  • Select multiple records from the Document Routing Viewer Window.


  • Right-click and press Edit.

This opens the Document routing window with fields and the corresponding check-boxes. This checkboxes will be enabled based on the document type being edited.

 

NOTE: If multiple document types have been selected, then only the username, warehouse, number of copies, machine name, and device name are editable. All fields will be disabled until the user checks one of the enabled checkboxes. So the field can be edited only after the checkbox is enabled. If multiple records have been selected and there are multiple values for a field, then the field will show multiple. These fields can also be updated to a single value.

 

 

 

Deleting Single Document Routing Record...

You can delete a single record from the Configuration Explorer as well as from the Document Routing Viewer Window. Right-click on the selected record and press Delete to delete the specific record.

 

 

 

Deleting Multiple Document Routing Records...

You can delete multiple records from the Document Routing Viewer Window.

  • Select multiple records from the Document Routing Viewer Window.


  • Right-click and press Delete.

This opens a confirmation window. Click Yes if you confirm the delete action.

 

 

Copying Single Document Routing Record...

You can copy a single record from the Configuration Explorer as well as from the Document Routing Viewer Window. Right-click on the selected record and press Copy to copy the specific record. This opens the Document Routing - Create New dialog box in the copy mode. If the document routing records get successfully updated, you will receive a confirmation message.

 

 

 

Copying Multiple Document Routing Records...

You can copy multiple records from the Document Routing Viewer Window.

  • Select multiple records from the Document Routing Viewer Window.


  • Right-click and press Copy.

This opens the Document Routing - Create New dialog box in the copy mode. Multiple is shown for all the fields with multiple document routing records. You will be prompted to continue with the copy action after selecting multiple records from the Document Routing Viewer and clicking OK in the Document Routing - Create New dialog box. The message also will display the number of records being copied. If you continue and the document routing records get successfully created, you will receive a confirmation message.

 

NOTE: The system will automatically Refresh document routing records in the viewer after the completion of edit/deletion/copy action.
