Escalating Work Record Priority

You will use work priority escalation records to define what work records (header and detail) are eligible for priority updating by the work priority escalation scheduled job. When this scheduled job is started, it first goes to the database and determines which records are eligible for updating. Next, the system will update these records' priorities.

 

Having work record priority updated (post-creation) is helpful when you want to make sure that certain shipment's work is prioritized over others.

 

Configuring this work escalation priority process has two steps: defining the eligibility criteria and defining the time interval/parameters of the escalation scheduled job. For more details on the work priority escalation scheduled job, see the topic Creating a Scheduled Job.

 

Note that running this scheduled job is optional.

Below are the procedural steps for configuring the eligibility criteria and scheduled job settings for work escalation priority:

 

 

Step 1: Define the Criteria For Eligibility...

  1. Using the Filter Data Tab: You can use this tab to identify which criteria values the system will use to choose the work instructions/units that will be eligible for priority escalation. For example, suppose that filter value defined on the criteria rule is a work type of Shipment Work, and your warehouse has three work types configured in the system (Shipment Work, Receiving Work, and Work Order Work). When the priority escalation job runs, the system would then bring back all records (work instructions/units) with a work type of Shipment Work.
     
  2. When finished, press OK. The system will save your work priority selection criteria record.

 

Step 2: Define Scheduled Job Interval/Parameters...

  1. On the Scheduled Job Window's Scheduling Tab, you will first need to define the interval at which the work escalation priority job will run. See the topic Creating a Scheduled Job for more details on this procedure.



  2. On the Scheduled Job Window's Parameters Tab, you will next need to define the specific job settings for the work escalation priority job. See the topic Creating a Scheduled Job for more details on this procedure.
