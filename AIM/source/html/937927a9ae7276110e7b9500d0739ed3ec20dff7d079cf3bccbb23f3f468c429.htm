Labor Data Consolidation Process

The data consolidation process explains how the system gathers and organizes labor records. It also covers the available setup options and how the process works behind the scenes to help track employee activities and reporting.

What is consolidated?

Labor data is consolidated based on the following key attributes:

  • User Name

  • Activity

  • Warehouse

  • Shift

  • Warehouse Day

  • Handling Unit of Measure (UM)

  • Labor Group

  • Work Group

The system identifies all related records and creates a summarized entry for each activity group:

  • Start and end times: Identify the first and last task recorded.

  • Activity counts increase if the same activity is performed multiple times.

  • Quantities are added only if the unit of measure is consistent.

  • Gaps and breaks are excluded from this grouping and reported as separate entries.

 

Consolidation Process

The system runs a Scheduled Job at configured intervals to perform consolidation as shown below.

  • Identifies eligible labor records.

  • Groups and processes them in batches.

  • Continues processing until all records are consolidated or a system-defined limit is reached.

Note: Any records not processed in the current cycle are picked up in the next Scheduled Job run.

 

Example:

Assume there are 8,000 labor records pending consolidation

  • The system is configured to process a maximum of 5,000 records per job.

  • These 5,000 records are divided into 5 batches of 1,000 records each, based on the batch limit.

  • Once the 5 batches are processed, the job reaches its maximum record limit and stops.

  • The remaining 3,000 records will be processed in the next scheduled job run(s).
