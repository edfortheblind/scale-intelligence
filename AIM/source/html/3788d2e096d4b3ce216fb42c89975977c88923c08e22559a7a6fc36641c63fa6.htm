Reviewing Internal Status Names (Inbound & Outbound)

You can use these windows to determine the names associated with inbound or outbound system-defined statuses. These values are provided with the system for all system defined statuses, such as check in pending, in putaway, in wave, etc.

Procedures...

  1. Access the appropriate internal status name window. Open the appropriate record.

  2. Review the value in the Description Field. If necessary, you can change the value in the Description Field.

  3. Press OK. The system will save your changes.
