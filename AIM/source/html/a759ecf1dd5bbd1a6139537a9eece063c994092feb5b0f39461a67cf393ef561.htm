Defining Default Inbound Quality Control Inventory Status

This setting indicates the inventory status that the system will assign to a receipt's item quantity when it is due to enter inbound quality control.

 

 

Procedures...

  1. Access the Receiving System Values Window and open the "Inventory Status for Quantity Needing QC" record.

  2. Use the System Value Field to indicate the appropriate inventory status.
     
  3. Press OK. The system will save your changes.
