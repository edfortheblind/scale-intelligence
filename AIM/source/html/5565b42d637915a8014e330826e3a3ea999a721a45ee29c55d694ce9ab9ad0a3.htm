Reviewing Labor Types

When labor management records are generated, the system captures a "labor type" value for each warehouse action performed. These are associated with the work on the Work Type Window.

Default Labor Types...

  • Automatic Direct Labor: This describes an activity that was performed in the system (both full screen and RF). The system will automatically log labor if an automatic direct labor event is associated with a work type. Note that there are some areas (such as immediate dock transfer or container nesting) that do not have this work type association, but the system will log labor anyway.

  • Approved Direct Labor: This describes an activity that provides direct value to the warehouse, but is not performed directly in the system. For example, consider the physical building of a work order. This process is not performed by using system resources; however, this action is necessary for delivering product to the customer.

  • Approved Indirect Labor: This describes a basic maintenance activity that is required for the business to operate, but does not directly impact the customer. For example, these include such duties as cleaning the warehouse, building pallets, and meetings.

  • Unapproved Indirect Labor: This describes an activity that does not directly benefit business operation. For example, this could include such things as informal breaks, fire drills, or personal phone calls. Note that even if an unapproved indirect labor event is associated with a work type, the system will not automatically log labor for this event.
