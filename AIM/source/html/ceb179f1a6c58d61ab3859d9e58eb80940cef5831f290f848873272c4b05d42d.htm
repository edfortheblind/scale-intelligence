Work Pick List

The work pick list is a general term for two documents: a Batch Pick List and an Order Pick List:

  • Batch Pick List: This represents a list of work instructions for multiple orders. Generally, a batch pick groups together multiple details requesting either the same item or the same location. It identifies what item(s) to pick, where to pick, and how much to pick for all shipments requiring an item be picked from a location. You can manually generate a batch pick list in the Work Insight Screen.

This document tells a picker what to pick, where to pick it from, and how much to pick. You can manually generate an order pick list in the Work Insight Screen.
