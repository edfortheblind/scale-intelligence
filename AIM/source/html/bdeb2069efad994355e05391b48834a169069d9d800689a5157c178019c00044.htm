GS1-AI Label

A GS1-AI label contains two or more "smart" barcodes (which include such data as item/item cross reference, container ID, quantity, lot, etc.). These barcodes meet internationally accepted standards that are set by the GS1 standards association. Each barcode is comprised of one or more segments (called application identifiers), that define the data that the barcode represents.

 

NOTE: These labels use ZPL code and SCALE stored procedures to retrieve data. Any changes to these labels or stored procedures could be lost when performing an upgrade or applying a service pack. It is recommended that you create their own stored procedures and labels when customizing.

 

There are three generic GS1-AI shipping labels that are shipped with the system:

  • Generic shipping label with Item Cross Reference (02), Quantity (37), and License Plate ID (00)application identifiers
     
  • Generic shipping label with Lot (10), Item Cross Reference (02), Quantity (37), Expiration Date (17), and License Plate ID (00) application identifiers
     
  • Generic shipping label with Serial Number (21), Item (01), and License Plate ID (00) application identifiers

You can use these generic labels to create a custom GS1 label that will work for your warehouse's needs. See the topic Defining Application Identifier Templates for a graphical diagram of a GS1-AI label.
