Item Configuration

Overview

Define an item record in the system, which enables you to manage how it is processed, what allocation and locating rules are applied to it, and what handling controls (lot-controlled, serial number-tracked, etc) are required during processing. An item record identifies a product's unique characteristics, such as list price, department, style, and size. If your warehouse supports multi-company processing, you can identify the company on each item record.

 

Configuration Hierarchy

 

 

Configure Item

 

1. Item Record Information

Configure the Item name, description and company details.

  • Item Template - Selecting the item template will accept the item name as structured in the template.

  • Inventory Tracking - Enables the system to track this item at location inventory and perform allocation and replenishment operations.

  • Company - Select the company associated to the Item.

2. General

These values are optional properties that will be associated with the item.

 

  • Allocation Rule - An allocation rule determines how the system will select allocation locations. The system will consider this rule if not defined in the shipment line for the item.

  • NMFC Code -This code links an item to a class for freight rating purposes. Each NMFC value is a sequence of letters and/or numbers representing a group of like items with similar characteristics. It is used primarily by LTL carriers.

  • Packing Class - This identifies items that can be shipped in the same container. Packing classes also identify which containers this item can be packed into.

  • Locating Rule -This determines how the system will locate this product in storage locations. The system will reference this field if a locating rule was not defined on the receipt container record.

  • Item Class - This identifies a group of items that share common characteristics, such as unit of measure values and container dimensions.

  • Storage Template - This groups together quantity UM values that service a general type of product, like liquid, gas, or solid products.

3. Item Characteristics

These values represent the basic characteristics such as Color, Style, Division, Department, Cost, List Price and Net Price that are associated with this item.

  • Shipment BOM - Three Options are available for selection. Click for more information.

  • EPC - Indicate the pre-defined identifier for a company associated with a particular item. This value is used when the system computes an Electronic Product Code (EPC) information.

  • Fedex - Configure the Internal and External Transaction number.

  • GS1 - Configure GTIN for the item. Click for more information.

4. Handling Properties

These values will determine how the items will be processed in the system.

  • Immediate Needs - Configure this item as eligible for immediate needs processing; and the locating rule that the system will use when processing this item.

  • Inbound QC - Configure this item as eligible for inbound quality control processing; and the locating rule and UM that the system will use when processing this item. Also, you can use the Compute Quantity As buttons and the Inspection Qty field to further define the quantity you want the system to send to QC.

  • Handling - Configure the catch weight, lot controlled, day to expire and Lot Template.

  • Serial Number - It determine how the system will track serial numbers for this item. Choose the warehouse flow (Inbound, Inventory, or Outbound) based on which the system will track the serial number for the item.

  • Internet - Enter the Web Image, Web Thumbnail Image URL and corresponding Description.

  • Alternate - This will associate an alternate item with the current item. Typically, you would use an alternate item when you have designated the current item as obsolete or permanently out of stock. When an alternate item designation exists for an item, the system will alert the user that they are about to order an obsolete item, and that an alternate item is available. The user can then decide whether or not to use this alternate item on their order/shipment line.

6. International Configuration

  • International - For items to be shipped to international markets, these values are defined.

    • Preference criterion - This identifies where all raw materials container in the item originated from. This information can be obtained from the United States government: This value is printed on the NAFTA Certificate of Origin.

    • Country of origin - The country where the item is manufactured.

  • Harmonized Code - This is a universal value, assigned by the government, that identifies the product on an international shipment.

  • Net Cost - This will define whether the item is subjected to a regional value content requirement.

7. Item Cross Reference

You can create a cross-reference record for any item defined in the system. Generally, a cross-reference number is established to identify an item's UPC or GS1 number. A user processing an item can use either the item number or the cross-reference number to identify it on an Warehouse Mobile device.

Packing Note: If you are packing, and a shipment happens to have more than one item that shares a single item cross reference, the system will force you to pack the entire quantity of the first item that appears in the record grid.

  • Use the Item Field to identify the item that you want to create a cross-reference record for.

  • Use the Company Field to select the company associated with this item.

  • Use the Cross-Reference Item Number Field to identify the number that you want to associate with this item. This value can be an alpha-numeric value.

  • Use the Quantity Unit of Measure Field to associate a quantity UM with an item cross reference. Note that an item/company/item cross reference combination can only be assigned to one quantity UM. Also note that this quantity UM association is used only in certain parts of the system.

GTIN Enabled?

You can use this field to assign a default quantity UM to a specific GTIN (Global Trade Item Number). If a quantity is specified on the GTIN, then it will be assumed to be of this quantity UM. For example, suppose you have a beverage item that only is stocked in cases. You would then need to associate a quantity UM of "CS" to this beverage's item cross reference. Therefore, any time this item's GS1 barcode is scanned, the system assumes it is a case (CS).
