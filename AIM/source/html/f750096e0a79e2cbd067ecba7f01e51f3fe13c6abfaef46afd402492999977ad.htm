Creating Security Records

The SCALE window security system is extremely flexible and can support all environments. A relaxed security system will allow all employees to access and perform all actions on every window. You can then restrict user permissions as security problems arise. On the other hand, a highly-restrictive security system will allow only select employees access to certain windows. You can then grant user permissions as needed. The system is not shipped with any default security settings, so you will need to create your own security records to take advantage of the security system. If you do not create any security records, all users will be able to access and perform actions on any SCALE window. There are three types of security records: user-level, group and system-level. If there is security set up for a user, it must be honored over any security set up for a group to which that user belongs. So in other words, the hierarchy for checking security is user, then group, then system.

"User" Security Records...

You can create user security records on the Security Permissions Window. When an employee attempts to access a SCALE window, the system will determine if he/she has any user-level security records. If an employee has a user-level record, the system will apply that record each time the employee attempts to access the window. User-level security limits a single employee's ability to access and/or perform actions on a specific window.
 

 

"Group" Security Records...

Group level security allows you to establish a group of users who are all assigned the same security. This security level is setup using the 'Security Group' Window. Group-level security is especially helpful if your employees work in departments and only need to access particular windows. For example, you could restrict a packing employee's access to Labor Management, which is a supervisor-level window. Users can be added or removed from the group. Any security settings for a group can be changed and all users in the group automatically reflect the new settings. A security "group" can be assigned on the User Profile or Security Permissions windows.

 

 

"System" Level Security Records...

System-level security limits all employees' ability to access and/or perform actions on a specific window. One system-level security record will apply to all users. System-level security is especially helpful if you want to ensure that critical records, such as status flows, are not deleted or modified.

 

If the employee does not have a specific user level record for a window that he/she wants to access, the system will look for a group level security record. If a group level security record exists, then it applies the group level security. The system level security record is applied if both user and group level security records do not exist. The system will still allow all users access to that window if a system level record is not created for a window.

 

 

Security Decisions: Relaxed vs. Highly-Restrictive...

Before you start creating security records, decide whether you want a system with highly-restrictive security or a minimum-security system that is restrictive when needed:

  • Relaxed Security: This security strategy allows all employees to access and perform all actions on all windows. You can then set more restrictive security for particular users, as needed. You can implement this type of strategy by a creating system-level record that allows permission to perform all actions on a window. Then, you will create specific restrictive records for the appropriate employees.

     

  • Restrictive: This security strategy allows only select employees access to certain windows. You can then grant user permissions to perform actions as needed. You can implement this type of strategy by creating user-level or group level record(s) that allow the appropriate window permissions.

 

Security And RF Processing...

In order to address the security settings on RF processing, adjust the settings on the following areas of the security window:

 

SECURITY WINDOW AREA

 

RF SECURITY OPTIONS

 

Work Confirmation

The options in this area determine what actions a user can perform during various RF processing sessions:

- Allow Dock Management Bypass

- Allow New Container

- Allow Pass

- Allow Short Pick

- Allow Skip

- Bypass

- Override Location

 

RF Main Menu

The options in this area determine what RF process(es) a user will have access to from the RF Main Menu:

- Cycle Count Reconcile

- Dock Management

- Inventory Management

- Location Inquiry

- Receipt Container Nesting

- Receiving

- Shipping Container Nesting

- Work

 

RF Change Password

The options in this area determine if a user will be allowed to change their password during an RF session.

 

Blind Receipt RF Header Fields

 

The options in this area determine what fields that appear on the receipt information entry window when processing blind receipts on an RF device.
