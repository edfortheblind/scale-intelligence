Shipping Preference Configuration

Overview

A shipping preference record allows you to manage how a user or group of users will ship confirm orders. The default shipping preference record should accommodate the majority of employees. Create specific preference records for employees with unique processing needs.

 

General Information

 

Preference Name and Description

 

Auto Work execution work type

  • Select the Auto Work Execution Field to associate this action with a work type. The system will generate a labor management record (labeled with the selected work type) when the load confirmation process needs to execute any outstanding open work instructions. The system needs to address these outstanding instructions before it can confirm a load.

Consolidation work type

  • Select the Consolidation Field to associate this action with a work type. The system will generate a labor management record (labeled with the selected work type) when the consolidation action is complete.

Low and High Status

  • The Low and High status drop-down enable to define when a shipment line is eligible for ship confirmation. The system will only confirm a shipment line within this range. This range provides you the flexibility to ship confirm lines that are not necessarily in the "Ship Confirm Pending" status. Note that when product is ship confirmed, it moves to the first status after Ship Confirm Pending. Unless you warehouse has specific tasks it completes directly before ship confirmation, the next status will be Ship Confirmed. This insures that product can ship confirmed if it skipped statuses that it either bypassed or does not require and be ship confirmed.

Immediate dock transfer work type

  • Select the Immediate Dock Transfer Field to indicate the work type that the system will associate with immediate dock transfers (manual transfers, without work). The system will use this work type for the writing of transaction history and labor management details when manual transfers of containers are performed.

 

Processing

 

Auto Print at Load confirm

  • Select the Auto Print At Load Confirm Checkbox to indicate if you want the system to automatically print any/all documents with print process of Shipment or Load. If the default option is checked, auto printing during load confirmation will be enabled.

Compute delivery Date

  • Select the Compute Delivery Date Checkbox to indicate if you want the system to automatically calculate the anticipated delivery date of a shipment using the shipment's "days to deliver" data. For example, suppose you have a shipment that has a scheduled to ship date of Monday, and the shipment should take two days to arrive. Therefore, if this checkbox is selected, the system will calculate that the shipment should arrive at its destination on Wednesday, and populate the appropriate delivery date field on the shipment.

Create dock work on assigning load to dock door

  • Select the Create Dock Work On Assigning Load To Dock Door Checkbox to indicate when manually assigning a dock door to a shipping load, whether or not the system will skip the normal "transfer shipping container / create dock management work" processing and instead directly assign the dock door to the load.

 

Create orders from shipment

Select the Create Orders From Shipments option if you want the system to create orders from single shipments entered on the Shipment Screen. This applies to single order entries only. You will enter multiple orders using the Order Entry Window.

  • If this checkbox is checked, the system will create orders as well as shipments from the Shipment /Shipment Line Screens. The system creates these orders in an "In Process" condition, and are viewable from Trading Partner Management.

  • NOTE: If this setting is selected, if you manually copy a shipment (and the original shipment has a blank ERP Order Number on the shipment), the system will insert the Shipment ID value into the ERP Order Number field. In addition, the system will also copy this value to the shipment line(s) if they are blank.

  • If this checkbox is not checked, these windows will just create shipments.

 

Manifest un-manifested containers during ship confirm

  • Select the Manifest Unmanifested Containers During Ship Confirm Checkbox to indicate, during ship confirmation, if the system should attempt to manifest any containers that are currently unmanifested. Typically, this setting would be used in situations where the shipment and its container(s) have not been closed at the time of ship confirmation.

 

Transfer failed shipments during load confirm

 

Select the Transfer Failed Shipments During Load Confirmation Checkbox if you want any unconfirmed shipment on a load to be transferred if it fails confirmation during the load confirmation process. The system will then transfer this shipment to a new load, so the original load can be confirmed.

  • If this option is selected, the system will transfer any unconfirmed shipment to a new load, and confirm the original load.

  • If this option is not selected, the system will not confirm any load that contains unconfirmed shipments.

Container ID assignment method

Indicate how you want the system to split shipments/loads when a worker encounters a situation where a split is needed:

  • Do not split shipment - This option will not confirm any portion of the shipment if any quantity is in a status less than Ready For Ship Confirm (as defined by the high status in your Shipping Preferences). The shipment will instead be transferred to an alternate load.

  • Prompt - This option will offer the user to decide (during confirmation) from the three options described below.

  • Split Shipment - This option will only confirm that portion of the shipment that is in a Ready For Ship Confirm status (as defined by the high status in your Shipping Preferences). Any portion of the shipment that is not in this status will be split off to a new shipment with the same shipment ID.

  • Split Shipment if not in range - This option will confirm the entire shipment as long as it is in the status range defined in your Shipping Preferences. The system will, if needed, update work as lines and containers are transferred to new shipments. If any part of the shipment is outside the status range, this portion will be split off to a new shipment with the same shipment ID.
