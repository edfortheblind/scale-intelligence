Adjusting Inventory (Desktop and RF)

The term "inventory adjustment" refers to adding/subtracting an item quantity from a location's inventory (outside of a pick or a putaway action). Adjustments allow you to quickly respond to unexpected location activity in real time. You can make adjustments by loose item quantities as well as whole license plates.

 

Adjustment types are associated with adjustment classes and are user-configurable. It is this class that determines how the system will process the adjustment type. Because the class determines how the system will process inventory, you can create as many adjustment types as you need. This allows you to use specialized adjustment types for different kinds of inventory or locations. For each adjustment type, you can also determine if can be applied to frozen locations. Also, to minimize errors, you can set minimum and maximum quantity values per adjustment type.

 

You can also have the system generate work instructions for certain types of inventory adjustments (performed from the desktop). This allows adjusted quantities to not show up as available in a location until the quantity is actually present (on hand) in the location.

 

Notes:

  • The status of allocated inventory can be changed in the shipping and receiving dock.
  • From the Lot insight screen, user will not be able to perform inventory adjustment/status change/transfer when the updated inventory is linked with inventory attributes.
  • While editing lot information, user will be able to change status/expiration date. This change will be updated across all inventory records for the item/company/lot in the system.

Adjustment Type Descriptions...

 

Positive Adjustment
  • This type of adjustment adds an item quantity to a location.

  • The quantity value must be a positive number.

  • You can only perform this action on non-parent license plates.

 

Negative Adjustment
  • This type of adjustment removes an item quantity from a location.

  • The quantity value must be a negative number (for example, -12).

  • You can only perform this action on non-parent license plates.

 

 

 

Desktop: Performing an Adjustment...

The following procedures are for performing a positive or negative inventory adjustment from the desktop screen. Note that if you access this screen from the Inventory Insight, then the system will default value(s) into some of these fields where appropriate.

  1. Select the Inventory Adjustment Screen from the system menu. The system will display the Adjustment Type Field.

  2. Use the Adjustment Type Field to select a positive or negative adjustment type. The system will display the user and warehouse authorized adjustment types.

    - If the selected adjustment type is configured with license plate initiation type, the Adjustment screen is shown with the License Plate field. The system will prompt you to also enter a license plate ID. When you enter an existing license plate and press the Arrow button, the system will display the processing fields. Note that in this instance, only the following fields will be editable: Lot, Expiration Date, Quantity. UM, and Status (positive adjustment only).

  3. Use the License Plate Field to indicate the license plate that represents either the license plate that contains the loose quantity that you are adjusting; or, the whole license plate that you are adjusting. If the location you are adjusting into is not license plate tracked, then this field will not be editable.

  4. Use the Location Field to indicate the location where the item resides.

    Locate Action: If necessary, you can use this action (accessed from the Actions menu) to have the system suggest a To location. You will need to choose a locating rule for the system to use in the locating process.

  5. Use the Item Field to indicate the item that you want to adjust. Note that you can only adjust an item if it its "inventory tracking" setting is active (defined on the Item Window).

  6. Use the Company Field to indicate the company associated with the item that you are adjusting.

  7. Use the Lot Field to indicate the item's lot ID. After the adjustment is initiated, the system will display the Lot Update Confirmation Screen if you change this value.

  8. Use the Expiration Date Field to indicate the lot's expiration date. After the adjustment is initiated, the system will display the Lot Update Confirmation Screen if you change this value.

  9. Use the Quantity and UM Fields to indicate the amount that you want to adjust. Note that you will not have to enter this value if you are adjusting a full license plate.

  10. Use the Status Field to indicate the item's inventory status that will be applied after the adjustment is performed. Note that this field is not available or is ignored when performing a negative adjustment.

  11. When finished...

    Press the Adjust Button, and the system will perform the adjustment.

    OR

    Press the Create Work Button to have the system perform the adjustment and create work for the transaction. The system will prompt you to confirm that you want to have the work created. Note that the Create Work Button will only be active if this adjustment type is configured to create work.

 

Processing Notes
  • The system will not allow you to perform an adjustment to a parent license plate.

  • The values for the user defined fields will be defaulted from the Adjustment Type Window record for this particular adjustment type. You can then enter in these fields comments that will be viewable from the transaction history record for this adjustment transaction.

  • If it is a new inventory record being adjusted into a location, the user defined field values will be written to the inventory. If inventory already exists for the item/location/lot/license plate, the existing user defined fields will be retained.

  • When entering serial numbers for positive adjustments, you will need to enter the major and minor serial number(s) for this item. When entering serial numbers for negative adjustments, you will only need to select the major serial number(s).

 

 

 

RF: Performing an Adjustment...

The following procedures are for performing a positive or negative inventory adjustment from an RF device.

  1. Select the Inventory Management Screen from the RF main menu. The system will display the Adjustment Type Field.

  2. Use the Adjustment Type Field to select a positive or negative adjustment type. Note that inventory transfers are also listed in this field, but the procedures below are for inventory adjustments only. The system will display the user and warehouse authorized adjustment types.

  3. The system will then display the appropriate processing fields. If the selected adjustment type is configured with license plate initiation type, the Inventory Management screen is shown with the License Plate field. The system will prompt you to also enter a license plate ID. When you enter an existing license plate and press the Arrow button, the system will display the processing fields.

  4. Use the Item Field to indicate the item that you want to adjust. Note that you can only adjust an item if it its "inventory tracking" setting is active (defined on the Item Window).

  5. Use the Company Field to indicate the company associated with the item that you are adjusting.

  6. Use the Lot Field to indicate the item's lot ID. After the adjustment is initiated, the system will display the Lot Update Confirmation Screen if you change this value.

  7. Use the Expiration Date Field to indicate the lot's expiration date. After the adjustment is initiated, the system will display the Lot Update Confirmation Screen if you change this value.

  8. Use the Quantity and UM Fields to indicate the amount that you want to adjust. Note that you will not have to enter this value if you are adjusting a full license plate.

  9. Use the LP Field to indicate the license plate that represents either the license plate that contains the loose quantity that you are adjusting; or, the whole license plate that you are adjusting. If the location you are adjusting is not license plate tracked, then this field will not be editable.

  10. Use the Loc Field to indicate the location where the item resides.

    Locate Action: If necessary, you can use this action (accessed from the Actions menu) to have the system suggest a To location. You will need to choose a locating rule for the system to use in the locating process. Note that the locating functionality does not create any work.

  11. Use the Status Field to indicate the item's inventory status that will be applied after the adjustment is performed. Note that this field is not available or is ignored when performing a negative adjustment.

  12. When finished, press the OK Button, and the system will perform the adjustment.

 

Processing Notes
  • In order for the system to display the User Defined Values screen, you need to activate the Inventory Control Value setting "Edit User Def In RF".

 

 

 

Using Inventory Attributes With Inventory Adjustments...

  • If you try to perform an adjustment (Desktop or RF) to/from a location that has inventory attributes, the system will display an error when selecting a location inventory record from the Inventory Insight screen that represents multiple inventory attributes. If the "Show All License Plates And/Or Inventory Attributes" checkbox on the insight screen is selected, then the system will adjust inventory for the selected record.

  • The system will add/subtract inventory at the location without inventory attributes when performing a positive/negative adjustment through the Inventory Adjustment Desktop menu.

  • When you access RF inventory management directly from the RF Main Menu screen, the system does not adjust or change the status for inventory linked to inventory attributes.

  • When changing inventory status, the system will notify the user that the inventory does not exist when the system has one or more location inventory records linked to inventory attributes. See the topic Using Inventory Attributes (RF) for more information.

  • Any time you perform an adjustment from system menu for a location having inventory with and without attribute or inventory with different attributes, system always brings up the oldest record and the adjustments are done to the record that was shown.
