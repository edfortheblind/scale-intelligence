Defining Web Screen Data Values

You can use these values determine what search fields will appear on web inquiry windows. Note that the system will not display the Available and Selected Field lists when you are creating a record for a screen type that does not have any details (fields) to select from.

Procedures...

  1. Use the Web Screen Field to indicate which web screen you are creating this screen data record for.
     
  2. Use the Company Field to indicate if this screen is to be restricted to one company's users.
     
  3. Press the Apply Button. The system will allow you to edit the remaining fields.
     

  4. Use the URL to Call Field to indicate what you want the system to display when a menu option is selected on the Trading Partner Management main menu. You can only input a value in this field if you are creating a record for a top-level "inquiry" web screen, NOT a "results" or "details" screen.

     

    • If this field has a value, the system will display the provided URL. For example, suppose there is a record for the web screen "OutboundStatisticsInquiry," and the URL to Call Field contains a value. The system then would display your custom page when this option is chosen in Trading Partner Management.

       

    • If this field is blank, the system will display the base system page. For example, suppose there is a record for the web screen "OutboundStatisticsInquiry," and the URL to Call Field is blank. The system, then, would display the Outbound Statistics Inquiry Window when this option is chosen in Trading Partner Management.

     

  5. Use the Add Buttons to move fields from the left pane (Available Fields) to the right pane (Selected Fields). If a field appears in the Selected Fields pane, the system will display it as a search criteria field on the inquiry window. There is no limit on how many fields you can add. This option is only available when defining web statistics inquiry screens. If no fields appear on the left side, then this screen does not allow tailoring of the fields to be displayed.
     
  6. Use the Remove Buttons to delete field(s) from the right pane (Selected Fields). This option is only available when defining statistics inquiry screens. If no fields appear on the left side, then this screen does not allow tailoring of the fields to be displayed. If a field is locked (has a lock icon associated with it), you cannot remove it. The locked fields are the default fields that are shipped with the system.
     

  7. Use the Active Checkbox to indicate to the system that you want to display this screen in Trading Partner Management. For example, if you select this checkbox for the "Reports" screen, the system will display a link for this screen on the TPM Main Menu. If you did not select this setting, the system would not display the link to the "Reports" screen.

     

  8. Press OK. The system will save your changes.
