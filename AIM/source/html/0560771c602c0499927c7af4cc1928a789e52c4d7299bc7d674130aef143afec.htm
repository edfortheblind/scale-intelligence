Field Length Field

This field appears on template windows (Item Template, Location Template, etc.) and on the System Text Editor Detail Window. It has a unique purpose on both types of windows.

 

On a Storage Template Window...

This field determines the following:

  • The number of letters or numbers that should come before a specific separator value. Field lengths are defined in item template records.

     

  • When a particular value is inserted in a group of item records. After this number of characters in the item number, the separator character will appear.

 

On the System Text Editor Window...

This file determines the following:

  • How many characters a field will accommodate. You can only modify a custom text's field size.

 

 

Note About Keeping 14 Digits To the Left of the Decimal...

Below are the settings that are allowed for numeric fields in the System Text Editor if you want to keep 14 digits to the left of the decimal. This is applicable for any numeric fields throughout the system which have a maximum field length of 19,5:

 

[field length, decimal position]

  1. 14,0
  2. 15,1
  3. 16,2
  4. 17,3
  5. 18,4
  6. 19,5

Note that anything having more than 14 digits to the left of the decimal would be an invalid setting.
