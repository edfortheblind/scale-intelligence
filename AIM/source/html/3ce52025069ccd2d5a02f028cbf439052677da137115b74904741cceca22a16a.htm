Removing Container Groups (RF)

The RF Remove Container Group Screen allows the user to manually ungroup a single container from a picking group. Note that the user can also remove all the containers that are part of the group at one time. When a container is removed from a group, the system deletes the group ID and spot value from the shipping container (and its related work), and logs process history representing this removal. Keep in mind that in order to ungroup container(s) from a picking group, the work has to be open, assigned a group ID, and not currently assigned to user.

 

An example of when a user may want to manually remove a container from a group is outlined in the scenario below:

Suppose you have 5 shipments with a single container each ( 4-5 items in each container). All the containers contain some slow-moving items that are located in Zone C (slow-moving inventory) along with items in Zone A (fast-movers that are part of a conveyor picking system). So, the user would add these containers to a cart as he assigned them to a picking group. Then, the user would first execute the picks for the Zone C (slow-moving) items. Then, they would put the containers on the conveyor for the other pickers to do the Zone A (fast-moving items) work. Now, when the Zone A worker scans one of the containers to do the fast-moving items work, the system would display all the picks for all the containers (because they are still part of the group's single work unit). What the user should have done in this situation is manually remove the containers from the picking group after the slow-moving work has been performed. This can be done in two ways: automatically (upon passing the grouped work the system can automatically remove the containers from the group, depending on the Container Group Removal When Group Work Is Passed? work system value setting), or manually via the RF Remove Container Group screen.

Removing a Single Container from a Picking Group...

  1. Log onto your RF device, and select the Remove Container Group option.

  2. Enter the container ID of the container that you want to remove from the picking group.

  3. Press the Remove Button. The system will remove the container from the group, and display a success message at the bottom of the screen.

 

Removing All Containers from a Picking Group...

  1. Log onto your RF device, and select the Remove Container Group option.

  2. Enter the container ID from one of the containers that you want to remove from the picking group.

  3. Press the Remove All Button. The system will display a confirmation message:

    - Press OK to indicate that you want to remove ALL of the containers from the group that the container (that was entered in step 2) is associated with. After you press this button, the system will remove the containers, and display a success message at the bottom of the screen.

    - Press Cancel to return to the RF Remove Container Group Screen without removing the containers from the group.
