Manually Selecting Wave Printers/Reprinting Wave Paperwork

The system allows you to print documents/labels both automatically when the wave is run, and manually as a reprint action after a wave has completed. You can also select to reprint this wave paperwork from different printers than were originally used when the wave was initially run.

Selecting a Printer for Wave Documents/Labels from Wave Insight...

Before running a wave, you can choose to manually select the printers that the system will use to print wave paperwork (documents and/or labels). These printers will override the print devices that were previously configured in your document routing/document master configuration records. You can access this function from the Wave Insight.

 

Open Wave Insight:

  1. Access an active wave record and select it.

  2. Click on Run (Select Printers) under Actions to open the Wave printer selection screen in a modal window. The action remains enabled only when the wave is not run (Active wave). Once the wave is run, the action remains disabled.

  3. Use the Document Printer Field to select a printer that you want the system to use when printing wave paperwork that is classified as documents in the Document Type Window. Note that this field lists all of the print devices that are currently configured in the system.

  4. Use the Label Printer Field to select a printer that you want the system to use when printing wave paperwork that is classified as labels in the Document Type Window. Note that this field lists all of the print devices that are currently configured in the system.

  5. Press the Run Wave button. The system will run the wave and print the paperwork, routed to the appropriate printer(s).

NOTE: If the document printer or the label printer fields are kept blank and the Run Wave button is clicked, system prompts for a confirmation message stating that the system will print the documents/labels using the printers configured in the document master/document routing records. If one of the document printers or the label printers are selected or both are selected and the Run Wave button is clicked, system prompts for a confirmation whether to run the wave or not.

 

 

 

 

Reprinting Wave Documents from Wave Insight...

After a wave has been completed, you can choose to reprint the paperwork, with the additional options of being able to select any document master or printer that you want to use. This is helpful if your documents did not print properly when the wave was initially run. You can access this window from the Wave Insight. Note that you can only reprint documents from one wave at a time. Note that if you leave a printer field blank, the system will use the printer that was defined in configurations.

 

Open the Wave Insight.

  1. Access a completed wave record and click the Reprint Wave Documents action.

  2. The system will display the Reprint Wave Documents screen.

  3. Use the Document Master Field to indicate the document master record that you want the system to use when regenerating the wave documents. Note the system allows you to choose a different document master than was used originally when the wave was run. This should not take any longer processing than when the system used the original document master (as the system always has to regenerate the wave paperwork upon a reprint action).

  4. Use the Document Printer Field to select a printer that you want the system to use for the reprint action. Note that this field lists all print devices currently configured in the system.

  5. Use the Label Printer Field to select a printer that you want the system to use for the reprint action. Note that this field lists all print devices currently configured in the system.

  6. Press the Print Button. The system will reprint the wave documents, routed to the appropriate printer(s).

 

 

 

Reprinting Wave Labels from Wave Insight

After a wave has been completed, you can choose to reprint the labels, with the additional options of being able to select any label master or printer that you want to use. This is helpful if your labels did not print properly when the wave was initially run. You can access this window from Wave Insight. Note that the Reprint Wave Labels action remains enabled only when the Released flag for a wave is set to N and the wave is not active or the Released flag is set to Y. The action remains disabled if the Show released waves flag for a wave is set to F and the wave is active.

 

Open the Wave Insight screen.

 

  1. Access a completed wave record and click the Reprint Labels action.

  2. The system will display the Reprint Wave Labels screen. System defaults the original label master used for printing the label in the wave in the Label Master field of Reprint Wave Labels screen.

  3. Use the Label Printer field to select a printer that you want the system to use for the reprint action. Note that this field lists all print devices currently configured in the system.

  4. Press the Print button.
