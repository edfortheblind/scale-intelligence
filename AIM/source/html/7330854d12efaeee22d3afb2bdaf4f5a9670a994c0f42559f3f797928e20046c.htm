Researching Current User Activity

The application allows you the ability to view how many users are currently online. When a user logs on/off of the system or an RF device, the system will create a user activity record that records such user activity data as logon time, last action time, and the device that the user is/was using. This information is helpful if you want to research how the number of current users are affecting the performance of the application server.

 

You can research the following information on the User Activity Insight Screen:

  • The number of concurrent users currently logged onto the system, and information about these users.

     
  • Information about a specific user who is currently logged on, or was logged on in the past.

Note that the application will also track user activity data for "abnormal" logoffs, such as when the client/server machine locks up, a user closes the RF browser window without signing off, etc. This logoff activity record will be generated by the WMMonitorService, which will periodically scan the user activity database table in order to perform a logoff to any orphaned logon records. This will allow you to view activity records for users that have been "stranded" on a machine where the system application has locked up.

Researching User Activity...

  1. Access the User Activity Insight Screen from the system menu.
     
  2. Enter the user that you want to research. If you leave this field blank, the system will return results for all system users.

  3. Enter the specific date span that you want to research user activity.
     
  4. Select the appropriate user type:

    - Full Screen: Indicates that you want results returned for all activity by full-screen system users.

    - RF: Indicates that you want results returned for all activity by system RF device users.



    Note that the system does not track Trading Partner Management website use through the User Activity Insight Screen. You can view this data on the Process History Insight Screen.
     
  5. Press the Apply button. The system will display the results of your query in the list pane grid.
