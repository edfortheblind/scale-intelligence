Defining Which Wave Records Require Paperwork

You will use the data selection windows listed below to identify which document types should be generated for a specific group of records in a wave, based on characteristics of the record. For example, if the document type is bill of lading, you can generate it for all shipment records assigned to an LTL or truckload carrier. You will also use this window to determine the order that the documents will be printed. You can create paperwork for the following wave records: container IDs, work instructions and shipments.

 

Later, you will associate the document type with a document master record. The document master record determines which document type will be printed for the records defined on the data selection window.

 

You will use one of the data selection windows to determine which document types are printed for particular records in a wave. There is one data selection record for each type of wave record that might require paperwork:



Specific Data Selection Window:

Can be applied to:

 
  • Container Data Selection

Container ID records in the wave.

 
  • Load Data Selection Window

Shipping loads in the wave.

 
  • Shipment Data Selection

Shipment number records in the wave.

 
  • Work Instruction Selection

Work instruction records in the wave.

Procedures...

You will first need to determine what type of wave record you want paperwork for. Open the appropriate data selection window (see list above).

  1. Using the Filter Data Tab: You can use this tab to specify the values that the system will use to evaluate wave records. These fields identify what characteristics a record must have for a particular document type to print.
     
  2. Using the Order By Tab: You can use this tab to define what record values determine if paperwork is needed, and establish how that paperwork will be organized. You can define the order that documents are generated, based on a record characteristic.
     
  3. When finished, press OK. The system will save your criteria record.
