Bypassing the Packing Process

Bypassing the packing process allows you to ship containers without identifying the contents in them. You will bypass packing by creating the container "on the fly" on the Close Container Window (accessed from the remote desktop system menu), and immediately closing it. You only need to identify its shipment ID, weight, and carrier. You will want to create and close containers in this fashion if your warehouse flow does not include a traditional packing station. Remember that when you close a container in the system, you cannot pack additional items in it. The system will automatically manifest the container if the Auto Manifest at Close Checkbox is selected on your packing preferences record (and Progistics CS is installed).

 

 

Prerequisites...

  • Shipment status determines what activities you can perform against a container. You cannot create a container if the shipment's status is not at least "In Packing", but not higher than "Ship Confirmed." Also, you cannot close a container if the shipment's leading status is not at least greater than or equal to "In Packing."
     
  • You can only use the process described in this topic if the "Allow Container Creation During Close Checkbox" on the Packing Preferences Window is selected.
     
  • Detail lines on a shipment do not need to exist to close a container in the Close Container Window. This is helpful when you want to send out such miscellaneous shipments as customer gifts or internal business shipments. However, you cannot manifest international shipments without including detail lines.
     
  • If the shipment was manually added from the Shipment Insight screen (not via a wave), you will need to set the "Default Status When Added In Shipment Insight" setting on the Outbound Status Action Window to "In Packing." Otherwise, there is no way to get the shipment into the required "In Packing" status without actually entering packing.

Procedures...

  1. Access the Close Container Window (accessed from the remote desktop system menu).
     

  2. Identify the existing Shipment ID and a new Container ID. Based on your packing preferences, the system may automatically assign a Container ID. Note that the system will validate this new container ID to ensure that it is unique among existing shipping containers and multiple order pallets.

     

  3. Identify the weight of the container by either manually entering the weight or using the scale interface (via the Action Menu) in the Weight Field. If appropriate, you can change the weight of the container. In this case, the system will remanifest the container.

     

  4. Are you grouping containers?

     

    • If Yes, provide the appropriate values in the Container Count Fields. If this is the first container in the group, both of the fields will be blank. If it is a subsequent container, the system will default the container values, but you can change them.

       

    • If No, continue to Step 5.

     

  5. Press the Close button. The system will create the container and close it automatically.

    PRINTING: The system may display the Print Documents screen, based on your packing preferences. If this window is not displayed, you can access it by selecting the Print Documents screen. All documents associated with the packing/unpacking process are displayed on the Print Documents screen. Some of these documents may be pre-selected to print. You can select any additional documents that you want to print, and deselect any documents that you do not want to print.

    INT'L SHIPMENTS: The system may also display a message box asking if you want to send this shipment to an international destination (this can be configured from the Rating ID Window). If you choose Yes, the system will navigate back to the Close Container screen. When you process further containers, processing will be normal except the manifesting process will not occur. Instead, when you press the End Shipment Button, the system will open the Shipment Level Manifesting screen. If you choose No, the system will return to the Close Container screenwith no further processing.

    Warning: If you attempt to close a container for an international shipment whose rating occurs at the shipment level AND trailing status is less than 401 (In Packing), the system will display a warning indicating that unpacked quantity exists for the shipment. If the shipment's trailing status is greater than or equal to 401, then no such warning will appear.
     
  6. After closing the container, the system will leave this screen open. If appropriate, close any other containers that are ready. When you are finished, select the Cancel Button to exit the screen.
