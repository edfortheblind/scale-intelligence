Defining Item Location Capacity

Item location capacity records identify the item quantity that can be stored in a location or location type. These records are defined for an item or item class. The system will use this information during the locating and replenishment processes. This allows you to set up item/location thresholds without having to weigh and measure each item that is placed into a location.

 

When using the real time replenishment method, you will need to define an item location capacity record for your location(s). This is because the real time mode does not do any mathematic calculations based on dimensions when determining if a location needs to be replenished. Therefore, this mode will only work correctly if you have set up these item location capacity records for each real-time location.



This process works as follows: any time a location's quantity is decremented, and the location is set up for real time replenishment, then the system evaluates the quantity based on the capacity. If the location needs replenished, the system flags it so it can be picked up the next time replenishment is run. The system will look to see if the location is eligible for real time replenishment; if it is, the system will replenish the location. If it is not, the system will retrieve the item location capacity record for the particular item and location.
 

Furthermore, if the item location capacity record is set up with a maximum quantity, the system will determine if the quantity at the locations is in need of replenishment. If a maximum quantity is not specified on the item location capacity record, the location will automatically be marked so that it can be reviewed the next time replenishment is executed.

Using the Header Fields

When you access this window, you must first define this record for either an entire class or just one item. Note that if an item location capacity record exists for both an item and its item class, the system will honor the specific item's record.

  1. Select Item Class to define the location capacity for a group of items.

    Select Item to define the location capacity for a specific item. If you support multi-company processing, you will also need to indicate the company associated with this item.
     
  2. Press OK. The system will display the General and User Defined Data tabs.
 
Using the General Tab

You will use the General Tab to associate this record with the appropriate locations and define its capacity thresholds.

  1. Use the Location Type Field to define the capacity for a group of locations. This minimizes setup time.

    OR

    Use the Location Field to define the capacity for a specific location. If you define this record for a specific location, verify that the value in the Warehouse Field is correct.

    - Note that if an item location capacity record exists for both a location and its location type, the system will honor the location's record.
     
  2. Use the Maximum Quantity Field to identify how much product can fit in this location or location type. This field is optional unless this is a multi-item location. For single item locations, if you do not provide a value in this field, the system will calculate how much product can fit in this location by comparing its dimensions to the item's dimensions.

    If the Maximum Quantity UM is different than the one defined on Replenishment Master Window, the system will convert the maximum quantity UM. It will reference the Item Unit of Measure Window to determine conversion values.
     
  3. Use the Minimum Replenishment Threshold Field to indicate the lowest possible percentage of product that is acceptable for this location or location type. When the location's quantity reaches this threshold, the system will automatically generate a replenishment request (the next time replenishment is run). This value is expressed as a percentage. If this minimum percentage is reached, the system will designate that location for replenishment.

    NOTE: This field applies only to the following replenishment types: Demand From Pool, Demand From RF Outbound Short Pick Work, Demand From Wave, Item Location Capacity.

  4. Use the Top-Off Minimum Replenishment Threshold Field to indicate the lowest possible percentage of product that is acceptable for this location or location type. When the location's quantity reaches this threshold, the system will automatically generate a replenishment request (the next time replenishment is run). This value is expressed as a percentage. If this minimum percentage is reached, the system will designate that location for replenishment.

    NOTE: This field applies only to the following replenishment type: Top-Off Item Location Capacity.
     
  5. Use the Maximum Replenishment Fill Percent Field to define the percentage to which you want to fill this location during replenishment. This value is a percentage. When replenishing, the system will only fill the location to this percent, unless the replenishment strategy Fill Location is used.
     
  6. Press OK. The system will save the record.
