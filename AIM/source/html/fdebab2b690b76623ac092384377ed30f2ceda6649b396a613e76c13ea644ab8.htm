Checking In and Locating Product (RF)

During check in, the system accepts product on the receiving dock into the warehouse. On a RF Device, the system also allows you to locate this product automatically after check in. The procedures below describe this process.

 

NOTE: You cannot check in the receipt lines after a receipt has been closed (i.e. the Closed Date is specified). However, you can still perform functions on existing receipt containers such as check-in, locate, and unlocate.

Procedures...

 

1. LOG ON to your RF Device, and choose Receiving from the Main RF Function Screen.

 

2. RECEIVING PREFERENCE: Choose the receiving preference you want to use for this session, and press OK. Note that the system will automatically load a preference if one is associated with your user profile record. Receiving preferences shown on the RF Receiving Preferences selection screen can be authorized by user from the Receiving Preference configuration screen.

4. ITEM CROSS REFERENCE: (if cross references are used) If an item cross reference has more than one item, you will have to choose which one you want to check in. Note that if the item is in the cross reference and not in the item master, the item will not be found. If it is not in the item cross reference and the item master, the system checks to see if it is on a receipt.

 

5. COMPANY VALIDATION: (for multi-company warehouses) Additionally, the system checks to see if the item has more than one company associated with it. If so, we display to the user a screen to choose a company. If not, then the item is not assigned a company. If the user does not have authority to access an item's company, the system will not display this receipt. You can change a user's authority in the Security Window.

 

6. MAIN CHECK IN SCREEN: Identify the quantity and correct unit of measure for the product you want to check in. If there is an Item Unit of Measure record for the item you are checking in, the Item UOM field will indicate the conversion quantity next to a unit(s) of measure. If no Item UOM records exist, the system will display only the base unit of measure in this field. When finished, press OK.

 

7. VALIDATIONS:  If configured to do so, you will also have to enter:

  • LICENSE PLATE ID: System will ask for the license plate ID that you want to associate with this checked-in item. Provide one and press OK. Otherwise, the system will create this ID for you.

  • CHECK IN VERIFICATION: System will display a "Check In Verification" message, based on your receiving preferences record (the Verify Item Dimensions Checkbox). You will need to decide if you want to continue checking in product in which all the dimensions are not defined. Choose "Yes" to continue, or "No" to cancel. If you did not choose to have the system verify dimensions, then no message will appear.
     
  • DISPOSITION CODE: System will display a Disposition Code screen, which allows you to enter information about the condition of the item you are checking in. This information is not required, simply do not enter it if your warehouse does not require it.

  • INVENTORY TRACKING: System will display the Enter Special Information screen, if the item you are checking in requires special tracking values such as lot ID, serial number, and/or catch weight. For serial numbers, you will need to provide, if necessary, the major and minor serial values for an item. A new entry screen will appear for every each you are attempting to check in. Note that if the item you are checking in is configured for serial number range entry, then the system will display a special screen that allows you to enter the first and last serial number in the range of numbers that is on the quantity that you are checking in. You can press the Skip Button to return to the regular serial number entry screen, so you can manually enter each number as opposed to providing the range.

    If you change the status or Expiration Date of the lot for an item, the system will display the Lot Update Confirmation Window. Review the detail information and press OK if you want to apply the lot change.

 

8. START CHECK IN/LOCATING PROCESS: After pressing OK, the system will check in and locate the product. When you do this, the system will only locate the containers that were just created by the check in process. Note that a single check in can create multiple containers.

 

- If the system converted the container's unit of measure during check in, it will only locate in the unit of measure it selected (during check in). For example, if the receipt line included 10 eaches and the system converted that to 1 case, it can only locate a case unit of measure. It cannot locate 10 eaches.

 

- You cannot locate items with different unit of measure records to the same location. For example, suppose location LOC123 contains a quantity of item A1 (with a casepack of 10). You then locate an additional quantity of item A1 (with a casepack of 8). The system will not locate this additional quantity because of the difference in the UM's of each casepack. However, if you locate some more A1 that has also has a casepack of 10, then the system will allow you to locate, as both quantities of A1 have the same UM properties.

 

- If the "Nest During Check In" checkbox on your Receiving Preferences was selected, the system will nest the container(s) on a receipt into one container. At the end of the check in process, the system will display a screen where you will enter a license plate ID and the container type.  The system then will nest the container(s) that you checked in during that “session” into the new container. Note that you can configure security for this process to skip nesting (see the "RF Receiving Container Nesting" value in the Security Window).

 

- When Using Delayed Locating: If the receipt container’s locating rule has Delayed Locating checked and the user’s receiving preference has Create Work Putaway checked, then the receipt container will locate to a location with the Receiving Pre-locate location class. If either flag is unchecked, then the system locates based on the receipt container’s locating rule details. The locating rule on the parent container is used when locating by parent, while the nested container’s locating rule is used when locating by child.

 

When Using Quick Receiving

- If the Bypass Location Capacity Validation Checkbox on your Receiving Preferences was selected, the system will suppress the following validations (any other validations will remain to be enforced): dimensions (length, width, height, weight), volume, and item location capacity.

This setting has the following behavior depending on which quick receiving execution method is used:

  • Quick Receive-User: The validations mentioned above will always be bypassed.

  • Quick Receive-System: The validations mentioned above will be bypassed only if the user is overriding the system-selected location.

- If the "Override System Selected Location" checkbox on your Receiving Preferences was selected, you can enter an alternate putaway location (different than the system-selected location) during license plate check in (when using the Quick Receive-System execution method). Note that you cannot use this setting when using the Quick Receive-User execution method.

 

- Pressing the Skip button will skip the locating process. The user will not be prompted again to locate the skipped receipt container. The user will need to use either the Receipt Workbench, or RF Receiving with a Receiving Preference configured with the License Plate initiation method to locate a skipped receipt container.

Process Notes...

 

Note When Locating To Multi-Item Locations

The locating process does a volumetric validation when locating an item to a multi-item location. When locating to a multi-item location, the system compares the current volume of the location's items to the total volume of the location to determine if a receipt container will fit. For example, suppose a receipt container has 10 of Item A in it, for a total volume of 100. Location AA001 currently contains Item A and Item B, with a total volume of 250. Also, location AA001 has a total volume capacity (using location type dimensions) of 500. The system, then, would successfully locate the receipt container to the multi-item location. Note that the system performs this volume check only when there is no item location capacity records defined for the item you are trying to locate. If an item location capacity record exists for the item/item class and location/location type, the system would use it to determine the amount of the item that can be placed into the location.  

 

 

NOTE: The locating process does not execute the volumetric calculation on a multi-item location when the location type is defined with a blank value. This is helpful if you want to, for example, create a returns location, and have the system treat it with infinite capacity so unlimited returns can be located there. In this case, you would want to make sure that no location type is assigned to the location (instead of, say, assigning a location type with a dimensions/volume = 999999), and the system will treat the location as infinite in size, and not execute the volumetric calculation during locating.
