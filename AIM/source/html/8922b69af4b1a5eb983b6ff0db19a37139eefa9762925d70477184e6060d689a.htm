Defining Companies

If you process product for one or more companies, you will need to define them in the system. You can define separate items, employees, customers, and other warehouse entities for each company you define in the system. In addition, you can calculate separate rates per company. You can also define which employees can process a company's products, which items and customers should be associated with a specific company, and generate system documentation that includes the company. Note that customers and items can be setup without companies if they are same values are shared by each company.

Using the General Tab
  1. Use the UCC/EAN Number Field to provide the UCC/EAN identifier assigned to this company. This number is a unique prefix that identifies this company.
     
  2. Use the Order ID Prefix Field to indicate the default prefix that the system will add to all orders created for this company in the full screen and web order entry system.
     
  3. Use the Receipt ID Prefix Field to indicate the default prefix that the system will attach to the beginning of the names of all web receipts created in web receipt entry.
     
  4. Use the Purchase Order ID Prefix Field to indicate the default prefix that the system will attach to the beginning of the names of all web purchase orders created in Trading Partner Management.
     
  5. Use the Availability Checking Checkbox to indicate that you want the system to verify if the warehouse contains enough quantity to satisfy a company's new shipment. The system performs this validation when an order is created via order entry, or a new shipment line is entered. The system will alert the user if enough inventory does not exist to meet this demand.

 

Warehouse/Company Information Tab

You can use this tab to configure ship from address(es) per warehouse/company combination. If defined, the system will use this address on shipping paperwork. If not defined, then the system will use the company address first, or the warehouse address (if no company address exists). Note that you can only create one address detail record per warehouse/company combination. Also, if the Returns Address and /or Freight Bill To Address tabs are left blank on this detail, then the shipping paperwork will use the values on the Ship From Tab address fields.

 

 

Warehouse/Company Information Detail Window Fields
  1. Use the Header Fields to define the warehouse/company combination that this address will apply to.

  2. Use the Ship From Address (required), Returns Address, and Freight Bill To Address Tab Fields to define the shipping information for this detail record.

  3. Press OK, and the system will save your warehouse/company detail record and display it in the tab grid.

 

Using the Company Address Tab
  1. Use the Address Fields to define the company's general shipping information.

 

Using the Returns Address Tab
  1. Use these fields to identify where all product shipped for this warehouse will be returned.

 

Using the Freight Bill To Tab
  1. Use these fields to identify the address where all shipping bills for this company should be sent.

 

Using the Internet Information Tab
  1. Use these fields to define settings related to the internet.

 

Using the Web Header Tab
  1. Use theCenter Graphic Values to indicate the path of the graphic that will appear at the top-center of the Trading Partner Management Main Menu. The path should be in this format: \\YourServer\Directory1\Directory2\graphic.gif.

    For more information on these values, see their field topics: Center
     
  2. Use the Center URL Values This field indicates the specific URL of the link that will be associated with the graphic that appears at the top-center of the Trading Partner Management Main Menu. The URL should be in this format:

    LOCAL URL: \\YourServer\Directory1\Directory2\yourPage.htm

    REMOTE URL: http::/www.manh.com

    For more information on these values, see their field topics: Center, Right

 

Using the Assigned Users Tab
  1. Use these checkboxes to assign employees with this company. Only employees that you select from this tab will be able to process entities for this company.

 

Using the Interface Tab
  1. Use these fields to identify if data should be interfaced for certain process conditions based on the company.
