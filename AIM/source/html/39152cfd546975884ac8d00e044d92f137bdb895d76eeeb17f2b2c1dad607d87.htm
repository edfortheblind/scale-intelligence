Warehouse Mobile - Pick to Tote

The process involves the user/system picking the items to transport containers which are also called a Tote. The pick to tote can be performed with user or system directed work initiation.

All tote related information is recorded in the tote_header and tote_details table after a putaway or automatic putaway is completed. Read Tote Insight and Tote Details Insight screen for more information

User can pick shipment allocation and shipment container work into a tote.

Configurations

The configuration in the Work Profile and work special handling will determine the validations and user interface flow.

 

User Directed/System Directed - Pick to Tote

 

Work Profile

  • Work Initiation method - User/System
  • Container Picking Method - Pick to tote
  • Select Sort Picked Quantity option to enable users to sort the item.

Note: When Sort Picked Quantity is set the tote records will be marked as eligible with condition to Sort Pending.

If Sort Picked Quantity is not selected, then the tote records will have condition set to Not Eligible. These tote cannot be sorted to putwall locations.

 

Screens Flow -Two screen flow to be used for the pick to tote execution

  • 300 - Tote work initiation
  • 310 - Initiate cart picking with pick to tote . Click for more information

User Directed pick to tote work execution

Perform a user directed pick to tote.

  1. Log in to the Warehouse Mobile application.
  2. Select the Work Execution option from the Warehouse Mobile Main Menu.
  3. Select the Work Profile and enter or scan the Work Unit or Tote ID.
  4. Tap Go to view the Pick Confirmation screen.
  5. Enter the Tote ID and Tap Go. Pick Successful message is displayed, and the system will navigate to the putaway confirmation screen after all the picks are completed.
  6. Tap Go.
Partial and Short Pick

You can also choose Short Pick and Partial Pick.

  • Select the Work Profile and enter or scan the Work Unit or Tote ID
  • Enter/Scan tote ID and Tap Go.

Partial Pick

  • In the Pick Confirmation screen, Actions >> Partial Pick . Read Perform Partial Pick

Short Pick

  • In the Pick Confirmation screen, Actions >> Short Pick. Read Perform Short Pick

Tote Insight and Tote Details Insight screen

 

The tote insight and details insight screen enable the user to search and list the totes for putwall sort. Read Tote Insight and Tote Details Insight screen for more information.

 

Notes

  • Pick to tote supports Shipment and Container work.
  • Cart picking - pick to tote enabled for container work will fail error is message Work tied to shipping containers does not support cart picking to tote .
  • A container work with a nested container will fail with an error message Cannot pick nested container into tote.
  • Lot controlled and serial number tracked items can be picked to the tote.
  • Labor activity is logged for the pick and putaway.
