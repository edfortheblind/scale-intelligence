Locating Strategies Field

This field identifies the locating strategy used to determine where checked in product should be located in the warehouse. A locating strategy determines how the system will attempt to locate product, based on one operational requirement or directive.

 

 

Locating to Multi-Item Locations...

The locating process does a volumetric validation when locating an item to a multi-item location. When locating to a multi-item location, the system compares the current volume of the location's items to the total volume of the location to determine if a receipt container will fit. Note that locating to multi-item locations is done purely on the volume and weight of what it is trying to put there vs. the volume and weight of what is already there. Unlike locating to single item locations, there is no calculation performed to figure out how much of something might fit by flipping the item around.

 

 

Predefined Locating Strategies...

The system provides several predefined locating strategies. Each strategy represents a specific system algorithm that the system will use to locate product. If this location is filled, then the system will split off the remaining quantity and try to locate it (if the Split Quantity Checkbox on the Locating Rule Detail Window is selected). See the Locating Overview for a brief description of each strategy.
