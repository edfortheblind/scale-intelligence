Creating Cycle Count Item Criteria Records

** Use with plan based cycle counting **

 

These records are used by the system to filter the number of locations eligible for a cycle count, according to settings defined on the cycle count master record. The system will then only create cycle count requests for locations that contain items that match this criteria.

Procedures...

 

Access the Cycle Count Item Criteria Window. Name this record and provide a description.

  1. Using the Filter Data Tab: You will use this tab to identify which item(s) you want eligible for cycle counting.
     
  2. Using the Order By Tab: You will not need to use the order by tab functions when creating cycle count item criteria records.
     
  3. When finished, press OK. The system will save your criteria record.
