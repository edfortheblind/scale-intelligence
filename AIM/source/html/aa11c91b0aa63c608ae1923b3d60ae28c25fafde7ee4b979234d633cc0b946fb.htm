Creating Work Types

A work type is a general subset of a work group, based on processing needs or characteristics. For example, batch picking could be a work type of the larger group, picking. In this example, the type identifies all picking work that is ideally processed in batch mode. Many common work types, such as batch picking and order picking, are provided with the system. However, you can create additional work types to support your business needs. Later, you can define work processing rules based on work types on the Work Profile Window.

Procedures...

  1. Access the Work Type Window.
     
  2. Use the Work Type Field to name your new work type.
     
  3. Use the Description Field to provide a text description for your work type.
     
  4. Use the Labor Type Field to describe the type of labor management record you want this work type to generate.
     
  5. Use the Labor Group Field to identify a group of users that perform similar work related functions.

  6. Use the Transaction Count Description to identify the text for a custom field that will appear on the Manual Labor Entry Screen. This text label will also have a numeric field associated with it. For example, suppose you have a work type defined for "Sweeping Floors," which the warehouse janitor is supposed to track their time with on the Manual Labor Entry Screen. If the Transaction Count Description Field has a value such as "Aisles Swept?, the user then could indicate on the Manual Labor Entry Screen how much work they finished during a certain time period.
     
  7. Use the Work Group Field to associate your work type with the appropriate work group.
     
  8. Use the Default Priority Field to determine the priority assigned to all work units for this work type. A user's work profile record includes a From Assignment value. This value determines how the system will sort work for that employee. If the From Assignment Field includes a priority sort, such as the Priority/Location/FIFO value, the system will reference the value defined here.

    NOTE: The priority value is only assigned if the work is performed in system directed mode, via an RF device. If you are processing work via a full screen (non-RF), the system cannot assign based on priority (since you manually assign the work).
     
  9. Use the Pick Management Active Checkbox to indicate if the system will display this work type on the Picking Management processing windows. Only work types that have this checkbox selected will be available to be picked from. Both this checkbox and the From Work Zone on the work instruction must have a value to be eligible for picking from these windows.
     
  10. Press OK. The system will save your record.
