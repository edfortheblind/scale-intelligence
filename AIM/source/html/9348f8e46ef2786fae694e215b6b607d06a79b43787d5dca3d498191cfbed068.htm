Operand Field

The operand field defines the relationship between an attribute and a value. They are primarily used to create rule sets on filter data configuration windows.

 

Value

Description

 

=

Equal to

 

!=

Not equal to

 

<

Less than

 

>

Greater than

 

<=

Less than or equal to

 

>=

Greater than or equal to

 

IS NULL

No value

 

IS NOT NULL

 

Must have a value

LIKE

Similar to another value(s)

 

MATCHES

(operand not used in all filter configurations)

This operand indicates that the field value that you choose as your filter attribute "matches" the database table value of the same attribute.

 

For example, on the Dock Area Anchor Criteria Window, suppose you choose an attribute of Carrier and select an operand of matches. Suppose then, using the anchoring processing, a container (associated with the carrier UPS) arrives at an empty dock area. Now, only containers that are associated with UPS can be anchored at that dock location. However, when those UPS containers are moved from the dock area (and it becomes empty), the dock area can accept any carrier's container (the "matches" anchoring would start again when a dock area houses its next container).
