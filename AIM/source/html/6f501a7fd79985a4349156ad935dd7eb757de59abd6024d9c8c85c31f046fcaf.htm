Appointment Calendar Screen

Appointment calendar screen enables you to view, edit and manage the inbound appointment schedules for every dock of a warehouse.

 

Features of this screen

  • View appointments for all dock doors of a warehouse in the screen.
  • View the calendar in two ways: Day and 7 Days view.
    • Day: view appointments for a 24 hour time line.
    • 7 Day : view appointment for a 7 day time line.
  • Preview the appointment details.
  • Edit the start and end time for an existing appointment.

Viewing Scheduled Appointments

 

The Appointment calendar enables you to manage inbound receipts for the warehouse. Read create an appointment for more details.

 

  1. To view scheduled appointments, navigate to Menu >> Receiving >> Appointment Calendar,

  2. The names of the receiving dock doors are listed under Dock Doors. The corresponding appointment for the door is displayed in the calendar.

  3. Toggle the Day and 7 Days buttons to view the following

    • Day: to view scheduled appointments for a single day.
    • 7 Days: to view scheduled appointment for a 7 day time line.

  4. Click each scheduled appointment on the calendar to view the details such as dock door, carrier, trailer ID, start and end time.

  5. Note: The scheduled appointments are refreshed on changing the selected warehouse. The date and time line on the calendar does not change by refreshing the screen.

Follow the steps to change the warehouse.

  1. In the navigation bar, select the drop-down list to view all the warehouse available for the system

     

  2. Select the warehouse of your choice. The screen is refreshed with the scheduled appointments for the selected warehouse.

When the appointment calendar is opened for Today, then calendar shows the time line for the current time offset by one hour. For example, if the current time is 10 am, then the left most time in calendar will be 9 am.

This feature works when we click Today button from either the Day or 7 Day view. This offset time is configurable in metadata in SDK. Refer to the SCALE SDK documentation for more information.

 

Previewing an Appointment

 

Each scheduled appointment details can be previewed

  1. Click the appointment in the calendar.

     

  2. The pop-up window displays the appointment details such as Door Dock, Trailer ID, Carrier, Start and End time.

     

  3. You can edit all above field values using the Scheduled Appointment screen.

Viewing 7 Day Appointment Schedule

The calendar screen has the ability to display appointments for 7 days from the current date.

  1. Click 7 Days button to toggle from Day to 7 Days view.

     

  2. The appointment schedule for next 7 days from the current date is displayed on the calendar.

     

  3. Scroll the calendar from left to right using the horizontal slider to view all the days in the 7 days view.

     

  4. To view the next 7 days and previous 7 days appointment schedules, click the < and > buttons respectively.

For example:

Today’s/ Current Date is: June 1.

Click 7 Days button.

Calendar displays the appointment schedule from June 1 to June 7.

Click the > button to view the appointments from June 8 to June 14

Click the < button to view the appointments schedule from May 25 to May 31.

 

 

Editing an Appointment

You can edit an existing appointment by following the steps:

 

  1. Select the appointment in the calendar to view the details in the pop-up window.

     

  2. Click Edit Appointment button to view the Receiving Appointment Scheduling screen.

     

  3. Change the Start date time/ End date time as required.

     

  4. Click Save. View the modified appointment in the Appointment Calendar screen.

    .

Note: The button in details window will be Edit Appointment or View Appointment based on user security permission. In case its View Appointment, then you have permission only to view and not to edit the appointment.

See the topic Creating/Viewing Receipt Appointments for more information.

 

Creating a new Appointment

A new appointment can be created in two ways

 

Using the Actions - New button

 

  1. Click Actions >> New to view the Receiving Appointment Scheduling screen.

     

  2. Enter the Start date time and End date time.

     

  3. Select the Receiving Dock from the drop-down list.

     

  4. Enter the Receipt id in the text box. Alternatively you can search for receipt ID in the lookup window.

    .

  5. Click Save and view the appointment created in the Appointment Calendar screen.

     

Selecting the appointment time line.

  1. Select the required dock door and select the time duration for appointment by cursory action of mouse. Click Actions >> New to view the Receiving Appointment Scheduling screen.

     

  2. The selected appointment start and end date time will be displayed. If required, modify the Start date time and End date time.

     

  3. Enter the Receipt id in the text box. Alternatively, you can search for receipt ID in the lookup window.

    .

  4. Click Save and view the appointment created in the Appointment Calendar screen.

See the topic Creating/Viewing Receipt Appointments for more information.
