Defining Wave Pick Location Groups

A wave pick location group record identifies the sequence rules that the system will use when creating picking groups. Each sequence represents a picking group and identifies the work zone(s) or location range where it can be used. Later, you will associate the pick location group record with a picking group record. The picking group record provides additional parameters, such as how many containers can be included in the group.

Wave Pick Location Group Window

Provide a name for this pick location group and a description. Select the Apply Button. Select the New Action. The system will display the Wave Pick Location Group Detail Window. When you access this window, the Detail Records Tab will not contain any values. After you define one or more sequences on the detail window, this tab will display them. This allows you to quickly review the order of the sequence records. You can perform all eligible actions against a sequence from this tab, including opening and deleting (to access the action list, right click or double-click on the sequence).

 

 

Wave Pick Location Group Detail Window

  1. The Wave Pick Location Group Field will default this record's name.

     

  2. The Sequence Field will contain the value 10. You can change the sequence number, but you cannot use the same sequence number for multiple detail records. The sequence number determines when this record will be used. The lower the sequence number, the sooner it's processed.

     

  3. Use the Warehouse Field to identify the warehouse where this detail record can be applied.

     

  4. Use either the Location Range Fields or the Work Zone Check boxes to select the locations where this picking group is used. You can select multiple locations or multiple work zones, but you cannot create a detail record containing both locations and zones. In the screen diagram above, the following work zones are selected: Outside - Off Season and Outside Storage - Bulk. Therefore, when this detail record is applied during a wave, the system will check to see if all of the product in the container was allocated from one of these zones. If all of the product was allocated from either zone, the system will apply this detail record and create a picking group. If one or more items was not allocated from either of these zones, the system cannot apply this detail record and a new picking group is not created. In this case, the system will check the next sequence.

     

  5. To define additional sequence values, select the New Action. The Sequence Field will contain the value 20.
