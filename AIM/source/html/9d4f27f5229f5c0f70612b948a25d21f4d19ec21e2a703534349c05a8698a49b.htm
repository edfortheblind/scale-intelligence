Defining User Attributes

A user attribute is a method of attaching characteristics to certain SCALE users. No default user attributes are shipped with the system, you can create up to 10 attributes, name them whatever you want, and also define the value(s) that are available for each attribute. For example, you could create a user attribute called "Employee Status" and the values full-time, part-time, and temporary. Also, the system tracks these user attributes in Labor Management.

Renaming the User Attribute Text Resource...

The first step in this process is to rename the user attribute field name to reflect what you want it to represent. This way, the system will display the user attribute with the correct name in the User Profile Window. For example, if you renamed the User Attribute 1 field to "Employee Status", then on the User Profile Window's User Attributes tab, the first field on this tab will reflect this new name.

  1. Access the System Text Editor Window.

  2. Choose "Text" as the resource group that you want to search for.

  3. Search for the user attribute resource that you want to rename (for example, USERATTRIBUTE01).

  4. Type the new resource name into the Custom Text Field.

 

 

Defining the User Attribute Values...

The second step in this process is to define what values are going to be available for the user to choose from a particular User Attribute Field. For example, for an "Employee Status" attribute, the user could choose from the values full-time, part-time, or temporary.

  1. Access the Configuration Explorer.

  2. Choose the User Attribute Window.

  3. Create a new record.

  4. Use the Identifier Field to provide the name of the attribute value.

  5. Use the Description Field to provide a text description for this record.

  6. Press OK when finished. The system will save your record.

NOTE: Whether or not that the system will validate for this attribute value is determined by the appropriate setting in the Reviewing User Attributes System Values.
