Activating Staging/Loading Functionality

In order to be able to place/transfer containers/shipments/loads onto staging and/or dock door locations on your shipping dock, you need to first indicate to the system that you want your outbound processing flow to place containers/details into these type of locations. You can do this by placing the following statuses into your status flow (in the Functional Area Window if you are using the default status flow, or the Custom Status Flow Window if you are using a custom status flow). Note that you do not need to add all of these statuses in order to use parts of this dock management functionality (for example, to use staging you do not need to add the status for the loading functionality).
