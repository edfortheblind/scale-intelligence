Defining Carrier Pro Numbers

Complete this procedure for LTL or truckload carriers only. You can use this window to define the pro number range used by a particular carrier. The system will assign one pro number per shipment that it ships with this carrier. This value is used by carriers to uniquely identify a particular shipment. It is displayed on the bill of lading and the truck manifest. Note that you can set up a warehouse alert to generate a history record and/or email message that will notify the user if a pro number range is close to running out of numbers (a configured percentage set in the Rating System Values Window).

Procedures...

Access the Pro Numbers Window, and select the New Action. The system will display the Pro Numbers Window. Generally, this name reflects the carrier associated with these pro numbers.

  1. Use the Pro Number Range Fields to define the range of numbers included in this set.
     
  2. Use the Next Pro Number Field to identify the next number that the system will assign to a shipment (for this carrier). Usually, the next number is set to the first pro number in the range.
     
  3. Use the Pro Number Length to identify how many characters a pro number will be, based on the longest value in the pro number range. For example, if the range is 1 - 1000, the pro number length would be 4. Do not include the prefix or suffix.
     
  4. Use the Pro Number Prefix Field to identify the value that will be added to the beginning of all pro numbers for this carrier. This value is only applied if the carrier requires it. It can be an alpha-numeric value.
     
  5. Use the Pro Number Suffix Field to identify the value that will be added to the end of all pro numbers for this carrier. This value is only applied if the carrier requires it. It can be an alpha-numeric value.
     
  6. Press OK. The system will add the record.
