Warehouse Mobile - Activity Architect

Activity Architect is the user interface utility that enables you to configure (build your own) the SRC screen flow files for Warehouse Mobile (WM). It is designed to make customizations easily and quickly for WM to meet the customers’ requirements.

 

Permission: User needs to have the required permission for Activity Architect.

 

Topics Discussed
  • Landing Page
  • Configuration screen

Landing Page

 

This screen will list out all the SRCs that are configured in SCALE and are grouped by functional area. User can copy or view any record. User’s will only be able to change or delete the custom (non-system created) files.

 

 

Each configuration has three actions that can be performed.

 

Copy () - will open the copy SRC window where the user will need to specify SRC description and File (json file) name (both need to be unique). Once you have the details entered, the system will open in edit mode and will be available for customization.

 

View () - Will open the configuration screen in read only mode and the user will be able to navigate and preview the properties of the SRC file.

 

Edit () - Will open the configuration screen in edit mode where user can make changes or customize the SRC as needed.

 

Delete () - Will be able to delete the custom SRC files created. Note: The SRC record which is assigned to a warehouse mobile menu cannot be deleted.

 

Actions - The actions drop down has the following options

  • New - Click to create new custom warehouse menu record.
  • Configuration - Click to to view the Warehouse Mobile Menu insight screen. For more information read Using Warehouse Mobile Menu Insight

 

Configuration screen

 

This is the User Interface based utility screen where user will be able to customize the SRC screen to meet the customer’s needs.

 

Below is a diagram explaining the user interface layout features of the Activity Architect.

 

1.- Tile of the screen is displayed.

 

2.- The name of the SRC file that is being viewed/edited.

 

3 -. Action Menu - Three actions can be performed which will be displayed in the drop-down on clicking the action menu.

  • View/Edit Config Data Model
  • View/Edit Initial Data Model
  • View/Edit Initial Config Model

4.- Cancel - Discard all the selections and return to the Landing page.

 

5.- Save - All selection/changes for the configuration SRC file is saved.

 

6. - Architect Pane - This pane loads the Json file in a easily navigable tree structure form. You can toggle the nodes and expand the specific areas of requirement. Each node can be expanded and collapsed for entering and modifying the file.

 

7.- Preview Pane - The pane dynamically renders the changes made to the configuration and enables the user to visualize the user interface changes made. Also, when the user selects each node, page or control in the architect pane, the corresponding user interface label gets highlighted.

 

8.- Properties Pane - Each node section that is selected on Architect pane is detailed in this pane. The properties pane enables user to specify the details for the specific control, action, comprised of accordions (properties, information, validation, action modal data and so on) depending on the type of control selected.

 

Note: Refer the Activity Architect User Guide for detailed functional information and examples of customizing SRC screen flows.
