Searching/Viewing Work Order Records...

You can use the Work Order Insight Screen to search for and view work order records in your warehouse.

  1. Open the Work Order Insight Screen.



  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.



  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

The Work Order Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

List Pane Icon Explanation

Certain conditions for the work order are represented by graphical icons on the list pane. Below are explanations of what each icon represents:

Icon Explanation

Work order has at least one line with a pending immediate need associated with it.

Work order has at least one line with an immediate need being fulfilled, and no lines with pending immediate needs.

Work order has at least one line with an immediate need fulfilled, and all immediate needs for the work order have been fulfilled.

Work order has at least one dependent shipment associated with it.


For more general information about the List Pane, see the topic Introduction to Insight Screens.



 

 

About the Detail Pane...

The Work Order Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Work Order Insight contains Indicator Tiles with counts of the other entities (i.e. work order lines, open work, and transactions). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Lines
    1. Displays the number of work order lines linked to the work order.

    2. Clicking on this tile takes you to Work Order Line Insight screen filtering on the given work order number.

  2. Open Work

    1. Clicking on this tile takes you to Work Insight filtering on the given work order number.

     

  3. Transactions

    1. Displays the transaction history of the work order.

    2. Clicking on this tile takes you to Transaction History Insight filtering on the Work Order ID.

       

  4. License Plates

    1. Displays the number of license plates for the selected work order.

    2. Clicking on this tile takes you to Work Order License Plate Insight screen filtering on the Work Order number.

  5. Planned Shipments

    1. Displays the count of those shipments for which status is less than Picking pending.

    2. Clicking on this tile takes you to Planned Shipment Insight filtering warehouse in the basic criteria and internal work order number in the advanced criteria.

     

  6. Waved Shipments

    1. Displays the count of those shipments for which status is greater than or equal to Picking pending.

    2. Clicking on this tile takes you to Shipment Insight filtering warehouse in the basic criteria and internal work order number in the advanced criteria. OTE

NOTE: Planned shipment and Waved shipment count will only be displayed if there are dependent shipments for the work order. After redirection to the insight screens, it will show the result for the dependent shipments for the work order.

 

For more general information about the Detail Pane, see the topic Introduction to Insight Screens.



 

 

Screen Actions

The following actions are accessible from the List Pane:

 

New

This action allows to create a new work order. Clicking on the New action will open the Work Order screen in New mode.

 

 

View/Edit

The View action allows you to open the Work Order Insight screen in the read-only mode and the Edit action allows you to open the Work Order Insight screen in the edit mode. So the View action only permits viewing the work order, while the Edit action permits editing certain fields on the work order.

 

 

Delete

The action allows to delete one or more work orders. The system will prompt for a confirmation message after the delete action is performed.

 

 

New Line

The action helps you to open the Work order Line screen in New mode.

 

 

Allocate All

This action allows you to allocate all the components of a work order. The action is enabled on selecting a work order which has one or more lines/components that are not been allocated. Selecting a work order and invoking Allocate All action will allocate all the work order lines. Refer to Processing Work Orders for more information.

 

 

Deallocate All

This action allows you to deallocate all the components of a work order. The action is enabled on selecting a work order which has line(s) that are allocated. Invoking the action by selecting a work order will deallocate all the lines. Refer to Processing Work Orders for more information.

 

 

Close

This action allows to manually close one or more work orders. The system will prompt for a confirmation message and closing a work order with all allocation and component work completed will return a success message. This action is disabled when one or more selected work order(s) is already closed.

 

 

Confirm

This action allows you to confirm a work order to identify the finished item as complete. Confirming a work order creates the finished item with the default inventory status from the assembler's work order preference. It does not create work when the "Create work" flag is unchecked on the assembler's work order preference. For more information on this topic, refer to the topic Processing Work Orders.

 

 

Immediate Needs

This action enables you to open the Immediate Needs Insight screen with Work Order ID and warehouse filled in the Filter Pane and the search results would be displayed at the same time. Refer to Immediate Needs Note Field for information on Immediate Needs icon colors.

 

 

Print Preview

This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to Printing Paperwork.

 

 

Print Default Docs

This action helps you to print the work order documents (Work Order Assembly Instructions and Work Order Component Pick List) which are marked as default in the Document type.

 

 

Print Selected Docs

This action allows you to select or unselect the work order documents you want to print. The documents will be selected when the work order is checked as a default print procedure on the document type configuration.

 

 

Release

This action enables you to release the work order. This allows confirming the component item work and confirm the finished item. Refer to the topic Processing Work Orders for additional information on releasing work orders.
