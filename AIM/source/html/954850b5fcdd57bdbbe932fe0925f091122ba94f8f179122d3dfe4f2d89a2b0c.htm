Creating Personal Alerts

A personal alert can communicate up-to-date warehouse data to anyone who has an email address. You will need to create a scheduled job to run your personal alert query. Each time the scheduled job runs, the system gathers the appropriate warehouse information resulting from your query. When the system has finished gathering this data, it will send an email to the recipient(s) that you define on the Notification Window. Note that the actual compiled data is attached to the email message as an .csv file. This file format opens into Microsoft Excel, or any similar spreadsheet program. You can access the actual result files in the directory defined for the "Personal Alerts Path" on the Technical Values Window. Examples of personal view queries that you could create are: how many shipments a particular customer has currently pending in the pool, or if all a particular customer's shipments have been confirmed.

 

Notes
  • If the system encounters a problem with generating data from a specific query (i.e., invalid SQL code), the system will generate an audit log record, and no email messages will be sent.

  • To separate data in the personal alerts file, the system uses the Separator value parameter in the Windows' Region and Language Settings configuration.

Active Scale users note:

The personal alert data query is available for Lower level users only.

  • Lower level users.
    • All editable fields will be enabled
    • Can Create, Delete, Copy criteria records
  • Production level user do not have access this screen.

(1) Create a Personal Alerts Data Query Record...

Access the Personal Alerts Data Query configuration window. Create a new record.

 

Active Scale users note:

The configuration is available for Staging and Production level users only.

  • Users can Create/edit/delete records.
  • While editing the existing records, user can only view customer SQL checkbox text and not edit it. Custom SQL text can be selected and copied.
Using the Header Fields
  1. Use the Data Source Field to indicate what system database table you want to choose field values from for this query. Note that the data source that you choose governs what values display on the Data Selection Tab.
     
  2. Select the Custom SQL Check box to enter the SQL code that the system will use to process your query. Note that entering custom code is instead of selecting values from the Data Selection Tab.
Using the Data Selection Tab

- Use this tab to select the values that you want the system to use when generating results from your query.

 

 

Using the Criteria Tab

- You can use this tab's fields to provide additional criteria that data must meet before the query data is generated. For example, you could limit the query to data from a certain company, customer, etc.

 

 

Using the Order By Criteria Tab

- You can use this tab to indicate the order in which you want the system to present the query's results.

 

 

 

 

(2) Create a Notification Record...

Access the Notification configuration window. Create a new record.

  • See the topic Creating Notifications for procedures.

 

 

 

(3) Define a Personal Alerts Scheduled Job...

Access the Scheduled Job configuration window. Create a new record.

  • On the Parameters tab, select a Notification and Data Query that you want the system to use when generating personal alerts with this scheduled job. Also, you will need to decide if you want a personal alert generated if the data query results have not changed since the last time the scheduled job was run.

  • See the topic Creating a Scheduled Job for more information and procedures on the other scheduled job fields.

 

 

 

(4) Run the Personal Alerts Scheduled Job

Access the Scheduled Job configuration window. Open an existing personal alerts scheduled job record.

  • See the topic Creating a Scheduled Job for procedures.
