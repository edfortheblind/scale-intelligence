Researching Data On The Dock Manager Window

You can use the various components of the Dock Manager Window to research current information about containers/shipments/loads on your shipping dock. This topic discusses in detail how you can use these components to better glean information about how efficiently your warehouse's shipping dock is operating.

Quick Reference Table...

RESULTING VIEW / ACTION

 

Home

Button

 

[Home View]

This view returns all components to their initial state (identical to when the Dock Manager Window was first opened).  No staging areas will be highlighted, all data grids will be closed, and any other components that have been minimized will be maximized.

 

Refresh

Button

 

[Refresh Data]

When you press this button, the system updates the data currently being displayed on the Dock Manager Window. Note that you can also refresh data by pressing the F5 button.

 

Percentage

Button

 

[Summary View]

This view displays the staging areas as "percentage-full" progress bars. Each area has a solid bar that is sized to represent how full a staging area and its positions are, and colored to represent the status of the area's contents. No staging areas will be highlighted, and all data grids will be closed.

 

 

Aerial

Button

 

[Aerial View]

This view displays detailed representations of each staging area (including positions, if defined), and indicates the current status of the positions' containers. Any data grids that are open will be closed.

 

Load

Button

 

[Dock Door Shipping Loads View]

This view displays the Shipping Loads Data Grid. This grid has two sections, Assigned and Not Assigned (indicating whether or not the loads listed have been assigned to a dock door). There are two purposes for this grid. One is to research the loads that are currently assigned/destined to a dock door (note that the loads displayed on this grid have not been ship confirmed). The second purpose is to assign/transfer loads to a dock door (see the assign/transfer topic for more details).

 

Carrier Toggle

Button

 

[Carrier Position View -- button toggled on] 

When you select a dock door button, the system displays this view in the Staging Areas component, which shows the staging areas/positions that have containers associated with the load's carrier.

 

 

[Load Position View -- button toggled off]

When you select a dock door button, the system displays this view in the Staging Areas component, which shows the staging areas/positions have containers that are assigned to the dock door's load.

 

Positions Toggle

Button

 

[Staging Area, Positions View]

Positions Grid (Container View) -- button toggled on

When you select a staging area and this button is toggled on, the system displays which positions are associated with the specific staging area (and the status of the contents). The Positions Grid (Container View) has two sections: Assigned Positions and Empty Positions (indicating whether or not a position has a container assigned to it).

 

Positions Grid (Container View) -- button toggled off

When this button is toggled off, the system reverts back to the Positions Grid (Shipment View). See below for a description of this view.

 

Staging

Area

 

[Positions Grid, Shipment View]

This view displays the shipments associated with a specific staging area, and which positions of this staging area are filled. The Positions Grid (Shipment View) has two sections, Assigned Positions and Not Assigned Positions (indicating whether or not containers/shipments have been assigned to an area or a specific position). When you select a staging area that is in its Summary View state, the staging area will be highlighted and brought to the forefront of the screen. The system will display information in the positions data grid, listing the shipments that have been assigned positions and those that have not been assigned positions. It is important to stress that the Not Assigned Positions grid lists containers or shipments that have been assigned to a staging area, but not assigned to a specific position within that area.

 

Dock Door

Button

 

[Load Position View]

When you select a dock door button, the system displays the view, which shows the staging areas/positions that have containers associated with a dock door's load. Note that the system will not display anything if the load's containers have not yet arrived at the shipping dock (they still need to be picked/packed, for example).

 

When you deselect a dock door button, the system will return you to the Aerial View.

 

 

[Reviewing Shipping Load Information]

When you right-click a dock door that is assigned to a load, you can choose the Edit Shipping Load option to review or change the details of the load assigned to this dock door.

 

 

[Creating a New Shipping Load]

When you right-click a dock door that is unassigned to a load, you can choose the New Shipping Load option to create a new load that will be assigned to this dock door.

 

 

 

 

 

Staging Area Color Indicators...

The system uses different colors to indicate the status of the contents residing in the staging areas/positions on your shipping dock. Containers assigned to a position can be at one of two statuses: on hand (meaning that the container is physically present at a location), or in transit (meaning that a container is scheduled to be putaway at a position, but it is not physically there).

 

COLOR

 

DESCRIPTION

 

Blue

Staging Area: If all containers assigned to an area are on hand, the system will color the staging area blue.

 

Position: If a container assigned to a position is on hand, the system will color the position blue.

 

 

Orange

Staging Area: If at least one container is in transit to an area, the system will color the staging area orange. When viewing a staging area in Aerial View (when it is represented by a solid color bar), the bar will be colored orange (in transit), even if there are containers have an on hand status at the dock location. The only time this bar will be colored blue (on hand) is if all containers at the staging area currently have an on hand status.

 

Position: If a container assigned to a position is in transit to this destination, the system will color the position orange.

 

 

Grey

 

Staging Area/Position: If no containers are currently assigned to a staging area/position, the system will color the staging area/position grey.

 

Note On Position

Color When Work

is Created for a Move

 

A position's color (when it is the "from position" on a transfer) will not change when work is created to move a container, unless the following occurs: The container was in transit to the "from position" when you chose to drag-and-drop the container to another position.

 

AND

 

The container is the only in transit container at the "from position." In this case, the position’s color will change from orange to either grey (if the position has no containers on hand) or blue (if the position has containers on hand).

 

 

 

 

 

Gauge Descriptions...

The following gauges are featured on the Dock Manager Window.

 

GAUGE

 

DESCRIPTION

 

PERCENTAGE VALUE DEFINITIONS

 

Pack Complete

 

This gauge tracks the percentage of shipments in your warehouse that have been packed for the current day. These shipments could be currently residing in the packing location or at a staging area. The system selects shipments that meet the following criteria: shipments that have a trailing status greater than In Packing, have not been load confirmed, and the scheduled ship date is today or earlier (this ensures that if a shipment is not packed today, it will still be included in the gauge data for the next day). The system will, however, include shipments that have been load confirmed if the actual ship date is today. In any case, the system will not include shipments with a scheduled ship date that is later than today's date.

 

0 = Indicates that no shipments (that are scheduled to ship on today's date) have been packed.

 

100 = All shipments (that are scheduled to ship on today's date) have been packed.

 

Loaded and Shipped

 

 This gauge tracks the percentage of shipments in your warehouse (with an scheduled ship date of today's date) that have been load confirmed, or currently have all containers at an on hand status at a dock door. The system selects shipments that meet the following criteria: shipments that have a trailing status greater than In Packing, have not been load confirmed, and the scheduled ship date is today or earlier (this ensures that if a shipment is not packed today, it will still be included in the gauge data for the next day). The system will, however, include shipments that have been load confirmed if the actual ship date is today. In any case, the system will not include shipments with a scheduled ship date that is later than today's date. 

 

0 = No shipments at the dock door (that are scheduled to ship on today's date) have been load confirmed, or are at an on hand status at a dock door. In other words, no shipments have left the warehouse today.

 

100 = All shipments (that are scheduled to ship on today's date) have been load confirmed and shipped from the warehouse; or, at least are currently residing at a dock door waiting to be confirmed and shipped.

 

Available Positions

 

This gauge tracks the percentage of staging positions that currently have no containers at an on hand or in transit status.

 

0 = No staging positions on your shipping dock are currently available for container assignment.

 

100 = All staging positions on your shipping dock are currently available for container assignment.
