Manually Assigning Printers (RF)

This feature, found on the RF selection page, allows the user to manually assign a default label printer on the worker’s user profile. This default printer will be used when an RF transaction (e.g., start work or close container) triggers label printing.

Assigning a Label Printer…

 

Open RF:

  1. Select Assign printer from the Selection screen. The system will display the Assign Printer screen.

  2. Enter the printer name in the Printer field.

  3. Click Assign. The system will set the selected printer as the default label printer on the worker’s user profile. A message will be displayed once the printer is successfully assigned.

 

 

 

Clearing a Label Printer…

 

Open RF:

  1. Select Assign printer from the Selection screen. The system will open the Assign Printer screen.

  2. Click Clear. The system will remove the default printer from the worker’s user profile. A message will be displayed once the printer is successfully cleared.
