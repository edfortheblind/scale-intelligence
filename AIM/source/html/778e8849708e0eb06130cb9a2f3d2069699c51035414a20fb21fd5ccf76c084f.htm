Rating ID

Use this configuration to specify the server used to calculate a carrier's rates. Progistics assigns a unique server to each carrier. To enable communication with Progistics, the system requires both the server symbol and the carrier symbol—both of which are provided by Progistics. The carrier symbol identifies the carrier, while the server symbol specifies the server associated with that carrier. For LTL Internal Rating, the Rating ID corresponds to the specific carrier and server symbols used for SCALE internal rating.

 

Create Rating ID Information

 

Rating ID

Use this field to identify the carrier associated with the Rating ID you are configuring.

 

Server Symbol

Specify the server used by the rating system to calculate this carrier's rates. This server may also be linked to the carrier’s website.

  • If using Progistics, this value is defined by Progistics.

  • If using LTL internal rating, this field must be set to 'ILS'. The value is defined in the Rating ID Server Symbols configuration.

 

Carrier Symbol

Use this field to identify the carrier within the rating system.

  • For Progistics, the correct carrier symbol must be provided; otherwise, rating will fail. This value is defined by Progistics.

  • For LTL internal rating, this field must be 'ILS.LTL', as defined in the Rating ID Carrier Symbols configuration.

 

Toggle Buttons

  • Rate at Shipment Level - Select this option if the carrier is an LTL or truckload carrier. This setting causes the system to rate the shipment as a whole, rather than at the container level. Do not select this option for parcel carriers.

  • Rate International at Shipment Level - Select, if you want shipments using this Rating ID to be rated as international shipments. When this is selected, after all containers are closed, the system will prompt you to confirm international rating at the shipment level. Manifesting will take place once all containers are closed.

  • EDI Transmit from SCALE - Enable this option if the carrier transmits parcel data electronically. This is required for UPS and FedEx. For other carriers, consult your Manhattan representative.

  • Update Container Charge at Manifest Close - Select this option if you want the system to update the shipping container and shipment records with the total freight, base freight, and accessorial charges once the manifest is closed.

  • Manifest Required Checkbox - Use this option to ensure that shipments with this carrier are always manifested. Manifesting will rate the container, apply any accessorial charges, and assign a tracking number. This is typically used for parcel carriers.
