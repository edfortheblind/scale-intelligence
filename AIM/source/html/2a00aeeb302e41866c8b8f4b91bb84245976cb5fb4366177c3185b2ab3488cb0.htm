Processing Work

Work execution is the process of how work instructions (generated during work creation) are processed. The procedures in this topic explain how to process work instructions in various stages of completion.

 

Work Special Handling Note
  • Keep in mind that the Work Insight Screen does not reference the work special handling settings (these are for RF work exclusively).

Picking Notes...

  • It is highly recommended that you do not confirm decimal quantities of serial number tracked items when picking.

  • When short picking an inventory serial number tracked item when the for "Short Pick Inventory Action" inventory control value is set to "No count, remove all unallocated on hand quantity" or "No count, remove transaction quantity", the system will remove serial numbers to match the quantity being removed from the location. Note that it will NOT prompt the user for which serial numbers are to be removed, it will simply just choose them. To avoid this, you will need to configure this system value to one of the "Count" options so that the inventory gets moved to Suspense and a cycle count gets generated.

 

 

 

Setting the Completed By User...

This only updates the Completed by User field on the work instruction header and detail. This does not confirm the work instruction.

 

  1. Open the Work Insight Screen.

  2. Select a work instruction detail and click on Completed By User from the actions menu.

  3. Press Save.

    • If selecting the work instruction header, the system will update the Completed by User field on all the work instruction details for the header with the selected user.

    • If selecting one or more work instruction details, the system will only update the Completed by User field on the selected work instruction details with the selected user.

    • The system will update the Completed by User field on work instruction header with the user setting the completed by user on the work instruction details. This is the user signed into the Work insight.

NOTE: Confirming a work unit where some of the work instruction details have the Completed by User set and other instructions that are blank will update the instructions with the blank Completed by User field with the user that confirmed the work.

 

 

 

 

Confirming a Work Instruction...

The procedures below describe how to confirm work using the Work Insight Screen. Confirmations would typically be completed from this screen when users are working off of paper pick lists (or some other non-RF) method. The system will not allow you to confirm a work unit using this window if any of its details reside at a P&D location.

 

You can confirm one or more work instruction headers or details using the Confirm action from the actions menu. Confirming a single work instruction detail shows the Pick Confirmation Screen to confirm a full, partial, or short pick.

 

You will be prompted to enter a serial number when the confirmed work instruction detail contains items that are tracked by serial numbers and the confirmed quantity is less than the entire quantity at the from location. If the To license plate is required, you will be prompted to enter the license plate when confirming single or multiple work instructions (details or headers).

 

Note About Work Profiles and Work Types

If your user profile has a default work profile specified, then the work types defined on the profile details are the work types that you will be authorized to confirm in the Work Insight Screen. If there is no default work profile specified, then you will be authorized to confirm all work types on all work profile details that you are authorized to.

 

 

Procedures

  1. Open the Work Insight Screen.

     

  2. Select one or more work instruction headers or details and click on Confirm from the actions menu.

    3.  

  3. If confirming multiple work instruction headers or details, you will be prompted on whether to confirm the work or not.

    - Upon pressing Yes, the selected work instruction details will be confirmed and closed. Confirming a work instruction header will confirm all the open and in process work instruction details belonging to the header.

  4. If confirming a single work instruction detail, you will see the Pick Confirmation Screen. You will be prompted to enter a serial number when the confirmed work instruction detail contains items that are tracked by serial numbers and the confirmed quantity is less than the entire quantity at the from location. You can confirm a full, partial, or short pick from this screen.

    - Clicking the Confirm option without adjusting the quantity will confirm a full pick.

    - Clicking the Confirm option after decreasing the quantity will confirm a partial pick.

    - Clicking the Short pick option after decreasing the quantity and selecting a reason code will confirm a short pick.

  5. If the To location is license plate tracked, then the system, under certain scenarios, will prompt for the license plate after requesting to confirm the work instruction.

You will be returned to the Work insight Screen with a message indicating the work was confirmed successfully. The confirmed work instruction(s) will be set to Closed. Unconfirmed instructions on the work unit will be set to In Process. Upon confirming the last work instruction on the work unit, the header will also be closed.

 

 

 

Editing a Work Instruction...

You can edit a work instruction that is in a status of open or in process. This is especially helpful if you want to change the instruction's detail information. The system will update the work unit to reflect your changes. If the instruction will be processed from pick lists (non-RF), you should reprint the pick lists and labels to ensure accuracy. Note that you cannot edit a closed work instruction.

  1. Open the Work Insight Screen, and access the work instruction record that you want to edit.

  2. Select the Edit Action. The system will display the Work Instruction Screen. You can then edit the instruction's values. The system will only allow editing to certain fields.

  3. When finished, press the Save button. The system will accept your changes and close the window.

 

 

 

Holding a Work Instruction...

If you release a wave that contains an instruction that's not yet ready to be processed, you can add a hold code on it. The system will not allow anyone to process a work unit that is on hold. The procedures below assume that the wave which generated the work unit(s) was released to the warehouse.

  1. Open the Work Insight Screen. Access the work unit that you want to hold. You can place a hold any work unit that is either Open or In Process. When you place a work unit on hold, the system will not allow anyone to commit work against this unit. This is especially helpful if when you want to assign the work to another employee.

  2. Select the Hold Action. The system will display the Work Hold Screen.

  3. In the Hold Code Field, provide an appropriate reason for the hold. Values defined in this field are not validated by the system, so you may enter any value.

  4. Press OK, and the system will place this instruction on hold.
Removing a Hold Code from a Work Instruction

If a hold code is placed on a work instruction and the wave has been released, the system will allow the hold code to be removed. However, if the removal of the hold code would cause the inventory to go into a negative status, the hold cannot be removed. Note that if a hold code is placed on a work instruction and the wave has not been released, the system will not allow the hold code to be removed.

 

 

 

 

Overriding a Pick Location...

This only updates the From location on the work instruction and related records. This does not confirm the work instruction.

  1. Open the Work Insight Screen.

  2. Select a work instruction detail and click on Override Pick from the actions menu.

  3. Enter a new location.

    • If the item is lot controlled, then you will be prompted to enter a new lot. If the item has a single lot at the location, the lot number is displayed by default.

    • If the new location is license plate tracked, then you will be prompted to enter a new license plate. If the location has a single license plate, the license plate number is displayed by default.

  4. Press the Override option.

    • The system will validate that the values are appropriate for the item you are picking. See the Override Pick General Rules section in Work Processing RF Work (Override Pick) for a list of rules that the system will enforce for an override pick. Note that any rules that reference Work Special Handling settings do not apply to overriding a pick from the Work Insight screen.

    • After successful validation, the system will update the From location on the work instruction with the new pick location, any changes to the lot or license plate along with related records.

 

 

Overriding a Putaway Location...

This only updates the To location on the work instruction and related records. This does not confirm the work instruction.

  1. Open the Work Insight Screen.

  2. Select a work instruction detail and click on Override Putaway from the actions menu.

  3. Enter a new location.

    • If overriding an Inventory location with a parent license plate, then the location is updated for all the parent’s child license plates.

    • If overriding a Shipping Dock location with a parent container, then the location is updated for the parent and its child containers.

  4. Press the Override option.

    • The system will validate the location is appropriate for the item you are putting away.

    • After successful validation, the system will update the To location on the work instruction with the new putaway location along with related records.

 

 

Deleting a Work Instruction...

The procedures below describe how to delete a work instruction from the Work Insight screen. When deleting a work instruction tied to a shipment, the system will update the shipment the work is tied to; specifically, the header, detail(s), and container(s). The system determines the shipment line statuses using the "Default Status When Shipment Is Rejected" outbound status action.

 

A work instruction cannot be deleted if the work is not closed, is active, is on an unreleased wave, the work was generated by replenishment or an inventory transfer AND its quantity is allocated at the To Location, or the work was created from shipment allocation requests, and the allocation request is linked to a shipment line with an associated shipping container.

 

  1. Open the Work Insight screen.

     

  2. Access the work instruction record that you want to delete.

     

  3. Select the Delete Action, and the system will display a confirmation message. Verify that you want to delete this work unit. The system (depending on what type of work the instruction is, and what status it is in) may or may not allow you to delete the instruction.

  4. Press Yes, and the system will delete the instruction and any inventory allocations created to support it.

 

 

 

Changing a Work Instruction's Priority...

You can change a work instruction's priority from the Work Insight Screen. The system will allow this change if the instruction is either Open or In Process.

  1. Open the Work Insight Screen.

     

  2. Access the work instruction record that you want to edit.

     

  3. Select the Change Priority Action. The system will display a window where you can change the priority value.

  4. Select OK. The system will update this instruction.
