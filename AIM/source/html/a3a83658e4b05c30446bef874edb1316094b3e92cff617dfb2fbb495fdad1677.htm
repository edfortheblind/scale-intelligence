Assigning/Transferring Entities To Dock Locations On The Dock Manager Window

You can use the Dock Management Window to manually assign or transfer containers/shipments/shipping loads to locations on your shipping dock. Whether or not an entity is available to assign depends on its status in the outbound flow of your warehouse (has it been picked? Packed?).

 

In this topic, "entities" can refer to containers, shipments, and/or shipping loads.

General Notes...

  • The system will allow you to move product around the Shipping Dock (and create the work to facilitate these moves), even if the shipment and its details were created "post-wave" (thus making the items non-inventory tracked).

  • Irrespective of the success or failure of the container transfer (with regards to the assignment of a load to a dock door), the dock door will still remain assigned.

 

 

Notes On Dock Management Work Creation...

  • When you manually assign entities to dock locations via the Dock Manager Window, the system will create the work to support the physical move that a dock worker would have to perform to place the entity at the destination dock location. Note that there is no way to "turn off" the creation of work in this situation. If a container is on hand at one location and you drag it to another, the system will always create the work to move the container.

  • If you unassign/transfer an entity from a dock location, then the system will update the work instructions for the in transit entity so that the to location is the new destination.

  • When assigning a load to a dock door, if the containers associated with the dock door currently reside at a staging area, the system will generate work instructions to move them to the appropriate dock door.


  • For more information on dock management work creation, please see the Dock Management Process Summary flow diagram.

 

 

Assigning Loads to a Dock Door...

 

ACTION

 

PROCEDURAL DETAILS

 

Assigning a load to a dock door

 

- Using the Shipping Loads grid, select and drag a load to an unassigned dock door button. The system will assign the load to the door (this will assign the load's carrier to the door as well). Note that only one shipping load can be assigned to a dock door at any one time.

 

- Additionally, if you select and drag a shipment or container to an unassigned dock door button, the system will assign the associated load to that dock door.

 

Assigning a container to a load

 

Using the Shipment View grid (Unassigned section), select and drag the container to the dock door button. When you attempt to assign the container to a dock door, the system will ask if you want to assign the whole shipment to the load currently assigned to the dock door. If yes, then the system will assign the shipment and all its container(s) to the load. If no, then the action is canceled.

 

Assigning a shipment to a load

 

Using the Positions grid (Shipment View, Not Assigned Positions section), select and drag a shipment to the destination dock door button. The system will assign all of the shipment's containers to the dock door.

 

Unassigning a load from a dock door

 

To see a load disappear from a dock door button (without confirming the load), you would need to unassign the load from its current dock door from the Shipping Load screen. You can access this window from the Dock Manager Window by right-clicking a dock door and select the edit load action.

 

Transferring a shipment to a different load

 

Using the Positions grid (Shipment View), select and drag a shipment to the dock door button that is associated with the destination load.

 

 

 

 

Transferring Loads from a Dock Door...

 

ACTION

 

PROCEDURAL DETAILS

 

Transferring an assigned load to a different dock door

Using the Shipping Loads grid (Assigned section), select and drag an assigned load to a dock door button. Note that the destination dock door has to currently be unassigned to a load to perform this transfer. Also, if there is anything on hand at the dock door you are transferring from, then the system will prevent the transfer action.

 

 

 

 

Assigning Containers to a Staging Area...

 

ACTION

 

PROCEDURAL DETAILS

 

Assigning a container to a staging area

 

Using the Positions grid (Shipment View, Not Assigned section), select and drag a container to the destination staging area.

 

Assigning a container to a position

 

Using the Positions grid (Shipment View, Not Assigned section), select and drag a container to the destination staging position.

 

Unassigning a container from an staging area

 

Using the Positions grid (Shipment View, Assigned Positions section), select and drag the container to the Not Assigned Positions section of the grid.

 

Unassigning a container from a position

 

Using the Positions grid (Shipment View, Assigned Positions section), select and drag the container to the Not Assigned Positions section of the grid.

 

 

 

 

Transferring Containers from a Staging Area...

 

ACTION

 

PROCEDURAL DETAILS

 

Transferring a container from a position to another position

 

Using the Positions grid (Shipment View), select and drag a container to the destination position.

 

Transferring a container from a position to an area

 

Using the Positions grid (Shipment View), select and drag a container to the destination area.

 

Transferring a container from an area to a position

 

Using the Positions grid (Shipment View), select and drag a container to the destination position.

 

Transferring a container from a position to a load at a dock door

 

Using the Positions grid (Container View) or the Shipping Loads Grid, select and drag a container to the dock door button that is associated with the destination load.

 

 

 

 

Assigning Shipments to a Staging Area...

 

ACTION

 

PROCEDURAL DETAILS

 

Assigning a shipment to a position

 

Using the Positions grid (Shipment View, Not Assigned Positions section), select and drag a shipment to the destination position. The system will assign all of the shipment's containers to the position.

 

Unassigning a shipment from a position

 

Using the Positions grid (Shipment View, Assigned Positions section), select and drag the shipment to the Not Assigned Positions section of the grid. The system will unassign all of the shipment's container(s) from the position.

 

Assigning a shipment to a staging area

 

Using the Positions grid (Shipment View, Not Assigned Positions section), select and drag a shipment to the destination staging area. The system will assign all of the shipment's containers to the area.

 

Unassigning a shipment from a staging area

 

Using the Positions grid (Shipment View, Assigned Positions section), select and drag a shipment to the Not Assigned Positions section of the grid. The system will unassign all of the shipment's container(s) from the position.

 

 

 

 

Transferring Shipments Between Staging Areas...

 

ACTION

 

PROCEDURAL DETAILS

 

Transferring a shipment between staging areas

 

Using the Positions Grid (Shipment View), select and drag a shipment to the destination staging area.
