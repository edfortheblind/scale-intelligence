Reviewing License Key Module Records

This window lists all the SCALE functionality categories (modules) that are restricted by license keys. Call your Manhattan representative if you wish to purchase a new module, or if you have questions about your license key. SCALE license features can be found under License Key Modules in the Generic Configuration Header configuration.
