Locating Process Summary

** Functionality **

 

 

Summary...

 

Locating determines where received product will be stored in the warehouse, based on user-defined rules. During the locating process, the system selects the optimal storage location for containers checked in on the Receipt Workbench or an RF device. You can locate product of multiple items and UMs to the same location, if they are stored in a manually created container. You can locate non-inventory items by UM (unit of measure). The system can generate putaway instructions for located product, based on the user's receiving preference record.

 

You can research locating activity on the History insight screens. Use the Process History insight to research locating activity (decisions). Use the Transaction History insight to research actual locating events.

The following are key features of the locating functional area:

 

Locating Strategies...

A locating strategy is a method for selecting putaway locations based on a storage management goal, such as locating product to those locations already containing that item. Each strategy represents a specific system algorithm that the system will use to locate product. The system includes predefined locating strategies. These strategies allow you to select a location based on specific business needs, such as consolidating product:

  • Item Location Assignment - The system attempts to locate product only to its permanent locations in the warehouse. This strategy is valid only if you have defined permanent locations for items on the Item Location Assignment Window. This strategy is used to locate non-inventory controlled product.

     
  • Consolidate To Location That Already Contains The Item - The system attempts to locate to locations that already contain this item. This strategy helps organize locations based on item. It can also minimize the number of locations that contain an item.

     
  • Consolidate Excluding Different Lots - The system attempts to locate product in a location that contains product with the same lot designation. This strategy will prevent users from picking the incorrect lot, as each lot will exist in a separate location.

  • Consolidate to multi-item location that already contains the item style - The system attempts to locate the products that have the same style characteristic into the same location. This strategy will help users to be efficient during putaway and picking.

    NOTE: This strategy only works for locating by child containers as the data required to consolidate the item style cannot be found on the parent container.
     
  • Fill One And Only One Location Within The Location Selection - The system attempts to locate to a single location within a location selection. After the location is filled, the system will no longer look for locations within this location selection for this sequence. If the system finds a location that already contains this item, it will attempt to fill this location. If this location is already full, or cannot fit anymore into this location, the system will not look for other locations within this selection.

     
  • Empty Location - The system attempts to locate the product to an empty location. Note that it will not locate an item to an empty location that is the permanent location of another item. This strategy is especially helpful when you are locating in a new warehouse.

     
  • Use Specific (Multi-Item) Location Regardless Of Status - The system attempts to locate the product using specific (multi-item) location regardless of the location's status.

 

 

Locating Rules...

A locating rule groups together all the components required to select a storage location to putaway checked in containers. These rules can be assigned manually on the item master, or automatically by the system via the rule set assignment process.

 

Sequences:

Generally a locating rule set includes multiple sequences, which the system processes in numerical order (1, 2, 3, etc.). The sequence identifies the location selection and locating strategy the system will apply during locating.

 

Location Selection:

The location selection record determines which locations the locating strategy can be applied to. For example, if the location selection includes all locations in Zone 'Bulk', the locating strategy will consider only those locations in Zone 'Bulk'.

 

 

 

Delayed Locating...

The system allows you to configure the application to temporarily locate receipt containers to a receiving pre-locate location. This is governed by two settings: the Delayed Locating value on the locating rule, and the Create Putaway Work value on the receiving preference. If both these values are active, then the receipt container is located with work to the receiving pre-locate location. If either value is not active, then the system locates based on the receipt container’s locating rule details. The locating rule on the parent container is used when locating by parent, while the nested container’s locating rule is used when locating by child.
