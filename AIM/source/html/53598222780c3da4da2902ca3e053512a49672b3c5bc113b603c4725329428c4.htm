Text Message

Text Messages provide important instructions or reminders during warehouse operations (Warehouse Mobile or Insight screens). You can configure these messages via the Text Message Window, then link them to items or accounts through the Text Message Assignment Window. Messages are displayed during shipment or dock management work.

To display interfaced shipment comments as text messages, refer to the section Configuring/Displaying Interfaced Text Messages.

 

Create Text message record

 

  • Message ID Field to provide a name for the message. This name will not appear on onscreen.

  • Comments Field to define the text of the message that you want the system to display onscreen.

  • Communication Method Buttons

    • Before the task is executed.

    • After the task is executed.
