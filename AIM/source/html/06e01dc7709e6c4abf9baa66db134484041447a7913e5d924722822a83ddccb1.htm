Upload Criteria Field

This field can be used to filter the below records to be uploaded for the upload process detail. Different filter criteria can be set for each process detail. The system will place the records in the upload directory defined on the interface process detail. If the process detail’s directory is blank, then the upload directory of the interface system value will be used.

 

Active Scale users note:

  • The upload configuration is available for Lower and Production level users only.
  • Lower level users
    • All editable fields will be enabled
    • Can Create, Delete, Copy criteria records
  • Production level users
    • Can view all editable fields. No permission for editing
    • Can select and copy text values
    • Cannot Create, Delete, Copy criteria records.

 

Shipping Upload Criteria

 

  • Records to be uploaded can be filtered using the shipment header fields.

  • Shipping uploads are conditional on the “Include in interface upload” value configurable for each status on the Outbound functional area status flow.

  • Note that the system will upload the shipment data using these records only as the shipment's status changes from one value to the next. The upload will not happen on the initial download of the shipment (regardless of whether that status has been configured for upload).

Receiving Upload Criteria

 

  • Records to be uploaded can be filtered using the receipt header fields.

  • Receiving uploads are conditional on the “Receipt upload level” and “Upload receipt containers at this status or higher” interface system values.

Inventory Transaction Upload Criteria

 

  • Records to be uploaded can be filtered using the transaction history and transaction history attributes fields.

  • Inventory transaction uploads are conditional on the “Include in interface upload” value configurable on the history transaction and adjustment types.

Item Balance Upload Criteria

 

  • Records to be uploaded can be filtered using the location, location inventory, and location inventory attributes fields.

  • Item balance uploads are conditional on the “Include In Item Balance Upload” value configurable on the location class.
