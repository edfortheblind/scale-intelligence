Order Entry Process Summary

** Functionality **

Process Flows

 

 

Summary...

An order represents one customer's request to receive certain items from your warehouse. An order can enter the system via three methods: interfaced from your ERP system; entered manually from the Trading Partner Management web module; or entered manually from the SCALE order entry module. After entry. orders can then be added to a wave, which in turn creates shipments from these orders during the run wave process.

 

The Order Entry Window uses a navigation tool called a wizard, which is similar to ones that are used in other Microsoft Windows applications. When you choose the Order Entry option on the system's desktop, SCALE will ask you to indicate what type of order you want to enter. The system will then display either the Shipment Screen (for single orders) or the Order Entry wizard (for all other order types). You would enter a single order then as you would enter any shipment/shipment line. When using the wizard to enter multiple orders, however, you will need to provide order data in several tabs.

 

SCALE also provides order entry functionality on the web using the Trading Partner Management module. When you enter a web order, the system saves it in a directory on your application server as an XML document. For this data to become a shipment, you will need to import the order file via the Order Entry Window (if the web user is set for "manual" order processing), which gives the opportunity to validate the order information before it enters the system as a shipment. Or, you can choose to have the system automatically save the order XML data to the database (if the web user is set for "automatic" order processing), and the SCALE interface will automatically import the data into the system shipment database tables.
