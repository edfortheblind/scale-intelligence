Using the Shipping Container Insight Screen

You can use the Shipping Container Insight Screen to search and manage shipping containers in your warehouse. All shipping containers in the system will be opened or displayed when there is no filter criteria. The screen allows you to view multiple levels of a shipping container from the topmost to the lowest level. The top-level containers (container without a parent container) will be displayed on navigating from the Containers indicator tile on the Shipment Insight screen. The "Show Only Top Level" toggle will be turned on. The Containers indicator tile on the Shipping Containers Insight screen will navigate to the next level of the shipping container. The Container Contents indicator tile will navigate to the container contents for the selected container.

 

The title and navigation trail on the Shipping Container Insight screen will reflect the level of the container that is being viewed. The title for a top-level container will not display a level.

  • Level 1 is the first level of containers below the top-level container. This is displayed as Shipping Container Insight (1).
  • Level 2, level 3, and so on can be viewed by tapping on the Containers indicator tile from the current Shipping Container Insight screen.
  • A Containers and Container Contents indicator tile with a 0 count indicates the lowest level has been reached.

Searching/Viewing Shipping Container Records...

You can use the Shipping Container Insight Screen to search for and view shipping containers in your warehouse on a tablet device.

  1. Open the Shipping Container Insight Screen.



  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.


    When a user selects a manifest record on Manifest Insight and clicks the View Container action, system redirects to Shipping Container Insight and narrow down containers based on populated manifest criteria in the Manifest Criteria Fields (located on the Filter Pane):

    - Manifest Name, Manifest Status, Rating ID, Shipper Code, and Tracking Number.

  3. Press the Apply Filter button. The system will display all information regarding the resulting records in the List Pane.

NOTE: 

  • Clicking the Container ID link in the results grid opens the Shipping container screen for the selected container. Clicking on the Shipment ID link in the results grid opens the Shipment screen for the internal shipment number associated with the grid line selected.

  • System will return search results only when all the three fields under Manifest Criteria namely Manifest Name, Rating ID, and Shipper Code are specified.

  • The “Show only top level” toggle is turned on by default when navigating from the Containers tile on the Shipment Insight screen to the Shipping Container Insight screen and only the top-level containers will be displayed on the Shipping Container Insight screen. Clicking the Containers indicator tile on the Shipping Containers Insight screen will navigate to the subsequent level of the shipping container.

  • The level of the shipping container is displayed on the Shipping Container Insight screen’s title. Level 1 is the first level of containers below the topmost container.

  • Subsequent levels (Level 2, level 3, and so on) can be viewed by clicking the Containers indicator tile from the current Shipping Container Insight screen. A Containers indicator tile displaying a 0 count indicates the lowest level has been reached.

  • Pressing the Container Contents indicator tile will display the item contents for the selected shipping container.

  • The Navigation History will display all the Shipping Container Insight screens that were previously visited. The filter criteria of all the previously visited Shipping Container Insight screens will also be retained.

  • You can turn off the "Show Only Top Level" toggle when you want to search for more than the top level containers.

 

 

 

 

 

 

About the List Pane...

  • The Shipping Container Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • The List Pane's Grid Fields contains some hidden fields. You can find this complete list of fields by clicking on 'Select columns'.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Shipping Container Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Shipping Container Insight contains Indicator Tiles with counts of the other entities (i.e. open work, and transactions). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Containers
    1. Clicking on this tile reopens the Shipping Container Insight screen to display the containers in the subsequent levels.

  2. Container Contents
    1. Clicking on this tile reopens the Shipping Container Insight screen to display the item contents for the selected container.

  3. Open Work
    1. Clicking on this tile takes you to Work Insight filtering on the internal container number and parent container ID.

     

  4. Transactions
    1. Displays the transaction history of the shipping container.
    2. Clicking on this tile takes you to Transaction History Insight filtering on the Shipping Container ID.

 

     

Screen Actions...

The following actions are accessible from the list pane of Shipping Container Insight screen:

 

 

View/Edit

View action helps you to open the Shipping Container Details Screen in read-only mode. Edit action, on the other hand, helps you to open the same screen in the Edit mode.

 

 

Delete

This action enables you to delete the shipping container from a shipment when no active work is associated with the container and it is at a packing dock location. Also, the container's status needs to be greater than or equal to Picking Pending and less than Load Confirm Pending. A confirmation message will appear when a parent container gets deleted or when the users try to delete a container on a shipment tied to an order. If there are nested containers associated with the parent container, they would also get deleted. For more information on deleting shipping containers, see the Shipment Processing topic.

 

 

View/Edit Accessorials

This action enables you to ship an order with the appropriate accessorials. Selecting a Shipping Container ID and clicking on this opens the Accessorial Assignment screen. Refer to the topic Assigning Accessorials for additional information.

 

 

Close

This action allows you to close a specific shipping container. This action is enabled when there is a container highlighted in the List Pane and the container status is less than or equal to "In Packing".

 

 

Confirm QC

This action allows you to confirming the QC for shipping containers with either pending and failed QC status. Selecting the action will open the QC workbench screen.

 

 

Dock Transfer

This action allows you to transfer container to a dock location from the List Pane of Shipping Container Insight. This option is disabled when the container status is greater than or equal to Load Confirm Pending.

 

 

Manifest

This action allows you to manifest a shipping container, so that the container is added to a container manifest and assigned a tracking number. You can manifest a container successfully when its status is one of the following: In Pool, Picking Pending, In Picking, In Packing, Ship Confirm Pending, Staging Pending, and Loading Pending. This option is enabled when the container has not been manifested and the container is selected in the List Pane.

 

 

Mark for QC

This action enables you to mark multiple shipping containers for quality audit from the List Pane of Shipping Container Insight.

 

 

Nest

If you select multiple containers that are eligible for nesting and click on this action Nest, Shipping Container Nesting screen will open. This action will be enabled for any containers with status less than load confirm pending and greater than or equal to packing pending. Nesting the selected containers onto one of an existing containers of the same shipment will nest all the selected containers on to the 'to container'. The system will display a confirmation massage upon successful nesting. For more information on this topic, refer to Nesting a Container.

 

 

Print Preview

This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to Printing Paperwork.

 

 

Print Default Docs

This action allows you to print the default shipping container documents that have both the print procedure for "shipping container" setting and the default setting selected on the document’s Document Type record.

 

 

Print Selected Docs

This action allows you to print all the selected container level documents. For more information on printing topic, see the Printing Paperwork topic.

 

 

Remove from Manifest

This action allows you to remove a shipping container from a manifest in order to facilitate additional proceedings. However, you cannot remove container from a manifest if the container has not been manifested at the first place and when its status is:

  • Greater than Wave Pending and less than Picking Pending.

  • Greater than or equal to Load Confirm Pending.

 

Remove from Nesting

This action allows you to remove container from nesting. It is enabled only for the containers which are nested. You can select only single container and invoke the Remove from Nesting action. A confirmation message with Yes/No buttons will pop up:

  • If you click on Yes, Nest Container Screen will open defaulting from container as the selected container.

    • Entering/Selecting the To container and tapping on 'Nest' will show the success message indicating that the nesting is successful.

    • Entering/Selecting the To container and tapping on 'Combine' will show the success message indicating that the Combine is successful.

    • If there is a failure to nest/combine, an error message is shown and the container is not removed from nesting.

  • If you click on No, the container will be removed from nesting without opening the nesting screen. The system will show a confirmation message indicating that the container is removed from nesting. Note that Removing the last container from a parent container will delete the parent container.

 

 

Transfer

This action allows you to transfer a container to a different shipment. When this action is selected, the system will open the Transfer Container screen. When the container’s status is less than Load Confirm Pending, this section is available on the List Pane.

 

 

Update Packed Quantity

This action allows you to decrease (unpack) the quantity of the selected item in the shipping container. A window will appear showing the existing quantity of the item in the container. To lower the quantity, specify the quantity that is still in the container. The system will unpack the difference and will write transaction history for the quantity unpacked. If the item is serial number tracked or catch weight tracked, the system will prompt the user for the serial numbers or catch weights being removed. This action is only available on individual items within a loose packed container. It is not available on parent container records or "full" container records.

 

 

VAS Activity

This action can be used to search the VAS activity associated with an individual container of a particular shipment.
