Defining Viewer Colors

You can define the colors of certain sets of records that display after a search query on the results grid of a SCALE viewer window. For example, suppose you want all the data for a specific carrier to be shaded in the color blue. You would then need to create a record in the Viewer Color Editor that defines what color the system should color record(s) associated with a specific carrier.

 

Important: Read the Notes on Viewer Setup before adding colors.

Procedures...

Open your custom viewer record on the Viewers Window. Press the Customize Button, and select the Colors Tab on the Customize Viewer Window. Open an existing color record, or right-click the list and select New Item. The system will display the Viewer Color Editor Window.

  1. Use the Color Field to choose a color that you want to assign to certain records that will display on the results screen. The system will use the rules defined in this window to determine what records it shades using this color. If you do not assign any rules to this color record, the system will shade all results row(s) using this color.

 

Establishing Rules for Color Shading...
  1. You will use the Field Name, Operand, and Value fields to define rules. Note that you will only be able to choose fields that are a part of the database table that the viewer is associated with.

    For example, suppose you have a viewer that displays shipment records. You could assign a separate color the system could use to shade different carrier records. So, when the system displays results from a query, shipments with different carriers are shaded different colors.
     
  2. Or Check box: See the field topic for a description.
     
  3. You can then create more rules, or press OK to save your color record.
