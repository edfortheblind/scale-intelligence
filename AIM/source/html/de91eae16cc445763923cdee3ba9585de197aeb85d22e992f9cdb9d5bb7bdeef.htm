Shipping Container Verification Field

This field determines the method of shipping container verification during picking:

  • None: The system will show the container ID in display mode (no additional user verification needed).

  • Container Verify: The system will require the user to correctly identify the shipping container that is being picked into.

  • Container Spot Verify: The system will require the user to correctly identify the shipping container's spot on the picking cart. Note that this setting is only valid when using group user picking (otherwise the system ignores it).

  • Allow Override: The system will default the container ID in the field, and the user can change this value if desired. The system then would validate this new ID to make sure that it does not already exist.

 

More Details On Picking Into Totes/Shipping Containers...

In the Work Special Handling configuration, there are various settings for shipping container verification that affect how the system handles prompting for a container ID when one is already associated with the shipment. This handling can be different depending on whether the user is picking to tote, picking to a shipping container being created during the picking process, or picking to a shipping container created in the wave. Note that on the first pick for a work unit for work created from allocation requests, the system simply displays a blank input field for the container ID since no picks have yet been done for any ID.
