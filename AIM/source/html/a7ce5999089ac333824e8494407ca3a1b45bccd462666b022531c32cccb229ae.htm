Defining Item Cross References

You can create a cross-reference record for any item defined in the system. Generally, a cross-reference number is established to identify an item's UPC or GS1 number. A user processing an item can use either the item number or the cross-reference number to identify it on an RF device. Packing Note: If you are packing, and a shipment happens to have more than one item that shares a single item cross reference, the system will force you to pack the entire quantity of the first item that appears in the record grid.

Procedures...

  1. Use the Item Field to identify the item that you want to create a cross-reference record for.

     

  2. Use the Company Field to select the company associated with this item.

     

  3. Use the Cross-Reference Item Number Field to identify the number that you want to associate with this item. This value can be an alpha-numeric value.
     
  4. Use the Quantity Unit of Measure Field to associate a quantity UM with an item cross reference. Note that an item/company/item cross reference combination can only be assigned to one quantity UM. Also note that this quantity UM association is used only in certain parts of the system.

    Using With GS1
    You can use this field to assign a default quantity UM to a specific GTIN (Global Trade Item Number). If a quantity is specified on the GTIN, then it will be assumed to be of this quantity UM. For example, suppose you have a beverage item that only is stocked in cases. You would then need to associate a quantity UM of "CS" to this beverage's item cross reference. Therefore, any time this item's GS1 barcode is scanned, the system assumes it is a case (CS).

  5. GTIN Enabled Check box: See the topic Enabling GTIN On Item Or Item Cross Reference for information on this field.

  6. Press OK. The system will save your record.
