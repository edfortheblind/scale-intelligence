Defining a Bill of Material

A bill of material record defines a finished item and its requirements. These requirements include what component parts are required to create the finished item and instructions on how to assemble the finished item from its components. When a work order is generated for a finished item, the system defaults relevant bill of material records on both the work order request and any paperwork generated for the finished item.

Using the Bill of Materials Window...

 

Using the Header Fields
  1. Use the Item Field to identify the finished item.

  2. If this finished item is associated with a company, identify it in the Company Field.

     

  3. Use the Revision Number Field to differentiate between different versions of the same bill of material. If you select the Copy action on an existing bill of material record, the system will replicate that record, and increment its revision number by 1. Therefore, if you have multiple bills of material with the same finished item, when you create a work order, the system retrieves its information from the bill of materials that has the highest-numbered revision. Any other BOM's are ignored.

     

  4. Use the Quantity UM Field to identify the finished item's unit of measure. Generally, you will select the lowest unit of measure available, unless this record supports the creation of multiple finished items.

     

  5. Use the Planned Unit Build Time Fields to identify how long it should take for someone to build one of these finished items. The time is in hours and minutes.

  6. Use the Build Location Field to indicate the location where you want to assemble the finished item that this bill of materials represents. Note that the location specified in this field must be a valid build location (i.e. have a location class of "work order build"). Also, if you do not provide a value in this field, the system will use the default build location defined on the Work Order Preferences Window.

 

Using the Item Characteristics Tab Fields

When you identify the item/company above, the system will default values in this tab's fields if the following conditions exist:

  • The item/company combination is defined in the system on the Item Window.

  • The defaulted values were defined on the item record associated with this finished item.

  • The defaulted values were defined on the item unit of measure record associated with this finished item or its item class.

- If these values are defaulted, the system displays a note at the bottom of the page indicating that these values were predefined. Provide any values that were not defaulted. Note that if you want the finished item to be located to warehouse storage locations, all dimension values must be provided.

 

- The Item Volume Unit of Measure Value is never defaulted. Provide that value and press Apply. The system will add this bill of materials record. You can now define the components.

 

 

Using the Components Tab Fields

 

When you first access the Components Tab, it will appear blank.

  1. To create a new component, right-click in the data grid and select New Component. The system will display the Bill of Materials Detail Window.

 

Using the Instructions Tab
  1. If appropriate, use this tab to provide instructions on how to create the finished item. These instructions print on the Work Order Instructions Assembly Document. They are also displayed on the Work Order. You can define up to 4000 characters on this tab.

 

 

Using the Bill of Materials Detail Window...

 

Using the Header Fields
  1. Use the Component Item Field and the Company Field to identify the component part. If this item was defined in the system, the system will default the item description.

 

Using the General Tab Fields
  1. Use the Build Level Field to identify if component parts are used to create another sub-component. For example, if the employee must first assemble a picture frame (components = frame, glass, back) before it can be included in a gift pack, all of the frame's components would be assigned to a different build level than the remaining components.

  2. Use the Build Sequence Field to identify-when this component is needed, in relation to other components in the same build level.

     

  3. Use the Quantity Needed Per Item Field and the Quantity UM Field to define how many units of this item are required to make the finished item.

     

  4. Use the Allocation Rule Field to associate this component with a particular allocation rule. Note that if you leave this field blank, the system will use the allocation rule as defined on the Item Window.

     

  5. Use the Location Field to indicate that you want this component allocated from a particular location.

  6. The Inventory Tracked Check box will default the value defined on the Item record for this component. If it is not defined on the Item Window, the system defaults the value defined in the Inventory Tracking Field on the Inventory Values Window.

 

Using the Increase Component Quantity Tab Fields
  1. Use the Eligible Check box to indicate that this component qualifies for a quantity increase (over allocation) during work creation for work orders. Note that you can only edit these settings prior to the first time allocation is attempted on the work order.

  2. Use the Compute Qty As Field to tell the system how you want to indicate the amount of extra allocation for a certain component.

    - If "amount" is chosen, then the Increase Qty Field defines a hard quantity for the additional quantity that the system will allocate. Suppose the quantity of the component needed on a work order was 50, and the increase quantity was 10; the system in this case would allocate 60.

    - If "percentage" is chosen, then the Increase Qty Field defines a percentage increase for the additional quantity that the system will allocate. For example, if the quantity of the component needed on a work order was 50, and the increase quantity was 10; the system in this case would allocate 55.

  3. Use the Minimum Required Qty Field to indicate the minimum quantity of this component that has to be requested on the work order before it will become eligible for this component quantity increase.

  4. Use the Increase Qty Field to indicate the actual value of the component increase in allocation. For example, if you wanted the system to allocate ten more components, you would enter "10" into this field. If you wanted the system to allocate fifteen percent more components, you would enter "15" into this field, without a percent sign.

  5. Use the UM Field to view the unit of measure associated with this component.
