Creating/Processing a Shipment Line

When an order is interfaced, the system creates a shipment line that corresponds to each order line. The system will also generate lines when one is split to accommodate warehouse activity, such as inadequate stock. You can also manually create a line to accommodate special circumstances, such as call-in orders.

Creating a Shipment Line...

The following information is a general description of each tab used in creating a shipment line using the Shipment Line Screen. For specific definitions of a certain field, see the "Field Links" section of this topic, or type the field name into the help index.

 

Common Fields
  1. Use the Internal Shipment Line Number Field to view the internal line number that was generated in the interface. The internal shipment line number represents the order line.

  2. Use the Shipment ID Field to view the shipment ID associated with this shipment line.

  3. Use the Internal Shipment Number Field to view the internal number assigned to a shipment in the system. This value identifies the shipment within the system. This value is unique.

  4. Use the Warehouse Field to view the warehouse associated with this shipment line.

  5. Use the Order Number Field to view the order number associated with a specific order request. All shipments are associated with an order. Order numbers originate in the ERP. When interfacing an order, the system assigns it a shipment ID number. All activity in the system is committed against the shipment ID number, not the order number.

  6. Use the Order Line Number Field to view the specific order line number associated with this specific shipment line. The system generates a shipment line for every existing order line number.

 

Item Info Tab

- You can use these fields to enter the item that you want on this shipment line.

 

Quantity Info Tab

- You can use these fields to enter the quantity that you want on this shipment line.

 

Item Dimensions Tab

- You can use these fields to enter the physical measurements of the line's item.

 

Item Characteristics Tab

- You can use these fields to define specific item-level values associated with this line, including such fields as Item Price/Color/Style/Size, Lot/Serial Control, and various allocation and unit of measure settings.

 

Dates Tab

- You can use these fields to view the dates associated with this line.

 

Status Tab

- You can use these fields to view/define information about this line's current status.

 

Advanced Allocation Tab

- You can use these fields when attempting to allocate quantity for a shipment line (this process is sometimes called variable quantity or percent allocation).

 

Packing Tab

- You can use these fields when attempting to associate shipment lines with containers, perform item validation, and generate packing labels.

 

Bill Of Materials Tab

- You can use these fields to view/define a finished items and its requirements.

 

Picking Tab

- You can use these fields to view/define picking associated with a shipment line.

 

Immediate Needs Tab

- You can use these fields to view/define immediate needs request associated with a shipment line.

 

Comments Tab

- You can use this tab to view the comments associated with this line.

 

VAS Activities Tab

- You can use these fields to review or add value added services to this shipment line.

 

Reference Info Tab

- You can use these fields to define various processing values for this line.

 

Classification Tab

- You can use this tab to view the various codes associated with this line.

 

Mark For Tab

- You can use these fields to define the "mark for address" for this line. This address represents the final destination for a shipment with a ship to address.

 

International Tab

- You can use these fields to define fields that deal with international shipping for this line.

 

Categories Tab

- You can use these "category" fields to associate these user-defined categories to this line.

 

User Defined Tab

- You can use these fields to define the user defined fields.

 

When Finished...

- Press Save. The system will add this new shipment line. Its leading and trailing status are determined by the status action value associated with the window that you're creating it on.

 

NOTE: If you created this line on the Shipment insight screen, its status is based on the value defined in the "Add From Shipping" status action setting. If you created this line on the Planned shipment insight, its status is based on the value defined in the "Add From Wave" status action setting. If you created this line on the Order Entry Window, its status is based on the value defined in the "Add From Order Entry" status action setting.

 

 

 

 

Canceling a Shipment Line...

You may need to delete a shipment line to accommodate a customer's request. If a shipment line is part of a wave, then the option is available to cancel the line item. If a shipment line is not part of a wave, see the procedures for deleting a shipment line. When you cancel the line from the wave, the system creates a duplicate shipment in the Planned Shipment Insight with a status of "In Pool."

  1. Access the Shipment Line Insight or the Planned Shipment Insight.

     

  2. Access the line that you want to cancel. Select the Cancel Action.

     

  3. The system will display a confirmation window. Verify that you want to cancel this detail.

     

  4. Press OK. The system will cancel the line.

 

 

 

Deleting a Shipment Line...

You may need to delete a shipment line to accommodate a customer's request. The system will not allow you to delete a line associated with a container or wave. To delete a shipment line associated with a wave, see the procedures for canceling a shipment line above.

  1. Access the Shipment Line Insight or the Planned Shipment Insight.

     

  2. Access the line record that you want to delete, and select the Delete Action.

     

  3. The system will display a confirmation window. Verify that you want to delete this line.

     

  4. Press OK. The system will delete the line.

 

 

 

Transferring a Shipment Line...

You can transfer a line to a different shipment as long as the original shipment has not been confirmed.

  1. Access the Shipment Line Insight screen.

  2. Select the line that you want to transfer to a different shipment.

  3. Select the Transfer Action. The system will display the Transfer Shipment Line Screen. Information about the detail and its current shipment (the shipment you are transferring from) is provided.

  4. Use the Shipment ID Field in the Destination Shipment accordion to identify the shipment that you want to transfer this detail to.

    - If you want to transfer to an existing shipment, you can use the Lookup Search to find a particular shipment.

    - If you want to transfer to a new shipment, select the New action in the Actions Menu. The system will display the Shipment screen in new mode. Define this shipment. Press Save when complete. The system will create the shipment and navigate back to the Transfer Shipment Line Screen. It will display this new shipment in the Shipment ID Field.

  5. Press the Transfer Button. The system will transfer the shipment line to the destination shipment.
