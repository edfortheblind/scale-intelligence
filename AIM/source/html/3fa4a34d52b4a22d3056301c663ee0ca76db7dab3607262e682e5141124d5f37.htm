Prerequisites...

Before you can create a receipt in this screen, you will need to address the "Ship Rec ID Type" and "Ship Rec Type" values on the Receiving System Values screen.

 

 

 

 

Procedures...

In the Shipment Insight Screen, select a shipment and click the action Receipt From Shipment. The system will open the Receipt From Shipment details screen with all the selected shipment related data populated on the screen.

  1. Indicate a warehouse and company for your new receipt.

  2. Select the Go Directly To Receipt Workbench Toggle if you want to load the receipt into the Receipt Workbench. See the Processing Receipt topic for information on how to process a receipt in the workbench.
     
  3. Enter the quantity you want to add to the receipt in the Returned Quantity Field.
     
  4. Press Save. The system will create your receipt. You can access this receipt on the Receipt Workbench.
    NOTE: Users can create receipt from shipment for a shipment with single as well as multiple details. System will use the returned quantity entered for each detail and create receipt with all the details based on inputs.

 

 

 

Screen Actions...

The following actions are accessible from the Receipt from Shipment Screen: 

 

Set Returned Quantities to Zero

This action enables you to set the "Return quantity" on the shipment lines to zero. After setting all the lines to zero and submitting for receipt creation, system will only create receipt without any details.
