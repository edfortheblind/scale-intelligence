Measurements Per Hour Field

This field is included in the Estimated Work Rates Window. It works with the Hourly Rate Field to define the ideal processing output for a particular work type/work zone combination. When work is processed for this work type/work zone, the system will track the activity and compare it against this record. For example, if the Hourly Rate Field contains the value 5 and the Measurement Per Hour Field contains the value Work Units Per Hour, the expected processing output for the work type/work zone combination would be 5 work units per hour.
