Location Status Field

This field indicates the status of a location. Location status are predefined. The system will update a location's status if it changes during processing.

 

Below is a list of the system-defined location statuses:

  • Empty - There is no inventory stored in this location. When you create a new location, you will assign it this status, unless you assign it product immediately.

     

  • Frozen - There is no activity allowed in this location. If product is stored in this location, it will not be allocated. If this location is empty, the system will not assign product to it. This status must be manually assigned to a location. You may want to assign this status to locations that are temporarily unavailable.

     

  • Storage - When product is allocated to a location and physically putaway, the system changes the location's status from Empty to Storage. This status identifies that product has been stored in the location, but no product has been picked yet. Note: if the location has the status Picking, the system does not change it to Storage.

     

  • Picking - When one or more units are physically picked from a location, the system changes its status from Storage to Picking. The location will remain in the Picking status until either its entire inventory is picked or you manually change it to Frozen.
