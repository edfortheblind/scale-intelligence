Carrier Type

A carrier type groups together carriers that share the same basic rate structure. You can review the system created carrier types on the Carrier Type configuration.

 

  • LTL Terms on BOL? Field to determine which VICS legal statement will be printed on a bill of lading.

    • - If Yes, the system will print the LTL legal statement on all bills of lading produced for this carrier type.

    • - If No, the system will print the TL legal statement on all bills of lading produced for this carrier type.

  • One Pro Number Per Load? Field to indicate if you want the system to assign one pro number to represent all the shipments per shipping load. This would commonly be used for loads that use the master BOL paperwork document.
