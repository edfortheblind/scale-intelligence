Configuring DIF HTTP Protocol Properties

To set up the SCALE Device Integration Framework (DIF), you will need to address some configuration values in the application's database. The third step in this process is to configure the DIF protocol properties. A protocol property record contains the specific HTTP data that is used to define the properties of a DIF endpoint. Note that there is no configuration screen to define protocols in the SCALE Configurations Explorer. You will need to configure these values directly in the application database's HTTP_PROTOCOL_PROPERTIES table.

 

Note: For the changes to the HTTP_PROTOCOL_PROPERTIES table to be reflected, you will need to restart the DIF Processing Service.

Access your application database using a database editing tool such as SQL Server Management Studio.

Access the HTTP_PROTOCOL_PROPERTIES database table. Each database row represents the properties of a separate DIF endpoint.

Define values for the following database fields:

 

OBJECT_ID (numeric 9,0): Represents the object ID.

 

ENDPOINT_ID - (numeric 9,0): Represents the endpoint tied to this protocol. This is a mandatory field.

 

DIF_OUTGOING_ENDPOINT_IDENTIFIER : Represents the unique identifier for outgoing endpoint.

 

RETRY_INTERVAL - (numeric 9,0): Represents the time between retry attempts at reconnecting the endpoint connection

 

RETRY_ATTEMPTS - (numeric 9,0): Represents the maximum number of retries at reconnecting the endpoint connection

 

PROCESS_STAMP (alpha-numeric,100) Represents the process entry record.

 

USER_STAMP (alpha-numeric,100) Represents the user name.

 

USER DEF1 - USER_DEF6 (alpha-numeric, 25): Represents user identified values, similar to other places in the system.

 

USER_DEF7 - USER_DEF8 (numeric 14, 5): Represents user identified values, similar to other places in the system.

 

DATE_TIME_STAMP (datetime): Records the date and time

When finished entering values, commit the changes to the database and exit your database editing tool.
