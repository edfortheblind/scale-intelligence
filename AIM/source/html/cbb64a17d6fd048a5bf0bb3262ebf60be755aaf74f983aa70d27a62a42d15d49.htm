Researching TPM Email Alerts

A TPM email alert is a message the system sends to an email address when a specific event occurs. The purpose of this message is to inform an email recipient as to the status of their shipment. The system triggers alerts if a shipment meets a certain system status, or if the system generates a certain piece of paperwork. These alerts can be created/updated from the TPM Email Alert Configuration screen or the SCALE Warehouse Alerts configuration. Note, however, if you want to delete an email alert, you can only do this from the Warehouse Alerts configuration.

 

 

Procedures...

  1. Log on to Trading Partner Management as an external web user (note that internal web users cannot setup TPM email alerts).

  2. Select the Email Alerts option in the Configurations section at the bottom of the screen. The system will display the Email Alerts Search Criteria screen.The system will list the currently-defined email alert(s) in the list at the bottom of this page.

  3. Use the Apply Filter Button to filter the email alerts that are listed on this screen. When you provide value(s) in the search criteria fields, and press the Apply Filter Button, the system will then display only the alerts that match your criteria.
     
  4. Select an alert to view its details. If you would like to sort these alerts, enter value(s) in the search criteria section and press the Apply Filter Button. The system will re-sort the alerts to your specifications.
