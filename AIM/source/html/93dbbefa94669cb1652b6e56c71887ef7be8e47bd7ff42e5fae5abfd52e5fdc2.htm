Processing Vocollect Work

Vocollect voice picking involves the picker speaking commands into a headset, and the system then performing the appropriate pick actions. Voice picking is done with a TalkMan device and headset. The basic flow of Vocollect picking is the same as RF work execution, except that the user speaks commands/data instead of scanning or pressing screen buttons with a stylus. Note that SCALE only supports certain picking functionality with Vocollect. See the Work Process Summary for more details.

Basic Vocollect Terms...

The following are definitions for a few basic Vocollect terms that are used in this topic:

  • Region: A Vocollect term for the set of work to be done. In SCALE, this is referred to as the work profile.

  • Talkman: The physical headset and device that Vocollect uses to gather and transmit voice data. This is also sometimes referred to as a terminal. Typically, a user would strap the TalkMan device to their belt, and wear the headset on their head.

  • Vehicle Type: A Vocollect term for a SCALE equipment type.

  • Vocollect: This is the voice recognition software that integrates with SCALE. Vocollect presents the work to the user via voice command and then accepts voice commands to trigger the execution of work in SCALE. This application can be installed on a separate server or on the SCALE application server.

  • Work ID: This is a Vocollect term for a SCALE work unit.

 

 

Notes Before Starting...

  • When the user turns on a Vocollect Talkman, the device requests the appropriate SCALE configuration data, and modifies its behavior based on these settings.

  • The user will always speak numbers when providing the TalkMan with picking commands or data, unless saying the actual word(s) of a specific Vocollect command (such as Sign Off, Skip Slot, or Yes/No).

  • The TalkMan will respeak most data you speak to it. You can confirm by speaking Yes or No.

  • It is recommended that you sign off/turn off the TalkMan device after the work day is complete. You can only log onto one TalkMan device at a time.

  • When speaking numbers into the TalkMan, be sure to speak each digit separately, as opposed to speaking the whole string. For example, if your password is 12, you would speak "one, two" into the device, not "twelve."

  • When the TalkMan confirms a value, it will speak the word Correct. The user will then confirm by speaking "Yes" or "No."

Other Important Commands...

Below are descriptions of other commands that you can use on the TalkMan device:

  • Sign Off: The TalkMan will ask for a confirmation of this action. If user says Yes, then the TalkMan locks, and you will need to speak a password when you want to use the device again. Current session information (region, etc.) is not saved.

  • Take A Break: The TalkMan will ask for a confirmation. If user says Yes, then the TalkMan will ask for the appropriate work type to use for the break time (as defined in the SCALE Work Type Window). User speaks the number that corresponds to the work type. The TalkMan confirms, and if the user says Yes, then locks. You will need to speak a password when you want to use the device again. Current session information (region, etc.) is saved.

  • TalkMan Sleep: The TalkMan will ask for a confirmation of this action. If the user says Yes, then the TalkMan goes into a powersave mode. Current session information (region, etc.) is saved.

  • TalkMan Wake Up: This command "wakes" the TalkMan from sleep mode.

  • Skip Aisle: This command allows the user to skip the current aisle and move to the next aisle. The user cannot skip if this is the last aisle on the work ID.

  • Skip Slot: This command allows the user to skip the current slot and move to the next slot. The user cannot skip if this is the last slot on the work ID.

  • Pass Assignment: If a user starts working on a work ID, and for some reason does not want to continue working on it, the user can speak Pass Assignment to get out without confirming the work.

  • Say Again: Have the TalkMan repeat the last command. If the TalkMan speaks this command, then it wants the user to repeat a command.

  • TalkMan Help <command>: TalkMan will speak the valid words that can be spoken by the user in a certain situation.

  • Ready: This command is spoken by the user to confirm actions.

  • Change Region: This command will allow the user to use a different region when picking.

 

 

Other Supported Vocollect Picking Flows...

In addition to the "basic" picking flow (outlined in the above procedure), SCALE supports these other voice picking flows. Be sure to address the appropriate fields in the SCALE Vocollect configurations to make sure these methods operate correctly.

  • Pick Into Final Shipping Container: This flow involves either creating the container on-the-fly, or during wave. You can choose to pick into those shipping containers directly. Once you do, you can close and send them out of the door.

  • Pick Into Tote/Transport Container: With this flow, there is no container created during wave, and you need to choose to specify the tote ID while picking. The basic idea here is to pick the items into this transport container. Once you have your items transferred to the shipping dock, the tote is emptied out and is ready to be used by a different work ID.

  • Pick/Pack Via RF Picking: This flow involves not using any container to transfer your items from its location to the shipping dock. You use equipment (such as a forklift) to do the move.

  • Lot Validation: Item validation with lot controlled items using Vocollect is not recommended at this time. However, if you would like to use this functionality, note that you will need to specify the same quantity twice when item quantity is validated.

 

 

Note on How Vocollect Work Instructions Are Sorted...

Below is how the system sorts the work instructions that it sends to a Vocollect device. Note that in some circumstances it is different than how instructions are sorted on an RF device. Note that this only pertains to the sort order of the individual instructions of a particular Vocollect assignment ID. The instructions are sorted in the following fashion:

  • If there is 1 work unit on the current Vocollect assignment and the user chooses the "Normal" sort order, the system will sort in ascending Sequence (from the Work Instruction table) order.

  • If there is 1 work unit on the current Vocollect assignment and the user chooses the "Reverse" sort order, the system will sort in descending Sequence (from the Work Instruction table) order.

  • If there is greater than 1 work unit on the current Vocollect assignment and the user chooses the "Normal" sort order, the system will sort in ascending Sequence (from the Work Instruction table) order.

  • If there is greater than 1 work unit on the current Vocollect assignment and the user chooses the "Reverse" sort order, the system will sort in descending Sequence (from the Work Instruction table) order.

 

 

Procedures: Basic Picking With Vocollect...

Below represents a normal picking flow when performing user or system-directed picks with a TalkMan device.

 

  1. Turn on the TalkMan device. The device will speak your user name. The user will speak Ready.
     
  2. The TalkMan asks for a password. The user will then speak the correct password, such as "one, two" for a password of 12.

  3. The TalkMan speaks the region that is associated with this user.

  4. The TalkMan asks for the Vehicle Type you want to use while picking, such as a forklift. Remember to speak the number, not the name, of the vehicle type.

  5. The TalkMan will speak the picking mode (such as Normal). If multiple functions are supported, the user will need to speak the function they want to use (SCALE currently supports Normal).
     
  6. The TalkMan asks how many assignment(s) the user wants. If more than one (as defined on the Maximum Assignments Field of the Vocollect Region Window) and using the user-directed assignment mode, the TalkMan will ask the user to speak all the work ID's before picking begins. In system-directed assignment mode, the system will assign the work IDs before picking begins.
     
  7. The TalkMan asks for the Vocollect Region you want to use while picking. The user speaks their desired region. A region record determines how the voice picking process is managed (similar to a work profile).

    NOTE: The region permissions for work type will be handled in SCALE at the work profile level. Note that this requires only one work profile detail configured per work profile header. The system will not cycle through the various work profile detail records (within a work profile header) for voice picking. Based on what Function the user has chosen, SCALE will send back the active Vocollect region(s) that are assigned to active work profiles. These records will contain the region number and region name of each Vocollect region.
     
  8. Next, the TalkMan will start the picking process, depending on if your region is configured for user-directed or system-directed picking:

    - If user-directed, the TalkMan asks for the work ID. The user will speak the work ID that they want to pick. Note that you will need to speak the last number of the work ID's digits that is defined on the Work ID Length Field of the Vocollect Region Window). Note that if, for example, there is a delimiter contained in the work ID (because there are two work IDs created with the same ID and appended with a delimiter, such as #00001), the system will return both of these work IDs to the Vocollect device. The Vocollect device would then ask the user to identify which work unit the user wants to process.

    - If system-directed, the TalkMan will begin to process the first eligible work ID (it does not speak the work ID to the user).

  9. The TalkMan will ask for the container type (if appropriate). The user will speak the value. The container types available for picking into a shipping container can be authorized by company and warehouse. See the Defining Container Types for more details.

  10. The TalkMan will ask for the container ID (if appropriate). The user will speak the value.
     
  11. The TalkMan will speak the picking location. This is done segment-by-segment. For example, suppose you need to pick 5 EA from the location 111-AAA-BB (made up of three segments). The TalkMan will speak the first segment, and then the user will say Ready. The TalkMan will then speak the rest of the segments in this manner. Note that if the location has more than four segments, then the TalkMan will speak the first three segments, and then skip to the last segment.

  12. When the last segment is spoken by the TalkMan, it will also speak the quantity and UM of the pick, if quantity verification is activated on the Vocollect Region Window. For example, for the above location, the TalkMan would say for the third segment BB, 5 EA.
     
  13. The TalkMan will ask for a check digit (if this verification is activated on the Location Window). The user will need to speak the check digit. If there is no check digit available, the user will speak the item ID or item cross reference (depending on what is indicated on the Item Reference Field of the Vocollect Region Window). You will need to speak the last five digits of the ID.
     
  14. The TalkMan will ask for the quantity of the pick:

    - Pick Exact Quantity: The TalkMan beeps, says Picking Complete, and then confirms the quantity picked. The TalkMan then asks for another work ID (see beginning of these procedures).

    - Pick Over Quantity: The TalkMan repeats user's spoken pick quantity, and then asks for a work ID. The TalkMan will not process over picks.

    - Pick Under Quantity: If the user speaks a quantity that is less than the full quantity, the TalkMan asks the user if this is a shortage.  If the user says yes, then the system confirms the short pick.  If the user says no (as if he is attempting to partial pick), then the system circles back around and starts again with the quantity request (as if starting the work instruction over). Vocollect will not allow the user to partial pick and move onto the next pick.
