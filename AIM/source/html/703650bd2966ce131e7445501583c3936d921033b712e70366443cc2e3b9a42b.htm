Rating Profile Configuration

The system uses the rating profile record to estimate the number of theoretical containers for shipments that have shipment lines but no assigned shipping containers. During wave processing, actual containers have not yet been created. Because parcel carriers calculate rates at the container level, the system must estimate how many containers are needed.

 

When the "Rate at Shipment Level" flag in the carrier's Rating ID is unchecked, the system bases its estimate on the theoretical container’s weight and/or volume. For example, if a shipment line weighs 100 pounds and the estimated container weight is 25 pounds, the system estimates 4 containers for that line. This estimation helps determine accurate shipping costs.

  • If the "Rate at Shipment Level" flag is checked, the system estimates containers based on the LTL (Less-than-Truckload) class of each shipment line:

  • If a shipment has one line weighing 100 pounds, the system assumes one container of 100 pounds.

  • If there are two shipment lines with different LTL classes, the system estimates one container per class.

  • If multiple shipment lines share the same LTL class, they are grouped into a single container, with the weight being the total of those lines.

Note: When estimating by weight and there is a remainder, it results in an additional container. For instance, if a shipment weighs 110 pounds and the estimated container weight is 25 pounds, the system estimates 4 containers at 25 pounds and 1 container at 10 pounds.

 

Configure Rating Profile

 

General Information

  • Profile Name field to identify this record.

  • Theoretical Container Weight - Specify the typical weight per container. The corresponding UM (Unit of Measure) field indicates the unit. This value is optional. If set to 0, the system will exclude container weight from calculations.

  • Theoretical Container Volume - Specify the typical volume per container. The corresponding UM field indicates the unit. This value is also optional. If set to 0, the system will exclude container volume from calculations.

 

Re-Rate at Ship Confirm toggle to determine if containers associated with this profile should be re-rated during ship confirmation.

  • If the carrier or service is set to system-calculated freight charges and charges already exist for the shipment, this toggle decides whether the system should re-rate it.

  • For parcel carriers rated at the container level, re-rating will involve remanifesting the containers.

  • If there are no freight charges associated with the shipment, the system will automatically rate it during ship confirmation, regardless of this setting.

Change Manifest Date at Ship Confirm toggle to control whether the system should remanifest a container using the ship confirmation date:

  • If enabled, the system will update the manifest date to the ship confirmation date.

  • If disabled, the container retains its original manifest date.

For example, if a shipment is confirmed after midnight, you may want to preserve the previous day’s date for containers that were actually shipped before midnight.
