Searching/Viewing Receipt Container Records...

  1. Open the Receipt Container Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.

 

 

About the List Pane...

The Receipt Container Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

List Pane Icon Explanation

Certain conditions for the receipt container are represented by graphical icons on the list pane. Below are explanations of what each icon represents:

 

Icon Explanation

Receipt container has not yet been through check in.

Receipt container is assigned to a putaway group.

Receipt container is fulfilling an immediate need.


For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

About the Details Pane...

  1. The Receipt Container Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

  2. The Detail Pane of Receipt Container Insight contains header fields comprising of Container ID, Container Type, and Container Status. You can click on the hyperlink in the Container ID field to open the corresponding Receipt Container Details screen.

  3. For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

Screen Actions...

The following actions are accessible from the Receipt Line Insight screen:

 

Edit/View

This action allows you to display and edit a receipt line’s information.

 

 

Cancel Container

This action allows you to cancel the selected receipt container. This action is available only for receipt containers that have been downloaded or created using pre-check in containers prior to its check-in. Canceling the receipt container marks it as closed and removes the inventory from the pre-receiving location.

 

 

Delete Container

This action allows you to delete the selected receipt container.

 

 

Immediate Needs

This action allows you to select an immediate needs transaction for the Immediate Needs Insights screen. For more information on Immediate Needs, see the Researching a Warehouse's Immediate Needs topic.

 

 

Locate

This action enables you to locate a single or multiple receipt containers at a time. Invoking the action by selecting a receipt container will locate the receipt container using the locating rule and user assigned receiving preference (in User Profile) to the receipt container. In case the user profile does not have an assigned receiving preference then the default preference is used to locate. This action is enabled for a receipt container with status 'Locate pending'. For more information on this topic, refer to Checking In and Locating Product.

 

 

Print Preview

This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to Printing Paperwork.

 

 

Print Default Docs

This action allows you to print the default receipt containers that have both the print procedure for "receipt" setting and the default setting selected on the document’s Document Type record.

 

 

Print Selected Docs

This action allows you to print all the selected documents. For more information on printing topic, see the Printing Paperwork topic.

 

 

Remove from Group

This action allows you to remove container from a group. The action is enabled for containers assigned to putaway groups that are not closed. Selecting a container and invoking the action will remove the container from putaway group. You can remove only single container from the putaway group at a time. For more information on the same, refer to the topic Viewing/Closing Putaway Groups.

 

Unlocate

User can unlocated one to many (multiple) eligible receipt containers. The process of unlocated is based on the receiving preference selected for the user. The default preference used in case there are no receiving preference is assigned.

 

Select the records and click Actions >> Unlocate and the system will prompt you to confirm with a Yes or No.

When you selects Yes

  • A successful message will be displayed.
  • Error message will be displayed when all receipt containers fail to unlocate.
  • Multiple errors will be displayed based on the records selected for unlocate. You can read each message to debug failures related to specific records.

When user selects No, system will navigate back to the Insight screen.

 

Significance of color coded validation messages

  • When we have all the selected record is successful - Green
  • When we have partial success selected records. - Orange
  • When all the selected records have failed - Red
