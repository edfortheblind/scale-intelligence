Using the Warehouse Dashboard

The Warehouse Dashboard offers a highly customizable interface designed to meet the specific reporting needs of each user. It now includes enhanced personalization features, integration with custom reports, and actionable insights through interactive widgets.

 

  • Custom Report Integration: Users can now create custom reports in SCI and seamlessly add them to the Warehouse Dashboard.

  • Personalize the Dashboard: Users can now select, remove, and rearrange report widgets in the dashboard.

  • Drill-Down Capability: Navigate directly from widgets to detailed Insight screens.

Warehouse Dashboard Screen Components

 

The different components of the Warehouse Dashboard screen are described here:

 

(A) Global Tiles:

 

The dashboard will only display the tiles you select from the settings option (gear icon) on the navigation bar. Pressing the gear icon will open the Dashboard Customization screen.

  • The dashboard defaults to having no tiles selected for the user. You must choose the action tiles to appear on the dashboard. 

  • There is a “gear” icon on the Warehouse Dashboard screen. Clicking on that opens a window with all action tiles available to you.

  • You can toggle ON/OFF individual tiles. Those that are toggled ON will appear on the warehouse dashboard.

Save Insight Screen Search criteria as Dashboard Tiles

 

You can save your search from any SCALE Insight screen as a tile and display it on the Warehouse Dashboard.

 

  • After performing a search (using either basic or advanced filters), click the icon to save your search as a tile. The system stores all your search criteria and links it to the specific Insight screen where it was created.

  • To display the saved tile on the Warehouse Dashboard, go to the Dashboard Customization settings and enable the "Add to Dashboard" toggle for the tile.

(B) Widgets:

The Warehouse Dashboard displays the widgets that are enabled. Click the gear icon on the Warehouse Dashboard to view the dashboard customization page to manage widget settings:

 

Under Widget Tab,

  • Four base widgets are displayed by default under the ‘Added’ section.

  • Widgets can be rearranged in any order through drag-and-drop.

  • Widgets can be removed by toggling off the Add to Dashboard option.

The four base reports are described below.

1. Outbound – Shipment Status Report

Provides a high-level view of the status of outbound shipments, helping users quickly identify shipment status and its metrics.

  • Displays the count of the shipments grouped by the trailing status.

  • For Closed Shipments, only today’s shipments will be considered.

 

Report

The Donut chart is displayed with the chart categorized with different shipment statuses and their counts.

  • Each segment of the donut chart represents a different shipment status.

  • The number reflects the number of shipments in that status.

Double-click on any segment of the chart to drill down into a more detailed report for that status.

  • In the list, Click on a status such as In Packing to open the related shipments in the application directly.

  • For example In Pool status hyperlink, will open Planned shipment Insight screen.

Note:

  • In Pool status: Opens Planned Shipment Insight screen.

  • Other statuses (example: In Packing, Load Confirm Pending): Opens Shipment Insight screen.

 

2. Outbound – Shipment Line Fill Rate by Week

 

 

Report

The report displays the following details.

  • X-axis:Start Day of a week

  • Y-Axis: Shipment line fill rate %

  • Line Color: Shipment Line Fill Rate%

By Default, View fill rate trends over the current week and the previous 3 weeks.

 

Calculation - Shipment line Fill rate = [(Number of shipment lines where total qty = requested qty)/ (Total number of shipment lines)]*100 for Shipping load trailing status 900.

 

3. Inbound – Today’s Receipt by Status

Displays the inbound receipts that are scheduled and processed today, grouped by their trailing status.

 

  • Double-click on any segment of the chart to drill down into a more detailed report for that status.

    • In the list, Click on a status category hyperlink to open the Receipt Insight screen

    Automatically filters the data to show only today’s receipts with the selected status.

  • For example, clicking on Check-in Pending will display all receipts in that status for today in the application.

 

 

4. Inbound – Dock to Stock vs Average

The time it takes to check in and putaway an entire receipt.

 

 

  • Dock to stock time = Receipt header's close date minus receipt header's start unitized (check-in) date time for receipts with a close date equal to today's date.

  • Shortest dock to stock = Shortest time from dock to stock for a receipt with a close date equal to today's date.

  • Longest dock to stock = Longest time from dock to stock for a receipt with a close date equal to today's date.

  • Average dock to stock = Sum of all the dock to stock times (close date - start unitize date time) divided by the number of such receipts with a close date equal to today's date.

Configure Custom Widget in the Application

The Supply Chain Intelligence custom reports can be rendered on the screen. Follow the steps below.

 

Create a new widget using Dashboard Widget configuration.

Add a new widget to render the customer report from SCI.

  • Navigate to Dashboard Widget configuration.

  • Click the Create New Dashboard Widget button.

  • Provide the following information:

    • Widget ID: Use the name of the report (Example: Outbound- Shipment Status).

    • Description: Brief explanation.

    • Widget URL: Paste the custom report URL copied from the SCI application.

  • Save the widget configuration.

 

Customize Dashboard to add the widget.

  • Click Customize to open the Dashboard Customization screen.

  • Go to the Widgets tab.

  • Use the search bar to find the widget by the ID or name you created earlier.

  • Enable the "Add to Dashboard" toggle for the widget.

  • Click Save to apply changes.

Open the Warehouse Dashboard screen to view the added widget.
