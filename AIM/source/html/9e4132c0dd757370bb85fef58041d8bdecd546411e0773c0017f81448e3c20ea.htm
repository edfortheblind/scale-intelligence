Using the General Tab

You can use this tab to tie together the different components required to create work from work requests.

  1. Use the Work Type Field to associate a work type with this master. The work type links this master to the eligible work profile records. A work profile manages who is assigned to process the work.

     

  2. If necessary, use the Work Unit Field to select the value that will identify each work unit generated for this work creation master. For example, if the value ERP Order is defined, when a work instruction is generated using this record, the ERP order number is displayed as the instruction number. The default work unit value is defined on the Work System Values Window.

     

  3. Use the Creation Method Field to indicate if the system will use this master to generate work. To use this master to generate work, select the Pre-Build Option. The system will generate work using this master (during the wave cycle). To prohibit using this master to generate work, select the Inactive Option. In this case, the system will not refer to this master during work creation.

     

  4. Use the Priority Field to identify when this master should be selected during work creation, in relation to the other work creation masters. During the wave, the system cycles through work creation masters in priority order. The lower the priority number, the sooner the master will be used: the master with priority 1 is processed before the master with priority 2.

     

  5. Use the Process Field to identify which work creation process this master is for. During creation, the system will reference particular database tables based on the value that you define here.

     

  6. Use the Work Criteria Field to associate this master with the appropriate work criteria. This value determines which work requests will be processed using this work creation master. It also determines how the work instructions will be organized. Note that if you complete this step after you define a value in the Process Field, the system will only allow you to select criteria values for that particular process.

     

  7. Use the SRC identifier to associate the master with the appropriate SRC identifier. System will use the configured SRC identifier during work creation and update the work created with the SRC identifier from the work creation master. This can be done for all work created in the system except cycle count. For cycle count, we need to define the SRC identifier in Cycle count system values.

     

  8. Select the Auto Print Documents Checkbox if the pick documents should be printed as soon as they are generated. If you select this checkbox, the system will print the documents as soon as the work creation step is completed. Note that if you select this checkbox AND the pick list document type is defined in a document master record, the system might generate the pick lists twice: first after work creation runs and second after paperwork runs. This will give you two sets of pick lists generated during one wave cycle.
Using the Maximums Tab
  • You can use this tab to set maximum capacity rules for a work unit. It includes maximum values for quantity (number of item units), weight, volume and instructions. As the system is creating a work unit, it will reference the values defined on this tab. As soon as it reaches the limits defined here, it will close the work unit and generate a new one. You can use any combination of these fields to define the maximums. If you define multiple maximums for a record, the system will close the work unit as soon as it reaches any one of these maximums. Use the field topic links on the summary page of this topic to find out more information about these fields. Note: that the system will not split a detail record as a result of the value exceeds the maximum in and of itself.
     
  • If you want to create a record with no maximums, leave the '0' value in all fields. If you leave the Maximum Instruction Field value '0', the system will include up to 500 instructions in a work unit. If more than 500 instructions can be processed using this creation record, the system generates additional work units to support the remaining instructions.
     
  • All of the maximum values can be applied to the following work: shipping containers, allocation, replenishment, work order line, and work order for finished items.
     
  • Cycle Count Work Note: Only the maximum number of instructions value can be applied to cycle count work.
