Creating Cycle Count Quick Plans

A cycle count "quick plan" allows you to choose plan variables at the time of plan creation, including the types of items/locations that will be counted, and the number of counts that the system will create from this plan. Note that quick plans differ from cycle count "master plans" because the quick plan settings are not stored as a configuration record for future use. Once a quick plan is created and released, the plan settings are not retained by the system. You can access the Cycle Count Quick Plan screen from Cycle Count Plan Insight through the Quick Plan action.

 

When creating a quick plan, you can define any setting available on the Cycle Count Master configuration. Additionally, some extra settings are provided, such as limiting locations counted to multi-item/permanent/LP-tracked locations, and limiting items counted to serial number-tracked items.

 

You can manually create a cycle count quick plan from the Cycle Count Plan Insight screen. Note that once a quick plan is created, it functions in the same manner as a master plan (with regards to the release, close, and delete actions). See the topic Using Cycle Count Plans for more information on these plan actions.

Manually-Created Quick Plans...

You can manually create a cycle count quick plan from the Cycle Count Plan Insight screen either by choosing the Quick Plan option from the Actions Menu, or by selecting this option from the right-click menu of the Active Plans Node. Note that you can enter any combination of values on the various criteria view pages.

 

 

 

Note On Wildcard Values...

For several fields on this window, you can use a wildcard value (a percent sign) to indicate that you want the system to consider a range of a criteria field when creating a quick plan. For example, you could enter an Item value of ITEM2%, and the system would generate counts for all items that begin with the prefix Item2. Other fields you can perform wildcard searches on include Location and Lot (among others, including the non-numeric item user-defined fields).

 

 

 

Button Actions...

- Use the Create Plan button or Create button (in the Cycle Count Quick Plan Screen) to have the system create your new quick plan. After pressing this button, the system will display a message that indicates how many cycle counts it will create for this quick plan, and ask you to confirm that you want to proceed with this quick plan creation. You can press Yes to create the plan, or Cancel to further modify your selection criteria.

 

- Use the Clear Button to restore the original field defaults and erase all the user-entered field values. This button is available only for the Windows version of the application.

 

 

Procedures: Plan Preferences Criteria View Fields...

  1. Use the Description Field to provide a text description of the quick plan you want to create. The system will include this description with the quick plan's ID on the Cycle Count Plan Insight screen (this allows for easy identification of your quick plans).

  2. Use the Maximum Number of Counts Field to indicate the most cycle counts that the system can generate for your quick plan. If you do not provide a value, then the system will generate all counts that meet the quick plan's criteria.

  3. Use the Counts Per Group Field to indicate how many cycle count requests you would like the system to group together during quick plan creation. Note that a zero or blank value indicates unlimited size. When you open the Cycle Count Quick Plan Window, the default value for this field is taken from the "Default Cycle Count Group Size" setting on the Cycle Count System Values Window.

  4. Use the Positive Adjustment Type Field to indicate the inventory adjustment type the system should use when performing positive inventory adjustments during the cycle counting process. If this value is left blank, the system then will use the adjustment type value specified in the "Planned Count - Positive Adjustment" cycle count system value setting. The system will display the user and warehouse authorized adjustment types.

  5. Use the Negative Adjustment Type Field to indicate the inventory adjustment type the system should use when performing negative inventory adjustments during the cycle counting process. If this value is left blank, the system then will use the adjustment type value specified in the "Planned Count - Negative Adjustment" cycle count system value setting. The system will display the user and warehouse authorized adjustment types.

  6. Use the Create Work Checkbox to indicate that you want the system to create work for each request that is generated from this quick plan. When you open the Cycle Count Quick Plan Window, whether or not this checkbox is selected by default is determined by the “Create Activity Driven and Quick Plan Cycle Count Work” setting on the Cycle Count System Values Window.

  7. Use the Update Cycle Count Work to Include All Items Checkbox to have the system create cycle count requests for all items currently at a multi-item location, as opposed to creating requests for just the item(s) at the location that match the cycle count item selection criteria.   Note that when a multi-item location is initially empty and then items are adjusted into it (prior to the cycle counting work being executed), the system will create a cycle count for every item adjusted into the location, regardless of whether this setting is on or off.

 

 

Procedures: Location Inventory Criteria View Fields...

  1. Use the Location Field to indicate the location(s) for which you want the system to generate cycle counts using this quick plan.

  2. Use the Item Field to indicate the item(s) for which you want the system to generate cycle counts using this quick plan.

  3. Use the Lot Field to indicate the lot(s) for which you want the system to generate cycle counts using this quick plan.

  4. Use the Company Field to indicate the company(s) for which you want the system to generate cycle counts using this quick plan.

  5. Use the Warehouse Field to indicate the warehouse for which you want the system to generate cycle counts using this quick plan.

  6. Use the Item Class Field to indicate the item class for which you want the system to generate cycle counts using this quick plan.

  7. Use the Inventory Status Field to indicate for which status you want inventory to be in when the system to generate cycle counts using this quick plan.

  8. Use the Expires By (In Days) Field to indicate the age a lot's expiration date should be in when the system is deciding which item quantities it should generate cycle counts using this quick plan.

    Blank = The system will not consider expiration date when including lots.

    0 (zero) = The system will include all lots that have already expired.

    1 = The system will include all lots that expire on today's date.

    Greater Than 1 = The system will include all lots that fall into a time span between today's date and a future date. For example, if you entered 10, then the system would include all lots that expire within the next ten days.

 

 

Procedures: Item Characteristics Criteria View Fields...

You can use the criteria fields on this view to have the system select items to count based on specific item characteristics such as list price, size, style, or color. You can also further define this criteria using the following settings:

  • Use the Multi-Item Locations Checkbox to indicate that you want the system to consider locations that house multiple items when generating cycle counts using this quick plan.

  • Use the Permanent Locations Checkbox to indicate that you want the system to consider locations that house items permanently when generating cycle counts using this quick plan.

  • Use the Serial Number Tracked Items Checkbox to indicate that you want the system to consider items that are serial-number tracked when generating cycle counts using this quick plan.

  • Use the License Plate Tracked Locations Checkbox to indicate that you want the system to consider locations that are license plate-tracked when generating cycle counts using this quick plan.

 

 

Procedures: Item Categories Criteria View Fields...

  1. Use the Item Category Fields to indicate that you want the system to consider special user-defined categories of item information when generating cycle counts using this quick plan. These categories are defined in the Item Category configuration windows. 

 

 

Procedures: Locating Zones Criteria View Fields...

  1. Use the Locating Zone Checkboxes to indicate the locating zone(s) for which you want the system to consider when generating cycle counts using this quick plan.

 

 

Procedures: Location Types Criteria View Fields...

  1. Use the Location Type Checkboxes to indicate the location type(s) for which you want the system to consider when generating cycle counts using this quick plan.

 

 

Procedures: Item User Defined Criteria View Fields...

  1. Use the Item User Defined Fields to enter in any item-related user-defined data information. Note that these fields correspond exactly to the user-defined fields that appear on the Item Window.
