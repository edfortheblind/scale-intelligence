Reviewing Application Identifiers

An application identifier is a segment of a GS1 barcode that represents the data that the barcode section contains. The identifiers provided with SCALE are standard for GS1 processing, and typically should not be edited. The application identifiers defined in this window mimic the requirements set by the GS1 standards association.

Procedures...

  1. The Application Identifier Field indicates the name of the AI. These are standard identifiers that cannot be changed.
     
  2. The Default SCALE Mapped Field indicates the value in the system that this AI will represent. For example, the GTIN application identifier maps to SCALE's "Item" field. This field allows the user to change the Default SCALE Mapped Field between the Item and Item Cross Reference fields for the 01 and 02 identifiers only. Note that none of the other AIs use this field.
     
  3. The GS1 Title Field indicates the name provided for this AI by the GS1 standards association. This value is not used in SCALE GS1 processing.
     
  4. The String Format Type Field indicates if this AI will have numeric or alphanumeric values.
     
  5. The String Length Field indicates the character length of this AI's value.
     
  6. The String Length Type Field indicates how SCALE will expect GS1 data to enter the system when scanned:

    - Fixed Length: The data value has to be of a certain size, or the system will return an error when the AI is scanned. For example, if the value is set at a length of three characters, then every value for this AI must be three digits (such as 002, 012, 124).

    - Variable Length: The data value can be of any size.
     
  7. The Decimal Indicator Checkbox is not used at this time.
     
  8. Press OK.
