Defining Comment Types

A comment type identifies when a specific message should be added to the paperwork associated with a document type: it links documents and messages together. Each comment type is defined in both the ERP and the system. When you define a comment type on this window, make sure it matches the comment type defined in the ERP. If these two values don't match, the system won't know what comments to print on a document. Later, you will associate this comment type with the document types that you want it to print on.

Procedures...

  1. Use the Comment Type Field to identify the comment type. The name you define here must be the same value that you defined on the ERP for this comment type. When this comment type appears on a shipment, shipment line, or work instruction, the system will reference back to the ERP and obtain the message associated with the comment type there.

     

  2. Use the Description Field to describe the comment type. This value does not have to match anything defined in the ERP. This value is for informational purposes only.

     

  3. The Communication Method Buttons determine when the system will display a comment on an RF device. NOTE: The system ignores the "before/after" designation when displaying comments on paperwork documents (such as pick lists).

     

    • Before: The system will display the comment before it displays the work instruction.

       

    • After: The system will display the comment after the work instruction is executed.

       
  4. Press OK. The system will save your record.
