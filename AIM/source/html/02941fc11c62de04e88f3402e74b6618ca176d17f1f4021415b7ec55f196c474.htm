Consolidation Criteria

A consolidation criteria record specifies a single attribute that two shipments must have in common for consolidation to take place. If more than one criterion is defined, the system will only consolidate shipments that meet all of the specified criteria. Typical criteria include Ship To, Company, and Warehouse.

 

Add New Criteria

 

Table Field: Select the shipment attribute to be used as a consolidation criterion. Common fields include Ship To, Carrier, and Requested Delivery Date.

  • In manual consolidation, only those criteria marked as "Required" must match.
