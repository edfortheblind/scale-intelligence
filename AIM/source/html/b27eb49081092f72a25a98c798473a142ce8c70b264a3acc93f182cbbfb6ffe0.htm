User Type Field

In Trading Partner Management...

This field indicates the type of access a web user will have on the Trading Partner Management website. There are two types of web users: external and internal.

 

External

External web users include users of the TPM website that are not employed by your organization. For example, a business partner or supplier. External users can access the complete website.

 

Internal

Internal web users include employees of the company that is hosting the TPM website. For example, employees using the company intranet or working offsite. Internal users cannot access the Email Notification Setup Page or the Statistics Page.

 

 

On the User Activity Insight Screen...

This field indicates the following:

- Full Screen: Indicates that you want results returned for all activity by full-screen system users.

- RF: Indicates that you want results returned for all activity by system RF device users.
