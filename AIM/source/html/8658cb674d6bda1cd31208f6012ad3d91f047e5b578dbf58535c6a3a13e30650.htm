Using the System Text Editor

You can use the System Text Editor to edit SCALE resource values. This is especially helpful if you want to add a custom graphic or change a term used on system windows. There are four types of resource files that you can modify: text, messages, images, and help. Also, there is one of these resource files for each language that you support. For example, if you support English and Spanish: there is an English text resource file and a Spanish text resource file. For detailed descriptions of each type of resource file, see the descriptions below. The System Text Editor also includes two tools (Translation Wizard and Localize Reports) to assist you with translation management.

Resource File Type Descriptions...

  • Text: This resource file consists of text labels that appear throughout the system, such as field names or menu options. Any change that you make to a value here is applied through the entire system. For example, if you change the word File to Start, all instances of the word File in the system's menus, toolbars and fields are changed to Start. Of course, phrases that include the word changed are not impacted.

  • Messages: This resource file contains all error messages and warnings generated by the system. These messages are tied to processes, not to particular screens. This allows them to be reused throughout the system on multiple screens.

  • Images: This resource file contains all graphic images used in the system, such as browser icons. If you want to add a new graphic to the system, you must first add it to the resourceImage directory on your server. It is located in a system directory and contains all graphics available to the system. Currently, the system supports the following graphic file types: .bmp and .gif

  • Help: This resource file contains the names/paths of help topics associated with system windows. Do not change a help name/path without discussing possible ramifications with your system consultant.

 

 

Screen Resource Key Shortcut...

You can press the key combination CTRL+R on any SCALE window, and the system will display the resource keys for all the fields on the current window. Note that if you press this sequence again, you can toggle back on the field's actual display name.

 

Results Row Coloring

Values that have had custom text provided for them are colored yellow.

 

 

 

Editing Resource Group Values...

You can use the System Text Editor Window to edit values in a resource group. This is especially helpful if you want to replace a default word with one that reflects your business or if you want to add your own graphics to the system.

 

Security Note

By default all users will have access to delete, edit and create resources from the System Text Editor. The system administrator can create User, Group or System security to restrict users from modifying resources.

 

Note: In web.configuration, Text Localization is the new name for this functionality. You can also delete and create custom resource keys based on base resource keys.

 

Access the System Text Editor Window.

  1. Use the Language and Group Fields to identify which resource group contains the values that you want to modify.

     

  2. Use the Additional Criteria Fields to narrow your search for records. The system will filter through the resource group's records and display only those that meet this criteria. You can use any combination of these fields.

     

    • Use the Key Field if you know the actual key name that you want to access. The key links the text, message, or image to the base code in the system.

       

    • The Screen Field is reserved for future use.

       

    • Use the Search Text Field if you know the name, or part of the name, of the value that you want to access. When you provide text here, the system displays all instances of this text in the record list. If you want to change all instances of this value, provide the replacement value in the Replace Text Field.

       

    • Use the Custom Text Only Checkbox if you only want to search for custom values. If you select this checkbox and provide a value in the Replace Text Field, the system will only replace custom values; base values will not be impacted.

       

    • Use the Case Sensitive Checkbox if you want the system to consider case when searching for values. When its selected, the system will only display those values with the same case as the value you defined in the Search Text Field.

       

    • Use the Search Text and Replace Text Fields to subset a search for a specific text string. When you enter a value in the Search Text Field, the system will search for your data in the "Base Text" column of the resource group (see the graphic below). When you enter a value in the Replace Text Field, the system will replace the Search Text Field value with the data you provide in this field.

       

      Note: You cannot use the Replace Option if the Group is Images.

     

  3. Select the Search and Replace Button. Did you provide a replacement value in the Replace Text Field?

     

    • If you used the Replace Text Field, the system will display all values that met your search in the record list. Your replacement value will appear in the Custom Value Column. The original value appears in the Base Value Column. You can change any of the values in the Custom Text Column, or remove them. This is especially helpful if you want the custom value to apply to most keys in the system, but want to further modify a few specific keys.

       

    • If you did not use the Replace Text Field, the system will display all values that meet your criteria in the Base Value Column. Any existing custom values are displayed in the Custom Value Column. Use the Base Value Column to locate the value you want to change. In the corresponding Custom Value Column, provide the new value that will replace this base value. If the Group is Images, the Custom Value Column is a pull-down menu that you can select the graphic from.

     

    If you are changing a time and/or date entry, it will include an ampersand (&) in the base value. You can move the ampersand in the custom value, but do not remove it! The system reads ampersands and replaces them with the appropriate time and/or date calculation.

     

  4. Select Apply. The system will display a message verifying that you want to commit this change to the database. Select Yes. The system will commit this change to the database. This change will impact the system's screens and windows as soon as the application is closed and reopened. An IISRESET is required to see changes in browser-based or WPF screens. The Text Last Updated phrase, at the top of the screen, will change to the current date and time.

     

  5. Repeat steps 1 – 4 to search and replace resource values for other languages or groups.

     

  6. Select Close to exit.

    WARNING: If you cannot see changes made in the System Text Editor after exiting and re-entering the system, a shutdown of the system package(s) in Component Services may be required.

    NOTE FOR BROWSER-RELATED SETTINGS: When you change a browser-related (TPM and RF) or WPF (Desktop and Dock Manager UI) resource file value, this new value will not take effect until the Windows IISRESET command is executed. This command completely shuts down and restarts IIS, so it should be performed when no one is using the TPM, RF or WPF screens.

 

Custom Values & New Releases

A new release of the system will have NO impact on a custom value. However, custom values are not automatically applied to new keys in this release.

 

 

 

Editing/Creating a Base Value...

You cannot modify a base value's field length or its decimal position. Instead, you will create a custom value that is exactly the same as the base value. Then, you can change this custom value's field length and/or decimal position. See the topic Defining Editable Field Decimal Positions topic for more information on this subject.

  1. Use the Language and Group Fields to identify which resource group contains the values that you want to modify.

  2. Use the Search Fields to locate the base value that you want to modify. See the procedures for "Editing Resource Group Values," (Step 2) for more information on the search fields.

  3. Right click on the appropriate base value. Select Open Custom Value. The system will display all of the base values for this new custom value. You can change any of the following fields: Custom Text, Field Length, and Decimal Position.

  4. Apply these changes. Generate a new Resource Group. Close and Reopen the system. See the procedures for "Editing Resource Group Values" (Steps 4-6) for more information about these procedures.

  5. When you access the value in the system, its field length and/or decimal position will reflect the changes that you made to the custom text.

 

 

Editing/Creating a Custom Text Value...

You can change the following characteristics for a custom value: field length and decimal position. You can also create a new custom text value.

  1. Use the Language and Group Fields to identify which resource group contains the values that you want to modify.

  2. Use the Search Fields to locate the base value that you want to modify. See the procedures for "Editing Resource Group Values" (Step 2) for more information on the search fields.

  3. Press the Search Button. The system will display the results in the record list.

  4. To edit a value, right click on the appropriate custom text value, and choose the "Open Custom Value" option. The system will display all of the base values for this new custom value. You can change any of the following fields: Custom Text, Field Length, and Decimal Position.

    To create a new value, right click on a custom text value and choose the "New Custom Value" option. The system will display the a window where you can define the specifics of your new custom text value. Press OK when finished.

  5. Click Apply to commit the changes. Close and Reopen the system. See the procedures for "Editing Resource File Values" (Steps 4-6) for more information about these procedures.

  6. When you access the value in the system, its field length and/or decimal position will reflect the changes that you made to the custom text.

 

 

Localizing Reports...

 

If you edit or translate a paperwork document field in the System Text Editor, you will need to "localize" the resource values of these documents, in order for your changes to actually appear on the document. This needs to be done for SQL Server Reporting Services (SSRS). For more information on this process, see the topic Localizing Values On Paperwork Documents.
