Creating Cycle Count Threshold Records

** Use with non-plan based [activity-driven] cycle counting **

 

These records determine when the system should trigger the creation of a non-plan based [activity-driven] cycle count request for a particular location. When the system checks to see if a location meets a threshold, it will first look to see if a location matches three variables (Location Type, Work Zone, and Movement Class). If it the location does not meet all these variables, the system searches for only Location Type and Movement Class. If no location meets that criteria, the system searches for Location Type only. If no locations meet this, the system looks for an all-blank threshold. Also, the user can control the "days between cycle counts" and indicate a threshold quantity (including unit of measure). This quantity determines the minimum item quantity a location has to have in order for the system to trigger a cycle count. By adding a record that has a blank UM and a quantity of '0', you can implement a "verify empty" algorithm. If you wanted to verify empty across the whole warehouse, you could create one record with blank criteria and the appropriate UMs.

 

Short Picking and Thresholds

  • If the short pick inventory action (on the Inventory Control Values Window) is set to a "count" option, the system will always to generate a cycle count when a location's quantity is short picked. The system will not take into consideration the cycle count threshold value in this scenario.

Using the Header Fields

  1. Use the Location Type Field to indicate the type of location you want the system to filter by when choosing locations eligible for cycle counting.

     

  2. Use the Work Zone Field to indicate the type of zone you want the system to filter by when choosing locations eligible for cycle counting.

     

  3. Use the Movement Class Field to indicate the movement class you want the system to filter by when choosing locations eligible for cycle counting.

 

Using the General Tab

  1. Use the Threshold Quantity Field to indicate that you want to count locations whenever they fall below a certain quantity. This value is compared to the location's on hand quantity to see if the location needs to be cycle counted. For example, you would set this value to "0," if you wanted to have a cycle count performed whenever a location is empty.
     

    NOTE: When you set up one quantity and UM combination, the UM does not have to be the base UM. For example, you could specify that a cycle count request should be generated anytime you hit a location in the "Bulk" work zone with a transaction that drops the quantity to 30 Cases or less, and the location has not been counted in the last 60 days.
     

  2. Use the Days Between Cycle Counts Field to indicate when the next time a cycle count should be performed on this location. The last cycle count date is stamped on the location, and a new request should not be created until the value in this field has exceeded that date.
     
  3. When finished, press OK. The system will save your record.
