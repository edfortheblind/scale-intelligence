Performing a Location Inquiry (RF)

You can use this function to have the system view location inventory data on your RF device. This is helpful if, for instance, you want to check if an item's actual quantity matches with the quantity that is physically present in a location. You can also view/edit inventory attributes from this screen.

Search Procedures...

  1. Choose Location Inquiry from the RF Main Menu. The system will display the Location Inquiry screen.

  2. Enter the values for any combination of the fields on this screen to perform your search. To perform a wildcard search, enter a % sign on the text entry field.

    - If a company is not used to filter, the system will display all the item/company combinations on the results screen.

    - In the LP field, you can enter any of the three types of license plates: an un-nested LP, a parent LP or a child LP.

  3. The system will display all location inventory records for the current warehouse that have item quantities that are in any of the four statuses: On-Hand (OH), In-Transit (IT), Allocated (AL) and Suspense (SU).

  4. Use the <<Prev and Next>> links to page through the item records. Note that if the search only returned one record, these links will be disabled and a message will say "Record 1 of 1."

    Serial Numbered Items:
    - If there are no serial numbers for the item at this location, the 'Serial Num' link will not appear.

    Lot Controlled Items:
    - If there is no lot for an item/company, the 'Lot Field' will not appear.
    - If the item/company has multiple lots in a location, then those are displayed as separate records.

    License Plate Tracked Items:
    - If the location is not license plate tracked, the 'LP Field' will not appear.
    - If the item/company has multiple license plates in a location, then those are displayed as separate records.
    - If the parent license plate was entered in the search, the system displays a record for each associated child license plate. There is not a record for the parent license plate.
    - If a child license plate was entered in the search, the system displays a record for the child license plate.
    - If there is no parent license plate value for a record, the 'Par LP' field is not displayed.

    Multi-Company Items:
    - If an item was entered and the company was not used as search criteria, the system displays all the item/company combinations.

    Permanent Locations:
    This icon is displayed to indicate a permanent location.

    NOTE: When using the Location Inquiry screen, if an administrator changes the company for which you have access on the user profile, it could take up to 5 minutes for the user to see any company access changes. The administrator has the ability of changing the caching time on the Location Inquiry screen. Refer to the SCALE SDK documentation on how this is accomplished.

 

 

Searching Using Item Cross Reference IDs...

  1. Choose Location Inquiry from the RF Main Menu. The system will display the Location Inquiry screen.

  2. Enter an item cross reference ID in the Item field to perform your search. Note that if there is more than one item associated with an item cross reference, the system will display a message indicating that there were multiple items for that cross reference, and will populate in a dropdown field all of these items. You will then need to select the correct item ID.

  3. Press the Search Button. The system will display the appropriate location inventory record(s).

 

 

Searching Items with Serial Numbers...

  1. Choose Location Inquiry from the RF Main Menu. The system will display the Location Inquiry Screen.

  2. Enter the values for any combination of the fields on this screen to perform your search. Also, indicate a serial number, or place a '%' in the Serial Number field.

  3. The system will display all location inventory record(s) for the current warehouse that have item quantities with serial numbers and the four statuses: On-Hand (OH), In-Transit (IT), Allocated (AL) and Suspense (SU).

  4. Use the <<Prev and Next>> links to page through the item records. Note that if the search only returned one record, these links will be disabled and a message will say "Record 1 of 1."

  5. Press the Serial Num link to view all the serial number(s) associated with the item. Note that the serial numbers are sorted sequentially.
