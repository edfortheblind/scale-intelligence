Inventory Control Values

Inventory control values help determine some miscellaneous technical values that are related to managing inventory. These values should only be reviewed or edited by a member of your IT staff or a system consultant. The system is shipped with the most common default values which should meet your business needs.

 

 

Description

 

Value Key

 

Value Description

 

10

Write Location UM Overrides On Item UM Change - If you set this value to Yes, when you update the Item Unit of Measure Window (and there is existing inventory), the system will write out overrides for all of the existing inventory to have the old values. If you set this value to No, the system will not write out these overrides when you update item units of measure.  If you set this value to Warn, then the Item Unit of Measure Window will prompt the user to confirm that they want to perform the "Yes" action as described above.

 

40

Default Inventory Status For Adjustments - This value indicates the inventory status that defaults into the Inventory Adjustment screen when adjusting inventory. You can create inventory statuses that meet your business needs in the Inventory Status Window. Examples of inventory statuses could be available (an item is available for picking and/or shipping) or held (an item is currently unavailable for picking and/or shipping).
 

50

Allow Duplicate Serial Numbers? This value indicates if you want to you allow different items to have duplicate serial numbers across the system. If this value is N, you will not be able enter a duplicate serial number for different items, regardless of its item/company designation. If this value is Y, the system will allow duplicate numbers to be entered for different items. Note that you have to have this value set to Y before the Allow Duplicates Checkbox on the Serial Number Template Window will become active.

 

60

Edit UserDef Fields In RF Inventory Management? - This value indicates if you want the system to display User Defined Data screen in RF inventory management. This screen appears after you perform an inventory management action on an RF device. It allows you to associate text (such as a reason code or other text) to an inventory adjustment.

 

70

Whether Inventory Is Being Tracked By Default - If you select the value "Yes," the system will allow adjustments for any item that is not defined in the system. If you select the value "No," then the system will not allow adjustments to any item not already defined in the system.

 

100

Use Location UM Overrides (Only Allocation) - This value indicates whether the Allocation process will look for overridden Item unit of measure records stored in the Location unit of measure table while inserting data in the shipment allocation requests table. These records are subsequently used by the container creation wave step.

The default dimensions and weight for an item are defined in the Item Unit of Measure Window, and that is what container creation wave step uses to calculate a container’s dimensions. However, an individual instance of an item can be overridden to have different dimensions; when this happens, these override dimensions are stored with the product itself, specifically in the Location Unit of Measure table.

- If this value is Y, the allocation/container creation wave step will look at the Location unit of measure table first for dimensions, and use those if they exist (meaning this product has specific unique dimensions). Note that the allocation process will run slower as a result of this extra calculation.

- If this value is N, the allocation/container creation wave step will use the dimensions as configured in the Item Unit of Measure Window. Thus, the allocation process will run “normally” (i.e., not checking the location unit of measure table for dimensions).

 

110

Should Item Be Validated Throughout System? - If you select the value Yes, the system will check to see if you have defined this item on the Item Master. If you select the value No, the system will not check the Item Master for this item. Therefore, you can enter any value in an Item Field, and the system will treat it as an item in the system.

 

120

Should Location Be Validated Throughout System? - Each time an employee attempts to use a location on any window (except the Location Window), the system will reference the Location Validation flag. If you set the flag to No, the system will create locations automatically as the user identifies them through processing. The system will not validate these locations. If you set the flag to Yes, the system will require users to create locations on the Location Window. It will catch any misspellings or typos when a user attempts to access the location on another window.

 

130

Inventory Status For Frozen Lots - This value indicates the status that the system will apply for inventory that has been frozen from the Lot Insight screen.

Note: Also if you receive inventory lot with in this status, the system will automatically mark the lot as Frozen.

 

140

 

Adjustment Type For Lot Status Change: The value you identify here is used by the system when writing transaction history records, whenever the user performs an adjustment that includes a change to an existing lot’s status. Note that this action can also be interfaced back to the ERP, if defined to do so on the Adjustment Type Window.

 

150

Short Pick Inventory Action: This value determines how the system will handle the remaining inventory that is leftover from a short pick. You will need to make a decision whether or not you want the system to suspend the remaining quantity, and if you want the system to create a cycle count request to resolve the location's balance of inventory. Note that this value does not apply to shipping dock locations (for these, the system always uses the "No count, remove transaction quantity" action since cycle counts are not supported there):

  • No count,remove all unallocated on hand quantity: The system will subtract all unallocated on hand quantity from inventory using a short pick adjustment.
     
  • No count, remove transaction quantity: The system will subtract all the transaction's quantity from inventory using a short pick adjustment.
     
  • Count,suspend all unallocated on hand quantity: The system will move all unallocated on hand quantity to the Suspense Quantity Field, and generate a cycle count request.
     
  • Count, suspend transaction quantity: The system will move all the transaction's quantity to the Suspense Quantity Field, and generate a cycle count request.

 
160

Adjustment Type For Status Change During Transfer: This value indicates the transaction type that the system will assign for status change history, when the user performs a transfer action that involves a status change.

 
170

Reuse Closed License Plates: This value indicates whether or not the user will be allowed to enter a license plate ID that exists in the system but is in a closed status. Note that putaway group ID's are also included in this validation. Duplicate open license plates cannot exist in the same warehouse even if this value is set to Yes.

 
180

Dock Location Separator Value: This value identifies the character that you want the system to use when displaying the concatenated dock location area/position value during yard management processing. Note that if you change the separator character and there are existing dock location records, these existing records will not be updated with the new character.

 
190

Allow Duplicate License Plates Across Warehouses: This value indicates whether or not the system will be allowed to assign the same license plate ID in different warehouses. Note that putaway group ID's are also included in this validation. Also, this applies only to receipt containers and license plates found in inventory. This inventory control value is not applicable for shipping containers. Duplicate license plates cannot exist in same warehouse even if this value is set to Yes.

 

200

 

Delimiter Used To Ensure Unique License Plate IDs: This value indicates the character that you want the system to use when it needs to create an LP ID that would otherwise be a duplicate of an existing LP ID. For example, if you define this value as an ampersand (&) character, the system would append it to the end of the LP ID in this manner: LP1234&000001.

 

220

 

Generate Cycle Count On Location Override Putaway: This value indicates that when the user overrides the putaway location while performing work execution, the system will automatically generate an activity-driven cycle count request for the original putaway location.

 

230

 

Generate Cycle Count on Location Override Pick: This value indicates that when the user overrides the pick location while performing work execution, the system will automatically generate an activity-driven cycle count request for the original pick location.

 

240

 

Show All Allocation Failures for Allocate Complete: This value indicates if, for a shipment that has the Allocate Complete setting active, you want the system to evaluate all of a shipment's lines for shipment allocation when at least one shipment line fails allocation. When there is an allocation failure, the system will update the shipment line's Allocation Rejection Quantity value.

  • If this system value is set to Yes, then the allocation process continues evaluating shipment lines when the system determines that at least one of the shipment line(s) failed allocation.

  • If this system value is set to No, then the allocation process stops evaluating shipment lines when system determines that at least one of the shipment line(s) failed allocation.

 

Notes:

  • The system will clear/modify the Allocation Rejection Quantity value based on the success/failure of the allocation of a shipment line (upon re-waving the shipment).

  • Shipment lines which are rejected due to Allocate Complete will always go back to the pool, regardless of what is configured as the outbound status action.

  • Shipment lines that are successfully allocated in the wave will have an Allocation Rejection Quantity value of zero.
