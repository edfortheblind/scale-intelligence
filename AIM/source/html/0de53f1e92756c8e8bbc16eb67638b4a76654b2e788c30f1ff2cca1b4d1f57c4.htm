Configuring/Displaying Interfaced RF and Warehouse Mobile Text Messages

You will need to complete the procedures outlined on this topic to display interfaced shipment comments that are associated with a shipment or shipment line.

Step 1: Defining a Text Message...

Performed on the Text Messages window

  • You will need to create a text message record to indicate when you want the system to display the text message (before or after a picking action).

    See the topic Defining Text Messages for more detailed information on using this window.

 

 

Step 2: Associating the Text Message with an Item, Company, or Account...

Performed on the Performed on the Text Message Assignment window

  • You will need to associate the message ID you created in step 1 with the item, company, or account. Once this is done, the system will display the appropriate text messages on the RF or Warehouse Mobile devices.

    See the topic Associating Text Messages for more detailed information on using this window.

 

 

Step 3: Activating Work Text Messages...

Performed on the Work System Values Window

  • The work system value "Display Warehouse Mobile Text Messages ?" must be set to yes for these text messages to appear on the RF and Warehouse Mobile devices.
