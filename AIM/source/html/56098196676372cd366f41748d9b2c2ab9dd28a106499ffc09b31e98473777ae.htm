Immediate Needs System

 

These system values that you define here impact how the system will fulfill an immediate needs request.

 

System Value Description

 

 

Value Key

Value Description

 

10

Immediate Needs Default Locating Rule: This value associates a default locating rule to use when processing immediate needs. The system will then use this rule to locate product that is being used to fulfill an immediate need.

 

20

Default Replenishment Work Creation Master: This value associates a default work creation master to use when processing immediate needs (using the replenishment trigger).

 

30

Default Shipment Work Creation Master: This value associates a default work creation master to use when processing immediate needs (using the shipment allocation or short picking trigger).

 

40

Default Work Order Component Work Creation Master: This value associates a default work creation master to use when processing immediate needs (using the work order trigger).
