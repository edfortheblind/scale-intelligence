Defining Locations

You will need to define a location for every physical space where inventory can be placed. This allows the system to always track and locate product while its in the warehouse. You will also create dock location area and positions (packing, staging, and dock door) on this window

 

Note on Location Ranges

To minimize setup time, create a range of locations instead of single locations. Since you can create locations in ranges, you can also edit an entire range at one time. To edit a location range, open one record within that range. When you edit the particular field value, enter a check in the checkbox next to the field. The system will update this field value on all records within the range. If you don't select the checkbox, changes are only applied to this record.

 

Note on Deleting Locations

You cannot delete a location record when transactions associated with the location still exist. You must completely process these transactions before the system will allow a location to be deleted.

Using the Header Fields

Access the Location Window. Create a new record.

  1. Associate this record with the appropriate location template.

    2. - A location template defines the segment characteristics for a location name. Location templates are defined on the Location Template Window. Note: After you move the cursor from this menu, the system will display the Location Entry Fields (Step 5), based on the template.

    NOTE: If there is no separator character defined for the template, then all the segments will be concatenated together with no separator at all.
     

  2. Choose the Warehouse that will contain the location(s).

     

  3. Use the Location Entry Fields to create a location or a range of locations.

     

    - After you removed the cursor from the Location Template Field (Step 2), the system will display the Location Entry Fields in the header. The following types of location fields are included: Starting Location, Ending Location and Increment. The actual number of fields for each type depends on the template.

     

    To create a single location: Enter a location name in the Starting Location Field(s). Do not enter values in either the Ending Location Field(s) or the Increment Field(s).

     

    To create a range of locations with the same attributes (using increments): Enter the first location's name in the Starting Location Field(s). Enter the last location's name in the Ending Location Field(s). Identify how you want the system to increment the location names that it creates. See the Increment Field description for more information about setting up increments.

 
Using the General Tab
  1. Use the Location Class Field to define the purpose of the location in relation to product. In most cases, this value is "Inventory." See the topic Location Class Field for more details.

  2. Use the Location Subclass Field to indicate what type of specific designation (such as dock door, packing, or staging) that a dock location will represent. You must choose a Location Class of "shipping" in order to select a subclass value. Note that while this value is optional, all warehouses need at least one "packing" dock location, and that the system only supports one of these packing locations per warehouse. Also, choosing a dock location subclass causes your location to be multi-item enabled, and the dock location will not track license plates.
     
  3. Use the Location Type Field to identify the physical dimensions of the location. Common location types include carton flow and rack.
     
  4. Use the Movement Class Field to identify what items the location can store, based on their movement classes. For example, if a location has the movement class A, it should only store items with the movement class A.
     
  5. Use the Location Status Field to determine how it should manage the location. Assign the Frozen Status if you will not be using it soon. Assign the Empty Status for all locations that are not frozen.
     
  6. Select the Real Time Replenishment Checkbox to indicate that you want to make this location eligible for real time replenishment (inventory storage locations only).  See the field topic for more details.

  7. Select the Allocate In Transit Checkbox to indicate whether or not the system should include "in transit" quantity when computing "available" quantity:

    - If you do not select this value, the system will use the normal computation (on hand - allocated - suspense).

    - If you select this value, the system will include the "in transit" quantity in the allocation computation (on hand + in transit - allocated - suspense). In this case, then, an allocation can potentially occur for an amount that is greater than the "on hand" quantity.

    NOTE: This value would be selected if you are performing replenishments within the flow of a normal work day and/or running demand based replenishment. The system, then, could allocate inventory during the wave, prior to the inventory movement actually taking place. This allows your shipments to allocate normally without having to execute all of the replenishments (prior to running the wave).
     

  8. Select the Multi-Item Checkbox to indicate if this location can store more than one item.

     

  9. Select the Track License Plates Checkbox if you want to track item quantity at the license plate level. Note that you cannot track license plates on a location that has a location class of Receiving Pre-Check In or Shipping Dock.

    10.  

  10. Use the Max Number of Lots Field to limit the number of different Lot ID's that the system can place into this location. Note that a value of zero ("0") in this field indicates that the system will place no limits on how many lots are allowed in a location. Note that multi item locations determine the maximum number of lots per item in the location. In other words, every different item present in the location will have its own individual maximum number of lots value.
     
  11. The Last Cycle Count Field indicates when a user last executed a cycle count instruction at this location.
 
Using the Zones Tab
  1. Use the Zones Field to identify the zones associated with this location. Zones are used to further define a location based on functional process. The system supports three functional zones: locating, allocation and work.

    - Locating zones group together locations that share the same locating requirements. Locating zones are reserved for future use.

    - Allocation zonesgroup together locations that share the same allocating requirements.

    - Work zones group together locations serviced by the same work teams and equipment types.
 
Using the Work Tab
  1. Use the Verification Method Buttons to select how employees will identify this location when performing transactions.

    - Select the None Button if you do not require employees to verify that they are at this location.



    - Select the Location Button if you do require employees to identify the location's ID when they are at this location.
     
  2. Use the Incoming P&D Field and the Outgoing P&D Field to associate a pickup and dropoff location to the location you are creating.

  3. Use the Allow Work Unit Selection On System-Directed Work Checkbox to indicate that you want this location to be eligible for work unit selection when initiating system-directed work. When a user scans the location that they are currently at (on the system-directed work initiation screen), the system will go out and find some appropriate work to assign. When that work is assigned, the system will display an additional system-directed initiation screen, which allows the user to scan any work unit at the current location. Keep in mind that this second screen will only display if the work's from location is eligible for this type of work unit selection. If the location was not eligible, the system would display the first work instruction from the work unit that it selected.

    This type of system-directed work initiation is helpful because it allows the system to determine the location where the work will be performed, but the user is allowed to choose the actual work unit that will be executed.

  4. If appropriate, assign picking and putaway sequence values to this location. The Picking and Putaway Sequences provide you with an alternate method for organizing location visits.

    - The Picking Sequence identifies the order that the system generates picking work instructions for this location. It is a numeric value. Picking sequences are optional, not required. These can be used to during work creation.

    - The Putaway Sequence identifies the order that the system generates putaway work instructions for this location. It is a numeric value. Putaway sequence are optional, not required. These can be used during work creation.
     
  5. The Vector Coordinate Field is reserved for future use. You do not need to supply it with a value.
 
Using the Quantity UM List Tab
  1. Use the Quantity UM List Tab to identify what unit of measures can be allocated or located from this location or range. You can select more than one unit of measure. The system will only allocate/locate product in the units of measure that you define. NOTE: If you do not select an UM values, the system will assume that all UMs can be allocated/located from this location.
 
Using the Dock Tab

These fields are only available if you choose "Shipping Dock" as a location class value.

  1. Use the Dock Area Button to indicate that you want this dock location to be defined as an inventory-tracked dock area. Dock areas can either represent the "to location" during dock location assignment, or a collection of inventory-tracked dock positions. A dock area may also be used as an overflow area when all dock positions in another dock area have been filled to capacity.

    You will then need to address the following dock area-related fields:

    - Anchor Criteria Field: Indicates the dock area anchor filter criteria record that you want the system to use when running the dock management selection strategy "Anchor Dock Area Using Shipment." For more information on this strategy, see the flow diagram in the Dock Management Process Summary.

    - Selection Priority Field: Determines the numeric priority value that is applied to this dock area location. The system uses this priority to determine which dock area will take precedence when a selection strategy is run.

    - Next Dock Area Field: Indicates the dock location you want the system to assign to a container for the "next leg" of its journey, i.e. creating its next move. In other words, you can use this field to pre-assign a dock location. The dock assignment wave step, prior to performing the selection strategy from the dock management flow detail, looks to see if there is a next dock area defined on the container's current dock area. If so, system uses the next dock area and does not use the selection strategy logic (it would go straight to the assignment strategy logic). If not, then the system uses the selection strategy logic as normal.

  2. Use the Next Dock Area Field to indicate the dock location you want the system to assign to a container for the "next leg" of its journey, i.e. creating its next move. In other words, you can use this field to pre-assign a dock location. The dock assignment wave step, prior to performing the selection strategy from the dock management flow detail, looks to see if there is a next dock area defined on the container's current dock area. If so, system uses the next dock area and does not use the selection strategy logic (it would go straight to the assignment strategy logic). If not, then the system uses the selection strategy logic as normal.

  3. Use the Position Button to indicate that you want this dock location to be defined as a dock position. Dock positions are inventory-tracked dock locations in a dock area, and they represent a specific area inside a dock area. Note that a dock area may include any number of dock positions (including zero).

  4. Use the Parent Dock Area Field to create a relationship between a dock position (the child) and a dock area (the parent). The system uses this link to group dock position(s) into the correct dock area on the Dock Manager Window. Note that these links are optional and are not required to use the dock management process. Also, a dock area and dock position do not need the same location template structure to be linked.

  5. Use the Number Of Rows Field to indicate the number of dock position rows that you want the Dock Manager Window to display for this staging area (this setting only applies to the staging location class). If you enter a 0 for this value, the system will display two rows for this dock location area on the Dock Manager Window, IF you have associated position(s) to this dock location area. If you have not associated any position(s) to this dock location area (such as if you were creating a general dock location area), then the system will not display rows for it on the Dock Manager Window.
