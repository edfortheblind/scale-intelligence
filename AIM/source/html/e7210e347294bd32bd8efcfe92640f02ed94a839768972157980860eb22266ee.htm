Reviewing Rate Bases

You will use this configuration to view a table of rates used in calculating the freight charges for LTL shipments. The system looks at the LTL class of the shipment, the weight of the shipment and the rates per weight break to calculate the freight charge. Rate bases point to a table of rates that a carrier uses to rate a shipment. The SCALE system determines the rate base to be used based on various criteria of the shipment:

  • Company
  • Carrier
  • Carrier Service
  • Origin Postal Code
  • Destination Country
  • Destination Postal Code
  • Effective Date

In addition, the 'Carrier Rate Base Assignment Criteria' window can be used to include shipment information in the selection of the rate base. Any field on the shipment can be included in the selection criteria for the rate base.

Using the Header Portion...

  1. Use the Rate Base Field to point to the table of rates that a carrier uses to rate a shipment.

  2. Use the Description Field to describe the rate base record.

  3. Use the Weight Breaks Field to represent the name of the record being defined for LTL weight breaks. This record is used by the Rate Base Configuration which contains the actual values for the weight breaks. This field is input capable when no rate base detail records exist.


  4. Use the Minimum Charge Weight Break Field to contain the weight used to determine the minimum charge break amounts used on the Rate Base configuration. This field is defined on the Weight Break window.

  5. Use the Minimum Charge Less Than Break Field to determine the minimum charge for the shipment if the total weight of the shipment is less than the 'Minimum Charge Weight Break' field. If it is, the system uses this amount. If it is more, then it uses the value in the 'Minimum Charge Greater Than or Equal to Break' Field. This field is located in both the header and detail levels of the rate base record. If there is a value defined in this field on the detail level of the rate base record, the value in the detail level field with be used.

  6. Use the Minimum Charge Greater Than Or Equal To Break Field to determine the minimum charge for the shipment if the total weight of the shipment is greater than or equal to the 'Minimum Charge Weight Break' field. If it is less, then the system uses the 'Minimum Charge Less Than Break Field' amount. This field is located in both the header and detail levels of the rate base record. If there is a value defined in this field on the detail level of the rate base record, the value in the detail level field with be used.

 

Using the General Tab...

  1. Use the LTL Class Field for the LTL class associated with an NMFC code.

  2. Use the Minimum Charge Less Than Break Field to determine the minimum charge for the shipment if the total weight of the shipment is less than the 'Minimum Charge Weight Break' field. This field is located in both the header and detail levels of the rate base record. If there is a value defined in this field on the detail level of the rate base record, the value in the detail level field with be used.

  3. Use the Minimum Charge Greater Than Or Equal To Break Field to determine the minimum charge for the shipment if the total weight of the shipment is greater than or equal to the 'Minimum Charge Weight Break' field. If it is less, then the system uses the 'Minimum Charge Less Than Break Field' amount. This field is located in both the header and detail levels of the rate base record. If there is a value defined in this field on the detail level of the rate base record, the value in the detail level field with be used.

  4. Use the Less than 'X' Weight Field to verify the charges per LTL class for each shipment weighing less than the defined amount on the weight break configuration. The system takes this rate and multiplies it by the weight divided by 100 (or the hundredweight).
