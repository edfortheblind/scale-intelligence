Creating Lot Templates

A lot template determines the physical structure of a lot ID. If associated with an item, the system will mandate that its lot IDs conform to this specific character structure. Lot templates can be made up of several character segments (one primary and any number of secondary segments). You also can define if a lot ID will be alpha-numeric or numeric, its length in characters. You can associate a lot template with an item on the Item Window. The first lot segment that you create is the primary Lot ID. This is the value that users will need to initially enter in the Lot Field when performing actions on lot-controlled items. Subsequent secondary lot segments that you define will be entered by users on the Attribute Tab of the Lot Details Window.

Procedures: Defining a Template Header

Access the Lot Template Window. Create a new record.
  1. Use the Template Name Field to indicate the general system identifier associated with this template. This is the value you will see when you choose a lot template to assign to an item.

 

Procedures: Description Area

  1. Use the Description Field to provide a text name for a lot template segment.

 

Procedures: Pattern Fields Tab

You can use these fields to define how each lot ID segment (primary and secondary) will be structured.
  1. Use the Type Field to indicate what type of character the system will expect for this segment of the lot ID:

    - Alpha: Letters only

    - AlphaNumeric: Letters and/or Numbers

    - Numeric: Numbers only

    - Constant: A specific letter, number, and/or symbol (such as a dash or a double-zero). This value will be the same for any lot ID entered using this segment. A constant would typically be used as a separator character.
     
  2. Use the Length Field to indicate the mandatory number of characters that the system will expect to be entered for this segment of the lot ID.
     
  3. Use the Value Field to indicate the characters you want as a constant on every lot ID that uses this segment. For example, you could enter a dash "-" to separate two segments of characters. Note that you must select constant in the Type Field in order to enter a value into this field.
     
  4. Press the Advanced Button to display more options you can configure for this segment:

    - Use the Pattern Field to view the code that represents the segments that you defined for this template. The system uses this string to "compute" a lot ID according to the parameters in your template. See the Pattern Field topic for more detailed information.

    - Use the Test Data Field to enter a sample lot ID value that you believe matches the structure of this segment.

    - Press the Test Button to have the system analyze your "test data" and decide if it matches the segment. The system will display a message with the test results.

    - Press the Basic Button to return to the general Pattern Fields Tab. The system will save any information you have entered into the advanced fields.
     
  5. Press the Add Button to confirm the data you have entered for the lot ID segment. After this button is pressed, you can enter additional secondary lot segments.
     
  6. When completely finished defining the lot ID segments, press OK. The system will save your new template.
