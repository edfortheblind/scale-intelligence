Estimated Work Rates

Use estimated work rate records to calculate how much time a task will take for a specific work type or work zone. This data helps display estimated workload on the Work Insight Screen, allowing managers to assess available work for employees.

 

Estimated Work Rates

 

  • Work Type and Work Zone - to define which work units that you want to estimate. The system will only apply the estimate when the values that your defined here are met. You can define values in both fields, or leave one blank.

  • Measurement Choices Buttons to define what type of measurements you want to use: measurements per hour or unit of measure. You can only select one of these buttons.

    • Measurements Per Hour Button - the system will measure one of the following variables: labor costs, work units, instructions, by weight or by volume.

    • Unit Of Measure Button - the system will measure a quantity unit of measure, such as a case or a pallet.

Measurement Per Hour

 

The system will display different values on the tab, based on the Measurement Choice Button that you selected.

 

  • If you selected the Measurements Per Hour Button the system will display the Measurement Per Hour Field and a corresponding Hourly Rate Field.

  • If you selected the Unit of Measure Button the system will display the Unit of Measure drop down menus and corresponding Hourly Rate Fields. You can define up to 8 unit of measure records here.
