Reviewing Status Actions (Inbound & Outbound)

Status actions determine how a receipt or shipment is managed when a unique circumstance occurs, such as a shipment is added from the Shipment Insight screen. You can review/change these on either the Inbound (receipts) or Outbound (shipments) Status Action Window.

 

Notes
  • If you select the outbound status Delete Rejected for a status action, the system will delete record(s) that meet this status. For example, if you select it for the Rejected Shipments status action, the system will delete the rejected shipment's quantity completely from the system.

  • When the outbound status action for reject shipments is "Delete Shipments," and BOM action is "Create WO For Rejected Shipment," then shipments are treated like the shipments are treated in the "In Pool" action.

  • WARNING: Two outbound status actions support a status value called Complete Rejection to Pool. For this status, the system, during partial rejections of a shipment, will reject the quantity (similar to what is done in the Delete Rejected outbound status action status). Once the entire quantity on a shipment has been rejected, then the system sends the shipment back to the pool, with all of its original quantities restored. Note that this status can be used only by the Reject Shipment and Short Pick outbound status actions.

Procedures...

 

Access the inbound or outbound status action window. The record list displays all of the default status actions. You can also create new ones.

  1. Open the appropriate record. If appropriate, change the description associated with this record.
     

  2. Use the System Status Field to review or change the status assigned to the receipt or shipment when the event identified occurs.

     

  3. Press OK. The system will save your changes.

OUTBOUND STATUS ACTIONS

 

Identifier

 

Description

 

10

Default Status For A Container With No Detail - The default status when a container ID is interfaced with a shipment number, but not a shipment line number. The system associates the container ID with its shipment, not a detail record. Also, this could occur if you were to delete all the details from a container, and thus would have an empty container.

 

20

Default Status When Added In Order Entry - The default status when a shipment is added to the system from the order entry module.

 

30

Default Status When Added From Shipping- The default status when a shipment is added on the Shipment Insight screen (i.e. the shipment was not interfaced to the system).

 

40

Default Status When Added From Wave -The default status when a shipment is added to the pool on the Planned Shipment Insight screen (i.e. the shipment was not interfaced to the system).

 

50

Default Status When Shipment Is Canceled - The default status when a shipment is added to a wave, but then removed before the wave was run.

 

60

Default Status When Shipment Is Rejected - The default status when a shipment is rejected during a wave. Note that the deletion of work instructions also honors this outbound status action, and that this setting is for work tied to outbound shipments only.

 

70

Default Status Of Short Picked/Short Putaway Portion Of Shipment - The default status when a portion OR all of a shipment's item quantity is not picked/putaway completely.
