Using the Work Monitoring: Group Screen

You can use the Work Monitoring: Group screen to research and manage employee workloads in your warehouse. It is accessible from the SCALE Desktop menu, as well as a tablet device. This allows you to be able to interact with the system from literally anywhere. The system uses a configurable framework called metadata to display this screen's components, which allows you the ability to customize certain parts on the screen.

 

Featured on the Breadcrumb Bar is a manual refresh button. This allows you to refresh the chart / related summary total data and indicator tile query values on the Monitoring Screen. When you tap / click on an indicator tile, the system will open up the Work Insight screen, with the criteria (that you have drilled-down through the chart levels) loaded into the Filter Pane along with the list of records.

 

Notes
  • This topic discusses specific data that is represented on this screen as it is shipped in the base SCALE product. If your screen has been customized, different data may appear on your screen.

  • You can select the warehouse from which you want the system to display the chart / summary total data and indicator tiles. The system will continue to load monitoring screens using the default warehouse.

Navigating the Work Monitoring: Group Chart

 

  1. Open the Work Monitoring: Group screen.

  2. The system will display the monitoring screen, with the chart on the first (highest) level, work group.

  3. Next, click/tap on a work group data column, and the system will then display the next level of the chart, work type.

  4. Again, click/tap on a work type data column, and the system will then display the final level of the chart, assigned user.

  5. Finally, when you click on an assigned user data column, the system will open the Work Insight screen (in a separate browser window), with all the record(s) that meet the criteria you have chosen on the chart displayed on the insight's data grid.
