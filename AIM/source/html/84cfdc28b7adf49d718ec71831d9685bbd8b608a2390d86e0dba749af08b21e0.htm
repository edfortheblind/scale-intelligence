Confirming Cycle Counts

Cycle counting is the physical verification that the inventory actually present in a location matches what the system believes is in the location. This helps you keep an accurate count of exactly how much inventory is present in your warehouse. Confirming is the process of adjusting a location's quantity to be the exact quantity that is physically present in that location. For example, suppose the system says that there are 10 eaches of an item in a particular location. When executing a cycle count, a worker counts 10 eaches. They would then enter this quantity into the RF device, thus "confirming" that the system count was the correct quantity in the location.

 

 

Cycle Counting Methods...

Regardless if cycle count requests have been generated using plans or not, if you have the system create work for cycle counts, then you will need to execute this work (confirm the cycle counts) on an RF device:

  • Non-Plan Based (activity-driven): The typical flow for this mode starts after an RF user has completed executing a work instruction (such as a pick). The system will display a screen prompting the user that a cycle count is required at the current location. The user will then enter the item quantity present in a certain location, and the system will either close the cycle count request, or place it in a "pending review" status, depending on what the count is. See the non plan-based process diagram for a more detailed discussion of this process.
     
  • Plan-Based: The typical flow for this mode is that the warehouse manager will create a cycle count plan in the Cycle Count Plan Insight screen. These plans are based off of cycle count master records, which contain filters for what item(s) and location(s) you want to count. When released, the system will create cycle count requests with work (use RF to count) or without work (use paper documents or the Cycle Count Request Insight screen to count). See the plan-based process diagram for a more detailed discussion of this process.

Prerequisites...

The following are some important prerequisites for confirming cycle counts:

 

Plan-Based Cycle Count Confirmation
  • It is important to remember that you will not be able to confirm the work for cycle counts generated from plans until the plan has been released in the Cycle Count Plan Insight screen. See the topic Using Cycle Count Plans for more information.
Adding Items During Cycle Count Confirmation
  • The ability for users to enter new items during a cycle count is controlled by the "Add New Inventory" option (from the RF Cycle Count form) in the Security Permissions Window.

 

 

 

Confirming Cycle Counts Using an RF Device...  

The following procedures are for executing cycle count work for both plan-based and activity-driven cycle counting (as performed on an RF device).

 

1. Log on to your RF Device.

 

2. Choose the Work function.

 

3. Choose a work profile:

  • When using plan-based cycle counting, select a work profile that supports executing cycle count work.

  • When using activity-driven cycle counting, select a work profile that supports the work type that you are going to be executing.

4. The system will display the appropriate work execution processing screen:

  • When using plan-based cycle counting, the system will display the user-directed work initiation screen, on which you will need to enter a work unit.

  • When using activity-driven cycle counting, the system will display the work confirmation screen (see the topic Processing RF Work for more details on using that screen). You would then use that screen to execute your picking/putaway work.

5. Next, the system will display the cycle count confirmation screen.

 

6. Enter the item quantity (and UM) OR the number of license plates that are currently present in the location of the item you are counting.  The type of count you will be required to make is determined by  how your work special handling record's cycle counting settings are defined.

  • Unit of Measure Note: The value under the Unit of Measure Field represents the base quantity/UM for the item quantity that you are counting. In the example, if there was a Case of item 0002 currently in the location (and 1 CS= 30 eaches), then the system would display the base quantity of 30 EA.

  • If you are counting a non-LP-tracked location, the system will require you to count the item quantity (even if you are configured to count the number of license plates.

  • If you are counting an LP-tracked location, you can count either item quantity or the number of LPs (depending on your work special handling settings).

  • The system also may require you to provide validations for such values as item IDs, or location IDs on this screen.

 

When Counting the Number of LPs for an LP-Tracked Location

  • If the number of license plates does not match the license plates in the location, the system will automatically direct the user to the count item quantity mode. 

  • If the number of license plates matches the license plates in the location, the system will confirm all the requests that exist for this location.

  • If the location is multi-item, you cannot count the number of license plates. The system will automatically direct you to the count item quantity mode.

 

When Counting the Item Quantity of an LP-Tracked Location

  • In user-initiated LP mode, the user will need to enter which license plate they want to confirm. Then the user will need to enter the quantity of the item in the license plate. 

  • In system-initiated LP mode, the system will display the license plate to be counted. Then the user will need to enter the quantity of the item in the license plate.

 

When "Grouping" Counts By Item/Company:

If your work special handling is configured to do so, you can cycle count all the quantity at a given location for the same item/company (regardless the lot ID, inventory attributes, or license plate). For example, suppose location 101/026/01 contains item NOR0001. Also, inventory attributes have been captured for NOR0001 that represent the country of origin, with a breakdown of the following: NOR0001 has 5 EA with an origin of "United States", 5 EA with an origin of "Canada", and 5 EA with an origin of "Mexico." You would then count the inventory for the United States, Canada, and Mexico with a combined "grouped" count of 15 EA for NOR0001. See the topic Count Level Field (the Group Count By Item/Company setting) for more information.

 

 

When Counting an Empty Location:

  • The user will have the same options as in the "not empty" scenarios listed above. 

  • Note that you can add new items using the Add Button (see later in this topic for details on adding items during a count).

 

7. Press one of the action buttons:

  • CONFIRM:Press this button to confirm the item/LP quantity that you are counting at the location.

    If the user count is different than the system count, and the Verify Bad Count on RF Checkbox is selected on the user's cycle count preference, the user will need to re-enter their count.

    - If location's new quantity IS ZERO, the system will confirm that the current location as empty.

    - If location's new quantity IS NOT ZERO, the system will: immediately reconcile the item quantity if the Immediate Reconcile of Bad Count Check box is checked on the user's Cycle Count Preference record. Remember that the system will only reconcile the location if the difference between the counted and system quantity falls within the user's tolerances. Also, the system will place the cycle count request into a "pending review" status if the system quantity and the quantity you count are different, and if the Immediate Reconcile of Bad Count Check box is not checked. You will then have to address this request in the Cycle Count Request Insight screen. However, if the quantities are the same, the system will close the request. See the topic Reconciling Cycle Counts for more information on the reconciling process.

    - If the counted item is lot controlled, the system will display the Enter Lot screen, where you can provide the appropriate lot data.

    - If the counted item is serial number tracked, the system will display the Serial Number Entry screen, where you can provide the appropriate serial number data.

  • ADD: Press this button to add item(s) that the system does not currently account for in your count of the location.Note that this functionality applies to RF cycle counting only.

    - When you press this button, the system will display the Inventory Management screen. When you are finished entering in the adjustment information, press Add Button on the Inventory Management screen to add the item quantity. The system will return you back to the Cycle Counting screen. You can also press the Cancel Button to return to the Cycle Count Confirmation screen.

    - The cycle count system value "Planned Count - Positive Adjustment" determines the adjustment type that you can perform when adding items to a location.

    - You can only adjust an item to the location you are currently counting.

    - After you have added an item (and all counts on the location have been completed), then the system will display only the Location Field, and you can continue to add item(s) until you press the Done Button.

    - Adding items during a count is subject to the same validation as inventory adjustments performed outside of cycle counting.

    - The system places all new items added to single item locations in a pending review status, IF if the location is either not empty, has another item in transit, or is the permanent location for another item.

    - You WILL NOT need to count the item quantity that you just added via an adjustment. However, if you are counting a single item location that is LP tracked, you will need to confirm the original item quantity on the count.

    - New items added to a multi-item location will use the "tolerances" defined on the cycle counting preferences to determine if the system should place them in pending review.

    - You cannot add items and count LPs. When you choose to add a new item, SCALE will require you to count contents (instead of LPs).

    - *** If an item is lot-controlled, then the system will display the Enter Lot screen after the adjustment information is entered and you press Add. Note that if you have the ability to add items, then you will also be allowed to enter new lots as well.

  • DONE: Press this button when you are finished cycle counting the current location, and you do not want to add any more items.

    - If you are counting a single-item location, this button will only appear if you are allowed to add items during counts.

    - If you are counting a multi-item location, this button will always appear on the confirmation screen (so you can opt to finish counting before all the locations on the work unit have been counted).

    •  

  • SKIP: Press this button to ignore the current cycle count request and advance to the next one (if one is available). Note that this button will not appear if no other cycle count instructions exist on the current work unit.

  • CANCEL:Press this button to stop processing on this cycle count work unit.

 

8. When you are finished confirming all the cycle counts on the current work unit, the system will return you to the user directed work initiation screen (using plan-based cycle counting), or proceed with the next work activity (using activity-driven cycle counting).

 

 

 

 

Confirming Cycle Counts Using the Cycle Count Request Insight Screen...  

You can only confirm from the Cycle Count Request Insight screen, if work was not created for a cycle count request.

1. Access the Cycle Count Request Insight screen.


2. Search for a cycle count request (that has no work associated with it). Note that the confirmation option will not be available for requests that have work associated with them.
 

3. Select the Confirm action. The system will ask you if you are sure you want to confirm the request. Choose Yes, and the system will confirm the request and set the status of the request to closed.

 

 

 

Confirming Cycle Counts Using Paperwork... 

The following procedures are for plan based cycle counting only.

  • If you are not generating work for cycle count requests, you can have the system print "cycle count list" paperwork, and users then would perform the counts from these documents. Then, typically a manager would confirm/reconcile the cycle count requests in SCALE (on the Cycle Count Request Insight screen). See the topics Using Cycle Count Plans and Reconciling a Cycle Count Request for more information these actions.
