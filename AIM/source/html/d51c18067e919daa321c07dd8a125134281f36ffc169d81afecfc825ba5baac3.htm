Transferring Inventory (Desktop and RF)

The inventory transfer process allows you to move product from one location within your warehouse to another location. You may initiate an inventory transfer request from the desktop or from an RF device. After the transfer is invoked, the system moves the inventory immediately as soon as you complete the transaction. You can also transfer at the license plate level. This allows you to process mixed product in one transaction. If the location supports license plate tracking, you can identify license plate information during the transactions.

 

You can also have the system generate work instructions for certain types of inventory transfers (performed from the desktop). This allows transferred quantities to not show up as available in a location until the quantity is actually present (on hand) in the location. The system will mark this quantity as " in transit" in the To location, and "allocated" in the From Location.

 

Work Creation

System creates work based on the way user accesses and performs the Inventory Transfer using the user interface.

Inventory Transfer from main menu - Adjust type as Transfer with Work

  • Select the adjustment type as Transfer with Work and click Transfer to adjust the inventory. The system will have inventory adjustment performed, but work will not be created. User needs to click Create Work to create the work. However in this case, in case the user closes the browser before selecting Create Work, system will prompt user to select Leave or Cancel.
    • If user selects Cancel and user stays on the browser, system will prompt user to complete the pending transactions and create work.
    • If user select Leave, then system will have incorrect inventory data without work being created.

Inventory Transfer from main menu - License Plate flow

When user performs inventory transfer using the license plate option, then work gets created immediately when user clicks Transfer button.

 

Inventory transfer screen from Insight Screen - Work gets created automatically when user clicks the Transfer button.

Types of Inventory Transfers...

 

Basic Inventory Transfer
  • This type of transfer moves an item's quantity from one inventory location to another. Also the company transfer will happen only if the item master have multiple item/company records.

 

Company Transfer (RF Only)
  • This type fo transfer changes a product's company association from one company to another. Company transfers can only be performed on locations where their entire quantity is in an Available or On Hand status. You cannot perform a company transfer on a location where any quantity is in an Allocated, In Transit or Suspense status.

  • You cannot perform a company transfer on product at the shipping dock, the receiving dock, or the receiving "pre-check in" location.

  • The company transfer will happen only if the item master have multiple item/company records.

  • You can transfer both parent and child license plates.

 

Warehouse Transfer (RF Only)
  • This type of transfer changes a product's warehouse association from one warehouse to another.

  • All quantities that are in On Hand and Available statuses can be transferred between warehouses.

  • You cannot perform this action against locations with inventory in other statuses, such as In Transit or Allocated.

  • You cannot transfer to a non-multi item location with existing quantity, or to a permanent location for a different item.

  • You cannot perform a warehouse transfer on product at the shipping dock, the receiving dock, or the receiving "pre-check in" location.

 

 

 

Desktop: Performing a Inventory Transfer...

The following procedures are for performing an inventory transfer from the desktop screen. Note that if you access this screen from the Inventory Insight, then the system will default value(s) into some of these fields where appropriate.

  1. Select the Inventory Transfer Screen from the system menu. The system will display the Adjustment Type Field.

  2. Use the Adjustment Type Field to select a transfer type. The system will display the user and warehouse authorized adjustment types.

    - If the selected transfer type is configured with license plate initiation type, the Transfer screen is shown with the License Plate field. The system will prompt you to also enter a license plate ID. When you enter an existing license plate and press the Arrow button, the system will display the processing fields, with ALL fields disabled except the To Location and User Defined fields. This is because in this instance, you are transferring the entire license plate. Skip to step 5 (and then 12).

  3. Use the License Plate Field to indicate the license plate that represents either the license plate that contains the loose quantity that you are transferring; or, the whole license plate that you are transferring. If the location you are transferring from is not license plate tracked, then this field will not be editable.

  4. Use the From Location Field to indicate the location where the item currently resides.

  5. Use the To Location Field to indicate the location to which you want to transfer the item.

    Locate Action: If necessary, you can use this action (accessed from the Actions menu) to have the system suggest a To location. You will need to choose a locating rule for the system to use in the locating process. Also, the Locate Button is not enabled when the selected adjustment type is configured with the license plate initiation type.

  6. Use the Status Field to indicate the item's inventory status that will be applied after the transfer is performed.

  7. Use the Item Field to indicate the item that you want to transfer. Note that you can only transfer an item if it its "inventory tracking" setting is active (defined on the Item Window).

  8. Use the Company Field to indicate the company associated with the item that you are transferring.

  9. Use the Lot Field to indicate the item's lot ID. After the transfer is initiated, the system will display the Lot Update Confirmation Screen if you change this value.

  10. Use the Expiration Date Field to indicate the lot's expiration date. After the transfer is initiated, the system will display the Lot Update Confirmation Screen if you change this value.

  11. Use the Quantity and UM Fields to indicate the amount that you want to transfer. Note that you will not have to enter this value if you are transferring a full license plate.

  12. When finished...

    Press the Transfer Button, and the system will perform the transfer.

    OR

    Press the Create Work Button to have the system perform the transfer and create work for the transaction. The system will prompt you to confirm that you want to have the work created. Note that the Create Work Button will only be active if this transfer type is configured to create work.
Processing Notes
  • You can transfer both parent and child license plates. 

 

 

 

RF: Performing an Inventory Transfer...

The following procedures are for performing an inventory transfer from an RF device.

  1. Select the Inventory Management Screen from the RF main menu. The system will display the Adjustment Type Field.

  2. Use the Adjustment Type Field to select a transfer type. Note that inventory adjustments are also listed in this field, but the procedures below are for inventory transfers only. The system will display the user and warehouse authorized adjustment types.

  3. The system will then display the appropriate processing fields. If the selected transfer type is configured with license plate initiation type, the Inventory Management screen is shown with the License Plate field. The system will prompt you to also enter a license plate ID. When you enter an existing license plate and press the Arrow button, the system will display the processing fields.

  4. Use the Item Field to indicate the item that you want to transfer. Note that you can only transfer an item if it its "inventory tracking" setting is active (defined on the Item Window).

  5. Use the Company Field to indicate the company associated with the item that you are transferring.

  6. Use the Lot Field to indicate the item's lot ID. After the transfer is initiated, the system will display the Lot Update Confirmation Screen if you change this value.

  7. Use the Expiration Date Field to indicate the lot's expiration date. After the transfer is initiated, the system will display the Lot Update Confirmation Screen if you change this value.

  8. Use the Quantity and UM Fields to indicate the amount that you want to transfer. Note that you will not have to enter this value if you are transferring a full license plate.

  9. Use the From LP Field to indicate the license plate that represents either the license plate that contains the loose quantity that you are transferring; or, the whole license plate that you are transferring. If the location you are transferring is not license plate tracked, then this field will not be editable.

  10. Use the From Loc Field to indicate the location where the item currently resides.

  11. Use the To Loc Field to indicate the location to which you want to transfer the item.

    Locate Action: If necessary, you can use this action (accessed from the Actions menu) to have the system suggest a To location. You will need to choose a locating rule for the system to use in the locating process. Note that the locating functionality does not create any work.

  12. Use the Set Status To Field to indicate the item's inventory status that will be applied after the transfer is performed.

  13. When finished, press the OK Button, and the system will perform the transfer.

 

Processing Notes
  • In order for the system to display the User Defined Values screen, you need to activate the Inventory Control Value setting "Edit User Def In RF".

 

 

 

Using Inventory Attributes With Inventory Transfers...

  • You can only transfer inventory (which includes inventory attributes) only if you access the Inventory Transfer screen from the inventory record via the Inventory Insight screen. If you access the Inventory Transfer screen directly from the main menu, then inventory with attributes cannot be transferred.

  • If you try to perform a transfer (Desktop or RF) to/from a location that has inventory attributes, the system will display an error when selecting a location inventory record from the Inventory Insight screen that represents multiple inventory attributes. If the "Show All License Plates And/Or Inventory Attributes" checkbox on the insight screen is selected, then the system will transfer inventory for the selected record.

  • When you access RF inventory management directly from the RF Main Menu screen, the system does not transfer inventory linked to inventory attributes.

  • Any time you perform a transfer from system menu for a location having inventory with and without attribute or inventory with different attributes, system always brings up the oldest record and the transfer is done to the record that was shown.
