UPS World Ease Setup Procedural Flow

This topic outlines the basic flow of how to configure UPS World Ease.

Setup Flow...

  1. In SCALE, create a new intermediate consignee record. Note the required data should be obtained from UPS prior to creating this record.

  2. The Progistics license should be enabled for UPS World Ease, after it is enabled from Connectship.

  3. Load the POE (Port Of Entry) file into Progistics. See the topic Prerequisites/Requirements When Using UPS World Ease for more information about POE files.

  4. Enable Progistics to allow World Ease shipments. This is done in the "Modify Shipper Account Information" screen, by selecting the Allow World Ease Shipments checkbox.

  5. In SCALE, add a carrier for the World Ease service: World Ease supports four different services, choose the appropriate one that is required for your shipper.



  6. Ensure that the SCALE shipper cross reference supports UPS World Ease for the respective shipper.



  7. Paperwork setup required (all are Progistics documents):

    - UPS World Ease Master Invoice (3 copies required, TANDATA_UPS_MASTER_INVOICE.STANDARD)

    8. - UPS World Ease Consolidated Invoice (1 copy required, TANDATA_UPS_CONSOLIDATED_INVOICE_DETAIL.STANDARD)

    - UPS World Ease Certificate of Origin (1 copy required, TANDATA_UPS_WE_CERTIFICATE_OF_ORIGIN.STANDARD)

     

     

  8. Labels required (all are Progistics labels):

    - UPS Shipping Label (TANDATA_UPS_WORLD_EASE_MAXICODE.STANDARD)UPS Doc Box label (TANDATA_UPS_DOCBOX.STANDARD)


    9. - Label Printing Note: The World Ease label is a combination of a 6x4 + 4x4 label (its total length is 4 x 11). You need to make sure that the stock symbol is set accordingly on the print device that is configured to print the World Ease labels. When printed, the label needs to be torn into two parts (6x4) and (4x4). The shorter label is stuck on top of the (6x4) label.

  9. Setup SCALE document routing to support the above labels and documents.
