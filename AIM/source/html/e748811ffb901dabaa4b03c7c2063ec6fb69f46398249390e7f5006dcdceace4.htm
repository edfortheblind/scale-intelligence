Warehouse Mobile - Indirect Labor

Users can now log indirect labor directly from the Warehouse Mobile application. The indirect activity remains open until it is completed, ensuring accurate time tracking. If a direct activity is initiated while an indirect activity is still active, the system automatically ends the indirect activity to maintain proper labor recording.

 

The Indirect labor is supported for the following areas:

 

• Receiving Check-In

• Container Close

• Picking

• Putaway

• Cycle Count

 

Indirect Labor :

 

Perform the following steps to log indirect labor activity.

 

1. Tap Indirect Labor from Warehouse mobile main menu to view the Start Indirect Labor Activity screen.

2. Select the Activity Type and Tap Go.

3. In the End Indirect Labor Activity screen, the User Name, Activity type and Start time is displayed

4. Tap Go and a successful message is displayed

 

Direct Activity Overlap:

  • Start an indirect labor activity.
  • The system records the start time and keeps the activity active.
  • Start a direct activity before ending the indirect activity.
  • The system automatically ends the indirect activity.
  • The indirect activity end time is set to the direct activity start time.
  • The direct activity continues as the active labor activity.

 

Notes

 

• When an indirect activity starts, the system records the Start Time and leaves the End Time blank.

• The indirect activity remains active until it is completed.

• When the activity is finished and Go is tapped again, the system records the End Time.
