Sequence Field

This field indicates the order in which the system will process steps or records. The lower the number, the sooner the record is processed. Sequences are typically used in system automated tasks, such as wave processing, allocation, replenishment or work creation, among others.

 

 

On the Bill of Materials and Other Work Order-Related Windows...

Sequence indicates the order that the user should complete a step, not the system.

 

 

On the Storage Template Window...

Note that if you change the sequence when adding a new storage template detail record, the system will only set the sequence number to one number higher than the highest value currently in your record list. For example, suppose you already have sequences "1" and "2" defined, and you change the sequence on the record you want to add to a "5". The system will still add the record with a sequence number of "3". Furthermore, if you try to insert a new record in between two existing steps (i.e., numbers "1" and "2"), the system would renumber the existing step "2" as "3", and the new step would be assigned the number "2."

 

 

On the Application Identifier Template Window...

This field indicates where in the barcode that the system will expect this segment to appear in.

 

 

On the Exit Point Parameters Window...

This field indicates the order of the parameters that are passed by an exit point.
