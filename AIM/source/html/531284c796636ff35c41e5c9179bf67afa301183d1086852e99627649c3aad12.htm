Parent Field

This field indicates the top-level accessorial detail that the accessorial detail you are configuring is subordinate to. This allows you the ability to create a parent/child relationship between accessorial details of the Address value type. This is helpful when Progistics expects full address values to be passed for a particular accessorial detail. Note that while only a value type of Address can be a parent accessorial detail, any value type can be a child accessorial detail.

 

When using Progistics, in order to pass a new address as the “Ship From” on a label, a subcode needs to be created with the external symbol of RETURN_ADDRESS. Then, each of the “child” subcodes will need to have the external symbols listed below (case sensitive):

Company

Address1

Address2

Address3

City

StateProvince

PostalCode

CountrySymbol

Contact

Phone

Fax
