Open Work Field

On the Manual Inventory Adjustment Window...

This field indicates the total open work (classified as both "open" and "in process") that exists for a particular item. This includes all types of work except cycle count work. The system will only calculate this value if you did not include a location value in your search.

 

 

On the Inventory Insight Screen...

Clicking on the Open Work Indicator Tile takes you to Work Insight displaying the work instructions associated with this item/company/warehouse/location/lot/license plate.

 

 

On the Shipping Container Insight Screen...

Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse, instruction type detail, parent container ID (when the parent container ID is selected), and internal container number fields (when the child container ID is selected). The list displays the number of open or in process work for the selected shipping container to the lowest level.

 

 

On the Work Insight Screen...

The Open Summary Tile indicates the number of work instruction details with the Open condition.

 

 

On the Work Order Insight Screen...

Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse and given work order number.

 

 

On the Work Order Line Insight Screen...

Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse and given work order number.

 

 

On the Work Order License Plate Insight Screen...

Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse, given work order license plate, and work order number for Work Order Putaway work.

 

 

On the Replenishment Insight Screen...

Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse, internal replenishment request number, and internal number type.

 

 

On the Cycle Count Plan Insight Screen...

Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse, internal plan number, and internal number type.

 

 

On the Cycle Count Request Insight Screen...

Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse, internal count number, and internal number type.
