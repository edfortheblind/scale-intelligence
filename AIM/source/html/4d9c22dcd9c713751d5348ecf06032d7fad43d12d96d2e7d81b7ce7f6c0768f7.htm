Creating Yard Locations

You can use this window to create yard locations. This type of location consists of an area and one or several position(s), and are not inventory-tracked. Yard locations are used as a temporary storage area for truck trailers that are going to be received into your warehouse. Once a trailer is residing in a yard location, workers then can move the trailers to other locations in the yard, or move them to the Receiving Dock for processing.

Procedures: Creating Locations...

 

Using the Header Fields

Open the Yard Location Window, and create a new record.

  1. Use the Warehouse Field to indicate where the new location will reside.

  2. Use the Location Area Field to indicate in which area you want to create your new location.

  3. Use the Location Separator Field to view what character will separate the location area and position values when displaying the concatenated value in yard management processing.

  4. Use the Position Range Field to create a single position or a range of positions. Note that you need to have at least one position for every location you create.

Using the General Tab
  1. Use the Multi Trailer Checkbox to indicate that you can have more than one trailer residing in a particular yard location.

 

 

Procedures: Deleting Locations...

Open the Yard Location Window.

  1. Right-click the record of a position you want to delete, and select the Delete Action. The system will display the record in the Yard Location Window.

  2. Use the Position Range Field to indicate which position(s) you want to delete:

    • If you want to delete ONE position, enter the position name in both parts of this field.

    • If you want to delete a RANGE of positions, enter the first position in the range in first field, and the last position in the range in the second field.

  3. Press OK. The system will prompt you to confirm that you want to delete these positions. Press OK again, and the system will perform the delete action.
