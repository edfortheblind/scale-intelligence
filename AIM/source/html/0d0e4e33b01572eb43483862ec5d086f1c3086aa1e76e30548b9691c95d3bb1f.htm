Using the Planned Shipment Insight Screen

You can use the Planned Shipment Insight Screen to search and manage shipments that have not yet been processed through a wave. This screen shows shipments that have a status less than or equal to Picking Pending.

Searching/Viewing Shipment Records...

You can use this screen to search for and view shipment records in your warehouse. Note that you can use the Shipment Type accordion buttons to filter the screen grid to display in pool shipments OR shipments on a wave.

  1. Open the Planned Shipment Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search:

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

Searching Using Planned Shipment Filters...

You can also perform searches in this insight screen using pre-defined search criteria for pooled shipments called "planned shipment filters." Each one of these filters include criteria that is defined on the Planned Shipment Filters configuration. For example, you could define a filter criteria record for a particular customer, carrier, and order type. When this filter is selected in the basic criteria section and a search is invoked, the system will display the results that match the criteria defined in this filter. The list of the available filters is displayed at the top of the Basic Criteria section of the Planned Shipment Insight in the field "Planned Shipment Filters".

 

Notes:

  • When a planned shipment filter is selected, the system will disable all of the remaining basic criteria fields.

  • The system will display results from these filters based on the filter configuration *regardless* of the user’s warehouse.

 

 

 

About the List Pane...

The Planned Shipment Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

List Pane Icon Explanation

Certain conditions for the planned shipment are represented by graphical icons on the list pane. Below are explanations of what each icon represents:

Icon Explanation

Shipment has a related work order. Once that work order has been completed, the shipment can be run through a wave to allocate the inventory.

Shipment has a rejection note. The most common cause is that at least one line has an allocation rejection.


For more general information about the List Pane, see the topic Introduction to Insight Screens.


 

 

About the Detail Pane...

The Detail Pane of Planned Shipment Insight contains an Indicator Tile for Shipment Lines and header fields (Shipment ID, Leading Status etc.). The ‘Lines’ indicator tile displays the number of lines for a shipment that is selected in the list pane. You can use this to open the Shipment Line Insight screen. The Shipment Line Insight screen displays all lines for this internal shipment number, if you have Run security for the screen.

 

 

 

 

Screen Actions...

The following actions are accessible from the Planned Shipment Insight screen:

 

 

New

This action enables you to manually create a new pre-wave shipment. For more information on creating shipments, see Creating/Editing a Shipment.

 

 

Copy

This action allows you to copy the selected pre-wave shipment from the List Pane. When this action is selected, the system will open the Shipment screen in new mode and it defaults the information from the shipment being copied.

 

 

Edit

This action allows you to change field values on the shipment. When this action is selected, the system will open the Shipment screen in edit mode.

 

 

Delete

This action allows you to delete a pre-wave shipment. For more information on deleting shipments, see Shipment Processing.

 

 

New Line

This action allows you to create a new shipment line and redirects you to the Shipment Line details screen in the new mode.

 

 

Add Shipment to Wave

This action enables you to manually add a shipment to the wave. When this action is selected, the system will open the Add Shipment to Wave screen, where you can indicate which wave you want to add the shipment to. For more information on this topic, see Adding a Shipment to a Wave.

 

 

Add All Filtered Shipments To Wave

This action enables the system to add all the shipments retrieved from your search criteria to a new or existing wave. Invoking this action will open the Add Shipment to Wave screen. Note that the system will disable this action if your search produces no results or you have not yet pressed the Search button. For more information on this topic, see Adding a Shipment to a Wave.

 

 

Clear Rejection Note

This action allows you to to remove rejection note from a shipment. For more information on this topic, see Processing a Wave.

 

 

Consolidate

This action allows you to consolidate all the shipments that meet the consolidation criteria with the one that you selected from the List Pane. When this action is selected, the system opens the Shipment Consolidation window. For more information on shipment consolidation, see Shipment Consolidation Screen.

 

 

Immediate Needs

This action allows you access the Immediate Needs Insight screen from Planned Shipment Insight. The Immediate Needs Insight action is enabled if the shipment line has at least one immediate needs item and there is an immediate needs request created for the item. If the immediate needs request is fulfilled, this action will be disabled while selecting the shipment from List Pane. Pressing on the immediate needs action will open the Immediate Needs Insight screen using the reference ID (Shipment ID) and the warehouse as predefined search criteria.

 

 

Print Preview

This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to Printing Paperwork.

 

 

Print Default Docs

This action allows you to print the default shipping documents that have both the print procedure for "shipment" setting and the default setting selected on the document’s document type record.

 

 

Print Selected Docs

This action allows you to print the shipment document(s) that you manually select. For more information on printing, see Printing Paperwork.

 

 

Remove from Wave

This action allows you to remove the selected shipment from the assigned wave.

 

 

Route

This action enables you to route a pre-wave shipment. This is especially helpful if you change something about the shipment (e.g. carrier, service) and need to re-route it with its new properties. For more information on routing, see Rating/Routing Shipments.

 

 

Split Shipment

You can split a single shipment into multiple shipments prior to it being run through a wave. To split multiple shipment lines to a new shipment, select the multiple rows by clicking on their respective grid row checkboxes and then select the Split Shipment action.

 

 

Transfer To Another Wave

This action allows you to transfer the selected shipment(s) to an existing or a new wave. For more information on this topic, see Adding a Shipment to a Wave.
