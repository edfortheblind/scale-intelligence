Split Consolidate Shipments on Upload Checkbox

If selected, this field will split the consolidated shipments on upload. The interface upload process will split the shipment on the basis of the unique ERP Order values. In other words, if you interface multiple orders and SCALE consolidates them, the system will interface the orders in the same format as they were received.

 

To achieve this result, you must interface a value in the ERP_ORDER field on each shipment line that is unique to that order. The upload interface process will use this to break apart the shipments  If you do not interface this value, the system will automatically set this field to the shipment ID that is interfaced. Additionally, shipping containers still get tied to a single shipment during the upload, since they could have mixed orders inside them, or could be nested onto a pallet with other orders.

 

Note that splitting consolidated shipments on an upload (as described above) requires the "Shipping Interface Download Record Types To Create" interface system value to be set to "Orders and Shipments" (to create the orders).
