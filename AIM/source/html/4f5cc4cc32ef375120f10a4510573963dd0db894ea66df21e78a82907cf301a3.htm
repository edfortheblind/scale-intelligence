Defining Document Routing Records

After you define a document, you need to provide its printing parameters on the Document Routing Window. The print parameters determine the following:

  • If a document should be printed, based on printing criteria. The printer criteria are values commonly included on printed documents, such as Ship To, Carrier and Container Class.

     

  • How many copies of the document will be produced.

     

  • What printer the document will be routed to, and which document will be used.
     
  • What machine the document will be printed from; for example, a particular packing station's client machine.

NOTE:

  • A default printer configured on the user profile will override the document routing printer. This also includes the default printer will override printers assigned to workstations.
  • In case of workstations assigned printers use document routing records to determine the printer.
  • The default printer has to be blank in order for the workstation printer to be used.

Procedures...

 

1. Use the Document Type Field to identify the general category associated with this document. The system will limit the documents available (in the Document Field) to only those values associated with this document type.

 

 

2. Use the Routing Criteria fields to define when this document will be printed, and where. The system will select this record when all of the criteria are met. If you don't define a value in any criteria field, the system will produce the document whenever it is requested.

- Use the Machine Name Field to refer to the machine requesting the printing (i.e. the workstation).

 

 

Printing using the Remote desktop service

The system is smart enough to determine the appropriate workstation if using Remote Desktop Services. It does not expect the domain name suffix. For example, suppose you have a printer located at a specific packing station, from which you want to generate Container Contents Labels. If you define a Machine Name, no matter the user that is signed onto this packing station client machine, the system will print the label at the printer present at that station. This is helpful because you do not have to set up this document by user, and force them to always use the same packing station. Also the default printers on the user profile will override the printer assigned to the workstation.

Note on Session Information and Document Routing

The system gathers "session" information when the application starts up, and stores this information for the duration that the application is open (without ever re-retrieving it). When a user goes from one client workstation to another and uses a previously open or disconnected remote desktop (RDP) session (i.e., a "stolen" RDP session), the system will NOT need to re-retrieve the session information. Therefore, the document routing process uses the "original" client device name when determining where a document should be routed. In order to prevent this (and have the document routed to the new workstation), you need to log off the RDP session when finished with a work station; or, if you disconnect from one workstation and connect to the same session from another workstation, you need to close the application and re-open it.

3. Use the Routing Selection Fields to identify what the system will produce when the routing criteria are met.

- Use the Device Name Field to identify the printer that will print this document.
 

- Use the Document Field to select the document that you want to print.
