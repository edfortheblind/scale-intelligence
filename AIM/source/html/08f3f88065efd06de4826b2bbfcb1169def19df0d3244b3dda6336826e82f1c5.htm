Functional Area Configuration

Overview

 

Functional Area configuration defines the status flow records used by each functional area in SCALE, such as Receiving, Shipping, and Work Order processing. You can review and maintain the status values and their flow properties for each functional area.

 

Configure Functional Area

 

1. Functional Area

 

The Review Functional Areas screen displays the available functional areas. Select a functional area to review and maintain its status flow records.

  • Functional Area: The identifier for the functional area.

  • Description: The description of the functional area.

 

2. Status Flow

 

The Status Flow screen displays the status records defined for the selected functional area.

  • Functional Area: Displays the selected functional area identifier (read-only).

  • Status: The numeric status value.

  • Status Name: The descriptive name for the status.

  • Related Status: The numeric status that this status relates to in the flow.

  • Mandatory: Indicates whether this status is required in the flow and cannot be skipped.

  • In Default Flow: Indicates whether this status is included in the default processing flow.

  • Include In Interface Upload: Indicates whether this status triggers an interface upload record.

  • Add New Status: Create a new status record for this functional area.

  • Edit/Delete: Update or remove the selected status record. Delete and edit are disabled for system-created records or records where changes are not allowed.

 

A. Status Information

 

Define the properties for a functional area status record.

  • Functional Area: Displays the functional area this status belongs to (read-only).

  • Status Name: Enter the descriptive name for this status value.

  • Status Number: Enter the numeric value that identifies this status.

  • Mandatory: Enable this option if this status is required and cannot be bypassed during processing.

  • In Default Flow: Enable this option to include this status in the default processing flow for the functional area.

  • Related Status: Select the status value that this status is associated with in the flow.

  • System Status: Select the system-level status that maps to this functional area status.

  • External Status: Enter the external status value used when uploading status data to an external system.

  • Include In Interface Upload: Enable this option to include this status in interface upload processing.

 

Use Back, Save, Continue, and Finish to manage and complete Functional Area status flow configuration.
