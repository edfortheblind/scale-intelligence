Inventory Transaction Touchpoint

Inventory transaction data, such as positive/negative adjustments and transfers, can be uploaded to your ERP via the system interface. This ensures that the ERP keeps its inventory balances aligned with the system's balances.

 

 

To see actual examples of the inventory transaction touchpoint, see the following topics:

- Delimited Interface Tutorial

- Fixed Length Interface Tutorial

- Direct Interface Tutorial

- XML Interface Tutorial

 

General Guidelines...

  • The interface can upload transaction history records that identify inventory changes at a particular location (or locations). Short picks are always included in inventory transaction uploads. All other adjustments can be interfaced if the Include in Interface Upload Checkbox is selected on its Adjustment Type Window.
     
  • The upload will include records for all locations that were touched by an adjustment, since the last time that the inventory interface was run. If multiple transactions were committed at one location, the system will generate one record per transaction. If a transfer occurs, one transaction record is generated per location involved. The record cannot have been interfaced previously.

 

 

Catch Weight Fields (XML Upload Only)

 

  • CatchWeight and CatchWeightUM are available only when the upload output method is XML.

 

Rejection Causes / Validations / Notes...

  • The SCALE interface process does not support using a comma as a "seperator" for numeric values. These values will need to be interfaced into the system using decimals as seperators (4.95, not 4,95). The system can, however, display these values with a comma seperator on SCALE windows, but in the database they must be in a decimal format.

 

 

Selection of Transaction History Records for the Upload Interface...

Depending on what transaction type the transaction history record has, the upload interface handles it differently. The following sections define how the system determines whether to upload the records based on transaction type.

 

A) Excluded Transactions

The following transaction history records are excluded from the inventory transaction upload, regardless of whether the history transaction type configuration has the "Include in Interface Upload" setting set to Yes. The reason is that these transactions get uploaded in other interfaces, such as the shipment upload, or they do not actually affect on hand inventory.
