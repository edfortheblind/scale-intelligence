Defining Print Devices

You will need to identify each printer to the system. Any printer that you can view from the network can print system documents; however, any printer you want to use must be declared on the server.

 

Prerequisites

Define the printer to the server using the Microsoft Windows Add Printer Option (Start | Settings | Printers | Add Printer). This must be completed on the server where the application is loaded.

 

WARNING: To minimize printer configuration maintenance, verify that the printer's Network Name is the same as its Share Name. You can check the Share Name by accessing the Printers Window in Microsoft Windows (Start | Settings | Printers). Right click on the printer. Select the Sharing Action. Review the value in the Share Name Field. Note: if you want the printer's Share Name to be different than its Network Name, see the "Changing the Printer's Share Name" section of the topic Printing Paperwork.

 

Printers and Vendor Compliant Labels

Printers producing vendor compliant labels must be accessible through a network share. Please refer to the Printer Configuration installation guide for more information.

Identifying a Printer

To route the data and template to a specific printer, you must identify the printer to the server.

  1. Use the Device Name Field to identify the printer to employees. This value should be descriptive and will later be displayed in the Device Field on the Document Routing Window.

     

  2. Use the Description Field to either reiterate the value in the Device Name Field or to provide a longer description.

     

  3. Select the printer from the Qualified Device Name Field. Any printer that you declared on the server is available.

     

    • If the Printer is Declared on a Personal Computer (or other non-server location), the qualified device name will identify both the machine that the printer is declared on and the printer itself. In the example below, Front_Office is the machine and Printer1 is the printer. Since the printer is not declared on the server, its network path is included in its name.

       

    • If this printer is declared on the server, the qualified device name will just identify the printer. Since the printer is already defined to the server, you will not see a network path.

 

Identify a Label & Print Driver

The procedures below assume that you already created this record when you identified a printer. You will need to complete this step if one of the following conditions exist:

  • You are printing a vendor compliant label.
     
  • You are printing a Progistics document or label.

The print driver translates information transmitted from Windows to the printer. If you don't select the correct driver, the printer cannot produce the document. Before you begin, obtain a list of the valid drivers from the Progistics CD.

  1. Use the Rating Printer Driver Symbol Field to identify the appropriate driver.
     
  2. The Rating Printer Stock Symbol Field will include all label choices that are valid for that driver. Select the appropriate label from this Field. See "More on Printers & Stocks" for additional information.
