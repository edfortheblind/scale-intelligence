Creating Labor Groups

This window allows you to define the types of labor being performed within your warehouse. These records in SCALE define such information as full time and temporary employees, as well as, what quantity unit(s) of measure they typically pick based upon a time factor. The system uses these records when processing labor plans during a wave. It uses the information to help calculate the estimated time it takes the workers, from a certain labor group, to pick their work or shipments. Labor planning and monitoring is established using labor groups. Labor planning can be defined at both the shipment and work levels. Labor monitoring occurs only at the work level. Only one labor group needs to be setup for shipment based planning, work based planning and work based monitoring, depending on your needs. To avoid multiple labor plan records from being written for one work unit, SCALE will not allow a work type to be assigned to multiple labor groups. If a labor group is assigned to a work type (using the Work Type configuration) and then the work type is later assigned to a different labor group, the system will update the records automatically.

Procedures...

Access the Labor Group Window. Create a new record.

  1. Use the Labor Group Field to provide a name for your labor group record.

  2. Use the Description Field to enter a description of the labor group.

 

Using the Resources Tab

Use this tab's information to calculate how much manpower is available to process a particular group of work or shipment details. The system uses this information to calculate how much manpower is available to process a particular group of work or shipment details.

  1. Use the Number of Full Time Employees Field to indicate the total number of full time employees that will work on this labor group's shipments.

  2. Use the Hours Per Full Time Employee Field to indicate the total hours a full time employee works per day (excluding such non-work activities as break time).

  3. Use the Number of Temporary Employees Field to indicate the total number of temporary (part time) employees that will work on this labor group's shipments.

  4. Use the Hours Per Temporary Employee Field to indicate the total hours a temporary employee works per day (excluding such non-work activities as break time).

  5. Press OK. The system will save your record.

 

Using the Estimation Tab

The system uses the fields on this tab to determine how much product can be processed by the employees defined on the Resources tab.

  1. Use the Estimated Time Per Transaction (In Minutes) Field to define how long it will take an employee to process the amount of products you are defining on this tab.

  2. Use the Calculate Time Based On Field to identify how the system will calculate labor time:

    - Unit of Measure: The system will calculate the estimated time data based on the UM that the worker will be picking. It assumes that it takes the same amount of time to process 1 instance of this unit of measure as it does 30 instances.For an example of this calculation, see the "Scenarios" section of the Labor Management Process Summary topic.

    - Quantity: The system will calculate the estimated time based on the quantity of the unit of measure that the worker will be picking. It assumes that it takes less items to process 1 instance of this unit of measure than it does 30 instances. For an example of this calculation, see the "Scenarios" section of the Labor Management Process Summary topic.

  3. Use the Quantity Units of Measure Field to select the units of measure that are processed under this labor group. For example, if a worker in this group typically picks only cases, you can indicate that here. Also, note that you do not have to specify any units of measure. If none are selected, then all units of measure can be processed. If you set this to more than one unit of measure, the system doesn't sum across the units of measure when applying the time value. For example, if you have the time set to 5 minutes and CS and EA values selected here, it just means it takes 5 minutes to process the CS and 5 minutes to process the EA. It doesn't mean it takes 5 minutes to process CS and EA at the same time.

Example of how fields work...

 

Suppose you set the 'Calculate Time Based On' Field' to 'UM' and the 'Estimated Time Per Transaction' Field to '5'. The 'Units of Measure' Field is set to 'CS'. When the user processes a request for 10 CS, the system will assume it will take 5 minutes to process these 5 cases. If the user processed 90 Cases, the system assumes it takes 5 minutes.

 

Now suppose you have the same setup, but switched the 'Calculate Time Based On' Field to 'Quantity'. When the user processes a request for 10 CS, the system thinks it will take 50 minutes to process the request; if the request is for 3 CS, the system assumes it will take 15 minutes.

 

 

Planning & Monitoring Tab

This tab allows you to define the labor group planning at both the shipment and work levels. The labor group monitoring is defined by work type.

  1. Use the Shipment Labor Planning Criteria Field to assign a criteria record to your labor group. This criteria includes rules that the system uses to determine what work or shipment(s) a labor group will pick. The system references this before a wave is run to calculate how long it will take to process the shipment details. If work creation fails to run, SCALE will revert back to this method of estimating work. This is just a planning tool, the system doesn't provide monitoring capabilities for shipment details.

  2. Use the Planning and Monitoring from Work Field to select which work type(s), or select all work types, that will be monitored for this labor group. This method allows the system to plan work activities and then monitor your progress. The system performs monitoring by checking to see if any work has been created and completed.
