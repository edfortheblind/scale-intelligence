Trading Partner Management Main Menu

You can use this window to access all of the Trading Partner Management modules, such as web order entry or web statistics. You can access this window by double-clicking the Trading Partner Management shortcut on your desktop. Also, you can access this window by opening Internet Explorer via the Windows Start Menu. Enter the following value into the Address Field: http://AppServer/eXchange/, where "AppServer" is the name of your application server).
