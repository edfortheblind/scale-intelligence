Yard Location

You can use this window to create yard locations. This type of location consists of an area and one or several position(s), and are not inventory-tracked. Yard locations are used as a temporary storage area for truck trailers that are going to be received into your warehouse. Once a trailer is residing in a yard location, workers then can move the trailers to other locations in the yard, or move them to the Receiving Dock for processing.

 

Create Yard Location

 

Use the Warehouse Field to indicate where the new location will reside.

Use the Location Area Field to indicate in which area you want to create your new location.

Use the Location Separator Field to view what character will separate the location area and position values when displaying the concatenated value in yard management processing.

Use the Position Range Field to create a single position or a range of positions. Note that you need to have at least one position for every location you create.

Use the Check Digit Field to indicate the check digit that you want a worker to enter into the system to verify he/she visited the correct location.

Use the Generate Check Digit Checkbox to indicate that you want the system to automatically generate check digits for this location.

Use the Multi Trailer Checkbox to indicate that you can have more than one trailer residing in a particular yard location.
