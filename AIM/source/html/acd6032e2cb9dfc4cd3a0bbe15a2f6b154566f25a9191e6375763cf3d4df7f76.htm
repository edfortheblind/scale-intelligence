Establishing Vendors

A vendor record identifies a company that supplies product to your warehouse. You are not required to define vendor records, but they are helpful if you need to contact a vendor concerning an particular receipt. You can create parent and child vendor records. This is usually beneficial if the parent record represents the corporate office and the child records represent different distribution hubs.

 

Parent Records, Child Records, & Inheritance

The parent record represents the corporate headquarters for the vendor. Often, the parent record is also the location where you will send payment for receipts. Each child record represents a distribution hub that sends the receipts to your warehouse. By creating separate records for the corporate office and each distribution hub, you can minimize setup time by using inheritance. Inheritance allows you to default values from the parent record to the child records. The system uses the Vendor, Company, and Ship From values to link the corporate address with the child record.

 

NOTE: If you change an inherited value on a parent record, the system will not automatically apply this change to any existing child records. You would need to manually make the change on each child record.

 

 

Do I Need To Create Both Parent & Child Records?

For the vendor record, you will only want to create both parent and child records a group of distribution centers share the same corporate address. Below are procedures for defining both the parent and the child record.

  • If you are defining a vendor that does not have a corporate address, just complete the procedures for "Defining the Parent Record."

     

  • If you defining a vendor that has a corporate address and multiple distribution centers, complete the procedures for "Defining the Parent Record" and "Defining a Child Record."

Defining the Parent Record...

 

Header Fields

You will use the header fields to identify this vendor. Provide values in the Vendor Field and the Description Field.

  1. Use the Ship From Field if this parent record also ships product to you . In this case, the parent record represents both a billing address and a supplier. If this parent record does not ship product, don't enter a value here.

     

  2. Select the Parent Check box if this vendor is a parent record.

 

General Tab

  1. If you are creating a parent record, use the address field to define the corporate address for this company. Use the contact fields (Attention To, Fax Number, etc), to identify personnel that you can contact at the corporate level.

     

  2. If you are not creating a parent record (this is the distribution center), use the address fields to identify the vendor who will directly send you product. Use the contact fields (Attention To, Fax Number, etc.) to identify personnel at this organization that you can contact.

 

Using the Verify Item Unit of Measure Checkbox

This setting determines if the system will require you to, during the receiving process (processing a receipt from a specific vendor), verify that a received container holds the amount of units as defined on the item's unit of measure record. This check box can be defined on either the parent record or on individual child records. Note that if you activate this setting on the parent record, create child records, and then unselect this setting on the parent record, it will remain selected on all child records (you will need to manually remove it from each child record).

 

NOTE: This setting also applies when creating pre-check in receipt containers.

 

 

 

Defining a Child Record...

 

Header Fields

  1. In the Vendor Field, provide the same value that you defined in this field on the parent record. The values must be exact, or the system will assume that you are creating a record not associated with the parent vendor.

     

  2. Use the Ship From Field to identify the distribution center that delivers product to you.

     

  3. If the parent record's Company Field contains a value, use the pull-down menu here to select that same company. If the parent record did not define a company, you will leave this field blank.

     

  4. You will not be able to provide a value in the Parent Check box. As soon as the system recognizes that this is a child record, it will disable this check box and display the Inherited Check box on each field that can obtain a value from the parent record.

 

General Tab

All inherited values reflect properties defined for the corporate office. These include address and contact information. For each field with an inherited value, determine if this value also applies to the distribution center, which you are defining with this child record. For example, does the distribution share the same address as the corporate office? If it does not, deselect the Inherited Check box. The system will remove the defaulted value from field. You can then identify the distribution center's actual address.

 

The system will associate the parent record's address with the child record via the Vendor Field and Ship From Field values, even when you deselect the inheritance check boxes.

 

 

Verify Item Unit of Measure Checkbox

This check box can be defined on either the parent or child record. See the description in the "Defining the Parent Record" for more details.
