Comment Type

A comment type determines when a specific message should be included on documents associated with a particular document type, effectively linking messages to documents. Each comment type must be defined in both the ERP and the system. When setting up a comment type in this screen, ensure it matches exactly with the one defined in the ERP—any mismatch will prevent the system from printing the correct comment on the document. Once the comment type is defined, you will associate it with the relevant document types for printing.

 

Create Comment Type record

  • Comment Type - Enter the name of the comment type. This value must exactly match the corresponding comment type defined in the ERP. When used in a shipment, shipment line, or work instruction, the system will refer back to the ERP to retrieve the related message.

  • Description - Provide a description of the comment type. This is for reference only and does not need to match any ERP value.

  • Communication Method Buttons: Specify when the comment will appear on an device. Note: The system does not consider the "before/after" timing for printed documents like pick lists.

    • Before: Displays the comment before the associated work instruction.

    • After: Displays the comment after the work instruction is completed.
