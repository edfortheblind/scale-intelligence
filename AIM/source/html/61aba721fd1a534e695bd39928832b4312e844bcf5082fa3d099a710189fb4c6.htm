Creating Zones

A zone manages the activity that can occur in a group of locations. Zones can also be used to group together locations for processing. For example, if an allocation rule identifies Zone B, the system will only consider allocating product from a location in Zone B (when this rule is used). This minimizes processing time and increases your control over which locations are considered during system processes such as locating and allocation.

Procedures...

Access the Zone Window. Name the record and provide a description.

  1. Use the Zone Type Field to identify the function of this zone. The system supports three zone types:

     

    • Locating zones group together locations that share the same locating requirements.

       

    • Allocation zones group together locations that share the same allocating requirements.

       

    • Work zones group together locations serviced by the same work teams and equipment types. In addition, the same work types are performed in a work zone.

     

  2. Use the Pick Management Active Checkbox to indicate if the system will display this zone in the Picking Management Explorer and Picking Window. Only zones that have this checkbox selected will be available to be picked from in these windows. You must choose a zone type of "Work" if you want to activate picking management. Note that both this flag and the work type associated with the work instruction must be checked to be eligible for picking from these windows.

     

  3. Press OK. The system will save your record.
