Wave Picking Group

A wave picking group defines the number of loose or full containers that can be included in a group, as well as the specific locations or work zones where the group can be used. It serves as a physical tool to streamline and consolidate the picking process within a warehouse.

Common types of picking groups include:

  • Carts

  • Cherry pickers

  • Forklifts

During a wave, the system can execute the group picking step, assigning containers (created during the container creation step) to the appropriate picking group based on configuration.

 

Add New record

  • Click Add new header to start creating a new wave picking group.

  • Provide a name for this wave picking location group and a description.

  • In the Number of Loose Containers field, specify how many open containers the pick group can accommodate.

    • For example, if using a 4x4 cart, determine how many loose containers can be easily placed and accessed. Since only a single layer of loose containers is typically used, carts often accommodate fewer containers than a group designed for full containers.

  • Note: If you have container types of varying sizes, we recommend that you determine this initial number based on the container type considered your medium sized container. Later, you can modify the number of containers allowed if too many or too few containers are being assigned to a group.

  • In the Number of Full Containers field, define how many fully packed containers the group can hold.

    • Unlike loose containers, full cases are shipped in their original storage container and not repacked, allowing them to be stacked and increasing the number a pick group can handle.

    • Use the same sizing strategy as above—base your estimate on a typical or medium-sized container, and fine-tune as needed.
