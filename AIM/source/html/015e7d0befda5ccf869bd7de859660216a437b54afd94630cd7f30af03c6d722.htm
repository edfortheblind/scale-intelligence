Defining Editable Field Decimal Positions

The decimal positions (number digits to the right of the decimal) of editable fields in the system are tied to the resource file and not the Decimal Positions Window. To adjust the number of positions on these fields, you will need to address these fields in the System Text Editor.

 

 

Note About Keeping 14 Digits To the Left of the Decimal...

Below are the settings that are allowed for numeric fields in the System Text Editor if you want to keep 14 digits to the left of the decimal. This is applicable for any numeric fields throughout the system which have a maximum field length of 19,5:

 

[field length, decimal position]

  1. 14,0
  2. 15,1
  3. 16,2
  4. 17,3
  5. 18,4
  6. 19,5

Note that anything having more than 14 digits to the left of the decimal would be an invalid setting.

 

 

 

Procedures...

  1. Open the System Text Editor from the desktop.
     
  2. Search for the field(s) that you want to change the decimal positions. Enter the search criteria in the Key Field and press the Search Button. The system will display the results in the record list.

    For example, suppose you want to change all quantity fields to not show any decimal positions. You would then want to search for any field that has a resource key containing the terms "Quantity" and/or "Qty".
     
  3. Select the entry you want to customize, right click, and choose the Open Custom Value option. The system will display the Custom System Text dialog.
     
  4. Use the Decimal Position Field to define how many decimal positions this field will display and press OK.
     
  5. Repeat for all field(s) that you would like to change.
     
  6. Choose Apply on the System Text Editor Window.

 

 

Updating All Fields To Zero Decimal Positions...

If you do not have any specific fields that you want to edit the decimal positions, you can run a quick query to update all of the fields at once to have a decimal position value of zero.  The queries below will insert custom records for QUANTITY and QTY resources with a decimal position value of 0. You could pull out the resource key section that narrows the results down to QUANTITY if you wanted to do this over all keys.

 

 

 

SQL Server Queries...

-- First update all existing custom records:

UPDATE RESOURCE_FILE_CUSTOM

SET DECIMAL_POS = 0, USER_STAMP = 'System', PROCESS_STAMP = 'Decimal Pos = 0', DATE_TIME_STAMP = getDate()

WHERE (RESOURCE_KEY like '%QUANTITY%' OR RESOURCE_KEY LIKE '%QTY%')

AND DECIMAL_POS = 5 AND RESOURCE_GROUP = 'Text';

 

-- Next insert any missing custom records:

INSERT INTO RESOURCE_FILE_CUSTOM

(RESOURCE_LANGUAGE, RESOURCE_GROUP,RESOURCE_KEY,TEXT,FIELD_LENGTH,DECIMAL_POS,USER_STAMP,PROCESS_STAMP,DATE_TIME_STAMP)

SELECT

RESOURCE_LANGUAGE,RESOURCE_GROUP,RESOURCE_KEY,TEXT,FIELD_LENGTH,0,'System','Decimal Pos = 0',getDate()

FROM RESOURCE_FILE_BASE

WHERE (RESOURCE_KEY like '%QUANTITY%' OR RESOURCE_KEY LIKE '%QTY%')

AND DECIMAL_POS = 5 AND RESOURCE_GROUP = 'Text'

AND NOT RESOURCE_KEY IN (SELECT RESOURCE_KEY FROM RESOURCE_FILE_CUSTOM

   WHERE (RESOURCE_KEY like '%QUANTITY%' OR RESOURCE_KEY LIKE '%QTY%')AND RESOURCE_GROUP = 'Text');
