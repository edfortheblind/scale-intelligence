Immediate Reconcile of Bad Count Checkbox

This checkbox indicates if the user can immediately adjust the inventory in this location as long as it's within the preference's positive and negative tolerances.

  • If this checkbox is checked, the user assigned to this preference can immediately adjust the inventory in this location, as long as it's within the preference's positive and negative tolerances.

     

  • If this checkbox is not checked, the user assigned to this preference can never adjust the inventory on his own. The system will place every cycle count request that this user encounters (that is not equal to the system quantity) into a "pending review" status. This request then will have to be reviewed by someone authorized to perform cycle counts.
