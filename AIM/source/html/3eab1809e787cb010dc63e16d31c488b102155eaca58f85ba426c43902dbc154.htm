Creating Document Criteria Records

Document criteria records allow the user to select and sort the detail data on particular document types. This is done by first creating a criteria record for a document (in one of the four Document Criteria Windows), and then assigning it to a document (in the Document Window).

Step 1: Creating the Criteria Record...

Choose one of the four document criteria windows from the Configurations Explorer, and create a new record.

  1. Using the Filter Data Tab: You can use this tab to indicate what field(s) that you want to filter out of your paperwork document. For example, if you do not want to print the component items on that Shipment Pack List with BOM Components, you could enter the following filter data rule: RELATED_LINE_NUM = 0. The system then would only print the non-component detail lines on the document.
     
  2. Using the Order By Tab: You can use this tab to sort the detail lines of a document in a different way than the system does by default. For example, on a Shipment Pack List with Containers, suppose you want to sort the details by order line number in an ascending order. You would enter the following attribute: SHIPMENT_DETAIL.ERP_ORDER_LINE_NUM / Ascending. The system then would print the shipment lines on this document in an ascending order.
     
  3. When finished, press OK. The system will save your document filter record.

 

Step 2: Associating a Filter Record with a Document...

Access the Document Window from the Configurations Explorer. Open the record of the document you want to assign a filter to.

  1. Use the Document Criteria Field to assign a document filter to this document. Now, when the system generates this paperwork, it will use this filter record to display the values on the document. Choose no value in this field if you want the system to use the default layout for a document.

     
  2. Press OK. The system will save your changes.
