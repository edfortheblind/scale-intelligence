Searching/Viewing Receipt Line Records...

  1. Open the Receipt Line Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search:

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.

 

 

 

About the List Pane...

  • The Receipt Line Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Receipt Line Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

 

  • The Detail Pane of Receipt Line Insight contains Indicator Tiles with counts of the other entities (i.e.receiving containers). The Container Indicator Tile displays the number of receipt containers associated with the receipt line. Clicking this will open the Receipt Container Insight screen by filtering through the Internal Receipt Line Number. If Run permission is not there for the Receipt Container Insight, the hyperlink will be disabled in the Indicator Tile.

 

 

For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

 

 

Screen Actions...

The following actions are accessible from the Receipt Line Insight screen:

 

Edit

This action allows you to display and edit a receipt line’s information.

 

Delete

This action allows you to delete the selected receipt line(s). You can delete single or multiple receipt details at a time and the action is enabled for the receipt line(s) for which no quantity has been checked in. If multiple receipt lines are selected with some eligible for deletion and some not eligible, system will delete all the records till it encounters the first receipt which is not eligible and stop there.

 

Immediate Needs

This action allows you to select an immediate needs transaction for the Immediate Needs Insights screen. For more information on Immediate Needs, see the Researching a Warehouse's Immediate Needs topic.

 

View

This action allows you to display a receipt line’s information.
