Creating Security Groups

Group level security allows you to establish a group of users who are all assigned the same security. A security group allows you to add users with common job functions. This allows you to add or remove users from the group as needed. A user will be allowed to belong to only one group at a time. If a user is already assigned to another security group, the user's name will be displayed in red on this window. Any security settings for a group can be changed and all users in the group would automatically reflect the new settings. For example, the security administrator wants to set up a “security profile” for all users in the 'Packing' department – with authority to just those options that people in the group need. As individuals join the packing area, the security administrator assign users to the 'Packing' group. This allows you to automatically implement the security for that group without having to do any other setup for that specific user.

 

A security "group" can be assigned on the User Profile or Security Permissions windows. A security group's permissions can be copied to a different security group. Or, the security group's permissions can be copied to a specific user. When a security group is copied, only the forms (windows) are copied. Users are not copied. The 'Security Permissions' window displays what group level security records are assigned to a specific form (window).

 

Security is defined from the Security Setup folder (accessed from the Configurations Explorer).

Using Security Groups...

Before a security group can be assigned to the security permissions records, a group needs to be created using the Security Group Window. Using a security group is optional depending on your operational security requirements.

  1. Enter the name of the security group and description.

  2. Assign/Unassign users to this group or create the group without any users assigned. (Note: if a user is already assigned to another security group, their name will be highlighted in red).

  3. Use the Display Only Current Group Users Checkbox to only display users that are assigned to this record's group.

  4. Use the Check All Checkbox for the system to select all the user(s) that are currently being displayed in the tab. If you unselect the 'Check All' checkbox, the system will unselect all the user(s) that are currently displayed.

  5. Use the Filter field, to type text into the edit box and the user names will automatically filter to your criteria. A '%' can also be entered as a wildcard. For example, '%smith'

  6. Click OK to update.

 

 

Copying a Groups Security Permissions to a User or Group...

  1. Access the Security Group Window (from the Configurations Explorer Security Folder).

  2. Select the Security Group you want to copy.

  3. Click OK. The security group is displayed.

  4. From the Actions Menu, select either Copy Group Security Permissions 'To User' or 'To Group' option..

  5. From the Copy Permissions To Window, select the destination security user or group.

  6. Click OK to update and copy.

 

 

Copying a User Profile to a Security Permissions Group or User...

  1. Access the User Profile Window.

  2. Select the user being copied.

  3. Click OK. The user profile is displayed.

  4. From the Actions Menu, select either Copy User Security Permissions to 'To Group' or 'To User' option.

  5. From the Copy Permissions To Window, select the destination group or user.

  6. Click OK to update and copy.
