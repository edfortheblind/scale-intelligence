Using The Lot Insight Screen

You can use either of these two screens to research the details of Lot IDs that are assigned to item quantities in your warehouse. This is helpful if you need to view the expiration date(s) of certain lots, or want to see all the lot ID's assigned to a specific item.

Searching/Viewing Lot Records...

You can use the Lot Insight Screen to search for and view lot records in your warehouse.

  1. Open the Lot Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

NOTE: Clicking on the Lot ID in the Detail pane header or List Pane Grid field opens the Lot screen for that specific lot record.

 

 

 

About the List Pane...

  • The Lot Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Lot Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Lot Insight contains Indicator Tiles with counts of the other entities (i.e. locations and transactions). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  • Locations

    1. This field displays the number of locations in the warehouse for the selected item, company, and lot in the warehouse.

    2. Clicking on this tile will open the Inventory Insight screen filtered by the item, company, and lot in the warehouse.

     

  • Transactions

    1. Displays the number of transactions for the selected item, company, and lot in the warehouse.

    2. Clicking on this tile will open the Transaction History Insight screen filtered by the item, company, and lot in the warehouse for all transaction types.


For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

 

Screen Actions...

The following actions are accessible from the List Pane:

 

 

View/Edit

The View action allows you to open the Lot Insight screen in the read-only mode and the Edit action allows you to open Lot Insight screen in the edit mode. You can edit the following fields: Inventory Status, Expiration Date, Frozen Toggle, Lot Attributes, and User Defined Fields. Updating the lot information except lot attributes and saving the record will show the Lot Update Confirmation Screen with affected inventory. For more information, refer to Using the Lot Update Confirmation Screen.

 

NOTE: You can also edit the lot details by opening the screen using hyper link on the list pane as well as through the indicator tiles section.

 

 

Adjust

This action allows you to adjust the inventory in your warehouse. Choosing this action opens the Inventory Adjustment screen. Refer to the Adjusting Inventory topic for more information.

 

 

Transfer

This action allows you to transfer the existing inventory on your warehouse. Choosing on this action opens the Inventory Transfer screen. Refer to the Transferring Inventory (Desktop and RF) topic for more information.
