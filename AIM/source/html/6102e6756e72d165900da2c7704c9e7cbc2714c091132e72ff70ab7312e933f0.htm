Using the Work Monitoring: Customer Screen

You can use the Work Monitoring: Customer screen to research and manage employee workloads in your warehouse. It is accessible from the SCALE Desktop menu, as well as a tablet device. This allows you to be able to interact with the system from literally anywhere. The system uses a configurable framework called metadata to display this screen's components, which allows you the ability to customize certain parts on the screen.

 

 

Notes
  • This topic discusses specific data that is represented on this screen as it is shipped in the base SCALE product. If your screen has been customized, different data may appear on your screen.

Navigating the Work Monitoring: Customer Chart

 

  1. Open the Work Monitoring: Customer screen.

  2. The system will display the monitoring screen, with the chart on the first (highest) level, customer category 1.

  3. Next, click/tap on a customer category 1 data column, and the system will then display the next level of the chart, customer name.

  4. Next, click/tap on a customer name data column, and the system will then display the next level of the chart, ship to name.

  5. Next, click/tap on a ship to name data column, and the system will then display the next level of the chart, work group

  6. Again, click/tap on a work group data column, and the system will then display the final level of the chart, work type.

  7. Finally, when you click on a work type data column, the system will open the Work Insight screen (in a separate browser window), with all the record(s) that meet the criteria you have chosen on the chart displayed on the insight's data grid.
