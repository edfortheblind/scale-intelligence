Stop Sequence Field

A stop sequence value associated with a shipment, which helps workers load shipments onto the truck in the correct order. The lower the number in this field, the sooner it will be due to be loaded onto the truck. For example, you would typically want to load the last stop on the truck first, since it will be farthest away from the truck door when it is opened. Conversely, you would want to load the first stop last so it is right at the truck's door and can be unloaded first. If you want the system to give the user the work in reverse stop sequence order, you will need to include the Stop Sequence field in your Dock Management Work Criteria's Order By (in descending sequence). Note that if you are performing user directed dock management work, there is no validation ensuring that the highest stop sequence is loaded first.
