Rendered Document PDF File Directory Field

This field indicates where you want SQL Server Reporting Services to place rendered (created).pdf files. Note that these .pdf files are not automatically deleted from this directory after they are printed by the default PDF reader application.

 

This field is present in the Warehouse and Document Type Configurations. The appending of the Document Type path onto the Warehouse path determines the full path to the PDF file directory. For example, if the warehouse path is \\Localhost\ILS\Reporting\SSRS and the document type path is Allocation Pick List, the full path used would be \\Localhost\ILS\Reporting\SSRS\Allocation Pick List when printing an Allocation Pick List.

 

NOTE: A blank document type path prints the document using the warehouse path. If the warehouse path is blank, then the document type has to be a valid path.
