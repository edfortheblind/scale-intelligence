Note On Serial Number Archiving

Inbound Serial Number Archiving...

If an item is defined for inbound serial number tracking (without inventory tracking), the system will archive the serial number when the receipt is closed. This keeps only the active serial numbers in the active serial number table. After archival, these serial numbers will still show up on the Receipt Container screen, any receipt container paperwork, and various search screens.

 

 

Outbound Serial Number Archiving...

If an item is defined for outbound serial number tracking, the system will archive the serial numbers once the shipment has been ship confirmed. This keeps only the active serial numbers in the active serial number table, and allows for serial numbers to re-enter the warehouse as a return. After archival, the serial numbers will still show up on the Shipping Container screen, any shipping container paperwork, and various search screens.
