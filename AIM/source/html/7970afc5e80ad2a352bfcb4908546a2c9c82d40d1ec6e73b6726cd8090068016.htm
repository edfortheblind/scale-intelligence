End Date Time Field

This field identifies the day and time that a certain action/event stopped.

 

 

Work-Related Notes...

The time that work was confirmed in the system. The value in this field depends on how the work was processed.

 

- If work is processed via an RF, the end time is associated with a work unit and its instructions. The end time is defined when an employee confirms an instruction record for this work unit. If multiple instructions are associated with a work unit, they will contain the last confirmed time in this field.

 

- If work is processed on the Work Insight Screen, the end time is associated with each work instruction. It is defined per instruction when its confirmed. The work unit has the same end time as the last confirmed instruction.

 

Since work processed on the Work Insight Screen is generally physically completed before its updated here, the end time is usually the same for all instructions and the work unit. The end date time is keyed on the screen. If processing against this work unit has not been initiated, the system will default the current time in this field.
