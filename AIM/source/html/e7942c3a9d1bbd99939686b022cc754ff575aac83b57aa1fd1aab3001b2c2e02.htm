Researching a Warehouse's Immediate Needs

The immediate needs module links the receiving and outbound processes to fulfill the immediate needs of your warehouse. There are two main components of the immediate needs process: the logging of an immediate needs request, and the fulfillment of that immediate need. Logging involves the system generating an immediate needs request to indicate that an entity (shipment, work order, replenishment, or short-picked shipment) cannot be completely fulfilled. The fulfillment process involves the system taking newly-received item quantity and automatically allocating this quantity to fulfill the immediate need. Users can view a list of the current immediate needs requests and their statuses on the Immediate Needs Insight Screen. These screens allow you to search for immediate needs requests using several search criteria fields. Once you fulfill an immediate need, the system will automatically close and delete the immediate needs request from the records grid.

 

NOTE: If there is no inventory currently in the warehouse for an immediate needs-eligible item, the shipment with this item will remain on the completed wave, and not be returned to the pool.

Researching Immediate Needs...

  1. Open the Immediate Needs Insight screen.

  2. Enter values in the criteria fields to define your immediate needs search (some key field explanations are below).

    - Request Key Field: This field identifies the system process that triggered an immediate needs request.

    - Internal Request Num Field: This field represents the system-assigned next number that is associated with an immediate needs request.

    - Display Requests Currently Being Fulfilled Checkbox: You can use this checkbox to have the system only display immediate needs requests that are currently being fulfilled, but have not yet been completely fulfilled (for example, inventory that has not reached the fulfill location).

    - Internal Fulfillment Num Field: This represents the internal number of the object fulfilling an immediate needs request. This value is a unique key of the immediate needs request.

    - Logged Date / Time Range Field: This field indicates the day or time that the system generated the immediate needs request.

  3. Press the Apply or Search button. The system will display the results of your search.

    - Note that you can delete an immediate needs request. Keep in mind that deleting immediate needs tied to work order details is not allowed. When selecting multiple immediate needs for deletion, the system deletes them in order. If it meets an immediate need it cannot delete, it stops processing and displays an error, and does not delete the remaining immediate needs.
     

 

Changing an Immediate Need Record's Priority...

An immediate needs request's priority setting determines when the system will attempt to fulfill it. The system assigns a default priority setting to an immediate needs request, as defined in the Immediate Needs Trigger. However, you can manually change a request's priority on the Immediate Needs Insight screen.

  1. First, perform a search for a particular immediate need record on the Immediate Needs Insight Screen.

  2. To change a record's priority setting, do the following :

    - Select a record or multiple records from the grid, and select the Change Priority option from the Actions Menu. The system will display a dialog where you can enter a new priority value.

    OR

    - Click or tap on the desired Immediate Needs record and then under Actions, select Edit.
