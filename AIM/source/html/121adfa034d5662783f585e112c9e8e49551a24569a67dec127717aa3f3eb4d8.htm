Defining Viewer Icons

You can define the icons that appear to the left of certain sets of records that display after a search query on the results grid of a SCALE viewer window. To add a custom icon to a viewer, add your graphic file to the following directory: \\ILS\ResourceImages\. For example, suppose you want the system to display an icon next to all the data records for a specific carrier. You would then need to create a record in the Viewer Icon Editor that defines which icon the system should display with the record(s) associated with a specific carrier. 

 

 Important: Read the Notes on Viewer Setup before adding icons.

Procedures...

Open your custom viewer record on the Viewers Window. Press the Fields Button, and select the Icons Tab on the Customize Viewer Window. Open an existing icon record, or right-click the list and select New Item. The system will display the Viewer Icon Editor Window.

  1. Use the Image Resource Key Field to indicate the icon that will appear to the left of certain records on the results grid. The system will use the rules defined in this window to determine what records it will display this icon for. If you do not assign any rules to this icon record, the system will display this icon for all results row(s).

 

Establishing Rules for Icons...

  1. You will use the Field Name, Operand, and Value fields to define rules. Note that you will only be able to choose fields that are a part of the database table that the viewer is associated with.

    For example, suppose you have a viewer that displays shipment records. You could assign a separate icon the system could use to display for different carrier records. So, when the system displays results from a query, shipments with different carriers are represented by different icons.  
     
  2. Or Checkbox: See the field topic for a description.
     
  3. You can then create more rules, or press OK to save your icon record.
