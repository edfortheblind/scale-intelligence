Searching/Viewing Labor Activity Records...

You can use the Labor Activity Insight Screen to search for and view labor activity records in your warehouse on a tablet device.

  1. Open the Labor Activity Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter button. The system will display all information regarding the resulting records in the List Pane.

 

 

About the List Pane...

  • The Labor Activity Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • The List Pane's Grid Fields contains some hidden fields. You can find this complete list of fields by clicking on 'Select columns'.

  • You can click on a hyperlink on the internal line number (per line) in the grid to open the Labor Activity Detail Screen for that line.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

  • The Labor Activity Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

  • For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

     

Screen Actions...

The following actions are accessible from the list pane of Labor Activity Insight screen:

 

View/Edit

View action when selecting a line in the grid helps you to open the Labor Activity Details Screen for that line in the read-only mode. Edit action, on the other hand, helps you to open the same screen for that line in the Edit mode.

 

 

Delete

This action allows to delete a labor activity record.

 

 

Manual Labor Entry

This action allows you to track labor works for manual activities. For additional information on this topic, refer to Using the Manual Labor Entry Screen.

 

Non Direct Labor Entry Screen

screen allows supervisors to enter indirect activities and gaps for multiple employees simultaneously. Read Using the Indirect Labor Workbench Screen for more details.
