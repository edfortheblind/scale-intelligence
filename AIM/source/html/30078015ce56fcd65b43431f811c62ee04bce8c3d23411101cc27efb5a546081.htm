Container Shape

A container shape indicates the physical shape of a shipping container. Examples include such shape descriptions as standard or irregular. During the wave's container creation process, the system attempts to put an entire item quantity into the next container type in the container group, and keeps trying until the items will not fit; therefore, putting it in the smallest possible container type. Note that the system will only downsize into sequences that have the same container shape as the container it started with. For example, if the first container the system packs a quantity into was irregular, then the system will attempt to downsize into the following sequences until it finds one that has a value different than irregular.

 

3D Cubing Container Creation Strategy Note...

Container shapes are handled differently when using 3D cubing as your container creation strategy. For more information, see the 3D Cubing: Determining Eligible Container Types section of the Container Creation in the Wave process flow topic.
