Creating a New Wave Record

Wave template records are created on the Wave Master Window. However, you can manually create a wave record from the Wave Insight screen. This is especially helpful when you need to select shipments into a specific wave that they are not generally processed through.

Creating a New Wave Record from the Wave Insight Screen:

  1. Access the Wave Insight screen from the Order Planning system menu.

  2. Open the Actions menu and tap on New. This opens the New Wave screen.

    - To define this wave based on a wave master record, select a wave master to create a wave based on a wave master. The auto release option is based on what is configured on the wave master and it is disabled when the wave master has been selected.

    Note: Only the authorized wave masters for the selected warehouse are shown which are defined in wave master configuration.


    - To define this wave based on a wave flow record, enter a wave name, select a wave flow, and set the auto release option to create a wave based on a wave flow.

  3. Tap on the Save button to add the wave to the system. A success message will be displayed and it will navigate back to the Wave Insight screen.

NOTE: The New option is available from the Wave Insight when showing active, completed, cancelled, or released waves, but the newly added wave is only visible when showing active waves.
