Creating Work Profiles

A work profile identifies the sequence rules associated with specific users and/or work teams. A sequence rule determines how will work will be released into the warehouse and completed. Generally a work profile includes multiple sequence rules, which the system processes in numerical order (10, 20, 30, etc.). Once all the work accommodated by the sequence has been processed, the system will apply the next sequence record. Note that a user can only be associated with one work profile at a time.

 

Each sequence rule defines a number of work parameters such as the following:

  • What equipment can be used to process the work?
     
  • Which work types can be processed in this sequence?
     
  • Who will initiate the work: the user or the system?
     
  • The order that the system will assign picking and putaway instructions.

Defining a Work Profile Header Record

The header record identifies the users and work teams that you want to associate with the sequence records. When you first access the header record, the Detail Records Tab will not contain any values, since you have not defined any sequences.

  1. Use the Authorized Users Tab to identify the employees who will process work based on this profile.

     

  2. Use the Warehouse Access Tab to identify the warehouse for which this work profile has access.

     

  3. Use the Work Team/Equipment Type Tab to identify the team(s) and equipment type(s) that will process work based on this profile.
     

  4. Use the Work Zone Tab to identify the work zone(s) that users will be able to execute work from while using this profile.

     

  5. After you have identified the people associated with this record, select the Apply Button. The system will leave this window open. You can now add sequences to this profile record.
     
  6. Select the New Action. The system will display the work profile detail window.

 

 

Defining a Work Profile Detail Record

 

Work Type Tab

These fields determine what work will be processed, when this sequence record will be invoked, and any equipment required to process the work.

  1. Use the Sequence Number to determine when this detail will be processed. Sequence records are processed in numeric order: sequence 10 is used before sequence 20. This field will contain a value that is 10 more than the last sequence number used. You can change the sequence number, but you cannot use the same sequence number for multiple detail records. For more information about sequences, see the "Tip" topic "Inserting New Details/Rules in a Sequence List."

     

  2. Use the Work Type Checkboxes to identify which work instructions will be processed using this sequence. If you do not select any work types, the system will assume that you want to process all work types with this sequence.
     
  3. During processing, the system uses the work types to determine when it should begin using the next sequence record. When all available work for these work types is completed, the system will begin using the next sequence record.
Work Processing Tab

These fields determine how work will be processed.

  1. Use the Work Initiation Method to indicate how the work will be assigned to the worker:

    - User initiated: The user selects which work he/she will process. User initiation is commonly used in paper-driven environments.
     
    - Cart Picking: The user will select which work he/she will process. Cart picking initiation is used in RF group picking environments.

    - System initiated: The system will assigns work to the user to process. System initiation is commonly used in tightly controlled environment.

  2. Use the Assign Multiple Work Units Checkbox to allow pickers (using system-directed work) to assign and execute multiple work units during a single picking session.

    Notes:
    - This setting is only available if you are using system-directed work.
    - You can only assign multiple work units if the From Location has a Location type that system assigns must be receiving dock and have “Allow work unit selection on system-directed work” setting selected.

  3. Use the Container Picking Method to indicate what type of RF pick/pack functionality, if any, that you want users of this work profile to perform:

    - Pick Into Shipping Container: Choose this option if you want users to be able to directly pick into the final shipping container. 

    - Pick Into Tote: Choose this option if you want users to be able to directly pick into a transport container, a.k.a. a "tote." Note that if you created containers in the wave, the Pick Into Tote option behaves during picking the same manner as the Pick Into Container option. Also note that you can pick multiple shipment lines going to different putaway locations into a single tote.
    Sort picked quantity - select to perform putwall sort.
    - None: Choose this option if you want users not to use the RF pick/pack functionality.-

  4. Use the System Directed Work Option to further define how the user will initiate system directed work:

    - Allow Renaming Of Existing Work Unit: This option determines whether or not the system will display the Rename Work Unit Field on the RF system directed work initiation screen. If this checkbox is selected, the system will display the Rename Work Unit field on the screen. Keep in mind that the user will be required to enter a value into this field. If it is not, then the system will only display the Location Field on the screen.

  5. Use the Picking Options to define settings related to the picking action:

    - Default LP ID As Container ID On Full Picks: This option is used to indicate that you want the system to default the location's license plate ID (from which you are picking quantity from) as the container ID of the shipping container that you are picking the quantity into. Note that you can enter a different container ID as well, this license plate ID is only defaulted into the field (its use is not mandatory).

    Notes:
    ** You can only use this functionality during RF pick into shipping container (not pick into tote or regular "not-into-container" picking).

    ** If you are not performing a full pick of the license plate's quantity, then the system will not default the LP ID as the container ID (even if this setting is active on your work profile). However, you can manually enter the LP ID into the Container ID Field.

    ** If the work instruction is for less than the license plate's full quantity, then the system will not default the LP ID as the container ID (even if this setting is active on your work profile). However, you can manually enter the LP ID into the Container ID Field.

    ** If there is an existing container associated with a shipment (and multiple items are/would be picked into the same container), then the system will default the existing container ID (not the LP ID, even if this setting is active on your work profile). Note that if you are picking single items into an existing container, the "override container" work special handling option must be active.

    ** If you choose to override the license plate from which you are picking from, then the system will default the new license plate ID as the container ID (if this setting is active on your work profile).

    - Group Picks By Loc/LP: This option is used in RF picking to indicate that if a work unit has multiple picks for the same item at the same location, you want the system to group this into one pick. For example, suppose a work unit has 2 instructions: (1) Item AAA, location 111, quantity 10 each, and (2) Item AAA, location 111, quantity 5 each. With this flag on, you will see a pick of 15 each from location 111 for item AAA. With this flag off, you will see the two picks one for 10 the other for 5. For more information on this setting, see the Group Picks By Loc/LP Checkbox field.

  6. Use the Group User Container Spot Assignment Field to determine if you want the user or the system to assign a spot (i.e., a place on a cart where the container that you are picking into resides) during cart picking work.

  7. Use the From Assign Method to determine how work units will be assigned during system-directed work initiation:

    - Priority/Location/FIFO: Work is assigned in priority order: the lower the priority, the sooner the work is assigned. This is commonly used to ensure that critical customers are processed first.   If the multiple pick instructions share the same priority, the system will assign the instructions in location order: the location closest to the user is assigned first. This minimizes travel time.   If multiple pick instructions share the same priority and location, the system will assign the instructions in FIFO. The first instruction generated during work creation is assigned first.

    - Location/Priority/FIFO: Work is assigned based in location proximity order: the location closest to the user is assigned first. This minimizes travel time. Please note that the system only recognizes number proximity in ascending order. In other words, if location 999-999-999 is physically next to 001-001-001, the system cannot recognize the distance between the locations. If multiple pick instructions share the same location, the system will assign the instructions in priority order: the lower the priority number, the sooner the instruction is assigned.   If multiple pick instructions share the same location and priority, the system will assign the instruction in FIFO order. The first instruction generated during work creation is assigned first.

    - FIFO: All work is assigned in the First In, First Out order. The first instruction generated during work creation is assigned first.  

  8. Use the To Assign Method to identify how putaway instructions will be assigned:

    - LIFO: All putaways are assigned in the Last In, First Out order. The last item picked is the first item put away. This is commonly used if you are processing product stacked on a pallet.

    - Location: All putaways are assigned in location proximity order: the putaway location closest to the user is assigned first. This is commonly used if you are processing product in a bin or other unorganized structure.

  9. Use the Putaway Options to indicate that you want pickers (using this profile) to perform putaway of item quantities into shipping containers. You can activate the following settings related to this action:

    - Putaway Into Shipping Container: This option indicates that you want the user to place product directly into shipping containers during the RF putaway process. Using this option, the system will either create a new shipping container, or add the item to an existing shipping container (whichever is appropriate).

    - Automatic Putaway Checkbox: This option is used to indicate that you want the system to automatically putaway items during the work execution process. This would bypass having to manually putaway each item on a shipment. Typically, this setting would be used when you are picking directly into shipping containers (but you can use it in any work scenario, except dock management work, where it is not supported). 

    - Consolidation After Putaway: This option identifies if you want to invoke the consolidation putaway process after performing a work putaway action on an RF device. Note that if the Automatic Putaway setting is selected, the Consolidation After Putaway setting will not be available to select.

    - Nest After Putaway Checkbox: This option is used in RF group picking, when you are picking into a final shipping container (only when the work unit is for a single shipment). If you check this checkbox, the system will display a nesting RF screen after you have putaway your shipping containers. If you specify a container, the picked containers are then nested under it. This allows you to do is pick into shipping containers, and then place those shipping containers on a pallet for shipping. Note that the nest after putaway functionality is not supported when performing putaway to shipping container.

    Also note that if receipt containers/license plates for these items were created during a wave, the system will group these as well. Suppose that 3 cases are ordered. During the wave, the system allocates the cases from the same location, and the system creates 3 full-case receipt containers/license plates. When a user performs the work via RF, they will have to verify and confirm only one time for all 3 cases combined.

    - Use Cross Dock LP ID From Receiving: This option indicates whether you want the system to use the license plate from receiving as the container ID when creating a new shipping container on the shipping dock. If this setting is not selected, then the user will have to manually enter a container ID in this situation. Note that this is an optional setting that is only available if you have enabled the Putaway Into Shipping Container option. Note that this functionality cannot be used if there was already a shipping container created for the shipment line during the wave or RF picking.

    - Group Putaway By Shipping Container: See this field topic for more information about this setting.

  10. Use the Print at WM Work Start Checkbox to indicate that you want the system to print shipping container label(s) when you begin to execute work units via an hand held mobile device. Note that the system will only print shipping container labels that have the "Start WM Work" print procedure checked on the document type record. Also, the system will only print in this manner if you are executing work that was created from shipping containers.

  11. Use the Enable RF Success Text Checkbox to indicate that you want the system to display a text message after each successful RF pick or putaway. The message will appear at the bottom of the appropriate RF screen. For example, you could have the system tell the user the last item that they picked, or the ID of the last container they picked into.

    Note that this message will appear after the first successful pick/putaway, not on the first picking/putaway screen. If the current executed pick was the last pick on the work unit, the system will display the message on the putaway confirmation screen. However, if the RF user goes on to execute another work unit immediately after executing a work unit, the system will display the RF Success Text on the Work Unit Entry screen for that work unit.

    In addition to displaying either the "success display" or "success message" field, you could have the system display both values to the user, For example, you could have the system show the text Last Item Picked: NOR0001, where "Last Item Picked:" is the success message, and "NOR0001" is the success display field.
     
  12. Use the Success Display Field to identify which field (from the work instruction database table) that you want the system to display in your RF success message. Keep in mind that you should choose an appropriate and useful field to display as a message on pick/putaway screens. If you choose an inappropriate value, the system may display irrelevant data (or no data at all), which could confuse the user.

  13. Use the Success Message Field to provide the actual text for your RF success message.

    - If you enter a resource key in this field, the system will display the text on the RF screen as defined in the key on the resource file.

    - If you enter text in this field, the system will display the RF screen as you type it in this field.
