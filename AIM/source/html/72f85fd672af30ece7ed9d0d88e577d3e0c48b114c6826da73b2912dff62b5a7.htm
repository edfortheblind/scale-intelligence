Please address the following configuration matters before using the Dock Manager Window.

Using the Dock Manager Window

 

 

General Setup Steps...

  • Create Dock Locations (staging, dock door) on the Location Window. If the appropriate locations are not created, nothing will display on the Dock Manager Window.

  • Perform other dock management configurations as appropriate. These are outlined on the Dock Management Setup Overview.

  • Note the Number Of Rows Field on the Dock Tab of the Location Window. This is where it is determined how many rows the system will display for a particular staging location on the Dock Manager Window.

  • In addition, you can add or modify some of the properties of the Dock Manager Window components, such as altering the data grids component columns, or adding gauges to the gauges component. These types of modifications need to be configured by a technical resource (see the SCALE SDK for information on these procedures).

 

Note About Security For Drag-And-Drop Actions...

You can define security for drag-and-drop actions in the same manner as action security in other SCALE windows. In the Security Window listing for the Dock Manager Window, there are a number of drag-and-drop security options available, such as "transfer load to dock door" and "assign shipment to position". For more information on configuring security settings, see the topic Creating Security Records.
