Creating Labor Plans

A labor plan record indicates what labor group(s) you want the labor plan execution wave step to process, and in what order. Labor plans can be automatically executed in the wave.

Procedures...

Access the Labor Plan Window. Create a new record.

  1. Use the Labor Plan Field to provide a name for your labor plan record. Also enter a description.

 

Using the Detail Records Tab

Right-click the grid area and select New. The system will display the Labor Plan Detail Window.

  1. Use the Sequence Number Field to indicate in what order you want the labor plan execution wave step to process through the group(s) assigned to this labor plan.

  2. Use the Labor Group Field to indicate a group that you want the wave step to generate estimated labor data for. Note that you can only create one detail record for any certain labor group (per each plan).

  3. Press OK. The system will add the record to the Detail Records Tab.

  4. To create another detail record, right-click the grid area again and select New.

  5. When finished, press OK. The system will save your record.
