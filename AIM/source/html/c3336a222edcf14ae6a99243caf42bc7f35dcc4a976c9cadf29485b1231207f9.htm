Processing RF Work (General Rules/Notes)

Processing RF Work:

  • Rules/Notes
  • Override Pick
  • User/System Directed
  • Group User
  • Pick Into Container

 

An RF device provides a portable method for warehouse work to be executed. Via RF, you can have the system drive the picking (system-directed work) or have the user scan/enter the work units that they would like to work on (user-directed work). Other flavors of picking that are supported via RF are group-user picking (assigning several work units to a transport container and picking them into it), or user directed picking directly into a shipping container. How you initiate your work depends on how you define your work profile.

Screen Display Notes...

The following items apply to the various RF work initiation/confirmation screens.

  • The number of decimal positions that the system displays on these screens is controlled by the Suppress Non-Significant Decimal Positions On RF Picking Screen setting on the Work System Values Window.

  • At the top of the Pick Confirmation screen, the system displays the following reference values/messages:

    - OH (On Hand quantity): This value represents the on hand quantity based upon the item/company/lot/LP at a location. Note that this value will not be displayed on the screen when executing dock management work.

    - ATP (Available To Pick quantity): This value is calculated by (available quantity) + (quantity on current work instruction), based upon the item/company/lot/LP uniqueness at the location. Note that this value will not exceed the "on hand" quantity value. Note that this value will not be displayed on the screen when executing dock management work.

    - VAS Required: This message indicates that the container that you are picking into has value added services associated with it.

    - QC Required: This message indicates that the container that you are picking into has QC associated with it. Note that if this container also has VAS associated with it, the system will not display this message.

  • If a current pick will empty a location of a particular item, the system will display an alert. This message is configurable in the Work System Values Window.

  • You can have the system default a pick location's license plate ID as the container ID of the shipping container that you are picking the quantity into. This option (Default LP ID As Container ID On Full Picks) is a setting on the Work Profile Window. For more details, see the topic Creating Work Profiles.

  • You can have the system-directed work initiation screen display either the Location and Rename Work Unit Fields, or just the Location Field. See the System Directed Work Additional Options section of Creating Work Profiles for more information.

  • After you perform a partial pick, and the system refreshes the screen, the partial quantity you just picked will display in the Quantity field, NOT the remaining quantity to pick for that instruction. This will speed up the picking process when picking to multiple containers (since it is likely that the same quantity will fit into each container). Also, if there is less remaining quantity than the last quantity picked, the screen will default the remaining quantity into the Quantity field.

  • You can view the lot's expiration date during RF pick confirmation. This expiration date format is dependent on user's local/regional date setting. However, if no expiration date has been captured or the maximum database value for this field has been assigned, the system will not display the expiration date.

  • The system places the cursor focus in certain fields in the following situations:

    ** The list below is in priority sequence (as soon as the first condition listed is met, that is where the system places the cursor).
    - If the "location verify" setting is enabled, the system places cursor focus on the Location field.

    - If the "item verify" setting is enabled, the system places the focus on the Item field.
    - If the "quantity verify" setting is enabled, the system places the focus on the Quantity field.
    - If the "put into shipping container" setting is enabled, then the system places focus on the Container ID field.
    - If the "put into shipping container" setting is enabled and a short putaway occurds, then the system places the focus on the Quantity field.
    - If the "container verify" setting is enabled and you are executing dock management work, then the system places focus on the Pallet field.
    - In all other situations, the system places focus on the upper-leftmost, input-capable field.

Picking Notes...

  • If executing a partial pick, the system will delete the remaining quantity from the work instruction (and close it) if the "Close After Partial Pick" check box (in Work Special Handling Window) is selected. If not, the system would keep the instruction open so the remainder could be picked later. Note that the "partial pick and close" action is only available for RF replenishment and work order picks, if it is defined to do so in the Work Special Handling Window.

  • You cannot perform a partial pick on a full container, full containers being containers created in the wave where the quantity allocated matches the quantity on that unit of measure for the item. In this case the system creates a single shipping container record that cannot be broken down further.

  • If you are executing a pick with the "Allow Over Picking" work special handling setting active, the system will allow the user to pick more quantity than exists on a work instruction, as long as this quantity is within the location's available quantity. When an over pick is performed, the system will increment the transaction quantity, and process the pick as a complete/normal pick. This option is only available for RF replenishment and work order picking. For example, suppose a work order component work instruction calls for 980 eaches of an item. It may be easier physically, then, for the worker to pick two cases of 500 (for a total of 1,000 eaches) rather than breaking one case open and leaving 20 eaches loose at the location. If this check box is checked, the system will increment the instruction by 20 eaches, and process the pick as normal.

  • If you are executing a pick with the "Allow Pick In Transit" work special handling setting active, the system will allow the user to pick quantities that are labeled as "in transit". Therefore, if there is not enough quantity in the location to be picked, but there is additional inventory that is on the way to the location, the user will be able to pick from that in transit quantity. Important: If the user picks this inventory, the on hand inventory at the location will show a negative quantity until that quantity is rectified by something such as a replenishment or an inventory transfer.

  • If you are executing a pick with the "Use Converted Quantity" work special handling setting active, the system will allow the user to pick quantities in the converted UM. If item has UM greater than base UM and pick quantity is a multiple of that converted quantity, the system uses converted UM as pick quantity when "Use converted quantity" checkbox is enabled. If the item only has base UM configured, the system uses base UM as pick quantity when "Use converted quantity" is enabled. If the item has UM greater than base UM but pick quantity is not a multiple of converted quantity UM, the system uses base UM as pick quantity when "Use converted quantity" is enabled. User cannot enter a decimal quantity for converted quantity to a partial/short pick.

  • If the item quantity being picked is catch weight and/or serial number tracked, the system will display an entry screen for each item being picked. Note that if the item you are picking is configured for serial number range entry, then the system will display a special screen that allows you to enter the first and last serial number in the range of numbers that is on the quantity that you are picking. You can also press the Skip button to return to the regular serial number entry screen (so you can manually enter each number as opposed to providing the range).

  • Note on Pallet Building (Picking Into Shipping Container mode): If you are picking product using the Pallet Building functionality, the system will display the Pallet ID and Pallet Container Type fields on this screen. Note that these fields will only appear if the shipping container you are working with has a parent container. Also, if defined in the work special handling configuration, you can have the user verify the Pallet ID for each pick.

  • If you are picking a full UM container (created out of the wave) that has serial number tracked items, then the system will not prompt the user to enter serial numbers.

  • It is highly recommended that you do not confirm decimal quantities of serial number tracked items when picking.

  • When short picking an inventory serial number tracked item when the for "Short Pick Inventory Action" inventory control value is set to "No count,remove all unallocated on hand quantity" or "No count, remove transaction quantity", the system will remove serial numbers to match the quantity being removed from the location. Note that it will NOT prompt the user for which serial numbers are to be removed, it will simply just choose them. To avoid this, you will need to configure this system value to one of the "Count" options so that the inventory gets moved to Suspense and a cycle count gets generated.

  • You can pick multiple shipments into totes when the following is true:

    - Work initiation is system or user directed.

    - Multiple shipments are on a single work unit being picked.

    - Group user initiation is not permitted and system will not assign a work unit with multiple shipments to a group user work group.

    - Group user initiation also will not allow user to assign same tote ID to multiple work units.

Putaway Notes...

  • Note that the system will require you to provide a License Plate ID if the To Location is license plate-tracked (and the quantity is not the entire license plate from the From Location).

  • If your work profile is defined to putaway into shipping containers (and you are putting away to a put-to-store location or the shipping dock), you will need to provide the Container ID that you are putting into. Also, if this is a new container, you will need to indicate the container type. The container types can be authorized by company and warehouse.

  • The system will allow a partial quantity to be putaway into either an existing or new shipping container. The system will prompt for the remainder of the quantity, or the quantity can be split again. Note that you can only do a partial putaway if there is a single item per putaway location. If there are multiple items being putaway to same location, the system will not allow a partial putaway.

  • When performing putaway to a shipping container, the system does not prompt for a catch weight value if the item requires catch weight.

  • When you are picking into a final shipping container (only when the work unit is for a single shipment), you may have the option of nesting the container after you perform the putaway action (if your work profile allows this). If you choose this option, the system will display a nesting RF screen after you have putaway your shipping containers. If you specify a container, the picked containers are then nested under it. This allows you to do is pick into shipping containers, and then place those shipping containers on a pallet for shipping.

  • When performing putaway, the system will display the Short Button if the following conditions are true:

    1. If the putaway location is a Put To Store location

    2. If you have security to the Short Button (putaway)

    - The system will also display this button if you override the original (non-Put To Store location) to a Put To Store location (assuming the above conditions are true).

    - When putting away multiple instructions to the same Put To Store location, the system will display the instructions separately, instead of displaying one summary screen (with the "All Items" designation). This is so the user can have the chance to indicate which instruction they wish to short put. If full quantities are entered as the putaway quantities, then the system proceeds with the normal putaway.

    - Partial putaways NOT into a shipping container to a Put To Store location are not allowed.

  • When doing receipt putaway work, the system tries to summarize (display one putaway screen for multiple license plates) whenever possible, depending on the item/location/license plate, and the user's work special handling settings.

  • If you are performing putaway for a full UM container (created out of the wave) that has serial number tracked items, then the system will not prompt the user to enter serial numbers.

  • If you are performing putaway to shipping container, the nest after putaway functionality (configured on the work profile) is not supported.

  • The putaway process on the shipping dock always does a putaway for all items and all quantities. It does not group these into separate putaways based on the shipment, or step through each work instruction. If putaway to shipping container is enabled, the work unit being put away must be for a single shipment if performing the putaway to a shipping dock location.

 

 

 

Consolidate putaway of Receipt Line to an existing LP Notes...

 

- You are allowed to putaway the same item into an existing LP (consolidate) and the system allows consolidation putaway of receipt line to an existing LP for:

  1. RF receipt putaway work

  2. Child LPs

 

- This is governed by work special handling “Receipt Putaway Verify Method” in which:

  1. Existing LP-Allow override and User Specified options will allow consolidation.

  2. Existing LP-No Override Allowed and Verify Existing LP will not allow consolidation.

  • You are allowed to consolidate different item only if the location is multi-item.

  • LP must exist in the putaway TO location. Putaway confirmation TO history uses the consolidated LP values.

  • The system cannot consolidate to a Parent LP (no nesting).

  • The system supports the option of override putaway location.

  • Item data is linked properly (Serial Numbers, Lot, and Inventory Attributes) to the consolidated LP.

 

 

Starting Work Notes...

  • You can relocate receipt containers with delayed locating when the following is true:

    • Start work in RF using user or system directed work initiation method.

    • Start work in RF assigning multiple work units:

      • - System directed mode and assign multiple work units on work profile

      - Receiving dock location allows work unit selection on system-directed work

    • Receipt container has been located using delayed locating to the receiving pre-locate location.

    • Work instruction for receipt putaway work has the receiving pre-locate location as the ‘to’ location.

      NOTE: Relocating is delayed until starting work for the P&D pick when the receiving dock has an outgoing P&D location.

  • You can configure your work profile to have the system print shipping container label(s) when you begin to execute work units via an hand help mobile device. Note that the system will only print shipping container labels that have the "Start WM Work" print procedure checked on the document type record. Also, this is only valid for work that was created from shipping containers.
