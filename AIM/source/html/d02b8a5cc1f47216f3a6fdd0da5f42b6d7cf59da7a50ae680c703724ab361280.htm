Pro Number

This procedure applies specifically to LTL (Less-than-Truckload) and truckload carriers. Use this configuration to define the Pro Number range that a carrier will use. The system will automatically assign a unique Pro Number to each shipment for the selected carrier. These numbers help carriers uniquely identify each shipment and appear on the Bill of Lading and Truck Manifest.

 

Note:

You can configure a warehouse alert to notify users when the Pro Number range is running low. This alert can create a history record and/or send an email notification when the remaining numbers fall below a predefined threshold, which is set in the Rating System Values configuration.

 

Add New Pro Number

  • Enter Pro number set name.

  • Use the Pro Number Range Fields to define the range of numbers included in this set. In the Pro Number From and Pro Number To fields, specify the start and end values for the range.

  • Next Pro Number - Enter the number that the system will assign next. This is typically the first number in the range..

  • Pro Number Length - Indicate the number of characters in the Pro Number, based on the maximum length in the defined range (excluding any prefix, suffix, or check digit).

    Example: For a range of 1–1000, the Pro Number length would be 4.

  • Pro Number Prefix - Identify the value that will be added to the beginning of all pro numbers for this carrier. This value is only applied if the carrier requires it. It can be an alpha-numeric value.

  • Pro Number Suffix- Identify the value that will be added to the end of all pro numbers for this carrier. This value is only applied if the carrier requires it. It can be an alpha-numeric value.

  • Check Digit Algorithm - Select the applicable check digit algorithm used by the carrier. If the desired algorithm isn’t available, a system consultant can add it in the Check Digits configuration.
