Allocation Rule Assignment

This record defines the sequence in which the system evaluates and assigns locating or allocating rules. Each entry specifies criteria and the corresponding rule to apply based on its priority. During processing, the system reviews these records in order of priority and assigns the first applicable rule. Once a receipt or shipment line is matched with a rule, it won’t be evaluated for any subsequent rules unless overriding is allowed.

 

General

 

Priority Field: Specify the order in which the system should assign this rule. A lower number indicates higher priority, meaning the system will apply the record earlier.

 

Allocating Rule (Outbound Processing): Specify the allocation rule that the system should use when processing an item. This rule governs how allocation locations are selected for picking.

 

During the allocation rule set assignment process, the system follows these steps:

  • The system identifies all shipment and receipt lines that don’t yet have an assigned locating or allocating rule.

  • It processes each active rule assignment record in order of priority.

  • If the criteria match, the corresponding rule is applied. If a rule has already been applied from a prior sequence, it will only be replaced if "Always Override" is enabled.

 

Criteria

 

Define the allocation rule assignment criteria associated with this priority setting. This criteria determines when the system should apply rule set assignment.

 

Select an existing rule assignment criteria record or create a new Allocation Rule Assignment criteria record.

 

Create new Allocation Rule Assignment Criteria record.

 

A rule assignment criteria record tells the system when to use a particular rule. For example, a criteria might specify: “Quantity less than 20 of Item A.” If a shipment or receipt meets this condition, the associated rule will be assigned.
