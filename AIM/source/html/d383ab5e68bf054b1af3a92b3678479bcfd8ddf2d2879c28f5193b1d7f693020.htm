Searching/Viewing Cycle Count Request Records...

You can use the Cycle Count Request Insight Screen to search for and view cycle count request records in your warehouse.

  1. Open the Cycle Count Request Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.



  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

  • The Cycle Count Request Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • There is a hyperlink in the Plan field to open the Cycle Count Plan Insight screen.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Cycle Count Request Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Cycle Count Request Insight contains Indicator Tiles with counts of the other entities (i.e. open work). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Open Work
    1. Displays the open cycle count work based on the work group cycle counting.
    2. Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse, internal count number, and internal number type.
    3. The internal number type is Cycle Count.


For more general information about the Detail Pane, see the topic Introduction to Insight Screens.



 

 

 

Screen Actions

The following actions are accessible from the List Pane:

 

 

Delete

The action allows you to delete one or more cycle count requests. The system will prompt for a confirmation message after the delete action is performed.

 

 

Confirm

This action allows you to confirm the cycle count request(s). Selecting the record (s) and invoking the action will show a confirmation message and success message is shown after the request is confirmed.

 

 

Reconcile

This action allows you to reconcile the cycle count request. The action is enabled for the cycle count requests which are in 'pending review' status or with 'open' status only if the cycle count request is created without work. Selecting the cycle count request and invoking the action opens the Cycle Count Reconcile screen. Refer to the topic Reconciling Cycle Counts (Insight Screen & RF) for additional information.
