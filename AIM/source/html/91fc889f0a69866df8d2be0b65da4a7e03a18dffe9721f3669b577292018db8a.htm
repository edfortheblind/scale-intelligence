Web Header URL Right Field

This field indicates the specific URL of the link that will be associated with the graphic that appears at the top-right of the Trading Partner Management Main Menu. The URL should be in this format:

 

LOCAL URL: \\YourServer\Directory1\Directory2\yourPage.htm

 

REMOTE URL: http::/www.manh.com

  • If you are associated with NO companies, the system will load this value from the Web System Values Window (for BOTH internal and external web users).

     
  • If you are associated with ONE company, the system will load this value from the Company Window (for BOTH internal and external web users).

     
  • If you are associated with MORE THAN ONE company, the system will load this value from the Company Window (for internal web users). External web users cannot be associated with multiple companies.
