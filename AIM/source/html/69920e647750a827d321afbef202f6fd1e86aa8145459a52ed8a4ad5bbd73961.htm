Creating a Routing Guide

A routing guide record associates a carrier or carrier group with a set of shipping requirements. When a shipment meets these requirements, the system will assign the associated carrier or carrier group.

Header Fields...

  1. The Routing ID Field represents a system-generated identifier.
     
  2. Use the Routing Name to provide a text ID for this routing guide record.

You will use the following tabs to define what shipments should be processed using a routing guide record. The more values that you provide, the more exact the shipment's values must be to qualify for processing using this routing guide.

 

 

Routing Criteria Tab...

This tab includes several different shipment-level values, which you can use as criteria on your routing guide. Note that there are no required values on this tab.

  • Use the Customer, Ship To, and Company Fields to link this record to a particular account. You can any combination of these fields. The Company Field is only available if you support multi-company processing.

     

  • Use the Routing Code Field to accommodate the specific needs of a customer, company or shipment. For example, suppose your customer, Toy Town, does not want smaller shipments transported by USPS. You could define the value 'No USPS' in this field. All Toy Town shipments interfaced with the value 'No USPS' in the routing field would be processed by this record (assuming that Ship To and Company field values match this record's values). Any value that you define in this field is valid.

     

  • Use the Container Class Field to identify the container class that this record applies to. If you do not include a value, the system will assume that this record will accept any container class.
     

  • Use the Max Num Containers at Class Field to identify the maximum number of containers a shipment can have at this specified class. If you do not include a value, the system will assume that this record has no container maximum. Please note that if you define a value in the container class field and the shipment contains both that class and other classes, the system will not select this record. All containers on the shipment must be of the class defined here.

     

  • Use the Priority Field to assign a priority to this record. It two or more records meet the shipment's criteria, the system will select a record based on priority. The lowest priority number will be selected. Priority is only used when two or more records share the same criteria and the system cannot select the 'best fit' record. For example, assume guide LMN shares the same container class as the shipment record. Guide OPQ has a blank container class. The system will always select LMN for this shipment, even if its priority value is higher than OPQ. The system would only consider priority if LMN and OPQ shared the same criteria values.
     

  • Use the Origin Information Fields to identify the warehouse shipping the product. If you want this record to apply to multiple warehouses, the values in the Postal Code Range Fields should encompass the warehouses that you want to include. If this record is only for one warehouse, put that warehouse's postal code in both range fields. If you do not provide an origin country, the system will apply this record to any shipments. You are not required to enter values in the Postal Code Range Fields. This accommodates routing guide records for countries that do not use zip codes.

     

  • Use the Destination Information Fields to accommodate all the destinations that this record will support. If you record is for only one destination, put that postal code in both range fields. If you do not provide a destination country, the system will apply this record to any shipments. You are not required to enter values in the Postal Code Range Fields. This accommodates routing guide records for countries that do not use zip codes.
     
  • Use the Shipment Weight Range to specify the shipment weights that this record will accommodate. If you do not include a value, the system will assume that this record has no weight maximum. Use the Weight UM Field to identify how weight should be measured for this record.
     
  • Use the Shipment Volume Range to specify the shipment volumes that this record will accommodate. If you do not include a value, the system will assume that this record has no volume maximum. Use the Volume UM Field to identify how volume should be measured for this record.

 

User Defined Shipment Criteria Tab...

  • This tab includes the user defined fields that appear on the shipment, which you can use as criteria on your routing guide. Note that there are no required values on this tab.

 

Routing Selection Tab...

  • You will use this tab to associate the routing guide with either a carrier or a carrier group. During routing, if this record best fits a shipment, the system will reference this tab. It will either assign the carrier (defined here) or select a carrier from the group (defined here). You must assign either a carrier or a carrier group to this record. If you define a carrier group, the system will assign the cheapest carrier in the group who can accommodate both the ship to address and the deliver by date.
