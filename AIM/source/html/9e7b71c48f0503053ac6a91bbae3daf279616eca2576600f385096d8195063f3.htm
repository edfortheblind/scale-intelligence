Work Created Field

This field indicates that work was created for a replenishment request.

 

There are four options:

  • I (Immediate). "Immediate" is set when the Replenishment Work Creation Method is set to "None". This indicates that the system has immediately moved the allocated inventory from the From location to the To location.

  • M (Manual). "Manual" is set when the Replenishment Work Creation Method on the Replenishment Master is set to "Manual". A replenishment request set to "Manual" can have work created from the Replenishment Insight Screen.

  • N (No). "No" indicates that the work has not been created when initially creating the replenishment request. This may be updated later once work creation has been run.

  • Y (Yes). "Yes" is set when work has been created automatically. The Replenishment Work Creation Method will be set to "Automatic" on the replenishment master. This work is generated in the wave or when manually initiated from the Inventory Insight Screen.
