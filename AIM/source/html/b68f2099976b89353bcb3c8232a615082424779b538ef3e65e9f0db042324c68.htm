Processing a Manifest

During the manifesting process, the system transmits container-specific information (such as its weight, carrier, and carrier service) to the Progistics third-party rating application. Progistics then contacts the carrier's server and manifests the container. It also retrieves the container's tracking number and its rate. Finally, Progistics transmits this information back to the system. The system displays this information (as a "manifest") on the Manifest Insight, and on the shipment line record. The Manifest Insight Screen can be used to research and perform actions on manifests.

Viewing the Containers on a Manifest...

In the Manifest Insight, you can view the containers that make up a manifest. The system will display basic container information, such as tracking number and container ID, in the record list. This is especially helpful if you need to quickly reference a container ID or tracking number.

  1. Open the Manifest Insight Screen, and access the appropriate manifest.

  2. Select the View Containers action. The Shipping Container Insight Screen will open and the system will display the containers associated with the selected manifest in the record list.

NOTE: You can search for manifested containers from the Shipping Container Insight Screen by turning on the "Include only manifested containers" toggle.

 

 

Removing a Container from a Manifest...

You can remove container(s) from the manifest before the manifest is closed. As long as the manifest is open, the customer will not be charged for the container. This is helpful if a shipment has already been closed, but a container needs to come off the manifest.

  1. Access the Shipping Container Insight screen, and access the appropriate container.

  2. Select the Remove From Manifest action. The system will delete the container from the manifest.

 

 

Closing a Manifest...

You can close a manifests using the Manifest Insight. Note that once you close a manifest, you cannot remove containers from it.

 

Close Manifest Batch Process

You can determine whether or not the system runs close manifest as a batch process by configuring the rating system value "Submit Close Manifest to Batch". Below are some notes about this batch process:

  • When a close manifest action is submitted to a batch process, the system sets the manifest to Closed. Turn the Include Closed Manifest toggle to On to view the closed manifests.

  • You cannot do any modifications to a manifest while it is processing.

  • If the system encounters an error during the close manifest process, the manifest's icon will change to red.

  • The system will not display to you any errors which are encountered during the batch process (they will instead be logged in process history). Note that the error messages logged in the history are retrieved from Progistics.
 
Procedures
  1. Access the Manifest Insight Screen, and select the manifest you want to close.

  2. Select Close form the Action menu. The system will display the Close Manifest screen:

    - To print a copy of the manifest, make sure that the Print the Manifest toggle is ON.

    - To print a UPS summary barcode label, make sure that the Print Summary Barcode Label toggle is ON. The system will then automatically print this label after the manifest is closed. Note that this check box will only appear if you are trying to close a UPS manifest.

    - To transmit this manifest electronically to the carrier, make sure the Transmit the Manifest toggle is ON. The system will transmit the manifest information to the carrier. Note that if this carrier does not support EDI transmissions, this check box will not be input capable and you will not be able to select it.

    Note on Ineligible Containers on the Manifest:
    If there are containers on the manifest that have not yet reached a status that is considered ready to ship, then the system will enable Ineligible containers options. For most carriers (such as UPS), you will be able to choose from three options when closing the manifest: move these containers to another manifest for today (if configured for multiple manifests), move these containers to the next shipping day's manifest, or to not move these containers off the manifest. For FedEx containers or containers using a web service, the system does not support moving ineligible containers off the manifest.

  3. Once the manifest is closed, it will be displayed in the Closed Summary field of the Manifest Insight Screen.
Note on Multiple Manifests Per Day

Usually, one manifest is closed per day, per carrier. If you have configured to allow multiple manifests closed daily, then the system will identify each manifest by assigning it a number. For example, the second manifest that is closed will be assigned a "#2", the third manifest that is closed will be assigned a"#3", etc.

 

 

 

 

Printing a Container Manifest...

You can print this document when you close a manifest, or you can print it later. The procedures below describe how to print a manifest for a closed container. Container manifests are generated in Progistics CS and routed to printers through the system. You can define this document's printer on the Document Routing Window. Note that the term "container manifest" is a SCALE term. Carriers may refer to these documents as "parcel manifests" or "summary manifests."

  1. Access the Manifest Insight, and use the treeview to drill down to the manifest level of the Closed Node.

  2. Right click on the manifest you want to print the Container Manifest for and select Print. Progistics will generate and print the document.
