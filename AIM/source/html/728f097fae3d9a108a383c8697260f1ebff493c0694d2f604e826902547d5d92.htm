Warehouse Mobile - Image Capture

Warehouse Mobile - Image capture feature enables warehouse workers to capture visual images quickly and easily. Using hand held devices with a camera, workers can capture picture of returned or damaged products during Warehouse mobile receipt check in, so that the system can have a visual record of the state of the product at the time of receipt in the warehouse.

 

Note:

  • The image capture feature is available only for Warehouse Mobile - Receiving flow.

  • In case users want to have this feature in other flows of Warehouse Mobile, read Warehouse Mobile - Image Capture extensibility topic in Developer Hub.

Image Capture Process

 

The following is the process to capture images using the Warehouse Mobile in a device.

Note: Image capture is available only on the device and will not be displayed in the browser application.

 

1. Capture Image using the device camera

  • Navigate to Warehouse Mobile >>Receiving >> Select Receiving Preference to start the receiving check in flow.

  • Tap the camera (icon) on any of the screens during the receiving flow and take a picture. The device will prompt the user to take a picture.

  • After an image is taken, tap OK and the device will prompt to save the image. Optionally, users can retake the image using the Retry option.

Note: The user interface elements such as capture, save, retry, and cancel buttons vary across different devices and versions of Android.

 

2. Save the Image

  • In the Save Image screen, you need to select the reference type (receipt ID or license plate) and enter the corresponding reference ID. For example, Receipt ID is selected as reference type, then enter the receipt ID in the reference ID text box.

  • Notes text box is used to enter relevant description to the image captured.

  • Tap GO to save the image in JPEG format in the application storage location.

Note on Reference Type listed for selection in the Save Image screen.

  • The reference type and reference id will be defaulted when it is available.

  • If the reference type is not available, then the reference type is not selected and the reference id is blank.

  • If the receipt ID is available and license plate is not available, then receipt id is selected as the reference type.

  • If the receipt ID is available and license plate is available, then license plate is selected as the reference type.

3. Image Data Processing

  • The images will be saved using the reference id and date time stamp (<reference id>_<date time>.jpeg) as the file name.

    For example. RCV_001_24-04-15-10-30.jpeg.

  • Images will be stored based on the configuration in Path for storing captured images technical values.

    • On -Premise - Windows shared folder

    • Active - Cloud Storage

  • If multiple users capture image for the same reference ID at the same time, then it is stored in incrementally sequential numbers.

    For example

    • RCV_001_24-04-15-10-30(1).jpeg

    • RCV_001_24-04-15-10-30(2).jpeg

4. Document Management Insight

  • The system will save image with internal reference number based on the reference category, reference type, and reference id selected. This internal reference number is saved in the Document Management table.

  • Document Management Insight screen enables user to retrieve and view the image records based on search criteria of reference category, reference type, and reference id. Users can also search with other attributes such as File name, Company, Warehouse and Date time stamp. For more information read Document Management Insight screen.

5. Configure Reference Types

  • You can extend the reference types listed for selection in the Save Imagescreen, using the Generic Config Header - Image Capture Reference Types configuration. . By default the system has Receipt ID , and License Plate as reference type for the Receiving flow.
