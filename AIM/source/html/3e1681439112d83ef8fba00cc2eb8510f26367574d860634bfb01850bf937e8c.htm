Packing/Shipping Process Summary

** Functionality **

Process Flows

 

 

 

Summary...

SCALE outbound processing includes two major components: packing and shipping. The packing process allows you to associate shipment lines with containers, perform item validation, and generate packing labels. The shipping process allows you to manage packed shipments when they arrive at the shipping dock, are load confirmed, and then finally shipped out of the warehouse.

The following are key features of the packing/shipping functional areas:

 

 

Bypassing Container Packing...

Bypassing the packing process allows you to ship containers without identifying the contents in them. You will bypass packing by creating the container "on the fly" on the Close Container Screen and immediately closing it. You only need to identify its shipment ID and weight. Bypassing containers is only available if the Create Containers at Closing Checkbox on the Packing Preference Window is selected. In addition, if your wave flow contains the container creation wave step, this allows you to assign containers to product during a wave, and therefore also completely bypassing the packing process.

 

 

 

Nesting Containers...

Nesting allows you to pack one container into another. When you nest a container, the system associates its contents with the "parent" container that you are nesting into. This allows you to track all shipped items, based on container ID. When you build pallets, you will nest the containers into the pallet.

 

 

 

Closing Containers...

You can close a container on the Close Container Screen or from an RF device. When you close a container in SCALE, you cannot pack additional items in it. You will provide such information as the weight of the container, and the type of container that you packed the product into. Also, you can have the system can automatically manifest during the close container process, if it is configured on your packing preferences record. Also, when you close a container, you can identify it as belonging to a group of containers. When you group containers together, the system generates one shipment packing list for them. It can also include the container values (container X of Y) on vendor compliance labels. Generally, you want to group containers together to meet a customer's needs. This grouping does not impact carrier rating or routing. All grouped containers must be on the same shipment.

 

 

 

Load Building During a Wave...

During a wave (which includes the load building wave step), the system can assign shipments to appropriate shipping loads. For more details, see the Load Building section of Defining Wave Flows.

 

 

 

Value-Added Services (VAS)...

Value Added Services (also know as VAS) is a term used for any process that “adds value” to the product being shipped, such as putting shirts on hangers, affixing price tags on items, or placing catalogs into the container. In other words, you are adding something additional to the base item as picked. The system features an insight screen where a user can confirm that VAS activities have been completed and continue on its way to the dock door. Users can use several criteria to search for and view the activities that are associated with containers.
