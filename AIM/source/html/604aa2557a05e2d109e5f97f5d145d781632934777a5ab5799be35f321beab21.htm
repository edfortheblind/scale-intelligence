Performing Address Validation on a Shipment

The address validation functionality offers users the opportunity to verify that a package has a customer's correct ship to address. When you perform a search, the system will communicate with Progistics to retrieve a list of potential matches for the ship to address currently on the shipment. You can then either choose one of these new addresses and apply it to the shipment; or, cancel out of the window to keep the header's existing ship to address. SCALE uses a web service to retrieve address values from Progistics and display them on the Address Validation Window.

Procedures...

  1. Select a shipment and choose the Address Validation Selection action. The system will display:

    - The Address Validation screen, if the ship to address is not valid, but Progistics found some potential candidates. Proceed to step 2 below.

    - A message indicating that the ship to address is not valid, and Progistics did not find any potential candidates.

    - A message indicating that the ship to address on the shipment is valid match.
     
  2. On the Address Validation screen, the system will display the ship to address that is currently on the shipment. Also, the system will display the potential address matches (retrieved from Progistics) in the results list. The maximum number of address matches that can be retrieved from Progistics is 30.

    NOTE: Progistics requires the following fields to be defined on the shipment in order to return potential address matches: Address 1, City, State, Postal Code, and Country.
     
  3. To assign a new address value to the header, select one of the address values and press OK.

    To exit this window without assigning a new address, press the Cancel button.
