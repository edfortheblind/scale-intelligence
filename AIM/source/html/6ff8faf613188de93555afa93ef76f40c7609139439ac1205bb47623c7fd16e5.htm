Using Inventory Attributes (RF)

You can capture and/or edit inventory attributes from a location inventory record using several RF screens. When an attribute is changed, the system will update the location inventory record. If you want to read more general functional information about inventory attributes (including specifically where they are supported in SCALE), please see the topic Inventory Attributes - Introduction.

RF Screen and the Relationship to Inventory Attributes Records...

Whether or not the system can display inventory attributes for certain location inventory is based on an RF screen’s relationship with the underlying data displayed on the screen. Below are explanations of these two types of data relationships.

  • One-To-One (attributes viewable): In this relationship there is a single record representing the data displayed on the RF screen. For example, suppose you have a pick for a work unit with a single work instruction. All the data displayed on the RF Pick Confirmation screen would be drawn from the data found on that work instruction. Therefore, the system can access the attributes from the inventory and display them on the RF screen.

  • Many-To-One (attributes not viewable): In this relationship, there are multiple records representing the data displayed on a single RF screen. For example, suppose you have a batch pick with the "Group Picks by Loc/LP" setting enabled on the user’s Work Profile. This work unit will have multiple work instructions for the same item at the same location for multiple orders. Therefore, the system cannot access the attributes from the inventory, and willnot display them on the RF screen.

 

 

 

General RF Screen Procedures...

The procedures below outline how you would use the Inventory Attributes RF screen, no matter where you access from in the system. You can use these procedures to capture, edit, or delete attribute values.

  1. Press the Attributes button from an RF processing screen.

  2. The system will open the first page of the Inventory Attributes screen, which displays the first five attribute values. Note that the system will display only five attributes fields per RF screen.

  3. Provide a value for the attribute field(s) that you want to capture/edit. Note that some screens only support the viewing of attribute values.

  4. Now select one of the action buttons:

    - Prev: The system will take you back to the previous page of attribute values. Note that this button will be inactive when you are viewing the first attributes page.

    - Next: The system will take you forward to the next page of attribute values. Note that this button will be inactive when you are viewing the last attributes page.

    - Save: The system will save the attribute value(s) that you have captured/edited (on screens where these actions are supported). Note that you only need to press this button once, even if you have added/edited values on multiple attribute pages, since the system saves all 20 attribute values at one time. Also, attribute value additions/changes cannot be saved in locations where allocated/in transit/suspense quantities exist for that inventory. In addition, you need the Edit security touchpoint enabled for the Save button to be available.

    - Cancel: The system will close the Inventory Attributes screen, without saving any value(s), and return you to the previous processing screen.

 

 

 

RF Screen Security...

Below are descriptions of the security touchpoints that are associated with the RF Inventory Attributes screen.

  • Run: Determines if the Attributes button is enabled/disabled on an RF processing screen.

  • Edit: Determines if the RF Inventory Attributes screen is in edit mode (applies only to the RF Check In and RF Location Inquiry screens).

 

 

 

Capturing Attributes - RF Receiving Check In...

You can capture attributes for inventory coming into your warehouse using the RF receiving check-in process. The system includes two receiving workflows (that includes the RF inventory attributes screen) that are based on the header-item initiation method. You can implement these workflows into your receiving process, or you can create custom inventory attributes workflows based on them. Note that you will have to manually create records in the RF Receiving Check In Initiation configuration in order to use these attribute workflows.

 

The two inventory attribute workflows that are included with the system are the following:

  • Header-Item Inv Attrib

  • Inv Attrib Flow GS1

 

Functional Notes
  • The RF check in process will prompt the user to capture inventory attributes after a license plate has been assigned.

  • If you do not capture any attributes when prompted, the system will check in and locate the receipt container without attributes.

  • When using the RF Inventory Attributes screen in capture mode, the system will not filter the attributes based on the "RF Inventory Attributes – Filter" exit point.

  • See the General Screen Procedures section for more specific information on how to use the attributes screen.

  • You can create your own pre-defined inventory attribute values that the user can select from on the RF Check In screen. See Creating Inventory Attribute Values for more details.

 

 

 

Editing Attributes - RF Location Inquiry...

You can edit attributes for inventory that resides in warehouse locations using the RF Location Inquiry screen. Note that attributes are visible from this screen since it displays inventory that has a one-to-one relationship with inventory attributes.

 

 

Functional Notes
  • The system requires that you save at least one attribute field value (you cannot save zero attribute values).

  • You can create your own pre-defined inventory attribute values that the user can select from on the RF Location Inquiry screen. See Creating Inventory Attribute Values for more details.

 

 

 

Viewing Attributes - RF Inventory Management...

You can view attributes for inventory that resides in warehouse locations using the RF Inventory Management screen (when it is accessed from the RF Location Inquiry results screen, and initiated by item/location). The attributes are visible from this screen since it displays inventory that has a one-to-one relationship with inventory attributes.

 

 

Functional Notes
  • On the RF Inventory Management screen, the Attributes button is visible for all adjustment types.

  • On the RF Inventory Management screen, the Attributes button is not visible when inventory management is initiated by license plate.

  • On the RF Inventory Management screen, the Attributes button is not active if the location inventory is not linked to inventory attributes.

  • On the RF Inventory Management screen, the Attributes button is not visible when you access RF Inventory Management directly from the RF Main Menu.

  • When you access RF Inventory Management directly from the RF Main Menu, and perform a positive/negative adjustment, the system will adjust inventory at the location without inventory attributes.

  • On the RF Inventory Management screen, when transferring inventory or changing inventory statuses, the system will notify you that the inventory does not exist if the system has one or more location inventory records linked to inventory attributes.

 

 

 

Viewing Attributes - RF Cycle Counting...

You can view attributes for inventory when performing an RF cycle count, or performing an RF cycle count reconcile.

 

 

Functional Notes
  • On the RF Cycle Count Work Execution screen, the Attributes button is visible when the cycle count work instruction is linked to inventory attributes. It is not active when the work is not linked to attributes.

  • On the RF Cycle Count Work Execution screen, the Attributes button is not visible when the cycle count page represents multiple cycle count work instructions.

  • On the RF Cycle Count Reconcile screen, the Attributes button is enabled when the cycle count request is linked to inventory attributes. It is not active when the request is not linked to attributes.

 

 

 

Viewing Attributes - RF Pick and Putaway Work Confirmation...

You can view attributes for inventory when performing RF picking or putaway work confirmation.

 

 

Functional Notes
  • On the RF Pick and Putaway Work Confirmation screens, the Attributes button is visible when the work instruction (shipment/receiving/inventory management/replenishment) is linked to inventory attributes. The system uses the From Inventory Attribute field on the work instruction to determine whether to display the Attributes button on these screens.

  • On the RF Pick Work Confirmation screen, the Attributes button is not visible when the "Group Picks by Loc/LP" setting is enabled on your work profile, since this scenario has a many-to-one relationship between the work instructions and the screen.

  • On the RF Putaway Work Confirmation screen, the Attributes button is not visible when work instructions are grouped during RF Putaway, since this scenario has a many-to-one relationship between the work instructions and the screen.

  • On the RF Pick and Putaway Work Confirmation screens, the Attributes button is not visible when work units are “grouped by inventory attributes” in group user mode on your work profile, since this scenario has a many-to-one relationship between the work instructions and the screen.

 

 

 

Filtering the Attributes Displayed on the RF Inventory Attributes Screen...

You can configure how the system displays the inventory attributes fields on the RF Inventory Attributes screen. This is done by enabling the "RF Inventory Attributes - Filter" exit point. The system would then display the appropriate attribute fields on the RF Inventory Attributes screen. If you need more technical information on this exit point, please see the exit point section of the SCALE SDK.

 

Functional Notes
  • Note that if the inventory attributes page shows all 20 attributes, the system will disable this filter.

  • This filter is honored when the RF Inventory Attributes screen is accessed from the following screens: RF Location Inquiry, RF Inventory Management, RF Cycle Count, and RF Pick and Putaway.

Verifying Inventory Attributes on the RF Inventory Attributes Screen...

You can configure the system to make the user verify inventory attributes during the RF Pick and Putaway Confirmation actions. This is done by enabling the "RF Inventory Attributes - Verify" exit point. This exit point functions for the following type of work execution: shipment, receiving, inventory management, and replenishment. Then, during RF work execution, the system will automatically display the RF Inventory Attributes screen (in verify mode) when you press OK on the confirmation screens, IF the attribute values have not been successfully verified. The system will prompt for verification one attribute value at a time. After you have verified an attribute value, the system hides it and displays the verification field for the next attribute value. The system will display an error if the verification value does not meet the attribute value, or if the verification value is left blank. Finally, after you have successfully verified all of the attribute value(s), the system will then permit the pick/putaway confirmation.

 

Functional Notes
  • Note that you will need "Run" security access for the RF Inventory Attributes page to have the ability to verify attributes (the system is shipped giving all users security access to this action).

Example:

  1. Suppose that you want the user to verify the inventory attributes after a pick or putaway is performed. Also, in the example below, suppose the "filter" exit point (explained earlier in this topic) is enabled as well.

  2. Then suppose you have the "verify" exit point enabled.

  3. The system then displays the RF Inventory Attributes screen, with a verify field under the first attributes edit box. You would enter the first validation value, and press the TAB button. The system then will validate that value, and if it is correct, display the verify field for the next attribute. If it is not the correct value, the system will display an error message, and you will have to enter the correct value.
