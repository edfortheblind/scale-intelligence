Before You Begin: Web Statistics Setup Prerequisites

You must address the following items in order for the system to correctly generate web statistics. If you have any further questions about these prerequisites, see your Manhattan consultant:

 

 

Inbound Statistics...

- Based on container status >= 900

- Company present on the detail

- Transaction history created for locating

- Date based on receipt container's date time stamp

 

 

Outbound Statistics...

- Must perform picking work

- Detail status > 800

- Company present on the detail

- Transaction history created for load confirmation

- System goes off of the load confirmation activity date time stamp.

 

 

Item Statistics...

- System gets all item, company, and inventory status records

- Updates based on inbound and outbound statistics

- System takes current inventory snapshot (If you re-generate the statistics on a different day, the current inventory records will be updated)
