Storage Connection String

When SCALE is installed within an Azure IaaS Virtual Machine, Azure File Storage can be used to automatically provide high availability for files that are heavily used by the application (such as interface files, wave labels, and so on). This field stores the connection string for storing this information in Azure.

 

An example of this connection string is:

DefaultEndpointsProtocol=https;AccountName=sgfsnode;AccountKey=g/B4/tPsHxRDiwi6/yKodpCIsf42uqn82IR0Vn24e9snFJt//QG1CYiFI1rCm7s3DyP1OO+KzKad99MtgC/L8g==;BlobEndpoint=https://sgfsnode.blob.core.windows.net/;TableEndpoint=https://sgfsnode.table.core.windows.net/;QueueEndpoint=https://sgfsnode.queue.core.windows.net/;FileEndpoint=https://sgfsnode.file.core.windows.net/

 

You will need to get this value from the storage account created in the Azure Portal.
