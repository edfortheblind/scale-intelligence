Creating a Putaway Location Group

A putaway location group allows a series of received items to be putaway as one group. The settings that define these groups are included in this configuration. Once you create one putaway group (using either a location range or a locating zone), then all groups will have to be created using either ranges or zones, whichever one you chose for the first group. When the system is performing locating, it locates to a location associated with a Putaway Group that includes the destination location selected during locating. It associates the receipt container to the existing Putaway Group. If there is not an existing Putaway Group for the destination location, the system will either create a new Putaway Group with the System ID or the user will assign a Putaway Group ID. The system will then update the Parent License Plate on the receiving dock inventory for this license plate with the Putaway Group ID. When work is executed, the pick is for the entire putaway group. One use of these groups is if you want all returned items to be placed on a certain area of the receiving dock, destined to be putaway either back into their original inventory locations, or to a special returns "repair" area.

Procedures...

 

Using the General Tab

Access the Putaway Location Group Window. Create a new record and name it.

  1. Use the Warehouse Field to indicate the warehouse where your putaway group will reside.

  2. Use the Location Range Field to identify the series of locations where product can be putaway as part of your location group.

  3. Use the Locating Zone Field to identify the zone of locations where product can be putaway as part of your location group.

  4. Use the Group Assignment Method Field to indicate if you want, upon creation, a putaway location's Group ID to be manually assigned by the user, or automatically assigned by the system.

  5. Use the Maximum Units Field to identify the most number of returned items that can be included in a particular putaway group. If the maximum units number is reached, then the system will close the group, and create a new group based on the previous group's settings.

  6. Use the One Per User Checkbox to indicate that, if there are multiple users processing returns, the system will assign each user's item(s) to separate putaway groups. This will ensure that no two users will assign items to the same putaway group.

  7. Use the Verify Group ID Checkbox to indicate that the system will require you to enter the existing putaway group ID during the check in process.

 

Using the Quantity UM List Tab
  1. Use the Quantity UM Field to indicate the eligible unit of measure(s) required for returned items to be a part of this putaway group.
