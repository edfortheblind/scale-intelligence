Reviewing Country Names

The system uses complete-word descriptions to represent the names of countries. You may create a new country name in the Country Window. These names will appear in country fields throughout the system. Note that the system is shipped with the most common default values which should meet your business needs. However, only certain country values (typically United States, Canada, and Mexico) will be shipped as "activated" records. Therefore, you can view only these values in country fields throughout the system. The other countries defined in the Country Window are shipped as "inactivated" records, so you will have to manually activate these countries in order for them to appear in the country fields.

Using the Header Fields

 

Access the Country Window. Create a new record.

  1. Use the Identifier and Description Fields to define the name of the country. The system will use the value you enter in the Description Field in country pull-down menus throughout the system. Note that if you have customers that have country codes that differ from the IATA standard used by the system. In this case, you will need to create new country name(s) and inactivate the unused country. For example, if you have a customer in Mexico that uses the abbreviation MEX (rather than the IATA standard MX), then you will need to create a new Mexico country record with the abbreviation MX.

 

Using the System Defined Values Tab
  1. Use the External Rating Symbol Field to identify the value (which corresponds to the Dimension UM) that is sent by SCALE to the transportation engine, either FSMS or Progistics. Valid values for this field are "I" (for inches) and "C" (for centimeters).
     
  2. Use the FedEx Rating Symbol Field to indicate the symbol that is used to identify a container to the FedEx rating software. FedEx will use this value during rating to help calculate the appropriate rates for containers associated with this container type.

  3. Use the Suppress State In Rating Field to indicate if you want the system to ignore the requirement of providing a state code when performing a manifesting request. This is necessary because some international destinations do not require a state code, but the application typically requires this information when you define a customer/ship to address.
     
  4. Use the Suppress Postal Code In Rating Field to indicate if you want the system to ignore the requirement of providing a postal code when performing a manifesting request. This is necessary because some international destinations do not require a postal code, but the application typically requires this information when you define a customer/ship to address.

  5. The Country Rating Symbol Field indicates the appropriate two-letter identifier for a country. You would need to enter a value in this field if you want a different country identifier during rating.

    • If there is a value in this field, then external rating systems will use this value as the country code when manifesting.

    • If this field is blank, then external rating systems will use the Country Window's identifier as the country code when manifesting.
