Performing RF Yard Management

After a truck trailer has been checked into one of your warehouse's yard locations, you will eventually need to move the trailer to another yard location or to the Receiving Dock. You will use the RF device to perform this action.

Procedures: RF Yard Management...

Log on to your RF Device and select the Yard Management function. The system will display the yard management pick screen.

  1. Use the Trailer ID Field to identify the trailer that you want to move.

  2. Press OK. The system will display the yard management pick screen.

  3. Use the Trailer ID and From Location fields to view which trailer you want to move and where it is currently located. These fields will be defaulted values by the system.

  4. Press OK. The system will display the yard management putaway screen.

  5. Enter the To Location where you are going to move the trailer to. Typically, you would enter another yard location or the Receiving Dock in this field. The system will populate this field with a value if a Destination Yard Location was identified at the time of yard check in.

  6. Press OK. The system will assign the new yard location to this trailer.

    Bypass Button: If the to location is a yard location, and there is a destination dock specified for this trailer (from the Yard Check In/Out Window), you can choose to skip moving the trailer to the yard location and send it directly to the Receiving Dock. This action is only available if a trailer is not currently present at the dock, and one is not already scheduled.
