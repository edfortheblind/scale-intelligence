Negative Price Tolerance Field

This field determines the amount below the total net price value that the system thinks is present in a location, where the system will allow you to successfully perform cycle count work. If the total net price for an item/location exceeds this defined value, the system will place the "overage" quantity into suspense (thus not committed immediately so a supervisor can review this transaction). In this case, the system will close the cycle count work, and the cycle count request will be placed in a "review pending" status.

 

For example, suppose the value in this field is 50.00, and you are presented with a cycle count request that indicates that there should be 400.00 dollars worth of an item in a particular location. When you count the units in the location, however, there is actually 200.00 dollars of the item present in the location. The system then will compare this number to the defined negative tolerance value. If the total net price falls within this tolerance, then the system will allow you to complete the cycle count and adjust the "overage" into the location. In this example, though, the item quantity in this location is 150.00 dollars over the defined tolerance. Therefore, the system will put this cycle count request in a pending review status, and the entire quantity (200.00 dollars worth) will be placed into suspense.

 

Note that if you define a zero value in this field, the system will not consider net price for tolerance.
