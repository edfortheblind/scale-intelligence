Using the Consolidated Container Location Viewer

You can use this viewer to find the deconsolidated shipments for an ERP order and the locations of the shipping containers for those orders on the shipping dock. The viewer groups the search results by ERP order. Under this grouping the ERP orders will have a header row for each unique order and shipment combination found for the ERP order. Each header row has details underneath showing the location on the shipping dock of the shipping containers for the order.

Searching for ERP Order Records

 

  1. Access the Consolidated Container Location Viewer.

  2. Use the fields on the Criteria Tab to enter the value(s) that you want to use to find the ERP orders to deconsolidate and the locations of the shipping containers on the shipping dock.

     

  3. Press Search. The system will display the results on the Results Tab.

 

 

Deconsolidating an ERP Order from a Shipment

 

  1. Access the Consolidated Container Location Viewer.

  2. Perform a search for the ERP order records. Refer to the Searching for ERP Order Records topic (illustrated above).

     

  3. Right-click on one or more ERP order “header” records and select the Deconsolidate action. The system will request confirmation on whether you want to continue with deconsolidating the ERP orders from the shipment.

    1. If you click OK to continue, it will submit the ERP order for the shipment to deconsolidation. A message will be displayed indicating that the ERP order has been successfully submitted for deconsolidation.

    2. If you click Cancel, it will navigate back to the selected record.

    NOTE: The system will deconsolidate the selected order’s shipment lines from the original shipment and transfer to a new shipment.
