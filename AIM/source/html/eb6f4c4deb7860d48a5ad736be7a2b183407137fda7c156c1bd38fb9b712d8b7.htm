Add Comments Field

This field is displayed on the Comment Text Window, which is accessible from the Shipment or Shipment Line Screen. You can use this window to define comments and associate them with a comment type. This comment type is linked to a document type. When paperwork with this document type is created for the shipment, the comments you created here are displayed on the paperwork.

 

 

NOTE: Most comments are interfaced from the ERP to the system. When you create them on this window, the system will only apply them to this specific shipment. It will not save the comments and apply them to future shipments.
