Creating Shipping Interface Upload Criteria Records

You will use shipping interface upload criteria records to determine the following:

  • Which shipment/shipment line upload records that the system will place in the upload directory defined on the interface process detail.

  • Which shipments the system will write header/detail upload records when a certain trailing status is met and that status is defined to include in the interface upload.
 
Notes
  • These criteria records apply to the shipping upload interface only.

  • The system will upload the shipment data using these records only as the shipment's status changes from one value to the next. The upload will not happen on the initial download of the shipment (regardless of whether that status has been configured for upload).
