Using Warehouse Mobile - Close Container

The Warehouse Mobile close container enables workers with hand held device to easily close containers on the shipping dock and quickly get them ready to be shipped from the warehouse. The close container process involves advancing a container’s status, as well as optionally (based on your packing preference settings) auto manifesting, auto printing, and assigning the container's shipment to a load. Basically, a closed container indicates that the packing process is complete. Also, a document/label will be printed upon closing the last container when the Close Last Container print procedure has been selected on the paperwork’s document type.

Close Container screen

Enables user to close containers on the shipping dock in the warehouse.

 

Closing a container with the calculated weight

Follow the steps to close a container based on the weight calculated by the system.

  1. Tap Close Container to view Close Container screen.
  2. Enter or scan the Container ID.
  3. In close container screen, the Container ID, System Weight and Actual Weight information is populated.
  4. Tap Go. to view the confirmation message as Container is Closed. No need to enter the actual weight value in this senario.
Closing a container by entering the actual weight

Follow the steps to close a container based on the weight calculated by the system.

  1. Tap Close Container to view Close Container screen.
  2. Enter or scan the Container ID.
  3. In close container screen, the Container ID, System Weight and Actual Weight information is populated.
  4. You can enter the Actual Weight in the text box. On entering the Actual Weight value is displayed in Close Container screen.
  5. Tap Go. to view the confirmation message as Container is Closed.

Notes:

  • Entering a valid container ID system will retrieve the appropriate weight value and display it on the screen as System and Actual Weight values. In case the actual weight is different, enter the same in the Actual Weight text box
  • Total weight for shipping is calculated as Weight of container type + Weight of Items in container.
  • When you close the container, system will validate as to whether the container's weight is within the defined tolerance.
  • If the weight is exceeding the tolerance limit, then it prompts the user to confirm the value to close the container.
