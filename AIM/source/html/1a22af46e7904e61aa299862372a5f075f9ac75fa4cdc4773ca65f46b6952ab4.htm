Defining Locating Rules

A locating rule identifies the rule details the system will use to locate product. A rule detail determines which location the system will assign product to. Generally a locating rule includes multiple details, which the system processes in numerical order (10, 20, 30, etc.).

 

Note on Locating Non-Inventory Items

Since non-inventory tracked items must be associated with a permanent location, the system will always attempt to locate the item to permanent locations only.

Procedures...

Before you identify a rule's details, access the Locating Rule Window. Name this record and provide peripheral information (description, etc). Select the Apply Button. The system will add the header record. Right-click and select the New action. The system will open the Location Rule Detail Window.

  1. Use the Locating Name Field to default rule set's name.

  2. Use the Delayed Locating Checkbox (along with the Create Work Putaway checkbox on receiving preferences) to indicate whether this locating rule will temporarily locate the receipt container to the receiving pre-locate location. If either checkbox is unchecked, then the system locates based on the receipt container’s locating rule details.

    3.  

  3. Use the Sequence Field to indicate what order you want the system to process this rule detail. The lower the sequence number, the sooner its processed. You cannot use the same sequence number for multiple detail records.

     

  4. Use the Locating Strategy Field to assign a strategy to this detail. You must assign a strategy to a rule detail. A sequence record can also include a location selection value. A locating strategy defines the system's methodology for selecting a storage location for checked in product. For example, if you select the strategy Consolidate, the system will attempt to locate product to locations that already contain it. Review descriptions of each locating strategy on the Locating Strategy Field.

     

  5. Use the Location Selection Field to assign a location selection to this detail. This is not required. A location selection record works with the strategy to help narrow the locations considered for locating. This minimizes processing time and increases your control over locating activity. The location selection can also have a sort defined, which the system will use to organize the locations selected for possible locating activity.

     

  6. Use the Split Quantity? Checkbox to indicate if you want to completely fill a location and split off any remaining item quantity to be located in a different location (using the locating rules).

    NOTE: The system cannot split a container that has serial numbers tied to it.

     

    • If this checkbox is checked, the system will try to meet the requirements of the first locating rule. If it cannot, then the system will split off the remaining quantity and create a new receipt container, using the same values (such as unit of measure, dimensions, etc). The system will then try to locate the remaining quantity using the second locating rule. This will continue until all the product is located, or locating fails because all of the existing locating rules cannot be met.

       

    • If this checkbox is not checked, the system will try to meet the requirements of the locating rule(s). If it cannot, then locating will fail.

     

  7. Press OK. The system will navigate back to the Locating Rule Window. The new rule will be displayed in the data grid. To define additional sequence values, select the New Action. Press OK again to save the complete rule record.
