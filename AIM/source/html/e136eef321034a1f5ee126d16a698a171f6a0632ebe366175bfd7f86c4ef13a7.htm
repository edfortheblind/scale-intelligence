Shipment BOM Action Field

You can choose one of the following options for this field:

  • If you choose the "Create Work Order for Rejected Quantity" option, the system will create a work order based on what was rejected on that line (when allocation is rejected & the "Work Order Creation" wave step is in your wave flow). The system will create a single work order for the total rejected quantity (for that item/company) in the entire wave. For example, if you had 10 shipments each rejecting 5 of an item, the system then would create one work order for 50. This option would be typically used for items which have a build process that needs to occur before the shipping process. The finished item, then, ships assembled.
     
  • If you choose the "Add BOM Components as Shipment Details" option, the system (for each of the BOM components, per item/company combination), will create a shipment line for each component item on the same shipment. In order for the system to do this, you must have the "Add BOM Components" wave step present in your wave flow. This option would be typically used when a finished item (such as a table) is ordered, and you want its children item components (the table top and the legs) broken out as separate shipment lines. Note that this option does not use the work order functionality.

    Suppose in the following example, you have a finished item (a kitchen table), of which the table top and the legs are both separate components.  The original shipment would have a line item for the table:

    1.000  Item 001 TABLE                    Quantity 10

    After the "Add BOM Components" wave step has run, the components would be added as shipment lines (with line numbers incremented by .001):

    1.000  Item 001    TABLE                 Quantity 10
    1.001  Item 001.1 TABLE TOP          Quantity 10
    1.002  Item 001.2 TABLE LEG          Quantity 40

    The system would first try to allocate the parent (for example, if you had some pre-assembled tables for shipment available) and if it could not do that, the system would then try to allocate the children. When it allocates the parent, it sets the status of the corresponding quantity on the child lines to indicate that the parent is allocated. When it allocates the children, it sets the corresponding quantity on the parent line to indicate that the children are allocated.

Note: Only one level of BOM in a shipment line will be created. When we have the shipment line as BOM inside which we have another BOM component, then the system will not process further to its component.
