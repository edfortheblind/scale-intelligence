Using the Intraday Labor Progress

The Intraday Labor Progress screen lets supervisors monitor intraday execution in real time by comparing tasked work with completed work, reviewing remaining units and hours, and understanding when work is expected to finish so they can take same-day actions.

Purpose and key notes

 

Intraday Labor Progress is for the current warehouse day only. It compares today's tasked work with today's completed work for each activity card and shows the current Full-Time Equivalent (FTE), Expected Time to Complete, and Ahead/Behind status.

  • Use unique Work Types for each Functional Area so the screen can report and display activity correctly.
  • The values shown on the screen are anchored to the Last Updated time, which is the timestamp of the last successful Consolidate labor data job.
  • Target End Time is the scheduled end time of the last shift configured for the warehouse for that warehouse day.
  • At this stage, the examples and descriptions below focus on outbound work.

Open and view the Intraday Labor Progress screen

 

Use the filter pane to enter the primary search criteria and then select Apply Filter.

  • Warehouse - The facility you want to monitor.
  • Work Group - The logical work grouping, such as Shipping
  • Activity Type - The activity or functional area you want to review.

The results are displayed as activity cards, not as a grid.

 

Screen overview and sort options

 

The top area of the screen gives the supervisor the context needed to interpret the activity cards.

  • Warehouse Day / Date - The current warehouse day being monitored.
  • Completed / Tasked legend - The color legend used in the units and hours bars.
  • Target End Time - The end time of the last configured shift for that warehouse day.
  • Last Updated - The timestamp of the last successful Consolidate labor data job used by the screen calculations.

The sort controls are used to sort the activity cards in ascending or descending order by one of these fields: Activity Type, Expected Time to Complete, FTE, Tasked Units, Tasked Hours, or % Complete.

 

Activity cards

 

Each card represents a single activity/work type for the current warehouse day.

  • Activity name - The activity being monitored, such as Shipping Work or Dock Management Work.
  • FTE - The number of distinct users currently active in that activity. A user is counted as active only when the gap between their latest transaction and the Last Updated time is within the configured Heel-to-Toe tolerance.
  • Expected Time to Complete (ETC) - The estimated completion time for the activity based on Remaining Hours, active FTE, and throughput performance.
  • Expected Time to Complete formula: Last Updated Time + [Remaining Hours / (Active FTE x Throughput%)].
  • Ahead / Behind - The difference between Expected Time to Complete and Target End Time, shown in hours. If the expected completion time is later than Target End Time, the card shows Behind by x hrs. If it is earlier than or equal to Target End Time, the card shows Ahead by x hrs.

Units section - Shipment work

 

The Units section shows how much work has been tasked, completed, and remains for the current warehouse day.

  • Tasked Units - The full scope of today's work for the activity. Tasked Units = Completed Units + Remaining Units.
  • Completed Units - Today's completed quantity from closed work instruction details for the activity.
  • Remaining Units - The quantity that is still open or in process for the activity.
  • % Complete - Completed Units / Tasked Units. The percentage is shown only when Tasked Units is greater than zero.

Unit of measure handling depends on whether the activity uses a single UOM or mixed UOMs.

 

Single UOM example

 

If all records for an activity use the same UOM, the screen displays that UOM. For example, if Shipping Work has only CS quantities, the screen can display values such as Tasked Units = 120 CS, Completed Units = 72 CS, Remaining Units = 48 CS, and % Complete = 60%.

 

Mixed UOM example

 

If an activity contains mixed UOMs, such as CS and EA, the quantities are normalized and displayed generically as Handling Units. For example, if Closed rows total 3 Handling Units and Open/In Process rows total 3 Handling Units, the screen shows Tasked Units = 6 Handling Units, Completed Units = 3 Handling Units, Remaining Units = 3 Handling Units, and % Complete = 50%.

 

Units section - Dock Management work

 

Dock Management work is container-based instead of item-based. The screen counts unique top-level containers rather than item quantities.

  • Processed - Unique containers in Closed status.
  • Remaining - Unique containers in Open or In Process status.
  • Tasked - Processed + Remaining unique containers.

Hours section

 

The Hours section converts today's work into labor hours and compares planned effort with actual completed time.

  • Tasked Hours - The hours required to complete the activity's tasked work. Tasked Hours = Tasked Units / Expected Throughput.
  • Completed Hours - The actual labor time already posted for the activity from the labor consolidation data.
  • Remaining Hours - Tasked Hours - Completed Hours.
  • The hours bar visually compares Completed Hours with Tasked Hours so the supervisor can see how much effort is left.

Employee Grid

 

 

The Employee grid shows who is currently working in the selected activity.

  • Select the FTE hyperlink or the employee icon on an activity card to open the Employee grid.
  • The grid shows one row per employee and includes Employee Name and Latest Activity.
  • When the grid is opened from a specific activity card, it is filtered to the employees currently working on that activity.
  • Clear the filter to see all active employees across all activities shown on the screen.

What-if simulations

 

The What-if section gives supervisors a safe way to test staffing and throughput scenarios without changing actual work, labor assignments, or configuration.

All What-if calculations use the same calculation anchor:

  • Start Time = Last Updated Time shown on the Intraday Labor Progress screen. Note that there is no separate field for Start time but for calculation purpose the Last Updated time is considered.
  • Remaining Hours = the actual Remaining Hours for that activity at that same Last Updated point.
  • The simulation result affects only the What-if output for the selected card.

What-if Expected Time to Complete
  • Purpose - Estimate when the activity will finish if FTE or Throughput% changes.
  • Defaults - FTE defaults to the current number of people working on the activity, and Throughput% defaults to the current throughput percentage for that activity.
  • Formula - Expected Time to Complete = Last Updated Time + [Remaining Hours / (Active FTE x Throughput%)].
  • Result - The card shows a simulated Expected Time to Complete for the entered FTE and Throughput% values.

What-if FTE
  • Purpose - Determine how many people are needed to finish the activity by a specific end time.
  • Defaults - End Time defaults to the Target End Time shown on the card, and Throughput% defaults to the current throughput percentage for the activity.
  • Formula - FTE Needed = Remaining Hours / [(End Time - Start Time) x Throughput%].
  • Result - The system displays the simulated FTE requirement for that scenario.

What-if Throughput%
  • Purpose - Determine what throughput percentage is required to finish the activity by a specific end time with a fixed FTE.
  • Defaults - End Time defaults to the Target End Time shown on the card, and FTE defaults to the current number of people working on the activity.
  • Formula - Throughput% Needed = [Remaining Hours / {(End Time - Start Time) x Active FTE}] x 100.
  • Result - The system displays the simulated throughput percentage needed for that scenario.
