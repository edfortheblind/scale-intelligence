Allow Override of Default Value Checkbox

On the Accessorial Detail Window...

This checkbox indicates if the default value for this accessorial can be changed. For example, suppose you want to assign an "Insurance" accessorial to a shipment, and the default "declared value" for this accessorial is 50.00.

  • If you activate the Allow Override of Default Value setting, then you will be able to assign a specific value, say 100.00, for this value.

  • If you do not activate the Allow Override of Default Value setting, then you will be able to assign this accessorial, but you will need to accept the 50.00 value.
