Pick Into Container...

This type of RF processing involves users picking product directly into shipping containers (or a tote). When you pick directly into a container, the system will perform the packing action as part of the picking process (the user will be able to assign the picked item and quantity to a specific container ID). Until this container is closed, any other items belonging the same shipment may be added to this container. When picking into a tote, the user can group products on the same shipment together. This picking action is a derivative of user/system-directed work, so please see the User/System-Directed section for details not covered explicitly in this section. 

 

 

Notes...

  • P&D Locations: When picking into final shipping containers from a pickup-and-dropoff location, the system will never actually display the P&D location to the user. Since there could be multiple items in the container, the system would not know which item/location to get the correct P&D location from.

  • Picking Into Totes: The procedures outlined below are the same when picking directly into a tote. However, the system will not ask for a container type, or create a shipping container. You will need to indicate on your work profile that you want to pick into totes (as opposed to shipping containers).

  • Creating Containers in the Wave: The following scenario is not supported: Creating containers during the wave (the work generated from allocation requests), and then executing the pick/putaway into a shipping container via RF, as the system would have no way to link the work from the allocation requests to the existing container that you would be picking into.

  • You can pick multiple shipment details going to different putaway locations into a single tote.

1. Log on to your RF Device and select the Work function. The system will display the Work Profile Selection Screen.

 

2. If you have a default work profile defined for your user profile, the system will automatically choose this profile and direct you to the appropriate work screen. Otherwise, you will need to manually choose a work profile.
