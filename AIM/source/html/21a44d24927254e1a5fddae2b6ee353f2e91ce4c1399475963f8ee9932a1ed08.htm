Using Warehouse Mobile - Immediate Dock Transfer

Typically, in a warehouse, you will either use work to facilitate the movement of containers into and through your shipping dock, or you will choose not to use work. The Warehouse Mobile immediate dock transfer enables you to perform container transfer movements without using work execution. You scan the container ID, move the container to the new location and then scan the destination location ID. When the dock transfer is done, the system will validate and success message is displayed. Once the transfer is done, the system will transfer the inventory on hand from its original location to destination location. All these activity can be performed without the need to create a work unit.

 

Permission

The immediate dock transfer is configured using the Warehouse Mobile Screen and user permission using the Security Permission Screen..

Perform Immediate Dock Transfer

Enables user to transfer container in the warehouse.

  1. Tap Immediate Dock Transfer to view Immediate Dock Transfer screen.
  2. Enter or scan the Container ID and Tap Go.
  3. In Immediate Dock Transfer screen, the Container ID, Assigned Location is populated.
  4. Scan the Dock location after moving the container. The Doc Location is populated in the screen.
  5. Tap Go. to view the success message.

Immediate Dock Transfer Notes:

 

When you Scan the ID of the "top-level" (parent) container that you want to transfer to the shipping dock door.

  • The container ID should be present in the system and the First (parent) Container.
  • Multiple Order pallet is supported. When container ID is entered/scanned, the MOPID is displayed.
  • The scanned container and its associated containers should not be associated with open or work instructions

  • if the container is associated with a load, then the system will default the dock door location into this field.

When we enter the destination location:

  • The destination location should not be in frozen state.
  • The destination location needs to have a location class of Shipping Dock
  • There needs to be a dock management flow detail record for the location subclass of the destination location.
  • If the destination location is a dock door location, then no other load can be assigned to that dock door
  • The load that the shipment is assigned to must either be assigned to that dock door or no dock door.

When Go button is tapped. In case the dock transfer does not happen,

  • If the container's shipment is not assigned to a load, then the system will create a shipping load and assign it to the appropriate dock door.

  • If the container's shipping load was not previously assigned to a dock door, the system will assign the appropriate dock door to the container's load.

  • If the carrier on the container's shipment matches the load at the door (but the shipment is not assigned to that load), the system will add the shipment to that load.

  • The system will not allow the transfer if the container's shipment is unassigned to a load and does not have a carrier.

  • If, during the execution of a transfer, the system creates work for this container, and you then press the Transfer Button to close the transaction, the system will not allow the transfer to complete.
