Identifying New Locations For Replenishment

You will use this window to identify which location(s) the system should replenish product to if either of the following situations occurs:

  • The amount of product that you have to replenish exceeds the locations available for replenishment. After the system replenishes to all of the locations that currently contain the product, this field identifies the next location(s) that it can replenish to.

     

    OR

     

  • No locations currently contain the item that you need to replenish. In this case, you will use this field to determine where to start replenishing.

Procedures...

Access the Replenishment Empty Location Criteria Window. Name this record and provide a description.
  1. Using the Filter Data Tab: You can use this tab to specify the values that the system will use to evaluate locations.
     
  2. Using the Order By Tab: You can use this tab to define the order that locations will be organized for possible replenishment. This tab is optional: you don't have to define this order. If you choose not to address this tab, the system processes through the locations in numeric (or alpha) order; for example, it checks location AAA before location AAB.
     
  3. When finished, press OK. The system will save your criteria record.
