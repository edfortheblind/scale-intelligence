Using the Indirect Labor Workbench Screen

The Indirect Labor Workbench screen allows supervisors to enter indirect activities and gaps for multiple employees simultaneously. This screen is accessible from both the main menu and the Labor Activity Insight screen.

Enter Indirect Labor activity

Follow the steps to enter indirect labor activity.

 

1. Open the Indirect Labor Workbench

Navigate to the screen from the main menu or the Labor Activity Insight.

 

2. Choose the Activity Type

Select the type of indirect work (e.g., meetings, maintenance).

  • You can also choose "Gap" if you are logging unaccounted idle time.

3. Set Start and End Time

Enter when the activity began and ended.

 

4. Select a Supervisor

  • Choose a supervisor from the dropdown.

  • Once selected, all employees reporting to that supervisor will appear in a list.

5. Employee Selection

  • Choose one or more employees from the list.

  • Click Save.

6. Confirm Your Entry

  • A pop-up will prompt the user to confirm. Click Yes.

  • If successful, a message will confirm that the entries were saved.

Notes

  • You cannot add an indirect activity if it fully overlaps with a direct work task the employee has already logged.

  • An error message is displayed,

    • If the entry is saved for some employees but not for others.

    • If it doesn’t work for any of the selected employees.
