Identifying Rating IDs

You will use this window to identify the server used to calculate a carrier's rates. Progistics provides a unique server for each carrier. To communicate with Progistics, the system must know the server symbol for that carrier. In addition, you must also provide the carrier's symbol. This identifies the carrier to Progistics. Both the carrier symbol and the server symbol are provided by Progistics. For LTL Internal Rating, the rating ID identifies the unique carrier and server symbols used for SCALE internal rating.

Procedures...

  1. Use the Rating ID Field to identify the carrier for which you are defining this Rating ID.

  2. Use the Server Symbol Field to identify the server used by the rating system to calculate this carrier's rates. The server may also be linked to the carrier's website.


    If you are using Progistics, this value is defined by Progistics.

    If you are using LTL internal rating, this field must be 'ILS'. This value was defined on the Rating ID Server Symbols Window.

     

  3. Use the Carrier Symbol Field to identify this carrier to the rating system.

    If you are using Progistics, Progistics cannot successfully rate this carrier if you don't provide the correct carrier symbol. This value is defined by Progistics.

    If you are using LTL internal rating, this field must be 'ILS.LTL'. This value was defined on the Rating ID Carrier Symbols Window.

  4. Use the Rate at Shipment Level Checkbox if this carrier is an LTL or truckoad carrier. If this value is selected, the system will rate the entire shipment instead of rating at the container level. Do not select this value for parcel carriers.
     
  5. Use the EDI Transmit from SCALE Checkbox if this carrier transmits parcel information electronically. This value must be selected for UPS and Fed Ex carriers. For information about other carriers, contact your Manhattan consultant.
     
  6. Use the Update Container Charge At Manifest Close Checkbox if, after a manifest is closed, you want the system to update the total freight charge, base freight charge and accessorial charge fields on the shipping container and the shipment record(s).
     
  7. Use the Rate International at Shipment Level Checkbox to indicate if you want shipments that are associated with this rating ID to be rated as international shipments. If this checkbox is checked (after closing a container), the system will display a prompt asking if you want to rate this shipment internationally at the shipment level. Manifesting will occur after all the containers are closed for this shipment.
     
  8. Use the Manifest Required Checkbox if you want to mandate that this carrier's shipments will always be manifested. Manifesting rates the container, adds any accessorial costs and assigns it a tracking number. You will usually only select this value for parcel carriers.
     
  9. Press OK. The system will save the record.
