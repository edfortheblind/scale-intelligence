Defining Allocation Rule Sets

An allocation rule set identifies the sequence rules the system will use to allocate product. A sequence rule determines which location the system will allocate product from. Generally an allocation rule set includes multiple sequence rules, which the system processes in numerical order (1, 2, 3, etc.). Each sequence rule can be tied to a location selection and/or strategy.

Procedures...

 

Header Window
  1. Access the Allocation Rule Window. Name this record and provide a description.

  2. Press the Apply Button. The system will add the record.

 

Detail Records Tab
  1. On the Detail Records Tab, right-click the grid and select the New option. The system will access the Allocation Rule Detail Window. This is where you define the sequences.

  2. The Sequence Field will contain the value 1 (or 2, 3, 4, etc). You can change the sequence number, but you cannot use the same sequence number for multiple detail records. The sequence number determines when this record will be used. The lower the sequence number, the sooner the system will process it.

  3. Use the Strategy Field to assign a strategy to this rule set detail. An allocation strategy defines the system's methodology for allocating product. It determines which location you will allocate from, based on an operational requirement or directive. A sequence record can include both a strategy and a location selection value, or just one of these values. For example, if you select the strategy Maximize Space value, the system will attempt to empty as many locations as possible via allocation. Review descriptions of each allocation strategy on the Allocation Overview.

  4. Use the Location Selection Field to to assign a location selection to this detail. A location selection record identifies the possible allocation locations. It narrows the locations that the system considers for the allocation. A sequence record can include both a strategy and a location selection value, or just one of these values. These help minimize processing time and increases your control over allocation activity. The location selection can also have a sort defined, which the system will use after the strategy's sort is completed.

  5. Use the Clear Location Checkbox to have the system allocate from a location inventory record (not the location as a whole) only if the location can be “emptied” without exceeding the demand quantity or the forward location capacity. Also, the system will filter out any location inventory records which has quantity more than the demand or the location capacity. Keep in mind that this setting applies to all types of allocation (shipment, replenishment, work order). For more details about this setting (including examples), see the field topic.

  6. Use the Lot Buttons to indicate how you want the system to allocate your lot-controlled items:

    - Any Lot (Multiple OK): Choose this option to have the system allocate items with any lot, when allocating multiple lots to satisfy the demand is acceptable. The system will use the allocation strategy and allocation location selection records to determine the order that the locations will be allocated from.

    - Any Lot (Single Only): Choose this option to have the system allocate any lot, but just a single lot. The system will use the allocation strategy and allocation location selection records to determine ordering (just like normal allocation). But once a lot is selected, it will be the only lot allocated. If the allocation demand cannot be met with this lot, the system will reject the rest of the quantity. If not enough quantity can be found for one lot, the system will allocate the largest quantity of one lot, and fail the rest of the quantity. Note that this single lot may exist in multiple locations.

    - Specified Lot (Single Only): Choose this option to have the system allocate only a specified lot. If the system cannot find the specified lot, allocation will fail. The system will only look for the lot specified (such as on the shipment or work order). It will not look for any other lots. If not enough quantity can be found for lot specified, the system will allocate all the quantity found for the specified lot and fail the rest of the quantity. Note that this single lot may exist in multiple locations. NOTE: If no lot is specified on the shipment line, then the system will not fail allocation, but will instead process as it would if using the "Any Lot (Multiple OK)" setting. When no lot is specified (as is often the case with replenishment which does not look at the lot on the shipment line), then allocation should not fail. Allocation will only fail in this scenario if no inventory/lot can be found which matches the specified allocation location selection criteria.

 

Eligible UMs Tab
  1. Use the Eligible UMs Field to indicate the units of measure that you want this rule to allocate for. The system will only attempt allocation for locations that support UMs selected on this list.

 

When Finished...
  1. Press OK. The system will navigate back to the Allocation Rule Window. The new rule will be displayed in the data grid. To define additional sequence values, select the New option again.
