Warehouse Mobile - Conditional Screen Formatting

Warehouse Mobile now supports custom-conditioned color styling across all screens. This enhancement allows users to dynamically style visual components based on specific conditions—helping highlight critical information or guide user actions more effectively.

 

Conditional screen formatting enables you to:

  • Alert users to important conditions, such as when handling hazardous materials.

  • Emphasize specific screen sections, like changing the background color to red when picking a hazardous item.

 

Custom Screen Options

You can apply conditional formatting at both the page level and the field level:

 

Page-Level Customizations

  • Title bar

  • Verification highlights

Entire screen background

  • Field-Level Customizations

  • Font color for text labels

  • Background, input, and label colors for text boxes

 

Customize method

 

Conditional formatting is defined using handlebars within the screen's SRC file. These handlebars allow you to specify dynamic conditions that determine when and how visual changes should be applied.

 

Conditional styling can be applied to individual screenflow steps within a process. For example:

  • Location verification

  • Item verification

  • Quantity verification

Each step can have its own unique set of formatting conditions.

 

Note:

The following components cannot be customized:

  • The bottom bar of the WM screen (where the GO button appears)

  • The background color of dropdown menus (remains fixed in base light blue)

  • Modal, popup, and message dialogs, such as:

    • Error messages

    • Actions menu

Note: Color customizations do not automatically adapt to Warehouse Mobile's light or dark themes. Users must manually test and validate your custom styling against each theme to ensure visual consistency and readability.
