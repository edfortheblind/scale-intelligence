Allow Range Entry Checkbox

You can use this checkbox to indicate that you want the system to ask for a range of serial numbers (created using this template) during the RF picking/check in of serial number-tracked items. This option is only available when the following criteria are met:

  • Templates do not contain minor serial numbers

  • Serial numbers end with a numeric value

 

Note

When range entry is active, the final segment of the serial number template must be numeric, and cannot exceed 9 digits. If for this type of serial number you need to enter a serial number range with greater than 9 digits, you will need to configure another numeric segment (before the final segment) for the additional digits required.

 

 

GS1 Processing Note

During the processing of GS1 scans, since the system allows the scanning of only a single serial number from a GS1 barcode, the system ignores a serial number template's "allow range entry" setting. You will, however, be able to enter serial number ranges as part of the normal check in process that occurs after the GS1 scan(s).
