Mode (Replenishment) Field

This field determines how a replenishment attempt will be initiated. There are three types of replenishment modes: manual, real time, and wave. Replenishment masters can have multiple modes selected. If none are selected, then the replenishment master is inactive and cannot be run by any means.

 

 

Manual

You must execute a replenishment attempt on the Inventory Insight screen.

 

Real Time

The system will run replenishment (via a scheduled job) throughout the day, for locations that would typically need frequent replenishment (you can make a location eligible for this on the Location Window). The replenishment process will run quicker than usual because the system will check for replenishment need only the locations that actually are currently in the need of replenishment, and ignore the ones that do not currently need replenishing. This type of replenishment is helpful because you can have replenishment masters running throughout the day, and keep your forward picking locations full for order processing.

 

Wave

The system will automatically execute a replenishment attempt during the wave cycle. Whenever any launch is run that has replenishment as a step in its launch flow, then this replenishment master will be executed.
