Using the Receipt Quality History Insight Screen

You can use the Receipt Quality History Insight screen to search and manage receipt quality records in your warehouse. Any time you check in a license plate on a new receipt, close a receipt, or reopen a closed receipt, the system writes a quality record with reason code. Examples of receipt quality history reason codes are Items not received, Receipt received on time, and Missed expected receipt date.

Searching/Viewing Receipt Quality History Records...

You can use the Receipt Quality History Insight Screen to search for and view receipt quality records in your warehouse.

  1. Open the Receipt Quality History Insight Screen.



  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.



  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane

  • The Receipt Quality History Insight Screen's List Pane displays the results from a query performed in the Filter Pane.



  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

Screen Actions...

The action accessible from the Receipt Quality History Insight screen:

 

View

This action allows you to view the receipt quality history records. When this action is selected, the system will open the Receipt Quality History Details screen in view mode with the following fields: Receipt Info, Item Info, Reference Info, and User Defined. For more information on these fields, see the topic Receipt Quality History Detail Screen.
