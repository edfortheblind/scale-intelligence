Checking In and Locating Product (Receipt Workbench)

You can check in and locate product from the Receipt Workbench. The check in process involves the accepting of product on the receiving dock of your warehouse. During check in, the system creates a receipt container to support the quantity on a receipt line. This receipt container can include either the entire detail line's quantity or part of the quantity. This quantity is then ready for locating. Locating is the process of selecting the appropriate storage location(s) for the checked in product. During locating, the system selects the optimal storage location for license plates checked in on the Receipt Workbench. You can also locate single or multiple receipt containers at a time through Receipt Container Insight screen. When you select to locate product, the system uses the locating rules, which you can define, to select the correct location for a specific item.

 

NOTE: You cannot check in the receipt lines after a receipt has been closed (i.e. the Closed Date is specified). However, you can still perform functions on existing receipt containers such as check-in, locate, and unlocate.

 

Terminology Note
  • In the SCALE receiving module, the terms "receipt container" and "license plate" are synonymous. Therefore, both in the help and the application, these terms may be used interchangeably, and keep in mind that they both refer to the same entity.

Check In Validation Prompts...

The following validation prompt screens may appear during the check in procedures described below, depending on what you have defined on your receiving preference record. Receiving preferences shown on the Receipt Workbench Receiving Preferences selection screen can be authorized by user from the Receiving Preference configuration screen. See the topic Defining Receiving Preferences for more detailed information.

  • License Plate Entry screen: You will need to manually enter the receipt container id(s).

  • Inbound QC Inspection screen: The system displays inbound QC-related information on this read-only screen.

  • Item Unit of Measure Verification screen: You will need to decide whether or not to change the defined unit of measure amounts (on the storage template record for the item/item class):

    - The "Quantity" field identifies how many receipt containers you want to process, at a particular unit of measure. If you selected to check in a partial quantity, the system will default the amount that you identified here. You cannot change the value in the Quantity Field.

    - The "Conversion Quantity" field establishes how many single units are expected in each UM. The system obtains these values from the Item Unit of Measure record. You can change the value in the Conversion Field if the unit of measure contains a different number of eaches than the system expected, based on the Item Unit of Measure record.

  • Item Dimensions Verification screen: If the item does not have dimensions defined, then you can decide whether or not to continue the check in process.

  • Reason Code / Disposition Code (on the Check In screen): You will have to select a reason code/disposition code before you can continue the check in process. Note that if these codes are required, the system will display the check in prompt screen even if you have indicated that you want to perform a "full" check in.

  • Lot Entry screen: You will need to provide lot id(s) for lot-tracked items.

  • Serial Number Entry screen: You will need to provide serial number(s) for serial number-tracked items.

  • Catch Weight Entry screen: You will need to provide catch weight(s) for catch weight-tracked items.

 

 

 

Checking In a Full Receipt Line...

  1. Access the Receipt Workbench.

  2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

  3. In the "Lines" accordion, select the line that you want to check in. Note that you can select multiple lines at one time.

  4. To check in the entire quantity of a receipt line, press the Full Line button.

  5. If necessary, the system will display validation prompt(s).

  6. After you enter the additional information (if prompted), the system will check in the product, and display the newly-created receipt container(s) in the "Containers" accordion. Also, the system will populate the item's assigned location rule into the grid's Destination column.

 

 

 

Checking In a Partial Receipt Line...

  1. Access the Receipt Workbench.

  2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

  3. In the "Lines" accordion, select the line that you want to check in. Note that you can select multiple lines at one time.

  4. To check in a partial quantity of a receipt line, press the Partial Line button. The system will display the Check In Quantity prompt screen.

  5. Enter the quantity amount that you want to check in, and if necessary, provide a locating rule and location value.

  6. Press the Check In Button.

  7. If necessary, the system will display validation prompt(s).

  8. After you enter the additional information (if prompted), the system will check in the product, and display the newly-created receipt container(s) in the "Containers" accordion. Also, the system will populate the item's assigned location rule into the grid's Destination column.

  3. To check in the entire quantity of ALL receipt lines, press the All Lines button.

  4. If necessary, the system will display validation prompt(s).

  5. After you enter the additional information (if prompted), the system will check in the product, and display the newly-created receipt container(s) in the "Containers" accordion. Also, the system will populate the items' assigned location rules into the grid's Destination column.

 

 

 

Checking in a Receipt Line into a New Parent Container...

  1. Access the Receipt Workbench.

  2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

  3. Press the box icon on the right of the Parent Container ID field. The system will display the Receipt Container screen. The container types can be authorized by company and warehouse.

  4. Enter the information for the new receipt container and press Save. The system will create the new container and return back to the workbench.

  5. Next, in the "Lines" accordion, select the line that you want to check in.

  6. To check in the entire quantity of a receipt line, press the Full Line button.

  7. If necessary, the system will display validation prompt(s).

  8. After you enter the additional information (if prompted), the system will check in the product, and display the newly-created nested receipt container(s) in the "Containers" accordion. Also, the system will populate the item's assigned location rule into the grid's Destination column.

    - The parent container(s) are listed on the top level of the "Containers" grid. The "Child" value in the grid represents how many child container(s) are nested under the listed parent. If you press on the numbered link, the system will display all of the child container(s) in a new grid view. You can press the back arrow button above the grid to return to the grid view which displays the parent containers.

  4. Next, in the "Lines" accordion, select the line that you want to check in.

    - The parent container(s) are listed on the top level of the "Containers" grid. The "Child" value in the grid represents how many child container(s) are nested under the listed parent. If you press on the numbered link, the system will display all of the child container(s) in a new grid view. You can press the back arrow button above the grid to return to the grid view which displays the parent containers.

 

 

 

Checking in a Receipt Line Using the Quick-Scan Item/Company Fields...

The following procedure concerns using the Item and Company fields on the top of the workbench to quickly initiate the check in action without selecting an item in the "Lines" grid. This could be used if you are using a scanner to enter the item ID and have an "ENTER" action programmed to occur after a scan. Note that the system will always display the Check In Quantity screen when using these fields to initiate a check in action.

  1. Access the Receipt Workbench.

  2. Scan/enter the receipt ID that you want to check in, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

  3. In the Item field, scan/enter the item that you want to process. Also select a company value if appropriate.

  4. Press the ENTER button (or program the scanner automatically invoke the "ENTER" action after a scan). The system will display the Check In Quantity prompt screen.

  5. Enter the quantity amount that you want to check in, and if necessary, provide a locating rule and location value.

  6. Press the Check In Button.

  7. If necessary, the system will display validation prompt(s).

  8. After you enter the additional information (if prompted), the system will check in the product, and display the newly-created receipt container(s) in the "Containers" accordion. Also, the system will populate the item's assigned location rule into the grid's Destination column.

Check in Receipt Line (partially or Fully) for a lot controlled items (Modify Expiration Dates)- Notes

 

The following are functional details when you perform receipt check in for lot controlled items and scenarios to change the expiration date.

 

  • When a lot does not have an expiration date set, then the system will not show lot entry screen during check in.
  • If there is no lot present, then system will prompt for Lot entry screen for partial or full receipt check in.
    • When user enters new lot ID and the Lot entry screen with the expiration date field disabled. Click OK, to move to the Lot details screen, and you can now change the expiration date and click Save. The save action will also perform the check in for the receipt line.
  • When existing lot it is entered, then existing expiration date is displayed.
    • If you modify the expiration date, then system will prompt the lot update confirmation screen, click OK, to have the expiration date updated for all lot across all locations.
    • If you do not change the expiration date, then system will check in without system prompting for any additional screen information.

 

Checking In Catch-Weight Items...

 

  • When you check in a receipt line for a catch-weight-tracked item, system opens the Catch Weight Entry screen as part of the Receipt Workbench check-in flow.
  • If the receiving preference uses system-assigned license plates, system creates the license plate and then prompts you to enter the catch weight. If the check-in quantity creates multiple license plates, system prompts you to enter a catch weight for each one before check-in is completed.
  • If the receiving preference uses manual license plate assignment, enter the license plate first and then enter the catch weight for that license plate. If multiple license plates are created, repeat the license plate, catch weight, and catch weight UOM entry for each license plate.
  • Select the catch weight unit of measure on the Catch Weight Entry screen. Receipt Workbench fetches item-specific weight UOM values before opening the catch-weight screen and validates the submitted UOM during check-in.
  • If the receipt line is lot-controlled, the lot on the Catch Weight Entry screen is shown so that the user can confirm the weight against the correct lot.
  • After you complete catch weight entry, system validates the entered data, and creates the receipt container records for the checked-in items.

Locating Process Notes...

  • When locating to multi-item locations: The locating process does a volumetric validation when locating an item to a multi-item location. When locating to a multi-item location, the system compares the current volume of the location's items to the total volume of the location to determine if a receipt container will fit. For example, suppose a receipt container has 10 of Item A in it, for a total volume of 100. Location AA001 currently contains Item A and Item B, with a total volume of 250. Also, location AA001 has a total volume capacity (using location type dimensions) of 500. The system, then, would successfully locate the receipt container to the multi-item location. Note that the system performs this volume check only when there is no item location capacity records defined for the item you are trying to locate. If an item location capacity record exists for the item/item class and location/location type, the system would use it to determine the amount of the item that can be placed into the location.  

    NOTE: The locating process does not execute the volumetric calculation on a multi-item location when the location type is defined with a blank value. This is helpful if you want to, for example, create a returns location, and have the system treat it with infinite capacity so unlimited returns can be located there. In this case, you would want to make sure that no location type is assigned to the location (instead of, say, assigning a location type with a dimensions/volume = 999999), and the system will treat the location as infinite in size, and not execute the volumetric calculation during locating.

  • If the system converted the license plate's unit of measure during check in, it will only locate in the unit of measure it selected (during check in). For example, if the receipt line included 10 eaches and the system converted that to 1 case, it can only locate a case unit of measure. It cannot locate 10 eaches.

  • You cannot locate items with different unit of measure records to the same location. For example, suppose location LOC123 contains a quantity of item A1 (with a casepack of 10). You then locate an additional quantity of item A1 (with a casepack of 8). The system will not locate this additional quantity because of the difference in the UM's of each casepack. However, if you locate some more A1 that has also has a casepack of 10, then the system will allow you to locate, as both quantities of A1 have the same UM properties.

  • If the receipt container’s locating rule has "Delayed Locating" active and the user’s receiving preference has "Create Putaway Work" active, then the receipt container will locate to a location with the Receiving pre-locate location class. If either setting is not active, then the system locates based on the receipt container’s locating rule details. The locating rule on the parent container is used when locating by parent, while the nested container’s locating rule is used when locating by child.

  • If the Create Putaway Work Checkbox on your receiving preferences record is active, work creation is initiated for work resulting from the locating process. If this checkbox is not active, the system assumes that the product is already at the location it chose. The quantity is considered on hand at the location.

 

 

 

Locating a Receipt Container...

  1. Access the Receipt Workbench.

  2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

  3. In the "Containers" accordion, select the license plate that you want to locate. Note that you can only select one container at a time.

  4. Select the Locate action from the Actions menu. The system will attempt to locate the product. If the license plate can be located, the system will display a success message and populate the putaway location value into the grid's Destination column.

 

 

 

Locating ALL Receipt Containers...

 

  1. Access the Receipt Workbench.

  2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

  3. To locate ALL containers listed in the "Containers" accordion, press the Locate All button near the top of the workbench.

  4. The system will attempt to locate the product. If the license plate(s) can be located, the system will display a success message and populate the putaway location values into the grid's Destination column.

 

Locating Catch-Weight Receipt Containers...

  • When you locate a catch-weight receipt container, the system preserves the entered catch weight and catch weight unit of measure for the destination inventory.
  • If the receiving method is Check In and Locate (Immediate), locating is completed during receiving, and putaway work can also be created as part of that flow. If the receiving method is Check In and Locate, the system preserves the catch weight through locating and putaway work processing.
  • If the destination location type has a maximum weight, the system validates the location capacity before locating the container.
  • If locating splits a receipt container across multiple destination locations, the system proportionally distributes the catch weight across the resulting containers and locations.

 

 

Assigning a Putaway Group...

Receipt containers can be assigned to a putaway group in two ways: 

  • If the "Execute Group Putaway" setting is active on your receiving preference, then the system will display the Putaway Group Assignment prompt screen after the locating process is successful. From this prompt, you can either simply add the container to the putaway group, or add it and at the same time close the putaway group.

  • If group putaway is not active on your receiving preference, but you still want to add a container to a putaway group, you can select the container in the grid and choose the Assign to Putaway Group action from the "Containers" accordion Actions menu. The system will then perform the locate action on the container, and also display the Putaway Group Assignment prompt screen. Note that you are only able to do this if the receipt container gets located to a location with an associated putaway group. Otherwise, when this action is invoked, the system will simply locate the container without prompting for a putaway group.

For more information on putaway groups, see the topic Using the Putaway Group Insight Screen

 

 

 

 

Unlocating a Receipt Container...

  1. Access the Receipt Workbench.

  2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

  3. In the "Containers" accordion, select the license plate that you want to unlocate. Note that you can only select one container at a time.

  4. Select the Unlocate action from the Actions menu. The system will unlocate the product and display a success message.

NOTE: If work was created for a receipt container and that work has been executed, the system will not allow you to unlocate a container.

 

 

 

 

Unlocating ALL Receipt Containers...

 

  1. Access the Receipt Workbench.

  2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

  3. To unlocate ALL containers listed in the "Containers" accordion, press the Unlocate All button near the top of the workbench.

  4. The system will prompt you to confirm that you want to unlocate the containers. If you press Yes, the system will continue with the action.

  5. The system will unlocate the product, and display a success message.

NOTE: If work was created for a receipt container and that work has been executed, the system will not allow you to unlocate all containers.

 

 

 

 

Cancel Check In Process Notes...

 

  • The system will allow you to cancel the check in of any product that has not been located.
  • If the system displays a warning message indicating that some of this quantity has been included in an upload interface, when you check in this product again, it will be included in another interface upload. Because cancel check in actions are not interfaced, this quantity will be identified as cancelled twice in your ERP system. We recommend that you manually update the ERP to reflect the cancelled state of this product. If no, none of the checked in quantity has been uploaded to the interface.
  • When a receipt container is cancelled, the system removes it from the receipt container table and places it in the DELETED_RECEIPT_CONTAINER database table; but, it remains tied to the receipt in the database. Pre-check in containers (ASN) are not placed into this table when they are cancelled; instead they are moved to a Closed (900) status.
  • When you cancel check-in for a catch-weight item, system removes the receipt container from the receiving location, removes the recorded catch weight for that license plate, returns the quantity and catch weight to an open check-in-pending state on the receipt line, and lets you receive the product again.

    Cancel Check In of a Receipt Line...

    1. Access the Receipt Workbench.

    2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

    3. In the "Containers" accordion, select the container for which you want to cancel check in.

    4. Select the Cancel Check In action from the Actions menu. The system will cancel the check in of the product. The system will delete the receipt container, and the system will return the product quantity as open quantity in the "Lines" accordion grid. You can now check in this product's quantity again.

     

     

     

    Cancel Check In of ALL Receipt Lines...

     

    1. Access the Receipt Workbench.

    2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

    3. To unlocate ALL containers listed in the "Containers" accordion, press the Cancel All button near the top of the workbench.

    4. The system will prompt you to confirm that you want to cancel check in for all the containers. If you press Yes, the system will continue with the action.

    5. The system will cancel check in of the product. The system will delete the receipt containers, display a success message, and return the product quantity as open quantity in the "Lines" accordion grid. You can now check in this product's quantity again.

     

     

     

    Cancel "Pre-Check In" Container...

    You can also cancel receipt containers if they are in a “check-in pending” status. When you cancel a "pre-check in" container, the system will perform three actions: change the container status to 900, change the container quantity to 0, and subtract the quantity from the “pre-receive” inventory location.

     

    NOTE: If a parent container is in "check-in pending" status, canceling it will cancel all of the child containers. If the status of any one of the child containers is greater than "check in pending," then the parent container status will not be "check in pending" and therefore you will not be able to cancel the parent container.

     

    1. Access the Receipt Workbench.

    2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

    3. In the "Containers" accordion, select the "pre-check in" container for which you want to cancel.

    4. Select the Cancel Container action from the Actions menu. The system will cancel the check in of the product. The system will delete the receipt container, and the system will return the product quantity as open quantity in the "Lines" accordion grid. You can now check in this product's quantity again.

    Creating a New Receipt Line...

    1. Access the Receipt Workbench.

    2. Scan/enter the receipt ID that you want to process, and press the Arrow button. The system will display the receipt line(s) and container(s) that are associated with this receipt ID.

    3. Select the New Line action from the Actions menu near the top of the workbench. The system will display the Receipt Line screen in new mode.

    4. Enter in the appropriate receipt line information, and press the Save button when completed.

    5. The system will create the new line for the receipt loaded into the workbench.
