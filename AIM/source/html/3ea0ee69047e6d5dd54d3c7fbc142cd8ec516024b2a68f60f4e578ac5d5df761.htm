Catch Weight Required Checkbox/Toggle

You can use this checkbox to indicate that the employees will need to identify an item's catch weight when adjusting or transferring items, assigning items to receipt containers (such as at receipt check in), executing work (through warehouse mobile) or shipping containers (such as at packing). Note that you cannot set up an item to validate both catch weight and a serial number. Also, changing the catch weight flag on the item master does not affect the existing shipment details in the system.
