Meeting Additional Direct Mode Requirements

To interface data using direct mode, you will also need to complete some programming activities to communicate table values between the ERP and the system. Below is a list of the procedures that you need to address.

 

 

Procedures...

  1. Review the interface table values. Determine which table values you want to interface (in addition to the required values).

     

  2. Determine where the data that you want to communicate is located on the ERP system. This data should correspond with the values on the system interface table.

     

  3. Complete the custom logic to fill the system download interface tables with the data selected at Step 2.

     

  4. Complete the custom logic to obtain values from the system upload interface tables.
