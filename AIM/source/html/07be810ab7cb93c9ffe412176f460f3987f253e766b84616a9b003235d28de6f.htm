Defining User Profiles

You need to create a user profile for each employee who will process entities in the system. You cannot access the system if you are not associated with a user profile. The system references the user profile to determine how an employee will perform tasks (such as packing, shipping, receiving, etc).

Using the General Tab

Access the User Profile Window. Name this record and provide a description.

  1. Use the Default Warehouse Field to define the employee's default working warehouse. When the employee opens the application, it will automatically select his/her default warehouse.
     
  2. Use the Department Field to identify the department where the employee works.
     
  3. Use the Email Address Field to enter the employee's email address. This field supports up to 500 characters. It is mandatory, else a validation message will be displayed. Also, duplicate email addresses in the user profile configuration records are not allowed.

  4. Use the Security Group Field to enter or select the name of the security group the employee is assigned to. This is not a required field. The security group is defined on the Security Group configuration.

  5. Use the Payroll Information fields to provide payroll information for an employee. This is used to track productivity costs in the Labor Management.

  6. Use the Wage Rate Field to indicate how much money this user will make on a per-hour basis. Note that if you do not have security to view this wage rate value, then the system will mask this value with asterisks, and not allow you to edit it.
     
Using the Preferences Tab
  1. Use the Cycle Count Preferences Field to associate the employee with the appropriate cycle count preference record. This preference record will determine whether activity-driven cycle count requests should be executed immediately or created as pending requests. Also, you can define positive and negative tolerance values which determine when a user can make a location adjustment.

  2. Use the Packing Preferences Field to associate the employee with the appropriate packing preferences record. This preference record will determine how the employee will pack containers. If you leave this field blank, the preference record named *Default will be associated with this user. For more information, see "Establishing Packing Preferences."

  3. Use the Receiving Preferences Field to set a default receiving preference for the employee. The default receiving preference will be what is selected when opening the Receipt workbench or RF Receiving. The user can be authorized to one to many receiving preferences. The receiving preferences found under the Receiving Preferences Field will only be those that have been authorized for the user. For more information, see Defining Receiving Preferences.
     
  4. Use the Shipping Preferences Field to associate the employee with the appropriate shipping preference record. This preference record will determine how the employee will manage shipments and shipping loads. If you leave this field blank, the preference record named *Default will be associated with this user. For more information, see "Establishing Shipping Preferences."
     
  5. Use the Work Order Preferences Field to associate the employee with the appropriate work order preference record. This preference record will determine how a user or group of users will process work orders. The default preference record should accommodate the majority of employees.

  6. Use the Desktop Template Field to assign an Desktop theme to this user. A template record contains what link groups will display on the desktop.

  7. Use the RF Style Sheet Field to indicate the font size used for RF text for certain RF screens (Close Container, Immediate Dock Transfer, and Location Inquiry). This is a user-specific setting that supercedes a similar system-level setting on the Technical Values Window.

  8. Use the Default Document Printer and Default Label Printer to indicate all the printers in the print device configuration. The default printer on the user profile overrides document routing printer configured for the document type. Selecting a printer when printing selected documents will override the default printer. It will also override printers assigned to the workstations. For more information on using default printers, see Printing Paperwork and Manually Assigning Printers (RF). Using the Company Access Tab
  1. Use the company access fields to assign this employee to the appropriate company(s).

 

Using the Warehouse Access Tab
  1. Use the warehouse access fields to assign this employee to the appropriate warehouse(s).

 

Using the Work Profile Tab
  1. Use this tab to select the work profile(s) that this user will be able to use in work processing.

 

Using the Authorized Adjustment Types Tab
  1. Use the Adjustment Type Checkboxes to indicate the adjustments that you want this user to be allowed to perform on the Inventory Adjustment screen or an RF device.

 

Using the User Attributes Tab
  1. Use the User Attributes 1-10 Fields to indicate the attribute(s) that you want to associate with this user.

 

Using the Time Tracking Button
  1. Use the Time Tracking Button to create a time tracking record for this user. For more information, see Creating Time Tracking Records.
