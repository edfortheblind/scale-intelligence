Quantity Verify Checkbox

This checkbox indicates if a work instruction or cycle count request will require the employee to verify how much product he/she is processing. This checkbox is displayed on the Work Special Handling Window. For example, if this checkbox is selected, the system will display a blank quantity field, and the user will have to actually enter the quantity, thereby "verifying" it. If this checkbox is not selected, the system will default the quantity value in the field, and the user will not have to manually enter a value.
