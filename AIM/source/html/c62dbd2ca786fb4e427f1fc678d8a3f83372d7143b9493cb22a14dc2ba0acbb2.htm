Cycle Count System Values

These values are miscellaneous technical values that the system uses when processing cycle counts. You will need to address some of these values, depending whether or not if you are using cycle count plans. Ask your system consultant before changing any of these values.

 

Note: Use with plan based and non-plan based (activity-driven) cycle counting

 

Use the following table to see what values you will need to address for the two methods of cycle counting:

System Value Descriptions

 

Value Key

Value Description

 

10

Auto Print Cycle Count List: The system uses this value to determine if you want the system to print a cycle count list, after a plan has been run using a scheduled job.

 

20

Auto Release Cycle Count Plan: The system uses this value to determine if you want the system to automatically release a plan, after a plan has been run using a scheduled job.

 

30

Activity Count - Negative Adjustment: The value you identify here is used by the system when writing transaction history records, whenever you perform a negative adjustment on an activity (non-plan-based) driven cycle count request. Note that this action can also be interfaced back to the ERP, if defined to do so on the Adjustment Type Window.

 

40

Activity Count - Positive Adjustment: The value you identify here is used by the system when writing transaction history records, whenever you perform a positive adjustment on an activity (non-plan-based) driven cycle count request. Note that this action can also be interfaced back to the ERP, if defined to do so on the Adjustment Type Window.

 

50

Planned Count - Negative Adjustment: The value you identify here is used by the system when writing transaction history records, whenever you perform a negative adjustment on a plan-based driven cycle count request. Note that this action can also be interfaced back to the ERP, if defined to do so on the Adjustment Type Window.

 

** Note that the system will use the value specified on the cycle count quick plan and will only use this value if nothing is selected.

 

60

Planned Count - Positive Adjustment: The value you identify here is used by the system when writing transaction history records, whenever you perform a positive adjustment on a plan-based driven cycle count request. Note that this action can also be interfaced back to the ERP, if defined to do so on the Adjustment Type Window.

 

** Note that the system will use the value specified on the cycle count quick plan and will only use this value if nothing is selected.

 

70

Work Unit Field For Activity Driven Work: This value is used to set the work unit on activity [non-plan] driven requests (if you are creating work for these requests).

 

90

Create Activity Driven and Quick Plan Cycle Count Work: The system uses this value to indicate if it should create work instructions for both activity-driven [non-plan] requests and requests generated from cycle count "quick plans." Note that if this value is set to Y, then the Create Work Check box on the Cycle Count Quick Plan Window will default as selected (the user can always turn this option off from that window if desired).

 

100

Default Cycle Count Group Size: This value allows you to group your cycle counts, which provides easier ways of managing them. You can use these groups in the quick find window and when printing to limit the amount of cycle counts the system displays or prints. This default group size is used when creating a plan and when printing. The user, however, does have the ability to override the default. This value is also defaulted on the Counts Per Group Field on the Cycle Count Quick Plan Window.

 

110

SRC Identifier for Activity Driven Work- System will use this value during work creation and record it on the work unit details. The defined SRC identifier will be used to create work for activity driven cycle count.
