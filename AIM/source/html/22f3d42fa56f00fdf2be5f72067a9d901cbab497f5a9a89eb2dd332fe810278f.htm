Defining Accessorials

An accessorial is an additional cost levied to cover special processing for a parcel. Examples of accessorials include Cash On Delivery (COD), Delivery Confirmation, or Saturday Delivery. Accessorials are organized into categories, based on their purpose. These categories are referred to in SCALE as accessorial codes. Each code then can have multiple accessorials (which are referred to in SCALE as accessorial subcodes). For example, all of the Cash On Delivery accessorials, such as COD Amount and COD Instructions, are organized under the category COD. Then, when you are ready to actually assign the accessorial, you can easily skim through the categories to find a specific accessorial.

 

The system is shipped with many of the common accessorials predefined for Fed Ex and UPS.

Creating an Accessorial Header Record...

  1. Use the Accessorial Code Field to identify the accessorial to Progistics. This value is required by Progistics to calculate the accessorial. It is also provided by Progistics. Also provide a description for this code in the Description Field.

     

  2. Use the Rating ID Field to identify the carrier who offers this accessorial (a rating ID identifies a carrier to Progistics).

     

  3. Use the Rating Service Field to associate a service level with this accessorial.

     

  4. Use the Apply Per Container Checkbox to apply this accessorial at the container level, not the shipment level. If this accessorial is to be levied by a parcel carrier (not an LTL or truckload carrier), select this checkbox.

     

  5. Use the Always Apply Checkbox if this accessorial is required for all shipments assigned to this carrier/service combination.

 

 

Creating an Accessorial Detail Record...

After you select the Apply Button, select the Detail Records Tab. Select New from the Actions Menu. The system will display the Accessorial Detail Window.

  1. Use the Accessorial Subcode Field to identify the detail record. This value is provided by Progistics.

     

  2. Use the Description Field to provide a text description for this subcode.

  3. Use the Value Type Field to identify what type of information (Address, Alpha, Checkbox, Complex, and Numeric) will be represented with this accessorial detail. See the Value Type field topic for information on each of these value types.

  4. Use the Default Value Field to identify the default value this accessorial. For example, if you charge a flat fee for Saturday delivery, you would define that amount in this field. Later, this value will be displayed with this accessorial on the Accessorial Assignment Window. If you want users to have the option to edit this value when assigning the accessorial, select the Allow Override of Default Value Checkbox.

  5. Use the External Symbol Field to indicate the Progistics name for an accessorial. The system passes this symbol to Progistics, which will use it to identify the accessorial during rate calculations.

  6. Parent Field: For information, see the field topic.

  7. Apply at Container Contents Checkbox: For information, see the field topic.

  8. Use the Allow Override of Default Value Checkbox to indicate if the default value for this accessorial can be changed. For example, suppose you want to assign an "Insurance" accessorial to a shipment, and the default "declared value" for this accessorial is 50.00. If you activate this setting, then you will be able to assign a specific value, say 100.00, for this value. If you do not activate this setting, then you will be able to assign this accessorial, but you will need to accept the 50.00 value.

  9.  

    Use the Required Checkbox to identify if this accessorial subcode is required when its accessorial category is selected. Required subcodes include any value that must be provided for a charge to be computed, like insurance amounts or account numbers. Optional ones could include instructions and other peripheral values.

  10. Use the Use Value As Amount Checkbox to indicate whether the value of a container/shipment should become the value of the amount passed to Progistics. During manifesting, if this checkbox is selected, the system will insert the value of the container or shipment, instead of giving the user an error when the Amount Field is not filled. Note that in order for the system to recognize the value for this checkbox, the accessorial detail must be classified as "required for rating" by selecting the Required Checkbox...
     
  11. Use the Include Freight Charge In Amount Checkbox to indicate how the system will send the freight charge of a container to Progistics. If this checkbox is selected, the system will make two "calls" to Progistics. The first call will retrieve the freight charge from Progistics. The second will pass the container amount (including the freight charge) in as the amount for manifesting.
