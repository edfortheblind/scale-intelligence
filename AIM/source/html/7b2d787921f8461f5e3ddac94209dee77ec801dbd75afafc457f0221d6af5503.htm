Searching/Viewing Work Records...

You can use the Work Insight Screen to search for and view work records in your warehouse.

  1. Open the Work Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

NOTE: Clicking on the Work Unit in the Detail pane header opens the Work Detail screen for that specific instruction.

 

 

 

About the List Pane...

  • The Work Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

  • The Work Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

  • For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

 

Screen Actions...

The following actions are accessible from the List Pane:

 

 

Edit

This action allows you to change field values on the work instruction. When this action is selected, the system will open the Work Instruction Details screen in edit mode. This action will appear if the user has security access to the "Change" checkpoint.

 

 

Delete

This action allows you to delete a work instruction or multiple work instructions.

 

 

Assign Team

This action allows you to select a team to assign to a work instruction or multiple work instructions. Note that you can only assign a team to a "header" work instruction(s).

 

 

Assign User

This action allows you to select a user to assign to a work instruction or multiple work instructions. Note that you can only assign a user to a "header" work instruction(s).

 

 

Change Priority

This action allows you to change the priority of a work instruction or multiple work instructions, as long as the work instruction(s) is not closed. Note that changing the priority on a work instruction header sets the priority on the header and all the associated work instruction detail(s).

 

 

Completed By User

This action allows you to set the Completed By user field on the work instruction by selecting the work instruction header or work instruction detail. A list of active users will be displayed in the 'Enter a username' field on the prompt. For additional information on this topic, refer to Processing Work.

 

 

Confirm

This action allows you to confirm a single or multiple work instruction headers or details.


- Only full picks of the confirm quantity will be eligible for picking when selecting a single work instruction header or multiple work instruction headers or details. Partial, short, over picks, and prompting for serial numbers require confirming a single work instruction detail.

- Confirming a work instruction header will execute the work for all the open and in process work instruction details of the selected header.

- Pick Confirmation Screen is displayed when confirming a single work instruction detail. Selecting the Confirm option will confirm a full pick when the confirm quantity on the Pick Confirmation Screen equals the original confirm quantity from the work instruction.

- Selecting the Confirm option will confirm a partial pick when the confirm quantity on the Pick Confirmation Screen is less than the original confirm quantity on the work instruction.

- The short pick option is used when confirming a short pick. You must select a reason code when confirming a short pick.

- Confirming a single work instruction detail for an item that is tracked using a serial number in the inventory will prompt you to select serial numbers when the confirm quantity is less than the location’s quantity.

- If the To license plate is required, you will be prompted to enter the license plate when confirming single or multiple work instructions (details or headers) .

 

For additional information on this topic, refer to Processing Work.

 

 

Hold

This action you to assign a hold code to a work unit or multiple work units.

 

 

Override Pick

This action allows you to override the From location on the selected work instruction. For additional information on this topic, refer to Processing Work.

 

 

Override Putaway

This action allows you to override the To location on the selected work instruction. For additional information on this topic, refer to Processing Work.

 

 

Print Preview

This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to Printing Paperwork.

 

 

Print Default Docs

This action allows you to print all documents that have both the print procedure for "work" setting and the default setting selected on the document’s Document Type record.

 

 

Print Selected Docs

This action allows you to print all the selected documents. You can cancel or exit out of print select without printing.

 

 

Remove Hold

This action allows you to remove the hold code from a work instruction or multiple work instructions, as long as the hold code is not for one of the following: wave not released, cycle count plan not released, or work order not released. Also, if the work instruction selected is a Header record, then the hold code will be removed from all instructions under that work unit.

 

 

Unassign

This action allows you to unassign a user or team from a work unit or multiple work units, as long as the work(s) is not active. Note that this action will always unassign both user and team from work instruction(s). Also, this option is only allowed on Header records.

 

 

 

 

Screen Notes...

 

- Work for cycle counts and inventory adjustments (positive and negative) are not included in the calculations for the Open Quantity and the Picked Quantity summary values on the Work Insight screen. However, work for inventory transfers is included in these calculations.
