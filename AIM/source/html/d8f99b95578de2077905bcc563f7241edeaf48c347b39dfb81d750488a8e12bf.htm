Processing Picking Management Work

Picking Management is a different way to view and execute the work within the warehouse. Through regular work execution, each work unit must be completed by one user, moving throughout the warehouse and completing all the work for that work unit. Picking management provides a way for work to broken up by zone, and executed by multiple users. The procedures in this topic describe how to execute work in the various screens of the Picking Management module. Note that in order for a work unit to appear in the Picking Management Explorer/Picking Window, the  Pick Management Active check box must be selected on the work unit's associated work zone and work type configuration records.

1. Signing/Scanning on to a Picking Terminal (on the Picking Signon Window)...

To initiate work, you need to first sign or scan on to the appropriate picking terminal. Once you are logged on, you can select a zone from the appropriate picking terminal. You can perform this action on the Picking Signon Window. This window will display all of the zone(s) that are active for picking management.

  1. Choose the Picking Signon option from the desktop. The system will display the Picking Signon Window.

    OR

    Right-click a work unit record in the Picking Management Explorer and choose the Scan On option. The system will display the Picking Signon Window.

  2. Select the work zone that you want to pick from and press OK. The system will display the Picking Selection Window. If you signed on using the "scan on" option, the work unit you selected will populate the Work Unit field of the Picking Selection Window.

 

 

2. Assigning a Work Unit (on the Start Picking Window)...

Before a pick can be executed, you need to assign a work unit to a user. The system will display all of the work units (open, on hold, and assigned) in your selected zone in the Picking Selection Window. This window sorts the units in order by zones away, which indicates which zone is currently ready to be picked into the shipping container. You can also see the first and last location that you must pick from, as well as the total quantity you must pick. Note that a user can be assigned to multiple work units.

 

Work Unit Icon Explanation

Each work unit is represented by a graphical icon. This icon indicates the status of each unit. Below are explanations of what each icon represents:

 

 

Represents an open work unit.

 

Represents a work unit that has a user assigned to it.

 

Represents a work unit that has been placed on hold.

  1. Access the Picking Selection Window. The system displays this window after you choose a zone to work in from the Picking Signon Window.

     

  2. If necessary, research work unit(s) by selecting a work unit from the record list and pressing the Details Button. The system will display the Picking Details Window. Press OK when finished.

     

  3. Select the work unit that has a zones away value of 0. This represents the zone that you should pick from.

     

  4. Enter the user name that you want to assign to the work unit.

     

  5. Enter the work unit number you want to assign in the Work Unit Field.

     

  6. If needed, press the Print Button if you want to print a work pick list for this work unit.

     

  7. Press OK. The system will assign the work unit.

 

 

3. Starting a Pick (on the Start Picking Window)...

Once a user has been assigned to a work unit, you will need to confirm the that the pick information is correct. You can perform this action in the Start Picking Window. If appropriate, you can unassign a user as the picker associated with this work unit. You can also view zone details from this window.

  1. Access the Start Picking Window.

     

  2. Press the Details Button to view individual work instruction information from the Picking Details Window.

     

  3. If necessary, you can unassign this work unit by pressing the Unassign Button. The system will unassign the work unit from the current user and display the Picking Selection Window.

     

  4. To start picking, press OK. The system will display the Picking Selection Window.

     

  5. Enter your user name and the work unit you want to pick and press OK. The system will display the Complete Picking Window.

 

 

4. Completing a Pick (on the Complete Picking Window)...

You can execute a picking action on the Complete Picking Window. This window will appear when you enter a work unit on the Picking Selection Window that has been previously assigned to you.

  1. Access the Complete Picking Window from the Picking Selection Window.

  2. Enter a work unit:

    To Pick: Press OK; the system will perform the pick action, and close the work unit.

    To Hold: Press the Hold Button; the system will display the Work Hold Window. Enter the hold code that you want to apply to the instruction. The value you enter as a hold code will depend on your business practices. The system will display this code on the Work Instruction Window. Press OK. The system will place this instruction on hold. You can release this work unit from the Work Insight Screen. Note that if an instruction is on hold, you cannot perform any actions on it until it is released. Also, the current instruction(s) will not be confirmed.

    To Short Pick: Press the Short Pick Button; the system will display the Picking Short Pick Window. Enter the item and quantity data of the item you want to short pick. If the item is lot controlled, you will need to enter the lot ID as well. Press OK. The system will display the Complete Picking Window. Press OK again. The system will display the Quality Measures Window. Enter a reason code for your short pick and press OK. The system will perform the short pick and display the Picking Selection Window.

 

 

Unassigning a Pick...

You can unassign a user from an open work unit. This is helpful if for some reason the assigned user cannot perform a pick. A user cannot be unassigned from a work unit if that unit is on hold. You can also unassign a work unit from the Picking Management Explorer.

  1. Access the Start Picking Window or the Complete Picking Window.

     

  2. Select the work unit that you want to unassign and press the Unassign Button. The system will remove the user associated with the unit, and return you to the Picking Selection Window.
