Before You Begin: Billing Management Setup Prerequisites

Be sure to address the following when setting up Billing Management to work with SCALE:

  • You will need to install/configure the Billing Management application before you can integrate Billing Management with SCALE. :Billing Management is a stand-alone billing application that is sold by Manhattan Associates. 

  • Note that the setup steps listed in the help for Billing Management integration are for the SCALE portion only. If you have any questions about installing/configuring the Billing Management or Enterprise Integration Services applications, please talk to your Manhattan representative, or refer to the documentation for that application.

  • In order for Billing Management to process inventory data for a location, the location needs to be configured in a certain manner. Billing Management references a Class field that, in SCALE, is equivalent to the Location Class field. There are three valid classes in Billing Management: A (active location), C (case pick location), and R (reserve pick location). Since you cannot create custom location classes in SCALE, you will need to provide this designation on each location that you want to use with Billing Management, and then map this field to Billing Management's Class field:

    1. In SCALE, open your location configuration record. In one of the user defined fields, enter the value A, C, or R, depending on how you want to classify this location to Billing Management.

    2. In the Billing Management Trigger Window, you will now need to map this user defined field (configured in the previous step) to the Billing Management Class field. You will need to open the appropriate trigger record, right click on a location element (location, to location, pick location, etc), and choose the Maintain Trigger Detail Map option. Check the "current mappings" list to see if there is already a location class field mapped. If so, remove it. Then, add a mapping where the SCALE user defined field is mapped to the Billing Management Class field.
