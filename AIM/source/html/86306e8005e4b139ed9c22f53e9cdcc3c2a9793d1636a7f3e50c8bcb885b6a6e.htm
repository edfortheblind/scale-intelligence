Reviewing Carrier Rate Base Assignment

Carrier Rate Base Assignment establishes the relationship between each LTL carrier and carrier service and a specific rate base and its effective dates. Less than Truckload (LTL) rating is based on a postal code range pointing to a rate base. The rate base contains a breakdown of the rates per pound for each LTL class and its weight breaks. Rate bases determine how much a carrier will charge for shipping product, based on specific parameters, such as weight, class and travel distance. Before the system can rate the LTL carrier's shipment, it must be linked to a valid rate base. The Carrier Rate Base Assignment configuration provides the ability to configure a carrier/carrier service to the rate base. Each carrier rate base assignment record contains effective date ranges, postal code ranges and destination postal code ranges for the rate base.

Creating a Carrier Rate Base Assignment Record...

  1. Use the Carrier Field to define the LTL carrier these rate bases are assigned to. The carrier is an LTL carrier that is defined in the carrier configuration.

  2. Use the Carrier Service Field to associate it with the carrier. The carrier service is tied to the carrier. It typically identifies the type of carrier's service offering.

  3. Use the Company Field to define the company that owns the product being shipped.

 

Using the General Tab...

  1. Use the Beginning Effective Date Field to verify the first day that this rate base record will be in effect. A blank value represents no beginning date.

  2. Use the Ending Effective Date Field to verify the last day that this rate base record will be in effect. A blank value represents no ending date.

  3. Use the Origin Country Field to verify country where the shipments will originate.

  4. Use the Origin Postal Code From/To Fields to determine the postal code range from where the shipment is originating. The system verifies the Ship From Country and Postal Code. It looks to see if the postal code fits within this range. The rate base will use this origin postal code range to determine which rates are to be used for calculating the shipping charge.

  5. Use the Destination Country Field to verify if the country code for this rate base record is correct. This is the country of where the shipment is going 'to'.

  6. Use the Destination Postal Code From/To Fields to determine the postal code range where the shipment is being sent to. The system verifies the Ship To Country and Postal code. It looks to see if the postal code fits within this range.The rate base will use this postal code range to determine which rates are to be used for calculating the shipping charge.

  7. Use the Additional Criteria Field to establish additional rate base criteria. The additional criteria is used to tie the rate base assignment record to anything founds on the shipment record. For example, this could be used to establish rate bases that are unique for customers. Using this field is optional.

  8. Use the Rate Base Field to verify rate base assigned to the criteria. A rate base identifies which rate table is used based on a specific origin zip code range and destination zip code range.
