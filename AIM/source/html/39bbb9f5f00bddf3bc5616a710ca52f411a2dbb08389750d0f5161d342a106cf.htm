Work Zone Configuration

Overview

 

Work Zone configuration defines warehouse work zones used by work assignment and execution logic. You can create and maintain work zone records, then associate one or more work profiles to each zone.

Note: This configuration is currently accessible only from the Location Configuration wizard and is not available as a standalone configuration outside the wizard.

 

Configure Work Zone

 

1. Work Zone

 

Select or create a Work Zone record.

  • Create New: Create a new work zone record.

  • View All: Review and select an existing work zone record.

  • Current Selection: Displays the selected work zone record.

 

A. Information

 

Zone: Enter the work zone identifier.

Description: Enter the work zone description.

Cart Building Work Sequence: Enter the sequence value used for cart-building work processing.

 

B. Work Profiles

 

Select one or more work profiles that will be applied to this work zone.

  • All / None: Select or clear all work profiles.

  • Show Selected: Filter the list to selected profile values.

  • Search: Find profiles by name before selection.

 

Use Back, Save, Continue, and Finish to manage and complete Work Zone configuration.
