Reviewing Yes, No, Manual, or Immediate (Work Creation Method) Records

You can review the system-defined yes, no, manual, and immediate validation records for work creation methods that are provided with the system. The system references these records when you select or deselect Work Created checkbox in the Filter Pane of the Replenishment Insight Screen.

 

  • "Yes" is set when work has been created automatically. The Replenishment Work Creation Method will be set to Automatic on the Replenishment Master. This work is generated in the wave or when manually initiated from the Inventory Insight.

  • "No" indicates that the work has not been created when initially creating the replenishment request. This may be updated later once work creation has been run.

  • "Manual" is set when the Replenishment Work Creation Method on the replenishment master is set to Manual. A replenishment request set to Manual can have work created from the Replenishment Insight screen.

  • "Immediate" is set when the Replenishment Work Creation Method is set to None. This indicates that the system has immediately moved the allocated inventory from the From location to the To location.
