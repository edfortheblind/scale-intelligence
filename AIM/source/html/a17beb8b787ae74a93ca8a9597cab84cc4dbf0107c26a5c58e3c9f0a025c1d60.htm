Searching/Viewing Inventory Records...

You can use the Inventory Insight Screen to search for and view inventory records in your warehouse.

  1. Open the Inventory Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

About the List Pane...

The Inventory Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

List Pane Icon Explanation

Certain conditions for the inventory location are represented by graphical icons on the list pane. Below are explanations of what each icon represents:

 

Icon Explanation

Location unit of measure overrides exist for the inventory.

Location is a permanent location for this item (configured through Item Location Assignment).

Location is license plate tracked.
  • The Lot field value is a hyperlink that opens the Lot insight screen filtering by the selected lot.

  • The On Hand Quantity field in the list pane grid is a hyperlink that opens the Inventory Detail screen for the record. This is disabled when the line represents multiple license plates and/or attributes.

For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

About the Detail Pane...

  • The Inventory Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

  • The header section of the Detail Pane contains: Location, Item, and Image of the item.

  • There is an Indicator Tile for Open Work, which displays the number of open work instructions associated with this item/company/warehouse/location/lot/license plate. Clicking on the tile takes you to Work Insight displaying the work instruction Detail records associated with this item/company/warehouse/location/lot/license plate. If the line represents multiple license plates, then this tile will also show the work for all license plates associated with the selected line.

  • For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

Viewing Inventory Details...

Use the following procedures to research specific details about a specific inventory record.

  1. Open the Inventory Insight screen.



  2. Perform a search to locate the appropriate inventory record.



  3. Open the record either by selecting it and choosing the View action, or by pressing on the hyperlink on the value in the On Hand Quantity grid column.



  4. The system will open the record in the Inventory screen. If you need to make any changes, you can do so on this screen, and press Save to apply the changes and return to the Inventory Insight screen.

 

Screen Actions (Inventory Insight)...

Each of the actions listed can be done for multiple rows at the same time. The following actions are accessible from the List Pane:

 

NOTE: The options Edit, Adjust, Edit attributes, Delete attributes, Finished item breakdown, Immediate needs, and Transfer are not available when a line represents multiple license plates and/or attributes.

 

Notes:

  • The status of allocated inventory can be changed in the shipping and receiving dock.
  • From the Lot insight screen, user will not be able to perform inventory adjustment/status change/transfer when the updated inventory is linked with inventory attributes.
  • While editing lot information, user will be able to change status/expiration date. This change will be updated across all inventory records for the item/company/lot in the system.
  • When a lot controlled item status is changed to Unavailable, then the lot is not frozen when you select multiple lots for the same item. You can use the lot insight screen to freeze the lot.

 

Adjust

The Adjust action when highlighting a row passes the item and location information into the Inventory adjustment screen. If the row is lot controlled and/or license plate tracked, that information is also passed.

 

Company Transfer

This action enables you to change the company of item from one to another. For more information read Company Transfer.

 

Create Count

This action allows you to create a cycle count request for the selected row(s) based on the location/item/company/warehouse. If multiple rows are selected, a separate Cycle Count Quick Plan is created for each row selected. The cycle count will be added to a new plan named after the location of the selected row(s). The “Create Activity Driven & Quick Plan CC Work” cycle count system value setting will determine if the system will create cycle count work. The system will display a success message to confirm that the cycle count request has been successfully submitted. The system will display an error message in case an error is encountered.

 

 

Delete Attributes

This allows you to delete the Inventory attributes with the attribute ID. This is active if the selected line has existing inventory attributes.

 

 

Delete Overrides

This action allows you to delete overrides for the selected location (s) when Location Unit of Measure overrides exist for the selected location inventory. Upon clicking Yes on the confirmation prompt, you can continue with the deletion process.

 

 

Edit

This action allows you to display and edit the details of an inventory record.

 

 

Edit Attributes

This allows you to display and edit the Inventory attributes with the attribute ID. This is active if the selected line has existing inventory attributes. You can save or cancel the modifications based on your requirement.

 

 

Edit Overrides

This action allows you to create overrides for the selected location. Upon clicking Yes on the confirmation prompt, you can view the Location Unit of Measure screen. The icon in the Inventory Insight is displayed when override is created for the location.

  • If the item present in the location does not have any item unit of measure configured, the Location Unit of Measure defaults from the storage template linked to the item.

  • If the item present in the location has an item unit of measure configured, the Location Unit of Measure defaults from the item unit of measure record.

  • If the location already has an override based upon the storage template of the item and now the item is linked to a new storage template and item unit of measure is configured for the item, system will delete the existing override while editing the override and will show the Location Unit of Measure based upon the new item unit of measure for the item.

For more information, refer to the topic Editing/Deleting Location Unit of Measure Overrides.

 

 

Finished Item Breakdown

This action passes the item and location information into the Finished Item Breakdown screen. If the row is lot controlled and/or license plate tracked, that information is also passed. For more information on Finished Item Breakdown, see the Disassembling a Finished Item topic.

 

 

Freeze Lot

This action allows you to freeze the specified lot when highlighting a row containing a lot controlled item, provided you have the required authorization to do so. If you select multiple rows and any of the rows does not have a lot controlled item, the action will be disabled. The system will display a success message to confirm that the freeze lot has been successfully submitted. The system will display an error message in case an error is encountered.

 

 

Immediate Needs

This action allows you to select an immediate needs transaction for the Immediate Needs Insights screen. For more information on Immediate Needs, see the Researching a Warehouse's Immediate Needs topic.

 

 

Manual Replenishment

This action allows you to kick off the manual replenishment process by selecting which replenishment master(s) you want to execute. For more information on Manual Replenishment, see the Manual Replenishment topic.

 

 

Mark for Replenishment

This action enables you to choose replenishment requests to be marked as eligible for replenishment. The system will then evaluate the location for replenishment the next time the real-time replenishment scheduled job runs. Note that this action is only enabled for locations eligible for real-time replenishment. If you select multiple rows and any of the rows is not set up for real-time replenishment, the action will be disabled.

 

Status Change

This action enables you to change the status of one or more inventory records. For more information on Status change, see the Inventory status change topic.

 

Transfer

This action enables you to transfer one or more inventory records. The transfer of inventory records with lot controlled and/or license plate tracked information is also supported.

Multi-select inventory record transfer

This action enables you to transfer multiple inventory records to a single location. The inventory transfer with or without work adjustment type is supported.

 

Follow the steps to perform Inventory transfer

  • In the Inventory Insight screen, select multiple inventory records.
  • Click Actions >> Transfer to view the Inventory Transfer screen
  • Select the Adjustment Type from the drop down list.
  • Enter the To location. Also you can use the search feature to find a location.
  • Click Transfer and success message is displayed. Success and validation error message for all the inventory transfer is displayed in the screen.

Also perform locate and inventory transfer in the Inventory transfer screen. User can select one or more records for inventory transfer in the Inventory Insight screen.

  • Click Actions >> Locate.
  • In the Select a locating rule pop-up, enter the locating rule in the text box.
  • Click Locate. The system will locate and transfer the selected records.

Significance of color coded Validation messages

  • When we have all the selected record is successful - Green
  • When we have partial success in transfer of selected records. - Orange
  • When all the selected records have failed - Red
View

This action allows you to display and review the details of an inventory record.

Note: Multiple records selection is not allowed. The configuration will work for single record.

Enables user to create or edit items permanent location assignment. See Assigning a Permanent Location to an Item for more details.

 

Item Location Capacity

Enables user to create or edit items location capacity. See Defining Item Location Capacity for more details.

 

Item Unit of Measure

Enables user to create or edit items unit of measure. See Defining Item Unit of Measure for more details.
