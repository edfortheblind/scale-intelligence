Intermediate Consignee

This setup allows you to define a secondary delivery destination, such as a port or logistics hub. It is particularly used when shipping via the UPS World Ease service. UPS provides a list of international hubs and corresponding postal code ranges for authorized users. Each of these hubs must be defined in SCALE as an intermediate consignee.

 

Consignee Address

 

Use the Account Number Field to identify the secondary delivery destination (intermediate consignee) to the carrier.

 

UPS World Ease Note: For shipments using World Ease, this value is a ten-digit code provided by UPS that represents the hub address and its supported postal code range. During manifesting, SCALE sends this code to UPS for shipment grouping. These records are mandatory when using the World Ease service.

 

Ensure the consignee's address and contact details are also provided in this record.
