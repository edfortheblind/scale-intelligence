Creating Container Groups

A container group identifies all the containers that can be used to pack an item, or group of items. During the container creation wave step, the system processes through a container group's details in sequence order. After you define a container group, you will link it it to the correct packing class on the Packing Class Window.

Procedures..

 

Using the Container Group Window
  1. Provide a name for the container group and a description. Select the Apply Button. Select the New Action. The system will display the Container Group Detail Window.
 
Using the Container Group Detail Window
  1. The Sequence Field will contain the value 10. You can change the sequence number, but you cannot use the same sequence number for multiple detail records. The sequence number determines when this record will be used. The lower the sequence number, the sooner it's processed. Generally, the largest container in a group should be associated with the lowest sequence number. The remaining containers should also be assigned sequence numbers based in size: the smallest container should have the highest sequence number.
     

  2. Use the Container Type Field to assign a container type to this detail. This identifies the container that the system will attempt to pack product in during the container creation wave step.

     

  3. Use the Fill Percent Field to identify how much of this container's dimensional space is available for items. If you select 100, the system assumes that no packing materials, inserts or other non-saleable items are included in the container.

     

  4. Use the Container Shape Field to indicate the type of physical shape of a shipping container. Container shape values are used by the system during the container creation in a wave process to determine if a certain container type can be downsized into. Only container types with the same container shape (as the originally assigned container type) can be downsized into.

     

  5. To define additional sequence values, select the New Action.
