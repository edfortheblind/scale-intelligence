Using the Manifest Insight Screen

You can use the Manifest Insight Screen to search and manage the manifested shipping containers in your warehouse. You can identify the status of the Manifests: Open, Closed, and Transmit Status. Each of these statuses allow you to drill through the hierarchy to reach the amount of detail required for your research.

 

When the manifesting process is started, SCALE transmits container-specific information, such as its weight, carrier, and carrier service, to the rating engine (Progistics). Progistics then contacts the carrier's server, and manifests the container. Progistics also retrieves the container's tracking number and its rate, and then transmits this information to SCALE. When a container is packed and closed, the system may automatically manifest it (based on user's packing preference record). Containers can be manually manifested on the Shipping Container Insight screen, and shipments can be manually manifested on the Shipment Insight screen.

Searching/Viewing Manifests Records...

You can use the Manifest Insight Screen to search for and view Manifests in your warehouse on a tablet device.

  1. Open the Manifest Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter button. The system will display all information regarding the resulting records in the List Pane.



 

 

About the List Pane...

The Manifest Insight Screen's List Pane displays the results from a query performed in the Filter Pane. The List Pane's Grid Fields contains some hidden fields. You can find this complete list of fields by clicking on 'Select columns'.

List Pane Icon Explanation

Certain conditions for the manifested shipping containers are represented by graphical icons on the list pane. Below are explanations of what each icon represents:

About the Detail Pane...

The Manifest Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

     

Screen Actions...

The following actions are accessible from the list pane of Manifest Insight screen:

 

 

Close

This action will close an open manifest. Closing a manifest also provides options to print a manifest, print a summary barcode label, and transmit a manifest. These options will be enabled depending on the carrier. If there are ineligible containers on the manifest, you will be able to choose among these options: Move the containers to another manifest for today, Move the containers to the next shipping day’s manifest, or Do not move containers from manifest.

 

 

Print Container Manifest

This action allows to print the container manifest after the manifest has been closed. This action is not allowed with FedEx. For additional information on this, refer to Processing a Manifest topic.

 

 

View Containers

The action allows to view the shipping containers that are present in an open or closed manifest. Clicking on the action redirects to the Shipping Container Insight screen filtering on the Manifest name, Manifest status, Rating ID, and Shipper Code in the Manifest Criteria section of the filter pane. For additional information on this, refer to Processing a Manifest topic.

 

 

Print UPS Summary Barcode Label

This action allows to print the summary barcode label after the manifest has been closed. This action is only available for UPS or UPS Worldease. The action remains enabled only if the manifest selected is closed and the carrier is UPS or UPS Worldease. For additional information on this, refer to Processing a Manifest topic.

 

 

Note: The End of Day (EOD) feature in Progistics can be used to manage to re-transmit the un-transmitted files. (This is work around in case users are looking for Transmit action in the Manifest Insight screen).
