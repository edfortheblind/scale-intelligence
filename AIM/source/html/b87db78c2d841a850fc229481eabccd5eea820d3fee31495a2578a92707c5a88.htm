Inventory Tracking Process Summary

** Functionality **

 

 

Summary

Inventory tracking is the system's method for identifying where product is located (and the current state of said product) from the time its entered into the system until it leaves the warehouse. The system uses the concept of quantity "buckets" to accurately manage a location's quantity. These buckets identify the state of inventory at specific points in time during its journey through the warehouse. SCALE uses the following characteristics to track inventory quantities: lots, serial numbers, catch weights, and inventory attributes.

The following are key features of the inventory tracking functional area:

 

Quantity "Buckets"...

The following is a list of these quantity buckets and their meanings:

Available: Describes quantity available for picking at a location. The system derives this number via the following calculation: On Hand Quantity - Allocated Quantity - Suspense Quantity = Available Quantity.  

 

On Hand: Describes quantity that is physically present in a location. A location's on hand quantity does not diminish until the items are actually taken from a location. 

 

In Transit: Describes quantity that is inbound to a location, but has yet to be physically putaway.  

 

Allocated: Describes a location's quantity that will be leaving the location, but has yet to be physically picked.from the location.

 

Suspense: Describes quantity that has been counted during the cycle counting process, but does not equal the quantity the system has recorded for this location. Suspense is only updated in the following scenarios

  • Count is less than the System expected and is less than Allocated.
  • Location is empty and count is more than Positive Tolerance Allows.
  • Count is less than the Negative Tolerance Allows.
  • Count is equal to the system quantity and location has in-transit and suspense quantity.

 

Lot Tracking...

Lot values are typically tracked for such products as edible goods, medicines, or chemicals. SCALE can track an item's lot throughout the whole warehouse process (inbound processing, inventory storage, and outbound processing). You can also create lot templates, which dictate the structure of a lot ID.

 

 

 

Serial Number Tracking...

Serial numbers are typically tracked for such products as computers and other electronic components. SCALE can track an item's serial number(s) throughout the whole warehouse process (inbound processing, inventory storage, and outbound processing). The system tracks two different types of serial numbers: Master and Minor. A master serial number is the primary serial number that the system will reference and display for an item. A minor serial number is a secondary serial number that the system references behind-the-scenes, but is not typically viewable in application windows. Also, serial numbers are written to their own database table, which allows the system to easily access these serials for various processes.

 

You can also create serial number templates, which determine the physical structure of a serial number. You can define if a serial will be alpha-numeric/numeric, its length in characters, and whether a serial can be duplicated for items in the system. You can associate a serial number template with an item on the Item Window.

 

 

 

Catch Weight Tracking...

Catch weight represents the actual weight of an item recorded during operational processes such as packing, unpacking, picking during work execution, receipt check-in, inventory adjustments, and transfers. Catch weight is commonly used for products whose weight can vary from unit to unit, such as poultry, meat, and other fresh food items.

 

 

 

Inventory Attributes...

Inventory attributes represent values that are assigned to inventory, typically when it is checked into the warehouse. These attributes fill the need to track specific information about warehouse inventory. Typically, this type of information would need to be captured during receipt check in, maintained in inventory, items allocated and picked based on these attributes, and then uploaded to your ERP system. Also, you can view/edit/delete these attributes to inventory at select places in the system. The application supports twenty attribute fields, which are generically named Inventory Attribute 1, Inventory Attribute 2, etc. You can rename these attributes in the System Text Editor to reflect the specific attribute being captured, such as Country of Origin, Tax Seal, or Product Owner. The system supports inventory attributes for both license plate and non-license plate tracked locations. See the topic Inventory Attributes - Introduction for more information on inventory attributes.

 

 

 

Movement Class Analysis

As inventory spends more time housed in the warehouse, the movement class associated with them may change; or, a more optimal location will open up (based on the movement of other warehouse inventory). As these warehouse conditions change, there are times when moving inventory to a better location (or freeing up a prime location for faster moving product), is advised. Movement class analysis data (collected via a scheduled job) can identify inventory that is not optimally located and has the tools available to manually correct active items in your warehouse, based on user analysis of the data. With this optimal product placement (which is based on historical demand), you can increase your warehouse's efficiency and shorten order fulfillment cycles, among other benefits.
