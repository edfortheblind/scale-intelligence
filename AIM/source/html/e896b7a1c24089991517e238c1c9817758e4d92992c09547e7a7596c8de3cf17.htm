Using the Cycle Count Plan Insight Screen

You can use the Cycle Count Plan Insight Screen to search and manage cycle count plans in your warehouse. This helps you keep track of exactly how much inventory is present in your warehouse. There are two ways you can trigger cycle counts: by manually creating cycle count plans (called "plan-based"), or by having the system create cycle count work instructions automatically when a location is due for a cycle count (called "non-plan based" or "activity-driven"). This screen helps you to adopt the former method.

Searching/Viewing Cycle Count Plan Records...

You can use the Cycle Count Plan Insight Screen to search for and view cycle count plan records in your warehouse.

  1. Open the Cycle Count Plan Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

  • The Cycle Count Plan Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • There is a hyperlink in the Plan field to open the Cycle Count Plan Details screen.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Cycle Count Plan Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Cycle Count Plan Insight contains Indicator Tiles with counts of the other entities (i.e. requests, open work, and transactions). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Requests
    1. Displays the number of all the cycle count requests linked to the cycle count plan.

    2. Clicking on the Requests Indicator Tile takes you to the Cycle Count Request Insight screen filtering on the internal plan number.

  2. Transactions
    1. Displays the number of transaction history records for the cycle count plan.
    2. Clicking on this tile takes you to Transaction History Insight filtering on the internal plan number and transaction type.

  3. Open Work
    1. Displays the number of open and in process cycle count request work instruction details for the entire cycle count plan.
    2. Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the internal plan number and internal number type.
    3. The internal number type is Cycle Count.


For more general information about the Detail Pane, see the topic Introduction to Insight Screens.



 

 

Screen Actions

The following actions are accessible from the List Pane:

 

View

The View action allows you to open a specific cycle count plan against a selected record. Clicking on this action opens the Cycle Count Plan Details screen.

 

 

Delete

The action allows to delete one or more cycle count plans. The system will prompt for a confirmation message after the delete action is performed. If there are multiple records selected for deletion with one or more requests that are already deleted, system will ignore the records that are already deleted and deletes all the other records which are eligible for deletion.

 

 

Close

This action allows to manually close one or more cycle count plans. Selecting the record (s) and invoking the action will show a confirmation message and accepting a confirmation message will close the cycle count plan and a success message is shown once the plan is closed.

 

 

Master Plan

The Master Plan action allows you to open the Cycle Count Master Plan screen. The warehouse defaulted on the Cycle Count Master Plan screen is based on the warehouse selected by user counter on the Cycle Count Plan Insight. Selecting a cycle count master and tapping/clicking on 'Save' will submit for cycle count plan creation. For more information on this, refer to the topic Using Cycle Count Plans.

 

 

Print Default

This action allows you to print all the default documents for a cycle count plan. This is useful when performing manual cycle counting for plans created outside of a master plan. If the plan is divided into multiple groups, a separate document will be printed per group. There is no option to preview the document before printing.

 

 

Print Selected

This action allows you to select and print documents for a cycle count plan. If the plan is broken into multiple groups, a separate cycle count list will be printed for each group. There is no option to preview the document before printing.

 

 

Quick Plan

This action allows you to open the Cycle Count Quick Plan screen through which you can create a new cycle count plan. For more information, refer to the topic Creating Cycle Count Quick Plans.

 

 

Release

This action enables you to release a single or multiple cycle count plans. Selecting the record (s) and invoking the action will release the cycle count plan and a success message is shown after the plan is released. Refer to the topic Using Cycle Count Plans for additional information on releasing the cycle count plans.
