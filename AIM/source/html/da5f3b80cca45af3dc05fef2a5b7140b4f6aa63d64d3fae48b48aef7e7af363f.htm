Defining a Shipper Cross Reference

This record associates a shipper code with a specific warehouse/company combination. It determines which carriers the system can rate for this shipper. When you create a shipper cross-reference record in the system, it is automatically created in Progistics. In Progistics, the shipper cross-reference record identifies the shipper, it address and its eligible carriers. Before it will rate a carrier, Progistics references this record. If the carrier is not registered for this shipper, it will not be included in the rating process. If you change or delete a shipper record in the system, Progistics will also update or delete that shipper record. Note that you can create multiple cross reference records per warehouse/company combination, as long as the records have different shipper codes defined.

Using the Shipper Tab

  1. Access the Shipper Cross Reference Window.

     

  2. Use the Shipper Code Field to link this company/warehouse to the code you defined on the Shipper Code Window.

     

  3. Use the Warehouse Field to identify the warehouse that will use this shipper. If you do not support multi-company processing, the warehouse is the entity that will ship product. In this case, Progistics would then create only one manifest, for the entire warehouse. Conversely, if you select a company (Step 3), the system will generate the manifest per company, regardless of the value defined in this field.

     

  4. Use the Company Field to identify the company who will ship product. This value is only required if your warehouse supports multi-company processing AND you created a shipper code for this company. The system will create a manifest for this specific company.

  5. Use the Default Shipper Checkbox to indicate a particular cross reference record is to be used as the "default" shipper code. When a "default" cross reference record's warehouse/company combination is indicated on the Shipment Screen or Rate Shopping Window, then the system will rate as per the configured default shipper code.

    The following are a few things to consider when using this setting:
    - There can only be one default shipper cross reference record for a certain warehouse/company or warehouse/(blank company) combination.

    - The first cross reference record you create for a warehouse/company combination is automatically set as the default shipper. You cannot change this setting on this initial record until subsequent records are created for this warehouse/company combination.

    - If you choose to designate a cross reference record as the default shipper record (and there is an existing default record), then the system will make the current record the default, and unselect this setting from the previous default record.

    - If multiple records for a warehouse/company combination exist, the system will not allow you to delete a default shipper record.

 

Using the Change Shipper Status Tab
  1. Use the Change Shipper Status Checkboxes to identify all carriers that you want to associate with this shipper. The system will only rate the carriers that you select here. You can deselect a carrier by unselecting it.
