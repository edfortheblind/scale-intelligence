Configuring DIF File Protocol Properties

To setup the SCALE Device Integration Framework (DIF), you will need to address some configuration values in the application's database. The third step in this process is to configure the DIF protocol properties. A protocol property record contains the specific file transfer data that is used to define the properties of a DIF endpoint. Note that there is no configuration screen to define protocols in the SCALE Configurations Explorer. You will need to configure these values directly in the application database's FILE_PROTOCOL_PROPERTIES table.

 

IMPORTANT: In order for changes to the FILE_PROTOCOL_PROPERTIES table to be reflected, you will need restart the DIF Processing Service.

 

See the SDK for detailed/additional information about DIF.

Procedures...

  1. Access your application database using a database editing tool such as SQL Server Management Studio.



  2. Access the FILE_PROTOCOL_PROPERTIES database table. Each database row represents the properties of a separate DIF endpoint.

  3. Define values for the following database fields:

    Object_ID (numeric 9,0): Represents the unique protocol identifier. This is a required field.

    Endpoint_ID (numeric 9,0): Represents the endpoint tied to this protocol. This is a required field.

    From_Directory (alpha-numeric 255): Represents the file directory records are originally placed in to be processed.

    From_Ext (alpha-numeric 25): Represents the file extension the records must have to be eligible for processing.

    To_Directory (alpha-numeric 255): Represents the file directory records are placed into after processing.

    To_Ext (alpha-numeric 25): Represents the file extension the records are marked as after processing.

    Insert_Message (alpha 1): Represents whether or not a message will be inserted into the incoming DIF Message table. Supported values are Y or N.

    Sleep_Time (numeric 9,0): Represents the amount of time the system waits between processing records.

    USER_DEF1 - USER_DEF6 (alpha-numeric 25): Represents user identified values, similar to other places in the system.

    USER_DEF7 - USER_DEF8 (numeric 14,5): Represents user identified values, similar to other places in the system.

  4. When finished entering values, commit the changes to the database and exit your database editing tool.
