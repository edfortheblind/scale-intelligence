Editing/Deleting Location Unit of Measure Overrides

The system can create unit of measure (UM) overrides for a location if, during receiving, a user updates a location's item quantity in a higher unit of measure (i.e. not the base UM). Note that the system will only create these overrides only if the "Write Location UM Overrides On Item UM Change" AND the "Use Location UM Overrides" inventory control value settings are active. Most of the time these overrides are created for a valid reason, but there are cases when you may want to delete the override and allow the inventory to assume the base configured UM breakdown.

 

For example, suppose that item Z1 has an item unit of measure that says that 25 EA=1 CS, and that location A01 currently holds 2 CS of this item. Your warehouse receives in a CS that includes only 22 EA. Because the UM makeup is different than what is currently in the location, the system will not locate this CS to A01. The system would then locate it into an empty location (B01), creating a UM override so that the unique item UM (CS=22 EA) can be located there. The system would of course then not be able to locate the true case UM (CS=25 EA) in B01.

Editing/Creating Location Unit of Measure Overrides...

The system also allows you to manually edit or create new UM overrides for a location. You would typically only need to do this if you receive in an unusual UM quantity and need to "force" a location to store it.

  1. Access the Inventory Insight screen.

  2. Find the location that for which you want to edit the UM overrides.

  3. Select location and choose the Edit Overrides action. If there are no overrides that exist for this location, then the system will prompt you, asking if you want to create overrides. If you press Yes, then the system will create the overrides, and open them in the Location Unit of Measure screen.

  4. Edit the location unit of measure value(s) as appropriate.

  5. Press Save when finished. The system will save the location unit of measure overrides, and close the Location Unit of Measure screen.

 

 

 

Deleting Location Unit of Measure Overrides...

  1. Access the Inventory Insight screen.

  2. Find the location that for which you want to delete the UM overrides.

  3. Select the location and choose the Delete Overrides action. The system will prompt you to confirm that you actually want to delete these overrides. Choose Yes, and the system will delete the overrides.

NOTE: You cannot delete overrides for receiving dock locations.
