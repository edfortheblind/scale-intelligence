Using the Labor Employee Scorecard

The Employee Scorecard screen displays key warehouse labor metrics such as Utilization%, Throughput, and Throughput%. It provides both high-level performance summaries and detailed employee-level insights to monitor workforce productivity in real time.

  • Open the Employee Scorecard Screen.

  • Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  • Default filters

    • Warehouse

    • Warehouse Day

    • Shift

  • Click the Apply Filter button.

Performance Metrics

 

Utilization %

This metric shows the average percentage time spent on direct labor activities out of the total available time.

 

Calculation

Utilization% = (Actual Time / Total Available Time) × 100

  • Actual Time = Time spent on direct + indirect tasks.

  • Total Available Time = Actual Time + Gap Time.

Total Available Time Definition

Total Available Time represents the full period during which an employee has been productive.

 

Calculation: Total Available Time = Actual Time (Direct + Indirect)+Gap Time

  • Direct Time: Time spent on productive warehouse tasks like picking, packing and receiving.

  • Indirect Time: Time spent on necessary non-task activities (example, equipment checks).

  • Gap Time: Idle time detected between two logged activities (automatically captured by the system).

Throughput %

Throughput% helps to determine how efficiently the total available time was used to achieve the expected output.

 

Calculation

  • Throughput% = [Throughput Allowable Minutes / (Available Time)]* 100

  • Throughput Allowable Minutes- Represent the standard time the system expects the employee to take based on configured expectations for tasks completed.

Throughput (Units/Hour)

This value indicates the number of handling units completed per hour.

 

Calculation

  • Throughput (handling units/hour)=(Total Quantity Processed)/Total Time Taken (minutes))×60

 

Note:

  • Only direct labor activities (Labor Type 10 or 20) are considered.

  • Indirect activities, breaks, and gaps are excluded.

  • If tasks involve different unit of measurement (such as Each, Case, or Pallet), the system converts them into a single standard handling unit before calculation.

Performance Metric Cards

 

Each employee (user) working in the warehouse is represented through a metric card. These cards provide quick-glance data and can be clicked to view additional details.


Displayed on each card:

  • Employee Info: Name, User name, Department

  • Throughput Gauge: Handling units/hour

  • Utilization% Gauge: Percentage of productive time

 

Click on the card to view the details screen.

 

Additional details are shown on the detailed view:

  • Shift

  • Supervisor

  • Throughput%

  • Gap Time

Color Coding

 

Performance metrics are visually color-coded based on defined threshold values. Labor Configuration.

  • Green: Displayed when a metric value is greater than or equal to the configured threshold.

  • Red: Displayed when a metric value is below the configured threshold.
