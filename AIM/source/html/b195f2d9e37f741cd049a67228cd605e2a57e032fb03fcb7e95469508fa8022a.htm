Print Device and Document Routing Configuration

Overview

 

The printing process includes the generation and printing of paper documents and labels. You can obtain paperwork for all phases of the system's outbound and inbound processes, including such key processing points as running a wave, closing a container, or confirming a shipment/load.

 

Configuration Hierarchy

 

The following are the configurations needed for printing operations.

 

Configuring Print devices

 

The Printers in the network need to be configured for it to print documents.

 

Name and Description

Use the Name Field to identify the printer to users. This value should be descriptive and this will later be displayed in the Device Field on the Document Routing configuration. Use the Description Field to enter the appropriate alphanumeric description to identify the printer better. For example Printer for Return Labels only.

 

Qualified Device Name

  • If the Printer is set on a Personal Computer (or other non-server location), the qualified device name will identify both the machine that the printer is configured on and the printer itself. In the example below, Sales_office is the machine and Return_printer is the printer. Since the printer is not declared on the server, its network path is included in its name.

  • If this printer is configured on the server, the qualified device name will just identify the printer. Since the printer is already defined to the server, you will not see a network path.

Rating Printer Driver Symbol and Rating Printer Stock Symbol.

When the user needs to print vendor or progistics integrated labels, then users will need to configure these options. You can enter these details either when you create a new printer device or Edit an existing printer device.

Select the appropriate driver from the Rating Printer Driver symbol drop-down list. The corresponding label list for the driver selected will be displayed.

 

Printer Warehouse Access List

Use the Printer Warehouse Access List to control warehouse-level access for a print device when this feature is enabled.

After entering printer information, select Assign Docs to Printer to save and continue to Document Routing configuration.

 

Document Routing

 

The document routing parameters such as document type, template, printer selection, and routing criteria such as customer details, container class, carrier, rating ID, machine name (workstation), and more. You can either configure using the existing document routing record or create a new one.

 

Note: The Document Routing button from the System Configurations screen enables the user to only edit the printer and Document Routing information.

 

1. Document

Document are defined for the system to identify the document that needs to be printed. The template will configure the layout and associated applications that will generate the document (SSRS, Progistics, and more). The format is defined by the document type (label or document).

 

Document Type

You can choose an existing document type or define a new document type. A document type identifies a general document category, such as a pick list or a shipping label, and the physical structure (label or document) of all paperwork associated with the type. The system has a list of documents defined. Optionally users can configure a new Document Type.

  • Document Type Information - The name and description for the document type created.

     

  • Print Procedure - Select from drop down list for all the paperwork generated for this print procedure. Set the default print procedure for the printer by checking the Default check box.

     

  • Document Data - Configure the following

     

    • Data Source - This determines which data selection records are available when you are defining sequences on the Document Master

     

    • Detail Data Source - The database table that system will retrieve the document details information.

     

    • Document Generator - The document generator record is associated with this document type.

  • Classification - Indicate the Document Type you are creating as a Document ,Label or Collate

     

  • SQL Server Reporting Services - Use the Rendered Document PDF File Directory Field in the warehouse as well as in the document type to indicate where you want SQL Server Reporting Services to place rendered (created).pdf files. Note that these .pdf files are not automatically deleted from this directory after they are printed by the default PDF reader application.

 

Printed Format Information - Select the print format properties for the document.

  • Print As - Set the application that will process the printing.

  • Document Template -The system will have a list of pre-defined templates for selection. When users need to print documents, the system will need to have template to provide structure and types of information printed on the document.

  • Document Criteria - This criteria is used by the system to generate detail record values on the document.

  • Language - Set the language text the document needs to display.

Collate Label - This enables the user to print by combing documents using the collate document template. Read Collate List.

2. Routing Criteria

Once Document and Document Type are configured, you can optionally configure the following routing criteria.

  • Warehouse

  • Company

  • Customer/Ship To

  • Carrier/Service

  • Rating ID

  • Container Class

  • Work Type

  • Username

  • Country

  • Machine Name/Workstation

  • Number of Copies

3. Routing Summary

The Routing Summary screen will enable you to review the document routing record for the selected printer record.

 

4. Edit Existing Document Routing

To update an existing routing record, select a printer from the Printer Selection step, review the selected routing record in Routing Summary, and then use Edit to update routing criteria values and save changes.
