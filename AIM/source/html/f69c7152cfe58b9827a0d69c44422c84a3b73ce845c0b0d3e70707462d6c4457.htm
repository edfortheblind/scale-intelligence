Labor Logging

The labor logging explains how labor activity is recorded in the application, with a focus on the Heel-To-Toe (HTT) approach used to ensure continuous tracking. Heel-To-Toe aligns the start time of each activity with the end time of the previous one, preventing unintentional gaps in logged labor.

Heel to Toe Logic

 

Heel-To-Toe (HTT) is the process by which the system determines whether consecutive labor records are close enough in time to be considered continuous work. When tasks occur within a defined threshold period, they are logged together, and no gap is recorded. This approach eliminates unintended time gaps between tasks, helping maintain an accurate and complete labor log.

  • Activity Heel to Toe Tolerance (minutes) is configured in Labor Group

Example:

  • Task A ends at 10:00 AM.

  • Task B is scheduled to begin at 10:05 AM.

  • If the Heel To Toe threshold is set to 10 minutes, Task B falls within this limit.

  • Heel To Toe adjusts the End time of Task A to 10:05 AM, aligning it with the start Time of Task B.

Note:

  • Heel-To-Toe logic is applied separately for each labor group.

  • if an employee switches labor groups within the Heel To Toe gap time, then the system always applies Heel to Toe based on the previous activity’s labor group.

 

Gap Time Tracking

 

The Gap activity is used to record any idle time or breaks between two of your work tasks.

The system will automatically log a Gap if there is too much time between when you finish one task and started the next one. This helps track any time that wasn't spent on specific warehouse activities.

 

When is a Gap recorded?

  • A Gap is added only if the time between tasks is longer than what’s allowed for your labor group.

  • This check happens when you start your next task by scanning (for example, scanning a work unit).

  • The system compares the time you ended your last task with the time you start the next one.

  • If the gap is too long, it records that time as a Gap.

 

Next Task Outside Threshold (Gap Inserted):

  • Task A ends at 10:00 AM.

  • Task B is scheduled to begin at 10:30 AM.

  • With a 10-minute Heel To Toe threshold, this 30-minute delay exceeds the acceptable range.

  • In this case, a gap activity is automatically inserted from 10:00 AM to 10:30 AM to indicate an unaccounted time block.

  • Task B retains its original 10:30 AM start time.

Extension of Time

 

When the time gap between two tasks falls within the Heel To Toe threshold, the system extends the end time of the earlier task to match the start time of the next. This maintains continuity and avoids logging a Gap.

 

Example:

  • Task A ends at 9:00 AM

  • Task B starts at 9:00:30 AM

  • If the Heel To Toe threshold is 1 minute, the system adjusts Task A’s end time to 9:00:30 AM, creating a continuous flow.
