Working With Packing Classes

A packing class determines which container type(s) the system can evaluate when determining how to pack items during container creation in the wave. You can also indicate on a packing class which items can pack together in the same container. Packing classes can be associated with an item on the Item Window, and also on an shipment line record.

 

The container creation wave step uses the packing classes to determine which containers can be used to pack certain items. This ensures that only the proper container types are used for specific items. Packing classes can be associated with an item or interfaced on a shipment line. The system will assign the *Default packing class record if one is not defined with the item/shipment line.

 

The system attempts to find the correct packing class using the following process. As soon as it finds a matching packing class record to use, it stops and selects that record:

  • If the packing class was defined on the shipment line record, the system uses this record.

  • If the packing class was defined on the item record, the system defaults it on the shipment line when that line is interfaced. Please note that the system will never override any value originally defined on the shipment line; therefore, if the packing class is defined on both the shipment line and the item record, the system honors the value defined on the shipment line.

  • If the packing class was not defined on either the shipment line or the item record, the system uses the *Default packing class record.

Procedures...

Create a new record, and provide a packing class name and description.

  1. Use the Container Group Field to identify the container type(s) that you want the system to reference during container creation in the wave. The system will evaluate the container type(s) in this group when attempting to pack item quantities.
     
  2. Use the Packing Criteria Field to determine which items the system will allow to be packed into the same container. This is helpful if you want to keep certain items from being packed with others that are going to a different destination. For example, if you are shipping to a distribution center that forwards items to a company's stores, users would not be allowed to pack items that are being shipped to different stores into the same container.
