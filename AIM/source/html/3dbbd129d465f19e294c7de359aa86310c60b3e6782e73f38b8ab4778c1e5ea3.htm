Creating Pallet Building Criteria Records

These criteria records are used to determine the eligibility of shipping containers for palletizing during the wave (using the pallet building wave step). You can also use these records to indicate to the system how to group the containers on certain pallets. Typically, you would make a separate criteria record for each item or set of items that you want to be placed on the same pallet. For example, perhaps you want different palletizing rules for separate beverage types (soda, alcohol, etc), or just beverages in general. Furthermore, maybe you want to create criteria that would have the system put onto separate pallets a certain store or company's containers. Typically, you will palletize only shipping containers that are assigned to LTL carriers.

 

 

Note On Packing Criteria And Pallet Building

Container creation packs loose items into shipping containers based on Packing Criteria. These loose containers may contain multiple items. Pallet building nests these containers onto pallets using pallet building criteria. Since the loose container may contain items with different values (e.g., item departments, item categories, and NMFC Code) pallet building will nest loose containers based on the first item in the loose container. For example, the following three items were packed into a loose container using item category as the packing criteria:

 

 

Item

 

Item Category

 

Item Department

 

NMFC Code

 
Corn Flakes Non-perishable Cereal 12345
Mixed Nuts Non-perishable Snacks 45984
Whole Wheat Bread Non-perishable Bread 89000

 

 

Since all three have the same item category (non-perishable), they get packed into the same loose container. However, the pallet building criteria is based on Item Department and NMFC Code. Each of these items has a different department and NMFC Code. In this scenario we would nest this loose container onto a cereal pallet because that is the first item in this container. Carefully configuring packing criteria and pallet building criteria to have the same rules should avoid this scenario. You would also need to be careful not to allow packing items into loose containers that should not be nested on the same pallet. A loose container with paper towels, paper plates, and drain cleaner probably should not be nested on the same pallet with food stuffs (bread, cereal, etc). Adding Item Category and NMFC Code to a Packing Criteria that only has Item Category would only pack containers that have the same Item Category, Item Department, and NMFC Code values. The same attributes would need configured in the Pallet Building Criteria.

Procedures...

Access the Pallet Building Criteria Window. Create a new record, and provide a name and description.

  1. Use the Filter Tab to indicate how you want the system to determine which shipping containers are eligible for palletizing using the pallet building wave step. For example, you could create separate rules where the system will only palletize containers from a certain customer, company, or item category. Furthermore, you could limit the containers chosen to ones that use an LTL carrier. Note that all these rules would be defined on a single criteria record.

  2. Use the Order By Tab to determine how you want the system to sort the shipping containers on a pallet. Use the Group Pallet Check box if you want the system to start a new pallet when this "order by" value changes (such as soda beverages and dairy products on a separate pallet).

    For example:

    - If you wanted to group the containers by store on each pallet, then you would create a rule with "Mark For" as the attribute, and select the Group Pallet Check box.

    - If you wanted to group the containers by type of item on each pallet, then you would create a rule with "NMFC Code" as the attribute, and select the Group Pallet Check box.

    - If you wanted to make sure a heavy container is not set on a lighter container, you would choose the shipping container "Weight" as the attribute, and NOT select the Group Pallet Check box. If this check box had been selected, only containers that included items with the same weight would be placed on a pallet. With it not selected, the system can mix weights on the pallet.

  3. Press OK, and the system will save your record.
