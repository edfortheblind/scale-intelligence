Defining Container Creation Criteria Records

A container creation criteria record defines which items/shipments you want the system to create containers for during the wave. You can also define a certain order in which the system will attempt to pack certain items. By default, during a wave, the system's container creation process will attempt to create containers for everything in that wave. However, there may be certain items/shipments that you do not wish to create containers for. Container creation criteria records help the container creation process selectively create containers only for the items/shipments that you choose.

 

 

Note On Container Creation and the Order in which Shipments are Packed Into Containers

By default, the system groups the shipment allocation requests sent to the container creation process by internal shipment number. The allocation requests in each group are then sorted based on the container creation criteria's order by. See the Container Creation in a Wave Process Summary: Process Flows for more detailed information on the container creation process.

 

For example, suppose there are three shipments with A0001, A0002, and A0003 as the shipment IDs. The container creation criteria has “Shipment ID ascending” defined as the order by. The expectation is that the container creation process would pack the containers for shipment A0001 first, then A0002, and finally A0003. Now assume the container creation process packs two containers for each shipment for a total of six containers. If packed in this order, A0001 would have container IDs [container ID 01] and [container ID 02]. A0002 would have [container ID 03] and [container ID 04]. A0003 would have [container ID 05] and [container ID 06]. This would be true if shipment A0001 was created first, followed by A0002 and then A0003.

 

Now, suppose A0003 was created first, and A0001 last. The container IDs will not be sequenced by shipment ID as expected. A0003 would have container IDs [container ID 01] and [container ID 02], while A0001 would have [container ID 05] and [container ID 06]. The reason for this is the container creation process first groups the shipment allocation requests by internal shipment number. Then the container creation criteria order by is applied to the allocation requests in each of these groups. This all assumes there is a single container creation thread. If there were two or more threads, then the container IDs may appear to follow no obvious order, as the container creation process would be packing containers for different shipments at the same time.

Procedures...

Access the Container Creation Criteria Window. Create a new record, provide a name and description.

  1. Using the Filter Data Tab: You can use this tab to define the criteria that you want the system to use when choosing the items/shipments to create containers for.
     
  2. Using the Order By Tab: You can use this tab to define the sequence by which the system will attempt to pack certain items.
     
  3. When finished, press OK. The system will save your criteria record.
