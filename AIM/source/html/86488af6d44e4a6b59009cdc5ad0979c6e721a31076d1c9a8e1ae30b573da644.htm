Labor Plan

A labor plan record specifies which labor group(s) should be processed during the labor plan execution wave step, as well as the order in which they are processed. Labor plans can be executed automatically within the wave.

 

Create Labor Plan

  • Labor Plan : Enter a unique name for your labor plan record.

  • Description: Provide a brief explanation of the labor plan.

  • Sequence Number: Define the order in which the labor groups assigned to this plan are processed during the wave execution.

Add New Sequence

  • Labor Group - Select the labor group for which the wave step will generate estimated labor data. Note that only one detail record can be created per labor group within a single plan.
