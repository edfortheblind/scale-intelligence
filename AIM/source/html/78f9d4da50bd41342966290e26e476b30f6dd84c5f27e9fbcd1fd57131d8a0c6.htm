Creating a Document Template

To print paperwork (non-label) documents, the system uses SSRS (.rdl) document templates. A template provides the structure (how the document will look), and what type of information it will display. The system comes shipped with several default documents, and you also have the freedom to create your own custom paperwork. Note that it is strongly recommended that you do not modify an existing template. Future releases may include template updates, which will override your modified template. Instead, copy an existing template and modify the copy.

 

 

 

SQL Server Reporting Services...

All SSRS document templates must be stored in the system document template directory. The default directory for SSRS document templates is the //ILS/Reporting/SSRS/ directory. Make sure that all templates that you create are stored in this directory. SSRS requires uploading the documents to SQL Server Reporting Services. The upload instructions can be found in the Database Installation Guide.
