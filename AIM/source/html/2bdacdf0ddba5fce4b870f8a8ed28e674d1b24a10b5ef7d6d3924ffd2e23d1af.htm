Processing Receipts

After a receipt is created/interfaced into the system, you can perform several actions on it. This work is done in the following screens: Receipt Workbench, Receipt Insight, Receipt Line Insight, and Receipt Container Insight.

 

Terminology Note
  • In the SCALE receiving module, the terms "receipt container" and "license plate" are synonymous. Therefore, both in the help and the application, these terms may be used interchangeably, and keep in mind that they both refer to the same entity.

Manually Creating a Container From the Receipt Insight...

When you check in product, the system generates a receipt container  to accommodate it. However, you can also manually create containers. A manually created container can hold different items and different UMs. You can also nest these containers. In addition, you can locate all of its contents together, even if they are different items/UMs.

  1. Access the Receipt Insight.

     

  2. Access the receipt for which you want to create this container.

  3. Select the New Container action. The system will display the Receipt Container Screen in new mode.

  4. Enter in the appropriate container information, and press the Save button when finished. The system will create the new receipt container.

 

 

 

Creating a Pre-Check In Container From the Receipt Insight...

A pre-check in container is a receipt container that is created before going through the check in process. These are helpful so you can quickly receive product into your warehouse by scanning a receipt container label (created for the pre-check in container) during the typical check in process. The system creates these containers based on the conversion quantity and the item dimensions specified on the item's unit of measure record. Note that pre-check in containers are also known as an ASN (Advanced Shipping Notice).

 

NOTE: You cannot create pre-check in containers in the following scenarios: At the receipt line level, or with parent/child container combinations.

  1. Open the Receipt Insight.

  2. Select a receipt and select the Create Pre-Check In Containers action.

  3. The system will prompt you asking if you are sure you want to create the pre-check in containers:

    If you choose Yes, the system will create a pre-check in container for each receipt line. Note that if your receiving preferences are configured to "Verify Item Unit of Measure", then the system will prompt you to confirm the unit(s) of measure before creating the pre-check in containers.

    If you choose No, the system will not create any pre-check in containers.

 

 

 

Assigning Trailer ID's To A Receipt From the Receipt Insight...

You can quickly assign a trailer ID to a single receipt or multiple receipts. This can allow you to "consolidate" receipts without truly consolidating them in the database. Note that if a receipt is assigned to a trailer ID that has already been checked in through yard management, that trailer ID cannot be changed until the trailer ID has been checked out of yard management.

  1. Access the Receipt Insight.

  2. Select the appropriate receipt(s) and press the Assign Trailer ID action.

  3. Enter the new trailer ID and press Save. The system will assign the new trailer ID to the receipt(s). Note that the existing trailer ID(s) will be overwritten.

 

 

 

Canceling a Receipt Container From the Receipt Container Insight...

You can cancel receipt containers if they are in a “Check-in Pending” status. When you cancel a container, the system will perform three actions: change the container status to 900, change the container quantity to 0, and subtract the quantity from the “pre-receive” inventory location. Note that if a parent container is in "check-in pending" status, canceling it will cancel all of the child containers. If the status of any one of the child containers is greater than "check in pending," then the parent container status will not be "check in pending" and therefore you will not be able to cancel the parent container.

  1. Access the Receipt Container Insight.

  2. Select a receipt container, and choose the Cancel action.

  3. The system will display a confirmation message asking if you are want to delete this container. Press Yes, and the system will delete the container from the receipt.

 

 

 

Deleting a Receipt Container From the Receipt Container Insight...

You can delete receipt containers whether they have been checked in or they are still in a check in pending status. When a container is deleted, the system removes it from the receipt container table but it remains tied to the receipt in the database. You cannot delete receipt containers that are in a Closed (900) status. Note that the system places deleted ASN (pre check in) into the DELETED_RECEIPT_CONTAINER database table (just like regular deleted receipt containers).

  1. Access the Receipt Container Insight.

  2. Select a receipt container and choose the Delete option.

  3. The system will display a confirmation message asking if you are want to delete this container. Press Yes, and the system will delete the container from the receipt.

 

 

 

Printing Receipt-Related Paperwork...

You can print paperwork documents for receipts/receipt containers from the appropriate receipt processing screen. Note that you can print receipt container paperwork in all statuses except closed. In addition, if a document type has both the Receipt Container and Pre-Check in Receipt Container print procedures defined as a default, then the system will print duplicate labels during the pre-check in process and the check in process.

  1. Access the Receipt Insight or Receipt Container Insight.

  2. Select the appropriate receipt, and choose the Print Default Docs or Print Selected Docs action.

  3. If you chose the default action, the system will submit the document(s) for printing.

    If you chose the selected action, the system will open a prompt so you can choose which document(s) you want to print.
