Auto Print at Close Buttons

You can use these fields to indicate if the system will automatically print selected packing documents when you close the container.

 

The valid values are:

  • Y - The system will automatically print the packing documents. When the user selects the Close button, the system will print the documents. The system navigates back to the Close Container Screen. It does not display the Print Documents Screen.

  • N - The system will not automatically print the packing documents. When the user selects the Close button, the system will not print the selected documents. The system navigates back to the Close Container Screen. It does not display the Print Documents Screen. The packer can access the window by selecting the Print button on the Packing Screen.

  • Prompt - The system will display the Print Documents Screen. When the user selects the Close button, the system will display the Print Documents Screen. The user will verify that he/she wants to print particular documents. After the user selects the Print button, the system navigates back to the Close Container Screen.
