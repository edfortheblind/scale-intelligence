Setup Overviews: Inbound

Below are lists of the setup procedures required to use the inbound functional areas.

 

 

Receiving

  1. Create initiation workflow records
  2. Review the locating strategies
  3. Review the receiving system values
  4. Define location selection records
  5. Define locating rules
  6. Associate locating rules with the appropriate items
  7. Review the default locating rule
  8. Define item location capacity records
  9. Establish vendors
  10. Define the receipt types that you expect to receive in your warehouse
  11. Activate the header fields for the RF blind receiving screen
  12. Create disposition codes.
  13. Define the receiving preferences
  14. Use delayed locating.

 

 

Returns

  1. Address miscellaneous setup prerequisites
  2. Create putaway location groups
  3. Create disposition codes

 

 

Inbound Quality Control

  1. Activate inbound quality control
  2. Make items eligible for inbound quality control
  3. Define the default inbound quality control inventory status
  4. Create inbound quality control locations
