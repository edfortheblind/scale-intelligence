Item Balance Touchpoint

Item balance data can be uploaded from SCALE to your ERP via the system interface. This allows you to reconcile the current item quantities in your warehouse with the ERP's item master table. This is helpful so your ERP has a current and accurate listing of the items in your warehouse and how many are available.

General Guidelines...

  • In order to gather the item balance data, the system:

    1) Groups all location inventory records by warehouse, item, company, and inventory status.

    2) Excludes the records that are associated to a location classes that are not defined to be included in item balance uploads.

    3) Summarizes the quantity buckets across the remaining records in the group.

    4) Checks to see if the Include Zero On Hand Items flag is on. If so, then the system cycles through the item master and adds a record for each item/company that is not yet represented in the upload.

    5) Writes the information to the upload table/delimited output file.
     
  • Serial number information is included in item balance uploads.

 

 

Catch Weight Fields (XML Upload Only)

 

  • CatchWeight and CatchWeightUM are available only when the upload output method is XML.

 

Rejection Causes / Validations / Notes...

  • The SCALE interface process does not support using a comma as a "seperator" for numeric values. These values will need to be interfaced into the system using decimals as seperators (4.95, not 4,95). The system can, however, display these values with a comma seperator on SCALE windows, but in the database they must be in a decimal format.
