Maximum Weight Field

On the Work Creation Master...

This field indicates the most weight that can be processed in a particular wave or work unit. The work creation process will start a new work unit when it senses that adding the next work instruction to the current work unit will exceed this maximum value. Note that if a single work instruction in and of itself exceeds this maximum, the instruction will be placed onto a work unit by itself. It will NOT be broken down into multiple work instructions.

 

The weight is always calculated as the base unit of measure quantity (example: eaches) multiplied by the weight of the item, regardless of whether the quantity is sufficient to make a higher unit of measure (such as a case or pallet) or not.

 

For example:

  • Suppose the Maximum Weight value is set to 100 pounds on the shipment allocation work creation master record.

  • The shipment has four details (item 1 = 60 pounds, item 2 = 40 pounds, item 3 =30 pounds, item 4 = 80 pounds).

  • The first item will get added to the first work unit (weight=60). The system will not break the detail.

  • The second item will get added to the second work unit (weight= 100). The system will not break the detail.

  • The third item will get added to the third work unit (weight=30). The system will not break the detail.

  • The fourth item will NOT get added to the third work unit, because it would exceed the maximum weight value (volume would equal 110). Therefore, the fourth item will get added to the fourth work unit.

 

On Weight Break Window...

This field is used as part of the rate base to define the weight breaks used for LTL internal rating. The system will look at the shipment weight and compare it to the weight in these fields (the weight breaks) to obtain the rate per pound. The last record must have an entry of all 99999's to maximize the field and catch all weights. This field is defined on the Weight Break configuration and then used as part of the Rate Base table.
