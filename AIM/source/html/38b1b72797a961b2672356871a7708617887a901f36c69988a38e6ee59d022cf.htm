From Assign Method Field

This field determines how work units will be assigned during system-directed work initiation. This allows you to manage the movement of product from storage locations.

 

There are three possible choices:

  • Location/Priority/FIFO - Work is assigned based in location proximity order: the location closest to the user is assigned first. This minimizes travel time. Please note that the system only recognizes number proximity in ascending order. In other words, if location 999-999-999 is physically next to 001-001-001, the system cannot recognize the distance between the locations.

     

    If multiple pick instructions share the same location, the system will assign the instructions in priority order: the lower the priority number, the sooner the instruction is assigned.

     

    If multiple pick instructions share the same location and priority, the system will assign the instruction in FIFO order. The first instruction generated during work creation is assigned first.



  • Priority/Location/FIFO - Work is assigned in priority order: the lower the priority, the sooner the work is assigned. This is commonly used to ensure that critical customers are processed first.

     

    If the multiple pick instructions share the same priority, the system will assign the instructions in location order: the location closest to the user is assigned first. This minimizes travel time.

     

    If multiple pick instructions share the same priority and location, the system will assign the instructions in FIFO. The first instruction generated during work creation is assigned first.



  • FIFO - All work is assigned in the First In, First Out order. The first instruction generated during work creation is assigned first.
