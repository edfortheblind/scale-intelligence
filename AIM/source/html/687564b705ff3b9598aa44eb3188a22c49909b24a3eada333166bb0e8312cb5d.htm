Reviewing the SSRS File Name Record IDs Configuration Records

Printing with a configured record ID for the document type saves the SSRS document file name with the document type identifier, record ID based on document type, and GUID (e.g., <Document Type Identifier>_<Shipment ID>_<GUID>.pdf). You can review all the record IDs for the shipped SSRS document types in order to find all the documents for a specific shipment, receipt, or work order, and so on.

SSRS File Name Record IDs field

 

 

 

Each SSRS document type will be defaulted with a record ID from this list. These record IDs are used to determine what record id to include when creating the SSRS pdf file name. One exception to this is the All Bills of Lading document type. The record ID on All Bills of Lading document type is blank. Since the All Bill of Ladings document type prints both the Master Bill of Lading and Bill of Ladings the record IDs from those documents are used when creating the file names.

 

Each configuration detail record has a system defined value for record ID and report parameter. The record ID value must be in the format TABLE_NAME.COLUMN_NAME and report parameter format would be COLUMN_NAME. The report parameter must be the key for the record ID's table.

 

For example, the record for ShipmentHeader.ShipmentId would have the record ID as SHIPMENT_HEADER.SHIPMENT_ID and report parameter as INTERNAL_SHIPMENT_NUM.
