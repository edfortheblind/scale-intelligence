Setup Overviews: Inventory

Below are lists of the setup procedures required to use the inventory functional areas.

 

 

Cycle Counting

Plan-Based Cycle Counting
  1. Define the cycle count system values
  2. Create a cycle count preference record
  3. Create a cycle count item criteria record
  4. Create a cycle count location criteria record
  5. Create a cycle count work criteria record
  6. Create a cycle count master record
  7. Define any work special handling constraints for the cycle count work
  8. Define cycle count request filter records

 

Non-Plan Based [Activity-Driven] Cycle Counting
  1. Define the cycle count system values
  2. Create a cycle count preference record
  3. Create a cycle count threshold record
  4. Define any work special handling constraints for the cycle count work
  5. Define cycle count request filter records

 

 

Inventory Management

Without Work...
  1. Review the available inventory control values
  2. Review the available inventory statuses
  3. Activate inventory tracking on an item
  4. Define adjustment type records

 

With Work...
  1. Review the available inventory control values
  2. Review the available inventory statuses
  3. Activate inventory tracking on an item
  4. Define adjustment type records
  5. Define inventory adjustment/ transfer work criteria.
  6. Define inventory adjustment/ transfer work creation master.

 

 

Item Setup

  1. Define item templates
  2. Define item classes
  3. Create movement classes
  4. Define items
  5. Define an item cross-reference
  6. Create a storage template
  7. Define an item's unit of measures
  8. Change an item UM conversion quantity
  9. Create item categories
  10. Review harmonized code records
  11. Add a hazardous code to an item
  12. Create pre-defined inventory attribute values
  13. Activate inventory attribute validation

 

 

Location Setup

  1. Define zones
  2. Review location classes
  3. Review location statuses
  4. Determine if users will create locations on the fly or only on the Location Window (system location validation)
  5. Create location templates
  6. Create location types
  7. Create movement classes
  8. Define locations
    1. Define P&D locations
  9. Define each item's location capacity
  10. Assign a permanent location to an item

 

 

Lot Setup

  1. Creating Lot Templates

 

 

Movement Class Analysis

  1. Creating movement classes

 

 

Replenishment

Basic Replenishment...
  1. Review the replenishment strategies
  2. Review the replenishment types
  3. Define when the system will check to determine if replenishment should occur:
    • To define replenishment needs for items in a wave or a pool
    • To define replenishment needs for locations in the warehouse
  4. Define a location's item capacity
  5. Identify new locations for replenishment
  6. Define when a replenishment should occur for a location
  7. Define the replenishment master records

 

Real Time Replenishment...
  1. Activate real time replenishment for a location
  2. Define a replenishment master record using real time mode
  3. Define item location capacity for a location
  4. Schedule a real time replenishment job

 

 

Rule Set Assignment

  1. Choose locating (inbound) or allocating (outbound) rules on the item master
  2. Add rule set assignment to a wave flow
  3. Create a rule set criteria record
  4. Create a rule set assignment record

 

 

Serial Number

- Notes On Serial Number Archiving

  1. Define a template for your item's serial number(s)

 

 

Work Order

  1. Define work order preferences
  2. Identify the components required to make the finished item (bill of materials)
  3. Review work order system values
  4. Create work criteria records (if you want work creation to manage component part allocation)
  5. Create work criteria records (if you want work creation to manage finished item putaway)
