Using the Putwall Insight Screen

You can use the Putwall Insight Screen to search and manage putwall location records in the application. This screen enables user to view the putwall locations that are ready to be cleared and the ones which are empty.

The putwall sort records that are ready for sorting, the row will be highlighted in Green color.

Searching/Viewing Work Records...

You can use the Putwall Insight Screen to search for and view work records in your warehouse.

  1. Open the Putwall Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

About the List Pane...

  • The Putwall Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

About the Detail Pane...

  • The Putwall Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

  • For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

Screen Actions...

The following actions are accessible from the List Pane:

 

Pack

This action enables you to pack the putwall items that have been sorted by shipment. The Pack option is disabled when shipment is sorted and sort completed is not completed.

 

procedure

  • In the Putwall insight screen
  • Select a record and Actions >> Pack
  • System will navigate to Packing screen.
    • If the packing initiation is set to Putwall location, the packing screen will automatically populate the Putwall location of the selected record.
    • If the packing initiation is not set to putwall location , the packing screen will be displayed with no putwall location. Enter the putwall location.
  • Complete the packing of the shipment and close the container.
  • Putwall location will be cleared.
Clear

This actions enables user to force sort and clear a putwall location. Clear actions is security permission controlled.

Clear actions can be performed on both shipment and container work.

 

Procedure

  • In the Putwall insight screen.
  • Select a record in Storage status and Actions >>Clear.
  • System will prompt user with System will mark the quantity as sorted and Putwall location will be cleared. Do you want to proceed?
  • Click Yes and a successful message indicating the selected tote quantity has been marked as sorted and the putwall location is cleared.
