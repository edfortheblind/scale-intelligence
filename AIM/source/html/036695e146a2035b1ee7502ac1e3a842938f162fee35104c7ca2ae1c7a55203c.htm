Zone Type Field

A zone type identifies the purpose of a zone. These are predefined in the system. A zone can be associated with multiple zones.

 

The system supports the following zone types:

 

Allocating

Use this zone type to establish the different location groups that you want to move product from. When the system runs the allocation plan, it will search the Picking Rule Sets to determine which allocation zones to process.

 

Locating

Use this zone type to establish the different location groups that you want the system to move product to. For example, many warehouse establish one zone for locating loose picks and another for locating bulk picks.

 

Work

Use this zone type to assign teams to particular locations. Configure the warehouse so each section requiring different equipment or picking constraints is a unique zone. Since teams work specific zones, this ensures that the appropriate resources are used in each zone.
