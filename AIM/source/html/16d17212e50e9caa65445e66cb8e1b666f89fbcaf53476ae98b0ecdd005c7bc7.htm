Making Items Eligible for Inbound Quality Control

These settings determine if an item is eligible for the inbound quality control process. If the item is eligible, then the system will suggest splitting off a portion of the item quantity received, if appropriate. You can establish how much of this receipt's item quantity will be sent to inbound quality control, and to which inbound quality control location the system will send it to.

 

 

Procedures...

  1. Access the Item Window open the appropriate item record, and select the Handling Tab.
     
  2. Use the Eligible Checkbox to indicate that an item is eligible for the inbound quality control process. If an item is not QC eligible, the system will not attempt to route any of this item to quality control.
     
  3. Use the Compute Qty As Buttons to determine how much quantity of an item should be routed to quality control:

    Amount:Choose this method when you want the system to route a certain number of items (per receipt) to quality control. When choosing to compute by amount, you also need to indicate the UM the system is to use when calculating the item quantity.

    For example, suppose you have a receipt that has 50 eaches of item AA001. If you enter the value "5" into this field (and "each" as a UM), the system will route five eaches from the original 50 to a quality control location. The system will locate the remaining 45 eaches of this item in an inventory location (according to the locating rule assigned to this item).

    Percentage: Choose this method when you want the system to route a certain percentage of items (per receipt) to quality control. You do not need to indicate a UM when the system is calculating the item quantity by a percentage.

    For example, suppose you have a receipt that has 50 eaches of item AA001. If you enter the value "20" into this field, the system will route 20 percent of this item (10 eaches) from the original 50 to a quality control location. The system will locate the remaining 45 eaches of this item in an inventory location (according to the locating rule assigned to this item).
     
  4. Use the Inspection Qty Field to enter the actual amount/percentage you want the system to set aside for quality control. Do not use a percentage sign (%) to indicate percentages. For example, you would enter the value 20 percent as "20".
     
  5. Use the UM Field to indicate the unit of measure that you want the system to use when calculating how much of an item to route to quality control. If this field is blank, the system will convert the item quantity to the lowest UM (as defined in the Quantity Units Of Measure Window).
     
  6. Use the Locating Rule Field to indicate how the system will decide which QC location to move the appropriate item quantity to. See the topic "Creating QC Locations" for more information.
     
  7. Press OK The system will save your changes.
