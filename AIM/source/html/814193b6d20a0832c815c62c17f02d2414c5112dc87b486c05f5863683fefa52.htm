Rating Service Configuration

Overview

A rating service specifies a carrier and service combination. Progistics uses this information to determine the appropriate rate based on the selected carrier and service. For SCALE Less Than Truckload (LTL) internal rating, this configuration displays the rating ID and server symbol being used. Note that rating services are not required for internal LTL rating.

 

Configure Rating Service

  • Rating Service - Select to identify the service. To minimize confusion, be sure to include the carrier's name in this field, because several carriers may have the same names for certain services they offer.

  • Use the Rating ID to identify the carrier who offers this service..

  • Use the Service Symbol to identify this carrier/service combination.
