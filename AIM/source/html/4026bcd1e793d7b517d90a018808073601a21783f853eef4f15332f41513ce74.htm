Container Picking Method Field

This field indicates what type of RF pick/pack functionality, if any, that you want users of this work profile to perform:

  • Pick Into Shipping Container: Choose this option if you want users to be able to directly pick into the final shipping container.

     
  • Pick Into Tote: Choose this option if you want users to be able to directly pick into a transport container, a.k.a. a "tote."

     
  • None: Choose this option if you want users not to use the RF pick/pack functionality.
