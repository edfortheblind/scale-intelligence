Using the Lot Update Confirmation Screen

The system will display this screen any time you want to change or update a lot. For example, if you are positively adjusting inventory into a location, and you need to change the expiration date of a lot, the system will display this screen allowing you to confirm your change. You can also view what locations or containers that will be affected by this change.

 

The Lot Update Confirmation Screen will appear (during receipt check-in, inventory adjustments, and using the Lot Insight) when you perform an action to an item quantity that is associated with a lot that already exists in warehouse inventory. If you perform an action to an item quantity where you are introducing a new lot to the warehouse, the system will display the Lot Screen.

Procedures....

  1. Review the lot information on the Lot Info tab.

  2. Review the inventory in your warehouse that will be affected by this lot change on the Affected Inventory tab.

  3. Review/change any user defined data values on the User Defined tab.

  4. Press the Save button to apply these lot changes to the inventory. Press the Cancel Button to not proceed with the changes.
