Warehouse Mobile - Override Pick

The Warehouse Mobile - Override Pick options can be selected during the picking process. Override Pick can be performed for outbound (allocation and shipping container) work, replenishment and inventory transfer work.

 

Topics Discussed

  • License Plate
  • Location
  • Lot
  • Override Notes

License Plate

Users can override the license plate from which they are going to pick if the license plate override is active on the work special handling record. The user would scan a different LP value (than the one currently assigned to the work instruction) in the LP field, and the system will treat this as an override of the original LP value.

 

To override the license plate,

  • Enable the Override pick security.
  • Work Special Handling
    • Override
    • Verification - License Plate selected.

The following is supported while overriding the license plate

 

Override license plates with different quantities at the same location (inline) or different location is supported for the following options in

  • work special handling

    • Allow override to different quantity

    • Container verify

  • Work Profile

    • Group picks by loc/LP

System will prompt to scan the location and scan the license plate when no locations or license plates have the available quantity, and there is another location and license plate have a sufficient allocated quantity to swap for override.

 

When Container verify is checked on work special handling and container creation and pallet building in the wave, then during override, system will prompt the user to verify the Pallet ID and nested container ID when overriding the license plate to the same or different location.

 

Location

Users can override the pick location from which they are going to pick the product if location override is active on your work special handling record. The user would scan a different location ID (than the one currently assigned to the work instruction) in the Location field, and the system will consider this as an override of the original location value.

 

For override location,

  • Enable the Override pick security.
  • Work Special Handling - Override - Locations and Lot selected.
Perform an override pick
  1. In the Pick Confirmation screen, select Actions >> Override.
  2. The system will prompt the user with an available list of locations to override. Select the location and tap Go.
  3. Optionally, the user can also enter the location that is not displayed in the list and tap Go.
Override to Location not on the list

Users can scan a location that is not part of the location list for selection.

  • In the Override Location screen, scan/enter the new location which is not part of the list.
  • Pick Confirmation screen displays the new location scan/entered.

Note:

  • The list of eligible locations is based on the Work System Value - Number of locations to display on the Override Pick configuration.

  • System allows override location when the original location has over allocated inventory. This happens only when the override location has sufficient available quantity to fulfill the original quantity.

  • override the original pick location for outbound serial number tracked items, enabling fulfillment from alternate locations.

Override Pick with Short Pick

Users can perform a short pick after initiating an Override pick.

  1. In the Pick Confirmation screen, select Actions >> Override.
  2. Select the overriding location and tap Go.
  3. Tap the arrow and select Short Pick.
  4. Enter the pick quantity value and tap Go. The Go button will be disabled if the entered quantity is more than the pick quantity or when no value is entered.
  5. The quantity entered for the short pick is now updated in the Pick Confirmation screen. Tap Go to complete the picking process.
Override Pick with Partial Pick

Users can perform the short pick after initiating the Override pick.

  1. In the Pick Confirmation screen, select Actions >> Override
  2. Select the overriding location and tap Go.
  3. Tap the arrow and select Partial Pick.
  4. Enter the pick quantity value and tap Go. The Go button will be disabled if the entered quantity is more than the pick quantity or when no value is entered.
  5. The quantity entered for the partial pick is now updated in the Pick Confirmation screen. Tap Go to complete the picking process. Note: This option will not be available if the user does not have security permission or quantity verification is turned on.

Lot

Users can override the lot ID of the item they are going to pick if the lot and location override is active on your work special handling record. When overriding a location, the user can choose a same location or different location with the same lot or different lot.

We can override using the cart picking, user directed, and system directed initiation methods.

 

Perform on override pick for same or different Lot

  1. In the Pick Confirmation screen, select Actions >> Override.
  2. In the Override Location screen, system displays the item, location and lot details. Swipe to see the list of locations available.
  3. Select the location and tap Go.

When overriding lot at same location, then system supports

  • Replenishment work with Group by picks loc/LP checked and override lot has available quantity only.

  • Shipping container work for full unit of measure containers only with Group by picks loc/LP checked and override lot has available quantity only.

  • Shipping container work for full unit of measure containers only with Group by picks loc/LP checked and override lot has partially allocated and fully allocated quantity only.

Notes

  • Override lot with outbound serial-number-tracked item at the same or different location.

  • Override lot with cart picking at a different location.

  • Override non-License Plate tracked location with License Plate tracked location.

  • Override License Plate tracked location with non-License Plate tracked location.

  • Override license plate with item verification, at the same or different location.

 

Override Notes

  • Override action can be invoked from the Item, Lot, check digit and Quantity verification screen during a pick.
  • Override pick is supported with replenishment work and inventory transfer work.
  • Partial and Short pick can be performed after an override pick.
  • System displays the converted Unit of Measure (UM) on the Override location and Override license plate screen when Use Converted qty is selected in Work Special Handling.
  • The system prompts a confirmation message to override values to complete the picking process. Note: This prompt is displayed if you have the location/lot/LP override selected in the Work special Handling configuration.
  • During cart picking, users can override group picks for same or different lot. For example, 2 work instructions for same item/location with two different shipments. The work unit and container labels will be displayed as Multiple in such a scenario.
  • When override is performed, then the location inventory, work instructions, and relevant records are updated to reflect the override license plate/lot/location.
