Automatic Replenishment (in Wave)

Automatic replenishment is a step in the wave flow. You can add replenishment to a wave flow in the Wave Step Window. When the system runs automatic replenishment, the system retrieves all of the replenishment masters that are selected on the Wave Master you are using. Note that if you do not use a wave master, and are running automatic replenishment in the wave, the system will run all eligible replenishment masters.

 

 

Notes...

  • You can use the Immediate Execution Checkbox (on the Replenishment Master Window) if you want to execute replenishment requests without creating work. When in immediate execution mode, you can define the wave step to also have the system generate a Replenishment Pick List when it runs a replenishment master. This document contains every request for a particular replenishment master. For more information, see the topic Defining Replenishment Master Records.

  • If you want to create work for replenishment requests created in the wave, you need to include the "Work Creation: Replenishment" wave step in your flow.
