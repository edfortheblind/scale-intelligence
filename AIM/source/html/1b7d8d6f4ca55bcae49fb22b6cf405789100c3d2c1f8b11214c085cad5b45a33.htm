Multi-Language Support Process Summary

** Functionality **

 

 

Summary...

SCALE can support multiple languages other than the base language of English. This can be configured at the network user level so that each warehouse employee can work with the system in the language that they speak.

 

 

 

Related Topics...

- Setup Overview

- Deploying Non English Help

- Using the Translation Wizard

 

 

 

The following are key features of the multi-language support functional area:

 

Resource Files...

Resource files determine what text the system displays on application windows. In order to view the system in multiple languages, you first will need to acquire a translated version of the resource files (if they are not already available in the system). You will need to have these files (which use a *.trp extension) translated to the appropriate language in order for the system to display text in this language. You can use the System Text Editor's Translation Wizard to import/export resources values to/from the system, and then translate these resources yourself manually, or outsource them to a translation vendor.

 

The language that the system chooses to use is governed by a setting on the current user's Microsoft Windows operating system regional setting (in the Control Panel). SCALE will use the resource file for the language that the operating system is currently using to display text.

 

 

 

Language Change on Server-Client Machine...

When you implement a language change on a server or client machine, all screens accessed from the remote desktop system menu (such as configurations, etc) will display this new language in field names, window titles, system-supplied records, error messages, and any other text that the system generates. The language used by the application is determined by the Windows user's language setting, NOT by a setting in SCALE. Therefore, you can have users who speaking different languages using the same system application server. For all other screens, the language used by the application is determined by your internet browser's language.

 

 

 

Language Change on RF Devices...

When you implement a language change on an RF device, all the RF screens will display this new language in field names, window titles, error messages, and any other text that the system generates. You can change the language that the system uses to display text on the RF device on the device itself, regardless of what language setting is currently being used on the SCALE application server.

 

 

 

Language Change on TPM Website...

When you implement a language change on the TPM website, all web screens will display this new language in field names, window titles, error messages, and any other text that the system generates. A web user, however, cannot change the language that the system uses to display text on web screens. TPM uses the language setting that is defined on the server (via the Web User Window) which hosts the website.

 

 

 

Online Help System...

The application was built to allow you to use multiple versions of the help system as well. Currently, Manhattan ships the system with an English version of the help system. To obtain another language's version of the help (if not already available with the system), you must work with your consultant to get the help topics translated into your desired language. Usually this would be done by outsourcing this to an outside translation company.

 

When a user accesses the system online help, the system will check to see what language is defined on the regional settings of their Windows network user. It then checks to see if this user's defined language (say it is Spanish) has a help folder that corresponds with it. This Spanish help folder (located in the help directory on the system application server) would be titled with the Spanish language code ("es-MX"). If the system finds that folder, it will display the "Spanish-Mexico" translated help system. If it does not find this folder, the system will load the "base" help system files, which will typically be the English language files.

 

 

 

Translation Wizard...

You can use the Translation Wizard to assist you in implementing language translations with SCALE. The wizard's screens help you perform actions that are related to translating SCALE resources into different languages, such as export/import resource values to/from the SCALE database, and copy existing values to a spreadsheet in order to create a new language file. You can access the Translation Wizard from the System Text Editor Window.
