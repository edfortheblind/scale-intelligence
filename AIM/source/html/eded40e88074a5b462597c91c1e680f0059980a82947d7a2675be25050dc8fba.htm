Entering a Web Shipment

You can enter a shipment into the system from Trading Partner Management. When you enter shipment data into TPM, the system will create a receipt record in SCALE. This is then processed in SCALE like a typical receipt. Trading Partner Management also allows you to create shipments from the Purchase Order Management screen. When you enter a shipment from P.O. Management, TPM will default purchase order data into the appropriate fields on the shipment entry screen.

 

NOTE: Remember that "shipments" in TPM become "receipts" when they enter SCALE.

Procedures...

Log into Trading Partner Management. Choose the Shipment Entry option from the Main Menu. The system will display the Web Shipment Entry screen.

 

Step 1: Shipment Lines

You will use this section to indicate the item(s) and their quantity that you want to add to your shipment.

  1. In the Shipment Line section, click the Add Button. The system will display the search criteria screen.

     

  2. Enter the item information. Press the Search Button. The system will display the item(s) that matches your criteria.
     

  3. Enter the Net and/or List Price for the item you want to add. Note that these values override this item's price values that may be defined in the system. Also, these values are tracked through the system after this item is located, and later allocated, for a SCALE shipment.

     

  4. Enter the quantity of the item(s) that you want to add. If the item is lot controlled, you may be required to also enter the lot value (depending on your business practices).
     

  5. Press the Add Items Button. The system will add the item quantity to the shipment line section of the Web Shipment Entry Window.

     

    NOTE: If you check the Delete Checkbox and press the Delete Button, the system will remove the item quantity from your shipment.
     

 

Step 2: Origins

You will use this section to indicate the ship from address(es) for your shipment.

  1. In the Origin section, click the Add Button. The system will display the search criteria screen.

     

  2. Enter the pertinent ship from information. Press the Search Button. The system will display the addresses that match your criteria

    OR

    Enter a new vendor in the name/address fields located below the Ship From Field. When finished, proceed to step 3 of this topic.
     
  3. Choose the ship from addresses that you want to associate with your shipment by selecting the checkbox next to the address.
     
  4. Enter the email address if appropriate.
     

  5. Press the Add Ship From's Button. The system will add the addresses to the Destination section of the Web Shipment Entry Window.

     

    NOTE: If you check the Delete Checkbox and press the Delete Button, the system will remove the ship to address from your shipment.

 

Step 3: Warehouse

You will use this section to indicate the warehouse where you want this shipment's items to be shipped to.

  1. In the Warehouse section, select the warehouse where you want your shipment shipped.

     

 

Step 4: Shipment ID & Shipment Type

You will use this section to indicate the name and type of shipment you want to create. This step is optional, as the system will default values for these fields if they are left blank.

  1. In the Shipment ID Field, enter the name you want to give to this shipment. When the system creates this shipment, it will add a prefix to this ID. This value is defined on the Receiving System Values Window. .
     
  2. In the Shipment Type Field, indicate the type of shipment you want to create.
     

 

Finishing Your Web Shipment
  • Press the Verify Shipment Button and the system will display a confirmation screen with your shipment information. If all the information is correct, you can press the Submit Shipment Button. The system will then create the shipment in the application.

    In the verification window, you can press the Modify Shipment Button to return to the shipment entry screen to edit any of the value(s) you provided.
