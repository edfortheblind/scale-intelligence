Creating Storage Templates

A storage template identifies all the units of measure that are associated with a general category of items. For example, a storage template is created to group together units of measure used for liquid products. Conversely, a storage template would also be created for solid products. A unit of measure can be shared across multiple storage templates. After you create a storage template, you will need to associate it with the correct items and UM values. If you do not, the system will apply the default template to the items and UM values. When defining a storage template, you should go from the smallest UM to the largest UM.

 

WARNING: If you change the storage template on an item to one that has a different base unit of measure, the system will change the UM on all related data, such as existing inventory, open shipments, and open receipts.

Using the Storage Template Header Window
  • Use the Name Field to identify this record. Use the Description Field to provide a description for the name. Select the Apply Button. The system will add the record. It will leave the window open. Select the New Action to access the Storage Template Detail Window. You will use this detail window to define the sequences.

 

Using the Storage Template Detail Window

 

The header will default the template name that you defined on the Storage Template Window.

  1. Use the UM Field to identify the UM value Select the appropriate measure from the UM Field. Note that once you assign a quantity UM value to detail record and save it, you can no longer edit this value. You will need to delete the record and create a new one.

     

  2. The system will automatically assign the Sequence Number 1 to the first detail that you add. The sequence number determines how the records are organized. The lower the sequence number, the smaller the unit of measure. Make sure that the UMs are defined in ascending order.

    Note that if you change the sequence when adding a new record, the system will only set the sequence number to one number higher than the highest value currently in your record list. For example, suppose you already have sequences "1" and "2" defined, and you change the sequence on the record you want to add to a "5". The system will still add the record with a sequence number of "3". Furthermore, if you try to insert a new record in between two existing steps (i.e., numbers "1" and "2"), the system would renumber the existing step "2" as "3", and the new step would be assigned the number "2."

     

  3. Use the Treat as Full Percent Field to indicate the percentage of an item quantity that the system will consider a "full" unit of measure, IF the system is attempting to allocate the complete quantity for a location/license plate. If the quantity is above the defined Treat As Full Percent value, then the system will treat that quantity as the next higher unit of measure (e.g., a case or pallet).

    For example, suppose the following:
    - The "full" quantity for the pallet unit of measure is defined as 100 EA
    - The Treat as Full Percent setting is defined at 50%
    - There is a quantity of 80 EA currently at the location

    Therefore, an allocation of 80 EA would be considered a "full" pallet allocation. However, an allocation of 79 EA would not.

     

  4. Use the Group During Check In Checkbox to indicate if containers for this UM should be checked in as one receipt container or as separate receipt containers. During locating, these groupings are located together to the same location.

    NOTE: This setting functions the same for pre-check in receipt containers as it does for receipt containers created during the check in process.

     

  5. To define additional sequence values, select the New Action. The Sequence Field will contain the value 2.
