Establishing Packing Preferences

A packing preference record allows you to manage how a user or group of users will pack shipments. These actions are primarily done in the Packing Screen or the Close Container Screen (desktop or RF). You can create specific preference records for employees with unique packing processing needs.

Procedures...

Access the Packing Preferences Window. Create a new record and provide a description.

 

Using the Packing Tab
  1. Use the Initiation Field to select the initiation value. When a user associated with this record accesses the Packing Screen, the system will require him/her to identify the shipment using this value. Commonly used initiation values include the shipment number, ERP order number, and the invoice number.

  2. Use the Packing Work Type Field to indicate the work type that you want to associate with the packing action, since the system creates no work instructions for packing (and therefore no work type would be assigned). The system uses this work type for labor tracking..

  3. Use the Workbench - Verify Item Work Type Field to indicate the work type that you want to associate with the verify item functionality in the Shipping Container Workbench, since the system creates no work instructions for this action (and therefore no work type would be assigned). The system uses this work type for labor tracking.

  4. Use the VAS Work Type Field to indicate the work type associated with confirming a VAS activity in the VAS Container: Insight Screen. This value is used by the system when logging labor requests, and is needed since there are no work instructions created for confirming VAS activities.

  5. Use the Allow Over Packing Checkbox if you want to allow users to over pack containers on the Packing Screen. If you select this check box, a user could pack an item quantity that is greater than the quantity available on a shipment line.

  6. Use the Status Range Field to define when a shipment line is eligible for packing. The system will only pack a shipment line record within this range. This range provides you the flexibility to pack product that is not necessarily in a status ready for packing. NOTE: When product is packed, it moves to the first status after the In Packing status. For example, if the range is from In Picking to In Packing, product packed while it was still in the In Picking status moves automatically to the first status after In Packing. This insures that it moves forward through the system and skips the statuses it either bypasses or does not require.

  7. Use the Validate Item Checkbox to indicate if employees will identify the item and quantity that they are packing. To minimize processing time, many organizations do not require item validation. However, you may want to require validation if your current accuracy measurements are not acceptable, you handle expensive product, or all items include a scannable barcode. The value you define here dramatically impacts the appearance of the Packing Screen.

     

    • If you select this checkbox, the system will display input fields on the screen. These fields are displayed above the item information grid. The user will need to enter the item and item quantity in these fields. If the quantity is not entered, the system will pack one unit. The user can also enter the weight being packed. In this case, the item information grid is for display purposes only. You will not use it to select product from.

       

    • If you do not select this checkbox, you will select the item that you want to pack from an item grid. You will select items by highlighting them in the grid. You will identify the quantity that you want to pack by using the +/- buttons. The system will calculate how much the packed quantity weighs.

     

  8. Use the Verify Container ID Checkbox to indicate if the system will display the last used container ID when the user packs subsequent items.

     

    • If the employee will pack either full cases or multiple cases simultaneously, consider selecting this checkbox. After he/she selects the Pack Button, the system will not display this Container ID. The Container ID Field will display the value New. However, the employee can select this container from the field.

       

    • If the employee packs mainly loose pick shipments, consider NOT selecting this value. After he/she selects the Pack Button, the system will display the last used container ID in the Container ID Field. It will also default this container's type in the Container Type Field. The user can still use a new container ID by selecting the New option.

     

  9. Use the Require Entry Of Quantity Checkbox to determine if the system will default the packed item quantity value in the Packed Quantity Field on the Packing Screen grid. If this checkbox is not selected, then the Packed Quantity value will be zero, and the user will have to manually indicate how much they are packing into the container.

  10. Use the Container Assignment Method Buttons to define who will generate container IDs; the system or the user.

      11.  

    • If you use UCC-128 barcodes, or other unique barcodes to identify a container, select System. The system will create all container ID barcodes.

       

    • If you do not use UCC-128 barcodes, or do not have a packing printer, select Manual. All container IDs will be assigned by the user.

     

  11. Use the Shipping Container Workbench Mode Buttons to define which window the system will display when choosing to edit item quantities (modify) or confirm the contents of a container (verify) in the Shipping Container Workbench.
     
    • If you choose Modify, the system will allow you to adjust the lot and quantity fields on the Shipping Container Contents Window. Typically you would do this by manually entering in new values.
       
    • If you choose Verify, the system will allow you to confirm what item quantity is actually packed in the Shipping Container Contents Window. Typically you would do this by scanning in each item that is present in the container.

 

Using the Quality Control Tab

It is important to note that these quality control settings only apply to the full-screen QC Workbench, and NOT the RF Shipping Container QC screen.

  1. The Blind QC Inspection Checkbox is not currently used.

  2. Use the Lot Verification Required Checkbox to determine if the user will need to enter a lot value for lot-controlled items when performing inspection on a container, and how the lot field will appear on the QC Workbench's inspection grid.

    - If this checkbox is selected, the lot field will appear in the “scan item fields”, there will be a lot column in the inspection grid, and the inspection grid will display a separate grid row for each item/lot combination.

    - If this checkbox is not selected, the lot field will not appear in the “scan item fields”, there will not be a lot column in the inspection grid, and the inspection grid will summarize all of an item's lot instances into a single grid row .

    NOTE: It is recommended that you not turn off lot verification on a user's preferences while the user is currently performing QC inspection on containers. If this is done, the system might not have any information about which lot(s) failed QC, so therefore the grid would not be able to accurately display to the user the correct failed quantity against the right item/lot combination.

  3. Use the Prompt When Unknown Item Entered Checkbox to determine if the system will display a prompt message when the user enters/scans an item in the QC Workbench that does not currently reside in the container being inspected.

 

Using the Close Container Tab
  1. Use the Auto Manifest at Close Checkbox if the system will manifest containers as soon as they are closed.

  2. Use the Allow Container Creation During Close Checkbox if the employee can create containers without identifying their contents. This allows him/her to create containers "on the fly" on the Close Container Screen, outside of the packing process. The employee identifies the shipment associated with the container, but never links it to particular shipment lines. Because the shipment line is not identified, the system cannot verify accuracy of contents, or track the contents through the system. Note that this setting only applied to the Close Container screen that is accessed from the remote desktop system menu.

  3. Use the Allow VAS Override At Close Container and Load Confirm Checkbox to indicate the system's behavior when a container has pending VAS at the time of close container and shipping load confirmation.

    - At close container (when this setting IS NOT selected) if a container has pending VAS, the system will display a message indicating that the container cannot be closed because it has pending VAS activity(s).

    - At close container (when this setting IS selected) if a container has pending VAS, the system will display a message indicating that the container has a pending VAS activity, and you can choose whether to allow the container to close or hold it up because of the pending VAS. If you choose to override, the system will write transaction history recording this action.

    - At load confirmation (when this setting IS NOT selected) if a container has pending VAS, the system will not confirm the load, and the load's truck icon will turn red indicating to you this fact. The system will write transaction history recording this failure. You will then need to address the pending VAS and reconfirm the load.

    - At load confirmation (when this setting IS selected) if a container has pending VAS, the system will ignore the pending VAS and will not stop the load from confirming. Note that the system will still label the container as "VAS Pending" after the load has been confirmed, and will not write any transaction history.

  4. Use the Assign Shipment To Load Checkbox to indicate whether or not you want the system to automatically attempt to assign a shipment to a load when a user closes a container on the shipment.

    If this checkbox is selected, the system will automatically check to see if the shipment has been already assigned to a shipping load. If it has not been, the system will either find the current open shipping load (for the appropriate carrier and scheduled ship date) and assign the shipment to it; or, the system will create a new shipping load.

    If this checkbox is not selected, the system will not attempt to assign a shipment to a shipping load in this situation.

  5. Use the Use Drop Down Checkbox to indicate that you want the system to, by default, populate the Container ID Field on the Close Container Screen with eligible containers from a specified shipment to close.

  6. Use the Initiation Method Buttons to indicate the active field (which contains the cursor) when entering the Close Container Screen:

    - Always Shipment ID: The Shipment ID Field will initially be active when the Close Container Screen is opened (and while closing containers). Note that if there are more open containers on the shipment, the Shipment ID Field value will be highlighted.

    - Always Container ID: The Container ID Field will initially be active when the Close Container Screen is opened (and while closing containers). Note that if there are more open containers on the shipment, the Shipment ID Field should contain the Shipment ID, and the Container ID Field should have focus.

    - Container ID Unless No Open Containers: The Container ID Field will be active when there are multiple open containers on a shipment, and the Shipment ID Field will be active when the last open container has been closed.

  7. Use the Auto Print at Close Buttons to determine how documents will be printed. You may want specific documents to print when a container is closed.

    • To print all packing documents, select the Yes Button. The system will print all the packing documents when each container is closed.

       

    • To allow the user to select which documents to print, select the Prompt Button. The system will display the Print Container Documents Screen. The user can select packing documents to print from this window.

       

    • To print no documents, select the No Button. The system will not print any documents when a container is closed. Employees can still access the Print Container Documents Screen from the Packing Screen.

 

Using the Assigned Users Tab
  1. Use the Assigned Users Tab to associate user profile records with this preference record. When you create the *Default record, the system will automatically select all user profile records that are not already associated with a packing preference record. New users are also automatically associated with the *Default record, unless you associate them with a specific packing preference record.
