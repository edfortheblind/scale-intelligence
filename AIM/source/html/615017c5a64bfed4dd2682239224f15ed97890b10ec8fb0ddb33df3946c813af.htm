Group Pallet Checkbox

This checkbox indicates if you want containers that have the same type of item quantities on the same pallet (such as soda beverages and dairy products on a separate pallet).

 

Example:

- If you wanted to group the containers by store on each pallet, then you would create a rule with "Mark For" as the attribute, and select the Group Pallet Checkbox.

 

- If you wanted to group the containers by type of item on each pallet, then you would create a rule with "NMFC Code" as the attribute, and select the Group Pallet Checkbox.

 

- If you wanted to make sure a heavy container is not set on a lighter container, you would choose the shipping container "Weight" as the attribute, and NOT select the Group Pallet Checkbox. If this checkbox had been selected, only containers that included items with the same weight would be placed on a pallet. With it not selected, the system can mix weights on the pallet.
