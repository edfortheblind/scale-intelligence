Using the Shipment Insight Screen

You can use the Shipment Insight Screen to search and manage shipments in your warehouse.

 

Notes
  • This topic discusses specific fields represented on this screen as it is shipped in the base SCALE product. If your screen has been customized, different field (s) may appear on your screen.

Searching/Viewing Shipment Records...

You can use the Shipment Insight Screen to search for and view shipment records in your warehouse.

  1. Open the Shipment Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

Invoke Shipment Insight from Shipping Load Insight...

If you want to invoke Shipment Insight from Shipping Load Insight, complete the procedures below:

 

  1. Select a record from the List Pane of Shipping Load Insight and tap on the Shipment Indicator Tiles to open the Shipment Insight screen.

     

  2. The Shipment Insight screen should open with these predefined search criteria - Shipping Load. All the shipments tied to that shipping load should get displayed accordingly in the list pane.

     

  3. Hyperlink does not appear if you do not have the required security permission for accessing the Shipment Insight screen.

 

 

 

About the List Pane...

The Shipment Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

List Pane Icon Explanation

Certain conditions for the shipment are represented by graphical icons on the list pane. Below are explanations of what each icon represents:

Icon Explanation

Shipment has at least one line with a pending immediate need associated with it.

Shipment has at least one line with an immediate need being fulfilled, and no lines with pending immediate needs.

Shipment has at least one line with an immediate need fulfilled, and all immediate needs for the shipment have been fulfilled.

 

For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Shipment Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Shipment Insight contains Indicator Tiles with counts of the other entities (i.e. shipment lines and shipping containers). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Lines

    1. Displays the number of shipment line records on the load.

    2. Clicking on this tile takes you to Shipment Line Insight web screen filtering on the given load number.

  2. Containers

    1. Displays total number of containers on the load.

    2. Clicking on this tile takes you to Shipping Container Insight filtering on the given load number.


For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

 

 

Screen Actions...

The following actions are accessible from the List Pane:

 

 

New

This action enables you to manually create a new shipment from the Shipment Insight screen. When this action is selected, the system will open the Shipment screen in new mode. The shipment will be created at the status configured in the “Default Status When Added from shipping” Outbound Status Action. For more information on creating shipments, see the Creating/Editing a Shipment topic.

 

 

Copy

This action allows you to copy the selected shipment from the List Pane of Shipment Insight into the Shipment screen. When this action is selected, the system will open the Shipment screen in new mode. You may edit the fields also in the shipment if required. The shipment will be created at the status configured in the “Default Status When Added from shipping” Outbound Status Action.

 

 

Edit

This action allows you to change field values on the shipment. When this action is selected, the system will open the Shipment screen in edit mode.

 

 

Delete

This action allows you to delete a shipment or multiple shipments when there is no active work associated with the shipment(s). Note that this action is disabled when the trailing status of the shipment is less than Picking Pending and the leading status is greater than or equal to Load Confirm Pending. For more information on deleting shipments, see the Shipment Processing topic.

 

 

New Line

This action allows you to create a new shipment line and redirects you to the Shipment Line screen in the new mode. The action is not available if the shipment is in cancellation or the shipment is being deleted or the shipment is in load confirmation or if the shipment's trailing status is greater than or equal to Load Confirm Pending.

 

 

View/Edit Accessorials

This action enables you to ship an order with the appropriate accessorials. Selecting a Shipment ID and clicking on this opens the Accessorial Assignment screen. Refer to the topic Assigning Accessorials for additional information.

 

 

Cancel

This action allows you to cancel a shipment or multiple shipments, as long as the leading status of the shipment(s) falls within Packing Pending and Ship Confirm Pending. For more information on canceling shipments, see the Shipment Processing topic.

 

 

Confirm

This action allows you to confirm one or more shipment, as long as the shipment is on a shipping load and the status is greater than or equal to Picking Pending and less than Load Confirm Pending. The Confirm Shipment action is not available when the shipment is on an unreleased wave, or when it is canceled or deleted, or the shipment is transferred or unassigned from a shipping load. For more information on confirming shipments, see the Shipment Processing topic.

 

 

Consolidate

This action enables you to consolidate all the shipments with the one that you selected from the List Pane of Shipment Insight. It opens the Shipment Consolidation Screen. For more general information on shipment consolidation, see the Shipment Consolidation Window topic.

 

 

Immediate Needs

This action allows you access the Immediate Needs Insight screen from Shipment Insight. The Immediate Needs Insight action is enabled if the shipment line has at least one immediate needs item and there is an immediate needs request created for the item. If the immediate needs request is fulfilled, this action will not be available while selecting the shipment from List Pane. Pressing on the Immediate Needs action will open the Immediate Needs Insight screen using the reference ID (Shipment ID) and the warehouse as predefined search criteria.

 

 

Manifest at Shipment Level

This action enables you to manually manifest a selected shipment, if the shipment is in a proper state to allow manifesting. For more information on manifesting containers, see the topic Manifesting a Container/Shipment.

 

 

Pack

This action allows you to pack shipment lines into shipping containers. Selecting the action will open the Packing screen.

 

 

Print Preview

This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to Printing Paperwork.

 

 

Print Default Docs

This action allows you to print the default shipping documents that have both the print procedure for "shipment" setting and the default setting selected on the document’s Document Type record.

 

 

Print Selected Docs

This action allows you to print all the selected documents. For more information on printing topic, see the Printing Paperwork topic.

 

 

Receipt from Shipment

This action allows you to open the Receipt from Shipment screen with all the selected shipment-related data populated on the screen. Users can create receipt from shipment for a shipment with single as well as multiple details. System will use the returned quantity entered for each detail and create receipt with all the details based on the inputs. Refer to the topic Creating a Receipt From a Shipment for additional information.

 

 

Remove from Load

This action allows you to remove the selected shipments from the assigned shipping load.

 

 

Route

This action enables you to route a shipment from the Shipment Insight. This is especially helpful if you change something about the shipment (e.g. weight, destination) and need to route it with its new properties. For more information on routing, see the topic Rating/Routing Shipments.

 

 

Transfer Shipment

This action allows you to transfer a shipment to a new shipping load.

 

 

Split Shipment

You can manually assign the shipments after they have been run through different waves by splitting it. To split multiple shipment lines to a new shipment, select the multiple rows by clicking on the respective checkboxes and then select the Split Shipment action.

 

 

VAS Activity

This action can be used to search VAS activities associated with all the containers for a particular shipment. On selecting this action, system redirects the user to the VAS Insight screen and the shipment ID will get defaulted to the Shipment Id field of the Filter Pane of VAS Insight. The related results get displayed on the list pane. A row in the List Pane of Shipment Insight needs to be selected for using this action.
