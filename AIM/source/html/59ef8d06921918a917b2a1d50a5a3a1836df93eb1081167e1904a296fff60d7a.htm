Single Unit Packing

This screen brings efficiency in Packing a single unit orders . Users can pick single unit orders into a tote and initiate the packing process by scanning a tote id and item details that are picked into the tote and be able to "confirm" to pack which will update the packed quantity and closes the container. The screen also provides key information like tote quantity (packed vs total), and shipment and container information. Note that this process expects the containers to be created in a wave.

 

Summary
  • Only single unit item containers can be packed in this screen.
  • Totes which is marked for sorting can also be packed.
  • The Container type can be modified during packing. Company and warehouse authorization is supported.
  • Serial and Lot controlled items are supported.

  • Scanned item related information summary is displayed in the accordions.

  • Optionally auto print documents on closing the containers in the tote.

Procedure

 

  • Navigate to the System >> Shipping >> Single Unit Packing
  • Scan the tote ID and click the arrow button. The system will validate whether the tote has single unit packing or not. For a valid tote, user is assigned, tote condition is moved to In Packing and the item entry screen is displayed.
  • Scan/enter an Item or item cross reference value and tab out. If a valid item is scanned, then the Tote Quantity number will increase by one. For example, before the scan, it will be 0 of 2 and after scan, it will be 1 of 2 under the tote quantity. The tote condition will change from (Not eligible or Sort Pending) to In Packing depending on the tote records scanned.
    • Note: If you press ENTER key after scan/enter of item ID, then the system will pack and close the container without showing the item information details.
  • The system prompts the user to select the Container Type from the drop-down list. The container types available for packing can be authorized by company and warehouse. See the Defining Container Types for more details.
  • The system will then display the appropriate information in the Item info, Shipment Info, Container Info, and Ship to accordion. Note: All fields in accordion are read only and cannot be modified.
  • Click Confirm to close and pack the container. The system process the following on clicking the Confirm button.
    • Close the container and update the quantity to pack to zero in the tote detail table.
    • The system may print documents for this container based on the Auto Print at Close Field on your packing preference record. For more information on printing, see the Printing Paperwork topic
    • When the last item in the tote is packed, the tote condition will be moved from In Packing to Packed.
Item with company

When an item has one or more companies.

  • If the item has only one company, then when you scan the item, the system displays the company field and container type.
  • If there are multiple companies for the same item, then the user is prompted to select the company from the drop-down list, and then the corresponding container type is displayed. The container type can be modified as required in all scenarios.
Lot Controlled Item

For lot controlled items

  • If there is only one Lot, then the system will populate the Lot ID
  • If there are multiple Lot IDs, then the system will prompt you to select the Lot ID.

  • If the company is defined for an item, the system first displays the company field for selection and then you can scan/enter the Lot ID.

Serial Number tracked item

For serial number tracked item

    • If there are multiple serial numbers tracked items with a different company, the system prompts you to select a company. On selecting the company, the corresponding serial number and container type is displayed.
    • If there is same item and company but different serial numbers, the system prompts you to select the serial number. After serial number selection, the container type is displayed.
    • If the serial number template is configured, then the Major serial number will be displayed.

    Notes

    • Singles Packing eligible containers can also be sorted using WM - putwall sort
    • Item and Item Cross reference is supported.
    • Totes which was marked for sorting once initiated in Single Unit packing, cannot be sorted again.

    • You can unassign a user for a tote and then continue the singles packing after assigning to your name. unassign will be allowed only till In Packing the tote condition.

      If there are multiple items configured with same cross reference value, then system will prompt for a lookup window for selection.
