Vendor Compliant Label

A vendor compliant label is a container identification label that is compliant with the ship to's specifications. If you want to include a UCC-128 barcode on the label, see UCC Code Field to review where the system retrieves its values from. Vendor compliant labels must be printed on a specific type of thermal printer, such as a Zebra. They must also be written in a programming language acceptable to the specified printer.

 

 

General Notes

- If you would like to print both a container contents label and a vendor compliant label from the wave, see the topic Container Contents & Vendor Labels.

 

 

Technical Notes

- Printers producing vendor compliant labels must be accessible through a network share. Please refer to the Printer Configuration Guide for more information.

 

- Also, make sure that the printer used by the application server and hosted on the application server are shared with the same name as they were created as. For example, if your printer's name is "VCL1", you must share it as "VCL1".
