Retail Process Summary

** Functionality **

Scenarios

Process Flows

 

 

 

Summary...

SCALE's retail functionality spreads across several functional areas of the system. You can create store orders (also known as distros) that allow you to move product out to multiple store destinations. Also featured is the ability to receive in product, and immediately transfer (cross-dock) it to the shipping dock for delivery to the customer.

The following are key features of the retail functional area:

 

 

Setup Prerequisites...

The following are the primary prerequisites that need to be configured in SCALE before using the Retail functionality:

  • Create put-to-store locations in the Location Window. This is a typical location, with the location class of put-to-store.

  • Configure immediate needs eligibility on the appropriate item master records.

  • Define the locating rules that you want to use for retail processing.

  • Define your receiving preferences and work profile that you want to use for retail processing.

  • Create store location assignment and assignment criteria records. These indicate how the system will assign product to put-to-store locations.

 

Store Orders (Distros)...

You can interface into SCALE store orders (a.k.a. distros). These orders consist of one shipment and separate detail lines for the item quantities whose destination are different stores. Each detail's mark for information is used to identify the store to which the shipment line will be sent. After download, the store order (a.k.a. new shipment) resides in the pool, and is not used anymore, as it was just a "placeholder" shipment that contained all the store details.

 

 

 

Shipment Distribution Wave Step...

You can run waves with the shipment distribution wave step, which will process the store orders from a particular wave. The system will then either consolidate the order's details with open/existing shipments, or create new shipments for each detail line of the order. The detail's mark for information (the store's address) becomes the new shipment's ship to address. The system would then allocate from inventory to fulfill the quantity on this shipment, or if there is not inventory, an immediate needs request would be generated (if the detail's item is configured as being eligible for immediate needs).

 

 

 

Cross-Docking...

You can cross dock product from the receiving dock directly to the shipping dock. After the store order goes through the wave process, there may be immediate needs to be fulfilled for some of the orders. When you receive in the order's item, the system can immediately locate the product to the shipping dock. During this process, the system updates the shipment/shipment line statuses accordingly, creates a shipping container when the putaway is executed on the shipping dock. Cross docking is helpful so the warehouse can fulfill outstanding store orders in a quick fashion.

 

 

 

Put-To-Store Locations...

When receiving product into your warehouse, you can also putaway the item quantity in a put-to-store location, which resides on or near the shipping dock. These locations, which are assigned to a specific store in configurations, sort the product on or near your shipping dock by their final destination (a specific store). This allows you the ability to always have a shipping container open for a certain store. In addition, you are able to constantly add more detail lines to this open shipment, and have it consolidate into the open container during putaway.
