Using the Employee Timeline

The Employee Timeline screen provides a timeline-based visual representation of consolidated labor activities for a selected employee and warehouse day. It allows supervisors and planners to review direct labor, indirect labor, shift coverage, gaps, and derived gaps across the day in a time-scaled view. The screen also displays a Warehouse Day label for the selected day range.

Selection Panels

 

The Warehouse Day Selector, Warehouse Day label, Time Interval Slider, and horizontal time axis allow users to set the timeline context by selecting the warehouse day, adjusting the level of time detail, and viewing the corresponding day and time scale for labor activity analysis.

 

Warehouse Day Selector

 

Users can:

  • Select the warehouse day.
  • Use the left and right arrow buttons to navigate to the previous or next warehouse day.
  • Select a specific date using the date drop-down.

Warehouse Day Label

 

The screen displays a Warehouse Day label showing the start and end of the selected warehouse day based on the warehouse time zone.

 

Time Interval Slider

 

Use the slider to adjust the timeline granularity, allowing you to view labor activity in intervals ranging from 3 hours to 15 minutes for higher-level or detailed analysis.

Available time intervals include:

  • 3 hours
  • 2 hours
  • 1 hour
  • 30 minutes
  • 15 minutes

Adjusting the slider dynamically resizes the timeline to more detailed views of labor activity.

 

Legends and Time Axis

 

The legend color-codes labor activity on the timeline, including shift duration, direct labor execution, indirect labor activities, and gaps.

The horizontal axis shows the time of day with markers displayed at regular intervals based on the selected view.

 

Navigating and Viewing the Employee Timeline

 

To view the timeline:

  • Open the Employee Timeline screen.
  • Use the Basic Criteria fields in the Filter Pane to define the search.
  • Basic filters include Warehouse, Employee, Department, Supervisor, and Shift.
  • Click Apply Filter to display the results in the grid.

Display Grid

 

A graphical, time-based view of labor activity is displayed for each employee returned by the search. The timeline displays consolidated labor records for the selected employee and warehouse day.

Notes:

  • Labor activities are positioned based on their actual start and end times.
  • Gaps between labor bars indicate periods where no productive or indirect activity was recorded.
  • The width of each bar reflects the duration of the activity.
  • The visualization automatically adjusts when the time interval slider is changed.
  • Timeline times are displayed based on browser time.

Derived Gap Display

 

For the current warehouse day, the system can display a derived Gap block even when a Gap record does not yet exist in the database. This gives supervisors near-real-time visibility when a user is effectively idle beyond heel-to-toe tolerance.

The derived Gap is shown up to the latest labor consolidation job run time when applicable, and the calculated Gap contributes to the gap displayed in the timeline and related metrics.

 

Quick Navigation to Related User Interface Screens

 

The system supports navigation from Employee Timeline to Employee Scorecard and Labor Activity Insight, while carrying forward relevant filters.

 

Navigate to Employee Scorecard

  • Clicking the User Name in the Timeline opens the Employee Scorecard in the same tab.
  • The scorecard is automatically filtered by Employee Name, Warehouse, Warehouse Day, and any other filters applied in Employee Timeline.

Navigate to Labor Activity Insight

  • Clicking the arrow icon within a time block opens Labor Activity Insight.
  • The system automatically applies Warehouse Day, User Name, Warehouse, From Activity Date/Time, and To Activity Date/Time filters.
  • All labor activities for the selected user within the specified time range are displayed.
