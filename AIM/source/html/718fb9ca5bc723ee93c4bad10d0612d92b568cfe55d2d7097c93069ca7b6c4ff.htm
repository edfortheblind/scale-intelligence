Immediate Needs Trigger

These records specify whether immediate needs functionality is active in specific areas of the system. Triggers control when the system should generate an immediate needs request. There are four places where the system can trigger immediate needs requests.

 

Modify the Immediate Need Trigger

 

  • Priority - Sets the order in which immediate needs are addressed when multiple requests require the same item. For example, failed shipments can be prioritized over failed work orders.

  • Create Work toggle button - Determines whether the system should automatically generate work to fulfill an immediate needs request triggered by this record. If left unchecked, the system will simply place the quantity at the destination location, and the transaction must be completed manually.
