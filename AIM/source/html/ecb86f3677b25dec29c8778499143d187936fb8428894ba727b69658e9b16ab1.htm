Creating Customer Categories

Customer categories are used in the order entry module to indicate such custom values as value-added inserts (catalogs, promotional gifts, etc.), special handling instructions, pay terms, or any other user-defined message/label. Note that you can define any value for these categories, as these categories do not affect system processing of orders. Also, you can indicate whether you want to have a category be inherited or not in the Customer Window.

Validating Customer Categories...

By default, the Customer Category fields are validated against values that you configured in the Customer Category 1-10 Window. You can turn this validation off, so that users could enter any value they want into these fields.

 

In the System Text Editor, there is a key called CUSTOMERCATEGORYxCFVV (where "x" is the number of the category code. For example, CUSTOMERCATEGORY7CFVV or CUSTOMERCATEGORY10CFVV). These all come shipped as "N," which indicates that the system SHOULD validate against the values previously configured for this field (in other words, "N" translates to "No, don't skip validation"). If you change this value to be "Y," then the system will skip the validation for that category.  

 

 

Procedures...

Access a Customer Category Window (1-10). Create a new record.

  1. Use the Identifier and Description Fields to indicate the name of the category. The system will use the values you enter in the Identifier Field to populate the Category (1-10) Field on the Order Entry Window. In the Order Entry Window, you can associate category(s) to an order.

     

  2. Press OK. The system will save your record.
