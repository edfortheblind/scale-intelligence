Reviewing Rating System Values

The rating system values should only be reviewed or edited by a member of your IT staff or a system consultant. The system is shipped with the most common default values which should meet your business needs.

Value Description

 

Allow Multiple Manifests

 

Allow Multiple Manifests Per Day?

 

This value indicates whether or not the system will allow more than one manifest per day.

- If this value is set at Yes, you can have more than one manifest for that day (but not open at the same time). For example, you can manifest for awhile, close the manifest, and start a new one for that day.

- If this value is set at No, you can have only one manifest per day. When you close a manifest, and start manifesting again, the system is manifesting for tomorrow and not today.

 

Base Shipper From Whs

 

Base Shipper Info From Cross Referenced Warehouse

 

This value indicates if address changes to a warehouse are sent to a cross-referenced Progistics shipper. If you choose Yes, the system will send any warehouse address changes to the shipper in Progistics for that warehouse. If you choose No, the system will not send to Progistics any address changes for the warehouse. This is helpful when many shipper cross references are created within the same warehouse, but they use different companies. The warehouse/company combination could point to a different shipper in Progistics with a different address; therefore, a change to the warehouse address field in the application would not be desired for the Progistics shippers.

 

Dflt LTL Class

 

Default LTL Rating Class

 

This value assigns a default LTL class if the shipment does not already have a class associated with it. This value applies to LTL carriers only.

 

FedEx Currency

 

Currency Designator For FedEx

 

This value indicates currency designator to be used by the FedEx rating software. For example, you would enter the value "USD" to indicate that the FedEx system will use the United States dollars currency to rate.

 

Print UPS Barcode Label

 

Print UPS Summary Barcode Label Default Checked?

 

This value determines if the system will by default select the Print Summary Barcode Label Checkbox. This checkbox indicates if you want the system to automatically print a UPS summary barcode label after a manifest is closed.

 

Print UPS Manifest

 

Print UPS Manifest Default Checked?

 

This value determines if the system will by default select the Print UPS Manifest Checkbox. This checkbox indicates if you want the system to automatically print a UPS manifest document after a manifest is closed.

 

Pro Number Percentage

 

Pro Number Range Remaining For Alert to be Given

 

This value determines the percentage of pro numbers remaining before the system runs out. When this percentage is reached, the system will send a warehouse alert that tells the user that a new range of pro numbers is needed.

 

Validate Carrier

 

Should Carrier Be Validated Throughout the System?

 

This value determines if the system should validate a carrier when used throughout the system.

 

10

 

Submit Close Manifest to Batch?

 

This value determines if the system will submit the close manifest process as a batch process. Note that if this value is set to Yes, and re-manifesting is required, the system will perform this as part of the batch process as well. Also note that the system will not display any errors encountered during the batch process to user (the system will instead log these as process history records).
