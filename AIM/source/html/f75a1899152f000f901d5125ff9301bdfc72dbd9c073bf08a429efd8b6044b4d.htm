Cross Docking

Cross docking enables users to receive and allocate products directly from the receiving dock to the outbound area without being stored in the warehouse. Cross docking eliminates the inbound putaway and outbound picking process of inventory, which results in the fulfillment operations being completed in reduced time and increased efficiency.

Configuration

 

The following configuration is mandatory for cross-docking.

 

Host System: SCALE expects the HOST system to be configured to send the correct information to process cross docking. SCALE validates the following values

  • Shipment process type

  • Cross dock mapping information.

Shipment Process Type

  • Cross Dock Process - The cross dock process type value will be validated by the SCALE from the host system to identify whether the interface is for cross dock or not. When interfacing the shipment with process type as cross dock, the SCALE will check for this configuration, then the shipment will be downloaded with Cross Dock pending status.

Generic Config Header

  • Cross Dock Mapping – This configuration enables you to define the mapping values for the shipment and receipt line. You need to define the System Defined Values for the Shipment line and Receipt line field values which will be mapped for the cross-dock. This allows the system to validate and match the shipment line and receipt line field values. For example, the User Define field 3 for both shipment and receipt line must be same to process the cross docking.

 

Receiving Preference – Putaway work is required to process cross dock. It is mandatory to select create putaway work.

 

Custom Status Flow – Users can optionally configure a custom status flow for dock management. The system will take the default dock management flow If a custom status flow is not defined.

 

Basic Flow

 

1. Interface Download file to SCALE: Downloading the Shipment interface file.

The host system will define the shipment process type as a cross dock in the shipment interface file and send it to SCALE for processing. While downloading, the system will validate for the shipment process type to be cross dock and if it matches, then the system successfully processes the shipment record.

The downloaded shipment will be in Cross Dock pending status and the shipment header will have the Cross Dock process type as defined by the host system. Navigate to the Planned Shipment insight screen to view the downloaded shipment.

 

2. Create/Download a Receipt

SCALE will now need a receipt to fulfill the Cross-dock shipment order downloaded from the host system. Users can either create or download a receipt. The receipt should have the mapping information sent by the host system with the shipment for Cross Docking. For example, User Defined 5 is set as System Defined Values for the Shipment line and Receipt line field values to match. it is ready to be processed using the Warehouse Mobile

 

3.Receipt Check-in and locate process – Warehouse Mobile – Receiving

Once the receipt is created, it will be processed only through Warehouse Mobile – Receiving.

  • Receiving Preference Configuration:

    • Mandatory: Select create putaway work

    • Supported

      • Check in and locate.

      • Check in and Locate (immediate)

Process Using Warehouse Mobile – Receiving.

During the Receipt check-in process using warehouse mobile, the system will fetch the Cross Dock mapping value in the receipt line and will automatically identify a matching shipment line. For example, if the User-defined 4 – CRX1 is in the Shipment line and the User Defined 4 – CRX1 is in the Receipt line, the system will look for shipment with the same shipment line field.

On successful check in, the system will locate the receipt containers.

 

4. Locating

After check in, the locating process will create shipping containers for each receipt containers. The default container type (configured) will be set for these shipping container.

During locating the shipping container will use default dock management flow to identify the To location. In case the custom status flow is configured, then dock assignment will happen based on the corresponding dock management flow.

Once locating is successful, the system will update the receipt and shipment header/details

 

5.Cross Dock work Execution

Cross Dock work will be executed using the Warehouse Mobile. The system will prompt the user to select the container type during putaway at the shipping dock.

 

Process Rules

 

Downloaded shipments

  • In case the shipment process type does not match, the shipment will be downloaded with In Pool status. These shipments marked with cross dock pending status cannot be processed through a wave.

Warehouse Mobile Receiving - Once the shipment is identified, the system will then validate the following matches the

  • Shipment and receipt line's item/company/lot.

  • The shipment header's total quantity must match the receipt header's total quantity.

  • The shipment line's total quantity must match the receipt line's total quantity.

Locating Process

  • For each receipt container located, the system will create one shipping container. The container type will default the container and the user can choose the container type during putaway.

  • The system will not honor the locating rules configured.
  • License plate quantity must be less than or equal to the shipment line's quantity, if the quantity is more than the shipment lines quantity locating would fail.
  • Single receipt cannot fulfill cross dock requests across multiple shipments or vice versa.
  • Users cannot check in and locate using the Receipt workbench screen to process cross docking.
  • If locating is un successful , the Process History will log locating failure reason.
  • After the locating is completed, the system updates the shipment and receipt header details.

Cross Dock Execution

  • A receipt putaway work will be created for processing a cross dock request.

  • Work for Pickup and Drop (P&D) location is supported.

  • Cross dock work cannot be processed from the Work Insight screen.

  • Work Profile configuration listed will be ignored by the system even if configured.

    • Putaway into shipping container.

    • Automatic putaway.

    • Nest after putaway.

    • Use cross dock LP id from receiving

  • Work Special Handling - receipt putaway verify method configuration is also ignored.

  • Cross docking process will take priority over immediate needs processing if the receipt is eligible for cross docking, and the Item has an open Immediate needs request to be fulfilled.

  • The system will prevent dock assignment directly to the dock door and fail to locate for cross docking.

 

Label Printing Process

The receipt, shipping, and vendor label or document can be printed automatically when the check-in and locate process is completed.

For illustration, the recommended configuration and flow are detailed below:

  • Navigate to Configuration >> Document Type.

  • Double-click on any of the document types to open the Document Type Window. Under General Tab, Print Procedure. Use the Print Procedure Field to identify the type of records the system will generate paperwork. See the Print Procedure Field topic for more information.

    • Vendor/shipping Label – Under Print Procedure, select Shipping Container as default.

    • Receipt container Label - Under Print Procedure, select Receipt shipping container.

  • When the default check box is selected, the system automatically prints all documents associated with a print procedure.

  • Using warehouse mobile receiving, complete the check-in process. Complete the locate process by Action >> Done. The default document configured will be printed when locating the receipt is completed.

 

Notes

  • The system does not use locating rule during locating process.

  • Pre-check-in containers can also be used to fulfill cross dock.

  • Single receipt cannot fulfill cross-dock requests across multiple shipments or vice versa.

  • Multiple receipts are required to fulfill cross-dock for multiple shipments.

  • Users cannot un-locate cross docked receipt containers.
