Reviewing Web System Values...

The web system values should only be reviewed or edited by a member of your IT staff or a system consultant. The system is shipped with the most common default values which should meet your business needs. Do not change any of the system-defined values unless you first talk to your system consultant.

Below are descriptions of the web system values. You can review and/or edit the following values:

 

Alert System Value Descriptions...

 

Value Key
Value Description

 

10

"Sent From" Address On Email From Email Alert: This value provides the email address for the person who will receive return emails. When you send an email alert and your recipient selects the Return/Reply Button, the value you defined here will appear in the To section of the return email. Generally, the email return address should be your support team's email.

 

20

"Sent from" Name On Email From Email Alert: This value identifies who sent the email alert from your warehouse to your customer. The address that you define here will appear in the From section of the email alert sent from your warehouse to the customer.

 

 

 

Web Order System Value Descriptions...

 

Value Key
Value Description

 

60

Storage Directory For Web Order Files: This value identifies the storage directory used for web order files generated by TPM.

 

90

Reviewed Web Order Directory: This value indicates the directory where you want the system to place your reviewed web orders. A reviewed order is an order that has been opened and processed through the system's main Order Entry Window. An order is moved from the Order Directory to this directory when this occurs.

 

 

 

General Web System Value Descriptions...

 

Value Key
Value Description

 

140

Graphic For Left/Center/Right Header Section: These values indicate the path of the graphic that will appear at the top-left/center/right of the Trading Partner Management Main Menu. The path should be in this format:\\YourServer\Directory1\Directory2\ graphic.gif.

 

170

Internet Address For Center Header Section:  These values indicate the specific URL of the link that will be associated with the graphic that appears at the top-center of the Trading Partner Management Main Menu. The URL should be in this format:

 

LOCAL URL: \\YourServer\Directory1\Directory2\yourPage.htm

REMOTE URL: http://www.manh.com.
