Allow Duplicates Checkbox

Select this checkbox to determine whether the system will allow users to enter the same serial number for multiple items. Note that this checkbox will be active only if the "Allow Duplicate Serial Numbers" flag in the Inventory Control Values is set at "Y." Be sure to only use this setting if your business process is not affected by having multiple items with the same serial number.

  • If unchecked, indicates that you want to prevent duplicate serial numbers from being entered for an individual item.

  • If checked, the system will allow duplicate serial numbers across items. The system will only allow duplicate serial numbers to be added to items that are associated with a serial number template.
