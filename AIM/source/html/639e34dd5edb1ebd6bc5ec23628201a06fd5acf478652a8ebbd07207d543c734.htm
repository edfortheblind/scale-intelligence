Check In and Locating Product (Warehouse Mobile)

During check in, the system accepts product on the receiving dock into the warehouse. Using the warehouse mobile application, it also allows you to locate this product automatically after check in. The procedures below describe this process.

 

NOTE: You cannot check in the receipt lines after a receipt has been closed (i.e. the Closed Date is specified). However, you can still perform functions on existing receipt containers such as check-in, locate, and unlocate.

Procedures

 

1. Sign in to Warehouse Mobile, and tap Receiving in the main menu screen.

 

2. Select Receiving Preference: Select and Tap the receiving preference you want to use for this session.. Note that the system will automatically load a preference if one is associated with your user profile record. Receiving preferences shown on the Select Receiving Preferences selection screen can be authorized by user from the Receiving Preference configuration screen.

 

3. Receipt Initiation Screen: The system will display a screen to initiate the check in process, depending on the initiation method defined in your receiving preference record:

 

Initiation Method

4. Item Cross Reference: (if cross references are used) If an item cross reference has more than one item, you will have to choose which one you want to check in. Note that if the item is in the cross reference and not in the item master, the item will not be found.

 

5. MAIN CHECK IN SCREEN: Identify the quantity and correct unit of measure for the product you want to check in. If there is an Item Unit of Measure record for the item you are checking in, the Item UOM field will indicate the conversion quantity next to a unit(s) of measure.

 

6. START CHECK IN/LOCATING PROCESS: After pressing OK, the system will check in the product.

 

7. VALIDATIONS: If configured to do so, you will also have to enter:

  • LICENSE PLATE ID: System will ask for the license plate ID that you want to associate with this checked-in item. Provide one and press OK. Otherwise, the system will create this ID for you.

     

  • CHECK IN VERIFICATION: System will display a "Check In Verification" message, based on Verify Quantity during check in can be enabled by checking Quantity under the Verification section on a work special handling record configured for the receiving preference's work type.

 

8. DONE button: Click DONE button, will redirect the user to the receipt ID entry screen from the Item entry screen. This happens when if it execution method is Check in and initiation method is Header item.
