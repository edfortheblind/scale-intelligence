Returns Process Summary

** Functionality **

Process Flows

 

 

 

Summary...

The returns module allows you to process product that is returned to your warehouse, whether it is a "good" return (an unwanted item) or a "bad" return (item is damaged or broken). This processing follows the returned merchandise from when it arrives to the receiving dock, to when it is ready to be put away back to an inventory location. The system uses putaway location groups to arrange these returned items after they are checked in and located. These putaway location groups also allow a series of received items to be put away as one group. Therefore, related items (or items that are part of the same locating zone) can be put away in one trip.
