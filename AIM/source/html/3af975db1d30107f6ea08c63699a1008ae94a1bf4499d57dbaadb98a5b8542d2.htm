Creating Cycle Count Master Records

** Use with plan based cycle counting **

 

The purpose of a cycle count master record is to control what cycle count requests the system creates. Master records are only used in generating plan-based cycle count requests. These records are driven off of item and location criteria records, which you define.

Procedures...

 

Create a new record. Provide a name and description.

  1. Use the Item Selection Field to choose an item filter record to associate with this master. This record is used to filter the locations eligible for cycle counting.

     

  2. Use the Location Selection Field to choose a location filter record to associate with this master. This record is used to filter the locations eligible for cycle counting.
     
  3. Use the Maximum Number of Counts Field to indicate the maximum number of cycle count requests you want the system to generate from a particular cycle count plan. Note that if you put a "0" in this field, there will be no maximum limit of requests that the system will create.
     
  4. Use the Randomize Check box to indicate that you want the system to create cycle count requests from a random set of locations (based on the range as defined in your Cycle Count Location Selection record for this master). Note that if you do not want the system to have the opportunity to choose the same location every time requests are generated using this master, make sure one of the following conditions exist:

    - On your Cycle Count Location Selection record, include a filter using the Last Cycle Count Date value. For example, if you define a location selection record where the Last Cycle Count Date is greater than 180 days, then the system will not pick a location again until it has not been cycle counted in the last 180 days. Thus, you will not get the unwanted "repeat" cycle count request until a desirable amount of time has elapsed since the last cycle count.

    - If a pending request exists for a location, the system cannot create another request for this location.
     

  5. Use the Run With Scheduled Job Check box to indicate that you want the system to execute a cycle count plan (using this master) at a certain date/time via a system scheduled job. In addition, note that you must set up a record in the Scheduled Job Window in order for the system to run this master with a scheduled job.

     

  6. Use the Create Work Check box indicates how the system should process cycle count plans.
     

    • If this check box is checked, the system will create work for this plan.

       

    • If this check box is not checked, the system will not create work for this plan. Instead, workers will execute this plan from a cycle count list paperwork document.

  7. Use the Update Cycle Count Work to Include All Items Check box to indicate to the system to create cycle count requests for all items currently at a multi-item location, as opposed to creating requests for just the item(s) at the location that match the cycle count item selection criteria.

    NOTE: When a multi-item location is initially empty and then items are adjusted into it (prior to the cycle counting work being executed), the system will create a cycle count for every item adjusted into the location, regardless of whether this setting is on or off.

    8.  

  8. When finished, press OK. The system will save your record.
