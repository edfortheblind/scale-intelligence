User Interface Theme

The user can customize the user interface look into one of two themes: Light and Dark. The main elements of user interface of top-bar, sidebar, tiles and background are distinct and unique in style and color for light and dark theme.

 

Note: By default the SCALE application will be in Light theme mode.

Theme selection

User can toggle the user interface theme between Light and Dark theme. The theme is universal application and need not be set for each screen.

 

To change the theme, select an option from User Profile >> Dark theme or Light Theme.
