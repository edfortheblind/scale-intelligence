Item Touchpoint

Item master information can be downloaded from the ERP via the system interface. This allows you to populate the item master configuration table, so you don't have to define your products manually in the system.

 

 

To see actual examples of the inventory transaction touchpoint, see the following topics:

- Delimited Interface Tutorial

- Fixed Length Interface Tutorial

- Direct Interface Tutorial

General Guidelines...

  • You can interface any field that appears on the following windows: Item Window, Item Cross-Reference Window, and the Item Unit of Measure Window.
     
  • For each item that you interface, you can include ten cross-reference values and ten units of measure. If an item has more than ten cross-references or units of measure, begin by sending the first ten instances in an interface file. After those records are interfaced, download up to ten more instances. You can continue this process until all cross-reference and unit of measure records are added for an item. Note that if you send down an existing item/company value and no cross-reference or unit of measure value, the system will reject this record as an attempt to duplicate the item.
     
  • All items are defined by item/company combination, if your warehouse is a multi-company environment.
     
  • If you do not specify a sequence value, the interface will default the sequence to the conversion quantity.
     
  • An item cannot be validated for both catch weight and a serial number.
     
  • The Item Download interface can process unit of measure values in any order (EA, CS, PL; CS, EA, PL; etc). However, their order (by conversion quantity) must conform to that of the Storage Template associated with the particular item.

  • When updating an existing record, if a value is not interfaced for a field, the system treats it as “no change” and retains the existing value.

  • If changing the item's storage template and item has item unit of measures and item cross references, then you will need to include the item unit of measures and item cross references for the new storage template in the download.

  • If adding or changing the item unit of measure and item cross references exist for the item unit of measure, then you will need to include the item cross reference for the item unit of measure being added or changed.

 

Rejection Causes / Validations / Notes...

  • You cannot download a new item master record if this item (with the same company designation) already exists in the system.
     
  • The SCALE interface process does not support using a comma as a "seperator" for numeric values. These values will need to be interfaced into the system using decimals as seperators (4.95, not 4,95). The system can, however, display these values with a comma seperator on SCALE windows, but in the database they must be in a decimal format.

  • When downloading an item and that includes an item cross reference (and there are user defined fields also specified), these fields get updated on both the Item and Item Cross Reference configurations.
