Adding Rule Set Assignment to a Wave Flow (Outbound only)

To use rule set assignment to allocate product for picking, you will also need to add a wave step to your wave flow. This step indicates to the system that it should use advanced rule set assignment when allocating product, instead of grabbing the allocating rule from the item master. You can perform this procedure on the Wave Flow Window.

 

 

Procedures...

  1. Access the Wave Flow Window from the Configurations Explorer, and open/create a wave flow record. The system will display the Wave Flow Header Window.
     
  2. Right-click on the Detail Records Tab and choose New. The system will display the Wave Flow Detail Window.
     
  3. In the Wave Step Field, choose the value "Rule Assignment." This wave step should come before the Allocation step in your wave flow to process correctly.
     
  4. For information on other fields in this window, see the topic Defining Wave Flows.
     
  5. Press OK. The system will save your changes.
