FedEx SED Accessorial Setup

Below are some setup guidelines/notes on using FedEx SED accessorials. Note that if these guidelines are not followed, the manifesting process will not work correctly.

Notes On Setup...

  • ITN (Internal Transaction Number): This is given by AES after an SED is submitted to them and it is unique per shipment.
     
  • XTN (External Transaction Number): This is an exemption number for the item given by the government.
     
  • Make sure all FedEx International Shipments with containers are manifested/shipped prior to upgrading. All FedEx International Containers should now only have a single item per container.
     
  • FedEx XTN and ITN fields have been added to the Item Window and the Item Download.
     
  • The "SED" Accessorial Header will now always apply at the container level.
     
  • The SED Filing Status Accessorial has been changed to default to "S". This indicates the shipper will be filing the SED.
     
  • Added the XTN Suffix Number Accessorial Detail to all Fed Ex "SED" Accessorial headers.
     
  • The XTN Suffix Number accessorial will be filled when the container is manifested. This will only occur during Shipment Level Manifesting for International Fed Ex containers. At the time of manifesting the XTN Suffix Number will be updated only when the FTSR Exemption Number is not given.
     
  • The XTN Suffix Number will be filled based on the values in the item configuration for the first item that was packed into the container. If the item has the ITN number filled in on the item configuration it will be used. Otherwise the XTN number from the item configuration will be set on the accessorial tied to the container. This information will then be sent to FedEx.
