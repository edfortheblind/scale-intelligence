
        
        <h1 data-source-node="n56"><a name="kanchor1147" data-source-node="n57"></a>Variable Type Field</h1>
        <p data-source-node="n58">The following are used when an application identifier has a variable length string length type:</p>
        <blockquote data-source-node="n59">
            <p data-source-node="n60">- <i data-source-node="n61">Calculated Length</i>: Use this when the application identifier uses a calculated length to determine when to parse for the next AI.  

AI 23 (lot/batch) is an example of an application identifier that requires a calculated length.  The first digit after the AI (e.g., 23x) indicates the length of the data.  This is the only SCALE-supported application identifier that uses calculated length.</p>
            <p data-source-node="n62"> </p>
            <p data-source-node="n63">- <i data-source-node="n64">FNC1 Separator</i>: Use this when the application identifier requires an FNC1 separator to determine when to parse for the next AI.  The majority of variable length application identifiers require an FNC1 separator.</p>
        </blockquote>
