Work Order Preference Configuration

Overview

A work order preference record allows you to manage how a user or group of users will process work orders. The default record should accommodate the majority of employees. However, you can create specific preference records for employees with unique processing needs.

 

General Information

 

Enter Preference Name and Description

 

Default Build Location

  • Select the Default Build Location Field to identify where the employee typically creates work units. This value is displayed on the Work Order Window; the user can override this value. It is also printed on the Work Order Component Pick List to identify where components should be delivered for processing. On the Work Order Finished Item Putaway List, this value identifies the from location for the finished items.

Default Storage Location

  • Select the Default Storage Location Field to identify the inventory location where the finished item should be located. The system will default this location on the Work Order Confirmation Window, but the user can select a different confirm location. It is also printed on the Work Order Finished Item Putaway List to identify where finished items should be putaway.

Default Inventory Status

  • Select the Default Inventory Status Field to define the status finished items are assigned when they're confirmed. Generally, you should select an "available" status if you want to allocate the product.

 

Processing

 

Create Work

Use the Create Work Checkbox if you want the system to generate work instructions for the allocated components and confirmed finished items.

  • If you select this checkbox, the system will call work creation as soon as the component is allocated or the finished item is confirmed.

  • If you do not select this checkbox, the system will not create work for either allocated components or confirmed finished items. Instead, it will automatically locate the quantity (either component or finished item) and put its quantity as On Hand at the destination location(s). Someone will need to ensure that the product is physically delivered to that location(s).

Generate paperwork on release

  • Select the Generate Paperwork on Release option if you want the Work Order Component Pick List and/or the Work Order Assembly Instructions printed when the work order is released. You can also print these documents from the Work Order, as long as at least one component has been allocated. To print automatically, this process must be set to Default on the document type record.

Generate paperwork on confirm

  • Select the Generate Paperwork on Confirm option if you want the Work Order Finished Item Putaway List printed when the finished items are confirmed. You can also print this document from the Work Order, as long as at least one finished item has been confirmed. To print automatically, this process must be set to Default on the document type record.

Logistics unit assignment method

Select the License Plate Assignment Method Buttons to determine if the user will assign or verify license plate IDs. A license plate ID identifies a finished item, or group of finished items, for putaway.

  • System: If you select system, the user never assigns a license plate ID; the system always assigns it.

  • Manual : If you select manual, the user will assign the license plate ID.
