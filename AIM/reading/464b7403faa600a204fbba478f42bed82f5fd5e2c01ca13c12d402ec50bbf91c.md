
        
        <h1 data-source-node="n56"><a name="kanchor920" data-source-node="n57"></a>Nest During Check In Checkbox</h1>
        <p data-source-node="n58">Select the Nest During Check In Checkbox to indicate that you want to 
 nest container(s) on a receipt into one container. At the end of the check 
 in process, the system will display a screen where you will enter a container 
 ID and the container type.  The container types  can be authorized by company and warehouse. The 
 system then will nest the container(s) that you checked in during that 
 “session” into the new container. Note that you can configure security 
 for this process to skip nesting (see the "WM Receiving Container 
 Nesting" value in the Security Window).</p>
