
        
        <h1 data-source-node="n56"><a name="kanchor909" data-source-node="n57"></a>EPC Encoding Field</h1>
        <p data-source-node="n58">NOTE: This field is not used currently.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">This field indicates which type of Electronic Product Code (EPC) the system will expect to read with RFID readers, and to burn on an RFID-supported labels. If the system attempts to perform an action and it expects a different type of encoding format, it will generate an audit, and the action will not execute.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">NOTE:  This EPC Encoding setting supersedes the default setting as defined in the RFID System Values Window.</p>
