
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">LTL Class</h1>
        <p data-source-node="n58">The LTL Class is used to categorize the type of goods loaded on an LTL truck and is required when rating LTL carriers. Review existing LTL classes through the LTL Class Window. If needed, additional classes can be created—ensure compatibility with third-party rating systems like Progistics before doing so.</p>
