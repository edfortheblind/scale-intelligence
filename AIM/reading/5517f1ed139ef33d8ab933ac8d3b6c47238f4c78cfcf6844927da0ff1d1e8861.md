
        
        <h1 data-source-node="n56"><a name="kanchor1052" data-source-node="n57"></a>Number of Days Field / Number of Days To Collect Field</h1>
        <h5 data-source-node="n58">On the Movement Class Insight / Scheduled Job Window... </h5>
        <p data-source-node="n59">This field indicates the amount of days (starting from the current date and counting backwards) where the system will collect movement class analysis data and write it to the database. Note that each time the "Movement Class Analysis Data Collection" scheduled job is run, the system will clear out the existing movement class records (per warehouse) in the database, and replace them with the new records (which are collected for the date range indicated on this field).</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">Notes On Valid Values for this Field on the Scheduled Job Window...</h5>
        <ul data-source-node="n63">
            <li data-source-node="n64">The default value for this field is 90<br data-source-node="n65"><br data-source-node="n66"></li>
            <li data-source-node="n67">The maximum value for this field is 9999<br data-source-node="n68"><br data-source-node="n69"></li>
            <li data-source-node="n70">Decimal and negative values are not allowed<br data-source-node="n71"><br data-source-node="n72"></li>
            <li data-source-node="n73">The values 0 and NULL are not allowed<br data-source-node="n74"></li>
        </ul>
