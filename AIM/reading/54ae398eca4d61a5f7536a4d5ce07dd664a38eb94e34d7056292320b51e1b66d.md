
        
        <h1 data-source-node="n56"><a name="kanchor594" data-source-node="n57"></a>Auto Print at Close Buttons</h1>
        <p data-source-node="n58">You can use these fields to indicate if the system will automatically 
 print selected packing documents when you close the container.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The valid values are:</p>
        <ul data-source-node="n61">
            <li data-source-node="n62"><i data-source-node="n63">Y</i> - The system will automatically print the packing documents. When the user selects the Close button, the system will print the documents. 
 The system navigates back to the Close Container Screen. It does not display the 
 Print Documents Screen.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66"><i data-source-node="n67">N</i> - The system will not automatically print the packing documents. When the user selects the Close button, the system will not print the selected 
 documents. The system navigates back to the Close Container Screen. It does not 
 display the Print Documents Screen. The packer can access the 
 window by selecting the Print button on the Packing Screen.<br data-source-node="n68"><br data-source-node="n69"></li>
            <li data-source-node="n70"><i data-source-node="n71">Prompt</i> - The system will display the Print Documents Screen. When the user selects the Close button, the system will display the Print 
Documents Screen. The user will verify that he/she wants to print 
 particular documents. After the user selects the Print button, the system 
 navigates back to the Close Container Screen.</li>
        </ul>
