Saving Viewer Window Search Queries

After performing a search for records on a viewer window, the system allows you to save a query's criteria values, so you can execute an identical search at a later time. Note that these query records are saved on a per user basis.

Procedures: Saving a Query...

  1. Access a viewer window and perform a record search.

  2. On the Query Menu, select the Save Search As Query option. The system will display the Query Editor Window.
     
  3. Use the Query Name Field to provide a text identifier for your query.
     
  4. Use the Shortcut Key to assign a keyboard combination that the user can press to execute this query.
     
  5. Select the Show Criteria Checkbox to have the system display the actual SQL statement for this query. You can also add your own SQL to this statement, if necessary.
     
  6. Press OK, and the system will save this query. It can then be invoked via a viewer's Query Menu, or by pressing its shortcut key combination.

 

Procedures: Editing a Saved Query...

  1. Access a viewer window.

  2. On the Query Menu, select the Edit Search Queries option. The system will display the Query Editor Window.  
     
  3. Use the Query Name Field to select the query that you want to edit. You can now change the shortcut key, or the query's criteria (by selecting the Show Criteria Checkbox).
     
  4. Press OK to save your query settings. Note that you can delete or rename queries as well using this same window.
