
        
        <h1 data-source-node="n56"><a name="kanchor764" data-source-node="n57"></a>Field / Field Name</h1>
        <h5 data-source-node="n58">In Packing...</h5>
        <p data-source-node="n59">This represents the field value that a detail line must have for the 
 system to pack it into a particular container. Note that only items whose 
 shipment line values match ALL of 
 the fields (as defined on the packing criteria record) will be packed 
 together. 
 You would receive a warning message since the field does not match. For example, suppose that "Mark For" is a field defined on the 
 packing criteria record. The detail line item being packed, however, has 
 a different "Mark For" value than an item already in the container. 
 The system, then, cannot pack this item into the container, because the 
 "Mark For" values do not match up. The system will then need 
 to look for another container to pack this item into.</p>
        <p data-source-node="n60"> </p>

 Custom Search Criteria Window...</h5>
        <p data-source-node="n68">This field indicates a field that you can add as additional search criteria.</p>

        <h5 data-source-node="n71">On the Carrier EDI Reference Window...</h5>
        <p data-source-node="n72">This field indicates the text name of an EDI reference field that you want to send to the transportation system.</p>

        <h5 data-source-node="n75">On the Interface Error Reference Field Configuration Windows...</h5>
        <p data-source-node="n76">This field indicates the path (i.e., the location of the value within the XML nodes, expressed using xpath) of a value that you want to use as a reference field for a specific interface process. For examples of how to express these values, see the topic <a href="28b2818dbc393a3087eb0ebbbac822dde8e0c66d514b2097d56939c2bd265e2e.html" data-source-node="n77">Defining Interface Validation Error Reference Fields</a>.</p>
