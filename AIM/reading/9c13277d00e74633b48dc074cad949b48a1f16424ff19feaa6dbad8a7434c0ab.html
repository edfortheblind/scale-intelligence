Status Field

DIF Incoming/Outgoing Message Insight Screens...

This field identifies one of the four statuses that an incoming or outgoing message can be at:

  • Ready - Indicates a message is ready to be processed by the DIF Message Processing service.

  • In Process - Indicates a message is currently being processed by the DIF Message Processing service.

  • Processed - Indicates a message has been successfully processed by the DIF Message Processing service.

  • Error - Indicates that there was an error that occurred when the DIF Message Processing service attempted to process a message.

 

On the Shipping Container Screen / Shipment Insight Screen...

This field identifies the current status at which the container is currently assigned. Note that containers do not have a leading and trailing status; rather, they are just assigned one status.

 

 

On the Cycle Count Request Insight Screen...

This field indicates the status of the specific cycle count request. For example, "pending review".

 

 

On the Purchase Order Insight Screen...

This field indicates the status of the specific purchase order. For example. "open". For more information, refer to the topic Reviewing Purchase Order Status Values.

 

 

On the Inventory Adjustment / Inventory Transfer Screens...

This field indicates the inventory status (Available, Held, etc) that an item quantity will have after an adjustment/transfer is performed.
