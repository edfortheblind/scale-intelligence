        <h1 data-source-node="n57"><a name="kanchor1712" data-source-node="n58"></a>Allow Percent Allocation Checkbox/Toggle</h1>
        <p data-source-node="n59">You can use this setting to indicate that you want the system to use 
 variable allocation when attempting to allocate quantity on a shipment 
 line.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"><span class="span_3" data-source-node="n62">NOTE:</span> You will also need to 
 enter values in the Minimum and Maximum Allocation Percentage Fields in 
 order to use variable allocation.</p>
