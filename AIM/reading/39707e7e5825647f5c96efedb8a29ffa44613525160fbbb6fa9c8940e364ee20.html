Metadata System Values

These values represent technical values that determine how the system uses wildcard search from the Insight screens will be configurable for both numeric and alphanumeric fields. These values will enable users to enable/disable the wildcard search across the insight screens.

These values are used with the Wildcardsearch screen control attribute to include/exclude specific field for a specific insight screen.

 

 

Value Key

 

Value Description

 

10

Include wildcard in numeric field search?

By default, the value is set to N. This enables users to configure the numeric value for wildcard search in the insight screens.

 

20

Include wildcard in alphanumeric field search?

By default, the value is set to Y. This enables users to configure the alphanumeric value for wildcard search in the insight screens.

 

30

Export datetime columns to browser timezone?

By default, the value is set to No. Set to Yes, which enables users to export date/time data from insight screens based on local browser time zone.

 

 

 

The above setting will behave in the following way when configured using the wildcardSearch screen control attribute in the insight screen.
