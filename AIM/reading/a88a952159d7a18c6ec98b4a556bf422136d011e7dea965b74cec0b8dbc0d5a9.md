        <h4 data-source-node="n67">Configure Adjustment Type</h4>
        <p data-source-node="n68"> </p>
        <h5 data-source-node="n69">1. General Information </h5>
        <p data-source-node="n70"> </p>
        <p data-source-node="n71"><b data-source-node="n72">Adjustment type</b>: This field is used to define an inventory management record, which allows product adjustments at the location level.</p>
        <p data-source-node="n73"> </p>
        <p data-source-node="n74"><b data-source-node="n75">Minimum and Maximum Quantity Fields</b>: Set limits on the quantity of the product that can be adjusted.</p>
        <ul data-source-node="n76">
            <li data-source-node="n77">
                <p data-source-node="n78">For negative adjustments, enter negative values (e.g., -1, -2, -3).</p>
            </li>
            <li data-source-node="n79">
                <p data-source-node="n80">Entering a positive value will increase the product quantity at the location instead of removing it.</p>
            </li>
        </ul>
        <p data-source-node="n81">Note: The system always uses the base unit of measure (UM) for these values.</p>
        <p data-source-node="n82"> </p>
        <p data-source-node="n83"><b data-source-node="n84">Adjustment Class</b> buttons: Select an adjustment class to specify how the system processes the adjustment internally. Note that this class affects the processing method, not the type of adjustment. Regardless of the value in the Adjustment Type field, the system will always perform an adjustment when using this record.</p>
        <h5 data-source-node="n85"> </h5>
        <h5 data-source-node="n86">2. Processing</h5>
        <p data-source-node="n87"> </p>
        <p data-source-node="n88"><b data-source-node="n89">Initiation Type</b>: Choose whether adjustments should be based on an item/location combination or by license plate.</p>
        <p data-source-node="n90"> </p>
        <h5 data-source-node="n91">Toggle Buttons</h5>
        <ul data-source-node="n92">
            <li data-source-node="n93">
                <p data-source-node="n94"><b data-source-node="n95">Allow for Frozen Locations</b>: Enable this option if adjustments should be allowed for locations with a "Frozen" status. Frozen locations typically contain inventory that cannot be allocated or are empty. However, you can enable this option to adjust product or change its status. </p>
            </li>
        </ul>
        <ul data-source-node="n96">
            <li data-source-node="n97">
                <p data-source-node="n98"><b data-source-node="n99">Include in Interface Uploads</b>: Select this button to interface records for this adjustment type back to the ERP system.</p>
            </li>
        </ul>
        <ul data-source-node="n100">
            <li data-source-node="n101">
                <p data-source-node="n102"><b data-source-node="n103">Create Work</b>: Select this button, if you want the system to generate work for transactions using this adjustment type.</p>
                <ul data-source-node="n104">
                    <li data-source-node="n105">
                        <p data-source-node="n106">You can also specify a Work Creation Master that the system will follow when creating work.</p>
                    </li>
                    <li data-source-node="n107">
                        <p data-source-node="n108">If no Work Creation Master is specified, the system will use all configured masters in priority order.</p>
                    </li>
                </ul>
            </li>
        </ul>
        <p data-source-node="n109">Note: Work creation applies only to positive/negative adjustments, basic transfers, and warehouse transfers.</p>
        <p data-source-node="n110"> </p>
        <h5 data-source-node="n111">3. Authorized Users</h5>
        <p data-source-node="n112">Select which users are authorized to perform this adjustment type on the Inventory Adjustment screen or Warehouse Mobile application.</p>
        <p data-source-node="n113"> </p>
        <h5 data-source-node="n114">4. Authorized Warehouses</h5>
        <p data-source-node="n115">Choose which warehouses are eligible for this adjustment type on the Inventory Adjustment screen or Warehouse Mobile application.</p>
