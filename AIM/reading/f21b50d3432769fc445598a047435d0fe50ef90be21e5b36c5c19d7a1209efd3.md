
        
        <h1 data-source-node="n56"><a name="kanchor1220" data-source-node="n57"></a>Suppress Postal Code In Rating Field</h1>
        <p data-source-node="n58">This field indicates if you want the system to ignore the requirement 
 of providing a postal code when performing a manifesting request. This 
 is necessary because some international destinations do not require a 
 postal code, but the application typically requires this information when 
 you define a customer/ship to address. Note: Also these values are not allowed when downloading a shipment with an address for the country that is set to suppress.</p>
