
        
        <h1 data-source-node="n56">Adding Rule Set Assignment to a Wave Flow (Outbound only)</h1>
        <p data-source-node="n57">To use rule set assignment to allocate product for picking, you will 
 also need to add a wave step to your wave flow. This step indicates to 
 the system that it should use advanced rule set assignment when allocating 
 product, instead of grabbing the allocating rule from the item master. 
 You can perform this procedure on the Wave Flow Window.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Procedures...</h4>
        <ol class="ol_2" data-source-node="n61">
            <li value="1" data-source-node="n62">Access the Wave 
 Flow Window from the Configurations Explorer, and open/create a 
 wave flow record. The system will display the Wave Flow Header Window.<br data-source-node="n63"> </li>
            <li value="2" data-source-node="n64">Right-click on 
 the Detail Records Tab and choose New. The system will display 
 the Wave Flow Detail Window.<br data-source-node="n65"> </li>
            <li value="3" data-source-node="n66">In the Wave Step 
 Field, choose the value "Rule Assignment." This wave 
 step should come before the   Allocation 
 step in your wave flow to process correctly.<br data-source-node="n67"> </li>
            <li value="4" data-source-node="n68">For information 
 on other fields in this window, see the topic   <a href="59caf3cae0c61859503c7fc632cbfa200d307634fa7d6d9df75480875d759655.html" data-source-node="n69">Defining 
 Wave Flows</a>.<br data-source-node="n70"> </li>
            <li value="5" data-source-node="n71">Press OK. 
 The system will save your changes.</li>
        </ol>
