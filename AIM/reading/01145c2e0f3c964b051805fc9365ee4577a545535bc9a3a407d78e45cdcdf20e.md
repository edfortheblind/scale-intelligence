
        
        <h1 data-source-node="n56"><a name="kanchor490" data-source-node="n57"></a>Packing Criteria Field</h1>
        <p data-source-node="n58">This field indicates the name for a packing criteria record. A packing 
 criteria record determines which items the system will allow to be packed 
 into the same container. This is helpful if you want to keep certain items 
 from being packed with others that are going to a different destination. 
 For example, if you are shipping to a distribution center that forwards 
 items to a company's stores, users would not be allowed to pack items 
 that are being shipped to different stores into the same container.</p>
