        <h4 data-source-node="n92"><a name="Defined" data-source-node="n93"></a>Inventory Attributes Defined...</h4>
        <p data-source-node="n94">Inventory Attributes represent values that are assigned to inventory, typically when it is checked into the warehouse. These attributes fill the need to track specific information about warehouse inventory.  Typically, this type of information would need to be captured  during receipt check in, maintained in inventory, items allocated and picked based on these attributes, and then uploaded to your ERP system.  Also, you can add/edit these attributes to inventory at select places in the system. Examples of inventory attributes include such values as Country of Origin, Region, or Product Owner. The system supports inventory attributes for both license plate and non-license plate tracked locations. All of the functional areas that support inventory attributes are listed in the <a href="#SystemSupport" data-source-node="n95">System Support for Inventory Attributes</a> section below.</p>
        <p data-source-node="n96"> </p>
        <p data-source-node="n97">All of the inventory attributes are stored in a separate database table called LOCATION_INVENTORY_ATTRIBUTES. The application supports twenty attribute fields, which are generically named Inventory Attribute 01, Inventory Attribute 02, etc. You can rename these attribute field names in the System Text Editor to reflect the specific attribute being captured, such as Country of Origin, Tax Seal, or Product Owner. Also pre-defined inventory attribute values can be created in the configurations that allow you to select from these values on certain processing screens. For this list of values to be displayed onscreen, they first need to be activated (per attribute) in the configurations. </p>
