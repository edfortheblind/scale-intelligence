
        
        <h1 data-source-node="n56"><a name="kanchor319" data-source-node="n57"></a>Default Work Profile Field</h1>
        <p data-source-node="n58">This field indicates the work profile that the system will automatically 
 choose for a user when performing RF work execution. You can associate 
 a default work profile on a user profile record. Note that if no default work profile is associated with a certain user, 
 that user will have to manually choose a work profile when processing 
 RF work.</p>
