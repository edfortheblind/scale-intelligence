Reviewing RF Device Style Sheet Records

You will use this window to link a specific RF style sheet for a particular device. The purpose of these style sheets is to adjust the look of the RF screens so that they can best be matched to work with the particular device you are using. For example, on touch screen devices there is a style sheet shipped with the system that allows options to be selected by touch rather than by keyboard entry.

 

 

Notes

  • If the identifier mentioned in the generic config detail matches any keyword from the User Agent string (which stores all the platform data including such things as operating system information/version and browser information/version), the system will apply this style sheet value.

  • The one record shipped with the system is "Android".

Order of Preference

The order of preference of a particular RF style sheet while accessing RF is as follows:

  1. Device-specific RF style sheet (if specified).

  2. User Profile RF style sheet (if specified).

  3. RF style sheet specified in technical values configuration (if specified).
