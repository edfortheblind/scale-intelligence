
        
        <h1 data-source-node="n56"><a name="kanchor1036" data-source-node="n57"></a>Releasing Work Units</h1>
        <p data-source-node="n58">You can manually release individual work units, instead of releasing 
 the entire wave. This is especially helpful when you can only process 
 a set number of units due to warehouse constraints, such as time, equipment 
 or personnel. If you held a work unit, you will also need to release it 
 manually. Also, if a work unit was previously placed into a "held" status, 
 then you will need to manually release it.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Prerequisites...</h4>
        <p data-source-node="n62">The procedures below assume the following:</p>
        <ul data-source-node="n63">
            <li data-source-node="n64">The wave that generated the work has not 
 been released to the warehouse.<br data-source-node="n65"><br data-source-node="n66">OR</li>
        </ul>
        <ul data-source-node="n67">
            <li data-source-node="n68">The work unit was previously placed in a held 
 status.</li>
        </ul>
        <p data-source-node="n69"> </p>
        <h4 data-source-node="n70">Procedures...</h4>
        <ol data-source-node="n71">
            <li value="1" data-source-node="n72">
                <p data-source-node="n73">Open the Work Insight Screen.</p>
                <p data-source-node="n74"> </p>
            </li>
            <li value="2" data-source-node="n75">
                <p data-source-node="n76">Access the held work unit.</p>
                <p data-source-node="n77"> </p>
            </li>
            <li value="3" data-source-node="n78">Select the Hold 
 Action. The system will display the Hold Code Screen. Remove the 
 value in the Hold Code Field. As long as this field is blank, the system 
 will release the work.</li>
            <p data-source-node="n79"> </p>
            <li value="4" data-source-node="n80">The system will 
 release this work unit, and it can now be processed by an employee.</li>
        </ol>
