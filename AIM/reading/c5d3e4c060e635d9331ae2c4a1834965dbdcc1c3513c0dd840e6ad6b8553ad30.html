Always Override Checkbox

During the allocation rule set assignment process, the system does the following:

  1. Selects all shipment/receipt lines that do not have an allocation/locating rule assigned.

  2. Reviews each active allocation rule assignment record in priority order.

  3. Using the filter tied to the allocation rule assignment record to determine eligibility, the system updates the allocation/locating rule on the matching details. If the shipment/receipt line already had a rule assigned by a previous sequence, then it will only be updated if the"Always Override" setting is selected.
