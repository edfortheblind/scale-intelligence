
        
        <h1 data-source-node="n56"><a name="kanchor773" data-source-node="n57"></a>Maximum Weight Field</h1>
        <h5 data-source-node="n58">On the Work Creation Master...</h5>
        <p data-source-node="n59">This field indicates the most weight that can be processed in a 
 particular wave or work unit. The  work creation process will start a new work unit when it senses that adding the next work instruction to the current work unit will exceed this maximum value. Note that if a single work instruction in and of itself exceeds this maximum, the instruction will be placed onto a work unit by itself.  It will NOT be broken down into multiple work instructions.</p>
        <p data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"> The weight is always calculated as the base unit of measure quantity (example: eaches) multiplied by the weight of the item,  regardless of whether the quantity is sufficient to make a higher unit of measure (such as a case or pallet) or not.</p>
        <p class="p_1" data-source-node="n62"> </p>
        <p data-source-node="n63">For example:</p>
        <ul data-source-node="n64">
            <li data-source-node="n65">Suppose the Maximum Weight value is set to 100 pounds on the shipment allocation work creation master record.<br data-source-node="n66"><br data-source-node="n67"></li>
            <li data-source-node="n68">The shipment has four details (item 1 = 60 pounds, item 2 = 40 pounds, item 3 =30 pounds, item  4 = 80 pounds).<br data-source-node="n69"><br data-source-node="n70"></li>
            <li data-source-node="n71">The first item will get added to the first work unit (weight=60).  The system will not break the detail.<br data-source-node="n72"><br data-source-node="n73"></li>
            <li data-source-node="n74">The second item will get added to the second work unit (weight= 100). The system will not break the detail.<br data-source-node="n75"><br data-source-node="n76"></li>
            <li data-source-node="n77">The third item will get added to the third work unit (weight=30). The system will not break the detail.<br data-source-node="n78"><br data-source-node="n79"></li>
            <li data-source-node="n80">The fourth item will NOT get added to the third work unit, because it would exceed the maximum weight value (volume would equal 110). Therefore, the fourth item will get added to the fourth work unit.</li>
        </ul>
        <p data-source-node="n81"> </p>
        <h5 data-source-node="n82">On Weight Break Window...</h5>
        <p data-source-node="n83">This field is used as part of the rate base to define the weight breaks used for LTL internal rating. The system will look at the shipment weight and compare it to the weight in these fields (the weight breaks) to obtain the rate per pound. The last record must have an entry of all 99999's to maximize the field and catch all weights. This field is defined on the Weight Break configuration and then used as part of the Rate Base table.</p>
