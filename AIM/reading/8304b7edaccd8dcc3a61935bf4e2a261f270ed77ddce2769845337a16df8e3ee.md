
        
        <h1 data-source-node="n56"><a name="kanchor162" data-source-node="n57"></a>Warehouse Authorization</h1>
        <p class="p_1" data-source-node="n58"> This tab enables you to select and identify the warehouse for the work profile configuration.</p>
        <p class="p_1" data-source-node="n59"> </p>
        <h5 data-source-node="n60">On Creating Work Profiles screen</h5>
        <p data-source-node="n61">This tab is used to identify the warehouses which will have work profile access.</p>
        <p class="p_1" data-source-node="n62"> </p>
        <h5 data-source-node="n63">On Define Adjustment Type screen</h5>
        <p data-source-node="n64">This tab is used to identify the warehouses for which the inventory management screen will have access for performing all adjustment types on the inventory.</p>
        <p data-source-node="n65"> </p>
        <ul data-source-node="n66">
            <li data-source-node="n67"><b data-source-node="n68">All</b> - If this radio button is selected, the configuration will have access to all warehouses. When new warehouse is added to the system records, the configuration will have automatically has access to them.</li>
            <li data-source-node="n69"><b data-source-node="n70">List</b> - If this radio button is selected, the system will allow you to select the required warehouse  from the list. You can select one or more values.</li>
        </ul>
