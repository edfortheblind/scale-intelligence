        <h4 data-source-node="n85"><a name="Process" data-source-node="n86"></a>Process</h4>
        <p data-source-node="n87"> </p>
        <p data-source-node="n88">Print using the Print selected documents option.</p>
        <p data-source-node="n89"> </p>
        <p data-source-node="n90">1.	SCALE system manifests a shipping container and printing is initiated (if printing option is selected) for collating the pack list . </p>
        <p data-source-node="n91"> </p>
        <p data-source-node="n92">2.	A shipping label is generated and saved as an image in a label table which is linked to the internal container number.</p>
        <ul data-source-node="n93">
            <li data-source-node="n94">
                <blockquote data-source-node="n95">
                    <p data-source-node="n96">If a return label is also printed, then the return label is also saved to the same table.</p>
                </blockquote>
            </li>
        </ul>
        <p data-source-node="n97">3.	PDF document is generated.</p>
        <p data-source-node="n98"> </p>
        <p data-source-node="n99">4.	Using document routing configuration will process which document is required, then the system will generate the PDF to the corresponding printer</p>
