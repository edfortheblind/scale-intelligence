Maintain Allocated Replenishments Upon Wave Cancellations Checkbox

This checkbox determines if the system should "maintain" a replenishment request from the wave if it is canceled. If this checkbox is selected and the system leaves the replenishment, the system will remove the request from the wave (along with its corresponding work). Note that the only time a replenishment will stay out on the system is if some other process has allocated the inventory that is being replenished. In this case, the system will leave the replenishment out there so as not to cause problems with the subsequent activity that allocated it. The system also generates history records that indicate the replenishment request and work was left from the wave.

 

For example:

- Suppose you run Wave1 which creates a replenishment for 10 of an item, and Wave1 allocates 3 of those.

 

- You then run Wave2, which allocates 5 of the same item from that same location

 

- If you now cancel Wave1 the system will leave a replenishment for 10 out there so that it does not cause problems with Wave2.
