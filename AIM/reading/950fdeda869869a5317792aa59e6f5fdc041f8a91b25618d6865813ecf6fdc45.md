
        
        <h1 data-source-node="n56"><a name="kanchor1269" data-source-node="n57"></a>Failover Partner Field</h1>
        <p data-source-node="n58">The Failover Partner field is the machine name of "mirrored" server when database mirroring is set up.  This gets added to the connection string stored for the database.  If you are not using database mirroring, leave this field blank.</p>
