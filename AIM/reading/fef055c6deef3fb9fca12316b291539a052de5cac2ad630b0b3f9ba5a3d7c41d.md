
        
        <h1 data-source-node="n56"><a name="kanchor677" data-source-node="n57"></a>Sign Release Auth Number Field</h1>
        <p data-source-node="n58">This field indicates the signature release authorization number that 
 is on file with FedEx. This value releases the FedEx courier from requiring 
 a signature upon package delivery. </p>
