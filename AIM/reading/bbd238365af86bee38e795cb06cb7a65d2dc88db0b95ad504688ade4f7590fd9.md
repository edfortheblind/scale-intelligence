        <h4 data-source-node="n73">Procedures...<br data-source-node="n74"></h4>
        <h5 style="font-weight: normal" data-source-node="n75">Open the Configurations Explorer. Choose the "Find Attribute" 
 option from the Actions Menu. The system will open the Find Attribute 
 Window.</h5>
        <ol class="ol_1" data-source-node="n76">
            <li value="1" data-source-node="n77">Use the Attribute 
 Field to indicate the field value you want to search for.<br data-source-node="n78"> </li>
            <li value="2" data-source-node="n79">Press the Search 
 Button. The system will display in the record list the field value 
 (Attribute) and what configuration 
 windows (Form Key Name) on which 
 this field appears. If you double-click a field value, the system will 
 navigate to the specific configuration window that contains this value.<br data-source-node="n80"> </li>
            <li value="3" data-source-node="n81">When finished, 
 press OK, and the system will close the Find Attribute Window.</li>
        </ol>
