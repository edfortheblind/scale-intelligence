
        
        <h1 data-source-node="n56"><a name="kanchor915" data-source-node="n57"></a>Creating Inventory Attribute Values</h1>
        <p data-source-node="n58">The application features twenty separate inventory attribute configurations, with each representing one of the twenty inventory attribute values that the system tracks in various functional areas. You will use these configurations to define a list of attributes values that can be selected from a drop-down field during processing. For example, if you create three "country of origin" values (United States, Canada, Mexico) in the Inventory Attribute 01 configuration, then these three country values will appear as selectable options in the Inventory Attribute 01 field on the appropriate processing screen (RF receiving, RF location inquiry).</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: You will still need to <a href="38fb81f6457cd50c53769ba3128a39f6113904e00fb18aedff5e02bb4c9573eb.html" data-source-node="n61">activate the validation</a> of these attributes in order for the system to force the user to select one of the pre-defined values on processing screens.</p>
