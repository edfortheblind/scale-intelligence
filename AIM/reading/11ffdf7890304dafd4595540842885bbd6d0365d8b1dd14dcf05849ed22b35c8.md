
        
        <h1 data-source-node="n56"><a name="kanchor973" data-source-node="n57"></a>License Plate Assignment Method Field</h1>
        <p data-source-node="n58">This value determines if the user will assign or verify license plate IDs. 
 It is defined on the Work Order Preference Window.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61">If this field contains the value 
 <i data-source-node="n62">System</i>, the system assigns the license plate ID and the user only verifies 
 it.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li data-source-node="n64">If 
 this field contains the value <i data-source-node="n65">Manual</i>, the employee assigns the license plate 
 ID.</li>
        </ul>
