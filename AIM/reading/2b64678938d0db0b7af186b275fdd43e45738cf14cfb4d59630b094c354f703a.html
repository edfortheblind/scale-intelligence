Template Field

Using the Interface...

This field identifies the XML schema that you want this trigger header record to use when processing the system data. The system Template values represent a list of the available schemas that the user can choose from to use for their mapping. The system uses this template to grab each of the attributes from that template and place them in the Billing Management list.

 

 

On the Item Window...

Use this field to select a template that the system will use to validate an entered serial number. You can also choose to not select a template, and then the user will be able to enter any combination of characters for a serial number.

 

 

On the Notification Window...

This field indicates the template that the system will use to generate a notification. The following template formats are supported: XML, HTML, plain text, and rich text. Inside the template, such things as links to Insight screens, links per data row returned in .csv file, and header/footer data. See the SDK for more information/examples on notification templates.
