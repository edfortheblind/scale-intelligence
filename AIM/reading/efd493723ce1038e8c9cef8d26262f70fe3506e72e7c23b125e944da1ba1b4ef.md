
        
        <h1 data-source-node="n56"><a name="kanchor1175" data-source-node="n57"></a>Include Inactive Checkbox</h1>
        <p data-source-node="n58">You can use this checkbox to indicate whether or not you want the system 
 to include inactive records in the results of a field lookup window search. 
 If this checkbox is selected, the system will display all records regardless 
 of their active/inactive status. Note that this checkbox only appears 
 on certain field lookup windows.</p>
