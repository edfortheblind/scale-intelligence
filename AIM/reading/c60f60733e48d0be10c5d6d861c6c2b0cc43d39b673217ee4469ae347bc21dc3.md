
        
        <h1 data-source-node="n56"><a name="kanchor1470" data-source-node="n57"></a>Increment Field</h1>
        <p data-source-node="n58">This field determines how the system will increment locations when it 
 creates a location range.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Incrementing Numeric Locations...</h5>
        <p data-source-node="n62">When the system increments numeric locations, it increments through 
 all positions in the location number.</p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64">In the example below, the location range includes two aisles. Each aisle 
 has two bays; each bay is three levels high. To obtain a location number 
 for each location in these aisles, you would provide the following increment 
 value: 001-001-001. As the values in the Locations Created column illustrate, 
 the system will increment across number positions.</p>

        <p data-source-node="n111"> </p>
        <p data-source-node="n112">Note: if you select an increment other than 001, the system will increment 
 by that value. For example, if you incremented by 001-001-002, the system 
 would have created 'every other location: 001-001-001, 001-001-003, etc. 
 In this case, it would skip all even numbered levels.</p>
        <p data-source-node="n113"> </p>
        <p data-source-node="n114"> </p>
        <h5 data-source-node="n115">Incrementing Alpha Locations...</h5>
        <p data-source-node="n116">When the system increments alpha locations, it increments by position 
 only. This minimizes setup errors and decreases the likelihood that you 
 will generate too many locations.</p>
        <p data-source-node="n117"> </p>
        <p data-source-node="n118">In the example below, the location range includes three shelves. Each 
 shelf has three bays. To obtain a location name for each location in these 
 shelves, you would provide the following increment value: 11. As the values 
 in the Locations Created column illustrate, the system will <span class="span_3" data-source-node="n119">not</span> 
 increment across number positions. Once it reaches the last letter in 
 the ending location sequence, it attempts to create new locations using 
 the next starting location letter.</p>
