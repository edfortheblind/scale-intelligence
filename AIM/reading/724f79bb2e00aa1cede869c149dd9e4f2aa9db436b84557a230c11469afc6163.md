
        
        <h1 data-source-node="n56"><a name="kanchor634" data-source-node="n57"></a>Printed As Buttons</h1>
        <p data-source-node="n58">When you define a document, you will need to identify what application 
 generates it. Depending on which type of document you choose, the appropriate files will appear in the Document Template Field.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">Reporting Services document - Choose this option if you want to generate a SQL Server Reporting Services (SSRS) document. The template file extension for SSRS documents is .rdl.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">
                <p data-source-node="n64">Progistics document - Choose this option if you want to generate a Progistics document.<br data-source-node="n65"><br data-source-node="n66"></p>
            </li>
            <li data-source-node="n67">Progistics label 
 - Choose this option if you want to generate a Progistics shipping label.<br data-source-node="n68"><br data-source-node="n69"></li>
            <li data-source-node="n70">SCALE label 
 - Choose this option if you want to generate a SCALE vendor compliant label.  The template file extension for SCALE labels is .lbl.<br data-source-node="n71"><br data-source-node="n72"></li>
            <li data-source-node="n73">FedEx 
 document/label - Choose this option if you want to generate a FedEx document/label.<br data-source-node="n74"><br data-source-node="n75"></li>
            <li data-source-node="n76">Microsoft Word document -Choose this option if you want to generate a Microsoft Word document. The template file extension for Microsoft Word documents is .doc.<br data-source-node="n77"><br data-source-node="n78"></li>
            <li data-source-node="n79">External Document/Label - Choose this option if you want to generate shipping labels or container manifests with an outside application that is not represented as an option on this field.  When the application encounters a document of this type, it calls into the Rating Service Action of PrintLabel or PrintManifest.<br data-source-node="n80"></li>
        </ul>
