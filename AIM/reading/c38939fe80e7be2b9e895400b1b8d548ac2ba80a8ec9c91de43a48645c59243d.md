
        
        <h1 data-source-node="n56">Build Wave Screen</h1>
        <p data-source-node="n57">You will use this screen to build wave(s) for a certain warehouse. During the wave building process, the system assigns pooled shipments 
 to the appropriate wave(s). You can either choose a specific wave master and /or warehouse for the system to use when building the new wave. Only the authorized  wave masters  for the selected warehouse are shown.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">Note that if you do specify a wave master, the system uses the wave criteria (associated with that wave master), and assigns shipments to that wave.  The system will only do the selections for that particular wave master and warehouse if the warehouse is specified.</p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">From Wave Insight: </h5>
