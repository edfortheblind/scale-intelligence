
        
        <h1 data-source-node="n56"><a name="kanchor1889" data-source-node="n57"></a>CC Group Number Field</h1>
        <p data-source-node="n58">This field indicates the numeric identifier of a system-created cycle 
 count "group." These groups are defined as part of a cycle count 
 plan. The system will create group(s) to collate cycle count instructions 
 into, which allows them to be assigned to the most appropriate user. When 
 the maximum group size is reached, the system will begin sorting the instructions 
 into another group, and so on, until all the instructions have been processed. 
 Each group is given a unique identifier.</p>
