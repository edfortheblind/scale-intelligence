
        
        <h1 data-source-node="n57"><a name="kanchor2079" data-source-node="n58"></a>Print Procedure Field</h1>
        <p data-source-node="n59">This field identifies what type of record the system can generate 
 paperwork for. Paperwork is always run in conjunction with a print procedure. Print procedures are associated with document types on the Document 
 Type Window. When paperwork is run, the system processes through the document 
 type records and checks the print procedure(s). If the print procedure 
 on the document type is the same one that initiated the print job, the 
 system will print the paperwork associated with this document type.
 For example, if you print from the Packing screen, paperwork is run 
 for the Shipping Container print procedure. </p>
        <p data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61">NOTE: 
 You cannot deselect 
 a predefined print procedure from a default document type, but you can 
 add new ones.</p>
