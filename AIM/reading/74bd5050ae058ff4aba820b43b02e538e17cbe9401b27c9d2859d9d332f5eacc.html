UPS World Ease Paperwork

The following documents are related to the UPS World Ease Paperwork:

  • UPS World Ease Box Label: This label is affixed on the Document Box. It identifies the hub that the World Ease group is being shipped to.
     
  • UPS World Ease Consolidated Invoice: This document summarizes the World Ease group. It identifies the individual consignees (the final ship to destinations beyond the hub), the number of containers per ship to destination, the container tracking number(s), and the total cost/weight per consignee.
     
  • UPS World Ease Certificate of Origin: This document is printed per shipment. It is only printed if the final ship to destination is in a country that requires a Certificate of Origin.
     
  • UPS World Ease Master Invoice: This document is printed per shipment. It details what items are on the shipment and their value.

 

For more information on the actual procedures for using this paperwork, see the topic Processing UPS World Ease Shipments.

 

 

 

Note On Rating Printer Stock Symbol...

Where for printing with the label templates "TANDATA_UPS_WORLD_EASE_MAXICODE.STANDARD" or "TANDATA_UPS_DOCBOX.STANDARD," set the Rating Printer Stock Symbol on the Print Device Window  to THERMAL_LABEL_UPS_WORLDEASE.

 

 

 

Document Routing Note...

When the system evaluates a document routing record for printing World Ease paperwork, it will consider the following values as they are defined on the appropriate Intermediate Consignee record (all other values will be evaluated as defined on the shipment):

  • Country

  • User Defined Fields
