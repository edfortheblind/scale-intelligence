
        
        <h1 data-source-node="n56"><a name="kanchor1675" data-source-node="n57"></a>QC Evaluation Method Field</h1>
        <p data-source-node="n58">This field determines when the system will evaluate and assign outbound QC to shipping containers. You will have to choose at least one of these options (you can also choose both):</p>
        <ul data-source-node="n59">
            <li data-source-node="n60"> <i data-source-node="n61">Wave</i>: The system will evaluate and assign QC to containers created in the wave, if the QC Assignment wave step is in your wave flow, and the QC assignment criteria is met.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64"><i data-source-node="n65">Start Work</i>: The system will evaluate and assign QC to containers at the time of work unit start, if the QC assignment criteria is met.<br data-source-node="n66"><br data-source-node="n67"></li>
            <li data-source-node="n68"><i data-source-node="n69">Manual</i>: The system will assign QC when a user manually marks a container for QC using the Mark for QC action on the Shipment Insight screen or RF Shipping Container QC screen.  Note that only one QC assignment record can be created that uses the "Manual" method of assignment.</li>
        </ul>
