Putaway Into Shipping Container Checkbox

This option indicates that you want the user to place product directly into shipping containers during the RF putaway process. Using this option, the system will either create a new shipping container, or add the item to an existing shipping container (whichever is appropriate). If a quantity less than is on the work instruction is entered, the system adds the quantity to the shipping container specified (new or existing). The system splits the work instruction into two work instructions. (This is only valid for work instructions tied to shipment lines either through allocation or through immediate needs). The user will be required to put away the entire quantity. 

 

Note that this functionality cannot be used if there was already a shipping container created for the shipment line during the wave or RF picking.

 

Also, when performing putaway to shipping container, the system does not prompt for a catch weight value if the item requires catch weight.
