
        
        <h1 data-source-node="n56"><a name="kanchor1068" data-source-node="n57"></a>Reconciling Cycle Counts (Insight Screen &amp; RF)</h1>
        <p data-source-node="n58">Reconciling is the process that occurs after a count of a location has been performed, when someone (usually a supervisor) indicates to the system that the system's 
 count of a location's item quantity was indeed incorrect, and what the correct item quantity actually is. For example, suppose the system says 
 that there are 10 eaches of an item in a particular location. When executing 
 a cycle count, however, the worker counts 14 eaches. A supervisor then would need 
 to "reconcile" the new item quantity that is currently present in the location. You can reconcile 
 cycle counts via an RF device or from the Cycle Count Request Insight screen. </p>

        <h4 data-source-node="n153"><a name="Note" data-source-node="n154"></a>Note About Reconciling at a Location Where Inventory Has Been Added...</h4>
        <p data-source-node="n155">When someone has added an item to a location during a cycle count, that item quantity is put into pending review status, if the quantity is outside of tolerances 	(for either a single or a multi item 	location), or it is a single item location associated 	with another item (such as another 	item on hand/in transit, or it is another 	item's permanent location). If there is another item associated with the location at which you are attempting to reconcile quantity, then you will not be allowed to reconcile from the Cycle Count Request Insight. Instead, you will need to use the Inventory Adjustment screen to adjust out the old item quantity from the location. Then you can return to the Cycle Count Request Insight to reconcile the new item's quantity.</p>
        <p data-source-node="n156"> </p>
        <p data-source-node="n157">See the topic <a href="326bf27ca3e89d45e0dc4280931d207e69f4f5fe0d7e29f31bcddc2f52792391.html" data-source-node="n158">Confirming Cycle Counts</a> for more information on adding items during cycle counting.</p>

        <h4 data-source-node="n164"><a name="RecCycleCouReq" data-source-node="n165"></a>Procedures: Reconciling from the Cycle Count Request Insight Screen...</h4>
        <ol data-source-node="n166">
            <li value="1" data-source-node="n167">Access the Cycle Count Request Insight Screen.<br data-source-node="n168"><br data-source-node="n169"></li>
            <li value="2" data-source-node="n170">Select a cycle count request and click on the Reconcile Action. The Cycle Count Reconcile screen opens. <br data-source-node="n171"><br data-source-node="n172"><ol data-source-node="n173"><li value="1" data-source-node="n174"><p data-source-node="n175">The action is enabled for the cycle count requests which are in 'pending review' status.<br data-source-node="n176"><br data-source-node="n177"></p></li><li value="2" data-source-node="n178"><p data-source-node="n179">The action is also enabled for cycle count requests with 'open' status only if the cycle count request is created without work.<br data-source-node="n180"><br data-source-node="n181"></p></li><li value="3" data-source-node="n182"><p data-source-node="n183">Canceling the screen without making any changes will close the screen without any changes to location inventory as well as cycle count request.<br data-source-node="n184"><br data-source-node="n185"></p></li><li value="4" data-source-node="n186">Canceling the screen after some modifications will show a message indicating that there is an uncommitted data and seek confirmation from the user and on confirmation the screen is cancelled without any modifications to any of the data.</li><br data-source-node="n187"></ol></li>
            <li value="3" data-source-node="n188">
                <p data-source-node="n189">Enter the reconcile quantity and submit the request for reconciliation. This will update the location inventory and writes the transaction history for the adjustment that has happened.</p>
            </li>
        </ol>
        <p data-source-node="n190"> </p>
        <p data-source-node="n191">NOTES: </p>
        <ul data-source-node="n192">
            <li data-source-node="n193">The reconciling will prompt for serial number entry when the item has been set up to track serial numbers in inventory.<br data-source-node="n194"><br data-source-node="n195"></li>
            <li data-source-node="n196">An existing serial number can be selected by entering the serial number into the text box and pressing the Add/Select button or checking the serial number in the grid.<br data-source-node="n197"><br data-source-node="n198"></li>
            <li data-source-node="n199">A new serial number can be added by entering the serial number into the text box and pressing the Add/Select button.</li>
        </ul>

        <h4 data-source-node="n204"><a name="RF" data-source-node="n205"></a>Procedures: Reconciling Using an RF Device...</h4>
        <ol class="ol_2" data-source-node="n206">
            <li value="1" data-source-node="n207">Log on to your 
 RF Device. <br data-source-node="n208"> </li>
            <li value="2" data-source-node="n209">Choose the "Cycle 
 Count Reconcile" function from the RF Main Menu screen. The system will display the Cycle Count Reconciliation screen.<br data-source-node="n210"> </li>
            <li value="3" data-source-node="n211">Narrow down the 
 reconcile requests that the system will display by entering values 
 for the fields on the Cycle Count Reconciliation screen. For example, 
 if you enter a value in the Item Field, the system will display any reconcile 
 requests that exist for this particular item. Or, you can simply press the OK Button, and the system will display a request to reconcilate.<br data-source-node="n212"> <br data-source-node="n213">NOTE: If the location tracks license plates, 
 the system will have you enter or verify the License Plate ID during the reconciliation 
 process.<br data-source-node="n214"> </li>
            <li value="4" data-source-node="n215">Press OK. 
 The system will display all applicable reconcile requests, ordered in 
 location sequence. If you want more detailed information about a request, 
 press the Details Button. <br data-source-node="n216"> </li>
            <li value="5" data-source-node="n217">Review the item 
 quantity information as needed (you can press the Details button for further information):<br data-source-node="n218"><br data-source-node="n219">- Use the Quantity Counted Field to view the item quantity that 
 the user entered when performing the original cycle count.<br data-source-node="n220"><br data-source-node="n221">- Use the On Hand Quantity Field to indicate the item quantity (and its unit of measure)
 that is currently present at the location.<br data-source-node="n222"><br data-source-node="n223">- The location quantity values on the Details page reflect the quantities that are present in the location at the time of the reconcile, NOT at the time that the cycle count was performed.<br data-source-node="n224"> </li>
            <li value="6" data-source-node="n225">Press OK. 
 The system will reconcile that location, and display the next request 
 (if one exists). Note that you can press the Cancel Button to skip any 
 request that the system displays. Skipped requests will remain in the 
 "Pending Review" status.<br data-source-node="n226"><br data-source-node="n227">SERIAL NUMBER NOTE: If the item being reconciled is serial number 
 tracked, the system will ask you to enter these values as well. Press 
 OK when finished.</li>
        </ol>
