Notes
  • This topic discusses specific fields represented on this screen as it is shipped in the base SCALE product. If your screen has been customized, different field(s) may appear on your screen.

Searching/Viewing Receipt Records...

You can use the Receipt Insight Screen to search for and view receipt records in your warehouse.

  1. Open the Receipt Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search:

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

  • The Receipt Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Receipt Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

 

The Detail Pane of Receipt Insight contains Indicator Tiles with counts of the other entities (i.e. receipt lines and receipt containers). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Lines
    1. Displays the number of lines on the receipt.

    2. Clicking on this tile takes you to Receipt Line Insight screen filtering on the internal receipt number.

  2. Containers

    1. Displays total number of parent containers on the receipt.

    2. Clicking on this tile takes you to Receipt Container Insight filtering on the internal receipt number.


For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

 

 

Screen Actions...

The following actions are accessible from the Receipt Insight screen:

 

New

This action allows you to create a new receipt. Clicking the New action opens Receipt Screen in new mode. For more information on this topic, see Creating a Receipt and Receipt Line.

 

 

Edit

This action allows you to change field values on the receipt. When this action is selected, the system will open the Receipt Screen in edit mode. This action will appear if the user has security access to the "Change" checkpoint.

 

 

Delete

This action allows you to delete single or multiple receipts at a time and is enabled for the receipt with leading and trailing status of 'Check-in pending'. Invoking this action will display a confirmation message and the receipt(s) will be deleted if you accept the prompt.

 

 

New Container

This action allows you to create a new receipt container. Clicking the New container action after selecting a specific receipt will open the Receipt Container Screen in new mode.

 

 

New Line

This action allows you to create a new receipt line. If you click on this action after selecting a specific receipt, the system will open the Receipt Line Screen in new mode. For more information on this topic, see Creating a Receipt and Receipt Line.

 

 

Assign Trailer ID

This action helps you to assign a trailer ID to for receipts that are coming in on the same trailer. You can assign a trailer ID for single or multiple receipts at a time. After the Trailer ID is entered and saved, you will receive a confirmation message showing successful assignment. You can also modify the existing Trailer ID(s) for single or multiple receipts. However, the action is enabled for the receipt with leading and trailing status less than "Closed" Also, if a receipt is assigned to a trailer ID that has already been checked in through yard management, that trailer ID cannot be changed until the trailer ID has been checked out of yard management. For information on the check in/check out procedures, see Using the Yard Check In / Out Window.

 

 

New Appointment

This action allows you to create receiving appointment schedules. For more information, see the topic Creating/Viewing Receipt Appointments.

 

View/Edit Appointment

View appointment enables you to view the appointment details. The edit Appointment enables you to edit an scheduled appointment.

The options View Appointment or Edit Appointment is displayed based on the user security permission. For more information, see the topic Creating/Viewing Receipt Appointments.

 
Cancel Close

This action enables you to reopen a closed receipt or multiple closed receipts at a time for further processing. If you click on this action after selecting receipts, the close dates will be cleared from the receipts and the receipts will be displayed in open receipts. The action is disabled for the receipts other than closed receipts. A warning message is shown if the receipt information is already uploaded to ERP (Interface upload) and you attempt to "cancel close" the receipt.

 

 

Check in

This action allows you to access the Receipt Workbench screen where the selected receipt ID and the receiving preference will be displayed by default. You can change the receiving preference and proceed to process the receipt. This action is enabled only when a single receipt record is selected. For more information on this topic, see Checking in and locating product.

 

 

Create Pre-Check in Containers

This action helps you to create a receipt container before going through the check in process. Accepting the confirmation message will create pre-check in containers for all the eligible receipt details and success message is shown. For more information on this topic, see Processing Receipts.

 

 

Close

This action enables you to close a receipt or multiple receipts at a time. Invoking the action also updates the close date on the receipt and you will receive a success message. The action is enabled for receipts with leading and trailing status less than "Closed". Note that you can manually close a receipt irrespective of what status the receipt quantity is in.

 

 

Delete Appointment

This action allows you to delete the receipt appointments. You can use this action to delete appointments for single receipt or multiple receipts and this action is enabled for the receipts which has scheduled appointment.

 

 

Immediate Needs

This action allows you access the Immediate Needs Insight Screen with predefined search criteria based on your selection from the Receipt Insight. Here the system will pass the warehouse and show requests corresponding to the warehouse. This action is enabled if the receipt line has at least one immediate needs item and there is an immediate needs request tied to this line. If the immediate needs request is fulfilled, this action will be disabled.

 

 

Print Preview

This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to Printing Paperwork.

 

 

Print Default Docs

This action allows you to print the default receiving documents that have both the print procedure for "Receipt" setting and the default setting selected on the document’s document type record. The system will display a success message to confirm that the documents were successfully printed. The system will display an error message in case a problem is encountered.

 

 

Print Selected Docs

This action allows you to print all the selected documents. You can cancel or exit out of print select without printing. For more information on printing topic, see the Printing Paperwork topic.

 

View

This action allows you to reference field values on the receipt. When this action is selected, the system will open the Receipt Screen in view mode. This action will appear if the user does not have security access to the "Change" checkpoint.

 

 

Yard Check in and Out

This action allows you to perform Yard Check In/Out from Receipt Insight. Selecting a receipt and invoking the action will open the Yard Check In and Out Screen (with the Trailer ID Field already populated). For more information, see the topic Using the Yard Check in and Out Screen.
