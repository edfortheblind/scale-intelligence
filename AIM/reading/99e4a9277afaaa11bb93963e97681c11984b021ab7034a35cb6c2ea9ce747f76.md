
        
        <h1 data-source-node="n56"><a name="kanchor1468" data-source-node="n57"></a>Negative Adjustment Type Field</h1>
        <p data-source-node="n58">This field indicates the inventory adjustment type the system should use when performing negative inventory adjustments during the cycle counting process.  If this value is left blank, the system then will use the adjustment type value specified in the "Planned Count - Negative Adjustment" cycle count system value setting.</p>
