Item Location Assignment

Overview

 

The Item Location Assignment process allows you to assign items to specific locations within a warehouse. This is a single-step configuration where you enter the necessary item and location information.

 

Enter Item and Location Information

 

Complete the following fields to assign an item to a location:

 

Item – Enter the item number or code. This field is required. The system will validate that the item exists in the system.

Company – Select the company associated with this item location assignment. This field is typically pre-populated based on your user context.

Permanent Location – Enter the permanent storage location code for the item. This field is required. This location code should match a valid location defined in your warehouse configuration.

Warehouse – Select the warehouse where the item location is being assigned. This field is required. The warehouse determines which location codes are available for assignment.

Quantity UM – Select the unit of measure for the quantity associated with this item location assignment. This field is optional and depends on your warehouse configuration.

 

Completing the Assignment

 

After entering all required information, you have the following options:

  • BACK – Return to the previous screen without saving changes.
  • EDIT USER DEFINED FIELDS – Add or modify custom fields that may be required for your organization's specific needs.
  • FINISH – Save the item location assignment and complete the process.

Once you click FINISH, the item location assignment will be saved to the system and the item will be associated with the specified location in the selected warehouse.
