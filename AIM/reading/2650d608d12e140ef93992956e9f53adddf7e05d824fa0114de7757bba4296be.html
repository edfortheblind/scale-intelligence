Searching/Viewing User Activity Records...

You can use the User Activity Insight Screen to search for and view user activity records in your warehouse.

  1. Open the User Activity Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply button. The system will display the resulting records in the List Pane.

 

 

About the List Pane...

  • The User Activity Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

About the Detail Pane...

  • The User Activity Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

  • For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

 

Screen Actions...

The following actions are accessible from the List Pane:

 

Log Off Vocollect User

This action allows you to log off one or multiple Vocollect users from SCALE. System prompts for a confirmation whether to continue with the log off. Upon clicking Yes in the confirmation, the user gets logged off and success message gets displayed.

  • This action remains disabled when no warehouse workers are logged into a Vocollect device.

  • This action remains disabled when some are eligible to be logged of while rest are not in case of multiple selected records.
