
        
        <h1 data-source-node="n56"><a name="kanchor1395" data-source-node="n57"></a>Print Mode Field</h1>
        <p data-source-node="n58">This field determines when in the wave process you want documents or labels to generate/print:</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60"><i data-source-node="n61">Print During 
 Wave</i>: The system will generate and print the document/label files when executing 
 the corresponding paperwork wave step. <br data-source-node="n62"> </li>
            <li data-source-node="n63"><i data-source-node="n64">Print At Release</i>: 
 The system will generate and print the document/label files after a wave has been 
 released. Note that when a wave master is set to auto release, wave documents set to print at release will not get printed.  If you wish to get these documents printed, you should select Print during wave.  This will accomplish the same thing, because there is not a separate release step in this scenario. <br data-source-node="n65"> </li>
            <li data-source-node="n66"><i data-source-node="n67">Manual</i>: 
 The system will generate the document/label files during the wave process, but 
 will not print them. The user then can manually print these using 
 the reprint options in the Wave Insight screen. This 
 option is useful if you do not want the user to wait for the system to 
 generate the documents/labels when manually reprinting them (they will have already 
 been generated via the wave).</li>
        </ul>
