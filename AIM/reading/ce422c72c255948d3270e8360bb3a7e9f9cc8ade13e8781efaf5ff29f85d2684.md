
        
        <h1 data-source-node="n56"><a name="kanchor1158" data-source-node="n57"></a>Max Number of Lots Field</h1>
        <p data-source-node="n58">This field limits the number of different Lot ID's that the system can 
 place into a particular location. Note that a value of zero ("0") 
 in this field indicates that the system will place no limits on how many 
 lots are allowed in a location. Note that multi item locations determine the maximum number of lots per item in the location. In other words, every different item present in the location will have its own individual maximum number of lots value.</p>
