
        
        <h1 data-source-node="n56"><a name="kanchor1071" data-source-node="n57"></a>Ending Location Field</h1>
        <p data-source-node="n58">This field indicates the ending location name for a range of new locations 
 to be created. The system will begin creating locations, starting with 
 the location name entered in the Starting Location Field. The system will 
 continue to create locations incrementally (as defined in the Increment 
 Field) until the location name entered in the Ending Location Field is 
 reached. All locations created in this range will have the same characteristics, 
 as defined in the Location Window. If you want to create a single location, do 
 not enter any value in the Ending Location Field or the Increment Field.</p>
