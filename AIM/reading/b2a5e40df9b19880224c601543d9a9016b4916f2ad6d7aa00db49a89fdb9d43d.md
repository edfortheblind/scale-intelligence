
        
        <h1 data-source-node="n56">Charge Requirement Buttons</h1>
        <p data-source-node="n57">You can use these buttons to indicate if an associated rating engine is going to be used to calculate a freight charge.</p>
        <ul data-source-node="n58">
            <li data-source-node="n59"><b data-source-node="n60"><a name="kanchor213" data-source-node="n61"></a>Manually</b> indicates that the charge is going to be manually added to the shipment.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64"><b data-source-node="n65">System Calculated</b> indicates that an internal or external rating service is going to be called to calculate the rate.<br data-source-node="n66"><br data-source-node="n67"></li>
            <li data-source-node="n68"><b data-source-node="n69">Not Required</b> indicates that no rate is required.</li>
        </ul>
