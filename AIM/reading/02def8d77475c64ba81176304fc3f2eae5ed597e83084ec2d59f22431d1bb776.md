
        
        <h1 data-source-node="n56"><a name="kanchor741" data-source-node="n57"></a>Making Items Eligible for Inbound Quality Control</h1>
        <p data-source-node="n58">These settings determine if an item is eligible for the inbound quality control 
 process. If the item is eligible, then the system will suggest splitting 
 off a portion of the item quantity received, if appropriate. You can establish 
 how much of this receipt's item quantity will be sent to inbound quality control, 
 and to which inbound quality control location the system will send it to.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures...</h4>
        <ol class="ol_1" data-source-node="n62">
            <li value="1" data-source-node="n63">Access the Item 
 Window open the appropriate item record, and select the Handling 
 Tab.<br data-source-node="n64"> </li>
            <li value="2" data-source-node="n65">Use the Eligible 
 Checkbox to indicate that an item is eligible for the inbound quality control 
 process. If an item is not QC eligible, the system will not attempt to 
 route any of this item to quality control.<br data-source-node="n66"> </li>
            <li value="3" data-source-node="n67">Use the Compute 
 Qty As Buttons to determine how much quantity of an item should 
 be routed to quality control:<br data-source-node="n68"><br data-source-node="n69">Amount:Choose this method 
 when you want the system to route a certain number of items (per receipt) 
 to quality control. When choosing to compute by amount, you also need 
 to indicate the UM the system is to use when calculating the item quantity. 
 <br data-source-node="n70"><br data-source-node="n71">For example, suppose you have a receipt that has 50 eaches of item 
 AA001. If you enter the value "5" into this field (and "each" 
 as a UM), the system will route five eaches from the original 50 to a 
 quality control location. The system will locate the remaining 45 eaches 
 of this item in an inventory location (according to the locating rule 
 assigned to this item).<br data-source-node="n72"><br data-source-node="n73">Percentage: Choose this 
 method when you want the system to route a certain percentage of items 
 (per receipt) to quality control. You do not need to indicate a UM when 
 the system is calculating the item quantity by a percentage. <br data-source-node="n74"><br data-source-node="n75">For example, suppose you have a receipt that has 50 eaches of item 
 AA001. If you enter the value "20" into this field, the system 
 will route 20 percent of this item (10 eaches) from the original 50 to 
 a quality control location. The system will locate the remaining 45 eaches 
 of this item in an inventory location (according to the locating rule 
 assigned to this item).<br data-source-node="n76"> </li>
            <li value="4" data-source-node="n77">Use the Inspection 
 Qty Field to enter the actual amount/percentage you want the system 
 to set aside for quality control.     Do not 
 use a percentage sign (%) to indicate percentages. For example, 
 you would enter the value 20 percent as "20".<br data-source-node="n78"> </li>
            <li value="5" data-source-node="n79">Use the UM Field 
 to indicate the unit of measure that you want the system to use when calculating 
 how much of an item to route to quality control. If this field is blank, 
 the system will convert the item quantity to the lowest UM (as defined 
 in the Quantity Units Of Measure Window).<br data-source-node="n80"> </li>
            <li value="6" data-source-node="n81">Use the Locating 
 Rule Field to indicate how the system will decide which QC location 
 to move the appropriate item quantity to. See the topic     "Creating 
 QC Locations" for more information.<br data-source-node="n82"> </li>
            <li value="7" data-source-node="n83">Press OK 
 The system will save your changes.</li>
        </ol>
