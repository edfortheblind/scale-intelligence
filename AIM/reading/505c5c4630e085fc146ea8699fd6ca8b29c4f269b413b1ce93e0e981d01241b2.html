Defining Items

If you do not want to interface item records from the ERP, you can define them in SCALE. By defining an item in the system, you can manage how its processed, what allocation and locating rules are applied to it, and what handling controls (lot controlled, etc) are required during processing. Item setup is optional. If you do not want to create records on the Item Window, the system will reference the item values defined on the shipment line records.

Using the Header Fields

You will use these fields to identify the item, its format and the company that distributes it.

  1. Use the Item Template Field to define how the item name is structured. As soon as you provide a value here, the Item Field input fields will accommodate the item template's structure. Note that this field is not required. If you don't select an item template, the Item Field will be a free-format field.

     

  2. If appropriate, use the Company Field to identify the company that will distribute this item. If your warehouse supports multi-company processing, you need to associate each item with the company that sells it. Therefore, if two or more companies use the same value to identify in item, the system can discern which record associated with each company.

     

  3. Use the Item Field and Description fields to identify the product. Provide a name for this record in the Item Field; this field is alpha-numeric. Provide a description. Generally, the values defined in both the Item Field and the Description Field are displayed together. Therefore, if the value in the Item Field is numeric, the user can reference the description value to visually identify the item during processing.

 

Using the General Tab Fields

You will use these fields to identify the item, its format and the company that distributes it.

  1. Use the Allocation Rule Field to associate this item with an allocation rule. An allocation rule determines how the system will select allocation locations. If an item has unique requirements, associate it with an allocation rule that meets its needs. The system will reference this field if an allocation rule was not define on the shipment line.

     

  2. Use the Locating Rule Field to associate this item with a locating rule. A locating rule determines how the system will locate this product to storage locations. The system will reference this field if a locating rule was not defined on the receipt container record. Note that this rule can be overridden if the Always Override setting was selected on the locating rule assignment record.

     

  3. Select the Inventory Tracking Checkbox to track which locations this item is stored in and how many units are associated with each location. The system will use this information to perform allocations and replenishments. This value will already be selected if the Track Inventory Option is selected on the Inventory System Value Window.

     

  4. If appropriate, use the NMFC Code Field to associate an NMFC to this item. The NMFC code links an item to a class for freight rating purposes. Each NMFC value is a sequence of letters and/or numbers representing a group of like items with similar characteristics. It is used primarily by LTL carriers.
     

  5. If appropriate, use the Item Class Field to associate a class to this item. An item class identifies a group of items that share common characteristics, such as unit of measure values and container dimensions. You can use item classes to manage the movement of like items through the warehouse. This is especially helpful for items that share the physical dimensions and space requirements. For example, if your warehouse distributes movie DVDs, you could associate all individual DVDs with the DVD item class.

     

  6. Use the Packing Class Field to link this item to a packing class. A packing class identifies items that can be shipped in the same container. Packing classes also identify which containers this item can be packed into.

     

  7. Use the Storage Template Field to associate this item with a storage template. A storage template groups together quantity UM values that service a general type of product, like liquid, gas, or solid products.

    WARNING: If you change the storage template on an item to one that has a different base unit of measure, the system will change the UM on all related data, such as existing inventory, open shipments, and open receipts.

 

Using the Item Characteristics (1) Tab Fields

You will use these fields to define the basic characteristics for your item.

  1. Use the Division and Department Fields to associate these values to the item.
     
  2. Use the Item Size Field to indicate the size of the item, such as S, M, L, XL.
     
  3. Use the Item Color Field to indicate the color of the item.
     
  4. Use the Item Style Field to indicate the style of the item.
     
  5. Use the Shipment BOM Action Field:See the field topic for a description.

 

Using the Item Characteristics (2) Tab Fields

You will use these fields to further define the basic characteristics for your item.

  1. Use the Cost Field to indicate the net cost of this item.
     
  2. Use the List Price Field to indicate the original price for this item.
     
  3. Use the Net Price Field to indicate the discounted price for this item.
     
  4. Use the EPC Company Prefix Field to indicate the pre-defined identifier for a company associated with a particular item. This value is used when the system computes an Electronic Product Code (EPC).
     
  5. Use the EPC Item Reference Field to indicate the identifier that is given to this item and its packing level (unit, inner-pack, case, or pallet). This value is used when the system computes an Electronic Product Code (EPC).
     
  6. Use the CAGE Code Field to identify that this item is associated with a company that does business with the United States Federal Government. The format of this is a five-position code, where the first and fifth position must be a numeric character. The second, third and fourth positions may be any mixture of alpha/numeric characters (excluding "I" and "O"). All positions are non-significant. Note that if you need to obtain a CAGE Code, contact the Defense Logistics Information Service (DLIS).
     
  7. GTIN Enabled Checkbox: See the topic Enabling GTIN On Item Or Item Cross Reference for information on this field.
     
  8. The FedEx ITN (Internal Transaction Number) Field  is given by AES after an SED is submitted to them, and it is unique per shipment.
     
  9. The FedEx XTN (External Transaction Number) Field is an exemption number for this item provided by the government.

 

Using the Handling (1) Tab Fields

You can use these check boxes to identify how the product will be processed through the system.

  1. Use the Immediate Needs Fields to make this item eligible for immediate needs processing; and the locating rule that the system will use when processing this item.
     
  2. Use the Inbound QC Fields to make this item eligible for inbound quality control processing; and the locating rule and UM that the system will use when processing this item. Also, you can use the Compute Quantity As buttons and the Inspection Qty field to further define the quantity you want the system to send to QC.

 

Using the Handling (2) Tab Fields

You can use these check boxes to identify how the product will be processed through the system.

  1. Select the Catch Weight Required Checkbox to require employees to identify this item's weight during packing/unpacking. Note that an item cannot be validated for both catch weight and a serial number.
     
  2. Select the Lot Controlled Checkbox to require employees to identify this item's lot during packing/unpacking.
     
  3. Use the Lot Template Field to associate this item with a lot template. These templates define a lot ID's structure.
     

  4. Use the Days To Expire Field to indicate the number of days that the system will add (to today's date) in order to calculate a lot's expiration date. Note that this value will not be honored if the lot already has an existing expiration date.
     

    NOTE: If you enter a 0 into this field, the system will not add any additional days when assigning an expiration date.

     

  5. Use the Serial Number option checkboxes to determine how the system will track serial numbers for this item. You will need to first choose which warehouse flow (Inbound, Inventory, or Outbound) for which you want the system to track serial numbers.

    The application allows you to track serial numbers in the following combinations:

    - Inbound only
    - Inventory only
    - Outbound only
    - Inbound and Outbound
    - Inbound and Inventory and Outbound
     
  6. Use the Template Field to select a serial number template that the system will use for computation. You can also choose to not select a template, and then the user will be able to enter any combination of characters for a serial number.

Using the Alternate/Substitute Tab Fields

You can use these fields to have the system suggest an appropriate replacement item to be used on a shipment line instead of the original item. Alternate/substitute items are available only when entering order/shipment lines on the Shipment Line Screen and the Order Entry Window. This functionality is not available when entering order/shipment lines using TPM Order Entry or the Order Download interface. Also note that you must activate the "Availability Checking" value on the Inventory Control Values Window if you want the system to check to see if an ordered item is currently in stock in the warehouse.

  1. Use the Alternate Item Field to associate an alternate item with the current item. Typically, you would use an alternate item when you have designated the current item as obsolete or permanently out of stock. When an alternate item designation exists for an item, the system will alert the user that they are about to order an obsolete item, and that an alternate item is available. The user can then decide whether or not to use this alternate item on their order/shipment line.

     

  2. Use the Substitute Item Field to associate substitute item(s) with the current item. You can use substitute item(s) to replace the original item if there is not enough quantity available in the warehouse. When entering an order/shipment line, the system will alert you that the desired item is not in stock, and that a substitute item exists. The user can then decide whether or not to use the substitute item on their order/shipment line.

    - You can enter more than one substitute item (the system will add it to the list box under the Substitute Item Field); the system will process through these items in sequential order, and choose the first one that can completely fulfill the original item's requested quantity.

    - The item(s) you choose as substitutes must have the same company designation as the original item.

    - Only one level of substitution is supported. For example, suppose Item A has Item B defined as its substitute, and Item B in turn has Item C defined as its substitute. The system will not suggest Item C when there is not enough inventory for Item A or Item B. The system will suggest Item B if Item A is lacking, but there is enough quantity of Item B to meet the request. The system will make no suggestion when neither Item A nor Item B can meet the request; Item A will be applied to the line, and allocation of Item A may fail during the wave if inventory is not available at that time.

    - The system will suggest a substitute only if the substitute item defined can fulfill the entire shipment line quantity. For example, suppose Item A has Item B defined as its substitute, and the available inventory is 5 EA for Item A and 5 EA for Item B. If the shipment line has a request for 10 EA of Item A, the system will not substitute the remaining 5 EA with Item B.

 

Using the International Tab Fields

You will use these fields if Progistics generates international documentation for the item. If you do not ship to international markets, do not provide values on this tab.

  1. The Preference Criterion Field identifies where all raw materials container in the item originated from. This information can be obtained from the United States government: This value is printed on the NAFTA Certificate of Origin. Please see the field topic for more information.

     

  2. Use the Harmonized Code Field to define this product's harmonize code. This is a universal value, assigned by the government, that identifies product on an international shipment. This is a required field.

     

  3. Use the Net Cost Buttons to determine if an item is subject to a regional value content requirement. Please see the field topic for more information.

     

  4. Use the Country of Origin Field to identify the country where this item was manufactured. This is a required field.

     

  5. Select the Producer Checkbox if the entity shipping an item is the same one who manufactured it. Please see the field topic for more information.

 

Using the Categories Tab Fields

You will use these fields if you want to associate a category to an item record. You can use these categories to hold user-defined information.

  1. Use the Category Fields to choose an item category to associate with this item. See the field topic Item Categories 1-10 for more information.
