Adding a Hazardous Code to an Item

The system allows you the opportunity to identify containers as being "hazardous" so they can be processed according to any special processing your warehouse may have. This is done by assigning a hazardous code to a specific National Motor Freight Classifications (NMFC) code. You can assign this code to an item in the Item Window. You can define this record on the National Motor Freight Classifications Window.

 

 

Procedures...

  1. Access the National Motor Freight Classifications Window from the Configurations Explorer.
     
  2. Open an NMFC record.
     
  3. Use the Hazardous Code Field to identify an item that uses this particular NMFC Code as being a hazardous material. The system will also display this code on a shipment's bill of lading document (in the "H.M." field).
     
  4. For information on other fields on this window, see the topic "Identifying NMFC Codes."
     
  5. Press OK when finished. The system will save your record.
