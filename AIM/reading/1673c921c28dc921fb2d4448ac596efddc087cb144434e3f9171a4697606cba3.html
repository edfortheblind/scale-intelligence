Cart Picking - Container work

The following details the steps for the Cart Picking. The cart picking container spot assignment is usually have two options.

  • User : User can select the spot on which the container can be placed.
  • System: System assigns the spot automatically for the container.

Sign in to your Warehouse Mobile screen and select the Work Execution

  1. Tap Work Execution to view Select Work Profile screen.
  2. Select cart picking work profile from the menu.
  3. In the Cart Picking screen. Enter/Scan Container ID and tap Go. The screen displays the Container Type and Container ID details.
  4. Enter Spot value. Note: Spot is prompted to user when Spot container is selected.
  5. A success message is displayed on assigning a container.
  6. Once all the required containers to the cart picking, Go to Actions >>Begin Picking to start picking items.
  7. In the Pick Confirmation screen, all details such as Work Unit, Location, Item, Description, Container, Spot, quantity is displayed.
  8. In case you have location or other validations configured, enter them in the field and tap Go.
  9. Cart Picking success message is displayed.

Pick to Tote - Cart Picking

Users can assign a tote to a cart before the start of cart picking.

 

Sign in to your Warehouse Mobile screen and select the Work Execution

  1. Tap Work Execution to view the Select Work Profile screen.
  2. Select cart picking work profile from the menu.
  3. In the Cart Picking screen. Enter/Scan TOTE ID and tap Go
  4. Enter/Scan the Work Unit ID and Tap Go. A success message that the assigning is completed.
  5. Users can repeat these steps 3 to 5 to enter the assigned tote to work units. When the user has completed assigning the work units, Tap Actions >> Begin pick
  6. The Begin Pick will initiate the pick and putaway process of the assigned work units. The steps are similar to the User Directed pick to tote work execution.
Put to Store

In case the put to store locations are configured for the work, then the system will pick and putaway the assigned work to the put to store location. Read Put to Store.

  • If the Putaway method is configured for Putaway to the container, then after the pick, in the putaway screen, the system will prompt for container ID and container type.
  • The system will not prompt for a container type if we scan an existing container ID.

New Cart Type

This functionality is used, when user need to create number of cart pickings. Once user has assigned the containers to the cart, user can skip picking process and go ahead to create a new cart.

  1. Tap Work Execution to view Select Work Profile screen.
  2. Select cart picking work profile from the menu.
  3. In the Cart Picking screen and enter/scan Container ID and Tap Go. The screen displays the Container Type and Container ID details.
  4. Enter Spot value. Note: Spot is prompted to user when Spot container is selected.
  5. A success message is displayed on assigning a container. Repeat the process to add multiple containers.
  6. Go to Actions >> New cart to view Cart Picking screen for new set of container assignment.

Cart Picking Actions

The following are the actions that user can perform from pick confirmation screen during cart picking.

 

Partial Pick - This enables user to pick a portion of total pick quantity that is set for execution. System prompts user to confirm the partial pick. Select Yes to perform the partial pick.

 

Pass: Users can completely stop the current instance of work execution. System will prompt a warning based on the Work System value configuration.

  • In Work System Value configuration - 50 - Remove container from cart when pass?, set system value to Warn to prompt warning message to user.

 

Short Pick - This enables user to pick quantity less than full pick instructed. User need to select appropriate reason and tap Go.

 

Skip- This enables user to move to next cart picking, without completing the cart picking the item quantity for the current instructions.

 

Remove Containers from Cart

The enables user to remove one or all containers from a cart. When the container is removed from the cart, system deletes group id and spot value from the shipping container.

Note: The work need to be in open state with group id assigned and not assigned to a user.

 

Remove a single container from a cart
  1. Tap Work Execution to view Select Work Profile screen.
  2. Select Remove Cart Container profile from the menu.
  3. In the Remove Cart Container screen, enter/scan Container ID and tap Go. The screen displays the success message as Container removed from the cart successfully.
Remove all containers from a cart
  1. Tap Work Execution to view Select Work Profile screen.
  2. Select Remove Cart Container profile from the menu.
  3. In the Remove Cart Container screen, enter/scan on of the Container ID that is part of the cart.
  4. Tap Actions >> Remove All, system will prompt user to select Yes or No.
  5. Tap Yes to remove all containers from the cart. Success message All Containers removed from cart successfully.

Notes

  • In the Work Profile Details configuration, the Work initiation method is selected as Cart Picking.
  • Currently the Container picking method is Pick into shipping container is supported.
  • When group user work is performed, the system batches the pick quantity across all shipping containers. This improves picking efficiency in the group user scenario.
  • serial number tracked items (outbound or inventory) or catch weight tracked items are exceptions to this grouping
  • You can directly scan an assigned container to begin cart picking process without the need to select Actions >> Begin Picks. The system prompts user with message to Begin Picks, Tap Yes to move to Pick Confirmation screen.

  • Users can enter/scan multiple tote and work units and begin pick.

  • Grouping of instructions is supported in the cart picking -pick to tote.

  • the system ungroup the batched work instructions if you partial or short pick the work.
