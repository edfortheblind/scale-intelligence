
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor472" data-source-node="n58"></a>Labor Type</h1>
        <p data-source-node="n59">When labor management records are generated, the system captures a "labor type" value for each warehouse action performed. These are associated with the work on the Work Type configuration.</p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Create Default Labor Type</h5>
        <ul data-source-node="n62">
            <li data-source-node="n63">
                <p data-source-node="n64"><b data-source-node="n65">Automatic Direct Labor</b>: This describes an activity that was performed in the system (both full screen and RF). The system will automatically log labor if an automatic direct labor event is associated with a work type. Note that there are some areas (such as immediate dock transfer or container nesting) that do not have this work type association, but the system will log labor anyway.</p>
            </li>
        </ul>
        <ul data-source-node="n66">
            <li data-source-node="n67">
                <p data-source-node="n68"><b data-source-node="n69">Approved Direct Labor</b>: This describes an activity that provides direct value to the warehouse, but is not performed directly in the system. For example, consider the physical building of a work order. This process is not performed by using system resources; however, this action is necessary for delivering product to the customer.</p>
            </li>
        </ul>
        <ul data-source-node="n70">
            <li data-source-node="n71">
                <p data-source-node="n72"><b data-source-node="n73">Approved Indirect Labor</b>: This describes a basic maintenance activity that is required for the business to operate, but does not directly impact the customer. For example, these include such duties as cleaning the warehouse, building pallets, and meetings.</p>
            </li>
        </ul>
        <ul data-source-node="n74">
            <li data-source-node="n75">
                <p data-source-node="n76"><b data-source-node="n77">Unapproved Indirect Labor</b>: This describes an activity that does not directly benefit business operation. For example, this could include such things as informal breaks, fire drills, or personal phone calls. Note that even if an unapproved indirect labor event is associated with a work type, the system will not automatically log labor for this event.</p>
            </li>
        </ul>
