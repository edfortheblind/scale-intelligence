
        
        <h1 data-source-node="n56"><a name="kanchor445" data-source-node="n57"></a>Header Data Source Field</h1>
        <p data-source-node="n58"> This field indicates the database table that you want to assign as the primary table for a viewer window. The table you select as the header data source identifies the following:<br data-source-node="n59"><br data-source-node="n60">- The fields that are eligible to be used as search criteria.<br data-source-node="n61"><br data-source-node="n62">- The database table that searches will be performed against.<br data-source-node="n63"><br data-source-node="n64">- The fields that are eligible to be displayed in the results grid for header records.</p>
