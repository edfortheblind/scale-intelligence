
        
        <h1 data-source-node="n56"><a name="kanchor190" data-source-node="n57"></a>Reviewing Manifest Status Values </h1>
        <p data-source-node="n58">The Manifest status column in the List Pane Grid Fields of Manifest Insight Screen displays the state of the manifests as Open and Closed. A Closed manifest status indicates the containers on the manifest have been shipped.  A manifest with an Open status has containers that have been manifested for the ship date, but have yet to be shipped. Refer to the <a href="d32d1cb9599446837bccbe29c7d9c4ca40c84eef3f478481bcf51ff363aa63e1.html" data-source-node="n59">Using the Manifest Insight Screen</a> topic for more information. </p>
