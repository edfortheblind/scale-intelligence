String Length Type Field

This field indicates how the application will expect GS1 data to enter the system when scanned:

Fixed Length: The data value has to be of a certain size, or the system will return an error when the AI is scanned. For example, if your quantity is set at a length of three characters, then every value for this AI must be three digits (such as 002, 012, 124).

 

Variable Length: The data value can be of any size.
