
        
        <h1 data-source-node="n56">Using the DIF Incoming Message Insight</h1>
        <p data-source-node="n57">You can use this Insight screen to search the incoming messages that have been sent from the application to material handling equipment (MHE) via the SCALE Device Integration Framework. If a message fails to process successfully, the system marks the message's status  as "Error". You can then use this insight screen to reset the message's status (after addressing what caused the error in the first place) to "Ready" so that the selected record can be reprocessed by the DIF Message Processing service.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">An incoming message can be in one of four <a href="9c13277d00e74633b48dc074cad949b48a1f16424ff19feaa6dbad8a7434c0ab.html" data-source-node="n60">statuses</a>: "Ready", "In Process", "Processed", and "Error".</p>
        <p data-source-node="n61"> </p>

        <h4 data-source-node="n116">Searching/Viewing the Incoming Message Records.</h4>
        <p data-source-node="n117">You can use the DIF Incoming Message Insight Screen to search for and view outgoing messages.</p>
        <p data-source-node="n118"> </p>
        <ol data-source-node="n119">
            <li value="1" data-source-node="n120">Open the DIF incoming Message Insight Screen.<br data-source-node="n121"><br data-source-node="n122"></li>
            <li value="2" data-source-node="n123">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n124"><br data-source-node="n125"></li>
            <li value="3" data-source-node="n126">Press the Apply Filter Button. The system will display the resulting records in the List Pane. <br data-source-node="n127"><br data-source-node="n128"></li>
            <li value="4" data-source-node="n129">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>

        <h4 data-source-node="n140">Resetting an Outgoing Message For Resubmission</h4>
        <p data-source-node="n141">You can change the status of an outgoing message record from "Error" to "Ready", so the record can be resubmitted to the DIF Message Processing service. </p>
        <ol data-source-node="n142">
            <li value="1" data-source-node="n143">Open the DIF Incoming Message Insight Screen.<br data-source-node="n144"><br data-source-node="n145"></li>
            <li value="2" data-source-node="n146">Use the Basic Criteria Fields and perform a search. The system will display the resulting records in the List Pane.<br data-source-node="n147"><br data-source-node="n148"></li>
            <li value="3" data-source-node="n149">Select a record and <b data-source-node="n150">Actions &gt;&gt; Reset</b> option. The system will change the status of the message record from "Error" to "Ready". The DIF Message Processing service will then reprocess this message the next time it runs.</li>
        </ol>
