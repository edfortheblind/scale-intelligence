
        
        <h1 data-source-node="n56"><a name="kanchor1231" data-source-node="n57"></a>Inventory Attributes Fields 1-20</h1>
        <p data-source-node="n58">These fields represent values that are attached to inventory in the system. Examples of inventory attributes could be Country of Origin, Region, or Product Owner. For more information on how inventory attributes are supported in the system, see the topic <a href="c3f65ac4de2fc3dce97e4180f4db0eaaa010a10166193e50df4370c1ee3c7799.html" data-source-node="n59">Using Inventory Attributes</a>.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Note that you can create your own pre-defined inventory attribute values that the user can select from on certain processing screens. See <a href="3afe0a0e91c3be424098655a59ac0655672a919ff3ef1c0b6cfc3c6a56a8444d.html" data-source-node="n62">Creating Inventory Attribute Values</a> for more details.</p>
