        <h4 data-source-node="n175"><a name="searching" data-source-node="n176"></a>Searching/Viewing Receipt Line Records...</h4>
        <ol data-source-node="n177">
            <li value="1" data-source-node="n178">Open the Receipt Line Insight Screen.<br data-source-node="n179"><br data-source-node="n180"></li>
            <li value="2" data-source-node="n181">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search:<br data-source-node="n182"><br data-source-node="n183"></li>
            <li value="3" data-source-node="n184">Press the Apply Filter Button. The system will display the resulting records in the List Pane. <br data-source-node="n185"></li>
        </ol>

        <h4 data-source-node="n203"><a name="AboutD" data-source-node="n204"></a>About the Detail Pane...</h4>
        <p data-source-node="n205">The Receipt Line Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.</p>
        <p data-source-node="n206"> </p>
        <ul data-source-node="n207">
            <li data-source-node="n208">The Detail Pane of Receipt Line Insight contains Indicator Tiles with counts of the other entities (i.e.receiving containers). The Container Indicator Tile displays the number of receipt containers associated with the receipt line. Clicking this will open the Receipt Container Insight screen by filtering through the Internal Receipt Line Number. If Run permission is not there for the Receipt Container Insight, the hyperlink will be disabled in the Indicator Tile.</li>
        </ul>
        <p data-source-node="n209"> </p>
        <p data-source-node="n210"> </p>
        <p data-source-node="n211">For more general information about the Detail Pane, see the topic <a href="444e9b8e14a977178c9ff48b972dd65c076a4adda44c3dfacddf94a4a6c24d22.html" data-source-node="n212">Introduction to Insight Screens</a>.</p>

        <h4 data-source-node="n218"><a name="actions" data-source-node="n219"></a>Screen Actions...</h4>
        <p data-source-node="n220">The following actions are accessible from the Receipt Line Insight screen: </p>
        <p data-source-node="n221"> </p>
        <h5 data-source-node="n222">Edit</h5>
        <p data-source-node="n223">This action allows you to display and edit a receipt line’s information.</p>
        <p data-source-node="n224"> </p>
        <h5 data-source-node="n225">Delete</h5>
        <p data-source-node="n226">This action allows you to delete the selected receipt line(s). You can delete single or multiple receipt details at a time and the action is enabled for the receipt line(s) for which no quantity has been checked in. If multiple receipt lines are selected with some eligible for deletion and some not eligible, system will delete all the records till it encounters the first receipt which is not eligible and stop there.</p>
        <p data-source-node="n227"> </p>
        <h5 data-source-node="n228">Immediate Needs</h5>
        <p data-source-node="n229">This action allows you to select an immediate needs transaction for the Immediate Needs Insights screen. For more information on Immediate Needs, see the <a href="c3bf7cdf689326981fbe4a20a7d35e0dbba65a1ade6ba7ef9ed7316b1db4121d.html" data-source-node="n230">Researching a Warehouse's Immediate Needs</a> topic.</p>
        <p data-source-node="n231"> </p>
        <h5 data-source-node="n232">View</h5>
        <p data-source-node="n233">This action allows you to display a receipt line’s information.</p>
