
        
        <h1 data-source-node="n56">Printing Help Topics</h1>
        <p data-source-node="n57">You can print any help topic displayed in the help window.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Procedures...</h4>
        <p data-source-node="n61"> </p>
        <p class="p_3" data-source-node="n62">Follow these steps in order 
 to print a help topic:</p>
        <ol data-source-node="n63">
            <li value="1" data-source-node="n64">
                <p data-source-node="n65">Access the topic you want to print. </p>
                <p data-source-node="n66"> </p>
                <p data-source-node="n67">- Open the Contents and Index from any window (Help | Contents and 
 Index). Use the table of contents to access the help topic you want to 
 print.<br data-source-node="n68"><br data-source-node="n69">OR<br data-source-node="n70"> </p>
                <p data-source-node="n71">- Open the topic relating to the current window (Help | On [Window Name])</p>
                <p data-source-node="n72"> </p>
            </li>
            <li value="2" data-source-node="n73">
                <p data-source-node="n74">Press the 
 Print button. The system will display the Print dialog.</p>
                <p data-source-node="n75"> </p>
            </li>
            <li value="3" data-source-node="n76">Choose your 
 settings and press Print. The system will print the selected topic.</li>
        </ol>
