Defining Text Messages

A text message provides additional procedures or notes to employees during work processing (RF, Warehouse Mobile or the Work Insight Screen). You will define a text message on the Text Message Window. Later, you will associate the message with the appropriate account or item on the Text Message Assignment Window. Note that the system will only display text messages when the user is executing shipment or dock management work. If you want interfaced shipment comments to appear as text messages in RF and Warehouse Mobile work execution, see the topic Configuring/Displaying Interfaced Text Messages for more information.

Procedures...

  1. Use the Message ID Field to provide a name for the message. This name will not appear on onscreen.

     

  2. Use the Comments Field to define the text of the message that you want the system to display onscreen.

     

  3. Use the Communication Method Buttons to define exactly when the system will display the message during work execution. Select Before if you want the message displayed before the user executes the pick. Select After if you want the message displayed after the user executes the pick.
     
  4. Press OK. The system will save your record.
