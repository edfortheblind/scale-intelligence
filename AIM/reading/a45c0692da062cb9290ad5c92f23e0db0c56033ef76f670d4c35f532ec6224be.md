
        
        <h1 data-source-node="n56">Defining Editable Field Decimal Positions</h1>
        <p data-source-node="n57">The decimal positions (number digits to the right of the decimal) of 
 editable fields in the system are tied to the resource file and not the 
 Decimal Positions Window. To adjust the number of positions on these fields, 
 you will need to address these fields in the System Text Editor. </p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Note About Keeping 14 Digits To the Left of the Decimal...</h4>
        <p data-source-node="n61">Below are the settings that are allowed for numeric fields in the System Text Editor if you want to keep 14 digits to the left of the decimal. This is applicable for any numeric fields throughout the system which have a maximum field length of 19,5:</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">[<i data-source-node="n64">field length, decimal position</i>]</p>
        <ol data-source-node="n65">
            <li value="1" data-source-node="n66">14,0</li>
            <li value="2" data-source-node="n67">15,1</li>
            <li value="3" data-source-node="n68">16,2</li>
            <li value="4" data-source-node="n69">17,3</li>
            <li value="5" data-source-node="n70">18,4</li>
            <li value="6" data-source-node="n71">19,5</li>
        </ol>
        <p data-source-node="n72">Note that anything having more than 14 digits to the left of the decimal would be an invalid setting.</p>
        <p data-source-node="n73"> </p>
        <p data-source-node="n74"> </p>
        <p data-source-node="n75"> </p>
        <h4 data-source-node="n76">Procedures...</h4>
        <ol class="ol_1" data-source-node="n77">
            <li value="1" data-source-node="n78">Open the System 
 Text Editor from the desktop. <br data-source-node="n79"> </li>
            <li value="2" data-source-node="n80">Search for the 
 field(s) that you want to change the decimal positions. Enter the 
 search criteria in the Key Field and press the Search Button. The system 
 will display the results in the record list. <br data-source-node="n81"><br data-source-node="n82">For example, suppose you want to change all quantity fields to not 
 show any decimal positions. You would then want to search for any field 
 that has a resource key containing the terms "Quantity" 
 and/or      "Qty".<br data-source-node="n83"> </li>
            <li value="3" data-source-node="n84">Select the entry 
 you want to customize, right click, and choose the Open Custom 
 Value option. The system will display the Custom System Text dialog.<br data-source-node="n85"> </li>
            <li style="font-style: normal" value="4" data-source-node="n86">Use the Decimal 
 Position Field to define how many decimal positions this field 
 will display and press OK.<br data-source-node="n87"> </li>
            <li value="5" data-source-node="n88">Repeat for all 
 field(s) that you would like to change. <br data-source-node="n89"> </li>
            <li value="6" data-source-node="n90">Choose Apply 
 on the System Text Editor Window. <br data-source-node="n91"></li>
        </ol>
        <p data-source-node="n92"> </p>
        <p data-source-node="n93"> </p>
        <h4 data-source-node="n94">Updating All Fields To Zero Decimal Positions...<br data-source-node="n95"></h4>
        <p data-source-node="n96">If you do not have any specific fields that you want to edit the decimal 
 positions, you can run a quick query to update all of the fields at once 
 to have a decimal position value of zero.  The 
 queries below will insert custom records for QUANTITY and QTY resources 
 with a decimal position value of 0. 
 You could pull out the resource key section that narrows the results down 
 to QUANTITY if you wanted to do this over all keys. </p>
        <p data-source-node="n97"> </p>
        <p data-source-node="n98"> </p>
        <p data-source-node="n99"> </p>
        <h4 data-source-node="n100">SQL Server Queries...<br data-source-node="n101"></h4>
        <p data-source-node="n102">-- First update all existing custom records:<br data-source-node="n103"></p>
        <blockquote data-source-node="n104">
            <p data-source-node="n105">UPDATE RESOURCE_FILE_CUSTOM</p>
            <p data-source-node="n106">SET DECIMAL_POS = 0, USER_STAMP = 'System', PROCESS_STAMP = 'Decimal 
 Pos = 0', DATE_TIME_STAMP = getDate()</p>
            <p data-source-node="n107">WHERE (RESOURCE_KEY like '%QUANTITY%' OR RESOURCE_KEY LIKE '%QTY%')</p>
            <p data-source-node="n108">AND DECIMAL_POS = 5 AND RESOURCE_GROUP = 'Text';</p>
        </blockquote>
        <p data-source-node="n109"> </p>
        <p data-source-node="n110">-- Next insert any missing custom records:<br data-source-node="n111"></p>
        <blockquote data-source-node="n112">
            <p data-source-node="n113">INSERT INTO RESOURCE_FILE_CUSTOM</p>
            <p data-source-node="n114">(RESOURCE_LANGUAGE, RESOURCE_GROUP,RESOURCE_KEY,TEXT,FIELD_LENGTH,DECIMAL_POS,USER_STAMP,PROCESS_STAMP,DATE_TIME_STAMP)</p>
            <p data-source-node="n115">SELECT</p>
            <p data-source-node="n116">RESOURCE_LANGUAGE,RESOURCE_GROUP,RESOURCE_KEY,TEXT,FIELD_LENGTH,0,'System','Decimal 
 Pos = 0',getDate()</p>
            <p data-source-node="n117">FROM RESOURCE_FILE_BASE</p>
            <p data-source-node="n118">WHERE (RESOURCE_KEY like '%QUANTITY%' OR RESOURCE_KEY LIKE '%QTY%')</p>
            <p data-source-node="n119">AND DECIMAL_POS = 5 AND RESOURCE_GROUP = 'Text'</p>
            <p data-source-node="n120">AND NOT RESOURCE_KEY IN (SELECT RESOURCE_KEY FROM RESOURCE_FILE_CUSTOM</p>
            <p data-source-node="n121">   WHERE 
 (RESOURCE_KEY like '%QUANTITY%' OR RESOURCE_KEY LIKE '%QTY%')AND RESOURCE_GROUP 
 = 'Text');</p>
        </blockquote>
