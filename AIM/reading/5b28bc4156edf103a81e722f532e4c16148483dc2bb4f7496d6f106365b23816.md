
        
        <h1 data-source-node="n56"><a name="kanchor881" data-source-node="n57"></a>Maximum Number of Containers at Class Field</h1>
        <p data-source-node="n58">The maximum number of containers, at a particular class, that can be 
 shipped using a particular routing guide record. This value is defined on the routing guide record. During routing, the 
 system will compare the value defined here to the shipment's container 
 amount.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61">If the shipment's container amount 
 is less than or equal to this value, the routing guide will be 
 assigned to the shipment provided all of the other criteria match or are 
 within range, and there is not another record with more matching criteria.</p>
                <p data-source-node="n62"> </p>
            </li>
            <li data-source-node="n63">If the shipment's 
 container amount is greater than this value, the routing guide 
 will not be assigned to this shipment.</li>
        </ul>
        <p data-source-node="n64">Note that if any of the containers on a shipment do NOT have a container class, the system 
 will only assign a routing guide that does not have a class assigned. To set an unlimited maximum, define the value 
 '0'.</p>
