
        
        <h1 data-source-node="n56"><a name="kanchor903" data-source-node="n57"></a>Randomize Checkbox</h1>
        <p data-source-node="n58">Use this checkbox to indicate that you want the system to create cycle 
 count requests from a random set of locations (based on the range as defined 
 in your Cycle Count Location Selection record for this master). </p>
        <p data-source-node="n59"> </p>
        <p class="p_27" data-source-node="n60">NOTE: 
 If you do not want the system to have the opportunity to choose the same 
 location every time requests are generated using this master, make sure 
 one of the following conditions exist: </p>
        <ul type="disc" class="ul_1" data-source-node="n61">
            <li data-source-node="n62">On your Cycle Count Location Selection record, 
 include a filter using the Last Cycle 
 Count Date value. For example, if you define a location selection 
 record where the   Last Cycle Count Date 
 is greater than 180 days, then the system will not pick a location again 
 until it has not been cycle counted in the last 180 days. Thus, you will 
 not get the unwanted "repeat" cycle count request until a desirable 
 amount of time has elapsed since the last cycle count.<br data-source-node="n63"> </li>
            <li data-source-node="n64">If a pending request exists for a location, the 
 system cannot create another request for this location. </li>
        </ul>
