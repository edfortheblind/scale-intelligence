
        
        <h1 data-source-node="n56"><a name="kanchor280" data-source-node="n57"></a>Start Date Time Field</h1>
        <p data-source-node="n58">This field identifies the day and time that a certain action/event began.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Work Related...</h5>
        <p data-source-node="n62">The time that work was initiated in the system. The value in this field 
 depends on how the work was processed.</p>
        <blockquote data-source-node="n63">
            <p data-source-node="n64">- If work is processed on an RF,  the start time is associated with a 
 work unit and its instructions. The start time is defined when an employee 
 begins processing the first work instruction for a work unit. If multiple 
 instructions are associated with a work unit, they will all share the 
 same start time value.</p>
            <p data-source-node="n65"> </p>
            <p data-source-node="n66">- If work is processed on the Work 
 Insight Screen, the start time is associated with each work instruction. 
 It is defined per instruction when its confirmed. Since work processed on the Work Insight Screen is generally physically 
 completed before its updated here, the start time is usually the same 
 for all instructions and the work unit. The user will type this value 
 on the screen. If processing against this work unit has not been initiated, 
 the system will default time that the work was created in this field.</p>
        </blockquote>
