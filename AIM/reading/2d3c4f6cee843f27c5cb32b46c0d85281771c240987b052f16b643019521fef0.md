
        
        <h1 data-source-node="n56"><a name="kanchor1229" data-source-node="n57"></a>Number Of Rows Field</h1>
        <p data-source-node="n58">This field indicates the number of dock position rows that you want the Dock Manager Window to display for a dock location area (note that this setting only applies to the staging location class). If  you enter a 0 for this value, the system will display two rows for this dock location area on the Dock Manager Window, IF you have associated position(s) to this dock location area. If you have not associated any position(s) to this dock location area (such as if you were creating a general dock location area), then the system will not display rows for it on the Dock Manager Window.
 
</p>
