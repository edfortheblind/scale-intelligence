
        
        <h1 data-source-node="n56"><a name="kanchor994" data-source-node="n57"></a>Default Checkbox (Paperwork)</h1>
        <p data-source-node="n58">This setting is defined on the Document Type 
 Window. If this checkbox is selected, the system will automatically print 
 documents when you execute a specific system process. For example, if 
 this checkbox is selected for the Packing process, the system will print 
 the document when containers are closed (and "Auto Print at Close" setting on the packing 
 preference record is set to Prompt).</p>
