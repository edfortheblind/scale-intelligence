Collate Document List

  The collate feature enables the user to print by combing documents using the collate document template. A common example of collating shipping documents is combining a return label with a packing slip and return instructions.

Process

 

Print using the Print selected documents option.

 

1. SCALE system manifests a shipping container and printing is initiated (if printing option is selected) for collating the pack list .

 

2. A shipping label is generated and saved as an image in a label table which is linked to the internal container number.

  • If a return label is also printed, then the return label is also saved to the same table.

3. PDF document is generated.

 

4. Using document routing configuration will process which document is required, then the system will generate the PDF to the corresponding printer
