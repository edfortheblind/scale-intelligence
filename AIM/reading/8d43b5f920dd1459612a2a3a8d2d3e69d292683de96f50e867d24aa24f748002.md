
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor708" data-source-node="n58"></a>Customer Category</h1>
        <p data-source-node="n59">Customer categories are used in the order entry module to indicate such custom values as value-added inserts (catalogs, promotional gifts, etc.), special handling instructions, pay terms, or any other user-defined message/label. Note that you can define any value for these categories, as these categories do not affect system processing of orders. Also, you can indicate whether you want to have a category be inherited or not in the Customer configuration.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Requiring and Validating Customer Categories</p>
        <p data-source-node="n62">Requiring Values: Refer to the "Reviewing Customer Category System Values" topic to enforce required input for each category.</p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64">Validation Settings: By default, customer category fields are validated against pre-defined values in the Customer Category 1–10 window.</p>
        <p data-source-node="n65">You can disable validation by updating system text keys:</p>
        <ul data-source-node="n66">
            <li data-source-node="n67">
                <p data-source-node="n68">Each category uses a key in the format CUSTOMERCATEGORYxCFVV (e.g., CUSTOMERCATEGORY7CFVV).</p>
            </li>
            <li data-source-node="n69">
                <p data-source-node="n70">A value of "N" enforces validation (default).</p>
            </li>
            <li data-source-node="n71">
                <p data-source-node="n72">Change to "Y" to allow free-text entry, bypassing the predefined list.</p>
            </li>
        </ul>
        <p data-source-node="n73"> </p>
        <h5 data-source-node="n74">Create Customer Category</h5>
        <p data-source-node="n75"> </p>
        <p data-source-node="n76">Use the Identifier and Description Fields to indicate the name of the category. The system will use the values you enter in the Identifier Field to populate the Category (1-10) Field on the Order Entry Window. In the Order Entry Window, you can associate category(s) to an order.</p>
