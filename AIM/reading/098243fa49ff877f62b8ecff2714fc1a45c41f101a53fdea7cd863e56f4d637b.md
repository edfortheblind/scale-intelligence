
        
        <h1 data-source-node="n56"><a name="kanchor1081" data-source-node="n57"></a>Bios Serial Number Field</h1>
        <p data-source-node="n58">This field indicates the serial number that identifies the processor chip in your machine. The BIOS contains all the code required to control the keyboard, display screen, disk drives, serial communications, and a number of miscellaneous functions of your machine.</p>
