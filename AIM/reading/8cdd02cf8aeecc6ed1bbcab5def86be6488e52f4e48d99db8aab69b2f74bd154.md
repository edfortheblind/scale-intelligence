
        
        <h1 data-source-node="n56"><a name="kanchor481" data-source-node="n57"></a>Decimal Position Field / Decimal Positions Field</h1>
        <h5 data-source-node="n58">On the System Text Editor Detail Window...</h5>
        <p class="p_1" data-source-node="n59">This field indicates the location of a decimal point in 
 a field value. You can only modify the decimal position of a custom text 
 value; you cannot edit a base text value.</p>
        <p class="p_1" data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"> </p>
        <h5 data-source-node="n62">On the Customize Viewer Window...</h5>
        <p class="p_1" data-source-node="n63">This field  represents how the system will display decimal positions for field values on your viewer's results tab. You can select from value categories that are defined on the Decimal Positions Window.</p>
        <p class="p_1" data-source-node="n64"> </p>
        <h5 data-source-node="n65">On Warehouse Dashboard</h5>
        <p data-source-node="n66">The decimal position on the warehouse dashboard is configured using the Dashboard record from the Decimal Positions configuration.</p>
        <p class="p_1" data-source-node="n67"> </p>
        <h5 data-source-node="n68">Note About Keeping 14 Digits To the Left of the Decimal...</h5>
        <p data-source-node="n69">Below are the settings that are allowed for numeric fields in the System Text Editor if you want to keep 14 digits to the left of the decimal. This is applicable for any numeric fields throughout the system which have a maximum field length of 19,5:</p>
        <p data-source-node="n70"> </p>
        <p data-source-node="n71">[<i data-source-node="n72">field length, decimal position</i>]</p>
        <ol data-source-node="n73">
            <li value="1" data-source-node="n74">14,0</li>
            <li value="2" data-source-node="n75">15,1</li>
            <li value="3" data-source-node="n76">16,2</li>
            <li value="4" data-source-node="n77">17,3</li>
            <li value="5" data-source-node="n78">18,4</li>
            <li value="6" data-source-node="n79">19,5</li>
        </ol>
        <p data-source-node="n80">Note that anything having more than 14 digits to the left of the decimal would be an invalid setting.</p>
