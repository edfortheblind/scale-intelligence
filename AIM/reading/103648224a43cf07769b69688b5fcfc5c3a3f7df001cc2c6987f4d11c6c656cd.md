
        
        <h1 data-source-node="n56"><a name="kanchor896" data-source-node="n57"></a>License Plate Verify Checkbox</h1>
        <p data-source-node="n58">This field requires the user to identify the ID of the license plate that he/she is picking from. If this is not checked, the License Plate Field on the RF Pick Confirmation screen will be read-only. If it is checked, the system will display the correct ID, and the user will need to scan the license plate to verify the value.</p>
