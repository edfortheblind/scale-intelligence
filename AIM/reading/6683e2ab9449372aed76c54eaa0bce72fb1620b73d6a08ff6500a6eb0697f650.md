
        
        <h1 data-source-node="n56"><a name="kanchor897" data-source-node="n57"></a>Creating Pallet Building Master Records</h1>
        <p data-source-node="n58">This master record indicates what criteria and strategy that you want the pallet building wave step to use when reviewing shipping containers for palletization eligibility. When configuring your wave master, you will identify the pallet building master record that you want the system to use when executing this wave step. When executing the pallet building wave step, the system will process through the master detail(s) in order of sequence. If a shipping container does not meet the first detail's criteria, the system will attempt to apply it to the next one. The system will continue this process until the container meets one of the master's criteria, or exhausts all sequences without finding matching criteria for the shipping container. It is recommended that you have the final detail in the sequence be a "general" one; in other words, have no criteria associated with it. That way, any remaining containers that did not meet any of the master's previous criteria will be picked up by this last detail, and those remaining containers will indeed get palletized.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: A *Default pallet building master record is shipped with the system. This is the master that the system references when a wave is run from a wave flow (instead of using a wave master). You will need to make sure that you define detail(s) for this default record, as none are provided.</p>

        <h4 data-source-node="n91">Procedures...</h4>
        <p data-source-node="n92">Access the Pallet Building Master Window. Create a new record.</p>
        <ol data-source-node="n93">
            <li value="1" data-source-node="n94">Provide a name and description for your master record.<br data-source-node="n95"><br data-source-node="n96"></li>
            <li value="2" data-source-node="n97">Press the Apply Button. The system will save your header information.<br data-source-node="n98"><br data-source-node="n99"></li>
            <li value="3" data-source-node="n100">Press the Add Button to add a detail record to your master.<br data-source-node="n101"><br data-source-node="n102"></li>
            <li value="4" data-source-node="n103">Select a pallet building criteria record to associate with your master detail. These records  indicate how the wave process will decide which shipping containers are eligible to add to a newly-constructed pallet. This criteria also determines how the containers are grouped onto pallets (for instance, having different item category's placed onto separate pallets).<br data-source-node="n104"><br data-source-node="n105"></li>
            <li value="5" data-source-node="n106">Select the container type that will represent the parent container type that the system will use when constructing pallets (using this wave master). Typically, this would be an actual "pallet," but in reality could be any large container in which smaller containers could fit inside of.<br data-source-node="n107"><br data-source-node="n108"></li>
            <li value="6" data-source-node="n109">If you would like to add another detail record, press the Add Button. <br data-source-node="n110"><br data-source-node="n111"></li>
            <li value="7" data-source-node="n112">Use the Up and Down Buttons to change the sequence of the detail records. When reviewing containers for palletizing eligibility, the system processes through the details according to this sequence.<br data-source-node="n113"><br data-source-node="n114"></li>
            <li value="8" data-source-node="n115">If you are finished, press OK, and the system will save your master record.</li>
        </ol>
