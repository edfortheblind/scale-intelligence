Warehouse Mobile - Assign Printer

The assign printer screen enables to define the label printer from the warehouse mobile application.

Assign Label Printer

The following details the steps for the

  1. Log in to Warehouse Mobile application.
  2. Select the Assign Printer option from the Warehouse Mobile Main Menu.
  3. Enter/Scan Label Printer name. In case a wrong printer name is entered, an error message is displayed.
  4. Tap Go and a success message is displayed as Assign Printer successful.

Note: You can verify the User Profile setting by Navigating to Preference>>Default Label field. The assigned label printer name is displayed.

 

Clear the Assigned Printer settings
  1. Log in to Warehouse Mobile application.
  2. Select the Assign Printer option from the Warehouse Mobile Main Menu.
  3. Go to Actions >> Clear and Clear Printer message is displayed.

You can verify the User Profile setting by Navigating to Preference>>Default Label field. The assigned label printer name is cleared.
