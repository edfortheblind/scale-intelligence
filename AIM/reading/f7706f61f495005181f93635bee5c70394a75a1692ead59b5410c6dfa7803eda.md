
        
        <h1 data-source-node="n56"><a name="kanchor1868" data-source-node="n57"></a>Location Subclass Field</h1>
        <h5 data-source-node="n58">Used For Dock Locations Only...</h5>
        <p data-source-node="n59"> This field indicates what type of specific designation (such as packing, staging, dock door) that a dock location will represent. You must choose a Location Class of "shipping" in order to select a subclass value. Note that while this value is optional, all warehouses need at least one "packing" dock location, and that the system only supports one packing location per warehouse. Also, choosing a dock location subclass causes your location to be multi-item enabled, and the dock location will not track license plates.</p>
