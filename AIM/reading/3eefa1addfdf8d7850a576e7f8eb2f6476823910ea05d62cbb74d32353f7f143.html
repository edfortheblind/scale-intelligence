Configuring/Displaying Interfaced RF Comments

You will need to complete the procedures outlined on this topic to display shipment comments while picking on the RF device.

Step 1: Defining a Custom "Work Execution" Comment Type...

Performed on the Comment Type Window

  • You will need to create a comment type record to indicate when you want the system to display the comments (before or after a picking action) associated with the shipment or shipment line. Note that the comments on your interfaced shipments must be of this comment type in order for the system to display it on the RF device.

    See the topic Defining Comment Types for more detailed information on using this window.

 

 

Step 2: Associating the Comment Type To a Document Type...

Performed on the Comment Type Doc Assignment Window

  • The document type "WorkExecution" represents the RF device. You will need to associate the comment type you created in step 1 with this "WorkExecution" document type. Once this is done, the system will display the appropriate shipment comments on the RF device.

    See the topic Associating Comment Types With Document Types for more detailed information on using this window.

 

 

Step 3: Activating RF Work Comments...

Performed on the Work System Values Window

  • The work system value "Display Comments during Work on RF?" must be set to yes for these comments to appear on the RF device.
