
        
        <h1 data-source-node="n56"><a name="kanchor1651" data-source-node="n57"></a>Permanent Location Toggle</h1>
        <h5 data-source-node="n58">On the Inventory Screen...</h5>
        <p data-source-node="n59">This indicates whether or not a location 
 has been defined as a permanent location. If you create a record 
 in the Item Location Assignment Window for a location, then the system will activate the 
 Permanent Location Toggle.</p>
        <p data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"> </p>
        <h5 data-source-node="n62">On the Cycle Count Quick Plan Screen...</h5>
        <p class="p_1" data-source-node="n63">This indicates that you want the system to consider locations that house items permanently (via the item location assignment configuration) when generating cycle counts using a quick plan.</p>
