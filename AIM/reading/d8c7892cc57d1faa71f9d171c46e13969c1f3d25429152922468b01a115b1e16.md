
        
        <h1 data-source-node="n56"><a name="kanchor1857" data-source-node="n57"></a>Dock Field</h1>
        <p data-source-node="n58">This field indicates the shipping dock where a particular carrier's product should be prepared 
 for shipping. This is an alpha-numeric field. It is not 
 validated in the system. On the Location Window, only one location can be defined to the system 
 as a shipping dock (location class = shipping dock). However, on the Carrier 
 Window, you can identify a unique dock value for the each carrier. During 
 picking, RF devices will display the value defined on the Carrier Window 
 as the 'to' location. This structure allows you to manage the movement 
 of product to the shipping dock in an orderly fashion, based on carrier.</p>
