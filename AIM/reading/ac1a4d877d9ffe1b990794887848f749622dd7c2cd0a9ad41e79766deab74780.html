Container Creation in the Wave Process Summary

** Functionality **

Process Flows

 

 

Summary

The container creation process involves the system creating containers for shipment line item quantities via the execution of a wave step. This wave step determines how many container(s) it will create to pack these allocated item quantities. There are four strategies that can be used by this wave step to determine how to distribute quantities into newly-created containers: Consolidate And Do Not Split, Split And Do Not Consolidate, Consolidate And Split Only Once, and 3D Cubing.
