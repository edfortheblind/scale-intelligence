
        
        <h1 data-source-node="n56"><a name="kanchor1375" data-source-node="n57"></a>Validate Location Field</h1>
        <p data-source-node="n58">You will use the Validate Locations flag to 
 determine where locations can be created. This is done in the Inventory 
 Control Values Window. This is helpful because you can determine if you 
 want users to create locations on the fly or only on the Location Window.</p>
