
        
        <h1 data-source-node="n56"><a name="kanchor2089" data-source-node="n57"></a>Commodity Description Field</h1>
        <p data-source-node="n58">This field is a general description of the 
 item taken from the item's NMFC Code. If more than one item are packed 
 in a freight container, the majority commodity is the description displayed.</p>
