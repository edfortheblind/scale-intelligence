Creating Cycle Count Location Criteria Records

** Use with plan based cycle counting **

 

These records are used by the system to filter the number of locations eligible for a cycle count, according to settings defined on the cycle count master record. The system will only create cycle count requests for locations that match this criteria.

 

Dock Location Note: It is recommended that you do not cycle count dock locations, even though the system will allow this. Dock locations should then be excluded from your cycle count location criteria record.

Procedures...

 

Access the Cycle Count Location Criteria Window. Name this record and provide a description.

  1. Using the Filter Data Tab: You will use this tab to identify which location(s) you want eligible for cycle counting.
     
  2. Using the Order By Tab: You will not need to use the order by tab functions when creating cycle count location criteria records.
     
  3. When finished, press OK. The system will save your location criteria record.
