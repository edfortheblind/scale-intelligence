
        
        <h1 data-source-node="n56"><a name="kanchor1141" data-source-node="n57"></a>Creating a Rule Set Assignment Record</h1>
        <p data-source-node="n58">You will use this record to define the order that the system will use 
 to attempt to assign a certain locating/allocating rule. On this record, 
 you will indicate the rule set criteria and locating/allocating rule that 
 you want to associate with this priority setting. When using rule set 
 assignment, the system will consider each criteria record in priority 
 order, and once a receipt line/shipment line satisfies a rule set, 
 it will not be considered for any other. </p>

        <h4 data-source-node="n87">Procedures...</h4>
        <h5 data-source-node="n88">Using the Header Fields</h5>
        <ol class="ol_1" data-source-node="n89">
            <li value="1" data-source-node="n90">Use the Priority 
 Field to indicate in the order that the system will use to assign 
 this rule. The lower the number, the sooner the system will use the record. 
 </li>
        </ol>
        <h5 data-source-node="n91"> </h5>
        <h5 data-source-node="n92">Using the General Tab</h5>
        <ol class="ol_1" data-source-node="n93">
            <li value="1" data-source-node="n94">Use the Criteria 
 Field to indicate what rule set assignment criteria record you 
 want to associate with this priority setting. This criteria defines how 
 the system will determine when it needs to use rule set assignment.<br data-source-node="n95"> </li>
            <li value="2" data-source-node="n96">(Inbound Processing) Use the Locating Rule Field to 
 indicate which locating rule you want the system to use when processing 
 an item. This rule determines how the system will select storage locations 
 when receiving product.<br data-source-node="n97"><br data-source-node="n98">	(Outbound Processing) Use the 
 Allocating Rule Field to indicate which allocation rule you want 
 the system to use when processing an item. This rule determines how the 
 system will select allocation locations for picking.<br data-source-node="n99"> </li>
            <li value="3" data-source-node="n100">Always 
 Override Checkbox: See the <a href="c5d3e4c060e635d9331ae2c4a1834965dbdcc1c3513c0dd840e6ad6b8553ad30.html" data-source-node="n101">field topic</a> for information on this checkbox.<br data-source-node="n102"> </li>
            <li value="4" data-source-node="n103">Press OK. 
 The system will save your record.</li>
        </ol>
