Serial Number Entry Screen

You can use this screen to enter in the serial number values of the item(s) that you are processing (such as packing a container, confirming work, or adjusting inventory into a location).

1. Existing Serial Numbers

 

You will get two options when prompted for existing serial numbers:

  • You can scan or type the serial number and press the Add button. Some scanners can be set up to automatically invoke an "ENTER" action after scanning. This would cause the Add button action to invoke.

  • Alternatively, tap on the serial number listed in the grid. This will check the serial number.

  • After all the serial numbers have been selected for the given quantity, press the Save button.

Note on Serial Number Templates: Items with serial number templates will only be prompted to scan/type or select the major serial number. The grid will show the major (also known as major serial numbers) and all minor serial numbers. The screen will validate that the entered serial number matches with the serial number template for that item.

 

2. New Serial Numbers

 

You will be prompted to scan or type in the new serial number:

  • Press the Add button to insert the serial number into the grid. Some scanners can be set up to automatically invoke an "ENTER" action after scanning. This would cause the Add button action to invoke.

  • After all new serial numbers have been added for the given quantity, press the Save button.

The screen will prompt for the "major" and all "minor" serial number(s) when entering a new serial numbers for an item that is linked to a serial number template. The grid will show the major and all minor serial numbers that have been added. The screen will validate that the entered major and minor serial numbers matches with the serial number template for that item.
