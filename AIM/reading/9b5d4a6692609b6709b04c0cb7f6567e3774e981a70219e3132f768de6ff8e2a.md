
        
        <h1 data-source-node="n56"><a name="kanchor427" data-source-node="n57"></a>Pre-Check In Quantity Field</h1>
        <p data-source-node="n58">This field indicates the receipt line quantity that has not been checked in and is not associated with an ASN (Advanced Shipping Notice) container. The system will allow the user to create pre-check in containers for a receipts which have a pre-check in quantity greater than zero.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The system calculates this value for a receipt in the following manner:</p>
        <blockquote data-source-node="n61">
            <p data-source-node="n62">Open Quantity – Quantity already present on 		ASN containers linked with the receipt line in a check in pending status</p>
        </blockquote>
        <p data-source-node="n63">.</p>
