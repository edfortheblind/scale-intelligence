
        
        <h1 data-source-node="n56"><a name="kanchor1765" data-source-node="n57"></a>Cross-Reference Item Number Field</h1>
        <p data-source-node="n58">A second identifier for an item. The cross-reference 
 number is often the UPC number associated with the item. These values 
 can be used in packing or an RF device to identify the item.</p>
