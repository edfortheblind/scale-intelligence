        </h1>
        <h4 data-source-node="n59">Overview</h4>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Serial Number Template configuration defines the structure used to capture and validate major and minor serial number values. You can configure fixed segment definitions and use advanced pattern validation for segment entry.</p>

        <h4 data-source-node="n69">Configure Serial Number Template</h4>
        <p data-source-node="n70"> </p>
        <h5 data-source-node="n71">1. Major Serial Information</h5>
        <p data-source-node="n72"> </p>
        <p data-source-node="n73"><b data-source-node="n74">Major Serial Number Description</b>: Enter the description for the major serial number template.</p>
        <ul data-source-node="n75">
            <li data-source-node="n76">
                <p data-source-node="n77"><b data-source-node="n78">Allow Range Entry</b>: Enable this option if users should enter serial numbers as a range when supported.</p>
            </li>
            <li data-source-node="n79">
                <p data-source-node="n80"><b data-source-node="n81">Allow Duplicates</b>: Enable this option if duplicate serial numbers are allowed for this template.</p>
            </li>
        </ul>
        <p data-source-node="n82"> </p>
        <h5 data-source-node="n83">2. Major Serial Segments</h5>
        <p data-source-node="n84"> </p>
        <p data-source-node="n85">Define major serial number segments using Segment Type, Length, and Value.</p>
        <ul data-source-node="n86">
            <li data-source-node="n87">
                <p data-source-node="n88"><b data-source-node="n89">Basic Mode</b>: Use basic segment setup for standard segment definitions.</p>
            </li>
            <li data-source-node="n90">
                <p data-source-node="n91"><b data-source-node="n92">Advanced Mode</b>: Use pattern-based configuration with Pattern and Test Data to validate segment rules.</p>
            </li>
        </ul>
        <p data-source-node="n93"> </p>
        <h5 data-source-node="n94">3. Minor Serial Templates</h5>
        <p data-source-node="n95"> </p>
        <p data-source-node="n96">Review and maintain minor serial number template records linked to the selected major template.</p>
        <ul data-source-node="n97">
            <li data-source-node="n98">
                <p data-source-node="n99"><b data-source-node="n100">Add New Minor Serial Number</b>: Create a minor template record.</p>
            </li>
            <li data-source-node="n101">
                <p data-source-node="n102"><b data-source-node="n103">Edit/Delete</b>: Update or remove the selected minor template.</p>
            </li>
        </ul>
        <p data-source-node="n104"> </p>
        <h5 data-source-node="n105">A. Minor Serial Information</h5>
        <p data-source-node="n106"> </p>
        <p data-source-node="n107"><b data-source-node="n108">Minor Serial Number Description</b>: Enter the description for the minor serial template.</p>
        <p data-source-node="n109"><b data-source-node="n110">Allow Duplicates</b>: Enable when duplicate values are allowed for minor serial numbers.</p>
        <p data-source-node="n111"> </p>
        <h5 data-source-node="n112">B. Minor Serial Segments</h5>
        <p data-source-node="n113"> </p>
        <p data-source-node="n114">Define minor serial number segments using Segment Type, Length, and Value.</p>
        <ul data-source-node="n115">
            <li data-source-node="n116">
                <p data-source-node="n117"><b data-source-node="n118">Basic Mode</b>: Configure standard segment definitions.</p>
            </li>
            <li data-source-node="n119">
                <p data-source-node="n120"><b data-source-node="n121">Advanced Mode</b>: Configure pattern-based validation with Pattern and Test Data.</p>
            </li>
        </ul>
        <p data-source-node="n122"> </p>
        <p data-source-node="n123">Use Save to preserve your progress and Continue to move through the configuration steps.</p>
