
        
        <h1 data-source-node="n56"><a name="kanchor1250" data-source-node="n57"></a>Pass Assignment Field</h1>
        <p data-source-node="n58">This field indicates whether a Vocollect user can choose to stop picking an in process work ID, and pass the rest of it on to another user for completion. Note that users cannot pass work during base picking or chase assignments. Work also cannot be passed while splitting a pick.</p>
