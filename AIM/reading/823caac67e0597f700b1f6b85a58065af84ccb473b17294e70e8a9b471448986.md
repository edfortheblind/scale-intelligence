
        
        <h1 data-source-node="n56"><a name="kanchor1598" data-source-node="n57"></a>Message ID Field</h1>
        <h5 data-source-node="n58">Text Messages...</h5>
        <p class="p_1" data-source-node="n59">An identifier associated with a message defined 
 on the Text Message Window. The message is displayed on an RF device for 
 a particular item/account/company combination. This allows you to provide 
 specific instructions at the item/account/company level. This is especially 
 helpful when an account requires unique handling for a particular item.</p>
