
        
        <h1 data-source-node="n56"><a name="kanchor1727" data-source-node="n57"></a>Pattern Field</h1>
        <h5 data-source-node="n58">On the Serial Number Template Window...</h5>
        <p data-source-node="n59">This field displays the code that represents the segments that are defined 
 for a serial number template. The system uses this string to "compute" 
 a serial number according to the parameters in a template. </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">On the Lot Template Window...</h5>
        <p data-source-node="n63">This field allows you to define the date format string if you want the system to auto-fill the date field.</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65">If you select the Custom button, you can enter in your own date format string, The following date formats are pre-defined:</p>
        <ul data-source-node="n66">
            <li data-source-node="n67"><i data-source-node="n68">MMddyyyy</i> (two-digit month, two-digit day, four-digit year)<br data-source-node="n69"><br data-source-node="n70"></li>
            <li data-source-node="n71"><i data-source-node="n72">ddMMyyyy</i> (two-digit day, two-digit month, four-digit year)<br data-source-node="n73"><br data-source-node="n74"></li>
            <li data-source-node="n75"><i data-source-node="n76">yyyyMMdd</i> (four-digit year, two-digit month, two-digit day)</li>
        </ul>
        <p data-source-node="n77"> </p>
        <p data-source-node="n78">Also, there are a number of additional valid characters that are supported to create date format strings. See the Microsoft website linked below for more information:</p>
        <ul data-source-node="n79">
            <li data-source-node="n80"><a href="http://msdn.microsoft.com/en-us/library/az4se3k1.aspx" data-source-node="n81">http://msdn.microsoft.com/en-us/library/az4se3k1.aspx</a>
            </li>
        </ul>
