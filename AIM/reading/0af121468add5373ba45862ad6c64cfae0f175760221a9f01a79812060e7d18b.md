
        
        <h1 data-source-node="n56"><a name="kanchor511" data-source-node="n57"></a>Shipping Label</h1>
        <p data-source-node="n58">A shipping label is used for carrier shipping purposes to identify a 
 shipping container. It includes ship from and ship to information. The 
 system automatically generates shipping labels during container packing 
 and container manifesting. Note that if the shipping container 
 is associated with a company, the system uses the company's name and address 
 as the ship from values on this label.</p>
