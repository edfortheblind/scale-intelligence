
        
        <h1 data-source-node="n56"><a name="kanchor654" data-source-node="n57"></a>Container Group Field</h1>
        <p data-source-node="n58">A container group identifies all of the container types that can be 
 used to pack a particular item. During the container creation wave step, 
 the system processes through the containers in a group, looking for the 
 container that best accommodates the item quantity that needs packed. Container groups are commonly used to ensure 
 that special packaging is reserved for the appropriate items/shipments. </p>
