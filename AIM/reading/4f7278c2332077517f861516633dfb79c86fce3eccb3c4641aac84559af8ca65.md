
        
        <h1 data-source-node="n56"><a name="kanchor2099" data-source-node="n57"></a>How Does the FedEx 
 Server Work With the Application?</h1>
        <p data-source-node="n58">The FedEx 
 PowerShip Plus 
 Server is a shipping tool that provides rating and routing information, 
 in addition to parcel manifest EDI 
 uploads. The server, which is provided by Federal Express, is loaded with 
 its own propriety software. It communicates with the system via a network 
 LAN.</p>

        <h4 data-source-node="n77"><a name="rating" data-source-node="n78"></a>How FedEx and the System Communicate: Manifesting...</h4>
        <p data-source-node="n79">These procedures assume that the FedEx 
 Server was installed at your site and tested to ensure accuracy:</p>
        <ol data-source-node="n80">
            <li value="1" data-source-node="n81">
                <p data-source-node="n82">The system sends a manifesting request to the FedEx 
 Server.</p>
                <p data-source-node="n83"> </p>
            </li>
            <li value="2" data-source-node="n84">
                <p data-source-node="n85">The server manifests the parcel and sends the information back to 
 the system.</p>
                <p data-source-node="n86"> </p>
            </li>
            <li value="3" data-source-node="n87">The system sends a request to the server each 
 time it manifests a parcel.</li>
        </ol>
        <h5 data-source-node="n88">Note on Dimensional Weight Rating:</h5>
        <p data-source-node="n89">Although you will define a parcel’s dimensions in the system, dimensional 
 weight rating is handled by the FedEx 
 Server. The server updates the parcel manifest to reflect the dimensional 
 weight rates that it assigns.</p>

        <h4 data-source-node="n93"><a name="revenue" data-source-node="n94"></a>How FedEx and the System Communicate: Uploading Revenue Files...</h4>
        <p data-source-node="n95">These procedures assume that an employee closed the parcel manifest:</p>
        <ol data-source-node="n96">
            <li value="1" data-source-node="n97">
                <p data-source-node="n98">When FedEx 
 parcel manifests are closed in the system, EDI 
 Files are generated, and a request is sent to transmit the data to FedEx.</p>
                <p data-source-node="n99"> </p>
            </li>
            <li value="2" data-source-node="n100">The FedEx 
 server will dial FedEx 
 Headquarters and transmit the data. FedEx 
 Headquarters will not send a successful transmission message; however, 
 they will send a bill via mail.</li>
        </ol>

        <h4 data-source-node="n109"><a name="download" data-source-node="n110"></a>How FedEx and the System Communicate: Downloads...</h4>
        <p data-source-node="n111">The term "downloads" refers to all information that is downloaded 
 from FedEx 
 Headquarters to the FedEx 
 Server. Downloads include new rates and routing data and updated software.</p>
        <ol data-source-node="n112">
            <li value="1" data-source-node="n113">
                <p data-source-node="n114">From the FedEx 
 Server terminal, an employee will access the ‘Demand Download’ Window; 
 he/she will select a download type.</p>
                <p data-source-node="n115"> </p>
            </li>
            <li value="2" data-source-node="n116">
                <p data-source-node="n117">The FedEx 
 Server dials FedEx 
 Headquarters and transmits the download request.</p>
                <p data-source-node="n118"> </p>
            </li>
            <li value="3" data-source-node="n119">FedEx 
 Headquarters reviews the response and transmits the appropriate data.</li>
        </ol>
