
        
        <h1 data-source-node="n56"><a name="kanchor58" data-source-node="n57"></a>Require Entry Of Quantity Checkbox</h1>
        <p data-source-node="n58">This setting determines if the system will default the packed item quantity value in the Packed Quantity Field on the Packing Screen. If this checkbox is not selected, then the Packed Quantity value will be zero, and the user will have to manually indicate how much they are packing into the container.</p>
