
        
        <h1 data-source-node="n56"><a name="kanchor1354" data-source-node="n57"></a>Maximum Number of License Plates in a Location
        </h1>
        <p data-source-node="n58">This feature allows you to define the maximum number of license plates (LPs) that can be placed in a location.</p>
        <p data-source-node="n59">Previously, SCALE allowed an unlimited number of LPs in an inventory location. With this enhancement, you can define a location-level limit that supports your warehouse picking and storage practices.</p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Configuration</h4>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">A new configuration value, <b data-source-node="n64">Max Number of License Plates</b>, is available in the <b data-source-node="n65">Location Wizard</b> under <b data-source-node="n66">Inventory Options</b>.</p>
        <ul data-source-node="n67">
            <li data-source-node="n68">
                <p data-source-node="n69">Default value: <b data-source-node="n70">0</b> (unlimited LPs).</p>
            </li>
            <li data-source-node="n71">
                <p data-source-node="n72">When set to a value greater than 0, the location enforces that maximum LP count.</p>
            </li>
        </ul>
        <p data-source-node="n73">The <b data-source-node="n74">Max Number of License Plates</b> value is available only when:</p>
        <ul data-source-node="n75">
            <li data-source-node="n76">
                <p data-source-node="n77">The location is configured to <b data-source-node="n78">Track License Plates</b>.</p>
            </li>
            <li data-source-node="n79">
                <p data-source-node="n80">The location class is <b data-source-node="n81">Inventory Storage</b>.</p>
            </li>
        </ul>
        <p data-source-node="n82"> </p>
        <h4 data-source-node="n83">Validation Rules</h4>
        <p data-source-node="n84"> </p>
        <p data-source-node="n85">The number of LPs counted against a location’s maximum value is determined by the following rules:</p>
        <ul data-source-node="n86">
            <li data-source-node="n87">
                <p data-source-node="n88"><b data-source-node="n89">Parent LP designation:</b> A parent LP counts as 1 toward the location maximum. A parent LP is counted only once.</p>
            </li>
            <li data-source-node="n90">
                <p data-source-node="n91"><b data-source-node="n92">Standalone LP:</b> A standalone LP counts as 1 toward the location maximum.</p>
            </li>
            <li data-source-node="n93">
                <p data-source-node="n94"><b data-source-node="n95">In-transit LPs:</b> LPs in transit to the location are included in the maximum LP count (using the same parent/standalone counting logic).</p>
            </li>
        </ul>
        <p data-source-node="n96"> </p>
        <h4 data-source-node="n97">System Behavior</h4>
        <ul data-source-node="n98">
            <li data-source-node="n99">
                <p data-source-node="n100">If placing an LP keeps the location at or below the configured maximum, the placement succeeds.</p>
            </li>
            <li data-source-node="n101">
                <p data-source-node="n102">If placing an LP would exceed the configured maximum, the placement is blocked and the user receives an error message.</p>
            </li>
        </ul>
        <p data-source-node="n103"> </p>
        <h4 data-source-node="n104">Example</h4>
        <p data-source-node="n105"> </p>
        <p data-source-node="n106">If <b data-source-node="n107">MaxLP = 3</b> and the current LP count is 2, adding one more qualifying LP succeeds (count becomes 3).</p>
        <p data-source-node="n108">If <b data-source-node="n109">MaxLP = 3</b> and the current LP count is already 3, adding another qualifying LP fails (count would become 4).</p>
