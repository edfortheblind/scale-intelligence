
        
        <h1 data-source-node="n56"><a name="kanchor861" data-source-node="n57"></a>Returns Shipping/Accessorial Charge Field</h1>
        <p data-source-node="n58">This value represents how much UPS will charge to ship the returned 
 package back to the warehouse, plus the accessorial charge it levies for 
 the return label. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"><span class="span_3" data-source-node="n61">NOTE:</span> This field will not have 
 a value in it unless the UPS Return accessorial is assigned to a container, 
 and the container is manifested.</p>
