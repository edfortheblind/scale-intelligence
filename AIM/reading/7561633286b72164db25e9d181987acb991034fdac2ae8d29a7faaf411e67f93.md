
        
        <h1 data-source-node="n56"><a name="kanchor1729" data-source-node="n57"></a>Route Field</h1>
        <p data-source-node="n58">This field represents a user-defined value 
 that is designed to describe the general area where a shipment is to be 
 shipped. The system can use this value for lane building or load building 
 in order to better distribute shipments.</p>
