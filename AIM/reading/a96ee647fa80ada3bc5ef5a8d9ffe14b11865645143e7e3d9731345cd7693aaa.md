
        
        <h1 data-source-node="n56"><a name="kanchor1892" data-source-node="n57"></a>Initiation Method (Workflow) Field</h1>
        <h5 data-source-node="n58">In the Receiving Preferences Window...</h5>
        <p data-source-node="n59">This field indicates the initiation workflow that you want the user to use during the RF receiving process. Included in each workflow are the separate activities that will occur during the pre-execution stage of RF receiving. Examples of these activities are the "initiation" field that the system will prompt for at the beginning of RF receiving (such as receipt ID, item, etc), whether QC inspection is active, or whether GS1 processing is to be used. See the <a href="81d022a2ab379af5c9e945433d1bd3f6e09728fcfd355546989e79b3a0ecfa54.html" data-source-node="n60">SCALE SDK</a> for more detailed information on how to use workflow with RF receiving.<br data-source-node="n61"></p>
