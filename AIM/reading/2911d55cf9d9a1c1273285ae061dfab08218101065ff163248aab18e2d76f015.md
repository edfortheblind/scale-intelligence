
        
        <h1 data-source-node="n56">Warehouse Mobile - Location Inquiry</h1>
        <p data-source-node="n57">The location inquiry enables you to search and view the location inventory records on warehouse mobile. This helps to validate the items actual quantity with that of the quantity physically present in a location. Also, you can access the adjust or transfer inventory actions from this screen.</p>

        <h4 data-source-node="n70"><a name="Search" data-source-node="n71"></a>Perform a search</h4>
        <p data-source-node="n72">The following details the steps you can use to search for inventory using this screen</p>
        <ol data-source-node="n73">
            <li value="1" data-source-node="n74">Log in to Warehouse Mobile application.</li>
            <li value="2" data-source-node="n75">Select the <b data-source-node="n76">Location Inquiry</b> option from the <b data-source-node="n77">Warehouse Mobile Main Menu.</b></li>
            <li value="3" data-source-node="n78">Enter any combination of field characters for <b data-source-node="n79">location</b>, <b data-source-node="n80">item</b> and <b data-source-node="n81">LP</b> and tap <b data-source-node="n82">Go</b>. For example, suppose you have two LP's in your warehouse called "LP12345" and "123LP45". If you enter the value "LP" and search, the system will display the record for "LP12345" but not the record for "123LP45", because it assumes that the criteria you enter appears at the beginning of the value.</li>
            <li value="4" data-source-node="n83">The following field information is displayed.<ul data-source-node="n84"><li data-source-node="n85">Record - It displays the record number of the total records listed. For example, 5 of 1500.</li><li data-source-node="n86">Location and item name is displayed. Tap <b data-source-node="n87">i</b> to see the detailed information pop-up screen.</li><li data-source-node="n88">The status, On hand and Unit of measurement is displayed. The system will display all location inventory records for the current warehouse that have item quantities that are in any of the four statuses: On-Hand, In-Transit, Allocated  and Suspense.</li><li data-source-node="n89">In case its serial number tracked item, then On Hand will have the information symbol. Tap to view all the serial numbers associated with the item.</li></ul></li>
            <li value="5" data-source-node="n90">Tap <b data-source-node="n91">Go</b> to view the next record.</li>
            <li value="6" data-source-node="n92">Tap <b data-source-node="n93">Actions</b> &gt;&gt; <b data-source-node="n94">Previous Record</b> to view the record already viewed.</li>
            <li value="7" data-source-node="n95">Tap <b data-source-node="n96">Actions &gt;&gt; Cancel</b> to go back to the  search screen.</li>
        </ol>
        <h4 data-source-node="n97"><a name="Inventory" data-source-node="n98"></a>Perform Inventory Management Action from Location Inquiry</h4>
        <p data-source-node="n99">Inventory transfer of adjustment and transfer can be performed in the following way.</p>
        <ul data-source-node="n100">
            <li data-source-node="n101">Log in to Warehouse Mobile application.</li>
            <li data-source-node="n102">Select the <b data-source-node="n103">Location Inquiry</b> option from the <b data-source-node="n104">Warehouse Mobile Main Menu.</b></li>
            <li data-source-node="n105">Enter search criteria value and tap <b data-source-node="n106">Go</b>. </li>
            <li data-source-node="n107">All the records for the warehouse based on the item/location or License plate is displayed.</li>
            <li data-source-node="n108">Adjustment<ul data-source-node="n109"><li data-source-node="n110">Tap <b data-source-node="n111">Actions</b> &gt;&gt; <b data-source-node="n112">Adjust</b>, to view <b data-source-node="n113">the Select Adjustment class</b> screen. </li><li data-source-node="n114"> Tap on the <b data-source-node="n115">Adjustment Type</b> to view the Pop-up. Select the required option. For example <b data-source-node="n116">Positive Adjustment</b> and Tap <b data-source-node="n117">Go</b></li><li data-source-node="n118"><p data-source-node="n119">Enter the quantity that needs to be adjusted, and tap <b data-source-node="n120">Go</b>.</p></li><li data-source-node="n121">System will prompt to select the Inventory Status and then Tap <b data-source-node="n122">Go</b></li><li data-source-node="n123">User Defined fields are highlighted for selection. </li><li data-source-node="n124">Tap <b data-source-node="n125">Actions</b> &gt;&gt; <b data-source-node="n126">Done</b>, to complete the adjustment for the inventory.</li></ul></li>
            <li data-source-node="n127">Status Change<ul data-source-node="n128"><li data-source-node="n129">Tap <b data-source-node="n130">Actions</b> &gt;&gt; <b data-source-node="n131">Status Change</b>, to view <b data-source-node="n132">Select Adjustment class</b> screen.</li><li data-source-node="n133">Tap on the <b data-source-node="n134">Status Change</b> to view the Pop-up. Select the required option and Tap <b data-source-node="n135">Go</b>.</li><li data-source-node="n136">Item and description details are displayed.</li><li data-source-node="n137">Select for  <b data-source-node="n138">All location</b> Yes or No and Tap <b data-source-node="n139">Go</b>.</li><li data-source-node="n140">System will prompt for LP and Lot values if needed.</li><li data-source-node="n141">Tap <b data-source-node="n142">Status</b> field, and modify the status. Tap <b data-source-node="n143">Go</b> and inventory status change success message is displayed.<ul data-source-node="n144"><li data-source-node="n145">System prompts for Inventory Attributes for location (if configured).</li><li data-source-node="n146">Tap Go and inventory status change success message is displayed.</li></ul></li></ul></li>
            <li data-source-node="n147">Transfer<ul data-source-node="n148"><li data-source-node="n149">Tap <b data-source-node="n150">Actions</b> &gt;&gt; <b data-source-node="n151">Transfer</b>, to view the <b data-source-node="n152">Select Adjustment class</b> screen.</li><li data-source-node="n153"> Tap on the <b data-source-node="n154">Adjustment Type</b> to view the Transfer adjustment class. Select the required option. For example <b data-source-node="n155">Transfer</b> and Tap <b data-source-node="n156">Go</b>.</li><li data-source-node="n157">Enter the transfer quantity value and Tap <b data-source-node="n158">Go</b>.</li><li data-source-node="n159">Enter the <b data-source-node="n160">To location</b> value and Tap <b data-source-node="n161">Go</b>.</li><li data-source-node="n162">Select the <b data-source-node="n163">Status to</b> and Tap <b data-source-node="n164">Go</b>.<ul data-source-node="n165"><li data-source-node="n166">System prompts for Inventory Attributes for location (if configured).</li></ul></li><li data-source-node="n167">Optionally enter User Defined fields if required. </li><li data-source-node="n168">Tap <b data-source-node="n169">Actions</b> &gt;&gt; <b data-source-node="n170">Done</b>. Inventory transfer successful message is displayed.</li></ul><p data-source-node="n171"> </p><p data-source-node="n172">Edit  Attributes</p><p data-source-node="n173"><b data-source-node="n174">Edit attributes</b> option is displayed only if the exit point <b data-source-node="n175">’WM Capture inventory attributes</b>’ is turned on. If not then system will not show the <b data-source-node="n176">Edit attributes</b> option.</p><ul data-source-node="n177"><li data-source-node="n178"><p data-source-node="n179">Tap <b data-source-node="n180">Actions</b> &gt;&gt; <b data-source-node="n181">Edit Attributes</b> to edit attributes for the location.</p><ul data-source-node="n182"><li data-source-node="n183"><p data-source-node="n184">System will populate attributes value if already saved for the location.</p></li></ul></li><li data-source-node="n185"><p data-source-node="n186">You can add/edit Inventory Attributes 1-9. </p></li><li data-source-node="n187"><p data-source-node="n188">Tap <b data-source-node="n189">Actions &gt;&gt; Done</b> to save the attributes.</p></li></ul></li>
        </ul>
