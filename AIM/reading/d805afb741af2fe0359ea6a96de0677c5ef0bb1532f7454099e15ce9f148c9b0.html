Item Process Summary

** Functionality **

 

 

 

Summary...

If you do not want to interface item records from your ERP system, you can define them in SCALE. By defining an item in the system, you can manage how its processed, what allocation and locating rules are applied to it, and what handling controls (lot-controlled, serial number-tracked, etc) are required during processing. Item setup is optional. If you do not want to create records on the Item Window, the system will reference the item values defined on the shipment line records. An item record identifies a product's unique characteristics, such list price, department, style and size. If your warehouse supports multi-company processing, you can identify the company on each item record.

 

 

 

Related Topics...

- Setup Overview

 

 

 

The following are key features of the item functional area:

 

 

Item Templates...

The system supports item templates, which you can use to define the structure of an item ID. An item template can also include a separator character.

 

 

 

Item Unit of Measure...

An item's unit of measure (UM) identifies the storage container used to move product through the warehouse. The system uses this information to calculate how much product can fit in a location based on its UM breakdown. Common examples of UMs include cases, pallets, eaches and inner packs. You can view the item's UM from the Movement Class Analysis Insight Screen and you can research on the movement class data (per item/company/location/warehouse) for each unit of measure for that item combination.

 

In the List Pane Grid Field of Movement Class Analysis Insight Screen, clicking on the View hyperlink opens the Movement Class Item Unit of Measure window where the system displays following fields:

  • Sequence
  • Conversion Quantity
  • Quantity UM
  • Movement Class
  • Length
  • Width
  • Height
  • Dimension UM
  • Weight
  • Weight UM

 

Alternate/Substitute Items...

You can associate alternate or substitute item(s) to an item master. An alternate item is an item that the system will assign to an order if the original item ordered is no longer available (because it is obsolete, out of season, etc). A substitute item is an item that the system will assign to an order if the original item ordered is no longer in stock in the warehouse.

 

 

 

Item Cross References...

You can create an item cross-reference record for any item defined in the application. A cross-reference number is established to identify an item's UPC or EAN-14 number. A user processing an item can use either the item number or the cross-reference number to identify it during SCALE processing.
