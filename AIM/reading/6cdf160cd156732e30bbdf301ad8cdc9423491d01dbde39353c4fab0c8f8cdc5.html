Verification Method Field

This field identifies the method of work verification at a location, such as a location name. A worker uses this verification method to prove that work at a specific location has been completed.

 

None

 

If you choose this option, then the system will not require any method of work verification at this location.

 

Location Name

 

 If you choose this option, then the system will require the worker to enter a location name to verify work done at this location.
