
        
        <h1 data-source-node="n56">Short Pick Screen</h1>
        <p data-source-node="n57">You can use this window to perform a short pick from the Shipment Line Screen. You may need to perform a short pick if you want to pick less 
 inventory than the system has allocated for a certain shipment. The system 
 will display this window if you enter a quantity less than the quantity 
 allocated for a shipment line. Note that this window is only displayed 
 when short picking a shipment that has no work created for it.</p>
