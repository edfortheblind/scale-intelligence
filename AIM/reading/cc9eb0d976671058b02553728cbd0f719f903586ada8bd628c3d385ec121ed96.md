
        
        <h1 data-source-node="n56"><a name="kanchor705" data-source-node="n57"></a>Rating ID Field</h1>
        <p data-source-node="n58">This field is used for rating. It contains the name used to identify a carrier.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Using Progistics Rating...</h5>
        <p data-source-node="n62">This value is obtained 
 from Progistics and defined on the following the system window: Rating 
 ID Window. The rating ID is linked to the carrier in the system on the 
 Carrier Window. If you need additional rating IDs for other 
 carriers, contact your system representative. Although you can add rating 
 IDs yourself, we strongly recommend that 
 your system consultant define all rating IDs. If a rating ID is 
 improperly defined, Progistics will be unable to generate rates for any 
 carrier associated with that ID.</p>
        <p align="left" class="p_13" data-source-node="n63"> </p>
        <p align="left" class="p_13" data-source-node="n64"> </p>
        <h5 align="left" data-source-node="n65">Using Internal Less Than Truckload Rating...</h5>
        <p align="left" data-source-node="n66">In order to identify LTL internal rating within SCALE,the 'Carrier Symbol' defined on the rating ID must be 'ILS.LTL'. This will allow you to set up carriers that rate using the internal LTL rating process.</p>
