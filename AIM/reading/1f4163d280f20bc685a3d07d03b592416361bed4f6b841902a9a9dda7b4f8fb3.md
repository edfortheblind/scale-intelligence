
        
        <h1 data-source-node="n56"><a name="kanchor189" data-source-node="n57"></a>Associating Text Messages</h1>
        <p data-source-node="n58">You will use this window to associate an existing text message with 
 an item/company or account/company: company is an optional, not required 
 value. When the item/company or account/company is processed, the system 
 will display the message on the RF and Warehouse Mobile devices. This is especially helpful 
 when the account requires special handling for a specific item, such as 
 additional labeling or handling. The actual text message must be defined 
 on the Text Message Window before you can associate it with an item/company 
 or account/company.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">For example, if you want employees to insert a safety booklet into a company's item box, you can associate the text message "Insert Safety Message" 
 with the company's item. When the employee picks the company's item, the 
 system will display the message; it will not display the message when 
 the employee picks an item associated with another company. The message 
 is displayed on an RF and Warehouse Mobile devices or the Text Message Window (from the Work 
 Insight Screen).</p>

        <h4 data-source-node="n89">Procedures...</h4>
        <ol data-source-node="n90">
            <li value="1" data-source-node="n91">Use the Item 
 Field to associate a specific item with a text message. Each time 
 this item is processed during a work execution, the system will display 
 the message.</li>
            <ul type="disc" class="ul_1" data-source-node="n92">
                <p data-source-node="n93"> </p>
            </ul>
            <li value="2" data-source-node="n94">Use the Account 
 Field to associate a specific account with a text message. Each 
 time someone processes a work instruction for this account, the system 
 will display the message.</li>
            <ul type="disc" class="ul_1" data-source-node="n95">
                <p data-source-node="n96"> </p>
            </ul>
            <li value="3" data-source-node="n97">
                <p data-source-node="n98">Use the Company Field to 
 identify a the company associated with the item and/or account you specified 
 above. This allows you narrow when the message is displayed based on company. 
 For example, in the screen graphic below, the message will only display 
 when item 712.885 is processed for company 001.</p>
                <p data-source-node="n99"> </p>
            </li>
            <li value="4" data-source-node="n100">
                <p data-source-node="n101">Use the Message ID Field 
 to identify the message that you want displayed.</p>
                <p data-source-node="n102"> </p>
            </li>
            <li value="5" data-source-node="n103">
                <p data-source-node="n104">Press OK. The system will 
 save your record. Note that after you add a record, the 
 message's text will appear in the right portion of the screen, which appears 
 blank in the graphic above, because the user has not yet selected OK to 
 add the record.</p>
            </li>
        </ol>
