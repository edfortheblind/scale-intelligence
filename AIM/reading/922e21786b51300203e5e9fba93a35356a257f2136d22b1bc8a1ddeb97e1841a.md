
        
        <h1 data-source-node="n56"><a name="kanchor2025" data-source-node="n57"></a>Identifier Field</h1>
        <p data-source-node="n58">This field represents the name of a record defined on a generic configuration 
 or dynamic calling window. The value that you enter in this field is dependent 
 on what type of record it is. For example, if you are creating a record 
 in the Location Class Window, the identifier will represent a location 
 class name, such as Shipping Dock. Later, the system uses this field to 
 identify a record in the system.</p>
