
        
        <h1 data-source-node="n56"><a name="kanchor760" data-source-node="n57"></a>Internal Shipment Line Number Field</h1>
        <p data-source-node="n58">The internal line number 
 is generated in the interface. In the interface, shipments are created 
 to accommodate orders; shipment lines are created to accommodate order 
 lines. The internal shipment line number represents the order line. All 
 updates to the order line are based on activity at the internal line number 
 level.</p>
