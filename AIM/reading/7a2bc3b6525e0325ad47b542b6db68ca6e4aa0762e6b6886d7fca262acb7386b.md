
        
        <h1 data-source-node="n56"><a name="kanchor45" data-source-node="n57"></a>Creating Zones</h1>
        <p data-source-node="n58">A zone manages the activity that can occur in a group of locations. 
 Zones can also be used to group together locations for processing. For 
 example, if an allocation rule identifies Zone B, the system will only 
 consider allocating product from a location in Zone B (when this rule 
 is used). This minimizes processing time and increases your control over 
 which locations are considered during system processes such as locating 
 and allocation.</p>

        <h4 data-source-node="n91">Procedures...</h4>
        <p data-source-node="n92">Access the Zone Window. Name the record and provide a description.</p>
        <ol data-source-node="n93">
            <li value="1" data-source-node="n94">
                <p data-source-node="n95">Use the Zone Type Field 
 to identify the function of this zone. The system supports three zone 
 types:</p>
                <p data-source-node="n96"> </p>
            </li>
            <ul type="disc" class="ul_1" data-source-node="n97">
                <li data-source-node="n98">
                    <p data-source-node="n99">Locating zones group 
 together locations that share the same locating requirements.</p>
                    <p data-source-node="n100"> </p>
                </li>
                <li data-source-node="n101">
                    <p data-source-node="n102">Allocation 
 zones group together locations that share the same allocating 
 requirements.</p>
                    <p data-source-node="n103"> </p>
                </li>
                <li data-source-node="n104">Work 
 zones group together locations serviced by the same work 
 teams and equipment types. In addition, the same work types are performed 
 in a work zone.</li>
            </ul>
            <p data-source-node="n105"> </p>
            <li value="2" data-source-node="n106">
                <p data-source-node="n107">Use the Pick Management Active 
 Checkbox to indicate if the system will display this zone in the 
 Picking Management Explorer and Picking Window. Only zones that have this 
 checkbox selected will be available to be picked from in these windows.   You must choose a zone type of "Work" if 
 you want to activate picking management. 
 Note that both this flag and the work type associated with 
 the work instruction must be checked to be eligible for picking from these 
 windows.</p>
                <p data-source-node="n108"> </p>
            </li>
            <li value="3" data-source-node="n109">
                <p data-source-node="n110">Press OK. The system will 
 save your record.</p>
                <p data-source-node="n111"> </p>
            </li>
        </ol>
