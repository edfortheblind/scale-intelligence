FedEx Generic Configuration Windows

You will use this window to define the values for some FedEx fields contained in various system windows. For example, the values created in this window for FedEx Container Types will appear in the FedEx Container Types Field in SCALE. You can access these windows from the Generic Config Header Window (via the Configurations Explorer). Use these windows the same as you would use any other system configuration.

 

The following are considered FedEx Generic Configuration Windows:

  • FedEx Container Types

  • FedEx Doc Types

  • FedEx Express Payment Code

  • FedEx Ground Payment Code

  • FedEx Terms of Sale
