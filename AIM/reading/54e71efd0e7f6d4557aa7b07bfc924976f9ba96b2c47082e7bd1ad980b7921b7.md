
        
        <h1 data-source-node="n56"><a name="kanchor1298" data-source-node="n57"></a>Change Manifest Date At Ship Confirm Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates that you want the system to remanifest a container 
 for the ship confirmation date:</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">If this checkbox 
 is selected, the system will remanifest a container for a different 
 date.<br data-source-node="n61"> </li>
            <li data-source-node="n62">If this checkbox 
 is not selected, a container will keep the date it was originally 
 manifested for. For example, if you ship confirm after midnight, you would 
 not want to change the date on all the containers that really left the 
 date before (i.e. before midnight).</li>
        </ul>
