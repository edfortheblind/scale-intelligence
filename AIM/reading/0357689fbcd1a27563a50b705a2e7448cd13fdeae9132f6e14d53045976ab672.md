
        
        <h1 data-source-node="n56"><a name="kanchor1150" data-source-node="n57"></a>Marked For Work Creation Checkbox or Toggle</h1>
        <p data-source-node="n58">This checkbox/toggle indicates that the system should create work for a certain replenishment request. When the Create Replenishment Work scheduled job is run, the system will pick up all requests that are "marked" for work creation. This setting can be activated in the following instances:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">The <i data-source-node="n61">user </i>sets it from the Replenishment Request screen.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64">The <i data-source-node="n65">system </i>sets it due to a pick occurring where the quantity at a location falls below the defined replenishment threshold, and a replenishment request awaits work.<br data-source-node="n66"><br data-source-node="n67"></li>
            <li data-source-node="n68">The <i data-source-node="n69">system </i>sets it during a replenishment wave, when the Multiple Requests For Permanent Location Checkbox is selected on a permanent location, the Create Work Method is automatic/manual, and the location's on hand quantity is less than the defined replenishment threshold. In this case, the first replenishment request would have its Mark For Work Creation flag set to Y.<br data-source-node="n70"><br data-source-node="n71"></li>
            <li data-source-node="n72">
                <p data-source-node="n73">When Marked for Work creation flag is set to N and Work created is also set to N, the icon is red.<br data-source-node="n74"><br data-source-node="n75"></p>
            </li>
            <li data-source-node="n76">
                <p data-source-node="n77">When Marked for Work creation flag is set to Y and Work created is set to N, the icon is green.</p>
            </li>
        </ul>
