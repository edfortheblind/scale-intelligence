
        
        <h1 data-source-node="n56"><a name="kanchor3" data-source-node="n57"></a>Bits Per Byte Field</h1>
        <p data-source-node="n58">This field represents the number of bits used 
 to represent the character being transmitted. The receiver (the system) 
 and the transmitter (the scale) must agree on the number of data bits. 
 Almost all devices transmit data using 7 or 8 bits. See the scale manual 
 for the setting for your scale.</p>
