Searching/Viewing Interface Error Records...

  1. Open the Interface Error Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search:

  3. Press the Filter Button. The system will display the resulting records in the List Pane.

 

 

 

About the List Pane...

  • The Interface History Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.
