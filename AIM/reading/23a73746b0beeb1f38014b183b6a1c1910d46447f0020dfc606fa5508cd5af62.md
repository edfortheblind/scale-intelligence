
        
        <h1 data-source-node="n56"><a name="kanchor642" data-source-node="n57"></a>Revision Number Field</h1>
        <p data-source-node="n58">This field is used to differentiate between 
 different versions of the same bill of material. If you select the Copy 
 action on an existing bill of material record, the system will replicate 
 that record, and increment its revision number by 1. Therefore, if you have multiple bills of material 
 with the same finished item, when you create a work order, you are allowed to choose which revision version you want to use for this particular work order.</p>
