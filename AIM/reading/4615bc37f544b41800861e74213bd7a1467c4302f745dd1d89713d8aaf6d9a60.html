Procedures...

  1. Use the Warehouse Address Tab fields to define the warehouse's general shipping information.

    - Use the UCC/EAN Number Field to provide the UCC/EAN identifier assigned to this warehouse. This number is a warehouse prefix that is a unique value which identifies this warehouse. Note that if you define company(s) in the Company Window, then you do not need to provide this value. You will have to provide a UCC/EAN Number for each company in the Company Window.
     
  2. Use the Returns Address Tab fields to identify where all product shipped for this warehouse will be returned.
     
  3. Use the Freight Bill To Address Tab fields to identify the billing address, if it is different than the shipping address.
     
  4. Use the Authorized Users Tab Checkboxes to assign employees to this warehouse. Only employees that you select from this tab will be able to process entities in this warehouse.

  5. Use the Interface tab fields to identify if data should be interfaced for certain process conditions based on the company.

  6. Use the Miscellaneous Tab fields to define several warehouse-related values:

     

    SQL Server Reporting Services
    - Use the Rendered Document PDF File Directory Field in the warehouse as well as in the document type to indicate where you want SQL Server Reporting Services to place rendered (created).pdf files. Note that these .pdf files are not automatically deleted from this directory after they are printed by the default PDF reader application. For additional information, refer to the Rendered Document PDF File Directory Field topic.

  7. Press OK. The system will save your record.
