
        
        
        <h1 data-source-node="n57"><a name="kanchor514" data-source-node="n58"></a>Creating Security Groups</h1>
        <p data-source-node="n59">Group level security allows you to establish a group of users who are all assigned the same security. A security group allows you to add users with common job functions. This allows you to add or remove users from the group as needed.  A user will be allowed to belong to only one group at a time. If a user is already assigned to another security group, the user's name will be displayed in red on this window.  Any security settings for a group can be changed and all users in the group would automatically reflect the new settings. For example, the security administrator wants to set up a “security profile” for all users in the 'Packing' department – with authority to just those options that people in the group need. As individuals join the packing area, the security administrator  assign users to the 'Packing' group.  This allows you to automatically implement the security for that group without having to do any other setup for that specific user. </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">A security "group" can be assigned on the User Profile or Security Permissions windows. A security group's permissions can be copied to a different security group. Or, the security group's permissions can be copied to a specific user. When a security group is copied, only the forms (windows) are copied. Users are not copied. The 'Security Permissions' window displays what group level security records are assigned to a specific form (window).</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">Security is defined from the Security Setup folder (accessed from the Configurations 
 Explorer). </p>

        <h4 data-source-node="n109"><a name="Groups" data-source-node="n110"></a>Using Security Groups...</h4>
        <p data-source-node="n111">Before a security group can be assigned to the security permissions records, a group needs to be created using the Security Group Window. Using a security group is optional depending on your operational security requirements.</p>
        <ol data-source-node="n112">
            <li value="1" data-source-node="n113">Enter the name of the security group and description.<br data-source-node="n114"><br data-source-node="n115"></li>
            <li value="2" data-source-node="n116">Assign/Unassign users to this group or create the group without any users assigned. (Note: if a user is already assigned to another security group, their name will be highlighted in red).<br data-source-node="n117"><br data-source-node="n118"></li>
            <li value="3" data-source-node="n119">Use the Display Only Current Group Users Checkbox to only display users that are assigned to this record's group.<br data-source-node="n120"><br data-source-node="n121"></li>
            <li value="4" data-source-node="n122">Use the Check All Checkbox for the system to select all the user(s) that are currently being displayed in the tab. If you unselect the 'Check All' checkbox, the system will unselect all the user(s) that are currently displayed.<br data-source-node="n123"><br data-source-node="n124"></li>
            <li value="5" data-source-node="n125">Use the Filter field, to type text into the edit box and the user names will automatically filter to your criteria. A '%' can also be entered as a wildcard. For example, '%smith'<br data-source-node="n126"><br data-source-node="n127"></li>
            <li value="6" data-source-node="n128">Click OK to update.</li>
        </ol>

        <h4 data-source-node="n131"><a name="CopyG" data-source-node="n132"></a>Copying a Groups Security Permissions to a User or Group...</h4>
        <ol data-source-node="n133">
            <li value="1" data-source-node="n134">Access the Security Group Window (from the Configurations Explorer Security Folder). <br data-source-node="n135"><br data-source-node="n136"></li>
            <li value="2" data-source-node="n137">Select the Security Group you want to copy.<br data-source-node="n138"><br data-source-node="n139"></li>
            <li value="3" data-source-node="n140">Click OK. The security group is displayed.<br data-source-node="n141"><br data-source-node="n142"></li>
            <li value="4" data-source-node="n143">From the Actions Menu, select either Copy Group Security Permissions  'To User' or 'To Group' option..<br data-source-node="n144"><br data-source-node="n145"></li>
            <li value="5" data-source-node="n146">From the Copy Permissions To Window, select the destination security user or group.<br data-source-node="n147"><br data-source-node="n148"></li>
            <li value="6" data-source-node="n149">Click OK to update and copy.</li>
        </ol>

            <li value="4" data-source-node="n164">From the Actions Menu, select either Copy User Security Permissions to 'To Group'  or 'To User' option.<br data-source-node="n165"><br data-source-node="n166"></li>
            <li value="5" data-source-node="n167">From the Copy Permissions To Window, select the destination group or user.<br data-source-node="n168"><br data-source-node="n169"></li>
