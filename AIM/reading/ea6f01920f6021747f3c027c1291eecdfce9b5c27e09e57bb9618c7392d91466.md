
        
        <h1 data-source-node="n56"><a name="kanchor858" data-source-node="n57"></a>Assign Shipment To Load Checkbox</h1>
        <p data-source-node="n58">You can use this checkbox to indicate whether or not you want the system to automatically attempt to assign a shipment to a load when a user closes a container on the shipment. </p>
        <ul data-source-node="n59">
            <li data-source-node="n60"><b data-source-node="n61">If this checkbox is selected</b>, the system will automatically check to see if the shipment has been already assigned to a shipping load.  If it has not been, the system will either find the current open shipping load (for the appropriate carrier and scheduled ship date) and assign the shipment to it; or, the system will create a new shipping load.
<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64"><b data-source-node="n65"> If this checkbox is not selected</b>, the system will not attempt to assign a shipment to a shipping load in this situation.</li>
        </ul>
