
        
        <h1 data-source-node="n56"><a name="kanchor1127" data-source-node="n57"></a>User Assigned Field</h1>
        <p class="p_1" data-source-node="n58">The employee assigned to process a particular work unit. If you associated 
 a specific user with a work creation record, the system will assign that 
 employee with the work unit. No other user can execute the work. You can use the Assign User action on the Work Insight to 
 change the employee associated with a work unit.</p>
