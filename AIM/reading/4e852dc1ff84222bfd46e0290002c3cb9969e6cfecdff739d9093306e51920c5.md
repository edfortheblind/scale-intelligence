
        
        <h1 data-source-node="n56"><a name="kanchor52" data-source-node="n57"></a>Add License Plates During Cycle Count Checkbox</h1>
        <h5 data-source-node="n58"><b style="color: #000080" data-source-node="n59">On the Work Special Handling Window (Cycle Count Tab)</b>
        </h5>
        <p data-source-node="n60">This setting (when enabled) allows you to identify a new license plate to the system  when performing a cycle count for a location. </p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62"><span style="color: #ff0000;font-style: italic" data-source-node="n63">Important:</span> If you want to confirm less license plates than the system thinks exist in the location, then this checkbox will expose the <i data-source-node="n64">Done</i> button on RF so that you are not forced to count all of the license plates in order to complete the cycle count work.</p>
        <p data-source-node="n65"> </p>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67"> </p>
        <p data-source-node="n68"><u style="font-style: italic" data-source-node="n69">Notes</u>
        </p>
        <p data-source-node="n70">- This setting is only available when you are using a License Plate Selection Method of <i data-source-node="n71">user initiated</i>. </p>
        <p data-source-node="n72"> </p>
        <p data-source-node="n73">- When the user attempts to add a new license plate, the system will reference the user's cycle count preferences:</p>
        <ul data-source-node="n74">
            <li data-source-node="n75"><i data-source-node="n76">If the license plate falls within the user's positive tolerance</i>, then the system will add to the location the new license plate/item quantity. <br data-source-node="n77"><br data-source-node="n78"></li>
            <li data-source-node="n79"><i data-source-node="n80"> If the license plate falls above the user's positive tolerance</i>, then the system will set the count of this location to pending review.</li>
        </ul>
        <p data-source-node="n81">- You can have the system set all counts that involve new license plates to a pending review status using the Set New License Plates To Pending Review Checkbox.</p>
        <p data-source-node="n82"> </p>
        <p data-source-node="n83">- The system will ignore this setting if you have the ability to add items during a count. Since you are always allowed to add license plates when adding an item to a location's count, this setting is not recognized.</p>
        <p data-source-node="n84"> </p>
