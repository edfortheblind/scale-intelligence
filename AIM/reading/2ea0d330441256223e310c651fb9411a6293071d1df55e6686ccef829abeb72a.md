
        
        <h1 data-source-node="n57"><a name="kanchor219" data-source-node="n58"></a>Verify Container ID Checkbox</h1>
        <p data-source-node="n59">This field is displayed on the Packing Preferences Window. It determines 
 if the system will display a container ID after something has been packed 
 in it.</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">If this checkbox 
 is selected, the system will not display a container ID after something 
 has been packed in it. Each time you select the Pack Button, the system 
 will refresh the Container ID Field and it will appear blank. You can 
 still select this container ID from the field. If your employees process 
 multiple containers at one time, consider selecting this checkbox.</li>
        </ul>
        <ul data-source-node="n62">
            <li class="li_1" data-source-node="n63">If 
 this checkbox is not selected, the system will display the container 
 ID after something has been packed in it. When you select the Pack Button, 
 the system will display the last Container ID that you created. This allows 
 you to continue putting product in the container. If your employees process 
 many loose pick shipments, consider NOT selecting this checkbox.</li>
        </ul>
