Reviewing Image Capture Reference Types

The Image capture reference types generic configuration determines the list reference types found on the Save image screen for a given reference category.

By default the system have the RECEIPTID and LICENSEPLATE reference types for the RECEIVING reference category. The generic configuration supports up to five reference types.

 

Extending references types can be done by adding another reference type. For example, if capturing the trailer id is required, a TRAILERID reference type can be added to the Receiving category reference types. Trailer id will now be available in the list of reference types on the Warehouse Mobile - Save image screen.

 

Note:

  • Image Capture – Link internal reference number exit point - Using this exit point, Reference types can be linked to internal reference numbers.

  • Image Capture – Update Company exit point - Company can be set on the Document Management record when saving an image.
