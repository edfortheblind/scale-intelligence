
        
        <h1 data-source-node="n56"><a name="kanchor274" data-source-node="n57"></a>Identifying Rating IDs</h1>
        <p data-source-node="n58">You will use this window to identify the server 
 used to calculate a carrier's rates. Progistics 
 provides a unique server for each carrier. To communicate with Progistics, 
 the system must know the server symbol for that carrier. In addition, 
 you must also provide the carrier's symbol. This identifies the carrier 
 to Progistics. 
 Both the carrier symbol and the server symbol are provided by Progistics. For LTL Internal Rating, the rating ID identifies the unique carrier and server symbols used for SCALE internal rating. </p>

        <h4 data-source-node="n97">Procedures...</h4>
        <ol data-source-node="n98">
            <li value="1" data-source-node="n99">
                <p data-source-node="n100">Use the Rating ID Field to 
 identify the carrier for which you are defining this Rating ID. <br data-source-node="n101"><br data-source-node="n102"></p>
            </li>
            <li value="2" data-source-node="n103">
                <p data-source-node="n104">Use the Server Symbol Field 
 to identify the server used by the rating system 
 to calculate this carrier's rates. The server may also be linked to the 
 carrier's website. 
 </p>
                <p data-source-node="n105">
                    <br data-source-node="n106">If you are using Progistics, this value is defined by Progistics. <br data-source-node="n107"><br data-source-node="n108">If you are using LTL internal rating, this field must be 'ILS'. This value was defined on the Rating ID Server Symbols Window.</p>
                <p data-source-node="n109"> </p>
            </li>
            <li value="3" data-source-node="n110">Use the Carrier 
 Symbol Field to identify this carrier to the rating system. <br data-source-node="n111"><br data-source-node="n112">If you are using Progistics, Progistics 
 cannot successfully rate this carrier if you don't provide the correct 
 carrier symbol. This value is defined by Progistics.   <br data-source-node="n113"><br data-source-node="n114">If you are using LTL internal rating, this field must be 'ILS.LTL'. This value was defined on the Rating ID Carrier Symbols Window.<br data-source-node="n115"><br data-source-node="n116"></li>
            <li value="4" data-source-node="n117">Use the Rate 
 at Shipment Level Checkbox if this carrier is an LTL 
 or truckoad 
 carrier. If this value is selected, the system will rate the entire shipment 
 instead of rating at the container level.        Do 
 not select this value for parcel carriers.<br data-source-node="n118"> </li>
            <li value="5" data-source-node="n119">Use the EDI 
 Transmit from SCALE Checkbox if this carrier 
 transmits parcel information electronically. This value must be selected 
 for UPS and Fed Ex carriers. For information about other carriers, contact 
 your Manhattan consultant.<br data-source-node="n120"> </li>
            <li value="6" data-source-node="n121">Use the Update 
 Container Charge At Manifest Close Checkbox if, after a manifest 
 is closed, you want the system to update the total freight charge, base 
 freight charge and accessorial charge fields on the shipping container 
 and the shipment record(s).<br data-source-node="n122"> </li>
            <li value="7" data-source-node="n123">Use the Rate 
 International at Shipment Level Checkbox to indicate if you want 
 shipments that are associated with this rating ID to be rated as international 
 shipments. If this checkbox is checked (after closing a container), the 
 system will display a prompt asking if you want to rate this shipment 
 internationally at the shipment level. Manifesting will occur after all 
 the containers are closed for this shipment. <br data-source-node="n124"> </li>
            <li value="8" data-source-node="n125">Use the Manifest 
 Required Checkbox if you want to mandate that this carrier's shipments 
 will always be manifested. Manifesting rates the container, adds any accessorial 
 costs and assigns it a tracking number. You will usually only select this 
 value for parcel carriers.<br data-source-node="n126"> </li>
            <li value="9" data-source-node="n127">Press OK. 
 The system will save the record.</li>
        </ol>
