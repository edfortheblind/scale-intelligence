
        
        <h1 data-source-node="n56"><a name="kanchor1342" data-source-node="n57"></a>Notes on Printing with SQL Server Reporting Services</h1>
        <p data-source-node="n58">The following are some things to take into consideration when using SQL Server Reporting Services for printing:</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Installation Notes...</h4>
        <ul data-source-node="n62">
            <li data-source-node="n63">Please see the installation guides regarding certified print drivers.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66">Please see the installation guides regarding necessary Windows operating system updates.</li>
        </ul>
        <p data-source-node="n67"> </p>
        <h4 data-source-node="n68">Functional Notes...</h4>
        <ul data-source-node="n69">
            <li data-source-node="n70">The following are the statuses for SSRS printing requests:<br data-source-node="n71"><br data-source-node="n72">- Ready = Waiting to be printed.<br data-source-node="n73"><br data-source-node="n74">- In Process = In printing.<br data-source-node="n75"><br data-source-node="n76">- Closed = Printing completed.<br data-source-node="n77"><br data-source-node="n78">- Error = An exception has occurred (such as timeout).<br data-source-node="n79"><br data-source-node="n80">- Note that these statuses indicate when a print request has been sent to the spooler. Once a request is in the print spooler, it is up to the printer to generate the physical printed document.<br data-source-node="n81"><br data-source-node="n82"></li>
            <li data-source-node="n83">Print requests are placed in a "Ready" state, which means they are waiting to be picked up and sent to the PDF reader for printing.<br data-source-node="n84"><br data-source-node="n85"></li>
            <li data-source-node="n86">When a print request is picked up for printing, it is marked with an "In Process" state, and the "process start date time" value is recorded.<br data-source-node="n87"><br data-source-node="n88"></li>
            <li data-source-node="n89">When a print request is consumed by the PDF reader within the specified allowable time, then it is marked with a state of "Closed" and the "process end date time" value is recorded.<br data-source-node="n90"><br data-source-node="n91"></li>
            <li data-source-node="n92">When a print request is not consumed by the PDF reader within the specified allowable time, then it is marked with a state of "Error" and the "process end date time" value is recorded.<br data-source-node="n93"><br data-source-node="n94"></li>
            <li data-source-node="n95">Note that "Closed" does not mean that a record printed successfully, but that it was sent to the PDF Reader successfully.<br data-source-node="n96"><br data-source-node="n97"></li>
            <li data-source-node="n98">The following are the date/time definitions for SSRS printing requests:<br data-source-node="n99"><br data-source-node="n100">- Render time – The time it took to render the document.<br data-source-node="n101"><br data-source-node="n102">- Inserted date time – When the print request was inserted into the database.<br data-source-node="n103"><br data-source-node="n104">- Process start date time – The time when the record was picked up and sent to the PDF reader print application.<br data-source-node="n105"><br data-source-node="n106">- Process end date time – The time when the record was finished being consumed by the PDF reader print application.<br data-source-node="n107"></li>
        </ul>
