User Defined Fields

The majority of configuration windows and data record windows (shipment, receipt line, etc.) include eight configurable, user defined fields:

  • User Defined Fields 1-6 are alpha-numeric, with a maximum length of 25 characters.

  • User Defined Fields 7-8 are numeric, with a maximum length of 19,5 characters.

You can use these fields to identify and track custom data fields that are included in the base system

 

 

On Shipment Records...

In addition to the eight User Defined fields described above, there are an additional twelve fields available on a shipment record:

  • User Defined Fields 9-10 are numeric, with a maximum length of 19,5.

  • User Defined Fields 11-12 are alphanumeric, with a maximum length of 250 characters.

  • User Defined Fields 13-16 are alphanumeric, with a maximum length of 100 characters.

  • User Defined Fields 17-20 are date/time fields.

Note that you can only view these additional fields via the Shipment Insight Screen.

 

 

On the Routing Guide Window...

On a routing guide record, these fields represent the user defined fields on the shipment.
