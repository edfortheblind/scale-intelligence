
        
        <h1 data-source-node="n56"><a name="kanchor114" data-source-node="n57"></a>Creating Lot Templates</h1>
        <p data-source-node="n58">A lot template determines the physical structure of a lot ID. If associated 
 with an item, the system will mandate that its lot IDs conform to this 
 specific character structure. Lot templates can be made up of several 
 character segments (one primary and any number of secondary segments). 
 You also can define if a lot ID will be alpha-numeric or numeric, its 
 length in characters. You can associate a lot template with an item on 
 the Item Window. The first lot segment that you create is the primary 
 Lot ID. This is the value that users will need to initially enter in the 
 Lot Field when performing actions on lot-controlled items. Subsequent    secondary lot segments that you 
 define will be entered by users on the Attribute Tab of the Lot Details 
 Window.</p>

        <h4 data-source-node="n94">Procedures: Defining a Template Header <br data-source-node="n95"></h4>
        <h5 style="font-weight: normal" data-source-node="n96">Access the Lot Template Window. Create a new record.</h5>
        <ol class="ol_1" data-source-node="n97">
            <li value="1" data-source-node="n98">Use the Template 
 Name Field to indicate the general system identifier associated 
 with this template. This is the value you will see when you choose a lot 
 template to assign to an item.</li>
        </ol>
        <p data-source-node="n99"> </p>
        <h4 data-source-node="n100">Procedures: Description Area</h4>
        <ol class="ol_1" data-source-node="n101">
            <li value="1" data-source-node="n102">Use the Description 
 Field to provide a text name for a lot template segment.</li>
        </ol>

        <h4 data-source-node="n104">Procedures: Pattern Fields Tab<br data-source-node="n105"><br data-source-node="n106"></h4>
        <h5 data-source-node="n107">You can use these fields to define how each lot ID segment (primary 
 and secondary) will be structured.</h5>
        <ol class="ol_1" data-source-node="n108">
            <li value="1" data-source-node="n109">Use the Type 
 Field to indicate what type of character the system will expect 
 for this segment of the lot ID:<br data-source-node="n110"><br data-source-node="n111">	- Alpha: Letters only<br data-source-node="n112"><br data-source-node="n113">	- AlphaNumeric: Letters and/or 
 Numbers<br data-source-node="n114"><br data-source-node="n115">	- Numeric: Numbers only<br data-source-node="n116"><br data-source-node="n117">	- Constant: A specific letter, 
 number, and/or symbol (such as a dash or a double-zero). This value will 
 be the same for any lot ID entered using this segment. A constant would 
 typically be used as a separator character. <br data-source-node="n118"> </li>
            <li value="2" data-source-node="n119">Use the Length 
 Field to indicate the mandatory number of characters that the system 
 will expect to be entered for this segment of the lot ID.<br data-source-node="n120"> </li>
            <li value="3" data-source-node="n121">Use the Value 
 Field to indicate the characters you want as a   constant 
 on every lot ID that uses this segment. For example, you could enter a 
 dash "-" to separate two segments of characters. Note that you 
 must select   constant in the Type 
 Field in order to enter a value into this field.<br data-source-node="n122"> </li>
            <li value="4" data-source-node="n123">Press the Advanced 
 Button to display more options you can configure for this segment:<br data-source-node="n124"><br data-source-node="n125">	- Use the Pattern Field to 
 view the code that represents the segments that you defined for this template. 
 The system uses this string to "compute" a lot ID according 
 to the parameters in your template.   See the <a href="c19d7654cf65d7fae64fd03668eb3210078a07050f57ba9148b5a749a1351f12.html" data-source-node="n126">Pattern Field</a> topic for more detailed information.<br data-source-node="n127"><br data-source-node="n128">	- Use the Test Data Field 
 to enter a sample lot ID value that you believe matches the structure 
 of this segment.<br data-source-node="n129"><br data-source-node="n130">	- Press the Test Button to 
 have the system analyze your "test data" and decide if it matches 
 the segment. The system will display a message with the test results.<br data-source-node="n131"><br data-source-node="n132">	- Press the Basic Button to 
 return to the general Pattern Fields Tab. The system will save any information 
 you have entered into the advanced fields.<br data-source-node="n133"> </li>
            <li value="5" data-source-node="n134">Press the Add 
 Button to confirm the data you have entered for the lot ID segment. 
 After this button is pressed, you can enter additional secondary lot segments. 
 <br data-source-node="n135"> </li>
            <li value="6" data-source-node="n136">When completely finished defining the lot ID segments, 
 press OK. The system will save your new template.</li>
        </ol>
