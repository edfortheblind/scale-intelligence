        </h1>
        <h4 data-source-node="n59">Overview</h4>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Item Unit Of Measure configuration defines unit conversion, movement handling, and dimensional values used during inventory and execution operations. You configure the record by selecting item scope, maintaining unit properties, and defining physical dimensions.</p>

        <h4 data-source-node="n69">Configure Item Unit Of Measure</h4>
        <p data-source-node="n70"> </p>
        <h5 data-source-node="n71">1. Type</h5>
        <p data-source-node="n72"> </p>
        <p data-source-node="n73">Select whether the Unit Of Measure record is maintained by individual item or by item class.</p>
        <ul data-source-node="n74">
            <li data-source-node="n75">
                <p data-source-node="n76"><b data-source-node="n77">Item</b>: Configure unit values for a specific item.</p>
            </li>
            <li data-source-node="n78">
                <p data-source-node="n79"><b data-source-node="n80">Item Class</b>: Configure unit values shared by items in the selected class.</p>
            </li>
        </ul>
        <p data-source-node="n81"> </p>
        <h5 data-source-node="n82">2. Unit Of Measures</h5>
        <p data-source-node="n83"> </p>
        <p data-source-node="n84">Review and maintain the Unit Of Measure records for the selected item or class.</p>
        <p data-source-node="n85">From this screen, select a record to continue into Properties and Dimensions details.</p>
        <p data-source-node="n86"> </p>
        <h5 data-source-node="n87">A. Properties</h5>
        <p data-source-node="n88"> </p>
        <p data-source-node="n89"><b data-source-node="n90">Quantity Unit of Measure</b>: Select the unit used for quantity entry and conversion.</p>
        <p data-source-node="n91"><b data-source-node="n92">Conversion Quantity</b>: Enter the conversion quantity value for the selected unit.</p>
        <p data-source-node="n93"><b data-source-node="n94">Movement Class</b>: Select the movement class associated with this unit definition.</p>
        <p data-source-node="n95"><b data-source-node="n96">Treat As Full Percent</b>: Define the percent value used to treat the unit as full.</p>
        <p data-source-node="n97"><b data-source-node="n98">EPC Package ID</b>: Enter the EPC package identifier when required.</p>
        <p data-source-node="n99"><b data-source-node="n100">Treat As Loose in Container Creation</b>: Enable when this unit should be treated as loose during container creation.</p>
        <p data-source-node="n101"> </p>
        <h5 data-source-node="n102">B. Dimensions</h5>
        <p data-source-node="n103"> </p>
        <p data-source-node="n104"><b data-source-node="n105">Length</b>: Enter the unit length.</p>
        <p data-source-node="n106"><b data-source-node="n107">Width</b>: Enter the unit width.</p>
        <p data-source-node="n108"><b data-source-node="n109">Height</b>: Enter the unit height.</p>
        <p data-source-node="n110"><b data-source-node="n111">Weight</b>: Enter the unit weight.</p>
        <p data-source-node="n112"><b data-source-node="n113">Dimension Unit of Measure</b>: Select the UOM for length, width, and height values.</p>
        <p data-source-node="n114"><b data-source-node="n115">Weight Unit of Measure</b>: Select the UOM for weight.</p>
        <p data-source-node="n116"> </p>
        <p data-source-node="n117">Use Back and Continue to move through screens, and Finish to save the Item Unit Of Measure configuration.</p>
