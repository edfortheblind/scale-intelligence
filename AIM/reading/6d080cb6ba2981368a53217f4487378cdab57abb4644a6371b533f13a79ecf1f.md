        <p data-source-node="n58">This document outlines the containers of a shipment that require VAS, and the activities that need to be performed on each container. You can print this document not only from the VAS Container: Insight Screen, but also from the wave.  A possible use of this document could include generating it in the wave, and then having it placed in the container so the VAS worker could use it to know what activities need to be performed on that container.</p>
