Alternate Item Field

Use this field to associate an alternate item with the current item. Typically, you would use an alternate item when you have designated the current item as obsolete or permanently out of stock. When an alternate item designation exists for an item, the system will alert the user that they are about to order an obsolete item, and that an alternate item is available. The user can then decide whether or not to use this alternate item on their order/shipment line.
