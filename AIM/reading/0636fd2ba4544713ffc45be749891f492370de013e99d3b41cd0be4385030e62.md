
        
        <h1 data-source-node="n56"><a name="kanchor419" data-source-node="n57"></a>Interface Process Field</h1>
        <h5 data-source-node="n58">On the Interface Error Insight Screen...</h5>
        <p data-source-node="n59">This field indicates the download interface process (such as Shipping or Receiving) that is associated with an interface error. Note that the upload/receipt entry/order entry interface processes are listed in this field as well, but are not supported in the Interface Error Insight Screen as they do not generate XML error files upon encountering an error.</p>
