
        
        <h1 data-source-node="n56"><a name="kanchor1510" data-source-node="n57"></a>Customer Category 1-10 Fields</h1>
        <p data-source-node="n58">These fields are used to store special user-defined information. You 
 can define up to ten of these categories and associate them to a customer 
 record. Customer categories are used in the order 
 entry module to indicate such custom values as value-added inserts (catalogs, 
 promotional gifts, etc.), special handling instructions, pay terms, or 
 any other user-defined message/label. Note that you can define any 
 value for these categories, as they do not affect system processing of 
 orders. For more information on these fields, see 
 the topic <a href="18c93d2c993faa3fb519edc8954b3418067887d7e54a4b0955e3bdcb8254bafa.html" data-source-node="n59">Creating Customer Categories</a>.</p>
