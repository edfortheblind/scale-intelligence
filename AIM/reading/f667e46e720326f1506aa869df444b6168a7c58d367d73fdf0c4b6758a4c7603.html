Processing Notifications

This topic outlines the basic process flow that the system uses when generating/delivering notifications.

Basic Process Flow...

 

The flow below assumes that the personal alerts scheduled job has run, and records have been written to the NOTIFICATION_MESSAGE database table.

  1. First, the process starts when the ILS Monitor Service detects a new record in the NOTIFICATION_MESSAGE database table.

  2. The ILS Monitor Service calls the appropriate delivery mechanism to process the notification record.

  3. The defined template is applied to the notification message data, along with any formatting specific to the mechanism (such as maximum length restrictions for SMS text, etc.).

  4. The notification message is sent to the appropriate recipient(s). The system marks the notification record in the database as processed (or as an error, if there was a problem sending the notification).

For more detailed information about this process, see the SCALE SDK.
