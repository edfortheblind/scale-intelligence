
        
        <h1 data-source-node="n56"><a name="kanchor590" data-source-node="n57"></a>Condition Field</h1>
        <p data-source-node="n58">This field determines indicates the processing state of a work unit. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">
 There are three condition values:</p>
        <blockquote data-source-node="n61">
            <p class="p_1" data-source-node="n62">- Open: 
 No processing for any work instruction on this work unit has been started. 
 <br data-source-node="n63"> </p>
            <p class="p_1" data-source-node="n64">- In Process: 
 An employee has started processing at least one work instruction associated 
 with this work unit. When a work unit is in process, it has been selected 
 but not confirmed. </p>
            <p class="p_1" data-source-node="n65">
                <br data-source-node="n66">- Closed: All work instructions for 
 this work unit have been confirmed.</p>
        </blockquote>
