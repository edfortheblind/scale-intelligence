Associating Comment Types With Document Types

After you replicated the ERP comment types in the application, you will need to associate them with the appropriate document types. A document type identifies which documents the comment type's message can appear on. When a comment type is included on a shipment, shipment line, or work instruction, its message will appear on all documents linked to the document type.

Procedures...

  1. Use the Comment Type Field to identify the comment type that you want to associate with a specific document type.
     
  2. Use the Document Type Field to identify the document type that this comment type will print on. When any document with this document type is produced, the system will add the text associated with this comment type. Please note that the text is only included if the comment type is also identified on a shipment, shipment line, or work instruction that requires a document with this document type.
     
  3. Press OK. The system will save your record.
