
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Allocation Rule Assignment</h1>
        <p data-source-node="n58">This record defines the sequence in which the system evaluates and assigns locating or allocating rules. Each entry specifies criteria and the corresponding rule to apply based on its priority. During processing, the system reviews these records in order of priority and assigns the first applicable rule. Once a receipt or shipment line is matched with a rule, it won’t be evaluated for any subsequent rules unless overriding is allowed.</p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">General </h4>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62"><b data-source-node="n63">Priority Field</b>: Specify the order in which the system should assign this rule. A lower number indicates higher priority, meaning the system will apply the record earlier.</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65"><b data-source-node="n66">Allocating Rule</b> (Outbound Processing): Specify the allocation rule that the system should use when processing an item. This rule governs how allocation locations are selected for picking.</p>
        <p data-source-node="n67"> </p>
        <p data-source-node="n68">During the allocation rule set assignment process, the system follows these steps:</p>
        <ul data-source-node="n69">
            <li data-source-node="n70">
                <p data-source-node="n71">The system identifies all shipment and receipt lines that don’t yet have an assigned locating or allocating rule.</p>
            </li>
            <li data-source-node="n72">
                <p data-source-node="n73">It processes each active rule assignment record in order of priority.</p>
            </li>
            <li data-source-node="n74">
                <p data-source-node="n75">If the criteria match, the corresponding rule is applied. If a rule has already been applied from a prior sequence, it will only be replaced if "Always Override" is enabled.</p>
            </li>
        </ul>
        <p data-source-node="n76"> </p>
        <h4 data-source-node="n77">Criteria</h4>
        <p data-source-node="n78"> </p>
        <p data-source-node="n79">Define the allocation rule assignment criteria associated with this priority setting. This criteria determines when the system should apply rule set assignment.</p>
        <p data-source-node="n80"> </p>
        <p data-source-node="n81">Select an existing rule assignment criteria record or create a new Allocation Rule Assignment criteria record.</p>
        <p data-source-node="n82"> </p>
        <h5 data-source-node="n83">Create new Allocation Rule Assignment Criteria record.</h5>
        <p data-source-node="n84"> </p>
        <p data-source-node="n85">A rule assignment criteria record tells the system when to use a particular rule. For example, a criteria might specify: “Quantity less than 20 of Item A.” If a shipment or receipt meets this condition, the associated rule will be assigned.</p>
