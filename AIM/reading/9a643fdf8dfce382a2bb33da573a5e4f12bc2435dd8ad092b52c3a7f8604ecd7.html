Company Transfer

The company transfer enables the user to change the item company from one to another. The company transfer can be accessed from the main menu and from the Inventory Insight screen and is available with user permission.

The Adjustment types are associated with adjustment classes and are user configurable. It is this class that determines which flow the system will process the company transfer.

Company Transfer is done for license plate tracked items flow, Item/location Flow and multiple - select flow.

Accessing Company Transfer Screen

The company transfer screen can be accessed in the following two ways

  • Navigate to Menu >> Inventory >> Company Transfer.
  • Select the Adjustment Type from the drop-down list.
  • The other fields are populated based on the Adjustment Type selected.

Or

  • Navigate to Menu >> Inventory >> Inventory Insight screen.
  • Select the required record and click Action >> Company Transfer.
  • The other fields are populated based on the Adjustment Type selected.

Performing Company Transfer

 

The company transfer is performed in the following three flows.

 

License Plate Flow

The company transfer of license plate tracked items is performed in two ways

  • From Main Menu
    • Navigate to Menu >> Inventory >> Company Transfer. . Select the Adjustment Type for the LP flow.
    • Enter the License Plate number.
    • The location, Item Name, From Company, Description information will be populated.

    • Select the To Company,to which the item should be transferred. Optionally you can select the Status from the drop-down list.

    • Enter the required User Defined attributes.
  • From Inventory Insight Screen
    • Navigate to Menu >> Inventory >> Inventory Insight screen. Select the required record and click Actions >> Company Transfer
    • Select the Adjustment Type as License Plate company transfer.
    • The location, Item Name, From Company, Description information will be populated.
    • Select the To Company,to which the item should be transferred. Optionally you can select the Status from the drop-down list.
    • Enter the required User Defined attributes.
  • All inventory in warehouse - Select Yes to transfer a warehouse's entire item quantity to the new company.
  • All lots - Select Yes to include all the lots for transfer to the new company.
  • Entire Location Quantity - Select Yes to transfer the company for a single location's quantity.
  • User Defined fields - Enter the required user defined attributes.
  • Click Transfer button. You can see the changed company name in the inventory insight screen.

Note: Note that company transfers can only be performed on locations where their entire quantity is in an Available or On Hand status. You cannot perform a company transfer on a location where any quantity is in an Allocated, In Transit and/or Suspended status. Also, you cannot perform a company transfer on product at the shipping dock, the receiving dock, or the receiving "pre-check in" location. Company transfer is allowed for items that do not have companies configured in item master. If you enter a company to a location inventory record, then all the records should be associated with a company.

 

Item/location Flow

The company transfer of item/location tracked is performed in two ways

  • From Main Menu
    • Navigate to Menu >> Inventory >> Company Transfer. . Select the Adjustment Type as company transfer.
    • Enter the Item name. If necessary, you can search the item using the Search option to search an item using criteria.

    • Enter the Location field to indicate the location where the item currently present.

    • In the From Company, the current company name of the item is displayed.

    • Select the To Company,to which the item should be transferred. Optionally you can select the Status from the drop-down list.

  • From Inventory Insight Screen
    • Navigate to Menu >> Inventory >> Inventory Insight screen. Select the required record and click Actions >> Company Transfer
    • Select the Adjustment Type as Company transfer.
    • The location, Item Name, From Company, Description information will be populated.
    • Select the To Company,to which the item should be transferred. Optionally you can select the Status from the drop-down list.
  • All inventory in warehouse - Select Yes to transfer a warehouse's entire item quantity to new company.
  • All lots - Select Yes to include all the lots for transfer to new company.
  • Entire Location Quantity - Select Yes to transfer the company for a single location's quantity.
  • User Defined fields - Enter the required user defined attributes.
  • Click Transfer button. You can see the changed company name in the inventory insight screen.

 

Multiple Select Flow

Company Transfer of multiple records can be done simultaneously.

  • Navigate to Menu >> Inventory >> Inventory Insight screen.
  • Select the multiple records from the list and click Actions >> Company Transfer.
  • Enter To Company from the drop-down list. Optionally you can select the Status from the drop-down list.
  • Click Transfer button.

 

Process Notes

  • The item inventory which is in allocated/in transit state, the system will disable the Actions >> Company Transfer option when accessed from the Inventory Insight screen.
  • Company transfers can only be performed on locations where their entire quantity is in an Available or On Hand status.
  • Company transfer on a location will fail where any of the quantity status is in an Allocated, In Transit or Suspense.
  • Inventory status change is optional and can be left blank.
  • In a multiple select flow, the serial number should be same for all the tracked item and company, if not then the system will throw an error.
  • The serial number configuration for the Item/From Company to Item/To company should be same.
  • If the item/From company is lot controlled, then the Item/To Company should also be also lot controlled.
  • The system will display error in case the warehouse does not have the required authorization for adjustment type selected.
  • The system will display error in case the item unit of measure is not same as destination item/company.
