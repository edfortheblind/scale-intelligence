
        
        <h1 data-source-node="n57"><a name="kanchor598" data-source-node="n58"></a>Validate Item Checkbox</h1>
        <p data-source-node="n59">This checkbox determines how you will identify the item that you want 
 to pack on the Packing Screen.</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">If this checkbox 
 is selected, the system will display input fields that you will 
 use to identify the item, item quantity and weight (optional) that you 
 want to pack. You can enter this information by typing it in the fields 
 or by scanning a barcode.</li>
        </ul>
        <ul data-source-node="n62">
            <li class="li_1" data-source-node="n63">If 
 this checkbox is not selected, you will select the item that you 
 want to pack from an item grid. You will select items by highlighting 
 them in the grid. You will identify the quantity 
 that you want to pack by using the +/- buttons. 
 The system will calculate how much the packed quantity weighs.</li>
        </ul>
