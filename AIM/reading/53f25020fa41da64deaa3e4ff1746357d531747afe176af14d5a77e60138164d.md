
        
        <h1 data-source-node="n56"><a name="kanchor573" data-source-node="n57"></a>Assign Multiple Work Units Checkbox</h1>
        <p data-source-node="n58">You can use this setting to allow pickers (using system-directed work) to assign and execute multiple work units during a single picking session. </p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Notes</h5>
        <ul data-source-node="n61">
            <li data-source-node="n62">This setting is only available if you are using system-directed work.<br data-source-node="n63"><br data-source-node="n64"></li>
            <li data-source-node="n65">You can only assign multiple work units if the From Location has a location class that system assigns must be receiving dock and have “Allow work unit selection on system-directed work” setting selected.</li>
        </ul>
