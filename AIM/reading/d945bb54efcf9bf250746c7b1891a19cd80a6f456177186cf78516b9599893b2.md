
        
        <h1 data-source-node="n56"><a name="kanchor353" data-source-node="n57"></a>Automatic Replenishment (in Wave)</h1>
        <p data-source-node="n58">Automatic replenishment is a step in the wave flow. You can add replenishment to 
 a wave flow in the Wave Step Window. When the system runs 
 automatic replenishment, the system retrieves all of the replenishment 
 masters that are selected on the Wave Master you are using. Note that if you do not use a wave master, and are running automatic replenishment in the wave, the system will run all eligible replenishment masters.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Notes...</h4>
        <ul data-source-node="n62">
            <li data-source-node="n63">You can use the Immediate Execution Checkbox (on the Replenishment Master 
 Window) if you want to execute replenishment requests without creating 
 work. When in immediate execution mode, you can define the wave step to 
 also have the system generate a Replenishment Pick List when it runs a 
 replenishment master. This document contains every request for a particular 
 replenishment master. For more information, see the topic <a href="551487cfc78f04ba61e3feb7db99fa8d0c7cfe57a71cf898be78f8bf311fd01c.html" data-source-node="n64">Defining 
 Replenishment Master Records</a>. <br data-source-node="n65"><br data-source-node="n66"></li>
            <li data-source-node="n67">If you want to create work for replenishment requests created in the wave, you need to include the "Work Creation: Replenishment" wave step in your flow.<br data-source-node="n68"></li>
        </ul>
