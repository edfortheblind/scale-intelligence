
        
        <h1 data-source-node="n56"><a name="kanchor39" data-source-node="n57"></a>Closed Checkbox/Field/Toggle</h1>
        <p class="p_1" data-source-node="n58">This checkbox/field/toggle indicates if a wave or cycle count plan has been 
 closed. You cannot add any shipments to a closed wave. </p>
        <p class="p_1" data-source-node="n59"> </p>
        <h5 data-source-node="n60">On the Cycle Count Request Insight Screen...</h5>
        <p class="p_1" data-source-node="n61">On the Filter Pane of Cycle Count Request Insight Screen, this toggle shows the cycle count request status as ON (Closed) and OFF (Not Closed). </p>
        <p class="p_1" data-source-node="n62"> </p>
        <p class="p_1" data-source-node="n63"> </p>
        <h5 data-source-node="n64">On the Cycle Count Plan Insight Screen...</h5>
        <p class="p_1" data-source-node="n65">This field in the List Pane - Grid Field of the Cycle Count Plan Insight Screen reflects the sum of Closed cycle count requests on the cycle count plan. On the List Pane - Summary Tile, it indicates the sum of the total closed for all the returned plans </p>
        <p class="p_1" data-source-node="n66"> </p>
        <p class="p_1" data-source-node="n67"> </p>
        <h5 data-source-node="n68">On the Manifest Insight Screen...</h5>
        <p data-source-node="n69">On the Summary Tile of Manifest Insight Screen, this field shows the total number of closed manifests. </p>
        <p class="p_1" data-source-node="n70"> </p>
        <p class="p_1" data-source-node="n71"> </p>
        <h5 data-source-node="n72">On the Purchase Order Insight Screen...</h5>
        <p class="p_1" data-source-node="n73">On the Summary Tile of Purchase Order Insight Screen, this field shows the total number of closed purchase orders. </p>
        <p class="p_1" data-source-node="n74"> </p>
        <p class="p_1" data-source-node="n75"> </p>
        <h5 data-source-node="n76">On the Purchase Order Line Insight Screen...</h5>
        <p class="p_1" data-source-node="n77">On the List Pane Grid Fields of Purchase Order Line Insight Screen, this field shows the total number of closed purchased orders. </p>
        <p data-source-node="n78"> </p>
        <p data-source-node="n79"> </p>
        <h5 data-source-node="n80">On the Putaway Group Insight Screen...</h5>
        <p data-source-node="n81">On the List Pane Grid Fields of Putaway Group Insight Screen, this field shows the putaway group status as ON (Closed) and OFF (Not Closed). </p>
