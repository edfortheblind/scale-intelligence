        <h5 data-source-node="n58">On 
 Viewer Configuration Window...</h5>
        <p data-source-node="n59">If you selected a DropdownType value for which the system requires additional 
 information to populate the drop down field, you will also need to choose 
 a Data Attribute value. For example, if you select a DropdownType of Generic, the system would need to know 
 what type of generic configuration values that should be populated in 
 the drop down field. Other DropdownTypes that require a data attribute 
 include   System and   Dynamic 
 (among others).</p>
