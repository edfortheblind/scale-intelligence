
        
        <h1 data-source-node="n56"><a name="kanchor192" data-source-node="n57"></a>Cycle Count Preference Field</h1>
        <p data-source-node="n58">This field indicates the cycle count preference that will be associated 
 with this user. You can use this preference record to manage how activity-driven 
 cycle count requests should be executed immediately or created as pending 
 requests. Also, you can define positive and negative tolerance values 
 which determine when a user can make a location adjustment.</p>
