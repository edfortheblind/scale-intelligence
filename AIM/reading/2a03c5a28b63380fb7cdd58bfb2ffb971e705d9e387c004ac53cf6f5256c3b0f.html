Using the Putaway Group Insight Screen

You can use this screen to view the containers that are assigned to a particular putaway location group. This screen allows you to rename, close or re-open a group, and remove a container from a group.

Searching/Viewing Putaway Groups...

You can use the Putaway Group Insight Screen to search for and view putaway location records in your warehouse.

  1. Open the Putaway Group Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

  • The Putaway Group Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Putaway Group Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Putaway Group Insight contains Indicator Tiles with counts of the other entities (i.e. containers). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Containers

    1. Displays the number of receipt containers that are associated with the selected putaway group.

    2. Clicking on this tile takes you to Receipt Container Insight Screen and shows only the containers associated to the selected putaway group.


For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

 

Screen Actions...

The following actions are accessible from the List Pane:

 

 

Close

This action enables you to close any of the open groups. The action is enabled only for the putaway groups that are not closed. Selecting a record from Putaway Group Insight and invoking the action will close the putaway group.

 

 

Rename

This action will allow you to rename any of the open groups. The action is enabled for all the putaway groups that are not closed. Selecting a record from Putaway Group Insight and invoking the action will allow you to rename the group ID.

 

 

Open

This action will allow you to open any of the closed groups. The action is enabled only for the putaway groups that are closed.
