License Plate Putaway Verify Method Field

You can use this field to determine how the system will require you to enter license plate IDs during putaway:

- If Use Existing License Plate (No Override Allowed), the system will show the existing license plate ID in display mode, and not allow you to enter a new value.

 

- If Verify Existing License Plate, the system will require you to enter the existing license plate ID for confirmation. An error will occur if you enter a new value.

 

- If Existing License Plate (Allow Override), the system will show the existing license plate, and you can either use the existing license plate or enter a new value.

 

- If User Specified, the system will not show the existing license plate. Therefore, you will have to enter a new value.
