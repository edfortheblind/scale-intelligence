
        
        <h1 data-source-node="n56"><a name="kanchor1199" data-source-node="n57"></a>Pad Character Field</h1>
        <p data-source-node="n58">You will use this field to indicate the text character you want the 
 system to add to a fixed length interface value as a placeholder. An common 
 example of a pad character would be an asterisk ( * ).</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">For example, suppose a field is configured to be 10 characters in length, 
 and your pad character is an asterisk. The actual value, however, has 
 only four characters (3212). The system, then, would output this value 
 as 3212***** or   ******3212, 
 depending on if you choose to pad from the left or the right.</p>
