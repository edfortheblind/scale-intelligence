
        
        <h1 data-source-node="n56">Manually Assigning Printers (RF)</h1>
        <p data-source-node="n57">This feature, found on the RF selection page, allows the user to manually assign a default label printer on the worker’s user profile.  This default printer will be used when an RF transaction (e.g., start work or close container) triggers label printing.</p>

        <h4 data-source-node="n85"><a name="Assigning_a_label_printer" data-source-node="n86"></a>Assigning a Label Printer…</h4>
        <p data-source-node="n87"> </p>
        <p data-source-node="n88">Open RF:<br data-source-node="n89"></p>
        <ol data-source-node="n90">
            <li value="1" data-source-node="n91">Select Assign printer from the Selection screen. The system will display the Assign Printer screen.<br data-source-node="n92"><br data-source-node="n93"></li>
            <li value="2" data-source-node="n94">Enter the printer name in the Printer field.<br data-source-node="n95"><br data-source-node="n96"></li>
            <li value="3" data-source-node="n97">Click Assign. The system will set the selected printer as the default label printer on the worker’s user profile. A message will be displayed once the printer is successfully assigned.</li>
        </ol>

        <h4 data-source-node="n102"><a name="Clearing_a_label_printer" data-source-node="n103"></a>Clearing a Label Printer…</h4>
        <p data-source-node="n104"> </p>
        <p data-source-node="n105">Open RF:</p>
        <ol data-source-node="n106">
            <li value="1" data-source-node="n107">Select Assign printer from the Selection screen. The system will open the Assign Printer screen.<br data-source-node="n108"><br data-source-node="n109"></li>
            <li value="2" data-source-node="n110">Click Clear. The system will remove the default printer from the worker’s user profile. A message will be displayed once the printer is successfully cleared.</li>
        </ol>
