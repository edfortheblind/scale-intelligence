
        
        <h1 data-source-node="n56"><a name="kanchor1437" data-source-node="n57"></a>Full Container Quantity / Full Container Quantity UM Fields</h1>
        <p data-source-node="n58">This field indicates the item quantity that is necessary for the system 
 to consider it full. The system will allocate this quantity into the unit 
 of measure that you provide. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">For example, suppose the following:</p>
        <ul data-source-node="n61">
            <li data-source-node="n62">A shipment line is interfaced for 20 EA of item AA001.<br data-source-node="n63"><br data-source-node="n64"></li>
            <li data-source-node="n65">You put "5" in the Full Container Quantity Field, and "CS" 
 in the Full Container Quantity UM Field. This means you want the system 
 to bundle 5 EA of the item into a case, and to consider that case full.<br data-source-node="n66"><br data-source-node="n67"></li>
            <li data-source-node="n68">When allocating, the system creates 4 CS, each including 5 EA apiece.</li>
        </ul>
        <p data-source-node="n69"> </p>
        <h5 data-source-node="n70">Keep In Mind...</h5>
        <ul type="disc" class="ul_1" data-source-node="n71">
            <li class="li_2" data-source-node="n72">The intended purpose 
 of this field is for warehouses that do not have item unit of measure 
 records defined for their inventory.<br data-source-node="n73"> </li>
            <li data-source-node="n74">This quantity/UM combination will override any 
 unit of measure settings previously defined for this item.<br data-source-node="n75"> </li>
            <li data-source-node="n76">These fields are only used for non-inventory tracked items.<br data-source-node="n77"><br data-source-node="n78"></li>
            <li data-source-node="n79">If you choose to have the system allocate using 
 this quantity/UM combination, then this is a one-time change for this 
 particular detail. It will not affect how the system processes future 
 shipments of this product.<br data-source-node="n80"> </li>
            <li data-source-node="n81">Note that if you enter a quantity that will not 
 break out into an even number of containers, the system will create bad 
 data when allocating. For example, in the situation described above, if 
 you entered "7" as the Full Container Quantity, the system would 
 try to allocate cases that have 2.8571 EA in them. Since one cannot pick 
 2.8571 of an item, inaccurate data will exist for this detail.</li>
        </ul>
