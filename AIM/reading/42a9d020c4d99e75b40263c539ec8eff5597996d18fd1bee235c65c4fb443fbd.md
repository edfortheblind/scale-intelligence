
        
        <h1 data-source-node="n56"><a name="kanchor41" data-source-node="n57"></a>Allocate In Transit Checkbox</h1>
        <p data-source-node="n58">Use this setting  to indicate whether or not the system should include "in 
 transit" quantity when computing "available" quantity: </p>
        <ul data-source-node="n59">
            <li data-source-node="n60"><i data-source-node="n61">If you do not select this value</i>, the system will use the normal computation 
 (<span class="span_1" data-source-node="n62">on hand - allocated - suspense</span>). <br data-source-node="n63"></li>
            <p data-source-node="n64"> </p>
            <li data-source-node="n65"><i data-source-node="n66">If you select this value</i>, the system will include the "in transit" 
 quantity in the allocation computation (<span class="span_1" data-source-node="n67">on 
 hand + in transit - allocated - suspense</span>). In this case, then, 
 an allocation can potentially occur for an amount that is greater than 
 the "on hand" quantity.</li>
        </ul>
        <p data-source-node="n68"><span class="span_1" data-source-node="n69">NOTE</span>: This value would be selected                
 if you are performing replenishments within the flow of a normal work 
 day and/or running demand based replenishment. The system, then, could 
 allocate inventory during the wave,                  <span class="span_1" data-source-node="n70">prior</span> 
 to the inventory movement actually taking place. This allows your shipments 
 to allocate normally without having to execute all of the replenishments 
 (prior to running the wave).</p>
