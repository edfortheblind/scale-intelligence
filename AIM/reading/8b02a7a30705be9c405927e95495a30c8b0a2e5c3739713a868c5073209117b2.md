
        
        <h1 data-source-node="n56"><a name="kanchor1505" data-source-node="n57"></a>Adding a Hazardous Code to an Item</h1>
        <p data-source-node="n58">The system allows you the opportunity to identify containers as being 
 "hazardous" so they can be processed according to any special 
 processing your warehouse may have. This is done by assigning a hazardous 
 code to a specific National Motor Freight Classifications (NMFC) code. 
 You can assign this code to an item in the Item Window. You can define this record on the National Motor Freight Classifications 
 Window.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures...</h4>
        <ol class="ol_2" data-source-node="n62">
            <li value="1" data-source-node="n63">Access the National 
 Motor Freight Classifications Window from the Configurations Explorer.<br data-source-node="n64"> </li>
            <li value="2" data-source-node="n65">Open an NMFC 
 record. <br data-source-node="n66"> </li>
            <li value="3" data-source-node="n67">Use the Hazardous 
 Code Field to identify an item that uses this particular NMFC Code 
 as being a hazardous material. The system will also display this code 
 on a shipment's bill of lading document (in the "H.M." field).<br data-source-node="n68"> </li>
            <li value="4" data-source-node="n69">For information 
 on other fields on this window, see the topic "Identifying 
 NMFC Codes."<br data-source-node="n70"> </li>
            <li value="5" data-source-node="n71">Press OK when 
 finished. The system will save your record.</li>
        </ol>
