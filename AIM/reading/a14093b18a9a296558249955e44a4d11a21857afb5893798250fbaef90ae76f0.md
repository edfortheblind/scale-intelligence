
        
        <h1 data-source-node="n56">Delivery Field</h1>
        <p data-source-node="n57">This field indicates the type of delivery prompt. Prompt Delivery Location means the TalkMan prompts the operator with the delivery location and waits for the user to say <i data-source-node="n58">Ready</i>. The <i data-source-node="n59">Prompt and Confirm</i> option means the TalkMan prompts the user with the delivery location and waits for the user to confirm it by saying the delivery location and <i data-source-node="n60"><a name="kanchor1311" data-source-node="n61"></a>Ready</i>. None means the TalkMan does not prompt the user with delivery information.</p>
