
        
        <h1 data-source-node="n56"><a name="kanchor1507" data-source-node="n57"></a>Routing Code Field</h1>
        <p data-source-node="n58">A shipment value used for routing. A shipment 
 routing value generally identifies a shipment characteristic or a shipping 
 requirement for particular products. Common examples include fragile, 
 hazardous or refrigeration.</p>
