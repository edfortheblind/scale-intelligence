Using the Metadata Data Filter Operands Window

The Metadata Data Filter Operands Window defines the various operands available for a user to select during an advance criteria search. The typical operands are equals, less than, greater than, etc.

 

Please see the SDK for detailed information on how to configure metadata screens.
