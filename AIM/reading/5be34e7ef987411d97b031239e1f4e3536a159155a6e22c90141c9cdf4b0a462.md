
        
        <h1 data-source-node="n56"><a name="kanchor2061" data-source-node="n57"></a>Using the Lot Update Confirmation Screen </h1>
        <p data-source-node="n58">The system will display this screen any time you want to change or update 
 a lot. For example, if you are positively adjusting inventory into a location, 
 and you need to change the expiration date of a lot, the system will display 
 this screen allowing you to confirm your change. You can also view what 
 locations or containers that will be affected by this change. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The Lot Update Confirmation Screen will appear (during receipt check-in, 
 inventory adjustments, and using the Lot Insight) when you perform an 
 action to an item quantity that is associated with a lot that already 
 exists in warehouse inventory. If you perform an action to an item quantity 
 where you are introducing a new lot to the warehouse, the system will 
 display the <a href="9aa89562d66d5fb765bf6f7c584ef96d0d7ba337108d46af681f48fd26a61fff.html" data-source-node="n61">Lot Screen</a>.</p>

        <h4 data-source-node="n117">Procedures.... </h4>
        <ol data-source-node="n118">
            <li value="1" data-source-node="n119">Review the lot information on the Lot Info tab. <br data-source-node="n120"><br data-source-node="n121"></li>
            <li value="2" data-source-node="n122">Review the inventory in your warehouse that will be affected by this lot change on the Affected Inventory tab.<br data-source-node="n123"><br data-source-node="n124"></li>
            <li value="3" data-source-node="n125">Review/change any user defined data values on the User Defined tab. <br data-source-node="n126"><br data-source-node="n127"></li>
            <li value="4" data-source-node="n128">Press the Save button to apply these lot changes to the inventory. Press the Cancel Button to 
 not proceed with the changes.</li>
