Using the Yard Check In and Out Screen

When a truck arrives at your warehouse, typically a guard (or other worker) would "check in" the trailer into your warehouse's yard area. They would perform this action using the Yard Check In and Out Screen. When you check in a trailer, you will assign its trailer to a specific yard location(s), and can also indicate at which Receiving Dock is its final destination. You can also use this window to view where a previously-checked in trailer is currently placed in the yard, and edit that location if necessary. When a trailer is ready to leave your warehouse (all its shipments have been received) and it currently resides at the Receiving Dock or a yard location, the guard would "check out" the trailer. This process indicates that the trailer has officially left the warehouse property. Note that the system will default information into this window's fields if the trailer has been checked into in the yard already, or if an appointment with the most recent scheduled date exists for this trailer. Also note that it is valid to schedule multiple appointments for the same trailer. Therefore, when a certain trailer is checked out of the yard, the same trailer may return at a future date.

Note About Trailer IDs...

  • If a receipt is assigned to a trailer ID that has already been checked in through yard management, that trailer ID cannot be changed until the trailer ID has been checked out of yard management.

 

 

Procedures: Trailer Check In...

  1. Access the Yard Check In and Out Screen from the system menu. You will need to use the Trailer ID Field to indicate the identifier for the truck trailer that you are allowing to enter the yard. This can be entered at the time of check in, or defaulted from an appointment (if one was scheduled for this receipt). 

    Access the Receipt Insight, select a receipt, and select the Yard Check In and Out action. The system will open the Yard Check In and Out Screen (with the Trailer ID Field already populated with a value). If no Trailer ID is assigned to this receipt, use the Assign Trailer ID option to do so.

  2. Use the Appointment Date/Time Field to view what day and time a trailer was scheduled to arrive at the warehouse. This value is defaulted from the appointment that was scheduled for this receipt. Note that this field will have no value if no appointment was scheduled.

  3. Use the Initial Yard Location Field to indicate the actual place where the trailer will be dropped off now, be it a yard location or the Receiving Dock. This field is required.

  4. Use the Destination Yard Location Field to indicate the yard location where this trailer will be moved to at a later time. For example, if the yard location identified in the Initial Yard Location Field is a general drop off area, the yard location in this field would be the actual yard location where this trailer will eventually be placed. This is an optional field.

  5. Use the Destination Receiving Dock Field to indicate the final post-yard location where this trailer is to be placed (typically the receiving dock). This is an optional field.

  6. Press the Check In Button to check this trailer into the yard. The system will assign to it the appropriate yard location, and change the status of this trailer to checked in.

 

 

 

Procedures: Viewing Trailer Information...

  1. Access the Yard Check In and Out Screen from the system menu. Enter the ID of the trailer you want to research. 

    Access the Receipt Insight, select a receipt, and select the Yard Check In and Out action. The system will open the Yard Check In and Out Screen (with the Trailer ID Field already populated with a value).

  2. The system will display the yard location information for this trailer. If appropriate, you can change any of the values.

  3. Press OK, and the system will either save your new changes, or exit the screen.

 

 

 

Procedures: Trailer Check Out...

  1. Access the Yard Check In and Out Screen from the system menu. Enter the ID of the trailer that you want to check out.

    Access the Receipt Insight, select a receipt, and select the Yard Check In and Out action. The system will display the Yard Check In and Out Screen (with the Trailer ID Field already populated).

  2. Press the Check Out Button, and the system will change the status of this trailer to checked out.
