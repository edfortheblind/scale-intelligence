
        
        <h1 data-source-node="n56"><a name="kanchor271" data-source-node="n57"></a>Trailer ID Field</h1>
        <p class="p_1" data-source-node="n58">This value identifies a specific trailer for 
 a carrier. After the carrier picks up the load, you can define the trailer 
 ID.</p>
        <p class="p_1" data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60"> </p>
        <h5 data-source-node="n61"> In Appointment Scheduling...</h5>
        <p class="p_1" data-source-node="n62">You can assign a trailer ID to the receipt at the time you make the appointment.</p>
        <p class="p_1" data-source-node="n63"> </p>
        <p class="p_1" data-source-node="n64"> </p>
        <h5 data-source-node="n65">On Receipts...</h5>
        <p class="p_1" data-source-node="n66">You can use the trailer ID to group together receipts that are coming in on the same trailer.  You can then use that trailer ID in RF receipt check in to drive the check in of receipts on that trailer. </p>
        <p class="p_1" data-source-node="n67"> </p>
        <p class="p_1" data-source-node="n68">NOTE: If a receipt is assigned to a trailer ID that has already been checked in through yard management, that trailer ID cannot be changed until the trailer ID has been checked out of yard management.</p>
        <p class="p_1" data-source-node="n69"> </p>
        <p class="p_1" data-source-node="n70"> </p>
        <h5 data-source-node="n71"> In Yard Management...</h5>
        <p class="p_1" data-source-node="n72">All yard check in processing is driven by trailer ID. </p>
        <p class="p_1" data-source-node="n73"> </p>
