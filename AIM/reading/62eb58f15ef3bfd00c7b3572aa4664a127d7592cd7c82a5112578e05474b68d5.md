
        
        <h1 data-source-node="n57">Single Unit Packing</h1>
        <p data-source-node="n58">This screen brings efficiency in Packing a single unit orders . Users can pick single unit orders into a tote and initiate the packing process by scanning a tote id and item details that are picked into the tote and be able to "confirm" to pack which will update the packed quantity and closes the container. The screen also provides key information like tote quantity (packed vs total), and shipment and container information. Note that this process expects the containers to be created in a wave.</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Summary</h5>
        <ul data-source-node="n61">
            <li data-source-node="n62">Only single unit item containers can be packed in this screen.</li>
            <li data-source-node="n63">Totes which is marked for sorting can also be packed.</li>
            <li data-source-node="n64">The Container type can be modified during packing. Company and warehouse authorization is supported.</li>
            <li data-source-node="n65">Serial and Lot controlled items are supported.</li>
            <li data-source-node="n66">
                <p data-source-node="n67">Scanned item related information summary is displayed in the accordions.</p>
            </li>
            <li data-source-node="n68">
                <p data-source-node="n69">Optionally auto print documents on closing the containers in the tote.</p>
            </li>
        </ul>

        <h4 data-source-node="n151"><a name="Perform" data-source-node="n152"></a>Procedure</h4>
        <p data-source-node="n153"> </p>
        <ul data-source-node="n154">
            <li class="li_1" data-source-node="n155">Navigate to the <b data-source-node="n156">System &gt;&gt; Shipping &gt;&gt; Single Unit Packing</b><br data-source-node="n157"></li>
            <li class="li_1" data-source-node="n158">Scan the <b data-source-node="n159">tote ID</b> and click the arrow button. The system will validate whether the tote has single unit packing or not. For a valid tote, user is assigned, tote condition is moved to <b data-source-node="n160">In Packing</b> and the item entry screen is displayed.<br data-source-node="n161"></li>
            <li class="li_1" data-source-node="n162">Scan/enter an Item or item cross reference value and tab out. If a valid item is scanned, then the <b data-source-node="n163">Tote Quantity</b> number will increase by one. For example, before the scan, it will be 0 of 2 and after scan, it will be 1 of 2 under the tote quantity. The tote condition  will change from (<b data-source-node="n164">Not eligible</b> or <b data-source-node="n165">Sort Pending</b>)  to <b data-source-node="n166">In Packing</b> depending on the tote records scanned.<ul data-source-node="n167"><li class="li_1" data-source-node="n168"><b data-source-node="n169">Note</b>: If you press ENTER key after scan/enter of item ID, then the system will pack and close the container without showing the item information details.</li></ul></li>
            <li class="li_1" data-source-node="n170">The system prompts the user to select the <b data-source-node="n171">Container Type</b> from the drop-down list. The container types available for packing can be authorized by company and warehouse. See the <a href="b8520236e77bf1d9729a56d56a398123183351403f9a3eff7e86595795483b9e.html" data-source-node="n172">Defining Container Types</a> for more details.</li>
            <li class="li_1" data-source-node="n173">The system will then display the appropriate
 information in the Item info, Shipment Info, Container Info, and Ship to accordion. Note: All fields in accordion are read only and cannot be modified.</li>
            <li class="li_1" data-source-node="n174">Click <b data-source-node="n175">Confirm</b> to close and pack the container. The system process the following on clicking the Confirm button.<ul data-source-node="n176"><li class="li_1" data-source-node="n177">Close the container and update the <b data-source-node="n178">quantity to pack</b> to zero in the tote detail table.</li><li class="li_1" data-source-node="n179">The system may print documents for this container based on the Auto Print at Close Field on your 
 packing preference record. For more information on printing, see the <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n180">Printing Paperwork</a> topic</li><li class="li_1" data-source-node="n181">When the last item in the tote is packed, the tote condition will be moved from <b data-source-node="n182">In Packing</b> to <b data-source-node="n183">Packed</b>.</li></ul></li>
        </ul>
        <h5 data-source-node="n184">Item with company</h5>
        <p data-source-node="n185">When an item has one or more companies.</p>
        <ul data-source-node="n186">
            <li class="li_1" data-source-node="n187">If the item has only one company, then when you scan the item, the system displays the company field and container type. </li>
            <li class="li_1" data-source-node="n188">If there are multiple companies for the same item, then the user is prompted to select the company from the drop-down list, and then the corresponding container type is displayed. The container type can be modified as required in all scenarios.</li>
        </ul>
        <h5 data-source-node="n189">Lot Controlled Item</h5>
        <p data-source-node="n190">For lot controlled items</p>
        <p class="li_1" data-source-node="n191">
            <ul data-source-node="n192">
                <li class="li_1" data-source-node="n193">If there is only one Lot, then the system will populate the Lot ID</li>
                <li class="li_1" data-source-node="n194">If there are multiple Lot IDs, then the system will prompt you to select the Lot ID.</li>
                <li data-source-node="n195">
                    <p data-source-node="n196">If the company is defined for an item, the system first displays the company field for selection and then you can scan/enter the Lot ID.</p>
                </li>
            </ul>
        </p>
        <h5 data-source-node="n197">Serial Number tracked item</h5>
        <p data-source-node="n198">For serial number tracked item</p>
        <li class="li_1" data-source-node="n199">
            <ul data-source-node="n200">
                <li class="li_1" data-source-node="n201">If there are multiple serial numbers tracked items with a different company, the system prompts you to select a company. On selecting the company, the corresponding serial number and container type is displayed.</li>
                <li class="li_1" data-source-node="n202">If there is same item and company but different serial numbers, the system prompts you to select the serial number. After serial number selection, the container type is displayed.</li>
                <li class="li_1" data-source-node="n203">If the serial number template is configured, then the Major serial number will be displayed.</li>
            </ul>
        </li>
        <h4 data-source-node="n204"> </h4>
        <h4 data-source-node="n205"><a name="Notes" data-source-node="n206"></a>Notes</h4>
        <ul data-source-node="n207">
            <li data-source-node="n208">Singles Packing eligible containers can also be sorted using WM - putwall sort </li>
            <li data-source-node="n209">Item and Item Cross reference is supported.</li>
            <li data-source-node="n210">Totes which was marked for sorting once initiated in Single Unit packing, cannot be sorted again. </li>
            <li data-source-node="n211">
                <p data-source-node="n212">You can unassign a user for a tote and then continue the singles packing after assigning to your name. unassign will be allowed only till <b data-source-node="n213">In Packing</b> the tote condition.</p>
                <p data-source-node="n214">If there are multiple items configured with same cross reference value, then system will prompt for a lookup window for selection.</p>
            </li>
        </ul>
