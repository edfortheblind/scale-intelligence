
        
        <h1 data-source-node="n56"><a name="kanchor571" data-source-node="n57"></a>Document Path Field</h1>
        <p data-source-node="n58">This field indicates the directory where a print engine's temporary 
 files (used to generate documents) will reside. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: Be sure that this directory 
 is local to the machine on which your print server resides. </p>
