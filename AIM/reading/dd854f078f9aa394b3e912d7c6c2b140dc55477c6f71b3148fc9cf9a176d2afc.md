
        
        <h1 data-source-node="n57"><a name="kanchor1457" data-source-node="n58"></a>Value Type Field</h1>
        <p class="p_1" data-source-node="n59">A value type identifies how an accessorial 
 choice will appear on the Accessorial Assignment Window. </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">The following are the value types that you can assign on the Accessorial Header Window:</p>

                        </p>

                        <p data-source-node="n71"> </p>
                    </td>
                    <td data-source-node="n72">
                        <p data-source-node="n73">Indicates  that the accessorial detail represents an address value. Using the Parent Field, you can associate other accessorial details (such as address lines, city, postal code, etc.) to a single "parent" address detail. See the <a href="a278ade03378ede7ef8d251c5e3607605cd66db02ef518799419a7e7e5553f7b.html" data-source-node="n74">Parent Field</a> topic for more information.</p>

 the user can select or deselect. This is commonly used for accessorial 
 services which are optional, such as Saturday Delivery. </p>

 type identifies the monetary amount levied to cover the accessorial task. </p>
