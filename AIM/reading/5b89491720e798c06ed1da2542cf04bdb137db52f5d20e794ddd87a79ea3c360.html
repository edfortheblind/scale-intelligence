Releasing Work Units

You can manually release individual work units, instead of releasing the entire wave. This is especially helpful when you can only process a set number of units due to warehouse constraints, such as time, equipment or personnel. If you held a work unit, you will also need to release it manually. Also, if a work unit was previously placed into a "held" status, then you will need to manually release it.

 

 

Prerequisites...

The procedures below assume the following:

  • The wave that generated the work has not been released to the warehouse.

    OR
  • The work unit was previously placed in a held status.

 

Procedures...

  1. Open the Work Insight Screen.

     

  2. Access the held work unit.

     

  3. Select the Hold Action. The system will display the Hold Code Screen. Remove the value in the Hold Code Field. As long as this field is blank, the system will release the work.

    4.  

  4. The system will release this work unit, and it can now be processed by an employee.
