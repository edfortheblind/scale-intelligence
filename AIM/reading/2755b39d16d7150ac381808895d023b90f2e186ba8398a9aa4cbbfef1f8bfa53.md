        <h4 data-source-node="n111"><a name="Searching" data-source-node="n112"></a>Searching/Viewing Work Records...</h4>
        <p data-source-node="n113">You can use the Putwall Insight Screen to search for and view work records in your warehouse. </p>
        <ol data-source-node="n114">
            <li value="1" data-source-node="n115">Open the Putwall Insight Screen.<br data-source-node="n116"><br data-source-node="n117"></li>
            <li value="2" data-source-node="n118">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n119"><br data-source-node="n120"></li>
            <li value="3" data-source-node="n121">Press the Apply Filter Button. The system will display the resulting records in the List Pane. <br data-source-node="n122"><br data-source-node="n123"></li>
            <li value="4" data-source-node="n124">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>

        <h4 data-source-node="n150"><a name="ScreenActions" data-source-node="n151"></a>Screen Actions...</h4>
        <p data-source-node="n152">The following actions are accessible from the List Pane:</p>
        <p data-source-node="n153"> </p>
        <h5 data-source-node="n154">Pack </h5>
        <p data-source-node="n155">This action enables you to pack the putwall items that have been sorted by shipment. The Pack option is disabled when shipment is sorted and sort completed is not completed.</p>
        <p data-source-node="n156"> </p>
        <p data-source-node="n157">procedure</p>
        <ul data-source-node="n158">
            <li data-source-node="n159">In the Putwall insight screen</li>
            <li data-source-node="n160">Select a record and <b data-source-node="n161">Actions</b> &gt;&gt; <b data-source-node="n162">Pack</b></li>
            <li data-source-node="n163">System will navigate to <b data-source-node="n164">Packing</b> screen.<ul data-source-node="n165"><li data-source-node="n166">If the packing initiation is set to Putwall location, the packing screen will automatically populate the Putwall location of the selected record.</li><li data-source-node="n167">If the packing initiation is not set to putwall location , the packing screen will be displayed with no putwall location. Enter the putwall location.</li></ul></li>
            <li data-source-node="n168">Complete the packing of the shipment and close the container.</li>
            <li data-source-node="n169">Putwall location will be cleared.</li>
        </ul>
        <h5 data-source-node="n170">Clear</h5>
        <p data-source-node="n171">This actions enables user to force sort and clear a putwall location. Clear actions is security permission controlled.</p>
        <p data-source-node="n172">Clear actions can be performed on both shipment and container work.</p>
        <p data-source-node="n173"> </p>
        <p data-source-node="n174">Procedure</p>
        <ul data-source-node="n175">
            <li data-source-node="n176">In the Putwall insight screen.</li>
            <li data-source-node="n177">Select a record in <b data-source-node="n178">Storage</b> status and <b data-source-node="n179">Actions &gt;&gt;Clear</b>.</li>
            <li data-source-node="n180">System will prompt user with <i data-source-node="n181">System will mark the quantity as sorted and Putwall location will be cleared. Do you want to proceed?</i></li>
            <li data-source-node="n182">Click <b data-source-node="n183">Yes</b> and a successful message indicating the selected tote quantity has been marked as sorted and the putwall location is cleared.</li>
        </ul>
