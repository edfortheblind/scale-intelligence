
        
        <h1 data-source-node="n56"><a name="kanchor166" data-source-node="n57"></a>Released Toggle</h1>
        <p data-source-node="n58">This toggle indicates whether or not a wave/cycle count plan/work order was released. </p>
        <ul data-source-node="n59">
            <li data-source-node="n60">When a cycle count plan is created, you cannot perform any actions to it until it is released. If work was created for the plan, when the plan is released, the work is also released and the work can then be executed.
<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">In the Work Order Insight Screen's List Pane Grid Fields, the flag remains checked when the Release Date Time field is not null for the Work order.</li>
        </ul>
