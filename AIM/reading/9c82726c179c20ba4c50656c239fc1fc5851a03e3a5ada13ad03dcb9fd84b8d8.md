
        
        <h1 data-source-node="n56"><a name="kanchor252" data-source-node="n57"></a>Defining a Shipper Cross Reference</h1>
        <p data-source-node="n58">This record associates a shipper code with a specific warehouse/company 
 combination. It determines which carriers the system can rate for this 
 shipper. When you create a shipper cross-reference record in the system, 
 it is automatically created in Progistics. 
 In Progistics, 
 the shipper cross-reference record identifies the shipper, it address 
 and its eligible carriers. Before it will rate a carrier, Progistics 
 references this record. If the carrier is not registered for this shipper, 
 it will not be included in the rating process. If you change or delete 
 a shipper record in the system, Progistics 
 will also update or delete that shipper record. Note that you can create multiple cross reference records per warehouse/company combination, as long as the records have different shipper codes defined.</p>

        <h4 data-source-node="n89">Procedures...<br data-source-node="n90"></h4>
        <h5 data-source-node="n91">Using the Shipper Tab</h5>
        <ol data-source-node="n92">
            <li value="1" data-source-node="n93">
                <p data-source-node="n94">Access the Shipper Cross Reference 
 Window.</p>
                <p data-source-node="n95"> </p>
            </li>
            <li value="2" data-source-node="n96">
                <p data-source-node="n97">Use the Shipper Code Field to 
 link this company/warehouse to the code you defined on the Shipper Code 
 Window.</p>
                <p data-source-node="n98"> </p>
            </li>
            <li value="3" data-source-node="n99">
                <p data-source-node="n100">Use the Warehouse Field 
 to identify the warehouse that will use this shipper. If you do not support 
 multi-company processing, the warehouse is the entity that will ship product. 
 In this case, Progistics 
 would then create only one manifest, for the entire warehouse. Conversely, 
 if you select a company (Step 3), the system will generate the manifest 
 per company, regardless of the value defined in this field.</p>
                <p data-source-node="n101"> </p>
            </li>
            <li value="4" data-source-node="n102">
                <p data-source-node="n103">Use the Company Field to 
 identify the company who will ship product. This value is only required 
 if your warehouse supports multi-company processing AND you created a 
 shipper code for this company. The system will create a manifest for this 
 specific company.<br data-source-node="n104"><br data-source-node="n105"></p>
            </li>
            <li value="5" data-source-node="n106">
                <p data-source-node="n107">Use the Default Shipper Checkbox to indicate a particular cross reference record is to be used as the "default" shipper code. When a "default" cross reference record's warehouse/company combination is indicated on the Shipment Screen or Rate Shopping Window, then the system will rate as per the configured default shipper code.<br data-source-node="n108"><br data-source-node="n109">The following are a few things to consider when using this setting:<br data-source-node="n110">- There can only be one default shipper cross reference record for a certain warehouse/company or warehouse/(blank company) combination.
<br data-source-node="n111"><br data-source-node="n112">- The first cross reference record you create for a warehouse/company combination is automatically set as the default shipper. You cannot change this setting on this initial record until subsequent records are created for this warehouse/company combination. <br data-source-node="n113"><br data-source-node="n114">- If you choose to designate a cross reference record as the default shipper record (and there is an existing default record), then the system will make the current record the default, and unselect this setting from the previous default record.<br data-source-node="n115"><br data-source-node="n116">- If multiple records  for a warehouse/company combination exist, the system will not allow you to delete a default shipper record.
</p>
            </li>
        </ol>
        <p data-source-node="n117"> </p>
        <h5 data-source-node="n118">Using the Change Shipper Status Tab</h5>
        <ol data-source-node="n119">
            <li value="1" data-source-node="n120">Use 
 the Change Shipper Status Checkboxes to identify all carriers that 
 you want to associate with this shipper. The system will only rate the 
 carriers that you select here. You can deselect 
 a carrier by unselecting 
 it.</li>
        </ol>
