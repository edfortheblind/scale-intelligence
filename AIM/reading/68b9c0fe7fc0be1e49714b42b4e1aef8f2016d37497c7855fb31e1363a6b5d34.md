
        
        <h1 data-source-node="n56"><a name="kanchor134" data-source-node="n57"></a>Auto Release Checkbox</h1>
        <p data-source-node="n58">This checkbox appears on the Wave Master screen. If its selected, the 
 work generated during the run wave process is automatically released to 
 the floor. If its not selected, you must manually release the wave from 
 the Wave Insight before the work is available for processing. 
 </p>
        <p data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60">NOTE: If a wave is set to automatically release, 
 you cannot cancel it.</p>
