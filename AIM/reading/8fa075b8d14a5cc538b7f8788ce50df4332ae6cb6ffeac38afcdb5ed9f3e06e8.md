
        
        <h1 data-source-node="n56"><a name="kanchor721" data-source-node="n57"></a>Export Help Resources Checkbox</h1>
        <p data-source-node="n58">This field indicates that you want to export the system "help" 
 resource values using the Translation Wizard. Help resources determine which help files are displayed 
 when a user chooses the window-specific help menu option from an application 
 window. By default, the system does not export these resources, because 
 typically they do not need to be translated. However, if for some reason 
 you do need to edit these values, you can do so by selecting this checkbox.</p>
