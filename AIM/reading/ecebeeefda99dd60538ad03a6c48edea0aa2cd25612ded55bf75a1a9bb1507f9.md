
        
        <h1 data-source-node="n56"><a name="kanchor672" data-source-node="n57"></a>Output Format Field</h1>
        <p class="p_1" data-source-node="n58">This field indicates the output format that you want the system to use 
 when displaying your web statistics inquiry results:</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">Choose HTML 
 if you want the system to display your inquiry results as an HTML web 
 page.<br data-source-node="n61"> </li>
            <li data-source-node="n62">Choose Text 
 if you want the system to display your inquiry results as a text document.<br data-source-node="n63"> </li>
            <li data-source-node="n64">Choose XML 
 if you want the system to display your inquiry results formatted as XML 
 code.</li>
        </ul>
