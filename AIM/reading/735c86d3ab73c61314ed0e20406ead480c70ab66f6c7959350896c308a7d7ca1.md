
        
        <h1 data-source-node="n56"><a name="kanchor493" data-source-node="n57"></a>Location Class Field</h1>
        <p data-source-node="n58">This field identifies a location's class, which is a predefined 
 value that identifies the purpose of a warehouse's location. In other words, these represent the general "categories" of locations. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Below is a list of the system defined location classes:</p>
        <ul type="disc" class="ul_1" data-source-node="n61">
            <li data-source-node="n62">
                <p data-source-node="n63"><i data-source-node="n64">Equipment</i> - You will not 
manually assign this location class value. The system assigns it to equipment during the picking process. 
 It creates an equipment location ID by concatenating the equipment type 
 and the user name. This location class and ID are only assigned while the 
 equipment is transporting inventory.</p>
                <p data-source-node="n65"> </p>
            </li>
            <li data-source-node="n66">
                <p data-source-node="n67"><i data-source-node="n68">Inventory</i> - You will assign 
 this location class to all locations used to store product in your warehouse.</p>
                <p data-source-node="n69"> </p>
            </li>
            <li data-source-node="n70"><i data-source-node="n71">P&amp;D</i> - 
 You will assign this location class to all P&amp;D (pickup and dropoff) locations. 
 These locations can be used as intermediate locations while moving product 
 between locations.<br data-source-node="n72"><br data-source-node="n73"></li>
            <li data-source-node="n74"><i data-source-node="n75">Put-To-Store</i> - You will assign this location class to locations at or near the shipping dock where loose item quantities are placed, when their final destination is a specific store (shipment line <i data-source-node="n76">mark for</i>). Each put-to-store location is assigned to a specific store via the configurations. <br data-source-node="n77"> </li>
            <li data-source-node="n78"><i data-source-node="n79">Receiving Dock</i> 
 - You will assign this location class to the receiving dock location.<br data-source-node="n80"><br data-source-node="n81"></li>
            <li data-source-node="n82"><i data-source-node="n83">Receiving Pre-Check 
 In</i> - You will assign this location class to temporarily hold all downloaded receipt 
 containers that are interfaced into the system. This 
 is a place (not a physical location but rather a system "bucket") 
 where interfaced inventory can reside in before it arrives into the receiving 
 dock. When the actual container arrives at the warehouse, the system will 
 place this container in an inventory status of "Check In Pending." 
 When the container is checked in, the system will place it in a "Locate 
 Pending" status. <br data-source-node="n84"><br data-source-node="n85"></li>
            <li data-source-node="n86"><i data-source-node="n87">Receiving Pre-Locate</i> - You will assign this location class to hold product that has been checked into the warehouse, but has not yet been located (using the <a href="cad5aec8b277e9340b3e41d8b76bf81d169a4845f7ec3854c36208e939a04c85.html" data-source-node="n88">delayed locating</a> functionality).<br data-source-node="n89"> </li>
            <li data-source-node="n90"><i data-source-node="n91">Shipping Dock</i>- You will assign this location class to create dock locations (packing, staging, and dock door). 
 This is used for outbound dock locations only.<br data-source-node="n92"> </li>
            <li data-source-node="n93"><i data-source-node="n94">Work Order Build 
 -</i> You will assign this location class to locations used to perform work order build 
 actions.</li>
        </ul>
