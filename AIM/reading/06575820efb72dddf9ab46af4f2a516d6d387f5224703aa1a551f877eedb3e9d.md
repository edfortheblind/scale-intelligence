
        
        <h1 data-source-node="n56"><a name="kanchor1600" data-source-node="n57"></a>Required Checkbox</h1>
        <h5 data-source-node="n58">Using 
 With the Accessorial Detail...</h5>
        <p data-source-node="n59">This checkbox indicates if a value must be defined in the accessorial 
 field on the Accessorial Assignment Window. This value is assigned to 
 an accessorial on the Accessorial Detail Window.If the checkbox 
 is selected, the system will require you to include a value in 
 the accessorial field. If 
 this checkbox is not selected, 
 the system will not require you to include a value in the accessorial 
 field.</p>
        <p class="p_1" data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"> </p>
        <h5 data-source-node="n62">Using 
 With Consolidation Criteria...</h5>
        <p class="p_1" data-source-node="n63">This checkbox determines if a consolidation 
 criteria value is required. The system references this checkbox and its 
 corresponding criteria during manual consolidation. If its selected, the 
 shipments must meet the criteria for consolidation to occur. This 
 value is assigned on the Consolidation Criteria Window.</p>
        <p class="p_1" data-source-node="n64"> </p>
        <p class="p_1" data-source-node="n65"> </p>
        <h5 data-source-node="n66">Using 
 With Packing Criteria...</h5>
        <p data-source-node="n67">Packing criteria records determine if an item should be packed into 
 the same container with other item(s). You can use this checkbox to indicate if the system will display 
 a packing criteria-related warning message, or an error, during full-screen 
 packing. If this checkbox is selected, 
 then users will not be allowed to pack items with differing values together.   If this checkbox is not selected, when the user attempts to pack 
 these differing items, the system will display a warning message asking 
 for confirmation to make sure they want to pack these items. Note that the container creation process and RF pick/pack functionality 
 <span class="span_1" data-source-node="n68">do not use</span> the Required Field. 
 All fields must match for the items to be packed together, regardless 
 of the Required Checkbox's value.</p>
