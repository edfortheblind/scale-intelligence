
        
        <h1 data-source-node="n56"><a name="kanchor482" data-source-node="n57"></a>Suppress State During Manifesting Field</h1>
        <p data-source-node="n58">This field indicates if you want the system to ignore the requirement 
 of providing a state code when performing a manifesting request. This 
 is necessary because some international destinations do not require a 
 state code, but the application typically requires this information when 
 you define a customer/ship to address.</p>
