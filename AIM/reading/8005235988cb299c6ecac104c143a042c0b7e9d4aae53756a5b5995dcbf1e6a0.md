
        
        <h1 data-source-node="n56"><a name="kanchor467" data-source-node="n57"></a>Container Picking Method Field</h1>
        <p data-source-node="n58">This field indicates what type of RF pick/pack functionality, if any, 
 that you want users of this work profile to perform:</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">Pick Into Shipping 
 Container: Choose this option if you want users to be able to directly 
 pick into the final shipping container.<br data-source-node="n61"> </li>
            <li data-source-node="n62">Pick Into Tote: 
 Choose this option if you want users to be able to directly pick into 
 a transport container, a.k.a. a "tote."<br data-source-node="n63"> </li>
            <li data-source-node="n64">None: 
 Choose this option if you want users not to use the RF pick/pack functionality.</li>
        </ul>
