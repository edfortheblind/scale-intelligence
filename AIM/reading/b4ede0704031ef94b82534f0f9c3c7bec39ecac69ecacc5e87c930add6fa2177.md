
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Pro Number</h1>
        <p data-source-node="n58">This procedure applies specifically to LTL (Less-than-Truckload) and truckload carriers. Use this configuration to define the Pro Number range that a carrier will use. The system will automatically assign a unique Pro Number to each shipment for the selected carrier. These numbers help carriers uniquely identify each shipment and appear on the Bill of Lading and Truck Manifest.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Note:</p>
        <p data-source-node="n61">You can configure a warehouse alert to notify users when the Pro Number range is running low. This alert can create a history record and/or send an email notification when the remaining numbers fall below a predefined threshold, which is set in the Rating System Values configuration.</p>
        <p data-source-node="n62"> </p>

        <ul data-source-node="n64">
            <li data-source-node="n65">
                <p data-source-node="n66">Enter Pro number set name.</p>
            </li>
        </ul>
        <ul data-source-node="n67">
            <li data-source-node="n68">
                <p data-source-node="n69">Use the Pro Number Range Fields to define the range of numbers included in this set. In the <b data-source-node="n70">Pro Number From</b> and <b data-source-node="n71">Pro Number To</b> fields, specify the start and end values for the range.</p>
            </li>
        </ul>
        <ul data-source-node="n72">
            <li data-source-node="n73">
                <p data-source-node="n74"> Next Pro Number  - Enter the number that the system will assign next. This is typically the first number in the range..</p>

        </ul>
        <ul data-source-node="n75">
            <li data-source-node="n76">
                <p data-source-node="n77">Pro Number Length - Indicate the number of characters in the Pro Number, based on the maximum length in the defined range (excluding any prefix, suffix, or check digit). </p>
                <p data-source-node="n78">Example: For a range of 1–1000, the Pro Number length would be 4.</p>
            </li>
        </ul>
        <ul data-source-node="n79">
            <li data-source-node="n80">
                <p data-source-node="n81">Pro Number Prefix  - Identify the value that will be added to the beginning of all pro numbers for this carrier. This value is only applied if the carrier requires it. It can be an alpha-numeric value.</p>
            </li>
        </ul>
        <ul data-source-node="n82">
            <li data-source-node="n83">
                <p data-source-node="n84">Pro Number Suffix- Identify the value that will be added to the end of all pro numbers for this carrier. This value is only applied if the carrier requires it. It can be an alpha-numeric value.</p>
            </li>
        </ul>
        <ul data-source-node="n85">
            <li data-source-node="n86">
                <p data-source-node="n87">Check Digit Algorithm - Select the applicable check digit algorithm used by the carrier. If the desired algorithm isn’t available, a system consultant can add it in the Check Digits configuration.</p>
            </li>
