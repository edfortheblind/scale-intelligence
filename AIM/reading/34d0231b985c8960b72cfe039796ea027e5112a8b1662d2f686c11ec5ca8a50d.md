
        
        <h1 data-source-node="n56">Reviewing Country Names</h1>
        <p data-source-node="n57">The system uses complete-word descriptions to represent the names of 
 countries. You may create a new country name in the Country Window. These 
 names will appear in country fields throughout the system. Note that the system is shipped 
 with the most common default values which should meet your business needs. 
 However, only certain country values (typically United States, Canada, 
 and Mexico) will be shipped as "activated" records. Therefore, 
 you can view only these values in country fields throughout the system. 
 The other countries defined in the Country Window are shipped as "inactivated" 
 records, so you will have to manually activate these countries in order 
 for them to appear in the country fields.</p>

        <h5 data-source-node="n96">Using the Header Fields</h5>
        <p class="p_15" style="font-weight: bold" data-source-node="n97"> </p>
        <p data-source-node="n98">Access the Country Window. Create a new record.</p>
        <ol data-source-node="n99">
            <li value="1" data-source-node="n100">
                <p data-source-node="n101">Use the Identifier and Description 
 Fields to define the name of the country. The system will use the 
 value you enter in the Description Field in country pull-down menus throughout 
 the system. Note that if you have customers 
 that have country codes that differ from the IATA standard used by the 
 system. In this case, you will need to create new country name(s) and 
 inactivate the unused country. For example, if you have a customer in 
 Mexico that uses the abbreviation MEX (rather than the IATA standard MX), 
 then you will need to create a new Mexico country record with the abbreviation 
 MX.</p>
            </li>
        </ol>
        <p data-source-node="n102"> </p>
        <h5 data-source-node="n103">Using the System Defined 
 Values Tab</h5>
        <ol class="ol_1" data-source-node="n104">
            <li class="li_4" value="1" data-source-node="n105">Use the External Rating 
 Symbol Field to identify the value 
 (which corresponds to the Dimension UM) that is sent by SCALE to the transportation 
 engine, either FSMS or Progistics. Valid values for this field are "I" 
 (for inches) and "C" (for centimeters). <br data-source-node="n106"> </li>
            <li class="li_4" value="2" data-source-node="n107">Use the FedEx Rating 
 Symbol Field to indicate the symbol 
 that is used to identify a container to the FedEx rating software. FedEx 
 will use this value during rating to help calculate the appropriate rates 
 for containers associated with this container type. <br data-source-node="n108"><br data-source-node="n109"></li>
            <li value="3" data-source-node="n110">Use the Suppress 
 State In Rating Field to indicate if you want the system to ignore 
 the requirement of providing a state code when performing a manifesting 
 request. This is necessary because some international destinations do 
 not require a state code, but the application typically requires this 
 information when you define a customer/ship to address.<br data-source-node="n111"> </li>
            <li value="4" data-source-node="n112">Use the Suppress 
 Postal Code In Rating Field to indicate if you want the system 
 to ignore the requirement of providing a postal code when performing a 
 manifesting request. This is necessary because some international destinations 
 do not require a postal code, but the application typically requires this 
 information when you define a customer/ship to address.<br data-source-node="n113"><br data-source-node="n114"></li>
            <li value="5" data-source-node="n115">The Country Rating Symbol Field indicates the appropriate two-letter identifier for a country. You would need to enter a value in this field if you want a different country identifier during rating.<br data-source-node="n116"><br data-source-node="n117"></li>
            <ul data-source-node="n118">
                <li style="font-weight: normal" data-source-node="n119"> If there is a value in this field, then external rating systems will use this value as the country code when manifesting.<br data-source-node="n120"><br data-source-node="n121"></li>
                <li style="font-weight: normal" data-source-node="n122">If this field is blank, then external rating systems will use the Country Window's identifier as the country code when manifesting.</li>
            </ul>
            <p style="font-weight: normal" data-source-node="n123"> </p>
        </ol>
