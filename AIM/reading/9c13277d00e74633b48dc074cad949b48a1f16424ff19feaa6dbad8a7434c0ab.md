
        
        <h1 data-source-node="n56"><a name="kanchor1665" data-source-node="n57"></a>Status Field</h1>
        <h5 data-source-node="n58">DIF Incoming/Outgoing Message Insight Screens...</h5>
        <p data-source-node="n59">This field identifies one of the four statuses that an incoming or outgoing message can be at:</p>
        <ul data-source-node="n60">
            <li data-source-node="n61"><i data-source-node="n62">Ready</i> - Indicates a message is ready to be processed by the DIF Message Processing service.<br data-source-node="n63"><br data-source-node="n64"></li>
            <li data-source-node="n65"><i data-source-node="n66">In Process</i> - Indicates a message is currently being processed by the DIF Message Processing service.<br data-source-node="n67"><br data-source-node="n68"></li>
            <li data-source-node="n69"><i data-source-node="n70">Processed</i> - Indicates a message has been successfully processed by the DIF Message Processing service.<br data-source-node="n71"><br data-source-node="n72"></li>
            <li data-source-node="n73"><i data-source-node="n74">Error</i> - Indicates that there was an error that occurred when the DIF Message Processing service attempted to process a message.</li>
        </ul>
        <p data-source-node="n75"> </p>
        <h5 data-source-node="n76">On the Shipping Container Screen / Shipment Insight Screen...</h5>
        <p data-source-node="n77">This field identifies the current status at which the container is currently assigned. Note that containers do not have a leading and trailing status; rather, they are just assigned one status.</p>
        <p data-source-node="n78"> </p>
        <p data-source-node="n79"> </p>
        <h5 data-source-node="n80">On the Cycle Count Request Insight Screen...</h5>
        <p data-source-node="n81">This field indicates the status of the specific cycle count request. For example, "pending review". </p>
        <p data-source-node="n82"> </p>
        <p data-source-node="n83"> </p>
        <h5 data-source-node="n84">On the Purchase Order Insight Screen...</h5>
        <p data-source-node="n85">This field indicates the status of the specific purchase order. For example. "open". For more information, refer to the topic <a href="2a527c5e7d8e6767787122c58edd13a2907206b5a7cd1f1e9b541bbc51546b85.html" data-source-node="n86">Reviewing Purchase Order Status Values</a>. </p>
        <p data-source-node="n87"> </p>
        <p data-source-node="n88"> </p>
        <h5 data-source-node="n89">On the Inventory Adjustment / Inventory Transfer Screens...</h5>
        <p data-source-node="n90">This field indicates the inventory status (Available, Held, etc) that an item quantity will have after an adjustment/transfer is performed.</p>
