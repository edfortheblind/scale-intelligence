
        
        <h1 data-source-node="n56"><a name="kanchor153" data-source-node="n57"></a>Use Rating in Selection Checkbox</h1>
        <p data-source-node="n58">This field determines if cost is considered a factor in selecting a 
 carrier from the carrier group. You can select this checkbox on the Carrier 
 Group Window. If this checkbox is selected 
 and at least two carriers within the group can meet the ship date, the 
 system will rate the carriers (that meet the date). It will select the 
 cheapest carrier. Please note that the system will only rate those carriers 
 that can meet the required ship date. If this checkbox 
 is not selected, the system will not consider rate costs when selecting 
 a carrier. If more than on carrier can meet the ship date, the system 
 will select the first carrier service in alphabetical order.</p>
        <p data-source-node="n59"><b data-source-node="n60">Preference Factor</b> used - </p>
        <p data-source-node="n61">When the Use rating in selection is checked in the carrier group, and if multiple carrier services can meet the ship date/delivery date requirements, the system first chooses the carrier service with the lowest freight rate. When there is a tie then the Preference Factor gets executed.</p>
        <p data-source-node="n62">Also when the Use rating in selection is unchecked, then the system considers Days to deliver over the preference factor. Only if there is a tie in days to deliver, the system will use the preference factor.</p>
