        <h4 data-source-node="n71">Setup Flow...</h4>
        <ol data-source-node="n72">
            <li value="1" data-source-node="n73">In SCALE, create a new <a href="c149d4ae2511ae553a00f4fa251b7f5353df9205d998ee5a95078f0ab5c29df9.html" data-source-node="n74">intermediate consignee</a> record. Note the required data should be obtained from UPS prior to creating this record.<br data-source-node="n75"><br data-source-node="n76"></li>
            <li value="2" data-source-node="n77">The Progistics license should be enabled for UPS World Ease, after it is enabled from Connectship.<br data-source-node="n78"><br data-source-node="n79"></li>
            <li value="3" data-source-node="n80">Load the POE (Port Of Entry) file into Progistics. See the topic <a href="c879644603496ead5efacebd25bf8e8d83c833efc26fa5a45f4603bc56c7fad8.html" data-source-node="n81">Prerequisites/Requirements When Using UPS World Ease</a> for more information about POE files.<br data-source-node="n82"><br data-source-node="n83"></li>
            <li value="4" data-source-node="n84">Enable Progistics to allow World Ease shipments. This is done in the "Modify Shipper Account Information" screen, by selecting the Allow World Ease Shipments checkbox.<br data-source-node="n85"><br data-source-node="n86"></li>
            <li value="5" data-source-node="n87">
                <p data-source-node="n88">In SCALE, add a carrier for the World Ease service:  World Ease supports four different services, choose the appropriate one that is required for your shipper.<br data-source-node="n89"><br data-source-node="n90"><img loading="eager" data-source-node="n91"><br data-source-node="n92"><br data-source-node="n93"></p>
            </li>
            <li value="6" data-source-node="n94">Ensure that the SCALE shipper cross reference supports UPS World Ease for the respective shipper.<br data-source-node="n95"><br data-source-node="n96"><img loading="eager" data-source-node="n97"><br data-source-node="n98"><br data-source-node="n99"></li>
            <li value="7" data-source-node="n100">Paperwork setup required (all are Progistics documents):<br data-source-node="n101"><br data-source-node="n102">- UPS World Ease Master Invoice (3 copies required, TANDATA_UPS_MASTER_INVOICE.STANDARD)<br data-source-node="n103"><br data-source-node="n104"></li>
            <p data-source-node="n105">- UPS World Ease Consolidated Invoice (1 copy required, TANDATA_UPS_CONSOLIDATED_INVOICE_DETAIL.STANDARD)<br data-source-node="n106"><br data-source-node="n107"></p>
            <p data-source-node="n108">- UPS World Ease Certificate of Origin (1 copy required, TANDATA_UPS_WE_CERTIFICATE_OF_ORIGIN.STANDARD)</p>
            <p data-source-node="n109"> </p>
            <p data-source-node="n110"> </p>
            <li value="8" data-source-node="n111">Labels required (all are Progistics labels):<br data-source-node="n112"><br data-source-node="n113">- UPS Shipping Label (TANDATA_UPS_WORLD_EASE_MAXICODE.STANDARD)UPS Doc Box label (TANDATA_UPS_DOCBOX.STANDARD)</li>
            <p data-source-node="n114">
                <br data-source-node="n115">- Label Printing Note: The World Ease label is a combination of a 6x4 + 4x4 label (its total length is 4 x 11). You need to make sure that the stock symbol is set accordingly on the print device that is configured to print the World Ease labels. When printed, the label needs to be torn into two parts (6x4) and (4x4).  The shorter label is stuck on top of the (6x4) label.<br data-source-node="n116"><br data-source-node="n117"></p>
            <li value="9" data-source-node="n118">Setup SCALE document routing to support the above labels and documents.</li>
        </ol>
