
        
        <h1 data-source-node="n56"><a name="kanchor625" data-source-node="n57"></a>Creating Container Groups</h1>
        <p data-source-node="n58">A container group identifies all the containers that can be used to 
 pack an item, or group of items. During the container creation wave step, 
 the system processes through a container group's details in sequence order. 
 After you define a container group, you will link it it to the correct 
 packing class on the Packing Class Window.</p>

        <h4 data-source-node="n101">Procedures..</h4>
        <p data-source-node="n102"> </p>
        <h5 data-source-node="n103">Using the Container Group 
 Window</h5>
        <ol class="ol_1" data-source-node="n104">
            <li value="1" data-source-node="n105">Provide a name 
 for the container group and a description. Select the Apply Button. 
 Select the New Action. The system will display the Container Group Detail 
 Window.</li>
        </ol>
        <h5 data-source-node="n106"> </h5>
        <h5 data-source-node="n107">Using the Container Group 
 Detail Window</h5>
        <ol data-source-node="n108">
            <li value="1" data-source-node="n109">The Sequence 
 Field will contain the value 10. You can change the sequence number, 
 but you cannot use the same sequence number for multiple detail records. 
 The sequence number determines when this record will be used. The lower 
 the sequence number, the sooner it's processed. Generally, the largest 
 container in a group should be associated with the <b data-source-node="n110">lowest</b> sequence number. The remaining containers should also be assigned 
 sequence numbers based in size: the smallest container should have the   <b data-source-node="n111">highest</b> sequence number.<br data-source-node="n112"> </li>
            <li value="2" data-source-node="n113">
                <p data-source-node="n114">Use the Container Type Field to 
 assign a container type to this detail. This identifies the container 
 that the system will attempt to pack product in during the container creation 
 wave step.</p>
                <p data-source-node="n115"> </p>
            </li>
            <li value="3" data-source-node="n116">Use the Fill 
 Percent Field to identify how much of this container's dimensional 
 space is available for items. If you select 100, the system assumes that 
 no packing materials, inserts or other non-saleable items are included 
 in the container.<br data-source-node="n117"> </li>
            <li value="4" data-source-node="n118">
                <p data-source-node="n119">Use the Container Shape Field 
 to indicate the type of physical shape of a shipping container. Container 
 shape values are used by the system during the container creation in a 
 wave process to determine if a certain container type can be downsized 
 into. Only container types with the same container shape (as the originally 
 assigned container type) can be downsized into.</p>
                <p data-source-node="n120"> </p>
            </li>
            <li value="5" data-source-node="n121">To define additional 
 sequence values, select the New Action.</li>
        </ol>
