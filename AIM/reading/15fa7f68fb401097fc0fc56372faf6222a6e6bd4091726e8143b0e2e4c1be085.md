
        
        <h1 data-source-node="n56"><a name="kanchor923" data-source-node="n57"></a>Override Pick Checkboxes</h1>
        <p data-source-node="n58">These checkboxes indicate  what value(s) that a user can change during RF pick confirmation. You can enable the user to override any/all of the following values: Location, Lot, License Plate. See <a href="0b84baf485eeccf7c908b56579b3b6a763c8bedeecef9558de7192c596b8df3a.html" data-source-node="n59">this topic</a> for rules that the system enforces for override picks.<br data-source-node="n60"></p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">When the "Prompt On LP/Location/Lot Override setting is active, the system will display an alert message when you attempt to override one of the pick values.</p>
