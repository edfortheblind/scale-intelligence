
        
        <h1 data-source-node="n56"><a name="kanchor9" data-source-node="n57"></a>Activating a Zone for Pick Management</h1>
        <p data-source-node="n58">You must activate picking management for a specific zones if you want 
 the system to display work unit(s) from these zones in the picking management 
 windows. Note that this topic discusses only 
 the steps needed to activate picking management for specific zones. For 
 more general information on creating zones, see the topic <a href="7a2bc3b6525e0325ad47b542b6db68ca6e4aa0762e6b6886d7fca262acb7386b.html" data-source-node="n59">Defining 
 Zones</a>. You will activate zones on the Zone Window.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62"> </p>
        <h4 data-source-node="n63">Using the Pick Management Active Checkbox</h4>
        <p data-source-node="n64">Access the Zone Window. Open or create a new zone record.</p>
        <ol data-source-node="n65">
            <li value="1" data-source-node="n66">
                <p data-source-node="n67">Choose the value "Work" 
 in the Zone Type Field. You must 
 choose a zone type of "Work" if you want to activate 
 picking management.</p>
                <p data-source-node="n68"> </p>
            </li>
            <li value="2" data-source-node="n69">Use the Pick 
 Management Active Checkbox to indicate if you want work units in 
 this zone to appear in picking management.<br data-source-node="n70"> </li>
            <ul type="disc" class="ul_1" data-source-node="n71">
                <li data-source-node="n72">
                    <p data-source-node="n73">If this checkbox is checked, 
 the system will display work units from this zone in picking management 
 windows, such as the Picking Selection Window or the Picking Management 
 Explorer.</p>
                    <p data-source-node="n74"> </p>
                </li>
                <li data-source-node="n75">If this 
 checkbox is not checked, the system will not display work units 
 from this zone in picking management windows.</li>
            </ul>
        </ol>
        <p data-source-node="n76"> </p>
