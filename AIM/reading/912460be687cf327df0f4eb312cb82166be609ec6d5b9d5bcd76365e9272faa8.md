
        
        <h1 data-source-node="n56"><a name="kanchor992" data-source-node="n57"></a>Maximum Number of Counts Field</h1>
        <p data-source-node="n58">This field indicates the maximum number of cycle count requests you 
 want the system to generate from a particular cycle count plan. Note that if you put a "0" (or do not provide a value) 
 in this field, there will be no maximum limit of requests that the system 
 will create.</p>
