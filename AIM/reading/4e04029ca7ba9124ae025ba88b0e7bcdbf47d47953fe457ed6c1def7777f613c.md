
        
        <h1 data-source-node="n56"><a name="kanchor1346" data-source-node="n57"></a>Print at WM Work Start Checkbox</h1>
        <p data-source-node="n58">This setting indicates that you want the system to print shipping container label(s) when you begin to execute work units via an hand held mobile device. Note that the system will only print shipping container labels that have the "Start WM Work" print procedure checked on the document type record. Also, this is only valid for work that was created from shipping containers.</p>
