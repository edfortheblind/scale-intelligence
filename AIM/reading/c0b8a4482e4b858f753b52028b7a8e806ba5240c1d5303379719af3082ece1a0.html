Work Profile Selection screen

Follow the steps to select a work profile

 

  1. Tap Work Execution to view Select Work Profile screen. The screen will list all the work units that user is authorized.
  2. Tap to select work profile as required. Note: In case of default work profile is set in the User Profile settings, the system will not prompt user to select work profile that has user and warehouse authorized.
    • In case there are multiple work units exists with same ID, then system will display all the work units. Slider feature enables users to swipe and see all the work units and select one of them.
  3. Enter or scan the Work Unit.
  4. Tap Go to view Pick Confirmation screen.

Pick actions

The following are the pick actions available in the pick confirmation screen.

 

 

Name

 

Actions

Partial Pick

 

You would select this action to confirm the instruction's pick quantity. To perform a partial pick, you would enter a quantity other than the full pick quantity and press Go.

This action will be enabled for receipt work only if receipt putaway verify method on your work special handling is set to either existing LP-allow override or user specified

Note: The action is not available if the user does not have security permission or the quantity verification is turned on your work special handling.

 

Short Pick

 

 

 

You would select this action to confirm a short pick of the instruction's item quantity. The system will then display the Short Pick Reason Code screen.

 

Skip

 

 

You would select this action to move to the next work instruction, without picking the item quantity of the current instruction.

 

Pass

 

 

You would select this action if you want to completely stop processing on this work unit. The system will return you to the appropriate work initiation screen.

 

Full

 

You would select this action ,if you want to indicate that the container you are picking into is full, and thus you cannot pick any further quantity on the instruction. The system will then proceed to the putaway screen for any picked quantity on the instruction. When done with the putaway, the system will not display anymore instructions from the work unit, but instead return to the work initiation screen.

 

 

Over Pick

You would select this action to perform an over pick in replenishment work and work order component. Using this action, you can pick more quantity that the on hand quantity present. This action will display over pick screen for user to enter the over pick quantity. System also shows the on-hand quantity at the location. You will not be able to proceed in case you enter quantity less than or equal to on hand quantity displayed.

 

 

Picking Notes
  • If executing a partial pick, the system would keep the instruction open so the remainder could be picked later.
  • You cannot perform a partial pick on a full container, full containers being containers created in the wave where the quantity allocated matches the quantity on that unit of measure for the item. In this case the system creates a single shipping container record that cannot be broken down further.
  • If executing a partial pick, the system will delete the remaining quantity from the work instruction (and close it) if the "Close After Partial Pick" check box (in Work Special Handling Window) is selected. If not, the system would keep the instruction open so the remainder could be picked later. Note that the "partial pick and close" action is only available for replenishment and work order picks, if it is defined to do so in the Work Special Handling Window.
  • If you are executing a pick with the "Allow Over Picking" work special handling setting active, the system will allow the user to pick more quantity than exists on a work instruction, as long as this quantity is within the location's available quantity. When an over pick is performed, the system will increment the transaction quantity, and process the pick as a complete/normal pick. This option is only available for replenishment and work order picking. For example, suppose a work order component work instruction calls for 980 each of an item. It may be easier physically, then, for the worker to pick two cases of 500 (for a total of 1,000 each) rather than breaking one case open and leaving 20 eaches loose at the location. If this check box is checked, the system will increment the instruction by 20 eaches, and process the pick as normal.
  • If you are executing a pick with the "Allow Pick In Transit" work special handling setting active, the system will allow the user to pick quantities that are labeled as "in transit". Therefore, if there is not enough quantity in the location to be picked, but there is additional inventory that is on the way to the location, the user will be able to pick from that in transit quantity. Note: If the user picks this inventory, the on hand inventory at the location will show a negative quantity until that quantity is rectified by something such as a replenishment or an inventory transfer.
  • If the item quantity being picked is serial number tracked, the system will display an entry screen for each item being picked. Note that if the item you are picking is configured for serial number range entry, then the system will display a screen that allows you to enter the first and last serial number in the range of numbers that is on the quantity that you are picking. You can also press the Skip button to return to the regular serial number entry screen (so you can manually enter each number as opposed to providing the range).
  • If you are picking a full UM container (created out of the wave) that has serial number tracked items, then the system will not prompt the user to enter serial numbers.
  • It is highly recommended that you do not confirm decimal quantities of serial number tracked items when picking.

  • If you are executing a pick with the "Use Converted Quantity" work special handling setting active, the system will allow the user to pick quantities in the converted UM. If item has UM greater than base UM and pick quantity is a multiple of that converted quantity, the system uses converted UM as pick quantity when "Use converted quantity" checkbox is enabled. If the item only has base UM configured, the system uses base UM as pick quantity when "Use converted quantity" is enabled. If the item has UM greater than base UM but pick quantity is not a multiple of converted quantity UM, the system uses base UM as pick quantity when "Use converted quantity" is enabled. User cannot enter a decimal quantity for converted quantity to a partial/short pick.

  • When there are multiple Work instructions for same work unit, then system will show work instructions in form of slider. For example if there are 3 work instructions, then in the Select a Work unit screen, 1/3 shows the first receipt line. Slide the screen left to see the second (2/3 as mentioned in the screen).

  • Override license plate is supported for
    • same quantity for same/different lot at different location.

    • same quantity different lot at same location.

    • same quantity same lot at same location.

  • When short picking an inventory serial number tracked item when the for "Short Pick Inventory Action" inventory control value is set to "No count, remove all unallocated on hand quantity" or "No count, remove transaction quantity", the system will remove serial numbers to match the quantity being removed from the location. Note that it will NOT prompt the user for which serial numbers are to be removed, it will simply just choose them. To avoid this, you will need to configure this system value to one of the "Count" options so that the inventory gets moved to Suspense and a cycle count gets generated.

 

Batch Picking notes

The batch feature in warehouse mobile enables the system to group multiple picks for items at same location for a work unit. For example, suppose a work unit has 2 instructions: (1) Item AAA, location 111, quantity 10 each, and (2) Item AAA, location 111, quantity 5 each. With this flag on, you will see a pick of 15 each from location 111 for item AAA. With this flag off, you will see the two picks one for 10 the other for 5.

 

Batch picking - same item - The application will group multiple picks in a work unit when Group pick by location or license plate is selected. The quantity value displayed in sum of the grouped work instruction pick quantity. It also groups the putaway instruction in case all of the picked quantity is sent to same location. tap on info icon to view information and swipe through the instructions that are grouped. System will show the page that you are navigating through.

 

Batch picking - Multiple item - Multiple items are being picked from same location/license plate. When batch picking for multiple items is done, in the Pick Confirmation screen shows the All items for Item and Entire quantity for Quantity as long as this is putaway to the same location. In the Putaway Confirmation screen, the system will group the putaway instruction of all the items. The information icon is available only for item. Tap to view the multiple items that are batched for this pick.

  • For Receipt putaway work system groups the putaway based on how the receipt containers are located.
  • If nested containers are located using parent locating method, system will not honor item and lot verifications and continue to group the putaway as long as the containers are going to same putaway location.
  • If nested containers are located using child locating method, system will honor item and lot verifications and shows the putaway per child container.
  • Quantity verification is not honored when Pick quantity shown as "Entire Quantity".
About Parent/Child License Plates

The following describes how to use this field to get one pick for parent license plate or child license plate, when all the associated location inventory records are on same work instruction for the full amount.

  • If this setting is not activated, the system will always process work instructions individually.
  • If this setting is activated, the system will allow one pick of multi-item child license plate, if all items on child are on work unit and for entire amount. Otherwise, the user will have to do each pick individually. The system allows one pick of parent license plate if all child license plates are on work instruction and are for full amount, otherwise user will have to do each picks individually.
Override Shipping Containers

Follow the steps to perform the override shipping container. Work special handling need to be configured.

  1. Tap the work entity as required to view Work Profile Selection screen.
  2. Scan the Work Unit or Container ID and details are displayed in the Pick Confirmation screen.
  3. Enter the new value in the Container ID text box and tap GO.
  4. System will prompt with the message to override the shipping container. Tap Yes.
  5. The new Shipping Container ID is displayed in the Pick Confirmation screen.
  6. Tap Go to complete the pick.

Note

  • Allow override option needs to be selected in Work special handling configuration.
  • Pick into shipping container needs to be selected in the Work Profile configuration.
  • Asynchronous validation is enabled for Container ID field and the user is prompted with appropriate error message based on the container id entered during override.
Create Containers during Pick

The system creates containers on the fly during the pick. This occurs when the wave creates only the allocation work and the Pick into shipping container is selected in the Work Profile.

  • In the Pick Confirmation screen, system prompts user to enter the Container ID.
  • Enter/Scan new container ID and Tap Go.
  • Select the Container type and Tap Go.
  • System navigates to the Putaway Confirmation screen.
Split Containers

This enables you to split off and pick a portion of the quantity into another container. To perform this action, user first performs an partial pick of the quantity and then the system will create a new work unit and container for the split quantity. Typically this situation would occur if you created containers in the wave, and the current pick physically will not completely fit into the container that the system created for it.

 

Note

  • Allow splitting of container option needs to be selected in Work special handling configuration.
  • Split container needs to be selected in the security permission.
  • Partial pick of the quantity has been completed.
  • Container has been created by a wave.
Inline partial Pick

Users can inline partial pick when a new container is created during pick. This occurs only when Prompt for quantity and Verification - Quantity is selected in Work Special Handling.

The system will prompt user to enter the quantity value without need to initiating Actions>>Partial Pick.

 

Typically, user can perform the following when creating containers on the fly

  • Pick the full item quantity into one new container.

  • Partial Pick item into the same new container.

  • Partial pick item into multiple new containers.

Note:

  • The system will not prompt for container type if partial pick into existing new container.
  • In case of partial pick into multiple new containers, then system will ask for the container ID and container type for first time, on the entering/scanning second quantity, the previously scanned container ID is displayed. Optionally, user can enter a new container ID for the second quantity.

Override Putaway and Receipt Methods

 

Based on Receipt Putaway Verification Settings:

  • Existing LP – No Override Allowed: - The system displays the existing license plate in read-only mode.

  • Verify Existing LP: - The system requires the entry of the existing license plate ID for confirmation. An error occurs if a new value is entered.

  • Existing LP – Allow Override: - The system shows the existing license plate. Users can choose to use the existing license plate or enter a new one.

  • User Specified: - The system does not display the existing license plate. Users must enter a new value.

Perform Locate during putaway confirmation

The Locate action will be available in the following configuration

  • Security Permission >> Locate check box selected
  • Work Special Handling - Key Value tab >> Location verify method >> Check digit or Location needs to be selected.

Follow the steps

  • In the Putaway Confirmation screen, tap the arrow and select Locate
  • In the Locate screen, select the locating rule from the picker control.
  • Tap Go to search and populate the location in the Putaway confirmation screen.
  • Tap Go to complete the putaway confirmation. The UI flow will change based on the verifications selection (check digit and Location)

Note: The locate actions is supported for Receipt putaway work.

Putaway Notes
  • The system will require you to provide a new License Plate ID when putaway to the location which tracks license plate and the putaway quantity is not the full license plate quantity.
  • When doing receipt putaway work, the system tries to summarize (display one putaway screen for multiple license plates) whenever possible, depending on the item/location/license plate, and the user's work special handling settings.
  • The putaway process on the shipping dock always does a putaway for all items and all quantities. It does not group these into separate putaways based on the shipment, or step through each work instruction. If putaway to shipping container is enabled, the work unit being put away must be for a single shipment if performing the putaway to a shipping dock location.

  • If your work profile is defined to putaway into shipping containers (and you are putting away to a put-to-store location or the shipping dock), you will need to provide the Container ID that you are putting into. Also, if this is a new container, you will need to indicate the container type. The container types can be authorized by company and warehouse.

  • Quantity verification is not honored when Pick quantity shown as "Entire Quantity".

  • We can execute cross dock work to put to store location. Also the Putaway to shipping container can be performed. In the putaway screen, user can enter/scan the container ID and container type. Note: System will not prompt for container type if container type exists for the container ID.

  • The cross dock LP ID can be used as container ID in the putaway screen. After a pick, enter the quantity in the putaway screen and in the container ID field, enter the LP ID and Tap Go. System will prompt to select the container type.

Put to Store

The put to store enables users to putaway individual items with partial quantity into specific new or existing containers. The put to store orders are usually used in retail distribution facilities, where the item is divided and putaway to individual retail store destinations.

When putaway is performed, If your work profile is defined to putaway into shipping containers (and you are putting away to a put-to-store location or the shipping dock), you will need to provide the Container ID that you are putting into. Also, if this is a new container, you will need to indicate the container type. The container types can be authorized by company and warehouse. The system will display an error if the entered shipment container is for different shipment and different location. Also, different shipment cannot be putaway into single container.

 

Put to store configuration.

The following are the configuration are necessary for put to store.

  • Create put-to-store locations in the Location with Put to store as location class.
  • Configure the item master for appropriate category class.
  • Define the locating rules that you want to use for processing.
  • Define the receiving preferences and work profile (putaway to Shipping container).
  • Create store location assignment and assignment criteria records.
Nest After Putaway

Work Profile >> Putaway Options >> Nest After putaway

The system will display the shipment nesting container screen after you have putaway all the shipping containers. Enter a container and the picked containers are then nested under the new container. This allows you to do is pick into shipping containers, and then place those shipping containers on a pallet for shipping.

Note: Nest after putaway feature will not be initiated if the Putaway to shipping container option is selected.

 

Consolidation after putaway

The Consolidation screen appears after Putaway confirmation if the "Consolidation after putaway" option is enabled in the Work Profile. The system will prompt for the entry of the Consolidation location area and location position once Putaway is completed. A consolidation success message is displayed after entering the location area and location position.

The following scenarios illustrate the behavior of consolidation after Putaway:

 

Example 1: Single Work Unit for a Shipment with Allocation Work

When the Work Profile is set to "Pick into shipping container" and two containers are created during the pick process:

  • In the Putaway Confirmation screen, tap "Go" to view the Consolidation screen.

  • The system will prompt for the Location Area and Location Position.

  • For the second container, the system will not prompt for the location area and position since it is part of the same shipment.

Example 2: Two Work Units for a Shipment with Container Work

When the Work Profile is set to "Pick into None" and two containers are created in a Wave:

  • In the Putaway Confirmation screen, tap "Go" to view the Consolidation screen.

  • The consolidation screen will be displayed after Putaway for each work unit.

  • After completing Putaway for the first work item, the system will prompt for the Location Area and Location Position.

  • The system will display a message under Container Count, such as "1 of 2 (1 Unpicked)".

  • After confirming Putaway for the second work unit, the system will not prompt for Location Area and Location Position.

  • Since it is a single shipment, the Consolidation location will remain the same.

Short Putaway

 

The Short Putaway option enables users to putaway less items than originally instructed.

 

The system will display the Short option in the following cases:

  • The putaway location is a Put To Store location.

  • The user has security access to the Short Putaway function.

 

Perform short putaway

Follow the steps to perform a short pick.

  1. In the Putaway Confirmation screen, tap the arrow and select Short .
  2. In case system has grouped instructions, then system will prompt user to ungroup the instructions.
  3. Enter the pick quantity value less than the original quantity and tap Go.
  4. Enter the reason code for short putaway and Tap Go.
  5. Putaway successful message is displayed.

Notes

  • If putaway instructions are grouped, the system will prompt you to ungroup the instructions before completing a Short Putaway.

  • When multiple instructions point to the same put to store location, the system shows them individually so you can choose which instruction to short.

  • If full quantities are entered, the system processes the putaway normally.

  • Serial Number tracked items can also be short putaway.

 

 

Pick and Putaway Field Verifications

The pick confirmation and putaway screen functions are based on the verification setting on your work special handling. The screens will function in non-verify mode if the Verification is turned off in special handling section.

When the verification is turned On, the screens will function in verify mode. Both these scenarios are described below.

 

Verification turned Off

Pick confirmation and putaway when the special handling section has the verification turned off.

  1. Tap to select work profile.
  2. Scan the Work Unit and the details are displayed on the Pick Confirmation screen.
  3. Tap Go to perform the pick. Pick Successful message is displayed.
  4. Screen will move to putaway screen or next pick based on the flow. if it moves to putaway screen, tap go and Putaway Successful message is displayed.
Verifications turned On

Pick confirmation and putaway when the special handling section has the verification turned on.

Following the work flow when we have the work handling section as verification turned on.

  1. Tap to select work profile.
  2. Scan the Work Unit and the details are displayed in the Pick Confirmation screen.
  3. Each field needs to be validated based on your work special handling settings. The blue highlight shows the current field being validated.
  4. Enter/Scan the value for the field and tap Go. On validation, the blue highlight moves to the next field validation. Invalid value specified error is displayed when validation fails. Note: You can use the Back button to navigate back to previous field.
  5. Once the last field verification is passed, pick is submitted for processing. Putaway screen is displayed for verification.
  6. Similarly once the last field in putaway screen is verified, the next putaway instruction or the work is started.
Receipt Putaway Work

The system validates the receipt putaway verify methods on work special handling for receipt work. The putaway screen will show putaway verify methods as authorized to the user. The following are verify methods. Read the License Plate Putaway Verify Method Field for more information.

  • Existing License Plate - No override
  • Verify Existing License Plate
  • Existing License Plate - Allow Override
  • User Specified
Cycle count threshold configuration
  • Users can configure the cycle count thresholds, which will initiate the cycle count process during the pick confirmation. This will happen when the inventory threshold for specified location will be lesser than specified quantity.
  • The Performs threshold counts immediately needs to be selected in the Cycle count preference screen.
  • Cycle count actions of Add item and Done is can also be performed.
  • When you are counting the quantity of License plates in a location, and you cancel out of cycle counting without finishing all the counts, the system will honor the counts you have completed, and keep the ones you have not done open.
  • Once cycle count actions are completed, system will display the next pick screen or the putaway screen as required to execute the work unit.
Pickup and Dropoff (P&D) Locations

Users can execute work that involves P&D locations for all types of work. Read Pickup and Drop locations for more Information.

 

The Bypass option appears on the Putaway Confirmation screen when the user has the Bypass security permission enabled in the Whs Mobile – Work Execution security settings. Choosing the Bypass action enables the user to skip the P&D (Pick and Drop) location in the workflow.

When performing Outbound work (such as Shipment Allocation or Shipping Container work), the system provides an option to short pick items when the required quantity is not available.

  • If Work Special Handling is set to Outbound Short Pick, and replenishment is active for the location, the system may display the following prompt: "In Transit quantity exists for the location. Do you wish to continue with the short pick?"

Starting Work Notes

You can relocate receipt containers with delayed locating when the following is true:

  • Start work using user or system directed work initiation method.
  • Start work assigning multiple work units:
    • System directed mode and assign multiple work units on work profile
    • Receiving dock location allows work unit selection on system-directed work
  • Receipt container has been located using delayed locating to the receiving pre-locate location.
  • Work instruction for receipt putaway work has the receiving pre-locate location as the ‘to’ location.
  • Relocating is delayed until starting work for the P&D pick when the receiving dock has an outgoing P&D location.
  • You can configure your work profile to have the system print shipping container label(s) when you begin to execute work units. Also, this is only valid for work that was created from shipping containers.

Work execution behavior for catch weight items:

 

For work-based inventory transactions, SCALE does not prompt for catch weight when the work is created. The prompt appears during work execution. This applies to work-based adjustments, transfers, cycle counting and outbound picking.

 

Outbound picking for Catch Weight items:

  • During shipment work pick confirmation, SCALE prompts the user to enter catch weight for catch weight items.
  • If the user continues without entering a weight, SCALE can calculate the weight by using average weight per unit and applying it to the picked quantity.
  • When catch weight items are picked directly into a shipping container, the captured weight is associated with that shipping container.
  • This applies both when the shipping container already exists and when it is created during the pick.

 

Grouping behavior:

Catch weight pick instructions are shown as ungrouped by default.
