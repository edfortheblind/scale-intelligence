        <p data-source-node="n58">Use this checkbox to indicate that you want the system to execute a 
 cycle count plan (using this master) at a certain date/time via a scheduled 
 job. In addition, note that you must set up a record in the Scheduled 
 Job Window in order for the system to run this master with a scheduled 
 job.</p>
