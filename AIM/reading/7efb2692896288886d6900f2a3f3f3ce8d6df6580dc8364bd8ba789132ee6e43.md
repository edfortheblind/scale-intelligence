
        
        <h1 data-source-node="n56"><a name="kanchor1883" data-source-node="n57"></a>Or Checkbox</h1>
        <h5 data-source-node="n58">On the Action / Customize Viewers Window...</h5>
        <p data-source-node="n59">This checkbox determines if the system should display an action, color, or icon for a particular data record. </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">For example, suppose that you wanted to have the system color the data records of two companies red. You would need to set up two rules in your viewer color record:</p>
        <ul data-source-node="n62">
            <li data-source-node="n63">Company = <i data-source-node="n64">Company A</i> [or checkbox selected]<br data-source-node="n65"><br data-source-node="n66"></li>
            <li data-source-node="n67">Company = <i data-source-node="n68">Company B</i></li>
        </ul>
        <p data-source-node="n69">If you selected the Or Checkbox in the above example, the system will shade red either company's data record(s). If you did not select the Or Checkbox, the system would not shade any records, because there can be no data that is associated with both companies.</p>
        <p data-source-node="n70"> </p>
        <p data-source-node="n71">An example of not needing to check the Or Checkbox would be if you wanted the system to shade data record(s) that meet the following criteria:</p>
        <ul data-source-node="n72">
            <li data-source-node="n73">Carrier = <i data-source-node="n74">UPS</i></li>
            <li data-source-node="n75">Carrier Service = <i data-source-node="n76">Ground</i></li>
        </ul>
        <p data-source-node="n77">Since the Or Checkbox is not selected, the system assumes that the criteria in both rules needs to be met before shading a record a certain color.</p>
