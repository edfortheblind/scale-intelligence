        <p data-source-node="n59">You can use this checkbox to activate immediate needs processing for 
 a certain item.</p>

        <h5 data-source-node="n62">In Inbound Quality Control...</h5>
        <p data-source-node="n63">You can use this checkbox to activate quality control validation for 
 this item. If this is eligible, the system will, after an item is checked 
 in, check to see if a portion of this item quantity should be routed to 
 a QC location. </p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">In Work Order Processing...</h5>
        <p data-source-node="n67">You can use this checkbox to indicate that this work order line qualifies for 
 a quantity increase (over allocation) during work creation for work orders. 
 You can define this over allocation on a work order's bill of materials 
 detail record or on the work order line itself.</p>
