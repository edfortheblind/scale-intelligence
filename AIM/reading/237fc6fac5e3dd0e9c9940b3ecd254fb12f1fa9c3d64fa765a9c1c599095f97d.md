
        
        <h1 data-source-node="n56"><a name="kanchor2058" data-source-node="n57"></a>Using Warehouse Mobile </h1>
        <p data-source-node="n58">Warehouse mobile is modern native android application that can be used to execute the RF functions of today. The application’s layout and screen flow are driven by JSON files. This allows for easy customization of the application. See the SDK for further information on the architecture of these files. Warehouse Mobile is the modernized app for Android devices, which will eventually replace the RF functionality of today.</p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Pre-requisites</h4>
        <ul data-source-node="n61">
            <li data-source-node="n62">The mobile device should be connected to the network.</li>
            <li data-source-node="n63">Manhattan SCALE should be configured on the application server.</li>
        </ul>
