
        
        <h1 data-source-node="n56"><a name="kanchor66" data-source-node="n57"></a>Change Allowed Field</h1>
        <p data-source-node="n58">This field indicates if a record can be changed.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The valid values are:</p>
        <ul data-source-node="n61">
            <li data-source-node="n62">Y - This record can be changed.<br data-source-node="n63"><br data-source-node="n64"></li>
            <li data-source-node="n65">N - This record cannot be changed.</li>
        </ul>
