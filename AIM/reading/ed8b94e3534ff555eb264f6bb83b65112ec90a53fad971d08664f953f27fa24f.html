Researching Outbound Statistics

The Outbound Statistics screen in Trading Partner Management allows you to view shipment statistical data that was generated by ILS's web statistics module. The system can output this statistical information in several formats, such as HTML, XML, or text.

 

 

Procedures...

 

Log into TPM. Choose the Outbound Statistics option from the Trading Partner Management Main Menu. The system will display the Outbound Statistics screen.

  1. Enter filter data in either of the first two sections: Search Criteria and Results Criteria. You can use the % sign as a wildcard character, similar to other system searches. Note that the actual fields displayed on this window vary depending on a company's Web Screen Data settings.
     
  2. Choose an "order by" criteria value to indicate how you want the system to organize your inquiry's results. This is an optional step.
     
  3. Choose a "view by" criteria value to indicate how you want the system to summarize your inquiry's results (this is an optional step):

    - Day: Choose if you want the system to list each statistic record by day.

    - Month: Choose if you want the system to list each statistic record by month.

    - Fiscal Period: Choose if you want the system to list each statistic record by fiscal period. These periods are defined on the Fiscal Calendar Window.
     
  4. Choose an output format that you want the system to display your inquiry's results:

    - HTML: Choose if you want the system to display your inquiry results as an HTML web page.

    - Text: Choose if you want the system to display your inquiry results as a text document.

    - XML: Choose if you want the system to display your inquiry results formatted as XML code.
     
  5. Press the Search Button. The system will display your inquiry's results in a separate browser window.
