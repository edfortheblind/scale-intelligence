Reference Fields 1-20

On the Interface Error Insight Screen / Interface Validation Warehouse Alerts...  

These fields represent the user-defined values that the system populates from the original interface data file (post-XML transformation). After the download interface encounters an error, the system writes these values to the INTERFACE_ERROR database table. These reference field values are available for viewing on the Interface Error Insight Screen and interface validation warehouse alert emails. You can define these reference values (per download interface process) in the Interface Error Reference configuration windows. Note that the system is shipped with default values for the first ten reference fields for each download interface process. You can choose to leave these values defined as they are, or change them to represent different values.
