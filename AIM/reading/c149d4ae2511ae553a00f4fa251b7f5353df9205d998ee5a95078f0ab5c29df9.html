Defining Intermediate Consignees

The general purpose of this window is to define to the application a secondary delivery destination, such as a port or a hub. These records are also used when you are processing shipments that use the UPS World Ease carrier service. When UPS authorizes someone to use the World Ease service, it sends them a list of the international hubs that it offers, and the postal code ranges that each hub supports. You will need to define each hub in SCALE as an intermediate consignee.

Procedures...

 

Access the Intermediate Consignee Window. Create a new record.

  1. Use the Account Number Field to identify the secondary delivery destination (intermediate consignee) to the carrier.

    UPS World Ease Note: If you are using this record with the World Ease service, this value will be represented by a ten-digit code supplied by UPS. This code represents a hub's address and the postal code range that the hub supports. During the manifesting process, SCALE will send this value to UPS so it can assign a group. Note that these records are required when using the World Ease Service.
     
  2. Provide your consignee's address and contact information.  
     
  3. Press OK. The system will save the record.
