Upload Output Field

Determines what method your warehouse uses to upload data from the system to the ERP.

 

 

Interface Tables

If you select this option, the system will upload the data in a "raw" data format, destined for placement in database tables.

 

Delimited File

If you select this option, the system will upload the data in a text file format, destined for placement in a file directory.

 

Fixed Length

If you select this option, the system will upload the data in a text file format, destined for placement in a file directory. (This mode is similar to Delimited Mode, except that all the values must have a specific length, which is defined on the interface data map record).

 

XML

If you select this option, the system will upload the data in an XML file format, destined for placement in a file directory.
