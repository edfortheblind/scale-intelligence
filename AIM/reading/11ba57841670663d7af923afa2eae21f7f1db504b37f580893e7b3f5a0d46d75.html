Dashboard System Values

These parameters manage the dashboard parameters for your warehouse.

 

The dashboard refresh rate system value sets the rate in minutes for each of the dashboard sections (e.g., Inbound Today, Tomorrow, Week, Receipts by Time, Dock to Stock, etc.). Loading or reloading the warehouse dashboard will update the dashboard data if the time that has passed since the last update is more than the refresh rate (also called the expiration time).
