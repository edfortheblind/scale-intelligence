Net Cost Buttons

You will use these buttons to identify if an item is subject to a regional value content requirement. This information is required for international documentation and it prints on the NAFTA Certificate of Origin document. The valid values for this field are outlined below:

 

 

None

 

0

 

C-RVC

 

1 - This product is subject to a regional value content requirement. That value is calculated based on the net cost of the product.

 

N-RVC

 

2 - This product is NOT subject to a regional value content requirement.
