
        
        <h1 data-source-node="n56">Reviewing Detail Data Source Values</h1>
        <p data-source-node="n57">Detail data source values indicate which database table is tied to a 
 particular document filter window. You can choose to change these associations, 
 or simply keep the system default settings. Each detail data source corresponds 
 to a document filter, and tells the system from which table a document 
 type will get its detail lines. You can then create document filters to 
 determine what lines you want to appear on individual documents, and how 
 you want them sorted. </p>

        <h4 data-source-node="n90">Procedures...</h4>
        <h5 style="font-weight: normal" data-source-node="n91">Access the Detail Data Source Window from the Configurations Explorer. 
 Open an existing record.</h5>
        <ol class="ol_1" data-source-node="n92">
            <li value="1" data-source-node="n93">Use the Identifier 
 and Description Fields to view the name of the detail data source 
 record.<br data-source-node="n94"> </li>
            <li value="2" data-source-node="n95">Use the Document 
 Criteria Record Type Field to choose the database table that is 
 associated with a particular document filter.<br data-source-node="n96"> </li>
            <li value="3" data-source-node="n97">Press OK 
 when finished.</li>
