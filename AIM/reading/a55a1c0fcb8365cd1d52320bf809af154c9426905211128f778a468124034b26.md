
        
        <h1 data-source-node="n56">Reviewing Carrier EDI Reference Records</h1>
        <p data-source-node="n57">Carrier EDI reference records define what type of data you want SCALE 
 to send to your transportation system during the manifesting process. 
 These values help support customer-level EDI manifesting in the application. Note that while you can change the "value" field of existing reference records, you cannot create or delete these records. You can access the Carrier EDI Reference Window from either 
 the Configurations Explorer or from the "Actions" menu on the 
 Customer Window.</p>
