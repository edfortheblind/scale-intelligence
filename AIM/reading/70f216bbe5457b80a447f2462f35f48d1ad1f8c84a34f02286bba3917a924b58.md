
        
        <h1 data-source-node="n56"><a name="kanchor163" data-source-node="n57"></a>Auto Print Documents Checkbox</h1>
        <p data-source-node="n58">This checkbox appears on the Work Creation Master Window. If its selected, 
 the system will automatically print pick lists during work creation.</p>
        <p data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60"><b data-source-node="n61">NOTE:</b> If you select this checkbox   <span class="span_1" data-source-node="n62">and</span> the pick list document type 
 is defined in a document master record, the system might generate the 
 pick lists twice: first after work creation runs and second after paperwork 
 runs. This will give you two sets of pick lists generated during one wave 
 cycle.</p>
