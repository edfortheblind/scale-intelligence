Creating Volume Units of Measure

The system supports any unit of measure that your company uses to identify volume units of measure. The system will use these to measure such things as containers, items, and locations. Note that the system is shipped with the most common default values which should meet your business needs.

Procedures...

Access the Volume Units of Measure Window. Create a new record.

  1. Use the Identifier and Description Fields to define the name and abbreviation for a volume unit of measure. The system will use the value you enter in the description to fill the volume unit of measure fields throughout the system.

     

  2. Press OK. The system will save your record.
