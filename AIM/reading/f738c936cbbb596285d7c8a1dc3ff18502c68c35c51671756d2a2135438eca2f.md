
        
        <h1 data-source-node="n56"><a name="kanchor607" data-source-node="n57"></a>Using the Metadata Screen Group Type Window</h1>
        <p data-source-node="n58">The Metadata Screen Group Type Window defines the screen metadata that indicates the type of User Interface (UI) element that the system will use to build the screen group.  Screen groups are typically placed on screen parts to partition the data in logical groups.  These groups host screen controls.</p>
        <p data-source-node="n59"> </p>

        </p>
