
        
        <h1 data-source-node="n56"><a name="kanchor409" data-source-node="n57"></a>Parent Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates if this record is 
 a parent record. A parent record can share values with its child records. If this checkbox 
 contains a value, this record can share its values with its child 
 records. If this checkbox 
 does not contain a value, this record is not a parent record. It 
 cannot share values with other records.</p>
