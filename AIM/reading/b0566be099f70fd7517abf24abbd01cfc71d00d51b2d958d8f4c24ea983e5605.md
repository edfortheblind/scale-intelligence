
        
        <h1 data-source-node="n56"><a name="kanchor980" data-source-node="n57"></a>Document Criteria Field</h1>
        <p data-source-node="n58">This field indicates the document filter that you want to assign  to 
 a document. When the system generates a particular paperwork document, 
 it will use this filter record to display the detail record values on 
 the document. Choose no value in this field if you want the system to 
 use the default layout for a document.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">- Note that you can only enter a value in this field when its corresponding document type has a value in its detail data source field.  In addition, that detail data source must have a record corresponding to that source type in the Document Criteria Window (such as shipment allocation document criteria or work instruction document criteria).  One other note is that there is special logic in SCALE to support document criteria, and that logic does not exist for all documents/labels.  Therefore, when modifying a system supplied document type, it is not valid to change the detail data source setting that is shipped with the system.  Additionally, when creating custom document types, you must make sure that document criteria logic exists if you wish to configure your document type with detail data source and your document with document criteria.</p>
