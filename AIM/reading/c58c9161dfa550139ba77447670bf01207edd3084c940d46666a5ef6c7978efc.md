
        
        <h1 data-source-node="n56"><a name="kanchor465" data-source-node="n57"></a>Defining Receipt ID Types</h1>
        <p data-source-node="n58">A receipt ID type indicates what type of number is used as a receipt's 
 ID. Common receipt ID types include PO number and manufacturer number. 
 You will want to define valid receipt ID types in the system if you plan 
 on allowing users to add receipts on the Receipt Workbench or the Receipt 
 Insight screen.</p>
