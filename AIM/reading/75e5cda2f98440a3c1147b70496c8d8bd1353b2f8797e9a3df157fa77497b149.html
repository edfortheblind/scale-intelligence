Labor Group

This configuration allows you to define the types of labor performed within your warehouse. SCALE uses these labor group records to capture information about full-time and temporary employees, as well as typical unit quantities picked based on time factors. This data helps estimate the time required for workers in each labor group to complete their picking tasks during a wave.

 

Labor groups are essential for labor planning and monitoring. Planning can be configured at both shipment and work levels, while monitoring happens at the work level only. Depending on your needs, only one labor group needs to be set up for shipment-based planning, work-based planning, and work-based monitoring.

 

Important: To prevent duplication, SCALE does not allow a single work type to be assigned to multiple labor groups. If a work type is reassigned from one labor group to another, the system will automatically update the records.

 

Add New Labor Group

For adding a new labor group, enter the following.

 

Labor Group General

  • Labor Group - Provide a name for this labor group.

     

  • Activity Heel to Toe Tolerance (minutes) - Specify the allowable time variance. Read Heel To Toe.

     

  • Expected Throughput (Units/Hour) - Enter the expected number of units processed per hour.

 

Resource Information

  • Number of Full-Time Employees: Total full-time workers assigned to this labor group.

     

  • Hours Per Full-Time Employee: Daily work hours per full-time employee (excluding breaks).

     

  • Number of Part-Time Employees: Total temporary (part-time) workers assigned.

     

  • Hours Per Part-Time Employee: Daily work hours per part-time employee (excluding breaks).

 

Estimation Information

 

Estimated Time Per Transaction - Define the average time required to process the specified quantity of products.

 

Calculate Time Based On - identify how the system will calculate labor time:

 

  • Unit of Measure: Time is based on the number of UM picked, assuming consistent time per unit (e.g., processing 1 or 30 units takes proportional time).

  • Quantity: Time is calculated based on the quantity within the UM, accounting for variable processing times per quantity.

  • Quantity Unit of Measure - Select the units of measure that are processed under this labor group. For example, if a worker in this group typically picks only cases, you can indicate that here. Also, note that you do not have to specify any units of measure. If none are selected, then all units of measure can be processed. If you set this to more than one unit of measure, the system doesn't sum across the units of measure when applying the time value. For example, if you have the time set to 5 minutes and CS and EA values selected here, it just means it takes 5 minutes to process the CS and 5 minutes to process the EA. It doesn't mean it takes 5 minutes to process CS and EA at the same time.

Planning and Monitoring

Enables you to define the labor group planning at both the shipment and work levels. The labor group monitoring is defined by work type.

  • Shipment Labor Planning Criteria - Assign criteria that determine which work or shipments the labor group will handle. This helps estimate processing time before wave execution. If work creation fails, SCALE reverts to this planning method. Note that shipment-level planning is only for estimation, without monitoring capability.

  • Planning and Monitoring from Work - Select work type(s) to be monitored for this labor group. This enables both planning and real-time monitoring of work progress by tracking creation and completion of work tasks.
