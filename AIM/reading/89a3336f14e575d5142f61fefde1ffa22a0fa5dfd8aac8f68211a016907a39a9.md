
        
        <h1 data-source-node="n56"><a name="kanchor1733" data-source-node="n57"></a>Use Cross Dock LP ID From Receiving Checkbox</h1>
        <p data-source-node="n58">This field  indicates whether you want the system to use the license plate from receiving as the container ID when creating a new shipping container on the shipping dock. If this setting is not selected, then the user will have to manually enter a container ID in this situation. Note that you can only select this setting if you have also selected the Putaway Into Shipping Container option.</p>
