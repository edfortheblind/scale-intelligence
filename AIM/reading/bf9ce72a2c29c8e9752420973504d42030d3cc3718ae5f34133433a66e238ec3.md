        <h4 data-source-node="n214"><a name="Searching" data-source-node="n215"></a>Searching/Viewing Work Order Records...</h4>
        <p data-source-node="n216">You can use the Work Order Insight Screen to search for and view work order records in your warehouse. </p>
        <ol data-source-node="n217">
            <li value="1" data-source-node="n218">Open the Work Order Insight Screen.<br data-source-node="n219"><br data-source-node="n220"></li>
            <li value="2" data-source-node="n221">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n222"><br data-source-node="n223"></li>
            <li value="3" data-source-node="n224">Press the Search Button. The system will display  the resulting records in the List Pane. <br data-source-node="n225"><br data-source-node="n226"></li>
            <li value="4" data-source-node="n227">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>

        <h4 data-source-node="n284"><a name="AboutDPane" data-source-node="n285"></a>About the Detail Pane...</h4>
        <p data-source-node="n286">The Work Order Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.<br data-source-node="n287"><br data-source-node="n288"></p>
        <p data-source-node="n289">The Detail Pane of Work Order Insight contains Indicator Tiles with counts of the other entities (i.e. work order lines, open work, and transactions).  If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following: </p>
        <ol data-source-node="n290">
            <li value="1" data-source-node="n291">Lines<ol data-source-node="n292"><li value="1" data-source-node="n293">Displays the number of work order lines linked to the work order. </li><li value="2" data-source-node="n294"><p data-source-node="n295">Clicking on this tile takes you to Work Order Line Insight screen filtering on the given work order number.<br data-source-node="n296"><br data-source-node="n297"></p></li></ol></li>
            <li value="2" data-source-node="n298">Open Work<ol data-source-node="n299"><li value="1" data-source-node="n300"><p data-source-node="n301">Clicking on this tile takes you to Work Insight filtering on the given work order number. </p></li></ol><p data-source-node="n302"> </p><li data-source-node="n303"><p data-source-node="n304">Transactions</p><ol data-source-node="n305"><li value="1" data-source-node="n306"><p data-source-node="n307">Displays the transaction history of the work order. </p></li><li value="2" data-source-node="n308"><p data-source-node="n309">Clicking on this tile takes you to Transaction History Insight filtering on the Work Order ID. </p><p data-source-node="n310"> </p></li></ol></li><li data-source-node="n311"><p data-source-node="n312">License Plates</p><ol         <h4 data-source-node="n344"><a name="ScreenActions" data-source-node="n345"></a>Screen Actions</h4>
        <p data-source-node="n346">The following actions are accessible from the List Pane:</p>
        <p data-source-node="n347"> </p>
        <h5 data-source-node="n348">New</h5>
        <p data-source-node="n349">This action allows to create a new work order. Clicking on the New action will open the Work Order screen in New mode. </p>
        <p data-source-node="n350"> </p>
        <p data-source-node="n351"> </p>
        <h5 data-source-node="n352">View/Edit</h5>
        <p data-source-node="n353">The View action allows you to open the Work Order Insight screen in the read-only mode and the Edit action allows you to open the Work Order Insight screen in the edit mode. So the View action only permits viewing the work order, while the Edit action permits editing certain fields on the work order. </p>
        <p data-source-node="n354"> </p>
        <p data-source-node="n355"> </p>
        <h5 data-source-node="n356">Delete</h5>
        <p data-source-node="n357">The action allows to delete one or more work orders. The system will prompt for a confirmation message after the delete action is performed. </p>
        <p data-source-node="n358"> </p>
        <p data-source-node="n359"> </p>
        <h5 data-source-node="n360">New Line</h5>
        <p data-source-node="n361">The action helps you to open the Work order Line screen in New mode.</p>
        <p data-source-node="n362"> </p>
        <p data-source-node="n363"> </p>
        <h5 data-source-node="n364">Allocate All</h5>
        <p data-source-node="n365">This action allows you to allocate all the components of a work order. The action is enabled on selecting a work order which has one or more lines/components that are not been allocated. Selecting a work order and invoking Allocate All action will allocate all the work order lines. Refer to <a href="b75404b61b104df6589e751092faac3526252b9fd8b616e130e6f5509dcc6eb4.html" data-source-node="n366">Processing Work Orders</a> for more information. </p>
        <p data-source-node="n367"> </p>
        <p data-source-node="n368"> </p>
        <h5 data-source-node="n369">Deallocate All</h5>
        <p data-source-node="n370">This action allows you to deallocate all the components of a work order. The action is enabled on selecting a work order which has line(s) that are allocated. Invoking the action by selecting a work order will deallocate all the lines. Refer to <a href="b75404b61b104df6589e751092faac3526252b9fd8b616e130e6f5509dcc6eb4.html" data-source-node="n371">Processing Work Orders</a> for more information. </p>
        <p data-source-node="n372"> </p>
        <p data-source-node="n373"> </p>
        <h5 data-source-node="n374">Close</h5>
        <p data-source-node="n375">This action allows to manually close one or more work orders. The system will prompt for a confirmation message and closing a work order with all allocation and component work completed will return a success message. This action is disabled when one or more selected work order(s) is already closed. </p>
        <p data-source-node="n376"> </p>
        <p data-source-node="n377"> </p>
        <h5 data-source-node="n378">Confirm</h5>
        <p data-source-node="n379">This action allows you to confirm a work order to identify the finished item as complete. Confirming a work order creates the finished item with the default inventory status from the assembler's work order preference. It does not create work when the "Create work" flag is unchecked on the assembler's work order preference. For more information on this topic, refer to the topic <a href="b75404b61b104df6589e751092faac3526252b9fd8b616e130e6f5509dcc6eb4.html" data-source-node="n380">Processing Work Orders</a>.</p>
        <p data-source-node="n381"> </p>
        <p data-source-node="n382"> </p>
        <h5 data-source-node="n383">Immediate Needs</h5>
        <p data-source-node="n384">This action enables you to open the Immediate Needs Insight screen with Work Order ID and warehouse filled in the Filter Pane and the search results would be displayed at the same time. Refer to <a href="eafa00a7ab4b49f033eb0270ab3275d5f2f64395fa9d56b4941215fb2a4a33cc.html" data-source-node="n385">Immediate Needs Note Field</a> for information on Immediate Needs icon colors. </p>
        <p data-source-node="n386"> </p>
        <p data-source-node="n387"> </p>
        <h5 data-source-node="n388">Print Preview</h5>
        <p data-source-node="n389">This action allows you to generate and display a PDF version of the selected document type.  For more information on this topic, refer to <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n390">Printing Paperwork</a>. </p>
        <p data-source-node="n391"> </p>
        <p data-source-node="n392"> </p>
        <h5 data-source-node="n393">Print Default Docs</h5>
        <p data-source-node="n394">This action helps you to  print the work order documents (Work Order Assembly Instructions and Work Order Component Pick List) which are marked as default in the Document type. </p>
        <p data-source-node="n395"> </p>
        <p data-source-node="n396"> </p>
        <h5 data-source-node="n397">Print Selected Docs</h5>
        <p data-source-node="n398">This action allows you to select or unselect the work order documents you want to print.  The documents will be selected when the work order is checked as a default print procedure on the document type configuration. </p>
        <p data-source-node="n399"> </p>
        <p data-source-node="n400"> </p>
        <h5 data-source-node="n401">Release</h5>
        <p data-source-node="n402">This action enables you to release the work order.  This allows confirming the component item work and confirm the finished item. Refer to the topic <a href="b75404b61b104df6589e751092faac3526252b9fd8b616e130e6f5509dcc6eb4.html" data-source-node="n403">Processing Work Orders</a> for additional information on releasing work orders. </p>
