
        
        <h1 data-source-node="n56"><a name="kanchor1382" data-source-node="n57"></a>Requiring Location Validations</h1>
        <p data-source-node="n58">Each time an employee attempts to enter a location on any processing 
 window, the system will reference the "Should location be validated 
 throughout system" setting found in the Inventory Control Values 
 Window:</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">If you set this 
 flag to N, the system will create locations automatically as the 
 user identifies them through processing. The system will not validate 
 these locations.</li>
            <ol class="ol_1" data-source-node="n61">
                <p data-source-node="n62"> </p>
            </ol>
            <li data-source-node="n63">If you set this 
 flag to Y, the system will require users to create locations on 
 the Location Window. It will catch any misspellings or typos when a user 
 attempts to access the location on other window.</li>
        </ul>
