
        
        <h1 data-source-node="n56"><a name="kanchor243" data-source-node="n57"></a>Removing Container Groups (RF)</h1>
        <p data-source-node="n58">The RF Remove Container Group Screen allows the user to manually ungroup a single container from a picking group. Note that the user can also remove all the containers that are part of the group at one time. When a container is removed from a group, the system deletes the group ID and spot value from the shipping container (and its related work), and logs process history representing this removal. Keep in mind that in order to ungroup container(s) from a picking group, the work has to be open, assigned a group ID, and not currently assigned to user.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">An example of when a user may want to manually remove a container from a group is outlined in the scenario below:</p>
        <blockquote data-source-node="n61">
            <p data-source-node="n62">Suppose you have 5 shipments with a single container each ( 4-5 items in each container).  All the containers contain some slow-moving items that are located in Zone C (slow-moving inventory) along with items in Zone A (fast-movers that are part of a conveyor picking system).  So, the user would add these containers to a cart as he assigned them to a picking group. Then, the user would first execute the picks for the Zone C (slow-moving) items.  Then, they would put the containers on the conveyor for the other pickers to do the Zone A (fast-moving items) work.  Now, when the Zone A worker scans one of the containers to do the fast-moving items work, the system would display all the picks for all the containers (because they are still part of the group's single work unit).
What the user should have done in this situation is manually remove the containers from the picking group after the slow-moving work has been performed. This can be done in two ways: automatically (upon passing the grouped work the system can automatically remove the containers from the group, depending on the Container Group Removal When Group Work Is Passed? work system value setting), or manually via the RF Remove Container Group screen.</p>
        </blockquote>

        <h4 data-source-node="n94"><a name="removeSingle" data-source-node="n95"></a>Removing a Single Container from a Picking Group...</h4>
        <ol data-source-node="n96">
            <li value="1" data-source-node="n97">Log onto your RF device, and select the Remove Container Group option.<br data-source-node="n98"><br data-source-node="n99"></li>
            <li value="2" data-source-node="n100">Enter the container ID of the container that you want to remove from the picking group.<br data-source-node="n101"><br data-source-node="n102"></li>
            <li value="3" data-source-node="n103">Press the Remove Button. The system will remove the container from the group, and display a success message at the bottom of the screen.</li>
        </ol>
        <p data-source-node="n104"> </p>

        <h4 data-source-node="n107">Removing All Containers from a Picking Group...</h4>
        <ol data-source-node="n108">
            <li value="1" data-source-node="n109">Log onto your RF device, and select the Remove Container Group option.<br data-source-node="n110"><br data-source-node="n111"></li>
            <li value="2" data-source-node="n112">Enter the container ID from one of the containers that you want to remove from the picking group.<br data-source-node="n113"><br data-source-node="n114"></li>
            <li value="3" data-source-node="n115">Press the Remove All Button. The system will display a confirmation message:<br data-source-node="n116"><br data-source-node="n117">- Press OK to indicate that you want to remove ALL of the containers from the group that the container (that was entered in step 2) is associated with. After you press this button, the system will remove the containers, and display a success message at the bottom of the screen.<br data-source-node="n118"><br data-source-node="n119">- Press Cancel to  return to the RF Remove Container Group Screen without removing the containers from the group.<br data-source-node="n120"><br data-source-node="n121"></li>
        </ol>
