
        
        <h1 data-source-node="n57"><a name="kanchor1323" data-source-node="n58"></a>Changing RF Text Font Properties</h1>
        <p data-source-node="n59">If desired, you can change the properties (size, display font) of certain texts displayed on the RF device. The shipped defaults for RF text are Arial 9 pt. Note that these font property changes are made per language, not per user or environment. Also, you will need to run an IISRESET or reboot your RF servers in order to view the new font properties.</p>

        <h4 data-source-node="n97">Procedures...</h4>
        <ol data-source-node="n98">
            <li value="1" data-source-node="n99">Access the System Text Editor Window.<br data-source-node="n100"><br data-source-node="n101"></li>
            <li value="2" data-source-node="n102">In the Key Field, enter the following string: RF_STD and press the Search Button. The system will display a series of records related to the RF screen display.<br data-source-node="n103"><br data-source-node="n104"></li>
            <li value="3" data-source-node="n105">To change the RF display font, change the RF_STDFONT custom value to the desired font.<br data-source-node="n106"><br data-source-node="n107">To change the RF font size, change the RF_STDFONTSIZE custom value to the desired font size.<br data-source-node="n108"><br data-source-node="n109"></li>
            <li value="4" data-source-node="n110">Press the Close Button. You will need to reboot your RF server and restart the application to view your new font display properties.</li>
        </ol>
