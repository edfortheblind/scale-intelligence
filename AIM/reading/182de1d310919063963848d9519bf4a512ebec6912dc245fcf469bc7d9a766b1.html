Full Container Quantity / Full Container Quantity UM Fields

This field indicates the item quantity that is necessary for the system to consider it full. The system will allocate this quantity into the unit of measure that you provide.

 

For example, suppose the following:

  • A shipment line is interfaced for 20 EA of item AA001.

  • You put "5" in the Full Container Quantity Field, and "CS" in the Full Container Quantity UM Field. This means you want the system to bundle 5 EA of the item into a case, and to consider that case full.

  • When allocating, the system creates 4 CS, each including 5 EA apiece.

 

Keep In Mind...
  • The intended purpose of this field is for warehouses that do not have item unit of measure records defined for their inventory.
     
  • This quantity/UM combination will override any unit of measure settings previously defined for this item.
     
  • These fields are only used for non-inventory tracked items.

  • If you choose to have the system allocate using this quantity/UM combination, then this is a one-time change for this particular detail. It will not affect how the system processes future shipments of this product.
     
  • Note that if you enter a quantity that will not break out into an even number of containers, the system will create bad data when allocating. For example, in the situation described above, if you entered "7" as the Full Container Quantity, the system would try to allocate cases that have 2.8571 EA in them. Since one cannot pick 2.8571 of an item, inaccurate data will exist for this detail.
