
        
        <h1 data-source-node="n56"><a name="kanchor1452" data-source-node="n57"></a>Upload Criteria Field</h1>
        <p data-source-node="n58">This field can be used to filter the  below records to be uploaded for the upload process detail. Different filter criteria can be set for each process detail.  The system will place the records in the upload directory defined on the interface process detail.  If the process detail’s directory is blank, then the upload directory of the interface system value  will be used.</p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Active Scale users note: </h4>
        <ul data-source-node="n61">
            <li data-source-node="n62">The upload configuration is available for <b data-source-node="n63">Lower</b> and <b data-source-node="n64">Production</b> level users only.</li>
            <li data-source-node="n65">Lower level users<ul data-source-node="n66"><li data-source-node="n67">All editable fields will be enabled</li><li data-source-node="n68">Can Create, Delete, Copy criteria records</li></ul></li>
            <li data-source-node="n69">Production level users<ul data-source-node="n70"><li data-source-node="n71">Can view all editable fields. No permission for editing</li><li data-source-node="n72">Can select and copy text values</li><li data-source-node="n73">Cannot Create, Delete, Copy criteria records.</li></ul></li>
        </ul>
        <p data-source-node="n74"> </p>
        <h5 data-source-node="n75">Shipping Upload Criteria</h5>
        <p data-source-node="n76"> </p>
        <ul data-source-node="n77">
            <li data-source-node="n78">Records to be uploaded can be filtered using the shipment header fields.<br data-source-node="n79"><br data-source-node="n80"></li>
            <li data-source-node="n81">Shipping uploads are conditional on the “Include in interface upload” value configurable for each status on the Outbound functional area status flow.<br data-source-node="n82"><br data-source-node="n83"></li>
            <li data-source-node="n84">Note that the system will upload the shipment data using these records only as the shipment's status changes from one value to the next.  The upload will not happen on the initial download of the shipment (regardless of whether that status has been configured for upload).<br data-source-node="n85"><br data-source-node="n86"></li>
        </ul>
        <h5 data-source-node="n87">Receiving Upload Criteria</h5>
        <p data-source-node="n88"> </p>
        <ul data-source-node="n89">
            <li data-source-node="n90">Records to be uploaded can be filtered using the receipt header fields.<br data-source-node="n91"><br data-source-node="n92"></li>
            <li data-source-node="n93">Receiving uploads are conditional on the “Receipt upload level” and “Upload receipt containers at this status or higher” interface system values.<br data-source-node="n94"><br data-source-node="n95"></li>
        </ul>
        <h5 data-source-node="n96">Inventory Transaction Upload Criteria</h5>
        <p data-source-node="n97"> </p>
        <ul data-source-node="n98">
            <li data-source-node="n99">Records to be uploaded can be filtered using the transaction history and transaction history attributes fields.<br data-source-node="n100"><br data-source-node="n101"></li>
            <li data-source-node="n102">Inventory transaction uploads are conditional on the “Include in interface upload” value configurable on the history transaction and adjustment types.<br data-source-node="n103"><br data-source-node="n104"></li>
        </ul>
        <h5 data-source-node="n105">Item Balance Upload Criteria</h5>
        <p data-source-node="n106"> </p>
        <ul data-source-node="n107">
            <li data-source-node="n108">Records to be uploaded can be filtered using the location, location inventory, and location inventory attributes fields.<br data-source-node="n109"><br data-source-node="n110"></li>
            <li data-source-node="n111">Item balance uploads are conditional on the “Include In Item Balance Upload” value configurable on the location class.<br data-source-node="n112"><br data-source-node="n113"></li>
        </ul>
