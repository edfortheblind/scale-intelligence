
        
        <h1 data-source-node="n57"><a name="kanchor983" data-source-node="n58"></a>Maximum Pickup Quantity Field</h1>
        <p class="p_1" data-source-node="n59">This checkbox indicates the maximum amount 
 of product the system will allow a user to process. If the work instruction 
 requires more than the value defined here, the system will ask the user 
 to pick this amount as many times as required to fulfill the work instruction. 
 If a user picks less than the maximum 
 pickup quantity, a partial pick will occur. However, in this case, the 
 system will move to the next work instruction (it will not cycle through 
 the current work instruction).</p>
