Container Contents Label

A container contents label identifies the items packed into a specific container. This label also includes such data as the item location, quantity, and basic shipment information. Container contents labels can be automatically printed during the container creation wave step. You can also manually print this label in the Shipping Container Insight (once the container has been packed).

 

 

Container Contents Label Schema

This file provides the structure of how SCALE generates and prints a container contents label. Please see the template "ContainerContents.lbl" (in the Printing directory on the application server) for an example of this schema in action.
