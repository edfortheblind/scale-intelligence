
        
        <h1 data-source-node="n56"><a name="kanchor932" data-source-node="n57"></a>User Defined Fields</h1>
        <p data-source-node="n58">The majority of configuration windows and data record windows (shipment, receipt line, etc.) include eight configurable, user 
 defined fields:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60"><i data-source-node="n61">User Defined Fields 1-6</i> are alpha-numeric, with a maximum length of 25 characters.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64"> <i data-source-node="n65">User Defined Fields 7-8</i> are numeric, with a maximum length of 19,5 characters.</li>
        </ul>
        <p class="p_1" data-source-node="n66">You can use these fields to identify and track custom data fields that are included in the base system</p>
        <p class="p_1" data-source-node="n67"> </p>
        <p class="p_1" data-source-node="n68"> </p>
        <h5 data-source-node="n69">On Shipment Records...</h5>
        <p class="p_1" data-source-node="n70">In addition to the eight User Defined fields described above, there are an additional twelve fields available on a shipment record:</p>
        <ul data-source-node="n71">
            <li data-source-node="n72"><i data-source-node="n73">User Defined Fields 9-10</i> are numeric, with a maximum length of 19,5.<br data-source-node="n74"><br data-source-node="n75"></li>
            <li data-source-node="n76"><i data-source-node="n77">User Defined Fields 11-12</i> are alphanumeric, with a maximum length of 250 characters.<br data-source-node="n78"><br data-source-node="n79"></li>
            <li data-source-node="n80"> <i data-source-node="n81">User Defined Fields 13-16</i> are alphanumeric, with a maximum length of 100 characters.<br data-source-node="n82"><br data-source-node="n83"></li>
            <li data-source-node="n84"><i data-source-node="n85">User Defined Fields 17-20</i> are date/time fields.</li>
        </ul>
        <p class="p_1" data-source-node="n86">Note that you can only view these additional fields via the Shipment Insight Screen.</p>
        <p class="p_1" data-source-node="n87"> </p>
        <p class="p_1" data-source-node="n88"> </p>
        <h5 data-source-node="n89">On the Routing Guide Window...</h5>
        <p class="p_1" data-source-node="n90">On a routing guide record, these fields represent the user defined fields on the shipment.</p>
