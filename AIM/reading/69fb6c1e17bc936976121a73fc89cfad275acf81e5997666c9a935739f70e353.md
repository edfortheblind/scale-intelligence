
        
        <h1 data-source-node="n56"><a name="kanchor1048" data-source-node="n57"></a>Manually Interfacing Data</h1>
        <p data-source-node="n58">You can manually interface data between SCALE and your ERP as your business 
 needs require. SCALE supports both the downloading of data from your order 
 system, and the uploading of SCALE data to your ERP.</p>

        <h4 data-source-node="n85">Procedures...</h4>
        <ol class="ol_1" data-source-node="n86">
            <li value="1" data-source-node="n87">Use the Process 
 Buttons to identify in which direction you want the system to interface 
 data in:<br data-source-node="n88"><br data-source-node="n89">	To download data from the ERP, select the Download Button.<br data-source-node="n90"><br data-source-node="n91">	To upload data to the ERP, select the Upload Button.<br data-source-node="n92"> </li>
            <li value="2" data-source-node="n93">If you selected 
 the Upload Button in Step 1,  use 
 the Upload Output Buttons to identify what method the system should use 
 to transmit the data. If you transmit using a text file, select 
 "Delimited File." If you transmit directly to the database, 
 select "Interface Tables." If you transmit using XML files, 
 select "XML." <br data-source-node="n94"> </li>
            <li value="3" data-source-node="n95">Define what type of data you want to interface. 
 <br data-source-node="n96"> </li>
            <li value="4" data-source-node="n97">Press OK. 
 The system will interface the data you selected. </li>
        </ol>
