
        
        <h1 data-source-node="n56"><a name="kanchor793" data-source-node="n57"></a>Creating Store Location Assignment Records</h1>
        <p data-source-node="n58">You can use this window to assign put-to-store locations to a certain store (warehouse/company/customer/ship to combination). The system uses this record to determine which put-to-store location an allocation request's quantity should be placed. Please note that all four of the header fields (warehouse, company, customer, and ship to/store) need to exactly match on the allocation request in order for the system to use this record to process through the put-to-store location details. The system will cycle through the details (in listed priority order) until a match is found. When the match is found, the system will assign the put-to-store location to the request.  Put-to-store locations are defined on the Location Window. They are created in the same way as other locations, with the exception of using the put-to-store location class.</p>
        <p data-source-node="n59">The inventory will be transferred to the put to store location while using the using store location assignment without considering the unit of measure state and loose items available with the shipment.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">NOTE: You should configure your store location assignment records with a detail that sends items to a put-to-store location if all other details fail to be eligible for processing. For example, your last detail should have general criteria defined for it, such as warehouse = your current warehouse.</p>

        <h5 data-source-node="n119">Store Location Assignment Window...</h5>
        <p data-source-node="n120">You will use this window to associate put-to-store locations with a certain store criteria setting (as defined in the Store Location Assignment Criteria Window).</p>
        <ol data-source-node="n121">
            <li value="1" data-source-node="n122">Access the Store Location Assignment Window, and create a new record. <br data-source-node="n123"><br data-source-node="n124"></li>
            <li value="2" data-source-node="n125">Use the header fields to define the "store" for this assignment record. Note that all four header fields (warehouse, company, customer, ship to) must exactly match the allocation request for the system to use this record to determine which put-to-store location the user should putaway quantity to.<br data-source-node="n126"><br data-source-node="n127"></li>
            <li value="3" data-source-node="n128">To create assignment details, press the Add Button. The system will display a row under the field name column.<br data-source-node="n129"><br data-source-node="n130"></li>
            <li value="4" data-source-node="n131">Use the Store Location Assignment Criteria Field to indicate the criteria that you want the system to use when determining which put-to-store location to assign an item quantity.<br data-source-node="n132"><br data-source-node="n133"></li>
            <li value="5" data-source-node="n134">Use the Put-To-Store Location Field to indicate the location ID of the put-to-store location that you want to assign to this store. This class of location resides on the shipping dock, and houses product whose destination is a particular store (shipment line mark for).<br data-source-node="n135"><br data-source-node="n136"></li>
            <li value="6" data-source-node="n137">To add another detail record, press the Add Button. Otherwise, press OK, and the system will save your record.<br data-source-node="n138"></li>
        </ol>
        <p data-source-node="n139"> </p>
        <h5 data-source-node="n140">Store Location Assignment Criteria Window...</h5>
        <ul data-source-node="n141">
            <li data-source-node="n142">You will use this window to define the specific criteria that the system will use to determine which put-to-store location the allocation process will choose to putaway an item quantity to. For example, suppose you want the system to locate items that have a packing class of "perishable" to be putaway in a certain put-to-store location. You would define a criteria record that indicates that the packing class on the shipment line has to equal "perishable." Then, when the system is processing though the assignment record details for a store, it will see that "perishable" items are to be putaway at a certain put-to-store location.</li>
        </ul>
        <p data-source-node="n143">Note: If the client needs to send full cases directly to the shipping dock, we achieve this by using an override data wave step and dock assignment.  Container creation criteria is also required to only create containers for the Unit of Measure that need directed to the shipping dock.  The override data wave step would change the status flow on the container to one that redirects the container to the shipping dock.  Dock assignment would use the related dock management flow to reassign the full case container from the put to store location to the shipping dock.  Work creation is required for both shipping containers and allocation requests.</p>
