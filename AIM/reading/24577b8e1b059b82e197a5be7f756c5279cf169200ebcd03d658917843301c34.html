Work Order System Values

These parameters manage how work orders are processed in your warehouse.

 

Value Key

 
Value Description

 

10

Work Order Allocation Method: This value defines when components should be allocated for a work order. Select Allocate on Work Order Creation if you want the components allocated immediately. Select Allocate on Work Order Release if you don't need to allocate the components until the finished item can be assembled.

 

20

Should WO Be Automatically Released When Entered?: This value indicates when a work order should be released. Select Yes to release the work order automatically when it's created. Select No to release the work order manually at a later date.

 

30

Adjustment Type For Component Item Adjustment: The value you identify here is used by the system when writing transaction history records, whenever you perform an adjustment on component parts. Note that this action can also be interfaced back to the ERP, if defined to do so on the Adjustment Type Window.

 

40

Adjustment Type For Finished Item Adjustment: The value you identify here is used by the system when writing transaction history records, whenever you confirm that a finished item is complete. When you select the Confirm Action, the system first adjusts the finished item as inventory at the build location and then transfers it to its storage location. Note that this action can also be interfaced back to the ERP, if defined to do so on the Adjustment Type Window.

 

50

Adjustment Type For Finished Item Transfer: The value you identify here is used by the system when writing transaction history records, whenever you confirm that a finished item is complete. When you select the Confirm Action, the system first adjusts the finished item as inventory at the build location and then transfers it to its storage location. Note that this action can also be interfaced back to the ERP, if defined to do so on the Adjustment Type Window.
