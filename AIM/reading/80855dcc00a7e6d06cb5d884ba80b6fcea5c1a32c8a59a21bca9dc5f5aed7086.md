
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor277" data-source-node="n58"></a>Immediate Needs Trigger</h1>
        <p data-source-node="n59">These records specify whether immediate needs functionality is active in specific areas of the system. Triggers control when the system should generate an immediate needs request. There are <a href="5dc3ad182d2fa6eed29085709e0c784b0b831ddb4bf10e21616b711279fd1c2d.html#list" data-source-node="n60">four 
 places</a> where the system can trigger immediate needs requests.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">Modify the Immediate Need Trigger</p>
        <p data-source-node="n63"> </p>
        <ul data-source-node="n64">
            <li data-source-node="n65">
                <p data-source-node="n66"><b data-source-node="n67">Priority</b> - Sets the order in which immediate needs are addressed when multiple requests require the same item. For example, failed shipments can be prioritized over failed work orders.</p>
            </li>
        </ul>
        <ul data-source-node="n68">
            <li data-source-node="n69">
                <p data-source-node="n70"><b data-source-node="n71">Create Work toggle</b> button - Determines whether the system should automatically generate work to fulfill an immediate needs request triggered by this record. If left unchecked, the system will simply place the quantity at the destination location, and the transaction must be completed manually.</p>
            </li>
        </ul>
