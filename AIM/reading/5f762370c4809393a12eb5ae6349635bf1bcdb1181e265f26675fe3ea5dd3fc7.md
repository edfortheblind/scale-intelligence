
        
        <h1 data-source-node="n57"><a name="kanchor790" data-source-node="n58"></a>Create Work Checkbox</h1>
        <p data-source-node="n59">This checkbox determines if the system will generate work instructions 
 for the allocated components and located finished items. It appears on 
 the Work Order Preference Window.</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">If this checkbox is selected, 
 the system will call work creation as soon as the component is allocated 
 or the finished item is located.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li data-source-node="n64">If this checkbox 
 is not selected, the system will not create work for either allocated 
 components or located finished items. Instead, it will automatically locate 
 the quantity (either component or finished item) and put its quantity 
 as On Hand at the destination location(s). 
 Someone will need to ensure that the product is physically delivered to 
 the location(s).</li>
        </ul>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">For 
 Cycle Counting...</h5>
        <p data-source-node="n67">This checkbox indicates how the system should process cycle count plans:</p>
        <ul data-source-node="n68">
            <li data-source-node="n69">
                <p data-source-node="n70">If this checkbox is checked, 
 the system will create work for this plan.</p>
                <p data-source-node="n71"> </p>
            </li>
            <li class="li_1" data-source-node="n72">If 
 this checkbox is not checked, the system will not create work for 
 this plan. Instead, workers will execute this plan from a cycle count 
 list paperwork document.</li>
        </ul>
        <p data-source-node="n73"> </p>
        <h5 data-source-node="n74">For 
 Immediate Needs...</h5>
        <p data-source-node="n75">This checkbox indicates that the system will create work when fulfilling 
 an immediate needs request that is generated by a particular trigger. 
 If you do not select this option, the system will put the quantity on 
 hand at the destination location. You would then have to manually make 
 sure that the immediate needs transaction was actually completed.</p>
        <p data-source-node="n76"> </p>
        <p data-source-node="n77"> </p>
        <h5 data-source-node="n78">For 
 Inventory Management...</h5>
        <p data-source-node="n79">This checkbox indicates that you want the system to run the work creation 
 process for an adjustment type. You may also to select a Work 
 Creation Master that the system will use to create this work. If 
 you do not indicate a work creation master, the system will attempt to 
 use all of the configured masters (in priority order) when generating 
 work. By selecting one, you are forcing the system to use a specific master. 
 </p>
