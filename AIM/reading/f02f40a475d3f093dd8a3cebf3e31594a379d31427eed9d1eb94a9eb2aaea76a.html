Reviewing Detail Data Source Values

Detail data source values indicate which database table is tied to a particular document filter window. You can choose to change these associations, or simply keep the system default settings. Each detail data source corresponds to a document filter, and tells the system from which table a document type will get its detail lines. You can then create document filters to determine what lines you want to appear on individual documents, and how you want them sorted.

Procedures...

Access the Detail Data Source Window from the Configurations Explorer. Open an existing record.
  1. Use the Identifier and Description Fields to view the name of the detail data source record.
     
  2. Use the Document Criteria Record Type Field to choose the database table that is associated with a particular document filter.
     
  3. Press OK when finished.
