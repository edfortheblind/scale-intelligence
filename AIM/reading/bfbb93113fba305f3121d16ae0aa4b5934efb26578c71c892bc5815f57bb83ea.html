Configuring the SMTP Mail Server

You will need to configure a few technical settings in order for TPM email alerts to work with your mail server. When mail comes to a mail server, it needs to know how to deliver these messages. If your server cannot deliver message(s), the following settings will indicate to the mail server how to search for a server that does know how to deliver these messages. Some mail servers require specialized settings to work with the system. If you experience problems with email alerts after performing the following procedures, call support for further assistance. Note that the following procedures are performed outside of the SCALE application.

 

 

Procedures...

You will perform this action on the Windows Internet Information Services Manager.

  1. Access the Internet Information Services Manager on the application server (Start | Programs | Administrative Tools). The system will open the Internet Information Services Manager window.
     
  2. Locate the icon that represents your application server (in the window's left pane).
     
  3. Drill down to the "Default SMTP Server" node. Right-click this node and select Properties.
     
  4. On the Access Tab, press the Relay Button. On the ensuing screen, select the "All except the list below" button.
     
  5. Also on this window, select the " Allow all computers which successfully authenticate to relay, regardless of the list above" Check box.
     
  6. Press OK when finished, and press OK again to save your changes.
     
  7. To apply these setup settings, you will need to stop and restart the SMTP virtual server. To do this, right-click the "Default SMTP Server" node, and choose Stop and then Start.
