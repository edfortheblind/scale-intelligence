
        
        <h1 data-source-node="n56"><a name="kanchor1155" data-source-node="n57"></a>Immediate Needs Note Field</h1>
        <p data-source-node="n58">This field indicates the current fulfillment status of an immediate 
 needs request. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The Immediate Needs Note field on the List Pane Grid fields of Work Order Insight or Work Order Line Insight screen or Work Order Line Details Screen indicates the status of immediate needs (pending, being fulfilled, partially fulfilled, or fulfilled). These statuses are color coded as follows:</p>
