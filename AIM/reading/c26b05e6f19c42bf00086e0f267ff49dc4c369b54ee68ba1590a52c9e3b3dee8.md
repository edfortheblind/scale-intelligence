
        
        <h1 data-source-node="n56"><a name="kanchor1502" data-source-node="n57"></a>Reviewing Vocollect Generic Configuration Windows</h1>
        <p data-source-node="n58">SCALE has several configuration windows that are used to populate corresponding field values in the Vocollect Region Window. You typically will not need to edit or add to these values. You can access these in the Configurations Explorer in the Vocollect folder, or on the Generic Config Header Window:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">Vocollect Container Type<br data-source-node="n61"></li>
            <li data-source-node="n62">Vocollect Delivery</li>
            <li data-source-node="n63">Vocollect Functions</li>
            <li data-source-node="n64">Vocollect Go Back For Shorts</li>
            <li data-source-node="n65">Vocollect Item Reference</li>
            <li data-source-node="n66">Vocollect Pick Prompt</li>
            <li data-source-node="n67">Vocollect Print Labels</li>
            <li data-source-node="n68">Vocollect Prompts</li>
            <li data-source-node="n69">Vocollect Speak Slot Descriptions</li>
            <li data-source-node="n70">Vocollect Use Lookup Table</li>
            <li data-source-node="n71">Vocollect Yes/No Values</li>
        </ul>
