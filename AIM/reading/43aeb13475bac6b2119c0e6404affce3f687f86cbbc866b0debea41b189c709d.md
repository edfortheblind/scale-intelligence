
        
        <h1 data-source-node="n56"><a name="kanchor1886" data-source-node="n57"></a>Scheduled Ship Date Field</h1>
        <p class="p_1" data-source-node="n58">This field indicates the date that a 
 shipping load or a shipment should be ship confirmed and transported from 
 the warehouse. If a shipment is interfaced with a value in 
 this field, the system will honor it. If a value is not interfaced, the 
 system will default today's date in this field. During rating, the system 
 will calculate this value. If you change the carrier associated with 
 the shipment, the system will recalculate this value.</p>
