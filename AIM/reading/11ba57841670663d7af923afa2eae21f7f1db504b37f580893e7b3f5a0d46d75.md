
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n58">Dashboard System Values</h1>
        <p data-source-node="n59">These parameters manage the dashboard parameters for your warehouse.
</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">The dashboard refresh rate system value sets the rate in minutes for each of the dashboard sections (e.g., Inbound Today, Tomorrow, Week, Receipts by Time, Dock to Stock, etc.). Loading or reloading the warehouse dashboard will update the dashboard data if the time that has passed since the last update is more than the refresh rate (also called the expiration time).</p>
