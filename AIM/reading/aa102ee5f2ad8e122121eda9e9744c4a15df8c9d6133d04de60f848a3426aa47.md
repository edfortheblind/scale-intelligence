
        
        <h1 data-source-node="n56">Create Work Criteria Records for Components</h1>
        <p data-source-node="n57">If you want work creation to allocate components, identify how this 
 process will occur on the <a href="8305fd9aee481f63d2e049813cd1d6da7203e20f188f11ec2ec11b566a41b883.html" data-source-node="n58">Work 
 Order Component Work Criteria Window</a>.   This 
 is an optional step. If you don't use work creation, the system will generate 
 the Work Order Pick List that employees can use to deliver component items 
 from their storage locations to the build location. </p>
