
        
        <h1 data-source-node="n56"><a name="kanchor1361" data-source-node="n57"></a>Location Field</h1>
        <p data-source-node="n58">A location is the unique place in the warehouse where an item or license plate 
 can be picked, putaway, or replenished. Also, finished items (from work 
 orders) are assembled in locations called "build locations." 
 Locations are identified by location names that are defined in the Location 
 Template Window and Location Window. While locations typically are defined on the 
 Location Window, you can also create them 'on the fly' from other particular 
 system processing windows. To create locations in this manner, set the 
 Validate Location Field on the Inventory Control Values Window to 'N'. 
 If this field contains a 'Y', The system will require you to create all 
 locations only on the Location Window.</p>
        <p class="p_1" data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60"> </p>
        <h5 data-source-node="n61">On the Shipping Container Screen / Shipment Insight Screen...</h5>
        <ul data-source-node="n62">
            <li data-source-node="n63">This field indicates the physical location where the shipping container currently resides.<br data-source-node="n64"> <br data-source-node="n65"></li>
            <li data-source-node="n66">An exception to this is if the container was created during the wave, this field will represent the picking location. After shipment or dock management work putaway, the system will update this location value to represent the container's current "physical" location.<br data-source-node="n67"><br data-source-node="n68"></li>
            <li data-source-node="n69">After load confirmation, the system clears this location value.</li>
        </ul>
