
        
        <h1 data-source-node="n56"><a name="kanchor1531" data-source-node="n57"></a>Carrier Type Field</h1>
        <p data-source-node="n58">The type of carrier who will transfer your product. 
 A carrier type groups together carriers that share the same 
 basic rate structure.   All 
 carriers must be associated with a carrier type. You can set up a work creation record based 
 on carrier type. This is especially helpful if you want to process all 
 parcel carrier shipments together.</p>
