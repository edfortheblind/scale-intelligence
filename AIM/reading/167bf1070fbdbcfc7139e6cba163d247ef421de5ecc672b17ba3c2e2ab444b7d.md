        <h4 data-source-node="n70">Notes On Setup...</h4>
        <ul type="disc" class="ul_1" data-source-node="n71">
            <li data-source-node="n72">ITN (Internal 
 Transaction Number): This is given by AES after an SED is submitted 
 to them and it is unique per shipment.<br data-source-node="n73"> </li>
            <li data-source-node="n74">XTN (External 
 Transaction Number): This is an exemption number for the item given 
 by the government.<br data-source-node="n75"> </li>
            <li data-source-node="n76">Make sure all FedEx International Shipments with 
 containers are manifested/shipped prior to upgrading. All FedEx International 
 Containers should now only have a single item per container.<br data-source-node="n77"> </li>
            <li data-source-node="n78">FedEx XTN and ITN fields have been added to the 
 Item Window and the Item Download.<br data-source-node="n79"> </li>
            <li data-source-node="n80">The "SED" Accessorial Header will now 
 always apply at the container level.<br data-source-node="n81"> </li>
            <li data-source-node="n82">The SED Filing Status Accessorial has been changed 
 to default to "S". This indicates the shipper will be filing 
 the SED.<br data-source-node="n83"> </li>
            <li data-source-node="n84">Added the XTN Suffix Number Accessorial Detail 
 to all Fed Ex "SED" Accessorial headers. <br data-source-node="n85"> </li>
            <li data-source-node="n86">The XTN Suffix Number accessorial will be filled 
 when the container is manifested. This will only occur during Shipment 
 Level Manifesting for International Fed Ex containers. At the time of 
 manifesting the XTN Suffix Number will be updated only when the FTSR Exemption 
 Number is not given.<br data-source-node="n87"> </li>
            <li data-source-node="n88">The XTN Suffix Number will be filled based on 
 the values in the item configuration for the first item that was packed 
 into the container. If the item has the ITN number filled in on the item 
 configuration it will be used. Otherwise the XTN number from the item 
 configuration will be set on the accessorial tied to the container. This 
 information will then be sent to FedEx.</li>
        </ul>
