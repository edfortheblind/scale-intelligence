Progistics Bundle Document Checkbox

This checkbox indicates that this document is part of a "bundle" and should be rated as such. A bundle in Progistics is a set of containers that are to be rated together as one. There will be one document generated per bundle. In SCALE, international shipments are rated in the same manner because they are manifested at the shipment level. Therefore, they would only need one document for the whole "bundle." An example of a document that needs this checkbox selected is an international document, such as a commercial invoice.

 

 

DHL NOTE...

DHL shipping labels (regardless of destination) need to have this checkbox selected. With DHL, their shipping labels are considered "bundle" documents, because you can actually send over what DHL calls a multi-piece shipment, which is simply a set of containers shipping to the same place. It will give them all the same tracking number. In SCALE, you would need to close all of the containers separately, and then perform a Manifest at Shipment Level action.
