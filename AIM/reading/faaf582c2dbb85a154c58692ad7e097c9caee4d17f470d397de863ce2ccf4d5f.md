
        
        <h1 data-source-node="n56"><a name="kanchor1069" data-source-node="n57"></a>Nesting Containers Onto Multiple Order Pallets (RF)</h1>
        <p data-source-node="n58">You can use this screen to nest shipping containers onto multiple order pallets.  A <i data-source-node="n59">multiple order pallet</i> is a single shipping pallet that has different shipments (for different ship to addresses) placed on it. Also, you may remove container(s) from a multiple order pallet using this screen. Note that the only places in the application where you can view multiple order pallets is in the Multiple Order Pallet Insight Screen.</p>

        <h4 data-source-node="n96"><a name="nesting" data-source-node="n97"></a>Nesting a Container Onto a Multiple Order Pallet (RF)...</h4>
        <p data-source-node="n98"> </p>
        <p data-source-node="n99">Log onto the RF device. Access the Multiple Order Pallet Nesting RF Screen.</p>
        <ol data-source-node="n100">
            <li value="1" data-source-node="n101">Enter the ID of the container you want to nest.<br data-source-node="n102"><br data-source-node="n103"></li>
            <li value="2" data-source-node="n104">Enter the ID of the multiple order pallet that you want to nest the container onto. Whether the new multiple order pallet ID is manually or system generated is based on the user's Container Assignment Method setting in packing preferences.<br data-source-node="n105"><br data-source-node="n106">- If this multiple order pallet does not yet exist in the system, you can create it by nesting the first container onto it (as there is no other way to create a multiple order pallet in the system). The system will 	generate a UCC-128 ID for the multiple order pallet.<br data-source-node="n107"><br data-source-node="n108"></li>
            <li value="3" data-source-node="n109">Press the Nest Button. The system will nest the container onto the multiple order pallet. You can continue to nest containers, or exit the screen by pressing the Cancel button.</li>
        </ol>
        <blockquote data-source-node="n110">
            <h5 data-source-node="n111">Nesting Validations</h5>
            <p data-source-node="n112">The system performs the following validations when it determines whether a container can be nesting onto a multiple order pallet:</p>
            <ul data-source-node="n113">
                <li data-source-node="n114">The “from” shipping container must be at the same dock location as the shipping container(s) already nested on the multiple order pallet.<br data-source-node="n115"><br data-source-node="n116"></li>
                <li data-source-node="n117">A new multiple pallet ID must be unique in the system; it cannot be a currently-existing shipping container or multiple order pallet.<br data-source-node="n118"><br data-source-node="n119"></li>
                <li data-source-node="n120"> A shipping container must be the “top-level” container to be eligible for nesting onto a multiple order pallet.  Child shipping containers are NOT eligible for nesting.<br data-source-node="n121"><br data-source-node="n122"></li>
                <li data-source-node="n123">A shipping container must have a status greater than In Packing and less than or equal to Ship Confirm Pending to be eligible for nesting.<br data-source-node="n124"><br data-source-node="n125"></li>
                <li data-source-node="n126">A shipping container cannot be assigned to different carrier from the container(s) on the multiple order pallet.<br data-source-node="n127"><br data-source-node="n128"></li>
                <li data-source-node="n129">A shipping container cannot be assigned to a load different from the container(s) on the multiple order pallet.<br data-source-node="n130"><br data-source-node="n131"></li>
                <li data-source-node="n132">A shipping container cannot be assigned when the shipment(s) on the multiple order pallet are assigned to a closed shipping load.<br data-source-node="n133"><br data-source-node="n134"></li>
                <li data-source-node="n135">As a result of the nesting action, the system will not change the manifest state on any of the shipping container(s) that are being nested or are already nested on the multiple order pallet.<br data-source-node="n136"><br data-source-node="n137"></li>
                <li data-source-node="n138">A shipping container cannot already be assigned to a multiple order pallet.<br data-source-node="n139"><br data-source-node="n140"></li>
                <li data-source-node="n141">A shipping container cannot be nested onto the multiple order pallet if its wave has not been released.<br data-source-node="n142"><br data-source-node="n143"></li>
                <li data-source-node="n144">A shipping container cannot be nested onto the multiple order pallet if it has pending shipment work. <br data-source-node="n145"><br data-source-node="n146"></li>
                <li data-source-node="n147">A shipping container cannot be nested onto the multiple order pallet if it has pending or active dock management work.</li>
            </ul>
        </blockquote>

        <h4 data-source-node="n152"><a name="removing" data-source-node="n153"></a>Removing a Container From a Multiple Order Pallet (RF)...</h4>
        <p data-source-node="n154"> </p>
        <p data-source-node="n155">Log onto the RF device. Access the Multiple Order Pallet Nesting RF Screen.</p>
        <ol data-source-node="n156">
            <li value="1" data-source-node="n157">Enter the ID of the container you want to remove from the multiple order pallet.<br data-source-node="n158"><br data-source-node="n159"></li>
            <li value="2" data-source-node="n160">Enter the ID of the multiple order pallet that you want to remove the container from.<br data-source-node="n161"><br data-source-node="n162"></li>
            <li value="3" data-source-node="n163">Press the Remove Button. The system will remove the container from the multiple order pallet. You can continue to remove containers, or exit the screen by pressing the Cancel button.</li>
        </ol>
        <blockquote data-source-node="n164">
            <h5 data-source-node="n165">Removal From Nesting Validations</h5>
            <p data-source-node="n166">The system performs the following validations when it determines whether a container can be removed from a multiple order pallet:</p>
            <ul data-source-node="n167">
                <li data-source-node="n168">A shipping container must be the “top-level” container to be eligible for removing from a multiple order pallet.  Child shipping containers are NOT eligible to remove from nesting.<br data-source-node="n169"><br data-source-node="n170"></li>
                <li data-source-node="n171">A shipping container must have a status greater than In Packing and less than or equal to Ship Confirm Pending to be eligible to remove from nesting.<br data-source-node="n172"><br data-source-node="n173"></li>
                <li data-source-node="n174">As a result of the remove from nesting action, the system will not change the manifest state on any of the shipping container(s) that are being removed or are still already nested on the multiple order pallet.</li>
            </ul>
        </blockquote>
