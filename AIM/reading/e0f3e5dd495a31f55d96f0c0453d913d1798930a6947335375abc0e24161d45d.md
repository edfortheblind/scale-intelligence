
        
        <h1 data-source-node="n56"><a name="kanchor600" data-source-node="n57"></a>Creating VAS Activities</h1>
        <p data-source-node="n58">Value added services (commonly known as VAS) represent miscellaneous duties that workers perform to the contents of shipping containers.  A VAS activity record defines how the activity will be applied to a shipment, and the text instructions that will tell a worker how to perform an activity (these are displayed on the VAS Container: Insight Screen). Common VAS activities include putting hangers on clothes, affixing price tags to items, or placing catalogs into container boxes. You can associate VAS activities to shipments and lines, but the system only assigns VAS at the container level. The system assigns the VAS to a container per unique VAS activity/VAS instruction. In other words, the same activity could be assigned to a container if it has different instructions. For example, suppose a container has the same VAS activity "monogramming" assigned to it twice, but there are different VAS instructions associated with each instance of the activity (representing the different words you want monogrammed on the item). The system would evaluate the container to see if the VAS Activity/VAS Instruction combination is already assigned to a container. If it is not, then the system would assign it (in this example, it would assign the activity of "monogramming" twice to the container, with two different sets of instructions).</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The system can assign VAS activities in the following places:</p>
        <ul data-source-node="n61">
            <li data-source-node="n62">During the wave (using the VAS Assignment wave step).<br data-source-node="n63"><br data-source-node="n64"></li>
            <li data-source-node="n65">When a new container is created outside the wave process (i.e. picking into containers from RF, nesting containers after RF putaway, and splitting containers).<br data-source-node="n66"><br data-source-node="n67"></li>
            <li data-source-node="n68">New item is picked or packed into an existing container.<br data-source-node="n69"><br data-source-node="n70"></li>
            <li data-source-node="n71">Downloaded via the interface.<br data-source-node="n72"><br data-source-node="n73"></li>
            <li data-source-node="n74">Manually assigned by the user via the Shipment Screen and Shipping Container Screen.</li>
        </ul>

        <h4 data-source-node="n104">Procedures...</h4>
        <p data-source-node="n105"> </p>
        <p data-source-node="n106">Create a new record.</p>
        <ol data-source-node="n107">
            <li value="1" data-source-node="n108">Use the Name Field to identify your VAS activity record. This is the name that the system will label this activity in the VAS Container: Insight Screen and other windows.<br data-source-node="n109"><br data-source-node="n110"></li>
            <li value="2" data-source-node="n111">Use the Application Level Field to indicate how the system will apply this VAS activity to a shipment’s containers: either All Containers of a shipment, or just One Container of a shipment.

	<br data-source-node="n112"><br data-source-node="n113"></li>
            <li value="3" data-source-node="n114">Use the Activity Criteria Field to indicate the filter criteria record that you want to associate with this VAS activity. This criteria record determines the subset of container(s) that the system will assign this VAS activity to (for example, all containers whose contents include a certain item class). Note that you are not required to select a criteria record for an activity. If none is selected, the system will assign this activity to all containers. To indicate to the system that it should not assign an activity to containers in the wave, you will need to create a criteria record that has rules that would not return any results (such as <i data-source-node="n115">warehouse</i> does not equal the current warehouse). You would typically want to do this if you always interface VAS activities with you orders, and will not need to depend on the criteria record to identify containers that need VAS.<br data-source-node="n116"><br data-source-node="n117"></li>
            <li value="4" data-source-node="n118">Use the Instructions Field to indicate the directions for the person actually performing the VAS activity. This is a free-form text field, so you may enter any number of lines of text, including indentations.<br data-source-node="n119"><br data-source-node="n120"></li>
            <li value="5" data-source-node="n121">Press OK. The system will save your record.</li>
        </ol>
