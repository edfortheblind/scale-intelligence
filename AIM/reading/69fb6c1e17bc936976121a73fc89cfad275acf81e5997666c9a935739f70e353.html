Manually Interfacing Data

You can manually interface data between SCALE and your ERP as your business needs require. SCALE supports both the downloading of data from your order system, and the uploading of SCALE data to your ERP.

Procedures...

  1. Use the Process Buttons to identify in which direction you want the system to interface data in:

    To download data from the ERP, select the Download Button.

    To upload data to the ERP, select the Upload Button.
     
  2. If you selected the Upload Button in Step 1,  use the Upload Output Buttons to identify what method the system should use to transmit the data. If you transmit using a text file, select "Delimited File." If you transmit directly to the database, select "Interface Tables." If you transmit using XML files, select "XML."
     
  3. Define what type of data you want to interface.
     
  4. Press OK. The system will interface the data you selected.
