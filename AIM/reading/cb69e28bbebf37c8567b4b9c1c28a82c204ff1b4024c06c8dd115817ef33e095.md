
        
        <h1 data-source-node="n56"><a name="kanchor182" data-source-node="n57"></a>Warehouse Mobile - Receipt Container Nesting</h1>
        <p data-source-node="n58">The Receipt Container Nesting feature allows dock workers to group multiple receipt containers (license plates) under a parent container, such as a pallet. This helps streamline handling, storage, and locating of inbound containers by treating them as one unit.</p>

        <h4 data-source-node="n77"><a name="Nest" data-source-node="n78"></a>Receipt Container Nesting</h4>
        <p data-source-node="n79"> </p>
        <ol data-source-node="n80">
            <li value="1" data-source-node="n81">Tap <b data-source-node="n82">Receipt Container Nesting</b> to view the <b data-source-node="n83">Receipt Container Nesting</b> screen.</li>
            <li value="2" data-source-node="n84">Enter or scan the <b data-source-node="n85">License Plate</b> that you want to nest the container onto Tap <b data-source-node="n86">Go</b>. </li>
            <li value="3" data-source-node="n87">Enter <b data-source-node="n88">Parent License Plate</b> and Tap <b data-source-node="n89">Go</b>. the Parent License Plate (LP) field is blank for the first container, requiring the user to manually enter either a new or an existing parent LP. For all subsequent containers, the system automatically defaults the Parent LP to the most recently used one, which the user can accept or modify as needed.</li>
            <li value="4" data-source-node="n90">Select the <b data-source-node="n91">Container Type</b> and Tap <b data-source-node="n92">Go</b>. When a new parent license plate (LP) is created, the system automatically assigns the default configured container type, while an existing parent LP always keeps its original type</li>
            <li value="5" data-source-node="n93">Select the <b data-source-node="n94">Locating Rule</b> and Tap <b data-source-node="n95">Go</b>.  When new parent license plate (LP) defaults to the rule from the nested container or receipt line, while an existing parent LP always keeps its current locating rule</li>
            <li value="6" data-source-node="n96">System will next the container and display a success message.</li>
        </ol>

        <h4 data-source-node="n98"><a name="Nesting" data-source-node="n99"></a>Note</h4>
        <ul data-source-node="n100">
            <li data-source-node="n101">
                <p data-source-node="n102">Users can nest multiple receipt containers onto one parent pallet.</p>
            </li>
            <li data-source-node="n103">
                <p data-source-node="n104">System always defaults to the most recently used parent LP for convenience.</p>
            </li>
            <li data-source-node="n105">
                <p data-source-node="n106">Locating rule and container type cannot be overridden once the parent already exists.</p>
            </li>
        </ul>
