
        
        <h1 data-source-node="n56">Associating the Allocation Rule Set with an Item</h1>
        <p data-source-node="n57">An allocation rule set is associated with an item on the Item Window. 
 The system performs allocation for an item using this rule set defined 
 on the item record. If an allocation rule set is not defined on the item 
 record, the system will allocate product using the *Default allocation 
 rule. See the topic <a href="505c5c4630e085fc146ea8699fd6ca8b29c4f269b413b1ce93e0e981d01241b2.html" data-source-node="n58">Defining 
 Items</a> for more information. </p>
