
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">National Motor Freight Classification</h1>
        <p data-source-node="n58">An NMFC Code identifies LTL class for product and determines the description on the BOL. You will need to define the NMFC Codes associated with all product in your warehouse. If items with different NMFC codes are packed in the same container, the system will display the code with the highest class in the carrier information section of the Bill of Lading. Note that you should be sure to complete this procedure if you ship using LTL carriers.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Access the National Motor Freight Classifications Window. Select the New Action. Name the record, and provide a description.</p>
        <p data-source-node="n61">Define the LTL Class associated with the NMFC Code. The system will use this field during carrier rating for LTL carriers.</p>
        <p data-source-node="n62">Use the Hazardous Code Field to identify an item that uses this particular NMFC Code as being a hazardous material. The system will display this code on a shipment's bill of lading document (in the "H.M." field).</p>
