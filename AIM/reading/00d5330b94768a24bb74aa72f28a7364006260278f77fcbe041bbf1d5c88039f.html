Initiation Method Field

On the Packing Preferences Window...

You can use this field to indicate the active field (which contains the cursor) when entering the Close Container Window:

- Always Shipment ID: The Shipment ID Field will initially be active when the Desktop Close Container Window is opened (and while closing containers). Note that if there are more open containers on the shipment, the Shipment ID Field value will be highlighted.

 

- Always Container ID: The Container ID Field will initially be active when the Web Close Container Window is opened (and while closing containers). Note that if there are more open containers on the shipment, the Shipment ID Field should contain the Shipment ID, and the Container ID Field should have focus.

 

- Container ID Unless No Open Containers: The Container ID Field will be active when there are multiple open containers on a shipment, and the Shipment ID Field will be active when the last open container has been closed. This is available in Desktop Close Container screen.
