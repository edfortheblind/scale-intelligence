Assigning a Permanent Location to an Item

You can associate both inventory and non-inventory items with permanent locations. A permanent location identifies the one location where a specific item/unit of measure is stored. Note that if you want to replenish an item/unit of measure, you must assign it to a permanent location. If you create an item location assignment record and do not associate it with a UM, the system will use it to process any UM not identified on another item location assignment record.

  • Allocating Inventory Items - If you want to use the Check Item Location Strategy, associate an inventory tracked item with its permanent location. When that strategy is used, the system will always allocate the item from its permanent location.

  • Allocating Non-Inventory Items - Since non-inventory tracked items must be associated with a permanent location, the system will always attempt to allocate the item from permanent locations only.

  • Locating Non-Inventory Items - Since non-inventory tracked items must be associated with a permanent location, the system will always attempt to locate the item to permanent locations only.
Note on Unit of Measures

If you have no unit of measure assigned to an item (on the Item Unit of Measure Window), the system will use all units of measure when assigning a permanent location to an item. For example, if you have pallet as the unit of measure, then the system will only assign a permanent location for that unit of measure. If you locate a full pallet, the system would pick that up as a permanent location. However, if you locate a case, it would not. The same is true with allocation, as only full pallet allocation requests would use this as the permanent location.

 

Note on Creating Permanent Locations That Currently Do Not Exist

When creating/copying a item location assignment record, and the permanent location you indicate is not a location currently defined in the system, the system will create a new location record if the following is true:

  • The inventory control value "Should location be validated throughout system?" is set to "No"

  • The location you enter is not a location defined in the location configuration

The resulting Location Window record will be an "Inventory Storage" location that is designated as "Empty" and is assigned to the warehouse that you indicated for the item location assignment record.

Procedures...

  1. Use the Item Field to identify the item that you want to assign to a permanent location.
     
  2. Use the Company Field to identify the company associated with this item. This field is only displayed if your warehouse supports multi-company processing.
     
  3. Use the Quantity UM Field to identify the unit of measure that will be stored in this location. If you leave this field blank, the system can associate all of the item's units of measure with this location.
     
  4. If necessary, change the value in the Warehouse Field.
     
  5. Use the Permanent Location Field to identify the location that you want to assign to this item.
     
  6. Press OK. The system will save your changes.
