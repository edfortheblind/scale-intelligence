Movement Class

Movement classes categorize storage locations and item units (UMs) based on how frequently products are moved.

  • Location Level: Assign a movement class (e.g., Class A) to locations. Only items with a matching class should be stored there.

  • Item/Item Class Level: Assign movement classes to UMs of items to track how frequently they're picked or used.

This system helps you optimize storage decisions by matching fast-moving items with easily accessible locations.
