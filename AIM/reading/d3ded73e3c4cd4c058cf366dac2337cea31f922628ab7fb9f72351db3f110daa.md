        <h5 data-source-node="n71">Assign Label Printer </h5>
        <p data-source-node="n72">The following details the steps for the </p>
        <ol data-source-node="n73">
            <li value="1" data-source-node="n74">Log in to Warehouse Mobile application.</li>
            <li value="2" data-source-node="n75">Select the <b data-source-node="n76">Assign Printer</b> option from the Warehouse Mobile Main Menu.</li>
            <li value="3" data-source-node="n77">Enter/Scan Label Printer name. In case a wrong printer name is entered, an error message is displayed.</li>
            <li value="4" data-source-node="n78">Tap <b data-source-node="n79">Go</b> and a success message is displayed as Assign Printer successful.</li>
        </ol>
        <p data-source-node="n80">Note: You can verify the User Profile setting by Navigating to <b data-source-node="n81">Preference</b>&gt;&gt;<b data-source-node="n82">Default Label</b> field. The assigned label printer name is displayed.</p>
        <p data-source-node="n83"> </p>
        <h5 data-source-node="n84">Clear the Assigned Printer settings</h5>
        <ol data-source-node="n85">
            <li value="1" data-source-node="n86">Log in to Warehouse Mobile application.</li>
            <li value="2" data-source-node="n87">Select the <b data-source-node="n88">Assign Printer</b> option from the Warehouse Mobile Main Menu.</li>
            <li value="3" data-source-node="n89">Go to Actions &gt;&gt; Clear and Clear Printer message is displayed.</li>
        </ol>
        <p data-source-node="n90">You can verify the User Profile setting by Navigating to <b data-source-node="n91">Preference</b>&gt;&gt;<b data-source-node="n92">Default Label</b> field. The assigned label printer name is cleared.</p>
