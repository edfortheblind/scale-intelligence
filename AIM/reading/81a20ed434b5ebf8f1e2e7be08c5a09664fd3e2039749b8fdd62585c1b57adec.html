Changing RF Text Font Properties

If desired, you can change the properties (size, display font) of certain texts displayed on the RF device. The shipped defaults for RF text are Arial 9 pt. Note that these font property changes are made per language, not per user or environment. Also, you will need to run an IISRESET or reboot your RF servers in order to view the new font properties.

Procedures...

  1. Access the System Text Editor Window.

  2. In the Key Field, enter the following string: RF_STD and press the Search Button. The system will display a series of records related to the RF screen display.

  3. To change the RF display font, change the RF_STDFONT custom value to the desired font.

    To change the RF font size, change the RF_STDFONTSIZE custom value to the desired font size.

  4. Press the Close Button. You will need to reboot your RF server and restart the application to view your new font display properties.
