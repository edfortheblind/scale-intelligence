
        
        <h1 data-source-node="n56"><a name="kanchor11" data-source-node="n57"></a>From Assign Method Field</h1>
        <p data-source-node="n58">This field determines how work units will be assigned during system-directed work initiation. This allows 
 you to manage the movement of product from storage locations.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">There are three possible choices:</p>
        <ul type="disc" class="ul_1" data-source-node="n61">
            <li data-source-node="n62">
                <p data-source-node="n63"><i data-source-node="n64">Location/Priority/FIFO</i> 
 - Work is assigned based in location proximity order: the location closest 
 to the user is assigned first. This minimizes travel time. Please note 
 that the system only recognizes number proximity in ascending order. In 
 other words, if location 999-999-999 is physically next to 001-001-001, 
 the system cannot recognize the distance between the locations.</p>
                <p data-source-node="n65"> </p>
                <p data-source-node="n66">If multiple pick instructions share the same location, the system 
 will assign the instructions in priority order: the lower the priority 
 number, the sooner the instruction is assigned.</p>
                <p data-source-node="n67"> </p>
                <p data-source-node="n68">If multiple pick instructions share the same location and priority, 
 the system will assign the instruction in FIFO order. The first instruction 
 generated during work creation is assigned first.</p>
                <p data-source-node="n69">
                    <br data-source-node="n70">
                    <br data-source-node="n71">
                </p>
            </li>
            <li data-source-node="n72">
                <p data-source-node="n73"><i data-source-node="n74">Priority/Location/FIFO</i> 
 - Work is assigned in priority order: the lower the priority, the sooner 
 the work is assigned. This is commonly used to ensure that critical customers 
 are processed first.</p>
                <p data-source-node="n75"> </p>
                <p data-source-node="n76">If the multiple pick instructions share the same priority, the system 
 will assign the instructions in location order: the location closest to 
 the user is assigned first. This minimizes travel time.</p>
                <p data-source-node="n77"> </p>
                <p data-source-node="n78">If multiple pick instructions share the same priority and location, 
 the system will assign the instructions in FIFO. The first instruction 
 generated during work creation is assigned first.</p>
                <p data-source-node="n79">
                    <br data-source-node="n80">
                    <br data-source-node="n81">
                </p>
            </li>
            <li data-source-node="n82"><i data-source-node="n83">FIFO</i> 
 - All work is assigned in the First In, First Out order. The first instruction 
 generated during work creation is assigned first.</li>
        </ul>
