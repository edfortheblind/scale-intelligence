
        
        <h1 data-source-node="n56"><a name="kanchor736" data-source-node="n57"></a>Parcel Tracking Websites</h1>
        <p data-source-node="n58">If you are using the Trading Partner Management web module, you and your customers can research shipped containers from the Order Status page. This web page displays all the current orders in the system, and identifies the container IDs that were shipped with a specific carrier. You can make this ID a hyperlink to the carrier's parcel tracking website, which provides further information about the container and its status. To activate this link, you need to identify the website and the <i data-source-node="n59">tracking number token value</i> in the Internet Tracking Link Field on the Carrier Window. </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">When you define a tracking website in the Internet Tracking Link Field, you must provide the entire website address (including the token value). If you do not provide the entire address, the TPM module will not be able to activate the link. You will need to contact the appropriate carrier to obtain an up-to-date website address to use for this functionality.</p>
