Warehouse Mobile - Inventory Management

The inventory management enables you to do inventory adjustment or inventory transfer.

 

  • Adjustment Inventory- It is adding or subtracting an item quantity from a location's inventory. This enables you to quickly correct the inventory for a location activity in real time.

  • Transfer Inventory- This enables you to move product from one location within your warehouse to another location.

  • Warehouse Transfer - This enables you to move product from one warehouse location to another warehouse location.

 

The warehouse mobile has SRC files that enable user to inventory adjustment or transfer without work.

  • Inventory Adjustment - This enables to perform a positive or negative adjustment by item location.
  • Inventory Adjustment by License Plate - This enables to perform a positive or negative adjustment by License Plate.
  • Status Change - Perform status change for LP tracked location and lot controlled items.
  • Inventory Transfer by Item location - This enables to perform inventory transfer by Item location.
  • Inventory Transfer by license Plate - This enables to perform inventory transfer by license plate.

Perform Transfer by License Plate

  1. Log in to Warehouse Mobile application.
  2. Select the Inventory Management option view Select Adjustment Class screen.
  3. Tap Transfer to view Select Adjustment Type screen.
  4. Select the transfer by LP adjustment.
  5. Enter/scan the license plate number. Tap Go to view the information such as Item, Description, Company, Status, Quantity and From Location.
  6. Enter the Quantity to transfer to the new location.
  7. Enter the To Location .
  8. You can change the Status To with the user having the required permission.
  9. Tap Go and a success message is displayed as Inventory transfer successful.

Perform Inventory transfer by Item Location

  1. Log in to Warehouse Mobile application.
  2. Select the Inventory Management option view Select Adjustment Class screen.
  3. Tap Transfer to view Select Adjustment Type screen.
  4. Select Transfer by item location and Tap Go.
  5. Enter the Location and Tap Go
  6. Enter the Item and Tap Go
  7. Enter the Quantity number that will be transferred to the new inventory location.

  8. Enter the License plate the system and Tap Go.

    • If its lot-controlled item, then system will prompt user to enter Lot ID.
    • If its serial number tracked item quantity, then system will prompt user to enter serial numbers for the quantity adjusted.
    • In case all quantity is transferred, then system will not prompt for license plate.
  9. System has the ability to locate the To location.
  10. When system prompts user to enter the To Location, navigate to Actions >> Locate.
  11. The locating rules are displayed in window. Select a location rule and system will search and populate the To location based on the rule selected.
  12. System will display error message when it fails to locate a To location.
  13. You can change the Status to with the user having the required permission.
  14. Enter the To License Plate value (if required) and Tap Go.
  15. A successful message is displayed as Inventory Transfer is successful.

Perform Positive Adjustment by item location

  1. Log in to Warehouse Mobile application.
  2. Select the Inventory Management option view Select Adjustment Class screen.
  3. Tap Adjustment to view Select Adjustment Type screen.
  4. Tap Positive Adjustment to view Inventory Adjustment screen.
  5. Enter the Location and Tap Go.
  6. Enter the Item and Tap Go.
  7. Quantity Field is highlighted and enter the value to be added to the item/location.
    • If the item is LP tracked, the system will prompt user to enter the LP.
    • If its lot-controlled item, then system will prompt user to enter Lot ID.
    • Also, you can specify the expiration date for a new lot.
    • If its serial number tracked item quantity, then system will prompt user to enter serial number for the number of quantity adjusted.
  8. Tap Actions >> Done to complete the inventory adjustment.

Perform Positive Adjustment by License Plate

  1. Log in to Warehouse Mobile application.
  2. Select the Inventory Management option view Select Adjustment Class screen.
  3. Tap Adjustment to view Select Adjustment Type screen.
  4. Enter the License Plate number and Tap Go.
  5. System will populate the item/location details.
  6. Enter the Quantity value to be adjusted. Tap Go
  7. System will prompt to enter the serial numbers for quantity that is being adjusted.
  8. Tap Go.

Perform Status Change

  1. Log in to the Warehouse Mobile application.
  2. Select the Inventory Management option view Select Adjustment Class screen.
  3. Tap Status Change to view the Select Adjustment Type screen.
  4. Tap Status Change, to view Status Change screen.
  5. Enter or scan Location and Tap Go.
  6. Enter or scan the item and Tap Go. Item Details are displayed.
    • If it is lot-controlled item, then the system will prompt the user to enter Lot ID.
    • If it is LP tracked location, then the system will prompt for user to enter the LP.
  7. Select the Item to be Frozen to Yes or No.
  8. All Locations can be selected as Yes or No and then Tap Go.
  9. Select the Status field to view to select status in the pop-up. Select the required inventory status. Tap Go.
  10. Select Actions >> Done. Inventory Status change success message is displayed.

 

Perform Warehouse Transfer by Item/Location

  1. Log in to the Warehouse Mobile application.
  2. Select the Inventory Management option view Select Adjustment Class screen.
  3. Tap Warehouse Transfer to view the Select Adjustment Type screen.
  4. Tap the Adjustment type for warehouse transfer.
  5. Enter the From Location and Tap Go.
  6. Scan/Enter the item at the location. System will prompt user to select the company.
  7. Enter the Quantity value. Tap Go after value is entered.
  8. Optionally you can change the status. Tap Go.
  9. Select the To Warehouse from the drop-drown list.
  10. Enter/Scan the To location. Tap Go. Success Message is displayed.

Note:

  • Transfer by parent license plate is supported.

  • Warehouse Transfer can also be performed the Location Inquiry screen.

 

Notes:

  • Status To field is ignored or disabled when a negative adjustment is performed.
  • User defined fields are displayed only when system is configured with Inventory Control Value setting. If user defined fields are enabled, the system will prompt users to enter user defined function.
  • System will validate the serial number tracked items that are linked to serial number templates.
  • If All Location is set to Yes, then system will update all locations for the specified item/lot.
  • If Frozen is set to Yes, then the system will update the inventory status value as configured in the Inventory status for Frozen lots.
  • Whenever a warehouse mobile user adjusts or transfers inventory and enters a new expiration date, the system automatically updates the lot expiration date across all inventory locations tied to that lot.
    • The system also displays the affected inventory, and transaction history is recorded for both the lot and the location updates.
