Closed Checkbox/Field/Toggle

This checkbox/field/toggle indicates if a wave or cycle count plan has been closed. You cannot add any shipments to a closed wave.

 

On the Cycle Count Request Insight Screen...

On the Filter Pane of Cycle Count Request Insight Screen, this toggle shows the cycle count request status as ON (Closed) and OFF (Not Closed).

 

 

On the Cycle Count Plan Insight Screen...

This field in the List Pane - Grid Field of the Cycle Count Plan Insight Screen reflects the sum of Closed cycle count requests on the cycle count plan. On the List Pane - Summary Tile, it indicates the sum of the total closed for all the returned plans

 

 

On the Manifest Insight Screen...

On the Summary Tile of Manifest Insight Screen, this field shows the total number of closed manifests.

 

 

On the Purchase Order Insight Screen...

On the Summary Tile of Purchase Order Insight Screen, this field shows the total number of closed purchase orders.

 

 

On the Purchase Order Line Insight Screen...

On the List Pane Grid Fields of Purchase Order Line Insight Screen, this field shows the total number of closed purchased orders.

 

 

On the Putaway Group Insight Screen...

On the List Pane Grid Fields of Putaway Group Insight Screen, this field shows the putaway group status as ON (Closed) and OFF (Not Closed).
