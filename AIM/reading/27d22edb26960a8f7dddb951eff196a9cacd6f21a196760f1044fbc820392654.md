
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Inventory Attributes Values</h1>
        <p data-source-node="n58">The system supports 20 configurable inventory attribute types. Each type allows you to create a dropdown list of selectable values used across various processes.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Example:</p>
        <p data-source-node="n61">For the attribute "Country of Origin" (Inventory Attribute 01), you might define options like United States, Canada, and Mexico. These values will then appear in a dropdown wherever Inventory Attribute 01 is used.</p>
