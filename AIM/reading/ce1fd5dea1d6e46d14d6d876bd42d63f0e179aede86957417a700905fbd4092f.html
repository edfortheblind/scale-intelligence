Addressing Miscellaneous Setup Prerequisites (Returns)

The following miscellaneous setup settings must be addressed before using the returns processing:

 

 

Receiving Preferences Window

  • Putaway Groups: In order to be able to use putaway groups when processing returns, you first need to be assigned to a receiving preference that has the Execute Group Putaway Checkbox selected. This indicates that, when locating the return, you want it to be a part of a putaway group, as opposed to grouping it with the "normal" incoming items.
     
  • Disposition Code: If you want users to assign a disposition code to a returned item, make sure their receiving preference has the Disposition Code Required Checkbox selected. These codes describe the condition of an item, as well as assign a locating rule for the system to use during locating.

 

Locating Rule Window

  • Locating Rule for Returns: You should create a locating rule that you want the system to use when locating your returned item quantities. You can assign this locating rule at the receipt level, when checking in the item quantity, or as part of a disposition code.

 

Receipt ID Type

  • On the Receipt ID Type Window, the Returns Field indicates if you want receipts generated with this receipt type to be labeled by the system as "returns." The system uses this value when generating web statistics to differentiate receipts and returns.

 

Receiving System Values

  • Review the two values that deal with the receipt type and receipt ID type of receipts that are created from shipments.
