
        
        <h1 data-source-node="n56">Days To Expire Field</h1>
        <p data-source-node="n57">This field indicates the number of <a name="kanchor56" data-source-node="n58"></a>days that the system will add (to 
 today's date) in order to calculate a lot's expiration date. Note that 
 this value will not be honored if the lot already has an existing expiration 
 date. This field only works with lot-controlled items.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: If you enter a 0 into 
 this field, the system will not add any additional days when assigning 
 an expiration date.</p>
