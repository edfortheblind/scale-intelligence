
        
        <h1 data-source-node="n56"><a name="kanchor665" data-source-node="n57"></a>Reviewing the SSRS File Name Record IDs Configuration Records</h1>
        <p data-source-node="n58">Printing with a configured record ID for the document type saves the SSRS document file name with the document type identifier, record ID based on document type, and GUID (e.g., &lt;Document Type Identifier&gt;_&lt;Shipment ID&gt;_&lt;GUID&gt;.pdf). You can review all the record IDs for the shipped SSRS document types in order to find all the documents for a specific shipment, receipt, or work order, and so on. </p>

        <p data-source-node="n75">Each SSRS document type will be defaulted with a record ID from this list.  These record IDs are used to determine what record id to include when creating the SSRS pdf file name.  One exception to this is the All Bills of Lading document type.  The record ID on All Bills of Lading document type is blank.  Since the All Bill of Ladings document type prints both the Master Bill of Lading and Bill of Ladings the record IDs from those documents are used when creating the file names.</p>
        <p data-source-node="n76"> </p>
        <p data-source-node="n77">Each configuration detail record has a system defined value for record ID and report parameter.  The record ID value must be in the format TABLE_NAME.COLUMN_NAME and report parameter format would be COLUMN_NAME.  The report parameter must be the key for the record ID's table.</p>
        <p data-source-node="n78"> </p>
        <p data-source-node="n79">For example, the record for ShipmentHeader.ShipmentId would have the record ID as SHIPMENT_HEADER.SHIPMENT_ID and report parameter as INTERNAL_SHIPMENT_NUM.</p>
