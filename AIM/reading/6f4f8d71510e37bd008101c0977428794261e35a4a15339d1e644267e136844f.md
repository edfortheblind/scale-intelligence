
        
        <h1 data-source-node="n56"><a name="kanchor596" data-source-node="n57"></a>Container Type Field</h1>
        <p class="p_1" data-source-node="n58">A container type identifies the type of package 
 that inventory is either checked in during receiving or packed in for 
 shipping. Container types are usually defined by their dimensions. Create 
 a record for each container type that your warehouse uses during check 
 in or packing.</p>
        <p class="p_1" data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60"> </p>
        <h5 align="left" data-source-node="n61">On the Packing Screen section...</h5>
        <p align="left" class="p_13" data-source-node="n62">- The container types available for packing can be authorized by company and warehouse. </p>
        <p align="left" class="p_13" data-source-node="n63"> </p>
        <h5 align="left" data-source-node="n64">On the Single Unit Packing Screen section...</h5>
        <p align="left" class="p_13" data-source-node="n65">- The container types available for packing can be authorized by company and warehouse. </p>
        <p align="left" class="p_13" data-source-node="n66"> </p>
        <h5 align="left" data-source-node="n67">On the Shipping Container Screen section...</h5>
        <p align="left" class="p_13" data-source-node="n68">- The container types available for shipping container can be authorized by company and warehouse. </p>
        <p align="left" class="p_13" data-source-node="n69"> </p>
        <h5 align="left" data-source-node="n70">On the RF Container Type Screen section...</h5>
        <p align="left" class="p_13" data-source-node="n71">- The container types available for picking and putaway into shipping container can be authorized by company and warehouse.</p>
        <p align="left" class="p_13" data-source-node="n72"> </p>
        <h5 data-source-node="n73">On the Receipt Workbench Screen section</h5>
        <p align="left" class="p_13" data-source-node="n74">- The container types  can be authorized by company and warehouse while creating a new parent receipt container from the Receipt container screen.</p>
