
        
        <h1 data-source-node="n56"><a name="kanchor512" data-source-node="n57"></a>GS1-AI Label</h1>
        <p data-source-node="n58">A GS1-AI label contains two or more "smart" barcodes (which 
 include such data as item/item cross reference, container ID, quantity, 
 lot, etc.). These barcodes meet internationally accepted standards that 
 are set by the GS1 standards association. Each barcode is comprised of 
 one or more segments (called application identifiers), that define the 
 data that the barcode represents. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: These labels use ZPL code and SCALE stored procedures to retrieve data.  Any changes to these labels or stored procedures could be lost when performing an upgrade or applying a service pack.  It is recommended that you create their own stored procedures and labels when customizing.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">There are three generic GS1-AI shipping labels that are shipped with 
 the system:</p>
        <ul type="disc" class="ul_1" data-source-node="n63">
            <li data-source-node="n64">Generic shipping label with Item Cross Reference (02), 
 Quantity (37), and License Plate ID (00)application identifiers<br data-source-node="n65"> </li>
            <li data-source-node="n66">Generic shipping label with Lot (10), Item Cross Reference (02), 
 Quantity (37), Expiration Date (17), and License Plate ID (00) application identifiers<br data-source-node="n67"> </li>
            <li data-source-node="n68">Generic shipping label with Serial Number (21), Item (01), and License Plate ID (00) application identifiers</li>
        </ul>
        <p data-source-node="n69">You can use these generic labels to create a custom GS1 label that will 
 work for your warehouse's needs. See the topic <a href="35dec6ad34f49d25d8920adbcdef4b13c05fb806bae5ef96a196d59387de1735.html" data-source-node="n70">Defining 
 Application Identifier Templates</a> for a graphical diagram of a GS1-AI 
 label.</p>
