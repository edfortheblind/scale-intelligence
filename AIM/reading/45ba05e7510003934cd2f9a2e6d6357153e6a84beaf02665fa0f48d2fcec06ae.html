Defining Document Masters

The document master controls all aspects of paperwork document (non-label) generation during a wave; including determining which documents can be generated, the order that those documents are produced, and how they'll be printed. Note that this record must be defined on the wave master record being run to be used.

Document Master Header Fields

1. Provide a name and description for this record.

 

2. Use the Print Mode Field to determine when in the wave process you want documents or labels to generate/print:

Print During Wave: The system will generate and print the document/label files when executing the corresponding paperwork wave step.  

 

Print At Release: The system will generate and print the document/label files after a wave has been released. 

 

Manual: The system will generate the document/label files during the wave process, but will not print them. The user then can manually print these using the reprint options in the Wave Insight screen. This option is useful if you do not want the user to wait for the system to generate the documents/labels when manually reprinting them (they will have already been generated via the wave).

 

Adding Document Master Data Selection

You will use this window to define each sequence that the system will process during the paperwork wave step. A sequence identifies the document type to print and the criteria (data selection) that a record must meet to be considered for paperwork. You will also define the print break sequences that the system will reference during the actual printing process. You can only access this window from the Document Master Window.

1. When done entering the document master information, press the Apply Button.

 

2. Right-click the grid area and select New. The system will display the Document Master Data Selection Window.

 

3. Use the Document Type Field to select the type of document that you want to print during a wave.

 

4. Use the Data Selection Field to select a criteria record, which determines the wave records that require documentation. These records are defined on the Shipment or Container Data Selection Windows. Note that this field will only display data selection values that are available for the document type that you selected from the Document Type Field.

 

5. Press OK. The system will save your information, and return to the Document Master Window.

 

Adding Document Master Print Break

You will use this window to identify the printers that paperwork will be routed to during a wave. You will also define how many pieces of paperwork can be associated with a particular printer. Once the system reaches this maximum, it will route the remaining documents to the next printer identified on this window. If the system uses the last printer and more documents remain, it will return to the first printer defined and route the paperwork to it. This window applies only to documents generated during a wave (not labels). For example, you could send the first 50 container pack lists to Printer A, the next 50 to Printer B, etc. Press OK when finished defining print breaks, and the system will return you to the Document Master Window.NOTE: Any print breaks that you define here override the printer defined on the Document Routing Window. If you do not define a print break record, the system uses the document routing record.

1. When done entering the document master data selection information, press the Apply Button.

 

2. Right-click the grid area and select New. The system will display the Document Master Print Break Window.

 

3. Use the Print Device Field to indicate the network path of the print device to be used to print a document.

 

4. Use the Number of Documents Field to indicate the number of copies you want the system to print.

 

5. Press OK. The system will save your changes, and return to the Document Master Data Selection Window.
