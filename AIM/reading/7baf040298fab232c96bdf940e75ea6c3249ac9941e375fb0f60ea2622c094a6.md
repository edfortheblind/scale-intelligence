
        
        <h1 data-source-node="n56"><a name="kanchor1856" data-source-node="n57"></a>Consolidate Replenishment Requests Checkbox</h1>
        <p data-source-node="n58">Use the checkbox to indicate  that the system can consolidate replenishment requests that were created using this master. When this setting is active, the system will analyze each request and determine if the requests share the following criteria: <i data-source-node="n59">Item/Company</i>, <i data-source-node="n60">To/From Warehouse</i>, <i data-source-node="n61">To/From Location</i>, <i data-source-node="n62">License Plate</i> (at the From Location), and <i data-source-node="n63">Lot</i> (if applicable). If any requests share this criteria, then the system will determine if the <i data-source-node="n64">To Location</i> can physically handle combining the requests. If it can, the system will consolidate the requests. If the <i data-source-node="n65">To Location</i> cannot support the consolidation amount, then the system will create a new request.</p>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67">NOTE: The minimum replenishment threshold is taken into consideration when determining if the new replenishment demand can be added to the existing replenishment request.</p>
        <p data-source-node="n68"> </p>
        <p data-source-node="n69">This option is only available if you using the create work method of <i data-source-node="n70">Manual/Scheduled Job</i>. Note that this setting will consolidate across replenishment types and origination modes (as defined on the Replenishment Modes Tab of this window).</p>
        <p data-source-node="n71"> </p>
        <p data-source-node="n72">If this setting and the <i data-source-node="n73">Create Multiple Requests For Excess Demand Checkbox</i> are both selected, then the system will honor the user's desire to create requests that do not exceed the percentage that the To Location can hold.</p>
