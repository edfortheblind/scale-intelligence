
        
        <h1 data-source-node="n56"><a name="kanchor612" data-source-node="n57"></a>UCC/EAN Number Field</h1>
        <p style="font-style: italic" data-source-node="n58">** To read more about EPC generation, see the topic How an EPC is Generated **</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">** To read more about UCC Codes, see the topic <a href="6ef0a948ccfdfa8010ca699f397154c15983ded4d8123d43cc6afacb5debefb0.html" data-source-node="n61">UCC Code Field</a> **</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">The UCC/EAN identifier assigned to this shipping entity (company or 
 warehouse). If the system generates container IDs during packing, the UCC/EAN number 
 occupies up to positions 4 - 10 of the ID. Note that three flex positions exist for codes that are greater than 7 characters. In addition, if a vendor compliant label is 
 produced for a container linked to this number <span class="span_3" data-source-node="n64">and 
 </span>it includes a UCC-128 barcode, the UCC/EAN number occupies positions 
 4 - 10 of the barcode.</p>
