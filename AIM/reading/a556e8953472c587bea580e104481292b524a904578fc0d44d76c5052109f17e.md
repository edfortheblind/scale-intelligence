
        
        <h1 data-source-node="n57"><a name="kanchor1368" data-source-node="n58"></a>Inactive Checkbox</h1>
        <p data-source-node="n59">This checkbox indicates if a configuration record is active or inactive. If this checkbox is selected on a record, the system will not display the record in system dropdown fields. For example, if you have a company record flagged as inactive, this company will not be available to choose from in dropdown fields located in a window such as the Shipment Screen. However, note that any existing record(s) that have this company value associated with them will still process through the system as if the company was currently active.</p>
