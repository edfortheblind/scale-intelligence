
        
        <h1 data-source-node="n56"><a name="kanchor81" data-source-node="n57"></a>Today Only: Logged Date Time Toggle</h1>
        <p data-source-node="n58">You can use this switch to turn on/off the specific date and time of occurrence of an audit log record. When this is set On, the From and To date fields in the filter are disabled, and only today’s records are shown.  When it is set Off, you can specify the date range.  If it is Off and no date range is specified, all records are shown irrespective of date. </p>
