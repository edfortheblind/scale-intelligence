Work Special Handling Configuration

Overview

A work special handling configuration record defines processing validations or restrictions required for a specific group of work instructions. You can use these configuration to increase security for expensive product, support a customer account's requests, provide guidelines for new employees, and minimize errors occurring in specific warehouse zones.

 

Note: These work special handling constraints are only reflected in Warehouse Mobile or RF work processing and will not work in Work Insight Screen.

 

Configuration Hierarchy

 

 

Configure Work Special Handling

 

1. Select User

Select the user for which the work special handling constraint will be configured.

 

2. Work Types

In this screen select a specific type of work, such as order picking. You will define your warehouse's work types on the Work Type Window. Warehouse work type is selected. These work type selected will be associated with work creation records and work profiles. All work created in the system is assigned a work type.

 

3. Work Zones

This field identifies a group of locations where the same job function is performed by a specific employee or group of employees.

 

4. Verifications (1)

These settings are used to determine if the user will need to verify item, quantity, license plate, lot, or location during work execution processing. When verifying location, you can have the user be required to enter either the location's ID or its check digit.

 

5. Verification (2)

 

Receipt Putaway verification

This setting determines how the user interacts with the license plate when executing receipt putaway work.

  • Existing License Plate (No Override Allowed): the system will show the existing license plate ID in display mode, and not allow you to enter a new value.

  • Verify Existing License Plate - the system will require you to enter the existing license plate ID for confirmation. An error will occur if you enter a new value.

  • Existing License Plate (Allow Override) - the system will show the existing license plate, and you can either use the existing license plate or enter a new value.

  • User Specified - the system will not show the existing license plate. Therefore, you will have to enter a new value.

 

Shipping Container Verification.

This setting determines whether or not the user will need to verify containers when executing shipment work

  • None: The system will show the container ID in display mode (no additional user verification needed). Note that if the user partial picks the quantity, they will have to scan the container ID for the next instruction.

  • Container Verify: The system will require the user to correctly verify (by entering or scanning the ID) the shipping container that is being picked into.

  • Container Spot Verify: The system will require the user to correctly identify the shipping container's spot on the picking cart. Note that this setting is only valid when using group user picking (otherwise the system ignores it).

  • Allow Override: The system will default the container ID in the field, and the user can change this value if desired. The system then would validate this new ID to make sure that it does not already exist.

For more information read Shipping container verification page.

 

6. Select Picking Options

The following picking options affect how the user can interact with work instructions during picking.

 

  • Allow Splitting Of Container - Defines whether or not, you will be allowed to split off and pick a portion of the quantity into another container. To accommodate this action, the system will create a new work unit and container for the split quantity. This is helpful if the container that you are picking into gets full before you are done picking the current quantity. Typically this situation would occur if you created containers in the wave, and the current pick physically will not completely fit into the container that the system created for it.

  • Allow Over Picking - Allows the user to pick more quantity than exists on a work instruction, as long as this quantity is within the location's available quantity. When an over pick is performed, the system will increment the transaction quantity, and process the pick as a complete/normal pick. This option is only available for RF replenishment and work order picking. For example, suppose a work order component work instruction calls for 980 eaches of an item. It may be easier physically, then, for the worker to pick two cases of 500 (for a total of 1,000 eaches) rather than breaking one case open and leaving 20 eaches loose at the location. If this checkbox is checked, the system will increment the instruction by 20 eaches, and process the pick as normal.

  • Allow Pick In Transit - Allows the user to pick in transit quantities. If there is not enough quantity in the location to be picked but there is additional inventory that is 'on the way', this allows the user to pick from what is coming or 'in transit'. If the inventory is picked against what's in transit, the inventory will show a negative quantity.

  • Close After Partial Pick Checkbox - Allows the user to partial pick the quantity of a work instruction, and the system will delete the remaining quantity from the work instruction. The system will then close the work instruction. Therefore, the remaining quantity will never actually be picked. For example, suppose you have a replenishment request that calls for 620 eaches of an item. The user, however, may only want to pick 600 eaches of the item (because that is a more round number in regards to how things are packed), so they just want the other 20 eaches to “go away.” If this option is checked, the system would delete the remaining 20 eaches from the work instruction (after the user picks the 600), and close the work instruction.

  • Replenish On Outbound Short Pick - Indicate that when the user short picks an item quantity at a location, the system will attempt to run replenishment (based on the location's item demand resulting from the short pick). If there is enough In transit quantity that is on its way to the location for this item, then the system will display to the user a message asking whether or not they want to continue with the short pick.

  • Maximum Pickup Quantity - The maximum number of units that can be picked at one time. When the employee is picking the product, the system will require him/her to only pick the amount displayed here. If the work instruction requires more than the value defined here, the system will ask the user to pick this amount as many times as required to fulfill the work instruction. This constraint increases the likelihood that the employee will count the product.

  • Use Converted Quantity - This setting is used for workers who do not pick in the base UM and pick in either cases or pallets. If the user is not picking any item in eaches and always picks in an UM which is not the base UM, then the picks should also happen with the converted quantity (CS, PL etc.). For example, if 1 CS= 10 EA and a user picks 2 CS, the converted quantity is 20 EA.

    The system uses the converted quantity as the main pick quantity value and the base value as the secondary read-only values when the pick quantity is a multiple of the converted quantity. If the pick quantity is not a multiple of the converted quantity, the system uses base quantity UM as the pick quantity. Also, the system updates work, inventory, shipment, and transaction history correctly based on converted UM quantity picks.

  • NOTE: User cannot enter a decimal quantity for the converted quantity to a partial/short pick.

Container Creation During Pick

  • Prompt for Quantity -You can use this setting to perform Inline Partial Pick for Container Creation During Pick. The system will prompt with quantity field to enter the partial quantity.

8. Select Cycle Counting Work Options

These settings determine specific behaviors when executing cycle counting work.

 

License Plate Selection Method -This setting indicates how you want to handle license plate cycle count work:

  • System Initiated: This indicates that the system will tell the user the order of the license plates that they are required to cycle count.

  • User Initiated: This indicates that the user will be able to specify which license plate that they want to count.

Count Level - This setting indicates exactly how/what the user will perform a cycle count at a location when executing cycle count work

  • Standard Count: The user will count the individual cycle count(s) present for the location.

  • Blind Count: As in a standard count, the user will count the individual cycle count(s) present for the location. However, the system does not present any information on screen *except* for the location ID. Therefore, the user is forced to count each item that is physically present in the location without the system guiding them in what should be counted.

  • Count License Plates: The user will count the number of license plate(s) that are currently present at a location. For example, suppose a certain product is housed in a second story location. Since users would not be able to easily access and count the quantity contained in these license plates, you could configure counts for this product to ask for the number of license plates present at the location, rather than a count of the actual quantity. Note that if a license plate count differs from what the system expected, the system will require the user to count the actual quantity contained per license plate. Also note that multi-item locations always force the user to count individual quantities (even if you have this setting selected on your work special handling).

  • Group Count By Item/Company: The user will count all of the quantity at a given location for the same item/company (regardless of the lot ID, inventory attribute, and/or license plate values):

    • If the user's total-quantity count does not meet the system's total-quantity count, the system will ungroup the cycle count work and display an error message. If you are cycle counting multiple items at the same location OR an empty location, then you will have to confirm the counts individually (even if this setting is enabled).

    • If you choose to add an item when confirming a grouped count, the system will ungroup the cycle count work and you will need to confirm each count individually. Note that after you add an item, the system will give you the option to continue with the add item action, or to return to the group count.

    • If this setting is enabled AND lot/license plate verification is enabled, the system will ungroup the cycle count work and you will need to confirm each count individually.


Add License Plates During Cycle Count - This setting determines if you will have the ability to identify a new license plate to the system when performing a cycle count for a location.

  • This setting is only available when you are using a License Plate Selection Method of user initiated.

  • When the user attempts to add a new license plate, the system will reference the user's cycle count preferences

    • If the license plate falls within the user's positive tolerance, then the system will add to the location the new license plate/item quantity.

    • If the license plate falls above the user's positive tolerance, then the system will set the count of this location to pending review.

  • You can have the system set all counts that involve new license plates to a pending review status using the Set New License Plates To Pending Review

  • The system will ignore this setting if you have the ability to add items during a count. Since you are always allowed to add license plates when adding an item to a location's count, this setting is not recognized.

 

Set New License Plates To Pending Review - This setting indicates that you want the system to place in a pending review status all cycle counts that involve new license plates created by the user (while executing counts). A warehouse supervisor then will have to review the count before it is made official in the system. This option is only available when you are using a License Plate Selection Method of user initiated.

NOTE: The system will ignore this setting if you have the ability to add items during a count. Since any new additions during counts is automatically put into a pending review status, this setting is not recognized.
