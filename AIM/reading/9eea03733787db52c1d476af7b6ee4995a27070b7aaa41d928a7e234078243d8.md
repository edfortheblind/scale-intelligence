
        
        <h1 style="text-align: left;font-size: 14pt" data-source-node="n56"><span style="font-size: 14pt" data-source-node="n57"><a name="kanchor1607" data-source-node="n58"></a>Blind Receipt RF Header Record</span>
        </h1>
        <p data-source-node="n59">When using the blind receiving method to check in a receipt, users can enter specific header information into the RF device. This configuration window allows you to define which fields will appear on the receipt information entry screen during blind receipt processing. If no values are entered for these RF fields, the system will automatically populate them based on the settings defined in the Receiving System Values configuration.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Note: You can use this configuration to add new header fields, which will be displayed on the RF screen. However, these fields will not perform any function, nor will the system store their values in the database. As a result, additional fields beyond those included with the system are not supported.</p>
