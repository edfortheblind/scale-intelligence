
        
        <h1 data-source-node="n56"><a name="kanchor1247" data-source-node="n57"></a>Manual Inventory Adjustment Screen</h1>
        <p data-source-node="n58">You can use this window to manually adjust an item's inventory quantities 
 (<i data-source-node="n59">allocated/in transit/on hand/suspense</i>) at a specific location. You can only access 
 this screen from the desktop.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">SECURITY NOTE: This window is 
 shipped with restrictive, system-level security settings. You must create 
 a user-level record for this window in order to gain access.</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">WARNING: Do not change the quantity values in this window 
 unless you are completely sure you want to do so. Inaccurate quantity 
 values could cause major problems with system processing. The proper venue 
 for adjusting inventory quantities is the Inventory Adjustment screen. 
 The Manual Inventory Adjustment screen should only be used in certain 
 situations when an item's quantity is in 
 an immediate need of change. Also note that no history records are logged 
 by the system for these manual adjustments.</p>
