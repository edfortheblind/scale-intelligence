
        
        <h1 data-source-node="n56">User Interface Theme</h1>
        <p data-source-node="n57">The user can customize the user interface look into one of two themes: Light and Dark. The main elements of user interface of top-bar, sidebar, tiles and background are distinct and unique in style and color for light and dark theme.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"><b data-source-node="n60">Note</b>: By default the SCALE application will be in <b data-source-node="n61">Light theme</b> mode.</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63"> </p>

        <h4 data-source-node="n73"><a name="kanchor1925" data-source-node="n74"></a><a name="Theme" data-source-node="n75"></a>Theme selection</h4>
        <p data-source-node="n76">User can toggle the user interface theme between Light and Dark theme. The theme is universal application and need not be set for each screen. </p>
        <p data-source-node="n77"> </p>
        <p data-source-node="n78">To change the theme, select an option from  <b data-source-node="n79">User Profile &gt;&gt; Dark theme</b> or <b data-source-node="n80">Light Theme</b>.</p>
