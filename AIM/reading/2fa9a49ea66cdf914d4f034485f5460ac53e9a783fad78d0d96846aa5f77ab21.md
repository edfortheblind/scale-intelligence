
        
        <h1 data-source-node="n56"><a name="kanchor1791" data-source-node="n57"></a>Performing a Location Inquiry (RF)</h1>
        <p data-source-node="n58">You can use this function to have the system view location inventory 
 data on your RF device. This is helpful if, for instance, you want to 
 check if an item's actual quantity matches with the quantity that is physically 
 present in a location. You can also view/edit inventory attributes from this screen.</p>

        <h4 data-source-node="n88"><a name="Search" data-source-node="n89"></a>Search Procedures...</h4>
        <p data-source-node="n90">
            <ol class="ol_1" data-source-node="n91">
                <li value="1" data-source-node="n92">Choose Location 
 Inquiry from the RF Main Menu. The system will display 
 the Location Inquiry screen.<br data-source-node="n93"><br data-source-node="n94"></li>
                <li value="2" data-source-node="n95">Enter the values for any combination of the fields on this screen to perform your search. To perform a wildcard search, enter a % sign on the text entry field.<br data-source-node="n96"><br data-source-node="n97">- If a company is not used to filter, the system will display all the item/company combinations on the results screen.<br data-source-node="n98"><br data-source-node="n99">- In the LP field, you can enter any of the three types of license plates: an un-nested LP, a parent LP or a child LP.<br data-source-node="n100"><br data-source-node="n101"></li>
                <li value="3" data-source-node="n102">The system will display all location inventory records for the current warehouse that have item quantities that are in any of the four statuses: On-Hand (OH), In-Transit (IT), Allocated (AL) and Suspense (SU).<br data-source-node="n103"><br data-source-node="n104"></li>
                <li value="4" data-source-node="n105">Use the &lt;&lt;Prev and Next&gt;&gt; links to page through the item records. Note that if the search only returned one record, these links will be disabled and a message will say "Record 1 of 1."<br data-source-node="n106"><br data-source-node="n107">Serial Numbered Items:<br data-source-node="n108">- If there are no serial numbers for the item at this location, the 'Serial Num' link will not appear.<br data-source-node="n109"><br data-source-node="n110">Lot Controlled Items:<br data-source-node="n111">- If there is no lot for an item/company, the 'Lot Field' will not appear.<br data-source-node="n112">- If the item/company has multiple lots in a location, then those are displayed as separate records.<br data-source-node="n113"><br data-source-node="n114">License Plate Tracked Items:<br data-source-node="n115">- If the location is not license plate tracked, the 'LP Field' will not appear.<br data-source-node="n116">- If the item/company has multiple license plates in a location, then those are displayed as separate records.<br data-source-node="n117">- If the parent license plate was entered in the search, the system displays a record for each associated child license plate. There is not a record for the parent license plate.<br data-source-node="n118">- If a child license plate was entered in the search, the system displays a record for the child license plate.<br data-source-node="n119">- If there is no parent license plate value for a record, the 'Par LP' field is not displayed.<br data-source-node="n120"><br data-source-node="n121">Multi-Company Items:<br data-source-node="n122">- If an item was entered and the company was not used as search criteria, the system displays all the item/company combinations.<br data-source-node="n123"><br data-source-node="n124">Permanent Locations:<br data-source-node="n125"><img loading="eager" data-source-node="n126"> This icon is displayed to indicate a permanent location.<br data-source-node="n127"><br data-source-node="n128">NOTE: When using the Location Inquiry screen, if an administrator changes the company for which you have access on the user profile, it could take up to 5 minutes for the user to see any company access changes. The administrator has the ability of changing the caching time on the Location Inquiry screen. Refer to the <a href="81d022a2ab379af5c9e945433d1bd3f6e09728fcfd355546989e79b3a0ecfa54.html" style="font-weight: normal" data-source-node="n129">SCALE SDK</a> documentation on how this is accomplished.<br data-source-node="n130"></li>
            </ol>
        </p>

        <h4 data-source-node="n133"><a name="Xref" data-source-node="n134"></a>Searching Using Item Cross Reference IDs...</h4>
        <p data-source-node="n135">
            <ol data-source-node="n136">
                <li value="1" data-source-node="n137">Choose Location Inquiry from the RF Main Menu. The system will display the Location Inquiry screen.<br data-source-node="n138"><br data-source-node="n139"></li>
                <li value="2" data-source-node="n140">Enter an item cross reference ID in the Item field to perform your search. Note that if there is more than one item associated with an item cross reference, the system will display a message indicating that there were multiple items for that cross reference, and will populate in a dropdown field all of these items. You will then need to select the correct item ID.<br data-source-node="n141"><br data-source-node="n142"></li>
                <li value="3" data-source-node="n143">Press the Search Button. The system will display the appropriate location inventory record(s).</li>
            </ol>
        </p>

        <h4 data-source-node="n146"><a name="Serial" data-source-node="n147"></a>Searching Items with Serial Numbers...</h4>
        <p data-source-node="n148">
            <ol class="ol_1" data-source-node="n149">
                <li value="1" data-source-node="n150">Choose Location 
 Inquiry from the RF Main Menu. The system will display 
 the Location Inquiry Screen.<br data-source-node="n151"><br data-source-node="n152"></li>
                <li value="2" data-source-node="n153">Enter the values for any combination of the fields on this screen to perform your search. Also, indicate a serial number, or place a '%' in the Serial Number field.<br data-source-node="n154"><br data-source-node="n155"></li>
                <li value="3" data-source-node="n156">The system will display all location inventory record(s) for the current warehouse that have item quantities with serial numbers and the four statuses: On-Hand (OH), In-Transit (IT), Allocated (AL) and Suspense (SU).<br data-source-node="n157"><br data-source-node="n158"></li>
                <li value="4" data-source-node="n159">Use the &lt;&lt;Prev and Next&gt;&gt; links to page through the item records. Note that if the search only returned one record, these links will be disabled and a message will say "Record 1 of 1."<br data-source-node="n160"><br data-source-node="n161"></li>
                <li value="5" data-source-node="n162">Press the Serial Num link to view all the serial number(s) associated with the item. Note that the serial numbers are sorted sequentially.</li>
            </ol>
        </p>
