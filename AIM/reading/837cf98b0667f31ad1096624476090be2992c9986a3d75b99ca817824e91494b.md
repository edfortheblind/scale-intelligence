
        
        <h1 data-source-node="n56"><a name="kanchor1411" data-source-node="n57"></a>One Per User Checkbox</h1>
        <p data-source-node="n58">You can use this checkbox to indicate that, if there are multiple users 
 processing returns, the system will assign each user's items to separate 
 putaway groups. This will ensure that no two users will assign items to 
 the same putaway group.</p>
