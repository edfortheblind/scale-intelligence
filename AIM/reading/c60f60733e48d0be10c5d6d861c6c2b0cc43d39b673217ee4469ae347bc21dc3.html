Increment Field

This field determines how the system will increment locations when it creates a location range.

 

 

Incrementing Numeric Locations...

When the system increments numeric locations, it increments through all positions in the location number.

 

In the example below, the location range includes two aisles. Each aisle has two bays; each bay is three levels high. To obtain a location number for each location in these aisles, you would provide the following increment value: 001-001-001. As the values in the Locations Created column illustrate, the system will increment across number positions.

Note: if you select an increment other than 001, the system will increment by that value. For example, if you incremented by 001-001-002, the system would have created 'every other location: 001-001-001, 001-001-003, etc. In this case, it would skip all even numbered levels.

 

 

Incrementing Alpha Locations...

When the system increments alpha locations, it increments by position only. This minimizes setup errors and decreases the likelihood that you will generate too many locations.

 

In the example below, the location range includes three shelves. Each shelf has three bays. To obtain a location name for each location in these shelves, you would provide the following increment value: 11. As the values in the Locations Created column illustrate, the system will not increment across number positions. Once it reaches the last letter in the ending location sequence, it attempts to create new locations using the next starting location letter.
