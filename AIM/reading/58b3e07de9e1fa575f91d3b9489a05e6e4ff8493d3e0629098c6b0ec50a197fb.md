
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><span style="font-size: 18pt" data-source-node="n58">Storage Template Configuration</span>
        </h1>
        <h4 data-source-node="n59">Overview</h4>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Storage Template configuration defines the unit of measure hierarchy used to store inventory. You can create templates with ordered detail records that specify unit of measure values, treat-full percentages, and unitization grouping behavior for item storage.</p>
        <h4 data-source-node="n62"> </h4>
        <h4 data-source-node="n63">Configure Storage Template</h4>
        <p data-source-node="n64"> </p>
        <h5 data-source-node="n65">1. Storage Template</h5>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67">The Review Storage Templates screen displays existing records and allows record maintenance.</p>
        <ul data-source-node="n68">
            <li data-source-node="n69">
                <p data-source-node="n70"><b data-source-node="n71">Review Storage Templates</b>: View existing templates with Storage Template and Description columns.</p>
            </li>
            <li data-source-node="n72">
                <p data-source-node="n73"><b data-source-node="n74">Add New Storage Template</b>: Create a new storage template record.</p>
            </li>
            <li data-source-node="n75">
                <p data-source-node="n76"><b data-source-node="n77">Edit/Delete</b>: Update or remove the selected storage template record.</p>
            </li>
        </ul>
        <p data-source-node="n78"> </p>
        <h5 data-source-node="n79">A. Information</h5>
        <p data-source-node="n80"> </p>
        <p data-source-node="n81">Enter the core storage template details.</p>
        <ul data-source-node="n82">
            <li data-source-node="n83">
                <p data-source-node="n84"><b data-source-node="n85">Storage Template</b>: Enter the unique identifier for the storage template record.</p>
            </li>
            <li data-source-node="n86">
                <p data-source-node="n87"><b data-source-node="n88">Description</b>: Enter a description for the storage template.</p>
            </li>
        </ul>
        <p data-source-node="n89"> </p>
        <h5 data-source-node="n90">2. Details</h5>
        <p data-source-node="n91"> </p>
        <p data-source-node="n92">The Details screen displays the ordered list of unit of measure detail records for this storage template.</p>
        <ul data-source-node="n93">
            <li data-source-node="n94">
                <p data-source-node="n95"><b data-source-node="n96">Sequence</b>: The order in which the detail record appears in the template hierarchy.</p>
            </li>
            <li data-source-node="n97">
                <p data-source-node="n98"><b data-source-node="n99">Unit of Measure</b>: The unit of measure assigned to this detail level.</p>
            </li>
            <li data-source-node="n100">
                <p data-source-node="n101"><b data-source-node="n102">Treat Full %</b>: The percentage at which the system considers this unit of measure level to be full.</p>
            </li>
            <li data-source-node="n103">
                <p data-source-node="n104"><b data-source-node="n105">Group During Unitization</b>: Indicates whether inventory should be grouped during the unitization process at this level.</p>
            </li>
            <li data-source-node="n106">
                <p data-source-node="n107"><b data-source-node="n108">Add New Detail</b>: Add a new detail record to the template.</p>
            </li>
            <li data-source-node="n109">
                <p data-source-node="n110"><b data-source-node="n111">Edit/Delete</b>: Update or remove the selected detail record.</p>
            </li>
        </ul>
        <p data-source-node="n112"> </p>
        <h5 data-source-node="n113">A. Detail Information</h5>
        <p data-source-node="n114"> </p>
        <p data-source-node="n115">Define the properties for a storage template detail record.</p>
        <ul data-source-node="n116">
            <li data-source-node="n117">
                <p data-source-node="n118"><b data-source-node="n119">Unit of Measure</b>: Select the unit of measure for this detail level. This value is required.</p>
            </li>
            <li data-source-node="n120">
                <p data-source-node="n121"><b data-source-node="n122">Treat Full %</b>: Enter the percentage threshold at which this unit of measure level is treated as full by the system.</p>
            </li>
            <li data-source-node="n123">
                <p data-source-node="n124"><b data-source-node="n125">Group During Unitization</b>: Enable this option to group inventory of this unit of measure during unitization processing.</p>
            </li>
        </ul>
        <p data-source-node="n126"> </p>
        <p data-source-node="n127">Use Back, Save, Continue, and Finish to manage and complete Storage Template configuration.</p>
