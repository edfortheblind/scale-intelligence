
        
        <h1 data-source-node="n56"><a name="kanchor439" data-source-node="n57"></a>Allow Splitting Of Container Checkbox</h1>
        <p data-source-node="n58">This checkbox defines whether or not you will be allowed to split off and pick a portion of the quantity into another container. To accommodate this action, the system will create a new work unit and container for the split quantity. This is helpful if the container that you are picking into gets full before you are done picking the current quantity. Typically this situation would occur if you created containers in the wave, and the current pick physically will not completely fit into the container that the system created for it.</p>
