
        
        <h1 data-source-node="n56"><a name="kanchor640" data-source-node="n57"></a>Print For Nested Containers Checkbox</h1>
        <p data-source-node="n58">Select this checkbox if you want the system to print labels 
 for any existing nested child containers, as well as their parent container. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"><b style="text-decoration: underline" data-source-node="n62">Notes</b>
        </p>
        <ul data-source-node="n63">
            <li data-source-node="n64"> This setting is only available for selection when the Printed 
 As Field is set to SCALE Label, and the document type you want to use 
 has a print procedure setting of Shipping Container.<br data-source-node="n65"><br data-source-node="n66"></li>
            <li data-source-node="n67">This setting can only be used to print labels post-wave. Wave label processing does  not generate labels for child containers when this setting is selected on a label's Document Window record.</li>
        </ul>
