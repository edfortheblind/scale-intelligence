
        
        <h1 data-source-node="n56"><a name="kanchor538" data-source-node="n57"></a>Expires By (In Days) Field</h1>
        <p data-source-node="n58">You can use this field to indicate the age a lot's expiration date should be in when the system is deciding which item quantities it should generate cycle counts using this quick plan. </p>
        <ul data-source-node="n59">
            <li data-source-node="n60"><i data-source-node="n61">Blank</i> = The system will not consider expiration date when including lots.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64"><i data-source-node="n65">0 (zero)</i> = The system will include all lots that have already expired.<br data-source-node="n66"><br data-source-node="n67"></li>
            <li data-source-node="n68"><i data-source-node="n69">1</i> = The system will include all lots that expire on today's date. <br data-source-node="n70"><br data-source-node="n71"></li>
            <li data-source-node="n72"><i data-source-node="n73">Greater Than 1</i> = The system will include all lots that fall into a time span between today's date and a future date. For example, if you entered 10, then the system would include all lots that expire within the next ten days.</li>
        </ul>
