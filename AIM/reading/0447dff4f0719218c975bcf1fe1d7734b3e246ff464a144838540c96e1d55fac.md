
        
        <h1 data-source-node="n56"><a name="kanchor206" data-source-node="n57"></a>End Position Field</h1>
        <p data-source-node="n58">This field (used in conjunction with the Start Position Field) indicates 
 what characters in the response string the system will recognize as the 
 data you are trying to capture.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">For example, when a scale weighs an item, the scale sends back a response 
 string of 16 or more characters, such as the following:</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">&lt;lf&gt;xxxx.xxuu&lt;cr&gt;&lt;lf&gt;hh...&lt;cr&gt;&lt;etx&gt;</p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64">In the above example, &lt;lf&gt; 
 represents a line feed,   &lt;cr&gt; 
 represents a carriage return,   &lt;etx&gt; 
 represents the end of transmission character,   x 
 represents the numbers of the weight,   u 
 represents the units of the weight, and   h 
 represents the status of the scale. In this example, the significant positions 
 of the string are the numbers of the weight, so you would enter a "2" 
 in the Start Position Field and an "8" in the End Position Field.</p>
        <p data-source-node="n65"> </p>
        <p data-source-node="n66">So, if the scale sent back the following string...</p>
        <p data-source-node="n67"> </p>
        <p data-source-node="n68">&lt;lf&gt;0002.34LB&lt;cr&gt;&lt;lf&gt;00&lt;cr&gt;&lt;etx&gt;</p>
        <p data-source-node="n69"> </p>
        <p class="p_1" data-source-node="n70">...then the system would recognize the weight 
 in pounds as "2.34".</p>
