Maximum Lines Field

This field represents the most shipment lines that can be processed in a particular wave.

 

The system supports the following wave maximums:

  • Maximum lines
  • Maximum quantity
  • Maximum shipments
  • Maximum value
  • Maximum volume
  • Maximum weight

If more than one maximum applies to a wave record, the system will close a wave when it reaches one of the maximums. This allows you to manage the waves at multiple levels.
