
        
        <h1 data-source-node="n56">Warehouse Mobile - Activity Architect</h1>
        <p data-source-node="n57"><b data-source-node="n58">Activity Architect</b> is the user interface utility that enables you to configure (build your own) the SRC screen flow files for Warehouse Mobile (WM). It is designed to make customizations easily and quickly for WM to meet the customers’ requirements.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Permission: User needs to have the required permission for Activity Architect.</p>
        <p data-source-node="n61"> </p>

            </li>
            <li data-source-node="n66"><a href="#Configuration" data-source-node="n67">Configuration screen</a>

        <h4 data-source-node="n68"><a name="Landing" data-source-node="n69"></a>Landing Page</h4>
        <p data-source-node="n70"> </p>
        <p data-source-node="n71">This screen will list out all the SRCs that are configured in SCALE and are grouped by functional area.  User can copy or view any record.  User’s will only be able to change or delete the custom (non-system created) files.</p>
        <p data-source-node="n72"> </p>
        <p data-source-node="n73">
            <img loading="eager" data-source-node="n74">
        </p>
        <p data-source-node="n75"> </p>
        <p data-source-node="n76">Each configuration has three actions that can be performed.</p>
        <p data-source-node="n77"> </p>
        <p data-source-node="n78">Copy (<img style="width: 27;height: 26" loading="eager" data-source-node="n79">) - will open the copy SRC window where the user will need to specify SRC description and File (json file) name (both need to be unique). Once you have the details entered, the system will open in edit mode and will be available for customization.</p>
        <p data-source-node="n80"> </p>
        <p data-source-node="n81">View (<img style="width: 29;height: 26" loading="eager" data-source-node="n82">) - Will open the configuration screen in read only mode and the user will be able to navigate and preview the properties of the SRC file.</p>
        <p data-source-node="n83"> </p>
        <p data-source-node="n84">Edit (<img style="width: 29;height: 29" loading="eager" data-source-node="n85">) - Will open the configuration screen in edit mode where user can make changes or customize the SRC as needed.</p>
        <p data-source-node="n86"> </p>
        <p data-source-node="n87">Delete (<img loading="eager" data-source-node="n88">) - Will be able to delete the custom SRC files created. Note: The SRC record which is assigned to a warehouse mobile menu cannot be deleted.</p>
        <p data-source-node="n89"> </p>
        <p data-source-node="n90">Actions - The actions drop down has the following options</p>
        <ul data-source-node="n91">
            <li data-source-node="n92">New - Click to create new custom warehouse menu record. </li>
            <li data-source-node="n93">Configuration - Click to to view the Warehouse Mobile Menu insight screen. For more information read <a href="e7b8c0dac59d9e7ba6729183550dbb140adbb73accd313c5b32a0ea8a9252235.html" class="MCXref xref" data-source-node="n94">Using Warehouse Mobile Menu Insight</a></li>
        </ul>
        <p data-source-node="n95"> </p>
        <h4 data-source-node="n96"><a name="Configuration" data-source-node="n97"></a>Configuration screen</h4>
        <p data-source-node="n98"> </p>
        <p data-source-node="n99">This is the User Interface based utility screen where user will be able to customize the SRC screen to meet the customer’s needs.</p>
        <p data-source-node="n100"> </p>
        <p data-source-node="n101">Below is a diagram explaining the user interface layout features of the Activity Architect.<img style="width: 1140;height: 650" loading="eager" data-source-node="n102"></p>
        <p data-source-node="n103"> </p>
        <p data-source-node="n104"><b data-source-node="n105">1</b>.- Tile of the screen is displayed. </p>
        <p data-source-node="n106"> </p>
        <p data-source-node="n107"><b data-source-node="n108">2</b>.- The name of the SRC file that is being viewed/edited.</p>
        <p data-source-node="n109"> </p>
        <p data-source-node="n110"><b data-source-node="n111">3</b> -. <b data-source-node="n112">Action Menu</b> - Three actions can be performed which will be displayed in the drop-down on clicking the action menu.</p>
        <ul data-source-node="n113">
            <li data-source-node="n114">View/Edit Config Data Model</li>
            <li data-source-node="n115">View/Edit Initial Data Model</li>
            <li data-source-node="n116">View/Edit Initial Config Model</li>
        </ul>
        <p data-source-node="n117"><b data-source-node="n118">4</b>.- <b data-source-node="n119">Cancel</b> - Discard all the selections and return to the Landing page.</p>
        <p data-source-node="n120"> </p>
        <p data-source-node="n121"><b data-source-node="n122">5</b>.- <b data-source-node="n123">Save</b> - All selection/changes for the configuration SRC file is saved.</p>
        <p data-source-node="n124"> </p>
        <p data-source-node="n125"><b data-source-node="n126">6</b>. - <b data-source-node="n127">Architect Pane</b> - This pane loads the Json file in a easily navigable tree structure form. You can toggle the nodes and expand the specific areas of requirement. Each node can be expanded and collapsed for entering and modifying the file.</p>
        <p data-source-node="n128"> </p>
        <p data-source-node="n129"><b data-source-node="n130">7</b>.- <b data-source-node="n131">Preview Pane</b> - The pane dynamically renders the changes made to the configuration and enables the user to visualize the user interface changes made. Also, when the user selects each node, page or control in the architect pane, the corresponding user interface label gets highlighted. </p>
        <p data-source-node="n132"> </p>
        <p data-source-node="n133"><b data-source-node="n134">8</b>.- <b data-source-node="n135">Properties Pane</b> - Each node section that is selected on Architect pane is detailed in this pane. The properties pane enables user to specify the details for the specific control, action, comprised of accordions (properties, information, validation, action modal data and so on) depending on the type of control selected.</p>
        <p data-source-node="n136"> </p>
