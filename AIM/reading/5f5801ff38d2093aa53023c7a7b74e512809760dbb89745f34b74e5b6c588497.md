
        
        <h1 data-source-node="n56"><a name="kanchor976" data-source-node="n57"></a>Master Bill Of Lading (BOL)</h1>
        <p data-source-node="n58">A master bill of lading has generally the same layout as a regular bill 
 of lading, but it displays a combination of several shipments instead 
 of one. For example, if you had three shipments and the system generates 
 a master BOL document for those shipments, the master BOL would represent 
 the characteristics (carton count, weight, etc.) of all the shipments 
 as if they were one shipment. The master BOL, then, is a document that 
 covers an entire shipping load, rather than just one shipment.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>

        <h4 data-source-node="n71"><a name="types" data-source-node="n72"></a>Master Bill of Lading Types...</h4>
        <p data-source-node="n73">There are two types of Master Bill of Lading's in the application:</p>
        <ul type="disc" class="ul_1" data-source-node="n74">
            <li data-source-node="n75">Consolidator: 
 This type of master BOL is used when you have several shipments going 
 to different final destinations, but are all first hauled to a single 
 consolidation point. This "consolidator" document will display 
 the grand total of shipments that are destined for the freight consolidation 
 point, and the underlying regular bill of lading documents for each shipment 
 will indicate which shipment is going where. You can define the consolidation 
 destinations in the Freight Consolidator Window.<br data-source-node="n76"> </li>
            <li data-source-node="n77">Multi-Stop: 
 This type of master BOL is used for a multi-stop truck load (TL), where 
 the master BOL document represents the entire trip. Each shipment’s regular 
 bill of lading, then, represents just one of the stops along the route. 
 </li>
        </ul>
        <p data-source-node="n78"> </p>
        <p data-source-node="n79"> </p>
        <h4 data-source-node="n80"><a name="multOrderPallet" data-source-node="n81"></a>Master BOLs and Multiple Order Pallets...</h4>
        <p data-source-node="n82">The system never represents multiple order pallets on an underlying bill of lading, only on a Master Bill of Lading. The reason for this is because it is possible to have multiple Ship To’s on the same multiple order pallet. Since the Master BOL can represent multiple Ship To’s for the consolidation shipments type, and multiple stops for the truckload with multiple stops type, the multiple order pallet is represented as a "handling unit." The handling unit on the Master BOL will always represent the top level containers. When a multiple order pallet is used, however, it is possible that this pallet could contain child or parent containers from multiple underlying BOL’s.   For this reason, a multiple order pallet ID will only be counted once in the handling unit calculation on the Master BOL.</p>
        <p data-source-node="n83"> </p>
        <h5 data-source-node="n84">Example: Multiple Order Pallets with one level of shipping containers and loose containers [Consolidation]
</h5>
        <p data-source-node="n85">The Master Bill of Lading will represent the multiple order pallet as the top-level container and the single level shipping containers as a package.  A loose container (container is NOT on a multiple order pallet) will be counted as a handling unit and package. 

The underlying Bills of Lading will represent the handling unit, package, and weight totals as if the shipping containers were NOT tied to multiple order pallet (i.e. the system will ignore the multiple order pallet when calculating these  values).</p>

        <h4 data-source-node="n107"><a name="notes" data-source-node="n108"></a>Miscellaneous Notes...</h4>
        <ul type="disc" class="ul_1" data-source-node="n109">
            <li data-source-node="n110">
                <p data-source-node="n111">The Pro Numbers will be same in Master Bill of Lading and the underlying Bills of Lading if the flag ‘'One Pro Number per load" is set to Yes in Carrier type Configuration. The Pro Numbers will be unique in both Master Bill of Lading and the underlying Bills of Lading if that flag is set to No.<br data-source-node="n112"><br data-source-node="n113"></p>
            </li>
            <li data-source-node="n114">Master Bills of Lading can be automatically generated 
 during the paperwork wave step. You can also manually generate a master 
 BOL from the Shipment Insight screen.<br data-source-node="n115"><br data-source-node="n116"></li>
        </ul>
