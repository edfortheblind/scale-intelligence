Defining Dock Management Flow Records

A dock management flow record includes information which determines how the system will assign a dock location destination to a shipment line/container, and if the line/container is eligible for assignment. Each flow record is made up of a series of detail records that identify what selection and assignment strategies that the system should use when a quantity hits a certain status in your status flow. You can indicate what type of dock location you want the system to assign to this entity. Also, both the flow header and detail(s) have a default location that the system will assign as a "fallback" option in case no eligible dock area/positions are found. Dock Area Carrier Assignment is only used when the dock assignment wave step uses the “Select Dock Area Using Carrier” selection strategy. If the flow detail does not have a selection strategy associated with it, then dock assignment uses the detail’s default location. The default location on the header is used as a fallback when no detail has been found.

 

The first step in assigning shipments (lines/containers) a dock location is to find a Dock Management Flow Header record that matches the shipment record type’s (shipment line’s/shipping container’s) warehouse and custom status flow. After finding a matching dock management flow header record, the system will select a flow detail record that matches the shipment line’s/shipping container’s status. The status retrieved is based on whether the shipment line/shipping container is in a pre-picking status (anything before In Picking) or post-picking status (anything beyond In Picking). Dock Assignment needs to look into the “future” when assigning dock locations in the wave. The system considers a line/container in a "pre-picking status" when assigning dock locations in the wave. Dock Assignment will retrieve the first status after In Picking ("post-picking status") to find the correct dock management flow detail record. The close container and shipment/dock management work putaway (when creating the next move) processes will use the current status of the container ("post-picking") to determine whether to create the next move, and then look at the next status to determine what dock location subclass, strategy, and dock location to assign. Please note that if the line/container does not have a custom status flow assigned to it, the system will look for a flow record with a blank status flow.

 

NOTE: Dock location assignment only occurs for entities that have a status of greater than In Picking and less than or equal to Ship Confirm Pending.

 

To see more details on how the system determines what dock location to assign, see the process flow diagram on the Dock Management Process Summary topic.

Procedures: Header Fields...

  1. Use the Warehouse Field to indicate the warehouse where the dock locations managed by this flow record reside.

  2. Use the Custom Status Flow Field to indicate the status flow that will determine which shipment lines/containers are eligible for the system to evaluate using this flow record. Note that if the shipment line does not have a custom status flow specified, then the system will look for a record in this flow with a blank custom status flow defined.

  3. Use the Default Location Field to indicate the dock location that the system will assign if no dock management flow details match the line's/container's current status. Note that the system limits your choices in this field to dock locations with a packing subclass. Therefore, you would most likely select your warehouse's packing area location for this field's value.

  4. Use the Manual Dock Door Assignment Checkbox to indicate that the system will not create the next move when the dock door on a shipping load is not assigned. Once the dock door has been manually assigned, the system will then create the dock management work next move to the dock door (when the create next move setting is selected on the flow). Note that the system only evaluates this setting when the next move is to the dock door.

 

Procedures: Detail Fields...

  1. Use the Status Field to indicate the status that a shipment line/container needs to be at in order to be eligible to be assigned the indicated type of dock location. For example, suppose your status flow is configured that a container goes into a Staging Pending status when it is closed. If you have set up a flow detail record for Staging Pending (and a location subclass of Staging), then the system will assign a staging location to a line/container that is in this status.

  2. Use the Location Subclass Field to indicate the type of dock location that you want the system to assign to a line/container when it is processed by this flow detail.

  3. Use the Allow Nest After Putaway Checkbox to indicate to the system that you want the nest after putaway screen to display (upon delivery to a To Dock Location) when putting away shipping containers. Note that the Nest After Putaway Check box on the Work Profile Window must also be selected to use this functionality.

  4. Use the Create Next Move Checkbox to indicate that the system will invoke the work creation process to create the work to represent the transfer of a container from one dock location to another. This is referred to as "creating the next move" for the transfer action. For example, a dock worker may need to move a container residing at a packing location to a staging location. When the packer closes the container, the system automatically locates the container to a staging location. The system will find the appropriate flow detail record (based on the shipping container’s warehouse, custom status flow, and status), and determine if work for this transfer needs to be created.

    A situation where you would not want to create the next move is if you want a user to manually assign all dock locations.

  5. Press OK. The system will save your record.
