Text Message Assignment

This feature lets you link predefined text messages to specific items or accounts, optionally filtered by company. When a related work instruction is processed, the system displays the message on Warehouse Mobile devices. The actual text message must be defined on the Text Message Window before you can associate it with an item/company or account/company.

 

For example,If a company requires a safety booklet to be inserted with an item, a message such as “Insert Safety Message” can be assigned to that item for the specified company. This message will appear only when processing that item for that company.

 

Assign Text Message

 

  • Item Field to associate a specific item with a text message. Each time this item is processed during a work execution, the system will display the message.

  • Account Field to associate a specific account with a text message. Each time someone processes a work instruction for this account, the system will display the message.

  • Use the Company Field to identify a the company associated with the item and/or account you specified above. This allows you narrow when the message is displayed based on company.
