
        
        <h1 data-source-node="n57">Can Be Used in Carrier Assignment Checkbox</h1>
        <p class="p_1" data-source-node="n58">This checkbox indicates if the system can 
 select this carrier during carrier assignment.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">If 
 this checkbox is checked, the system can select this record during 
 carrier assignment. You will want<a name="kanchor2088" data-source-node="n61"></a> to select this checkbox for carriers 
 that regularly transport your products.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64">If 
 this checkbox is not checked, the system cannot select this record 
 during carrier assignment. However, you can manually assign this carrier 
 to a shipment. To minimize processing time, consider not selecting this 
 checkbox for carriers that rarely service your warehouse and customers.</li>
        </ul>
