Value Field

This field represents the monetary value of an entity.

 

 

On the Filter Data Configuration Windows / Query Configurations / Custom Search Criteria Window...

This field is included on all the filter data criteria windows. The Value Field, Attribute Field, and Operand Field work together to create the criteria that the system uses to select records. For example, if the wave criteria record identifies the attribute as 'Customer, the Operand as '=', and the value as 'Wal-Mart', then the criteria for selecting records is that the customer must be Wal-Mart.

 

 

Using Serial Number Templates / Lot Templates...

This field indicates the characters you want as a constant on every serial number/lot that uses this template. For example, you could enter a dash "-" to separate two segments of characters. Note that you must select constant in the Type Field in order to enter a value into this field.

 

 

On the Wave Screen...

This field indicates the total value of the shipment(s) associated with a certain customer that are currently in the pool. The system calculates this value using the item(s) "Net Value."

 

 

On the Shipping Container Screen...

This field indicates the total value of the item(s) in this container.

 

 

On the Shipment Screen...

This field indicates the total value of the line(s) on this shipment. The system calculates this value using the item(s) "Net Value."

 

 

On the Carrier EDI Reference Window...

This field indicates what actual data that you want SCALE to send to the transportation system.
