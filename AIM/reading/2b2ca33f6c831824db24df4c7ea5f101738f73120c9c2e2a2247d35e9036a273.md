
        
        <h1 data-source-node="n56"><a name="kanchor228" data-source-node="n57"></a>Quantity Needed Per Item Field</h1>
        <p data-source-node="n58">This field identifies the number of a component that you would need 
 to assemble one finished item. Note that this is only valid if the Related 
 Line Number Field contains a value.</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Interface Note... </h5>
        <p data-source-node="n61">The system will 
 calculate the total quantity based on the quantity of the parent item, if you leave the total quantity blank on the component 
 item.</p>
