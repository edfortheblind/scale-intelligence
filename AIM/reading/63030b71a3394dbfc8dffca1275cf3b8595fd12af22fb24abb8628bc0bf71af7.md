
        
        <h1 data-source-node="n56"><a name="kanchor2080" data-source-node="n57"></a>Rating Print Driver Symbol Field</h1>
        <p class="p_1" data-source-node="n58">This value is defined for Progistics documents 
 on the Print Device Window. The print driver translates information transmitted 
 from Windows to the printer. If you don't select the correct driver, the 
 printer cannot produce the document. Before you begin, obtain a list of 
 the valid drivers from the Progistics CD.</p>
