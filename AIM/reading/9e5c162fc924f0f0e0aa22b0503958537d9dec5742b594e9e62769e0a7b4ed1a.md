
        
        <h1 data-source-node="n56"><a name="kanchor615" data-source-node="n57"></a>Add and Delete Exit points (WebAPI)</h1>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">Exit points can be added and deleted for WebAPI category only. These WebAPI exit points are primarily used for Warehouse Mobile application.</p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Add Exit Point</h5>
        <ul data-source-node="n62">
            <li data-source-node="n63">Access 
 the <b data-source-node="n64">Exit Point Control</b> window. Click <b data-source-node="n65">Actions</b> &gt;&gt;<b data-source-node="n66">Add Exit Point</b>.</li>
            <li data-source-node="n67">In the <b data-source-node="n68">Exit Point Create new</b> window</li>
            <li data-source-node="n69">Select the actions from the drop-down list. The options for selection are get, post and put.</li>
            <li data-source-node="n70">Under Execute section, select Before or After<ul data-source-node="n71"><li data-source-node="n72">Before -Will call the exit point before the API action </li><li data-source-node="n73">After - Will call the exit point after the API action</li></ul></li>
            <li data-source-node="n74">Click <b data-source-node="n75">OK</b>.</li>
        </ul>
        <h5 data-source-node="n76">Delete Exit Point</h5>
        <ul data-source-node="n77">
            <li data-source-node="n78">Access 
 the <b data-source-node="n79">Exit Point Control</b> window. Click <b data-source-node="n80">Actions</b> &gt;&gt;<b data-source-node="n81">Delete Exit Point</b>.</li>
            <li data-source-node="n82">The <b data-source-node="n83">Exit Point - Delete</b> window is displayed.</li>
            <li data-source-node="n84">Select the Exit Point from the drop-down list.</li>
            <li data-source-node="n85">Click <b data-source-node="n86">OK</b>.</li>
        </ul>
