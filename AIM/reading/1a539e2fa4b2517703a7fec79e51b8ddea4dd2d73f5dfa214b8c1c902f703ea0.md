
        
        <h1 data-source-node="n57"><a name="kanchor2022" data-source-node="n58"></a>Activating Staging/Loading Functionality</h1>
        <p data-source-node="n59">In order to be able to place/transfer containers/shipments/loads onto staging and/or dock door locations on your shipping dock, you need to first indicate to the system that you want your outbound processing flow to place containers/details into these type of locations. You can do this by placing the following statuses into your status flow (in the <a href="c64663f2d1fe4bf8dc0a66e645cc75783e17198a92c170ac8ea0717151979dd8.html" style="font-weight: normal" data-source-node="n60">Functional Area Window</a> if you are using the default status flow, or the <a href="34d74c198eef5e1c5f428dd7a220e45d770547349bf3c11fc73ba3c50a3c0edd.html" style="font-weight: normal" data-source-node="n61">Custom Status Flow Window</a> if you are using a custom status flow). Note that you do not need to add all of these statuses in order to use parts of this dock management functionality (for example, to use staging you do not need to add the status for the loading functionality). </p>
