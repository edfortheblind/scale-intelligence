        <h5 data-source-node="n91">Creating a New Wave Record from the Wave Insight Screen:</h5>
        <ol data-source-node="n92">
            <li value="1" data-source-node="n93">
                <p data-source-node="n94">Access the Wave Insight screen from the Order Planning system menu.<br data-source-node="n95"><br data-source-node="n96"></p>
            </li>
            <li value="2" data-source-node="n97">
                <p data-source-node="n98">Open the Actions menu and tap on New.  This opens the New Wave screen.<br data-source-node="n99"><br data-source-node="n100">- To define this wave based 
 on a wave master record, select a wave master to create a wave based on a wave master.  The auto release option is based on what is configured on the wave master and it is disabled when the wave master has been selected. </p>
                <p data-source-node="n101">Note: Only the authorized  wave masters  for the selected warehouse are shown which are defined in wave master configuration.<br data-source-node="n102"></p>
                <p data-source-node="n103">
                    <br data-source-node="n104">
                </p>
                <p data-source-node="n105">- To define this wave based 
 on a wave flow record, enter a wave name, select a wave flow, and set the auto release option to create a wave based on a wave flow.<br data-source-node="n106"><br data-source-node="n107"></p>
            </li>
            <li value="3" data-source-node="n108">
                <p data-source-node="n109">Tap on the Save button to add the wave to the system.  A success message will be displayed and it will navigate back to the Wave Insight screen.</p>
            </li>
        </ol>
        <p data-source-node="n110">NOTE: The New option is available from the Wave Insight when showing active, completed, cancelled, or released waves, but the newly added wave is only visible when showing active waves. </p>
