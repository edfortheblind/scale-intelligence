Returns MSN Field

The Returns MSN (Master Sequence Number) value is an internal identifier assigned to a shipping container by Progistics. This value is used for UPS returns processing. It is assigned at the same time as the returns tracking number. Progistics uses it to search for containers in its system.

 

NOTE: This field will not have a value in it unless the UPS Return accessorial is assigned to a container, and the container is manifested.
