Wave Process Summary

** Functionality **

Process Flows

 

 

Summary...

A wave represents the different steps that the system uses to retrieve orders from the pool, and process them into the outbound portion of SCALE. All wave activity is defined on the wave master record. The system uses this master record to identify how to execute the wave during the run wave process, and what entities to create from the shipments included in the wave (such as allocation requests, containers, etc).

The following are key features of the wave functional area:

 

 

Wave Priority...

The wave priority value determines when the wave is initiated, in relation to other wave records. The lower the priority number, the sooner the wave is run.

 

 

 

Wave Criteria...

The wave criteria determines which shipments will be processed by a wave. You can set the wave criteria on any combination of shipment values. This allows you to create wave records for particular customers, carriers, or other shipment specific value.

 

 

 

Wave Modes...

A wave mode determines how a wave is initiated.

  • Automatic - When you process a wave in automatic mode, the system will automatically run it after the build wave process is complete. This provides a streamlined approach and minimizes user intervention.

     

  • Build Inactive - The wave is not available for use at this time. The system will not run this wave. This mode allows you turn off a wave that you don't want to delete, but should not currently use. Build Inactive is commonly used for seasonal items.

     

  • Manual - When you process a wave in manual mode, you must manually select to run a wave. The system will not automatically run it for you. Manual build is helpful for large waves. It also allows you to manage processing time demands per wave.

     

  • Scheduled - When you process a wave in scheduled mode, the system will run this wave according to the time interval defined on the Scheduled Job Window.

 

 

Wave Maximums...

A wave maximum determines how many shipments can be included in a wave. Any combination of the following values can be used to define a wave maximum:

  • Total number of shipments

     

  • Total number of shipment details

     

  • Total number of units (defined at the container type level)

     

  • Maximum value of product

     

  • Maximum weight of product

     

  • Maximum volume of product
