
        
        <h1 data-source-node="n56"><a name="kanchor1571" data-source-node="n57"></a>Dock Management Window Setup Prerequisites</h1>
        <p data-source-node="n58">Please address the following configuration matters before using the Dock Manager Window.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Related Topics...</h4>
        <p data-source-node="n62"><a href="9857f2ac70834cdabe3e8245f2ee06c0451ed99523ada65852b8863953ad7b1c.html" data-source-node="n63">Dock Management Process Summary</a>
        </p>
        <p data-source-node="n64"><a href="07edc31677cc85116035ff7f2dff1c2a3f7a1a38afdb4aaf867617691a7483ac.html" data-source-node="n65">Dock Management Setup Overview</a>
        </p>
        <p data-source-node="n66"><a href="01a557bc291612fca0d6350cf5de65e550888ef1bdffbf012f81b9fc22c8d55d.html" data-source-node="n67">Using the Dock Manager Window</a>
        </p>
        <p data-source-node="n68"> </p>
        <p data-source-node="n69"> </p>
        <h4 data-source-node="n70">General Setup Steps...</h4>
        <ul data-source-node="n71">
            <li data-source-node="n72">Create Dock Locations (staging, dock door) on the Location Window. If the appropriate locations are not created, nothing will display on the Dock Manager Window.<br data-source-node="n73"><br data-source-node="n74"></li>
            <li data-source-node="n75">Perform other dock management configurations as appropriate. These are outlined on the <a href="07edc31677cc85116035ff7f2dff1c2a3f7a1a38afdb4aaf867617691a7483ac.html" data-source-node="n76">Dock Management Setup Overview</a>.<br data-source-node="n77"><br data-source-node="n78"></li>
            <li data-source-node="n79">Note the <a href="2d3c4f6cee843f27c5cb32b46c0d85281771c240987b052f16b643019521fef0.html" data-source-node="n80">Number Of Rows Field</a> on the Dock Tab of the Location Window. This is where it is determined how many rows the system will display for a particular staging location on the Dock Manager Window.<br data-source-node="n81"><br data-source-node="n82"></li>
            <li data-source-node="n83">In addition, you can add or modify some of the properties of the Dock Manager Window components, such as altering the data grids component columns, or adding gauges to the gauges component. These types of modifications need to be configured by a technical resource (see the <a href="81d022a2ab379af5c9e945433d1bd3f6e09728fcfd355546989e79b3a0ecfa54.html" data-source-node="n84">SCALE SDK</a> for information on these procedures).</li>
        </ul>
        <p data-source-node="n85"> </p>
        <h4 data-source-node="n86">Note About Security For Drag-And-Drop Actions...</h4>
        <p data-source-node="n87">You can define security for drag-and-drop actions in the same manner as action security in other SCALE windows. In the Security Window listing for the Dock Manager Window, there are a number of drag-and-drop security options available, such as "transfer load to dock door" and "assign shipment to position". For more information on configuring security settings, see the topic <a href="7455e0507949c7f8485e8beb4cca47f7576e8f57283c073b96738a810f6a52f7.html" data-source-node="n88">Creating Security Records</a>.</p>
