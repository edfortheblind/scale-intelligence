
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Disposition Code Record</h1>
        <p data-source-node="n58">When receiving items, you can require workers to scan a disposition code for each container. These codes reflect the condition or status of the inventory in the container—such as good, damaged, or broken. Disposition codes are especially useful for processing returns. Additionally, since each code is tied to a specific locating rule, the system can determine storage locations based on the item's condition.</p>
        <p data-source-node="n59"> </p>
