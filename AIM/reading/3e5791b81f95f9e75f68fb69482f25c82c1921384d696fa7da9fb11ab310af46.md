
        
        <h1 data-source-node="n56"><a name="kanchor1985" data-source-node="n57"></a>Labor Plan Name Field</h1>
        <p data-source-node="n58">You can use this field  to provide an additional description for a labor plan. For example, suppose you are recalculating a labor plan for the third time. You could then give it a name of "My Labor Plan, Draft 3" (or something similar) to differentiate it from previous incarnations of this plan. Note that this is an optional field.</p>
