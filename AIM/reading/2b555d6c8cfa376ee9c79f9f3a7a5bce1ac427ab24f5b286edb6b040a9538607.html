Clear Location Checkbox/Toggle

If this setting is active, the system will allocate from a location inventory record (not the location as a whole) only if the location can be “emptied” without exceeding the demand quantity or the forward location capacity. Also, the system will filter out any location inventory records which has quantity more than the demand or the location capacity. Keep in mind that this setting applies to all types of allocation (shipment, replenishment, work order).

  

 

Examples...

Suppose Location A has two lots (lot-1 =150 EA, and lot-2=70 EA).

  • Replenishment Allocation: IF forward location capacity is only 100 EA, the system ignores the location inventory record with 150 EA, and allocates 70 EA of lot-2. Similarly, in the case of demand replenishment, if the demand is for 100 EA, the system ignores the location inventory record with 150 EA, and allocates 70 EA of lot-2.

  • Shipment Allocation: If the demand for the shipment is for 100 EA, the system ignores the location inventory record with 150 EA, and allocates 70 EA of lot-2.

  • Work Order Allocation: If the demand is for 100 EA of a component item, the system ignores the location inventory record with 150 EA, and allocates 70 EA of lot-2.
 
Advanced Allocation Note...

If a shipment is using the Advanced Allocation functionality, then this will take precedence over the Clear Location During Allocation setting.
