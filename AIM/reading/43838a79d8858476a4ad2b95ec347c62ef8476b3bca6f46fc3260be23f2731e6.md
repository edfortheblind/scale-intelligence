
        
        <h1 data-source-node="n56"><a name="kanchor1006" data-source-node="n57"></a>Activity Type Field</h1>
        <h5 data-source-node="n58">On the Billing Management 
 Window...</h5>
        <p data-source-node="n59">This field identifies the description for the activity type of a Billing 
 Management trigger header record. This text description can be any value 
 you choose, as long as it corresponds to this value in Billing Management. This value corresponds to Billing Management's <i style="font-style: italic" data-source-node="n60">ActivityType</i> field.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62"> </p>
        <h5 data-source-node="n63">On the Labor Activity Insight Screen...</h5>
        <p data-source-node="n64">This field indicates the work type associated with a particular labor 
 activity record. Note that non work related activities (such as nesting or close container) will use a text resource value to indicate the "work type" for labor activities. Labor Activity Insight Screen allows filtering by free format text on Activity type. See the <a href="../source/downloads/c9821f8e7e37de320979ee48542bd14869e82f531371c7e16571c0738506b924.xlsx" data-source-node="n65">Labor Tracking Values</a> document for more details.</p>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67"> </p>
        <h5 data-source-node="n68"><span class="span_5" data-source-node="n69">On 
 the Manual Labor Entry Screen...</span>
        </h5>
        <p data-source-node="n70">This field identifies a manual labor activity that has a work type of 
 "Approved Indirect Labor", "Approved Direct Labor", or "Unapproved Indirect Labor." 
 </p>
