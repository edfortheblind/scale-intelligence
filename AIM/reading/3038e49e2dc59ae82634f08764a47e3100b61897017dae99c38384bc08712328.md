
        
        <h1 data-source-node="n56"><a name="kanchor1861" data-source-node="n57"></a>Defining Accessorials</h1>
        <p data-source-node="n58">An accessorial is an additional cost levied to cover special processing 
 for a parcel. Examples of accessorials 
 include Cash On Delivery (COD), Delivery Confirmation, or Saturday Delivery. 
 Accessorials 
 are organized into categories, based on their purpose. These categories 
 are referred to in SCALE as accessorial 
 codes. Each code then can have multiple accessorials (which are 
 referred to in SCALE as               accessorial subcodes). 
 For example, all of the Cash On Delivery accessorials, 
 such as COD Amount and COD Instructions, are organized under the category               COD. Then, when you are ready 
 to actually assign the accessorial, you can easily skim through the categories 
 to find a specific accessorial. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The system is shipped with many of the common accessorials predefined 
 for Fed Ex and UPS.</p>

        <h4 data-source-node="n133">Creating an Accessorial Header Record...</h4>
        <ol data-source-node="n134">
            <li value="1" data-source-node="n135">
                <p data-source-node="n136">Use the Accessorial Code Field 
 to identify the accessorial to Progistics. 
 This value is required by Progistics 
 to calculate the accessorial. It is also provided by Progistics. 
 Also provide a description for this code in the Description Field.</p>
                <p data-source-node="n137"> </p>
            </li>
            <li value="2" data-source-node="n138">
                <p data-source-node="n139">Use the Rating ID Field 
 to identify the carrier who offers this accessorial (a rating ID 
 identifies a carrier to Progistics).</p>
                <p data-source-node="n140"> </p>
            </li>
            <li value="3" data-source-node="n141">
                <p data-source-node="n142">Use the Rating Service Field 
 to associate a service level with this accessorial.</p>
                <p data-source-node="n143"> </p>
            </li>
            <li value="4" data-source-node="n144">
                <p data-source-node="n145">Use the Apply Per Container Checkbox 
 to apply this accessorial at the container level, not the shipment 
 level. If this accessorial is to be levied by a parcel carrier (not an 
 LTL or truckload 
 carrier), select this checkbox.</p>
                <p data-source-node="n146"> </p>
            </li>
            <li value="5" data-source-node="n147">Use the Always 
 Apply Checkbox if this accessorial is required for all shipments 
 assigned to this carrier/service combination.</li>
        </ol>

        <h4 data-source-node="n150">Creating an Accessorial Detail Record...</h4>
        <p data-source-node="n151">After you select the Apply Button, select the Detail Records Tab. Select 
 New from the Actions Menu. The system will display the Accessorial Detail 
 Window.</p>
        <ol data-source-node="n152">
            <li value="1" data-source-node="n153">
                <p data-source-node="n154">Use the Accessorial Subcode 
 Field to identify the detail record. This value is provided by 
 Progistics. </p>
                <p data-source-node="n155"> </p>
            </li>
            <li value="2" data-source-node="n156">
                <p data-source-node="n157">Use the Description Field to provide a text description for this subcode.<br data-source-node="n158"><br data-source-node="n159"></p>
            </li>
            <li value="3" data-source-node="n160">Use the Value Type Field 
 to identify what type of information (Address, Alpha, Checkbox, Complex, and Numeric) will be represented with this accessorial 
 detail. See the <a href="dd854f078f9aa394b3e912d7c6c2b140dc55477c6f71b3148fc9cf9a176d2afc.html" data-source-node="n161">Value Type</a> field topic for information on each of these value types.<br data-source-node="n162"><br data-source-node="n163"></li>
            <li value="4" data-source-node="n164">Use the Default 
 Value Field to identify the default value this accessorial. For 
 example, if you charge a flat fee for Saturday delivery, you would define 
 that amount in this field. Later, this value will be displayed with this 
 accessorial on the Accessorial Assignment Window. If you want users to 
 have the option to edit this value when assigning the accessorial, select 
 the Allow Override of Default Value Checkbox.<br data-source-node="n165"><br data-source-node="n166"></li>
            <li value="5" data-source-node="n167">Use the External Symbol Field to indicate the Progistics name for an accessorial. The system passes this symbol to Progistics, which will use it to identify the accessorial during rate calculations.<br data-source-node="n168"><br data-source-node="n169"></li>
            <li value="6" data-source-node="n170">Parent Field: For information, see the <a href="a278ade03378ede7ef8d251c5e3607605cd66db02ef518799419a7e7e5553f7b.html" data-source-node="n171">field topic</a>.<br data-source-node="n172"><br data-source-node="n173"></li>
            <li value="7" data-source-node="n174">Apply at Container Contents Checkbox: For information, see the <a href="fd5741faeb28481042e65596e525048e6e675aefc86a70f1a011a721ad90234b.html" data-source-node="n175">field topic</a>.<br data-source-node="n176"><br data-source-node="n177"></li>
            <li value="8" data-source-node="n178">Use the Allow Override of Default Value Checkbox to indicate if the default value for this accessorial can be changed. For example, suppose you want to assign an "Insurance" accessorial to a shipment, and the default "declared value" for this accessorial is 50.00. If you activate this setting, then you will be able to assign a specific value, say 100.00, for this value. If you do not activate this setting, then you will be able to assign this accessorial, but you will need to accept the 50.00 value.</li>
            <li value="9" data-source-node="n179">
                <p data-source-node="n180"> </p>Use the Required Checkbox 
 to identify if this accessorial subcode 
 is required when its accessorial category is selected. Required subcodes 
 include any value that must be provided for a charge to be computed, like 
 insurance amounts or account numbers. Optional ones could include instructions 
 and other peripheral values.<br data-source-node="n181"><br data-source-node="n182"></li>
            <li value="10" data-source-node="n183">Use the Use Value 
 As Amount Checkbox to indicate whether the value of a container/shipment 
 should become the value of the amount passed to Progistics. During manifesting, 
 if this checkbox is selected, the system will insert the value of the 
 container or shipment, instead of giving the user an error when the Amount 
 Field is not filled. Note that 
 in order for the system to recognize the value for this checkbox, the 
 accessorial detail must be classified as "required for rating" 
 by selecting the Required Checkbox...<br data-source-node="n184"> </li>
            <li value="11" data-source-node="n185">Use the Include 
 Freight Charge In Amount Checkbox to indicate how the system will 
 send the freight charge of a container to Progistics. If this checkbox 
 is selected, the system will make two "calls" to Progistics. 
 The first call will retrieve the freight charge from Progistics. The second 
 will pass the container amount (including the freight charge) in as the 
 amount for manifesting. </li>
        </ol>
