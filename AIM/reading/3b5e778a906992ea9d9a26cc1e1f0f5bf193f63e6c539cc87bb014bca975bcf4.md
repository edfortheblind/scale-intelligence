
        
        <h1 data-source-node="n56"><a name="kanchor873" data-source-node="n57"></a>Integer Field</h1>
        <p data-source-node="n58">This field indicates the character you want to appear in that position 
 in the command string. Use an ASCII value to represent each character. 
 Each row in the grid represents a position in the command string.</p>
        <p data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60">For example, suppose you want to create the 
 following command string: W&lt;carriage 
 return&gt;. You would enter the ASCII value   87 
 in the Integer Field. The system will display its corresponding character 
 value in the Character Field (in this case, a   W). 
 Click the Add Button and the system will add another row to the grid. 
 Now enter the value   13 (representing 
 a carriage return) in the Integer Field. The system again displays its 
 corresponding character value in the Character Field (in this case, a 
 bar).</p>
