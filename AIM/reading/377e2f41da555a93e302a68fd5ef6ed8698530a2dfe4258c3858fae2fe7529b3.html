Defining Adjustment Types

An adjustment type record defines the parameters for a specific inventory management transaction.

 

Cycle Counting Adjustment Type Note...

An adjustment type record named "Cycle Counting" is shipped with the application. The system uses this adjustment type for writing transaction history when a reconciliation is performed from the Cycle Count Request Insight screen. You would not typically perform a cycle count action from the Inventory Adjustment screen.

Using the General Tab...

  1. Use the Adjustment Class Buttons to identify the kind of adjustment that you want the system to perform. This class determines how the system will process the adjustment internally, not its type. When the system uses this record, it will always perform an adjustment, regardless of the value in the Adjustment Type Field.
     
  2. Use the Minimum and Maximum Quantity Fields to set limits to the amount of product that can be adjusted. Note: For a negative adjustment, you must set these values as negatives (-1, -2, -3, etc.). If you use a positive value, the system will add product to the location, not remove it.

    NOTE: The system always uses base UM as the quantity UM for min/max values.

  3. Use the Initiation Type Field to indicate if you want people to adjust product based on item/location combination or solely by license plate.
     
  4. Use the Create Work Checkbox to indicate that you want the system to run the work creation process for transactions of this adjustment type. You may also to select a Work Creation Master that the system will use to create this work. If you do not indicate a work creation master, the system will attempt to use all of the configured masters (in priority order) when generating work. By selecting one here, you are forcing the system to use a specific master.Note also that the system can only create work for positive/negative adjustments, basic transfers, and warehouse transfers.
     
  5. Use the Allow for Frozen Locations Checkbox if this adjustment type can be applied to locations in the status Frozen. Generally, frozen locations are either empty or contain inventory that cannot be allocated. However, you may want to adjust the product in these locations or manipulate its status.
     
  6. Use the Include In Interface Uploads Checkbox if you want to interface records for this adjustment type back to the ERP.

 

Using the Authorized Users Tab

  1. Use the User Name Checkboxes to indicate which user(s) can perform this adjustment type on the Inventory Adjustment screen or RF device.

Using the Warehouse Access Tab

  1. Use the Warehouse Name Checkboxes to indicate which warehouses are eligible for this adjustment type on the Inventory Adjustment screen or RF device.

 

Using the User Defined Data Tab

  1. Use the User Defined Fields to define a value that the system will associate with inventory adjustments when they are performed. This provides an easy method to associate a string of data with every instance of an adjustment type. For example, when configuring an adjustment type, suppose you enter a value for User Defined Field 1 (such as an account number or reason code). Later, when a worker performs that adjustment type, they will see that value defaulted in User Defined Field 1. This could be helpful in tracking different adjustment types in transaction history. Note that you can even use the System Text Editor to edit the name of the user defined field to match the data that it will represent.
