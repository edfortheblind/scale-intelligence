
        
        <h1 data-source-node="n56"><a name="kanchor559" data-source-node="n57"></a>Language Field</h1>
        <h5 data-source-node="n58">Document Window...</h5>
        <p class="p_1" data-source-node="n59">This field indicates the language in which you want a document 
 to display text. </p>
        <p class="p_1" data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"> </p>
        <p class="p_1" data-source-node="n62"><i data-source-node="n63">Notes</i>:<br data-source-node="n64">- The system uses this field for SQL Server Reporting Services documents.</p>
        <p class="p_1" data-source-node="n65"> </p>
        <p class="p_1" data-source-node="n66">- SSRS Reports print the text resources for a document based on the value set in this field, not the language of the user printing the document.<br data-source-node="n67"> </p>
        <p data-source-node="n68"> </p>
