Accessorial Code

An accessorial is an additional charge applied to cover special handling or services for a parcel. Common examples include Cash On Delivery (COD), Delivery Confirmation, and Saturday Delivery. Accessorials are grouped into categories based on their purpose. These categories are referred to in SCALE as accessorial codes. Each code can contain multiple individual accessorials, known as accessorial subcodes in SCALE.

For example, all Cash On Delivery-related accessorials, such as COD Amount and COD Instructions, are grouped under the COD category. This organizational structure allows users to easily browse categories to locate and assign a specific accessorial when needed.

 

The system comes preloaded with many commonly used accessorials for FedEx and UPS.

 

General Information

  • Rating ID: Identifies the carrier offering the accessorial. (The Rating ID links a carrier to Progistics.)

  • Rating Service: Associates a specific service level with the accessorial.

  • Accessorial Code: Identifies the accessorial to Progistics. This field is required and provided by Progistics. A description should also be entered in the Description Field.

Toggle Buttons

 

Apply Per Container - Applies the accessorial at the container level rather than at the shipment level. Use this option for parcel carriers (not for LTL or truckload carriers).

 

Always Apply - Select this option if the accessorial should automatically be applied to all shipments associated with the selected carrier/service combination.

 

 

Add New Subcode

 

Accessorial Subcode- Identifies the specific accessorial detail. This value is provided by Progistics.

 

Description- Provides a brief text description of the subcode.

 

Value Type - Specifies the type of information required for this subcode (e.g., Address, Alpha, Checkbox, Complex, Numeric). Refer to the Value Type topic for more details.

 

Default Value - Specifies a default value for the accessorial. For example, if a flat fee is charged for Saturday Delivery, enter that amount here. This value will be displayed when assigning the accessorial.

To allow users to edit this value during assignment, select the Allow Override of Default Value checkbox.

 

Parent Field: Indicates the parent accessorial detail that the current subcode is subordinate to. Read Parent Field.

 

Miscellaneous Information

 

External Symbol - Represents the Progistics identifier for the accessorial. The system uses this symbol during rate calculation when communicating with Progistics.

 

Toggle Buttons

  • Apply at Container Contents- Typically used when hazardous materials are packed in containers. Refer to additional documentation for more details.. Read for more information.

  • Allow Override of Default Value to indicate if the default value for this accessorial can be changed. For example, suppose you want to assign an "Insurance" accessorial to a shipment, and the default "declared value" for this accessorial is 50.00. If you activate this setting, then you will be able to assign a specific value, say 100.00, for this value. If you do not activate this setting, then you will be able to assign this accessorial, but you will need to accept the 50.00 value.

  • Required - Indicates whether this accessorial subcode is mandatory when its accessorial category is selected.

    • Required subcodes include essential values such as insurance amounts or account numbers.

    • Optional subcodes may include instructions or supplementary information.

  • Use Value As Amount - If selected, this setting allows the value of the container or shipment to be used as the accessorial amount passed to Progistics. This prevents errors during manifesting when the Amount field is not filled. Note: The accessorial detail must be marked as Required for Rating by selecting the Required checkbox for this feature to take effect..

  • Include Freight Charge In Amount - Determines how freight charges are sent to Progistics. If enabled, the system will:

    • Retrieve the freight charge from Progistics.

    • Pass the total amount (including freight) during manifesting.
