
        
        <h1 data-source-node="n56"><a name="kanchor30" data-source-node="n57"></a>Web Session Timeout Field</h1>
        <p data-source-node="n58">This field identifies how long a user's window 
 can sit idle before they are timed out and have to sign on again. This 
 value is primarily a security measure. You can define this value on the 
 Web System Values Window.</p>
