Reviewing Freight Terms

Review the system created freight terms on the Freight Terms Window. During rating, the freight term is passed to Progistics. The system can also print this information on paperwork.

Default Freight Terms...

  • 3rd Party Billing (3rd) - The carrier will obtain payment from someone besides the shipper and the customer. 3rd party billing is often used to accommodate accounts that have one central billing address and multiple ship to locations.

  • Collect (COL) - The carrier will obtain payment from the customer. The shipper is not responsible for payment.

  • Duty and Taxes Will Be Billed To the Consignee (DDU) - The person signing for the parcel will then pay the duties and taxes for parcel, instead of the shipper.

  • Prepaid (PPD) - The shipper will pay the freight charges. The customer is not responsible for payment.

  • Prepaid & Add (PPA) - The shipper will pay the freight charges and later invoice the customer for it.

 

Procedures...

 

Using the System Defined Values Tab
  1. Use the External Rating Symbol Field to indicate the Progistics name for a freight term. The system passes this symbol to Progistics when the system requests a rate.
     
  2. Shipper Pays Freight? Field: This field determines if the shipper is responsible for paying freight charges, or if the recipient is responsible.

    - Select 'Yes' if the shipper is responsible for paying the freight charges. In this case, the system would assign the charges to the warehouse or company sending the product. The system will return the charges as normal if this field is set to 'Yes' (or, if the shipment does not have a freight term specified). Generally, you would select 'Yes' if the freight term is Prepaid or Prepaid and Add. Note that if this is not in a multi-company warehouse, the system will only assign freight charges to the warehouse. For a Bill of Lading, the system will fill the "freight bill to" information from shipment data.

    - Select 'No' if the recipient is responsible for paying the freight charges. In this case, the system would assign the charges to the appropriate party defined on the shipment record. The system will suppress the freight charges if this field is set as 'No.' Generally, you would select 'No' if the freight term is Collect or Third Party. For a Bill of Lading, the system will fill the "freight bill to" information from company/warehouse data.
     
  3. Use the FedEx Express Payment Code Field to indicate the FSMS value that corresponds to the freight term for Express services.
     
  4. Use the FedEx Ground Payment Code Field to indicate the FSMS value that corresponds to the freight term for Ground services.
     
  5. Use the FedEx Terms of Sale Field to indicate the FSMS value for the Terms corresponding to the freight term.
     
  6. Press OK. The system will save your changes.
