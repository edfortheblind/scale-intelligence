
        
        <h1 data-source-node="n56"><a name="kanchor1736" data-source-node="n57"></a>Default Storage Location Field</h1>
        <p data-source-node="n58">This field identify the inventory location where a finished item should 
 be located. The system will default this location on the Work Order Confirmation 
 Window; but, the user can select a different confirm location. This value 
 is also printed on the Work Order Finished Item Putaway List to identify 
 where finished items should be putaway.</p>
