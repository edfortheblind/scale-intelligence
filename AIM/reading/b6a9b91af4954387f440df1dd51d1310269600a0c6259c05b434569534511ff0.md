
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor2073" data-source-node="n58"></a>Container Shape</h1>
        <p data-source-node="n59">A container shape indicates the physical shape of a shipping container. Examples include such shape descriptions as standard or irregular. During the wave's container creation process, the system attempts to put an entire item quantity into the next container type in the container group, and keeps trying until the items will not fit; therefore, putting it in the smallest possible container type. Note that the system will only downsize into sequences that have the same container shape as the container it started with. For example, if the first container the system packs a quantity into was irregular, then the system will attempt to downsize into the following sequences until it finds one that has a value different than irregular.</p>
