
        
        <h1 data-source-node="n56"><a name="kanchor2092" data-source-node="n57"></a>Manual Field</h1>
        <p data-source-node="n58">In the Manual Labor Entry screen, you only have access to enter labor activity using a work type associated with one of these labor types: Approved Direct Labor, Approved Indirect Labor, and Unapproved Direct Labor.  The system automatically logs labor when an Automatic Direct Labor type is associated with a work type.  The system sets the Manual flag to No in these scenarios. For more information, refer to the topic <a href="ecd6824f4100f9dfdb15d4844f57ad203ff4ad1ff78a93680e89edfe421264d0.html" data-source-node="n59">Reviewing Labor Types</a>. </p>
