
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor276" data-source-node="n58"></a>Group Picking Work Sequence</h1>
        <p data-source-node="n59">Group Picking Work Sequence determines the order in which work units within a picking group are executed, aiming to maximize efficiency. When work units are assigned to a transport container, the system uses this configuration to decide the optimal picking sequence.</p>
        <p data-source-node="n60"> </p>
        <ul data-source-node="n61">
            <li data-source-node="n62">
                <p data-source-node="n63"><b data-source-node="n64">Sequence</b> - Determines the processing priority (lower numbers are processed first).</p>
            </li>
        </ul>
        <ul data-source-node="n65">
            <li data-source-node="n66">
                <p data-source-node="n67"><b data-source-node="n68">Order By</b> Field to indicate the order you want the system to process though your sequence records.</p>
                <ul data-source-node="n69">
                    <li data-source-node="n70">
                        <p data-source-node="n71"> Ascending: Choose this option if you want the work units to be processed in ascending order.</p>
                    </li>
                    <li data-source-node="n72">
                        <p data-source-node="n73"> Descending: Choose this option if you want the work units to be processed in descending order.</p>
                    </li>
                </ul>
            </li>
        </ul>
        <ul data-source-node="n74">
            <li data-source-node="n75">
                <p data-source-node="n76"><b data-source-node="n77">Attribute</b> Field to indicate what value you want to sequence work units by. For example, you could choose to sequence the work units by From Location, which would allow you to pick all of the item(s) that reside in the same location first.</p>
            </li>
        </ul>
