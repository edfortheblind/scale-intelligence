
        
        <h1 data-source-node="n57"><a name="kanchor1239" data-source-node="n58"></a>Qualified Device Name Field</h1>
        <p class="p_1" data-source-node="n59">This value identifies the printer to the system. It is defined on the 
 Print Device Window.</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">If this printer is associated with 
 a server, this name should be the exact value that you defined 
 when you added the printer using the Microsoft Add Printers option.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li class="li_1" data-source-node="n64">If 
 this printer is declared on a personal computer (or other non-server 
 location), the qualified device name will identify both the machine that 
 the printer is declared on and the printer itself.</li>
        </ul>
