
        
        <h1 data-source-node="n56"><a name="kanchor1934" data-source-node="n57"></a>Defining Print Devices</h1>
        <p data-source-node="n58">You will need to identify each printer to the system. Any printer that 
 you can view from the network can print system documents; however, any 
 printer you want to use must be declared on the server.</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Prerequisites</h5>
        <p data-source-node="n61">Define the printer to the server using the Microsoft Windows Add Printer 
 Option (Start | Settings | Printers | Add Printer). This 
 must be completed on the server where the application is loaded.</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">WARNING: To minimize printer configuration 
 maintenance, verify that the printer's Network Name is the same as its 
 Share Name. You can check the Share Name by accessing the Printers Window 
 in Microsoft Windows (Start | Settings | Printers). Right click on the 
 printer. Select the Sharing Action. Review the value in the Share Name 
 Field. Note: if you want the printer's Share Name to be different than 
 its Network Name, see the "Changing the Printer's Share Name" 
 section of the topic     <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n64">Printing Paperwork</a>.</p>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">Printers 
 and Vendor Compliant Labels</h5>
        <p data-source-node="n67">Printers producing vendor compliant labels must be accessible through a network share.  Please refer to the Printer Configuration installation guide for more information.</p>

        <h5 data-source-node="n98">Identifying a Printer</h5>
        <p data-source-node="n99">To route the data and template to a specific printer, you must identify 
 the printer to the server.</p>
        <ol data-source-node="n100">
            <li value="1" data-source-node="n101">
                <p data-source-node="n102">Use the Device Name Field 
 to identify the printer to employees. This value should be descriptive 
 and will later be displayed in the Device Field on the Document Routing 
 Window.</p>
                <p data-source-node="n103"> </p>
            </li>
            <li value="2" data-source-node="n104">
                <p data-source-node="n105">Use the Description Field to 
 either reiterate the value in the Device Name Field or to provide a longer 
 description.</p>
                <p data-source-node="n106"> </p>
            </li>
            <li value="3" data-source-node="n107">
                <p data-source-node="n108">Select the printer 
 from the Qualified Device Name Field. 
 Any printer that you declared on the server is available.</p>
                <p data-source-node="n109"> </p>
            </li>
            <ul type="disc" class="ul_1" data-source-node="n110">
                <li data-source-node="n111">
                    <p data-source-node="n112">If 
 the Printer is Declared on a Personal Computer (or other non-server location), the qualified device name will 
 identify both the machine that the printer is declared on and the printer 
 itself. In the example below, Front_Office 
 is the machine and Printer1 is the printer. Since the printer is not declared 
 on the server, its network path is included in its name.</p>
                    <p data-source-node="n113"> </p>
                </li>
                <li data-source-node="n114">If 
 this printer is declared on the server, the qualified device name will 
 just identify the printer. Since the printer is already defined to the 
 server, you will not see a network path.</li>
            </ul>
        </ol>
        <p data-source-node="n115"> </p>
        <h5 data-source-node="n116">Identify a Label &amp; Print 
 Driver</h5>
        <p data-source-node="n117">The procedures below assume that you already created this record when 
 you identified a printer. You will need to complete this step if one of 
 the following conditions exist:</p>
        <ul data-source-node="n118">
            <li data-source-node="n119">You are printing a vendor compliant label.<br data-source-node="n120"> </li>
            <li data-source-node="n121">You are printing a Progistics document or label.</li>
        </ul>
        <p data-source-node="n122">The print driver translates information transmitted from Windows to 
 the printer. If you don't select the correct driver, the printer cannot 
 produce the document. Before you begin, obtain a list of the valid drivers 
 from the Progistics CD.</p>
        <ol class="ol_1" data-source-node="n123">
            <li value="1" data-source-node="n124">Use the Rating 
 Printer Driver Symbol Field to identify the appropriate driver.<br data-source-node="n125"> </li>
            <li value="2" data-source-node="n126">The Rating Printer 
 Stock Symbol Field will include all label choices that are valid 
 for that driver. Select the appropriate label from this Field. See "More 
 on Printers &amp; Stocks" for additional information.</li>
        </ol>
