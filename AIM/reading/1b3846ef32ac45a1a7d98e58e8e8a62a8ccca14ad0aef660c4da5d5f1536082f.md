
        
        <h1 data-source-node="n56"><a name="kanchor1360" data-source-node="n57"></a>Defining Shipment Consolidation Criteria</h1>
        <p data-source-node="n58">A consolidation criteria record identifies one value that two shipments 
 must share for a consolidation to occur. If multiple consolidation criteria 
 exist, the system will require that the shipments meet all of the criteria 
 defined. Common criteria values include ship to, company and warehouse. 
 </p>

        <h4 data-source-node="n81">Procedures...</h4>
        <ol data-source-node="n82">
            <li value="1" data-source-node="n83">
                <p data-source-node="n84">Use the Table Field to identify 
 the shipment value that you want to use as a consolidation criteria. 
 Commonly used values include Ship To, Carrier, and Requested Delivery 
 Date.</p>
                <p data-source-node="n85"> </p>
            </li>
            <li value="2" data-source-node="n86">Select the Required 
 Checkbox if this value is required for manual consolidation. If 
 consolidation occurs during a wave, the system requires that all table 
 values (Step 1) are shared before it will consolidate shipments together. 
 However, during manual consolidation, only those values with this check box 
 selected are required for consolidation.<br data-source-node="n87"> </li>
            <li value="3" data-source-node="n88">Press OK. 
 The system will save your record.</li>
        </ol>
