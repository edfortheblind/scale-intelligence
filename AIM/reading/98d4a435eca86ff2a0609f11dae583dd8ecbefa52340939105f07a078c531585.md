
        
        <h1 data-source-node="n56"><a name="kanchor1798" data-source-node="n57"></a>Performing Address Validation on a Shipment</h1>
        <p data-source-node="n58">The address validation functionality offers users the opportunity to 
 verify that a package has a customer's correct ship to address. When you perform a search, the system will 
 communicate with Progistics to retrieve a list of potential matches for 
 the ship to address currently on the shipment. You can then either 
 choose one of these new addresses and apply it to the shipment; or, cancel 
 out of the window to keep the header's existing ship to address. SCALE uses a web service to retrieve address values from Progistics and 
 display them on the Address Validation Window. </p>

        <h4 data-source-node="n85">Procedures...</h4>
        <ol class="ol_1" data-source-node="n86">
            <li value="1" data-source-node="n87">Select a shipment and choose the Address 
 Validation Selection action. 
 The system will display:<br data-source-node="n88"><br data-source-node="n89">	- The Address Validation screen, 
 if the ship to address is not valid, but Progistics found some potential 
 candidates. Proceed to step 2 below.<br data-source-node="n90"><br data-source-node="n91">	- A message indicating that the ship 
 to address is not valid, and Progistics did not find any potential 
 candidates.<br data-source-node="n92"><br data-source-node="n93">	- A message indicating that the ship 
 to address on the shipment is valid match. <br data-source-node="n94"> </li>
            <li value="2" data-source-node="n95">On the Address 
 Validation screen, the system will display the ship to address 
 that is currently on the shipment. Also, the system will display 
 the potential address matches (retrieved from Progistics) in the results 
 list. The maximum number of address matches that can be retrieved from 
 Progistics is 30.   <br data-source-node="n96"><br data-source-node="n97">	NOTE: Progistics requires the following fields to be defined 
 on the shipment in order to return potential address matches: Address 
 1, City, State, Postal Code, and Country.<br data-source-node="n98"> </li>
            <li value="3" data-source-node="n99">To assign a new 
 address value to the header, select one of the address values and 
 press OK. <br data-source-node="n100"><br data-source-node="n101">	To exit this window without assigning a new address, press the 
 Cancel button.</li>
        </ol>
