
        
        <h1 data-source-node="n56"><a name="kanchor1575" data-source-node="n57"></a>Export Image Resources Checkbox</h1>
        <p data-source-node="n58">This field indicates that you want to export the system "image" 
 resource values using the Translation Wizard. Image resources determine which graphic files are displayed 
 in system windows. By default, the system does not export these resources, 
 because typically they do not need to be translated. However, if for some 
 reason you do need to edit these values, you can do so by selecting this 
 checkbox.</p>
