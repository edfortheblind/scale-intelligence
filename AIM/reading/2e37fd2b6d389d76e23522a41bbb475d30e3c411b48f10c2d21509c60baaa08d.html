Type Field

Using Location Templates...

This field indicates if a location name segment is going to consist of alpha characters (letters) or numeric characters (numbers). The actual values for each segment will be entered in the Location Window.

 

 

 

 

Using Serial Number Templates / Lot Templates...

This field indicates if a template segment is going to consist of alpha characters (letters only), alpha-numeric (letters and/or numbers), numeric (numbers only), or constant (a specific letter, number, and/or symbol, such as a dash or a double-zero).

 

 

Using Web Statistics...

This field is used when running an "Web Statistics" type of scheduled job. It indicates which type of web statistics (Inbound, Outbound, or Item) that you want the system to generate when using this scheduled job.
