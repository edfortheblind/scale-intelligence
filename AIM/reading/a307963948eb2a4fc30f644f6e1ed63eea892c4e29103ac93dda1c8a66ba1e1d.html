Using the Transaction History Insight Screen

You can use the Transaction History Insight screen to search and manage transaction history records in your warehouse. Any time inventory is impacted by either system or user activity, the system writes a transaction record identifying the issue. Examples of transaction types are shipment allocation and short pick adjustment.

Searching/Viewing Transaction History Records...

You can use the Transaction History Insight Screen to search for and view receipt quality records in your warehouse.

  1. Open the Transaction History Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply Filter Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

  • The Transaction History Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • The hyperlink in the internal Id field can be used to open the Transaction History Details screen.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Details Pane...

 

  • The Transaction History Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

  • The Detail Pane of Transaction History Insight contains header fields comprising of Reference ID, Transaction Type, and Location.

  • For more general information about the Detail Pane, see the topic Introduction to Insight Screens.
