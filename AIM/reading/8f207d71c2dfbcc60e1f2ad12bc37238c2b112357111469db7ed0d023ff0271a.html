Allocation Zone Configuration

Overview

 

Allocation Zone configuration defines grouping values used by allocation and picking logic. You can create and maintain allocation zone records and assign them to locations.

 

Note: This configuration is currently accessible only from the Location Configuration wizard and is not available as a standalone configuration outside the wizard.

 

Configure Allocation Zone

 

1. Allocation Zone

 

Select or create an Allocation Zone record.

  • Create New: Create a new allocation zone record.

  • View All: Review and select an existing allocation zone record.

  • Current Selection: Displays the selected allocation zone record.

 

A. Information

 

Zone: Enter the allocation zone identifier.

Description: Enter the allocation zone description.

 

Use Back, Save, Continue, and Finish to manage and complete Allocation Zone configuration.
