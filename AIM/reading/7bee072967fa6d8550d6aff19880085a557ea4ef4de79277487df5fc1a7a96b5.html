Performing Group User-Directed Work...

 

- There are two steps to group-user directed work:

A) Assigning a shipping container/tote to a group

B) Performing the work

- Notes

 

 

 

A) Assigning a Shipping Container/Tote to a Group...

Before you can begin to pick using RF group user picking, you must first assign a shipping container/tote to a group. Note that you can only assign an actual shipping container if that container was created during a wave, and work was created based on that container.

 

1. Log on to your RF Device and select the Work function. The system will display the Work Profile selection screen.

 

 

2. If you have a default work profile defined for your user profile, the system will automatically choose this profile and direct you to the appropriate work screen. Otherwise, you will need to manually choose a work profile.

 

 

3. Perform the next step, depending on if you are assigning a container or a tote:

For shipping containers
a) Scan the container ID.

 

b) Scan the spot you want to assign to this container. Note that if your work profile is configured for system container spot assignment, then you will not need to scan a spot value as it will be assigned automatically by the system.

 

For totes 
a) Scan the tote ID and the related work unit.

4. Press the Assign Button. The system will assign the shipping container/tote to a group. You can now assign another shipping container/tote if you choose to do so.

 

 

5. When finished assigning shipping containers/totes to a group, you can choose to perform one of the following actions:

Cancel: If you choose to cancel, the system will exit the group user work initiation screen.

 

Begin Picks: If you choose to begin picks, the system will display the appropriate first work instruction. Move onto the "Perform Group User Directed Work" section of this topic.

 

Create a New Group: If you choose to create a new group, the system will reset the screen, and you can start assigning containers/totes to a new group.

 

 

 

B) Performing Group User Directed Work...

Once the shipping containers/totes have been assigned to a group, you can now begin the RF group picking process. The procedures below describe how you would perform this pick.

 

1. Log on to your RF Device and select the Work function. The system will display the Work Profile selection screen.

 

 

2. If you have a default work profile defined for your user profile, the system will automatically choose this profile and direct you to the appropriate work screen. Otherwise, you will need to manually choose a work profile.

 

 

3. Scan the container that you want to pick into (either a transport container or the actual shipping container):

 

 

4. Press the Begin Picks button. The system displays the work unit's first instruction on the Pick Confirmation screen

 

 

5. Enter the quantity that you want to pick.

 

 

6. You may have to verify the following values (if your work special handling record is configured to do so):

View Pick Value Verification Options

 

7. You may choose to override certain pick values (if your work special handling record is configured to do so). This is done by entering one of the following values in an edit box next to the appropriate field on the Pick Confirmation Screen. Note that you can also configure the system in work special handling to warn the user an override is about to occur (after they press OK to confirm the pick):

View Override Pick Rules/Options

 

8. Press one of the following picking buttons:

View Pick Button Descriptions

NOTE: If the system groups picks across shipping containers (see Note on Group User Batch Picking), the system will display a pick into shipping container screen, which tells you how much inventory should be place in each container.

 

9. The system will then display the Putaway Confirmation screen, if automatic putaway is not configured on your work profile. Press one of the following buttons:

View Putaway Button Descriptions


 

 

 

Notes...

 

  • When group user work is performed, the system batches the pick quantity across all shipping containers. This improves picking efficiency in the group user scenario. Note that this is based on a unique location inventory record, is always in effect, and is not controlled by the "Group By Loc/LP" work profile setting. Note that serial number tracked items (outbound or inventory) or catch weight tracked items are exceptions to this grouping. Also, the system ungroups the batched work instructions if you partial or short pick the work.

  • You are allowed to pick multiple shipment details going to different putaway locations into a single tote.
