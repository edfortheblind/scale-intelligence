Shipper Cross Reference

This record links a shipper code to a specific warehouse and company combination. It controls which carriers can be rated for that shipper. When a shipper cross-reference record is created in the system, it is also automatically created in Progistics.

In Progistics, the cross-reference record stores the shipper's identity, address, and the carriers eligible for rating. Before rating a shipment, Progistics checks this record. If a carrier is not registered for that shipper, it won’t be included in the rating process. Any changes or deletions to this record in the system will also be reflected in Progistics.

You can define multiple cross-reference records for the same warehouse and company, as long as each record has a unique shipper code.

 

Create Shipper Cross Reference

 

  • Shipper Code - Use this field to link the warehouse/company to the shipper code you defined in the Shipper Code configuration.

  • Warehouse - Identify the warehouse that will use this shipper. If you do not support multi-company processing, the warehouse is the entity that will ship product. In this case, Progistics would then create only one manifest, for the entire warehouse. Conversely, if you select a company (Step 3), the system will generate the manifest per company, regardless of the value defined in this field.

  • Company - required only if your warehouse supports multi-company processing and the shipper code is tied to a specific company. The system will create a manifest for this specific company.

Toggle Button

 

  • Default Shipper -You can mark a cross-reference record as the default shipper using a toggle button. This setting tells the system which shipper code to use by default during rating when a matching warehouse/company is selected in the Shipment or Rate Shopping screens.

Notes

  • Only one default shipper is allowed per warehouse/company (or warehouse/blank company) combination.

  • The first cross reference record created for a warehouse/company is automatically set as the default. This setting can’t be changed on that first record until more records are added for the same combination.

  • Changing the default designation to another record will automatically remove it from the previous default.

  • If multiple records exist for the same warehouse/company, you cannot delete the one marked as the default.
