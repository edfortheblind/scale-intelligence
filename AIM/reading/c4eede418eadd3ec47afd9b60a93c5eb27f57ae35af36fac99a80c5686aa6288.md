
        
        <h1 data-source-node="n56"><a name="kanchor1040" data-source-node="n57"></a>Order ID Prefix Field</h1>
        <p data-source-node="n58">This field indicates the prefix that the system 
 will add to all orders created in the current order entry session. For 
 example, if you entered the value "CMP" in this field, the final 
 shipment ID's for these orders would be "CMP-01", "CMP-02", 
 "CMP-03", etc.</p>
