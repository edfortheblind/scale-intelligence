020/120 Global Ship Request / Reply ETD Field Information...

 

Field 2817 (Document Reference ID)
  • This field is used to indicate a unique ID for each given ETD being uploaded in the transaction.

  • This is a required field for 020/120 transactions.

 

Field 2818 (ETD Document Type)
  • This is an optional field for 020/120 transactions, as SCALE uses FedEx-generated documents.

  • Valid values are:
    1 — Commercial Invoice
    2 — Certificate of Origin
    3 — Pro forma Invoice
    4 — Other

 

Field 2819 (ETD Document Filename)
  • This field contains the fully-qualified filename of the document to be uploaded, including the valid path where this document is located.

  • This is an optional field for 020/120 transactions, as SCALE uses FedEx-generated documents.

  • The maximum length for an ETD filename is 30 characters.

 

Field 2820 (ETD Wait for Confirmation)
  • This is an optional setting to indicate if you want to wait for a confirmation from the back-end system that a customs document was uploaded successfully.

  • This field takes precedence over the configuration when passed in a transaction, IF there is a conflict between the transaction setting and the configuration setting.

  • Valid values are:
    Y — Wait for Confirmation (equates to “Required” in the configuration)
    N — Do Not Wait for Confirmation (equates to “Not Required” in the configuration)

 

Field 2821 (ETD Document Generation)
  • Set as F as SCALE supports only FedEx-generated documents.

 

Field 2822 (ETD Document Status)
  • This field indicates the status of a document within an ETD shipment when returned in the Reply transaction for Shipping (120), Pre-Shipment (149) or Shipment Query (124).

  • Valid values are: 
    01 — Successfully Uploaded
    02 — Upload Pending
    03 — Upload Unsuccessful
    04 — Virus Detected
    05 — File Too Large
    06 — Invalid File Format
    07 — Invalid Document Type
    08 — Invalid Filename
    09 — System Error
    10 — Duplicate File
