
        
        <h1 data-source-node="n56"><a name="kanchor714" data-source-node="n57"></a>Create Work Method Field</h1>
        <p data-source-node="n58">This field indicates how you want replenishment requests to be processed:<ol data-source-node="n59"><ul type="disc" class="ul_1" data-source-node="n60"><li data-source-node="n61"><p data-source-node="n62"><i data-source-node="n63">Automatic</i>: With this option, the replenishment process will allocate the inventory, generate the replenishment requests for eligible locations and mark the inventory as In Transit to the destination location. Work Creation is called directly after replenishment (or during the same wave for Demand Replenishment) and the system creates work  for these requests. If it cannot create work, the system deletes the requests and sets the inventory back to Available at the From Location. </p><p data-source-node="n64"> </p></li><li data-source-node="n65"><i data-source-node="n66">Manual/Scheduled Job</i>: With this option, the replenishment process will allocate the inventory and generate replenishment requests for eligible locations. The inventory is marked as In Transit to the destination location. The process will stop there, and it will be up to the user to manually kick off work creation for request(s) in the Replenishment Insight screen. From the viewer the user can either create work on the fly (the Create Work Immediately option) or mark it so the scheduled job picks it up (Mark for Work Creation option).<br data-source-node="n67"><br data-source-node="n68"></li><li data-source-node="n69"><i data-source-node="n70">None</i>: With this option, the system will allocate the inventory and generate replenishment requests for eligible locations, execute those requests (which marks the quantity On Hand at the destination location), and then generate a Replenishment Pick List (if paperwork is setup properly). You would then use this document to perform the actual inventory movements.<br data-source-node="n71"></li></ul></ol><p data-source-node="n72"> </p><p data-source-node="n73"> </p><p data-source-node="n74"> </p></p>
