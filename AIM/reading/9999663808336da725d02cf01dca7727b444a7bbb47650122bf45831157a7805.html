Changing Window Display Properties

The system includes several default font display properties that should meet most users' needs. These properties include font style, color, and size. The system will remember your personal display properties upon exiting and reopening the application. To view the new display properties, close any open windows. The system will reflect the properties that you set. You do not need to perform any other refresh functions.

 

 

Procedures...

  1. Open the Display Properties Window (Miscellaneous | Display Properties).

    2.  

  2. Select the display category you want to change in the Item Field. You can change the color and/or font for four different system items:

    - Tab Label: This represents the text label of a window tab.

    - Group Box Label: This represents a label of a grouped series of fields in a window.

    - Label: This represents the field names for most windows.

    - Output Data: This represents the value of a field.
     
  3. You can use this window to change the following display properties:
     

    • Change an item's font properties, including the font type, style, and size.

       

    • Change an item's font color by choosing a color from the color palette.

       

    • Indicate if you want tab icons to appear on window tabs. Tab icons are the small picture icons that appear next to a tab label. Check the tab icon field if you wish to have the system display tab icons.

       

    • Indicate if you want a tab text hot track to appear on window tabs. If you check the tab text hot track field, then the tab labels will change to a different color when you place you mouse over them.

       

  4. Press OK. The system will add your changes.
