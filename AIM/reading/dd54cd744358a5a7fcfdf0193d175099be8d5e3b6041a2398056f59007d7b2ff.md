
        
        <h1 data-source-node="n56"><a name="kanchor906" data-source-node="n57"></a>Receipt ID Field</h1>
        <p data-source-node="n58">This field identifies a receipt ID number. This field works with the 
 Receipt ID Type Field, which identifies what receipt ID number represents 
 (purchase order number, bill of lading number, etc). This value is interfaced from the ERP unless 
 the receipt is created on the Receipt Workbench. In this case, the system 
 assigns the receipt ID number. The system also assigns the receipt ID 
 number if you create a receipt using RF blind receiving. However, if you 
 create receipts using the Receipt Insight, you will always have to specify 
 the receipt ID.</p>
