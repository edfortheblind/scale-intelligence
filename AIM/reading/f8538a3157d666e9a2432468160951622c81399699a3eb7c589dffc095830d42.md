
        
        <h1 data-source-node="n56">Creating a Group Picking Work Sequence Record</h1>
        <p data-source-node="n57">The system uses group picking work sequence records to reorder work 
 units of an RF picking group so they can be executed in the most efficient 
 manner. After a worker assigns a number of work units to a transport container, 
 the system will use the rule(s) defined in this record to determine the 
 sequence that the worker will execute the picks. Note that in order to perform RF 
 group picking actions, you need to set up your work profile record to 
 have a work initiation method of "Group User." You will need 
 to log onto the RF device with this profile.</p>

        <h4 data-source-node="n82">Procedures...</h4>
        <ol class="ol_1" data-source-node="n83">
            <li value="1" data-source-node="n84">Use the Sequence 
 Field to indicate the order in which the system will process your 
 group picking sequence record. The lower the number, the sooner the system 
 will process the record.<br data-source-node="n85"> </li>
            <li value="2" data-source-node="n86">Use the Order 
 By Field to indicate the order you want the system to process though 
 your sequence records. <br data-source-node="n87"><br data-source-node="n88">	- Ascending: Choose this option 
 if you want the work units to be processed in ascending order.<br data-source-node="n89"><br data-source-node="n90">	- Descending: Choose this 
 option if you want the work units to be processed in descending order.  
 <br data-source-node="n91"> </li>
            <li value="3" data-source-node="n92">Use the Attribute 
 Field to indicate what value you want to sequence work units by. 
 For example, you could choose to sequence the work units by From Location, 
 which would allow you to pick all of the item(s) that reside in the same 
 location first.<br data-source-node="n93"> </li>
            <li value="4" data-source-node="n94">Press OK. 
 The system will save your record.</li>
        </ol>
