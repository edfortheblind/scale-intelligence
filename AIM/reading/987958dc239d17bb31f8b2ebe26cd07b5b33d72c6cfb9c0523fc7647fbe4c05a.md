
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">Location Type Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Location Type configuration defines physical dimensions and weight limits used by location processing rules. You can create and maintain location type records with dimensional and weight unit settings.</p>
        <p data-source-node="n61"><b data-source-node="n62">Note</b>: This configuration is currently accessible only from the Location Configuration wizard and is not available as a standalone configuration outside the wizard.</p>
        <h4 data-source-node="n63"> </h4>
        <h4 data-source-node="n64">Configure Location Type</h4>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">1. Location Type</h5>
        <p data-source-node="n67"> </p>
        <p data-source-node="n68">Select or create a Location Type record.</p>
        <ul data-source-node="n69">
            <li data-source-node="n70">
                <p data-source-node="n71"><b data-source-node="n72">Create New</b>: Create a new location type record.</p>
            </li>
            <li data-source-node="n73">
                <p data-source-node="n74"><b data-source-node="n75">View All</b>: Review and select an existing location type record.</p>
            </li>
            <li data-source-node="n76">
                <p data-source-node="n77"><b data-source-node="n78">Current Selection</b>: Displays the selected location type record.</p>
            </li>
        </ul>
        <p data-source-node="n79"> </p>
        <h5 data-source-node="n80">A. General</h5>
        <p data-source-node="n81"> </p>
        <p data-source-node="n82"><b data-source-node="n83">Location Type</b>: Enter the location type identifier.</p>
        <p data-source-node="n84"><b data-source-node="n85">Length</b>: Enter the location length value.</p>
        <p data-source-node="n86"><b data-source-node="n87">Width</b>: Enter the location width value.</p>
        <p data-source-node="n88"><b data-source-node="n89">Height</b>: Enter the location height value.</p>
        <p data-source-node="n90"><b data-source-node="n91">Dimension UM</b>: Select the unit of measure for length, width, and height.</p>
        <p data-source-node="n92"><b data-source-node="n93">Maximum Weight</b>: Enter the maximum allowable weight for this location type.</p>
        <p data-source-node="n94"><b data-source-node="n95">Weight UM</b>: Select the unit of measure for weight.</p>
        <p data-source-node="n96"> </p>
        <p data-source-node="n97">Use Back, Save, Continue, and Finish to manage and complete Location Type configuration.</p>
