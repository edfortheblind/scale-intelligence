
        
        <h1 data-source-node="n56"><a name="kanchor1554" data-source-node="n57"></a>Add Comments Field</h1>
        <p data-source-node="n58">This field is displayed on the Comment Text Window, which is accessible 
 from the Shipment or Shipment Line Screen. You can use this window to 
 define comments and associate them with a comment type. This comment type 
 is linked to a document type. When paperwork with this document type is 
 created for the shipment, the comments you created here are displayed 
 on the paperwork.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"><span class="span_3" data-source-node="n62">NOTE:</span> Most comments are interfaced from 
 the ERP to the system. When you create them on this window, the system 
 will only apply them to this specific shipment. It will <i data-source-node="n63">not</i> save the comments and apply them to 
 future shipments.</p>
