Using the Inventory Monitoring Screen

You can use the Inventory Monitoring screen to research and manage locations in a warehouse.

 

 

Notes
  • This topic discusses specific fields represented on this screen as it is shipped in the base SCALE product. If your screen has been customized, different field (s) may appear on your screen.

Navigating/Viewing the Inventory Monitoring Bar Chart...

  1. Access the Inventory Monitoring screen.

  2. The system will display a chart on the first (highest) level which indicates the numbers of active, empty locations in the user's current warehouse broken down by Locating Zone.

  3. Press on a Locating Zone data column, and the system will display the next level of the chart, Location Type.

  4. Press on a Location Type data column, and the system will then display the next level of the chart, Location Template Field One.

  5. When you press on a Location Template Field One column, the system will open the Inventory Insight screen with all the record(s) that meet the criteria you have chosen on the chart displayed on the Insight's data grid.

 

NOTES 
  • On any level of the chart, pressing the Insight button takes you to Inventory Insight with the locations selected that match that graph.

  • On each graph level, the totals at the top of the graph show number of active empty locations, total active locations, percent empty, and frozen empty locations pertaining to that graph.

  • Changing warehouse at the top of the Inventory Monitoring screen displays the open locations from the selected warehouse.

 

 

 

Summary Data

The following summary data totals are accessible from the Inventory Monitoring screen:

 

Total Locations

This value indicates the total number of locations in the warehouse.

 

 

Empty Locations

This value indicates the number of empty locations in the warehouse.

 

 

Percent Empty

This value indicates the percentage of empty locations (number of empty locations / total locations * 100%) in comparison to the total available locations.

 

 

Frozen Empty

This value indicates the number of locations that are active and have a status of Frozen.

 

 

 

 

Indicator Tiles

Indicator tiles display key warehouse data totals. Tapping on a tile will navigate you to the appropriate Insight screen loaded with the appropriate data. The following indicator tiles are shipped with the system:

 

 

Locations less than 10 On Hand

This tile represents the summation of the number of locations that have less than a 10 quantity on hand. Pressing on this tile opens the Inventory Insight screen displaying these locations.

 

 

Pending Replenishments

This tile indicates the number of open replenishment work units. Pressing on this tile opens the Work Insight with the selected instructions.

 

 

Pending Cycle Counts

This tile represents the number of open cycle counts. Pressing on this tile opens the Work Insight with the selected instructions.

 

 

Empty Permanent Locations- with none available (in transit)

This tile represents the number of empty permanent locations that also do not have any inventory in the warehouse. This information could be used to help redistribute forward locations during seasonal inventory changes. Pressing on this tile opens the Inventory Insight screen displaying these locations.
