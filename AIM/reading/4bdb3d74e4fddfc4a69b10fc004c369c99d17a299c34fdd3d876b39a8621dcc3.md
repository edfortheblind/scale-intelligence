
        
        <h1 data-source-node="n56"><a name="kanchor1461" data-source-node="n57"></a>Web Header URL Center Field</h1>
        <p data-source-node="n58">This field indicates the specific URL of the link that will be associated 
 with the graphic that appears at the top-center of the Trading Partner 
 Management Main Menu. The URL should be in this format:</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">LOCAL URL: <i data-source-node="n61">\\YourServer\Directory1\Directory2\yourPage.htm</i><br data-source-node="n62"> </p>
        <p data-source-node="n63">REMOTE URL: <i data-source-node="n64">http::/www.manh.com</i></p>
        <ul type="disc" class="ul_1" data-source-node="n65">
            <li class="li_7" data-source-node="n66">If 
 you are associated with NO companies, the 
 system will load this value from the Web System Values Window (for BOTH 
 internal and external web users).<br data-source-node="n67">	 </li>
            <li class="li_7" data-source-node="n68">If 
 you are associated with ONE company, the 
 system will load this value from the Company Window (for BOTH internal 
 and external web users).<br data-source-node="n69">	 </li>
            <li class="li_7" data-source-node="n70">If 
 you are associated with MORE THAN ONE company, the 
 system will load this value from the Company Window (for internal web 
 users). External web users cannot be associated with multiple companies.</li>
        </ul>
