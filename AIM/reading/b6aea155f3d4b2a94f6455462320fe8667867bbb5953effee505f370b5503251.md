
        
        <h1 data-source-node="n56">CUPS Printer Integration</h1>
        <p data-source-node="n57">Users can now integrate CUPS with the Manhattan Active SCALE application for printing documents and labels. CUPS is an open-source printing system that allows you to configure a system as a printer server. Customers can maintain their own CUPS printer servers and physical printers at their location and connect them to the SCALE application for printing purposes.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">This integration allows customers to have control over the printers accessible to the SCALE application and manage their printing requirements independently.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">The process of integration is as follows</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">1. <b data-source-node="n64">Set up CUPS Printer Servers and Physical Printers</b></p>
        <p data-source-node="n65">Customers have the option to install and maintain their own CUPS printer servers and physical printers. CUPS enables clients to configure and manage print queues, turning their systems into printer servers.</p>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67">2. <b data-source-node="n68">Integration with SCALE Application</b></p>
        <p data-source-node="n69">Customers can connect their CUPS printer servers and physical printers to the  SCALE application using the configuration steps given below. This integration allows users of the SCALE application to print documents and labels using the configured printers.</p>
        <p data-source-node="n70"> </p>
        <p data-source-node="n71"> <b data-source-node="n72">Configuration steps</b></p>
        <ul data-source-node="n73">
            <li data-source-node="n74">
                <p data-source-node="n75"><b data-source-node="n76">IPP (Internet Printing Protocol) of Printer</b>: The IPP of the printer needs to be copied from the CUPS server. This IPP will be used to identify and connect to the printer.</p>
            </li>
        </ul>
        <ul data-source-node="n77">
            <li data-source-node="n78">
                <p data-source-node="n79"><b data-source-node="n80">Creating a New Printer Device in SCALE</b>
                </p>
                <p data-source-node="n81"> </p>
                <ul data-source-node="n82">
                    <li data-source-node="n83">
                        <p data-source-node="n84">	Go to <b data-source-node="n85">Printer Devices</b> in the configuration.</p>
                    </li>
                    <li data-source-node="n86">
                        <p data-source-node="n87">	Choose the option to <b data-source-node="n88">Create New</b> printer device.</p>
                    </li>
                    <li data-source-node="n89">
                        <p data-source-node="n90">	Provide a <b data-source-node="n91">Qualified Device Name</b> which should be the IPP of the printer configured on the CUPS server. This information helps the SCALE application identify and connect to the printer.</p>
                    </li>
                </ul>
            </li>
        </ul>
        <p data-source-node="n92"><b data-source-node="n93">Notes</b>
        </p>
        <ul data-source-node="n94">
            <li data-source-node="n95">
                <p data-source-node="n96">The printer setup, CUPS server configuration, and printer network connectivity are separate from the  SCALE application.</p>
            </li>
        </ul>
        <ul data-source-node="n97">
            <li data-source-node="n98">
                <p data-source-node="n99">Customers are responsible for managing and maintaining their printer infrastructure, which is then connected to the SCALE application for printing.</p>
            </li>
        </ul>
