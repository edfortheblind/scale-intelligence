
        
        <h1 data-source-node="n56"><a name="kanchor513" data-source-node="n57"></a>Discussion: Labor Planning</h1>
        <p data-source-node="n58">Labor planning allows you to forecast how much time and money is required to process a wave's shipment and work details. Labor planning can assess how long it will take to process shipment lines in a wave. In addition, it can assess how long it will take to process work created in a wave. When a wave is run that has work associated with the work type, the system will look at the labor group to determine how many units of this work can be processed (such as pick and put) in a minute. The labor management configurations that you define will determine how the system calculates your labor plan. The Labor Groups and Work Groups work together to determine how your labor plan is calculated.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">System Decisions...</h4>
        <ol data-source-node="n62">
            <li value="1" data-source-node="n63">The system calculates the time required at the work instruction detail level. It sums the work details to calculate the time estimate.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li value="2" data-source-node="n66">The system includes all wave generated work in the plan, provided that its corresponding work type was included in the labor group record. This means that a plan can be generated for the following: shipment allocation work, shipment line work, shipping container work, replenishment work, work order creation work.<br data-source-node="n67"><br data-source-node="n68"></li>
            <li value="3" data-source-node="n69">Once work is created for one work creation request in a wave, the system no longer plans against shipment lines.<br data-source-node="n70"><br data-source-node="n71"></li>
            <li value="4" data-source-node="n72">If work creation cannot create a work unit for a particular shipment line, nothing is included in the planning estimates.<br data-source-node="n73"><br data-source-node="n74"></li>
            <li value="5" data-source-node="n75">If all work fails, so that not one work unit is created in a wave, the labor plan is based on the shipment level again.<br data-source-node="n76"><br data-source-node="n77"></li>
            <li value="6" data-source-node="n78">If a labor plan is called after work is created, the system only selects the labor group records where planning is at the work level. However, if the wave's work types are not defined on a labor group, the system will base the plan off the shipment.<br data-source-node="n79"><br data-source-node="n80"></li>
        </ol>
