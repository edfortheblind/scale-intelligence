Defining Shipment Distribution Criteria Records

The wave process uses a criteria record in this configuration to indicate which shipments (store orders/distros) should be processed using the shipment distribution wave step. For example, you could define a criteria record that said that only a certain customer's store orders are eligible for this processing. These records are associated with a wave master, and the shipment distribution criteria wave step uses the associated criteria record when processing. If you are running a wave without using a wave master (instead using only a wave flow), then the wave step will use the Default shipment distribution criteria record.
