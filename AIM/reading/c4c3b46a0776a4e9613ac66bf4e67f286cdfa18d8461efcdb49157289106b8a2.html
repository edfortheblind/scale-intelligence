Storage Template Field

The storage template used to group together the units of measure that can be used to store a particular group of items. For example, to store soft drinks, you might have a storage template with the following units of measure: can, bottle, 2 liter, case pack, 24 pack, pallet. These UMs (units of measure) are all of the possible containers used for storing soft drinks in your warehouse. When you set up the item unit of measure records for a particular item, you can only select from those values defined on the storage template. If the system processes product not associated with an item unit of measure record, the system will reference the storage template to determine the base unit of measure.

 

WARNING: If you change the storage template on an item to one that has a different base unit of measure, the system will change the UM on all related data, such as existing inventory, open shipments, and open receipts.
