
        
        <h1 data-source-node="n56"><a name="kanchor1702" data-source-node="n57"></a>RF Style Sheet Field / Style Sheet Field</h1>
        <h5 data-source-node="n58">User Profile Window</h5>
        <p data-source-node="n59">This field indicates the font size used for RF text for certain RF screens (Close Container, Immediate Dock Transfer, and Location Inquiry). This is a user-specific setting that supercedes a similar system-level setting on the Technical Values Window. However, the style sheet setting in the RF Style Sheet Window supercedes both of these settings. </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">RF Style Sheet Window</h5>
        <p data-source-node="n63">This field indicates the RF style sheet that is associated with a specific device. Note that this setting will supercede all other style sheet settings. </p>
