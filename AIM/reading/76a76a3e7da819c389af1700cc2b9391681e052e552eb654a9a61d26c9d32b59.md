
        
        <h1 data-source-node="n56"><a name="kanchor78" data-source-node="n57"></a>Work ID Length Field</h1>
        <p data-source-node="n58">This field is only used when a region is configured to allow manual work ID assignment. This value is used to specify how many digits of the work ID must be spoken by the user to manually request a work ID. The spoken work ID is matched to either the <i data-source-node="n59">entire</i> or the last &lt;<i data-source-node="n60">number</i>&gt; of digits of the work ID the user must speak. </p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">NOTE: When there is a suffix on the work unit due to a duplicate, the user will not speak that. Specifically, for example, suppose that there is a delimiter contained in the work ID (because there are two work IDs created with the same ID and appended with a delimiter, such as #00001), the system will return both of these work IDs to the Vocollect device. The Vocollect device would then ask the user to identify which work unit the user wants to process.</p>
