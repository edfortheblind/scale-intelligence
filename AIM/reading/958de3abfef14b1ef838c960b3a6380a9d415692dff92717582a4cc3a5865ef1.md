
        
        <h1 data-source-node="n56"><a name="kanchor1597" data-source-node="n57"></a>Minimum Charge Greater or Equal to Break Field</h1>
        <p data-source-node="n58">If the total weight of the LTL shipment is greater than or equal to what is defined in the Minimum Charge Weight Break Field, then the value in this field is used during freight charge comparison. This is the minimum amount that the system will charge when calculating the freight charge.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">This field is located in both the header and detail levels of the rate base record. If there is a value defined in this field on the detail level of the rate base record, the value in the detail level field with be used. If nothing is defined at the detail level, the header level value is used.
 </p>
