Start Date Time Field

This field identifies the day and time that a certain action/event began.

 

 

Work Related...

The time that work was initiated in the system. The value in this field depends on how the work was processed.

- If work is processed on an RF, the start time is associated with a work unit and its instructions. The start time is defined when an employee begins processing the first work instruction for a work unit. If multiple instructions are associated with a work unit, they will all share the same start time value.

 

- If work is processed on the Work Insight Screen, the start time is associated with each work instruction. It is defined per instruction when its confirmed. Since work processed on the Work Insight Screen is generally physically completed before its updated here, the start time is usually the same for all instructions and the work unit. The user will type this value on the screen. If processing against this work unit has not been initiated, the system will default time that the work was created in this field.
