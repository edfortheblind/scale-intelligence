
        
        <h1 data-source-node="n56"><a name="kanchor1143" data-source-node="n57"></a>Allocation Pick List</h1>
        <p data-source-node="n58">An allocation pick list identifies all of the items on a shipment and 
 where to pick them in the warehouse. You can manually print a shipment's 
 allocation pick list on the Shipment Insight screen.</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Note On Allocated/Requesting 
 Quantity Display</h5>
        <p data-source-node="n61">The system only displays the requested quantity value on the first allocation 
 request that is written for a line. All the other allocation requests 
 will have a displayed requested quantity of 0. In the following examples, 
 see how the system would display the allocation requests on the allocation 
 pick list:</p>
        <p data-source-node="n62"> </p>

        <p data-source-node="n150">The user then will have to calculate if the whole quantity was allocated 
 or not. In the first example above, the allocated quantity column adds 
 up to 200, while the requested quantity is clearly displayed as 250. Therefore, 
 a quantity of 50 must have been rejected when the system tried to allocate 
 it. However, in the second example, the allocated quantity column adds 
 up to 250, the same number as the requested quantity, so the system allocated 
 the correct quantity.</p>
