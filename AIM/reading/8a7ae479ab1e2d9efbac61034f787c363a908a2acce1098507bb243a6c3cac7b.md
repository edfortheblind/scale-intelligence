
        
        <h1 data-source-node="n56"><a name="kanchor1789" data-source-node="n57"></a>Counts Per Group Field</h1>
        <p data-source-node="n58">This field indicates how many cycle count 
 requests you would like the system to group together during plan creation. A zero or blank value indicates unlimited size. This field allows you to group the requests 
 so that they are evenly divided between workers. When printing cycle count 
 lists, each group is printed separately.</p>
