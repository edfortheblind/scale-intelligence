
        
        <h1 data-source-node="n56"><a name="kanchor1551" data-source-node="n57"></a>Defining Item Cross References</h1>
        <p data-source-node="n58">You can create a cross-reference record for any item defined in the 
 system. Generally, a cross-reference number is established to identify 
 an item's UPC 
 or GS1 number. A user processing an item can use either the item number 
 or the cross-reference number to identify it on an RF 
 device. Packing Note: If you are packing, 
 and a shipment happens to have more than one item that shares a single 
 item cross reference, the system will force you to pack the entire quantity 
 of the first item that appears in the record grid.</p>

        <h4 data-source-node="n87">Procedures...</h4>
        <ol data-source-node="n88">
            <li value="1" data-source-node="n89">
                <p data-source-node="n90">Use the Item Field to identify 
 the item that you want to create a cross-reference record for.</p>
                <p data-source-node="n91"> </p>
            </li>
            <li value="2" data-source-node="n92">
                <p data-source-node="n93">Use the Company Field to 
 select the company associated with this item.</p>
                <p data-source-node="n94"> </p>
            </li>
            <li value="3" data-source-node="n95">Use the Cross-Reference 
 Item Number Field to identify the number that you want to associate 
 with this item. This value can be an alpha-numeric value.<br data-source-node="n96"> </li>
            <li value="4" data-source-node="n97">Use the Quantity 
 Unit of Measure Field to associate a quantity UM with an item cross 
 reference. Note that an item/company/item cross reference combination can only 
 be assigned to one quantity UM. Also note that this quantity UM association is used only in certain parts of the system.<br data-source-node="n98"><br data-source-node="n99"><i data-source-node="n100">Using With GS1</i> <br data-source-node="n101">You can use this field to assign a default quantity UM to a specific GTIN (Global Trade Item Number). If a quantity is specified on the GTIN, then it will be assumed to be of this quantity UM. For example, suppose you have a beverage item that only is stocked in cases. You would then need to associate a quantity UM of "CS" to this beverage's item cross reference. Therefore, any time this item's GS1 barcode is scanned, the system assumes it is a case (CS).<br data-source-node="n102"><br data-source-node="n103"></li>
            <li value="5" data-source-node="n104">GTIN Enabled Check box: 
 See the topic      <a href="ca156d855503fd8eca1405d143a049a7be2e5baff1e85b12ea9193a15cd7f39a.html" data-source-node="n105">Enabling GTIN On Item Or Item Cross 
 Reference</a> for information on this field. <br data-source-node="n106"><br data-source-node="n107"></li>
            <li value="6" data-source-node="n108">Press OK. 
 The system will save your record.</li>
        </ol>
