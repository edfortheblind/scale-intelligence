
        
        <h1 data-source-node="n56">Reviewing RF Device Style Sheet Records</h1>
        <p data-source-node="n57">You will use this window to link a specific RF style sheet for a particular device. The purpose of these style sheets is to adjust the look of the RF screens so that they can best be matched to work with the particular device you are using.  For example, on touch screen devices there is a style sheet shipped with the system that allows options to be selected by touch rather than by keyboard entry.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"><u style="font-style: italic" data-source-node="n61">Notes</u>
        </p>
        <ul data-source-node="n62">
            <li data-source-node="n63">If the identifier mentioned in the generic config detail matches any keyword from the User Agent string (which stores all the platform data including such things as operating system information/version and browser information/version), the system will apply this style sheet value. <br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66">The one record shipped with the system is "Android".</li>
        </ul>
