Reason Code Field

A reason code identifies why an employee did not complete a task as anticipated. For example, if an work instruction was short picked, the employee can use the reason code to explain why the work instruction was not fulfilled.

 

 

On the QC Workbench...

This field indicates why an item quantity did not pass QC inspection. You will need to associate all of a failed quantity to the appropriate reason code(s) before container inspection confirmation can occur.

 

 

On the RF Shipping Container QC Screen...

This field indicates why an item quantity did not pass QC inspection. The system will always assign the RF QC Failed Quantity reason code to failed quantities counted on this screen.

 

 

On the Receipt Quality History Insight Screen...

Under Basic Criteria filter, this field captures the possible reason codes for reporting an issue or recording the quality.
