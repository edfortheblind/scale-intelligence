
        
        <h1 data-source-node="n57"><a name="kanchor2036" data-source-node="n58"></a>New Container Field</h1>
        <p data-source-node="n59">In picking management, this field indicates that no work has been started 
 for a particular work unit.</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">This field's value would be "Y" 
 if you were going to start picking a new work unit, and would need 
 to acquire a new container to pick into.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li class="li_1" data-source-node="n64">This 
 field's value would be "N" if the picking process had 
 already begun, and there was an existing container for the work unit.</li>
        </ul>
