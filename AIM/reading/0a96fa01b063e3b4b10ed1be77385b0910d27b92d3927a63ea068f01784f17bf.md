
        
        <h1 data-source-node="n56"><a name="kanchor1867" data-source-node="n57"></a>Warehouse Mobile - Sign in</h1>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">Warehouse mobile application provides a portable method for warehouse operations to be executed. The application is physically installed on the mobile device and functions with internet and intranet connection. You may choose to change the user by logging out and logging back in with the new user while connected to the network.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h4 data-source-node="n62">Prerequisites</h4>
        <ul data-source-node="n63">
            <li data-source-node="n64">The mobile device  be connected to the network.</li>
            <li data-source-node="n65">Warehouse mobile should be configured to communicate with the server-side application.</li>
            <li data-source-node="n66">
                <p data-source-node="n67">Each of the Warehouse mobile menu options require configuration on the server side (e.g, work profiles, receiving preferences, packing preferences, etc.)</p>
            </li>
        </ul>
        <p data-source-node="n68"> </p>
        <h4 data-source-node="n69">To Sign On to the Warehouse Mobile</h4>
        <p data-source-node="n70">The sign on is done using the Microsoft Entra ID or AD FS. The application needs to be connected to internet or company intranet.</p>
        <ul data-source-node="n71">
            <li data-source-node="n72">Enter the user ID and password in the Microsoft Sign in page.</li>
            <li data-source-node="n73">Tap Login to submit the entered user ID and password. </li>
        </ul>
        <p data-source-node="n74">After a successful login, the <b data-source-node="n75">Warehouse Mobile selection Menu </b>screen is displayed. Select the option for the required function</p>
