
        
        <h1 data-source-node="n56"><a name="kanchor2028" data-source-node="n57"></a>Eligible UMs 
 Field</h1>
        <p data-source-node="n58">This field indicates the units of measure that it will allow to be allocated 
 for a particular sequence. Therefore, even if a location allows all units 
 of measure to be allocated; when using a particular rule, the system will 
 only allocate these specific units of measure. For example, if a rule detail is defined to only allocate cases and 
 pallets, the system would not allocate a quantity less than a case using 
 this rule detail, even if some of the locations included in the allocation 
 location selection actually did allow allocation of eaches.</p>
