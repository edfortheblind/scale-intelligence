
        
        <h1 data-source-node="n56"><a name="kanchor1353" data-source-node="n57"></a>Putaway Sequence Field</h1>
        <p data-source-node="n58">This field identifies the putaway sequence number assigned to a location. 
 Putaway sequences allow you to redefine how the system orders putaway 
 work instructions. Later, you would define this sequence value as the 
 Order By attribute on the Allocation Location Selection Window. Putaway sequences are optional, not required.</p>
