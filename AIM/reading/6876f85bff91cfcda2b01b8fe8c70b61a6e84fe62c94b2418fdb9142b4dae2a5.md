
        
        <h1 data-source-node="n56"><a name="kanchor1787" data-source-node="n57"></a>Default LP ID As Container ID On Full Picks Checkbox</h1>
        <p data-source-node="n58">This checkbox is used  to indicate that you want the system to default the location's license plate ID (from which you are picking quantity from) as the container ID of the shipping container that you are picking the quantity into. Note that you can enter a different container ID as well, this license plate ID is only defaulted into the field (its use is not mandatory)</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Notes...</h5>
        <p data-source-node="n62">** You can only use this functionality during RF pick into shipping container (not pick into tote or regular "not-into-container" picking). </p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64">** If you are not performing a full pick of the license plate's quantity, then the system will not default the LP ID as the container ID (even if this setting is active on your work profile). 

However, you can manually enter the LP ID into the Container ID Field.</p>
        <p data-source-node="n65"> </p>
        <p data-source-node="n66">** If the work instruction is for less than the license plate's full quantity, then  the system will not default the LP ID as the container ID (even if this setting is active on your work profile). 

However, you can manually enter the LP ID into the Container ID Field.</p>
        <p data-source-node="n67"> </p>
        <p data-source-node="n68">** If there is an existing container associated with a shipment (and multiple items are/would be picked into the same container), then the system will default the existing container ID (not the LP ID, even if this setting is active on your work profile). Note that if you are picking single items into an existing container, the "override container" work special handling option must be active.</p>
        <p data-source-node="n69"> </p>
        <p data-source-node="n70">** If you choose to override the license plate from which you are picking from, then the system will default the new license plate ID as the container ID (if this setting is active on your work profile).</p>
