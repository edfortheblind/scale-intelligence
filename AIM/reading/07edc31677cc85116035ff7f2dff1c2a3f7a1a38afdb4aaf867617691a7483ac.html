Setup Overviews: Outbound

Below are lists of the setup procedures required to use the outbound functional areas.

 

NOTE: Actions without hyperlinks can be performed by your Manhattan Associates representative.

 

 

Allocation 

  1. Review the allocation strategies
  2. Define allocation location selection records
  3. Define allocation rule sets
  4. Associate the rule sets with the correct items
  5. Assign a permanent location to an item
  6. Define an advanced allocation record

 

 

Carrier Technical

  1. Review the system created check digit algorithms
  2. Define each carrier's pro numbers
  3. Review the system created carrier types
  4. Identify NMFC codes
  5. Review the system's rating values
  6. Review the system's LTL classes
  7. Review the system created freight terms
  8. Review the EDI reference records

 

 

Container Creation in a Wave

  1. Review container shape types
  2. Create the container groups
  3. Create packing criteria records
  4. Work with packing classes
  5. Define container creation criteria records
  6. Review container creation system values

 

 

Dock Management (Consolidation)

  1. Activate the consolidation putaway functionality
  2. Review dock location classes 
  3. Create consolidation location areas
  4. Create consolidation locations
  5. Define a carrier's default consolidation location area

 

 

Dock Management (Staging / Loading)

  1. Activate staging/loading functionality
  2. Create packing/staging/dock door locations (in the Location Window)
  3. Associate a carrier group type to dock areas (on the Carrier Group Window) [optional - define if using "Select Dock Area Using Carrier" selection strategy]
  4. Create dock area carrier assignment records [optional - define if using "Select Dock Area Using Carrier" selection strategy]
  5. Define dock management flow records
  6. Define dock management work criteria records
  7. Define dock area anchor criteria records [optional - define if using "Anchor Dock Area Using Shipment" selection strategy]
  8. Define dock location anchor criteria values (on the Location Window) [optional - define if using "Anchor Dock Area Using Shipment" selection strategy

 

 

Order Entry 

  1. Define order entry values
  2. Create customer categories
  3. Define order item selection records
  4. Define order ship to selection records
  5. Define shipment process types
  6. Review system values

 

 

Outbound Quality Control

  1. Define outbound QC assignment criteria records
  2. Define outbound QC assignment records
  3. Define outbound QC-related packing preferences
  4. Define outbound QC reason codes

 

 

Packing/Shipping 

  1. Define all necessary container classes
  2. Define all container types
  3. Define packing preferences
  4. If appropriate, identify regular customers that you service
  5. Define shipping preferences
  6. Define the values two shipments must share in order to consolidate
  7. Associate the packing and shipping preferences with the appropriate users
  8. Define a freight consolidators
  9. Define intermediate consignees
  10. Create store location assignment records
  11. Review delivery types

 

 

Pallet UM Conversion

  1. Define pallet UM conversion criteria records
  2. Define wave master

.

 

Pallet Building In A Wave 

 

Discussion: Pallet Building Strategy - Nesting using pallet maximum height

Prerequisite: Container Creation In A Wave setup

  1. Create a pallet container type
  2. Create pallet building criteria record
  3. Create a pallet building master record
  4. Choose a pallet building master on the appropriate wave master

 

 

Progistics   

  1. Identify that Progistics is installed
  2. Create each shipper's code
  3. Define a shipper cross-reference record
  4. Identify the shipper in Progistics

 

 

Rating 

  1. Create a rating profile for each carrier
  2. Review the default rating IDs
  3. Review the default services
  4. Complete the required Routing setup steps
  5. Define accessorials
  6. If appropriate, define carrier discounts in Progistics CS

 

 

Rating - LTL 

  1. Create a rating profile for each carrier
  2. Review the default rating IDs
  3. Complete the required Routing setup steps
  4. Create a weight break 
  5. Create a rate base
  6. Create additional criteria assignment - optional step
  7. Create a carrier rate base assignment record

 

 

Routing 

  1. Define when the carrier cannot transport product (shipping calendar)
  2. Define the carrier's record
  3. Define the carrier's postal code range (carrier commitment)
  4. Create any necessary carrier groups
  5. Create a routing guide

 

 

Status Technical 

  1. Review the default status action values
  2. Review the default system status names

 

 

Status/Status Flow

  1. Review the system defined statuses (Functional Area Window)
  2. Create all user defined statuses (Functional Area Window)
  3. Review the default status flow
  4. If necessary, create custom status flow

 

 

UPS World Ease 

  1. Setup Prerequisites/Requirements
  2. Define intermediate consignees
  3. UPS World Ease Setup Procedural Flow

 

 

Value Added Services

  1. Define VAS activity criteria records
  2. Define VAS activities
  3. Define VAS-related packing preferences

 

 

Wave Processing

  1. Review the wave statuses
  2. Define the wave steps into wave flows
  3. Define the wave criteria rule sets
  4. Define wave maximum records
  5. Define wave master records
  6. Define planned shipment filters
  7. Define how you want the system to override shipment data in the wave
  8. Create Pro and BOL number criteria

 

 

Work Creation

  1. Create the work creation master
  2. Review the work creation process summary
  3. Define the work creation setup
  4. Define work criteria records
  5. Define work types creation
