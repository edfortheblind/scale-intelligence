
        
        <h1 data-source-node="n56"><a name="kanchor1478" data-source-node="n57"></a>Configuring/Displaying Interfaced RF Comments</h1>
        <p data-source-node="n58">You will need to complete the procedures outlined on this topic to display 
 shipment comments  while picking on the RF 
 device. </p>

        <h4 data-source-node="n73">Step 1: Defining a Custom "Work Execution" 
 Comment Type...</h4>
        <p class="p_21" data-source-node="n74">Performed on the Comment 
 Type Window</p>
        <ul type="disc" class="ul_1" data-source-node="n75">
            <li data-source-node="n76">You will need to create a comment type record 
 to indicate when you want the system to display the comments (before 
 or after a picking action) associated with the shipment or shipment line. Note that the comments on your interfaced 
 shipments must be of this comment type in order for the system to display 
 it on the RF device. <br data-source-node="n77"><br data-source-node="n78">See the topic <a href="76fc4a17abe12f3727d6c97a974ac09ad52790785cd4b804dd761ac402c89ca6.html" data-source-node="n79">Defining 
 Comment Types</a> for more detailed information on using this window.</li>
        </ul>
        <p data-source-node="n80"> </p>
        <p data-source-node="n81"> </p>
        <h4 data-source-node="n82">Step 2: Associating the Comment Type To a Document Type...</h4>
        <p class="p_21" data-source-node="n83">Performed on the Comment 
 Type Doc Assignment Window</p>
        <ul type="disc" class="ul_1" data-source-node="n84">
            <li data-source-node="n85">The document type "WorkExecution" represents 
 the RF device. You will need to associate the comment type you created 
 in step 1 with this "WorkExecution" document type. Once this 
 is done, the system will display the appropriate shipment comments on 
 the RF device.<br data-source-node="n86"><br data-source-node="n87">See the topic <a href="d41bcb317237d7eb99aeb4458c926b6bcab4a4e7a8bbf00c96e5ed4a775debe5.html" data-source-node="n88">Associating 
 Comment Types With Document Types</a> for more detailed information 
 on using this window.</li>
        </ul>
        <p data-source-node="n89"> </p>
        <p data-source-node="n90"> </p>
        <h4 data-source-node="n91">Step 3: Activating RF Work Comments...</h4>
        <p data-source-node="n92">Performed on the Work System Values Window</p>
        <ul data-source-node="n93">
            <li data-source-node="n94">The work system value "Display Comments during Work on RF?" must be set to yes for these comments to appear on the RF device.</li>
        </ul>
