
        
        <h1 data-source-node="n56"><a name="kanchor2102" data-source-node="n57"></a>Export Field</h1>
        <p data-source-node="n58">This field indicates which values you want to export using the Translation Wizard:
</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">Choose ONLY VALUES NEEDING TRANSLATION to have the system export only the resources that do not exist for a particular language. The system will compare the values from a language's existing resources to the new version's values. This option will export the delta resources (in English) in the English Text column of the spreadsheet, and the Translation Text column on the spreadsheet will be blank. Note that only the resources that have been added/changed will be exported. Also, the system will export any custom resources that have been created.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">Choose ALL VALUES to have the system export all existing resources to a spreadsheet. Note that you are not allowed to choose a language with this option, as the system will simply export all of the English resources from the current version of the application. This will always export English resources. The Translation Text column on the spreadsheet will be blank.<br data-source-node="n64"><br data-source-node="n65"></li>
        </ul>
