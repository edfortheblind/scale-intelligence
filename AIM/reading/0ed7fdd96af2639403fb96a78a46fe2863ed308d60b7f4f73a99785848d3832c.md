
        
        <h1 data-source-node="n56"><a name="kanchor669" data-source-node="n57"></a>UPS Returns Service Shipping Label</h1>
        <p class="p_15" style="color: #000000" data-source-node="n58">This label is generated for use with UPS 
 returns processing: When the Print Return Label Accessorial is applied 
 to a container, and the container is manifested, this label is printed 
 at the same time as the container's regular shipping label (it will be 
 routed to the same printer, etc). </p>
        <p class="p_15" data-source-node="n59"> </p>
        <p class="p_15" data-source-node="n60"> </p>
        <h4 data-source-node="n61">Notes...</h4>
        <ul type="disc" class="ul_1" data-source-node="n62">
            <li class="li_3" data-source-node="n63">This label is not 
 defined on the Document or Document Type Window. <br data-source-node="n64"> </li>
            <li class="li_3" data-source-node="n65">The label looks exactly 
 like a container's regular shipping label, except that it has a different 
 ship to address, and an "RS" heading at the top of the label.<br data-source-node="n66"> </li>
            <li class="li_3" data-source-node="n67">The label's tracking 
 number is unique from that of a container's regular shipping label.<br data-source-node="n68"> </li>
            <li class="li_3" data-source-node="n69">No one is billed 
 for the accessorial or the return label itself until it is actually used. 
 UPS will bill for the use of the return 
 label based on the freight terms on the original shipment.</li>
        </ul>
