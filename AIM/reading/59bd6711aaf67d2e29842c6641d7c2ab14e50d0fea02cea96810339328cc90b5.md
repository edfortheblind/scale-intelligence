        <h4 data-source-node="n104"><a name="Creating" data-source-node="n105"></a>Electronically Sign Bills of Lading documents</h4>
        <p data-source-node="n106"> </p>
        <p data-source-node="n107">The shipper and carrier can electronically sign and preview the associated document for Bills of Lading.</p>
        <ul data-source-node="n108">
            <li data-source-node="n109">
                <p data-source-node="n110">Navigate to the <b data-source-node="n111">Shipping Load Insight</b> screen. Select the shipping load to e-sign, and click <b data-source-node="n112">Actions &gt;&gt; Sign BOL</b> to view the Bills of Lading screen. The screen displays information such as the Internal Load Number, carrier, route, seal ID, and Trailer ID of the selected shipping load.</p>
            </li>
        </ul>
        <ul data-source-node="n113">
            <li data-source-node="n114">
                <p data-source-node="n115"><b data-source-node="n116">Preview BOL</b> - Click to view the documents in the Bills of lading preview accordion. Shipper/Carrier can review the document before signing.</p>
            </li>
        </ul>
        <ul data-source-node="n117">
            <li data-source-node="n118">
                <p data-source-node="n119">The shipper and carrier signs electronically and click <b data-source-node="n120">Save</b>. Also optionally, you can click clear (X) to discard and record a new signature.</p>
            </li>
        </ul>
        <ul data-source-node="n121">
            <li data-source-node="n122">
                <p data-source-node="n123"><b data-source-node="n124">Shipping Load Info</b> accordion populates the load information such as Internal Load Number, Carrier, Seal ID, Route, and Trailer ID. Users can also choose to update Seal ID, Route, and Trailer ID.</p>
            </li>
        </ul>

        <h4 data-source-node="n127"><a name="Actions" data-source-node="n128"></a>Screen Actions</h4>
        <p data-source-node="n129">The following are the screen actions.</p>
        <p data-source-node="n130"> </p>
        <p data-source-node="n131"><b data-source-node="n132">Save</b>
        </p>
        <p data-source-node="n133">The Save button is used to record/update the digital signature of the shipper and carrier. This button is enabled only when either Shipper or Carrier has signed.</p>
        <p data-source-node="n134">.</p>
        <p data-source-node="n135"><b data-source-node="n136">Print</b>
        </p>
        <p data-source-node="n137">When user clicks <b data-source-node="n138">Actions &gt;&gt; Print</b>, system will display the Print Documents Window. You can select or deselect any document displayed on this window. Documents will appear in this window if their document type is associated with the print procedure associated with this window. Also note that documents are preselected if the print procedure's Default checkbox is selected for the document type associated with this paperwork.</p>
        <p data-source-node="n139"> </p>
        <p data-source-node="n140"><b data-source-node="n141">Cancel</b>
        </p>
        <p data-source-node="n142">This action allows you to cancel Sign bill of lading documents and the system will navigate back to the <b data-source-node="n143">Shipping load Insight</b> screen.</p>
