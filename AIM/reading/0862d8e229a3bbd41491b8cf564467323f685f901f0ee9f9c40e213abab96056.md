
        
        <h1 data-source-node="n56"><a name="kanchor426" data-source-node="n57"></a>Perform Threshold Counts Immediately Checkbox</h1>
        <p class="p_1" data-source-node="n58">This checkbox indicates if an RF user should 
 be presented with a cycle count request immediately, or if the system 
 should write the request and give it to another user later. This will 
 occur if a picking location's on hand quantity falls into one of the cycle 
 count thresholds set up in this window. In other words, this checkbox allows the system 
 to display cycle count instructions along with instructions from other 
 RF picking operations.</p>
