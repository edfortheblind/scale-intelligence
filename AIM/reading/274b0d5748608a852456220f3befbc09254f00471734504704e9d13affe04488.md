
        
        <h1 data-source-node="n56"><a name="kanchor1909" data-source-node="n57"></a>Wave Name &amp; Number Field</h1>
        <p data-source-node="n58">The unique identifier for a specific wave. 
 When the system runs the wave preparation job, it generates waves to support 
 the pooled shipments. It assigns a wave number to each wave. This number, 
 along with the wave name, identify the wave in the system.</p>
        <p class="p_1" data-source-node="n59">  </p>
        <h5 data-source-node="n60">On the Shipment Insight screen</h5>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">The wave number is displayed as a hyperlink. Clicking this link will navigate to the Wave Insight screen with the wave number filled in the filter criteria.</p>
