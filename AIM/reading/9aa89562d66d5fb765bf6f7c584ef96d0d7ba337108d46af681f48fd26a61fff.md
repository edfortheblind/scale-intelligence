
        
        <h1 data-source-node="n56"><a name="kanchor1564" data-source-node="n57"></a>Using The Lot Insight Screen</h1>
        <p data-source-node="n58">You can use either of these two screens to research the details of Lot IDs that are 
 assigned to item quantities in your warehouse. This is helpful if you 
 need to view the expiration date(s) of certain lots, or want to see all 
 the lot ID's assigned to a specific item. </p>

        <h4 data-source-node="n191"><a name="Searching" data-source-node="n192"></a>Searching/Viewing Lot Records...</h4>
        <p data-source-node="n193">You can use the Lot Insight Screen to search for and view lot records in your warehouse. </p>
        <ol data-source-node="n194">
            <li value="1" data-source-node="n195">Open the Lot Insight Screen.<br data-source-node="n196"><br data-source-node="n197"></li>
            <li value="2" data-source-node="n198">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search. <br data-source-node="n199"><br data-source-node="n200"></li>
            <li value="3" data-source-node="n201">Press the Apply Filter Button. The system will display the resulting records in the List Pane. <br data-source-node="n202"><br data-source-node="n203"></li>
            <li value="4" data-source-node="n204">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>
        <p data-source-node="n205">NOTE: Clicking on the Lot ID in the Detail pane header or List Pane Grid field opens the Lot screen for that specific lot record.</p>

        <h4 data-source-node="n222"><a name="DetailsPane" data-source-node="n223"></a>About the Detail Pane...</h4>
        <p data-source-node="n224">The Lot Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.<br data-source-node="n225"><br data-source-node="n226"></p>
        <p data-source-node="n227">The Detail Pane of Lot Insight contains Indicator Tiles with counts of the other entities (i.e. locations and transactions).  If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following: </p>
        <ul data-source-node="n228">
            <li data-source-node="n229">Locations<ol data-source-node="n230"><li value="1" data-source-node="n231"><p data-source-node="n232">This field displays the number of locations in the warehouse for the selected item, company, and lot in the warehouse.</p></li><li value="2" data-source-node="n233"><p data-source-node="n234">Clicking on this tile will open the Inventory Insight screen filtered by the item, company, and lot in the warehouse.</p></li></ol><p data-source-node="n235"> </p><li data-source-node="n236"><p data-source-node="n237">Transactions</p><ol data-source-node="n238"><li value="1" data-source-node="n239"><p data-source-node="n240">Displays the number of transactions for the selected item, company, and lot in the warehouse.</p></li><li value="2" data-source-node="n241"><p data-source-node="n242">Clicking on this tile will open the Transaction History Insight screen filtered by the item, company, and lot in the warehouse for all transaction types.</p></li></ol></li></li>
            <br data-source-node="n243">
        </ul>
        <p data-source-node="n244">For more general information about the Detail Pane, see the topic <a href="444e9b8e14a977178c9ff48b972dd65c076a4adda44c3dfacddf94a4a6c24d22.html" data-source-node="n245">Introduction to Insight Screens</a>.<br data-source-node="n246"></p>

        <h4 data-source-node="n251"><a name="ScreenActions" data-source-node="n252"></a>Screen Actions...</h4>
        <p data-source-node="n253">The following actions are accessible from the List Pane:</p>
        <p data-source-node="n254"> </p>
        <p data-source-node="n255"> </p>
        <h5 data-source-node="n256">View/Edit</h5>
        <p data-source-node="n257">The View action allows you to open the Lot Insight screen in the read-only mode and the Edit action allows you to open Lot Insight screen in the edit mode. You can edit the following fields: Inventory Status, Expiration Date, Frozen Toggle, Lot Attributes, and User Defined Fields. Updating the lot information except lot attributes and saving the record will show the Lot Update Confirmation Screen with affected inventory. For more information, refer to <a href="5be34e7ef987411d97b031239e1f4e3536a159155a6e22c90141c9cdf4b0a462.html" data-source-node="n258">Using the Lot Update Confirmation Screen</a>. </p>
        <p data-source-node="n259"> </p>
        <p data-source-node="n260">NOTE: You can also edit the lot details by opening the screen using hyper link on the list pane as well as through the indicator tiles section.</p>
        <p data-source-node="n261"> </p>
        <p data-source-node="n262"> </p>
        <h5 data-source-node="n263">Adjust</h5>
        <p data-source-node="n264">This action allows you to adjust the inventory in your warehouse. Choosing this action opens the Inventory Adjustment screen. Refer to the <a href="a7cf2d727b34fd54d1a4d2ebae0a553f1774916e43c15825e3292ee08de7ea9d.html" data-source-node="n265">Adjusting Inventory</a> topic for more information. </p>
        <p data-source-node="n266"> </p>
        <p data-source-node="n267"> </p>
        <h5 data-source-node="n268">Transfer</h5>
        <p data-source-node="n269">This action allows you to transfer the existing inventory on your warehouse. Choosing on this action opens the Inventory Transfer screen. Refer to the <a href="63281df7d4bc9db3bb55e5c0d127645d862916c21c7e9d8d18d0ebb2e3d95878.html" data-source-node="n270">Transferring Inventory (Desktop and RF)</a> topic for more information. </p>
