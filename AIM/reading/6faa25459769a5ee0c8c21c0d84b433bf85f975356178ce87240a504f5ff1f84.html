Set New License Plates To Pending Review Checkbox

This checkbox indicates that you want the system to place in a pending review status all cycle counts that involve new license plates created by the user (while executing counts). A warehouse supervisor then will have to review the count before it is made official in the system. This option is only available when you are using a License Plate Selection Method of user initiated. Note that the system will ignore this setting if you have the ability to add items during a count. Since any new additions during counts is automatically put into a pending review status, this setting is not recognized.
