
        
        <h1 data-source-node="n56"><a name="kanchor2059" data-source-node="n57"></a>Replace Text Field</h1>
        <p data-source-node="n58">This field is displayed on the System Text Editor Window. This field 
 is used in conjunction with the Search Field. You can use it to automatically 
 provide the custom values that should replace the value defined in the 
 Search Field.</p>
