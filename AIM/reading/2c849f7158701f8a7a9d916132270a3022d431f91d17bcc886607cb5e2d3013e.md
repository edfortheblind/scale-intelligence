
        
        <h1 data-source-node="n56"><a name="kanchor253" data-source-node="n57"></a>Value Required Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates if an accessorial detail record must be applied 
 when you select the header record on the Accessorial Assignment Window. For example, when you select the header Cash On Delivery, the COD Amount 
 will be pre-selected since the system must add it to the shipping charge. 
 The system will require you to add a value in the COD Amount Field.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">If the checkbox is selected, 
 the system will require you to include an accessorial detail record when 
 its header record is selected.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">If this checkbox 
 is not selected, the system will not require you to include an 
 accessorial detail record when its header record is selected.</li>
        </ul>
