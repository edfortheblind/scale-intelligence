
        
        <h1 data-source-node="n56"><a name="kanchor1745" data-source-node="n57"></a>Finished Item Field</h1>
        <p data-source-node="n58">A finished item is an item created during 
 the work order process. Finished items are assembled from build components.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">On the Work Order Insight Screen...</h5>
        <ul data-source-node="n62">
            <li data-source-node="n63">FI Avail: This field represents the total number of finished items available to build.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66">FI Built: This field represents the total number of finished items built. <br data-source-node="n67"><br data-source-node="n68"></li>
            <li data-source-node="n69">FI Total: This field represents the total number of finished items to be built.</li>
        </ul>
