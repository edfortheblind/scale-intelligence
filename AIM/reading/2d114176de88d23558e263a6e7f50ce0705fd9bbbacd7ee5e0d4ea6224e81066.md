
        
        <h1 data-source-node="n56">Scheduling a Real Time Replenishment Job</h1>
        <p data-source-node="n57">In order to have the system use the real time masters to replenish locations, 
 you first need to create a scheduled job to call the replenishment process. 
 The scheduled job for this process is called real-time 
 replenishment.
