
        
        <h1 data-source-node="n56"><a name="kanchor1251" data-source-node="n57"></a>Inherited Checkbox</h1>
        <p class="p_1" data-source-node="n58">This checkbox indicates if a child record 
 is obtaining field level information from a parent record.</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li class="li_1" data-source-node="n60">If 
 this checkbox contains a value, the information in this field is 
 defaulted from a parent record. This child will inherit this value from 
 the parent record. When you select the checkbox, the system will automatically 
 default the value from the parent record.     If 
 you make a change to the parent record, the system will automatically 
 update the children records<br data-source-node="n61"> </li>
            <li class="li_1" data-source-node="n62">If 
 this checkbox does not contain a value, the information in this 
 field was not defaulted from a parent record.</li>
        </ul>
