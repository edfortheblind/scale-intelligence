Closing Putaway Groups (RF)

Once a putaway group exists and has item quantity assigned to it, you can close it using the RF Close Putaway Group screen. For additional information on closing putaway groups, see the topic Viewing/Closing Putaway Groups.

Procedures...

Log onto an RF device.

  1. Select the Close Putaway Group option from the RF Main Menu.

  2. Use the Group ID Field to indicate the ID of the putaway group that you want to close.

  3. Press the Close Button. The system will close the putaway group. Note that if your receiving preferences are configured to create work, work creation will occur at this time.
