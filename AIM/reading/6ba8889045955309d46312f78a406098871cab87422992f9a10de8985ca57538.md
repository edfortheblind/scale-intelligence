
        
        <h1 data-source-node="n56"><a name="kanchor1519" data-source-node="n57"></a>Control Type Field</h1>
        <p data-source-node="n58">This field determines the type of component (such as a free-editable 
 text box or a drop-down type menu) that you will assign to a new viewer 
 window field. You need to be certain that this control type matches the 
 data the field represents. For example, it would not be appropriate to 
 choose a date range for the Carrier Field. Users will receive an error 
 when searching if the control type is not configured for a field correctly.<br data-source-node="n59"> </p>
