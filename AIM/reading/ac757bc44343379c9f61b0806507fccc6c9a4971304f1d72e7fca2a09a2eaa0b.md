
        
        <h1 data-source-node="n56"><a name="kanchor1120" data-source-node="n57"></a>Translation Parity Field</h1>
        <p data-source-node="n58">This field specifies the type of parity to 
 be used on the data included in the transmission. While parity detects 
 data corruption during transmission, translation parity converts the bytes 
 read from the port in a useable form.</p>
