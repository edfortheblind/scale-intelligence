Manual Inventory Adjustment Screen

You can use this window to manually adjust an item's inventory quantities (allocated/in transit/on hand/suspense) at a specific location. You can only access this screen from the desktop.

 

SECURITY NOTE: This window is shipped with restrictive, system-level security settings. You must create a user-level record for this window in order to gain access.

 

WARNING: Do not change the quantity values in this window unless you are completely sure you want to do so. Inaccurate quantity values could cause major problems with system processing. The proper venue for adjusting inventory quantities is the Inventory Adjustment screen. The Manual Inventory Adjustment screen should only be used in certain situations when an item's quantity is in an immediate need of change. Also note that no history records are logged by the system for these manual adjustments.
