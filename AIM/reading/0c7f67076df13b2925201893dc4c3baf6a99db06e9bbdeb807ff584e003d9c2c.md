
        
        <h1 data-source-node="n56"><a name="kanchor12" data-source-node="n57"></a>High Ship Confirm Status Field</h1>
        <p data-source-node="n58">The most advanced status that can be ship 
 confirmed. A shipment with this status can be ship confirmed. The system uses this field in conjunction 
 with the Low Ship Confirm Status Field to determine the status range eligible 
 for ship confirmation.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Defining Only One Eligible Status...</h5>
        <p data-source-node="n62">To define only one eligible ship confirm status, enter that value in 
 both the Low Ship Confirm Status Field and the High Ship Confirm Status 
 Field. The system will only ship confirm shipments with the status that 
 you defined.</p>
