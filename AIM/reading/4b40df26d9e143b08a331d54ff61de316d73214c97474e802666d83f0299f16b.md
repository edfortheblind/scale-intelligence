
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor1509" data-source-node="n58"></a>Movement Class</h1>
        <p data-source-node="n59">Movement classes categorize storage locations and item units (UMs) based on how frequently products are moved.</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">Location Level: Assign a movement class (e.g., Class A) to locations. Only items with a matching class should be stored there.</p>
            </li>
            <li data-source-node="n63">
                <p data-source-node="n64">Item/Item Class Level: Assign movement classes to UMs of items to track how frequently they're picked or used.</p>
            </li>
        </ul>
        <p data-source-node="n65">This system helps you optimize storage decisions by matching fast-moving items with easily accessible locations.</p>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67">Create New Record</p>
        <p data-source-node="n68"> </p>
        <p data-source-node="n69">Provide an identifier and description for each movement class. Common identifiers include using letters of the alphabet to represent each movement class, or such names as Fast Movers, Medium Movers, and Slow Movers.</p>
