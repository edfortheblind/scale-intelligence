
        
        <h1 data-source-node="n56"><a name="kanchor1807" data-source-node="n57"></a>Close After Partial Pick Checkbox</h1>
        <p data-source-node="n58">Use this checkbox to allow the user to partial pick the quantity of 
 a work instruction, and the system will delete the remaining quantity 
 from the work instruction. The system will then close the work instruction. 
 Therefore, the remaining quantity will never actually be picked. Note that this option is only available 
 for RF replenishment and work order picks. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Example...</h5>
        <p data-source-node="n62">For example, suppose you have a replenishment request that calls for 
 620 eaches of an item. The user, however, may only want to pick 600 eaches 
 of the item (because that is a more round number in regards to how things 
 are packed), so they just want the other 20 eaches to “go away.” If this 
 checkbox is checked, the system would delete the remaining 20 eaches from 
 the work instruction (after the user picks the 600), and close the work 
 instruction.</p>
