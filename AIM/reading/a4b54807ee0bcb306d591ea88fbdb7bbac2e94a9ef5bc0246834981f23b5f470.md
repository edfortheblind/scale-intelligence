 pending" and "ship confirm pending." You can access this 
 screen from the shipment line level. For more information on this process, please see the topic <a href="b8cac7af3607a14a426e1d6a3d5e77e50dacdb7dc06933dc6737652d5d59d465.html#Activating" data-source-node="n58">Shipment Processing</a>.</p>
