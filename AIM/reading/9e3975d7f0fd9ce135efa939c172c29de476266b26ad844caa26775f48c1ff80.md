            </li>
        </ul>
        <ul data-source-node="n63">
            <li data-source-node="n64">
                <p data-source-node="n65">Personalize the Dashboard: Users can now select, remove, and rearrange report widgets in the dashboard.</p>
            </li>
        </ul>

            <li data-source-node="n67">
                <p data-source-node="n68">	Drill-Down Capability: Navigate directly from widgets to detailed Insight screens.</p>

        <h4 data-source-node="n75">Warehouse Dashboard Screen Components</h4>
        <p data-source-node="n76"> </p>
        <p data-source-node="n77">The different components of the Warehouse Dashboard screen are described here: </p>
        <p data-source-node="n78"> </p>
        <h5 data-source-node="n79">(A) Global Tiles:</h5>
        <p data-source-node="n80"> </p>
        <p data-source-node="n81">The dashboard will only display the tiles you select from the settings option (gear icon) on the navigation bar. Pressing the gear icon will open the Dashboard Customization screen. </p>
        <ul data-source-node="n82">
            <li data-source-node="n83">The dashboard defaults to having no tiles selected for the user.  You must choose the action tiles to appear on the dashboard. <br data-source-node="n84"><br data-source-node="n85"></li>
            <li data-source-node="n86">There is a “gear” icon <img loading="eager" data-source-node="n87"> on the Warehouse Dashboard screen.  Clicking on that opens a window with all action tiles available to you. <br data-source-node="n88"><br data-source-node="n89"></li>
            <li data-source-node="n90">You can toggle ON/OFF individual tiles.  Those that are toggled ON will appear on the warehouse dashboard.<br data-source-node="n91"><br data-source-node="n92"></li>
        </ul>
        <h5 data-source-node="n93">Save Insight Screen Search criteria as Dashboard Tiles</h5>
        <p data-source-node="n94"> </p>
        <p data-source-node="n95">You can save your search from any SCALE Insight screen as a tile and display it on the Warehouse Dashboard.</p>
        <p data-source-node="n96"> </p>
        <ul data-source-node="n97">
            <li data-source-node="n98">
                <p data-source-node="n99">After performing a search (using either basic or advanced filters), click the  <img style="width: 19;height: 21" loading="eager" data-source-node="n100"> icon to save your search as a tile. The system stores all your search criteria and links it to the specific Insight screen where it was created.</p>
            </li>
        </ul>
        <ul data-source-node="n101">
            <li data-source-node="n102">
                <p data-source-node="n103">To display the saved tile on the Warehouse Dashboard, go to the Dashboard Customization settings and enable the <b data-source-node="n104">"Add to Dashboard"</b> toggle for the tile.</p>
            </li>
        </ul>
        <h5 data-source-node="n105">(B) Widgets:</h5>
        <p data-source-node="n106">The Warehouse Dashboard displays the widgets that are enabled. Click the <img loading="eager" data-source-node="n107"> gear icon on the Warehouse Dashboard to view the dashboard customization page to manage widget settings:</p>
        <p data-source-node="n108"> </p>
        <p data-source-node="n109">Under Widget Tab,</p>
        <ul data-source-node="n110">
            <li data-source-node="n111">
                <p data-source-node="n112">Four base widgets are displayed by default under the <b data-source-node="n113">‘Added’</b> section.</p>
            </li>
            <li data-source-node="n114">
                <p data-source-node="n115">Widgets can be rearranged in any order through drag-and-drop.</p>
            </li>
            <li data-source-node="n116">
                <p data-source-node="n117">Widgets can be removed by toggling off the <b data-source-node="n118">Add to Dashboard</b> option.</p>
            </li>
        </ul>
        <p data-source-node="n119">The four base reports are described below.</p>
        <h5 data-source-node="n120">1. Outbound – Shipment Status Report</h5>
        <p data-source-node="n121">Provides a high-level view of the status of outbound shipments, helping users quickly identify shipment status and its metrics.</p>
        <ul data-source-node="n122">
            <li data-source-node="n123">
                <p data-source-node="n124">Displays the count of the shipments grouped by the trailing status.</p>
            </li>
            <li data-source-node="n125">
                <p data-source-node="n126">	For Closed Shipments, only today’s shipments will be considered.</p>
            </li>
        </ul>
        <p data-source-node="n127">
            <img loading="eager" data-source-node="n128">
        </p>
        <p data-source-node="n129"> </p>
        <p data-source-node="n130"><b data-source-node="n131">Report</b>
        </p>
        <p data-source-node="n132">The Donut chart is displayed with the chart categorized with different shipment statuses and their counts.</p>
        <ul data-source-node="n133">
            <li data-source-node="n134">
                <p data-source-node="n135">Each segment of the donut chart represents a different shipment status.</p>
            </li>
            <li data-source-node="n136">
                <p data-source-node="n137">The number reflects the number of shipments in that status.</p>
            </li>
        </ul>
        <p data-source-node="n138">Double-click on any segment of the chart to drill down into a more detailed report for that status.</p>
        <ul data-source-node="n139">
            <li data-source-node="n140">
                <p data-source-node="n141">In the list, Click on a status such as In Packing to open the related shipments in the application directly.</p>
            </li>
            <li data-source-node="n142">
                <p data-source-node="n143">For example In Pool status hyperlink, will open Planned shipment Insight screen. </p>
            </li>
        </ul>
        <p data-source-node="n144">Note:</p>
        <ul data-source-node="n145">
            <li data-source-node="n146">
                <p data-source-node="n147">In Pool status: Opens Planned Shipment Insight screen.</p>
            </li>
            <li data-source-node="n148">
                <p data-source-node="n149">Other statuses (example: In Packing, Load Confirm Pending): Opens Shipment Insight screen.</p>
            </li>
        </ul>

        <h5 data-source-node="n185">4. Inbound – Dock to Stock vs Average</h5>
        <p data-source-node="n186">The time it takes to check in and putaway an entire receipt.</p>
        <p data-source-node="n187"> </p>
        <p data-source-node="n188">
            <img loading="eager" data-source-node="n189">
        </p>
        <p data-source-node="n190"> </p>
        <ul data-source-node="n191">
            <li data-source-node="n192">
                <p data-source-node="n193">Dock to stock time = Receipt header's close date minus receipt header's start unitized (check-in) date time for receipts with a close date equal to today's date.</p>
            </li>
            <li data-source-node="n194">
                <p data-source-node="n195">Shortest dock to stock = Shortest time from dock to stock for a receipt with a close date equal to today's date.</p>
            </li>
            <li data-source-node="n196">
                <p data-source-node="n197">Longest dock to stock = Longest time from dock to stock for a receipt with a close date equal to today's date.</p>
            </li>
            <li data-source-node="n198">
                <p data-source-node="n199">Average dock to stock = Sum of all the dock to stock times (close date - start unitize date time) divided by the number of such receipts with a close date equal to today's date.</p>
            </li>
        </ul>
        <h4 data-source-node="n200">Configure Custom Widget in the Application</h4>
        <p data-source-node="n201">The Supply Chain Intelligence custom reports can be rendered on the screen. Follow the steps below.</p>
        <p data-source-node="n202"> </p>
        <h5 data-source-node="n203">Create a new widget using Dashboard Widget configuration.</h5>
        <p data-source-node="n204">Add a new widget to render the customer report from SCI.</p>
        <ul data-source-node="n205">
            <li data-source-node="n206">
                <p data-source-node="n207">Navigate to <b data-source-node="n208">Dashboard Widget</b> configuration.</p>
            </li>
        </ul>
        <ul data-source-node="n209">
            <li data-source-node="n210">
                <p data-source-node="n211">Click the <b data-source-node="n212">Create New Dashboard Widget</b> button.</p>
            </li>
        </ul>
        <ul data-source-node="n213">
            <li data-source-node="n214">
                <p data-source-node="n215">Provide the following information:</p>
                <ul data-source-node="n216">
                    <li data-source-node="n217">
                        <p data-source-node="n218"><b data-source-node="n219">Widget ID</b>: Use the name of the report (Example: Outbound- Shipment Status).</p>
                    </li>
                    <li data-source-node="n220">
                        <p data-source-node="n221"><b data-source-node="n222">Description</b>: Brief explanation.</p>
                    </li>
                    <li data-source-node="n223">
                        <p data-source-node="n224"><b data-source-node="n225">Widget URL</b>: Paste the custom report URL copied from the SCI application.</p>
                    </li>
                </ul>
            </li>
        </ul>
        <ul data-source-node="n226">
            <li data-source-node="n227">
                <p data-source-node="n228">Save the widget configuration.</p>
            </li>
        </ul>
        <p data-source-node="n229"> </p>
        <h5 data-source-node="n230">Customize Dashboard to add the widget.</h5>
        <ul data-source-node="n231">
            <li data-source-node="n232">
                <p data-source-node="n233">Click <img loading="eager" data-source-node="n234"> Customize to open the <b data-source-node="n235">Dashboard Customization</b> screen.</p>
            </li>
        </ul>
        <ul data-source-node="n236">
            <li data-source-node="n237">
                <p data-source-node="n238">Go to the <b data-source-node="n239">Widgets</b> tab.</p>
            </li>
        </ul>
        <ul data-source-node="n240">
            <li data-source-node="n241">
                <p data-source-node="n242">Use the search bar to find the widget by the ID or name you created earlier.</p>
            </li>
        </ul>
        <ul data-source-node="n243">
            <li data-source-node="n244">
                <p data-source-node="n245">Enable the <b data-source-node="n246">"Add to Dashboard"</b> toggle for the widget.</p>
            </li>
        </ul>
        <ul data-source-node="n247">
            <li data-source-node="n248">
                <p data-source-node="n249">Click <b data-source-node="n250">Save</b> to apply changes.</p>
            </li>
        </ul>
        <p data-source-node="n251">Open the Warehouse Dashboard screen to view the added widget.</p>
