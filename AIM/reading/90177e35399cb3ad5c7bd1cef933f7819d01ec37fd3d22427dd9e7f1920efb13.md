
        
        <h1 data-source-node="n56"><a name="kanchor94" data-source-node="n57"></a>System Status Field</h1>
        <p data-source-node="n58">The status associated with a status action. A system status indicates 
 when a particular process should occur. A status action is assigned 
 to a detail when it requires an action not anticipated in most status 
 flows. Common examples of unanticipated actions include adding or deleting 
 records. A   system 
 status identifies the status that the system will assign to the 
 record when the unanticipated event occurs. For example, the status action Cancel Shipment 
 is assigned to shipments that are removed from a wave build. The system 
 status associated with Cancel Shipment is In Pool; when shipments are 
 canceled from a wave, they return to the shipment pool.</p>
