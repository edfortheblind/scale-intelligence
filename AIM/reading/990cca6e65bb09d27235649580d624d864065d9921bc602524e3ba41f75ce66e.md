
        
        <h1 data-source-node="n56"><a name="kanchor1520" data-source-node="n57"></a>Shipment Consolidation Screen</h1>
        <p data-source-node="n58">The system displays this window when you select the Consolidate action 
 for a shipment. It displays all the shipments that you can consolidate 
 with the one that you selected. You can use it to pick which shipments 
 should be consolidated with your initial shipment. This window can 
 be accessed by selecting the Consolidate action on a shipment from the Shipment Insight or Planned Shipment Insight.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Notes</h5>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">- The following are the rules regarding a shipment's eligibility for manual consolidation:</p>
        <blockquote data-source-node="n64">
            <ul data-source-node="n65">
                <li data-source-node="n66">You can consolidate shipments that are in an In Pool status only with other shipments that are in an In Pool status.<br data-source-node="n67"><br data-source-node="n68"></li>
                <li data-source-node="n69">You can consolidate shipments in a Wave Pending status only with other shipments assigned to that same wave.<br data-source-node="n70"><br data-source-node="n71"></li>
                <li data-source-node="n72">You can consolidate shipments beyond a Wave Pending status if their associated wave has been released, or if they have no associated wave.  They may only be consolidated with other shipments whose wave has been released, or who has no associated wave.<br data-source-node="n73"><br data-source-node="n74"></li>
                <li data-source-node="n75">You cannot consolidate shipments that are on a wave that is either currently running or has completed running, but has not yet been released.</li>
            </ul>
        </blockquote>
        <p data-source-node="n76">- Shipment(s) highlighted 
 in yellow meet the original shipment's required criteria, but contain 
 differences in the criteria that are not required. For the Shipment Consolidation screen, this goes into the Required Criteria accordion. </p>
