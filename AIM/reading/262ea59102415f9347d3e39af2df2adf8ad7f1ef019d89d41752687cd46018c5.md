
        
        <h1 data-source-node="n56"><a name="kanchor1043" data-source-node="n57"></a>Defining Default Inbound Quality Control Inventory Status</h1>
        <p data-source-node="n58">This setting indicates the inventory status that the system will assign 
 to a receipt's item quantity when it is due to enter inbound quality control.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures...</h4>
        <ol class="ol_1" data-source-node="n62">
            <li value="1" data-source-node="n63">Access the Receiving 
 System Values Window and open the "Inventory Status for Quantity 
 Needing QC" record.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li value="2" data-source-node="n66">Use the System 
 Value Field to indicate the appropriate inventory status.<br data-source-node="n67"> </li>
            <li value="3" data-source-node="n68">Press OK. 
 The system will save your changes.</li>
        </ol>
