Transfer Container Screen

You will use this window to transfer a container to a different shipment. When you transfer a container, the system first verifies that no work associated with this container is active. It then transfers all items associated with it. Any portion of shipment lines associated with the container or its children are moved to the new shipment. Each portion transferred becomes a new shipment line (for example, if there are multiple shipping containers tied to the same shipment line, the result will be multiple shipment lines on the new shipment). The system also moves any portion of any work instructions associated with the container or its shipment lines to the new shipment.
