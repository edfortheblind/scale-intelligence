
        
        <h1 data-source-node="n57"><a name="kanchor488" data-source-node="n58"></a>Total One Step Errors Field</h1>
        <p data-source-node="n59">This field indicates the total number of a cycle count plan's one step 
 errors. These errors indicate that it only took "one step" to 
 fix an location's quantity discrepancy. There are two ways you can get 
 a one step error:</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">To not create work and to reconcile the location.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li class="li_1" data-source-node="n64">To create work and the 
 location needs to be reconciled, the preferences are set up so that the 
 user can execute immediate adjustments, and the discrepancy is not outside 
 the user's cycle count preference tolerances.</li>
        </ul>
