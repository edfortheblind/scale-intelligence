        <h4 data-source-node="n155"><a name="Prerequisites" data-source-node="n156"></a>Prerequisites...</h4>
        <p data-source-node="n157">Before you can create a receipt in this screen, you will need to address 
 the "Ship Rec 
 ID Type" and "Ship Rec Type" values on the Receiving System 
 Values screen. </p>

        <h4 data-source-node="n163"><a name="Procedures" data-source-node="n164"></a>Procedures...</h4>
        <p data-source-node="n165">In the Shipment Insight Screen, select
 a shipment and click the action Receipt From Shipment. The system will open the 
 Receipt From Shipment details screen with all the selected shipment related data populated on the screen. </p>
        <ol class="ol_1" data-source-node="n166">
            <li value="1" data-source-node="n167">Indicate a warehouse 
 and company for your new receipt.<br data-source-node="n168"><br data-source-node="n169"></li>
            <li value="2" data-source-node="n170">Select the Go Directly To Receipt Workbench Toggle if you want to load the receipt into the Receipt Workbench. See the  <a href="cdd035231269b9e86ef14a592f83a10888f073e35b300f82b60fe7301b4832ee.html" data-source-node="n171">Processing Receipt</a> topic for information on how to process a receipt in the workbench.<br data-source-node="n172"> </li>
            <li value="3" data-source-node="n173">Enter the quantity 
 you want to add to the receipt in the Returned Quantity Field.<br data-source-node="n174"> </li>
            <li value="4" data-source-node="n175">Press Save. 
 The system will create your receipt. You can access this receipt on the 
Receipt Workbench.<br data-source-node="n176">NOTE: Users can create receipt from shipment for a shipment with single as well as multiple details. System will use the returned quantity entered for each detail and create receipt with all the details based on inputs.</li>
        </ol>

        <h4 data-source-node="n181"><a name="Screen" data-source-node="n182"></a>Screen Actions...</h4>
        <p data-source-node="n183">The following actions are accessible from the Receipt from Shipment Screen: </p>
        <p data-source-node="n184"> </p>
        <h5 data-source-node="n185">Set Returned Quantities to Zero </h5>
        <p data-source-node="n186">This action enables you to set the "Return quantity" on the shipment lines to zero. After setting all the lines to zero and submitting for receipt creation, system will only create receipt without any details.</p>
