
        
        <h1 data-source-node="n56"><a name="kanchor237" data-source-node="n57"></a>Selected Field</h1>
        <p data-source-node="n58">This is a list of fields on the Interface Data Map Window. When an interface 
 data map record is used, the Selected Fields List determines what values 
 are included in an interfaced delimited file, and the order that they 
 appear. Note that you will only need to address this window 
 if you interface data using the delimited or fixed length modes.</p>
