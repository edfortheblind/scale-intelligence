
        
        <h1 data-source-node="n56"><a name="kanchor305" data-source-node="n57"></a>Entering a Web Shipment</h1>
        <p data-source-node="n58">You can enter a shipment into the system from Trading Partner Management. 
 When you enter shipment data into TPM, the system will create a receipt 
 record in SCALE. This is then processed in SCALE like a typical receipt. Trading 
 Partner Management also allows you to create shipments from the Purchase 
 Order Management screen. When you enter a shipment from P.O. Management, 
 TPM will default purchase order data into the appropriate fields on the 
 shipment entry screen.</p>
        <p data-source-node="n59"> </p>
        <p class="p_4" data-source-node="n60">NOTE: Remember that "shipments" in TPM become "receipts" when they enter SCALE.</p>

        <h4 data-source-node="n75">Procedures...</h4>
        <p data-source-node="n76">Log into Trading Partner Management. Choose 
 the Shipment Entry option from the Main Menu. The system will display 
 the Web Shipment Entry screen.</p>
        <p data-source-node="n77"> </p>
        <h5 data-source-node="n78">Step 1: Shipment Lines</h5>
        <p data-source-node="n79">You will use this section to indicate the item(s) 
 and their quantity that you want to add to your shipment.</p>
        <ol data-source-node="n80">
            <li value="1" data-source-node="n81">
                <p data-source-node="n82">In the Shipment Line section, 
 click the Add Button. The system will display the search criteria screen.</p>
                <p data-source-node="n83"> </p>
            </li>
            <li value="2" data-source-node="n84">Enter the item 
 information. Press the Search Button. The system will display the 
 item(s) that 
 matches your criteria.<br data-source-node="n85"> </li>
            <li value="3" data-source-node="n86">
                <p data-source-node="n87">Enter the Net and/or List Price 
 for the item you want to add. Note that these values override this 
 item's price values that may be defined in the system. Also, these values 
 are tracked through the system after this item is located, and later allocated, 
 for a SCALE shipment. </p>
                <p data-source-node="n88"> </p>
            </li>
            <li value="4" data-source-node="n89">Enter the quantity 
 of the item(s) 
 that you want to add. If the item is lot controlled, you may be 
 required to also enter the lot value (depending on your business practices).<br data-source-node="n90"> </li>
            <li value="5" data-source-node="n91">
                <p data-source-node="n92">Press the Add Items Button. 
 The system will add the item quantity to the shipment line section of 
 the Web Shipment Entry Window.</p>
                <p data-source-node="n93"> </p>
                <p data-source-node="n94">NOTE: If you check the Delete Checkbox and press the Delete Button, the 
 system will remove the item quantity from your shipment.<br data-source-node="n95"> </p>
            </li>
        </ol>
        <p data-source-node="n96"> </p>
        <h5 data-source-node="n97">Step 2: Origins</h5>
        <p data-source-node="n98">You will use this section to indicate the ship from address(es) 
 for your shipment.</p>
        <ol data-source-node="n99">
            <li value="1" data-source-node="n100">
                <p data-source-node="n101">In the Origin section, click the 
 Add Button. The system will display the search criteria screen.</p>
                <p data-source-node="n102"> </p>
            </li>
            <li value="2" data-source-node="n103">Enter the pertinent 
 ship from information. Press the Search Button. The system will 
 display the addresses that match your criteria<br data-source-node="n104"><br data-source-node="n105">OR<br data-source-node="n106"><br data-source-node="n107">Enter a new vendor in the name/address fields located below 
 the Ship From Field. When finished, proceed to step 3 of this topic.<br data-source-node="n108"> </li>
            <li value="3" data-source-node="n109">Choose the ship 
 from addresses that you want to associate with your shipment by 
 selecting the checkbox next to the address. <br data-source-node="n110"> </li>
            <li value="4" data-source-node="n111">Enter the email 
 address if appropriate.<br data-source-node="n112"> </li>
            <li value="5" data-source-node="n113">
                <p data-source-node="n114">Press the Add Ship From's Button. 
 The system will add the addresses to the Destination section of the Web 
 Shipment Entry Window.</p>
                <p data-source-node="n115"> </p>
                <p data-source-node="n116">NOTE: If you check the Delete Checkbox and press the Delete Button, the 
 system will remove the ship to address from your shipment.<br data-source-node="n117"></p>
            </li>
        </ol>
        <p data-source-node="n118"> </p>
        <h5 data-source-node="n119">Step 3: Warehouse</h5>
        <p data-source-node="n120">You will use this section to indicate the warehouse where you want this 
 shipment's items to be shipped to.</p>
        <ol data-source-node="n121">
            <li value="1" data-source-node="n122">
                <p data-source-node="n123">In the Warehouse section, 
 select the warehouse where you want your shipment shipped.</p>
                <p data-source-node="n124"> </p>
            </li>
        </ol>
        <p data-source-node="n125"> </p>
        <h5 data-source-node="n126">Step 4: Shipment ID &amp; 
 Shipment Type</h5>
        <p data-source-node="n127">You will use this section to indicate the name and type of shipment 
 you want to create. This step is optional, as the system will default 
 values for these fields if they are left blank.</p>
        <ol class="ol_1" data-source-node="n128">
            <li value="1" data-source-node="n129">In the Shipment 
 ID Field, enter the name you want to give to this shipment. When 
 the system creates this shipment, it will add a prefix to this ID. This 
 value is defined on the Receiving System Values Window. .<br data-source-node="n130"> </li>
            <li value="2" data-source-node="n131">In the Shipment 
 Type Field, indicate the type of shipment you want to create.<br data-source-node="n132"> </li>
        </ol>
        <p data-source-node="n133"> </p>
        <h5 data-source-node="n134">Finishing Your Web Shipment</h5>
        <ul type="disc" class="ul_1" data-source-node="n135">
            <li class="li_2" data-source-node="n136">Press 
 the Verify Shipment Button and the system will display a confirmation 
 screen with your shipment information. If all the information is correct, 
 you can press the      Submit Shipment Button. 
 The system will then create the shipment in the application.<br data-source-node="n137"><br data-source-node="n138">In the verification window, you can press the Modify Shipment Button to return to the shipment entry screen to edit any of the value(s) you provided.<br data-source-node="n139"></li>
        </ul>
