
        
        <h1 data-source-node="n56"><a name="kanchor1084" data-source-node="n57"></a>Receipt ID Prefix Field</h1>
        <p data-source-node="n58">This field indicates the prefix that the system will attach to the beginning 
 of the names of all receipts created in Trading Partner Management. The 
 system will use this value if no receipt ID is provided on the web receipt 
 entry screen.</p>
