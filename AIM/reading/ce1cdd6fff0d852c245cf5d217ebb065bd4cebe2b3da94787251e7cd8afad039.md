
        
        <h1 data-source-node="n56"><a name="kanchor492" data-source-node="n57"></a>Transaction Count Description Field</h1>
        <p data-source-node="n58">Use this value to identify the text for a custom field that will appear 
 on the Manual Labor Entry Screen. 
 This text label will also have a numeric field associated with it. For example, suppose you have a work type defined for "Sweeping 
 Floors," which the warehouse janitor is supposed to track their time 
 with on the Manual Labor Entry Screen. If the Transaction Count Description 
 Field has a value such as "Aisles Swept?, the user then could indicate 
 on the Manual Labor Entry Screen how much work they finished during a 
 certain time period. </p>
