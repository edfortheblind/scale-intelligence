
        
        <h1 data-source-node="n56"><a name="kanchor76" data-source-node="n57"></a>Only Select Records With Mark For Work Creation Set To Yes Checkbox</h1>
        <p data-source-node="n58">Select this checkbox if you want the Create Replenishment Work scheduled job to only choose replenishment requests that have been "marked" by a user in the Replenishment Request screen as being eligible for work creation. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"><i data-source-node="n61">WARNING</i>:  You should typically keep this checkbox selected when using this scheduled job. If you do not, then the system would create work for all requests that do not have this setting selected. </p>
