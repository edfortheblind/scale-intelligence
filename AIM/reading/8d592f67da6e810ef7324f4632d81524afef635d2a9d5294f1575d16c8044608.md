
        
        <h1 data-source-node="n56"><a name="kanchor1899" data-source-node="n57"></a>Message Field</h1>
        <p data-source-node="n58">A message is a descriptive explanation of what happened during a process 
 or action. Messages are displayed on the Warehouse Alerts Window, the Transaction History Insight, and the Process
 History Insight. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Using Warehouse Alerts...</h5>
        <p data-source-node="n62">This field represents the text of an alert, if 
 an email template will not be used. The system uses this message 
 value as a default if the system process does not create its own message. 
 Note that all alert processes create their own message except "Inbound 
 Alert" and "Outbound Alert."</p>
        <p class="p_1" data-source-node="n63">  </p>
        <p class="p_1" data-source-node="n64"> </p>
        <h5 data-source-node="n65">Using Notifications...</h5>
        <p class="p_1" data-source-node="n66">This field represents  the body text of the notification. Note that if a template is selected on the Details Tab of the Notification Window, then the system will ignore the value in this field.</p>
