        <h5 data-source-node="n58">On the Document Type Window...</h5>
        <p data-source-node="n59">This field represents the actual database table that the system will 
 pull data from for this document type. The values in this field are defined 
 on the Detail Data Source Window, and are associated with a particular 
 document filter window. You can only choose this value when 
 creating a new document type. Note that this field is only referenced by the system during wave processing.</p>
