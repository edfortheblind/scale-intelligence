Immediate Needs Note Field

This field indicates the current fulfillment status of an immediate needs request.

 

The Immediate Needs Note field on the List Pane Grid fields of Work Order Insight or Work Order Line Insight screen or Work Order Line Details Screen indicates the status of immediate needs (pending, being fulfilled, partially fulfilled, or fulfilled). These statuses are color coded as follows:

 

Immediate Needs Status Color
01: Pending Red
02: One or More line pending Red
10: Being fulfilled Yellow
11: One or more lines being fulfilled Yellow
12: Partially Fulfilled Yellow
13: One or more lines have been partially fulfilled Yellow
20: Fulfilled Green

 

For more information on this topic, refer to Researching a Warehouse's Immediate Needs.
