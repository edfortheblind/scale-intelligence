
        
        <h1 data-source-node="n56"><a name="kanchor158" data-source-node="n57"></a>Creating Cycle Count Master Records</h1>
        <p class="p_15" style="font-style: italic" data-source-node="n58">** 
 Use with plan based cycle counting 
 **</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The purpose of a cycle count master record is to control what cycle 
 count requests the system creates. Master records are only used in generating 
 plan-based cycle count requests. These records are driven off of item 
 and location criteria records, which you define.</p>
        <p data-source-node="n61"> </p>

        <h4 data-source-node="n97">Procedures...</h4>
        <p data-source-node="n98"> </p>
        <p data-source-node="n99">Create a new record. Provide a name and description.</p>
        <ol data-source-node="n100">
            <li value="1" data-source-node="n101">
                <p data-source-node="n102">Use the Item Selection Field 
 to choose an item filter record to associate with this master. This record 
 is used to filter the locations eligible for cycle counting.</p>
                <p data-source-node="n103"> </p>
            </li>
            <li value="2" data-source-node="n104">Use the Location 
 Selection Field to choose a location filter record to associate 
 with this master. This record is used to filter the locations eligible 
 for cycle counting.<br data-source-node="n105"> </li>
            <li value="3" data-source-node="n106">Use the Maximum 
 Number of Counts Field to indicate the maximum number of cycle 
 count requests you want the system to generate from a particular cycle 
 count plan. Note that if you put a "0" in this field, there 
 will be no maximum limit of requests that the system will create.<br data-source-node="n107"> </li>
            <li value="4" data-source-node="n108">Use the Randomize 
 Check box to indicate that you want the system to create cycle count 
 requests from a random set of locations (based on the range as defined 
 in your Cycle Count Location Selection record for this master). Note that 
 if you do not want the system to have the opportunity to choose the same 
 location every time requests are generated using this master, make sure 
 one of the following conditions exist: <br data-source-node="n109"><br data-source-node="n110">	- On your Cycle Count Location Selection 
 record, include a filter using the Last Cycle Count Date value. 
 For example, if you define a location selection record where the Last 
 Cycle Count Date is greater than 180 days, then the system will not pick 
 a location again until it has not been cycle counted in the last 180 days. 
 Thus, you will not get the unwanted "repeat" cycle count request 
 until a desirable amount of time has elapsed since the last cycle count.<br data-source-node="n111"><br data-source-node="n112">	- If a pending request exists for 
 a location, the system cannot create another request for this location. 
 <br data-source-node="n113"> </li>
            <li value="5" data-source-node="n114">
                <p data-source-node="n115">Use the Run With Scheduled Job 
 Check box to indicate that you want the system to execute a cycle 
 count plan (using this master) at a certain date/time via a system scheduled 
 job. In addition, note that you must set up a record in the Scheduled 
 Job Window in order for the system to run this master with a scheduled 
 job.</p>
                <p data-source-node="n116"> </p>
            </li>
            <li value="6" data-source-node="n117">Use the Create 
 Work Check box indicates how the system should process cycle count 
 plans.<br data-source-node="n118"> </li>
            <ul type="disc" class="ul_1" data-source-node="n119">
                <li data-source-node="n120">
                    <p data-source-node="n121">If this check box is checked, the system will create work for this 
 plan.</p>
                    <p data-source-node="n122"> </p>
                </li>
                <li data-source-node="n123">If this 
 check box is not checked, the system will not create work for this 
 plan. Instead, workers will execute this plan from a cycle count list 
 paperwork document.<br data-source-node="n124"><br data-source-node="n125"></li>
            </ul>
            <li value="7" data-source-node="n126">Use the Update Cycle Count Work to Include All Items Check box to indicate to the system to create cycle count requests for all items currently at a multi-item location, as opposed to creating requests for just the item(s) at the location that match the cycle count item selection criteria.<br data-source-node="n127"><br data-source-node="n128">NOTE: When a multi-item location is initially empty and then items are adjusted into it (prior to the cycle counting work being executed), the system will create a cycle count for every item adjusted into the location, regardless of whether this setting is on or off.<br data-source-node="n129"></li>
            <p data-source-node="n130"> </p>
            <li value="8" data-source-node="n131">When finished, 
 press OK. The system will save your record.</li>
        </ol>
