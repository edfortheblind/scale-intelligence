Choosing the Default System Language

You can define which language that you want the system to use for certain messages and text. For example, when someone is logging onto the RF and Trading Partner Management, the system has not established who the user is yet. Therefore, the system needs to choose a language to display these windows, so it uses this value to decide which language to present these windows with. Another example of the system using this value is to decide which language to use when displaying an error message if a non-system user attempted to start the system application.

Procedures...

  1. Access the Technical Values Window.
     
  2. Open the "Default Language" record.
     
  3. Use the System Value Field to indicate the default system language you want the system to use when displaying certain messages and text.
     
  4. Press OK. The system will save your record.
