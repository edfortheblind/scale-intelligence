Warehouse Mobile System Values

 

These values enable user to activate buffer for scanning, configure buffer queue size and success notification duration for Warehouse Mobile operations.

 

 

System Value Descriptions...

 

Value Key

Value Description

 

10

This setting determines whether buffering is active during scans for all Warehouse Mobile transactions.

 

If set to Yes, scan buffering is enabled, allowing users to buffer the scans during Warehouse Mobile transactions, with the system maintaining a queue of scanned records. The maximum number of scans that can be held in the queue is configured using the "Buffer Queue Size" value. For instance, if the buffer queue size is set to 5, scanning will be disabled when there are 5 records in the queue. Once the number of queued records decreases, scanning is re-enabled. Additionally, if a user encounters an error during a scan, all the unprocessed records in the queue will be cleared, requiring a rescan.

 

If set to No, buffering is deactivated for scanning in Warehouse Mobile. By default, the value is set to No.

 

20

Buffer Queue Size - This value indicates the maximum number of records that can be present in the queue when scan buffering is enabled.

Note: While this setting is designed to help Warehouse Mobile performance, consult your technical personnel before changing this value. By default, value is set to 10 (record).

 

30

Duration for Success Notification (Up to 5000 milliseconds) – This value indicates setting controls how long the success message is displayed on the Warehouse Mobile. Users can configure this duration for a maximum of up to 5000 milliseconds. If a user enters a value exceeding 5000, such as 8000, the system will display the success message for 5000 milliseconds only. If the value is set to zero, the success message won't be displayed on the screen. The default value is set to 3000 milliseconds.

 

If the value is set to zero, then success message is not displayed on the screen.

 

Note: While this setting is designed to help Warehouse Mobile performance, consult your technical personnel before changing this value. By default value is set to 3000 milliseconds.
