
        
        <h1 data-source-node="n56"><a name="kanchor725" data-source-node="n57"></a>Internal Key ID field</h1>
        <p data-source-node="n58">The Internal key ID represents an internal number or ID related to the transaction type.  This can be the Internal Shipment Number for shipment transactions, Internal Container Number for shipping container transactions,  Internal Instruction Number for work execution transactions, and so on.  The internal key id would provide a way to retrieve all the transaction history for a specific shipment.  Some transactions (for example, check in, pack confirmation, and inventory adjustments) do not have an internal key ID.</p>
