
        
        <h1 data-source-node="n56"><a name="kanchor16" data-source-node="n57"></a>Work Order Component Pick List</h1>
        <p data-source-node="n58">A work order component pick list identifies what build components must 
 be picked to build a finished item. It also identifies pick locations 
 for the build components, the quantity required and the build location 
 where they will be delivered. This document is often printed when work 
 is not created for work order processing. Based on the user's work order 
 preferences record and the document type record, the system can print 
 this document automatically when the build components are released.</p>
