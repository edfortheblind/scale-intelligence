Defining TPM Email Alerts

A Trading Partner Management email alert is a message the system sends to a recipient's address when a specific event occurs. The purpose of this message is to inform the email recipient as to the status of their shipment/receipt. The system triggers alerts if a shipment/receipt meets a certain system status, or if the system generates a certain piece of documentation. These alerts can be created/updated from the TPM Email Alert Configuration screen or the SCALE Warehouse Alerts configuration. Note, however, if you want to delete an email alert, you can only do this from the Warehouse Alerts configuration.

 

 

 

Procedures: Defining a new TPM Email Alert...

  1. Log on to Trading Partner Management as an external web user (note that internal web users cannot setup TPM email alerts).

  2. Select the Email Alerts option in the Configurations section at the bottom of the screen. The system will display the Email Alerts Search Criteria screen.

  3. Press the Create New Button (which is located directly under the search criteria fields section, and the system will display the email alert configuration fields.
     
  4. Use the Alert Type Field to indicate if you want the system to generate an inbound (receiving) or outbound (shipping) alert.

  5. Use the Web Description Field to provide a text description for your email alert.

  6. Use the following criteria fields to indicate the data value(s) that you want the system to use when deciding whether to trigger an email alert. Note that you do not need to provide values in all the fields:

    - Status

    - Carrier

    - Company

    - Vendor/Ship From (inbound alerts only)

    - Customer/Ship To (outbound alerts only)

    - Threshold Fields (indicate a minimum weight, minimum number of lines, and/or minimum value)

  7. Use the Email Address Field and Email Template Field to identify the address where the system should send the alert to (for example, customer@store.com), and the template the system should use to format this email. Press the Add button to add this address/template combination to the alert. Note that you can add multiple addresses to an alert, and you can also remove them from the list after they have been added.

  8. Press the Add Alert Button. The system will save the email alert.
