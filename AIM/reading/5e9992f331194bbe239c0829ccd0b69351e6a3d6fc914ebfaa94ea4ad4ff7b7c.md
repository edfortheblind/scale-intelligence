
        
        <h1 data-source-node="n56"><a name="kanchor1337" data-source-node="n57"></a>Automatic Putaway Checkbox</h1>
        <p data-source-node="n58">Select this checkbox if you want the system to automatically putaway 
 items during the work execution process. This would bypass having to manually 
 putaway each item on a shipment. Typically, this setting would be used 
 when you are picking directly into shipping containers (but you can use 
 it in any work scenario, except dock management work, where it is not supported).</p>
        <p data-source-node="n59">Note: When a putaway is performed from a non LP tracked Item location to a LP tracked location, then system will prompt enter the License plate ID. In such scenario, the automatic putaway will not be considered.</p>
