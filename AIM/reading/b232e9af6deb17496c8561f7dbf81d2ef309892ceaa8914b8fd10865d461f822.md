
        
        <h1 data-source-node="n56"><a name="kanchor2" data-source-node="n57"></a>Work Order Assembly Instructions...</h1>
        <p data-source-node="n58">A work order assembly instructions document provides both a list of 
 the build components required to make a finished item and the instructions 
 that describe how to assemble the component parts. This document is often 
 printed when work is not created for work order processing. Based on the 
 user's work order preferences record and the document type record, the 
 system can print this document automatically when the build components 
 are released.</p>
