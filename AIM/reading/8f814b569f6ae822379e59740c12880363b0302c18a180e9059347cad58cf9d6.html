Delivery Date Buttons

These buttons provide the context for the requested delivery date for a specific shipment.

 

 

Deliver On

If this button is selected, the shipment should be delivered on the requested delivery date.

 

Deliver By

If this button is selected, the shipment should be delivered on or before the requested delivery date.

     

Deliver After

If this button is selected, the shipment should be delivered after the requested delivery date. It should not be delivered before or on this date.

 

None

If this button is selected, there is no requested delivery date.

 

 

 

On the Shipment Line Screen...

This field is referred to as the "Requested Delivery Type Field." You cannot edit this field.
