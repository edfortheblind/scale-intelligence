
        
        <h1 data-source-node="n56"><a name="kanchor1841" data-source-node="n57"></a>Record Type Field</h1>
        <p data-source-node="n58">A system-defined value that identifies what 
 type of record you are creating. This value only appears on the following 
 window types: filter criteria windows, generic configuration windows, 
 and the Interface Data Map Window. The system will default this field, 
 and you cannot change the value.</p>
