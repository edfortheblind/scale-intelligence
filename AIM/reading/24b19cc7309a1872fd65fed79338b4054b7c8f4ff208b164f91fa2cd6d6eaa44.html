Group Putaway By Shipping Container Checkbox

This setting indicates that you want the system to group putaway instructions by shipping container, when there are multiple putaway locations associated with multiple containers on the work unit. In other words, if a work unit has multiple putaway locations, then the system will group the putaway instructions for all items in a container to one instruction for that whole container. It will continue to do this for all containers associated with this work unit, until there is only one putaway location left on the work unit. Then, the system will display one instruction telling you to put away the remaining container(s) at the single putaway location.

 

For example, suppose you have the following containers on your work unit:

 

Container 123 (item/putaway loc)

Container 456 (item/putaway loc)

Container 789 (item/putaway loc)

Item AA (2 EA), Yellow staging location

Item AA (13 EA), UPS staging location

Item AA (23 EA), UPS staging location

Item BB (34 EA), Yellow staging location

Item BB (6 EA), UPS staging location

Item BB (11 EA), UPS staging location

Item CC (4 EA), Yellow staging location

  

Item CC (1 EA), UPS staging location
   

Item DD (5 EA), UPS staging location

 

 

If this setting is selected, the system would display two putaway instructions in this example:

  1. One putaway instruction for Container 123 to the Yellow staging location.

  2. One putaway instruction for Container 456 and Container 789 to the UPS staging location (these are putaway together since there is only one putaway location left on the work unit).

 

If this setting is not selected, the system would display four putaway instructions in this example:

  1. One putaway instruction for Container 123, Item AA to the Yellow staging location.

  2. One putaway instruction for Container 123, Item BB to the Yellow staging location.

  3. One putaway instruction for Container 123, Item CC to the Yellow staging location.

  4. One putaway instruction for Container 456 and Container 789 to the UPS staging location (these are putaway together since there is only one putaway location left on the work unit).

 

Other Notes...

This setting is not available if any of the following is selected on your work profile:

  • Container Picking Method of Pick Into Tote

  • Container Picking Method of None

  • To Assign Method of LIFO

  • Putaway Option of Automatic Putaway

  • Putaway Option of Putaway Into Shipping Container
