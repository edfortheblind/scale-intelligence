
        
        <h1 data-source-node="n56"><a name="kanchor90" data-source-node="n57"></a>Hold Code Field</h1>
        <p data-source-node="n58">This field determines whether work can be 
 processed. If this field contains a value, the work will not be released 
 to the warehouse. All work included in a wave that is not automatically 
 released, is held until the wave is released. You can also hold a specific 
 work unit after its been released. This ensures that no one will process 
 the work. </p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61">For waves that are not automatically 
 released, the value is defined on the Work System Values Window.</p>
                <p data-source-node="n62"> </p>
            </li>
            <li data-source-node="n63">For work units 
 that are released by a user, all values are considered valid. The 
 system does not verify this value.</li>
        </ul>
