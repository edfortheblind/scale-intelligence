
        
        <h1 data-source-node="n56"><a name="kanchor1224" data-source-node="n57"></a>Generate Config File Checkbox</h1>
        <p data-source-node="n58">On the Scale Configurations window, when this checkbox is selected, instead of updating the user.config file on the application server with the scale communication information, the system generates a file called Scale weight service.exe.config that must be copied to the client machine where the weigh scale is connected.  This file is generated on the application server C:\Program Files\Manhattan Associates\ILS\&lt;release level&gt;\Client\Scale weight service and needs to be copied to the client machine at C:\Program Files (X86)\Manhattan Associates\Scale weight service.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">A message appears indicating the name and location of the file, and where it needs to be copied to. After copying the Scale weight service.exe.config file to the client machine's Program Files (x86)\Manhattan Associates\Scale weight service folder, the scale attached to the client machine communicates with the client machine, and the user can use it during Close container on that machine.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">NOTE: After copying this to the client machine, the Scale weight service must be restarted on the client machine.</p>
