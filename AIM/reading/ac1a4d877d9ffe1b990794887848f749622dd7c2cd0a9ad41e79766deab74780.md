        <h4 data-source-node="n64">Summary</h4>
        <p data-source-node="n65">The container creation process involves the system creating containers for shipment line item quantities via the execution of a wave step. This wave step determines how many container(s) it will create to pack these allocated item quantities. There are four strategies that can be used by this wave step to determine how to distribute quantities into newly-created containers: <i data-source-node="n66">Consolidate And Do Not Split</i>, <i data-source-node="n67">Split And Do Not Consolidate</i>, <i data-source-node="n68">Consolidate And Split Only Once</i>, and <i data-source-node="n69">3D Cubing</i>. </p>
