
        
        <h1 data-source-node="n56"><a name="LinesActionTiles" data-source-node="n57"></a><a name="kanchor1802" data-source-node="n58"></a>Lines Indicator Tile</h1>
        <p data-source-node="n59">This tile displays the total number of shipment line records for a shipment. Pressing this tile takes you to the Shipment Line Insight screen, filtering the results by specific parameters depending on from which screen it has been accessed.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">On the Purchase Order Insight Screen...</h5>
        <p data-source-node="n63">The Lines Indicator Tile on the Purchase Order Insight represents the count of the number of details the selected purchase order has.  Pressing on this tile takes you to Purchase Order Line Insight screen filtering on the warehouse and Purchase Order Object ID. </p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">On the Wave Insight Screen...</h5>
        <p data-source-node="n67">The Lines Indicator Tile on the Wave Insight represents the total number of shipment lines on that wave. </p>
        <p data-source-node="n68"> </p>
        <p data-source-node="n69"> </p>
        <h5 data-source-node="n70">On the Work Order Insight Screen...</h5>
        <p data-source-node="n71">The Lines Indicator Tile on the Work Order Insight represents the work order lines linked to the specific work order.  Pressing on this tile takes you to Work Order Line Insight screen filtering on the given work order number.</p>
        <p data-source-node="n72"> </p>
        <p data-source-node="n73"> </p>
        <h5 data-source-node="n74">On the Tote Insight Screen...</h5>
        <p data-source-node="n75">The Lines Indicator Tile on the Tote Insight represents the Tote details linked to the specific Tote ID.  Click on this tile takes you to Tote Details Insight screen filtering on the given Tote ID number.</p>
        <p data-source-node="n76"> </p>
