
        
        <h1 data-source-node="n56"><a name="kanchor1494" data-source-node="n57"></a>Manual Dock Door Assignment Checkbox</h1>
        <p data-source-node="n58">If this setting is selected, the system will not create the next move when the dock door on a shipping load is not assigned.  Once the dock door has been manually assigned, the system will then create the dock management work next move to the dock door (when the create next move setting is selected on the flow). Note that the system only evaluates this setting when the next move is to the dock door.</p>
