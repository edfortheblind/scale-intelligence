Installation Guide List

Manhattan SCALE ships with the application a number of installation guides that will assist you in the install/setup processes. You can access these guides using one of the following methods:

  • View a guide by selecting one of the links in this topic.

  • Download a copy of a guide by right-clicking a link and selecting the "Save Target As" (Internet Explorer) or "Save Link As" (Chrome, FireFox).

  • Use Windows Explorer to access the directory that the guides are located: \\SCALE Home\WebHelp\Content\Installation Guides\.
