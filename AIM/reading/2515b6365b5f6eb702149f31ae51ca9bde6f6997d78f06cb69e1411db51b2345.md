
        
        <h1 data-source-node="n56"><a name="kanchor2014" data-source-node="n57"></a>Rate International At Shipment Level Checkbox</h1>
        <p data-source-node="n58">You can use this checkbox to indicate if you want shipments that are 
 associated with this rating ID to be rated as international shipments. 
 If this checkbox is checked (after closing a container), the system will 
 display a prompt asking if you want to rate this shipment internationally 
 at the shipment level. Manifesting will occur after all the containers 
 are closed for this shipment. </p>
