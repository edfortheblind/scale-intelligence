Creating a Carrier Group

A carrier group narrows the number of carriers that the system will rate. If a carrier group is assigned to a shipment, the system will rate only those carriers within the group and select the best carrier. In addition, they help minimize processing time and provide greater control over carrier selection. All carriers must be defined on the Carrier Window before they can be included on the Carrier Group Window. Also, carrier groups can be used with dock management during the dock assignment process to narrow the containers eligible for dock location assignment.

Header Fields...

Identify this group in the Carrier Group Field, and provide a description.

  1. Use the Group Type Field to indicate which process this carrier group will be used for:

    - Rating: If a carrier group record is assigned to a shipment, the system will rate only those carriers within the group and select the best carrier


 

Detail Tab...

After you select the Apply Button, select the Detail Records Tab (not shown). Select New from the Actions Menu. The system will display the Carrier Group Detail Window.

  1. Select the carrier and service that you want to include in the group.

     

  2. Use the Preference Factor Field to assign a preference rating to a carrier. If two valid carriers within the group can meet the ship date, this record serves as the 'tie breaker'. The carrier with the lowest preference factor number is selected. For example, if Fed Ex is assigned the preference factor 1 and UPS is assigned the preference factor 2, the system will selected Fed Ex instead of UPS, assuming that both carriers can meet the required ship date.

 

General Tab...

  1. Select the Use Rating Selection Checkbox if you want the system to rate carriers within this group.  If this checkbox is selected and at least two carriers within the group can meet the ship date, the system will rate the carriers (that meet the date). It will select the cheapest carrier.

     

  2. The Shortest Time Factor Field is reserved for future use.
