
        
        <h1 data-source-node="n56"><a name="kanchor789" data-source-node="n57"></a>Threshold Quantity Field</h1>
        <p data-source-node="n58">This field indicates that you want to count locations whenever they 
 fall below a certain quantity. This value is compared to the location's 
 on hand quantity to see if the location needs to be cycle counted. This 
 value is only used for activity-driven requests. For example, you would set this value to "0," 
 if you wanted to have a cycle count performed whenever a location has 
 a quantity of empty.</p>
