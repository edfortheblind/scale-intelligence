
        
        <h1 data-source-node="n57"><a name="kanchor428" data-source-node="n58"></a>Progistics Bundle Document Checkbox</h1>
        <p data-source-node="n59">This checkbox indicates that this document is part of a "bundle" and should be rated as such. A bundle in Progistics is a set of containers that are to be rated together as one. There will be one document generated per bundle. In SCALE, international shipments are rated in the same manner because they are manifested at the shipment level. Therefore, they would only need one document for the whole "bundle." An example of a document that needs this checkbox selected is an international document, such as a commercial invoice.</p>

        <h5 data-source-node="n62">DHL NOTE...</h5>
        <p class="p_1" data-source-node="n63">DHL shipping labels (regardless of destination) need to have this checkbox selected. With DHL, their shipping labels are considered "bundle" documents, because you can actually send over what DHL calls a multi-piece shipment, which is simply a set of containers shipping to the same place.  It will give them all the same tracking number. In SCALE, you would need to close all of the containers separately, and then perform a Manifest at Shipment Level action.  </p>
