
        
        <h1 data-source-node="n56"><a name="kanchor1780" data-source-node="n57"></a>Wave Mode Field</h1>
        <p class="p_1" data-source-node="n58">The wave mode determines how a wave will be 
 run. There are three types of wave modes:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60"><i data-source-node="n61">Automatic</i> - The system will 
 automatically run the wave as soon as its built.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64"><i data-source-node="n65">Build Inactive</i> - This wave master 
 record is not available for processing. The system will not apply it to 
 any shipments in the pool.<br data-source-node="n66"><br data-source-node="n67"></li>
            <li data-source-node="n68"><i data-source-node="n69">Manual</i> - You must select to 
 run this wave. The system will never automatically run a manual wave.</li>
        </ul>
