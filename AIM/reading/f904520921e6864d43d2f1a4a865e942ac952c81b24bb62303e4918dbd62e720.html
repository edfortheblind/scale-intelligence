Defining Carriers

To be considered during routing and rating, all carriers must be defined on the Carrier Window. The procedures on this page describe how to define carrier and carrier service records. The carrier record is sometimes referred to as the parent record. The carrier service record is sometimes referred to as the child record.

 

 

Parent Records, Child Records, & Inheritance

The parent record represents the transportation company that offers multiple services at different pricing scales, such as UPS or Fed Ex. A child record represents each service provided by that carrier, such as 2nd Day Delivery or Overnight Delivery. By creating separate records for the carrier and its services, you can minimize setup time by using inheritance. Inheritance allows you to default the appropriate carrier values onto the service records. As soon as you provide a value in the Carrier Field and access the Service Field, the system will display the Inherited Checkbox on all other field in the Carrier Window. You can select the checkbox when appropriate, instead of manually entering this information. Of course, you need to define the parent record before you define the child records.

 

 

Do I Need To Create Both Parent & Child Records?

Before setting up a carrier, use the following question to determine if you can benefit from inheritance: Does the carrier provide multiple services that it charges different prices for?

  • If yes, you can minimize setup time by creating a parent record and multiple child records. The parent record would identify the carrier. Each child record would identify a specific service that the carrier supported. This will allow you to inherit shared values, such as address and carrier type. See the Defining the Parent Record section for more details.

     

  • If no, you should create just a parent record. If you only use one service provided by a carrier, or the carrier does not offer any services, you will not need to inherit values across multiple records. You will only need to create one parent record. See the Defining a Child Record section for more details.

 

Note On Using the Inherited Checkbox

If you select the Inherited Checkbox (on any field), the system will default the value from the parent record.

Procedures (Defining the Parent Carrier Record)...

Using the Header Fields
  • You will use the header fields to identify this carrier as an LTL, truckload or parcel parent. You will provide values in the Carrier Field and the Description Field. You will not provide a value in the Service Field. The Service Field identifies a child record.

 

Using the General Tab

  1. Use the Type Field to select what kind of carrier will transport this carrier's product, such as parcel or LTL.

     

  2. Use the Load Size Definition Field to identify the type of trailer this carrier uses to transport product.

     

  3. Use the SCAC Field to identify the carrier's SCAC (Standard Carrier Alpha Code) value. The carrier will supply this code.

     

  4. Use the Shipping Calendar Field to associate this carrier with the appropriate shipping calendar record. These define "no ship days," such as holidays.

     

  5. Use the Pro Number Set Name Field to associate the carrier with its Pro Numbers. The carrier will supply these numbers. This is only done if the carrier is an LTL or truckload carrier.

     

  6. Use the Can Be Used to Ship Checkbox to indicate if this carrier can ship product. Generally, you will want to select this checkbox unless you are creating a parent record that is used for inheritance purposes only.
     

    • If you are defining a parent record only, select this checkbox for the parent record.

       

    • If you are defining both parent & child records, do not select this checkbox for the parent record if its only used for inheritance purposes. Later, when you create the child records, you will select this checkbox for each child record.

       

  7. Use the Can Be Used in Carrier Assignment Checkbox to indicate if this carrier can be rated. Carriers that the system cannot select during assignment can be manually selected.

     

    • If this carrier can accommodate most of your shipments, select this checkbox. During rating, the system will include this carrier and might select it.

       

    • If this carrier rarely transports product for you, consider not selecting this checkbox. This will minimize processing time. You can still select this carrier manually.

 

Using the Address Tab
  1. Use the Address Tab fields to provide the carrier's billing address. You can also identify your contact name at the carrier, his/her phone number and fax number.

 

Using the Rating Tab

 

This tab is only required if you plan to use the rating module. Note: you will not be able to complete this tab's values until you finish the Rating Setup procedures.

  1. Use the Charge Requirement Buttons to indicate whether rating is 'not required', calls an associated internal or external rating engine (system calculated)or is 'manually' added to the shipment.

    2.  

  2. Use the Rating ID Field to identify the server/carrier symbols used to identify where rating is coming from. .

     

  3. Use the Rating Service Field to identify a carrier/service combination. It is used by the system to call external rating engines. For LTL internal rating, this field should be left blank.

     

  4. Use the Rating Profile Field to associate a profile record to this carrier. When rating is run during a wave, the system usually does not know how many containers are on a shipment. It uses the rating profile to estimate how many containers are on a shipment.

  5. Use the FAK LTL Class Field for LTL internal rating. If you want the entire shipment to get rated at the specified LTL Class regardless of the actual classes of the items on the shipment.

  6. Use the Commitments Required for Routing Checkbox to identify how the system will make a carrier decision during routing, when a particular carrier is part of a carrier group. The following is based on when a carrier commitment record does not exist for a certain carrier:

    • If this checkbox is checked, commitments are required for this carrier. Therefore, the system will reject this carrier because no commitment record exists.

    • If this checkbox is not checked, that indicates that commitments are not required for this carrier. Therefore, the system will not reject the carrier. However, a large number of days to deliver is used (999), which makes it almost impossible for that carrier to "win" the selection process and be assigned to the shipment.

 

Using the Internet Information Tab

  1. Use the Email Address Field to provide your contact person's email address.

     

  2. Use the Web Site Field to provide the carrier's website address.

     

  3. Use the Internet Tracking Link Field to identify the carrier's tracking parcels website. This value is required if you want to link a container ID to its carrier's web page in Trading Partner Management. You can obtain this value from the particular carrier that you are linking to.

     

  4. Use the Available for Web Order Checkbox to indicate that you want to be able to choose this carrier when entering a web order via Trading Partner Management.

 

Using the Dock Tab
  1. Use the Consolidation Location Area Field to indicate the default dock location area you want to use when consolidating this carrier's shipments.

 

 

Procedures (defining the child carrier record)...

 

Using the Header Fields

After you define the parcel parent record, you can create the parent child records. These records identify a specific service offered by the carrier that you defined on the parcel parent record. If an LTL or truckload carrier offers services, you can create child records for it.

  1. In the Carrier Field, identify the carrier that offers this service, or the parent carrier. Make sure that you enter this value exactly as it appears on the parent record. When you exit this field and enter the Service Field, the system will recognize that you are creating a child record. It will display the Inherited Checkbox on each field that can obtain its value from the parent record.

     

  2. In the Service Field, identify the service level that you want to define a record for. The value in this field, along with the value in the Carrier Field, will identify this record to the system.
