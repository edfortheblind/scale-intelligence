
        
        <h1 data-source-node="n56"><a name="kanchor1757" data-source-node="n57"></a>Replenish On Outbound Short Pick Checkbox</h1>
        <p data-source-node="n58">This setting indicates that when the user short picks an item quantity at a location, the system will attempt to run replenishment (based on the location's item demand resulting from the short pick). If there is enough In transit quantity that is on its way to the location for this item, then the system will display to the user a message asking whether or not they want to continue with the short pick. For more detailed information about this replenishment process, see the process diagram on the <a href="61f0a241aded189425d956f7a9408608bd793068a8dc510d53f5fb402c6c9b58.html" data-source-node="n59">Replenishment Process Summary</a> topic.</p>
