
        
        <h1 data-source-node="n56"><a name="kanchor209" data-source-node="n57"></a>Enabling GTIN On Item Or Item Cross Reference</h1>
        <p data-source-node="n58">Another step when configuring GS1 barcode processing is to enable the 
 GTIN (Global Trade Item Number) on either your item or item cross reference 
 records (depending on which value you use with GS1). Both of these windows 
 contain a GTIN Enabled Check box, which indicates which application identifier 
 the system needs to use to validate for items (01 is the default) or item 
 cross references (02 is the default). The system will make sure that the 
 ID string lengths for these values (as defined in the Application Identifier 
 Window) are the correct length. 
 This is done so the system can correctly generate valid GS1 barcodes. 
 These validations are performed when you press OK to save the record:<br data-source-node="n59"><br data-source-node="n60">- If the ID is too small, the 
 system will display an alert, and pad the ID with zeros (starting on the 
 left of the value).<br data-source-node="n61"><br data-source-node="n62">- If the ID is too large, the 
 system will display an alert, and you can edit the value.<br data-source-node="n63"><br data-source-node="n64"></p>
