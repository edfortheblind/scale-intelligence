
        
        <h1 data-source-node="n56"><a name="kanchor4" data-source-node="n57"></a>Allocate Complete Checkbox or Toggle</h1>
        <p data-source-node="n58">This checkbox indicates if you want to tell the system that if any part 
 of a shipment fails allocation, the system will reject the entire shipment. 
 You can define this setting at the shipment level.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: If you have this setting active, you can choose to have the system  evaluate all of a shipment's lines for shipment allocation when at least one shipment line fails allocation. See the description of the inventory control system value  
 <a href="2b54fb14f76caf5a3374dd4340c31f58784373a7cddf579f5aa07f62b6059641.html" data-source-node="n61">Show All Allocation Failures for Allocate Complete</a> for more information.</p>
