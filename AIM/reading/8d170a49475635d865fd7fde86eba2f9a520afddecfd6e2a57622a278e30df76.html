Creating Location Templates

A location template defines the structure of a location name. A template record can have up to five segments. Each segment is defined as either alpha or numeric; the system will require users to honor these segment values when they create locations. The maximum amount of characters per template record is 25 (this includes both fields and separator values).

Access the Location Template Window. Create a new record and provide a name in the Location Template Field.

  1. Use the Separator Character Field to identify the value that you want to insert in the location name string. Any text character is valid to use as a separator character except an asterisk (*). Common separator character examples include dashes ( - ) or periods ( . ). Also, users can check the Use space as separator if there are no special characters as sperator.
     

  2. Use the values on each field line to define a field segment of the location template. You can define up to 5 field segments.
     

    • Use the Length Field to define how many numbers or letters should appear before the separator. For example, if you define 4 here, the system will only allow you to type four characters in the first segment.

       

    • Use the Type Field to define what types of values should be required before the separator: letters (alpha) or numbers (numeric).

       

    • Use the Description Field to provide the actual name of the location name segment. The descriptions are included on the Location Window. You can use them to determine where to define each part of the location name.
       
  3. Press OK. The system will save your record.
