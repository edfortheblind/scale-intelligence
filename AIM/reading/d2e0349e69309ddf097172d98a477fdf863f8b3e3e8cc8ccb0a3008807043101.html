Rating/Routing Shipments

Routing and rating determine which carrier will transport a shipment. They are run during a wave. First, routing determines if a particular routing guide should be applied to a shipment. If a routing guide should be applied to the shipment, the system will assign the carrier on the guide to the shipment. The system then selects a carrier to transport a shipment or container, based on predefined parameters. Then, the rating process provides an estimate of how much a carrier will charge to transport a container or shipment. In addition, if a carrier is not already assigned to a container/shipment, rating will select a carrier based on cost. Rating is an optional step. If you are shipping with an LTL carrier, the rate is applied to the shipment. If you are shipping with a parcel carrier, the rate is applied to the container.

Rating Shipments in the Wave...

You can perform rating automatically during the wave cycle. You can add rating as a wave step in the Wave Step Window.

 

 

 

 

Rating Shipments During Ship Confirmation...

When you ship confirm a shipment in the Shipment Insight screen, the system will automatically perform rating if the shipment has not previously been rated. Note that the system will re-rate the shipment only if your rating profile has the "Re-Rate at Ship Confirm" checkbox selected.

 

 

 

 

Routing a Shipment from the Shipment Insight Screen...

You can use the Shipment Insight screen to manually route a shipment. This is especially helpful if you change something about the shipment (e.g. weight, destination) and need to route it with its new properties.

  1. Access the Shipment Insight and select the shipment.

  2. Choose the Route action. The system will route the shipment.

 

 

 

Routing Shipments in the Wave...

To route automatically during a wave, define routing as a wave step. Defining routing guide records that will accommodate the shipments. When the wave is run, it will perform routing for all shipments accepted by a routing guide record.
