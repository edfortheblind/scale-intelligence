Warehouse Mobile - Blind Cycle Count

The Warehouse Mobile blind cycle count enables users with hand held devices to easily blind count the individual cycle count(s) present for the location. The warehouse mobile only displays the location id and does not provide item related information. So the user needs to count each item physically present at the location and enter the quantity.

Blind Cycle Count

Execute a blind cycle count for a single item location by following the steps.

Note: Work special handling is set to perform blind cycle counting.

 

  1. Tap Work Execution and then select work profile in the Select Work Profile screen.
  2. Enter or scan the Work unit and the Blind Cycle Count screen is displayed with the Location ID.
  3. Enter/scan the item at the location. The system will prompt for company selection if configured for the item.
    • If a lot controlled item, the system will prompt for Lot ID.
    • For a license plate tracked location, the system will prompt for License Plate ID.
    • If serial number tracked item, system will prompt for the serial number.
  4. If the capture inventory attributes exit point is enabled, then the system will prompt user to capture 1- 20 inventory attributes. Tap Go to save or skip an attribute.
  5. Enter Quantity and UM.
  6. Click Go to submit the blind cycle count.
  7. The screen navigates back to the Item entry screen to count the next item at the location. Repeat steps 3 to 7.
  8. When you have finished counting all the item(s) in the location, tap Actions >> Done. The system will then stop the blind cycle count for the location and will consider any remaining item quantity as zero.

Actions >> Skip - All instructions at the location will be skipped. If the skip is selected at the last location, then system will navigate back to the first location.

The Skip action will not be available once the location has been completed with cycle count.

 

Actions >> Done - When selected in any of the blind cycle count screen, the system will consider remaining cycle count requests for the location as empty.

 

Cycle Count Preference >> Verify Bad Count - If selected, then when the user entered quantity is more or less than the system count at the location, system prompts a confirmation screen. Tap Yes, to confirm the cycle count for the entered quantity.

 

Work Special Handling >> Set new license plates to pending review

  • When selected, the system will mark the cycle count request to Pending Review when cycle counting for license plates are within the tolerance.

  • When unselected, the system will close the cycle count request and update the On Hand quantity for license plates within the tolerance range.

 

Notes:

  • Item/quantity/check digit/ verification is supported when configured in the work special handling.
  • During blind cycle count, the work special handling configuration is considered over the location configuration.
  • Add inventory for items, lot or license plate which are not found in the location.
  • Add inventory attributes when counting or adding an item.
  • In case the entered item cross reference value is linked to multiple items, then multiple items are displayed in the slider for selection.

  • Counting the same number of license plates the system expects at the location closes the cycle count requests and closes the work instructions.

  • Counting a number less than or greater than expected number of license plates redirects to count quantity for each license plate with message indicating the LP count does not match the system count.

  • Verify empty screen when the license plate tracked location is empty.
