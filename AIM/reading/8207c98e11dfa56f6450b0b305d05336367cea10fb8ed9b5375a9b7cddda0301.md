
        
        <h1 data-source-node="n56"><a name="kanchor2057" data-source-node="n57"></a>Only Custom Text? Checkbox</h1>
        <p data-source-node="n58">You can use this checkbox to subset a search on the System Text Editor 
 Window. If you select this checkbox, the system will 
 only search across custom text in the resource file; it will not search 
 for base text values. Usually, this checkbox is used in conjunction with 
 the Search Field to subset the values dispalyed in the window's record 
 list.</p>
