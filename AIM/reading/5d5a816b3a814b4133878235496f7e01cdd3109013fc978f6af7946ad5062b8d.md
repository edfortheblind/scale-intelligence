
        
        <h1 data-source-node="n56"><a name="kanchor1699" data-source-node="n57"></a>Defining Serial Number Templates</h1>
        <p data-source-node="n58">A serial number template determines the physical structure of a serial 
 number. You can define if a serial will be alpha-numeric or numeric, its 
 length in characters, and whether a serial number can be duplicated (for this template)
 in the system. You can associate a serial number template with an item 
 on the Item Window. SCALE tracks two different types of serial numbers: <i data-source-node="n59">major</i> and <i data-source-node="n60">minor</i>. 
 A major serial number is the 
 primary serial number that the system will reference and display in SCALE. 
 A      minor serial number is a secondary 
 serial number that the system references behind-the-scenes, but is not 
 typically viewable in SCALE windows. Note that you are not required 
 to define minor serial numbers when using serial number tracking. The system can validate serial numbers 
 throughout the warehouse (the Inbound, Inventory, and Outbound processes). 
 Serial numbers are written to their own database table, which allows the 
 system to easily access these values for various processes.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">NOTE: The length of the entire serial number template cannot exceed 50 characters, as that is the maximum length of the Serial Number field in the database.</p>

 drive, and a       modem. The

 templates, then, would need to have the following structure:</p>

        <h4 data-source-node="n133"><a name="Procedures" data-source-node="n134"></a>Procedures: Defining a Serial 
 Number...</h4>
        <p data-source-node="n135">The following procedures explain how to create a serial number template. 
 See the graphics in the example section above to view the screen flow 
 for defining master and minor serial numbers.</p>
        <p data-source-node="n136"> </p>
        <h5 data-source-node="n137">Using the Header Fields... </h5>
        <p data-source-node="n138"> </p>
        <p data-source-node="n139">Access the Serial Number Template Window. Create a new record.</p>
        <ol class="ol_1" data-source-node="n140">
            <li value="1" data-source-node="n141">Use the Template 
 Name Field to indicate the general system identifier associated 
 with this template. In our example, you would enter the value       IBN 
 Computer. This is the value you will see when you choose a serial 
 number template to assign to an item.<br data-source-node="n142"><br data-source-node="n143"></li>
            <li value="2" data-source-node="n144">Use the Description 
 Field to provide a text name for the major serial number.<br data-source-node="n145"><br data-source-node="n146"></li>
            <li value="3" data-source-node="n147">Use the Allow 
 Duplicates Checkbox to determine whether the system will allow 
 users to enter the same serial number for this particular template. Note that this 
 checkbox will be active only if the "Allow Duplicate Serial Numbers" 
 flag in the Inventory Control Values is set at "Y." Be sure 
 to only use this setting if your business process is not affected by having item(s) with the same serial number.<br data-source-node="n148"><br data-source-node="n149">- If unchecked, indicates 
 that you want to prevent duplicate serial numbers from being entered for 
 an individual serial number template.<br data-source-node="n150"><br data-source-node="n151">- If checked, the system will 
 allow duplicate serial numbers across serial number templates. The system will only allow 
 duplicate serial numbers to be added to items that are associated with 
 a serial number template.<br data-source-node="n152"><br data-source-node="n153"></li>
            <li value="4" data-source-node="n154">Use the Allow Range Entry Checkbox to indicate that you want the system to ask for a range of serial numbers (created using this template) during the RF picking/check in of serial number-tracked items. This option is only available when the following criteria are met:<br data-source-node="n155"><br data-source-node="n156">- Templates do not contain minor serial numbers<br data-source-node="n157"><br data-source-node="n158">- Serial numbers end with a numeric value<br data-source-node="n159"><br data-source-node="n160">Note: When range entry is active, the final segment of the serial number template must be numeric, and cannot exceed 9 digits. If for this type of serial number you need to enter a serial number range with greater than 9 digits, you will need to configure another numeric segment (before the final segment) for the additional digits required.<br data-source-node="n161"><br data-source-node="n162">GS1 Note: During the processing of GS1 scans, since the system allows the scanning of only a single serial number from a GS1 barcode, the system ignores a serial number template's "allow range entry" setting. You will, however, be able to enter serial number ranges as part of the normal check in process that occurs after the GS1 scan(s).<br data-source-node="n163"></li>
        </ol>

        <h5 data-source-node="n165">Using the Pattern Fields Tab...</h5>
        <p data-source-node="n166"> </p>
        <p data-source-node="n167">You can use these fields to define how each segment of a serial number 
 will be structured.</p>
        <ol class="ol_1" data-source-node="n168">
            <li value="1" data-source-node="n169">Use the Type 
 Field to indicate what type of character the system will use for 
 this segment of the serial number:<br data-source-node="n170"><br data-source-node="n171">- Alpha: Letters only<br data-source-node="n172"><br data-source-node="n173">- AlphaNumeric: Letters and/or 
 Numbers<br data-source-node="n174"><br data-source-node="n175">- Numeric: Numbers only<br data-source-node="n176"><br data-source-node="n177">- Constant: A specific letter, 
 number, and/or symbol (such as a dash or a double-zero). This value will 
 be the same for any serial number entered using this template. A constant 
 would typically be used as a separator character.<br data-source-node="n178"><br data-source-node="n179"></li>
            <li value="2" data-source-node="n180">Use the Length 
 Field to indicate the mandatory number of characters that the system 
 will expect to be entered for this segment of the serial number.<br data-source-node="n181"><br data-source-node="n182"></li>
            <li value="3" data-source-node="n183">Use the Value 
 Field to indicate the characters you want as a       constant 
 on every serial number that uses this template. For example, you could 
 enter a dash "-" to separate two segments of characters. Note 
 that you must select       constant 
 in the Type Field in order to enter a value into this field.<br data-source-node="n184"><br data-source-node="n185"></li>
            <li value="4" data-source-node="n186">Press the Advanced 
 Button to display more options you can configure for this template:<br data-source-node="n187"><br data-source-node="n188">- Use the Pattern Field to 
 view the code that represents the segments that you defined for this template. 
 The system uses this string to "compute" a serial number according 
 to the parameters in your template.       You 
 should only edit the values in this field if you are strongly familiar 
 with the syntax that is used to code the serial number segments.<br data-source-node="n189"><br data-source-node="n190">- Use the Test Data Field 
 to enter a sample serial number value that you believe matches the structure 
 of this template.<br data-source-node="n191"><br data-source-node="n192">- Press the Test Button to 
 have the system analyze your "test data" and decide if it matches 
 the template. The system will display a message with the test results.<br data-source-node="n193"><br data-source-node="n194">- Press the Basic Button to 
 return to the general Pattern Fields Tab. The system will save any information 
 you have entered into the advanced fields.<br data-source-node="n195"><br data-source-node="n196"></li>
            <li value="5" data-source-node="n197">Press the Add 
 Button to confirm the data you have entered for a major/minor 
 serial number, or one of its particular segment(s). After this button 
 is pressed, you can enter new number/segment data. </li>
        </ol>
