
        
        <h1 data-source-node="n56"><a name="kanchor1237" data-source-node="n57"></a>"Work Unit Field" Field</h1>
        <p data-source-node="n58">The value chosen in this field identifies each work unit generated for 
 this particular work creation master. When the system generates a work 
 instruction, the value chosen in this field is displayed as the instruction 
 number. The system will apply this value to all work units generated for 
 this creation master record.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">For example, if you choose the value "ERP Order" for this 
 field, when a work instruction is generated using this work creation master, 
 the system will display the ERP order number as the instruction number.</p>
