
        
        <h1 data-source-node="n56"><a name="kanchor1992" data-source-node="n57"></a>To Assign Method Field</h1>
        <p data-source-node="n58">This field determines 
 how putaway instructions will be organized on an RF device. This allows 
 you to manage the movement of product to storage locations, dock spots 
 and staging areas.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">There are two possible choices:</p>
        <ul type="disc" class="ul_1" data-source-node="n61">
            <li data-source-node="n62">
                <p data-source-node="n63">LIFO- All putaways are assigned in the Last In, First Out order. The 
 last item picked is the first item put away. This is commonly used if 
 you are processing product stacked on a pallet.</p>
                <p data-source-node="n64"> </p>
            </li>
            <li data-source-node="n65">
                <p data-source-node="n66">Location 
 - All putaways are assigned in location proximity order: the putaway location 
 closest to the user is assigned first. This is commonly used if you are 
 processing product in a bin or other unorganized structure.</p>
            </li>
        </ul>
