
        
        <h1 data-source-node="n56"><a name="kanchor732" data-source-node="n57"></a>Adjusting Inventory (Desktop and RF)</h1>
        <p data-source-node="n58">The term "inventory adjustment" refers to adding/subtracting an item quantity from a location's inventory (outside of a pick or a putaway action). Adjustments allow you to quickly respond to unexpected location activity 
 in real time. You can make adjustments by loose item quantities as well as whole license plates. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> Adjustment 
 types are associated with adjustment classes and are user-configurable. 
 It is this class that determines how the system will process the adjustment 
 type. Because the class determines how the system will process inventory, 
 you can create as many adjustment types as you need. This allows you to 
 use specialized adjustment types for different kinds of inventory or locations. For each adjustment type, you can 
 also determine if can be applied to frozen locations. Also, to minimize errors, 
 you can set minimum and maximum quantity values per adjustment type.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">You can also have the system generate work instructions for certain 
 types of inventory adjustments (performed from the desktop). This allows adjusted quantities 
 to not show up as available in 
 a location until the quantity is actually present (on 
 hand) in the location. </p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64">Notes:</p>
        <ul data-source-node="n65">
            <li data-source-node="n66">The status of allocated inventory can be changed in the shipping and receiving dock.</li>
            <li data-source-node="n67">From the Lot insight screen, user will not be able to perform inventory adjustment/status change/transfer when the updated inventory is linked with inventory attributes.</li>
            <li data-source-node="n68">While editing lot information, user will be able to change status/expiration date. This change will be updated across all inventory records for the item/company/lot in the system.</li>
        </ul>

        <h4 data-source-node="n139"><a name="typeNotes" data-source-node="n140"></a>Adjustment Type Descriptions...</h4>
        <p data-source-node="n141"> </p>
        <h5 data-source-node="n142">Positive Adjustment  </h5>
        <ul data-source-node="n143">
            <li data-source-node="n144">This type of adjustment adds an item quantity to a location.<br data-source-node="n145"><br data-source-node="n146"></li>
            <li data-source-node="n147">The quantity value must be a positive number.<br data-source-node="n148"><br data-source-node="n149"></li>
            <li data-source-node="n150">You can only perform this action on non-parent license plates.</li>
        </ul>
        <p data-source-node="n151"> </p>
        <h5 data-source-node="n152">Negative Adjustment</h5>
        <ul data-source-node="n153">
            <li data-source-node="n154">This type of adjustment removes an item quantity from a location.<br data-source-node="n155"><br data-source-node="n156"></li>
            <li data-source-node="n157">The quantity value must be a negative number (for example, <i data-source-node="n158">-12</i>).<br data-source-node="n159"><br data-source-node="n160"></li>
            <li data-source-node="n161">You can only perform this action on non-parent license plates.</li>
        </ul>

        <h4 data-source-node="n166"><a name="Procedures" data-source-node="n167"></a>Desktop: Performing an Adjustment...</h4>
        <p data-source-node="n168">The following procedures are for performing a positive or negative inventory adjustment from the desktop screen. Note that if you access this screen from the Inventory Insight, then the system will default value(s) into some of these fields where appropriate.</p>
        <ol data-source-node="n169">
            <li value="1" data-source-node="n170">Select the Inventory Adjustment Screen from the system menu. The system will display the Adjustment Type Field.<br data-source-node="n171"><br data-source-node="n172"></li>
            <li value="2" data-source-node="n173">Use the Adjustment Type Field to select a positive or negative adjustment type. The system will display the user and warehouse authorized adjustment types.<br data-source-node="n174"><br data-source-node="n175">- If the selected adjustment type is configured with license plate initiation type, the Adjustment screen is shown with the License Plate field. The system will prompt you to also enter a license plate ID. When you enter an existing license plate and press the Arrow button, the system will display the processing fields. Note that in this instance, only the following fields will be editable: Lot, Expiration Date, Quantity. UM, and Status (positive adjustment only).<br data-source-node="n176"><br data-source-node="n177"></li>
            <li value="3" data-source-node="n178">Use the License Plate Field to indicate the license plate that represents either the license plate that<i data-source-node="n179"> contains the loose quantity</i> that you are adjusting; or, the <i data-source-node="n180">whole license plate</i> that you are adjusting. If the location you are adjusting into is not license plate tracked, then this field will not be editable.<br data-source-node="n181"><br data-source-node="n182"></li>
            <li value="4" data-source-node="n183">Use the Location Field to indicate the location where the item resides.<br data-source-node="n184"><br data-source-node="n185">Locate Action: If necessary, you can use this action (accessed from the Actions menu) to have the system suggest a To location. You will need to choose a locating rule for the system to use in the locating process.  <br data-source-node="n186"><br data-source-node="n187"></li>
            <li value="5" data-source-node="n188">Use the Item Field to indicate the item that you want to adjust. Note that you can only adjust an item if it its "inventory tracking" setting is active (defined on the Item Window).<br data-source-node="n189"><br data-source-node="n190"></li>
            <li value="6" data-source-node="n191">Use the Company Field to indicate the company associated with the item that you are adjusting.<br data-source-node="n192"><br data-source-node="n193"></li>
            <li value="7" data-source-node="n194">Use the Lot Field to indicate the item's lot ID. After the adjustment is initiated, the system will display the Lot Update Confirmation Screen if you change this value.<br data-source-node="n195"><br data-source-node="n196"></li>
            <li value="8" data-source-node="n197">
                <p style="font-size: 10pt" data-source-node="n198">Use the Expiration Date Field to  indicate the lot's expiration date. After the adjustment is initiated, the system will display the Lot Update Confirmation Screen if you change this value.<br data-source-node="n199"><br data-source-node="n200"></p>
            </li>
            <li value="9" data-source-node="n201">Use the Quantity and UM Fields to indicate the amount that you want to adjust. Note that you will not have to enter this value if you are adjusting a full license plate. <br data-source-node="n202"><br data-source-node="n203"></li>
            <li value="10" data-source-node="n204">Use the Status Field to indicate the item's inventory status that will be applied after the adjustment is performed. Note that this field is not available or is ignored when performing a negative adjustment.<br data-source-node="n205"><br data-source-node="n206"></li>
            <li value="11" data-source-node="n207">When finished...<br data-source-node="n208"><br data-source-node="n209"><i data-source-node="n210">Press the Adjust Button</i>, and the system will perform the adjustment. <br data-source-node="n211"><br data-source-node="n212">OR<br data-source-node="n213"><br data-source-node="n214"><i data-source-node="n215">Press the Create Work Button</i> to have the system perform the adjustment and create work for the transaction. The system will prompt you to confirm that you want to have the work created. Note that the Create Work Button will only be active if this adjustment type is configured to create work.</li>
        </ol>
        <p data-source-node="n216"> </p>
        <h5 data-source-node="n217">Processing Notes</h5>
        <ul data-source-node="n218">
            <li data-source-node="n219">The system will not allow you to perform an adjustment to a parent license plate.<br data-source-node="n220"><br data-source-node="n221"></li>
            <li data-source-node="n222">The values for the user defined fields will be defaulted from the Adjustment Type 
 Window record for this particular adjustment type. You can then enter in these fields comments that will 
 be viewable from the transaction history record 
 for this adjustment transaction.<br data-source-node="n223"><br data-source-node="n224"></li>
            <li data-source-node="n225">If it is a new inventory record being adjusted into a location, the user defined field values will be written to the inventory.  If inventory already exists for the item/location/lot/license plate, the existing user defined fields will be retained.<br data-source-node="n226"><br data-source-node="n227"></li>
            <li data-source-node="n228">When entering serial numbers for positive adjustments, you will need to enter the major and minor serial number(s) for this item. When entering serial numbers for negative adjustments, you will only need to select the major serial number(s).</li>
        </ul>

        <h4 data-source-node="n285"><a name="invAtt" data-source-node="n286"></a>Using Inventory Attributes With Inventory Adjustments...</h4>
        <ul data-source-node="n287">
            <li data-source-node="n288">If you try to perform an adjustment (Desktop or RF) to/from a location that has inventory attributes, 
the system will display an error when selecting a location inventory record from the Inventory Insight screen that represents multiple inventory attributes.  If the "Show All License Plates And/Or Inventory Attributes" checkbox on the insight screen is selected, then the system will adjust inventory for the selected record. <br data-source-node="n289"><br data-source-node="n290"></li>
            <li data-source-node="n291">The system will add/subtract inventory at the location without inventory attributes when performing a positive/negative adjustment through the Inventory Adjustment Desktop menu. <br data-source-node="n292"><br data-source-node="n293"></li>
            <li data-source-node="n294">When you access RF inventory management directly from the RF Main Menu screen, the system does not adjust or change the status for inventory linked to inventory attributes.<br data-source-node="n295"><br data-source-node="n296"></li>
            <li data-source-node="n297">When changing inventory status, the system will notify the user that the inventory does not exist when the system has one or more location inventory records linked to inventory attributes. See the topic <a href="8b4ea1511cabbc4ffdc3f55e9e2be35a1b2fcdea91d0088e93891ce192d7e6e5.html" data-source-node="n298">Using Inventory Attributes (RF)</a> for more information.<br data-source-node="n299"><br data-source-node="n300"></li>
            <li data-source-node="n301">Any time you perform an adjustment from system menu for a location having inventory with and without attribute or inventory with different attributes, system always brings up the oldest record and the adjustments are done to the record that was shown.</li>
        </ul>
