Company Configuration

Overview

If you process product for one or more companies, you will need to define them in the system. You can define separate items, employees, customers, and other warehouse entities for each company you define in the system. In addition, you can calculate separate rates per company. You can also define which employees can process a company's products, which items and customers should be associated with a specific company, and generate system documentation that includes the company. Note that customers and items can be setup without companies if they are same values are shared by each company.

 

Configuration Hierarchy

 

 

 

General Company Information

 

  • Company Name: unique entity that ships product from your warehouse, usually under its own brand name.

  • Use the UCC/EAN Number Field to provide the UCC/EAN identifier assigned to this company. This number is a unique prefix that identifies this company.

If a vendor-compliant label is produced for a container linked to this number, and it includes a UCC-128 barcode, the UCC/EAN number will appear in positions 4-10 of the barcode.

  • Use the Order ID Prefix Field to indicate the default prefix that the system will add to all orders created for this company in the full screen and web order entry system.

  • Use the Receipt ID Prefix Field to indicate the default prefix that the system will attach to the beginning of the names of all web receipts created in web receipt entry.

  • Use the Purchase Order ID Prefix Field to indicate the default prefix that the system will attach to the beginning of the names of all web purchase orders created in Trading Partner Management.

  • Use the Availability Checking to indicate that you want the system to verify if the warehouse contains enough quantity to fulfill a company's new shipment. The system performs this validation when an order is created via order entry, or a new shipment line is entered. The system will alert the user if enough inventory does not exist to meet this demand.

 

Company Address

 

This section defines the address associated with the company. The following fields can be used to provide the complete address:

  • City

  • Country

  • Postal Code

  • State

  • Address Fields 1-3: These fields can be used to enter the name, street, and suite address. At least Address Field 1 must contain a value.

These address fields are also used for the Return Address and Freight Bill Address

 

The address fields are similar for the Company Address, Return Address, and Freight Bill-To Address sections.

 

Additional Company Values

 

Attention To: This field specifies the individual who should receive correspondence, invoices, shipments, or any other items related to receipts sent to or shipments sent from the warehouse.

 

Add Phone Number, Fax Number and Email Address.

 

The address fields are the same for the Additional Return Address, and Additional Freight Bill-To Address sections.

 

Warehouse/Company Information

 

You can use this to configure ship from address(es) per warehouse/company combination. If defined, the system will use this address on shipping paperwork. If not defined, then the system will use the company address first, or the warehouse address (if no company address exists). Note that you can only create one address detail record per warehouse/company combination. Also, if the Returns Address and /or Freight Bill To Address tabs are left blank on this detail, then the shipping paperwork will use the values on the Ship From Tab address fields.
