
        
        <h1 data-source-node="n56"><a name="kanchor1950" data-source-node="n57"></a>Field Length Field</h1>
        <p data-source-node="n58">This field appears on template windows (Item Template, Location Template, 
 etc.) and on the System Text Editor Detail Window. It has a unique purpose 
 on both types of windows. </p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">On a Storage Template Window...</h5>
        <p data-source-node="n61">This field determines the following:</p>
        <ul data-source-node="n62">
            <li data-source-node="n63">
                <p data-source-node="n64">The number of letters or numbers that should come before a specific 
 separator value. Field lengths are defined in item template records.</p>
                <p data-source-node="n65"> </p>
            </li>
            <li data-source-node="n66">When a particular value is inserted in a group 
 of item records. After this number of characters in the item number, the 
 separator character will appear.</li>
        </ul>
        <p data-source-node="n67"> </p>
        <h5 data-source-node="n68">On the System Text Editor Window...
</h5>
        <p data-source-node="n69"> This file determines the following:</p>
        <ul data-source-node="n70">
            <li data-source-node="n71">How many characters a field will accommodate. 
 You can only modify a custom text's field size.</li>
        </ul>
        <p class="p_1" data-source-node="n72"> </p>
        <p class="p_1" data-source-node="n73"> </p>
        <h5 data-source-node="n74">Note About Keeping 14 Digits To the Left of the Decimal...</h5>
        <p data-source-node="n75">Below are the settings that are allowed for numeric fields in the System Text Editor if you want to keep 14 digits to the left of the decimal. This is applicable for any numeric fields throughout the system which have a maximum field length of 19,5:</p>
        <p data-source-node="n76"> </p>
        <p data-source-node="n77">[<i data-source-node="n78">field length, decimal position</i>]</p>
        <ol data-source-node="n79">
            <li value="1" data-source-node="n80">14,0</li>
            <li value="2" data-source-node="n81">15,1</li>
            <li value="3" data-source-node="n82">16,2</li>
            <li value="4" data-source-node="n83">17,3</li>
            <li value="5" data-source-node="n84">18,4</li>
            <li value="6" data-source-node="n85">19,5</li>
        </ol>
        <p data-source-node="n86">Note that anything having more than 14 digits to the left of the decimal would be an invalid setting.</p>
