Defining Cycle Count Request Filter Records

 

** Use with plan based and non plan based [activity-driven] cycle counting **

 

A cycle count request filter determines which cycle count plans will be included in the Cycle Count Request Insight screen. Cycle count request filter records display cycle count plans based on criteria that you select. This allows you to create views based on your business needs.

Procedures...

 

Access the Cycle Count Request Filters window. Name this record and provide a description.

  1. Using the Filter Data Tab: You can use this tab to identify which requests will be displayed under the Cycle Count Request Insight Screen's Basic Criteria.

  2. When finished, press OK. The system will save your custom view.
