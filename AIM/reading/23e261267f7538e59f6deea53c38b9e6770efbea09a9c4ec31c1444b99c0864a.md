
        
        <h1 data-source-node="n56"><a name="kanchor1685" data-source-node="n57"></a>Minimum Required Quantity Field</h1>
        <h5 data-source-node="n58">In Work Orders...</h5>
        <p data-source-node="n59">This field indicates the minimum quantity of a component that has to 
 be requested on the work order before it will become eligible for the 
 component quantity increase. Note that you can only edit this 
 setting prior to the first time allocation is attempted on the work order.</p>
