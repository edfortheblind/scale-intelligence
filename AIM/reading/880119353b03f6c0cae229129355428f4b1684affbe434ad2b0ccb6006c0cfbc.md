
        
        <h1 data-source-node="n56"><a name="kanchor1516" data-source-node="n57"></a>Maintain Allocated Replenishments Upon Wave Cancellations Checkbox</h1>
        <p data-source-node="n58">This checkbox determines if the system should "maintain" a replenishment request from the wave if it is canceled. If this checkbox is selected and the system leaves the replenishment, the system will remove the request from the wave (along with its corresponding work). Note that the only time a replenishment will stay out on the system is if some other process has allocated the inventory that is being replenished. In this case, the system will leave the replenishment out there so as not to cause problems with the subsequent activity that allocated it. The system also generates history records that indicate the replenishment request and work was left from the wave.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">For example:</p>
        <p data-source-node="n61">- Suppose you run <i data-source-node="n62">Wave1</i> which creates a replenishment for 10 of an item, and <i data-source-node="n63">Wave1</i> allocates 3 of those.</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65">- You then run <i data-source-node="n66">Wave2</i>, which allocates 5 of the same item from that same location</p>
        <p data-source-node="n67"> </p>
        <p data-source-node="n68">- If you now cancel <i data-source-node="n69">Wave1</i> the system will leave a replenishment for 10 out there so that it does not cause problems with <i data-source-node="n70">Wave2</i>.
</p>
