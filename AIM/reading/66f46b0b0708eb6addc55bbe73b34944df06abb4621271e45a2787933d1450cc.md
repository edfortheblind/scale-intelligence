
        
        <h1 data-source-node="n56"><a name="kanchor503" data-source-node="n57"></a>Defining Text Messages</h1>
        <p data-source-node="n58">A text message provides additional procedures or notes to employees 
 during work processing (RF, Warehouse Mobile or the Work Insight Screen). You will define a text message on the Text Message 
 Window. Later, you will associate the message with the appropriate account 
 or item on the Text Message Assignment Window. Note that the system will only display text messages when the user is executing shipment or dock management work. If you want 
 interfaced shipment comments to appear as text messages in RF and Warehouse Mobile work execution, 
 see the topic    <a href="05dbd950702a3c93f18a1b650e6319fd8e32942de01507409218086f059738cb.html" data-source-node="n59">Configuring/Displaying 
 Interfaced  Text Messages</a> for more information.</p>

        <h4 data-source-node="n89">Procedures...</h4>
        <ol data-source-node="n90">
            <li value="1" data-source-node="n91">
                <p data-source-node="n92">Use the Message ID Field 
 to provide a name for the message. This name will not appear on onscreen.</p>
                <p data-source-node="n93"> </p>
            </li>
            <li value="2" data-source-node="n94">
                <p data-source-node="n95">Use the Comments Field to 
 define the text of the message that you want the system to display onscreen. </p>
                <p data-source-node="n96"> </p>
            </li>
            <li value="3" data-source-node="n97">Use the Communication 
 Method Buttons to define exactly when the system will display the message during work execution. Select    <i data-source-node="n98">Before</i> if you want the message 
 displayed before the user executes the pick. Select    <i data-source-node="n99">After</i>  if you want the message displayed after 
 the user executes the pick.<br data-source-node="n100"> </li>
            <li value="4" data-source-node="n101">Press OK. 
 The system will save your record.</li>
        </ol>
