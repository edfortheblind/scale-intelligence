Logging On To An RF Device

When using an RF device, you will need to log on to the SCALE RF system. Note that during times of inactivity, the RF Device may automatically go into standby mode, which conserves battery life. Press the Power Button to return to the regular power mode. You can also access the RF system from a client machine (via the desktop).

 

The system will display the green dot and red dot icon on the upper right corner of every RF screen when the server is connected and disconnected respectively. The action buttons in each and every page on RF, the hyperlinks, and the shortcut keys are disabled when the server goes offline. Once the server is online, the buttons and hyperlinks are enabled automatically and the shortcut keys will also work.

 

Language Note

You can change the language that the system will use to display text on the RF device on the device itself, regardless of what language setting is currently used on the SCALE application server.

 

Logging Onto Multiple RF Sessions

Do not log onto multiple browser sessions from the same RF device, since the system will treat all sessions as if they were logged on by the same user. If you do this, the system will encounter data issues. Note that this also applies to RF browser sessions running from a full-screen application session as well.

 

 

Procedures...

Access the Terminal Server Client application on your RF Device (via the Windows Start Menu). The system will automatically open the Terminal Server logon screen.
  1. Enter the server where the RF module is located (usually the application server or a special server dedicated to processing RF transactions). You can also select the server name from the "Recent Servers" list.

  2. Press the Connect Button. The system will display the Windows Logon Screen.

  3. Enter your network user name and password, and if necessary, the domain that you are logging onto.

  4. Enter the application environment you want to log on to.

    5.  

  5. Press OK. The system will:

    - Log you onto the RF system, if you do not have an RF password (as defined on the User Profile Window), or if your RF and network password are the same.

    - Display the RF Logon Screen, if your RF and network password are not the same. You will then need to enter your RF user name (the same as you system user name) and password (this value is defined on the User Profile Window). Press the Sign On Button to log on to the RF Device.

    If you get a "User Is Already Signed Onto An RF Session" error when logging on, choose one of the following options: continue or cancel. Choose "continue" if you want the system to end the old RF session and log you on to a new one. Choose "cancel" if you want to work on the old RF session, or log in as a different user. The system will navigate you back to the Logon Screen.
