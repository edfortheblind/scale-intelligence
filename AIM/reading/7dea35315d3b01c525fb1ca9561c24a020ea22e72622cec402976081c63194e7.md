
        
        <h1 data-source-node="n56"><a name="kanchor1721" data-source-node="n57"></a>Status Number Field</h1>
        <p data-source-node="n58">The status number associated with a specific status name. The system 
 uses status numbers to process shipments through all system functions. Status numbers will not appear on any screens; instead, the system will 
 display the corresponding status names. Employees will use the status 
 name to determine the next processing step for a particular shipment. 
 For example, if shipment has the status name 'Ready for Shipping', employees 
 will recognize that it can be ship confirmed. Each functional area has its own status numbers. Any status name defined in the Functional Area 
 Window is considered valid. The system is shipped with predefined statuses: 
 you can change the status name associated with a status number. You cannot 
 change any system defined status numbers.</p>
