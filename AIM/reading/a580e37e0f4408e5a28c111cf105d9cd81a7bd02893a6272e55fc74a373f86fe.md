
        
        <h1 data-source-node="n56"><a name="kanchor226" data-source-node="n57"></a>Activity Criteria Field</h1>
        <p data-source-node="n58">This field indicates the filter criteria record that you want to associate with this VAS activity. This criteria record determines the subset of container(s) that the system will assign this VAS activity to (for example, all containers whose contents include a certain item class). Note that you are not required to select a criteria record for an activity. If none is selected, the system will assign this activity to all containers. To indicate to the system that it should not assign an activity to containers in the wave, you will need to create a criteria record that has rules that would not return any results (such as <i data-source-node="n59">warehouse</i> does not equal the current warehouse). You would typically want to do this if you always interface VAS activities with you orders, and will not need to depend on the criteria record to identify containers that need VAS.</p>
