Inventory Status Change

Inventory status change allows you to change the status of an item quantity in a location. Multiple records can also be selected to change the status. When you perform a status change, then all the locations with the item/company/lot specified will be updated.

Status Change Descriptions...

 

Status Change
  • You can use the "All Locations" toggle to apply a new inventory status to all existing quantities of an item, including all location(s) in the warehouse that contain this item. You will need to enter an "origin" location to perform this action, which simply represents one location that currently contains this item.

  • Status updates do not affect inventory at shipping dock locations.

  • You can only perform status changes on locations that do not have allocated quantities.

Note: When the lot-controlled items status is changed to Unavailable for multiple lots for the same item, the system does not move the lot to Freeze state. In such a scenario, navigate to the Lot insight screen and freeze the lot.

 

Desktop: Performing a Status Change...

The following procedures are for performing a status change from the desktop screen. Note that if you access this screen from the Inventory Insight or Lot Insight screens, then the system will default value(s) into some of these fields where appropriate.

  1. Select the Inventory Status Change Screen from the system menu. The system will display the Adjustment Type Field.

  2. Use the Adjustment Type Field to select the type of status change. The system will display the user and warehouse authorized adjustment types.

    - If the selected status change type is configured with license plate initiation type, the screen is shown with the License Plate field. The system will prompt you to also enter a license plate ID. When you enter an existing license plate and press the Arrow button, the system will display the processing fields. Note that in this instance, only the Status field will be editable.

  3. Use the License Plate Field to indicate the license plate for which you are changing the inventory status. If the location is not license plate tracked, then this field will not be editable.

  4. Use the Item Field to indicate the item for which you want to change the status.

  5. Use the Company Field to indicate the company associated with the item for which you want to change the status.

  6. Use the Lot Field to indicate the item's lot ID. After the status change is performed, the system will display the Lot Update Confirmation Screen if you change the status of the lot after the status change is initiated.

  7. Use the Status Field to indicate the item's inventory status that will be applied after the status change is performed.

  8. Once finished, press the Save button and the system will perform the status change.
