
        
        <h1 data-source-node="n56"><a name="kanchor2000" data-source-node="n57"></a>Maximum Assignments Field</h1>
        <p data-source-node="n58">This field determines the maximum number of work ID(s) that a Vocollect user can work on at one time.
 If it is greater than 1 (with user-directed assignment), then the user will have to speak all of the work IDs before beginning to pick. If it is greater than 1 (with system-directed assignment), the system will assign all of the work IDs first, and then the user will pick them one at a time.</p>
