Closing a Container

You can close containers using the Close Container Screen. The close container process involves advancing a container’s status, and optionally (based on your packing preference settings) auto manifesting, auto printing, and assigning the shipment to a load. Basically, a closed container indicates that the packing process is complete (you cannot pack additional items into it).

 

 

General Notes
  • A document/label will be printed upon closing the last container when the Close Last Container print procedure has been selected on the paperwork’s document type. 

  • If you close a container and there are unpacked quantities (and you are not creating the container at close), the system will not print any "Close Last Container" documents.

  • The system can automatically manifest a container if the Auto Manifest at Close Checkbox is selected on your packing preferences record (and Progistics is installed).

  • If you are grouping containers for this shipment, pack all containers in the group before accessing this screen.

Procedures...

1. After packing a container in the Packing Screen, select the Close Container action or choose the Close Container system menu option. The system will display the Close Container Screen.

2. Enter a shipment ID or container ID (if the value was not already defaulted).

- If configured in packing preferences, you can also enter a new container ID to close as well. Note that the system will validate this new container ID to ensure that it is unique among existing shipping containers and multiple order pallets.

 

3. The system will then display the appropriate container information, such as its container type and weight. If a carrier and service were already assigned to this container, the system will also display this information.

 

4. Identify the weight of the container by either manually entering the weight or using the scale interface (via the Actions menu) in the Weight Field. The system will check the Weight Deviation Field on the container creation record. If this new weight exceeds the deviation, the system will display a warning message. You can then either disregard the message or research the weight deviation.

 

- Note that the scale interface is only available if you have configured the scan and weigh device on the machine you are currently using. Also, if the Close Container Action exit point has been enabled, it will be executed instead of the base package scale interface.

 

- If appropriate, you can change the weight of a container. In this case, the system will remanifest the container.

 

5. Are you grouping containers?

    • If Yes, provide the appropriate values in the Container Count Fields. If this is the first container in the group, both of the fields will be blank. If it is a subsequent container, the system will default the container values, but you can change them.

       

    • If No, leave the Container Count Fields blank, and continue to Step 6.

6. If a carrier is not associated with this container, you can assign one here. The system will assign the shipment and its containers to the carrier's load, if one exists. If a load does not exist, the system will create one (if configured to do so in packing preferences). If appropriate, you can also identify a service with the container.

 

7. Choose a container type if you are creating a new container. The container types available can be authorized by company and warehouse. See the Defining Container Types for more details.

 

8. Press OK. The system will close this container. You will now not be able to pack additional product into this container. After this action, the system will leave the Close Container Screen open. If appropriate, you can close any other containers that are ready. When you are finished closing containers, select the Close Button to exit the screen.

 

 

 

 

Printing Notes...

- The system may produce paperwork for this container, or display the Print Documents Screen, based on the Auto Print at Close Field on your packing preference record. You can also manually print paperwork by selecting the "Print selected documents" option from the Actions menu.

 

- For more information on printing, see the Printing Paperwork topic.

 

 

 

 

Pending VAS Activities...

- There is a setting in packing preferences that allows you to configure if the system will allow the user to ignore a container's pending VAS activities if they exist at the time of close container. See the Allow VAS Override At Close Container and Load Confirm Check box topic for more information.

 

 

 

 

Pending/Failed QC Inspection...

If a container has pending or failed QC inspection associated with it at the time of close container, then the system will prompt the user indicating that they cannot close the container until the QC is performed/resolved.

 

 

 

 

Using Scale Weight...

This action enables you to set a value to get the weight information from an attached scale when it is configured: Once you set this value, the screen remembers the setting and the same setting gets applied whenever you navigate back to the screen on that same browser and machine.

  • When the "Use scale weight" setting is active and the scale is configured properly, upon closing the container the system will retrieve the weight from the scale, apply it to the container, and close the container.

  • When the "Use scale weight" setting is active (but the scale weight service is not running), an error will appear upon closing a container and a message will be logged to the audit log.

  • When the "Use scale weight" setting is active, and the scale weight service is running (but there is a configuration error with the scale on the client machine), an error will appear upon closing a container and a message will be logged to the event log on the client machine.

NOTE: 

When the workstation is configured to use RemoteApp or RDP to access a server and run the web browser from there (such as when using virtualization software), the scale must be set up to communicate to the screen via "wedge" software. This is software that takes the output of the device and sends it to the cursor on the screen, as if it were entered on the keyboard. In this situation, the user must have the cursor on the weight field at the time of placing the container on the scale. The "Use scale weight” setting is ignored in this configuration.

 

For additional information on scale configuration, refer to the Configuring a Scale topic.
