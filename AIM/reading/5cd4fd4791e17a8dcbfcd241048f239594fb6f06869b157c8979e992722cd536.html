Real Time Replenishment Checkbox

You can use this checkbox to indicate that you want to make a location eligible for real time replenishment. When a real time replenishment master is run, the system will run replenishment (via a scheduled job) throughout the day, only for specific locations that would typically need frequent replenishing. Note that the system will check for replenishment need only in locations that actually are currently in the need of replenishment, and are eligible for real time replenishment.

 

 

Item Location Capacity Note

You need to make sure that the item location capacity record for a location is configured correctly when using real time replenishment. If the item location capacity record's minimum threshold value is set to 0%, the system will never set the replenishment evaluation database setting in the database to "Y", even if the location is emptied. That is because this setting only gets changed if the location falls below the minimum threshold. Therefore, the minimum threshold value needs to be set to at least 1%. Once the location falls below 1%, then the system changes the database setting to "Y"and the location is now eligible for real time replenishment.
