
        
        <h1 data-source-node="n56"><a name="kanchor965" data-source-node="n57"></a>Item Touchpoint</h1>
        <p data-source-node="n58">Item master information can be downloaded from the ERP via the system 
 interface. This allows you to populate the item master configuration table, 
 so you don't have to define your products manually in the system. </p>

        <h4 data-source-node="n73">General Guidelines...</h4>
        <ul type="disc" class="ul_1" data-source-node="n74">
            <li data-source-node="n75">You can interface any field that appears on the 
 following windows: Item Window, Item Cross-Reference Window, and the Item 
 Unit of Measure Window. <br data-source-node="n76"> </li>
            <li data-source-node="n77">For each item that you interface, you can include 
 ten cross-reference values and ten units of measure. If an item has more 
 than ten cross-references or units of measure, begin by sending the first 
 ten instances in an interface file. After those records are interfaced, 
 download up to ten more instances. You can continue this process until 
 all cross-reference and unit of measure records are added for an item. 
 Note that if you send down an existing item/company value and no cross-reference 
 or unit of measure value, the system will reject this record as an attempt 
 to duplicate the item.<br data-source-node="n78"> </li>
            <li data-source-node="n79">All items are defined by item/company combination, 
 if your warehouse is a multi-company environment.<br data-source-node="n80"> </li>
            <li data-source-node="n81">If you do not specify a sequence value, the interface 
 will default the sequence to the conversion quantity. <br data-source-node="n82"> </li>
            <li data-source-node="n83">An item cannot be validated for both catch weight 
 and a serial number.<br data-source-node="n84"> </li>
            <li data-source-node="n85">The Item Download interface can process unit of 
 measure values in any order (EA, CS, PL; CS, EA, PL; etc). However, their 
 order (by conversion quantity) must conform to that of the Storage Template 
 associated with the particular item.<br data-source-node="n86"><br data-source-node="n87"></li>
            <li data-source-node="n88">When updating an existing record, if a value is not interfaced for a field, the system treats it as “no change” and retains the existing value.<br data-source-node="n89"><br data-source-node="n90"></li>
            <li data-source-node="n91">If changing the item's storage template and item has item unit of measures and item cross references, then you will need to include the item unit of measures and item cross references for the new storage template in the download.<br data-source-node="n92"><br data-source-node="n93"></li>
            <li data-source-node="n94">If adding or changing the item unit of measure and item cross references exist for the item unit of measure, then you will need to include the item cross reference for the item unit of measure being added or changed.<br data-source-node="n95"><br data-source-node="n96"></li>
        </ul>
        <p data-source-node="n97"> </p>
        <h4 data-source-node="n98">Rejection Causes / Validations / Notes...</h4>
        <ul type="disc" class="ul_1" data-source-node="n99">
            <li data-source-node="n100">You cannot download a new item master record if 
 this item (with the same company designation) already exists in the system. 
 <br data-source-node="n101"> </li>
            <li data-source-node="n102">The SCALE interface process does not support using 
 a comma as a "seperator" for numeric values. These values will 
 need to be interfaced into the system using decimals as seperators (4.95, not      4,95). 
 The system can, however, display these values with a comma seperator on 
 SCALE windows, but in the database they must be in a decimal format.<br data-source-node="n103"><br data-source-node="n104"></li>
            <li data-source-node="n105">
                <p data-source-node="n106">When downloading an item and that includes an item cross reference (and there are user defined fields also specified), these fields get updated on both the Item and Item Cross Reference configurations.</p>
            </li>
        </ul>
