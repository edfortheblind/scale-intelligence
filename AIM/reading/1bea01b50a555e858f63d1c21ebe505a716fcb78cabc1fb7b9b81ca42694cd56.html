Choosing Rules on the Item Master

In order for the system to use advanced rule set assignment for an item, you first need to indicate on the item master that you want to use rule set assignment for this item, by choosing a blank or default allocating/locating rule. This allows the system to choose an appropriate allocating/locating rule using the rule set criteria that you define. You will indicate this setting on the Item Window.

 

 

Procedures...

  1. Access the Item Window from the Configurations Explorer, and open/create an item record.
     
  2. For Inbound Processing: In the Locating Rule Field, choose the *Default value or leave the field blank.

    For Outbound Processing: In the Allocation Rule Field, choose the *Default value or leave the field blank.
     
  3. For information on other fields in this window, see the topic Defining Items in the System.
     
  4. Press OK. The system will save your changes.
