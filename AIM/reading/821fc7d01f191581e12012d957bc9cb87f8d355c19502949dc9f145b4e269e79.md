
        
        <h1 data-source-node="n56">Reviewing Yes, No, Manual, or Immediate (Work Creation Method) Records</h1>
        <p data-source-node="n57">You can review the system-defined yes, no, manual, and immediate validation records for work creation methods that 
 are provided with the system. The system references these records when 
 you select or deselect Work Created checkbox in the Filter Pane of the Replenishment Insight Screen.</p>
        <p data-source-node="n58"> </p>
        <ul data-source-node="n59">
            <li data-source-node="n60">"Yes" is set when work has been created automatically.  The Replenishment Work Creation Method will be set to Automatic on the Replenishment Master.  This work is generated in the wave or when manually initiated from the Inventory Insight.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">
                <p data-source-node="n64">"No" indicates that the work has not been created when initially creating the replenishment request.  This may be updated later once work creation has been run.<br data-source-node="n65"><br data-source-node="n66"></p>
            </li>
            <li data-source-node="n67">
                <p data-source-node="n68">"Manual" is set when the Replenishment Work Creation Method on the replenishment master is set to Manual.  A replenishment request set to Manual can have work created from the Replenishment Insight screen.<br data-source-node="n69"><br data-source-node="n70"></p>
            </li>
            <li data-source-node="n71">
                <p data-source-node="n72">"Immediate" is set when the Replenishment Work Creation Method is set to None.  This indicates that the system has immediately moved the allocated inventory from the From location to the To location.</p>
            </li>
        </ul>
