
        
        <h1 data-source-node="n56"><a name="kanchor1749" data-source-node="n57"></a>Default Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates that you want the user to be able to double-click a record in a viewer/gadget results grid and have the system automatically invoke an action. For example, you may want the 
 system to automatically invoke the Display action when the user double-clicks a shipment record. Note that there can only be one action that is designated as the default for your menu.</p>
