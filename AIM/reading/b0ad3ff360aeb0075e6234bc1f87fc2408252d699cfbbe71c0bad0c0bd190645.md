
        
        <h1 data-source-node="n56"><a name="kanchor1326" data-source-node="n57"></a>Maximum Volume Field</h1>
        <h5 data-source-node="n58">On the Work Creation Master...</h5>
        <p data-source-node="n59">This field indicates the most volume that can be processed in a 
 particular wave or work unit. The  work creation process will start a new work unit when it senses that adding the next work instruction to the current work unit will exceed this maximum value. Note that if a single work instruction in and of itself exceeds this maximum, the instruction will be placed onto a work unit by itself.  It will NOT be broken down into multiple work instructions.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> The volume is always calculated as the base unit of measure quantity (example: eaches) multiplied by the length, width, and height of the item,  regardless of whether the quantity is sufficient to make a higher unit of measure (such as a case or pallet) or not.</p>
        <p data-source-node="n62"> </p>
        <p class="p_1" data-source-node="n63"> </p>
        <p data-source-node="n64">For example:</p>
        <ul data-source-node="n65">
            <li data-source-node="n66">Suppose the Maximum Volume value is set to 100 cubic inches on the shipment allocation work creation master record.<br data-source-node="n67"><br data-source-node="n68"></li>
            <li data-source-node="n69">The shipment has four details (item 1 = 60 cubic inches, item 2 = 40 cubic inches, item 3 =30 cubic inches, item  4 = 80 cubic inches).<br data-source-node="n70"><br data-source-node="n71"></li>
            <li data-source-node="n72">The first item will get added to the first work unit (volume =60).  The system will not break the detail.<br data-source-node="n73"><br data-source-node="n74"></li>
            <li data-source-node="n75">The second item will get added to the second work unit (volume = 100). The system will not break the detail.<br data-source-node="n76"><br data-source-node="n77"></li>
            <li data-source-node="n78">The third item will get added to the third work unit (volume=30). The system will not break the detail.<br data-source-node="n79"><br data-source-node="n80"></li>
            <li data-source-node="n81">The fourth item will NOT get added to the third work unit, because it would exceed the maximum volume value (volume would equal 110). Therefore, the fourth item will get added to the fourth work unit.</li>
        </ul>
