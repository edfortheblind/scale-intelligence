Manifesting a Container/Shipment

When the manifesting process is started, SCALE transmits container-specific information, such as its weight, carrier, and carrier service, to the rating engine (Progistics). Progistics then contacts the carrier's server, and manifests the container. Progistics also retrieves the container's tracking number and its rate, and then transmits this information to SCALE. When a container is packed and closed, the system may automatically manifest it (based on user's packing preference record). Containers can be manually manifested on the Shipping Container Insight screen, and shipments can be manually manifested on the Shipment Insight screen.

Manifesting a Container Automatically During Packing...

The system can manifest a container automatically during the close container process. Automatic manifesting is especially helpful when you want to use the packing station as the place where you pack, manifest and apply the shipping label. A prerequisite to do this is to set your packing preferences to automatically manifest a container when it is closed.

 

 

 

 

Manifesting a Container Manually...

You can use the Shipping Container Insight screen to manually manifest a container. This insight screen action allows you to manifest a shipping container, so that the container is added to a container manifest and assigned a tracking number. You can manifest a container when its status is one of the following: In Pool, Picking Pending, In Picking, In Packing, Ship Confirm Pending, Staging Pending, and Loading Pending. This option is enabled when the container has not been manifested and the container is selected in the List Pane.This is especially helpful if you change something about the container (e.g. weight, destination) and need to re-manifest it with its new properties.

 

Procedures
  1. Access the Shipping Container Insight screen. Access the container you want to manifest.

  2. Select the Manifest action. The system will manifest the container.

 

 

 

Manifesting a Container at the Shipment Level...

You can use the Shipment Level Manifesting Window to manifest a shipment's containers. This is typically used if you need to manifest container(s) at the shipment level, which is typically done for international shipments. Note that the Manifest at Shipment Level action is not enabled if the shipment does not have a carrier assigned or the shipment leading status is greater than Load Confirm Pending.

 

Procedures
  1. Access the Shipment Insight screen, and access the appropriate shipment. Select the Manifest at Shipment Level action.

    OR

    Access the Close Container screen, and close a container from an international shipment, and press the End Shipment Button.

  2. The system will display the Shipment Level Manifesting screen.

  3. Press the Manifest button. The system will manifest the shipment's container(s).

 

 

 

Manifesting a Container at Shipping Load Confirmation...

When you ship confirm a load, the system requires you to manifest all containers that have not yet been manifested.

 

Procedures
  1. Access either the Shipping Load Insight screen, and access the load that you want to confirm.

  2. Select the Confirm action.

  3. Before the system can confirm a load, all the containers on that load must be manifested. The system will review each open shipment and attempt to confirm it. If one or more containers on a shipment have not been manifested, the system will display a message telling you that there are containers not manifested on this load, and asks you if you want to manifest, split, or cancel:

    - If you decide to manifest, the system will manifest all containers.

    - If you decide to split, the system performs the following activity: all containers not yet manifested are assigned to new shipments, which the system automatically generates. All containers that are associated with one shipment are grouped together in one shipment on the new load. The system will not group together containers on different shipments to one shipment on the new load. The system will assign the shipment to a shipping load. If a load exists for this carrier, the system assigns this shipment to the load. If a load does not exist for this carrier, the system creates one for the carrier and assigns the shipment.

    - If you decide to cancel, the system cancels the activity. The load is not confirmed.

 

 

 

Manifesting a Container Using a Conveyor Belt...

If you support a conveyor interface, you can manifest closed containers via the conveyor system. The container will travel down the conveyor belt, and a scanner will scan the shipping label for the container's weight and ID. The container will then be routed to the appropriate dock. A prerequisite to do this is to set your Packing Preferences to "Auto Manifest at Close." Note that the actual manifesting procedures will depend on the conveyor belt setup in your warehouse. Ask your system consultant for more information. For more information on setting up a scan and weigh device, see the topic Configuring a Scale.
