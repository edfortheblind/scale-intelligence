
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor729" data-source-node="n58"></a>Text Message Assignment</h1>
        <p data-source-node="n59">This feature lets you link predefined text messages to specific items or accounts, optionally filtered by company. When a related work instruction is processed, the system displays the message on Warehouse Mobile devices. The actual text message must be defined on the Text Message Window before you can associate it with an item/company or account/company.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">For example,If a company requires a safety booklet to be inserted with an item, a message such as “Insert Safety Message” can be assigned to that item for the specified company. This message will appear only when processing that item for that company.</p>
        <p data-source-node="n62"> </p>
        <h4 data-source-node="n63">Assign Text Message</h4>
        <p data-source-node="n64"> </p>

            </li>

            <li data-source-node="n69">
