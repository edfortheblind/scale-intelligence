
        
        <h1 data-source-node="n56"><a name="kanchor336" data-source-node="n57"></a>Identifying New Locations For Replenishment</h1>
        <p data-source-node="n58">You will use this window to identify which location(s) the system should 
 replenish product to if either of the following situations occurs:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61">The amount of product that you 
 have to replenish exceeds the locations available for replenishment. 
 After the system replenishes to all of the locations that currently contain 
 the product, this field identifies the next location(s) that it can replenish 
 to.</p>
                <p data-source-node="n62"> </p>
                <p data-source-node="n63">OR</p>
                <p data-source-node="n64"> </p>
            </li>
            <li data-source-node="n65">No locations 
 currently contain the item that you need to replenish. In this 
 case, you will use this field to determine where to start replenishing.</li>
        </ul>

        <h4 data-source-node="n106">Procedures...</h4>
        <h5 style="font-weight: normal" data-source-node="n107">Access the Replenishment Empty Location Criteria Window. Name this record 
 and provide a description.</h5>
        <ol class="ol_1" data-source-node="n108">
            <li value="1" data-source-node="n109">Using the Filter 
 Data Tab: You can use this tab to specify the values that the system 
 will use to evaluate locations.<br data-source-node="n110"> </li>
            <li value="2" data-source-node="n111">Using the Order 
 By Tab: You can use this tab to define the order that locations 
 will be organized for possible replenishment.   This 
 tab is optional: you don't have to define this order. If you choose 
 not to address this tab, the system processes through the locations in 
 numeric (or alpha) order; for example, it checks location AAA before location 
 AAB.<br data-source-node="n112"> </li>
            <li value="3" data-source-node="n113">When finished, 
 press OK. The system will save your criteria record.</li>
        </ol>
