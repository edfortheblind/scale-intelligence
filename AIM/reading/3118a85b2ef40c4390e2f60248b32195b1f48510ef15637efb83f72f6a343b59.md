
        
        <h1 data-source-node="n56"><a name="kanchor1253" data-source-node="n57"></a>Using the Process History Insight Screen</h1>
        <p data-source-node="n58">You can use the Process History Insight screen to search and manage the process history records in your warehouse. Any time the system either makes a decision or performs a transaction without user assistance, the system writes a process history record identifying the proceedings. For example, during carrier routing, the system assigns a carrier to each shipment in a wave. During this process, the system generates process history capturing the decision making process, including which carriers are rejected and why.</p>

        <h4 data-source-node="n136"><a name="Searching" data-source-node="n137"></a>Searching/Viewing Process History Records...</h4>
        <p data-source-node="n138">You can use the Process History Insight Screen to search for and view receipt quality records in your warehouse. </p>
        <ol data-source-node="n139">
            <li value="1" data-source-node="n140">Open the Process History Insight Screen.<br data-source-node="n141"><br data-source-node="n142"></li>
            <li value="2" data-source-node="n143">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n144"><br data-source-node="n145"></li>
            <li value="3" data-source-node="n146">Press the Apply Filter Button. The system will display  the resulting records in the List Pane. <br data-source-node="n147"><br data-source-node="n148"></li>
            <li value="4" data-source-node="n149">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>
