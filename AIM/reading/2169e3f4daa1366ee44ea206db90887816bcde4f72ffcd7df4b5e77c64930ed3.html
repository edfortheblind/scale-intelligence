Entering a Web Order

You can enter an order into the system from Trading Partner Management. The file format of a web order is an XML document that is generated by the system. You will have to import this order file into the system's Order Entry Window for this order to become a shipment.

 

 

Procedures...

Log into Trading Partner Management. Choose the Order Entry option from the Main Menu. The system will display the Web Order Entry Window.

 

 

Step 1: Order Detail Section...

You will use this section to indicate the item(s) and their quantity that you want to add to your order.

  1. Click the Add Button. The system will display the search criteria screen.

     

  2. Enter the item information, and press the Search Button. The system will display the item(s) that matches your criteria. Note that the system will display the available quantity of the item(s) you are choosing from, if you have configured your web user profile to do so.

     

  3. Enter the quantity of the item(s) that you want to add to your order. If you check the Delete Check box and press the Delete Button, the system will remove the item quantity from your order.
     
  4. Press the Add Items Button. If necessary, you can enter the item's lot number as well. The system will add the item quantity to the Order Detail section of the Web Order Entry Window.

 

Step 2: Destinations Section...

You will use this section to indicate the ship to address(es) for your order.

  1. Click the Add Button. The system will display the search criteria screen.

     

  2. Enter the pertinent ship to information, and press the Search Button. The system will display the addresses that match your criteria.

     

  3. Choose the ship to addresses that you want to associate with your order by selecting the check box next to the address. Enter an Email address if appropriate. Press the Add Ship To's Button. The system will add the ship to addresses to the Destination section of the Web Order Entry Window. Note that if you check the Delete Check box and press the Delete Button, the system will remove the ship to address from your order.

 

Step 3: Warehouse Section...

You will use this section to indicate what warehouse the item(s) you are ordering are housed in.

  1. In the Warehouse section, select the warehouse that contains the items you are ordering. The system will then display this warehouse's address.

 

Step 4: Carrier and Service Section...

You will use this section to indicate the carrier/service that you want to use to ship your order.

  1. In the Carrier and Service section, select the carrier/service that you want to use to ship your order.

 

Step 5: Process Type Section...

You will use this section to indicate an additional classification for the order. For example, this might be defined to indicate what type of monetary processing an order requires (cash or credit card).

  1. In the Processing Type section, select a process type that you want to associate with this order.

 

Step 6: Comments Section...

You will use this section to include a comment on your order.

  1. Enter any comments that you want to include with your order. The system will save these comments as header-level comments. You can define the comment type assigned to web order entry comments. This is done in the Web System Values Window.

 

Finishing Your Web Order...

- Press the Verify Order Button and the system will display a confirmation screen with your order information. If all the information is correct, you can press the Submit Order Button. The system will then:

  • If your web user "order processing" setting is "manual," then the system will create a file with your pending order. The web order file will be stored in the directory you define in the Web System Values Window. - To see this order as a shipment in the system, you will need to import this order on the Order Entry Window.

  • If your web user "order processing" setting is "automatic," the system will create the order and import it into SCALE, without any user intervention.

  • In the verification window, you can press the Modify Order Button to return to the order entry screen to edit any of the value(s) you provided.
