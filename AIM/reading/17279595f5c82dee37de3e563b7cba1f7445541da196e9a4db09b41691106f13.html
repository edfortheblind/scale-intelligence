Defining When To Check Replenishment Needs For a Location

A replenishment location criteria record determines when a location may be considered for replenishment. It this record is associated with a replenishment master that generates replenishment based on item location capacity, it determines which locations are evaluated for replenishment needs. If this record is associated with a replenishment master which generates replenishment based on pool or wave demand, this record determines which locations the system will attempt to replenish. Any location, inventory, or inventory attributes value(s) can be used to define a replenishment location criteria record

Procedures...

Access the Replenishment Location Criteria Window. Name this record and provide a description.
  1. Using the Filter Data Tab: You can use this tab to specify the values that the system will use to evaluate locations.
     
  2. Using the Order By Tab: You can use this tab to define the order that locations will be organized for possible replenishment. This tab is optional: you don't have to define this order. If you choose not to address this tab, the system processes through the items in numeric order. For example, the system would evaluate location 001-01-9999 before 010-01-9999.
     
  3. When finished, press OK. The system will save your criteria record.
