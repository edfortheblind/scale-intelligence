
        
        <h1 data-source-node="n56"><a name="kanchor1879" data-source-node="n57"></a>Performing Manual Replenishment</h1>
        <p data-source-node="n58">You can manually initiate replenishment from the Inventory Insight screen. When you kick off the manual replenishment 
 process, the system allows you to choose which replenishment master(s) 
 you want to execute. If the "Create Work" checkbox is selected on a replenishment 
 master, the system will create replenishment requests and invoke the work 
 creation process. The system also will generate a replenishment pick list 
 when you run a replenishment, which contains every request for a particular 
 replenishment master.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: Once the system generates a replenishment request, you can manually create work for it on the Replenishment Insight screen.</p>
        <p align="left" class="p_4" data-source-node="n61"> </p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63"> </p>
        <h4 data-source-node="n64">Procedures...</h4>
        <ol data-source-node="n65">
            <li value="1" data-source-node="n66">Access the Inventory Insight, select the 
 location you want to replenish, and select the Replenishment action. The 
 system will display the Manual Replenishment screen. <br data-source-node="n67"> </li>
            <li value="2" data-source-node="n68">Select the replenishment 
 master(s) that you want to run. The system will display only master 
 records that are configured to run in manual mode.<br data-source-node="n69"> </li>
            <li value="3" data-source-node="n70">Press the Replenish button. 
 The system will display a confirmation message, so press Yes to verify that 
 you want to replenish using the selected master record(s). The system 
 will now start the replenishment process. After the replenishment process is complete, the system will run work creation to accommodate the replenishment 
 requests (if configured to do so on the replenishment master). You can 
 research if replenishment was successful on the Process History Insight screen.</li>
        </ol>
