
        
        <h1 data-source-node="n56"><a name="kanchor1408" data-source-node="n57"></a>Creating Receipts From Purchase Orders</h1>
        <p data-source-node="n58">From the Purchase Order Insight screen, you can choose to create 
 a receipt/receipt line from the information contained on a purchase order. This is helpful if your ERP interface does not download receipts into 
 SCALE, but you want to use receipts in your inbound processing flow. Using 
 this functionality, you are able to bypass the need for these downloaded 
 receipts by creating them directly from purchase orders. 
 On a purchase order with open lines, clicking the Receipt from PO action opens the Receipt From Purchase Order Screen with the header and line information from the selected purchase order. Only purchase order lines with open quantity are displayed in the grid specifying lines to be added to a receipt.</p>

        <h5 data-source-node="n151">Warehouse Section</h5>
        <ol class="ol_1" data-source-node="n152">
            <li value="1" data-source-node="n153">Access the Receipt From Purchase Order Screen:<br data-source-node="n154"><br data-source-node="n155">	- Enter a new ID in the Receipt ID 
 Field. The system will then create a new receipt, using the ID 
 that you provided. It will copy all the shared values from the purchase 
 order to the new receipt (company, source address information, etc.)  <br data-source-node="n156"><br data-source-node="n157">	- Enter an existing ID in the Receipt 
 ID Field. The system will accept any receipt ID that exists, and 
 also shares the same company and vendor information. In the case of the 
 vendor information, the receipt and the PO must share the same vendor/company 
 information, but they can be from different ship froms. Also, the receipt 
 cannot be closed. If you happen to assign one receipt ID to multiple POs, 
 the system will display the value "Multiple" in the Purchase 
 Order ID Field on the Receipt screen. <br data-source-node="n158"><br data-source-node="n159">- If you leave the Receipt ID field blank, after a confirmation message the receipt gets created with a receipt ID equal to the purchase order ID plus a numeric next number suffix.  For example, if the purchase order ID were 12345, the first receipt would be created with a receipt ID of 12345-01.  The second receipt would be created with a receipt ID of 12345-02, and so on.<br data-source-node="n160"> </li>
            <li value="2" data-source-node="n161">The Company Field 
 is defaulted by the system from the Purchase Order Screen. <br data-source-node="n162"> </li>
            <li value="3" data-source-node="n163">Select the Go 
 Directly To Receipt Workbench Toggle to have the system to 
 automatically open a new receipt in the Receipt Workbench for 
 processing after you have finished using this screen. <br data-source-node="n164"><br data-source-node="n165"></li>
            <li value="4" data-source-node="n166">Click Save after updating the lines. </li>
        </ol>

        <h5 data-source-node="n173">Item Info Section</h5>
        <p data-source-node="n174">This section identifies the detail lines and quantities to assign to 
 this new receipt. You can choose to set all the line(s) quantities using 
 a percent value or a specific amount; or, you can manually define the 
 quantities separately for each receipt line. These methods are 
 described below:</p>
        <ul type="disc" class="ul_1" data-source-node="n175">
            <li data-source-node="n176">Use the % Toggle to set all the detail lines to a particular percent. 
 This is selected by default; the default value is 100%. When specifying a percent, the percent is taken against the available quantity on the line and rounded to the nearest whole number. After inputting 
 a value, press the Update All Lines Button. The system will then calculate the amount 
 per detail line and display those numbers in the Receipt Quantity Field. 
 <br data-source-node="n177"> </li>
            <li data-source-node="n178">Use the  Quantity Toggle to set all the detail lines to a specific 
 quantity. If the Available Quantity for a particular line is less than 
 the amount defined here, the system will assign the entire amount to this 
 detail. After inputting a value, press the Update All Lines Button. The system will 
 set all of the values in the Receipt Quantity Field to match this value. 
 <br data-source-node="n179"> </li>
            <li data-source-node="n180">You can also 
 manually set the quantity for each of the lines. Using this method, 
 you would directly enter each detail line's quantity to a specific value 
 in the Receipt Quantity Field. If you do not change a value in this field, 
 it remains at the "available quantity" amount.</li>
        </ul>
