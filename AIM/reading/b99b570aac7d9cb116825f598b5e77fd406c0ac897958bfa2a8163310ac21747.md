
        
        <h1 data-source-node="n56"><a name="kanchor137" data-source-node="n57"></a>Separator Character Field</h1>
        <p data-source-node="n58">This field indicates the value that you want to insert into an item 
 or location number string. Common separator characters include the period (.) and the dash (-). Note that an 
 asterisk ( * ) MAY NOT be used as a separator character.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">For item strings, you can define the separator character as part of the item template. Note that you cannot have a blank separator for an item template.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">For location strings, you can define the separator 
 character as part of the location template. These records determine 
 the character to insert after a segment of the ID. Note that you can define a blank value as a separator for a location template. When you specify a blank separator, the system simply concatenates the template segments together with no separator character in between.</li>
        </ul>
