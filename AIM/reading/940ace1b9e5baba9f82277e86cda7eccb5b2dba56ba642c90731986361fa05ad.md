
        
        <h1 data-source-node="n56"><a name="kanchor899" data-source-node="n57"></a>Reference Type Field</h1>
        <p data-source-node="n58">An internally assigned value that identifies 
 a record based on where it originated. The values in this field are dependent 
 on the module that you are researching. For example, if you are researching 
 a work instruction, the record type identifies the order type associated 
 with a work instruction.</p>
