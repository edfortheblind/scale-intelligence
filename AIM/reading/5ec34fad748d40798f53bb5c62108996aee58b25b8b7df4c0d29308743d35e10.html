Determining Maximum Number of Search Records

When the system searches for history records, it retrieves up to a maximum number that you define on the Technical Values Window. This limits the strain on the system as it does not have to search for unwanted records. The default maximum value is 1000 records. Note that the system will display only the first records it retrieves before it reaches the maximum number. To retrieve the most recent records available, you will have to narrow your search further by using the criteria fields.

 

 

Procedures...

 

Access the Technical Values Window.

  1. Select the following value: "Record Number Displayed in Insight and Lookups" (#160). This value defines the maximum amount of history records you want the system to display:
     

    • To limit the number of records, enter a whole number in the field. For example, if you enter the value 1000 in this field, the History Insight screens will only display the first 1000 records it finds that meet your search criteria.

       

      NOTE: This value also applies to other system search windows, such as quick find and lookup windows.

       

    • To see all the records that meet your criteria, enter a "0" in the field. Note that this may affect system performance, depending on how many records the system will need to retrieve from the database.
