        <p data-source-node="n58">Use this window to identify what criteria should be used by Carrier Assignment when determining the rate base. This information is used by Carrier Assignment for any additional criteria that must be used. This criteria must be defined from the shipment. Usage of this window is optional. Carrier Assignment does not require that this additional criteria is defined. For instance, maybe you negotiated a special deal when shipping to Wal-Mart.</p>
