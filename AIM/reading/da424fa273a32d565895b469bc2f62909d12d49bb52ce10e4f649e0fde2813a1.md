
        
        <h1 data-source-node="n56"><a name="kanchor752" data-source-node="n57"></a>Create Next Move Checkbox</h1>
        <p data-source-node="n58">This field indicates that the system will  invoke the work creation process to create the work to represent the transfer of a container from one dock location to another. This is referred to as "creating the next move" for the transfer action.   For example, a dock worker may need to move a container residing at a packing location to a staging location. When the packer closes the container, the system automatically locates the container to a staging location.

  The system will find the appropriate flow detail record (based on the shipping container’s warehouse, custom status flow, and status), and determine if work for this transfer needs to be created.  </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">A situation where you would not want to create the next move is if you want a user to manually assign all dock locations via the Dock Manager Window.<br data-source-node="n61"></p>
