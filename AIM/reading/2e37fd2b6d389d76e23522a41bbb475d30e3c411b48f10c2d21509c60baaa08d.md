        <h5 data-source-node="n58">Using Location Templates...</h5>
        <p class="p_1" data-source-node="n59">This field indicates if a location name segment 
 is going to consist of alpha characters (letters) or numeric characters 
 (numbers). The actual values for each segment will be entered in the Location 
 Window.</p>

        <h5 data-source-node="n64">Using Serial Number Templates / Lot Templates...</h5>
        <p class="p_1" data-source-node="n65">This field indicates if a template segment 
 is going to consist of alpha characters (letters only), alpha-numeric 
 (letters and/or numbers), numeric (numbers only), or constant (a specific 
 letter, number, and/or symbol, such as a dash or a double-zero).</p>
        <p class="p_1" data-source-node="n66"> </p>

        <h5 data-source-node="n68">Using 
 Web Statistics...</h5>
        <p data-source-node="n69">This field is used when running an "Web Statistics" type of 
 scheduled job. It indicates which type of web statistics (Inbound, Outbound, 
 or Item) that you want the system to generate when using this scheduled 
 job.</p>
