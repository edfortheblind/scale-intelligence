
        
        <h1 data-source-node="n56"><a name="kanchor592" data-source-node="n57"></a>Command String Field</h1>
        <p class="p_1" data-source-node="n58">This field indicates the action you want the 
 scale to perform. For example, the "weight" command string will 
 tell the scale to measure the weight of a parcel.</p>
