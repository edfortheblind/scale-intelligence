
        
        <h1 data-source-node="n56"><a name="kanchor1556" data-source-node="n57"></a>Server Symbol Field</h1>
        <p data-source-node="n58">The name of the rating server for a particular carrier. This value is 
 assigned by Progistics. The server is maintained by Progistics. The system provides default server symbols 
 for many common carriers, such as UPS. Review this list and verify that 
 all required carriers are supported. If you need to add a server, contact 
 your system representative. Only a certified 
 system consultant is authorized to identify Progistics servers.</p>
