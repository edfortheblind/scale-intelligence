
        
        <h1 data-source-node="n56"><a name="kanchor953" data-source-node="n57"></a>Locked Field</h1>
        <p data-source-node="n58">This field in the List Pane Grid Fields of Planned Shipment Insight Screen indicates whether the current shipment is locked for some operation (deletion, updating, and so on) or not. A row is only enabled if it is not locked. </p>
