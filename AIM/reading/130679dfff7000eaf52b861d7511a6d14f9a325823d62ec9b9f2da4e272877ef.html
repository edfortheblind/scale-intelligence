Creating a Purchase Order in SCALE

SCALE allows you to review, maintain, and create purchase order information. A purchase order is the entity by which an original request for goods is placed. A purchase order record includes high-level data, such as supplier address information and summary quantities. A purchase order line represents a single line of a purchase order, including item quantities, characteristics, and categories. You can create these new records from the Purchase Order Insight screen.

Creating a Purchase Order Record...

 

The following information is a general description of each accordion used in creating a purchase order. For specific definitions of a certain field, see the "Field Description" section of this topic, or type the field name into the help index.

 

Access the New action in Purchase Order Insight to invoke the Purchase Order screen in new mode.

 

NOTE: You can only edit Purchase Order ID, Receipt Type, and all fields of Source, Ship From, and User Defined accordions.

 

Reference Info Fields

- You can use these fields to identify the new purchase order.

 

Source Fields

- You can use these fields to provide the address information for the source of the items included on this purchase order.

 

Ship From Fields

- You can use these fields to provide the ship from address information, if it is different from the customer's address. If this information is the same, select the Use Source Address toggle. If this toggle is set to Y, the Ship from fields will also get populated with the data of the Source Fields section.

 

Lines Fields

- You can use these fields to view the detail(s)/lines that are associated with this purchase order.

 

Dates Fields

- You can use these fields to define various fields related to purchase order creation and closed dates and time stamps.

 

Totals Field

- You can use these fields to define the number of detail lines associated with this purchase order.

 

User Defined

- You can use these fields to define various user defined fields related to purchase order.

 

When Finished...

- Press Save. The system will create this new purchase order record.

 

 

 

Copying a Purchase Order Record...

 

- Access the Purchase Order Insight Screen, select a purchase order, and choose the Copy action. The system will open the Purchase Orderscreen in copy mode.

 

NOTE: Copying a purchase order copies certain fields (receipt type, source, ship from, user defined, and warehouse) from the selected purchase order along with the selected purchase order’s lines.

 

- You can add values to other purchase order fields. For specific definitions of a certain field, see the "Field Description" section of this topic, or type the field name into the help index.

 

- Press Save to create a new purchase order with the copied lines.

 

 

 

 

Creating a Purchase Order Line Record...

 

The following information is a general description of each accordion used in creating a purchase order line. For specific definitions of a certain field, see the "Field Descriptions" section of this topic, or type the field name into the help index.

 

- Access the New Line action of Purchase Order Insight Screen to open the Purchase Order Line Screen in New mode.

 

Item Info Fields

- You can use these fields to identify the new purchase order line.

 

Quantity Info Fields

- You can use these fields to provide the item quantity and UM data.

 

Item Dimensions Fields

- You can use these fields to further provide an item's properties, such as length, volume, weight.

 

Item Characteristics Fields

- You can use these fields to choose the item attributes, such as color, style, department.

 

Reference Info Fields

- You can use these fields to reference various fields related to purchase order line creation, such as dates and time stamps.

 

Categories Field

- You can use these fields to choose the item category(s) that are associated with this purchase order line record.

 

User Defined Fields

- You can use these fields to define the user defined fields related to this purchase order line.

 

When Finished...

- Press Save. The system will create this new purchase order line record.

 

 

 

Copying a Purchase Order Line Record...

 

- Access the Purchase Order Line Insight Screen and click Copy. Invoking this action will open the Purchase Order Line screen in copy mode.

 

NOTE: All the fields get copied from the purchase order line except for open quantity, purchase order line number, and internal order line number.

 

- You can edit purchase order line fields apart from the read-only fields (Item Info, Quantity Info, Item Dimensions, and Reference Info). For specific definitions of a certain field, see the "Field Description" section of this topic, or type the field name into the help index.

 

- Press Save to create a new purchase order line record.
