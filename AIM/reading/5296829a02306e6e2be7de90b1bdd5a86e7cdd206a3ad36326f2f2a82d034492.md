
        
        <h1 data-source-node="n56"><a name="kanchor1746" data-source-node="n57"></a>Group Position Field / Spot Field</h1>
        <p class="p_1" data-source-node="n58">A group position / spot represents a place on a picking cart where a shipping container will reside. This value is called a Group Position when discussing picking groups created via the wave, and a Spot when discussing RF group user picking. Each picking group is divided into group positions/spots. For example, suppose a 
 group represents a cart whose space is divided into a 4 x 4 grid 
 (four positions horizontally/vertically, for a total of 16 positions). This field identifies the place within a 
 group where a particular container is placed. The user 
then determines from the Picking Group Pick List or RF Pick Confirmation screen which container the picked 
 product will go in (based on its group position/spot). </p>
