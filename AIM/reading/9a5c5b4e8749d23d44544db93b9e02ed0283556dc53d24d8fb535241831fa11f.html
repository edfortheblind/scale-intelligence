Using SCALE's Dynamics AX Built-In Interface

The following is an overview of how the Microsoft Dynamics AX interface works in SCALE.

 

 

 

Interfacing Dynamics AX Data...

 

 

Overview

SCALE is able to receive and transmit data from Microsoft's Dynamics AX application. Data leaves the Dynamics AX system already formatted to SCALE XML standards (no special style sheet transformation is required). Microsoft Dynamics AX and SCALE transfer data through the use of XML data files (using defined XML schemas), using either MSMQ or a write-to-folder protocol. MSMQ is a "listener service" which interacts with Dynamics AX when transferring data between SCALE and Dynamics AX. This service will continuously check for Dynamics AX data that is eligible to be downloaded/uploaded into SCALE.

 

The system also checks for inbound documents during Queue synchronization, which is a configurable timed batch process. The imported documents can then be processed (batch enabled) into their respective recipient tables and fields. Any errors encountered during the import process will be flagged for manual correction for later import into the system.

 

 

 

Touchpoints Supported...

The Dynamics AX Interface supports the following touchpoints:

  • Inventory Transaction Upload

  • Item Master Download

  • Receipt Upload & Download

  • Order Upload & Download

  • Production Orders (Bill of Material in SCALE)

  • Returns

 

 

General Process Flows...

Download Flow: Dynamics AX will generate the data for the supported touchpoints. Dynamics AX will then prepare this data as an XML file (formatted to a SCALE XML schema). As this is going on, the Gateway Queue is continuously checking for eligible data to download from Dynamics AX. Once Dynamics AX has finished formatting the data, the data will be interfaced into SCALE via MSMQ, or writing the files to folders. SCALE will either retrieve the XML files from the MSMQ or by using the folder protocol.

 

Upload Flow: For eligible data, the system will prepare an XML file via SCALE XML interface processing. Queue synchronization will then retrieve any available files, and send them to Dynamics AX.
