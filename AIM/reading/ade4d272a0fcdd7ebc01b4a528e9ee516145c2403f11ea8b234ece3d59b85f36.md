
        
        <h1 data-source-node="n56"><a name="kanchor364" data-source-node="n57"></a>Allocation Name/Allocation Rule Set Field</h1>
        <p data-source-node="n58">This field identifies an allocation rule or rule set. An allocation 
 rule determines how product is allocated from locations. A rule set is 
 a group of rules. The system processes through these rules in sequence 
 order: if the first rule cannot allocate product, the system will attempt 
 to use the second rule, and so on.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60"><span class="span_1" style="font-weight: normal" data-source-node="n61">Allocation 
 rules can also be associated with replenishment records</span>: In this 
 case, the determine how the system will allocate product for replenishment.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64"><span class="span_1" style="font-weight: normal" data-source-node="n65">No allocation 
 rule (work orders)</span>: If you leave the allocation rule blank on the 
 bill of material detail, and then enter a work order line and also leave 
 this value blank, the system will use the allocation rule as defined on 
 the Item Window.</li>
        </ul>
