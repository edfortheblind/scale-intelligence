
        
        <h1 data-source-node="n56"><a name="kanchor1335" data-source-node="n57"></a>Hours Per Day Field</h1>
        <p data-source-node="n58">This field indicates the number of hours (not including breaks) that 
 an employee is regularly scheduled to work. Note that you can provide 
 partial-hour totals in this field by using decimal values (such as 8.5 
 hours).</p>
