
        
        <h1 data-source-node="n56"><a name="kanchor47" data-source-node="n57"></a>Packing Work Type Field</h1>
        <p data-source-node="n58">This field indicates the work type that you want to associate with the packing action, since the system creates no work instructions for packing (and therefore no work type would be assigned). The system uses this work type for labor tracking.</p>
