
        
        <h1 data-source-node="n56"><a name="kanchor653" data-source-node="n57"></a>Dependent Shipments Field</h1>
        <p data-source-node="n58">This field in the List Pane Grid Field of Work Order Insight indicates some quantity or all the quantities of a finished item that are rejected during allocation and for those rejected quantities, work order is created via wave. A blue icon adjacent to the Work Order ID reflects whether the work order has dependent shipments. Work Order Insight Screen has indicator tiles for planned dependent shipments and waved dependent shipments. If the work order has dependent shipments, then these tiles will indicate which shipments are planned and which have already been waved. </p>
