
        
        <h1 data-source-node="n56"><a name="kanchor1941" data-source-node="n57"></a>Profile Name Field</h1>
        <p data-source-node="n58">This field identifies a profile record. A 
 profile record defines the theoretical container weight and volume acceptable 
 for a shipment. During the wave process, the system will reference the rating profile 
 records associated with each carrier. All shipments are theoretically 
 divided into shipping containers during rating. The system references 
 the rating profile record to determine the maximum weight and volume for 
 a container. The system will not exceed 
 the weight or volume defined on the record. If a container exceeds either 
 value, the system will theoretically divide it into multiple containers.</p>
