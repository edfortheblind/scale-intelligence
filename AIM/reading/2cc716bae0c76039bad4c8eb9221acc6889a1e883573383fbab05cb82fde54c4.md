
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Store Location Assignment Criteria</h1>
        <p data-source-node="n58">You will use this configuration to define the specific criteria that the system will use to determine which put-to-store location the allocation process will choose to putaway an item quantity to. For example, suppose you want the system to locate items that have a packing class of "perishable" to be putaway in a certain put-to-store location. You would define a criteria record that indicates that the packing class on the shipment line has to equal "perishable." Then, when the system is processing though the assignment record details for a store, it will see that "perishable" items are to be putaway at a certain put-to-store location.</p>
