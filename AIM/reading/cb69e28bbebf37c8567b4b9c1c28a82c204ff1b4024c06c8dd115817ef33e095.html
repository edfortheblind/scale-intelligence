Warehouse Mobile - Receipt Container Nesting

The Receipt Container Nesting feature allows dock workers to group multiple receipt containers (license plates) under a parent container, such as a pallet. This helps streamline handling, storage, and locating of inbound containers by treating them as one unit.

Receipt Container Nesting

 

  1. Tap Receipt Container Nesting to view the Receipt Container Nesting screen.
  2. Enter or scan the License Plate that you want to nest the container onto Tap Go.
  3. Enter Parent License Plate and Tap Go. the Parent License Plate (LP) field is blank for the first container, requiring the user to manually enter either a new or an existing parent LP. For all subsequent containers, the system automatically defaults the Parent LP to the most recently used one, which the user can accept or modify as needed.
  4. Select the Container Type and Tap Go. When a new parent license plate (LP) is created, the system automatically assigns the default configured container type, while an existing parent LP always keeps its original type
  5. Select the Locating Rule and Tap Go. When new parent license plate (LP) defaults to the rule from the nested container or receipt line, while an existing parent LP always keeps its current locating rule
  6. System will next the container and display a success message.

,

Note

  • Users can nest multiple receipt containers onto one parent pallet.

  • System always defaults to the most recently used parent LP for convenience.

  • Locating rule and container type cannot be overridden once the parent already exists.
