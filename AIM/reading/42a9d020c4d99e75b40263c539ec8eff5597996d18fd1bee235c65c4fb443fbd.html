Allocate In Transit Checkbox

Use this setting to indicate whether or not the system should include "in transit" quantity when computing "available" quantity:

  • If you do not select this value, the system will use the normal computation (on hand - allocated - suspense).

    •  

  • If you select this value, the system will include the "in transit" quantity in the allocation computation (on hand + in transit - allocated - suspense). In this case, then, an allocation can potentially occur for an amount that is greater than the "on hand" quantity.

NOTE: This value would be selected if you are performing replenishments within the flow of a normal work day and/or running demand based replenishment. The system, then, could allocate inventory during the wave, prior to the inventory movement actually taking place. This allows your shipments to allocate normally without having to execute all of the replenishments (prior to running the wave).
