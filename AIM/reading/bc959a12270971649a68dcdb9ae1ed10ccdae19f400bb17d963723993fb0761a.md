        <h4 data-source-node="n242"><a name="Searching" data-source-node="n243"></a>Searching/Viewing Work Records...</h4>
        <p data-source-node="n244">You can use the Work Insight Screen to search for and view work records in your warehouse. </p>
        <ol data-source-node="n245">
            <li value="1" data-source-node="n246">Open the Work Insight Screen.<br data-source-node="n247"><br data-source-node="n248"></li>
            <li value="2" data-source-node="n249">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n250"><br data-source-node="n251"></li>
            <li value="3" data-source-node="n252">Press the Apply Filter Button. The system will display the resulting records in the List Pane. <br data-source-node="n253"><br data-source-node="n254"></li>
            <li value="4" data-source-node="n255">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>
        <p data-source-node="n256">NOTE: Clicking on the Work Unit in the Detail pane header opens the Work Detail screen for that specific instruction.</p>

        <h4 data-source-node="n285"><a name="ScreenActions" data-source-node="n286"></a>Screen Actions...</h4>
        <p data-source-node="n287">The following actions are accessible from the List Pane:</p>
        <p data-source-node="n288"> </p>
        <p data-source-node="n289"> </p>
        <h5 data-source-node="n290">Edit </h5>
        <p data-source-node="n291">This action allows you to change field values on the work instruction. When this action is selected, the system will open the Work Instruction Details screen in edit mode. This action will appear if the user has security access to the "Change" checkpoint.</p>
        <p data-source-node="n292"> </p>
        <p data-source-node="n293"> </p>
        <h5 data-source-node="n294">Delete </h5>
        <p data-source-node="n295">This action allows you to delete a work instruction or multiple work instructions. </p>
        <p data-source-node="n296"> </p>
        <p data-source-node="n297"> </p>
        <h5 data-source-node="n298">Assign Team </h5>
        <p data-source-node="n299">This action allows you to select a team to assign to a work instruction or multiple work instructions. Note that you can only assign a team to a "header" work instruction(s).</p>
        <p data-source-node="n300"> </p>
        <p data-source-node="n301"> </p>
        <h5 data-source-node="n302">Assign User </h5>
        <p data-source-node="n303">This action allows you to select a user to assign to a work instruction or multiple work instructions. Note that you can only assign a user to a "header" work instruction(s).</p>
        <p data-source-node="n304"> </p>
        <p data-source-node="n305"> </p>
        <h5 data-source-node="n306">Change Priority </h5>
        <p data-source-node="n307">This action allows you to change the priority of a work instruction or multiple work instructions, as long as the work instruction(s) is not closed. Note that changing the priority on a work instruction header sets the priority on the header and all the associated work instruction detail(s).</p>
        <p data-source-node="n308"> </p>
        <p data-source-node="n309"> </p>
        <h5 data-source-node="n310">Completed By User</h5>
        <p data-source-node="n311">This action allows you to set the Completed By user field on the work instruction by selecting the work instruction header or work instruction detail. A list of active users will be displayed in the 'Enter a username' field on the prompt. For additional information on this topic, refer to <a href="2a849da2c18bc5244f4e44f5346f871a765c86c96d43a011314a5857cfea60c5.html" data-source-node="n312">Processing Work</a>. </p>
        <p data-source-node="n313"> </p>
        <p data-source-node="n314"> </p>
        <h5 data-source-node="n315">Confirm</h5>
        <p data-source-node="n316">This action allows you to confirm a single or multiple work instruction headers or details. </p>
        <p data-source-node="n317">
            <br data-source-node="n318"> - Only full picks of the confirm quantity will be eligible for picking when selecting a single work instruction header or multiple work instruction headers or details.  Partial, short, over picks, and prompting for serial numbers require confirming a single work instruction detail.<br data-source-node="n319"><br data-source-node="n320"></p>
        <p data-source-node="n321">- Confirming a work instruction header will execute the work for all the open and in process work instruction details of the  selected header.<br data-source-node="n322"><br data-source-node="n323"></p>
        <p data-source-node="n324">- Pick Confirmation Screen is displayed when confirming a single work instruction detail. Selecting the Confirm option will confirm a full pick when the confirm quantity on the Pick Confirmation Screen equals the original confirm quantity from the work instruction.<br data-source-node="n325"><br data-source-node="n326"></p>
        <p data-source-node="n327">- Selecting the Confirm option will confirm a partial pick when the confirm quantity on the Pick Confirmation Screen is less than the original confirm quantity on the work instruction.<br data-source-node="n328"><br data-source-node="n329"></p>
        <p data-source-node="n330">-   The short pick option is used when confirming a short pick. You must select a reason code when confirming a short pick.<br data-source-node="n331"><br data-source-node="n332"></p>
        <p data-source-node="n333">- Confirming a single work instruction detail for an item that is  tracked using a serial number in the inventory will prompt you to select serial numbers when the confirm quantity is less than the location’s quantity.<br data-source-node="n334"><br data-source-node="n335"></p>
        <p data-source-node="n336">- If the To license plate is required, you will be prompted to enter the license plate when confirming single or multiple work instructions (details or headers) .<br data-source-node="n337"></p>
        <p data-source-node="n338"> </p>
        <p data-source-node="n339">For additional information on this topic, refer to <a href="2a849da2c18bc5244f4e44f5346f871a765c86c96d43a011314a5857cfea60c5.html" data-source-node="n340">Processing Work</a>. </p>

        <p data-source-node="n353">This action allows you to override the To location on the selected work instruction. For additional information on this topic, refer to <a href="2a849da2c18bc5244f4e44f5346f871a765c86c96d43a011314a5857cfea60c5.html" data-source-node="n354">Processing Work</a>. </p>

For more information on this topic, refer to <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n359">Printing Paperwork</a>. </p>

        <p data-source-node="n365"> </p>
        <h5 data-source-node="n366">Print Selected Docs</h5>
        <p data-source-node="n367">This action allows you to print all the selected documents. You can cancel or exit out of print select without printing.</p>
        <p data-source-node="n368"> </p>
        <p data-source-node="n369"> </p>
        <h5 data-source-node="n370">Remove Hold </h5>
        <p data-source-node="n371">This action allows you to remove the hold code from a work instruction or multiple work instructions, as long as the hold code is not for one of the following: <i data-source-node="n372">wave not released</i>, <i data-source-node="n373">cycle count plan not released</i>, or <i data-source-node="n374">work order not released</i>. Also, if the work instruction selected is a Header record, then the hold code will be removed from all instructions under that work unit.</p>
        <p data-source-node="n375"> </p>
        <p data-source-node="n376"> </p>
        <h5 data-source-node="n377">Unassign </h5>
        <p data-source-node="n378">This action allows you to unassign a user or team from a work unit or multiple work units, as long as the work(s) is not active. Note that this action will always unassign both user and team from work instruction(s). Also, this option is only allowed on Header records. </p>
