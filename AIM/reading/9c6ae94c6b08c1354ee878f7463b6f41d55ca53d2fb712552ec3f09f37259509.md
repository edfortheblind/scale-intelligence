
        
        <h1 data-source-node="n56"><a name="kanchor1115" data-source-node="n57"></a>SCALE Template Field</h1>
        <p data-source-node="n58">This field  indicates the XML schema that you want a billing management trigger to 
 use. Each trigger is tied to an XML schema (called a system Template). 
 The system template values represent a list of the available schemas that 
 the user can choose from to use for their mapping. This document is the 
 schema that is translated to a pure XML formatted document, and modified 
 to work with the system. After the user chooses a template, it will be 
 used when defining records in the Billing Management Trigger Detail Map 
 screen. The system uses this template to grab each of the attributes from 
 that template and place them in the Billing Management list. It uses Resource 
 Keys to translate the text, but if a key does not exist it will use the 
 original text from the system Template file.</p>
