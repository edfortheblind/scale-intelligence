        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Pallet UM Conversion Criteria defines the filter used to identify eligible records and the ordering rules used to evaluate those records. This configuration is completed in a three-step guided flow: Create, Condition Builder, and Order By.</p>
        <p data-source-node="n61"> </p>

        <h4 data-source-node="n67">Configure Pallet UM Conversion Criteria</h4>
        <p data-source-node="n68"> </p>
        <h5 data-source-node="n69">1. Create Criteria</h5>
        <p data-source-node="n70">Define the filter identity details used by the Pallet UM Conversion Criteria configuration.</p>
        <ul data-source-node="n71">
            <li data-source-node="n72">
                <p data-source-node="n73"><b data-source-node="n74">Filter Name</b> is required and validated for uniqueness in new mode.</p>
            </li>
            <li data-source-node="n75">
                <p data-source-node="n76"><b data-source-node="n77">Description</b> is optional. If left blank, the value defaults to the Filter Name when you continue.</p>
            </li>
            <li data-source-node="n78">
                <p data-source-node="n79">In change mode, Filter Name is read-only and can only be reviewed.</p>
            </li>
        </ul>
        <p data-source-node="n80">Use <b data-source-node="n81">Back</b> to return to the criteria list, <b data-source-node="n82">Save</b> to save and return to Wave configuration, or <b data-source-node="n83">Continue</b> to define conditions.</p>
        <p data-source-node="n84"> </p>
        <h5 data-source-node="n85">2. Build Conditions</h5>
        <p data-source-node="n86">Define selection logic in the Condition Builder for record type <b data-source-node="n87">PALLETUMCONVERSIONCRIT</b>.</p>
        <ul data-source-node="n88">
            <li data-source-node="n89">
                <p data-source-node="n90">Add condition statements to control which records are evaluated.</p>
            </li>
            <li data-source-node="n91">
                <p data-source-node="n92">Use available value helpers for supported attributes, including location-based values.</p>
            </li>
        </ul>
        <p data-source-node="n93">Use <b data-source-node="n94">Back</b> to return to Create, <b data-source-node="n95">Save</b> to save and return to Wave configuration, or <b data-source-node="n96">Continue</b> to define sorting.</p>
        <p data-source-node="n97"> </p>
        <h5 data-source-node="n98">3. Define Order By Rules</h5>
        <p data-source-node="n99">Define the sequence in which matching records are evaluated.</p>
        <ul data-source-node="n100">
            <li data-source-node="n101">
                <p data-source-node="n102">Add one or more order-by rows for <b data-source-node="n103">Attribute</b> and <b data-source-node="n104">Asc/Desc</b>.</p>
            </li>
            <li data-source-node="n105">
                <p data-source-node="n106">Sequence is maintained internally to preserve the configured rule order.</p>
            </li>
        </ul>
        <p data-source-node="n107">Select <b data-source-node="n108">Continue</b> to save criteria details and return to the Wave Picking Group flow.</p>
