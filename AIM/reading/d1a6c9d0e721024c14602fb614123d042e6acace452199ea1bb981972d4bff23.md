
        
        <h1 data-source-node="n56"><a name="kanchor863" data-source-node="n57"></a>License Plate / License Plate ID Field</h1>
        <p class="p_1" data-source-node="n58">This field is a unique, alpha-numeric identifier 
 that represents the identifier for a receipt container or location's license plate. The system uses this value 
 to associate the container/license plate with its contents. If a single line represents multiple license plates, this field will have the value “Multiple”.</p>
        <p class="p_1" data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60"> </p>
        <h5 data-source-node="n61">For Work Orders...</h5>
        <p class="p_1" data-source-node="n62">This field is assigned to finished item(s) during confirmation. The system uses this value to track the item(s) until they're located.</p>
