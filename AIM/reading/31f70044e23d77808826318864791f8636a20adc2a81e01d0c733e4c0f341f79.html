Detail Data Source Field

On the Document Type Window...

This field represents the actual database table that the system will pull data from for this document type. The values in this field are defined on the Detail Data Source Window, and are associated with a particular document filter window. You can only choose this value when creating a new document type. Note that this field is only referenced by the system during wave processing.

On the Viewers Window...

This field indicates the database table that you want to assign as the secondary table for a viewer window. The table you select as the detail data source identifies the following:

- The fields that are displayed for detail records associated with each header record in the results grid.

NOTE: You cannot use fields from a detail data source table as search criteria fields.
