
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor716" data-source-node="n58"></a>Cycle Count Request Filters configuration</h1>
        <p data-source-node="n59">Cycle count request filters define which cycle count plans appear in the Cycle Count Request Insight screen. These filters display plans based on selected criteria, allowing tailored views based on business needs.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Note: Use with plan based and non plan based [activity-driven] cycle counting.</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">You can use this record to identify which requests will be displayed under the Cycle Count Request Insight Screen's Basic Criteria.</p>
