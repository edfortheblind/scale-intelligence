Machine Name Field

On the Document Routing Window...

This field refers to the machine requesting the printing (i.e. the workstation). It does not expect the domain name suffix.

Note: The default printers override printers assigned to workstations. Read Defining User Profiles

 

For example,. suppose you have a printer located at a specific packing station, from which you want to generate Container Contents Labels. If you define a Machine Name, no matter the user that is signed onto this packing station client machine, the system will print the label at the printer present at that station. This is helpful because you do not have to set up this document by user, and force them to always use the same packing station.
