Creating Notifications

Notifications provide you a method by which you can configure multiple recipients who will be sent an e-mail/text message based on the results of a personal alerts data query. Note that notifications are generated using the Personal Alerts scheduled job.

Procedures...

Access the Notifications configuration window from the Configurations Explorer.

 

Using the Header Fields
  1. Provide a Name and Description for this record.

  2. Use the Subject Field to indicate the title of the notification.

  3. Use the Message Field to indicate the body text of the notification. Note that if a template is selected on the Details Tab, then the system will ignore the value in this field.
 
Using the Detail Records Tab

You can define any number of notification recipients using this tab. Note that you can select different templates/delivery mechanisms for each recipient.

  1. Use the Address Field to indicate the email address of the recipient for this notification.

  2. Use the Template Field to indicate the template that the system will use to generate this notification. The following template formats are supported: XML, HTML, plain text, and rich text. Inside the template, things such as links to Insight screens, links per data row returned in .csv file, and header/footer data are supported. See the SDK for more information/examples on notification templates.

  3. Use the Delivery Mechanism Field to indicate how the system will send this notification: by Email or SMS (text message). The system will invoke the selected delivery mechanism when the Notification Processing scheduled job runs.

  4. Use the Include Field Checkbox to indicate if you want the system to attach the data file (in .csv format) to this notification.

  5. Use the Active Checkbox to indicate that you want the system to send a notification to this recipient. If this is not selected, then the system will not send a notification to this address, but it will remain in the details grid so you can activate it at a later time.
 
When Finished...
  1. Press the OK button, and the system will save your record.
