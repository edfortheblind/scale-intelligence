
        
        <h1 data-source-node="n56"><a name="kanchor604" data-source-node="n57"></a>Defining Equipment Types</h1>
        <p data-source-node="n58">An equipment type identifies the purpose of equipment in your warehouse. 
 When you define equipment types in the system, you identify the equipment's 
 physical maximum capacity. The system uses this information to determine 
 when an equipment type can be used to process a work unit.</p>

        <h4 data-source-node="n96">Procedures...</h4>
        <ol data-source-node="n97">
            <li class="li_3" value="1" data-source-node="n98">Use 
 the Equipment Type Field to provide a name to the equipment you 
 want to define.<br data-source-node="n99"> </li>
            <li class="li_3" value="2" data-source-node="n100">Use the Description Field to provide a text description for your equipment type.<br data-source-node="n101"> </li>
            <li class="li_3" value="3" data-source-node="n102">Use 
 the maximum fields to indicate the maximum capacity (with their 
 corresponding UM's) that this equipment type can handle.<br data-source-node="n103"> </li>
            <li class="li_3" value="4" data-source-node="n104">Press 
 OK. The system will save your record.</li>
        </ol>
