Work Creation Flow Diagram...

 

 

This process generates work instructions for work requests from various sources.

 

Step 1: The system organizes the appropriate work creation master records in priority order.

  1. The system determines which records it needs to retrieve, based on the process that requested work creation. The process determines why work creation was initiated. On each work creation record, the system checks the Process Field to determine if it applies.

    2.  

  2. The system organizes the appropriate work creation master records based on priority number.

     

    • After the system determines which records can be applied to the work requests, the system organizes them in priority order. The priority number is defined on the work creation master record. The lower the priority number, the sooner the record is used to process work requests.

       

Step 2: The system compares each work request to the first eligible work creation master record.

  1. Based on priority, the system selects the first creation master record that it will compare to the work requests.

     

  2. The system references the work criteria record associated with this work creation master. The work criteria record defines which work requests can be processed using the work creation master record.

     

    • If the request does meet the criteria defined on the work criteria record, the system will associate it with the work creation master record. This request will not be reviewed by the next work creation master: it is 'reserved'. The system will compare the remaining requests to this work creation master record.

       

    • If the request does not meet the criteria defined on the work criteria record, the system temporarily holds the request. It retrieves the next request and attempts to process it using this work creation master record. After the system has processed through all of the requests, it will compare the 'declined' request to the next work creation master record.

       

Step 3: The system organizes the requests based on the order by attributes on the work criteria record.

  1. The system checks the attributes defined on the Order By Tab on the Work Criteria Record. It organizes the requests based on the values defined on this tab.

  • For example, assume the tab contains the following value: Shipment ID, Ascending Order. The system will organize the requests in shipment ID order, with the lowest ID number first.

     

  • If multiple values are defined on the tab, the system will further organize the requests within the first attribute. For example, in the screen diagram below, each of the requests would be organized in Shipment ID order, ascending. So, all requests for Shipment ID 1 would be ordered before all requests for Shipment ID 2. Within each Shipment ID, the details are further organized in pick location order, ascending. So, requests for location 100-100-001 are ordered before requests for location 100-100-002. Finally, within each location, the requests are organized in item number order, ascending.

 

 

Note that this screen diagram is from the Order By Tab on the Work Criteria Window.

 

 

Step 4: The system assigns instruction numbers to each detail and generates work units.

  1. The system processes through the detail records in the order created during Step 3.

     

  2. Each request becomes a detail. Each detail is assigned a work instruction number. This is an internal number that identifies the detail to the system.

     

  3. The system determines which estimated work rate record it can apply to each instruction. It uses this record to calculate how long it will take an employee to process the instruction.

 

Step 5: The system creates work units.

  1. The system references the work creation master record to determine how to create the work unit. Note that when the work is replenishment work created out of the wave process, and the "Wave Replen Work Type" setting (on the Work System Values Window) is activated, the system will use this special replenishment work type instead of using the work type as defined on the work creation master.
     

  2. When the system reaches the work unit break, it creates a work unit. The work unit is assigned an instruction number. The work unit groups together all instructions that will be assigned to one employee.

     

  3. If the Auto Print Checkbox on the Work Creation Master Window is selected and this work unit was created for an outbound process, the system will print the pick list as soon as the work unit is created.

     

  4. For order picking, work units are often created at the order or shipment number level. For batch picking, work units are often created at the pick location level.

Non-RF Work Execution

The work execution process occurs when employees obtain the product required to fullfill customers' shipment requests. The work units processed during work execution were generated during work creation. Work that is not executed on an RF device is typically completed from pick lists. The procedures below provide a general method for executing Non-RF work; since system intervention is minimal, the actual procedures are based on your business practices.

 

 

Step 1: The system generates the pick lists.

  1. Pick lists are generated at the work unit level. To system references the work criteria record to determine which instructions are included in the pick list.

     

  2. The following values are defined on the pick list:

     

    • Work Unit Number

       

    • Team (if applicable)

       

    • From Zone

       

    • From Location

       

    • To Zone

       

    • To Location

       

    • Item # / Description

       

    • Quantity

       

    • Order Number

       

    • Order Line Number.

     

Step 2: A manager distributes the pick lists to the appropriate personnel.

  1. Employees will obtain product from the From Locations and deliver it to the To Locations. If applicable, they will use a time/date stamp to indicate when product was picked and putaway.

     

Step 3: An administrator confirms the work activity on the Work Insight Screen.

  1. After the employee has processed the work on the pick list, he/she will deliver the pick list to the data administrator responsible for entering work activity in the system. Note: The user and warehouse must have access to a work profile that supports the work type and work zones on the work instruction.

     

  2. The data administrator will use the Work Insight Screen to indicate what work activity occurred on the floor. He/she will complete the following activities:

     

    • Identify the person who processed the work unit.

       

    • Identify when the product was picked and putaway in the Start Time/Date and End Time/Date Fields (if a time/date stamp was used).

       

    • Identify the quantity picked.

       

    • If appropriate identify why a short pick or other irregular activity occur.

       

    • Confirm the work.

     

  3. Once the work is confirmed, the system will change its status to Ready for Packing.

     

    • If you have created additional status between In Picking and Ready for Packing, the unit will change to the next appropriate status.

RF Work Execution

The work execution process occurs when employees obtain the product required to fulfill customers' shipment requests. The work units processed during work execution were generated during work creation.

 

 

Step 1: The employee signs on to an RF device. The system determines which work profile to associate with the employee

How an employee can work is determined by the work profile record associated with his/her user sign on. When the employee signs on to an RF device (and chooses the Work function), the system will determine how he/she should process work. The system uses the following process to select the appropriate work profile:

  1. First, the system will reference the employee's user profile. If a work profile is defined as the "default work profile"on his/her user profile, the system will assign this profile to the user. The system will not continue to step B.

  2. However, if the employee's user profile does not have a work profile associated with it, the system will prompt with work profiles that are user and warehouse authorized.

 

Step 2: The system retrieves the user's existing work profile detail record(s)

  1. The system can only assign those work instructions that match a detail record on the user's assigned work profile. It looks for the following fit:

    - The work instruction's work type must match the work type on the work profile.

    - The work instruction's work zone must accept the equipment type defined on the work profile detail record.

Note that if none of the detail records match the work instructions, the system will display a message requiring the employee to obtain work from a supervisor.

 

 

Step 3: The system will determine the method of work initiation: the system or the user?

  • If the system should initiate work, the user will scan the nearest location barcode. The system will assign the work unit closest to this location. The employee will identify the work unit with an arbitrary barcode.

    System-Directed Work Unit Selection: If the from location (where the system assigned you a work unit) is eligible for system-directed work unit selection, then the system will display an additional initiation screen. This allows you to choose the work unit you wish to execute. All the work unit validations for this system-directed work unit selection screen are identical to the validations that the system performs when initiating work with the user-directed initiation screen (such as the work unit cannot be closed, cannot be active, etc).

  • If the user should initiate work, he/she will determine which work unit should be processed first. He/she will scan the work unit's barcode, usually from the pick list generated during work creation. Note that "Group user" work can also be initiated, which allows you to consolidate container picks. For more detailed information on executing group-user work, see the topic Processing RF Work (Group User section)

  • If starting receipt putaway work from RF for a receipt container and the To location on the work instruction is the receiving pre-locate location, then the system will relocate the receipt container.

  

Step 4: The system will assign the appropriate work unit to the employee

  1. Within the work unit, instructions are assigned based on the From Assign Method Field on the work profile detail record.

  2. Within the work unit, the system assigns work summaries, not work instructions, to the user.

 

Step 5: The system applies any special handling constraints to the work unit; system displays instruction/quantity to be picked

The system references the Work Special Handling Constraints Window to identify unique handling requirements for this work unit. A special handling constraints record determines the following:

  1. When additional handling constraints are required. These constraints can be set for any of the following characteristics:

    - Per Item / Company

    - Per Account / Company

    - Per User Profile / Work Zone / Work Type

  2. If constraints are required, the system will determine what type of constraint is used. Any combination of the following constraints can be used, including:

    - Employee must identify the pick location by scanning the location number .

    - Employee must verify the item quantity that he/she is processing.

    - A maximum quantity pickup set to minimize breakage or loss.

    - The ability to override the location, lot, or license plate data for specific work instructions.

  3. System then displays the work unit's first/next work instruction, or the quantity to be picked (after performing a partial pick action), in the Pick Confirmation Window.

 

 

Step 6: The user picks the product

Next, the user picks the product, and enters the appropriate data into the RF device.

  • If the user performs a complete pick, the system will process the pick.

  • If the user performs a short pick, the system will reject the quantity that was short picked, and decrement the short picked quantity from the On Hand quantity at the location.

  • If the user performs a partial pick, the system will delete the remaining quantity from the work instruction, and close it, if the "Close on Partial Pick" checkbox (in Work Special Handling Window) is selected. If not, the system would keep the instruction open so the remainder could be picked later. Note that the "partial pick and close" action is only available for RF replenishment and work order picks if it is defined to do so in the Work Special Handling Window. If you are partial picking into a tote or shipping container, the system will return you to the same pick again after a partial pick, displaying the remaining quantity that is yet to be picked. The system will repeat this action until the whole quantity is picked. This is helpful if you cannot fit a complete pick into one tote/container.

  • If the user performs an over pick, the system will increment the transaction quantity, and process the pick as a complete pick. Note that this action is only available for RF replenishment and work order picks if it is defined to do so in the Work Special Handling Window.

After the pick processing is completed:

  • The system will display the work unit's first/next putaway instruction.

    OR

  • The system will automatically putaway the work unit's item, if the Select After Putaway Checkbox was selected on the current user's work profile record. This would bypass having to manually putaway the item. Typically, this setting would be used when you are picking directly into shipping containers (but you can use it in any work scenario).

 

 

Step 7: The user performs putaway.

The user will putaway the item quantity at the appropriate location. Note that if your work profile is defined to putaway into shipping containers, and you are putting away to a put-to-store location or the shipping dock, you will need to provide the container ID that you are putting into. Also, if this is a new container, you will need to indicate the container type. After the user performs the putaway action on the item, the system will putaway the quantity in the specified location. If the user's work profile indicates that they should nest container(s) after putaway, the system will display a screen to perform this action. The system will also check to see if there is any more putaway to be completed for this work unit. If there is, the next instruction will be displayed. If not, the system will check to see if there is any more work for this work profile detail.
