
        
        <h1 data-source-node="n56"><a name="kanchor2002" data-source-node="n57"></a>Container Putaway List</h1>
        <p data-source-node="n58">A container putaway list identifies all receipt containers that have 
 been located by the system and are ready for putaway. This document tells 
 an employee what product to putaway, which location to take it to, and 
 how much product to take. This document only displays containers that 
 have been located. If you print this list from a parent container level, 
 it will only display those child containers that have been located. Any 
 unlocated containers associated with this parent record won't be displayed 
 on the document. Container putaway lists can be automatically generated 
 when a container is located. You can manually generate a container putaway 
 list for located product from the Receipt Workbench.</p>
