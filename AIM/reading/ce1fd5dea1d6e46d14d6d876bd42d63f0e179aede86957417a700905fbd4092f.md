
        
        <h1 data-source-node="n56">Addressing Miscellaneous Setup Prerequisites (Returns)</h1>
        <p data-source-node="n57">The following miscellaneous setup settings must be addressed before 
 using the returns processing:</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Receiving 
 Preferences Window</h4>
        <ul type="disc" class="ul_1" data-source-node="n61">
            <li data-source-node="n62">Putaway Groups: 
 In order to be able to use putaway groups when processing returns, 
 you first need to be assigned to a receiving preference that has the Execute 
 Group Putaway Checkbox selected. This indicates that, when locating the 
 return, you want it to be a part of a   putaway 
 group, as opposed to grouping it with the "normal" incoming 
 items.<br data-source-node="n63"> </li>
            <li data-source-node="n64">Disposition 
 Code: If you want users to assign a disposition code to a returned 
 item, make sure their receiving preference has the Disposition Code Required 
 Checkbox selected. These codes describe the condition of an item, as well 
 as assign a locating rule for the system to use during locating.<br data-source-node="n65"></li>
        </ul>
        <p data-source-node="n66"> </p>
        <h4 data-source-node="n67">Locating 
 Rule Window</h4>
        <ul data-source-node="n68">
            <li data-source-node="n69">Locating Rule for Returns: You should create a locating rule that you want the system to use when locating your 
 returned item quantities. You can assign this locating rule at the receipt level, when checking in the item quantity, or as part of a disposition code.</li>
        </ul>
        <p data-source-node="n70"> </p>
        <h4 data-source-node="n71">Receipt 
 ID Type</h4>
        <ul data-source-node="n72">
            <li data-source-node="n73">On the Receipt ID Type Window, the Returns Field indicates  if you want receipts generated with this receipt 
 type to be labeled by the system as "returns."  The system uses this value when generating web statistics to differentiate receipts and returns.</li>
        </ul>
        <p data-source-node="n74"> </p>
        <h4 data-source-node="n75">Receiving 
 System Values</h4>
        <ul data-source-node="n76">
            <li data-source-node="n77">Review the two values that deal with the receipt type and receipt ID type of receipts that are created from shipments.</li>
        </ul>
