
        
        <h1 data-source-node="n56"><a name="kanchor812" data-source-node="n57"></a>Verify Item Unit of Measure Checkbox</h1>
        <h5 data-source-node="n58">On the Receiving Preferences Window...</h5>
        <p data-source-node="n59"> This setting determines if the system 
 will require you to, during the receiving process, verify that a received container holds the 
 amount of units as defined on the item's unit of measure record. </p>
        <p class="p_1" data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"> </p>
        <h5 data-source-node="n62">On the Vendor Window...</h5>
        <p data-source-node="n63"> This setting determines if the system 
 will require you to, during the receiving process (processing a receipt from a specific vendor), verify that a received container holds the 
 amount of units as defined on the item's unit of measure record.  This checkbox can be defined on either the parent record or on  individual child records. Note that if you activate this setting on the  parent record, create child records, and then unselect this setting on the  parent record, it will remain selected on all child records (you  will need to manually remove it from each child record). </p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">Notes...</h5>
        <p data-source-node="n67">- This setting also applies when creating pre-check in receipt containers.</p>
