
        
        <h1 data-source-node="n56"><a name="kanchor1443" data-source-node="n57"></a>Internal Shipment Number Field</h1>
        <p data-source-node="n58">The internal number assigned to a shipment 
 in the system. This value identifies the shipment within the system. The shipment number is unique. If you split 
 one shipment into two, the system will generate a new shipment number 
 to accommodate the split. This is a numeric field.</p>
