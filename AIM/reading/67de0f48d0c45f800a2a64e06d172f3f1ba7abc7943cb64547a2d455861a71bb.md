
        
        <h1 data-source-node="n56"><a name="kanchor1679" data-source-node="n57"></a>Create Shipments Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates how the system will process orders entered on 
 the Order Entry Window. Note that the value 
 of this field is linked to the Create Orders Checkbox.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61">If ONLY the Create Shipments Checkbox 
 is checked, the order entry module will output shipments.</p>
                <p data-source-node="n62"> </p>
            </li>
            <li data-source-node="n63">If BOTH the Create 
 Shipments and the Create Orders Checkbox are checked, the order 
 entry module will output shipments AND orders.</li>
        </ul>
        <p data-source-node="n64">The created shipment's status will depend on the "Add From Order 
 Entry" value on the Outbound Status Action Window.</p>
