Defining No Ship Days

"No ship days" indicate when a carrier cannot transport product. You can define no ship days that prohibit shipping on a weekend day (Saturday or Sunday). You can also define unique no ship days which occur only once during the calendar year, such as holidays. Later, you will associate shipping calendar records with the appropriate carriers. When the system calculates the days to deliver for a shipment, it references the carrier's shipping calendar record. If shipment is to be shipped on a no ship date, it will be manifested on the next valid shipping date. If the carrier has a no ship day between today and the shipment's delivery date, the system will adjust the delivery date to account for the no ship date. For example, suppose your warehouse does not ship product on July 4th because you are closed for the holiday, and today is July 3rd. Shipment AAAA requires 5 shipping days to reach its destination. When the system calculated the ship date for Shipment AAAA it would assume that 6 shipping days are required (not 5 days), since it cannot ship on July 4th. Therefore, the calculated shipping date would be July 8th, not July 7th.

 

NOTE: If a carrier is not tied to a shipping calendar, then the system will assume that this carrier does not ship on Saturday or Sunday.

Using the Weekends Tab

You can use this tab to identify no ship weekend days. If you identify either Saturday or Sunday as a no ship day, the system will assume that carriers associated with this calendar never ship on the excluded day(s). This tab includes the following checkboxes: the Exclude All Saturdays Checkbox and the Exclude All Sundays Checkbox. Both of these checkboxes are preselected for you. If you leave them both checked, any carrier associated with this calendar will not ship product on either Saturday or Sunday. When the system calculates the days to deliver for the carrier (associated with this calendar), it factors in these no ship days.

 

 

Using the Holidays Tab

You can use the Holidays Tab to identify specific days that a carrier does not ship product.

  • Use the Date Field to select the appropriate date from this calendar. The system will display it in the records list.

     

  • Use the Description Field to identify the holiday.

     

  • Select the Apply to All Calendars Checkbox if you want to associate this no ship date with all shipping calendars. Generally, you will only select this value if your warehouse is closed on this date.

     

  • Press Apply. The system will activate the data grid.

     

  • Select the Add Button. The system will display the no ship date in the data grid. Create additional records if necessary.
