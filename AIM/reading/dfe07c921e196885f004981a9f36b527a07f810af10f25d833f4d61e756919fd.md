
        
        <h1 data-source-node="n56"><a name="kanchor460" data-source-node="n57"></a>Machine Name Field</h1>
        <h5 data-source-node="n58">On 
 the Document Routing Window...</h5>
        <p data-source-node="n59">This field refers to the machine requesting the printing (i.e. the workstation). It does not expect the domain name suffix.</p>
        <p data-source-node="n60">Note: The default printers override printers assigned to workstations. Read <a href="80b3ffb7968806f7f9c954f5e2af42c649492c456ff19cd59e91cecca1bd3f51.html" data-source-node="n61">Defining User Profiles</a></p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">For example,. suppose you have a printer located at a specific 
 packing station, from which you want to generate Container Contents Labels. 
 If you define a Machine Name, no matter the user that is signed onto this 
 packing station client machine, the system will print the label at the 
 printer present at that station. This is helpful because you do not have 
 to set up this document by user, and force them to always use the same 
 packing station.</p>
