
        
        <h1 data-source-node="n56"><a name="kanchor1471" data-source-node="n57"></a>Description Field</h1>
        <p data-source-node="n58">The description associated with a record or item. A short description 
 or the name of the record. This field 
 is provided for informational purposes only. It is typically not used 
 for system processing; however, the system may display this value on a 
 window.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">In 
 RF Setup... </h5>
        <p class="p_1" data-source-node="n62">In the RF Miscellaneous Options Window, the 
 value in this field refers to a resource file key value, as opposed to 
 an actual text description (as described above). When the RF runs, the 
 Select Functions Screen will use the value of the corresponding resource 
 key as text for this record. However, if the system does 
 not find a matching key, it will use the text as typed in the Description 
 Field.  </p>
