Confirming Cycle Counts Using Blind Cycle Counting (RF)

Similar to performing a standard cycle count, on a "blind" count, the user will count the individual cycle count(s) present for the location. However, the system does not present any information on screen *except* for the location ID. Therefore, the user is forced to count each item that is physically present in the location without the system guiding them in what should be counted. This type of count is useful if you want to make sure your users are actually making physical counts, and not instead simply confirming whatever the system tells them is there (without actually making physical counts).

 

NOTE: You can only perform blind cycle counting using an RF device.

Performing a Basic Blind Cycle Count...

The following procedures outline how you would use the RF device to execute a blind cycle count for a single item location. These steps assume that you have your work special handling record set to perform blind cycle counting.

  1. Log onto RF work execution, and select the appropriate work profile.

  2. Enter a cycle count work unit (or, the system will display the cycle count work unit if using system-directed work).

  3. The system will display the RF Blind Cycle Count screen, with only the location ID visible to the user.

  4. Enter the item ID for the first item residing in this location.

  5. Select a company (if appropriate).

  6. Enter a lot ID if the item is lot controlled. Note that the Lot field only appears if you enter a lot controlled item. Also, the system will display the Lot Entry screen after confirming if the lot is new.

  7. Enter a license plate ID if the location is license plate tracked.

  8. Enter the quantity and unit of measure of the item.

  9. When you are finished entering item data, press the Confirm button to submit this item count. The system will process the item count data,update the cycle count request/work instruction, and adjust the inventory based on the user's tolerance preferences.

  10. The system will next display the RF Blind Cycle Count Screen, with all of the onscreen fields again blank (except the location ID). You can now begin count this location's next item (repeat the above steps).

  11. When you are finished counting all the item(s) in the location, press the Done button. This will indicate to the system that you do not want to count any more item quantities for this location. At this point, any remaining open counts for this location will be treated as a zero quantity count, the system will close the associated work/cycle count request, and update the inventory based on the user's tolerance preferences.

  12. The system will then display the next location to count on the RF Blind Cycle Count screen. Or, if no more pending location count requests exist, the system will display the work initiation screen.

 

 

 

Performing a Blind Cycle Count on an Empty Location...

If you want to count a location as empty, you will need to enter a zero as the quantity (leaving the other fields blank), and press the Confirm OR Done button. The system then will display a message to check to be sure that you want to count the location as empty. If you press the OK button, then the system will count the location as empty. If you press the Cancel button,

the system will not confirm the count, and instead will allow you to enter item data like normal. Note that the system will not allow you to enter a zero quantity if an item has already been counted at the location for this cycle count work unit.

 

 

 

 

Functional Notes...

While blind cycle counting and standard cycle counting essentially perform the same function, there are several differences between the two modes, primarily centered around the limited data displayed on-screen for blind cycle counting. These functionality differences are discussed below:

 

  • The system enforces the typical screen data entry validations for empty fields/invalid data.

  • Blind cycle counting does not honor the item/quantity/license plate/lot verification settings on the work special handling record.

  • Blind cycle counting does honor the location verification settings on the work special handling record.

  • If you press the Cancel button to stop counting a location, the following will happen:

    - The system will not update any remaining open work/cycle count requests.

    - All confirmed counts will remain processed and will not be rolled back.

    - The system will ignore any information on the current screen.

    - Another user can pick up the remaining open work at a later time.

    - If you cancel out of existing cycle count (that has no open work or requests remaining), the system will close the work unit.

  • Consider the following about the Skip button functionality:

    - You can use the Skip button to cycle through the locations on a work unit.

    - Once you start counting a location, however, the Skip button will not be available again until you complete counting the existing location.

    - If a single location exists or remains on cycle count, then the Skip button will not be available.

  • If you have the "Verify Bad Count on RF" setting selected on your cycle count preferences:

    - This setting works similar to normal cycle count functionality, as it requires you to re-enter count for the "bad count" item. You will need to enter the same count two times in a row for the system to accept the count value.

  • Consider the following when counting an item quantity that has inventory attributes:

    - You cannot view inventory attributes when performing a blind cycle count.

    - The system will group multiple attributes, and you will need to enter the aggregate total quantity (across attributes) per unique item instance.

    - If you count the correct summed quantity, the system moves to next item. However, if you provide a count for the summed quantity that is different that the system count, the system will revert back to the standard cycle count screen mode. The system will then revert back to blind cycle count mode once user has completed all counts for the item.

  • Consider the following if you are trying to use the "Update Cycle Count Work to Include All Items" setting on your cycle count master:

    - The blind cycle count process will always try to update the cycle count request to include all items regardless of the setting.

    - If an item exists on another cycle count request that is open and not active, the system will move it from the original cycle count request to the blind count that is currently being worked on.

    - If the item is on a cycle count request that is active, the system does not transfer it over, and the user will get message when they count this item that it is already on another cycle count request.

  • When displaying interleaved (cycle count requests that are displayed after performing a pick confirmation) activity-based cycle counts, the system will load the request into the standard cycle count screen mode and not the blind cycle count mode. An activity count that is not interleaved and is processed at a later time can be processed using the blind count mode.

  • If you press the Done button when some (but not all) of the data fields have values in them, then the system will disregard the current count and not process it.
