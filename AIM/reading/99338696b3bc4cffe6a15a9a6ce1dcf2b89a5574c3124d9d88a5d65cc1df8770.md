
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor696" data-source-node="n58"></a>Planned Shipment Filters</h1>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">This configuration filters planned shipments based on user-defined criteria (e.g., customer, carrier, order type). These filters are used in the Planned Shipment Insight to display relevant shipment data.</p>
        <ul data-source-node="n61">
            <li data-source-node="n62">
                <p data-source-node="n63">Filters can reference either shipment headers or shipment line values.</p>
            </li>
            <li data-source-node="n64">
                <p data-source-node="n65">If any shipment line matches a filter rule, the entire shipment is included in the view.</p>
            </li>
            <li data-source-node="n66">
                <p data-source-node="n67">Use the Planned Shipment Filters dropdown in the Filter Pane to apply predefined views.</p>
            </li>
        </ul>
        <p data-source-node="n68">Using the Filter Builder: You can use this tab to identify which shipments will be displayed under the Planned Shipment Insight Screen's Basic Criteria.</p>
