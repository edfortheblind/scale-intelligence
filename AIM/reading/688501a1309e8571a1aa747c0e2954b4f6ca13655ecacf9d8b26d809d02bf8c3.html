Putaway Location Group

A Putaway Location Group enables received items to be grouped together and put away as a unit. The configuration settings define how these groups function. When the first putaway group is created—either using a location range or a locating zone—all subsequent groups must follow the same method (either all range-based or all zone-based).

 

During the locating process, the system attempts to assign items to a location that belongs to an existing Putaway Group. It associates the receipt container with this group. If no group exists for the target location, the system will either:

  • Create a new Putaway Group automatically using a system-generated ID, or

  • Prompt the user to assign a Putaway Group ID manually.

Once assigned, the system updates the Parent License Plate of the received inventory with the Putaway Group ID.

When executing putaway work, tasks are generated at the group level—meaning all items in the group are handled together.

 

You can use putaway groups to manage returned items by placing them in a designated receiving dock area. From there, they can either be returned to their original inventory locations or moved to a special returns or repair zone.

 

Create a Putaway Group Location

 

  • Warehouse: Select the warehouse where the putaway group will reside.

  • Location Range: Specify the range of locations included in the group.

  • Locating Zone: Identify the zone of locations that define the putaway group.

  • Group Assignment Method: Choose whether Group IDs should be manually assigned by the user or automatically generated by the system.

  • Maximum Units: Set the maximum number of items allowed in a group. Once reached, the system closes the group and creates a new one using the same settings.

 

Toggle Buttons

  • One Per User: Enable this to ensure each user processing returns is assigned a separate group, preventing overlap.

  • Verify Group ID: When enabled, the system requires users to manually enter an existing Putaway Group ID during check-in.
