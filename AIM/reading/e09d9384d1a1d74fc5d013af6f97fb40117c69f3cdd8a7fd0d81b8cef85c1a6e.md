
        
        <h1 data-source-node="n56"><a name="kanchor2039" data-source-node="n57"></a>Creating Location Types</h1>
        <p data-source-node="n58">If a group of locations share the same dimensions, you can create a 
 location type to identify those dimensions. Later, you can associate this 
 type with the appropriate locations instead of defining each location's 
 dimensions separately. This minimizes setup time and decreases the likelihood 
 of user error inputting the dimensions. During locating, the system will 
 reference a location's type to gauge how many item units can be stored 
 in a certain locations. Note that if there is no item location 
 capacity record associated with a location, the system will determine 
 the item quantity amount that can fit in the location by comparing the 
 dimensions defined on the location type record to the dimensions defined 
 on the item UM record.</p>

        <h4 data-source-node="n94">Procedures...<br data-source-node="n95"></h4>
        <h5 style="font-weight: normal" data-source-node="n96">Access the Location Type Window. Create a new record and provide a name 
 in the Location Type Field.</h5>
        <ol data-source-node="n97">
            <li type="1" class="li_13" value="1" data-source-node="n98">Define the dimensions 
 associated with this location type. Use the Length, Width and Height 
 Fields to define the location type's dimensions. The system references 
 this information during locating and replenishment. To ensure that the 
 correct amount of product is located to locations associated with this 
 location type, provide exact measurements in these fields.<br data-source-node="n99"> </li>
            <li type="1" class="li_13" value="2" data-source-node="n100">Use the Maximum 
 Weight Field to indicate the weight value that the system will 
 not exceed during the locating process.<br data-source-node="n101"> </li>
            <li type="1" class="li_13" value="3" data-source-node="n102">Press OK. 
 The system will save the record.</li>
        </ol>
