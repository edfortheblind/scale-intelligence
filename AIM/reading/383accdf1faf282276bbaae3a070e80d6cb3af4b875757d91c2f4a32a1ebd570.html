Activating Inventory Tracking

Inventory management allows you to control and adjust product at the location level. The system will update its inventory history of the product based on these inventory management activities. Therefore, the system must perform inventory tracking on the item if you want to adjust it. If the system does not track the item, it will have no inventory count for the product and no inventory records for the item/location. You will need to activate inventory tracking in one of two places, depending on the item you are trying to track. If the item you are trying to track is defined in the system, you will have to activate a setting in the Item Window. If the item you are trying to track is not defined in the system, you will have to activate a setting in the Inventory Control Values Window.

 

 

 

Procedures: An Item Defined in the System

Access the Item Window. Open an item record.

  • To activate inventory tracking for an item defined in the system, select the Inventory Tracking Checkbox. The system will now allow Inventory adjustments on this item. NOTE: This setting takes precedence over the system value (when configured to "No" in the procedure below).

     

 

Procedures: An Item NOT Defined in the System

Access the Inventory Control Values Window. Select the Inventory Tracking record.

  • To activate inventory tracking for items not defined in the system, select the value "Yes" in the Inventory Tracking Field. The system will now allow adjustments for any item that is not defined in the system. NOTE: If you select the value "No," then the system will not allow adjustments to any item not already defined in the system.
