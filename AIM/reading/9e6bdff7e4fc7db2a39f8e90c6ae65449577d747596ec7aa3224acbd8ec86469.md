
        
        <h1 data-source-node="n56"><a name="kanchor204" data-source-node="n57"></a>And/Or Buttons</h1>
        <p class="p_1" data-source-node="n58">The And/Or buttons appear only on filter criteria 
 windows. You will use them to define multiple criteria lines for a filter 
 record. To create a critiera line with multiple stipulations, select the 
 AND Button. To create a criteria line with multiple options, select the 
 OR Button.</p>
        <p class="p_1" data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60"><span class="span_3" data-source-node="n61">NOTE:</span> 
 All ANDs are processed before ORs. For example, the record X and Y or 
 C and D is processed as follows: (X and Y) or (C and D).</p>
