
        
        <h1 data-source-node="n56"><a name="kanchor1756" data-source-node="n57"></a>Next Dock Area Field</h1>
        <p data-source-node="n58">This field indicates the dock location you want the system to assign to a container for the "next leg" of its journey, i.e. creating its next move. In other words, you can use this field to pre-assign a dock location. The dock assignment wave step, prior to performing the selection strategy from the dock management flow detail, looks to see if there is a next dock area defined on the container's current dock area. If so, system uses the next dock area and does not use the selection strategy logic (it would go straight to the assignment strategy logic). If not, then the system uses the selection strategy logic as normal.</p>
