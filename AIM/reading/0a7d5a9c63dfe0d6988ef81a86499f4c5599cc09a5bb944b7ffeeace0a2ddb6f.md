
        
        <h1 data-source-node="n56"><a name="kanchor1880" data-source-node="n57"></a>Value Field</h1>
        <p style="font-style: normal;font-weight: normal" data-source-node="n58">This field represents the monetary value of an entity.</p>
        <p style="font-style: normal;font-weight: normal" data-source-node="n59"> </p>
        <p style="font-style: normal;font-weight: normal" data-source-node="n60"> </p>
        <h5 data-source-node="n61">On the Filter Data Configuration Windows / Query Configurations  / 
 Custom Search Criteria Window...
</h5>
        <p data-source-node="n62">This field is included on all the filter data 
 criteria windows. The Value Field, Attribute Field, 
 and Operand Field work together to create the criteria that the system 
 uses to select records. For example, if the wave criteria record identifies 
 the attribute as 'Customer, the Operand as '=', and the value as 'Wal-Mart', 
 then the criteria for selecting records is that the customer must be Wal-Mart.</p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64"> </p>
        <h5 data-source-node="n65">Using Serial Number Templates / Lot Templates...</h5>
        <p data-source-node="n66">This field indicates the characters you want 
 as a constant on every serial 
 number/lot that uses this template. For example, you could enter a dash 
 "-" to separate two segments of characters. Note that you must 
 select  constant in the Type Field 
 in order to enter a value into this field.</p>
        <p data-source-node="n67"> </p>
        <p data-source-node="n68"> </p>
        <h5 data-source-node="n69">On the Wave Screen...</h5>
        <p data-source-node="n70">This field indicates the total value of the 
 shipment(s) associated with a certain customer that are currently in the 
 pool. The system calculates this value using the item(s) "Net Value."</p>
        <p data-source-node="n71"> </p>
        <p data-source-node="n72"> </p>
        <h5 data-source-node="n73">On the Shipping Container Screen...</h5>
        <p data-source-node="n74">This field indicates 
 the total value of the item(s) in this container. </p>
        <p style="font-weight: bold;color: #000080" data-source-node="n75"> </p>
        <p style="font-weight: bold;color: #000080" data-source-node="n76"> </p>
        <h5 data-source-node="n77">On the Shipment 
 Screen...</h5>
        <p data-source-node="n78">This field indicates 
 the total value of the line(s) on this shipment. The system calculates 
 this value using the item(s) "Net Value."</p>
        <p data-source-node="n79"> </p>
        <p data-source-node="n80"> </p>
        <h5 data-source-node="n81">On the Carrier EDI Reference Window...</h5>
        <p data-source-node="n82">This field indicates  what actual 
 data that you want SCALE to send to the transportation system.</p>
        <p data-source-node="n83"> </p>
