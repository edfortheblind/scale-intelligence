
        
        <h1 data-source-node="n56"><a name="kanchor64" data-source-node="n57"></a>Classification Field</h1>
        <p data-source-node="n58">This field indicates to the system that a document type is a  Document (i.e. a piece of paper) or a Label. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Also, the user can at times override the document routing settings and manually specify a document/label printer to use during a particular business process (such as printing out of the wave).  When the paperwork is printed, this Classification setting is used to determine which printer the system will use to print.</p>
