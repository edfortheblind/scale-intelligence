Process Field

Audit Log Records...

This field indicates the process that the logic was going through at the time the exception occurred.

 

 

History...

Identifies what system process for which the process history record was generated.

 

 

Interface...

Identifies what interface activity you want to perform. This field appears on the Interface Process Window.

 

Download

 

If you select download, the interface will retrieve data from the ERP and transmit it to the system.

Upload

 

If you select upload, the interface will transmit data from the system to the ERP.

 

 

Interface Process Details...

Identifies the specific XSL style sheet that the system will execute when a certain process step is run.

 

 

Quality History Reason Codes...

Indicates during which type of system action (receiving, packing, etc.) that a particular reason code can be chosen by the user.

 

 

Work Creation...

This field indicates how work was initiated into the system. See Work Creation Overview for more information about how work is generated in the system.

 

Cycle Count

This work is initiated to process the cycle count requests.

Dock Management

This work is initiated to facilitate the movement of containers to and around the shipping dock.

Inventory Adjustments

This work is created when an adjustment is done using full screen Inventory Management when the adjustment type has "Create Work" specified, or when adjustments are interfaced into the system.

Inventory Transfers

This work is created when an inventory transfer is done using full screen Inventory Management when the adjustment type has "Create Work" specified, or when inventory transfers are interfaced into the system.

Shipment Allocation

This work is generated to accommodate allocation requests for product. During allocation, the system selects allocation locations. Work creation generates the picking instructions required to fulfill the allocation requests.

 

Shipping Container

 

This process creates work based on shipment details, shipping containers, or allocation requests.

Receipt

 

This work is generated to create putaway instructions for located containers.

Replenishment

This work is generated to accommodate replenishment requests for product. During replenishment, the system identifies the replenishment locations. Work creation generates the picking and putaway instructions required to fulfill the replenishment requests.

Work Order Component

 

This work is generated for allocated components for work orders.

Work Order Finished Item

This work is generated for putaway instructions for work order finished items.
