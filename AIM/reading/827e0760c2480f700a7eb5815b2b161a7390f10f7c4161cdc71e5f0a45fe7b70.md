        <h4 data-source-node="n320"><a name="Searching" data-source-node="n321"></a>Searching/Viewing Replenishment Request Records...</h4>
        <p data-source-node="n322">You can use the Replenishment Insight Screen to search for and view replenishment request records in your warehouse. </p>
        <ol data-source-node="n323">
            <li value="1" data-source-node="n324">Open the Replenishment Insight Screen.<br data-source-node="n325"><br data-source-node="n326"></li>
            <li value="2" data-source-node="n327">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n328"><br data-source-node="n329"></li>
            <li value="3" data-source-node="n330">Press the Search Button. The system will display  the resulting records in the List Pane. <br data-source-node="n331"><br data-source-node="n332"></li>

        <h4 data-source-node="n408"><a name="Screen" data-source-node="n409"></a>Screen Actions</h4>
        <p data-source-node="n410">The following actions are accessible from the List Pane and/or Detail Pane:</p>
        <p data-source-node="n411"> </p>
        <h5 data-source-node="n412">View/Edit</h5>
        <p data-source-node="n413">The Edit action is shown instead of the View action when you got the Edit security. </p>
        <p data-source-node="n414"> </p>
        <p data-source-node="n415"> </p>
        <h5 data-source-node="n416">Create Work Immediately</h5>
        <p data-source-node="n417">This action allows you to create a work for replenishment requests that are waiting in queue from replenishment insight. The action is enabled for the replenishment requests which has work created marked as 'No'. Selecting the replenishment request(s) for which work is not created and invoking the action will send the request to work creation process.</p>
        <p data-source-node="n418"> </p>
        <p data-source-node="n419"> </p>
        <h5 data-source-node="n420">Mark for Work Creation</h5>
        <p data-source-node="n421">This action allows you to mark replenishment requests for work creation. The action is enabled for the replenishment requests which has 'Work Created' and 'Marked for work creation' marked as 'No'. Selecting the replenishment request(s) which are not marked for work creation and invoking the action will label the request for work creation.</p>
