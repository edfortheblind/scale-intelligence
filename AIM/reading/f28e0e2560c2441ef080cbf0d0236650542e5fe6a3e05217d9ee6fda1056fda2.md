
        
        <h1 data-source-node="n56"><a name="kanchor1207" data-source-node="n57"></a>GS1 Scan Required Checkbox</h1>
        <p data-source-node="n58">Use the GS1 Scan Required Checkbox to indicate that the user assigned 
 to a receiving preference will be using RF check in to process GS1 barcode 
 labels. Also for this preference record, you will need to choose an application 
 identifier template, which determines how the system will parse the GS1 
 barcode data.  </p>
