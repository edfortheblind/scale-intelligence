
        
        <h1 data-source-node="n56"><a name="kanchor40" data-source-node="n57"></a>Hourly Rate Field</h1>
        <p data-source-node="n58">This field is included in the 
 Estimated Work Rates Window. It works with the Measurement Per Hour Field 
 or the Unit of Measure Field to define the ideal processing output for 
 a particular work type/work zone combination. When work is processed for 
 this work type/work zone, the system will track the activity and compare 
 it against this record.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">For example, if the Hourly Rate 
 Field contains the value 5 and the Measurement Per Hour Field contains 
 the value Work Units Per Hour, the estimated processing output for the 
 work type/work zone combination would be 5 work units per hour.</p>
