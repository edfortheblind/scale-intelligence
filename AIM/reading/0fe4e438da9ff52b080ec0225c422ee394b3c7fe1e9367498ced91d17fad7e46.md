        <h4 data-source-node="n72"><a name="1orderentry" data-source-node="n73"></a>Issue: Encountering "Operation is not valid due to the current state of the object." error during order entry process...</h4>
        <p data-source-node="n74">Microsoft has released some patches that may cause Trading Partner Management to encounter a "Operation is not valid due to the current state of the object" error. This error may occur when adding Ship To's during the order entry process in TPM. To verify the error the the ThrowIfMaxHttpCollectionKeysExceeded() exception will be visible in the error the stack trace.  </p>
        <p data-source-node="n75"> </p>

        <h5 data-source-node="n105">Resolutions...</h5>
        <ol data-source-node="n106">
            <li value="1" data-source-node="n107">Narrow your search results. The amount of data returned exceeds the limit of data allowed by ASP.NET.<br data-source-node="n108"><br data-source-node="n109"></li>
            <li value="2" data-source-node="n110">Add the aspnet:MaxHttpCollectionKeys value to the apsettings node of the web.config file in the TPM folder of the SCALE installation directory.  The value field can be any value greater than 1001. Depending on the amount of results returned this value will need to be increased to accomodate the data returned. An IISRESET should be performed after making the changes to the web.config file to allow the changes to be loaded into ASP.NET.<br data-source-node="n111"><br data-source-node="n112">&lt;add key="aspnet:MaxHttpCollectionKeys" value="2000" /&gt;<br data-source-node="n113"></li>
        </ol>
