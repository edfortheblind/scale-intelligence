
        
        <h1 data-source-node="n56">Identifying that Progistics is Installed</h1>
        <p data-source-node="n57">You will need to identify to SCALE that Progistics is properly installed on the Rating 
 System Values Window.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>

        <ol data-source-node="n62">
            <li type="1" class="li_3" value="1" data-source-node="n63">Open the Configurations 
 Explorer.<br data-source-node="n64"> </li>
            <li type="1" class="li_3" value="2" data-source-node="n65">Access the Rating System Values Window, and select the <i data-source-node="n66">Progistics Installed?</i> record.<br data-source-node="n67"> </li>
            <li type="1" class="li_3" value="3" data-source-node="n68">Select "Yes" if you have installed the Progistics rating application.<br data-source-node="n69"><br data-source-node="n70"></li>
            <li type="1" class="li_3" value="4" data-source-node="n71">Press OK. The system will save your changes.</li>
        </ol>
