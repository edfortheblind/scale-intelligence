
        
        <h1 data-source-node="n56">Check In Information Entry Window</h1>
        <p data-source-node="n57">This window identifies the ID associated with a checked in 
 license plate. This value is either assigned by the system or by the user 
 on this window, based on the user's receiving preference record. In addition, 
 you can use this window to provide the following special item information, 
 when appropriate: lot ID, serial number and catch weight. This window 
 can only be accessed from the Receipt Workbench.</p>
