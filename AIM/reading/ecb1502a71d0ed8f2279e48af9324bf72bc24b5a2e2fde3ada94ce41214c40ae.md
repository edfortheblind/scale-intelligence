
        
        <h1 data-source-node="n56"><a name="kanchor943" data-source-node="n57"></a>Creating Packing Criteria Records</h1>
        <p data-source-node="n58">The system uses a packing criteria record determines which items the system will allow 
 to be packed into the same shipping container. The system references this record during the wave's container creation 
 process and also during the manual packing process. Using these records are helpful if you want to keep certain items from being 
 packed with others that are going to a different destination. For example, 
 if you are shipping to a distribution center that forwards items to a 
 company's stores, users would not be allowed to pack items that are being 
 shipped to different stores into the same container.</p>

        <h4 data-source-node="n99">Procedures...</h4>
        <p data-source-node="n100">Access the Packing Criteria Window. Create a new record, and provide 
 it a name and description. The Detail Records Tab lists all of the packing 
 criteria detail records in sequence order. Double-click a record to open 
 or create a new record. The system will open the Packing Criteria Detail 
 Window:</p>
        <p data-source-node="n101"> </p>
        <h5 data-source-node="n102">Using 
 the Header Fields</h5>
        <ol class="ol_1" data-source-node="n103">
            <li value="1" data-source-node="n104">Use the Packing 
 Criteria Field to identify the name of the packing criteria record 
 that this detail record is associated with.<br data-source-node="n105"> </li>
            <li value="2" data-source-node="n106">Use the Sequence 
 Field to indicate the order in which the system will process through 
 the packing criteria records.</li>
        </ol>
        <p data-source-node="n107"> </p>
        <h5 data-source-node="n108">Using 
 the General Tab</h5>
        <ol class="ol_1" data-source-node="n109">
            <li value="1" data-source-node="n110">Use the Field 
 Name Field to indicate the field value that a detail line must 
 have for the system to pack it into a particular container. Note that 
 only items whose shipment line values match    ALL 
 of the fields (as defined on the packing criteria record) will 
 be packed together. <br data-source-node="n111"><br data-source-node="n112">	For example, suppose that "Item Size" is a field defined 
 on the packing criteria record. The detail line item being packed, however, 
 has a different "Item Size" value than an item already in the 
 container. The system, then, cannot pack this item into the container, 
 because the "Item Size" values do not match up. The system will 
 then need to look for another container to pack this item into. <br data-source-node="n113"> </li>
            <li class="li_4" value="2" data-source-node="n114">Use the Required Check box 
 to indicate if the system will display 
 a packing criteria-related warning message, or an error, during full-screen 
 packing:<br data-source-node="n115"><br data-source-node="n116">	- If 
 this check box is selected, then 
 users will not be allowed to pack items with differing values together. 
 <br data-source-node="n117"><br data-source-node="n118">	- If this check box 
 is not selected, when the user 
 attempts to pack these differing items, the system will display a warning 
 message asking for confirmation to make sure they want to pack these items. 
 Note that the container creation process and RF pick/pack functionality 
 do not use the Required Field. All fields must match 
 for the items to be packed together, regardless of the Required Checkbox's 
 value.<br data-source-node="n119"><br data-source-node="n120"></li>
            <li value="3" data-source-node="n121">Press OK. The system will save the detail record.</li>
        </ol>
