        <h5 data-source-node="n68">General Warehouse Information </h5>
        <p data-source-node="n69"> </p>
        <p data-source-node="n70"><b data-source-node="n71">Warehouse</b>: This field identifies the warehouse linked to a user, data entity (such as shipment, receipt, item, etc.), or any process, procedure, or activity associated with the warehouse.</p>
        <p data-source-node="n72"> </p>
        <p data-source-node="n73"><b data-source-node="n74">Warehouse Name</b>: The name of the warehouse.</p>
        <p data-source-node="n75"> </p>
        <p data-source-node="n76"><b data-source-node="n77">Time Zone</b>: Choose the appropriate time zone for the warehouse. The system will use this time zone when defaulting date-only fields to determine the correct date.</p>
        <p data-source-node="n78"> </p>
        <p data-source-node="n79"><b data-source-node="n80">UCC/EAN Number</b>:</p>
        <p data-source-node="n81"> </p>
        <p data-source-node="n82">This field holds the UCC/EAN identifier assigned to the warehouse or shipping entity (such as a company).</p>
        <p data-source-node="n83">If the system generates container IDs during packing, the UCC/EAN number will occupy positions 4-10 of the ID.</p>
        <p data-source-node="n84">For codes longer than 7 characters, three flexible positions are available.</p>
        <p data-source-node="n85"> </p>
        <p data-source-node="n86">If a vendor-compliant label is produced for a container linked to this number, and it includes a UCC-128 barcode, the UCC/EAN number will appear in positions 4-10 of the barcode.</p>
        <p data-source-node="n87"> </p>
        <h5 data-source-node="n88">Warehouse Address </h5>
        <p data-source-node="n89"> </p>
        <p data-source-node="n90">This section defines the address associated with the warehouse. The following fields can be used to provide the complete address:</p>
        <ul data-source-node="n91">
            <li data-source-node="n92">
                <p data-source-node="n93">City</p>
            </li>
            <li data-source-node="n94">
                <p data-source-node="n95">Country</p>
            </li>
            <li data-source-node="n96">
                <p data-source-node="n97">Postal Code</p>
            </li>
            <li data-source-node="n98">
                <p data-source-node="n99">State</p>
            </li>
        </ul>
        <p data-source-node="n100">Address Fields 1-3: These fields can be used to enter the name, street, and suite address. At least Address Field 1 must contain a value.</p>
        <p data-source-node="n101">These address fields are also used for the Return Address and Freight Bill Address</p>
        <p data-source-node="n102"> </p>
        <p data-source-node="n103">The address fields are the same for the <b data-source-node="n104">Warehouse Address</b>, <b data-source-node="n105">Return Address</b>, and <b data-source-node="n106">Freight Bill-To Address</b> sections.</p>
        <p data-source-node="n107"> </p>

        <p data-source-node="n119">The fields at Additional Return Values, Additional Freight Bill to Values are same as above.</p>

        <p data-source-node="n140"><b data-source-node="n141">SQL Server Reporting Services</b>
        </p>
        <p data-source-node="n142"> </p>
        <p data-source-node="n143"><b data-source-node="n144">Rendered Document PDF File Directory</b>: This field specifies where SQL Server Reporting Services should save rendered PDF files. Note that these files are not automatically deleted after being printed by the default PDF reader application</p>
        <p data-source-node="n145">.</p>
        <p data-source-node="n146">This field is part of the Warehouse and Document Type Configurations. The document type path is appended to the warehouse path to form the full path for the PDF directory. For example, if the warehouse path is \\Localhost\ILS\Reporting\SSRS and the document type path is Allocation Pick List, the full path will be \\Localhost\ILS\Reporting\SSRS\Allocation Pick List.</p>
        <p data-source-node="n147"> </p>
        <p data-source-node="n148"><b data-source-node="n149">Note</b>: If the document type path is left blank, the document will be printed using the warehouse path. If the warehouse path is blank, the document type path must be a valid path</p>
