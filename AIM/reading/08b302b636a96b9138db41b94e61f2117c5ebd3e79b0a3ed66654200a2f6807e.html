Discussion: Labor Planning

Labor planning allows you to forecast how much time and money is required to process a wave's shipment and work details. Labor planning can assess how long it will take to process shipment lines in a wave. In addition, it can assess how long it will take to process work created in a wave. When a wave is run that has work associated with the work type, the system will look at the labor group to determine how many units of this work can be processed (such as pick and put) in a minute. The labor management configurations that you define will determine how the system calculates your labor plan. The Labor Groups and Work Groups work together to determine how your labor plan is calculated.

 

 

System Decisions...

  1. The system calculates the time required at the work instruction detail level. It sums the work details to calculate the time estimate.

  2. The system includes all wave generated work in the plan, provided that its corresponding work type was included in the labor group record. This means that a plan can be generated for the following: shipment allocation work, shipment line work, shipping container work, replenishment work, work order creation work.

  3. Once work is created for one work creation request in a wave, the system no longer plans against shipment lines.

  4. If work creation cannot create a work unit for a particular shipment line, nothing is included in the planning estimates.

  5. If all work fails, so that not one work unit is created in a wave, the labor plan is based on the shipment level again.

  6. If a labor plan is called after work is created, the system only selects the labor group records where planning is at the work level. However, if the wave's work types are not defined on a labor group, the system will base the plan off the shipment.
