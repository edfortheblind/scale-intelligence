
        
        <h1 data-source-node="n56">Country Rating Symbol Field</h1>
        <p data-source-node="n57">This field indicates the appropriate two-letter identifier for a country. You would need to enter a value in this field if you want a different country identifier during rating.</p>
        <ul data-source-node="n58">
            <li style="font-weight: normal" data-source-node="n59">  If there is a value in this field, then external rating systems will use this value as the country code when manifesting.<br data-source-node="n60"><br data-source-node="n61"></li>
            <li style="font-weight: normal" data-source-node="n62">If this field is blank, then <a name="kanchor1459" data-source-node="n63"></a>external rating systems will use the Country Window's identifier as the country code when manifesting.</li>
        </ul>
