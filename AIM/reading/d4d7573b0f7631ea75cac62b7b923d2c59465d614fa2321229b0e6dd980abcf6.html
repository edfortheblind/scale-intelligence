Create Orders From Shipments Checkbox

This field indicates if the system will generate an order when you create a new shipment (when entering a Single Order in the system order entry system).

  • If this checkbox is checked, the system will generate orders (as well as shipments) when you create a new shipment from the Shipment /Shipment Line Screens and the Shipment Insight. The system creates these orders in an "In Process" condition, and are viewable from Trading Partner Management.

    NOTE: If this setting is selected, if you manually copy a shipment (and the original shipment has a blank ERP Order Number on the shipment), the system will insert the Shipment ID value into the ERP Order Number field. In addition, the system will also copy this value to the shipment line(s) if the ERP Order Number is blank.

  • If this checkbox is not checked, these windows will simply generate shipments.
