Message ID Field

Text Messages...

An identifier associated with a message defined on the Text Message Window. The message is displayed on an RF device for a particular item/account/company combination. This allows you to provide specific instructions at the item/account/company level. This is especially helpful when an account requires unique handling for a particular item.

 

 

DIF Incoming/Outgoing Message Insight Sscreens...

This field represents a numeric value used to identify a DIF message record.
