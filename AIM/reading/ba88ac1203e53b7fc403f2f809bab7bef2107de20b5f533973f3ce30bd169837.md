
        
        <h1 data-source-node="n56"><a name="kanchor301" data-source-node="n57"></a>Defining Wave Picking Groups</h1>
        <p data-source-node="n58">A wave picking group record determines how many loose or full containers 
 can be included in a group and the locations and/or work zones where the 
 pick group can be used. It represents a physical tool used to consolidate 
 the picking process. Common picking groups in a warehouse include carts, 
 cherry pickers and forklifts. During a wave, the system can run the group 
 picking step to assign containers created during container creation to 
 the appropriate picking group.</p>

        <h4 data-source-node="n102">Procedures...</h4>

        <h5 data-source-node="n104">Wave Picking Group Window:</h5>
        <ol data-source-node="n105">
            <li value="1" data-source-node="n106">
                <p data-source-node="n107">Provide a name for this wave picking location group and a description.</p>
                <p data-source-node="n108"> </p>
            </li>
            <li value="2" data-source-node="n109">
                <p data-source-node="n110">Use the Number of Loose Containers 
 Field to define how many open containers can fit on the pick group. 
 For example, if the pick group represents a 4 x 4 cart, how many open 
 containers can a person place on the cart and easily place items in them? 
 Since you can only place a single layer of loose containers on a cart, 
 they can generally hold fewer containers than a full container pick group.</p>
                <p data-source-node="n111"> </p>
                <p data-source-node="n112">Hint: 
 If you have container types of varying sizes, we recommend that you determine 
 this initial number based on the container type considered your medium 
 sized container. Later, you can modify the number of containers allowed 
 if too many or too few containers are being assigned to a group.</p>
                <p data-source-node="n113"> </p>
            </li>
            <li value="3" data-source-node="n114">
                <p data-source-node="n115">Use the Number of Full Containers 
 Field to define how many full containers can fit in the pick group. 
 Full cases are shipped in the storage container; they are not placed into 
 additional shipping containers and other items are not packed in them. 
 Generally, you can fit more full containers on a pick group since they 
 can be stacked on top of each other. See the hint above for additional 
 information on selecting a container size.</p>
                <p data-source-node="n116"> </p>
            </li>
            <li value="4" data-source-node="n117">Select the Apply Button. Select the New Action. 
 The system will display the Wave Picking Group Detail Window.</li>
        </ol>
        <p data-source-node="n118"> </p>
        <h5 data-source-node="n119">Wave Picking Group Detail Window:</h5>
        <ol data-source-node="n120">
            <li value="1" data-source-node="n121">
                <p data-source-node="n122">The Wave Picking Group Field will 
 default this record's name.</p>
                <p data-source-node="n123"> </p>
            </li>
            <li value="2" data-source-node="n124">
                <p data-source-node="n125">The Sequence Field will 
 contain the value 10. You can change the sequence number, but you cannot 
 use the same sequence number for multiple detail records. The sequence 
 number determines when this record will be used. The lower the sequence 
 number, the sooner it's processed. </p>
                <p data-source-node="n126"> </p>
            </li>
            <li value="3" data-source-node="n127">
                <p data-source-node="n128">Use the Wave Pick Location Group Field 
 to associate a pick location group with this sequence. A pick   location group 
 identifies the allocation locations/work zones where this pick group can 
 operate.</p>
                <p data-source-node="n129"> </p>
            </li>
            <li value="4" data-source-node="n130">To define additional sequence values, select the 
 New Action. The Sequence Field will contain the value 20.</li>
        </ol>
