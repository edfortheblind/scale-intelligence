
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">User Profile Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59">The User profiles are created for all associates using the application  to be identified by the system. The system references the user profile to determine how an associate will perform tasks (such as packing, shipping, receiving, etc).</p>

        <h4 data-source-node="n66">Configure User Profile</h4>
        <p data-source-node="n67"> </p>
        <h5 data-source-node="n68">1. User Profile Information </h5>
        <ul data-source-node="n69">
            <li data-source-node="n70">
                <p data-source-node="n71">The Username and Email Address must be unique for each user.</p>
            </li>
            <li data-source-node="n72">
                <p data-source-node="n73">The Default Warehouse represents the user's primary working location.</p>
                <ul data-source-node="n74">
                    <li data-source-node="n75">
                        <p data-source-node="n76">When the user logs into the application, this warehouse is automatically selected.</p>
                    </li>
                </ul>
            </li>
            <li data-source-node="n77">
                <p data-source-node="n78">Assign a Supervisor to the user during profile creation.</p>
            </li>
        </ul>
        <p data-source-node="n79"> </p>
        <h5 data-source-node="n80">2. Security Information</h5>
        <p data-source-node="n81"> Configure the user security group and its Vocollect password. </p>
        <p data-source-node="n82"> </p>
        <h5 data-source-node="n83">3. Payroll Information</h5>
        <p data-source-node="n84">The payroll ID, wage rate, and hiring date are defined for the user. </p>
        <p data-source-node="n85"> </p>
        <h5 data-source-node="n86">4. Receiving Preference</h5>
        <p data-source-node="n87">The default receiving preference will be what is selected when opening the Receipt Workbench or Warehouse Mobile Receiving. The user can be authorized to one to many receiving preferences. The receiving preferences found under the Receiving Preferences Field will only be those that have been authorized for the user. Read <a href="841e4f396e3164fcb48092ce4b8e0f19221105d9d3f2ec1325ef8088ec378645.html" data-source-node="n88">Receiving Preference</a>.</p>
        <h5 data-source-node="n89"> </h5>
        <h5 data-source-node="n90">4. Packing Preference</h5>
        <p data-source-node="n91">A packing preference record allows you to manage how a user or group of users will pack shipments. These actions are primarily done in the Packing Screen or the Close Container Screen. Read <a href="2a80413d51ed3c94ca2be82243e928edd5889e6dfe997b8c8da3043580405aab.html" data-source-node="n92">Packing Preference</a>.</p>
        <p data-source-node="n93"> </p>
        <h5 data-source-node="n94">5. Shipping Preference</h5>
        <p data-source-node="n95">A shipping preference record allows you to manage how a user or group of users will ship confirm orders. The default shipping preference record should accommodate the majority of employees. Create specific preference records for employees with unique processing needs. Read <a href="b92f55232c56b2a948eda3cf6cab621044ed9ec3958a22556c0e43415f1744b0.html" data-source-node="n96">Shipping Preference</a></p>
        <p data-source-node="n97"> </p>
        <h5 data-source-node="n98">6. Cycle Count Preference</h5>
        <p data-source-node="n99">This preference record will determine whether activity-driven cycle count requests should be executed immediately or created as pending requests. Read <a href="abe7d95dd7321512c90ca7f15571fe8905422c187190edcf9516ba1de5d7dc17.html" data-source-node="n100">Cycle Count Preference</a></p>
        <p data-source-node="n101"> </p>
        <h5 data-source-node="n102">7. Work Order Preferences</h5>
        <p data-source-node="n103">This preference record will determine how a user or group of users will process work orders. The default preference record should accommodate the majority of associates. Read <a href="1577f2ce5fe09cde6a8664f90a0d78e37cc6639981b5f6c74900e4376172d1f2.html" data-source-node="n104">Work Order Preference</a>.</p>
        <p data-source-node="n105"> </p>
        <h5 data-source-node="n106">8. Printer </h5>
        <p data-source-node="n107">The default printer on the user profile overrides the document routing printer configured for the document type. Selecting a printer when printing selected documents will override the default printer. It will also override printers assigned to the workstations.</p>
        <p data-source-node="n108"> </p>
        <h5 data-source-node="n109">9. System Values </h5>
        <p data-source-node="n110">Configure the Desktop template, SCALE Theme, RF Style sheet and Excel export directory for the user.</p>
        <p data-source-node="n111"> </p>
        <h5 data-source-node="n112">10. Default Work Profile </h5>
        <p data-source-node="n113">Configure the work profile that the user will use during work processing.</p>
