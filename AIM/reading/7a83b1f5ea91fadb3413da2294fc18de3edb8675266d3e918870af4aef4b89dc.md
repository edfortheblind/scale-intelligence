
        
        <h1 data-source-node="n56"><a name="kanchor1618" data-source-node="n57"></a>Comment Type Field</h1>
        <p data-source-node="n58">The comment type identifies a message that you want to appear on paperwork 
 associated with a document type. You will define each comment type in both the ERP and the system. In 
 the ERP, the comment type is linked to the message. In the system, it 
 is associated with the document type. When that document type is requested 
 for a specific shipment, shipment line, or work instruction, the system 
 will print the message on any paperwork generated (for that document type). You can also manually associate comment types 
 with shipment headers in the system. In this case, you must manually identify 
 the message on this shipment.</p>
