
        
        <h1 data-source-node="n56"><a name="kanchor712" data-source-node="n57"></a>Defining Viewer Colors</h1>
        <p data-source-node="n58">You can define the colors of certain 
 sets of records that display after a search query on the results grid of a SCALE viewer window. For example, suppose you want all the data for a specific carrier to be shaded in the color blue. You would then need to create a record in the Viewer Color Editor that defines what color the system should color record(s) associated with a specific carrier.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Important: Read the <a href="a2be91555d338145450001160e7b087ad9a5e585369ec12e988059d1d9bf481a.html" data-source-node="n61">Notes on Viewer Setup</a> before adding colors.</p>

        <h4 data-source-node="n94">Procedures...</h4>
        <p data-source-node="n95">Open your custom viewer record on the Viewers Window. Press the Customize 
 Button, and select the Colors Tab on the Customize Viewer Window. Open 
 an existing color record, or right-click the list and select New Item. 
 The system will display the Viewer Color Editor Window.</p>
        <ol class="ol_1" data-source-node="n96">
            <li value="1" data-source-node="n97">Use the Color 
 Field to choose a color that you want to assign to certain records 
 that will display on the results screen. The system will use the rules 
 defined in this window to determine what records it shades using this 
 color. If you do not assign any rules to this color record, the system 
 will shade all results row(s) using this color. </li>
        </ol>
        <p data-source-node="n98"> </p>
        <h5 data-source-node="n99">Establishing 
 Rules for Color Shading...</h5>
        <ol class="ol_1" data-source-node="n100">
            <li value="1" data-source-node="n101">You will use 
 the Field Name, Operand, and Value fields to define rules. Note 
 that you will only be able to choose fields that are a part of the database 
 table that the viewer is associated with.<br data-source-node="n102"><br data-source-node="n103">For example, suppose you have a viewer that displays shipment 
 records. You could assign a separate color the system could use to shade 
 different carrier records. So, when the system displays results from a 
 query, shipments with different carriers are shaded different colors. 
 <br data-source-node="n104"> </li>
            <li value="2" data-source-node="n105">Or 
 Check box: See the <a href="7efb2692896288886d6900f2a3f3f3ce8d6df6580dc8364bd8ba789132ee6e43.html" data-source-node="n106">field topic</a> for a description.<br data-source-node="n107"> </li>
            <li value="3" data-source-node="n108">You can then 
 create more rules, or press OK to save your color record. </li>
        </ol>
