
        
        <h1 data-source-node="n56">Warehouse Mobile - Indirect Labor</h1>
        <p data-source-node="n57">Users can now log indirect labor directly from the Warehouse Mobile application. The indirect activity remains open until it is completed, ensuring accurate time tracking. If a direct activity is initiated while an indirect activity is still active, the system automatically ends the indirect activity to maintain proper labor recording.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">The Indirect labor is supported for the following areas:</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">•	Receiving Check-In</p>
        <p data-source-node="n62">•	Container Close</p>
        <p data-source-node="n63">•	Picking</p>
        <p data-source-node="n64">•	Putaway</p>
        <p data-source-node="n65">•	Cycle Count</p>
        <p class="p_5" data-source-node="n66"> </p>
        <p class="p_5" data-source-node="n67">
            <h4 data-source-node="n68">Indirect Labor :</h4>
        </p>
        <p data-source-node="n69"> </p>
        <p data-source-node="n70">Perform the following steps to log indirect labor activity.</p>
        <p data-source-node="n71"> </p>
        <p data-source-node="n72">1.	Tap Indirect Labor from Warehouse mobile main menu to view the Start Indirect Labor Activity screen.</p>
        <p data-source-node="n73">2.	Select the Activity Type and Tap Go.</p>
        <p data-source-node="n74">3.	In the End Indirect Labor Activity screen, the User Name, Activity type and Start time is displayed</p>
        <p data-source-node="n75">4.	Tap Go and a successful message is displayed</p>
        <p data-source-node="n76"> </p>
        <p data-source-node="n77">
            <h4 data-source-node="n78">Direct Activity Overlap: </h4>
        </p>
        <ul data-source-node="n79">
            <li data-source-node="n80">Start an indirect labor activity.</li>
            <li data-source-node="n81">The system records the start time and keeps the activity active.</li>
            <li data-source-node="n82">Start a direct activity before ending the indirect activity.</li>
            <li data-source-node="n83">The system automatically ends the indirect activity.</li>
            <li data-source-node="n84">The indirect activity end time is set to the direct activity start time.</li>
            <li data-source-node="n85">The direct activity continues as the active labor activity.</li>
        </ul>
        <p data-source-node="n86"> </p>
        <p data-source-node="n87">
            <h5 data-source-node="n88">Notes</h5>
        </p>
        <p data-source-node="n89"> </p>
        <p data-source-node="n90">•	When an indirect activity starts, the system records the Start Time and leaves the End Time blank.</p>
        <p data-source-node="n91">•	The indirect activity remains active until it is completed.</p>
        <p data-source-node="n92">•	When the activity is finished and Go is tapped again, the system records the End Time.</p>
