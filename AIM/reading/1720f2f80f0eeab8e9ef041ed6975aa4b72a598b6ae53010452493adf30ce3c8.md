
        
        <h1 data-source-node="n56"><a name="kanchor1489" data-source-node="n57"></a>Verify Item Dimensions Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates if the system will 
 check item dimensions when checking in items. If any item does not have 
 dimension(s), the user can choose whether the check in should continue 
 or not. If this checkbox is selected, the system will display a message 
 warning the user that all the dimensions are not defined. The user then 
 will be able to continue or cancel the check in, knowing that all the 
 dimensions are not defined. If it is not selected, the system will not 
 check to see if an item has dimensions when performing a check in.</p>
