
        
        <h1 data-source-node="n56"><a name="kanchor1893" data-source-node="n57"></a>Web Header Graphic Center Field</h1>
        <p data-source-node="n58">This field indicates the path of the graphic that will appear at the 
 top-center of the Trading Partner Management Main Menu. The path should 
 be in this format: <i data-source-node="n59">\\YourServer\Directory1\Directory2\graphic.gif</i></p>
        <ul type="disc" class="ul_1" data-source-node="n60">
            <li class="li_7" data-source-node="n61">If 
 you are associated with NO companies, the 
 system will load this value from the Web System Values Window (for BOTH 
 internal and external web users).<br data-source-node="n62">	 </li>
            <li class="li_7" data-source-node="n63">If 
 you are associated with ONE company, the 
 system will load this value from the Company Window (for BOTH internal 
 and external web users).<br data-source-node="n64">	 </li>
            <li class="li_7" data-source-node="n65">If 
 you are associated with MORE THAN ONE company, the 
 system will load this value from the Company Window (for internal web 
 users). External web users cannot be associated with multiple companies.</li>
        </ul>
