Assigning/Unassigning A Work Unit To A Team/User

You can assign a work unit that is either open or in process. This is especially helpful if you want to assign or unassign a work unit to a user/team. Note that you cannot edit a closed unit. The system will update the work unit to reflect the newly-assigned user. If the unit's instruction(s) are to be processed from pick lists (non-RF), you should reprint the pick lists and labels to ensure accuracy.

 

 

Procedures...

  1. Open the Work Insight screen.

     

  2. Access a work unit or multiple work units that you want to assign/unassign.

     

  3. Select either the Assign Team/User or Unassign action.

    • The system will display the Assign Team/User Window for the Assign action.

      1. Enter a work team or a username as applicable and press Save.

      2. If the user is not authorized for any work profile(s), you will be notified with an error message. Similarly, you will receive confirmation message if the user or team assignment is successful.

    • The system will prompt yes/no confirmation for the Unassign action. If you click Yes, you will receive confirmation for successful unassignment.
