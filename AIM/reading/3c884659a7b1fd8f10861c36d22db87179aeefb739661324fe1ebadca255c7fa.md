
        
        <h1 data-source-node="n56"><a name="kanchor1373" data-source-node="n57"></a>Creating a Shipper Code</h1>
        <p data-source-node="n58">A shipper code identifies the entity who will ship product. Progistics/FSMS 
 requires this value and it will generate a container manifest for each 
 shipper. If you do not support multi-company processing, set up 
 one shipper per warehouse postal code. If two or more warehouses share 
 a postal code, they can also share a shipper code. If you do support multi-company 
 processing, determine which companies require their own manifests. Create 
 a unique shipper code for each company that wants its own manifest. Link 
 all other companies to a warehouse level shipper code; their shipments 
 will appear on the warehouse's manifest.</p>

        <h4 data-source-node="n100">Using the General Tab...</h4>
        <ol data-source-node="n101">
            <li value="1" data-source-node="n102">
                <p data-source-node="n103">Open 
 the Configurations Explorer.</p>
                <p data-source-node="n104"> </p>
            </li>
            <li value="2" data-source-node="n105">
                <p data-source-node="n106">Use the Shipper Code Field 
 to identify this shipper to Progistics/FSMS. It must begin with an alpha 
 character, but it can contain both alpha and numeric characters. It cannot 
 contain symbols or spaces. All characters must be upper-case: MANHATTAN, 
 etc. Also, provide a description in the Description Field.<br data-source-node="n107"><br data-source-node="n108"></p>
            </li>
            <li value="3" data-source-node="n109">
                <p data-source-node="n110">Use the Contact Name Field to 
 identify the contact for this shipper code. This represents the person who can 
 be contacted if shipping concerns arise for the warehouse/company associated 
 with this shipper code.</p>
                <p data-source-node="n111"> </p>
            </li>
            <li value="4" data-source-node="n112">Use the Phone 
 Number Field to provide this contact's phone number.<br data-source-node="n113"> </li>
            <li value="5" data-source-node="n114">Use the Employer 
 ID/Tax Number Field to provide the employer ID number/tax number 
 for this particular shipper code contact.<br data-source-node="n115"> </li>
            <li value="6" data-source-node="n116">Use the Haz Mat 
 Phone Number Field to provide the phone number of the person who needs to be called 
 if there is an emergency dealing with hazardous materials. </li>
        </ol>
        <p class="p_8" data-source-node="n117"> </p>
        <h4 data-source-node="n118">Using the FedEx Tab...</h4>
        <ol class="ol_1" data-source-node="n119">
            <li class="li_7" value="1" data-source-node="n120">Using 
 the Meter Number Field to identify a unique shipping location for 
 a FedEx account. For example, if a company has warehouses in three different 
 locations (i.e. three shippers), then FedEx would provide them with three 
 different meter numbers.<br data-source-node="n121"> </li>
            <li class="li_7" value="2" data-source-node="n122">Using 
 the Sign Release Auth Number Field to indicate the signature release 
 authorization number that is on file with FedEx. This value releases the 
 FedEx courier from requiring a signature upon package delivery.</li>
        </ol>
