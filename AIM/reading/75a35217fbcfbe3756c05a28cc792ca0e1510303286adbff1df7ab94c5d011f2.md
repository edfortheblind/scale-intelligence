
        
        <h1 data-source-node="n56"><a name="kanchor914" data-source-node="n57"></a>Wage Rate Field</h1>
        <p data-source-node="n58">This field indicates the wage rate associated with this user. This is 
 an optional field used for reference purposes. Note that if you do not have security to view this wage rate value, then the system will mask this value with asterisks, and not allow you to edit it. The system also uses this field to calculate 
 the cost of the work done. It determines the cost of the task by taking 
 the user's wage rate times the amount of time (in hours) that the user 
 took to accomplish the task. </p>
