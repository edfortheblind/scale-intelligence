
        
        <h1 data-source-node="n56"><a name="Reviewing" data-source-node="n57"></a><a name="kanchor857" data-source-node="n58"></a>Reviewing Status Actions (Inbound &amp; Outbound)</h1>
        <p data-source-node="n59">Status actions determine how a receipt or shipment is managed when a 
 unique circumstance occurs, such as a shipment is added from the Shipment 
 Insight screen. You can review/change these on either the Inbound (receipts) 
 or Outbound (shipments) Status Action Window.</p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Notes</h5>
        <ul data-source-node="n62">
            <li data-source-node="n63">If you select the outbound 
 status    Delete Rejected for a 
 status action, the system will delete record(s) that meet this status. 
 For example, if you select it for the    Rejected 
 Shipments status action, the system will delete the rejected shipment's 
 quantity completely from the system.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66">When the outbound status action for reject shipments is "Delete Shipments," and BOM action is "Create WO For Rejected Shipment," then shipments are treated like the shipments are treated in the "In Pool" action.<br data-source-node="n67"><br data-source-node="n68"></li>
            <li data-source-node="n69">WARNING:   Two outbound status actions support a status 
 value called Complete 
 Rejection to Pool. For this status, 
 the system, during partial rejections of a shipment, will reject the quantity 
 (similar to what is done in the Delete 
 Rejected outbound status action status). 
 Once the entire quantity on a shipment has been rejected, then the system 
 sends the shipment back to the pool, with all of its original quantities 
 restored. Note that this status can be used only by the Reject 
 Shipment and Short 
 Pick outbound status actions.</li>
        </ul>

        <h4 data-source-node="n98">Procedures...</h4>
        <p data-source-node="n99"> </p>
        <p data-source-node="n100">Access the inbound or outbound status action window. The record list 
 displays all of the default status actions. You can also create new ones. 
 </p>
        <ol data-source-node="n101">
            <li value="1" data-source-node="n102">Open the appropriate 
 record. If appropriate, change the description associated with 
 this record.<br data-source-node="n103"> </li>
            <li value="2" data-source-node="n104">
                <p data-source-node="n105">Use the System Status Field to 
 review or change the status assigned to the receipt or shipment when the 
 event identified occurs.</p>
                <p data-source-node="n106"> </p>
            </li>
            <li value="3" data-source-node="n107">Press OK. 
 The system will save your changes.</li>
        </ol>
