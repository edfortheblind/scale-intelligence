Researching History Data

Anytime something is impacted by either a system or user operation, the system writes a history record identifying what happened. For example, when a user picks an item from a location, the system generates a transaction history record. This record identifies the user who picked the item, the item and quantity picked, the location that it was removed from, the time/date that the transaction occurred, and other pertinent information.

 

You can view system and user activity on several history insight screens: Transaction, Process, Quality, and Receipt Quality.

History Insight Screen Fields...

The search fields displayed on a history insight screen will depend on which type of history you are searching for. The following fields are especially important in history searches. Use the help's index to access information on other criteria fields.

 

 

History Type

 

Important Fields

 

Transaction

Transaction Type: Indicates the system transaction used on a particular piece of inventory.

 

Process

Action:Indicates the actual work done in a process, such as the starting of a build wave, or the cancelling of a wave.

 

Identifier 1-4:Each Identifier Field indicates part of the "history message field," which the system generates with each process. Each field's value will depend on the type of process you are researching.

 

Message:Indicates the message ID provides a descriptive explanation of what happened during a process or action. The messages do not just identify problems: they also identify any system action.

 

Process: Indicates an action or decision that the system has performed.

 

Quality

Reason Code: Identifies why an employee did not complete an outbound action as anticipated, such as a pick (i.e. short picking a work instruction).

 

Receipt Quality

Vendor: Identifies the entity that delivers product to your warehouse.

 

Reason Code: Identifies why an employee did not complete an inbound action as anticipated, such as checking in less than the original total quantity for the receipt line.
