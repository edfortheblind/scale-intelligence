Creating Consolidation Locations

You can use this window to create consolidation locations. This type of location can consist of an area and one or several position(s), and is not inventory-tracked. A consolidation location typically would represent either an actual packing station or an area on the floor near a packing station. When a detail/container from a shipment is assigned to a certain consolidation location, then the system will assign all of the shipment's detail(s)/container(s) to this consolidation location.

Procedures: Creating Locations...

 

Using the Header Fields

Open the Consolidation Location Window, and create a new record.

  1. Use the Warehouse Field to indicate where the new location will reside.
     
  2. Use the Location Area Field to indicate in which area you want to create your new location.

  3. Use the Position Range Field to create a single position or a range of positions. Note that you need to have at least one position for every location you create.

    • If you want to create a RANGE of positions, enter the first position in the range in first field, and the last position in the range in the second field:

  1. Use the Multi Shipment Check box to indicate that you can have more than one shipment residing in a particular consolidation location.
