
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">QC Assignment Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59">This record determines how to assign QC to shipping containers in the wave. The system also checks QC when the work unit starts, based on the picker (only for containers in the wave)</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">Users can set QC assignment for the wave and/or work unit start.</p>
            </li>
            <li data-source-node="n63">
                <p data-source-node="n64">Specify indicate how many shipping container(s) you want the system to apply QC to; for instance, 1 out of every 3 shipping containers that are evaluated by this assignment record.</p>
            </li>
        </ul>

        <h4 data-source-node="n71">Configure QC Assignment Records</h4>
        <p data-source-node="n72"> </p>
        <h5 data-source-node="n73">1. QC Information </h5>
        <p data-source-node="n74">The QC information of QC Name, Assignment Reason, Priority, Apply to 1 of x containers and Current container count.</p>
        <p data-source-node="n75"> </p>
        <ul data-source-node="n76">
            <li data-source-node="n77">
                <p data-source-node="n78">Assignment Reason - This is description of the assignment method you are defining with this record. This field's value is displayed on both the QC Workbench and the Shipping Container Window's QC tab.</p>
            </li>
        </ul>
        <ul data-source-node="n79">
            <li data-source-node="n80">
                <p data-source-node="n81">Priority - This indicates to the system in what order the system should process through the QC assignment records. The record with the lowest priority (that matches the appropriate criteria) will be used by the system to assign QC to the shipment's container.</p>
            </li>
        </ul>
        <ul data-source-node="n82">
            <li data-source-node="n83">
                <p data-source-node="n84">Apply to 1 of x containers - indicate to the system how many container(s) using this assignment record will be eligible for QC assignment.</p>
                <ul data-source-node="n85">
                    <li data-source-node="n86">
                        <p data-source-node="n87">For example</p>
                    </li>
                    <li data-source-node="n88">
                        <p data-source-node="n89">1 of 1 containers indicates that the system will assign QC to all shipping containers that meet the assignment filter criteria.</p>
                    </li>
                    <li data-source-node="n90">
                        <p data-source-node="n91">1 of 10 containers indicates that the system will assign QC to one out of every ten shipping containers that meet the assignment filter criteria.</p>
                    </li>
                </ul>
            </li>
        </ul>
        <p data-source-node="n92">Note: That 1 of 0 and NULL are invalid values for this field.</p>
        <ul data-source-node="n93">
            <li data-source-node="n94">
                <p data-source-node="n95">Current Container Count - the current count of containers that have matched this QC assignment criteria. The system will increment this count value up by one every time QC evaluation occurs and a matching container is found. Note that this field is never editable by the user.</p>
                <ul data-source-node="n96">
                    <li data-source-node="n97">
                        <p data-source-node="n98">For example:</p>
                    </li>
                    <li data-source-node="n99">
                        <p data-source-node="n100">For the first container, the system will increment current container count to 1. No QC will be assigned.</p>
                    </li>
                    <li data-source-node="n101">
                        <p data-source-node="n102">For the second container, the system will increment the current container count to 2. No QC will be assigned.</p>
                    </li>
                    <li data-source-node="n103">
                        <p data-source-node="n104">For the third container, the system will increment the current container count to 3. QC is assigned to that container, since it is the third container that used this record, which matches the 1 of 3 container application criteria.</p>
                    </li>
                    <li data-source-node="n105">
                        <p data-source-node="n106">When a fourth container is evaluated using this record, the current container count is incremented to 4, and the pattern continues as described above</p>
                    </li>
                </ul>
            </li>
        </ul>
        <h5 data-source-node="n107">2. QC Assignment Criteria</h5>
        <p data-source-node="n108">System identifies the rules that will determine to which containers the system assigns QC. Also, users can create new QC assignment criteria information</p>
        <p data-source-node="n109"> </p>
        <h5 data-source-node="n110">3. QC Evaluation Method.</h5>
        <p data-source-node="n111"> </p>
        <p data-source-node="n112">Determine when the system will evaluate and assign outbound QC to shipping containers. You will have to choose at least one of these options (you can also choose both).</p>
        <p data-source-node="n113"> </p>
        <ul data-source-node="n114">
            <li data-source-node="n115">
                <p data-source-node="n116">Wave - The system will evaluate and assign QC to containers created in the wave, if the QC Assignment wave step is in your wave flow, and the QC assignment criteria is met.</p>
            </li>
        </ul>
        <ul data-source-node="n117">
            <li data-source-node="n118">
                <p data-source-node="n119">Start Work - The system will evaluate and assign QC to containers at the time of work unit start, if the QC assignment criteria is met.</p>
            </li>
        </ul>
        <ul data-source-node="n120">
            <li data-source-node="n121">
                <p data-source-node="n122">Manual - The system will assign QC when a user manually marks a container for QC using the Mark for QC action on the Shipment Insight screen or RF Shipping Container QC screen. Note that only one QC assignment record can be created that uses the "Manual" method of assignment.</p>
            </li>
        </ul>
