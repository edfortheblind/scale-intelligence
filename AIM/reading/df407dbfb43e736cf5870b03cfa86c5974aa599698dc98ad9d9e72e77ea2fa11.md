
        
        <h1 data-source-node="n56"><a name="kanchor817" data-source-node="n57"></a>Conversion Quantity Field</h1>
        <p data-source-node="n58">This field identifies the number 
 of units associated with a UM (unit of measure), in comparison to the 
 smallest UM for the item/item class. For example, if the smallest UM for 
 item number 11AA is 1 each and a case of this item contains 50 eaches, 
 the conversion quantity for one case is 50. If 50 cases fit on 1 pallet, 
 the pallet conversion quantity is 2500.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The 
 system uses this value to calculate how many UM containers to select during 
 allocation 
 and replenishment. For example, 
 if a shipment contains 50 units of 11AA, the system could convert this 
 quantity and allocate one case of product.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">For receiving, 
 the conversion quantities are displayed on the Verify Item Unit of Measure 
 Window. Each Conversion Qty. Field identifies how many single units are 
 in a particular UM. On this window, you can change the conversion quantity 
 value if the amount that you receive is different than the amount displayed. 
 For example, if the conversion quantity for a case is 50 (eaches), but 
 you receive a case containing 40 eaches, you could change the conversion 
 quantity to 40. This conversion change applies to a specific receipt line only; the system does not override the original value. </p>
        <p data-source-node="n63"> </p>
        <p class="p_1" data-source-node="n64">Conversion 
 values can be defined for both items and item classes. If a conversion 
 quantity record exists for both an item and its associated class, the 
 system will reference the item's conversion quantity record.</p>
