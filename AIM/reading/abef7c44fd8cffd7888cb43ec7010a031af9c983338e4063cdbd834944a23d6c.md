
        
        <h1 data-source-node="n56"><a name="kanchor208" data-source-node="n57"></a>Receipt Detail Number Field</h1>
        <p data-source-node="n58">This value identifies a receipt line record. It is used internally 
 by the system to track the contents of a receipt line as it is checked 
 in. It is also displayed on all receipt containers containing product 
 for the checked in receipt line. This is a system assigned number.</p>
