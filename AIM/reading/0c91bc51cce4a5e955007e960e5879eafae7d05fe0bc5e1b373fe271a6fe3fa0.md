
        
        <h1 data-source-node="n56"><a name="kanchor92" data-source-node="n57"></a>View By Field</h1>
        <p data-source-node="n58">This field indicates how you want the system to display your web statistics 
 inquiry results, by date:</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">Choose Day 
 if you want the system to list each statistic record by day.<br data-source-node="n61"> </li>
            <li data-source-node="n62">Choose Month 
 if you want the system to list each statistic record by month.<br data-source-node="n63"> </li>
            <li data-source-node="n64">Choose Fiscal 
 Period if you want the system to list each statistic record by 
 fiscal period. These periods are defined on the Fiscal Calendar Window.</li>
        </ul>
