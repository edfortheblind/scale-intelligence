Interface Data Map Configuration

Overview

 

Interface Data Map configuration defines the field mappings used when interfacing data between SCALE and an external system. You can create maps for delimited or fixed-length file formats and define the sequence and properties of each mapped field.

 

Configure Interface Data Map

 

1. Interface Data Map

 

The Review Interface Data Maps screen displays existing records and allows record maintenance.

  • Review Interface Data Maps: View existing maps with Name, Mode, Record Type, Action, and Direction columns.

  • Add New Interface Data Map: Create a new data map record.

  • Delete: Remove the selected data map record.

 

A. Information

 

Enter the general data map details.

  • Name: Enter the unique identifier for the data map. This value is required and cannot be changed after creation.

  • Record Type: Select the type of data record this map applies to. This value is required and determines the available Interface Actions.

  • Interface Action: Select the interface action associated with the chosen Record Type. This field is enabled only after a Record Type is selected.

  • Mode: Select the interface file format. Choose Delimited for delimiter-separated files or Fixed Length for positional fixed-width files. This value is required and cannot be changed after creation.

 

2. Map Fields

 

The Map Fields screen displays the ordered list of fields defined for this data map.

  • Position: The sequence position of the field in the map.

  • Field: The name of the mapped data field.

  • Required: Indicates whether the field is required. Required fields cannot be deleted.

  • Length (Fixed Length mode only): The character width allocated to the field.

  • Pad Character (Fixed Length mode only): The character used to pad the field to its defined length.

  • Pad From (Fixed Length mode only): Indicates whether padding is applied from the left or right of the field value.

  • Add New Field: Add a new field entry to the map. Fields can be reordered by dragging rows.

  • Edit/Delete: Update or remove the selected field. Delete is disabled for required fields.

 

A. Field Properties

 

Define the properties for a data map field.

  • Field: Select the field from the list of available fields for the data map (New mode), or view the read-only field name (Change mode).

  • Length (Fixed Length mode only): Enter the number of characters allocated to this field in the fixed-length record.

  • Pad Character (Fixed Length mode only, not applicable to first field): Enter the character used to pad this field when the value is shorter than the defined length.

  • Pad From (Fixed Length mode only, not applicable to first field): Select whether padding is applied from the Left or Right side of the field value. Defaults to Right.

 

Use Back, Save, Continue, and Finish to manage and complete Interface Data Map configuration.
