
        
        <h1 data-source-node="n56"><a name="kanchor1744" data-source-node="n57"></a>Initiation Method Field</h1>
        <h5 data-source-node="n58">On the Packing Preferences Window...</h5>
        <p data-source-node="n59">You can use this field to indicate the active field (which contains the cursor) when entering the Close Container Window:</p>
        <blockquote data-source-node="n60">
            <p data-source-node="n61">- <i data-source-node="n62">Always Shipment ID</i>: The Shipment ID Field will initially be active when the Desktop Close Container Window is opened (and while closing containers). Note that if there are more open containers on the shipment, the Shipment ID Field value will be highlighted.  </p>
            <p data-source-node="n63"> </p>
            <p data-source-node="n64">- <i data-source-node="n65">Always Container ID</i>: The Container ID Field will initially be active when the Web Close Container Window is opened (and while closing containers). Note that if there are more open containers on the shipment, the Shipment ID Field should contain the Shipment ID, and the Container ID Field should have focus.  </p>
            <p data-source-node="n66"> </p>
            <p data-source-node="n67">- <i data-source-node="n68">Container ID Unless No Open Containers</i>:  The Container ID Field will be active when there are multiple open containers on a shipment, and the Shipment ID Field will be active when the last open container has been closed. This is available in Desktop Close Container screen.</p>
        </blockquote>
