
        
        <h1 data-source-node="n56"><a name="kanchor1558" data-source-node="n57"></a>Auto Manifest at Close Checkbox</h1>
        <p class="p_1" data-source-node="n58">This checkbox indicates if the system will 
 automatically manifest a container when its closed. When you manifest 
 a container, the system sends its shipping information to Progistics CS. 
 Progistics uses this information to calculate the container's actualshipping 
 cost. It also provides a tracking number for the container.</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li class="li_1" data-source-node="n60">If 
 this checkbox contains a value, the system will automatically manifest 
 a container when the Close Button is pressed.<br data-source-node="n61"> </li>
            <li class="li_1" data-source-node="n62">If 
 this checkbox does not contain a value, the system will not automatically 
 manifest a container when the Close Button is pressed.</li>
        </ul>
