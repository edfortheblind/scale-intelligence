
        
        <h1 data-source-node="n56"><a name="kanchor860" data-source-node="n57"></a>Researching Outbound Statistics</h1>
        <p data-source-node="n58">The Outbound Statistics screen in Trading Partner Management allows 
 you to view shipment statistical data that was generated by ILS's web 
 statistics module. The system can output this statistical information 
 in several formats, such as HTML, XML, or text.</p>
        <p data-source-node="n59"> </p>
        <p class="p_1" style="text-align: left" data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures...</h4>
        <p data-source-node="n62"> </p>
        <p class="p_1" style="text-align: left" data-source-node="n63">Log into TPM. Choose the Outbound Statistics 
 option from the Trading Partner Management Main Menu. The system will 
 display the Outbound Statistics screen.</p>
        <ol class="ol_1" data-source-node="n64">
            <li class="li_1" value="1" data-source-node="n65">Enter 
 filter data in either of the first two sections: Search Criteria and Results 
 Criteria.  You can use the % sign as a wildcard character, similar 
 to other system searches. Note that the actual fields displayed on this 
 window vary depending on a company's Web Screen Data settings. <br data-source-node="n66"> </li>
            <li class="li_1" value="2" data-source-node="n67">Choose 
 an "order by" criteria value  to indicate how you want 
 the system to organize your inquiry's results. This is an optional step.<br data-source-node="n68"> </li>
            <li class="li_1" value="3" data-source-node="n69">Choose 
 a "view by" criteria value  to indicate how you want the 
 system to summarize your inquiry's results (this is an optional step):<br data-source-node="n70"><br data-source-node="n71">- Day:  Choose if you want 
 the system to list each statistic record by day.<br data-source-node="n72"><br data-source-node="n73">- Month:  Choose if you want 
 the system to list each statistic record by month.<br data-source-node="n74"><br data-source-node="n75">- Fiscal Period:  Choose if 
 you want the system to list each statistic record by fiscal period. These 
 periods are defined on the Fiscal Calendar Window.<br data-source-node="n76"> </li>
            <li class="li_1" value="4" data-source-node="n77">Choose 
 an output format  that you want the system to display your inquiry's 
 results:<br data-source-node="n78"><br data-source-node="n79">- HTML:  Choose if you want 
 the system to display your inquiry results as an HTML web page.<br data-source-node="n80"><br data-source-node="n81">- Text:  Choose if you want 
 the system to display your inquiry results as a text document.<br data-source-node="n82"><br data-source-node="n83">- XML:  Choose if you want 
 the system to display your inquiry results formatted as XML code.<br data-source-node="n84"> </li>
            <li class="li_1" value="5" data-source-node="n85">Press 
 the Search Button. The system will display your inquiry's results 
 in a separate browser window.</li>
        </ol>
