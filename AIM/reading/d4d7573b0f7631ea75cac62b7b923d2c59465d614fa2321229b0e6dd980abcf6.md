
        
        <h1 data-source-node="n57"><a name="kanchor1183" data-source-node="n58"></a>Create Orders From Shipments Checkbox</h1>
        <p data-source-node="n59">This field indicates if the system will generate an order when you create 
 a new shipment (when entering a Single Order in the system order entry 
 system).</p>
        <ul type="disc" class="ul_1" data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">If this checkbox is checked, 
 the system will generate orders (as well as shipments) when you create 
 a new shipment from the Shipment /Shipment Line Screens and the 
 Shipment Insight. The system creates these orders in an "In Process" condition, and are viewable from Trading Partner Management.<br data-source-node="n63"><br data-source-node="n64">NOTE: If this setting is selected, if you manually copy a shipment (and the original shipment has a blank ERP Order Number on the shipment), the system will insert the Shipment ID value into the ERP Order Number field. In addition, the system will also copy this value to the shipment line(s) if the ERP Order Number is blank.<br data-source-node="n65"><br data-source-node="n66"></p>
            </li>
            <li data-source-node="n67">
                <p data-source-node="n68">If this checkbox is not checked, 
 these windows will simply generate shipments.</p>
                <p class="p_1" data-source-node="n69"> </p>
            </li>
        </ul>
