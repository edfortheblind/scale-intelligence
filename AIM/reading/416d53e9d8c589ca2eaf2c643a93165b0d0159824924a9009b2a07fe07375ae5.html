Transactions Indicator Tile

On the Cycle Count Plan Insight Screen...

Clicking on this tile takes you to Transaction History Insight filtering on the internal plan number and transaction type.

 

 

On the Lot Insight Screen...

Clicking on this tile will open the Transaction History Insight screen filtered by the item, company, and lot in the warehouse for all transaction types.

 

 

On the Replenishment Insight Screen...

Clicking on this tile takes you to Transaction History Insight filtering on the warehouse, internal replenishment request number, and transaction type. In Transaction History Insight, the internal replenishment request number gets populated in the reference Id field of Transaction history insight.

 

 

On the Shipping Container Insight Screen...

Clicking on this tile takes you to Transaction History Insight filtering on the Shipping Container ID.

 

 

On the Work Order Insight Screen...

Clicking on this tile takes you to Transaction History Insight filtering on the Work Order ID.

 

 

On the Work Order Line Insight Screen...

Clicking on this tile takes you to Transaction History Insight filtering on the Work Order ID.

 

 

On the Work Order License Plate Insight Screen...

Clicking on this tile takes you to Transaction History Insight filtering on the license plate and item for the Pick & Put Confirmation transactions.
