Override Pick Checkboxes

These checkboxes indicate what value(s) that a user can change during RF pick confirmation. You can enable the user to override any/all of the following values: Location, Lot, License Plate. See this topic for rules that the system enforces for override picks.

 

When the "Prompt On LP/Location/Lot Override setting is active, the system will display an alert message when you attempt to override one of the pick values.
