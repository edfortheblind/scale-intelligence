
        
        <h1 data-source-node="n56"><a name="kanchor887" data-source-node="n57"></a>Defining Allocation Location Selection Records</h1>
        <p data-source-node="n58">These records identify a set of possible allocation locations the system 
 can assign to an allocation rule detail. Any location, inventory, or inventory attributes value(s) 
 can be used to define an allocation location record. You can also use 
 these records to define allocation rules on the Allocation Rule Window.</p>

        <h4 data-source-node="n100">Procedures...</h4>
        <p data-source-node="n101">Access the Allocation Location Selection Window. Name this record and 
 provide a description.</p>
        <ol class="ol_1" data-source-node="n102">
            <li value="1" data-source-node="n103">Using the Filter 
 Data Tab: You can use this tab to identify which locations should 
 be considered for allocation. <br data-source-node="n104"> </li>
            <li value="2" data-source-node="n105">Using the Order 
 By Tab: You can use this tab to organize the locations selected 
 for review.<br data-source-node="n106"><br data-source-node="n107">	NOTE: If a   strategy 
 is defined on the allocation rule detail, that strategy sort organizes 
 the locations. The values defined on this tab will be used next, to perform 
 any 'tie-breakers' created during the sort generated by the strategy record.<br data-source-node="n108"> </li>
            <li value="3" data-source-node="n109">When finished, 
 press OK. The system will save the selection record.</li>
        </ol>
