        <h4 data-source-node="n111"><a name="Summary" data-source-node="n112"></a>Performance Metrics</h4>
        <p data-source-node="n113"> </p>
        <h5 data-source-node="n114">Utilization %</h5>
        <p data-source-node="n115">This metric shows the average percentage time spent on direct labor activities out of the total available time.</p>
        <p data-source-node="n116"> </p>
        <p data-source-node="n117">Calculation</p>
        <p data-source-node="n118">Utilization% = (Actual Time / Total Available Time) × 100</p>
        <ul data-source-node="n119">
            <li data-source-node="n120">
                <p data-source-node="n121">Actual Time = Time spent on direct + indirect tasks.</p>
            </li>
        </ul>
        <ul data-source-node="n122">
            <li data-source-node="n123">
                <p data-source-node="n124">Total Available Time = Actual Time + Gap Time.</p>
            </li>
        </ul>
        <blockquote data-source-node="n125">
            <h5 data-source-node="n126">Total Available Time Definition</h5>
            <p data-source-node="n127">Total Available Time represents the full period during which an employee has been productive.</p>
            <p data-source-node="n128"> </p>
            <p data-source-node="n129">Calculation: Total Available Time = Actual Time (Direct + Indirect)+Gap Time</p>
            <ul data-source-node="n130">
                <li data-source-node="n131">
                    <p data-source-node="n132">Direct Time: Time spent on productive warehouse tasks like picking, packing and receiving.</p>
                </li>
                <li data-source-node="n133">
                    <p data-source-node="n134">Indirect Time: Time spent on necessary non-task activities (example, equipment checks).</p>
                </li>
                <li data-source-node="n135">
                    <p data-source-node="n136">Gap Time: Idle time detected between two logged activities (automatically captured by the system).</p>
                </li>
            </ul>
        </blockquote>

        <p data-source-node="n362">Throughput % summary is calculated as shown below</p>
        <ul data-source-node="n363">
            <li data-source-node="n364">
                <p data-source-node="n365"> Throughput% (summary) = ((Sum of throughput allowable minutes for all the employees)/ (Sum of Total Direct Labor time and Total Gap time))*100.</p>
            </li>
        </ul>
        <ul data-source-node="n366">
            <li data-source-node="n367">
                <p data-source-node="n368">For the above example table: throughput% = (18/(37+4))*100 = 43.90%</p>
            </li>
        </ul>
        <p data-source-node="n369"> </p>
        <p data-source-node="n370">Throughput % for a user is calculated as below.</p>
        <ul data-source-node="n371">
            <li data-source-node="n372">
                <p data-source-node="n373">Throughput% = [(Throughput Allowable Minutes) / (Direct Labor time + Gap time)]* 100. </p>
                <p data-source-node="n374"> </p>
            </li>
            <li data-source-node="n375">
                <p data-source-node="n376">From the above table, for Employee A, it is calculated as (3/11)*100 = 27.27%</p>
            </li>
        </ul>
        <h5 data-source-node="n377">Throughput (Units/Hour)</h5>
        <p data-source-node="n378">This value indicates the number of handling units completed per hour.</p>
        <p data-source-node="n379"> </p>
        <p data-source-node="n380">Calculation</p>
        <ul data-source-node="n381">
            <li data-source-node="n382">
                <p data-source-node="n383">Throughput (handling units/hour)=(Total Quantity Processed)/Total Time Taken (minutes))×60</p>
            </li>
        </ul>
        <p data-source-node="n384"> </p>
        <p data-source-node="n385">Note:</p>
        <ul data-source-node="n386">
            <li data-source-node="n387">
                <p data-source-node="n388">Only direct labor activities (Labor Type 10 or 20) are considered.</p>
            </li>
        </ul>
        <ul data-source-node="n389">
            <li data-source-node="n390">
                <p data-source-node="n391">Indirect activities, breaks, and gaps are excluded.</p>
            </li>
        </ul>
        <ul data-source-node="n392">
            <li data-source-node="n393">
                <p data-source-node="n394">If tasks involve different unit of measurement (such as Each, Case, or Pallet), the system converts them into a single standard handling unit before calculation.</p>
            </li>
        </ul>
