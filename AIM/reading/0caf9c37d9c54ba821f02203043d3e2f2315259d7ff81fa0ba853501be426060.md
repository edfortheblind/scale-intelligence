
        
        <h1 data-source-node="n56"><a name="kanchor1310" data-source-node="n57"></a>Maximum Requests Field</h1>
        <p class="p_1" data-source-node="n58">This field defines the maximum amount of requests 
 that a system service can retrieve for processing, per session. The service 
 will retrieve up to this amount of records (if the records have been generated), 
 sleep for a defined interval, and then retrieve records again. If there 
 are records left after this retrieval, the system will reduce its sleep 
 time so that it can catch up. Once it has caught up, the system will increase 
 its sleep time again.</p>
