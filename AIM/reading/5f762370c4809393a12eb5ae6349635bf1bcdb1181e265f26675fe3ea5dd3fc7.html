Create Work Checkbox

This checkbox determines if the system will generate work instructions for the allocated components and located finished items. It appears on the Work Order Preference Window.

  • If this checkbox is selected, the system will call work creation as soon as the component is allocated or the finished item is located.

     

  • If this checkbox is not selected, the system will not create work for either allocated components or located finished items. Instead, it will automatically locate the quantity (either component or finished item) and put its quantity as On Hand at the destination location(s). Someone will need to ensure that the product is physically delivered to the location(s).

 

For Cycle Counting...

This checkbox indicates how the system should process cycle count plans:

  • If this checkbox is checked, the system will create work for this plan.

     

  • If this checkbox is not checked, the system will not create work for this plan. Instead, workers will execute this plan from a cycle count list paperwork document.

 

For Immediate Needs...

This checkbox indicates that the system will create work when fulfilling an immediate needs request that is generated by a particular trigger. If you do not select this option, the system will put the quantity on hand at the destination location. You would then have to manually make sure that the immediate needs transaction was actually completed.

 

 

For Inventory Management...

This checkbox indicates that you want the system to run the work creation process for an adjustment type. You may also to select a Work Creation Master that the system will use to create this work. If you do not indicate a work creation master, the system will attempt to use all of the configured masters (in priority order) when generating work. By selecting one, you are forcing the system to use a specific master.
