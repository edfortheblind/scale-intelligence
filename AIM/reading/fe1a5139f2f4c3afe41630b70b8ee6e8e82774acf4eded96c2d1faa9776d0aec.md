
        
        <h1 data-source-node="n56"><a name="kanchor1904" data-source-node="n57"></a>Item Class Field</h1>
        <p data-source-node="n58">The class associated with a particular item. 
 An item class groups together items that share common characteristics, 
 such as unit of measure values and dimensions. To minimize setup time, create an item class for items that share the 
 same unit of measure values and dimensions. On each item's record, identify 
 the item class. Then, you can setup units of measure by class instead 
 of by item. Item classes are especially helpful if you 
 process many items that are similar. For example, if your warehouse distributes DVDs, you could associate all individual DVDs with the "DVD" item class.</p>
