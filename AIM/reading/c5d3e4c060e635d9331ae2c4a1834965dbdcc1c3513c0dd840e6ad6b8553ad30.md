
        
        <h1 data-source-node="n56"><a name="kanchor1285" data-source-node="n57"></a>Always Override Checkbox</h1>
        <p data-source-node="n58">During the allocation rule set assignment process, the system does the following:</p>
        <ol data-source-node="n59">
            <li value="1" data-source-node="n60">Selects all shipment/receipt lines that do not have an allocation/locating rule assigned.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li value="2" data-source-node="n63">Reviews each active allocation rule assignment record in <u data-source-node="n64">priority</u> <u data-source-node="n65">order</u>.<br data-source-node="n66"><br data-source-node="n67"></li>
            <li value="3" data-source-node="n68">Using the filter tied to the allocation rule assignment record to determine eligibility, the system updates the allocation/locating rule on the matching details. If the shipment/receipt line already had a rule assigned by a previous sequence, then it will only be updated if the"Always Override" setting is <u data-source-node="n69">selected</u>.</li>
        </ol>
