
        
        <h1 data-source-node="n56"><a name="kanchor1436" data-source-node="n57"></a>Container ID Field</h1>
        <p data-source-node="n58">This field is a unique, alpha-numeric value 
 that represents a shipping container. The system uses this value 
 to associate a container with its contents. A container ID can also represent the parent of child containers.  This would be called the parent container ID.  For example, if you have shipping containers nested onto a pallet, then the pallet’s ID is considered to be the parent container ID and the nested containers are considered the child containers.</p>
