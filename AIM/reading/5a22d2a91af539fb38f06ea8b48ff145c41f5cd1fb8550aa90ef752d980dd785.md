
        
        <h1 data-source-node="n56"><a name="kanchor1627" data-source-node="n57"></a>Starting Location Field</h1>
        <p data-source-node="n58">This field indicates the starting location name for a range of new locations 
 to be created. The system will begin creating locations, starting with 
 the location name entered in this field. The system continue to create 
 locations incrementally (as defined in the Increment Field) until the 
 location named entered in the Ending Location Field is reached. All locations 
 created in this range will have the same characteristics, as defined in 
 the Location Window. If you want to create a single location, do 
 not enter any value in the Ending Location Field or the Increment Field.</p>
