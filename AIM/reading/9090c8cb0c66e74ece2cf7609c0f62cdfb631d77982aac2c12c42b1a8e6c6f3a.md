
        
        <h1 data-source-node="n56"><a name="kanchor2095" data-source-node="n57"></a>Defining a Carrier's Postal Code Ranges</h1>
        <p data-source-node="n58">A postal code range identifies a group of postal codes that the carrier 
 can service within a specific time frame. During routing, the system will 
 reference these records to determine if the carrier can deliver to the 
 destination postal code and how long it will take to deliver the package. 
 Note that this step is required for LTL and Truckload 
 carriers, and any other carrier not supported by Progistics.</p>

        <h4 data-source-node="n96">Procedures...</h4>
        <ol data-source-node="n97">
            <li value="1" data-source-node="n98">
                <p data-source-node="n99">Identify the carrier and the service. 
 Select the carrier from   the Carrier 
 Field. Select the service from the Service Field.</p>
                <p data-source-node="n100"> </p>
            </li>
            <li value="2" data-source-node="n101">
                <p data-source-node="n102">Identify the location of the pick-up 
 warehouse. Select the origin country from the Origin Country Field. 
 Select the origin postal code from the Origin Postal Code Field.<br data-source-node="n103"><br data-source-node="n104">	NOTE: You are not required to enter values in the Postal Code 
 Fields. This accommodates carrier commitment records for countries that 
 do not use zip codes.</p>
                <p data-source-node="n105"> </p>
            </li>
            <li value="3" data-source-node="n106">
                <p data-source-node="n107">Identify the postal code range 
 that the carrier will deliver product to. Note: the carrier must 
 be able to reach all of these postal codes in the same time span (days 
 to deliver). Select the destination country from the Destination Country 
 Field. Use the Destination Postal Code Range to identify the start and 
 end postal codes for this range.<br data-source-node="n108"><br data-source-node="n109">	NOTE: You are not required to enter values in the Postal Code 
 Range Fields. This accommodates carrier commitment records for countries 
 that do not use zip codes.</p>
                <p data-source-node="n110"> </p>
            </li>
            <li value="4" data-source-node="n111">
                <p data-source-node="n112">Use the Days to Deliver Field 
 to identify how long it takes the carrier to reach this postal code range.<br data-source-node="n113"><br data-source-node="n114">	NOTE: If a carrier does not have a carrier commitments record 
 associated with it, the system will default this field's value to 999 
 days. If you then try to route a shipment using this carrier, the system 
 will alert you that the package might not arrive on time, if you have 
 less than 1000 days between the requested date and the ship date.</p>
                <p data-source-node="n115"> </p>
            </li>
            <li value="5" data-source-node="n116">Use the Effective 
 Date Range to identify the time span when this record is valid. 
 The system defaults today's date in both effective date fields. Change 
 these dates to reflect when this record is valid.   If 
 this record will not expire, select the No End Date Checkbox. The 
 system will default a non-active value in the To Date Field, but this 
 record will never expire.</li>
        </ol>
