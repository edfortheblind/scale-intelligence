Searching/Viewing Work Order Line Records...

You can use the Work Order Line Insight Screen to search for and view work order line records in your warehouse.

  1. Open the Work Order Line Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

The Work Order Line Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

List Pane Icon Explanation

Certain conditions for the work order line are represented by graphical icons on the list pane. Below are explanations of what each icon represents:


Icon Explanation

Work order line has a pending immediate need associated with it.

Work order line has an immediate need being fulfilled.

Work order line has an immediate need that has been fulfilled.


For more general information about the List Pane, see the topic Introduction to Insight Screens.



 

 

About the Detail Pane...

The Work Order Line Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Work Order Line Insight contains Indicator Tiles with counts of the other entities (i.e. open work, and transactions). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Open Work

    1. Clicking on this tile takes you to Work Insight filtering on the given work order number.

  2. Transactions

    1. Displays the transaction history of the work order.

    2. Clicking on this tile takes you to Transaction History Insight filtering on the Work Order ID.


For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

Screen Actions

The following actions are accessible from the List Pane:

 

 

 

View/Edit

The View action allows you to open the Work Order Insight screen in the read-only mode and the Edit action allows you to open the Work Order Insight screen in the edit mode. So the View action only permits viewing the work order, while the Edit action permits editing certain fields on the work order.

 

 

Delete

This Delete action allows you to delete an existing work order line. This action is enabled when the work order condition is either Scheduled or In process. System prompts for a confirmation message after invoking the action and then displays a success message upon confirming the deletion process.

 

 

Allocate

This action allows you to allocate a work order line. The action is enabled on selecting a line which has not been allocated. Invoking the action will open Work Order Component Allocation screen. Refer to Processing Work Orders for more information.

 

 

Deallocate

This action allows you to deallocate a work order line. The action is enabled on selecting a line which has been allocated. Invoking the action by selecting a line will deallocate the line and a success message will be displayed. Refer to Processing Work Orders for more information.

 

 

Immediate Needs

This action enables you to open the Immediate Needs Insight screen with Work Order ID and warehouse filled in the Filter Pane and the search results would be displayed at the same time. Refer to Immediate Needs Note Field for information on Immediate Needs icon colors.
