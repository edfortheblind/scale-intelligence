
        
        <h1 data-source-node="n56"><a name="kanchor878" data-source-node="n57"></a>Defining Wave Maximums</h1>
        <p data-source-node="n58">During the wave building process, the wave maximum record determines 
 when a wave will stop accepting shipments. When the system stops accepting 
 shipments, it generates a new wave and therefore continues accepting shipments. 
 You will establish wave maximums on the Wave Maximums Window. Later, you 
 will associate these maximums with the appropriate waves on the Wave Master 
 Window.</p>

        <h4 data-source-node="n100">Procedures...</h4>
        <ol data-source-node="n101">
            <li value="1" data-source-node="n102">
                <p data-source-node="n103">Identify this record in 
 the Wave Maximum Field. </p>
                <p data-source-node="n104"> </p>
            </li>
            <li value="2" data-source-node="n105">
                <p data-source-node="n106">Use the maximum fields to 
 define how much product can be processed in a wave.<br data-source-node="n107"> </p>
                <ul type="disc" class="ul_1" data-source-node="n108">
                    <li data-source-node="n109">
                        <p data-source-node="n110">If you want to define one 
 of the values with no maximums, leave the '0' value in the field.</p>
                        <p data-source-node="n111"> </p>
                    </li>
                    <li data-source-node="n112">If you define 
 multiple values on this tab, the system will honor the first maximum 
 it reaches during wave building process. For example, suppose two maximum 
 values are defined: Maximum Shipments (100) and Maximum Weight (200 lbs). 
 If the system reached either of these values during the wave building 
 process, it would close the wave and start a new one.</li>
                </ul>
                <p data-source-node="n113"> </p>
            </li>
            <li value="3" data-source-node="n114">Press OK. 
 The system will save the record.</li>
        </ol>
