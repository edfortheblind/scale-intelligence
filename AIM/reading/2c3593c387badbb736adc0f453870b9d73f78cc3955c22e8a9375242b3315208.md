
        
        <h1 data-source-node="n56"><a name="kanchor2070" data-source-node="n57"></a>Length Field (Location)</h1>
        <p data-source-node="n58">This field indicates the text character length of a alpha or numeric 
 segment of a location name. For example, in the location 111-222-333, 
 the length of each of the segments is three. All values defined on the Location Template Window 
 are valid. Each location has a maximum length of 25 characters, including 
 separators and all segment(s).</p>
