
        
        <h1 data-source-node="n56">Labor Logging</h1>
        <p data-source-node="n57">The labor logging explains how labor activity is recorded in the application, with a focus on the Heel-To-Toe (HTT) approach used to ensure continuous tracking. Heel-To-Toe aligns the start time of each activity with the end time of the previous one, preventing unintentional gaps in logged labor.</p>

        <h4 data-source-node="n82"><a name="Heel" data-source-node="n83"></a>Heel to Toe Logic</h4>
        <p data-source-node="n84"> </p>
        <p data-source-node="n85">Heel-To-Toe (HTT) is the process by which the system determines whether consecutive labor records are close enough in time to be considered continuous work. When tasks occur within a defined threshold period, they are logged together, and no gap is recorded. This approach eliminates unintended time gaps between tasks, helping maintain an accurate and complete labor log.</p>
        <ul data-source-node="n86">
            <li data-source-node="n87">
                <p data-source-node="n88"><b data-source-node="n89">Activity Heel to Toe Tolerance (minutes)</b> is configured in <a href="75e5cda2f98440a3c1147b70496c8d8bd1353b2f8797e9a3df157fa77497b149.html" data-source-node="n90">Labor Group</a></p>
            </li>
        </ul>
        <p data-source-node="n91">Example:</p>
        <ul data-source-node="n92">
            <li data-source-node="n93">
                <p data-source-node="n94">Task A ends at 10:00 AM.</p>
            </li>
            <li data-source-node="n95">
                <p data-source-node="n96">Task B is scheduled to begin at 10:05 AM.</p>
            </li>
            <li data-source-node="n97">
                <p data-source-node="n98">If the Heel To Toe threshold is set to 10 minutes, Task B falls within this limit.</p>
            </li>
            <li data-source-node="n99">
                <p data-source-node="n100">Heel To Toe adjusts the End time of Task A to 10:05 AM, aligning it with the start Time of Task B.</p>
            </li>
        </ul>
        <p data-source-node="n101">Note: </p>
        <ul data-source-node="n102">
            <li data-source-node="n103">
                <p data-source-node="n104">Heel-To-Toe logic is applied separately for each labor group.</p>
            </li>
            <li data-source-node="n105">
                <p data-source-node="n106">if an employee switches labor groups within the Heel To Toe gap time, then the system always applies Heel to Toe based on the previous activity’s labor group.</p>
            </li>
        </ul>

        <h4 data-source-node="n108"><a name="GAP" data-source-node="n109"></a>Gap Time Tracking</h4>
        <p data-source-node="n110"> </p>
        <p data-source-node="n111">The Gap activity is used to record any idle time or breaks between two of your work tasks.</p>
        <p data-source-node="n112">The system will automatically log a Gap if there is too much time between when you finish one task and started the next one. This helps track any time that wasn't spent on specific warehouse activities.</p>
        <p data-source-node="n113"> </p>
        <p data-source-node="n114">When is a Gap recorded?</p>
        <ul data-source-node="n115">
            <li data-source-node="n116">
                <p data-source-node="n117">A Gap is added only if the time between tasks is longer than what’s allowed for your labor group.</p>
            </li>
            <li data-source-node="n118">
                <p data-source-node="n119">This check happens when you start your next task by scanning (for example, scanning a work unit).</p>
            </li>
            <li data-source-node="n120">
                <p data-source-node="n121">The system compares the time you ended your last task with the time you start the next one.</p>
            </li>
            <li data-source-node="n122">
                <p data-source-node="n123">If the gap is too long, it records that time as a Gap.</p>
            </li>
        </ul>
        <p data-source-node="n124"> </p>
        <p data-source-node="n125">Next Task Outside Threshold (Gap Inserted):</p>
        <ul data-source-node="n126">
            <li data-source-node="n127">
                <p data-source-node="n128">Task A ends at 10:00 AM.</p>
            </li>
            <li data-source-node="n129">
                <p data-source-node="n130">Task B is scheduled to begin at 10:30 AM.</p>
            </li>
            <li data-source-node="n131">
                <p data-source-node="n132">	With a 10-minute Heel To Toe threshold, this 30-minute delay exceeds the acceptable range.</p>
            </li>
            <li data-source-node="n133">
                <p data-source-node="n134">In this case, a gap activity is automatically inserted from 10:00 AM to 10:30 AM to indicate an unaccounted time block.</p>
            </li>
            <li data-source-node="n135">
                <p data-source-node="n136">Task B retains its original 10:30 AM start time.</p>
            </li>
        </ul>
        <p data-source-node="n137"><b data-source-node="n138">Extension of Time</b>
        </p>
        <p data-source-node="n139"> </p>
        <p data-source-node="n140">When the time gap between two tasks falls within the Heel To Toe threshold, the system extends the end time of the earlier task to match the start time of the next. This maintains continuity and avoids logging a Gap.</p>
        <p data-source-node="n141"> </p>
        <p data-source-node="n142">Example:</p>
        <ul data-source-node="n143">
            <li data-source-node="n144">
                <p data-source-node="n145">Task A ends at 9:00 AM</p>
            </li>
            <li data-source-node="n146">
                <p data-source-node="n147">Task B starts at 9:00:30 AM</p>
            </li>
            <li data-source-node="n148">
                <p data-source-node="n149">If the Heel To Toe threshold is 1 minute, the system adjusts Task A’s end time to 9:00:30 AM, creating a continuous flow.</p>
            </li>
        </ul>
