
        
        <h1 data-source-node="n56"><a name="kanchor444" data-source-node="n57"></a>Shipper Code Field</h1>
        <p data-source-node="n58">This value identifies a shipper and its postal code to Progistics. Progistics 
 uses the shipper code to determine the rate data table it will apply to 
 a specific shipper/origin postal code. If the companies in a warehouse have negotiated special shipping rates, 
 each company needs its own shipper code. Since rates 
 are based on the origin postal code, any warehouses that share the same 
 postal code can also share the same shipper code. Also, if one 
 company is supported by two or more warehouses with the same postal code, 
 you only need to create one shipper code for that company.</p>
