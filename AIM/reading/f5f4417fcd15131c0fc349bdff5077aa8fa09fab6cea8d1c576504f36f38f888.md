
        
        <h1 data-source-node="n56"><a name="kanchor1276" data-source-node="n57"></a>Group Field</h1>
        <p data-source-node="n58">This field indicates the type of resource file you want to edit in the 
 System Text Editor Window. There are four types of system resource values 
 you can edit:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61"><i data-source-node="n62">Text</i>: This group of values 
 consists of text labels throughout the system, such as field names or 
 menu options.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li data-source-node="n64">
                <p data-source-node="n65"><i data-source-node="n66">Messages</i>: This group of 
 values consists of system-generated error messages and warnings.</p>
                <p data-source-node="n67"> </p>
            </li>
            <li data-source-node="n68">
                <p data-source-node="n69"><i data-source-node="n70">Images</i>: This group of values 
 consists of the file names of graphic images used throughout the system, 
 such as browser icons.</p>
                <p data-source-node="n71"> </p>
            </li>
            <li data-source-node="n72"><i data-source-node="n73">Help</i>: This 
 group of values consists of the names/paths of help topics associated 
 with the system windows.   NOTE: Do 
 not change any of the help values in this group unless you talk to a system 
 consultant first.</li>
        </ul>
