
        
        <h1 data-source-node="n56">Warehouse Mobile - Override Pick</h1>
        <p data-source-node="n57">The Warehouse Mobile - Override Pick options can be selected during the picking process. Override Pick can be performed for outbound (allocation and shipping container) work, replenishment and inventory transfer work. </p>
        <p data-source-node="n58"> </p>

        <h4 data-source-node="n69"><a name="License" data-source-node="n70"></a>License Plate</h4>
        <p data-source-node="n71">Users can override the license plate from which they are going to pick if the license plate override is active on the work special handling record. The user would scan a different LP value (than the one currently assigned to the work instruction) in the LP field, and the system will treat this as an override of the original LP value. </p>
        <p data-source-node="n72"> </p>
        <p data-source-node="n73">To override the license plate, </p>
        <ul data-source-node="n74">
            <li data-source-node="n75">Enable the Override pick security.</li>
            <li data-source-node="n76">Work Special Handling <ul data-source-node="n77"><li data-source-node="n78">Override </li><li data-source-node="n79">Verification - License Plate selected.</li></ul></li>
        </ul>
        <p data-source-node="n80">The following is supported while overriding the license plate </p>
        <p data-source-node="n81"> </p>
        <p data-source-node="n82">Override license plates with different quantities at the same location (inline) or different location is supported for the following options in</p>
        <ul data-source-node="n83">
            <li data-source-node="n84">
                <p data-source-node="n85"> work special handling</p>
                <ul data-source-node="n86">
                    <li data-source-node="n87">
                        <p data-source-node="n88"><i data-source-node="n89">Allow override to different quantity</i> </p>
                    </li>
                    <li data-source-node="n90">
                        <p data-source-node="n91"><i data-source-node="n92">Container verify</i>
                        </p>
                    </li>
                </ul>
            </li>
            <li data-source-node="n93">
                <p data-source-node="n94">Work Profile</p>
                <ul data-source-node="n95">
                    <li data-source-node="n96">
                        <p data-source-node="n97">Group picks by loc/LP</p>
                    </li>
                </ul>
            </li>
        </ul>
        <p data-source-node="n98">System will prompt to scan the location and scan the license plate when no locations or license plates have the available quantity, and there is another location and license plate have a sufficient allocated quantity to swap for override.</p>
        <p data-source-node="n99"> </p>
        <p data-source-node="n100">When Container verify is checked on work special handling and container creation and pallet building in the wave, then during override, system will prompt the user to verify the Pallet ID and nested container ID when overriding the license plate to the same or different location.</p>
        <h4 data-source-node="n101"> </h4>
        <h4 data-source-node="n102"><a name="Location" data-source-node="n103"></a>Location</h4>
        <p data-source-node="n104">Users can override the pick location from which they are going to pick the product if location override is active on your work special handling record. The user would scan a different location ID (than the one currently assigned to the work instruction) in the Location field, and the system will consider this as an override of the original location value.</p>
        <p data-source-node="n105"> </p>
        <p data-source-node="n106">For override location, </p>
        <ul data-source-node="n107">
            <li data-source-node="n108">Enable the Override pick security.</li>
            <li data-source-node="n109">Work Special Handling - Override - Locations and Lot selected.</li>
        </ul>
        <h5 data-source-node="n110">Perform an override pick</h5>
        <ol data-source-node="n111">
            <li value="1" data-source-node="n112">In the <b data-source-node="n113">Pick Confirmation</b> screen, select <b data-source-node="n114">Actions &gt;&gt; Override</b>.</li>
            <li value="2" data-source-node="n115"> The system will prompt the user with an available list of locations to override. Select the location and tap  <b data-source-node="n116">Go</b>.</li>
            <li value="3" data-source-node="n117">Optionally, the user can also enter the location that is not displayed in the list and tap <b data-source-node="n118">Go</b>.</li>
        </ol>
        <h5 data-source-node="n119">Override to Location not on the list</h5>
        <p data-source-node="n120">Users can scan a location that is not part of the location list for selection. </p>
        <ul data-source-node="n121">
            <li data-source-node="n122">In the <b data-source-node="n123">Override Location</b> screen, scan/enter the new location which is not part of the list.</li>
            <li data-source-node="n124"><b data-source-node="n125">Pick Confirmation</b> screen displays the new location scan/entered.</li>
        </ul>
        <p data-source-node="n126">Note: </p>
        <ul data-source-node="n127">
            <li data-source-node="n128">
                <p data-source-node="n129">The list of eligible locations is based on the Work System Value - Number of locations to display on the Override Pick configuration.</p>
            </li>
            <li data-source-node="n130">
                <p data-source-node="n131">System allows override location when the original location has over allocated inventory. This happens only when the override location has sufficient available quantity to fulfill the original quantity.</p>
            </li>
            <li data-source-node="n132">
                <p data-source-node="n133">override the original pick location for outbound serial number tracked items, enabling fulfillment from alternate locations.</p>
            </li>
        </ul>
        <h5 data-source-node="n134">Override Pick with Short Pick</h5>
        <p data-source-node="n135">Users can perform a short pick after initiating an Override pick.</p>
        <ol data-source-node="n136">
            <li value="1" data-source-node="n137">In the <b data-source-node="n138">Pick Confirmation</b> screen, select <b data-source-node="n139">Actions &gt;&gt; Override</b>.</li>
            <li value="2" data-source-node="n140">Select the overriding location and tap  <b data-source-node="n141">Go</b>.</li>
            <li value="3" data-source-node="n142">Tap the arrow and select <b data-source-node="n143">Short Pick</b>.</li>
            <li value="4" data-source-node="n144">Enter the pick quantity value and tap <b data-source-node="n145">Go</b>. The <b data-source-node="n146">Go</b> button will be disabled if the entered quantity is more than the pick quantity or when no value is entered.</li>
            <li value="5" data-source-node="n147">The quantity entered for the short pick is now updated in the <b data-source-node="n148">Pick Confirmation</b> screen. Tap <b data-source-node="n149">Go</b> to complete the picking process.</li>
        </ol>
        <h5 data-source-node="n150">Override Pick with Partial Pick</h5>
        <p data-source-node="n151">Users can perform the short pick after initiating the Override pick.</p>
        <ol data-source-node="n152">
            <li value="1" data-source-node="n153">In the <b data-source-node="n154">Pick Confirmation</b> screen, select <b data-source-node="n155">Actions &gt;&gt; Override</b></li>
            <li value="2" data-source-node="n156">Select the overriding location and tap  <b data-source-node="n157">Go</b>.</li>
            <li value="3" data-source-node="n158">Tap the arrow and  select <b data-source-node="n159">Partial Pick</b>.</li>
            <li value="4" data-source-node="n160">Enter the pick quantity value and tap <b data-source-node="n161">Go</b>. The <b data-source-node="n162">Go</b> button will be disabled if the entered quantity is more than the pick quantity or when no value is entered.</li>
            <li value="5" data-source-node="n163">The quantity entered for the partial pick is now updated in the <b data-source-node="n164">Pick Confirmation</b> screen. Tap <b data-source-node="n165">Go</b> to complete the picking process. <b data-source-node="n166">Note</b>: This option will not be available if the user does not have security permission or quantity verification is turned on.</li>
        </ol>
        <h4 data-source-node="n167"><a name="Lot" data-source-node="n168"></a>Lot</h4>
        <p data-source-node="n169">Users can override the lot ID of the item they are going to pick if the lot and location override is active on your work special handling record. When overriding a location, the user can choose a same location or different location with the same lot or different lot. </p>
        <p data-source-node="n170">We can override using the cart picking, user directed, and system directed initiation methods.</p>
        <p data-source-node="n171"> </p>
        <p data-source-node="n172">Perform on override pick for same or different Lot</p>
        <ol data-source-node="n173">
            <li value="1" data-source-node="n174">In the <b data-source-node="n175">Pick Confirmation</b> screen, select <b data-source-node="n176">Actions &gt;&gt; Override</b>.</li>
            <li value="2" data-source-node="n177">In the <b data-source-node="n178">Override Location</b> screen, system displays the item, location and lot details. Swipe to see the list of locations available.</li>
            <li value="3" data-source-node="n179">Select the location and tap  <b data-source-node="n180">Go</b>.</li>
        </ol>
        <p data-source-node="n181">When overriding lot at same location, then system supports </p>
        <ul data-source-node="n182">
            <li data-source-node="n183">
                <p data-source-node="n184">Replenishment work with Group by picks loc/LP checked and override lot has available quantity only.</p>
            </li>
            <li data-source-node="n185">
                <p data-source-node="n186">Shipping container work for full unit of measure containers only with Group by picks loc/LP checked and override lot has available quantity only.</p>
            </li>
            <li data-source-node="n187">
                <p data-source-node="n188">Shipping container work for full unit of measure containers only with Group by picks loc/LP checked and override lot has partially allocated and fully allocated quantity only.</p>
            </li>
        </ul>
        <p data-source-node="n189">Notes</p>
        <ul data-source-node="n190">
            <li data-source-node="n191">
                <p data-source-node="n192">Override lot with outbound serial-number-tracked item at the same or different location.</p>
            </li>
            <li data-source-node="n193">
                <p data-source-node="n194">Override lot with cart picking at a different location.</p>
            </li>
            <li data-source-node="n195">
                <p data-source-node="n196">Override non-License Plate tracked location with License Plate tracked location.</p>
            </li>
            <li data-source-node="n197">
                <p data-source-node="n198">Override License Plate tracked location with non-License Plate tracked location.</p>
            </li>
            <li data-source-node="n199">
                <p data-source-node="n200">Override license plate with item verification, at the same or different location.</p>
            </li>
        </ul>

        <h4 data-source-node="n202"><a name="Notes" data-source-node="n203"></a>Override Notes</h4>
        <ul data-source-node="n204">
            <li data-source-node="n205">Override action can be invoked from the Item, Lot, check digit and Quantity verification screen during a pick.</li>
            <li data-source-node="n206">Override pick is supported with replenishment work and inventory transfer work.</li>
            <li data-source-node="n207">Partial and Short pick can be performed after an override pick.</li>
            <li data-source-node="n208">System displays the converted Unit of Measure (UM) on the <b data-source-node="n209">Override location</b> and <b data-source-node="n210">Override license plate</b> screen when <b data-source-node="n211">Use Converted qty</b> is selected in <b data-source-node="n212">Work Special Handling</b>.</li>
            <li data-source-node="n213">The system prompts  a confirmation message to override values to complete the picking process. Note: This prompt is displayed if you have the location/lot/LP override selected in the Work special Handling configuration.</li>
            <li data-source-node="n214">During cart picking, users can override group picks for same or different lot. For example, 2 work instructions for same item/location with two different shipments. The work unit and container labels will be displayed as Multiple in such a scenario.</li>
            <li data-source-node="n215">When override is performed, then the location inventory, work instructions, and relevant records are updated to reflect the override license plate/lot/location.</li>
        </ul>
