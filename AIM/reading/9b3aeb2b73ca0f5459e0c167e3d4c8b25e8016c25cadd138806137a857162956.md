
        
        <h1 data-source-node="n56"><a name="kanchor589" data-source-node="n57"></a>Using the VAS Insight: Container Screen</h1>
        <p data-source-node="n58">The VAS Container: Insight Screen displays the value-added activities (such as putting hangars on clothes, or including a catalog with an order) that are assigned to a shipment's containers. You can use this screen to confirm these activities.  When you confirm an activity, you are simply indicating to the system that an activity has actually been performed on the container's contents.</p>

        <h4 data-source-node="n116"><a name="searching" data-source-node="n117"></a>Searching For VAS Activities...</h4>
        <p data-source-node="n118">Access the VAS Container: Insight Screen.</p>
        <ol data-source-node="n119">
            <li value="1" data-source-node="n120">Indicate the container(s) whose activities you want the system to display in the grid. You can do this by using any combination of the following criteria:<br data-source-node="n121"><br data-source-node="n122">- Container ID: You can enter a container ID, and the system will display all VAS activity(s) that are associated with that container. <br data-source-node="n123"><br data-source-node="n124">- Shipment ID: You can enter a shipment ID, and the system will display all VAS activity(s) that are associated with any container(s) on that shipment.      <br data-source-node="n125"><br data-source-node="n126">- VAS Activity: You can choose one or several activities, and the system will display all container(s) that have those VAS activity(s) associated with them.<br data-source-node="n127"><br data-source-node="n128"></li>
            <li value="2" data-source-node="n129">Use the Include Confirmed Activities setting to indicate if you want the system to display activities in the grid that have been finished (confirmed) by a user.<br data-source-node="n130"><br data-source-node="n131"></li>
            <li value="3" data-source-node="n132">Press the Apply Button. The system will display the results in the grid. The system will represent each container/activity as a separate row in the grid. </li>
        </ol>

        <h4 data-source-node="n137"><a name="viewing" data-source-node="n138"></a>Viewing VAS Activities...</h4>
        <p data-source-node="n139">The VAS activities grid includes several reference fields, which are described below:</p>
        <ul data-source-node="n140">
            <li data-source-node="n141">Container ID: This represents the container that has an activity assigned to it.<br data-source-node="n142"><br data-source-node="n143"></li>
            <li data-source-node="n144">Shipment ID: This represents the shipment that is associated with the VAS-assigned container.<br data-source-node="n145"><br data-source-node="n146"></li>
            <li data-source-node="n147">VAS Activity: This represents the activity that is assigned to a container.<br data-source-node="n148"><br data-source-node="n149"></li>
            <li data-source-node="n150">Instructions: This represents an activity's instructions text, which provides the user directions on how to perform the activity.<br data-source-node="n151"><br data-source-node="n152"></li>
            <li data-source-node="n153">Status: This represents the status of the container that has a VAS activity associated with it. In order to confirm a VAS activity, a container needs to be in at least an "In Packing" status. The system will make activity rows inactive if they are not at least at the minimum status to confirm VAS.<br data-source-node="n154"><br data-source-node="n155"></li>
            <li data-source-node="n156">QC Required: This indicates if QC is also required for this container, and the condition of that QC action (pending, failed, passed).</li>
        </ul>

        <h4 data-source-node="n161"><a name="confirming" data-source-node="n162"></a>Confirming VAS Activities...</h4>
        <p data-source-node="n163">The act of confirming a VAS activity indicates that said activity has actually been performed to the contents of a container. For example, if you have an activity for placing a catalog into a container, then when you confirm this activity on the VAS Container: Insight Screen, that tells the system that this activity as been performed. If a container's status is not at least "In Packing", the system will not allow you to confirm any activities for that container.</p>
        <p data-source-node="n164"> </p>
        <p data-source-node="n165">You can confirm VAS activities by selecting the Confirmed Checkbox for an activity row, and choose Confirm button:<br data-source-node="n166"><br data-source-node="n167"></p>
        <p data-source-node="n168">- Note that you can confirm activities one-by-one, or multiple activities at one time.</p>
        <p data-source-node="n169"> </p>
        <p data-source-node="n170">- After an activity has been confirmed, the system inactivates the row. You cannot undo a confirmation once it has been performed.</p>
        <p data-source-node="n171"> </p>

        <h4 data-source-node="n176"><a name="printing" data-source-node="n177"></a>Printing VAS Paperwork...</h4>
        <p data-source-node="n178">The VAS Container: Insight Screen also features a paperwork document called the VAS Activity List, which outlines the containers of a shipment that require VAS, and the activities that need to be performed on each container. You can print this document not only from the VAS Container: Insight Screen, but also from a wave. </p>
        <p data-source-node="n179"> </p>
        <p data-source-node="n180">The following procedures describe how to print this document from the VAS Container: Insight Screen:</p>
        <ol data-source-node="n181">
            <li value="1" data-source-node="n182">Select an activity row that is associated with the shipment for which you want to print the VAS Activity List. <br data-source-node="n183"><br data-source-node="n184"></li>
            <li value="2" data-source-node="n185">Press the Print Selected Docs or Print Default Docs button as needed.<br data-source-node="n186"> </li>
            <ul data-source-node="n187">
                <li data-source-node="n188">If you select Print Selected Docs option, the system will display the Print Documents Window. <br data-source-node="n189"><br data-source-node="n190"></li>
                <li data-source-node="n191">If you select Print Default Docs option, the system prints the documents configured as "default" (with no further prompting).<br data-source-node="n192"><br data-source-node="n193">- Note that when multiple rows are selected in VAS insight, both options remain disabled. For more information, see the <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n194">Printing Paperwork</a> topic. <br data-source-node="n195"><br data-source-node="n196"></li>
            </ul>
            <li value="3" data-source-node="n197">Press the Submit Button. The system will print that shipment's VAS Activity List.</li>
        </ol>
