        <h4 data-source-node="n198"><a name="Creating" data-source-node="n199"></a>Creating 
 a Shipping Load...</h4>
        <p data-source-node="n200"> </p>
        <p data-source-node="n201">You can use the Add action in Shipping Load Insight to create a shipping load. When this action is invoked, the system will open to the Shipping Load Screen in new mode. The Shipping Load screen has the following sections:</p>
        <p data-source-node="n202"> </p>
        <h5 data-source-node="n203">Shipping Load Info </h5>
        <p data-source-node="n204">- You can use these fields to define various values that the system 
 will use to process a load.</p>
        <p data-source-node="n205"> </p>
        <h5 data-source-node="n206">Dates </h5>
        <p data-source-node="n207">- You can use these fields to define a load's planned/actual ship 
 or departure dates.</p>
        <p data-source-node="n208"> </p>
        <h5 data-source-node="n209">Status </h5>
        <p data-source-node="n210">- You can use these fields to view the leading and trailing statuses 
 of a load.</p>
        <p data-source-node="n211"> </p>
        <h5 data-source-node="n212">Consolidator </h5>
        <p data-source-node="n213">- You can use these fields to indicate the place where the shipping 
 load will delivered to, in lieu of its final destination (that is the "consolidator"). 
 The consolidator then would organize the particular shipments of a load 
 according to where they are to be delivered. The system references the 
 information on this tab only when generating a "consolidator" 
 master bill of lading.</p>
        <p data-source-node="n214"> </p>
        <h5 data-source-node="n215">Totals </h5>
        <p class="p_8" data-source-node="n216">- You can use these fields to view current 
 summary and unit of measure data about a load.</p>
        <p class="p_8" data-source-node="n217"> </p>
        <h5 data-source-node="n218">Reference Info</h5>
        <p class="p_8" data-source-node="n219">- You can use this section to view some additional information on a load. </p>
        <p data-source-node="n220"> </p>
        <p data-source-node="n221">After the mandatory fields are specified and saved, system displays a success message stating that the shipping load is created and the screen automatically gets refreshed to display the shipping load number that got generated. </p>
        <p data-source-node="n222"> </p>

        <p data-source-node="n331">This action allows you to change field values on the shipping load. When this action is selected, the system will open the Shipment Load Screen in edit mode.</p>
        <p data-source-node="n332"> </p>
        <h5 data-source-node="n333">Delete</h5>
        <p data-source-node="n334">This action allows you to delete a shipping load or multiple loads. Before deleting a load, you need to transfer its shipments to a different shipping load. You cannot delete a shipping load tied to shipments.</p>
        <p data-source-node="n335"> </p>
        <h5 data-source-node="n336">Close</h5>
        <p data-source-node="n337">This action enables you to close a shipping load or multiple loads. This is especially helpful when it is critical that new shipments are not added on the dock floor. When you close a shipping load, additional shipments cannot be added to it. It will only include those shipments previously assigned.</p>
        <p data-source-node="n338"> </p>
        <h5 data-source-node="n339">Confirm</h5>
        <p data-source-node="n340">This action enables you to  confirm a shipping load. The system allows one or more loads to be confirmed at a time. You cannot confirm a shipment if it has not been released from its wave. If a load contains both released and unreleased shipments, the system will ship confirm the released shipments, if the released shipments are in the correct status. However, neither the load nor the unreleased shipments will be confirmed. The unreleased shipments will have to be transferred to an alternate load, or removed from the load altogether. For more information on confirming shipments, see the topic <a href="1ddb11546762b120c182699cb150bf7e033c1b04a7fc1cccafed87f467e08b53.html" data-source-node="n341">Creating/Processing a Shipping Load</a>. </p>
        <p data-source-node="n342"> </p>
        <h5 data-source-node="n343">Print Preview</h5>
        <p data-source-node="n344">This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n345">Printing Paperwork</a>. </p>
        <p data-source-node="n346"> </p>
        <h5 data-source-node="n347">Print Default Docs</h5>
        <p data-source-node="n348">This action allows you to print the default shipping load documents that have both the print procedure for "load" setting and the default setting selected on the document’s document type record. </p>
        <p data-source-node="n349"> </p>
        <h5 data-source-node="n350">Print Selected Docs</h5>
        <p data-source-node="n351">This action allows you to print all the selected documents. </p>
