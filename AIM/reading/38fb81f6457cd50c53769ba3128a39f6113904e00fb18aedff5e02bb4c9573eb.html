Activating Inventory Attribute Validation

You can use this window to indicate if the system will force the user to select one of the pre-defined inventory attributes (defined on the Inventory Attribute Value configuration windows), or allow them to type in any value into the field. There are twenty separate attribute validation values, one for each of the twenty attributes that are tracked throughout the system.

 

NOTE: During processing, you will still able to leave the attribute value blank even if validation is active. This allows you to indicate that an attribute does not exist for some reason (even though validation is required).
