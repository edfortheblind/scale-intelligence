Using the Manual Labor Entry Screen

Apart from accessing this window from the Labor Management functional group, you can also invoke this window from the Action menu of Labor Activity Insight screen. You can use this window to log time for warehouse tasks that are not tracked by SCALE, such as cleaning aisles, taking breaks, etc. A warehouse worker would access this window, choose the work activity that they are going to perform, and then tell the system to start keeping tracking of the time spent on this activity.

 

 

Note that a specific user can only have the system track one Manual Labor Entry activity at a time. Also, an activity has to be stopped before another can be started.

Procedures: Starting a Manual Labor Activity...

Access the Manual Labor Entry Screen:

  1. Use the User Name Field to identify the user that will be performing the manual labor activity.
     
  2. Use the Activity Type Field to indicate the type of work activity that the user will be performing. Note that you will only be able to choose from activities that have a work type of 'Approved Indirect Labor', 'Approved Direct Labor', or 'Unapproved Indirect Labor'. Examples of these activities could include cleaning warehouse floors, taking breaks, or attending union meetings, and so on. When finished, you would again access this window and tell the system to stop tracking time.

     
  3. Press the Start Button. The system will begin keeping track of the time that this user is spending on the indicated activity.

 

Procedures: Stopping a Manual Labor Activity...

Access the Manual Labor Entry Screen: 

  1. Use the User Name Field to identify the user that is currently performing the manual labor activity. If this user is currently working on a 'started' activity, the system will display the activity's name and some detail information.
     
  2. If appropriate, use the activity type description field to enter information about the activity. For example, suppose a worker is cleaning location aisles. In the Work Type Window, this particular work type was defined to have a description of "Aisles Cleaned." On the Manual Labor Entry Screen, the system will display a field with the label of "Aisles Cleaned," and the user can enter a numeric value of how many aisles they actually cleaned. Note that the system does not require a value to be entered into this field.

  3. Use the Start Date/Time and End Date/Time Fields to view the time an activity started and ended (after an activity has been stopped).
     
  4. Use the Elapsed Time Field to view how long the user has been performing this activity. Note that the value in this field does not update unless you close and re-enter the Manual Labor Entry Screen.
     
  5. Press the Stop Button to have the system stop tracking the time worked on an activity. The system will generate a labor management detail record that indicates the total time that this user spent working on this activity (you can view this record in the Labor Activity Insight Screen).

  6. Press the Cancel Button if you just want to review the detail information about this user's activity, but do not want the system to stop tracking time.
