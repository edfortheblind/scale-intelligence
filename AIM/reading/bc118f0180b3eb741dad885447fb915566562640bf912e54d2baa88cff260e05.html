Create Warehouse Mobile menu

Create a new warehouse menu record by following the steps

 

  • Navigate to Menu >> System Management >> Activity Architect to view the Landing Page.
  • In the Landing page, click Actions >> Configuration button to view the Warehouse Mobile menu insight screen
  • Click Actions >> New to view the Warehouse Mobile menu screen.
  • The left pane displays all the section. Click to optionally close the left pane.
  • In Menu Option section enter Menu option name, Menu Resource Key, Form ID, Sequence, Object ID, Parent, SRC Identifier.
    • Also optionally toggle the warehouse menu created to be Active or not.
  • In Submenu section, enter Submenu name and submenu resource key details.
  • In User Defined section, add additional user defined fields using the ten User defined field 1 - 10.
  • Click Save.

 

Edit Warehouse Mobile menu

Follow the steps to edit a warehouse menu record.

  • Navigate to Menu >> System Management >> Activity Architect to view the Landing Page.
  • In the Landing page, click Actions >> Configuration button to view the Warehouse Mobile menu insight screen.
  • Enter search criteria and list the warehouse menu in the list pane.
  • Select the warehouse mobile menu record to be edited. Once selected, the record is highlighted on the screen.
  • Click Actions >> Edit to open the the Warehouse Mobile menu screen.
  • Modify the required fields in the Menu Option, Submenu and User defined sections.
  • Click Save.

Field Descriptions

 

Menu option name - The name of the menu option is displayed.

 

Menu resource key - This used as translated resource key.

 

Form Id - This indicates the menu resource key associated with parent menu record that does not have an SRC assigned.

 

Sequence - The value which will be displayed as sequence in menu.

 

Object ID - The unique identify for the new record created by the system

 

Parent- The name of the parent menu option used for child submenu option.

 

SRC identifier- The name of the SRC associated to the menu option

 

Active- You can toggle to make the SRC menu option active or not in Warehouse Mobile

 

System created- This identifier indicates whether the menu option was system created or manually created.

 

Submenu name- The name of the submenu associated with this menu option.

 

Submenu resource key- The translated resource key.
