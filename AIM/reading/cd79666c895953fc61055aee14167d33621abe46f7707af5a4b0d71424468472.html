Container Class Field

A container class allows you to link container types that share common characteristics, such as package category (carton, case, pallet, etc). All containers in a class share a UCC Code. If the system generates container IDs during packing, the container class occupies position 3 of the ID. In addition, if a vendor compliant label is produced for a container linked to this class and it includes a UCC-128 barcode, the container class occupies position 3 of the barcode.
