
        
        <h1 data-source-node="n56"><a name="kanchor518" data-source-node="n57"></a>Ascending/Descending Order Button</h1>
        <p data-source-node="n58">You will use this button to define how records selected by a criteria 
 rule set will be organized. A criteria rule set determines which records 
 the system will include in a particular process. For example, a wave criteria 
 rule set determines which shipment records will be included in a wave 
 and processed. The ascending/descending order button determines how the 
 system will organize these selected records. Generally, records are processed 
 in the order that they are organized.</p>
