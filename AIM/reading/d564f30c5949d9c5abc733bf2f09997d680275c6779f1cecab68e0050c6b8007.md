        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Shipping Calendar configuration defines carrier no-ship days used by routing and delivery commitment calculations. You can manage weekend exclusions and holiday dates, then associate the calendar to carrier records.</p>

        <h4 data-source-node="n68">Configure Shipping Calendar</h4>
        <p data-source-node="n69"> </p>
        <h5 data-source-node="n70">1. Shipping Calendar</h5>
        <p data-source-node="n71"> </p>
        <p data-source-node="n72">Select or create the shipping calendar record from the Shipping Calendar step.</p>
        <ul data-source-node="n73">
            <li data-source-node="n74">
                <p data-source-node="n75"><b data-source-node="n76">Create New</b>: Create a new calendar record.</p>
            </li>
            <li data-source-node="n77">
                <p data-source-node="n78"><b data-source-node="n79">View All</b>: Review and select an existing calendar record.</p>
            </li>
            <li data-source-node="n80">
                <p data-source-node="n81"><b data-source-node="n82">Current Selection</b>: Displays the selected shipping calendar record used by the carrier.</p>
            </li>
        </ul>
        <p data-source-node="n83"> </p>
        <h5 data-source-node="n84">A. General</h5>
        <p data-source-node="n85"> </p>
        <p data-source-node="n86"><b data-source-node="n87">Shipping Calendar</b>: Enter the calendar identifier.</p>
        <p data-source-node="n88"><b data-source-node="n89">Description</b>: Enter a description for the calendar.</p>
        <p data-source-node="n90"><b data-source-node="n91">Exclude All Saturdays</b>: Enable to mark Saturday as a no-ship day.</p>
        <p data-source-node="n92"><b data-source-node="n93">Exclude All Sundays</b>: Enable to mark Sunday as a no-ship day.</p>
        <p data-source-node="n94"> </p>
        <h5 data-source-node="n95">B. Holidays</h5>
        <p data-source-node="n96"> </p>
        <p data-source-node="n97">Review and maintain holiday entries linked to the selected calendar.</p>
        <ul data-source-node="n98">
            <li data-source-node="n99">
                <p data-source-node="n100"><b data-source-node="n101">Add New Holiday</b>: Create a new holiday date record.</p>
            </li>
            <li data-source-node="n102">
                <p data-source-node="n103"><b data-source-node="n104">Edit</b>: Update the selected holiday record.</p>
            </li>
            <li data-source-node="n105">
                <p data-source-node="n106"><b data-source-node="n107">Delete</b>: Remove the selected holiday record.</p>
            </li>
        </ul>
        <p data-source-node="n108"> </p>
        <h5 data-source-node="n109">B1. Define Holiday</h5>
        <p data-source-node="n110"> </p>
        <p data-source-node="n111"><b data-source-node="n112">Date</b>: Enter the no-ship holiday date.</p>
        <p data-source-node="n113"><b data-source-node="n114">Description</b>: Enter the holiday description.</p>
        <p data-source-node="n115"><b data-source-node="n116">Apply To All Calendars</b>: Enable to apply the holiday to all shipping calendars.</p>
        <p data-source-node="n117"> </p>
        <p data-source-node="n118">Use Back, Save, and Continue through the configuration steps, then Finish to complete shipping calendar setup.</p>
