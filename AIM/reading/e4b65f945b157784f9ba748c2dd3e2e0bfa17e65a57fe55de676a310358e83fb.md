
        
        <h1 data-source-node="n56"><a name="kanchor1952" data-source-node="n57"></a>Order Type Field</h1>
        <p data-source-node="n58">The order type associated with a specific 
 shipment or order. Order types indicate the overall characteristic of 
 an order and its status, such as 'Rush', 'Regular', 'Emergency' and 'Seasonal'. Order types are typically used to define a 
 wave. For example, you may want to create a wave type that only services 
 rush orders. This field also identifies the order type 
 associated with any value defined on the shipment record, such 
 as carrier, shipment date or customer. For example, you can use this field 
 to identify the order type associated with a particular carrier.</p>
