
        
        <h1 data-source-node="n56"><a name="kanchor407" data-source-node="n57"></a>Activating Items &amp; Carriers for Web Order Entry</h1>
        <p data-source-node="n58">In order for an item or carrier record to be available when entering 
 web orders, you first must activate it for web order entry. This is done 
 in the Item Window or the Carrier Window.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures: Window...</h4>
        <p data-source-node="n62">Access the Item Window. Open an item records.</p>
        <ol data-source-node="n63">
            <li value="1" data-source-node="n64">
                <p data-source-node="n65">Select the Internet Information Tab.</p>
                <p data-source-node="n66"> </p>
            </li>
            <li value="2" data-source-node="n67">Select the Available 
 For Web Order Check box. You will now be able to choose this item 
 when entering a web order.</li>
        </ol>
        <p data-source-node="n68"> </p>
        <h4 data-source-node="n69">Procedures: Carrier Window...</h4>
        <p data-source-node="n70">Access the Carrier Window. Open a carrier record.</p>
        <ol data-source-node="n71">
            <li value="1" data-source-node="n72">
                <p data-source-node="n73">Select the Internet Information Tab.</p>
                <p data-source-node="n74"> </p>
            </li>
            <li value="2" data-source-node="n75">Select the Available 
 For Web Order Check box. You will now be able to choose this carrier 
 when entering a web order.</li>
        </ol>
