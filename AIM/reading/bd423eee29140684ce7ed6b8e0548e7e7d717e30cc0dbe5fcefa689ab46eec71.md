        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59">Putaway configuration involves configuring locating rules, their sequence, location strategy and location selection. The locating rules will enable the system to locate a product. </p>
        <h4 data-source-node="n60"> </h4>

        <h4 data-source-node="n67"> Locating Rules Configuration</h4>
        <p data-source-node="n68"> </p>
        <h5 data-source-node="n69">1. Locating Rule Information</h5>
        <p data-source-node="n70">Enter the Name and Description. Optionally select Delayed Locating check box. This check box will be selected along with Create Work Putaway checkbox on receiving preferences. On selection, it indicates that this locating rule will temporarily locate the receipt container to the receiving pre-locate location. If either checkbox is unchecked, then the system locates based on the receipt container’s locating rule details.</p>
        <p data-source-node="n71"> </p>
        <p data-source-node="n72">Use the Sequence Field to indicate what order you want the system to process this rule detail. The lower the sequence number, the sooner it is processed. You cannot use the same sequence number for multiple detail records.</p>
        <p data-source-node="n73"> </p>
        <h5 data-source-node="n74">2. Add sequence record. </h5>
        <p data-source-node="n75"> </p>
        <p data-source-node="n76"><b data-source-node="n77">Strategy</b> - Select on of the location strategy for the sequence record. A locating strategy defines the system's methodology for selecting a storage location for checked in product. For example, if you select the strategy Consolidate, the system will attempt to locate the product in locations that already contain it.</p>
        <p data-source-node="n78"> </p>
        <p data-source-node="n79"><b data-source-node="n80">Location Selection</b> - A location selection record works with the strategy to help narrow the locations considered for locating. This minimizes processing time and increases your control over locating activity. The location selection can also have a sort defined, which the system will use to organize the locations selected for possible locating activity. Users can create a new location selection or select an existing record. Read Create location selection for more details.</p>
        <p data-source-node="n81"> </p>
        <p data-source-node="n82"><b data-source-node="n83">Sequence split quantity</b> -Select Yes or No. if Yes, this indicates that the system will fill a location and split the remaining item quantity to be located in a different location.</p>
        <p data-source-node="n84"> </p>
        <p data-source-node="n85">Note: The system cannot split a container that has serial numbers tied to it.</p>
        <ul data-source-node="n86">
            <li data-source-node="n87">
                <p data-source-node="n88">If Yes is selected, then the system will try to meet the requirements of the first locating rule. If it cannot, then the system will split off the remaining quantity and create a new receipt container, using the same values (such as unit of measure, dimensions, etc). The system will then try to locate the remaining quantity using the second locating rule. This will continue until all the product is located, or locating fails because all of the existing locating rules cannot be met.</p>
            </li>
        </ul>
        <ul data-source-node="n89">
            <li data-source-node="n90">
                <p data-source-node="n91">If NO is selected, then the system will try to meet the requirements of the locating rule(s). If it cannot, then locating will fail.</p>
            </li>
        </ul>
