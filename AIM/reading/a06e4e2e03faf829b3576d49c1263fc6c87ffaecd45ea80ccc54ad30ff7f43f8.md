
        
        <h1 data-source-node="n56"><a name="kanchor1896" data-source-node="n57"></a>Item Reference Field</h1>
        <p data-source-node="n58">This field indicates  how you want the TalkMan to handle item validation during the picking process.  If there is no check digit assigned to the work ID, this field will be used to indicate whether the user needs to speak the last 5 digits of the item ID or its cross reference number.</p>
