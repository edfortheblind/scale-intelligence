
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor1932" data-source-node="n58"></a>Intermediate Consignee</h1>
        <p data-source-node="n59">This setup allows you to define a secondary delivery destination, such as a port or logistics hub. It is particularly used when shipping via the UPS World Ease service. UPS provides a list of international hubs and corresponding postal code ranges for authorized users. Each of these hubs must be defined in SCALE as an intermediate consignee.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Consignee Address</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">Use the Account Number Field to identify the secondary delivery destination (intermediate consignee) to the carrier.</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65">UPS World Ease Note: For shipments using World Ease, this value is a ten-digit code provided by UPS that represents the hub address and its supported postal code range. During manifesting, SCALE sends this code to UPS for shipment grouping. These records are mandatory when using the World Ease service.</p>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67">Ensure the consignee's address and contact details are also provided in this record.</p>
