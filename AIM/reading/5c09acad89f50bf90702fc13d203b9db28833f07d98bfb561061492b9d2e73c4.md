
        
        <h1 data-source-node="n56"><a name="kanchor173" data-source-node="n57"></a>Researching Current User Activity</h1>
        <p data-source-node="n58">The application allows you the ability to view how many users are currently 
 online. When a user logs on/off of the system or an RF device, the system 
 will create a user activity record that records such user activity data 
 as logon time, last action time, and the device that the user is/was using. 
 This information is helpful if you want to research how the number of 
 current users are affecting the performance of the application server.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">You can research the following information on the User Activity Insight Screen:</p>
        <ul type="disc" class="ul_1" data-source-node="n61">
            <li data-source-node="n62">The number of concurrent users currently logged 
 onto the system, and information about these users.<br data-source-node="n63"> </li>
            <li data-source-node="n64">Information about a specific user who is currently 
 logged on, or was logged on in the past.</li>
        </ul>
        <p data-source-node="n65">Note that the application will also 
 track user activity data for "abnormal" logoffs, such as when 
 the client/server machine locks up, a user closes the RF browser window 
 without signing off, etc. This logoff activity record will be generated 
 by the WMMonitorService, which will periodically scan the user activity 
 database table in order to perform a logoff to any orphaned logon records. 
 This will allow you to view activity records for users that have been 
 "stranded" on a machine where the system application has locked 
 up.</p>

        <h4 data-source-node="n101"><a name="researching" data-source-node="n102"></a>Researching User Activity...</h4>
        <ol class="ol_1" data-source-node="n103">
            <li value="1" data-source-node="n104">Access the User 
 Activity Insight Screen from the system menu.<br data-source-node="n105"> </li>
            <li value="2" data-source-node="n106">Enter the user 
 that you want to research. If you leave this field blank, the system 
 will return results for all system users.<br data-source-node="n107"><br data-source-node="n108"></li>
            <li value="3" data-source-node="n109">Enter the specific 
 date span that you want to research user activity.<br data-source-node="n110"> </li>
            <li value="4" data-source-node="n111">Select the appropriate 
 user type:<br data-source-node="n112"><br data-source-node="n113">- Full Screen: Indicates that 
 you want results returned for all activity by full-screen system users.<br data-source-node="n114"><br data-source-node="n115">- RF: Indicates that you want 
 results returned for all activity by system RF device users.<br data-source-node="n116"><br data-source-node="n117"><br data-source-node="n118"><br data-source-node="n119">Note that the system does not track Trading Partner Management website 
 use through the User Activity Insight Screen. You can view this data on the Process History Insight Screen.<br data-source-node="n120"> </li>
            <li value="5" data-source-node="n121">Press the Apply button. 
 The system will display the results of your query in the list pane grid.</li>
        </ol>
