
        
        <h1 data-source-node="n56"><a name="kanchor755" data-source-node="n57"></a>Work Created Field</h1>
        <p data-source-node="n58">This field indicates that work was created for a replenishment request. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">There are four options: </p>
        <ul data-source-node="n61">
            <li data-source-node="n62">I (<i data-source-node="n63">Immediate</i>). "Immediate" is set when the Replenishment Work Creation Method is set to "None".  This indicates that the system has immediately moved the allocated inventory from the From location to the To location.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66">M (<i data-source-node="n67">Manual</i>). "Manual" is set when the Replenishment Work Creation Method on the Replenishment Master is set to "Manual".  A replenishment request set to "Manual" can have work created from the Replenishment Insight Screen.<br data-source-node="n68"><br data-source-node="n69"></li>
            <li data-source-node="n70"> N (<i data-source-node="n71">No</i>). "No" indicates that the work has not been created when initially creating the replenishment request.  This may be updated later once work creation has been run.<br data-source-node="n72"><br data-source-node="n73"></li>
            <li data-source-node="n74">Y (<i data-source-node="n75">Yes</i>). "Yes" is set when work has been created automatically.  The Replenishment Work Creation Method will be set to "Automatic" on the replenishment master.  This work is generated in the wave or when manually initiated from the Inventory Insight Screen.</li>
        </ul>
