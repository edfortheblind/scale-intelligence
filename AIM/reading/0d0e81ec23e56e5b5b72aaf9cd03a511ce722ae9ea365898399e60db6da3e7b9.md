
        
        <h1 data-source-node="n56">Meeting Additional Direct Mode Requirements</h1>
        <p data-source-node="n57">To interface data using direct mode, you will also need to complete 
 some programming activities to communicate table values between the ERP 
 and the system. Below is a list of the procedures that you need to address.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Procedures...</h4>
        <ol data-source-node="n61">
            <li value="1" data-source-node="n62">
                <p data-source-node="n63">Review the interface table 
 values. Determine which table values you want to interface (in addition 
 to the required values).</p>
                <p data-source-node="n64"> </p>
            </li>
            <li value="2" data-source-node="n65">
                <p data-source-node="n66">Determine where the data that you want to communicate is located 
 on the ERP system. This data should correspond with the values on the 
 system interface table.</p>
                <p data-source-node="n67"> </p>
            </li>
            <li value="3" data-source-node="n68">
                <p data-source-node="n69">Complete the custom logic to fill the system download 
 interface tables with the data selected at Step 2.</p>
                <p data-source-node="n70"> </p>
            </li>
            <li value="4" data-source-node="n71">Complete the custom logic to obtain values from 
 the system upload interface tables.</li>
        </ol>
