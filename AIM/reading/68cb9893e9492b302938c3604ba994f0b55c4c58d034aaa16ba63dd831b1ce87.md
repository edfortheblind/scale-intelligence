
        
        <h1 data-source-node="n56"><a name="kanchor2051" data-source-node="n57"></a>Account Number Field</h1>
        <p data-source-node="n58">This field identifies the secondary delivery destination (intermediate 
 consignee) to the carrier. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61"><b data-source-node="n62">Using 
 UPS World Ease...</b>
        </h5>
        <p data-source-node="n63">If you are using this field with the UPS World Ease service, it will 
 represent a ten-digit code supplied by UPS. This code represents a hub's 
 address and the postal code range that the hub supports. During the manifesting 
 process, SCALE will send this value to UPS so it can assign a group. </p>
