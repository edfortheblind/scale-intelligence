Maximum Quantity Field (a.k.a. Maximum Qty, Maximum Units)

A maximum quantity indicates the largest amount of X that can be included in an action, or placed in a location.

 

 

On the Work Creation Master...

This value defines the maximum quantity that can be included in a work unit.

 

Note that the system will not split a detail record as a result of the value in this field. For example:

  • Suppose the Maximum Quantity value is set to 5 EA on the shipment allocation work creation master record.

  • The shipment has six details (item 1 = 6 EA, item 2 = 6 EA, item 3 =3 EA, item 4 = 2 EA, item 5= 4 EA, item 6= 10 EA)

  • The first item will get added to the first work unit and the quantity =6. The system will not break the detail.

  • The second item will get added to the second work unit and the quantity = 6. The system will not break the detail.

  • The third and fourth items will get added to the third work unit.

  • The fifth item will get added to the fourth work unit.

  • The sixth item will get added to the fifth work unit. The system will not break the detail.

 

Note: There may be scenarios where work creation maximums do not break on the highest unit of measure due to limitations with decimal rounding. For example:

 

Work instructions will break on 5 CS, 5 CS, and 1 CS instead of 6 CS and 5 CS when the work instruction quantity is for 11 CS (462 EA).

The item unit of measure records are 1 CS = 42 EA, 1 PL = 252 EA, and 6 CS = 1 PL.

The system breaks on 5 CS instead of 6 CS due to automatic rounding when the system calculates the percentage of 1 CS of 1 PL (e.g., 42 EA/252 EA = 0.167).

 

On Adjustment Types...

This value identifies the maximum quantity that the user can adjust at one time. It is meant to prevent keying errors where the user mistakenly attempts to adjust an extremely high quantity. It is defined on the Adjustment Type Window.

 

 

On Item Location Capacity...

This value identifies the maximum number of one item (or item class) that can be stored in a location (or location type). This value is defined at the unit of measure level. For example, suppose you identified the maximum quantity as 50 and associated it with the Case UM. This record identifies that 50 cases can fit in the location.

 

 

On Waves...

This value identifies the most number of item units that can be processed in a particular wave.

 

 

On Putaway Location Groups...

This value identifies the most number of returned items that can be included in a particular putaway group. When this maximum value is met, the system will automatically close a putaway group. Note that a "unit" in this case is a single item; in other words, a unit at the Base UM. So, if you are checking in 1 case of 20 eaches, the system considers this as 20 units, not 1 unit.
