
        
        <h1 data-source-node="n56"><a name="kanchor1642" data-source-node="n57"></a>Planned Ship Date Field</h1>
        <p class="p_1" data-source-node="n58">This field indicates the original scheduled 
 ship date that was interfaced from the ERP. This value is not updated 
 by the system.</p>
        <p class="p_1" data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60"> </p>
        <h5 data-source-node="n61">Notes...</h5>
        <ul data-source-node="n62">
            <li data-source-node="n63">When the scheduled ship date is interfaced 
 from the ERP, the system defaults this value in the Planned Ship Date 
 Field.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66">When a shipment is copied or split, the Planned Ship Date of the original shipment is used on the resulting new shipment.</li>
        </ul>
