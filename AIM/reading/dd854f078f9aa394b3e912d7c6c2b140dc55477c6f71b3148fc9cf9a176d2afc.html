Value Type Field

A value type identifies how an accessorial choice will appear on the Accessorial Assignment Window.

 

The following are the value types that you can assign on the Accessorial Header Window:

Address

 

 

Indicates that the accessorial detail represents an address value. Using the Parent Field, you can associate other accessorial details (such as address lines, city, postal code, etc.) to a single "parent" address detail. See the Parent Field topic for more information.

 

Alpha

 

Indicates that the accessorial detail is an alphabetical value. This value type is usually reserved for special instructions.

 

Checkbox

 

Indicates that the accessorial detail displays a checkbox which the user can select or deselect. This is commonly used for accessorial services which are optional, such as Saturday Delivery.

 

Complex

 

Indicates that the accessorial detail has a complex structure.

 

Numeric

 

Indicates that the accessorial detail is a numeric value. This value type identifies the monetary amount levied to cover the accessorial task.
