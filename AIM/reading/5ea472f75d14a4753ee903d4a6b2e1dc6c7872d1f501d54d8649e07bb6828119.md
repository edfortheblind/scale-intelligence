
        
        <h1 data-source-node="n57"><a name="kanchor829" data-source-node="n58"></a>Default Build Location Field</h1>
        <p data-source-node="n59">This field identifies where the employee typically assembles finished 
 items. This value appears on the RF device as the To Loc Field for component 
 putaway; it appears as the From Loc Field for finished item putaway. It 
 is also included on the following paperwork:</p>
        <ul type="disc" class="ul_1" data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">Work Order Finished Item Putaway List</p>
                <p data-source-node="n63"> </p>
            </li>
            <li data-source-node="n64">
                <p data-source-node="n65">Work Order Pick List</p>
            </li>
        </ul>
        <p class="p_1" data-source-node="n66">NOTE: 
 The system uses this field's value as the work order build location (when 
 entering a work order),   if the 
 build location on the bill of materials is not specified.</p>
