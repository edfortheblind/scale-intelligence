Maximum Number of License Plates in a Location

This feature allows you to define the maximum number of license plates (LPs) that can be placed in a location.

Previously, SCALE allowed an unlimited number of LPs in an inventory location. With this enhancement, you can define a location-level limit that supports your warehouse picking and storage practices.

 

Configuration

 

A new configuration value, Max Number of License Plates, is available in the Location Wizard under Inventory Options.

  • Default value: 0 (unlimited LPs).

  • When set to a value greater than 0, the location enforces that maximum LP count.

The Max Number of License Plates value is available only when:

  • The location is configured to Track License Plates.

  • The location class is Inventory Storage.

 

Validation Rules

 

The number of LPs counted against a location’s maximum value is determined by the following rules:

  • Parent LP designation: A parent LP counts as 1 toward the location maximum. A parent LP is counted only once.

  • Standalone LP: A standalone LP counts as 1 toward the location maximum.

  • In-transit LPs: LPs in transit to the location are included in the maximum LP count (using the same parent/standalone counting logic).

 

System Behavior

  • If placing an LP keeps the location at or below the configured maximum, the placement succeeds.

  • If placing an LP would exceed the configured maximum, the placement is blocked and the user receives an error message.

 

Example

 

If MaxLP = 3 and the current LP count is 2, adding one more qualifying LP succeeds (count becomes 3).

If MaxLP = 3 and the current LP count is already 3, adding another qualifying LP fails (count would become 4).
