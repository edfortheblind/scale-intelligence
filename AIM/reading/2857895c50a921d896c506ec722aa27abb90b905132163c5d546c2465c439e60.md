
        
        <h1 data-source-node="n56"><a name="kanchor496" data-source-node="n57"></a>Delayed Locating Checkbox</h1>
        <p data-source-node="n58">The Delayed Locating checkbox, along with the Create Work Putaway checkbox on receiving preferences, indicates whether this locating rule will temporarily locate the receipt container to the receiving pre-locate location.  If either checkbox is unchecked, then the system locates based on the receipt container’s locating rule details.</p>
