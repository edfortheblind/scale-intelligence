Reviewing User Attributes System Values

These values determine if the system will validate values provided by the user for the user attribute fields on the User Profile Window. Ask your system consultant before changing any of these values.

System Value Descriptions...

Each of the system values listed below affects the validation of a user attribute field in the following manner:

  • When a system value is set to Y, the system will validate that the data user enters/selects in a user attribute field is one of the pre-defined values, and display an error if the value does not exist. Note that the system does allow the user to leave a user attribute field blank.

  • When a system value is set to N, the system will allow the user to freely enter any data into a user attribute field, or choose a pre-defined value.

 

NOTE: If you have validation turned off for an attribute, and users manually enter values for this attribute on the User Profile Window, if you then later choose to turn validation on, the system will not save these manually-added attribute values as part of the user profile. You would need to define user attribute records to represent these values in order to select them in a user profile (when attribute validation is turned on).
