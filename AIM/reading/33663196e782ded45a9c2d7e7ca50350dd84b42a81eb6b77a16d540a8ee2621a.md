        <p data-source-node="n58">This field associates this action with a work type. The system will 
 generate a labor management record (labeled with the selected work type) 
 when the load confirmation process needs to execute any outstanding open 
 work instructions. The system needs to address these outstanding instructions 
 before it can confirm a load.</p>
