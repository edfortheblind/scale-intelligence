
        
        <h1 data-source-node="n56"><a name="kanchor597" data-source-node="n57"></a>Error Message Field</h1>
        <h5 data-source-node="n58">On the DIF Incoming/Outgoing Message Insight screen...</h5>
        <p data-source-node="n59">This field displays an error message (written by the DIF Messaging Service) that describes why an incoming or outgoing message failed processing.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">On the Interface Error Insight Screen / Interface Validation Warehouse Alerts...</h5>
        <p data-source-node="n63">This field reflects the same error message that is included with an interface XML error file, i.e. the text that is enclosed by the ERROR nodes in the XML.</p>
