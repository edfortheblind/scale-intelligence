Show Container Contents Toggle

This toggle indicates if the system will display the contents of a container, in addition to the container's "header" information, as separate record(s) in the Shipping Container Insight Screen. Note that the system defaults this toggle as not selected.

  • If this toggle is selected, the system will display a record that represents the actual container AND a record for each item packed in that container. The item-level records will have a dash ("-") as the value for the Container Type Field.

  • If this toggle is not selected, the system will only display actual container records.
