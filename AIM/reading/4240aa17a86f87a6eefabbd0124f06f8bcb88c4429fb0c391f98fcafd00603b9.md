
        
        <h1 data-source-node="n56">System Built Cart Picking - Process</h1>
        <p data-source-node="n57">The system directed cart building process enables the application to assign containers created in a wave to a cart when the user initiates the work unit using Warehouse Mobile. This enables the system to include on carts containers that were created after the initial day’s wave(s) have been run. Also, the system tries to assign containers to the cart in an order (configured by zone) that will provide an optimum walking path when the worker picks products into the cart. This improves the picker(worker) efficiency by reducing the picking time against the manually assigned containers to the cart.</p>

        <h4 data-source-node="n67"><a name="Configurations" data-source-node="n68"></a>Configurations</h4>
        <p data-source-node="n69">System Build carts need the following configuration. </p>
        <p data-source-node="n70"> </p>
        <p data-source-node="n71"><b data-source-node="n72">Work Profile &gt;&gt; Work Processing</b> Tab </p>
        <p data-source-node="n73"> </p>
        <p data-source-node="n74">Work Initiation method - Select <b data-source-node="n75">Cart Picking</b>. The following two options are available for the selection</p>
        <ul data-source-node="n76">
            <li data-source-node="n77">
                <p data-source-node="n78"><b data-source-node="n79">System-built carts</b> - Select for the system to assign containers to a cart at the time of work initiation</p>
            </li>
            <li data-source-node="n80">
                <p data-source-node="n81"><b data-source-node="n82">Cart spots</b> - Define the size of the cart. The value determines the number of spots present in the cart.  One container per spot is allowed by the system.</p>
            </li>
        </ul>
        <p data-source-node="n83"><b data-source-node="n84">Zone &gt;&gt; Cart Building</b> tab</p>
        <ul data-source-node="n85">
            <li data-source-node="n86">
                <p data-source-node="n87"><b data-source-node="n88">Zone sequence</b> - This sequence value enables the system to optimize the walking order for various work zones in the warehouse for the picker. This improves the picking time and efficiency.</p>
            </li>
        </ul>
        <h4 data-source-node="n89"><a name="Using" data-source-node="n90"></a>Using Warehouse Mobile - Work Execution</h4>
        <p data-source-node="n91"> </p>
        <ol data-source-node="n92">
            <li value="1" data-source-node="n93">Tap <b data-source-node="n94">Work Execution</b> to view the <b data-source-node="n95">Select Work Profile</b> screen.</li>
            <li value="2" data-source-node="n96">Select system build cart picking work profile from the menu.</li>
            <li value="3" data-source-node="n97">
                <p data-source-node="n98">The system will analyze the eligible work units, and build the cart assigning a shipping container to each spot.</p>
            </li>
            <li value="4" data-source-node="n99">
                <p data-source-node="n100">The system will next display the Build Cart screen, which will display each spot and what container (ID, type) that is assigned to each cart spot. You then will physically build the cart before proceeding to the next screen.</p>
                <ol data-source-node="n101">
                    <li value="1" data-source-node="n102">Cart Spot - Value of cart spot</li>
                    <li value="2" data-source-node="n103">Container type - type of container is displayed</li>
                    <li value="3" data-source-node="n104">Container ID - last four digits of the container is displayed. </li>
                </ol>
            </li>
            <li value="5" data-source-node="n105">
                <p data-source-node="n106">When you are finished placing the containers on your cart, tap <b data-source-node="n107">Go</b>, and the system will display the first work instruction in the Pick confirmation screen. You can then move with the cart to complete picking in the warehouse</p>
            </li>
        </ol>
        <p data-source-node="n108">Note:</p>
        <ul data-source-node="n109">
            <li data-source-node="n110">
                <p data-source-node="n111">If there are no eligible work units for system-built carts, the system will display the Build Cart screen with no spots assigned.</p>
            </li>
        </ul>
        <ul data-source-node="n112">
            <li data-source-node="n113">
                <p data-source-node="n114">If you press the Back button on the Build Cart screen, the system will return to the Work Profile Selection screen. The cart that the system just built will stay built.</p>
            </li>
        </ul>

        <h4 data-source-node="n116"><a name="Process" data-source-node="n117"></a>Criteria for System Cart Building</h4>
        <p data-source-node="n118">The application uses the following criteria to decide the work/containers that will be assigned to a cart during the work creation process.</p>
        <p data-source-node="n119"> </p>
        <p data-source-node="n120">1. Priority - The least numbered priority work units are allotted first. For example, priority with value 2 is processed first then with value 10.</p>
        <p data-source-node="n121"> </p>
        <p data-source-node="n122">2. Minimum and Maximum Work Zone - The work unit header record has the Minimum (lowest ) and Maximum (highest) zone sequence values. The system will take these zones the from locations of the instructions on the work unit.</p>
        <p data-source-node="n123"> </p>
        <p data-source-node="n124"><b data-source-node="n125">Note:</b>
        </p>
        <ul data-source-node="n126">
            <li data-source-node="n127">
                <p data-source-node="n128">The system will ignore the work units that does not have the Minimum/Maximum zone sequence configured. </p>
            </li>
            <li data-source-node="n129">
                <p data-source-node="n130">If there is only one work instruction on a work unit, then the Minimum Work Zone and Maximum Work Zone values will be identical.</p>
            </li>
            <li data-source-node="n131">
                <p data-source-node="n132">Zone sequence value is NULL on the work zone record, the system will ignore that zone when determining the Minimum/Maximum zone values.</p>
            </li>
        </ul>
        <p data-source-node="n133">3. Aging Date/Time</p>
        <p data-source-node="n134">This value represents the date/time the work was created. The older the work unit is created; it is considered first for cart building assignment.</p>
