
        
        <h1 data-source-node="n56"><a name="kanchor212" data-source-node="n57"></a>UPS Summary Bar Code Label</h1>
        <p data-source-node="n58">The UPS Summary Bar Code Label is a label that displays UPS summary 
 manifest information and a UPS 
 bar code. You can also print a UPS Summary Manifest at the same time as 
 this label (if configured in the Rating System Values Window). This label is Progistics-generated. The system can automatically generate 
 this label after you close a manifest. You can also manually print it 
 from a closed manifest in the Manifest Insight Screen. Note that the system provides 
 a document type record for this label that supports both the new version 
 of the UPS server (indicated by the word "TAN" in parenthesis) 
 and the previous UPS server.</p>
