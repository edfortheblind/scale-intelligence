        <h4 data-source-node="n199"><a name="Searching" data-source-node="n200"></a>Searching/Viewing Cycle Count Request Records...</h4>
        <p data-source-node="n201">You can use the Cycle Count Request Insight Screen to search for and view cycle count request records in your warehouse. </p>
        <ol data-source-node="n202">
            <li value="1" data-source-node="n203">Open the Cycle Count Request  Insight Screen.<br data-source-node="n204"><br data-source-node="n205"></li>
            <li value="2" data-source-node="n206">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n207"><br data-source-node="n208"></li>
            <li value="3" data-source-node="n209">Press the Search Button. The system will display  the resulting records in the List Pane. <br data-source-node="n210"><br data-source-node="n211"></li>
            <li value="4" data-source-node="n212">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>

        <h4 data-source-node="n233"><a name="AboutDPane" data-source-node="n234"></a>About the Detail Pane...</h4>
        <p data-source-node="n235">The Cycle Count Request  Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.<br data-source-node="n236"><br data-source-node="n237"></p>
        <p data-source-node="n238">The Detail Pane of Cycle Count Request  Insight contains Indicator Tiles with counts of the other entities (i.e. open work).  If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following: </p>
        <ol data-source-node="n239">
            <li value="1" data-source-node="n240">Open Work<ol data-source-node="n241"><li value="1" data-source-node="n242">Displays the open cycle count work based on the work group cycle counting. </li><li value="2" data-source-node="n243">Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse, internal count number, and internal number type.</li><li value="3" data-source-node="n244">The internal number type is Cycle Count.<br data-source-node="n245"></li></ol></li>
            <br data-source-node="n246">
            
        </ol>

        <h4 data-source-node="n255"><a name="Screen" data-source-node="n256"></a>Screen Actions</h4>
        <p data-source-node="n257">The following actions are accessible from the List Pane:</p>
        <p data-source-node="n258"> </p>
        <p data-source-node="n259"> </p>
        <h5 data-source-node="n260">Delete</h5>
        <p data-source-node="n261">The action allows you to delete one or more cycle count requests. The system will prompt for a confirmation message after the delete action is performed. </p>
        <p data-source-node="n262"> </p>
        <p data-source-node="n263"> </p>
        <h5 data-source-node="n264">Confirm</h5>
        <p data-source-node="n265">This action allows you to confirm the cycle count request(s). Selecting the record (s) and invoking the action will show a confirmation message and  success message is shown after the request is confirmed.</p>
        <p data-source-node="n266"> </p>
        <p data-source-node="n267"> </p>
        <h5 data-source-node="n268">Reconcile</h5>
        <p data-source-node="n269">This action allows you to reconcile the cycle count request. The action is enabled for the cycle count requests which are in 'pending review' status or with 'open' status only if the cycle count request is created without work. Selecting the cycle count request and invoking the action opens the Cycle Count Reconcile screen. Refer to the topic <a href="f2525d356a78d56ce268321ce6192fd66106ddd02604c28d27e8a9a9bd3ef739.html" data-source-node="n270">Reconciling Cycle Counts (Insight Screen &amp; RF)</a> for additional information. </p>
