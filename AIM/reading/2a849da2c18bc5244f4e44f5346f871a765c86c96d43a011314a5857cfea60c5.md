        <h4 data-source-node="n246"><a name="pickingNotes" data-source-node="n247"></a>Picking Notes...</h4>
        <ul data-source-node="n248">
            <li data-source-node="n249">It is highly recommended that you do not confirm decimal quantities of serial number tracked items when picking.<br data-source-node="n250"><br data-source-node="n251"></li>
            <li data-source-node="n252">
                <p data-source-node="n253">When short picking an inventory serial number tracked item when the for "Short Pick Inventory Action" inventory control value  is set to "No count, remove all unallocated on hand quantity" or "No count, remove transaction quantity", the system will remove serial numbers to match the quantity being removed from the location.  Note that it will NOT prompt the user for which serial numbers are to be removed, it will simply just choose them.  To avoid this, you will need to configure this system value to one of the "Count" options so that the inventory gets moved to Suspense and a cycle count gets generated.</p>
            </li>
        </ul>

        <h4 data-source-node="n258"><a name="CompletedByUser" data-source-node="n259"></a>Setting the Completed By User...</h4>
        <p data-source-node="n260">This only updates the Completed by User field on the work instruction header and detail. This does not confirm the work instruction.</p>
        <p data-source-node="n261"> </p>
        <ol data-source-node="n262">
            <li value="1" data-source-node="n263">Open the Work Insight Screen. <br data-source-node="n264"><br data-source-node="n265"></li>
            <li value="2" data-source-node="n266">Select a work instruction detail and click on Completed By User from the actions menu.<br data-source-node="n267"><br data-source-node="n268"></li>
            <li value="3" data-source-node="n269">

                <ul data-source-node="n273">
                    <li data-source-node="n274">If selecting the work instruction header, the system will update the Completed by User field on all the work instruction details for the header with the selected user.<br data-source-node="n275"><br data-source-node="n276"></li>
                    <li data-source-node="n277">

                    </li>
                    <li data-source-node="n281">The system will update the Completed by User field on work instruction header with the user setting the completed by user on the work instruction details.  This is the user signed into the Work insight.<br data-source-node="n282"></li>
                </ul>

        <h4 data-source-node="n289"><a name="Confirming" data-source-node="n290"></a>Confirming a Work Instruction...</h4>
        <p data-source-node="n291">The procedures below describe how to confirm work using the Work Insight 
 Screen. Confirmations would typically be completed from this screen when users are 
 working off of paper pick lists (or some other non-RF) method. The system 
 will not allow you to confirm a work unit using this window if any of its details reside 
 at a P&amp;D location. </p>
        <p data-source-node="n292"> </p>
        <p data-source-node="n293">You can confirm one or more work instruction headers or details  using the Confirm action from the actions menu. Confirming a single work instruction detail shows the Pick Confirmation Screen to confirm a full, partial, or short pick.</p>
        <p data-source-node="n294"> </p>
        <p data-source-node="n295">You will be prompted to enter a serial number when the confirmed work instruction detail contains items that are tracked by serial numbers and the confirmed quantity is less than the entire quantity at the from location.  If the To license plate is required, you will be prompted to enter the license plate when confirming single or multiple work instructions (details or headers). </p>
        <p data-source-node="n296"> </p>
        <h5 data-source-node="n297">Note About Work Profiles and Work Types</h5>
        <p data-source-node="n298">If your user profile has a default work profile specified, then the work types defined on the profile details are the work types that you will be authorized to confirm in the Work Insight Screen.  If there is no default work profile specified, then you will be authorized to confirm all work types on all work profile details that you are authorized to.</p>
        <p data-source-node="n299"> </p>
        <p data-source-node="n300"> </p>
        <h5 data-source-node="n301">Procedures</h5>
        <ol data-source-node="n302">
            <li value="1" data-source-node="n303">
                <p data-source-node="n304">Open the Work Insight Screen.</p>
                <p data-source-node="n305"> </p>
            </li>
            <li value="2" data-source-node="n306">
                <p data-source-node="n307">Select one or more work instruction headers or details and click on Confirm from the actions menu.</p>
            </li>
            <p data-source-node="n308"> </p>
            <li value="3" data-source-node="n309">If confirming multiple work instruction headers or details, you will be prompted on whether to confirm the work or not. <br data-source-node="n310"><br data-source-node="n311">- Upon pressing Yes, the selected work instruction details will be confirmed and closed. Confirming a work instruction header will confirm all the open and in process work instruction details belonging to the header.<br data-source-node="n312"><br data-source-node="n313"></li>
            <li style="font-style: normal" value="4" data-source-node="n314">If confirming a single work instruction detail, you will see the Pick Confirmation Screen.   You will be prompted to enter a serial number when the confirmed work instruction detail contains items that are tracked by serial numbers and the confirmed quantity is less than the entire quantity at the from location. You can confirm a full, partial, or short pick from this screen.<br data-source-node="n315"><br data-source-node="n316"> - Clicking the Confirm option without adjusting the quantity will confirm a full pick.<br data-source-node="n317"><br data-source-node="n318"> - Clicking the Confirm option after decreasing the quantity will confirm a partial pick.<br data-source-node="n319"><br data-source-node="n320"> - Clicking the Short pick option after decreasing the quantity and selecting a reason code will confirm a short pick. <br data-source-node="n321"><br data-source-node="n322"></li>

The confirmed work instruction(s) will be set to Closed.  Unconfirmed instructions on the work unit will be set to In Process.  Upon confirming the last work instruction on the work unit, the header will also be closed.<br data-source-node="n325"><br data-source-node="n326"></p>

        <p data-source-node="n333">You can edit a work instruction that is in a status of open or in process. 
 This is especially helpful if you want to change the instruction's detail 
 information. The system will update the work unit to reflect your changes. 
 If the instruction will be processed from pick lists (non-RF), you should 
 reprint the pick lists and labels to ensure accuracy. Note that you cannot edit 
 a closed work instruction.</p>
        <ol data-source-node="n334">
            <li value="1" data-source-node="n335">Open the Work Insight Screen, and access the work 
 instruction record that you want to edit.<br data-source-node="n336"><br data-source-node="n337"></li>
            <li value="2" data-source-node="n338">Select the Edit
 Action. The system will display the Work Instruction Screen. You 
 can then edit the instruction's values. The system will only allow editing 
 to certain fields.<br data-source-node="n339"><br data-source-node="n340"></li>
            <li value="3" data-source-node="n341">When finished, 
 press the Save button. The system will accept your changes and close the window.</li>

        <h4 data-source-node="n346"><a name="Holding" data-source-node="n347"></a>Holding a Work Instruction...</h4>
        <p data-source-node="n348">If you release a wave that contains an instruction that's not yet ready 
 to be processed, you can add a hold code on it. The system will not allow 
 anyone to process a work unit that is on hold. The procedures below assume 
 that the wave which generated the work unit(s) was released 
 to the warehouse.</p>
        <ol data-source-node="n349">
            <li value="1" data-source-node="n350">Open the  Work Insight Screen. Access the work unit 
 that you want to hold. You can place a hold any work unit that is either  Open or In Process.                   When you place a work unit on 
 hold, the system will not allow anyone to commit work against this unit. 
 This is especially helpful if when you want to assign the work to another 
 employee.<br data-source-node="n351"><br data-source-node="n352"></li>
            <li value="2" data-source-node="n353">Select the Hold 
 Action. The system will display the Work Hold Screen.<br data-source-node="n354"><br data-source-node="n355"></li>
            <li value="3" data-source-node="n356">In the Hold Code 
 Field, provide an appropriate reason for the hold. Values defined 
 in this field are not validated by the system, so you may enter any value.<br data-source-node="n357"><br data-source-node="n358"></li>
            <li value="4" data-source-node="n359">Press OK, and 
 the system will place this instruction on hold. </li>
        </ol>
        <h5 data-source-node="n360">Removing a Hold Code from a Work Instruction</h5>
        <p data-source-node="n361">If a hold code is placed on a work instruction and the wave has been released, the system will allow the hold code to be removed. However, if the removal of the hold code would cause the inventory to go into a negative status, the hold cannot be removed. Note that if a hold code is placed on a work instruction and the wave has not been released, the system will not allow the hold code to be removed. </p>

        <h4 data-source-node="n440"><a name="Deleting" data-source-node="n441"></a>Deleting a Work Instruction...</h4>
        <p data-source-node="n442">The procedures below describe how to delete a work instruction from 
 the Work Insight screen. When deleting 
 a work instruction tied to a shipment, the system will update the shipment the work is tied 
 to; specifically, the header, detail(s), and container(s). The system determines the shipment line statuses using the "Default Status When Shipment Is Rejected" outbound status action. </p>
        <p data-source-node="n443"> </p>
        <p data-source-node="n444">A work instruction cannot be deleted if the work is not closed, is active, is on an unreleased wave, the work was generated by replenishment or an inventory transfer AND its quantity is allocated at the To Location, or the work was created from shipment allocation requests, and the allocation request is linked to a shipment line with an associated shipping container. </p>
        <p data-source-node="n445"> </p>
        <ol data-source-node="n446">
            <li value="1" data-source-node="n447">
                <p data-source-node="n448">Open the Work Insight screen.</p>
                <p data-source-node="n449"> </p>
            </li>
            <li value="2" data-source-node="n450">
                <p data-source-node="n451">Access the work instruction 
 record that you want to delete.</p>
                <p data-source-node="n452"> </p>
            </li>
            <li value="3" data-source-node="n453">Select the Delete 
 Action, and the system will display 
 a confirmation message. Verify that you want to delete this work 
 unit. The system (depending on what type of work the instruction is, and 
 what status it is in) may or may not allow you to delete the instruction. 
<br data-source-node="n454"><br data-source-node="n455"></li>
            <li value="4" data-source-node="n456">Press Yes, and the system will delete the instruction and any inventory allocations created 
 to support it.</li>
        </ol>
