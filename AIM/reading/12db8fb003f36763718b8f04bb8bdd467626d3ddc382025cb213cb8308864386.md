
        
        <h1 data-source-node="n56"><a name="kanchor838" data-source-node="n57"></a>Commitments Required For Routing Checkbox</h1>
        <p data-source-node="n58">This checkbox identifies how the system will make a carrier decision 
 during routing, when a particular carrier is part of a carrier group. 
 The following is based on when a carrier commitment record does 
 not exist for a certain carrier:  </p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">If this checkbox 
 is checked, commitments are required for this carrier. Therefore, 
 the system will reject this carrier because no commitment record exists.<br data-source-node="n61"> </li>
            <li data-source-node="n62">If this checkbox 
 is not checked, that indicates that commitments are not required 
 for this carrier. Therefore, the system will not reject the carrier. However, 
 a large number of days to deliver is used (999), which makes it almost 
 impossible for that carrier to "win" the selection process and 
 be assigned to the shipment.</li>
        </ul>
