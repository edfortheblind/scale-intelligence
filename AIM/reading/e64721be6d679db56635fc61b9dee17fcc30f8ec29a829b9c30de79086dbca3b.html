Developer Hub

Developer Hub website details customers with tutorials and code samples for SCALE extensibility.

 

The website is accessible in the following ways.

 

Direct Website

 

Users with Manhattan credentials can log in to the developer hub website.

  • URL: scale.developer.manh.com.

 
Using SCALE Application

  • Enable the Developer Hub security permission for the user.

  • Navigate to Menu >> System Management >> Developer hub.
