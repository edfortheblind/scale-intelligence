
        
        <h1 data-source-node="n57"><a name="kanchor2041" data-source-node="n58"></a>Reviewing Web System Values...</h1>
        <p data-source-node="n59">The web system values should only be reviewed or edited by a member 
 of your IT staff or a system consultant. The system is shipped with the 
 most common default values which should meet your business needs. Do not 
 change any of the system-defined values unless you first talk to your 
 system consultant.</p>
        <p data-source-node="n60"> </p>
