
        
        <h1 data-source-node="n56">Determining Maximum Number of Search Records</h1>
        <p data-source-node="n57">When the system searches for history records, it retrieves up to a maximum 
 number that you define on the Technical Values Window. This limits the 
 strain on the system as it does not have to search for unwanted records. 
 The default maximum value is 1000 records. Note that the system will display 
 only the first records it retrieves before it reaches the maximum number. 
 To retrieve the most recent records available, you will have to narrow 
 your search further by using the criteria fields.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Procedures...</h4>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">Access the Technical Values Window. </p>
        <ol data-source-node="n63">
            <li value="1" data-source-node="n64">Select the following 
 value: "Record Number Displayed in Insight and Lookups" 
 (#160). This value defines the maximum amount of history records you want 
 the system to display:<br data-source-node="n65"> </li>
            <ul type="disc" class="ul_1" data-source-node="n66">
                <li class="li_1" data-source-node="n67">
                    <p data-source-node="n68">To limit the number of records, enter a whole number in the field. For example, if you enter the value 
 1000 in this field, the History Insight screens will only display the first 
 1000 records it finds that meet your search criteria.</p>
                    <p data-source-node="n69"> </p>
                    <p data-source-node="n70">NOTE: This value also applies to other system search windows, 
 such as quick find and lookup windows.</p>
                    <p data-source-node="n71"> </p>
                </li>
                <li class="li_1" data-source-node="n72">To see all 
 the records that meet your criteria, enter a "0" in the field. Note that this may affect system 
 performance, depending on how many records the system will need to retrieve 
 from the database.</li>
            </ul>
            <p data-source-node="n73"> </p>
        </ol>
