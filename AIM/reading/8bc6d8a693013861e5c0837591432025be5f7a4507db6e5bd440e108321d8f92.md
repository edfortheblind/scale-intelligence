
        
        <h1 data-source-node="n56"><a name="kanchor2103" data-source-node="n57"></a>Days Between Cycle Counts Field</h1>
        <p data-source-node="n58">This field indicates when the next time a cycle count should be performed 
 on this location. The last cycle count date is stamped on the location, 
 and a new request should not be created until the value in this field 
 has exceeded that date. These dates are only used for activity-driven 
 cycle counts.</p>
