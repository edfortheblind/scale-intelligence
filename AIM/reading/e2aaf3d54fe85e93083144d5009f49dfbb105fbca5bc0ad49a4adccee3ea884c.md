
        
        <h1 data-source-node="n56"><a name="kanchor126" data-source-node="n57"></a>Creating Shipping Interface Upload Criteria Records</h1>
        <p data-source-node="n58">You will use shipping interface upload criteria records to determine the following:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">Which shipment/shipment line upload records that the system will place in the upload directory defined on the interface process detail.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">Which shipments the system will write header/detail upload records when a certain trailing status is met and that status is defined to include in the interface upload.</li>
        </ul>
        <h5 data-source-node="n64"> </h5>
        <h5 data-source-node="n65">Notes</h5>
        <ul data-source-node="n66">
            <li data-source-node="n67"> These criteria records apply to the shipping upload interface only.<br data-source-node="n68"><br data-source-node="n69"></li>
            <li data-source-node="n70">
                <p data-source-node="n71">The system will upload the shipment data using these records only as the shipment's status changes from one value to the next.  The upload will not happen on the initial download of the shipment (regardless of whether that status has been configured for upload).</p>
            </li>
        </ul>
