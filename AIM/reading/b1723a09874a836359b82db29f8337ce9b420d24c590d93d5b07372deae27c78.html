Defining Web Users

Before customers can access their order information through Trading Partner Management, you must first configure them as a web user. The system supports two types of users: external and internal:

  • External User: Has access to certain company(s) information. An external user is not employed by your organization. You can restrict an external user's access to one customer (via a customer ID) or a series of customers (via the customer group value). Common external users include customers, business partners and suppliers. These people need access only to their own shipments. You will need to associate an external user to either a customer ID or a customer group value to view shipment information.
     
  • Internal User: Has a greater freedom of access, based on how you define his/her web user profile. An internal user who is employed by your organization. You can use the Assigned Companies Tab and Assigned Customer ID Tab to limit the internal user's access; if you don't use these tabs to set limits, external users have access to all shipments in the system. These people can use Trading Partner Management to access any shipment in the system.

Using the Header Fields
  1. Use the Web User Field to identify the user name. He/she will use this name to logon to the Trading Partner Management website.

 

Using the General Tab

  1. Use the Email Address Field to enter the user's email address (for example, customer@store.com). This field supports up to 500 characters. It is mandatory, else a validation message will be displayed. Also, duplicate email addresses in the web user configuration records are not allowed.

     

  2. Use the User Type Field to indicate the type of web user you are defining (external or internal).
     
  3. Use the Order Processing Field to indicate how you want the system to handle orders that are entered via Trading Partner Management.

    - Automatic: If you choose this method, the system will automatically create the orders for this user through Trading Partner Management. No additional user intervention is required.

 

Using the Company Access Tab

Use this tab to identify which companies this user can access shipments for. The fields displayed on this tab will depend on whether you chose to create an external or internal user. Generally, external users should be associated with only one company; internal users are typically associated with multiple companies.

  • If this is an external user, you will need to assign him/her a customer ID, a customer group, and/or a vendor. This is required for external users to view their own order information. If this is a multi-company environment, the customer ID, along with the company, determines what orders this user can access.

     

  • If this is an internal user, associate him/her with a company if you want to limit access to only order information for customers of that company. Internal users will have access to all the customers of whichever company(s) they are authorized to view.

 

Using the Ship to Selection Access Tab
  • Use this tab to identify which order ship to selection record that you want this user to have access to when entering web orders. These records contain the rules for selecting a series of ship to addresses for your order.

 

Using the Item Selection Access Tab
  • Use this tab to identify which order item selection record that you want this user to have access to when entering web orders. These records contain the rules for selecting a series of item(s) for your order.
