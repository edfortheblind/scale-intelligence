Activity Type Field

On the Billing Management Window...

This field identifies the description for the activity type of a Billing Management trigger header record. This text description can be any value you choose, as long as it corresponds to this value in Billing Management. This value corresponds to Billing Management's ActivityType field.

 

 

On the Labor Activity Insight Screen...

This field indicates the work type associated with a particular labor activity record. Note that non work related activities (such as nesting or close container) will use a text resource value to indicate the "work type" for labor activities. Labor Activity Insight Screen allows filtering by free format text on Activity type. See the Labor Tracking Values document for more details.

 

 

On the Manual Labor Entry Screen...

This field identifies a manual labor activity that has a work type of "Approved Indirect Labor", "Approved Direct Labor", or "Unapproved Indirect Labor."
