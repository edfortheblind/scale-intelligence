Creating Inventory Attribute Values

The application features twenty separate inventory attribute configurations, with each representing one of the twenty inventory attribute values that the system tracks in various functional areas. You will use these configurations to define a list of attributes values that can be selected from a drop-down field during processing. For example, if you create three "country of origin" values (United States, Canada, Mexico) in the Inventory Attribute 01 configuration, then these three country values will appear as selectable options in the Inventory Attribute 01 field on the appropriate processing screen (RF receiving, RF location inquiry).

 

NOTE: You will still need to activate the validation of these attributes in order for the system to force the user to select one of the pre-defined values on processing screens.
