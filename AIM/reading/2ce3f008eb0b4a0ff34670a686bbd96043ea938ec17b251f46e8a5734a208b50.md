
        
        <h1 data-source-node="n56"><a name="kanchor1583" data-source-node="n57"></a>Shipment Level Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates if you want to retrieve 
 information based on Pro Number. If you do not select this checkbox, the 
 system will retrieve information based on tracking number. Generally, 
 you will select this checkbox for LTL and truckload carriers, and NOT 
 select this checkbox for parcel carriers.</p>
