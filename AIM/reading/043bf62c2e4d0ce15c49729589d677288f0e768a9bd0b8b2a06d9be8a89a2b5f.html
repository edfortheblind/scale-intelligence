Allow Over Picking Checkbox

Use this checkbox to allow the user to pick more quantity than exists on a work instruction, as long as this quantity is within the location's available quantity. When an over pick is performed, the system will increment the transaction quantity, and process the pick as a complete/normal pick. Note that this option is only available for RF replenishment and work order picking.

 

 

Example

For example, suppose a work order component work instruction calls for 980 eaches of an item. It may be easier physically, then, for the worker to pick two cases of 500 (for a total of 1,000 eaches) rather than breaking one case open and leaving 20 eaches loose at the location. If this checkbox is checked, the system will increment the instruction by 20 eaches, and process the pick as normal.
