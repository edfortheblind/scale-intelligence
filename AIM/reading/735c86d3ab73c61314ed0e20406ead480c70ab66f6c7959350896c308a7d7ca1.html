Location Class Field

This field identifies a location's class, which is a predefined value that identifies the purpose of a warehouse's location. In other words, these represent the general "categories" of locations. 

 

Below is a list of the system defined location classes:

  • Equipment - You will not manually assign this location class value. The system assigns it to equipment during the picking process. It creates an equipment location ID by concatenating the equipment type and the user name. This location class and ID are only assigned while the equipment is transporting inventory.

     

  • Inventory - You will assign this location class to all locations used to store product in your warehouse.

     

  • P&D - You will assign this location class to all P&D (pickup and dropoff) locations. These locations can be used as intermediate locations while moving product between locations.

  • Put-To-Store - You will assign this location class to locations at or near the shipping dock where loose item quantities are placed, when their final destination is a specific store (shipment line mark for). Each put-to-store location is assigned to a specific store via the configurations.
     
  • Receiving Dock - You will assign this location class to the receiving dock location.

  • Receiving Pre-Check In - You will assign this location class to temporarily hold all downloaded receipt containers that are interfaced into the system. This is a place (not a physical location but rather a system "bucket") where interfaced inventory can reside in before it arrives into the receiving dock. When the actual container arrives at the warehouse, the system will place this container in an inventory status of "Check In Pending." When the container is checked in, the system will place it in a "Locate Pending" status.

  • Receiving Pre-Locate - You will assign this location class to hold product that has been checked into the warehouse, but has not yet been located (using the delayed locating functionality).
     
  • Shipping Dock- You will assign this location class to create dock locations (packing, staging, and dock door). This is used for outbound dock locations only.
     
  • Work Order Build - You will assign this location class to locations used to perform work order build actions.
