Setup Overviews: Cross-Application

Below are lists of the setup procedures required to use the cross-application functional areas.

 

NOTE: Actions without hyperlinks can be performed by your Manhattan Associates representative.

 

 

Desktop Setup...

  1. Review Desktop layout records
  2. Review Desktop functional groups
  3. Create Desktop templates
  4. Add Custom Links to the Desktop

 

 

Global Paperwork...

  1. Review the internal print procedures
  2. Define the document types
  3. Create document templates
  4. Define documents
  5. Define all print devices
  6. Define default printers on the user profile
  7. Identify a documents label and print driver (on the Print Device Window)
  8. Define document routing records
  9. Define comment types
  10. Associate comment types with document types
  11. Review detail data source values
  12. Review paperwork filter records
  13. Create document criteria records

 

 

Group Picking...

  1. Define the picking location group that identifies the locations/work zones where a pick group can operate
  2. Define the picking group record and link the appropriate picking location groups to it

 

 

GS1 Barcode Setup...

Inbound RF Processing

  1. Review application identifiers
  2. Define application identifier template
  3. Enable GTIN on Item/Item Cross Reference
  4. Require GS1 Scan on Receiving Preference

 

 

Outbound Label Generation...

  1. Enable GTIN on Item/Item Cross Reference
  2. Configure the GS1 label according to the Global Paperwork or Wave-Specific Paperwork setup steps.

 

 

Immediate Needs...

  1. Review the immediate needs system values
  2. Maintain the immediate needs triggers
  3. Make an item eligible for immediate needs

 

 

Initial System Setup...

  1. Create environments
  2. Define warehouses
  3. Define companies
  4. Define all system users

 

 

Picking Management...

  1. Activate picking management for the appropriate work type(s)
  2. Activate picking management for the appropriate work zone(s)

 

 

RF Device...

  1. Review the RF screen properties
  2. Review the RF-related work system values

 

 

RF Group Picking...

  1. Create a group picking work sequence record

 

 

SQL Server Reporting Services Documents...

  1. Define a document as an SSRS document
  2. Define a document type’s rendered PDF file directory
  3. Define a warehouse's rendered PDF file directory

 

 

Wave-Specific Paperwork...

  1. Complete the global paperwork steps on the appropriate windows (see "Global Paperwork Setup")
  2. Define which wave records require paperwork
  3. Define document masters
  4. Create label masters
  5. Associate a master to the appropriate wave master 

 

 

Window Security...

  1. Create Security Records

 

 

Work Creation...

  1. Create work groups
  2. Create work types
  3. Review the work creation processes
  4. Define which requests will become work (using work criteria records)
  5. Define how work is generated
  6. Create each work creation record on the Work Creation Master Window

 

 

Work Execution...

  1. Review zone types
  2. Create work zones
  3. Establish work teams
  4. Create advanced user profiles
  5. Define equipment types
  6. Define work profiles
  7. Define specific handling rules
  8. Define estimated work rates records
  9. Review the work system values
  10. Define text messages
  11. Associate text messages
  12. Configure/Display Interfaced RF Text Messages
  13. Escalate Work Record Priority
