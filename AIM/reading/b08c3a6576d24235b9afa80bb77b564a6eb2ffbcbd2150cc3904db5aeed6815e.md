
        
        <h1 data-source-node="n56"><a name="kanchor1680" data-source-node="n57"></a>Reviewing Image Capture Reference Types</h1>
        <p data-source-node="n58">The <b data-source-node="n59">Image capture reference types</b> generic configuration determines the list reference types found on the Save image screen for a given reference category.</p>
        <p data-source-node="n60">By default the system have the <i data-source-node="n61">RECEIPTID</i> and <i data-source-node="n62">LICENSEPLATE</i> reference types for the RECEIVING reference category. The generic configuration supports up to five reference types. </p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64">Extending references types can be done by adding another reference type. For example, if capturing the trailer id is required, a TRAILERID reference type can be added to the Receiving category reference types. Trailer id will now be available in the list of reference types on the Warehouse Mobile - Save image screen.</p>
