
        
        <h1 data-source-node="n56"><a name="kanchor1919" data-source-node="n57"></a>Email Sent Field</h1>
        <p data-source-node="n58">This field indicates whether or not the system has sent an interface validation warehouse alert email for a certain error message. Note that this field may have an "I" value if the system is currently in the process of sending the email.</p>
