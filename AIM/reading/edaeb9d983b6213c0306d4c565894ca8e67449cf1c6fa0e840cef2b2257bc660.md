
        
        <h1 data-source-node="n56"><a name="kanchor1980" data-source-node="n57"></a>Escalating Work Record Priority</h1>
        <p data-source-node="n58">You will use work priority escalation records to define what work records (header and detail) are eligible for priority updating by the work priority escalation scheduled job. When this scheduled job is started, it first goes to the database and determines which records are eligible for updating. Next, the system will update these records' priorities.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Having work record priority updated (post-creation) is helpful when you want to make sure that certain shipment's work is prioritized over others. </p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">Configuring this work escalation priority process has two steps: defining the eligibility criteria and defining the time interval/parameters of the escalation scheduled job. For more details on the work priority escalation scheduled job, see the topic <a href="89cd7c907a14ac69519371eda239e33c8578f7f1e4049b7feebd15cb21bfc537.html" data-source-node="n63">Creating a Scheduled Job</a>.</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65">Note that running this scheduled job is optional.</p>
        <p data-source-node="n66"> </p>

        <p class="p_12" data-source-node="n103">Below are the procedural steps for configuring the eligibility criteria and scheduled job settings for work escalation priority:</p>
        <p class="p_12" data-source-node="n104"> </p>
        <p class="p_12" data-source-node="n105"> </p>
        <h4 data-source-node="n106">Step 1: Define the Criteria For Eligibility...</h4>
        <ol class="ol_1" data-source-node="n107">
            <li value="1" data-source-node="n108">Using the Filter 
 Data Tab: You can use this tab to identify which criteria values the system will use to choose the work instructions/units that will be eligible for priority escalation. For example, suppose that filter value defined on the criteria rule is a work type of Shipment Work, and your warehouse has three work types configured in the system (Shipment Work, Receiving Work, and Work Order Work). When the priority escalation job runs, the system would then bring back all records (work instructions/units) with a work type of Shipment Work.<br data-source-node="n109"> </li>
            <li value="2" data-source-node="n110">When finished, 
 press OK. The system will save your work priority selection criteria record.</li>
        </ol>
        <p data-source-node="n111"> </p>
        <h4 data-source-node="n112">Step 2: Define Scheduled Job Interval/Parameters...</h4>
        <ol data-source-node="n113">
            <li value="1" data-source-node="n114">On the Scheduled Job Window's Scheduling Tab, you will first need to define the interval at which the work escalation priority job will run. See the topic <a href="89cd7c907a14ac69519371eda239e33c8578f7f1e4049b7feebd15cb21bfc537.html" data-source-node="n115">Creating a Scheduled Job</a> for more details on this procedure.<br data-source-node="n116"><br data-source-node="n117"></li>
            <li value="2" data-source-node="n118">On the Scheduled Job Window's Parameters Tab, you will next need to define the specific job settings for the  work escalation priority job.  See the topic <a href="89cd7c907a14ac69519371eda239e33c8578f7f1e4049b7feebd15cb21bfc537.html" data-source-node="n119">Creating a Scheduled Job</a> for more details on this procedure.</li>
        </ol>
