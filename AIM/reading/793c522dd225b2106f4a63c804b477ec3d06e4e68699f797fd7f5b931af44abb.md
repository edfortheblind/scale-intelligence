                <td colspan="1" rowspan="1" class="td_15" data-source-node="n96">
                    <p data-source-node="n97">Delay Between Running Auto Logout Check 
 (In Hours): This value indicates the delay (in hours) between times 
 that the WMMonitorService will run an auto logout check. For example, 
 if you define this value for 5 hours, the system will wait that long before 
 checking the user activity database table for user records that do not 
 have a "logoff" record. If this record does not exist, the service 
 will generate a logoff record.</p>

                </td>
                <td colspan="1" rowspan="1" class="td_15" data-source-node="n102">
                    <p data-source-node="n103">Lack Of Activity Period For Auto Logout 
 (In Days): This value indicates the delay (in days) the lack of 
 activity period a user has to have to be eligible for an auto logout from 
 the application. Once a user can be logged off, the WMMonitorService will 
 automatically logoff the user (according to the value described above). 
 For example, if you define this value for 3 days, a user will have to 
 be logged onto the system for this duration of time before this user will 
 be available for the WMMonitorService to automatically logoff.</p>
