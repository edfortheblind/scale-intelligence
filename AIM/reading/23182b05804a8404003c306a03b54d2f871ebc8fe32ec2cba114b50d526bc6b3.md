
        
        <h1 data-source-node="n56"><a name="kanchor1393" data-source-node="n57"></a>Before You Begin: Using the Generic Config Header</h1>
        <p data-source-node="n58">The Generic Config Header is a "menu" of all of the generic 
 configurations in the system. You can access these windows from the record 
 list. This is also the only place in the system where you can create a 
 new generic config in the system. However, if there is no code behind 
 this new database table, it will not do anything. See your system consultant 
 for more information on creating new generic configurations. For more information on this window, see the topic <a href="445667c2178c3c3239d7ae2e3c68242365f87e743b756a6129d0bee2ec64e6b0.html" data-source-node="n59">Generic 
 Config Header Window</a> in the Navigating the system section of the help.</p>
