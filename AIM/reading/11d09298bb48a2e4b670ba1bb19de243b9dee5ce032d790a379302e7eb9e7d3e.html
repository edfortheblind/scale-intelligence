Split Shipment Mode Field

This field indicates how you want the system to split shipments/loads when a worker encounters a situation where a split is needed:

- Prompt: This option will offer the user to decide (during confirmation) from the three options described below.

 

- Split Shipment: This option will only confirm that portion of the shipment that is in a Ready For Ship Confirm status (as defined by the high status in your Shipping Preferences). Any portion of the shipment that is not in this status will be split off to a new shipment with the same shipment ID.

 

- Split Shipment If Not In Range: This option will confirm the entire shipment as long as it is in the status range defined in your Shipping Preferences. The system will, if needed, update work as details and containers are transferred to new shipments. If any part of the shipment is outside the status range, this portion will be split off to a new shipment with the same shipment ID.

 

- Do Not Split Shipment: This option will not confirm any portion of the shipment if any quantity is in a status less than Ready For Ship Confirm (as defined by the high status in your Shipping Preferences). The shipment will instead be transferred to an alternate load.
