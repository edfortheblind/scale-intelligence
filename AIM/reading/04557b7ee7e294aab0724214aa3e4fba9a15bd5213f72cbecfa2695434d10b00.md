
        
        <h1 data-source-node="n56"><a name="kanchor869" data-source-node="n57"></a>Shipment Pack List with BOM Components</h1>
        <p data-source-node="n58">A shipment pack list with BOM components displays all the same information 
 as a regular "Shipment Pack List with Containers", except it will also display 
 as lines any work order components associated with the shipment. 
 If there is no work order associated with a shipment's line, but it 
 does have a bill of materials created for it, the system then would print 
 the components from the bill of materials. Also, the bill of material 
 components will always appear immediately following the parent item regardless 
 of how you have the document sorted. You may manually print a shipment 
 pack list with BOM components from the Shipment Insight.</p>
