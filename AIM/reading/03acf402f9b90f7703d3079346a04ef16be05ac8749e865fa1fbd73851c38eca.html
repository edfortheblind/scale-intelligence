Group Picking Work Sequence

Group Picking Work Sequence determines the order in which work units within a picking group are executed, aiming to maximize efficiency. When work units are assigned to a transport container, the system uses this configuration to decide the optimal picking sequence.

 

  • Sequence - Determines the processing priority (lower numbers are processed first).

  • Order By Field to indicate the order you want the system to process though your sequence records.

    • Ascending: Choose this option if you want the work units to be processed in ascending order.

    • Descending: Choose this option if you want the work units to be processed in descending order.

  • Attribute Field to indicate what value you want to sequence work units by. For example, you could choose to sequence the work units by From Location, which would allow you to pick all of the item(s) that reside in the same location first.
