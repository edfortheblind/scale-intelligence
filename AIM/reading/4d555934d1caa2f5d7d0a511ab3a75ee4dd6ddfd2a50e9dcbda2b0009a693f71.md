
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Consolidation Location</h1>
        <p data-source-node="n58">You can use this configuration to set up consolidation locations, which are non-inventory-tracked areas consisting of one or more positions. These typically represent a physical packing station or a designated area near a packing station.</p>
        <p data-source-node="n59">When you assign a detail or container from a shipment to a consolidation location, the system automatically assigns all related details or containers from that shipment to the same location.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Create Consolidation Location record.</p>
        <ul data-source-node="n62">
            <li data-source-node="n63">
                <p data-source-node="n64"><b data-source-node="n65">Warehouse</b> - Select the warehouse where the new location will be created.</p>
            </li>
        </ul>
        <ul data-source-node="n66">
            <li data-source-node="n67">
                <p data-source-node="n68"><b data-source-node="n69">Location Area</b> - Choose the area within the warehouse where this location should be placed.</p>
            </li>
        </ul>
        <ul data-source-node="n70">
            <li data-source-node="n71">
                <p data-source-node="n72"><b data-source-node="n73">Position Range</b> - Define the position(s) for the location</p>
                <ul data-source-node="n74">
                    <li data-source-node="n75">
                        <p data-source-node="n76">To create a single position, enter the same position name in both fields.</p>
                    </li>
                    <li data-source-node="n77">
                        <p data-source-node="n78">To create a range of positions, enter the first and last positions in the respective fields.</p>
                    </li>
                </ul>
            </li>
            <li data-source-node="n79">
                <p data-source-node="n80">Note: Each location must have at least one position.</p>
            </li>
        </ul>
        <ul data-source-node="n81">
            <li data-source-node="n82">
                <p data-source-node="n83"><b data-source-node="n84">Check Digit</b> - Enter the check digit workers must input to confirm they are at the correct location.</p>
            </li>
        </ul>
        <p data-source-node="n85"> </p>
        <p data-source-node="n86">Toggle Buttons</p>
        <ul data-source-node="n87">
            <li data-source-node="n88">
                <p data-source-node="n89"><b data-source-node="n90">Generate Check Digit</b>  indicate that you want the system to automatically generate check digits for this location.</p>
            </li>
        </ul>
        <ul data-source-node="n91">
            <li data-source-node="n92">
                <p data-source-node="n93"> <b data-source-node="n94">Multi Shipment</b>  - indicate that you can have more than one shipment residing in a particular consolidation location.</p>
            </li>
        </ul>
