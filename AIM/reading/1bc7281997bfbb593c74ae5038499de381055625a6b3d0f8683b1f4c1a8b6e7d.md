
        
        <h1 data-source-node="n56"><a name="kanchor2066" data-source-node="n57"></a>Sequence Field</h1>
        <p data-source-node="n58">This field indicates the order in which the system will process steps 
 or records. The lower the number, the sooner the record is processed. 
 Sequences are typically used in system automated tasks, such as wave processing, 
 allocation, replenishment or work creation, among others.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">On the Bill of Materials and Other Work Order-Related 
 Windows...</h5>
        <p class="p_1" data-source-node="n62">Sequence indicates the order that the user 
 should complete a step, not the system.</p>
        <p class="p_1" data-source-node="n63"> </p>
        <p class="p_1" data-source-node="n64"> </p>
        <h5 data-source-node="n65">On the Storage Template Window...</h5>
        <p class="p_1" data-source-node="n66">Note that if you change the sequence when 
 adding a new storage template detail record, the system will only set 
 the sequence number to one number higher than the highest value currently 
 in your record list. For example, suppose you already have sequences "1" 
 and "2" defined, and you change the sequence on the record you 
 want to add to a "5". The system will still add the record with 
 a sequence number of "3". Furthermore, if you try to insert 
 a new record in between two existing steps (i.e., numbers "1" 
 and "2"), the system would renumber the existing step "2" 
 as "3", and the new step would be assigned the number "2." 
 </p>
        <p class="p_1" data-source-node="n67"> </p>
        <p class="p_1" data-source-node="n68"> </p>
        <h5 data-source-node="n69">On the Application Identifier 
 Template Window...</h5>
        <p class="p_1" data-source-node="n70">This field indicates where in the barcode 
 that the system will expect this segment to appear in. </p>
        <p class="p_1" data-source-node="n71"> </p>
        <p class="p_1" data-source-node="n72"> </p>
        <h5 data-source-node="n73">On the Exit Point Parameters Window...</h5>
        <p class="p_1" data-source-node="n74">This field indicates the order of the parameters that are passed by an exit point.</p>
