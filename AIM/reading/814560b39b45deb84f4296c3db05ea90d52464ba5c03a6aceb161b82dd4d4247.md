
        
        <h1 data-source-node="n56"><a name="kanchor1146" data-source-node="n57"></a>Defining Item Templates</h1>
        <p data-source-node="n58">An item template determines when non-alpha numeric separators, such 
 as dashes or dots, should be added in an item number string. It also determines 
 the structure of all item numbers associated with the template. The structure 
 includes the number of characters in an item number string and when a 
 letter or a number is required. Later, you will associate each template 
 with the appropriate items on the Item Window. The system will validate 
 the Item ID against the item template: if the item number structure must 
 match the template structure. For example, if the template requires the 
 following structure: ## - ### - ##, the system will require that the item 
 number include 7 numbers. The system will not associate this template 
 with a number that includes any letters, or less than 7 numbers.</p>

        <h4 data-source-node="n88">Procedures...</h4>
        <ol data-source-node="n89">
            <li value="1" data-source-node="n90">
                <p data-source-node="n91">Use the Item Template Field 
 to identify this record.</p>
                <p data-source-node="n92"> </p>
            </li>
            <li value="2" data-source-node="n93">
                <p data-source-node="n94">Use the Separator Field to 
 identify the text character you want inserted between the item number 
 segments. </p>
                <p data-source-node="n95"> </p>
            </li>
            <li value="3" data-source-node="n96">
                <p data-source-node="n97">For each template segment, you will need to define two values. Use the Length Field to define how many 
 numbers should come before the separator. For example, if you define the 
 value 4 here, the system will insert the separator after the first four 
 numbers are displayed: 1234-. Use the 
 Type Field to define what type of values should be displayed before 
 the separator: letters (alpha) or numbers (numeric).</p>
                <p data-source-node="n98"> </p>
            </li>
            <li value="4" data-source-node="n99">Press OK, 
 and the system will save your template.</li>
        </ol>
