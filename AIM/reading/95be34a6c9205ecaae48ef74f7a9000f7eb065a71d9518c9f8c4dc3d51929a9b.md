
        
        <h1 data-source-node="n56"><a name="kanchor1696" data-source-node="n57"></a>Open Work Field</h1>
        <h5 data-source-node="n58">On the Manual Inventory Adjustment Window...</h5>
        <p data-source-node="n59">This field indicates the total open work (classified as both "open" 
 and "in process") that exists for a particular item. This includes 
 all types of work except cycle count work. The system will only calculate this value if you did not include a location 
 value in your search.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">On the Inventory Insight Screen...</h5>
        <p data-source-node="n63">Clicking on the Open Work Indicator Tile takes you to Work Insight displaying the work instructions associated with this item/company/warehouse/location/lot/license plate.</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">On the Shipping Container Insight Screen...</h5>
        <p data-source-node="n67">Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the warehouse, instruction type detail, parent container ID (when the parent container ID is selected), and internal container number fields (when the child container ID is selected). The list displays the number of open or in process work for the selected shipping container to the lowest level.</p>
        <p data-source-node="n68"> </p>
        <p data-source-node="n69"> </p>
        <h5 data-source-node="n70">On the Work Insight Screen...</h5>
        <p data-source-node="n71">The Open Summary Tile indicates the  number of work instruction details with the Open condition.</p>
        <p data-source-node="n72"> </p>
        <p data-source-node="n73"> </p>
