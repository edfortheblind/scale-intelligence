
        
        <h1 data-source-node="n56"><a name="kanchor1659" data-source-node="n57"></a>Item Category 1-10 Fields</h1>
        <p data-source-node="n58">These fields are used to store special user-defined information. You 
 can define up to ten of these categories and associate them to an item 
 record. Item categories are used in the 
 order entry module to indicate such custom values as value-added inserts 
 (catalogs, promotional gifts, etc.), special handling instructions, pay 
 terms, or any other user-defined message/label. Note that these values 
 are not validated by the system.</p>
