
        
        <h1 data-source-node="n56"><a name="kanchor1635" data-source-node="n57"></a>laAccessorial Code Field</h1>
        <p data-source-node="n58">This code represents an accessorial category (Accessorial Type) , which 
 is an additional charge levied for special carrier handling, such as <span class="span_1" data-source-node="n59">Saturday Delivery</span> or    <span class="span_1" data-source-node="n60">COD</span>.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">An accessorial category may have subcodes (a.k.a. "subcategories"). 
 For example, the category <span class="span_1" data-source-node="n63">COD</span> 
 includes such subcategories (Accessorial) as    <span class="span_1" data-source-node="n64">COD Amount</span>,    <span class="span_1" data-source-node="n65">COD Instructions</span>, or    <span class="span_1" data-source-node="n66">COD 
 Number</span>.</p>
