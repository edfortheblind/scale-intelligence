
        
        <h1 data-source-node="n57"><a name="kanchor57" data-source-node="n58"></a>To Quantity Field</h1>
        <p data-source-node="n59">This field identifies the quantity that should 
 be delivered to the to location. </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">The value in this field is dependent on the status of the instruction:</p>
        <ul data-source-node="n62">
            <li data-source-node="n63">
                <p data-source-node="n64">If the instruction has not been 
 picked, this field will contain the value '0'.</p>
                <p data-source-node="n65"> </p>
            </li>
            <li data-source-node="n66">
                <p data-source-node="n67">If the instruction is currently 
 being processed, this field will contain the amount of product 
 in transport to the 'to' location.</p>
                <p data-source-node="n68"> </p>
            </li>
            <li class="li_1" data-source-node="n69">If 
 the instruction has been confirmed, this field will contain the 
 value '0'.</li>
        </ul>
        <p data-source-node="n70"> </p>
        <p class="p_1" data-source-node="n71"> </p>
