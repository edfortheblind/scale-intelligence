Defining Advanced Allocation Records

Advanced allocation records allow the allocation process to use percentages when attempting to allocate quantity for a shipment line (this process is sometimes called variable quantity or percent allocation). The allocation process will only look in one location (or one license plate in one location) when performing advanced allocation. You will define these minimum/maximum percentages on the Advanced Allocation Window. It is also possible to manually indicate that a shipment line should use the advanced allocation process, whether an advanced allocation record exists for this item or not. You can indicate the minimum/maximum percentages that will be used for this line only.

Procedures...

 

Using the Header Fields

Open the Advanced Allocation Window. Create a new record.

  1. Select the Item Class Button if you want to define an advanced allocation record for an entire item class.

    OR

    Select the Item Button if you want to define an advanced allocation record for a specific item.

 

Using the General Tab Fields
  1. Use the Allocate Full Location Quantity Checkbox to indicate if you want the system to attempt to find a location where it can allocate the exact amount that is required for the shipment line. If the system does not find this location, allocation will fail.
     
  2. Use the Allow Percent Allocation Checkbox to indicate that you want the system to use the advanced allocation process when attempting to allocate quantity on a shipment line. To use this percentage allocation, you will need to enter values for the minimum and maximum percentage fields (as described below).
     
  3. Use the Minimum and Maximum Allocation Percentage Fields to indicate the thresholds that the system should use for performing variable quantity allocation. Note that these percentage fields refer to the line quantity, not the location's quantity. For example, suppose you define an advanced allocation record for Item A (garden hose), and indicated that you want to allow percent allocation. A customer then orders 100 feet of garden hose:

    - If the Minimum Percentage=100% and the Maximum Percentage=110%, then the system would be able to allocate a quantity of Item A in the range of 100 to 110 feet.

    - If the Minimum Percentage=100% and the Maximum Percentage=100%, then the system would have to allocate the exact quantity of Item A (100 feet).

    NOTE: If both these percentages are set to 100%, then the system will need to find the exact detail quantity to allocate from a location, or allocation will fail.

  4. Press OK. The system will create your record.

 

Important Note

If you create an advanced allocation record that has both the Allocate Full Location Quantity and the Allow Percent Allocation checkboxes not selected, the system will allocate this item/item class as if an advanced allocation record did not exist.

 

 

Example Scenarios...

Suppose you have an item defined in the application that requires advanced allocation processing, such as a garden hose.

 

Scenario 1 - One Location Fulfills Allocation

The item has the following advanced allocation settings:

Allocation Full Location Quantity Checkbox = not selected

Allow Percent Allocation Checkbox = selected

Minimum Allocation Percentage = 95%

Maximum Allocation Percentage = 110%

1. You have a shipment line that requires 25 Feet of garden hose.

 

2. When the system attempts to allocate quantity for 25 Feet of an item, it finds that there is a location/license plate available with this item:

Location

LP001

25 Feet

3. Therefore, allocation would succeed because a unique location/license plate does not currently exist that meets the minimum allocation percentage range (which in this case would be 23 Feet).
