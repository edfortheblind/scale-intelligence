
        
        <h1 data-source-node="n56">Reviewing Rate Bases</h1>
        <p data-source-node="n57">You will use this configuration to view a table of rates used in calculating the freight charges for LTL shipments. The system looks at the LTL class of the shipment, the weight of the shipment and the rates per weight break  to calculate the freight charge. Rate bases point to a table of rates that a carrier uses to rate a shipment. The SCALE system determines the rate base to be used based on various criteria of the shipment:</p>
        <ul data-source-node="n58">
            <li data-source-node="n59">Company</li>
            <li data-source-node="n60">Carrier</li>
            <li data-source-node="n61">Carrier Service</li>
            <li data-source-node="n62">Origin Postal Code</li>
            <li data-source-node="n63">Destination Country</li>
            <li data-source-node="n64">Destination Postal Code</li>
            <li data-source-node="n65">Effective Date</li>
        </ul>
        <p data-source-node="n66">In addition, the 'Carrier Rate Base Assignment Criteria' window can be used to include shipment information in the selection of the rate base. Any field on the shipment can be included in the selection criteria for the rate base.</p>

        <h4 data-source-node="n109">Using the Header Portion...</h4>
        <ol data-source-node="n110">
            <li value="1" data-source-node="n111">Use the Rate Base Field to point to the table of rates that a carrier uses to rate a shipment.<br data-source-node="n112"><br data-source-node="n113"></li>
            <li value="2" data-source-node="n114">Use the Description Field to describe the rate base record. <br data-source-node="n115"><br data-source-node="n116"></li>
            <li value="3" data-source-node="n117">Use the Weight Breaks Field to represent the name of the record being defined for LTL weight breaks. This record is used by the Rate Base Configuration which contains the actual values for the weight breaks. This field is input capable when no rate base detail records exist.</li>
            <p data-source-node="n118">
                <br data-source-node="n119">
            </p>
            <li value="4" data-source-node="n120">Use the Minimum Charge Weight Break Field to contain the weight used to determine the minimum charge break amounts used on the Rate Base configuration. This field is defined on the Weight Break window.<br data-source-node="n121"><br data-source-node="n122"></li>
            <li value="5" data-source-node="n123">Use the Minimum Charge Less Than Break Field to determine the minimum charge for the shipment if the total weight of the shipment is less than the 'Minimum Charge Weight Break' field. If it is, the system uses this amount. If it is more, then it uses the value in the 'Minimum Charge Greater Than or Equal to Break' Field. This field is located in both the header and detail levels of the rate base record. If there is a value defined in this field on the detail level of the rate base record, the value in the detail level field with be used.<br data-source-node="n124"><br data-source-node="n125"></li>
            <li value="6" data-source-node="n126">Use the Minimum Charge Greater Than Or Equal To Break Field to determine the minimum charge for the shipment if the total weight of the shipment is greater than or equal to the 'Minimum Charge Weight Break' field. If it is less, then the system uses the 'Minimum Charge Less Than Break Field' amount. This field is located in both the header and detail levels of the rate base record. If there is a value defined in this field on the detail level of the rate base record, the value in the detail level field with be used.<br data-source-node="n127"></li>
        </ol>
        <p data-source-node="n128"> </p>
        <h4 data-source-node="n129">Using the General Tab...</h4>
        <ol data-source-node="n130">
            <li value="1" data-source-node="n131">Use the LTL Class Field for the LTL class associated with an NMFC code.<br data-source-node="n132"><br data-source-node="n133"></li>
            <li value="2" data-source-node="n134">Use the Minimum Charge Less Than Break Field to determine the minimum charge for the shipment if the total weight of the shipment is less than the 'Minimum Charge Weight Break' field. This field is located in both the header and detail levels of the rate base record. If there is a value defined in this field on the detail level of the rate base record, the value in the detail level field with be used.<br data-source-node="n135"><br data-source-node="n136"></li>
            <li value="3" data-source-node="n137">Use the Minimum Charge Greater Than Or Equal To Break Field to determine the minimum charge for the shipment if the total weight of the shipment is greater than or equal to the 'Minimum Charge Weight Break' field. If it is less, then the system uses the 'Minimum Charge Less Than Break Field' amount. This field is located in both the header and detail levels of the rate base record. If there is a value defined in this field on the detail level of the rate base record, the value in the detail level field with be used.<br data-source-node="n138"><br data-source-node="n139"></li>
            <li value="4" data-source-node="n140">Use the Less than 'X' Weight Field to verify the charges per LTL class for each shipment weighing less than the defined amount on the weight break configuration. The system takes this rate and multiplies it by the weight divided by 100 (or the hundredweight).<br data-source-node="n141"><br data-source-node="n142"></li>
        </ol>
