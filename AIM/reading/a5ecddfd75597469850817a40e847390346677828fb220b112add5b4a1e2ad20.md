
        
        <h1 data-source-node="n56"><a name="kanchor537" data-source-node="n57"></a>Language Selection Field</h1>
        <p data-source-node="n58">This field allows you to define which language that you want the system 
 to display text for Trading Partner Management screens. Note that this 
 setting is made at the user, not global, level. This is helpful if you 
 have different users whom require different language configurations.</p>
