
        
        <h1 data-source-node="n56"><a name="kanchor1135" data-source-node="n57"></a>Show Data - Item Price Field</h1>
        <p data-source-node="n58">This field determines if the net and actual 
 prices of an item will be displayed on the Trading Partner Management 
 website. The default value for this field is Y (Yes). You may not want 
 to show item costs if the amount charged varies based on discounts, customer 
 negotiations, etc. You can define this value on the Web System Values 
 Window.</p>
