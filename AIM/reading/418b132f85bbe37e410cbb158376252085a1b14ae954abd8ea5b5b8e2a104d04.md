
        
        <h1 data-source-node="n56"><a name="kanchor388" data-source-node="n57"></a>Only Unassigned Checkbox</h1>
        <p data-source-node="n58">You can use this checkbox to narrow your search 
 on the Work Filter Window.  If you select this checkbox, 
 the system will display only those work instructions that have not been 
 assigned to a user or a work team. If you do 
 not select this checkbox, the system will not use assignment as 
 a search criteria. </p>
