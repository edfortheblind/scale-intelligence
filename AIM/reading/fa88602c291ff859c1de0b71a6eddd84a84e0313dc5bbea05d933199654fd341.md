
        
        <h1 data-source-node="n56"><a name="kanchor1014" data-source-node="n57"></a>Validate Attribute Field</h1>
        <p data-source-node="n58">This field indicates if the system will require validate the entry of an inventory attribute value during processing:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">If Yes, the system will force the user to select one of the pre-defined inventory attributes (as defined on the <a href="3afe0a0e91c3be424098655a59ac0655672a919ff3ef1c0b6cfc3c6a56a8444d.html" data-source-node="n61">Inventory Attribute Value</a> configuration windows) for an attribute field.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64">If No, the system will allow the user to type any value into an attribute field.</li>
        </ul>
