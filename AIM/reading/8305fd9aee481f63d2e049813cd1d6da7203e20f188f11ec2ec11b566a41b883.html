Defining Work Criteria Records

All work criteria records are created on a work criteria window. There is one work criteria window for each type of work creation process. A work criteria record manages the following activities: it determines which work requests are selected for work processing; it creates a work unit; and it determines the order that work instructions are generated and released to the warehouse floor. The table below identifies the specific windows that you will use to create criteria records.

Defining Which Requests Become Work...

All work is created as a response to a work request. You will use the Filter Data Tab on the work criteria windows (listed above) to define which requests the system will generate work creation records for. Regardless of the request source, a work criteria record manages the following activities:

  • Determines which work requests are selected for work processing.

     

  • Creates a work unit.

     

  • Determines the order that work instructions are generated and released to the warehouse floor.

     

  • Summarizes instructions within a work unit. Most summaries are at the item level or location level.
Procedures: Creating a Criteria Record (Using the Filter Data Tab)...

Before you identify which work requests will be processed, access the appropriate work criteria window in the Configurations Explorer.

  1. Use the Filter Data Tab to indicate the values that the system will use to evaluate work requests. The value list displays all of the filter criteria rules in the order that they'll be processed. Both of these field sections are described below. A work request record must meet the criteria defined here to be processed by this criteria record.
     
  2. Use the Order By Tab to define how the system will generate the work for these detail records.
     
  3. When finished, press OK. The system will save your work criteria record.

 

 

 

Defining How Work Is Generated...

After you identify which requests will become work, you need to define how that work will be organized. You will use the Order By Tab on the work criteria windows to define the following parameters for a work instruction: when the system will create a work unit, and the order that work instructions are generated and released to the warehouse floor. During work creation, the system references the records defined on this value list. The steps below describe how the system processes these records. These processes are provided in the order that they appear.

  1. The system organizes the work instructions based on the first record in the value list.

     

  2. If the Work Unit Checkbox is selected for an attribute, the system will create work units each time a new attribute value is defined on an instruction. In the example above, the checkbox is selected on the from location attribute, the system will create one work unit per location. Note that you can also create work units by defining a maximum record on the Work Creation Master.
More on Work Units...

Although the Work Unit Checkbox is described above, this list provides additional considerations you may want to know as you use this tab.

  • You do not need to create work units. If you don't use the Work Unit Checkbox on any rule in a set, the system will organize the work based on the value in the Attribute Field. So, if the attribute contains the value Location, all work be organized based on its location number.

     

  • If you don't select a work unit value, consider setting the maximums on the Work Creation Master Window. The system will create work unit when it reaches the threshold that you set here.

     

  • You can select to create work units on multiple attributes. In this case, the system generates a new work unit when any of these attributes' values change.
Prerequisites...

These procedures should be completed after the record was created. The instructions below assume that you have used the Filter Tab fields (on the appropriate work criteria window) to establish how work requests are accepted as work.

 

Procedures: Creating the Criteria Record (Using the Order By Tab)...
  1. Using the Order By Tab: This tab has two field sections: the order by fields and the value list. You will use the order by fields to organize how the work instructions will be generated. For each record that you create here, you can identify the following: the request record that the system will use to organize the instructions, the order that they are organized (ascending/descending), and if a work unit will be created at this request value. The value list displays all of the records created on the order by fields. These records are processed in the order that they appear in the list. Both of these field sections are described below.

    How multiple rules are applied: Regardless of the number of rules defined on a Value List, the system makes one pass through the work requests. If multiple rules exists, it applies each rule in the order that they appear in the list. This strategy minimizes processing time and streamlines system activity. Of course, multiple records can narrow the number of request records that the system considers allocating product for.
     
  2. Use the Create Work Unit Checkbox to group together work instructions into a work unit. A work unit groups together work instructions to streamline processing. The work unit is assigned to one employee. Note that you can select this checkbox on multiple attribute records.
