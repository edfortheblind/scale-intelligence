
        
        <h1 data-source-node="n56"><a name="kanchor93" data-source-node="n57"></a>Allow Override of Default Value Checkbox</h1>
        <p data-source-node="n58"><b style="color: #000080" data-source-node="n59">On the Accessorial Detail Window...</b>
        </p>
        <p data-source-node="n60">This checkbox indicates if the default value for this accessorial can 
 be changed. For example, suppose you want to assign an "Insurance" 
 accessorial to a shipment, and the default "declared value" 
 for this accessorial is 50.00. </p>
        <ul data-source-node="n61">
            <li data-source-node="n62">If you activate the <span class="span_1" data-source-node="n63">Allow 
 Override of Default Value</span> setting, then you will be able to assign 
 a specific value, say 100.00, for this value. <br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66">If you do not activate the    <span class="span_1" data-source-node="n67">Allow Override of Default Value</span> 
 setting, then you will be able to assign this accessorial, but you will 
 need to accept the 50.00 value.</li>
        </ul>
