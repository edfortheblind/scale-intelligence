
        
        <h1 data-source-node="n56"><a name="kanchor84" data-source-node="n57"></a>Reason Code Field</h1>
        <p data-source-node="n58">A reason code identifies why an employee did 
 not complete a task as anticipated. For example, if an work instruction 
 was short picked, the employee can use the reason code to explain why 
 the work instruction was not fulfilled.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">On the QC Workbench...</h5>
        <p data-source-node="n62">This field indicates why an item quantity did not pass QC inspection. You will need to associate all of a failed quantity to the appropriate reason code(s) before container inspection confirmation can occur.</p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64"> </p>
        <h5 data-source-node="n65">On the RF Shipping Container QC Screen...</h5>
        <p data-source-node="n66">This field indicates why an item quantity did not pass QC inspection. The system will always assign the <i data-source-node="n67">RF QC Failed Quantity</i> reason code to failed quantities counted on this screen.</p>
        <p data-source-node="n68"> </p>
        <p data-source-node="n69"> </p>
        <h5 data-source-node="n70">On the Receipt Quality History Insight Screen...</h5>
        <p class="p_1" data-source-node="n71">Under Basic Criteria filter, this field captures the possible reason codes for reporting an issue or recording the quality. </p>
