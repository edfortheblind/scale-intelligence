Defining Interface Data Map Records

*** Interface data map records are required for Delimited and Fixed Length modes. ***

 

An interface data map record identifies what fields should be included in an interfaced file, and the position of each field. The system uses this information to read files it obtains from the ERP. Note that you only need to provide data map values if you use the delimited or fixed length mode for interfacing data.

Procedures...

 

Access the Interface Data Map Window. Create a new record, and enter a value in the Data Map Name Field.

  1. Use the Record Type Field to identify the interface activity (upload or download) that you want to initiate, and also what type of records that you want to the system to transmit.

     

  2. Use the Action Field to select the action that this data map will use when interfacing data:

      3.  

    • New should be used if you want to interface new records into the system.

       

    • Change should be used to modify records, if you know the shipment/receipt/item already exists.
      .
    • Delete should be used if you want to remove existing system records.
       
    • Save should be used to update a record if it already exists; otherwise, insert it as a new record. This action should be used if (a) you do not know whether the ERP data represents a new record or just changed data, or (b) you never want duplicate records in the database.

     

  3. Use the Mode Field to indicate if the data contained in files interfaced (using this map) will be provided as delimited data or as fixed length data. Note that if you choose fixed length mode, the system will require that each field defined for this data map be given a specific length.
     
  4. Press the Apply Button. The Action Field then will become input-capable.
     

  5. You will now be able to move values between the Available and Select Fields Lists. The Available Fields list identifies all values that can be included in a data map for this record type/action. The Selected Fields list will default all values required for this record type:

     

    • Required values that cannot be moved from their position are denoted with a lock icon. The must remain in the position defined in the Number (#) Field.

     

  6. Highlight a value and select the Add Button if you want to add a particular field to the Selected Fields list. The system will then move this field to the Selected Fields list. It is assigned the first available position in the Number (#) Field. Once you move a value over to the Selected Fields list, it no longer appears in the Available Fields list.
     
  7. Select the Add Button if you want to add all of the values in the Available Fields list to the Selected Fields list. The fields are assigned a position in the Number (#) Field alphabetically.
     

  8. Highlight a field and use the Up and Down Buttons to change a selected field's position.

     

  9. Select the Remove Button if you want to remove a selected field from the Selected Fields list.
     

  10. Select the Remove All Button to remove all non-mandatory fields from the Selected Fields list.

     

  11. When finished selecting fields, press OK. The system will save your record.
