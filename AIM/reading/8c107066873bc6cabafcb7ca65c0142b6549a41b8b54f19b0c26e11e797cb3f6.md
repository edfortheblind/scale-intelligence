
        
        <h1 data-source-node="n56"><a name="kanchor1398" data-source-node="n57"></a>Parent Element Field</h1>
        <p data-source-node="n58">This field indicates the parent XML element for this Billing Management 
 trigger detail record. XML has a hierarchy and elements can be children 
 of other elements. This field is necessary so that the trigger details 
 that are sent to Billing Management are in the proper order. Note that when you are choosing 
 a parent element on the trigger detail record, the system does not display 
 a warning if the user picks an element that isn't truly a parent to the 
 detail that you are defining. You should review the system template to 
 make sure you are selecting the actual parent. </p>
