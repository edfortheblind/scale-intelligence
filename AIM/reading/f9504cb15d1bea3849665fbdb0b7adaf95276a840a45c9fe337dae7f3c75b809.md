
        
        <h1 data-source-node="n56"><a name="kanchor1547" data-source-node="n57"></a>Defining User Attributes</h1>
        <p data-source-node="n58">A user attribute is a method of attaching characteristics to certain SCALE users. No default user attributes are shipped with the system, you can create up to 10 attributes, name them whatever you want, and also define the value(s) that are available for each attribute. For example, you could create a user attribute called "Employee Status" and the values full-time, part-time, and temporary. Also, the system tracks these user attributes in Labor Management.</p>

        <h4 data-source-node="n95"><a name="rename" data-source-node="n96"></a>Renaming the User Attribute Text Resource...</h4>
        <p style="text-align: left" data-source-node="n97">The first step in this process is to rename the user attribute     field name to reflect what you want it to represent. This way, the system will display the user attribute with the correct name in the User Profile Window. For example, if you renamed the User Attribute 1 field to "Employee Status", then on the User Profile Window's User Attributes tab, the first field on this tab will reflect this new name.</p>
        <ol data-source-node="n98">
            <li value="1" data-source-node="n99">Access the System Text Editor Window.<br data-source-node="n100"><br data-source-node="n101"></li>
            <li value="2" data-source-node="n102">Choose "Text" as the resource group that you want to search for.<br data-source-node="n103"><br data-source-node="n104"></li>
            <li value="3" data-source-node="n105">Search for the user attribute resource that you want to rename (for example, USERATTRIBUTE01).<br data-source-node="n106"><br data-source-node="n107"></li>
            <li value="4" data-source-node="n108">Type the new resource name into the Custom Text Field.</li>
        </ol>
        <p data-source-node="n109"> </p>
        <p data-source-node="n110"> </p>
        <h4 data-source-node="n111"><a name="defining" data-source-node="n112"></a>Defining the User Attribute Values...</h4>
        <p data-source-node="n113">The second step in this process is to define what values are going to be available for the user to choose from a particular User Attribute Field. For example, for an "Employee Status" attribute, the user could choose from the values full-time, part-time, or temporary.</p>
        <ol data-source-node="n114">
            <li value="1" data-source-node="n115">Access the Configuration Explorer.<br data-source-node="n116"><br data-source-node="n117"></li>
            <li value="2" data-source-node="n118">Choose the User Attribute Window.<br data-source-node="n119"><br data-source-node="n120"></li>
            <li value="3" data-source-node="n121">Create a new record.<br data-source-node="n122"><br data-source-node="n123"></li>
            <li value="4" data-source-node="n124">Use the Identifier Field to provide the name of the attribute value.<br data-source-node="n125"><br data-source-node="n126"></li>
            <li value="5" data-source-node="n127">Use the Description Field to provide a text description for this record.<br data-source-node="n128"><br data-source-node="n129"></li>
            <li value="6" data-source-node="n130">Press OK when finished. The system will save your record.</li>
        </ol>
        <p data-source-node="n131">NOTE: Whether or not that the system will validate for this attribute value is determined by the appropriate setting in the <a href="78edd73fb6ed59cc13da57c6d2e183eac98deb195b2fa9e468c6390984cf6f96.html" data-source-node="n132">Reviewing User Attributes System Values</a>. </p>
