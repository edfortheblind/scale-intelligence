Creating Custom DIF API's

If the DIF Message Processing Service finds an incoming message in the database, the service will send the message’s data to an API. You will need to create this API, as it is not included with the SCALE application. When this API is executed, it parses the message data, and sends the data to the appropriate SCALE business logic (as defined in the DIF event). For example, if container ID and weight values were sent, the SCALE close container logic would perform the container close action (if defined in the DIF event).

 

For detailed information on how to create a custom API, please see the SCALE SDK.
