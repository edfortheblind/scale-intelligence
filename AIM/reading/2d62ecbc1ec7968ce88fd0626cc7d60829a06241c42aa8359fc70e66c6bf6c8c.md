
        
        <h1 data-source-node="n56">Using the Wave Screen</h1>
        <p data-source-node="n57">This window provides information about a specific wave, such as its 
 total value and weight, the wave flow that it was processed through, and 
 the step that it is currently processing. The window can be accessed from the Wave Insight screen.  You must select the View or Edit action to access the screen.</p>
