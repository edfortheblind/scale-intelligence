Warehouse Mobile - Sign in

 

Warehouse mobile application provides a portable method for warehouse operations to be executed. The application is physically installed on the mobile device and functions with internet and intranet connection. You may choose to change the user by logging out and logging back in with the new user while connected to the network.

 

 

Prerequisites

  • The mobile device be connected to the network.
  • Warehouse mobile should be configured to communicate with the server-side application.

  • Each of the Warehouse mobile menu options require configuration on the server side (e.g, work profiles, receiving preferences, packing preferences, etc.)

 

To Sign On to the Warehouse Mobile

The sign on is done using the Microsoft Entra ID or AD FS. The application needs to be connected to internet or company intranet.

  • Enter the user ID and password in the Microsoft Sign in page.
  • Tap Login to submit the entered user ID and password.

After a successful login, the Warehouse Mobile selection Menu screen is displayed. Select the option for the required function
