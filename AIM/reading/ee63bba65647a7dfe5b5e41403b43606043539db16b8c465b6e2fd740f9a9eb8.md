
        
        <h1 data-source-node="n56"><a name="kanchor1017" data-source-node="n57"></a>Print Device Field</h1>
        <p data-source-node="n58">This field indicates the network path of the 
 print device to be used to print a document. You need to indicate the 
 network name and the printer description. For example, if you network 
 was named "YOURNETWORK," and the description of your printer 
 was "HP Laserjet 5 Plus," then the path would read as follows: 
 <b data-source-node="n59">\\YOURNETWORK\HP Laserjet 5 Plus.</b></p>
