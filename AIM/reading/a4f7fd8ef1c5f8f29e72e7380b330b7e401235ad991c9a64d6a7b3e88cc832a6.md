
        
        <h1 data-source-node="n56"><a name="kanchor1862" data-source-node="n57"></a>Group Number Field</h1>
        <h5 data-source-node="n58">In Picking... </h5>
        <p data-source-node="n59">When the system creates a pick group, it assigns it a group number. 
 
 The group number identifies all of the containers in the picking group. Picking groups are created during the pick group creation wave step and during group user work initiation. You can view the group number in the following places: Putaway Group Insight Screen, Work Instruction screen, and the Picking Group Pick List paperwork document.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">In Cycle Counting...</h5>
        <p class="p_1" data-source-node="n63">This field indicates the number of a cycle 
 count request group. The size of these groups are defined on the Cycle 
 Count Plan Creation screen. For example, if there are 100 requests to 
 execute, and you indicate that you want to distribute these requests in 
 groups of 50, then there would be a group "1" and a group "2."</p>
