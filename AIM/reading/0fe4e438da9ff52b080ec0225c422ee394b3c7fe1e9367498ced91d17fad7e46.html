Issue: Encountering "Operation is not valid due to the current state of the object." error during order entry process...

Microsoft has released some patches that may cause Trading Partner Management to encounter a "Operation is not valid due to the current state of the object" error. This error may occur when adding Ship To's during the order entry process in TPM. To verify the error the the ThrowIfMaxHttpCollectionKeysExceeded() exception will be visible in the error the stack trace.

 

Error Details...

Description:

An unhandled exception occurred during the execution of the current web request. Please review the stack trace for more information about the error and where it originated in the code.

 

Exception Details:

System.InvalidOperationException: Operation is not valid due to the current state of the object.

 

Source Error:

An unhandled exception was generated during the execution of the current web request. Information regarding the origin and location of the exception can be identified using the exception stack trace below.

Resolutions...
  1. Narrow your search results. The amount of data returned exceeds the limit of data allowed by ASP.NET.

  2. Add the aspnet:MaxHttpCollectionKeys value to the apsettings node of the web.config file in the TPM folder of the SCALE installation directory. The value field can be any value greater than 1001. Depending on the amount of results returned this value will need to be increased to accomodate the data returned. An IISRESET should be performed after making the changes to the web.config file to allow the changes to be loaded into ASP.NET.

    <add key="aspnet:MaxHttpCollectionKeys" value="2000" />

See this article for more information: http://support.microsoft.com/kb/2661403
