
        
        <h1 data-source-node="n56"><a name="kanchor1633" data-source-node="n57"></a>Shipment ID Field</h1>
        <p data-source-node="n58">This field represents a shipment's identification number. This 
 value corresponds to the order number defined in the interface. You can 
 use the shipment ID to identify a shipment in the system. The shipment ID represents the order. The interface creates one shipment 
 for each order. It assigns a shipment ID to the shipment. This value is 
 a generally equal to the order number. If you transfer a detail line to 
 another shipment, this number will change. All activity in the system is committed against 
 the shipment ID, not the order number. As the shipment is processed through 
 the system, the system transmits status updates to the interface.</p>
