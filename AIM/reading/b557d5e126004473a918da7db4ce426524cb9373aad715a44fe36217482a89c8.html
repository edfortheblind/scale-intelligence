Reviewing Receiving System Values

These values are miscellaneous technical values that the system uses when processing receipts. Ask your system consultant before changing any of these values.

Value Key

 

Value Description t

 

10

 

Blind Receiving Receipt ID Prefix: This value indicates the receipt ID prefix that the system will use when creating receipts during check in (using the RF Blind Receiving initiation method). The application will attach this prefix to the beginning of its system-generated ID for the container. Note that the system will only use this default value when the user does not provide a value for this particular RF field.

 

20

Blind Receiving Receipt ID Type: This value indicates the receipt ID type that the system will use when creating receipts during check in (when using the RF Blind Receiving initiation method). Note that the system will only use this default value when the user does not provide a value for this particular RF field.

 

30

Blind Receiving Receipt Type: This value indicates the receipt type that the system will associate with a new receipt when you check in containers using the RF Blind Receiving initiation method. Note that the system will only use this default value when the user does not provide a value for this particular RF field.

 

40

Inventory Status For Quantity Needing QC: This value indicates the status of a partially checked-in item quantity that will be eligible to be routed to the quality control inspection process.

 

50

 

Receipt ID Prefix: This value indicates the prefix that the system will add to any receipt ID that is created via the web receipt entry module (if there is not one configured on the Company Window)

 

60

 

Default Web Receipt ID Type: This value identifies the web receipt ID that the system will apply to new web receipts, by default.

70

Receipt ID Type For Creating Receipt From Shipment: This value indicates the receipt ID type the system will use when creating receipts from shipments.

 

80

Receipt Type For Creating Receipt From Shipment: This value indicates the receipt type the system will use when creating receipts from shipments.

 
90

Purchase Order ID Prefix: This value identifies the prefix that the system attaches to the beginning of new PO ID’s (if a PO prefix is not defined on the Company Window).

 
100

Separator For Receipt ID During Receipt From PO: This value is used when you use the “Receipt from PO” option in the Purchase Order Insight. When the system creates this receipt, it uses the PO number as the Receipt ID, and concatenates this character followed by a unique next number. This is done so that you have a unique Receipt ID if you create multiple receipts from the same PO. For example, if the PO is 12345, the first Receipt ID would be 12345-01, the second would be 12345-02, etc.

 
110

Locating Rule Assignment During: This value indicates where in the inbound process you want the system to assign a locating rule to product they are receiving into the warehouse. You can choose to have a locating rule assigned at the time of receipt line creation, or at the time of receipt check in. When using the receipt check in option, then the system will assign the locating rule based off of data from the receipt container.

 
120

Receipt ID Type for Creating Receipt from PO: This value is used when you use the “Receipt from PO” option in the Purchase Order Insight. When the system creates this receipt, it assigns the Receipt ID Type that is defined in this system value.

 
130

Prompt for Receiving Preference in RF: This value indicates whether the system will always display the list of available receiving preferences whenever a user logs onto RF receiving (even if they have a default preference defined on their user profile). If this system value is set to No, then if a user has a default preference defined, then the system will not display this list of preferences.

 

140

 Separator for RF Receiving Lot Exp Date Entry: This value is used to differentiate same expiry date for the RF receiving.
