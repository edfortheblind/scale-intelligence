
        
        <h1 data-source-node="n56"><a name="kanchor1076" data-source-node="n57"></a>Associating A Master To The Appropriate Wave Master</h1>
        <p data-source-node="n58">During a wave, only one document master can be run. That record must 
 be defined on the wave master record used during the wave cycle. If a 
 document master is not defined on the wave master record, the system uses 
 the *Default document master. See the topic <a href="ab5c4eb3e7913e74aff2897104eaa06f23730db414ea39a3dc6b6572c9252f8d.html" data-source-node="n59">Defining Wave Masters</a> for procedural information.</p>
