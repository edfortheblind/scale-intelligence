        <h4 data-source-node="n74">Procedures: RF Yard Management...<br data-source-node="n75"></h4>
        <p data-source-node="n76">Log on to your RF Device and select the Yard Management function. The system will display the yard management pick screen.</p>
        <ol data-source-node="n77">
            <li value="1" data-source-node="n78">Use the Trailer ID Field to identify the trailer that you want to move.<br data-source-node="n79"><br data-source-node="n80"></li>
            <li value="2" data-source-node="n81">Press OK. The system will display the yard management pick screen.<br data-source-node="n82"><br data-source-node="n83"></li>
            <li value="3" data-source-node="n84">Use the Trailer ID and From Location fields to view which trailer you want to move and where it is currently located. These fields will be defaulted values by the system.<br data-source-node="n85"><br data-source-node="n86"></li>
            <li value="4" data-source-node="n87">Press OK. The system will display the yard management putaway screen.<br data-source-node="n88"><br data-source-node="n89"></li>
            <li value="5" data-source-node="n90">Enter the To Location where you are going to move the trailer to. Typically, you would enter another yard location or the Receiving Dock in this field. The system will populate this field with a value if a Destination Yard Location was identified at the time of yard check in.<br data-source-node="n91"><br data-source-node="n92"></li>
            <li value="6" data-source-node="n93">Press OK. The system will assign the new yard location to this trailer.<br data-source-node="n94"><br data-source-node="n95">Bypass Button: If the to location is a yard location, and there is a destination dock specified for this trailer (from the Yard Check In/Out Window), you can choose to skip moving the trailer to the yard location and send it directly to the Receiving Dock. This action is only available if a trailer is not currently present at the dock, and one is not already scheduled.</li>
        </ol>
