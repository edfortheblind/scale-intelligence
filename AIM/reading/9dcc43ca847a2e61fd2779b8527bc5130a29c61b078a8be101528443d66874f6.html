Available Quantity Field

When Picking...

This field indicates the item quantity available for picking at a certain location. The system derives this number via the following calculation: On Hand Quantity - Allocated Quantity - Suspense Quantity = Available Quantity.  All "Inventory" locations in the warehouse that contain the item/company are considered for this calculation.

 

 

Calculation Notes...

  • If the "Allocate In Transit" setting (in the Location Window) is activated, the In Transit Quantities will be added to the On Hand Quantity before the others are subtracted.
     
  • Available quantity does not take location status into account, so Available/Unavailable/Damaged/Frozen inventory is all considered "available quantity" here.
     
  • If the "Should in pool quantities count as allocated" setting (in the Order Entry Values Window) is selected, the quantity required by shipments that are "In Pool" will be subtracted from the calculated Available Quantity value described above.
     
  • NOTE: When using unlimited allocation mode, the system allows the on hand quantity calculation to return a negative available quantity value. However, the system will display this negative amount as a 0. For example, suppose the following for a certain location:

    - On Hand quantity = -100

    - In Transit quantity = 0

    - Allocated quantity = 0

    - These values would yield an Available Quantity of -100. The system, then, will display this quantity to the user as a 0.

 

On the Receipt From Purchase Order Screen...

This field indicates the maximum quantity for which a receipt line can be created.
