
        
        <h1 data-source-node="n56"><a name="kanchor1152" data-source-node="n57"></a>Stop Bits Field</h1>
        <p data-source-node="n58">After a character has been transmitted (in 
 the number of bits defined in the Bits Per Byte Field), a stop bit is 
 sent to signal the end of a packet. This field specifies how many bits 
 will be used to represent this signal.</p>
