
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Labor Group Criteria</h1>
        <p data-source-node="n58">This section defines the conditions under which the system processes shipments during the labor plan execution wave step. These criteria are linked to a labor group and help determine which shipments the group should handle.</p>
        <p data-source-node="n59">Example: If you want a labor group to only process shipments containing items from a specific work zone, you would create a labor group criteria record that filters for shipment lines originating from that zone.</p>
