Using the Shipment Line Insight Screen

You can use the Shipment Line Insight Screen to display the specific field values associated with shipment line. If you click on the Indicator Tiles for Lines in the Detail Pane of the Shipment Insight screen, it takes you to Shipment Line Insight filtering by this internal shipment number. This screen opens and displays all open shipment lines in the system when there is no filter criteria.

Searching/Viewing Shipment Line Records...

You can use the Shipment Line Insight Screen to search for and view shipment line records in your warehouse.

  1. Open the Shipment Line Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Apply filter. The system will display all information regarding the resulting records in the List Pane.


    4. NOTE: Clicking on the Shipment ID field in the results grid opens the Shipment screen for the chosen internal shipment number. Clicking on the ERP Order Line Number field in the results grid will navigate you to the Shipment Line Screen.

 

 

 

About the List Pane...

The Shipment Line Insight Screen's List Pane displays the results from a query performed in the Filter Pane.


List Pane Icon Explanation

Certain conditions for the shipment line are represented by graphical icons on the list pane. Below are explanations of what each icon represents:


Icon Explanation
Shipment line has an allocation rejection.

Shipment line has a pending immediate need associated with it.

Shipment line has an immediate need being fulfilled.

Shipment line has an immediate need that has been fulfilled.


For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

  • The Detail Pane header displays the ERP Order Line Number, Item, Company, Item Description. The ERP Order Line Number hyperlink can be used to open the Shipment Line Screen

 


 

Screen Actions...

The following actions are accessible from the List Pane of Shipment Line Insight:

 

Cancel

You can use this action to cancel a shipment line if you got the security check point for Cancel. If the cancel happens successfully, the shipment line should be returned into a status as defined in "Default status when shipment is cancelled" under Configurations.

 

 

Copy

You can use this action to copy the shipment line. On selecting the Copy action, the system opens the Shipment Line Screen and after updating any value on the screen, the system returns to the Shipment Line Insight screen and displays a success message.

 

 

Deconsolidate

You can use this action to deconsolidate shipment lines for an ERP order from the consolidated shipment to a new shipment (with the same shipment ID).

 

Delete

You can use this action to delete a single shipment line or multiple shipment lines from a shipment.

 

 

Edit

This action allows you to modify the field values associated with the shipment line. When this action is selected, the system will open the Shipment Line Screen in edit mode.

 

 

Immediate Needs

You can use this action to open the Immediate Needs Insight Screen. The Reference ID and Warehouse get auto-populated in the filter pane of Immediate Needs Insight and the result for that particular shipment line will get displayed accordingly.

  • The flag "Immediate needs request created" would be set to Yes if immediate needs request is created for the immediate needs item.

  • The flag "Immediate needs request created" would be set to No if immediate needs request is not created for the immediate needs item.

  • The Immediate Needs action should be enabled if the item has an immediate needs request created.

 

 

Transfer

You can transfer the shipment line to a new or existing shipment by clicking on the Transfer action of the Shipment Line Insight screen.

 

  1. Access the Shipment Line Insight screen.

  2. Access the shipment line that you want to transfer to a different shipment.

  3. Select the Transfer action. The system will display the Transfer Shipment Line Screen. Information about the line and its current shipment (the shipment you are transferring from) are provided.

  4. Access the Destination shipment field to identify the shipment that you intend to transfer this line to.

    • If this is an existing shipment, you can use the Lookup Search to find a particular shipment.


Update Quantity to Pack

You can change the quantity on the shipment line by selecting the Update Quantity to Pack action of the Shipment Line Insight screen.

  1. Access the Shipment Line Insight screen.

  2. Access the line record that you want to update.

  3. Select the Update Quantity to Pack action. The system will display the Update Quantity to Pack Screen with the populated Available Quantity field.

    • Enter the Pack Quantity under Quantity to Pack and press Update. The system will display a confirmation message.

    • If you wish to continue, press Yes. Once the update process is successful, the system refreshes the window with the revised Available Quantity.

 

NOTE: The action is enabled when the line is highlighted in the Line section of the List pane of Shipment Line Insight. The action is disabled when the status of entire shipment line is Load Confirm Pending or higher.
