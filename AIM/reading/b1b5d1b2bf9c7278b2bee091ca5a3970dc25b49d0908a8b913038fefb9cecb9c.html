Dock Management Configuration

Overview

 

A dock management flow record includes information which determines how the system will assign a dock location destination to a shipment line/container, and if the line/container is eligible for assignment. Each flow record is made up of a series of detail records that identify what selection and assignment strategies that the system should use when a quantity hits a certain status in your status flow.

 

Configuration Hierarchy

 

 

Configure Dock Management

 

1. Dock Management Flow Information

The information such as Warehouse, Custom status flow, Default location is configured.

 

  • Custom Status Flow - This will determine which shipment lines/containers are eligible for the system to evaluate using this flow record. Note that if the shipment line does not have a custom status flow specified, then the system will look for a record in this flow with a blank custom status flow defined.

  • Default Location - The dock location that the system will assign if no dock management flow details match the line's/container's current status. Note that the system limits your choices in this field to dock locations with a packing subclass. Therefore, you would most likely select your warehouse's packing area location for this field's value.

  • Manual Dock Door Assignment Checkbox - the system will not create the next move when the dock door on a shipping load is not assigned. Once the dock door has been manually assigned, the system will then create the dock management work next move to the dock door (when the create next move setting is selected on the flow). Note that the system only evaluates this setting when the next move is to the dock door.

 

2. Sequences - Detail Records Information

Users Add/Edit the sequences for the dock management flow.

 

  • Status - The status that a shipment line/container needs to be at in order to be eligible to be assigned the indicated type of dock location. For example, suppose your status flow is configured that a container goes into a Staging Pending status when it is closed. If you have set up a flow detail record for Staging Pending (and a location subclass of Staging), then the system will assign a staging location to a line/container that is in this status.

  • Location Subclass - The type of dock location that you want the system to assign to a line/container when it is processed by this flow detail.

  • Selection Strategy - The dock location selection strategy that you want the system to use when assigning a dock location to a shipment line/container. See the process flow diagram on the Dock Management Process Summary topic for more details on how this strategy works.

  • Assignment Strategy - The dock location assignment strategy that you want the system to use when assigning a dock location to a shipment line/container. See the process flow diagram on the Dock Management Process Summary topic for more information on how this strategy works.

  • Default Location - The dock location that the system will assign if the dock location selection strategy does not find matching dock location area for this line/container. When this occurs, the dock assignment strategy “Assign One Dock Position Per Pallet” will use the dock location passed in to determine whether to assign to an area or position:

    • If dock location is dock area, then the assignment strategy will first attempt to assign the container to an open dock positions. If no open dock positions exist, then it will assign it to the dock area.

    • If dock location is an open dock position, then the assignment strategy will assign it to that position. If the passed in dock location is not an open position, then the assignment strategy will assign the container to the position’s parent dock area.

  • Allow nest after putaway - The system that you want the nest after putaway screen to display (upon delivery to a To Dock Location) when putting away shipping containers. Note that the Nest After Putaway Check box on the Work Profile Window must also be selected to use this functionality.

  • Create next move - the system will invoke the work creation process to create the work to represent the transfer of a container from one dock location to another. This is referred to as "creating the next move" for the transfer action. For example, a dock worker may need to move a container residing at a packing location to a staging location. When the packer closes the container, the system automatically locates the container to a staging location. The system will find the appropriate flow detail record (based on the shipping container’s warehouse, custom status flow, and status), and determine if work for this transfer needs to be created.
