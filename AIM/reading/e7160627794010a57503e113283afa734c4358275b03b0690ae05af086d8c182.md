
        
        <h1 data-source-node="n56"><a name="kanchor1362" data-source-node="n57"></a>Customer ID Field</h1>
        <p data-source-node="n58">The value used to identify a customer's account. If this customer is a corporate customer with 
 multiple delivery sites, this field identifies the corporate, billing 
 office. In this case, you will use the Ship To ID Field to identify a 
 specific delivery site. This is an alpha-numeric field.</p>
