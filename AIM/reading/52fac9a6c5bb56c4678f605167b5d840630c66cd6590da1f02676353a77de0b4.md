
        
        <h1 data-source-node="n56">Defining System Monitor Service Parameters </h1>
        <p data-source-node="n57">The application uses the service called "WMMonitorService" 
 to manage the priority of system packages. When this service starts, and 
 then subsequently every time it "wakes up" from sleeping, it 
 goes through and resets the priorities on the packages. It will do this 
 every time it wakes up because packages could have been reset in the meantime 
 (i.e. brought down and restarted), so even if the priorities themselves 
 haven’t changed, 
 the system will go through the priority assignment step every time. This service uses two text files to manage priority: one containing 
 the mapping of components to packages, and the other containing the package priorities to perform the priority 
 changing. You can manage the settings for this service in the Service System Values 
 Window. </p>
