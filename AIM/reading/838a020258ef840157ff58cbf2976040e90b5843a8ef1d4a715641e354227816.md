
        
        <h1 data-source-node="n56">Using Warehouse Mobile - Immediate Dock Transfer</h1>
        <p data-source-node="n57">Typically, in a warehouse, you will either use work to facilitate the movement of containers into and through your shipping dock, or you will choose not to use work. The Warehouse Mobile immediate dock transfer enables you to perform container transfer movements without using work execution. You scan the container ID, move the container to the new location and then scan the destination location ID. When the dock transfer is done, the system will validate and success message is displayed. Once the transfer is done, the system will transfer the inventory on hand from its original location to destination location. All these activity can be performed without the need to create a work unit.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">Permission</p>
        <p data-source-node="n60">The immediate dock transfer is configured using the <b data-source-node="n61">Warehouse Mobile Screen</b> and user permission using the <b data-source-node="n62">Security Permission Screen.</b>. </p>

        <h4 data-source-node="n89"><a name="Close" data-source-node="n90"></a>Perform Immediate Dock Transfer</h4>
        <p data-source-node="n91">Enables user to transfer container in the warehouse. </p>
        <ol data-source-node="n92">
            <li value="1" data-source-node="n93">Tap <b data-source-node="n94">Immediate Dock Transfer</b> to view <b data-source-node="n95">Immediate Dock Transfer</b> screen.</li>
            <li value="2" data-source-node="n96">Enter or scan the <b data-source-node="n97">Container ID</b> and Tap <b data-source-node="n98">Go</b>.</li>
            <li value="3" data-source-node="n99">In Immediate Dock Transfer screen, the <b data-source-node="n100">Container ID</b>, <b data-source-node="n101">Assigned Location</b> is populated.</li>
            <li value="4" data-source-node="n102">Scan the <b data-source-node="n103">Dock location</b> after moving the container. The Doc Location is populated in the screen.</li>
            <li value="5" data-source-node="n104">Tap <b data-source-node="n105">Go</b>. to view the success message.</li>
        </ol>
        <h4 data-source-node="n106"><a name="Notes" data-source-node="n107"></a>Immediate Dock Transfer Notes:</h4>
        <p data-source-node="n108"> </p>
        <p data-source-node="n109">When you Scan the ID of the "top-level" (parent) container that you want to transfer to the shipping dock door.</p>
        <ul data-source-node="n110">
            <li data-source-node="n111">The container ID should be present in the system and the First (parent) Container.</li>
            <li data-source-node="n112">Multiple Order pallet is supported. When container ID is entered/scanned, the MOPID is displayed. </li>
            <li data-source-node="n113">The scanned container and its associated containers should not be associated with open or work instructions</li>
            <li data-source-node="n114">
                <p data-source-node="n115">if the container is associated with a load, then the system will default the dock door location into this field.</p>
            </li>
        </ul>
        <p data-source-node="n116">When we enter the destination location:</p>
        <ul data-source-node="n117">
            <li data-source-node="n118">The destination location should not be in frozen state.</li>
            <li data-source-node="n119">The destination location needs to have a location class of Shipping Dock</li>
            <li data-source-node="n120">There needs to be a dock management flow detail record for the location subclass of the destination location.</li>
            <li data-source-node="n121">If the destination location is a dock door location, then no other load can be assigned to that dock door</li>
            <li data-source-node="n122">The load that the shipment is assigned to must either be assigned to that dock door or no dock door.</li>
        </ul>
        <p data-source-node="n123">When Go button is tapped. In case the dock transfer does not happen, </p>
        <ul data-source-node="n124">
            <li data-source-node="n125">
                <p data-source-node="n126">If the container's shipment is not assigned to a load, then the system will create a shipping load and assign it to the appropriate dock door.</p>
            </li>
            <li data-source-node="n127">If the container's shipping load was not previously assigned to a dock door, the system will assign the appropriate dock door to the container's load.</li>
            <li data-source-node="n128">
                <p data-source-node="n129">If the carrier on the container's shipment matches the load at the door (but the shipment is not assigned to that load), the system will add the shipment to that load.</p>
            </li>
            <li data-source-node="n130">
                <p data-source-node="n131">The system will not allow the transfer if the container's shipment is unassigned to a load and does not have a carrier.</p>
            </li>
            <li data-source-node="n132">
                <p data-source-node="n133">If, during the execution of a transfer, the system creates work for this container, and you then press the Transfer Button to close the transaction, the system will not allow the transfer to complete.</p>
            </li>
        </ul>
