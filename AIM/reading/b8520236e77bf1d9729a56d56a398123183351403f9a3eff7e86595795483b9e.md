
        
        <h1 data-source-node="n56"><a name="kanchor1638" data-source-node="n57"></a>Defining Container Types</h1>
        <p data-source-node="n58">A container type identifies the type of package that inventory is packed 
 in for shipping. Container types are usually defined by their dimensions. 
 Create a record for each container type that your warehouse uses for 
 packing.</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Creating Container Types For Use In Pallet Building...</h5>
        <p data-source-node="n61">When creating container type(s) that are used with the pallet building wave step, consider the following:</p>
        <ul data-source-node="n62">
            <li data-source-node="n63">This process is not limited to actual pallets. For example, you could also have the wave step place smaller shipping containers into a larger box. For purposes of discussion in the help, however, this process is referred to as "pallet building" or "palletizing."<br data-source-node="n64"></li>
            <li data-source-node="n65">You will need to create separate "pallet" container type(s) than the one you are having the system consider a "full pallet." The pallet building logic will fail using these "full pallets," because they are defined with no dimensions. The pallet building wave step logic uses dimensions to determine which shipping containers can fit on a certain pallet. You should exclude this "full pallet" container type from your pallet building criteria.</li>
            <li data-source-node="n66">The container type company or warehouse authorization are not used to create container and build pallets. Container creation by company is filtered by configuring Packing classes, container groups, and container types. Similarly to filter pallet building by company you need to configure the pallet building criteria and pallet building masters.<br data-source-node="n67"></li>
        </ul>

        <h4 data-source-node="n123">Procedures...</h4>
        <ol data-source-node="n124">
            <li value="1" data-source-node="n125">
                <p data-source-node="n126">Use the Container Type Field 
 to identify this record.</p>
                <p data-source-node="n127"> </p>
            </li>
            <li value="2" data-source-node="n128">
                <p data-source-node="n129">Use as Default Checkbox: 
 If you use scan and weigh, consider selecting the Default Checkbox. If 
 containers are created using scan and weigh and a container type is   NOT interfaced to the system, the system will 
 assign the default container type. If you do not use scan and weigh, this 
 field will not have any impact on your processing. Note that you have 
 to deselect this checkbox from a container type before you can assign 
 a different container type as the default. If this checkbox is selected then sets the company authorization to All and disables the All/List option under Company Access.</p>
                <p data-source-node="n130"> </p>
            </li>
            <li value="3" data-source-node="n131">
                <p data-source-node="n132">Use the Container Class Field 
 to associate this container with the appropriate container class. The 
 system uses container classes to organize types for shipping purposes. 
 All container types within a class share common characteristics, such 
 as package category (carton, case, pallet, etc). They also share the same 
 UCC Code.</p>
                <p data-source-node="n133"> </p>
            </li>
            <li value="4" data-source-node="n134">Use the Rating 
 Symbol Field to identify this container type to Progistics. Progistics 
 will use this value during rating to help calculate the appropriate rates 
 for containers associated with this container type. If you have not defined 
 the container type specifically to TanData, use the value 'Custom'.<br data-source-node="n135"> </li>
            <li value="5" data-source-node="n136">
                <p data-source-node="n137">Use the FedEx Rating Symbol Field 
 to identify this container to the FedEx rating software. FedEx will use 
 this value during rating to help calculate the appropriate rates for containers 
 associated with this container type.</p>
                <p data-source-node="n138"> </p>
            </li>
            <li value="6" data-source-node="n139">Identify the 
 container type's physical dimensions (Length, Width, Height fields). 
 </li>
            <p data-source-node="n140"> <ol data-source-node="n141"><li value="1" data-source-node="n142"><p data-source-node="n143">Use the Empty Weight Field 
 to identify what the container's actual weight is with no contents inside 
 of it. During rating, the container's empty weight is included in the 
 rate calculated for a shipment.</p><p data-source-node="n144"> </p></li></ol></p>
            <li value="7" data-source-node="n145">
                <p data-source-node="n146">Use the Maximum Weight Field 
 to identify how much product the container can hold. During the container 
 creation wave step, the system references this value when it assigns items 
 to containers. This maximum should also include the weight of the empty 
 container as the system includes the container's weight in the total during 
 processing.</p>
                <p data-source-node="n147"> </p>
            </li>
            <li value="8" data-source-node="n148">Use the Weight 
 Tolerance Field to identify how much of a deviation can exist between 
 a container's actual weight and how much the system believes that it weighs. 
 The system estimates how much a container weighs during the wave and during 
 manual packing. When it closes this container, it checks the actual weight 
 of the container and compares it to the estimate. If there is a weight 
 deviation above or below the tolerance set here, the system displays an 
 alert message. You can override this value or research the weight difference.<br data-source-node="n149"> </li>
            <li value="9" data-source-node="n150">
                <p data-source-node="n151">Use the Company access tab to assign container types to companies. The container types company authorization is used during close container, nesting, packing, picking into shipping and putaway into shipping container.</p>
                <ul data-source-node="n152">
                    <li data-source-node="n153">Only the authorized container types for a shipment header's company and warehouse will be eligible for use.</li>
                    <li data-source-node="n154">If the company is entered in the shipment header, then the company and warehouse authorization is required.</li>
                </ul>
            </li>
            <li value="10" data-source-node="n155">
                <p data-source-node="n156">Use the Warehouse access tab to assign container types to warehouse. The container types warehouse authorization is used during close container, nesting, packing, picking into shipping, and putaway into shipping container.</p>
                <ul data-source-node="n157">
                    <li data-source-node="n158">The authorized container types for a shipment header's company and warehouse will be eligible for usage only when the shipment header's company is blank or filled.</li>
                </ul>
                <p data-source-node="n159"> </p>
            </li>
            <li value="11" data-source-node="n160">Press OK. 
 The system will save your record.</li>
        </ol>
