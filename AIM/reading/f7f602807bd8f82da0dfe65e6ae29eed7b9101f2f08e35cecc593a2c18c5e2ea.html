Document Printer Field

On the Select Wave Printers Window...

This field indicates the printer that you want the system to use when printing wave paperwork that is classified as documents in the Document Type Window. Note that this field lists all of the print devices that are currently configured in the system.

 

 

On the Reprint Wave Documents Window...

This field indicates the printer that you want the system to use for the reprint action. Note that this field lists all print devices currently configured in the system.

 

 

On the User Profile Default Printers Window...

This field indicates a list of all the document printers in the print device configuration. The default printer on the user profile overrides document routing printer configured for the document type. Selecting a printer when printing selected documents will override the default printer.

NOTE: Printing still requires a document routing record that matches the document routing criteria for the user submitting the print request.
