Processing Returns

You can use SCALE's receiving module to process product that is returned to your warehouse. Below are the procedures that you will need to perform to get the returned items from the receiving dock, back to their original locations.

Returns Processing Notes...

This topic assumes the following returns process flow:

  • "Good" returns (items that do not need any repair) would be located from the receiving dock to their appropriate inventory storage location.

  • "Bad" returns (items that need some sort of repair) would first be located from the receiving dock to a special "returns location." From there, repairs would be made, and then the item would be adjusted into its appropriate inventory storage location.

 

 

 

Putaway Groups Note... 

Using putaway groups is optional when processing returns. It is helpful to use these when you want to take a group of returned items to a specific location, as opposed to a one-by-one basis.

 

 

 

 

Returns Procedures...

  1. For the process flow, assume that the returned item was part of a shipment that was sent from your warehouse at an earlier date. In this case, you would need to find the existing shipment in the system, and create a receipt off of the shipment. However, if for some reason this shipment is no longer in the system, you could create a new receipt on the spot using blind receiving. The procedures below describe this process using the creating a receipt off of a shipment flow.
     
  2. Create a receipt from a returned shipment from the Shipment Insight screen:

    a. Use the filter criteria to locate the returned shipment. Select the shipment in the record list and choose the Receipt From Shipment action. The system will display the Receipt From Shipment screen.

    b. Enter/confirm the returned quantity you want on the receipt and press Save. The system will create the receipt. Next, open this receipt in the Receipt Workbench.

  3. In the Receipt Workbench, access your receipt and check it in. The system will display the Check In screen. Be sure to:

    - Indicate the appropriate reason code and/or disposition code.

    - Confirm the correct locating rule for returns (this should default from the disposition code value).

    Press Check In when finished entering these values. The system will display the License Plate Entry screen.
     
  4. Enter a license plate ID for the returned quantity. Press Save, and the system will return you to the Receipt Workbench.
     
  5. Locate the returned quantity by invoking the Locate or Locate All action. The system will:

    - If using putaway groups, the system locates the location and assigns the receipt container to the putaway group associated with the putaway location group. If there is not an existing putaway group for the destination location, the system will either create a new putaway group with system-generated ID or the user will assign an ID. It will also update the parent license plate on the receiving dock inventory for this license plate with the putaway group ID.

    - If not using putaway groups, the system will locate the quantity to the location.
