
        
        <h1 data-source-node="n56"><a name="kanchor744" data-source-node="n57"></a>Accessorial Subcode Field</h1>
        <p data-source-node="n58">This code represents an accessorial 
 sub-category. This allows you to create different types of accessorials 
 within a general category. For example, if you use multiple insurance 
 accessorials, you would create one insurance accessorial code with one 
 subcode for each type of insurance.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"><span class="span_3" data-source-node="n61">NOTE:</span> You must define at least 
 one accessorial subcode for each accessorial code, even if you do not require 
 multiple subcodes.</p>
