
        
        <h1 data-source-node="n56"><a name="kanchor1850" data-source-node="n57"></a>Researching Interface Errors</h1>
        <p data-source-node="n58">When the download interface process encounters an error when validating the data that is being downloaded from the ERP, the system generates an XML error file and places it into the Interface/Output directory. In addition, the system will write a record to the INTERFACE_ERROR database table, which will include such informational data as the error message, error file/original file path, and other reference values. The system will also place the original data file (in the same form as was downloaded from the ERP) into the "original data file" directory (as defined in the Interface System Values Window). The Interface Error Insight Screen allows you to research these interface errors.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Notes</h5>
        <ul data-source-node="n62">
            <li data-source-node="n63">An error will only be displayed in this viewer if there is an ERROR node in the related XML error file. For example, if an XML schema validation error occurs, the resulting error file does not include an ERROR node and therefore this error will not be represented in the viewer.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66">Note that the upload and receipt entry/order entry processes are listed in the Interface Error Viewer/Insight Screen's Interface Process field, even though errors for those processes are not displayed. This is because uploads do not generate error files, and receipt entry/order entry validate data errors as the data is entered.<br data-source-node="n67"><br data-source-node="n68"></li>
            <li data-source-node="n69">Item Master and Bill of Material validation errors do not have a Warehouse value written to the INTERFACE_ERROR table. So, when searching for these error records, the Warehouse criteria field has to be blank for the system to display the appropriate results.</li>
        </ul>
