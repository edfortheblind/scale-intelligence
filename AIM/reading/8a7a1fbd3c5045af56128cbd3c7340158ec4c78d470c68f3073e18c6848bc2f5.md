
        
        <h1 data-source-node="n56"><a name="kanchor400" data-source-node="n57"></a>Status Name Field</h1>
        <p data-source-node="n58">The name associated with a specific status number. The system uses status 
 numbers to process receipts through all inbound functions and shipments 
 through all outbound functions. Status numbers 
 will not appear on any screens; instead, the system will display the corresponding 
 status names. Employees will use the status name to determine the next 
 processing step for a particular shipment. For example, if shipment has 
 the status name 'Ship Confirm Pending', employees will recognize that 
 it can be ship confirmed.</p>
