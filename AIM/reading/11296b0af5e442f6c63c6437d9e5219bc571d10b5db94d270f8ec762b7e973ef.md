        <h4 data-source-node="n85">Procedures...</h4>
        <p data-source-node="n86"> </p>
        <p data-source-node="n87">Open the Immediate Needs Trigger Window. Open an existing trigger record.</p>
        <ol class="ol_1" data-source-node="n88">
            <li value="1" data-source-node="n89">Use the Priority 
 Field to assign a priority to this trigger. If there are multiple 
 requests that need the same item, the system processes them in this order 
 when fulfilling an immediate need. For example, this could allow you to 
 make sure that all failed shipments get serviced before failed work orders. 
 <br data-source-node="n90"> </li>
            <li value="2" data-source-node="n91">Use the Create 
 Work Checkbox to indicate that the system will create work when 
 fulfilling an immediate needs request that is generated by this trigger. 
 If you do not select this option, the system will put the quantity on 
 hand at the destination location. You would then have to manually make 
 sure that the immediate needs transaction was actually completed.<br data-source-node="n92"> </li>
            <li value="3" data-source-node="n93">Press OK. 
 The system will save your changes.</li>
        </ol>
