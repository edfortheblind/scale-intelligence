Entering Orders

An order is either interfaced from the ERP to the application, or entered from the web (in Trading Partner Management) or the order entry module (in SCALE). Orders represent one customer's request to receive certain items from you. To maintain order integrity, the system does not process orders. Instead, the system creates one or more shipments which contain the order's requests. These shipments are then processed. The order is updated in the ERP to reflect the shipments' processing activities. The Order Entry Window uses a navigation tool called a wizard, which is similar to ones that are used in other Microsoft Windows applications. When you choose the Order Entry option on the desktop, SCALE will ask you to indicate what type of order you want to enter. The system will then display either the Shipment Screen (for single orders) or the Order Entry wizard (for all other order types).

1. Initial Screen...

This is the first screen of the Order Entry wizard. You can use this screen to indicate if you are going to enter a single order or multiple orders at a time. Employees can also enter an order using an existing template or from an XML document that was generated by the Trading Partner Management order entry system.

  1. Access the Order Entry Window from the desktop.

  2. Choose the type of order you want to enter:

    - Single Order: Choose this option to enter a single order into the system. When you press the Next Button, the system will display the system Shipment Screen. Enter your order into this window and press OK when finished. You could use this method to quickly enter a missed order into the system.

    - Multiple Order: Choose this option to enter multiple orders or implement a rollout. Choose the company that the order is for and press the Next Button. The system will display the first screen in the system Order Entry wizard, the Customer/Ship To Selection screen. You can use this wizard to enter the order's ship to addresses, routing information, header information, and item(s).

    - Use Template: Choose this option if you want to load a template to enter orders into the Order Entry Window. When you press the Next Button, the system will display the Ship To Selection screen in the wizard (using the information from your template). These templates are created on the Item Selection screen of the Order Entry Window. You can only use/create templates when entering multiple orders.

    - Web Order: Choose this option to load a pre-configured order from an XML document. You can use this to validate orders entered into the Trading Partner Management order entry system or by external web users over the web.

    3.  

  3. Press the Next Button.

    - If you are entering a single order, the system will display the Shipment Screen.

    - If you are entering multiple orders, the system will display the Order Entry wizard.

 

 

2. Ship To Selection Screen...

This is the second screen of the Order Entry wizard. The system will display this screen if the user has chosen to enter the "multiple orders" option, the "use template" option, or the "web order" option on the Mode Selection screen. The values on the left pane of this window represent the ship to addresses that are eligible for inclusion on this order. The values on the right pane of this screen represents the ship to addresses of the customers that you are creating this order for. The system will default this data from a template if one has been chosen from the Mode Selection screen.

 

NOTE: To add a new ship to address, select "New Ship To" from the Actions Menu. The system will display the Customer Window

  1. Add a ship to address to the order by choosing:

    - Company/Customer/Ship To or a Ship To Template.

    OR

    - Ship To Template Button if you want to load a template that contains a batch of ship to addresses. These templates are set up in the Order Ship To Selection Window.

    OR

    - Import Text File Button to load a text file that was generated by your ERP system. This option will not be available unless you activate the "Import Ship To Addresses" exit point. Ask your consultant for more information.
     
  2. Press the Add To List Button to add this to the screen's left pane.

    3.  

  3. Use the Arrow Buttons to add/remove ship to addresses to the right pane of the screen. This pane categorizes the addresses as "manually-selected" or "imported."

    4.  

  4. To edit a ship-to's address information, right-click a record in the right pane and choose Edit Address. The system will display the Address Edit Window. You can use this window to override the properties of a ship-to address. These changes are for this order only, as they do not update the configuration record for this address. Press OK when finished editing.

     

  5. Press the Next Button. The system will display the next screen in the wizard.

 

 

3. Routing Selection Screen...

This is the third screen of the Order Entry wizard. You can use the Routing Selection screen to choose the carrier and delivery date information for your new orders.

  1. Choose how you want the system to ship your order(s):

     

    • Select the Carrier/Service Button if you want to assign your order to a specific service.

       

    • Select the Carrier Group Button if you want to assign your order to a specific carrier group.

       

  2. Use the Default Carrier/Service Button & Field to load a customer's default carrier and service (as defined on the Customer Window). Choose the customer name and press the button. The system will load the default values of the customer you choose into the carrier and service fields.

     

  3. Use the Routing Code Field if you want to associate a routing code (i.e. fragile, hazardous, etc). This is helpful if the system needs to make a special determination over which carrier(s) should be used to ship this order.

      4.  

  4. Use the Freight Terms Field if you want to associate a freight term with this order.

     

  5. Choose a Scheduled Ship Date and, if appropriate, a Requested Delivery Date for your order(s).

     

  6. Press the Next Button. The system will display the next screen in the wizard.

 

 

4. Miscellaneous Selection Screen...

This is the third screen of the Order Entry wizard. You can use the Miscellaneous Selection screen to complete entering order header information. None of the fields on this window are mandatory.

 

General Tab

  1. Enter any additional order header information on the Miscellaneous Tab.

     

    • Select a Warehouse where the order will be picked. The system will default to the user's current warehouse.

       

    • Provide an Order Type if you want to indicate a specific order status, such as "seasonal," "rush," or "emergency."
       
    • Add an Order ID Prefix if you want the system to add a prefix to all orders created in the current order entry session. For example, if you entered the value "CMP" in this field, the final shipment ID's for these orders would be "CMP-01", "CMP-02", "CMP-03", etc.
       
    • Add a Priority to an order, such as "1" or "2". The system uses this field to determine when it should select or process an order, based on its priority in relation to the other orders that need processing.
       
    • Check the Override Customer Check box if you want to bill the order to a different customer than you are shipping to. The system will display a window in which you can search for a different customer to bill to.
       
    • Indicate a Process Type if you want to label this order with an additional classification. For example, this field might be defined to indicate what type of monetary processing an order requires (cash or credit card).

     

  2. If appropriate, associate Customer Category Codes to your order.

     

  3. Use the Default Categories Button & Field to load a customer's default categories (as defined on the Customer Window). Choose the customer name and press the button. The system will load the default values of the customer you choose into the category fields.
Comments Tab

  1. Right-click on the record list and select Add Comments. The system will display the Comment Entry Window.

     

  2. Choose a comment type and enter your comment's text in the Comment Field. Press the Add Button. The system will list your comment in the record list.

     

  3. Press OK. The system will store these as header-level comments.
     
  4. When finished, press the Next Button. The system will display the next screen in the wizard. .

 

 

5. Item Selection Screen...

This is the fourth screen of the Order Entry wizard. This screen allows the user to choose the items to be included on the orders. When you are finished entering data in this window, the system will create the orders. Also, you can create special item order entry data template records that can be used the next time you want to enter an order. The values on the left pane of this window represent the items that are eligible for inclusion on this order. The values on the right pane of this screen represent the items that you have included on this order.

 

NOTE: The order entry process will accept an Inactive item, if there is an alternate item defined on the item master.

 

  1. Add an item to the order by choosing a Company and Item Number

    OR

    Choose a order entry Item Template

  2. Press the Add To List Button to add this to the screen's left pane

     

  3. Enter the Quantity and UM (Unit of Measure) of the item that you want to add to your order.

     

  4. Use the Arrow Buttons to add the item(s) to the right pane of the screen. This will add the item(s) to your order.

     

    Alternate Items: If there is an alternate item associated to the item you are ordering, the system will prompt you indicating that the current item is obsolete. You can then choose whether or not to add the alternate item to your order. You will not be able to add the obsolete item to your order.

     

    Substitute Items: The system will alert you that you can add a substitute item to an order if there is not enough quantity available of the original item. You can then choose to add the substitute item to the order, or go ahead and add the original item.

     

  5. Associate a comment to this item by right-clicking a record in the right pane and choosing Add Comment. The system will display the Comment Entry Window. Enter your comment by choosing a comment type and entering a text value. Press OK. Your comment will be displayed in the record list. The system will store these as detail-level comments.

     

  6. You can also change the quantity of an item by entering a new value in the Quantity column. The system will pass any changes you make to the quantity value to the shipments you are creating, as well as the template when/if one is chosen.

     

  7. You can also change the price of an item by entering a new value in the Price column. The system will pass any changes you make to the price value to the shipments you are creating, as well as the template when/if one is chosen.

     

  8. Use the Save as Template Checkbox if you want to save the current order as a template.

     

    • If this check box is checked, the flow of screens in the current order entry session will be saved as a template. When you press Finish, the system will display the Template Name Selection Window. Provide a name and description for your order entry template. Press OK. The system will save your template. You can then load this template in future sessions using the Use Template Button on the first screen of the Order Entry Window.

       

    • If this check box is not checked, the system will process the order without saving it as a template.

       

  9. Use the Create Shipments Checkbox and the Create Orders Checkbox to indicate how the system will process these order(s). NOTE: The created shipment's status will depend on the "Add From Order Entry" value on the Outbound Status Action Window.

     

    • If ONLY the Create Shipments Checkbox is checked, the order entry module will output shipments.

       

    • If BOTH the Create Shipments and the Create Orders Checkbox are checked, the order entry module will output shipments AND orders.

       

  10. Press the Finish Button. The system will create:

     

    • Templates: If you selected the Save As Template Checkbox. You can load this template on the mode selection screen when entering future orders.

       

    • Shipment(s): If you selected the Create Shipments Checkbox.

       

    • Orders AND Shipments: If you selected the Create Shipment and Create Orders Checkboxes.
