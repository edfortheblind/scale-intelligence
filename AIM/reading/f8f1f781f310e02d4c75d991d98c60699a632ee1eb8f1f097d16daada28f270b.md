
        
        <h1 data-source-node="n56">Creating Custom DIF API's</h1>
        <p data-source-node="n57">If the DIF Message Processing Service finds an incoming message in the database, the service will send the message’s data to an API. You will need to create this API, as it is not included with the SCALE application. When this API is executed, it parses the message data, and sends the data to the appropriate SCALE business logic (as defined in the DIF event). For example, if container ID and weight values were sent, the SCALE close container logic would perform the container close action (if defined in the DIF event).</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">For detailed information on how to create a custom API, please see the SCALE <a href="81d022a2ab379af5c9e945433d1bd3f6e09728fcfd355546989e79b3a0ecfa54.html" data-source-node="n60">SDK</a>.</p>
