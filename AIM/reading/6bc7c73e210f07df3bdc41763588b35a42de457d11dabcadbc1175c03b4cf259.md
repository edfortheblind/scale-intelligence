
        
        <h1 data-source-node="n56"><a name="kanchor1347" data-source-node="n57"></a>Location Template Field</h1>
        <p data-source-node="n58">The location template associated with a specific location. A location 
 template determines the structure of a location's ID. It generally includes 
 separator characters that should be added to an item number at specific 
 intervals. For example, if your loose bulk locations are defined in the 
 aisle-bay-level structure, there template would include two dashes, which 
 are separator characters that occur at specific intervals: ### - ### - 
 ###. Note that if the separator character is blank, then all the segments 
 will be concatenated together with no separator at all (in the above example, 
 the template would be #########, with no dashes).</p>
        <p data-source-node="n59"> </p>

 you can define the location (or location range).</p>
