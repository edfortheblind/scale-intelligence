        <p data-source-node="n57">The system includes predefined statuses per functional area. These predefined 
 statuses allow you to complete common warehouse transactions, such as 
 ship confirmation and packing. You cannot change system defined values. 
 See the <a href="5457fa08c32aa8b1137227340752ca7675d89f3e0a75f512094c3fb5a453b39d.html" data-source-node="n58">Status Overview</a> topic to 
 review the system defined statuses, per functional area, that are included 
 with the system.</p>
