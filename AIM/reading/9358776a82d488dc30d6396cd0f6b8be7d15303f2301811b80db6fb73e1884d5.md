
        
        <h1 data-source-node="n56"><a name="kanchor1860" data-source-node="n57"></a>URL To Call Field</h1>
        <p data-source-node="n58">You can use this field to indicate what you want the system to display 
 when a menu option is selected on the Trading Partner Management main 
 menu. You can only input a value in this field if you are creating a record 
 for a top-level "inquiry" web screen, NOT a "results" 
 or "details" screen.</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">If this field 
 has a value, the system will display the provided URL. For example, 
 suppose there is a record for the web screen "OutboundStatisticsInquiry," 
 and the URL to Call Field contains a value. The system then would display 
 your custom page when this option is chosen in TPM.<br data-source-node="n61"> </li>
            <li data-source-node="n62">If this field 
 is blank, the system will display the base system page. For example, 
 suppose there is a record for the web screen "OutboundStatisticsInquiry," 
 and the URL to Call Field is blank. The system, then, would display the 
 Outbound Statistics Inquiry Window when this option is chosen in TPM.</li>
        </ul>
