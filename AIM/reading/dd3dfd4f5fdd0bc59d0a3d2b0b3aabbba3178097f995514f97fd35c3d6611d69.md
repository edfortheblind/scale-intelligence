
        
        <h1 data-source-node="n56"><a name="kanchor2008" data-source-node="n57"></a>Document Type Field</h1>
        <p data-source-node="n58">This field identifies if a document is a paper or label document, when 
 it will print, and what data it can display. Common document types include 
 bill of lading, pick list, shipping label and pack list. All documents 
 must be associated with a document type. Document types are defined on the Document 
 Type Window. The system includes predefined document types that should 
 accommodate most business needs. You can create additional document types 
 to support documents that are unique to your warehouse.</p>
