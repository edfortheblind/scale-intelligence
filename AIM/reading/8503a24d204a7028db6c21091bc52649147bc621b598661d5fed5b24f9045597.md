
        
        <h1 data-source-node="n56"><a name="kanchor1632" data-source-node="n57"></a>Reviewing LTL Classes</h1>
        <p data-source-node="n58">Review the system-provided LTL 
 classes on the LTL 
 Class Window. When you rate LTL 
 carriers, an LTL 
 class has to be associated with a container. The LTL 
 Class is used 
 to classify what type of item you are loading on the LTL 
 truck. Note that if you require additional LTL 
 classes, you may create them on the LTL 
 Class Window. If you are using Progistics for rating, make sure Progistics
 supports the new LTL 
 class before you create it.</p>
