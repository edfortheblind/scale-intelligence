From Quantity Field

The value in this field is dependent on the status of the instruction:

  • If the instruction has not been completed, this field will contain the value generated during the work creation process.

     

  • If the instruction is currently being processed, this field will contain the amount of product not yet obtained from the location.

     

  • If the instruction has been confirmed, this field will contain the value '0'.

This field identifies the quantity that should be removed from the from location. It appears on the Work Instruction Window.
