
        
        <h1 data-source-node="n56"><a name="kanchor1577" data-source-node="n57"></a>Quantity Verification Field</h1>
        <p data-source-node="n58">This field indicates if you want the user to verify the quantity being picked. When you have this field set to <i data-source-node="n59">Yes</i>, the TalkMan will ask you to verify the quantity.  When this field is set to <i data-source-node="n60">No</i>, the TalkMan will pick the full quantity right away, unless it is a lot-controlled item.  This is because the TalkMan will ask for the quantity of a lot-controlled item.</p>
