
        
        <h1 data-source-node="n56"><a name="kanchor631" data-source-node="n57"></a>Treat As Loose Checkbox/Toggle</h1>
        <p data-source-node="n58">If this checkbox or toggle is selected, the system will not actually create a 
 "full case" container for that level. The item quantities will 
 still be shown in the base unit of measure (each, 
 for example). However, when the system decides what container to put the 
 item quantity in, it will not break up a UM's quantity across containers. 
 The system will use the dimensions of that UM (rather than the base UM   times the quantity) when determining 
 which container type to use.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: The system will only use this value from the shipment line (in the manner described above) if no item unit of measure records for that item or item class exist. </p>
