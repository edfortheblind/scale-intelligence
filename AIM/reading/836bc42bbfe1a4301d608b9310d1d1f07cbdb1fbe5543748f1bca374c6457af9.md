
        
        <h1 data-source-node="n56">Reviewing the *Default Rule</h1>
        <p data-source-node="n57">You may want to review the "*Default" rule record on the Locating 
 Rule Window to make sure it is correct for your warehouse flow. When a 
 rule is not associated with an item (on the Item Window) or defined on 
 the receipt line or container, the system will locate it using the *Default 
 record. To minimize setup time, edit the default rule so that it can be 
 applied to many item records.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Accessing the *Default Rule Record...</h4>
        <ol class="ol_1" data-source-node="n61">
            <li value="1" data-source-node="n62">Open the Locating Rule configuration window.<br data-source-node="n63"> </li>
            <li value="2" data-source-node="n64">Open the *Default 
 record in the record list. Review the information, and change if necessary.</li>
        </ol>
