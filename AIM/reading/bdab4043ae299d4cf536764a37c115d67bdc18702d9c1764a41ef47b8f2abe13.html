Processing a Wave

Most orders entering SCALE are processed into the system via a wave. A wave is a group of orders that the system is going to bring into SCALE (as shipments) using the same processing logic. You will use the Wave Insight screen to manage waves and their orders.

Deleting a Wave...

You can delete any wave that has not been run. When you delete a wave, all the shipments are returned to the pool and can be assigned to a new wave. You can delete waves from the Wave Insight screen.

 

 

 

 

Closing a Wave...

When you close a wave, new shipments cannot be added to it. This is especially helpful when you are creating a wave using a record with no maximums. A wave can only be closed if it has not been run. To close a wave, open a wave and select the Closed Checkbox. The system will close the wave and not accept additional shipments.

 

 

 

 

Releasing a Wave...

If a wave was not set to automatically release, you will need to manually release it to the warehouse. When you release it, the work generated for this wave becomes available for processing.

 

From the Wave Insight Screen:
  1. Locate the wave that you want to release.

  2. Select the Release action. The system will display a confirmation window.

  3. Press Yes, and the system will release the wave and will remove the hold code from all work in the wave. The work is now available for processing.

 

 

 

Manually Consolidating Shipments...

Consolidation allows you to merge multiple shipments for the purpose of reducing shipping costs. All consolidated shipments must meet the required criteria defined on the Consolidation Criteria Window. Generally, these criterion require that consolidated shipments be sent to the ship to address, from the same company, etc. However, any non-required criteria are optional: shipments can be consolidated when they do not share the same non-required values. Common non-required values include carrier or other values that can be changed on a shipment, if necessary. These values are defined on the Consolidation Criteria Window.

 

- The following are the rules regarding a shipment's eligibility for manual consolidation:

  • You can consolidate shipments that are in an In Pool status only with other shipments that are in an In Pool status.

  • You can consolidate shipments in a Wave Pending status only with other shipments assigned to that same wave.

  • You can consolidate shipments beyond a Wave Pending status if their associated wave has been released, or if they have no associated wave. They may only be consolidated with other shipments whose wave has been released, or who has no associated wave.

  • You cannot consolidate shipments that are on a wave that is either currently running or has completed running, but has not yet been released.

  1. Access Planned Shipment Insight screen. Access the shipment that you want to find consolidation opportunities for.

     

  2. Select the Consolidate action. The system will display the Shipment Consolidation screen. Information about the shipment that you want to consolidate is provided.

     

  3. These shipments are divided into two accordions:

     

    • Shipments that meet "all criteria". This shipment is the perfect consolidation opportunity since it shares the same criteria values as the shipment that you want to consolidate.

       

    • Shipments that just meet the "required criteria". All consolidation opportunities must meet the required criteria. However, shipments in this category do not share the same non-required criteria values as the shipment that you want to consolidate. These shipments are denoted with a caution icon to ensure that you recognize that consolidation can occur, but might not be appropriate. You will need to review the shipments in this category before consolidating.

     

  4. Select which shipment(s) in the record list should be consolidated with your shipment.

    5.  

  5. Press the Consolidate Button. The system will consolidate the shipment(s).

 

 

 

Building a Wave...

During the wave building process, the system assigns pooled shipments to the appropriate wave(s). When you select the Build Wave action, the system will process through all of its In Pool shipments of a certain warehouse and create as many waves as possible, using the wave master of your choosing.

  1. Access the Wave Insight, and select the Build Wave action. The system will display the Build Wave screen.

  2. Choose the warehouse for which you want to build a wave. Select a wave master for the warehouse. Only the authorized wave masters for the selected warehouse are displayed for selection.

  3. Press OK, and the system will initiate wave building. It will assign all eligible pool shipments to the appropriate waves. The system will process through all the wave template records, in priority order, and compares them to the pooled shipments. When a record's parameters match a shipment, the system builds a wave and assigns the shipment to it. Additional shipments that meet the record's criteria are also assigned to the wave.

    - If a shipment meets the criteria of multiple waves, the system will assign the wave with the highest priority.

    - If a shipment does not meet the criteria of any wave template, it will remain in the pool. When this process is finished, the system will display a success message.

Note: In some scenarios, the wave will cause bad data, when waved shipments are distributed to an existing shipment with allocate complete checked. In such scenarios, user needs to check shipment has allocation completion checked. This will ensure that no bad data is created on completion of wave.

For building a wave using Wave Insight, see the Using the Wave Insight Screen topic.

 

 

 

 

Manually Running a Wave...

If a wave was manually created, or operates in manual mode, you must manually execute it.

  1. Access the Wave Insight, and locate the wave that you want to run.

  2. Select the Run Wave Action. The system will display a confirmation window.

     

    NOTE: The Run wave action under the Action menu of Wave Insight screen is disabled for completed, released, or failed wave.

  3. Verify that you want to run the wave. The Current Wave Step field in the grid displays the wave step that is currently running. Only one wave can be executing a certain step at one time. Many waves can, however, be running at a certain time; they just have to be executing different steps. For example, if you ran several waves at one time, they all would execute concurrently. However, only one wave would be executing a certain wave step at a given time: one would run the allocation step, one the paperwork step, etc. Therefore, no two waves would ever be running the same step at the same time.

    NOTE: If all detail lines on a shipment fail the allocation wave step, the entire shipment is removed from the wave and returned to the pool, if your Outbound Status Action for Reject in Wave is set to "In Pool." If this is set to "Delete," then when all lines reject for a shipment, you will get a shipment in the pool with no lines attached.

  4. Press the Apply Filter button to refresh the screen. Once the wave has completed, the Status field will be set to Completed. If the wave insight is grouped on the Status field, the wave will move from the Active group to the Completed group.

 

 

 

 

Removing a Shipment from a Wave...

You can remove a shipment from a wave unless its been run.

 

From the Insight Screen: 

 

You can remove a shipment from a wave unless its been run.

  • Locate a shipment that is on active wave from shipment insight, pool select the record, and choose the Remove action. The system will display a confirmation window.

  • Verify that you want to remove this shipment from the wave.

  • Press OK, and the system will display success message after removing that shipment from the wave. The shipment will be returned to the pool.

 

 

 

Removing the Rejection Note from a Shipment...

When a shipment either fails a wave step or is canceled from the Shipment Insight, it is considered rejected. Rejected shipments are denoted with a yellow hazard triangle icon and a message in the Rejection Note Field. After you review a rejected shipment, you may want to remove the rejection indicators and reprocess it. Note that it is recommend that you remove the rejection note before adding this shipment to a subsequent wave. The system will never automatically remove the rejection note. So unless the rejection note is manually removed, a previously rejected shipment will always appear rejected even after it has been successfully processed through a wave. To do this, access the shipment and select the Clear Rejection Note action. The system will remove the rejection note.

 

 

 

 

Load Building During a Wave...

During a wave (which includes the load building wave step), the system can assign shipments to appropriate shipping loads. For more details, see the Load Building section of the Defining Wave Flows topic.

 

 

 

 

Routing a Pooled Shipment...

During a wave, the system will route shipments to carriers if routing is a wave step. However, a user can manually route a pooled shipment. This is especially helpful if you only route a few shipments and do not want to run all shipments through the routing wave step. It can also be used to research and test carrier routing outside of a wave. To do this, locate the pooled shipment that you want to route and select the Route action. The system will route the shipment. It will display a confirmation window identifying the carrier/service that it assigned to this shipment. Is this carrier/service acceptable? If yes, press OK. The shipment is routed to this carrier/service. If no, press Cancel. The shipment will not be routed to this carrier. You can manually assign a carrier/service on the Shipment Screen.
