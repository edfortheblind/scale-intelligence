
        
        <h1 data-source-node="n56"><a name="kanchor726" data-source-node="n57"></a>Container Count Fields</h1>
        <p data-source-node="n58">These fields represent the number of containers that are on a shipment (2 of 5, 1 of 1, etc)</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">During the container creation wave step, the system assigns container 
 count values to all containers it creates for a shipment.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">You can assign these values to containers created outside of a wave 
 to identify packages shipped as a grouping. For example, if there are 
 5 containers that should be shipped as a group, the first container would 
 be Container 1 of 5. Subsequent containers would be assigned numbers 2, 
 3, 4, 5.<br data-source-node="n64"><br data-source-node="n65"></li>
            <li data-source-node="n66">
                <p data-source-node="n67">When you close the last container in the group, the system can generate 
 one shipment pack list that includes all of the containers in the group. 
 In addition, vendor compliant labels can include these fields.</p>
            </li>
        </ul>
