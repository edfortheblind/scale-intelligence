        <h4 data-source-node="n148"><a name="Confirming" data-source-node="n149"></a>Confirming a Work 
 Order...</h4>
        <p data-source-node="n150">You will confirm a work order to identify the finished item as complete. 
 At that time, this item is considered inventory in the warehouse. You 
 cannot confirm a finished item when there is not enough component quantity 
 at the build location. If this is attempted, the system will alert you 
 of the situation. You will then need to perform some inventory adjustment(s) 
 before you will be allowed to confirm the work order. You 
 cannot delete a work order if a non-inventory item has been allocated. 
 First, you must deallocate the non-inventory item, because non-inventory 
 items are marked as on hand immediately upon allocation. Once this deallocation 
 has occurred, you can then delete the work order.</p>
        <p data-source-node="n151"> </p>
        <p data-source-node="n152">Note: A new item/company/lot  confirmed quantity will take on the inventory status that already exists. This happens when all the inventory is in single status. It is only if the lot exists in multiple inventory statuses or the lot does not exist at all that the inventory status gets assigned from work order preferences.</p>
        <p data-source-node="n153"> </p>
        <p data-source-node="n154">Access the Work Order Insight Screen:</p>
        <ol data-source-node="n155">
            <li value="1" data-source-node="n156">
                <p data-source-node="n157">Access the work order that you 
 want to confirm, and select the Confirm Action. The system will 
 display the Work Order Confirmation screen.</p>
                <p data-source-node="n158"> </p>
            </li>
            <li value="2" data-source-node="n159">
                <p data-source-node="n160">The system may provide a License Plate ID (based on the License Plate Assignment value selected 
 on the Work Order Preferences screen). If this value is not provided, 
 define a License Plate ID. The License Plate Screen prompts for a license plate when work order preferences has Create Work unchecked. </p>
                <p data-source-node="n161"> </p>
            </li>
            <li value="3" data-source-node="n162">Use the Quantity 
 Field to identify how many finished item units you want to confirm.<br data-source-node="n163"><br data-source-node="n164"></li>
            <li value="4" data-source-node="n165">Use the Lot Field 
 to indicate the lot ID that is associated with this work order's finished 
 item. The system will inactivate this field if the finished item is not 
 lot controlled. <br data-source-node="n166"><br data-source-node="n167">NOTE: Entering a new lot will display the Lot Screen to capture inventory status or freeze the lot.  You can also change the lot and expiration date from this screen. <br data-source-node="n168"><br data-source-node="n169"></li>
            <li value="5" data-source-node="n170">
                <p data-source-node="n171">Use the Expiration Date Field 
 to indicate the expiration date that is associated with this work order's 
 finished item. The system will inactivate this field if the finished item 
 is not lot controlled. The Expiration Date is also disabled when an existing lot for the finished item is entered in the Lot field.  The expiration date will be filled with the date for the existing lot.  If the expiration date for an existing lot needs to be changed, then the user would need to use the Lot screen from the Lot insight to update the expiration date.</p>
                <p data-source-node="n172"> </p>
            </li>
            <li value="6" data-source-node="n173">
                <p data-source-node="n174">Use the Putaway Location Field 
 to identify the storage location for the finished item(s). If this item 
 has previously been located to a storage location, the system will default 
 that value in this field. For assistance in choosing a putaway location, press the Locate 
 Button. The system will display the Locating Rule Selection Screen. Choose 
 the locating rule that you want the system to use when calculating a location 
 (the system displays the item's default locating rule, as defined on the 
 Item screen), and press Locate. The system will run through the typical locating 
 logic, and choose a location. The Putaway Location Field then will be 
 populated with the newly-calculated location. </p>
                <p data-source-node="n175"> </p>
                <p data-source-node="n176">NOTE: The Locating Rule Selection Screen also defaults the split quantity when the selected locating rule from the  screen splits the quantity because the location can only fit part of the quantity being confirmed. For additional information, refer to the topic <a href="ee78649c7ada411fe3be07bde8e8b66f78d3269929161c2d4c4d6c54a8521dd7.html" data-source-node="n177">Locating Rule Selection Screen</a>. </p>
                <p data-source-node="n178"> </p>
            </li>
            <li value="7" data-source-node="n179">
                <p data-source-node="n180">Press Confirm. The system will:<br data-source-node="n181"><br data-source-node="n182">- Print the Work Order Finished Item 
 Putaway List if the Generate Paperwork on Confirm Check box is selected 
 on the Work Order Preferences screen.<br data-source-node="n183"><br data-source-node="n184">- Display the Work Order Serial Number 
 Entry Screen if you are confirming the work order for a serial-tracked 
 finished item. This screen allows you to indicate the serial number(s) 
 for the components of this finished item or component. Press Save when finished 
 entering these values. The system will confirm the work order.<br data-source-node="n185"><br data-source-node="n186"></p>
                <p data-source-node="n187">- Generate putaway work instructions 
 if work is created for finished item putaway (based on work order preferences 
 record).</p>
            </li>
        </ol>

        <h4 data-source-node="n192"><a name="Closing" data-source-node="n193"></a>Closing a Work Order...</h4>
        <p data-source-node="n194">You can close a work order or multiple work orders at any point in the work order process. . 
 </p>
        <ol data-source-node="n195">
            <li value="1" data-source-node="n196">
                <p data-source-node="n197">Open the Work Order Insight and access the work order that you 
 want to close.</p>
                <p data-source-node="n198"> </p>
            </li>
            <li value="2" data-source-node="n199">
                <p data-source-node="n200">Select the Close Action. 
 The system will close the work order. You 
 will not be able to complete any finished items on this work order.</p>
            </li>
        </ol>

        <h4 data-source-node="n205"><a name="Releasing" data-source-node="n206"></a>Releasing a Work 
 Order...</h4>
        <p data-source-node="n207">A work order cannot be processed until it is released. At that time, 
 employees can assemble the finished item. You can manually release a work 
 order in the Work Order Insight. You can choose to have the work order 
 automatically released when it is created, or manually released when appropriate. The system can allocate component parts automatically when you either 
 create a new work order or release an existing one. You can use the Work 
 Order Allocation Method Field on the Work Order Values screen. You can 
 also manually allocate component parts from the Component Parts Tab on 
 the Work Order screen. Note that you can update the build location of a work order when the 
 work order has not been released, 
 and no components on the work order have been allocated.</p>
        <ol data-source-node="n208">
            <li value="1" data-source-node="n209">
                <p data-source-node="n210">Access the Work Order Insight Screen. </p>
                <p data-source-node="n211"> </p>
            </li>
            <li value="2" data-source-node="n212">
                <p data-source-node="n213">Access the work order that you 
 want to release, and select the Release Action.</p>
                <p data-source-node="n214"> </p>
            </li>
            <li value="3" data-source-node="n215">
                <p data-source-node="n216">The system will display a verification 
 message. Verify that you want to release this work order. The system 
 will release the work.</p>
                <p data-source-node="n217"> </p>
            </li>
            <ul type="disc" class="ul_1" data-source-node="n218">
                <li data-source-node="n219">
                    <p data-source-node="n220">The system will allocate the 
 component parts if you set Work Order Allocation Method to 'Release'.</p>
                    <p data-source-node="n221"> </p>
                </li>
                <li data-source-node="n222">
                    <p data-source-node="n223">If work was created for this 
 finished item, it is removed from the hold status and can be executed.</p>
                    <p data-source-node="n224"> </p>
                </li>
                <li data-source-node="n225">The system 
 will print the Work Order Component Pick List if the Generate Paperwork 
 on Release Check box is selected on the Work Order Preferences screen.</li>
            </ul>
        </ol>

        <h4 data-source-node="n230"><a name="Allocating" data-source-node="n231"></a>Allocating/Deallocating a Work 
 Order...</h4>
        <p data-source-node="n232">You can allocate or deallocate component(s) from a work order with Work Order Line Insight Screen. The system can perform these actions either 
 per component or in a batch. </p>
        <p data-source-node="n233"> </p>
        <p data-source-node="n234">- Invoking the Allocate action will open the Work Order Component Allocation screen. You can select the allocation rule or enter the location from where the components needs to be allocated and tap on Allocate action. On allocating with both Allocation Rule and Location fields left blank, system will use the default allocation rule for allocation. Inventory is adjusted properly at both From and To locations on successful allocation. </p>
        <p data-source-node="n235"> </p>
        <p data-source-node="n236">NOTE: You can allocate work order line with and without work. System looks at the work order preference configuration to decide whether work needs to be created or not for the allocated quantity.</p>
        <p data-source-node="n237"> </p>
        <p data-source-node="n238">- Invoking the Deallocate action by selecting a line will deallocate the line. When the 'Allocated' flag is set to 'N', Inventory is adjusted properly at both From and To location on successful deallocation and system writes the deallocation history.</p>
        <p data-source-node="n239"> </p>
        <p data-source-node="n240">Refer to the topic <a href="4196b033e578df0f1407a5be0d499dca89dd2960b7980caa1be11b359d1d8677.html" data-source-node="n241">Using the Work Order Line Insight Screen</a> for additional information. </p>

        <h4 data-source-node="n247"><a name="AllocatingAll" data-source-node="n248"></a>Allocating /Deallocating all Work Order Lines...</h4>
        <p class="p_5" data-source-node="n249">You can allocate all component lines of work order or deallocate all the work components with Work Order Insight Screen. </p>
        <p class="p_5" data-source-node="n250"> </p>
        <p class="p_5" data-source-node="n251">- Selecting a work order and invoking Allocate All action will allocate all the work order lines and if all the lines are allocated, 'Allocated' flag is set to 'Y'. Inventory is adjusted properly at both From and To location on successful allocation. If one or more lines fails to get allocated, a message is shown indicating that only partial allocation is successful.</p>
        <p data-source-node="n252"> </p>
        <p class="TopicSubtitle_2" data-source-node="n253">NOTE: You can allocate a work order with and without work. System looks at the work order preference configuration to decide whether work needs to be created or not for the allocated quantity.</p>
        <p class="TopicSubtitle_2" data-source-node="n254"> </p>
        <p class="TopicSubtitle_2" data-source-node="n255">- Invoking the Deallocate All action by selecting a work order will deallocate all the work order lines. On deallocation, the 'Allocated' flag is set to 'N' on the deallocated work order lines, inventory is adjusted properly at both From and To location on successful deallocation, and the system writes deallocation history. </p>
