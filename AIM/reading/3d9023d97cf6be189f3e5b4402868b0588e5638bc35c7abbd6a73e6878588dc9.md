
        
        <h1 data-source-node="n56"><a name="kanchor455" data-source-node="n57"></a>Reviewing Transmit Status Values </h1>
        <p data-source-node="n58">A transmit status indicates whether the Manifests have been transmitted to the appropriate carrier or not. There are two Transmit statuses- Transmitted and Not transmitted. Transmitted status indicates an EDI (Electronic Data Interchange) file with manifest data has been transmitted for the carrier associated with the manifest.  Not transmitted status suggests that the manifest was not transmitted when the manifest was closed. Refer to the <a href="d32d1cb9599446837bccbe29c7d9c4ca40c84eef3f478481bcf51ff363aa63e1.html" data-source-node="n59">Using the Manifest Insight Screen</a> topic for more information. </p>
