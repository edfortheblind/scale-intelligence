Close After Partial Pick Checkbox

Use this checkbox to allow the user to partial pick the quantity of a work instruction, and the system will delete the remaining quantity from the work instruction. The system will then close the work instruction. Therefore, the remaining quantity will never actually be picked. Note that this option is only available for RF replenishment and work order picks.

 

 

Example...

For example, suppose you have a replenishment request that calls for 620 eaches of an item. The user, however, may only want to pick 600 eaches of the item (because that is a more round number in regards to how things are packed), so they just want the other 20 eaches to “go away.” If this checkbox is checked, the system would delete the remaining 20 eaches from the work instruction (after the user picks the 600), and close the work instruction.
