        <p data-source-node="n58">These values represent  technical values that determine 
 how the system uses wildcard search from the Insight screens will be configurable for both numeric and alphanumeric fields. These values will enable users to enable/disable the wildcard search across the insight screens.</p>
        <p data-source-node="n59">These values are used with the Wildcardsearch screen control attribute to include/exclude specific field for a specific insight screen.</p>
