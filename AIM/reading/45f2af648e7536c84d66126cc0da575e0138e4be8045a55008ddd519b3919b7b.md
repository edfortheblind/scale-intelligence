
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Receipt ID Type</h1>
        <p data-source-node="n58">A receipt ID type indicates what type of number is used as a receipt's ID. Common receipt ID types include PO number and manufacturer number. You will want to define valid receipt ID types in the system if you plan on allowing users to add receipts on the Receipt Workbench or the Receipt Insight screen.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Use the <b data-source-node="n61">Returns</b>  to indicate if you want receipts generated with this receipt type to be labeled by the system as "returns." The system uses this value when generating web statistics to differentiate receipts and returns.</p>
