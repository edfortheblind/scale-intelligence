
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Work System Values</h1>
        <p data-source-node="n58">These system-defined values accommodate specific events that may occur 
 during the work process. When the system encounters an unexpected experience 
 during work creation or work execution, it will display the appropriate 
 system defined values. You should not need to create unique values on 
 this configuration. </p>

 </p>

 value and append it to the existing container ID. Therefore, if container 
 A was split into two containers, the resulting two containers would have
