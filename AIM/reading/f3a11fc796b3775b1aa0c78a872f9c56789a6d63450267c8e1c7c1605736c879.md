
        
        <h1 data-source-node="n56"><a name="kanchor1955" data-source-node="n57"></a>Using the Desktop</h1>
        <p data-source-node="n58">The 
 Desktop will appear when you start the application. You will use the Desktop for configurations and some system administration functions. Also, the Desktop has such interactive features as user-defined groups for screen shortcuts, and configurable <a href="c53141cc7bb6a9fa71cc07ddfedfe862e527a7b3f9cb1b028b6df9eb40031bd5.html" data-source-node="n59">gadgets</a> that can display a wide range of warehouse-related data. Also, the system then will perform a security check to assess what functional components the user logging in
 has permission to access.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">NOTE: For information regarding Desktop gadgets, please see the topic <a href="c53141cc7bb6a9fa71cc07ddfedfe862e527a7b3f9cb1b028b6df9eb40031bd5.html" data-source-node="n62">Using Gadgets</a>.</p>

        <h4 data-source-node="n87"><a name="titlebar" data-source-node="n88"></a>Using the Titlebar...</h4>
        <p data-source-node="n89">The Titlebar is comprised of the space at the top of the Desktop, which includes several menus and the standard Windows minimize/maximize/close buttons. The following graphic outlines the different parts of the Titlebar:</p>
        <p data-source-node="n90"> </p>
        <p data-source-node="n91">
            <img src="../source/assets/a0c7500fc607df3a4bc9dc218369ca19f370b291466863c974622bce7d0153a5.jpg" loading="eager" data-source-node="n92">
        </p>
        <p data-source-node="n93"> </p>
        <p data-source-node="n94"> </p>
        <p data-source-node="n95">(A) User Name: This area displays the name of the current user that is logged into the system. Note that the name displayed here is the Description value of your user profile record.</p>
        <p data-source-node="n96"> </p>
        <p data-source-node="n97">(B) Warehouse: Your current warehouse is displayed as a drop-down menu on 
 the Titlebar. The warehouse that initially displays is the default on your user profile record. You can change the warehouse that you are currently viewing data from by selecting a different one from this menu.</p>
        <p data-source-node="n98"> </p>
        <p data-source-node="n99">(C) Quick Launch Menu: You can quickly access any system window from the Titlebar. When you choose a window from the drop-down list and press the Go button (or the keyboard's Enter button), the system will display the selected window.</p>
        <p data-source-node="n100"> </p>
        <p data-source-node="n101">(D) Help Menu: You can access the online help and the SCALE informational screen using the Titlebar. </p>
        <p data-source-node="n102"> </p>

        <h4 data-source-node="n106"><a name="taskbar" data-source-node="n107"></a>Using the Taskbar...</h4>
        <p data-source-node="n108">The Desktop's Taskbar includes the shortcuts that you can use to access the windows defined on the desktop.  Note that if you do not have security to access a certain window, it will appear inactivated. </p>
        <p data-source-node="n109"> </p>
        <p data-source-node="n110"> </p>
        <p data-source-node="n111">
            <img src="../source/assets/7ab2cce3ef664d51c6b4b1ae86812825b07e8abbfe9217b9335b817a87d5f926.png" loading="eager" data-source-node="n112">
        </p>
        <p data-source-node="n113"> </p>
        <h4 data-source-node="n114">Docking the Taskbar...</h4>
        <p data-source-node="n115">You can dock the Taskbar to the left-hand side of the screen. This is helpful if you need extra room on the screen.</p>
        <p data-source-node="n116"> </p>
        <p data-source-node="n117">1. Press the Push Pin button on the top right corner of the Taskbar.</p>
        <p data-source-node="n118"> </p>
        <p data-source-node="n119">
            <img src="../source/assets/4e031c59d7c94ef980493b38c0e63fc8f543ae797923367a67c875509d982395.PNG" loading="eager" data-source-node="n120">
        </p>
        <p data-source-node="n121"> </p>
        <p data-source-node="n122">2. The system will then dock the Taskbar to the left side of the Desktop.</p>
        <p data-source-node="n123"> </p>
        <p data-source-node="n124">
            <img src="../source/assets/141424295e0cb1fcab1ba30e297a8131692f048fd8aad9f49c460c0e726f3c43.PNG" loading="eager" data-source-node="n125">
        </p>
        <p data-source-node="n126"> </p>
        <p data-source-node="n127">3. To have the Taskbar reappear, hover the mouse over the Taskbar button.</p>
        <p data-source-node="n128"> </p>
        <p data-source-node="n129"> </p>
        <h4 data-source-node="n130">Shortcut Groups</h4>
        <p data-source-node="n131">You can create custom menu shortcut groups on the Taskbar. These groups can contain 
 any number of links to various application windows. Also, these shortcut groups are user-specific, 
 so different users can maintain their own separate groups. In addition to creating groups, you can also delete/edit the existing groups as well.</p>
        <p data-source-node="n132"> </p>
        <p data-source-node="n133"> </p>
        <h5 data-source-node="n134">To Creating A New Shortcut Group</h5>
        <ol class="ol_1" data-source-node="n135">
            <li value="1" data-source-node="n136">Right-click the Desktop Taskbar, and select Add Group. The system will 
 add a new shortcut group to the bottom of the Taskbar menu.<br data-source-node="n137"> </li>
            <li value="2" data-source-node="n138">Right-click the 
 name of the new group and choose Rename Group. Provide text for 
 the name and press the Enter button. The system will now display the group's new name on the Taskbar.</li>
        </ol>
        <p data-source-node="n139">
            <img src="../source/assets/353b73a2684895643dd3853670a674b007cea5bd3bda3aba1b0d467e45c29aa5.PNG" loading="eager" data-source-node="n140">
        </p>
        <p data-source-node="n141"> </p>
        <h5 data-source-node="n142">To Add Window Shortcuts To An Existing Shortcut Group</h5>
        <ol class="ol_1" data-source-node="n143">
            <li value="1" data-source-node="n144">Access the shortcut that you want to add to your shortcut group.<br data-source-node="n145"><br data-source-node="n146"></li>
            <li value="2" data-source-node="n147">With the mouse, drag and drop the shortcut to your group.<br data-source-node="n148"><br data-source-node="n149"></li>
            <li value="3" data-source-node="n150">The system will then add the shortcut to your group.<br data-source-node="n151"></li>
        </ol>
        <p data-source-node="n152">
            <img src="../source/assets/f427cd9d6e3557784134cea87903b2921ae6bfe40e9681ba39706c3d5541035c.PNG" loading="eager" data-source-node="n153">
        </p>
        <p data-source-node="n154">- You can also move shortcuts back to their original group, and move them around in order on a jumplist.</p>
        <p data-source-node="n155"> </p>
        <p data-source-node="n156">- You cannot delete a shortcut group that contains link(s) in it. You will first need to remove the links, and then the system will allow deletion of the group.</p>
        <p data-source-node="n157"> </p>
        <p data-source-node="n158">- You cannot create a group name using the character ^ .</p>

        <h4 data-source-node="n164"><a name="desktopSettings" data-source-node="n165"></a>Defining Desktop Settings...</h4>
        <p data-source-node="n166"> </p>
        <h5 data-source-node="n167">Changing the Background Image</h5>
        <p data-source-node="n168">By default, the Desktop displays a warehouse image in the background. You can choose to add a custom graphic image as the background of the Desktop.</p>
        <p data-source-node="n169"> </p>
        <p data-source-node="n170">1. On the Desktop, right-click the Desktop area and choose Desktop Settings. The system will display the Desktop Settings Window:</p>
        <p data-source-node="n171"> </p>
        <p data-source-node="n172">
            <img src="../source/assets/6b061cc9cbed168f8199b64a1bd5083236b59019f0355e8c8411aa7f1d8ea4db.jpg" loading="eager" data-source-node="n173">
        </p>
        <p data-source-node="n174"> </p>
        <p data-source-node="n175">2. Use the Background Image Path Field to indicate where the image that you want to use as a background is located. Note that the image file must be located in a local directory of the machine that you are using (provide a local path, as seen in the above example). The type of image files that are supported are .bmp, .gif, .jpeg, .jpg, and .png.</p>
        <p data-source-node="n176"> </p>
        <p data-source-node="n177">3. Select the Disable Background Image Checkbox if you want the system to not display an image on the Desktop (the background will appear completely white).</p>
        <p data-source-node="n178"> </p>
        <p data-source-node="n179">4. Use the Background Image Stretch Field to indicate how you want the system to display your image on the Desktop:<br data-source-node="n180"></p>
        <ul data-source-node="n181">
            <li data-source-node="n182">None - Indicates that the image will be displayed in its original size (without any stretching).<br data-source-node="n183"><br data-source-node="n184"></li>
            <li data-source-node="n185">Fill - Indicates that the image will completely fill the current dimensions of the Desktop.<br data-source-node="n186"><br data-source-node="n187"></li>
            <li data-source-node="n188">Uniform - Indicates that the image will be resized to fit in the Desktop's dimensions while it preserves its native aspect ratio.<br data-source-node="n189"><br data-source-node="n190"></li>
            <li data-source-node="n191">Uniform To Fill - Indicates that the image will be resized to fill the Desktop's dimensions while it preserves its native aspect ratio. If the aspect ratio of the destination rectangle differs from the source, the source content is clipped to fit in the Desktop's dimensions.</li>
        </ul>
        <p data-source-node="n192">5. Press OK to save your settings. The image you defined will now display as the Desktop background.</p>

        <h4 data-source-node="n197"><a name="custom" data-source-node="n198"></a>Adding a Custom Desktop Logo...</h4>
        <p data-source-node="n199">You can also add your company's logo to the bottom of the Desktop screen.</p>
        <p data-source-node="n200"> </p>
        <p data-source-node="n201">1. Place the logo's graphic file in the Resource/Images folder on your application server. Note that if you have multiple application servers, this file will need to be present on each of these servers.</p>
        <p data-source-node="n202"> </p>
        <p data-source-node="n203">2. In the application's System Text Editor, search for the Images BMP_INSERTLOGO  key. Update this resource key with the name of the image.  </p>
        <p data-source-node="n204"> </p>
        <p data-source-node="n205">3. To view the new logo on the Desktop, you will need to commit the Image resource by clicking Apply from the System Text Editor, and restart the application.</p>
