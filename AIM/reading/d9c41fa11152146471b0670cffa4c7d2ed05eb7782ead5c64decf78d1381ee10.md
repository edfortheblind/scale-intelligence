
        
        <h1 data-source-node="n56"><a name="kanchor1504" data-source-node="n57"></a>Show Container Contents Toggle</h1>
        <p data-source-node="n58">This toggle indicates if the system will display the contents of a 
 container, in addition to the container's "header" information, as separate 
 record(s) in the Shipping Container Insight Screen. Note that the system defaults this 
 toggle as not selected.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">If this toggle is selected, 
 the system will display a record that represents the actual container    AND a record for each item packed 
 in that container. The item-level records will have a    dash 
 ("-") as the value for the Container Type Field. <br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">If this toggle is not selected, the system will only display actual container records.</li>
        </ul>
