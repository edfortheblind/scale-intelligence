
        
        <h1 data-source-node="n56"><a name="kanchor435" data-source-node="n57"></a>Allocate Full Location Quantity Checkbox/Toggle</h1>
        <p data-source-node="n58">This checkbox/toggle allows you to indicate if you want the system to attempt 
 to find a location where it can allocate the exact amount that is required 
 on the shipment line. If the system does not find this location, allocation 
 will fail. For example, suppose a shipment line that requires 40 feet of garden 
 hose, and you have this checkbox selected. When the system attempts to 
 allocate quantity for this line, if a location is not found that contains 
 exactly 40 feet of hose, allocation will fail.</p>
