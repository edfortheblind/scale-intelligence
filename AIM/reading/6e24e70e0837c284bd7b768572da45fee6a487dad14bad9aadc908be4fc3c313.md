
        
        <h1 data-source-node="n56"><a name="kanchor1840" data-source-node="n57"></a>Default Flow Field / In Default Flow Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates the default flow associated 
 with a functional area. When a specific status flow is not associated 
 with a receipt line or shipment line, the system will process it using the 
 default flow. Use the In Default Flow Checkbox to add or 
 remove a status from the default flow. The default flow should support the processing 
 required for most of your products.</p>
        <blockquote data-source-node="n59">
            <p data-source-node="n60">- Selected: This status should be included in the default status flow. It can be 
 applied to the majority of products processed through the warehouse.</p>
            <p data-source-node="n61"> </p>
            <p data-source-node="n62">- Not Selected: This step should not be included in the default status flow. It is reserved 
 for user created unique status flows.</p>
        </blockquote>
