
        
        <h1 data-source-node="n56"><a name="kanchor1695" data-source-node="n57"></a>Reviewing Work Creation Process Values</h1>
        <p data-source-node="n58">A work creation process initiates the generation of work units/instructions 
 in the system. When you select a work process on the Work Creation Master 
 Window, the system narrows the available work criteria options to only 
 those that are eligible for this work process. These values are predefined, 
 and you cannot add new ones.</p>

        <h4 data-source-node="n83">Descriptions...</h4>
        <p data-source-node="n84"> </p>
        <p data-source-node="n85">Work creation is initiated by any of the following system processes:</p>
        <blockquote data-source-node="n86">
            <p data-source-node="n87"> <i data-source-node="n88">Allocation</i> - Work creation 
 is initiated to process allocation requests. During allocation, the system 
 selects allocation locations. Work creation generates the picking instructions 
 required to fulfill the allocation requests.<br data-source-node="n89"> </p>
            <p data-source-node="n90"> <i data-source-node="n91">Cycle Count</i> - Work creation 
 is initiated to process cycle count requests.</p>
            <p data-source-node="n92"> </p>
            <p data-source-node="n93"><i data-source-node="n94">Dock Management</i> - Work creation 
 is initiated to facilitate the movement of containers to and around the shipping dock. </p>
            <p data-source-node="n95"> </p>
            <p data-source-node="n96"><i data-source-node="n97">Inventory Adjustments</i> - This work is created when an adjustment is done using full screen Inventory Management when the adjustment type has "Create Work" specified, or when adjustments are interfaced into the system.</p>
            <p data-source-node="n98"> </p>
            <p data-source-node="n99"><i data-source-node="n100">Inventory Transfers</i> - This work is created when an inventory transfer is done using full screen Inventory Management when the adjustment type has "Create Work" specified, or when inventory transfers are interfaced into the system.</p>
            <p data-source-node="n101"> </p>
            <p data-source-node="n102"> <i data-source-node="n103">Replenishment</i> - Work creation 
 is initiated to process replenishment requests. During replenishment, 
 the system identifies the replenishment locations. Work creation generates 
 the picking and putaway instructions required to fulfill the replenishment 
 requests.</p>
            <p data-source-node="n104"> </p>
            <p data-source-node="n105"> <i data-source-node="n106">Shipping Container</i> - Work 
 creation is initiated from shipping container records.</p>
            <p data-source-node="n107"> </p>
            <p data-source-node="n108"> <i data-source-node="n109">Receiving</i> - During locating, 
 the system assigns storage locations to checked in containers. You can 
 use the work creation process to generate putaway work instructions for 
 these containers.</p>
            <p data-source-node="n110"> </p>
            <p data-source-node="n111"> <i data-source-node="n112">Work Order Component Allocation</i> 
 - Work creation is initiated to meet work order demand. </p>
            <p data-source-node="n113"> </p>
            <p data-source-node="n114"> <i data-source-node="n115">Work Order Finished Item Putaway</i> 
 - Work creation is initiated to create putaway requests for finished items. </p>
        </blockquote>
