Closing a Container (RF)

The system features a close container option on the RF device so you can easily close containers on the shipping dock and quickly get them ready to be shipped from the warehouse. The close container process involves advancing a container’s status, as well as optionally (based on your packing preference settings) auto manifesting, auto printing, and assigning the container's shipment to a load. Basically, a closed container indicates that the packing process is complete. Also, a document/label will be printed upon closing the last container when the Close Last Container print procedure has been selected on the paperwork’s document type. Note that if you close a container and there are unpacked quantities, the system will not print any "Close Last Container" documents. Also, if configured in your dock management settings, closing a container via RF will "create the next move" to the container's next destination dock location. Closing a container from an RF device is helpful, for example, if you are a picker that wants to close a shipping container on the shipping dock, without having to first take the container to a packing location to close it.

 

Notes

- If you try to close a container from an international shipment on RF, then the system will display an error, and the container will not be closed. Containers that are part of shipments that have this type of destination will need to be closed using the full screen Close Container Window.

 

- Pending VAS Activities Note: 

There is a setting in packing preferences that allows you to configure if the system will allow the user to ignore a container's pending VAS activities if they exist at the time of close container. See the Allow VAS Override At Close Container and Load Confirm Checkbox topic for more information.

 

- Pending/Failed QC Inspection Note: If a container has pending or failed QC inspection associated with it at the time of close container, then the system will prompt the user indicating that they cannot close the container until the QC is performed/resolved.

Procedures...

Log on to your RF Device and select the Close Container function from the main selection screen. The system will display the Close Container Screen.

  1. Use the Container ID Field to enter/scan the container that you want to close. Note that the container you want to close must be present in the warehouse you are currently assigned to.

  2. The system will then display the container's weight in the Weight Field after you tab out of the Container ID Field. Note that you can edit the weight from the value that the system defaults into this field. Note that the total weight for a shipping container includes the container type weight plus the weight of the container’s contents. This weight calculation starts at the selected container and includes all nested (child) container weights.

    NOTE: If your scanning device is setup to submit the close of the container when the user scans the Container ID. The system will retrieve the appropriate weight value and display it on the screen before triggering the close of the container.

  3. Press the Close Button:

    - If the system determines that the container's weight IS within the tolerance of its container type, the system will close the container and display a success message..

    - If the system determines that the container's weight IS NOT within the tolerance of its container type, the system will verify the user wishes to continue with the closing of the container. You would then press OK and the system would close the container.

  4. You can then scan a new container ID to close, or exit the window.
