
        
        <h1 data-source-node="n56"><a name="kanchor87" data-source-node="n57"></a>Custom Text Field</h1>
        <p class="p_1" data-source-node="n58">This field appears as a column header on the 
 System Text Editor Window after you perform a search. It identifies a 
 value that someone at your organization defined. It overrides the base 
 text value, which was provided with the system. Generally, you will use 
 custom text values to replace industry standard words with ones that are 
 pertinent to your organization. For example, you may want to change the 
 default value 'Item' with ISBN if you are a publishing firm.</p>
