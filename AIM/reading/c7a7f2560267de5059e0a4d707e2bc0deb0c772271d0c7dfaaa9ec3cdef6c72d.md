
        
        <h1 data-source-node="n56"><a name="kanchor1920" data-source-node="n57"></a>Shipment Line Field</h1>
        <p data-source-node="n58">A shipment line represents a customer's 
 request for product. When the system generates picking and packing instructions, 
 the line indicates the item and quantity requested by the customer. When an order is interfaced, the system creates 
 a shipment line that corresponds to each order line. The 
 system will also generate lines when it splits one to accommodate 
 warehouse activity, such as inadequate stock. You can also manually create 
 a line to accommodate special circumstances, such as call-in orders. This field also identifies the shipment 
 line associated with any value defined on the shipment record, 
 such as carrier, shipment date or customer. For example, you can use this 
 field to identify the shipment line associated with a particular 
 carrier.</p>
