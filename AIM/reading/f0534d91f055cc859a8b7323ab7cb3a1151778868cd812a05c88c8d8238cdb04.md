
        
        <h1 data-source-node="n57"><a name="kanchor1738" data-source-node="n58"></a>Shipper Pays Freight? Field</h1>
        <p data-source-node="n59">This field determines if the shipper is responsible for paying freight charges, or if the recipient is responsible. </p>
        <ul type="disc" class="ul_1" data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">Select 'Yes' if the shipper is responsible for paying the freight charges.In this case, 
 the system would assign the charges to the warehouse or company 
 sending the product. The system will return the charges as normal if this 
 field is set to 'Yes' (or, if the shipment does not have a freight term 
 specified). Generally, you would select 'Yes' if the freight term is Prepaid 
 or Prepaid and Add. Note that if this is not in a multi-company warehouse, 
 the system will only assign freight charges to the warehouse. For a Bill 
 of Lading, the system will fill the "freight bill to" information 
 from shipment data.<br data-source-node="n63"><br data-source-node="n64"></p>
            </li>
            <li data-source-node="n65">Select 'No' if the recipient is responsible for paying the freight charges. In this case, 
 the system would assign the charges to the appropriate party defined 
 on the shipment record. The system will suppress the freight charges 
 if this field is set as 'No.' Generally, you would select 'No' if the freight 
 term is Collect or Third Party. For a Bill of Lading, the system will 
 fill the "freight bill to" information from company/warehouse 
 data.</li>
        </ul>
