
        
        <h1 data-source-node="n56">Using the Intraday Labor Progress</h1>
        <p data-source-node="n57">The Intraday Labor Progress screen lets supervisors monitor intraday execution in real time by comparing tasked work with completed work, reviewing remaining units and hours, and understanding when work is expected to finish so they can take same-day actions.</p>

        <h2 class="Heading2" data-source-node="n83"><a name="Purpose" data-source-node="n84"></a>
            <h4 data-source-node="n85"><span style="font-weight: bold;font-size: 12pt" data-source-node="n86">Purpose and key notes</span>
            </h4>
        </h2>
        <p data-source-node="n87"> </p>
        <p data-source-node="n88">Intraday Labor Progress is for the current warehouse day only. It compares today's tasked work with today's completed work for each activity card and shows the current Full-Time Equivalent (FTE), Expected Time to Complete, and Ahead/Behind status.</p>
        <ul style="margin-left: 18pt" data-source-node="n89">
            <li data-source-node="n90">Use unique Work Types for each Functional Area so the screen can report and display activity correctly.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n91">
            <li data-source-node="n92">The values shown on the screen are anchored to the Last Updated time, which is the timestamp of the last successful Consolidate labor data job.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n93">
            <li data-source-node="n94">Target End Time is the scheduled end time of the last shift configured for the warehouse for that warehouse day.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n95">
            <li data-source-node="n96">At this stage, the examples and descriptions below focus on outbound work.</li>
        </ul>
        <h2 class="Heading2" data-source-node="n97"><a name="Open" data-source-node="n98"></a>
            <h4 data-source-node="n99"><span style="font-size: 10pt" data-source-node="n100"><span style="font-size: 12pt" data-source-node="n101">Open and view the Intraday Labor Progress screen</span></span>
            </h4>
        </h2>
        <p data-source-node="n102"> </p>
        <p data-source-node="n103">Use the filter pane to enter the primary search criteria and then select Apply Filter.</p>
        <ul style="margin-left: 18pt" data-source-node="n104">
            <li data-source-node="n105">Warehouse - The facility you want to monitor.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n106">
            <li data-source-node="n107">Work Group - The logical work grouping, such as Shipping</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n108">
            <li data-source-node="n109">Activity Type - The activity or functional area you want to review.</li>
        </ul>
        <p data-source-node="n110">The results are displayed as activity cards, not as a grid.</p>
        <p data-source-node="n111"> </p>
        <h2 class="Heading2" data-source-node="n112"><a name="Screen" data-source-node="n113"></a>
            <h4 data-source-node="n114"><span style="font-size: 10pt" data-source-node="n115"><span style="font-size: 12pt" data-source-node="n116">Screen overview and sort options</span></span>
            </h4>
        </h2>
        <p data-source-node="n117"> </p>
        <p data-source-node="n118">The top area of the screen gives the supervisor the context needed to interpret the activity cards.</p>
        <ul style="margin-left: 18pt" data-source-node="n119">
            <li data-source-node="n120">Warehouse Day / Date - The current warehouse day being monitored.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n121">
            <li data-source-node="n122">Completed / Tasked legend - The color legend used in the units and hours bars.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n123">
            <li data-source-node="n124">Target End Time - The end time of the last configured shift for that warehouse day.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n125">
            <li data-source-node="n126">Last Updated - The timestamp of the last successful Consolidate labor data job used by the screen calculations.</li>
        </ul>
        <p data-source-node="n127">The sort controls are used to sort the activity cards in ascending or descending order by one of these fields: Activity Type, Expected Time to Complete, FTE, Tasked Units, Tasked Hours, or % Complete.</p>
        <p data-source-node="n128"> </p>
        <h2 class="Heading2" data-source-node="n129"><a name="Activity" data-source-node="n130"></a>
            <h4 data-source-node="n131"><span style="font-size: 12pt" data-source-node="n132">Activity cards</span>
            </h4>
        </h2>
        <p data-source-node="n133"> </p>
        <p data-source-node="n134">Each card represents a single activity/work type for the current warehouse day.</p>
        <ul style="margin-left: 18pt" data-source-node="n135">
            <li data-source-node="n136">Activity name - The activity being monitored, such as Shipping Work or Dock Management Work.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n137">
            <li data-source-node="n138">FTE - The number of distinct users currently active in that activity. A user is counted as active only when the gap between their latest transaction and the Last Updated time is within the configured Heel-to-Toe tolerance.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n139">
            <li data-source-node="n140">Expected Time to Complete (ETC) - The estimated completion time for the activity based on Remaining Hours, active FTE, and throughput performance.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n141">
            <li data-source-node="n142">Expected Time to Complete formula: Last Updated Time + [Remaining Hours / (Active FTE x Throughput%)].</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n143">
            <li data-source-node="n144">Ahead / Behind - The difference between Expected Time to Complete and Target End Time, shown in hours. If the expected completion time is later than Target End Time, the card shows Behind by x hrs. If it is earlier than or equal to Target End Time, the card shows Ahead by x hrs.</li>
        </ul>
        <h2 class="Heading2" data-source-node="n145"><a name="Units" data-source-node="n146"></a>
            <h4 data-source-node="n147"><span style="font-size: 10pt" data-source-node="n148"><span style="font-size: 11pt" data-source-node="n149"><span style="font-size: 12pt" data-source-node="n150">Units section - Shipment work</span></span></span>
            </h4>
        </h2>
        <p data-source-node="n151"> </p>
        <p data-source-node="n152">The Units section shows how much work has been tasked, completed, and remains for the current warehouse day.</p>
        <ul style="margin-left: 18pt" data-source-node="n153">
            <li data-source-node="n154">Tasked Units - The full scope of today's work for the activity. Tasked Units = Completed Units + Remaining Units.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n155">
            <li data-source-node="n156">Completed Units - Today's completed quantity from closed work instruction details for the activity.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n157">
            <li data-source-node="n158">Remaining Units - The quantity that is still open or in process for the activity.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n159">
            <li data-source-node="n160">% Complete - Completed Units / Tasked Units. The percentage is shown only when Tasked Units is greater than zero.</li>
        </ul>
        <p data-source-node="n161">Unit of measure handling depends on whether the activity uses a single UOM or mixed UOMs.</p>
        <p data-source-node="n162"> </p>
        <h3 class="Heading3" data-source-node="n163">
            <h5 data-source-node="n164">Single UOM example</h5>
        </h3>
        <p data-source-node="n165"> </p>
        <p data-source-node="n166">If all records for an activity use the same UOM, the screen displays that UOM. For example, if Shipping Work has only CS quantities, the screen can display values such as Tasked Units = 120 CS, Completed Units = 72 CS, Remaining Units = 48 CS, and % Complete = 60%.</p>
        <p data-source-node="n167"> </p>
        <h3 class="Heading3" data-source-node="n168">
            <h5 data-source-node="n169">Mixed UOM example</h5>
        </h3>
        <p data-source-node="n170"> </p>
        <p data-source-node="n171">If an activity contains mixed UOMs, such as CS and EA, the quantities are normalized and displayed generically as Handling Units. For example, if Closed rows total 3 Handling Units and Open/In Process rows total 3 Handling Units, the screen shows Tasked Units = 6 Handling Units, Completed Units = 3 Handling Units, Remaining Units = 3 Handling Units, and % Complete = 50%.</p>
        <p data-source-node="n172"> </p>
        <h2 class="Heading2" data-source-node="n173"><span style="font-size: 10pt;font-weight: bold;color: #000000" data-source-node="n174"><h5 style="font-size: 10pt" data-source-node="n175">Units section - Dock Management work</h5></span>
        </h2>
        <p data-source-node="n176"> </p>
        <p data-source-node="n177">Dock Management work is container-based instead of item-based. The screen counts unique top-level containers rather than item quantities.</p>
        <ul style="margin-left: 18pt" data-source-node="n178">
            <li data-source-node="n179">Processed - Unique containers in Closed status.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n180">
            <li data-source-node="n181">Remaining - Unique containers in Open or In Process status.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n182">
            <li data-source-node="n183">Tasked - Processed + Remaining unique containers.</li>
        </ul>
        <h2 class="Heading2" data-source-node="n184">
            <h5 style="font-weight: bold;color: #000000;font-size: 10pt" data-source-node="n185"><span style="color: #00008b" data-source-node="n186"><span style="color: #191970" data-source-node="n187">Hours section</span></span>
            </h5>
        </h2>
        <p data-source-node="n188"> </p>
        <p data-source-node="n189">The Hours section converts today's work into labor hours and compares planned effort with actual completed time.</p>
        <ul style="margin-left: 18pt" data-source-node="n190">
            <li data-source-node="n191">Tasked Hours - The hours required to complete the activity's tasked work. Tasked Hours = Tasked Units / Expected Throughput.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n192">
            <li data-source-node="n193">Completed Hours - The actual labor time already posted for the activity from the labor consolidation data.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n194">
            <li data-source-node="n195">Remaining Hours - Tasked Hours - Completed Hours.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n196">
            <li data-source-node="n197">The hours bar visually compares Completed Hours with Tasked Hours so the supervisor can see how much effort is left.</li>
        </ul>
        <h2 class="Heading2" data-source-node="n198"><a name="Employee" data-source-node="n199"></a>
            <h4 data-source-node="n200">Employee Grid</h4>
        </h2>
        <p data-source-node="n201"> </p>
        <p data-source-node="n202"> </p>
        <p data-source-node="n203">The Employee grid shows who is currently working in the selected activity.</p>
        <ul style="margin-left: 18pt" data-source-node="n204">
            <li data-source-node="n205">Select the FTE hyperlink or the employee icon on an activity card to open the Employee grid.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n206">
            <li data-source-node="n207">The grid shows one row per employee and includes Employee Name and Latest Activity.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n208">
            <li data-source-node="n209">When the grid is opened from a specific activity card, it is filtered to the employees currently working on that activity.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n210">
            <li data-source-node="n211">Clear the filter to see all active employees across all activities shown on the screen.</li>
        </ul>
        <h2 class="Heading2" data-source-node="n212"><a name="What-if" data-source-node="n213"></a>
            <h4 data-source-node="n214">What-if simulations</h4>
        </h2>
        <p data-source-node="n215"> </p>
        <p data-source-node="n216">The What-if section gives supervisors a safe way to test staffing and throughput scenarios without changing actual work, labor assignments, or configuration.</p>
        <p data-source-node="n217">All What-if calculations use the same calculation anchor:</p>
        <ul style="margin-left: 18pt" data-source-node="n218">
            <li data-source-node="n219">Start Time = Last Updated Time shown on the Intraday Labor Progress screen. Note that there is no separate field for Start time but for calculation purpose the Last Updated time is considered.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n220">
            <li data-source-node="n221">Remaining Hours = the actual Remaining Hours for that activity at that same Last Updated point.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n222">
            <li data-source-node="n223">The simulation result affects only the What-if output for the selected card.</li>
        </ul>
        <h2 class="Heading2" data-source-node="n224">
            <h5 style="color: #000000" data-source-node="n225">What-if Expected Time to Complete</h5>
        </h2>
        <ul style="margin-left: 18pt" data-source-node="n226">
            <li data-source-node="n227">Purpose - Estimate when the activity will finish if FTE or Throughput% changes.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n228">
            <li data-source-node="n229">Defaults - FTE defaults to the current number of people working on the activity, and Throughput% defaults to the current throughput percentage for that activity.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n230">
            <li data-source-node="n231">Formula - Expected Time to Complete = Last Updated Time + [Remaining Hours / (Active FTE x Throughput%)].</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n232">
            <li data-source-node="n233">Result - The card shows a simulated Expected Time to Complete for the entered FTE and Throughput% values.</li>
        </ul>
        <h2 class="Heading2" data-source-node="n234">
            <h5 data-source-node="n235">What-if FTE</h5>
        </h2>
        <ul style="margin-left: 18pt" data-source-node="n236">
            <li data-source-node="n237">Purpose - Determine how many people are needed to finish the activity by a specific end time.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n238">
            <li data-source-node="n239">Defaults - End Time defaults to the Target End Time shown on the card, and Throughput% defaults to the current throughput percentage for the activity.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n240">
            <li data-source-node="n241">Formula - FTE Needed = Remaining Hours / [(End Time - Start Time) x Throughput%].</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n242">
            <li data-source-node="n243">Result - The system displays the simulated FTE requirement for that scenario.</li>
        </ul>
        <h2 class="Heading2" data-source-node="n244">
            <h5 style="color: #000000" data-source-node="n245">What-if Throughput%</h5>
        </h2>
        <ul style="margin-left: 18pt" data-source-node="n246">
            <li data-source-node="n247">Purpose - Determine what throughput percentage is required to finish the activity by a specific end time with a fixed FTE.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n248">
            <li data-source-node="n249">Defaults - End Time defaults to the Target End Time shown on the card, and FTE defaults to the current number of people working on the activity.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n250">
            <li data-source-node="n251">Formula - Throughput% Needed = [Remaining Hours / {(End Time - Start Time) x Active FTE}] x 100.</li>
        </ul>
        <ul style="margin-left: 18pt" data-source-node="n252">
            <li data-source-node="n253">Result - The system displays the simulated throughput percentage needed for that scenario.</li>
        </ul>
