
        
        <h1 data-source-node="n56"><a name="kanchor1391" data-source-node="n57"></a>Confirming Cycle Counts</h1>
        <p data-source-node="n58">Cycle counting is the physical verification that the inventory actually 
 present in a location matches what the system believes is in the location. 
 This helps you keep an accurate count of exactly how much inventory is 
 present in your warehouse. Confirming is the process of adjusting a location's quantity to be the 
 exact quantity that is physically present in that location. For example, 
 suppose the system says that there are 10 eaches of an item in a particular 
 location. When executing a cycle count, a worker counts 10 eaches. They 
 would then enter this quantity into the RF device, thus "confirming" 
 that the system count was the correct quantity in the location.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Cycle Counting Methods...</h4>
        <p data-source-node="n62">Regardless if cycle count requests have been generated using plans or 
 not, if you have the system create work for cycle counts, then you will 
 need to execute this work (confirm the cycle counts) on an RF device:</p>
        <ul type="disc" class="ul_1" data-source-node="n63">
            <li data-source-node="n64">Non-Plan Based 
 (activity-driven): The typical flow for this mode starts 
 after an RF user has completed executing a work instruction (such as a 
 pick). The system will display a screen prompting the user 
 that a cycle count is required at the current location. The user will 
 then enter the item quantity present in a certain location, and the system 
 will either close the cycle count request, or place it in a "pending 
 review" status, depending on what the count is. See the non plan-based             <a href="71e9cfa8294b965b70be00b564408c726a41da70ba6c002fe00adf6da5a0b3f7.html" data-source-node="n65">process diagram</a> for a more detailed 
 discussion of this process. <br data-source-node="n66"> </li>
            <li data-source-node="n67">Plan-Based: 
 The typical flow for this mode is that the warehouse manager will create 
 a cycle count plan in the Cycle Count Plan Insight screen. These plans are based 
 off of cycle count master records, which contain filters for what item(s) 
 and location(s) you want to count. When released, the system will create 
 cycle count requests with work (use RF to count) or without work (use 
 paper documents or the Cycle Count Request Insight screen to count). See the plan-based             <a href="71e9cfa8294b965b70be00b564408c726a41da70ba6c002fe00adf6da5a0b3f7.html" data-source-node="n68">process diagram</a> for a more detailed 
 discussion of this process.</li>
        </ul>

        <h4 data-source-node="n110"><a name="prereq" data-source-node="n111"></a>Prerequisites...</h4>
        <p data-source-node="n112">The following are some important prerequisites for confirming cycle counts:</p>
        <p data-source-node="n113"> </p>
        <h5 data-source-node="n114">Plan-Based Cycle Count Confirmation</h5>
        <ul data-source-node="n115">
            <li data-source-node="n116">It is important to remember that you will not be able to confirm the work for cycle counts generated from plans until the plan has been released in the Cycle Count Plan Insight screen. See the topic <a href="63ca81ffeb83c9db93ca5ad3d9373b618888c32081943359d9e605b8bfe949d8.html" data-source-node="n117">Using Cycle Count Plans</a> for more information.</li>
        </ul>
        <h5 data-source-node="n118">Adding Items During Cycle Count Confirmation</h5>
        <ul data-source-node="n119">
            <li data-source-node="n120">The ability for users to enter new items during a cycle count is controlled by the "Add New Inventory" option (from the RF Cycle Count form) in the Security Permissions Window.</li>
        </ul>

        <h4 data-source-node="n125"><a name="rf" data-source-node="n126"></a>Confirming Cycle Counts Using 
 an RF Device...  </h4>
        <p class="p_10" data-source-node="n127">The following procedures are for executing cycle count work for 
 both plan-based and activity-driven cycle counting (as performed on an 
 RF device).</p>
        <p class="p_10" data-source-node="n128"> </p>
        <p data-source-node="n129">1. Log on to your 
 RF Device.</p>
        <p data-source-node="n130"> </p>
        <p data-source-node="n131">2. Choose the Work function.</p>
        <p data-source-node="n132"> </p>
        <p data-source-node="n133">3. Choose a work profile:</p>
        <ul data-source-node="n134">
            <li data-source-node="n135">When using plan-based cycle counting, select a work profile that supports executing cycle count work.<br data-source-node="n136"><br data-source-node="n137"></li>
            <li data-source-node="n138">When using activity-driven cycle counting, select a work profile that supports the work type that you are going to be executing.</li>
        </ul>
        <p data-source-node="n139">4. The system will display the appropriate work execution processing screen:</p>
        <ul data-source-node="n140">
            <li data-source-node="n141">When using plan-based cycle counting, the system will display the user-directed work initiation screen, on which you will need to enter a work unit.<br data-source-node="n142"><br data-source-node="n143"></li>
            <li data-source-node="n144">When using activity-driven cycle counting, the system will display the work confirmation screen (see the topic <a href="5ea80956b207057fdc2d841bb836a676ef62f554f56c6da1c57f1997b9f84e20.html" data-source-node="n145">Processing RF Work</a> for more details on using that screen). You would then use that screen to execute your picking/putaway work.</li>
        </ul>
        <p style="font-weight: normal" data-source-node="n146">5. Next, the system will display the cycle count confirmation screen. </p>
        <p data-source-node="n147"> </p>
        <p style="font-weight: normal" data-source-node="n148">6. Enter the item quantity (and UM) OR the number of license plates that are currently present in the location of the item you are counting.  The type of count you will be required to make is determined by  how your  work special handling record's cycle counting settings are defined.</p>
        <ul data-source-node="n149">
            <li data-source-node="n150">Unit of Measure Note: The value under the Unit of Measure Field represents the base quantity/UM 
 for the item quantity that you are counting. In the example, if there 
 was a Case of item 0002 currently in the location (and 1 CS= 30 eaches), 
 then the system would display the base quantity of 30 EA.<br data-source-node="n151"><br data-source-node="n152"></li>
            <li data-source-node="n153">If you are counting a non-LP-tracked location, the system will require you to count the item quantity (even if you are configured to count the number of license plates.<br data-source-node="n154"><br data-source-node="n155"></li>
            <li data-source-node="n156">If you are counting an LP-tracked location, you can count either item quantity or the number of LPs (depending on your work special handling settings).<br data-source-node="n157"><br data-source-node="n158"></li>
            <li data-source-node="n159">The system also may require you to provide validations for such values as item IDs, or location IDs on this screen.</li>
        </ul>
        <p data-source-node="n160"> </p>
        <p style="font-style: italic" data-source-node="n161">When Counting the Number of LPs for an LP-Tracked Location</p>
        <ul data-source-node="n162">
            <li data-source-node="n163">If the number of license plates does not match the license plates in the location, the system will automatically direct the user to the count item quantity mode. <br data-source-node="n164"><br data-source-node="n165"></li>
            <li data-source-node="n166">If the number of license plates matches the license plates in the location, the system will confirm all the requests that exist for this location. <br data-source-node="n167"><br data-source-node="n168"></li>
            <li data-source-node="n169">If the location is multi-item, you cannot count the number of license plates. The system will automatically direct you to the count item quantity mode.</li>
        </ul>
        <p data-source-node="n170"> </p>
        <p style="font-style: italic" data-source-node="n171">When Counting the Item Quantity of an LP-Tracked Location</p>
        <ul data-source-node="n172">
            <li style="color: #000000" data-source-node="n173">In user-initiated LP mode, the user will need to enter which license plate they want to confirm. Then the user will need to enter the quantity of the item in the license plate. <br data-source-node="n174"><br data-source-node="n175"></li>
            <li style="color: #000000" data-source-node="n176">In system-initiated LP mode, the system will display the license plate to be counted. Then the user will need to enter the quantity of the item in the license plate.</li>
        </ul>
        <p data-source-node="n177"> </p>
        <p style="font-style: italic" data-source-node="n178">When "Grouping" Counts By Item/Company:</p>
        <p data-source-node="n179">If your work special handling is configured to do so, you can cycle count all the quantity at a given location for the same item/company (regardless the lot ID, inventory attributes, or license plate). For example, suppose location 101/026/01 contains item NOR0001.  Also, inventory attributes have been captured for NOR0001 that represent the country of origin, with a breakdown of the following:  NOR0001 has 5 EA with an origin of "United States", 5 EA with an origin of "Canada", and 5 EA with an origin of "Mexico."  You would then count the inventory for the United States, Canada, and Mexico with a combined "grouped" count of 15 EA for NOR0001. See the topic <a href="7491e857e15613b5c1a1e8e9cfb650475e8e7822d5f56084ab47e4eaa3664bf9.html" data-source-node="n180">Count Level Field</a> (the Group Count By Item/Company setting) for more information.</p>
        <p data-source-node="n181"> </p>
        <p data-source-node="n182"> </p>
        <p style="font-style: italic" data-source-node="n183">When Counting an Empty Location:</p>
        <ul data-source-node="n184">
            <li data-source-node="n185">The user will have the same options 
 as in the "not empty" scenarios listed above. <br data-source-node="n186"><br data-source-node="n187"></li>
            <li data-source-node="n188">Note that you can add new items using the Add Button (see later in this topic for details on adding items during a count).</li>
        </ul>
        <p data-source-node="n189"> </p>
        <p data-source-node="n190">7. Press one of the action buttons:</p>
        <ul data-source-node="n191">
            <li data-source-node="n192">CONFIRM:Press this button to confirm the item/LP quantity that you are counting at the location.<br data-source-node="n193"><br data-source-node="n194">If the user count is different than the system count, and the Verify 
 Bad Count on RF Checkbox is selected on the user's cycle count preference, the user will need to re-enter their count.<br data-source-node="n195"><br data-source-node="n196">- If location's new quantity IS ZERO, the system will confirm that the current location as empty.<br data-source-node="n197"><br data-source-node="n198">- If location's new quantity 
 IS NOT ZERO, the system will: immediately reconcile the item quantity 
 if the Immediate Reconcile of Bad Count Check box is checked on the user's 
 Cycle Count Preference record. Remember that the system will only reconcile 
 the location if the difference between the counted and system quantity 
 falls within the user's tolerances. Also, the system will place the cycle 
 count request into a "pending review" status if the system quantity 
 and the quantity you count are different, and if the Immediate Reconcile 
 of Bad Count Check box is not checked. You will then have to address this 
 request in the Cycle Count Request Insight screen. However, if the quantities are the 
 same, the system will close the request. See the topic      <a href="f2525d356a78d56ce268321ce6192fd66106ddd02604c28d27e8a9a9bd3ef739.html" data-source-node="n199">Reconciling 
 Cycle Counts</a> for more information on the reconciling process.<br data-source-node="n200"><br data-source-node="n201">- If the counted item is lot controlled, the system will display the Enter Lot screen, where you can provide the appropriate lot data.<br data-source-node="n202"><br data-source-node="n203">- If the counted item is serial number tracked, the system will display the Serial Number Entry screen, where you can provide the appropriate serial number data.<br data-source-node="n204"><br data-source-node="n205"></li>
            <li data-source-node="n206">ADD: Press this button to add item(s) that the system does not currently account for in your count of the location.Note that this functionality applies to RF cycle counting only.<br data-source-node="n207"><br data-source-node="n208">- When you press this button, the system will display the Inventory Management screen. When you are finished entering in the adjustment information, press Add Button on the Inventory Management screen to add the item quantity. The system will return you back to the Cycle Counting screen. You can also press the Cancel Button to return to the Cycle Count Confirmation screen.<br data-source-node="n209"><br data-source-node="n210">- The cycle count system value "Planned Count - Positive Adjustment" determines the adjustment type that you can perform when adding items to a location.<br data-source-node="n211"><br data-source-node="n212">- You can only adjust an item to the location you are currently counting.<br data-source-node="n213"><br data-source-node="n214">- After you have added an item (and all counts on the location have been completed), then the system will display only the Location Field, and you can continue to add item(s) until you press the Done Button.<br data-source-node="n215"><br data-source-node="n216">- Adding items during a count is subject to the same validation as inventory adjustments performed outside of cycle counting. <br data-source-node="n217"><br data-source-node="n218">- The system places all new items added to single item locations in a pending review status, IF if the location is either not empty, has another item in transit, or is the permanent location for another item.<br data-source-node="n219"><br data-source-node="n220">- You WILL NOT need to count the item quantity that you just added via an adjustment. However, if you are counting a single item location that is LP tracked, you will need to confirm the original item quantity on the count.<br data-source-node="n221"><br data-source-node="n222">- New items added to a multi-item location will use the "tolerances" defined on the cycle counting preferences to determine if the system should place them in pending review.<br data-source-node="n223"><br data-source-node="n224">-  You cannot add items and count LPs. When you choose to add a new item, SCALE will require you to count contents (instead of LPs).<br data-source-node="n225"><br data-source-node="n226">- *** If an item is lot-controlled, then the system will display the Enter Lot screen after the adjustment information is entered and you press Add. Note that if you have the ability to add items, then you will also be allowed to enter new lots as well.<br data-source-node="n227"><br data-source-node="n228"></li>
            <li data-source-node="n229">DONE: Press this button when you are finished cycle counting the current location, and you do not want to add any more items.<br data-source-node="n230"><br data-source-node="n231">- If you are counting a single-item location, this button will only appear if you are allowed to add items during counts.<br data-source-node="n232"><br data-source-node="n233">- If you are counting a multi-item location, this button will always appear on the confirmation screen (so you can opt to finish counting before all the locations on the work unit have been counted).<br data-source-node="n234"></li>
            <p data-source-node="n235"> </p>
            <li data-source-node="n236">SKIP: Press this button to ignore the current cycle count request and 
 advance to the next one (if one is available). Note that this button will not appear if no other cycle count instructions exist on the current work unit.<br data-source-node="n237"><br data-source-node="n238"></li>
            <li data-source-node="n239">CANCEL:Press this button to stop processing on this cycle count work 
 unit.<br data-source-node="n240"></li>
        </ul>
        <p data-source-node="n241"> </p>
        <p data-source-node="n242">8. When you are finished confirming all the cycle counts on the current work unit, the system will return you to the user directed work initiation screen (using plan-based cycle counting), or proceed with the next work activity (using activity-driven cycle counting).</p>

        <h4 data-source-node="n248"><a name="exp" data-source-node="n249"></a>Confirming Cycle Counts 
 Using the Cycle Count Request Insight Screen...  </h4>
        <p data-source-node="n250">You can only confirm 
 from the Cycle Count Request Insight screen, if work was not created for a cycle count 
 request.</p>
        <blockquote data-source-node="n251">
            <p data-source-node="n252">1. Access the Cycle 
 Count Request Insight screen. </p>
            <p data-source-node="n253">
                <br data-source-node="n254">2. Search for a 
 cycle count request (that has no work associated with it). Note 
 that the confirmation option will not be available for requests that have 
 work associated with them.<br data-source-node="n255"> </p>
            <p data-source-node="n256">3. Select the Confirm action. 
 The system will ask you if you are sure you want to confirm the request. 
 Choose Yes, and the system will confirm the request and set the status 
 of the request to closed.</p>
        </blockquote>
