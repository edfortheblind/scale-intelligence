
        
        <h1 data-source-node="n56">Document Data Selection Window</h1>
        <p data-source-node="n57">You will use this window to define each sequence that the system will 
 process during the paperwork wave step. A sequence identifies the document 
 type to print and the criteria (data selection) that a record must meet 
 to be considered for paperwork. You will also define the print break sequences 
 that the system will reference during the actual printing process. You 
 can only access this window from the Document Master Window.</p>
