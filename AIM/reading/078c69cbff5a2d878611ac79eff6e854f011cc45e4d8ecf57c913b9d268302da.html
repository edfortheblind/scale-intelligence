Warehouse Mobile - Cycle Count Reconcile

Reconciling is the process that occurs after a count of a location has been performed. This is a correction process when the supervisor finds that the cycle count of a location item quantity is inaccurate.

Perform a cycle count reconcile

The following details the steps for the cycle count reconcile.

  1. Log in to Warehouse Mobile application.
  2. Select the Cycle Count Reconciliation option from the Warehouse Mobile Menu.
  3. Enter location and Tap Go.
  4. Location and Item name is displayed. Tap i to view Information pop-up.

  5. The system also displays the lot if there is one associated with the item quantity.

  6. In the Counted field, the system displays the cycle count quantity value (and its unit of measure) that the user originally entered when performing the cycle count. You can tap the "i" icon to view the details about this quantity.

  7. The On Hand quantity and UM are highlighted in the screen.
  8. Optionally change the UM. Tap UM to view the pop-up. Select the required UM. Enter the On hand value and Tap GO and if the reconcile action is successful, then the system will display a message.
  9. Screen displays the next location for reconciliation.
Reconciliation Actions
  • Cancel - Tap to stop the process and go back to the Cycle Count Reconciliation screen.
  • Skip - Tap to skip to the next cycle count request that meets the location criteria you entered, if another one exists. Any records that you skip will not be processed and continue to be in a pending review status.
Notes
  • If the location tracks license plates, the system will have you enter or verify the License Plate ID during the reconciliation process.
  • Use the Counted Field to view the item quantity that the user entered when performing the original cycle count.
  • The location quantity values on the Details page reflect the quantities that are present in the location at the time of the reconcile, NOT at the time that the cycle count was performed.
  • If the item being reconciled is serial number tracked, the system will ask you to enter these values as well.
  • System will validate the serial number tracked items that are linked to serial number templates
