
        
        <h1 data-source-node="n56"><a name="kanchor1737" data-source-node="n57"></a>Increase Quantity Field</h1>
        <p data-source-node="n58">This field indicates the actual value of a component's increase in allocation. 
 For example, if you wanted the system to allocate an extra ten eaches 
 of a component, you would enter "10" into this field. If you 
 wanted the system to allocate fifteen percent more of a component, you 
 would enter "15" into this field, without a percent sign. Note that you can only edit this 
 setting prior to the first time allocation is attempted on the work order.</p>

 Buttons</a> for more detailed information on how this field works.
