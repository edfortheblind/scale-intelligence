Activating a Work Type for Pick Management

You must activate picking management for a specific work type if you want the system to display work unit(s) with this type in the picking management windows. Note that this topic discusses only the steps needed to activate picking management for a specific work type. For more information on creating work types in general, see the topic Defining Work Types. You will activate a work type on the Work Type Window.

 

 

Using the Pick Management Active Checkbox...

Access the Work Type Window. Open or create a new work type record.

  1. Use the Pick Management Active Checkbox to indicate if you want work units with this work type to appear in picking management.
     

    • If this checkbox is checked, the system will display work units with this work type in picking management windows, such as the Picking Selection Window or the Picking Management Explorer.

       

    • If this checkbox is not checked, the system will not display work units with this work type in picking management windows.
