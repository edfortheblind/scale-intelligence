
        
        <h1 data-source-node="n56"><a name="kanchor1543" data-source-node="n57"></a>Default Inventory Status Field</h1>
        <p data-source-node="n58">The status that the system will assign to all product during either 
 check in or work order processing. For checked in receipts, this field is defined on the Receiving Preferences 
 Window. For work orders, this field is defined on the Work Order Preferences 
 Window. Note that generally, 
 you should select the value Available. If you are creating this record 
 for someone processing returns, you may want to define a hold or damaged 
 status here.</p>
