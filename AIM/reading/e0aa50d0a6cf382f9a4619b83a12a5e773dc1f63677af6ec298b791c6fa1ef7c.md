
        
        <h1 data-source-node="n56"><a name="kanchor242" data-source-node="n57"></a>Logging On To An RF Device</h1>
        <p data-source-node="n58">When using an RF device, you will need to log on to the SCALE RF system.  Note that during times of inactivity, the RF Device may automatically go into standby mode, which conserves battery life. Press the Power Button to return to the regular power mode. You can also access the RF system from a client machine (via the desktop).</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The system will display the green dot and red dot icon on the upper right corner of every RF screen when the server is connected and disconnected respectively. The action buttons in each and every page on RF, the hyperlinks, and the shortcut keys are disabled when the server goes offline. Once the server is online, the buttons and hyperlinks are enabled automatically and the shortcut keys will also work.</p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">Language Note  <br data-source-node="n63"></h5>
        <p data-source-node="n64">You can change the language that the system will use to display text on the RF device on the device itself, regardless of what language setting is currently used on the SCALE application server.
</p>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">Logging Onto Multiple RF Sessions<br data-source-node="n67"></h5>
        <p data-source-node="n68">Do  not log onto multiple browser sessions from the same RF device, since the system will treat all sessions as if they were logged on by the same user. If you do this, the system will encounter data issues. Note that this also applies to RF browser sessions running from a full-screen application session as well.</p>
        <p data-source-node="n69"> </p>
        <p data-source-node="n70"> </p>
        <h4 data-source-node="n71">Procedures...<br data-source-node="n72"></h4>
        <h5 style="font-weight: normal" data-source-node="n73">Access the Terminal Server Client application on your RF Device (via the Windows Start Menu). The system will automatically open the Terminal Server logon screen. </h5>
        <ol data-source-node="n74">
            <li value="1" data-source-node="n75">Enter the server where the RF module is located (usually the application server or a special server dedicated to processing RF transactions). You can also select the server name from the "Recent Servers" list.<br data-source-node="n76"><br data-source-node="n77"></li>
            <li value="2" data-source-node="n78">Press the Connect Button. The system will display the Windows Logon Screen.
<br data-source-node="n79"><br data-source-node="n80"></li>
            <li value="3" data-source-node="n81">Enter your network user name and password, and if necessary, the domain that you are logging onto.<br data-source-node="n82"><br data-source-node="n83"></li>
            <li value="4" data-source-node="n84">Enter the application environment you want to log on to.</li>
            <p data-source-node="n85"> </p>
            <li value="5" data-source-node="n86">Press OK. The system will:
<br data-source-node="n87"><br data-source-node="n88">- Log you onto the RF system, if you do not have an RF password (as defined on the User Profile Window), or if your RF and network password are the same.
<br data-source-node="n89"><br data-source-node="n90">- Display the RF Logon Screen, if your RF and network password are not the same. You will then need to enter your RF user name (the same as you system user name) and password (this value is defined on the User Profile Window). Press the Sign On Button to log on to the RF Device.<br data-source-node="n91"><br data-source-node="n92">If you get a "User Is Already Signed Onto An RF Session" error when logging on, choose one of the following options: continue or cancel. Choose "continue" if you want the system to end the old RF session and log you on to a new one. Choose "cancel" if you want to work on the old RF session, or log in as a different user. The system will navigate you back to the Logon Screen.

 
</li>
        </ol>
