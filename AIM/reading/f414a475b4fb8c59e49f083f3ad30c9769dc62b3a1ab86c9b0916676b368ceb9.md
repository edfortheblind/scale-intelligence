
        
        <h1 data-source-node="n56"><a name="kanchor2053" data-source-node="n57"></a>Routing Name Field</h1>
        <p data-source-node="n58">The system uses this field to sort routing guide records. On the routing guide record, this field provides an English description 
 for the routing ID. The routing ID identifies a routing guide to the system. 
 A routing record defines when a specific carrier or carrier group should 
 be selected to transport a shipment. </p>
