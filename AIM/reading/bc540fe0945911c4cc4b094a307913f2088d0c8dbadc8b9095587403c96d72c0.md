
        
        <h1 data-source-node="n56"><a name="kanchor157" data-source-node="n57"></a>Viewer Resource Key Field</h1>
        <p data-source-node="n58">This field indicates the resource key that the system will use 
 to display the name for a viewer window. The system will suggest a default value; you can change this to a different value if desired. You can reference this value in the System Text Editor at a later time if you want to edit the viewer title (or translate it).</p>
