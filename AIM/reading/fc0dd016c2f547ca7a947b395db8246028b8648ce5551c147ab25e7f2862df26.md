
        
        <h1 data-source-node="n56"><a name="kanchor13" data-source-node="n57"></a>Internal Container Number Field</h1>
        <p data-source-node="n58">A system-generated number that identifies a unique container. If the system generates container IDs during packing, this number occupies 
 positions 11 - 19 of the ID. In addition, if a vendor compliant label is produced for the container 
 and it includes a UCC-128 barcode, 
 this number occupies positions 11 - 19 of the barcode.</p>
