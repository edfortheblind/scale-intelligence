
        
        <h1 data-source-node="n56"><a name="kanchor295" data-source-node="n57"></a>Charge Information Buttons</h1>
        <p data-source-node="n58">These buttons indicates how accessorial charges will be calculated and 
 assigned. Currently, the only valid value is External Symbol. All valid external 
 values required for FedEx and UPS are provided with the system. You can select one of these buttons on the 
 Accessorial Detail Window.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The valid values are:</p>
        <ul data-source-node="n61">
            <li data-source-node="n62">External Symbol - Progistics will calculate and assign the accessorial charge (for 
 UPS). It will pass the charge to the system, which will associate it with 
 the container/shipment. All external symbols are defined by Progistics. To obtain an external symbol, please contact Progistics.<br data-source-node="n63"><br data-source-node="n64"></li>
            <li data-source-node="n65">Charge Type - This button is reserved for future use. When 
 its available, the system will calculate and assign accessorial charges.</li>
        </ul>
