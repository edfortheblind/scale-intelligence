
        
        <h1 data-source-node="n56"><a name="kanchor247" data-source-node="n57"></a>Processing Vocollect Work</h1>
        <p data-source-node="n58">Vocollect voice picking involves the picker speaking commands into a headset, and the system then performing the appropriate pick actions. Voice picking is done with a TalkMan device and headset. The basic flow of Vocollect picking is the same as RF work execution, except that the user speaks commands/data instead of scanning or pressing screen buttons with a stylus. Note that SCALE only supports certain picking functionality with Vocollect. See the <a href="76770f4602f9b9e52b4fce3fb8973ffa25b3e882ead4fd0e2faea14766f877a3.html#vocollect" data-source-node="n59">Work Process Summary</a> for more details.</p>

        <h4 data-source-node="n93"><a name="basicTerms" data-source-node="n94"></a>Basic Vocollect Terms...</h4>
        <p data-source-node="n95">The following are definitions for a few basic Vocollect terms that are used in this topic:</p>
        <ul data-source-node="n96">
            <li data-source-node="n97">Region: A Vocollect term for the set of work to be done. In SCALE, this is referred to as the work profile.<br data-source-node="n98"><br data-source-node="n99"></li>
            <li data-source-node="n100">Talkman: The physical headset and device that Vocollect uses to gather and transmit voice data. This is also sometimes referred to as a terminal. Typically, a user would strap the TalkMan device to their belt, and wear the headset on their head.<br data-source-node="n101"><br data-source-node="n102"></li>
            <li data-source-node="n103">Vehicle Type: A Vocollect term for a SCALE  equipment type.<br data-source-node="n104"><br data-source-node="n105"></li>
            <li data-source-node="n106">Vocollect: This is the voice recognition software that integrates with SCALE. Vocollect presents the work to the user via voice command and then accepts voice commands to trigger the execution of work in SCALE. This application can be installed on a separate server or on the SCALE application server.<br data-source-node="n107"><br data-source-node="n108"></li>
            <li data-source-node="n109">Work ID: This is a Vocollect term for a SCALE  work unit.<br data-source-node="n110"></li>
        </ul>

        <h4 data-source-node="n113"><a name="notesBeforeStarting" data-source-node="n114"></a>Notes Before Starting...</h4>
        <ul data-source-node="n115">
            <li data-source-node="n116">When the user turns on a Vocollect Talkman, the device requests the appropriate SCALE configuration data, and modifies its behavior based on these settings.<br data-source-node="n117"><br data-source-node="n118"></li>
            <li data-source-node="n119">The user will always speak numbers when providing the TalkMan with picking commands or data, unless saying the actual word(s) of a specific Vocollect command (such as Sign Off, Skip Slot, or Yes/No).<br data-source-node="n120"><br data-source-node="n121"></li>
            <li data-source-node="n122">The TalkMan will respeak most data you speak to it. You can confirm by speaking Yes or No.<br data-source-node="n123"><br data-source-node="n124"></li>
            <li data-source-node="n125">It is recommended that you sign off/turn off the TalkMan device after the work day is complete. You can only log onto one TalkMan device at a time.<br data-source-node="n126"><br data-source-node="n127"></li>
            <li data-source-node="n128">When speaking numbers into the TalkMan, be sure to speak each digit separately, as opposed to speaking the whole string. For example, if your password is 12, you would speak "one, two" into the device, not "twelve."<br data-source-node="n129"><br data-source-node="n130"></li>
            <li data-source-node="n131">When the TalkMan confirms a value, it will speak the word Correct. The user will then confirm by speaking "Yes" or "No."</li>
        </ul>

        <h4 data-source-node="n148"><a name="importantCommands" data-source-node="n149"></a>Other Important Commands...</h4>
        <p data-source-node="n150">Below are descriptions of other commands that you can use on the TalkMan device:</p>
        <ul data-source-node="n151">
            <li data-source-node="n152">Sign Off: The TalkMan will ask for a confirmation of this action. If user says Yes, then the TalkMan locks, and you will need to speak a password when you want to use the device again. Current session information (region, etc.) is not saved.<br data-source-node="n153"><br data-source-node="n154"></li>
            <li data-source-node="n155">Take A Break: The TalkMan will ask for a confirmation. If user says Yes, then the TalkMan will ask for the appropriate work type to use for the break time (as defined in the SCALE Work Type Window). User speaks the number that corresponds to the work type. The TalkMan confirms, and if the user says Yes, then locks. You will need to speak a password when you want to use the device again. Current session information (region, etc.) is saved.<br data-source-node="n156"><br data-source-node="n157"></li>
            <li data-source-node="n158">TalkMan Sleep: The TalkMan will ask for a confirmation of this action. If the user says Yes, then the TalkMan goes into a powersave mode. Current session information (region, etc.) is saved.<br data-source-node="n159"><br data-source-node="n160"></li>
            <li data-source-node="n161">TalkMan Wake Up: This command "wakes" the TalkMan from sleep mode.<br data-source-node="n162"><br data-source-node="n163"></li>
            <li data-source-node="n164">Skip Aisle: This command allows the user to skip the current aisle and move to the next aisle. The user cannot skip if this is the last aisle on the work ID.<br data-source-node="n165"><br data-source-node="n166"></li>
            <li data-source-node="n167">Skip Slot: This command allows the user to skip the current slot and move to the next slot. The user cannot skip if this is the last slot on the work ID.<br data-source-node="n168"><br data-source-node="n169"></li>
            <li data-source-node="n170">Pass Assignment: If a user starts working on a work ID, and for some reason does not want to continue working on it, the user can speak <i data-source-node="n171">Pass Assignment</i> to get out without confirming the work.<br data-source-node="n172"><br data-source-node="n173"></li>
            <li data-source-node="n174">Say Again: Have the TalkMan repeat the last command. If the TalkMan speaks this command, then it wants the user to repeat a command.<br data-source-node="n175"><br data-source-node="n176"></li>
            <li data-source-node="n177">TalkMan Help &lt;command&gt;: TalkMan will speak the valid words that can be spoken by the user in a certain situation.<br data-source-node="n178"><br data-source-node="n179"></li>
            <li data-source-node="n180">Ready: This command is spoken by the user to confirm actions.<br data-source-node="n181"><br data-source-node="n182"></li>
            <li data-source-node="n183">Change Region: This command will allow the user to use a different region when picking. </li>
        </ul>

        <h4 data-source-node="n186"><a name="otherSupportedFlows" data-source-node="n187"></a>Other Supported Vocollect Picking Flows...</h4>
        <p data-source-node="n188">In addition to the "basic" picking flow (outlined in the above procedure), SCALE supports these other voice picking flows. Be sure to address the appropriate fields in the SCALE Vocollect configurations to make sure these methods operate correctly.</p>
        <ul data-source-node="n189">
            <li data-source-node="n190">Pick Into Final Shipping Container: This flow involves either creating the container on-the-fly, or during wave.  You can choose to pick into those shipping containers directly.  Once you do, you can close and send them out of the door.<br data-source-node="n191"><br data-source-node="n192"></li>
            <li data-source-node="n193">Pick Into Tote/Transport Container: With this flow, there is no container created during wave, and you need to choose to specify the tote ID while picking.  The basic idea here is to pick the items into this transport container.  Once you have your items transferred to the shipping dock, the tote is emptied out and is ready to be used by a different work ID.<br data-source-node="n194"><br data-source-node="n195"></li>
            <li data-source-node="n196">Pick/Pack Via RF Picking: This flow involves not using any container to transfer your items from its location to the shipping dock.  You use equipment (such as a forklift) to do the move.<br data-source-node="n197"><br data-source-node="n198"></li>
            <li data-source-node="n199">Lot Validation: Item validation with lot controlled items using Vocollect is not recommended at this time. However, if you would like to use this functionality, note that you will need to specify the same quantity twice when item quantity is validated.</li>
        </ul>

        <h4 data-source-node="n202"><a name="workInstSort" data-source-node="n203"></a>Note on How Vocollect Work Instructions Are Sorted...</h4>
        <p data-source-node="n204">Below is how the system sorts the work instructions that it sends to a Vocollect device. Note that in some circumstances it is different than how instructions are sorted on an RF device. Note that this only pertains to  the sort order of the individual instructions of a particular Vocollect  assignment ID. The instructions are sorted in the following fashion: </p>
        <ul data-source-node="n205">
            <li data-source-node="n206">If there is 1 work unit on the current Vocollect assignment and the user chooses the "Normal" sort order, the system will sort in ascending Sequence (from the Work Instruction table) order.<br data-source-node="n207"><br data-source-node="n208"></li>
            <li data-source-node="n209">If there is 1 work unit on the current Vocollect assignment and the user chooses the "Reverse" sort order, the system will sort in descending Sequence (from the Work Instruction table) order.<br data-source-node="n210"><br data-source-node="n211"></li>
            <li data-source-node="n212">If there is greater than 1 work unit on the current Vocollect assignment and the user chooses the "Normal" sort order, the system will sort in ascending Sequence (from the Work Instruction table) order.<br data-source-node="n213"><br data-source-node="n214"></li>
            <li data-source-node="n215">If there is greater than 1 work unit on the current Vocollect assignment and the user chooses the "Reverse" sort order, the system will sort in descending Sequence (from the Work Instruction table) order.</li>
        </ul>

        <h4 data-source-node="n218"><a name="basicPickingProc" data-source-node="n219"></a>Procedures: Basic Picking With Vocollect...</h4>
        <p data-source-node="n220">Below represents a normal picking flow when performing user or system-directed picks with a TalkMan device. </p>
        <p data-source-node="n221"> </p>
        <ol data-source-node="n222">
            <li value="1" data-source-node="n223">Turn on the TalkMan device. The device will speak your user name. The user will speak Ready. <br data-source-node="n224"> </li>
            <li value="2" data-source-node="n225">The TalkMan asks for a password. The user will then speak the correct password, such as "one, two" for a password of 12.<br data-source-node="n226"><br data-source-node="n227"></li>
            <li value="3" data-source-node="n228">The TalkMan speaks the region that is associated with this user.<br data-source-node="n229"><br data-source-node="n230"></li>
            <li value="4" data-source-node="n231">The TalkMan asks for the Vehicle Type you want to use while picking, such as a forklift. Remember to speak the number, not the name, of the vehicle type.<br data-source-node="n232"><br data-source-node="n233"></li>
            <li value="5" data-source-node="n234"> The TalkMan will speak the picking mode (such as Normal). If multiple functions are supported, the user will need to speak the function they want to use (SCALE currently supports Normal). <br data-source-node="n235"> </li>
            <li value="6" data-source-node="n236">The TalkMan asks how many assignment(s) the user wants. If more than one (as defined on the Maximum Assignments Field of the Vocollect Region Window) and using the user-directed assignment mode, the TalkMan will ask the user to speak all the work ID's before picking begins. In system-directed assignment mode, the system will assign the work IDs before picking begins.<br data-source-node="n237"> </li>
            <li value="7" data-source-node="n238">The TalkMan asks for the Vocollect Region you want to use while picking. The user speaks their desired region. A region record determines how the voice picking process is managed (similar to a work profile).<br data-source-node="n239"><br data-source-node="n240">NOTE: The region permissions for work type will be handled in SCALE at the work profile level.  Note that this requires only one work profile detail configured per work profile header. The system will not cycle through the various work profile detail records (within a work profile header) for voice picking.  Based on what Function the user has chosen, SCALE will send back the active Vocollect region(s) that are assigned to active work profiles.  These records will contain the region number and region name of each Vocollect region. <br data-source-node="n241"> </li>
            <li value="8" data-source-node="n242">Next, the TalkMan will start the picking process, depending on if your region is configured for user-directed or system-directed picking:<br data-source-node="n243"><br data-source-node="n244">- If user-directed, the TalkMan asks for the work ID. The user will speak the work ID that they want to pick. Note that you will need to speak the last number of the work ID's digits that is defined on the Work ID Length Field of the Vocollect Region Window). Note that if, for example, there is a delimiter contained in the work ID (because there are two work IDs created with the same ID and appended with a delimiter, such as #00001), the system will return both of these work IDs to the Vocollect device. The Vocollect device would then ask the user to identify which work unit the user wants to process.<br data-source-node="n245"><br data-source-node="n246">- If system-directed, the TalkMan will begin to process the first eligible work ID (it does not speak the work ID to the user).<br data-source-node="n247"><br data-source-node="n248"></li>
            <li value="9" data-source-node="n249">The TalkMan will ask for the container type (if appropriate). The user will speak the value. The container types available for picking into a shipping container can be authorized by company and warehouse. See the <a href="b8520236e77bf1d9729a56d56a398123183351403f9a3eff7e86595795483b9e.html" data-source-node="n250">Defining Container Types</a> for more details.<br data-source-node="n251"><br data-source-node="n252"></li>
            <li value="10" data-source-node="n253">The TalkMan will ask for the container ID (if appropriate). The user will speak the value.<br data-source-node="n254"> <br data-source-node="n255"></li>
            <li value="11" data-source-node="n256">The TalkMan will speak the picking location. This is done segment-by-segment. For example, suppose you need to pick 5 EA from the location 111-AAA-BB (made up of three segments). The TalkMan will speak the first segment, and then the user will say Ready. The TalkMan will then speak the rest of the segments in this manner. Note that if the location has more than four segments, then the TalkMan will speak the first three segments, and then skip to the last segment.<br data-source-node="n257"><br data-source-node="n258"></li>
            <li value="12" data-source-node="n259">When the last segment is spoken by the TalkMan, it will also speak the quantity and UM of the pick, if quantity verification is activated on the Vocollect Region Window. For example, for the above location, the TalkMan would say for the third segment BB, 5 EA. <br data-source-node="n260"> </li>
            <li value="13" data-source-node="n261">The TalkMan will ask for a check digit (if this verification is activated on the Location Window). The user will need to speak the check digit. If there is no check digit available, the user will speak the item ID or item cross reference (depending on what is indicated on the Item Reference Field of the Vocollect Region Window). You will need to speak the last five digits of the ID.<br data-source-node="n262"> </li>
            <li value="14" data-source-node="n263">The TalkMan will ask for the quantity of the pick:<br data-source-node="n264"><br data-source-node="n265">- Pick Exact Quantity: The TalkMan beeps, says Picking Complete, and then confirms the quantity picked. The TalkMan then asks for another work ID (see beginning of these procedures).<br data-source-node="n266"><br data-source-node="n267">- Pick Over Quantity: The TalkMan repeats user's spoken pick quantity, and then asks for a work ID. The TalkMan will not process over picks.<br data-source-node="n268"><br data-source-node="n269">- Pick Under Quantity: If the user speaks a quantity that is less than the full quantity, the TalkMan  asks the user if this is a shortage.  If the user says yes, then the system confirms the short pick.  If the user says no (as if he is attempting to partial  pick), then the system circles back around and starts again with the quantity  request (as if starting the work instruction over). Vocollect <u data-source-node="n270">will</u> <u data-source-node="n271">not</u> allow the user to partial pick and move onto the next pick.<br data-source-node="n272"></li>
        </ol>
