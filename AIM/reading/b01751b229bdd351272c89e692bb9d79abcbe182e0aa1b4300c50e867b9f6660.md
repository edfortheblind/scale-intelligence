
        
        <h1 data-source-node="n56"><a name="kanchor1025" data-source-node="n57"></a>Default SCALE Mapped Field / SCALE Mapped Field</h1>
        <p data-source-node="n58">This field indicates the value in the system that an application identifier will 
 represent. For example, the GTIN application identifier maps to the system's
 "Item" field. This field allows the user to change the Default SCALE Mapped Field between the Item and Item Cross Reference fields for the 01 and 02 identifiers only.  Note that none of the other AIs use this field.</p>
