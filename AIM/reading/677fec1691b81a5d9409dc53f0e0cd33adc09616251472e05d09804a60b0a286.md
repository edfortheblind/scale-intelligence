
        
        <h1 data-source-node="n56">Warehouse Mobile Screen Flow</h1>
        <p data-source-node="n57">The Warehouse Mobile application uses the  Screen Rendering File (SRC) file to display and control the screen user interface functionality. </p>
        <p data-source-node="n58"> </p>
        <h5 data-source-node="n59">Pre-requisites</h5>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">The following needs to be done before we define the Warehouse Mobile Screen Flow.</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63"><b data-source-node="n64">SRC Files</b>
        </p>
        <p data-source-node="n65">The SRC files are shipped with the application. It is recommended  to use these SRC file. Download and save the SRC file in the system. All SRC files are available in the screen flow folder of the application binary.</p>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67"><b data-source-node="n68">Define SRC file path</b>
        </p>
        <p data-source-node="n69">Navigate to <b data-source-node="n70">Configurations&gt;&gt;Technical &gt;&gt; Technical Values</b>. In the <b data-source-node="n71">Technical Values</b> page, select <b data-source-node="n72">SRC File path (Key 440 )</b>. </p>
        <p data-source-node="n73">In the <b data-source-node="n74">System Value</b> text box enter the SRC File path stored in the system.</p>
        <p data-source-node="n75"> </p>
        <h4 data-source-node="n76">Configuration steps</h4>
        <p data-source-node="n77">Follow the steps to configure the work flow JSON file.</p>
        <ul data-source-node="n78">
            <li data-source-node="n79">Navigate to <b data-source-node="n80">Configurations &gt;&gt;Personalization/Extensibility &gt;&gt;Work Flow &gt;&gt;Warehouse Mobile Screen Flow</b></li>
            <li data-source-node="n81">Add New configuration. Enter Identifier, Record type and Description. </li>
            <li data-source-node="n82"> select the <b data-source-node="n83">Workflow file</b> from the drop down list. </li>
        </ul>
