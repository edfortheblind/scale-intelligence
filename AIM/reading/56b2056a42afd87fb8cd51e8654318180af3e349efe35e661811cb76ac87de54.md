
        
        <h1 data-source-node="n56"><a name="kanchor1512" data-source-node="n57"></a>Creating/Processing a Shipment Line</h1>
        <p data-source-node="n58">When an order is interfaced, the system creates a shipment line 
 that corresponds to each order line. The system will also generate 
 lines when one is split to accommodate warehouse activity, such 
 as inadequate stock. You can also manually create a line to accommodate 
 special circumstances, such as call-in orders.</p>

        <h4 data-source-node="n368"><a name="Creating" data-source-node="n369"></a>Creating a Shipment Line...</h4>
        <p data-source-node="n370">The following information is a general 
 description of each tab used in creating a shipment line using the Shipment Line Screen. For specific 
 definitions of a certain field, see the "Field Links" section 
 of this topic, or type the field name into the help index. </p>
        <p data-source-node="n371"> </p>
        <h5 data-source-node="n372">Common Fields</h5>
        <ol class="ol_1" data-source-node="n373">
            <li value="1" data-source-node="n374">Use the Internal 
 Shipment Line Number Field to view the internal line number that 
 was generated in the interface. The internal shipment line number represents 
 the order line.<br data-source-node="n375"><br data-source-node="n376"></li>
            <li value="2" data-source-node="n377">Use the Shipment 
 ID Field to view the shipment ID associated with this shipment 
 line.<br data-source-node="n378"><br data-source-node="n379"></li>
            <li value="3" data-source-node="n380">Use the Internal 
 Shipment Number Field to view the internal number assigned to a 
 shipment in the system. This value identifies the shipment within the 
 system. This value is unique.<br data-source-node="n381"><br data-source-node="n382"></li>
            <li value="4" data-source-node="n383">Use the Warehouse 
 Field to view the warehouse associated with this shipment line.<br data-source-node="n384"><br data-source-node="n385"></li>
            <li value="5" data-source-node="n386">Use the Order 
 Number Field to view the order number associated with a specific 
 order request. All shipments are associated with an order. Order numbers 
 originate in the ERP. When interfacing an order, the system assigns it 
 a shipment ID number. All activity in the system is committed against 
 the shipment ID number, not the order number.<br data-source-node="n387"><br data-source-node="n388"></li>
            <li value="6" data-source-node="n389">Use the Order 
 Line Number Field to view the specific order line number associated 
 with this specific shipment line. The system generates a shipment 
 line for every existing order line number.</li>
        </ol>
        <p data-source-node="n390"> </p>
        <h5 data-source-node="n391">Item Info Tab </h5>
        <p data-source-node="n392">- You can use these fields to enter the item that you want 
 on this shipment line. </p>
        <p data-source-node="n393"> </p>
        <h5 data-source-node="n394">Quantity Info Tab </h5>
        <p data-source-node="n395">- You can use these fields to enter the quantity that you want 
 on this shipment line. </p>
        <p data-source-node="n396"> </p>
        <h5 data-source-node="n397">Item Dimensions Tab </h5>
        <p data-source-node="n398">- You can use these fields to enter the physical measurements of the 
 line's item.</p>
        <p data-source-node="n399"> </p>
        <h5 data-source-node="n400">Item Characteristics Tab </h5>
        <p data-source-node="n401">- You can use these fields to define specific item-level values associated 
 with this line, including such fields as Item Price/Color/Style/Size, 
 Lot/Serial Control, and various allocation and unit of measure settings.</p>
        <p data-source-node="n402"> </p>
        <h5 data-source-node="n403">Dates Tab</h5>
        <p data-source-node="n404">- You can use these fields to view the dates associated with this line.</p>
        <p data-source-node="n405"> </p>
        <h5 data-source-node="n406">Status  Tab </h5>
        <p data-source-node="n407">- You can use these fields to view/define information about this line's 
 current status.</p>
        <p data-source-node="n408"> </p>
        <h5 data-source-node="n409">Advanced Allocation Tab</h5>
        <p data-source-node="n410">- You can use these fields when attempting to allocate quantity for a shipment line (this process is sometimes called variable quantity or percent allocation).</p>
        <p data-source-node="n411"> </p>
        <h5 data-source-node="n412">Packing Tab</h5>
        <p data-source-node="n413">- You can use these fields when attempting to  associate shipment lines with containers, perform item validation, and generate packing labels. </p>
        <p data-source-node="n414"> </p>
        <h5 data-source-node="n415">Bill Of Materials Tab</h5>
        <p data-source-node="n416">- You can use these fields to view/define a finished items and its requirements. </p>
        <p data-source-node="n417"> </p>
        <h5 data-source-node="n418">Picking Tab</h5>
        <p data-source-node="n419">- You can use these fields to view/define picking associated with a shipment line. </p>
        <p data-source-node="n420"> </p>
        <h5 data-source-node="n421">Immediate Needs Tab</h5>
        <p data-source-node="n422">- You can use these fields to view/define immediate needs request associated with a shipment line. </p>
        <p data-source-node="n423"> </p>
        <h5 data-source-node="n424">Comments Tab</h5>
        <p data-source-node="n425">- You can use this tab to view the comments associated with this line.</p>
        <p data-source-node="n426"> </p>
        <h5 data-source-node="n427">VAS Activities Tab </h5>
        <p data-source-node="n428">- You can use these fields to review or add value added services to this shipment line.</p>
        <p data-source-node="n429"> </p>
        <h5 data-source-node="n430">Reference Info Tab </h5>
        <p data-source-node="n431">- You can use these fields to define various processing values for this 
 line.</p>
        <p data-source-node="n432"> </p>
        <h5 data-source-node="n433">Classification Tab </h5>
        <p data-source-node="n434">- You can use this tab to view the various codes associated with this line.</p>
        <p data-source-node="n435"> </p>
        <h5 data-source-node="n436">Mark For Tab </h5>
        <p data-source-node="n437">- You can use these fields to define the "mark for address" 
 for this line. This address represents the final destination for a shipment 
 with a ship to address. </p>
        <p data-source-node="n438"> </p>
        <h5 data-source-node="n439">International Tab </h5>
        <p data-source-node="n440">- You can use these fields to define fields that deal with international 
 shipping for this line.</p>
        <p data-source-node="n441"> </p>
        <h5 data-source-node="n442">Categories Tab </h5>
        <p data-source-node="n443">- You can use these "category" fields to associate these user-defined 
 categories to this line.</p>
        <p data-source-node="n444"> </p>
        <h5 data-source-node="n445">User Defined Tab</h5>
        <p data-source-node="n446">- You can use these fields to define the user defined fields. </p>
        <p data-source-node="n447"> </p>
        <h5 data-source-node="n448">When Finished...</h5>
        <p data-source-node="n449">- Press Save. The system will 
 add this new shipment line. Its leading and trailing status are determined 
 by the status action value associated with the window that you're creating 
 it on. </p>
        <p data-source-node="n450"> </p>
        <p data-source-node="n451">NOTE: If you created this line
 on the Shipment insight screen, its status is based on 
 the value defined in the "Add From Shipping" status action setting. If you created 
 this line on the Planned shipment insight, its status is based 
 on the value defined in the "Add From Wave" status action setting. If you created 
 this line on the Order Entry Window, its status is based on the value 
 defined in the "Add From Order Entry" status action setting.</p>

        <h4 data-source-node="n457"><a name="Cancelling" data-source-node="n458"></a>Canceling a Shipment 
 Line...</h4>
        <p data-source-node="n459">You may need to delete a shipment line to accommodate a customer's 
 request. If a shipment line is part of a wave, then the option is available 
 to cancel the line item. If a shipment line is not part of a 
 wave, see the procedures for deleting a shipment line. When you 
 cancel the line from the wave, the system creates a duplicate shipment 
 in the Planned Shipment Insight with a status of "In Pool."</p>
        <ol data-source-node="n460">
            <li value="1" data-source-node="n461">
                <p data-source-node="n462">Access the Shipment Line Insight or the Planned Shipment Insight.</p>
                <p data-source-node="n463"> </p>
            </li>
            <li value="2" data-source-node="n464">
                <p data-source-node="n465">Access the line that you 
 want to cancel. Select the Cancel Action.</p>
                <p data-source-node="n466"> </p>
            </li>
            <li value="3" data-source-node="n467">
                <p data-source-node="n468">The system will display a confirmation 
 window. Verify that you want to cancel this detail.</p>
                <p data-source-node="n469"> </p>
            </li>
            <li value="4" data-source-node="n470">Press OK. 
 The system will cancel the line.</li>
        </ol>

        <h4 data-source-node="n475"><a name="Deleting" data-source-node="n476"></a>Deleting a Shipment 
 Line...</h4>
        <p data-source-node="n477">You may need to delete a shipment line to accommodate a customer's 
 request. The system will not allow you to delete a line associated 
 with a container or wave. To delete a shipment line associated with 
 a wave, see the procedures for canceling a shipment line above.</p>
        <ol data-source-node="n478">
            <li value="1" data-source-node="n479">
                <p data-source-node="n480">Access the Shipment Line Insight or the Planned Shipment Insight.</p>
                <p data-source-node="n481"> </p>
            </li>
            <li value="2" data-source-node="n482">
                <p data-source-node="n483">Access the line record that you 
 want to delete, and select the Delete Action.</p>
                <p data-source-node="n484"> </p>
            </li>
            <li value="3" data-source-node="n485">
                <p data-source-node="n486">The system will display a confirmation 
 window. Verify that you want to delete this line.</p>
                <p data-source-node="n487"> </p>
            </li>
            <li value="4" data-source-node="n488">Press OK. 
 The system will delete the line.</li>
        </ol>

        <h4 data-source-node="n493"><a name="Transferring" data-source-node="n494"></a>Transferring 
 a Shipment Line...</h4>
        <p data-source-node="n495">You can transfer a line to a different shipment as long as the 
 original shipment has not been confirmed.</p>
        <ol data-source-node="n496">
            <li value="1" data-source-node="n497">
                <p data-source-node="n498">Access the Shipment Line Insight screen.<br data-source-node="n499"><br data-source-node="n500"></p>
            </li>
            <li value="2" data-source-node="n501"> Select the line that you want 
 to transfer to a different shipment.<br data-source-node="n502"><br data-source-node="n503"></li>
            <li value="3" data-source-node="n504">Select the Transfer 
 Action. The system will display the Transfer Shipment Line Screen. 
 Information about the detail and its current shipment (the shipment you 
 are transferring from) is provided.<br data-source-node="n505"><br data-source-node="n506"></li>
            <li value="4" data-source-node="n507">Use the Shipment ID Field in the Destination 
 Shipment accordion to identify the shipment that you want to transfer 
 this detail to.<br data-source-node="n508"><br data-source-node="n509">- If you want to transfer to an 
 existing shipment, you can use the Lookup Search to find a particular 
 shipment.<br data-source-node="n510"><br data-source-node="n511">- If you want to transfer to a new shipment, select the New action in the Actions Menu. The system 
 will display the Shipment screen in new mode. Define this shipment. Press Save when complete. 
 The system will create the shipment and navigate back to the Transfer 
 Shipment Line Screen. It will display this new shipment in the 
 Shipment ID Field. <br data-source-node="n512"><br data-source-node="n513"></li>
            <li value="5" data-source-node="n514">Press the Transfer Button. 
 The system will transfer the shipment line to the destination shipment.</li>
