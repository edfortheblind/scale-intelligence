
        
        <h1 data-source-node="n56"><a name="kanchor1465" data-source-node="n57"></a>Lot Verify Checkbox</h1>
        <p data-source-node="n58">This setting determines whether or not the user is required to identify the lot ID associated with the item quantity that he/she is picking. If this is not checked, the Lot Field on the RF Pick Confirmation screen will be read-only. If it is checked, the system will display the correct ID, and the user will need to scan the lot to verify the value. </p>
