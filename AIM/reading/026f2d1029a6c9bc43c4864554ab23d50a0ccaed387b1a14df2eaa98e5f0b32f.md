
        
        <h1 data-source-node="n56"><a name="kanchor578" data-source-node="n57"></a>Auto Print At Load Confirm Checkbox</h1>
        <p data-source-node="n58">Use this checkbox to indicate that you would require the system to automatically print any/all documents with print process of Shipment or Load. Keep the "default" option checked. If this option is checked, auto printing during load confirmation will be enabled. No documents will be printed when this option is unchecked. Printing errors will be written to the audit log. </p>
