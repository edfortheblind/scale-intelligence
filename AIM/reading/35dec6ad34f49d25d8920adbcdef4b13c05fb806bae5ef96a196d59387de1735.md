
        
        <h1 data-source-node="n56"><a name="kanchor1394" data-source-node="n57"></a>Defining Application Identifier Templates</h1>
        <p data-source-node="n58">An application identifier template is used by the system to determine 
 how GS1 barcodes will be parsed by SCALE during RF receipt check in. This 
 template record indicates such things as how many user scans are required, 
 what order the AI segments will be scanned, and whether or not users will 
 have to manually verify scanned data. AI templates are associated with 
 a user's receiving preference record. Note that these templates are not 
 used to determine the actual physical layout of a GS1 label. They are 
 used to determine how the system will process GS1 barcode information 
 during RF receipt check in.</p>

 and provide it with a name and description.</p><p data-source-node="n129"> </p><p data-source-node="n130"> </p><h4 data-source-node="n131">General 
 Tab...</h4><ol class="ol_1" data-source-node="n132"><li value="1" data-source-node="n133">Use the Number 
 of Scans Allowed Field to indicate the number of barcodes that 
 the user will be required to scan on a GS1 label. The system will expect 
 this number of scans during GS1 RF receipt check in.<br data-source-node="n134"> </li><li value="2" data-source-node="n135">Use the FNC1 
 Separator Field to indicate what character you want the system 
 to use to divide segments on a barcode. This separator can be any alphanumeric, 
 ASCII, or non-printable character, and is required. <br data-source-node="n136"><br data-source-node="n137">- The default/standard GS1 seperator 
 is ASCII value 29 (a non-printable character). 
 This should be sufficient for most situations. <br data-source-node="n138"><br data-source-node="n139">- Note that if you define 
 a printable character as a separator, then it will appear in the human 
 readable portion of the barcode/label.<br data-source-node="n140"><br data-source-node="n141">- 
The FNC1 separator is only placed at the end of a variable length AI when it is not the last AI in the barcode.  <br data-source-node="n142"> </li><li value="3" data-source-node="n143">Use the Show 
 Verification Screen Checkbox to indicate the system should display 
 an extra screen during RF GS1 check in processing, so that after a scan, 
 the user will have to verify that the data they scanned from a barcode 
 was correct. This screen will appear after all the barcodes for a template 
 have been scanned.</li></ol><p data-source-node="n144"> </p><h4 data-source-node="n145">Detail 
 Records Tab...</h4><ul type="disc" class="ul_1" data-source-node="n146"><li data-source-node="n147">To create a new 
 template detail record, right-click and choose New. The system 
 will display the Application Identifier Template Detail Window.</li></ul><p data-source-node="n148"> </p><h4 data-source-node="n149">Procedures: Template Detail Window...</h4><ol class="ol_1" data-source-node="n150"><li value="1" data-source-node="n151">Use the Sequence 
 Field to indicate where in the barcode that the system will expect 
 this segment to appear in (starting from the left side of the barcode). 
 <br data-source-node="n152"> </li><li value="2" data-source-node="n153">Use the Scan 
 Field to indicate which user scan the system can expect this segment's 
 data to be a part of. For example, if your label has three barcodes, there 
 would be three scans required.<br data-source-node="n154"> </li><li value="3" data-source-node="n155">Use the Application 
 Identifier Field to indicate which GS1 data segment will be a part 
 of this scan.<br data-source-node="n156"> </li><li value="4" data-source-node="n157">Use the SCALE Mapped 
 Field to indicate the SCALE field that this application identifier 
 segment will represent. The system will default a value into this field 
 when you choose an AI in step 3; only edit this value if, because of your 
 business practices, you want this segment to point to a value different 
 than the GS1 standard. For example, the GS1 standard for the 02 AI is 
 Item Cross Reference. If you want this AI to point to the Item Field for 
 this template, you would choose Item as the mapped field.<br data-source-node="n158"> </li><li value="5" data-source-node="n159">Variable 
 Type Field: The following are used when an application identifier has a variable length string length type:<br data-source-node="n160"><br data-source-node="n161">- Calculated Length: Use this when the application identifier uses a calculated length to determine when to parse for the next AI.  

AI 23 (lot/batch) is an example of an application identifier that requires a calculated length.  The first digit after the AI (e.g., 23x) indicates the length of the data.  This is the only SCALE supported application identifier that uses calculated length.<br data-source-node="n162"><br data-source-node="n163">- FNC1 Separator: Use this when the application identifier requires an FNC1 separator to determine when to parse for the next AI.  The majority of variable length application identifiers require an FNC1 separator. <br data-source-node="n164"> </li><li value="6" data-source-node="n165">Press OK.
