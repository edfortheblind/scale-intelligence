        <h4 data-source-node="n124"><a name="OverridePickOptions" data-source-node="n125"></a>Override Pick Options</h4>
        <p data-source-node="n126">The following override pick options are available during the picking process. These options are defined in the Work Special Handling Window:  </p>
        <p data-source-node="n127"> </p>
        <p data-source-node="n128"> </p>
        <h5 data-source-node="n129">License Plate</h5>
        <p data-source-node="n130">You can override the license plate from which you are going to pick if license plate override is active on your work special handling record. The user would scan a different LP value (than the one currently assigned to the work instruction) in the LP field, and the system will treat this as an override of the original LP value. When you then press OK or Short Pick, the system will validate the new LP value. However, if either of the LP’s have any Suspense Quantity, then the override of the LP will not be allowed.  </p>
        <p data-source-node="n131"> </p>
        <p data-source-node="n132"> </p>
        <h5 data-source-node="n133">Location</h5>
        <p data-source-node="n134">You can override the pick location from which you are going to pick product if location override is active on your work special handling record. The user would scan a different location ID (than the one currently assigned to the work instruction) in the Location field, and the system will treat this as an override of the original location value. When you then press OK or Short Pick, the system will validate that the new location has the correct item quantity to pick from. Note that you would likely have to override the original LP as well when you want to choose a new pick location. For non-license plate tracked locations, an override is allowed as long as the location being overridden to has enough available quantity (subtracting out the suspense quantity) to complete the override.</p>
        <p data-source-node="n135"> </p>
        <p data-source-node="n136"> </p>
        <h5 data-source-node="n137">Lot</h5>
        <p data-source-node="n138">You can override the lot ID of the item you are going to pick if lot override is active on your work special handling record. The user would scan a different lot ID (than the one currently assigned to the item on the work instruction) in the Lot field, and the system will treat this as an override of the original lot value. When you then press OK or Short Pick, the system will validate the item's new lot ID.</p>
        <p data-source-node="n139"> </p>
        <p data-source-node="n140"> </p>
        <h5 data-source-node="n141">Shipping Container</h5>
        <p data-source-node="n142">You can override the shipping container that you are picking into, if the allow shipping container override setting is active on your work special handling record. Note this is only for use when picking into shipping container.</p>
        <p data-source-node="n143"> </p>
        <p data-source-node="n144"> </p>

        <h4 data-source-node="n148"><a name="OverridePickGenRules" data-source-node="n149"></a>Override Pick General Rules</h4>
        <p data-source-node="n150">Below are the rules that the system applies when you attempt to override during a pick:</p>
        <p data-source-node="n151"> </p>
        <p data-source-node="n152"> </p>
        <h5 data-source-node="n153">License Plate</h5>
        <p data-source-node="n154"> </p>
        <p data-source-node="n155">The override license plate must:</p>
        <ul data-source-node="n156">
            <li data-source-node="n157"> Contain the ITEM <br data-source-node="n158"><br data-source-node="n159"></li>
            <li data-source-node="n160">Reside in the same LOCATION as the original license plate (unless location override is allowed)<br data-source-node="n161"><br data-source-node="n162"></li>
            <li data-source-node="n163">Match the QUANTITY (if the "allow different quantity" work special handling setting is not selected)<br data-source-node="n164"></li>
        </ul>
        <p data-source-node="n165"> </p>
        <p data-source-node="n166">When the License Plate is overridden:</p>
        <ul data-source-node="n167">
            <li data-source-node="n168">The location inventory, work instructions, and relevant records are updated to reflect the override license plate (shipment allocation, shipment line, shipping containers, replenishment, work order, inventory management).</li>
        </ul>
        <p data-source-node="n169"> </p>
        <h5 data-source-node="n170">Location</h5>
        <p data-source-node="n171"> </p>
        <p data-source-node="n172">The override location must:</p>
        <ul data-source-node="n173">
            <li data-source-node="n174">Contain the ITEM (with enough quantity)<br data-source-node="n175"><br data-source-node="n176"></li>
            <li data-source-node="n177">Contain the LOT</li>
        </ul>
        <p data-source-node="n178"> </p>
        <p data-source-node="n179">When the location is overridden:</p>
        <ul data-source-node="n180">
            <li data-source-node="n181">The location inventory, work instructions, and relevant records are updated to reflect the override location (shipment allocation, shipment line, shipping containers, replenishment, work order, inventory management).</li>
        </ul>
        <p data-source-node="n182"> </p>
        <h5 data-source-node="n183">Lot</h5>
        <p data-source-node="n184"> </p>
        <p data-source-node="n185">The override lot must:</p>
        <ul data-source-node="n186">
            <li data-source-node="n187"> Be tied to the ITEM<br data-source-node="n188"><br data-source-node="n189"></li>
            <li data-source-node="n190">Reside in the same LOCATION (unless location override is allowed)<br data-source-node="n191"><br data-source-node="n192"></li>
            <li data-source-node="n193">Have enough QUANTITY</li>
        </ul>
        <p data-source-node="n194">The override lot must not:</p>
        <ul data-source-node="n195">
            <li data-source-node="n196">Be allocated at the destination location. This restriction is applicable only when the replenishment destination location is non-LP tracked location, and the allocated quantity is greater than on hand quantity.</li>
        </ul>
        <p data-source-node="n197"> </p>
        <p data-source-node="n198">When the Lot is overridden:</p>
        <ul data-source-node="n199">
            <li data-source-node="n200">The location inventory, work instructions, and relevant records are updated to reflect the override Lot (shipment allocation, shipment line, shipping containers, replenishment, work order, inventory management).</li>
        </ul>
        <p data-source-node="n201"> </p>

        <h4 data-source-node="n205"><a name="OverrideLPlessQty" data-source-node="n206"></a>Override License Plate With Less Quantity</h4>
        <p data-source-node="n207">
        The quantity does not need to match if the "Allow different quantity override" setting is selected on your work special handling record. In this case, the override is allowed if the available quantity on the license plate being overridden to is greater than or equal to the pick quantity, OR the available quantity plus allocated quantity on the license plate being overridden to is greater than or equal to the pick quantity, and there is enough available quantity on the original license plate to move all allocated quantity from the license plate being overridden to, to the original license plate.</p>
        <p data-source-node="n208"> </p>
        <p data-source-node="n209">
         
        <i style="text-decoration: underline" data-source-node="n210">Example 1</i></p>
        <p data-source-node="n211"> </p>
        <p data-source-node="n212">- LP1 has on hand quantity 36 with Shipment1 allocated for quantity 20.</p>
        <p data-source-node="n213">- LP2 has on hand quantity 24 with Shipment2 allocated for quantity 4.</p>
        <p data-source-node="n214">- When user performs pick for Shipment1, overrides to LP2.</p>
        <p data-source-node="n215">- <b data-source-node="n216">Override is allowed</b> with no change to allocations for LP2, since there was enough available quantity to handle the override.</p>

        <h4 data-source-node="n281"><a name="AutoLicenseOverridePick" data-source-node="n282"></a>Automatic Defaulting of License Plate during Override Pick</h4>
        <p data-source-node="n283"> </p>
        <p data-source-node="n284">When you enter or scan a new location in order to override the current pick, the system can default the license plate in certain instances. When you change the location value to pick from a different location than requested, the system will check to determine whether the license plate should be defaulted. The system will default the license plate when all of the following conditions are met:</p>
        <ul data-source-node="n285">
            <li data-source-node="n286">
                <p data-source-node="n287">The new location entered is license plate tracked<br data-source-node="n288"><br data-source-node="n289"></p>
            </li>
            <li data-source-node="n290">The user is not required to scan the license plate (license plate verification is inactive)<br data-source-node="n291"><br data-source-node="n292"></li>
            <li data-source-node="n293">
                <p data-source-node="n294">The new location entered contains a single license plate</p>
            </li>
        </ul>
        <p data-source-node="n295"> </p>
        <hr width="100%" align="center" data-source-node="n296">
        <p data-source-node="n297"> </p>
        <p data-source-node="n298"> </p>
        <h4 data-source-node="n299"><a name="AutoLotOverridePick" data-source-node="n300"></a>Automatic Defaulting of Lot during Override Pick</h4>
        <p data-source-node="n301"> </p>
        <p data-source-node="n302">When you enter or scan a new location in order to override the current pick, the system can default the lot in certain instances. When you change the location value to pick from a different location than requested, the system will check to determine whether the lot should be defaulted. The system will default the lot when all of the following conditions are met:</p>
        <ul data-source-node="n303">
            <li data-source-node="n304">
                <p data-source-node="n305">The item being picked is lot tracked<br data-source-node="n306"><br data-source-node="n307"></p>
            </li>
            <li data-source-node="n308">
                <p data-source-node="n309">The user is not required to scan the lot (lot verification is inactive)<br data-source-node="n310"><br data-source-node="n311"></p>
            </li>
            <li data-source-node="n312">
                <p data-source-node="n313">The new location entered does not track license plates and there is a single lot in the location, or the new location entered does track license plates and there is a single license plate in the location that contains a single lot value</p>
            </li>
        </ul>
        <p data-source-node="n314"> </p>
        <p data-source-node="n315">The system can default the lot when you enter or scan a new license plate either in the existing pick location or in the new location. When you change the license plate value to pick from a different license plate than requested, the system will check to determine whether the lot should be defaulted. The system will default the lot in this scenario when all of the following conditions are met: </p>
        <ul data-source-node="n316">
            <li data-source-node="n317">
                <p data-source-node="n318">The item being picked is lot tracked<br data-source-node="n319"><br data-source-node="n320"></p>
            </li>
            <li data-source-node="n321">
                <p data-source-node="n322">The user is not required to scan the lot (lot verification is inactive)<br data-source-node="n323"><br data-source-node="n324"></p>
            </li>
            <li data-source-node="n325">
                <p data-source-node="n326">The new license plate entered contains a single lot value</p>
            </li>
        </ul>
        <p data-source-node="n327"> </p>

        <h4 data-source-node="n331"><a name="PartialPickOverride" data-source-node="n332"></a>Performing a Partial Pick When Overriding</h4>
        <p data-source-node="n333">The system allows you to perform a partial pick when doing an override.  All the validations are the same as a full pick, except that they will be based on the partial picked quantity.  If the validation passes, the system will split the work instruction and allocation request for the partial quantity and update that record with the override location/license plate/lot information. The remaining quantity's work instruction will still have the original location/license plate/lot information.</p>
        <p data-source-node="n334"> </p>
        <p data-source-node="n335"> </p>
        <p data-source-node="n336"><u style="font-style: italic" data-source-node="n337">Example 1</u>
        </p>
        <p data-source-node="n338"> </p>
        <p data-source-node="n339">- LP1 has on hand quantity 36 with Shipment1 allocated for quantity 20.</p>
        <p data-source-node="n340">- LP2 has on hand quantity 16 with nothing allocated.</p>
        <p data-source-node="n341">- When user performs partial pick of 16 for Shipment1, by overriding to LP2.</p>
        <p data-source-node="n342">- <b data-source-node="n343">Override is allowed</b> since there is enough available quantity on the new LP 2 and no allocations to move.  The system will split the instruction and leave the remaining 4 allocated on LP1.</p>
