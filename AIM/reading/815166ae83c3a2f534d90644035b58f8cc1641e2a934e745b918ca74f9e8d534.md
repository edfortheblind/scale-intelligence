        <p data-source-node="n58">This field indicates that a zone or a work 
 type is available for picking using the Pick Management Explorer/Picking 
 Window. You must have this checkbox selected on both the "from" 
 work zone and the work instruction's work type if you want to use these 
 windows to pick.</p>
