
        
        <h1 data-source-node="n56"><a name="kanchor843" data-source-node="n57"></a>Defining the "Reporting" Link on the Web Main Menu</h1>
        <p data-source-node="n58">You can create a custom menu option for the Trading Partner Management 
 Main Menu, which is represented by the "Reporting" link on the 
 main menu. You could use this to display a custom web application, Internet 
 web site, or other type of document. Note that both internal and external 
 web users can view the "Reporting" link. You cannot change the 
 name of this link. The system will always display this with the title 
 of "Reporting."</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">WARNING: You cannot use the "Reporting" 
 link to open an SSRS report. </p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62"> </p>
        <h4 data-source-node="n63">Procedures...<br data-source-node="n64"></h4>
        <h5 style="font-weight: normal" data-source-node="n65">Access the Web Screen Data Window. Open the "Reports" record.</h5>
        <ol data-source-node="n66">
            <li value="1" data-source-node="n67">Use the URL To 
 Call Field  to indicate what you want displayed when a user selects 
 the "Reporting" main menu option. Example values include Internet 
 sites (http://www.manh.com) or 
 other local/network files.</li>
            <p data-source-node="n68"> </p>
            <li value="2" data-source-node="n69">Use the Active 
 Checkbox to indicate if the "Reporting" link will appear 
 on the TPM main menu (the system default is to not make this record active).<br data-source-node="n70"> </li>
            <li value="3" data-source-node="n71">Press OK. 
 The system will save your changes.</li>
        </ol>
