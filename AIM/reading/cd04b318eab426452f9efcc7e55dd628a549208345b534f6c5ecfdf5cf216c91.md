        <p data-source-node="n58">In order to implement consolidation location putaway (which involves the putaway of a shipment's 
 items at an area near the packing stations), you will first need 
 to activate this functionality. The activation of this function is performed on the work profile. See the topic <a href="671ff642f3216ae5a948a064d208b7b4bf66e0f9e75327a7802cd2f83a97d544.html" data-source-node="n59">Creating Work Profiles</a> (the "Consolidate After Putaway" checkbox) for a description of this setting.</p>
