
        
        <h1 data-source-node="n56"><a name="kanchor18" data-source-node="n57"></a>Allow Pick In Transit Checkbox</h1>
        <p data-source-node="n58">This field is located on the Work Special Handling Configuration. If this checkbox is selected, when there is not enough quantity in the location to pick but there is an in transit amount, this will allow the user or work zone to pick against the in transit amount. If this occurs, the inventory will display a negative amount.</p>
