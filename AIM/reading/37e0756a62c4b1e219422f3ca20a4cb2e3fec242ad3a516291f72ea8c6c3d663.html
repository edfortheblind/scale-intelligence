These records define time tracking data for a particular warehouse worker.

Procedures...

 

Access the Time Tracking Window. Create a new record.

  1. Use the User Name Field to identify the warehouse employee whose time will be defined by this record.
     
  2. Use the Days Per Week Field to select which days this employee is regularly scheduled to work.
     
  3. Use the Hours Per Day Field to indicate the number of hours (not including breaks) that this employee is regularly scheduled to work. Note that you can provide partial-hour totals in this field by using decimal values (such as 8.5 hours).
     
  4. Use the Break Hours Per Day Field to indicate the number of hours that this employee is regularly scheduled to take breaks (lunch, etc). Note that you can provide partial-hour totals in this field by using decimal values (such as 1.5 hours).
     
  5. Use the Default Shift Field to indicate the work shift that this employee is scheduled for (such as day shift, first shift, etc).
     
  6. Use the Start Time Until End Time Fields to indicate the time span when the employee starts to work, and when their shift ends. This span should equal the combined values of the Hours Per Day and Break Hours Per Day Fields.
     
  7. Press OK. The system will save your record.
