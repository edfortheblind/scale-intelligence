Creating Movement Classes

Movement classes are associated with both locations and items/item class. At the location level, the movement class identifies what products should be stored in a location. For example, a location classified as a movement class A location should only store those UMs with the same movement class (A). At the item/item class level, the movement class is identified per UM (unit of measure). This allows you to identify how frequently a UM for the item/item class is requested. You can use this information to determine which UMs to store, based on how quickly they can be moved. Note that if you associate movement classes with locations, you should also associate item/item class UMs with these movement classes.
