Labor Shift Assignment Process

The shift assignment process ensures that each user’s work is accurately linked to the correct shift based on their first transaction of the warehouse day. This process works dynamically, using transaction timestamps and the warehouse configured shift schedule.

Warehouse User's First Transaction

The system starts tracking shift assignments as soon as a warehouse user performs their first task of the day using Warehouse Mobile.

 

Example: If a user scans a work unit to begin picking at 6:45 AM, the system will use that timestamp to determine which shift the user will be assigned to.

 

Determining the Shift Based on Transaction Start Time

  • The system identifies the user’s first transaction for the warehouse day and matches it to the shift time configured. Read Shift Time configuration and Warehouse Day for more information.

  • The system then applies the Upcoming Shift Assignment Window configuration to determine whether the transaction should be assigned to the current shift or the upcoming one.

 

What is Upcoming Shift Assignment Window?

 

A defined time period before a shift starts during which an arriving user is assigned to that upcoming shift instead of the current one is called the Upcoming Shift Assignment Window (USAW).

This is configured under: Warehouse Configuration > Labor> Upcoming Shift Assignment Window.

  • Note: The time zone is based on the warehouse local time zone.

 

Example:

Assume we have a shift time defined from 7 AM to 1 PM.

  • If the Upcoming Shift Assignment Window is set to 15 minutes and an employee performs a transaction at 6:50 AM, it will be assigned to the 7:00 AM shift.

Note:

  • If the system adds a Gap (which marks idle or untracked time) before your first task, it will still follow the same rules to figure out your shift.

  • If shift times are not configured, then the system will not record the shift value in labor records.

  • If shift times are configured but your first transaction time doesn't match any of them, the system won’t assign a shift for that day.

 

Rules for Shift Reassignment

A shift reassignment is performed based on the following rules.

  • Consecutive Shifts: If a user works through the end of one shift and continues directly into the next (e.g., works from Shift 3 into Shift 1 of the next day), they will remain assigned to their original shift (Shift 3), and the additional time will be treated as overtime for that shift.

  • Non-Consecutive Shifts: If a user has a significant break between shifts (e.g., works Shift 1, misses Shift 2, and then works again in Shift 3), the system will treat the work in Shift 3 as part of a new session and assign them to Shift 3 for the current day.

Warehouse Day

 

The Warehouse Day defines the operating window (time period) used to track all warehouse activities, such as receiving, picking, packing, and shipping. It is based on a set start and end time that may not align with the standard calendar day. This helps ensure activity tracking is consistent with warehouse shifts and business hours.

 

Determining the Start time and End time of the Warehouse Day

  • Start Time: The warehouse day begins at the start time of the first scheduled shift for the warehouse.

  • End Time: The warehouse day ends at the end time of the last scheduled shift for that warehouse.
