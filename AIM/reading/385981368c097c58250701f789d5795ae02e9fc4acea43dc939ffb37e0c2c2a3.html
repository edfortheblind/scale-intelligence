Label Printer Field

On the Select Wave Printers Window...

This field indicates the printer that you want the system to use when printing wave paperwork that is classified as labels in the Document Type Window. Note that this field lists all of the print devices that are currently configured in the system.

 

 

On the Reprint Wave Documents Window...

This field indicates the label printer that you want the system to use for the reprint action. Note that this field lists all print devices currently configured in the system.

 

 

On the Reprint Wave Labels Window...

This field indicates the label printer that you want the system to use for the reprint action. Note that this field lists all print devices currently configured in the system. If you leave this field blank, then the system will use the printer that was originally used to print these labels in the wave.

 

 

On the User Profile Default Printers Window...

This field indicates a list of all the label printers in the print device configuration. The default printer on the user profile overrides document routing printer configured for the document type. Selecting a printer when printing selected documents will override the default printer.

Note: Printing still requires a document routing record that matches the document routing criteria for the user submitting the print request.

 

 

On the Assign Printer RF Screen

The Default Label Printer field displays the default printer configured for the user profile.

 

The Printer field can be used to change the default printer for the user profile.

 

Performing an action in RF that triggers printing a label will use the default label printer instead of the document routing printer.
