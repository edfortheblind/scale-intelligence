
        
        <h1 data-source-node="n56"><a name="kanchor1596" data-source-node="n57"></a>Work Order Finished Item Putaway List</h1>
        <p data-source-node="n58">A work order finished item putaway list identifies the to and from locations 
 associated with a finished item. This 
 document is often printed when work is not created for finished item putaway. 
 Based on the user's work order preferences record and the document type 
 record, the system can print this document automatically when a finished 
 item is confirmed. </p>
