Creating Inventory Transaction Interface Upload Criteria Records

You can use the Inventory Transaction Interface Upload Criteria to filter the inventory transaction records to be uploaded for the upload process detail. Different filter criteria can be set for each inventory transaction process detail. The system will place the records in the upload directory defined on the interface process detail. If the process detail’s directory is blank, then the upload directory of the interface system value will be used.
