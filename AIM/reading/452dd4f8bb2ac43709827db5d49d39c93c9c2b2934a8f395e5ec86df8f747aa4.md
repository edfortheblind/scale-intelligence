 or outbound system-defined statuses. These values are provided with the 
 system for all system defined statuses, such as check 
 in pending,   in putaway,   in wave, etc.</p>

        <h4 data-source-node="n82">Procedures...</h4>
        <ol data-source-node="n83">
            <li value="1" data-source-node="n84">Access the appropriate 
 internal status name window. Open the appropriate record.<br data-source-node="n85"><br data-source-node="n86"></li>
            <li value="2" data-source-node="n87">Review the value 
 in the Description Field. If necessary, you can change the value 
 in the Description Field.<br data-source-node="n88"><br data-source-node="n89"></li>
            <li value="3" data-source-node="n90">Press OK. 
 The system will save your changes.</li>
        </ol>
