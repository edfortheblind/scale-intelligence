
        
        <h1 data-source-node="n56"><a name="kanchor200" data-source-node="n57"></a>Internet Tracking Link Field</h1>
        <p class="p_1" data-source-node="n58">This field identifies a carrier's parcel tracking 
 website. You will provide this value on the Carrier Window. If you are using the Trading Partner Management 
 program to track parcels, this value is required. It will link container 
 IDs (generated in the system) to the carrier's web page from TPM.</p>
