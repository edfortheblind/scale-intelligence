
        
        <h1 data-source-node="n57"><a name="kanchor1760" data-source-node="n58"></a>Create Putaway Work Checkbox</h1>
        <p data-source-node="n59">This checkbox appears on the Receiving Preferences Window. It determines 
 if the system will locate the user's checked in containers.</p>
        <ul type="disc" class="ul_1" data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">If you select this checkbox, 
 the system will generate putaway instructions as soon as the container 
 is located. The system releases the work automatically.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li class="li_1" data-source-node="n64">If 
 you don't select this checkbox, the system will not create work 
 for what's located. Instead, it will automatically locate the container 
 and put its quantity as On Hand at the destination location(s). Someone 
 will need to ensure that the product is physically delivered to that location(s).</li>
        </ul>
