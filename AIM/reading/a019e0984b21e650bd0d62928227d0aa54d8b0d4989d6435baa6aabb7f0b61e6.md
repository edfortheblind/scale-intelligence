
        
        <h1 data-source-node="n56"><a name="kanchor1125" data-source-node="n57"></a>Theoretical Container Volume Field</h1>
        <p data-source-node="n58">This field defines the maximum volume per container on a rating profile 
 record. During rating, the system will use this field to estimate the 
 number of containers associated with a shipment. For example, if the shipment 
 equals 100 cubic liters and the theoretical container volume is set at 
 25 liters, the system would estimate that four containers were required 
 for the shipment. This value is defined on the Rating Profile 
 Window.</p>
