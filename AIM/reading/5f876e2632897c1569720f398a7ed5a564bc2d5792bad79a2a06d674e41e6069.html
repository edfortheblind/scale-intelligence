GS1 Barcode Process Summary...

** Functionality **

 

 

Summary...

A GS1 barcode is a "smart" barcode that includes item information in addition to the typical item ID value. These barcodes meet internationally accepted standards that are set by the GS1 standards association. Each barcode is comprised of one or more segments (called application identifiers), that define the data that the barcode represents. In SCALE, you can define application identifier templates, which determine how the system will parse the barcode information. These templates then can be associated with a user's receiving preference.

 

A GS1-AI label typically contains two or more barcodes (which include such data values as item/item cross reference, container ID, quantity, lot, etc.). SCALE supports the printing of GS1 labels from the wave and from the close container process. The application is shipped with several generic labels that you can use to create customized labels for your warehouse.

 

NOTE: GS1 barcodes were formally referred to as EAN/UCC.

The following are key features of the GS1 functional area:

 

Inbound RF Processing...

The inbound component of GS1 processing includes using RF to check in license plates that have GS1 labels affixed to them. The RF receipt processing flow is somewhat different when using GS1 than it is when scanning typical barcodes. GS1 barcodes contain multiple informational segments (application identifiers) which represent the data that the barcode section contains. Examples of these application identifier values include item/item cross reference, quantity, lot, and license plate ID. As a result, the system presents the RF user with a different set of screens to scan in the GS1 barcode data. The user will first be presented with a typical initiation screen, and then be taken directly into a series of screens that allow them to scan the GS1 barcodes from the label.

 

An application identifier template is used by the system to determine how GS1 barcodes will be parsed by SCALE during RF receipt check in. This template record indicates such things as how many user scans are required, what order the AI segments will be scanned, and whether or not users will have to manually verify scanned data. AI templates are associated with a user's receiving preference record. Note that these templates are not used to determine the actual physical layout of the Outbound GS1 label.

 

For a more detailed look on how RF receipt processing is altered when using GS1 barcodes, see the topic GS1 RF Processing.

 

 

 

Outbound Label Generation...

The outbound component of GS1 processing includes creating and printing these labels either from a wave or during the close container process. You will configure GS1 label printing just as you would do for a regular shipping label. There are three generic GS1-AI shipping labels that are shipped with the system. These labels include various combinations of application identifiers. The intention of providing these generic labels is so you can use them as a basis for creating customized GS1 labels that will work for your warehouse's needs.
