        </h1>
        <h4 data-source-node="n59">Overview</h4>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Web User configuration is used to create and maintain web user records for SCALE web access. You can define the user type, then associate the user to one or more warehouses and companies.</p>

        <h4 data-source-node="n68">Configure Web User</h4>
        <p data-source-node="n69"> </p>
        <h5 data-source-node="n70">1. Web User</h5>
        <p data-source-node="n71">The Review Web Users screen displays existing records and allows record maintenance.</p>
        <ul data-source-node="n72">
            <li data-source-node="n73">
                <p data-source-node="n74"><b data-source-node="n75">Review Web Users</b>: View existing users with Web User, Type, and Email Address columns.</p>
            </li>
            <li data-source-node="n76">
                <p data-source-node="n77"><b data-source-node="n78">Add New Web User</b>: Create a new web user record.</p>
            </li>
            <li data-source-node="n79">
                <p data-source-node="n80"><b data-source-node="n81">Edit/Delete</b>: Update or remove the selected web user record.</p>
            </li>
        </ul>
        <p data-source-node="n82"> </p>
        <h5 data-source-node="n83">1. General</h5>
        <p data-source-node="n84">Enter core web user details.</p>
        <ul data-source-node="n85">
            <li data-source-node="n86">
                <p data-source-node="n87"><b data-source-node="n88">Web User</b>: Enter the web user ID.</p>
            </li>
            <li data-source-node="n89">
                <p data-source-node="n90"><b data-source-node="n91">Email Address</b>: Enter the email address for the web user.</p>
            </li>
            <li data-source-node="n92">
                <p data-source-node="n93"><b data-source-node="n94">Type</b>: Select either <b data-source-node="n95">Internal</b> or <b data-source-node="n96">External</b>.</p>
            </li>
        </ul>
        <p data-source-node="n97"> </p>
        <h5 data-source-node="n98">2. Warehouse</h5>
        <p data-source-node="n99">Select one or more warehouses that will be applied to the web user.</p>
        <ul data-source-node="n100">
            <li data-source-node="n101">
                <p data-source-node="n102"><b data-source-node="n103">All/List</b>: Toggle selection behavior for warehouse records.</p>
            </li>
            <li data-source-node="n104">
                <p data-source-node="n105"><b data-source-node="n106">Show Selected</b>: Filter the display to selected warehouses.</p>
            </li>
            <li data-source-node="n107">
                <p data-source-node="n108"><b data-source-node="n109">Search</b>: Search warehouse values before selection.</p>
            </li>
        </ul>
        <p data-source-node="n110"> </p>
        <h5 data-source-node="n111">3. Company</h5>
        <p data-source-node="n112">Select one or more companies that will be applied to the web user.</p>
        <ul data-source-node="n113">
            <li data-source-node="n114">
                <p data-source-node="n115"><b data-source-node="n116">All/List</b>: Toggle selection behavior for company records.</p>
            </li>
            <li data-source-node="n117">
                <p data-source-node="n118"><b data-source-node="n119">Show Selected</b>: Filter the display to selected companies.</p>
            </li>
            <li data-source-node="n120">
                <p data-source-node="n121"><b data-source-node="n122">Search</b>: Search company values before selection.</p>
            </li>
        </ul>
        <p data-source-node="n123"> </p>
        <p data-source-node="n124">Use Back, Continue, and Finish to move through the configuration steps and save the Web User record.</p>
