
        
        <h1 data-source-node="n57"><a name="kanchor1030" data-source-node="n58"></a>Document Master Field</h1>
        <p data-source-node="n59">This field identifies the document master record associated with a wave 
 master. When the wave master is applied to shipments in a wave, the document 
 master determines the following:</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">What criteria a record in a wave must meet for the system to generate 
 documentation.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li data-source-node="n64">
                <p data-source-node="n65">Which document types to print when that criteria is met.</p>
                <p data-source-node="n66"> </p>
            </li>
            <li class="li_1" data-source-node="n67">Which printers to route 
 the documents to. How many pieces of documentation to print at each of 
 these printers.</li>
        </ul>
