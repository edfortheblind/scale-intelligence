
        
        <h1 data-source-node="n56"><a name="kanchor1634" data-source-node="n57"></a>Use As Default Checkbox</h1>
        <p data-source-node="n58">This field indicates if the system will use this container type as the 
 default when automatically creating a container during scan and weigh 
 processing. Note that if any container type record has this checkbox selected, then the system 
 will inactivate the Use As Default Checkbox for all other records, including 
 new records. If you want to designate a different container type as the 
 default, you must first deselect the checkbox from the old default container 
 type.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61">If this checkbox is selected on 
 any record, the system will use this container type as the default 
 type on any batch container requests. The system will automatically create 
 a container using this container type.</p>
                <p data-source-node="n62"> </p>
            </li>
            <li data-source-node="n63">If this checkbox 
 is not selected on any record, the system will automatically create 
 a container using the value "DEFAULT."</li>
        </ul>
