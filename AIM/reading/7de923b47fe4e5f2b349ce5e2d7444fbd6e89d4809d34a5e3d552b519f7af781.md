
        
        <h1 data-source-node="n56"><a name="kanchor1387" data-source-node="n57"></a>Container Shape Field</h1>
        <p data-source-node="n58">This field indicates the type of physical shape of a shipping container. 
 Container shape values are used by the system during the container creation 
 in a wave process to determine if a certain container type can be downsized 
 into. Only container types with the same 
 container shape (as the originally assigned container type) can 
 be downsized into.</p>
