
        
        <h1 data-source-node="n56"><a name="kanchor2045" data-source-node="n57"></a>Creating Labor Groups</h1>
        <p data-source-node="n58">This window allows you to define the types of labor being performed within your warehouse. These records in SCALE define such information as full time and temporary employees, as well as, what quantity unit(s) of measure they typically pick based upon a time factor. The system uses these records when processing labor plans during a wave. It uses the information to help calculate the estimated time it takes the workers, from a certain labor group, to pick their work or shipments. Labor planning and monitoring is established using labor groups. Labor planning can be defined at both the shipment and work levels. Labor monitoring occurs only at the work level. Only one labor group needs to be setup for shipment based planning, work based planning and work based monitoring, depending on your needs. To avoid multiple labor plan records from being written for one work unit, SCALE will not allow a work type to be assigned to multiple labor groups. If a labor group is assigned to a work type (using the Work Type configuration) and then the work type is later assigned to a different labor group, the system will update the records automatically.</p>

        <h4 data-source-node="n112">Procedures...</h4>
        <p class="p_15" style="font-weight: normal;color: #000000" data-source-node="n113">Access the Labor Group Window. Create a new record.</p>
        <ol data-source-node="n114">
            <li style="font-weight: normal;color: #000000" value="1" data-source-node="n115">Use the Labor Group Field          to provide a name for your labor group record. <br data-source-node="n116"><br data-source-node="n117"></li>
            <li style="font-weight: normal;color: #000000" value="2" data-source-node="n118">Use the Description Field to enter a description of the labor group.<br data-source-node="n119"></li>
        </ol>
        <p style="font-weight: normal;color: #000000" data-source-node="n120"> </p>
        <h5 data-source-node="n121">Using the Resources Tab</h5>
        <p data-source-node="n122">Use this tab's information to calculate how much manpower is available to process a particular group of work or shipment details. The system uses this information to calculate how much manpower is available to process a particular group of work or shipment details.</p>
        <ol data-source-node="n123">
            <li value="1" data-source-node="n124">Use the Number of Full Time Employees Field to indicate the total number of full time employees that will work on this labor group's shipments.<br data-source-node="n125"><br data-source-node="n126"></li>
            <li value="2" data-source-node="n127">Use the Hours Per Full Time Employee Field to indicate the total hours a full time employee works per day (excluding such non-work activities as break time).<br data-source-node="n128"><br data-source-node="n129"></li>
            <li value="3" data-source-node="n130">Use the Number of Temporary Employees Field to indicate the total number of temporary (part time) employees that will work on this labor group's shipments.<br data-source-node="n131"><br data-source-node="n132"></li>
            <li value="4" data-source-node="n133">Use the Hours Per Temporary Employee Field to indicate the total hours a temporary employee works per day (excluding such non-work activities as break time).<br data-source-node="n134"><br data-source-node="n135"></li>
            <li value="5" data-source-node="n136">Press OK. The system will save your record.</li>
        </ol>
        <p data-source-node="n137"> </p>
        <h5 data-source-node="n138">Using the Estimation Tab</h5>
        <p data-source-node="n139">The system uses the fields on this tab to determine how much product can be processed by the employees defined on the Resources tab.</p>
        <ol data-source-node="n140">
            <li value="1" data-source-node="n141">Use the Estimated Time Per Transaction (In Minutes) Field to define how long it will take an employee to process the amount of products you are defining on this tab.<br data-source-node="n142"><br data-source-node="n143"></li>
            <li value="2" data-source-node="n144">Use the Calculate Time Based On Field to identify how the system will calculate labor time:<br data-source-node="n145"><br data-source-node="n146">- Unit of Measure: The system will calculate the estimated time data based on the UM that the worker will be picking. It assumes that it takes the same amount of time to process 1 instance of this unit of measure as it does 30 instances.For an example of this calculation, see the "Scenarios" section of the <a href="7dd4c71c4fffda7e9ee1126c5142b92f5d6ebf82faf4a4f204c59dfe5f1bfd65.html" data-source-node="n147">Labor Management Process Summary</a> topic.<br data-source-node="n148"><br data-source-node="n149">- Quantity: The system will calculate the estimated time based on the quantity of the unit of measure that the worker will be picking. It assumes that it takes less items to process 1 instance of this unit of measure than it does 30 instances. For an example of this calculation, see the "Scenarios" section of the <a href="7dd4c71c4fffda7e9ee1126c5142b92f5d6ebf82faf4a4f204c59dfe5f1bfd65.html" data-source-node="n150">Labor Management Process Summary</a> topic.<br data-source-node="n151"><br data-source-node="n152"></li>
            <li value="3" data-source-node="n153">Use the Quantity Units of Measure Field to select the units of measure that are processed under this labor group. For example, if a worker in this group typically picks only cases, you can indicate that here. Also, note that you do not have to specify any units of measure. If none are selected, then all units of measure can be processed. If you set this to more than one unit of measure, the system doesn't sum across the units of measure when applying the time value. For example, if you have the time set to 5 minutes and CS and EA values selected here, it just means it takes 5 minutes to process the CS and 5 minutes to process the EA. It doesn't mean it takes 5 minutes to process CS and EA at the same time.<br data-source-node="n154"></li>
        </ol>
        <p style="font-style: italic" data-source-node="n155">Example of how fields work...</p>
        <p data-source-node="n156"> </p>
        <p data-source-node="n157">Suppose you set the 'Calculate Time Based On' Field' to 'UM' and the 'Estimated Time Per Transaction' Field to '5'. The 'Units of Measure' Field is set to 'CS'. When the user processes a request for 10 CS, the system will assume it will take 5 minutes to process these 5 cases. If the user processed 90 Cases, the system assumes it takes 5 minutes.</p>
        <p data-source-node="n158"> </p>
        <p data-source-node="n159">Now suppose you have the same setup, but switched the 'Calculate Time Based On' Field to 'Quantity'. When the user processes a request for 10 CS, the system thinks it will take 50 minutes to process the request; if the request is for 3 CS, the system assumes it will take 15 minutes.</p>

        <h5 data-source-node="n162">Planning &amp; Monitoring Tab</h5>
        <p data-source-node="n163">This tab allows you to define the labor group planning at both the shipment and work levels. The labor group monitoring is defined by work type.</p>
        <ol data-source-node="n164">
            <li value="1" data-source-node="n165">Use the Shipment Labor Planning Criteria Field to assign a criteria record to your labor group. This criteria includes rules that the system uses to determine what work or shipment(s) a labor group will pick. The system references this before a wave is run to calculate how long it will take to process the shipment details. If work creation fails to run, SCALE will revert back to this method of estimating work. This is just a planning tool, the system doesn't provide monitoring capabilities for shipment details.<br data-source-node="n166"><br data-source-node="n167"></li>
            <li value="2" data-source-node="n168">Use the Planning and Monitoring from Work Field to select which work type(s), or select all work types, that will be monitored for this labor group. This method allows the system to plan work activities and then monitor your progress. The system performs monitoring by checking to see if any work has been created and completed.</li>
        </ol>
