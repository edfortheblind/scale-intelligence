
        
        <h1 data-source-node="n56"><a name="kanchor1278" data-source-node="n57"></a>Parent Record Field</h1>
        <p data-source-node="n58">This field identifies the container that another 
 container is nested into. On the Receipt Workbench, containers 
 can be nested into other containers. The license plate ID number of the container 
 nested into is the parent record for the container being nested. This 
 allows the system to track the movement of checked in product on the workbench.</p>
