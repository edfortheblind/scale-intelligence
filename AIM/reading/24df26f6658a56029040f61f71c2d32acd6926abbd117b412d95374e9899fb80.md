
        
        <h1 data-source-node="n56"><a name="kanchor747" data-source-node="n57"></a>Web Marquee Field</h1>
        <p data-source-node="n58">This field indicates the text message that 
 will appear on the logon page of the Trading Partner Management website. 
 This is especially helpful if you want to add a text message advertising 
 specials or new products. You can define this value on the Web System Values Window.</p>
