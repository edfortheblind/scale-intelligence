
        
        <h1 data-source-node="n56"><a name="kanchor1226" data-source-node="n57"></a>Serial Number Field</h1>
        <p class="p_1" data-source-node="n58">The unique identifier for one item unit. You can require serial number validation per 
 item on the Item Window.</p>
        <p class="p_1" data-source-node="n59"> </p>
        <h5 data-source-node="n60">On the Inventory Details Screen...</h5>
        <p data-source-node="n61">The serial number grid under the accordion can look different depending on whether the serial number tracked item has serial number template.  In the absence of a template, the column header will be serial number.  The column header is the description of the major (also known as master serial numbers) and minor serial numbers when there is a template.</p>
        <p data-source-node="n62"> </p>
        <p class="p_1" data-source-node="n63"> </p>
        <h5 data-source-node="n64">On 
 the Receipt Container Screen...</h5>
        <p class="p_1" data-source-node="n65">The system displays all the serial number(s) 
 associated with this receipt container's items.</p>
        <p class="p_1" data-source-node="n66"> </p>
        <p class="p_1" data-source-node="n67"> </p>
        <h5 data-source-node="n68">On the Receipt Container Details Screen...</h5>
        <p class="p_1" data-source-node="n69">The serial number grid under the accordion can look different depending on whether the serial number tracked item has serial number template. The system displays major and minor serial number(s) in a grid when item is associated with a serial number template. The system displays only the serial number(s) in a grid when the item is not associated with a serial number template. Only after the check in of a serial number item in receipt container, the grid will be visible. Otherwise, the grid will be blank.</p>
        <p class="p_1" data-source-node="n70"> </p>
        <p class="p_1" data-source-node="n71"> </p>
        <h5 data-source-node="n72">On 
 the Shipping Container Screen...</h5>
        <p class="p_1" data-source-node="n73">The system displays all the serial number(s) 
 associated with this shipping container's items.</p>
        <p class="p_1" data-source-node="n74"> </p>
        <p class="p_1" data-source-node="n75"> </p>
        <h5 data-source-node="n76">On the Transaction History Details Screen...</h5>
        <p class="p_1" data-source-node="n77">The system displays all the serial number(s) 
 associated with this transaction history record. </p>
