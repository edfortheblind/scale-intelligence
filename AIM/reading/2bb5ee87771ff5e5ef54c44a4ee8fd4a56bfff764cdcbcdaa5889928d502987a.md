
        
        <h1 data-source-node="n56"><a name="kanchor53" data-source-node="n57"></a>String Length Type Field</h1>
        <p data-source-node="n58">This field indicates how the application will expect GS1 data to enter the system 
 when scanned:</p>
        <blockquote data-source-node="n59">
            <p data-source-node="n60"><i data-source-node="n61">Fixed Length</i>: 
 The data value has to be of a certain size, or the system will return 
 an error when the AI is scanned. For example, if your quantity is set 
 at a length of three characters, then every value for this AI must be 
 three digits (such as 002, 012, 124). </p>
            <p data-source-node="n62"> </p>
            <p data-source-node="n63"><i data-source-node="n64">Variable Length</i>: 
 The data value can be of any size. </p>
        </blockquote>
