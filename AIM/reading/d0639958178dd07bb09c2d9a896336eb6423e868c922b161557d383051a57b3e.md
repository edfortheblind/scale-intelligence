
        
        <h1 data-source-node="n56"><a name="kanchor1908" data-source-node="n57"></a>Position Range Field</h1>
        <p data-source-node="n58">This field is used to create a single position or a range of positions 
 for a consolidation or yard location. You need to have at least one position for every 
 location you create. </p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">If you want to create ONE 
 position, enter the position ID in both parts of this field.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">If you want to create a RANGE 
 of positions, enter the first position ID of the range in first field, 
 and the last position ID of the range in the second field.<br data-source-node="n64"></li>
        </ul>
