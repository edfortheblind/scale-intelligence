        <h4 data-source-node="n76"><a name="Process" data-source-node="n77"></a>Process Flow</h4>
        <p data-source-node="n78"> </p>
        <p data-source-node="n79">
            <br data-source-node="n80">
            <img src="../source/assets/db3b85bd4f598c47ec513216fbb3b4911b0093bfbb82e48523c3657021e9d288.png" style="width: 998;height: 944" loading="eager" data-source-node="n81">
        </p>
        <p data-source-node="n82"> </p>
        <ol data-source-node="n83">
            <li value="1" data-source-node="n84">Access the Single Unit Packing 
 Screen. 
 <br data-source-node="n85"></li>
            <p data-source-node="n86"> </p>
            <li value="2" data-source-node="n87">Identify the Tote for which single packing need to be performed.<br data-source-node="n88"></li>
            <p data-source-node="n89"> </p>
            <li value="3" data-source-node="n90">Enter/Scan the Tote ID click the initiation (arrow) button. <br data-source-node="n91"> </li>
            <li value="4" data-source-node="n92">Enter/Scan the Item ID or Item cross reference value. If company is configured, then the system will display or prompt user to choose the Company from the drop-down.<br data-source-node="n93"> </li>
            <li value="5" data-source-node="n94"> Lot Controlled items - When Lot controlled Items are scanned, the system will display the Lot information and then user can select the container type as required.<br data-source-node="n95"><br data-source-node="n96"></li>
            <li value="6" data-source-node="n97">Serial number items - When serial number Items are scanned, the system will display the serial number drop-down list. User can choose the serial number if there are multiple configured for the item.</li>
            <li value="7" data-source-node="n98">Use the Container Type Field 
 to identify the type of container you are packing into.  The container types available for packing can be authorized by company and warehouse. See the <a href="b8520236e77bf1d9729a56d56a398123183351403f9a3eff7e86595795483b9e.html" data-source-node="n99">Defining Container Types</a> for more details.<br data-source-node="n100"><br data-source-node="n101"></li>
            <li value="8" data-source-node="n102">
                <p data-source-node="n103">Select the <b data-source-node="n104">Confirm</b> Button. 
 The system will pack the tote item into the container. The success message will be based if the item in Tote is packed or all items in the tote is packed.<br data-source-node="n105"></p>
            </li>
        </ol>
