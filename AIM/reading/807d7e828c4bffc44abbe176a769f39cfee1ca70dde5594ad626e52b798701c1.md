
        
        <h1 data-source-node="n57"><a name="kanchor223" data-source-node="n58"></a>Data Selection Field</h1>
        <h5 data-source-node="n59">Paperwork/Wave...</h5>
        <p data-source-node="n60">This field links a sequence on the document master to the appropriate 
 data selection record. The data selection record determines which document 
 type should be applied to a group of records in a wave. It also sorts 
 the order that the paperwork is generated.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">There are four types of data selection records. Each data selection 
 type applies to a specific type of record generated during the wave. Below 
 is a list of the data selection types and the types of records that they 
 can be applied to:</p>
        <ul data-source-node="n63">
            <li data-source-node="n64">
                <p data-source-node="n65">Container data selection 
 - This record is applied to container records generated in a wave. It 
 is used to generate shipping labels and container packing lists.</p>
                <p data-source-node="n66"> </p>
            </li>
            <li data-source-node="n67">
                <p data-source-node="n68">Load data selection - This 
 record is applied to shipping load records generated in a wave. It is 
 used to generate truckload manifests.</p>
                <p data-source-node="n69"> </p>
            </li>
            <li data-source-node="n70">
                <p data-source-node="n71">Shipment data selection - 
 This record is applied to shipment records generated in a wave. It is 
 used to generate pick lists, packing lists, and bills of lading.</p>
                <p data-source-node="n72"> </p>
            </li>
            <li data-source-node="n73">Work data selection 
 - This record is applied to work instruction records generated in a wave. 
 It is used to generate pick lists.</li>
        </ul>
