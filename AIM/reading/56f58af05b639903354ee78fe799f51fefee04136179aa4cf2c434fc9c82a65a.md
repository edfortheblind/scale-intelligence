
        
        <h1 data-source-node="n56"><a name="kanchor959" data-source-node="n57"></a>Using the Shipping Container Insight Screen</h1>
        <p data-source-node="n58">You can use the Shipping Container Insight Screen to search and manage shipping containers in your warehouse. All shipping containers in the system will be opened or displayed when there is no filter criteria. The screen allows you to view multiple levels of a shipping container from the topmost to the lowest level. The top-level containers (container without a parent container) will be displayed on navigating from the Containers indicator tile on the Shipment Insight screen.  The "Show Only Top Level" toggle will be turned on.  The Containers indicator tile on the Shipping Containers Insight screen will navigate to the next level of the shipping container. The Container Contents indicator tile will navigate to the container contents for the selected container.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The  title and navigation trail on the Shipping Container Insight screen will reflect the level of the container that is  being viewed.  The title for a top-level container will not display a level.  </p>
        <ul data-source-node="n61">
            <li data-source-node="n62">Level 1 is the first level of containers below the top-level container.  This is displayed as Shipping Container Insight (1).  </li>
            <li data-source-node="n63">Level 2, level 3, and so on can be viewed by tapping on the Containers indicator tile from the current Shipping Container Insight screen.</li>
            <li data-source-node="n64">  A Containers and Container Contents indicator tile with a 0 count indicates the lowest level has been reached.</li>
        </ul>

        <h4 data-source-node="n249"><a name="Searching" data-source-node="n250"></a>Searching/Viewing Shipping Container Records...</h4>
        <p data-source-node="n251">You can use the Shipping Container Insight Screen to search for and view shipping containers in your warehouse on a tablet device. </p>
        <ol data-source-node="n252">
            <li value="1" data-source-node="n253">Open the Shipping Container Insight Screen.<br data-source-node="n254"><br data-source-node="n255"></li>
            <li value="2" data-source-node="n256">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<p data-source-node="n257"><br data-source-node="n258"> When a user selects a manifest record on Manifest Insight and clicks the View Container action, system redirects to Shipping Container Insight and narrow down containers based on populated manifest criteria in the Manifest Criteria Fields (located on the Filter Pane):<br data-source-node="n259"><br data-source-node="n260">- Manifest Name, Manifest Status, Rating ID, Shipper Code, and Tracking Number. <br data-source-node="n261"><br data-source-node="n262"></p></li>
            <li value="3" data-source-node="n263">Press the Apply Filter button. The system will display all information regarding the resulting records in the List Pane. <br data-source-node="n264"><br data-source-node="n265"></li>
        </ol>
        <p data-source-node="n266">NOTE: </p>
        <ul data-source-node="n267">
            <li data-source-node="n268">Clicking the Container ID link in the results grid opens the Shipping container screen for the selected container. Clicking on the Shipment ID link in the results grid opens the Shipment screen for the internal shipment number associated with the grid line selected.<br data-source-node="n269"><br data-source-node="n270"></li>
            <li data-source-node="n271">System will return search results only when all the three fields under Manifest Criteria namely Manifest Name, Rating ID, and Shipper Code are specified. <br data-source-node="n272"><br data-source-node="n273"></li>
            <li data-source-node="n274">The “Show only top level” toggle is turned on by default when navigating from the Containers tile on the Shipment Insight screen to the Shipping Container Insight screen and only the top-level containers will be displayed on the Shipping Container Insight screen. Clicking the Containers indicator tile on the Shipping Containers Insight screen will navigate to the subsequent level of the shipping container.<br data-source-node="n275"><br data-source-node="n276"></li>
            <li data-source-node="n277">The level of the  shipping container is displayed on the Shipping Container Insight screen’s title.  Level 1 is the first level of containers below the topmost container. <br data-source-node="n278"><br data-source-node="n279"></li>
            <li data-source-node="n280">Subsequent levels (Level 2, level 3, and so on) can be viewed by clicking the Containers indicator tile from the current Shipping Container Insight screen.  A Containers indicator tile displaying a 0 count indicates the lowest level has been reached.<br data-source-node="n281"><br data-source-node="n282"></li>
            <li data-source-node="n283">Pressing the Container Contents indicator tile will display the item contents for the selected shipping container.<br data-source-node="n284"><br data-source-node="n285"></li>
            <li data-source-node="n286">The Navigation History will display all the Shipping Container Insight screens that were previously visited. The filter criteria of all the  previously visited Shipping Container Insight screens will also be retained.<br data-source-node="n287"><br data-source-node="n288"></li>
            <li data-source-node="n289">
                <p data-source-node="n290">You can turn off the "Show Only Top Level" toggle when you want to search for more than the top level containers.</p>
            </li>
        </ul>

        <h4 data-source-node="n344"><a name="Screen" data-source-node="n345"></a>Screen Actions...</h4>
        <p data-source-node="n346">The following actions are accessible from the list pane of Shipping Container Insight screen:</p>
        <p data-source-node="n347"> </p>
        <p data-source-node="n348"> </p>
        <h5 data-source-node="n349">View/Edit </h5>
        <p data-source-node="n350">View action helps you to open the Shipping Container Details Screen in read-only mode. Edit action, on the other hand, helps you to open the same screen in the Edit mode.</p>
        <p data-source-node="n351"> </p>
        <p data-source-node="n352"> </p>
        <h5 data-source-node="n353">Delete </h5>
        <p data-source-node="n354">This action enables you to delete the shipping container from a shipment when no active work is associated with the container and it is at a packing dock location. Also, the container's status needs to be greater than or equal to Picking Pending and less than Load Confirm Pending. A confirmation message will appear when a parent container gets deleted or when the users try to delete a container on a shipment tied to an order. If there are nested containers associated with the parent container, they would also get deleted. For more information on deleting shipping containers, see the <a href="b8cac7af3607a14a426e1d6a3d5e77e50dacdb7dc06933dc6737652d5d59d465.html" data-source-node="n355">Shipment Processing</a> topic.</p>
        <p data-source-node="n356"> </p>
        <p data-source-node="n357"> </p>
        <h5 data-source-node="n358">View/Edit Accessorials</h5>
        <p data-source-node="n359">This action enables you to ship an order with the appropriate accessorials. Selecting a Shipping Container ID and clicking on this opens the Accessorial Assignment screen. Refer to the topic <a href="20ae483e95cd8c4155eef53cafcca4eaa8681885f39691a08a794a733dcc116a.html" data-source-node="n360">Assigning Accessorials</a> for additional information. </p>
        <p data-source-node="n361"> </p>
        <p data-source-node="n362"> </p>
        <h5 data-source-node="n363">Close</h5>
        <p data-source-node="n364">This action allows you to close a specific shipping container. This action is enabled when there is a container highlighted in the List Pane and the container status is less than or equal to "In Packing".</p>
        <p data-source-node="n365"> </p>
        <p data-source-node="n366"> </p>
        <h5 data-source-node="n367">Confirm QC</h5>
        <p data-source-node="n368">This action allows you to confirming the QC for shipping containers with either pending and failed QC status.  Selecting the action will open the <a href="c50fb44b95eba1ce592e78f136693443608d558c2299ade354a5b287a31a8e11.html" data-source-node="n369">QC workbench</a> screen. </p>
        <p data-source-node="n370"> </p>
        <p data-source-node="n371"> </p>
        <h5 data-source-node="n372">Dock Transfer</h5>
        <p data-source-node="n373">This action allows you to transfer container to a dock location from the List Pane of Shipping Container Insight. This option is disabled when the container status is greater than or equal to Load Confirm Pending. </p>
        <p data-source-node="n374"> </p>
        <p data-source-node="n375"> </p>
        <h5 data-source-node="n376">Manifest</h5>
        <p data-source-node="n377">This action allows you to manifest a shipping container, so that the container is added to a container manifest and assigned a tracking number. You can manifest a container successfully when its status is one of the following: In Pool, Picking Pending, In Picking, In Packing, Ship Confirm Pending, Staging Pending, and Loading Pending. This option is enabled when the container has not been manifested and the container is selected in the List Pane. </p>
        <p data-source-node="n378"> </p>
        <p data-source-node="n379"> </p>
        <h5 data-source-node="n380">Mark for QC</h5>
        <p data-source-node="n381">This action enables you to mark multiple shipping containers for quality audit from the List Pane of Shipping Container Insight. </p>
        <p data-source-node="n382"> </p>
        <p data-source-node="n383"> </p>
        <h5 data-source-node="n384">Nest</h5>
        <p data-source-node="n385">If you select multiple containers that are eligible for nesting and click on this action Nest, Shipping Container Nesting screen will open. This action will be enabled for any containers with status less than load confirm pending and greater than or equal to packing pending. Nesting the selected containers onto one of an existing containers of the same shipment will nest all the selected containers on to the 'to container'. The system will display a confirmation massage upon successful nesting. For more information on this topic, refer to <a href="7b4a6ef1c835af34ee3893ec7445fc39b81925227dcfef1fff39adfb2392e9e9.html" data-source-node="n386">Nesting a Container</a>.</p>
        <p data-source-node="n387"> </p>
        <p data-source-node="n388"> </p>
        <h5 data-source-node="n389">Print Preview</h5>
        <p data-source-node="n390">This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n391">Printing Paperwork</a>. </p>
        <p data-source-node="n392"> </p>
        <p data-source-node="n393"> </p>
        <h5 data-source-node="n394">Print Default Docs</h5>
        <p data-source-node="n395">This action allows you to print the default shipping container documents that have both the print procedure for "shipping container" setting and the default setting selected on the document’s Document Type record. </p>
        <p data-source-node="n396"> </p>
        <p data-source-node="n397"> </p>
        <h5 data-source-node="n398">Print Selected Docs</h5>
        <p data-source-node="n399">This action allows you to print all the selected container level documents. For more information on printing topic, see the <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n400">Printing Paperwork</a> topic. </p>
        <p data-source-node="n401"> </p>
        <p data-source-node="n402"> </p>
        <h5 data-source-node="n403">Remove from Manifest</h5>
        <p data-source-node="n404">This action allows you to remove a shipping container from a manifest in order to facilitate additional proceedings. However, you cannot remove container from a manifest if the container has not been manifested at the first place and when its status is:</p>
        <ul data-source-node="n405">
            <li data-source-node="n406"> Greater than Wave Pending and less than Picking Pending.<br data-source-node="n407"><br data-source-node="n408"></li>
            <li data-source-node="n409">
                <p data-source-node="n410">Greater than or equal to Load Confirm Pending.</p>
            </li>
        </ul>
        <p data-source-node="n411"> </p>
        <h5 data-source-node="n412">Remove from Nesting</h5>
        <p data-source-node="n413">This action allows you to remove container from nesting. It is enabled only for the containers which are nested. You can select only single container and invoke the Remove from Nesting action. A confirmation message with Yes/No buttons will pop up:</p>
        <ul data-source-node="n414">
            <li data-source-node="n415">If you click on Yes, Nest Container Screen will open defaulting from container as the selected container.<br data-source-node="n416"><br data-source-node="n417"><ul data-source-node="n418"><li data-source-node="n419"><p data-source-node="n420">Entering/Selecting the To container and tapping on 'Nest' will show the success message indicating that the nesting is successful. </p></li><li data-source-node="n421"><p data-source-node="n422">Entering/Selecting the To container and tapping on 'Combine' will show the success message indicating that the Combine is successful.</p></li><li data-source-node="n423">If there is a failure to nest/combine, an error message is shown and the container is not removed from nesting.<br data-source-node="n424"></li><br data-source-node="n425"></ul></li>
            <li data-source-node="n426">If you click on No, the container will be removed from nesting without opening the nesting screen. The system will show a confirmation message indicating that the container is removed from nesting. Note that Removing the last container from a parent container will delete the parent container.</li>
        </ul>
        <p data-source-node="n427"> </p>
        <p data-source-node="n428"> </p>
        <h5 data-source-node="n429">Transfer </h5>
        <p data-source-node="n430">This action allows you to transfer a container to a different shipment.  When this action is selected, the system will open the Transfer Container screen. When the container’s status is less than Load Confirm Pending, this section is available on the List Pane.</p>
        <p data-source-node="n431"> </p>
        <p data-source-node="n432"> </p>
        <h5 data-source-node="n433">Update Packed Quantity </h5>
        <p data-source-node="n434">This action allows you to decrease (unpack) the quantity of the selected item in the shipping container.  A window will appear showing the existing quantity of the item in the container.  To lower the quantity, specify the quantity that is still in the container.  The system will unpack the difference and will write transaction history for the quantity unpacked.  If the item is serial number tracked or catch weight tracked, the system will prompt the user for the serial numbers or catch weights being removed.  This action is only available on individual items within a loose packed container.  It is not available on parent container records or "full" container records.</p>
