
        
        <h1 data-source-node="n56"><a name="kanchor1271" data-source-node="n57"></a>FNC1 Separator Field</h1>
        <p data-source-node="n58">This field indicates what character you want the system 
 to use to divide segments on a barcode. This separator can be any alphanumeric, 
 ASCII, or non-printable character, and is required. <br data-source-node="n59"><br data-source-node="n60">- The default/standard GS1 separator 
 is ASCII value 29 (a non-printable character). 
 This should be sufficient for most situations. <br data-source-node="n61"><br data-source-node="n62">- Note that if you define 
 a printable character as a separator, then it will appear in the human 
 readable portion of the barcode/label.<br data-source-node="n63"><br data-source-node="n64">- 
The FNC1 separator is only placed at the end of a variable length AI when it is not the last AI in the barcode.</p>
