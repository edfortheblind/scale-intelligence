
        
        <h1 data-source-node="n56"><a name="kanchor1322" data-source-node="n57"></a>Replenishment Pick List</h1>
        <p data-source-node="n58">A replenishment pick list contains every request for a particular replenishment 
 master. This document is used to support executing replenishment transactions 
 when work creation is not used. This pick list identifies the from and 
 to location of the item to be replenished, the item's number and description, 
 and its quantity and base quantity.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61">When running replenishment from 
 the wave, this document should be placed in the paperwork wave 
 step. The system will then automatically print a replenishment pick list 
 when it runs this wave step. The system will generate a pick list for 
 each replenishment master.</p>
                <p data-source-node="n62"> </p>
            </li>
            <li data-source-node="n63">In the Inventory Insight screen, the system will generate this document 
 when you manually run a replenishment master. </li>
        </ul>
