
        
        <h1 data-source-node="n56"><a name="kanchor1232" data-source-node="n57"></a>Total Containers Field</h1>
        <p class="p_1" data-source-node="n58">The number of containers associated with a 
 receipt, shipment or shipping load. Note that this value also includes nested containers. So, if you have a pallet with 
 two nested containers, the system will count this as three containers.</p>
        <p class="p_1" data-source-node="n59"> </p>
        <p class="p_1" data-source-node="n60"> </p>
        <h5 data-source-node="n61">On the Shipment Insight Screen...</h5>
        <p data-source-node="n62">This field indicates the number of shipping containers that are included in the results of a query performed on this insight screen.</p>
