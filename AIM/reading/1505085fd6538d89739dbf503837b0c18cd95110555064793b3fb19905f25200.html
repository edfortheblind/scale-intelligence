Trigger Type Field

This field to indicate how a Billing Management trigger will be activated.

  • When In-Line is selected, the trigger will activate automatically when an event (such as closing a shipping load) occurs in the system. In-line triggers include events that are embedded in the system functional flow, such as Packing or Receiving. To use this type of trigger, you first have to activate it, and then when a particular event happens, the system will send the data resulting from the trigger to Billing Management. No further user intervention is required.
     
  • When Manual is selected, the user will have to manually activate a trigger via the Billing Management Manual Generation Window. Manual triggers include any events that are unrelated to a functional event, such as the storage snapshot trigger. To use this type of trigger, you would access the Billing Management Manual Generation Window and select the appropriate trigger. The system will then send the data resulting from the trigger to Billing Management.
