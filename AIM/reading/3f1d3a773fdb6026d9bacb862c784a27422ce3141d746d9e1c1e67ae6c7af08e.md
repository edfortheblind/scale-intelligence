
        
        <h1 data-source-node="n56"><a name="kanchor1769" data-source-node="n57"></a>Base Text Field</h1>
        <p class="p_1" data-source-node="n58">This field appears as a column header on the 
 System Text Editor Window after you perform a search. It identifies a 
 default value provided with the system and linked to the Key. You cannot 
 change this value; however, you can associate a custom text value with 
 the Key which overrides the base text.</p>
