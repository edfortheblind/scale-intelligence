
        
        <h1 data-source-node="n56">Defining a Carrier's Default Consolidation Location Area</h1>
        <p data-source-node="n57">When you perform a consolidation action, the system will check to see if the shipment's carrier has a 
 default consolidation location area associated with it. If it does, the system will 
 use this default when you consolidate a container/detail. Note 
 that you always have the option to manually change which dock location 
 you want to use. You can configure this on the Carrier Window. See the Dock Tab section of the topic <a href="f904520921e6864d43d2f1a4a865e942ac952c81b24bb62303e4918dbd62e720.html" data-source-node="n58">Defining 
 A Carrier Record</a> for information on these procedures.</p>
