
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Carrier Type</h1>
        <p data-source-node="n58">A carrier type groups together carriers that share the same basic rate structure. You can review the system created carrier types on the Carrier Type configuration.</p>
        <p data-source-node="n59"> </p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62"><b data-source-node="n63">LTL Terms on BOL?</b> Field to determine which VICS legal statement will be printed on a bill of lading. </p>
                <ul data-source-node="n64">
                    <li data-source-node="n65">
                        <p data-source-node="n66">- If Yes, the system will print the LTL legal statement on all bills of lading produced for this carrier type.</p>
                    </li>
                    <li data-source-node="n67">
                        <p data-source-node="n68">- If No, the system will print the TL legal statement on all bills of lading produced for this carrier type.</p>
                    </li>
                </ul>
            </li>
        </ul>
        <ul data-source-node="n69">
            <li data-source-node="n70">
                <p data-source-node="n71"><b data-source-node="n72">One Pro Number Per Load</b>? Field to indicate if you want the system to assign one pro number to represent all the shipments per shipping load. This would commonly be used for loads that use the master BOL paperwork document.</p>
            </li>
        </ul>
