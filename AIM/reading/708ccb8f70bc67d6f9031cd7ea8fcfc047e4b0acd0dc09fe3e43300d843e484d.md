
        
        <h1 data-source-node="n56"><a name="kanchor1254" data-source-node="n57"></a>Transfer Failed Shipments During Load Confirmation Checkbox</h1>
        <p class="p_1" data-source-node="n58">If 
 this checkbox is selected, any unconfirmed shipment on a load will 
 be transferred if it fails confirmation during the load confirmation process. 
 The system will then transfer this shipment to a new load, so the original 
 load can be confirmed. If this checkbox 
 is not selected, when one shipment fails confirmation (for any 
 reason), then the entire load will fail confirmation.</p>
