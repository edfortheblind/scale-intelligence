Work Initiation Method Field

This field indicates how work instructions will be generated on an RF device. Work instructions are initiated by either the user or the system.

 

User

 

The user will initiate all work. On an RF device, the employee will scan/input the barcode that he/she wants to process.

 

System

 

The system will initiate all work. On an RF device, the employee will scan/input the nearest location barcode. The system will reference the From Assignment Method to determine which work unit should be assigned to the user, based on proximity.

 

System-directed work also allows you to assign multiple work units.

 

Group User

 

The user will initiate all work. On an RF device, there are two potential work flows:

  • You could have several workers picking part of one work unit into the same container (a transport container or an actual shipping container)

    OR
     
  • You could have one worker picking a group of work units along with their corresponding container.
