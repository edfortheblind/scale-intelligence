
        
        <h1 data-source-node="n57">Carrier Group Button</h1>
        <p class="p_1" data-source-node="n58">This button indicates if a routing guide record 
 is associated with a carrier group.</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">If 
 this button contains a value, a carrier group is associated with 
 the routing guide record. When this routing guide is used, the system 
 will select one of the group's carriers to transport the shipment.<a name="kanchor603" data-source-node="n61"></a><br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64">If 
 this button does not contain a value, a carrier/service is associated 
 with the routing guide record.</li>
        </ul>
