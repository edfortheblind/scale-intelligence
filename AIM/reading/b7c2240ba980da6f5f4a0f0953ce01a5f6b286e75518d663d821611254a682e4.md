
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">Functional Area Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Functional Area configuration defines the status flow records used by each functional area in SCALE, such as Receiving, Shipping, and Work Order processing. You can review and maintain the status values and their flow properties for each functional area.</p>
        <h4 data-source-node="n61"> </h4>
        <h4 data-source-node="n62">Configure Functional Area</h4>
        <p data-source-node="n63"> </p>
        <h5 data-source-node="n64">1. Functional Area</h5>
        <p data-source-node="n65"> </p>
        <p data-source-node="n66">The Review Functional Areas screen displays the available functional areas. Select a functional area to review and maintain its status flow records.</p>
        <ul data-source-node="n67">
            <li data-source-node="n68">
                <p data-source-node="n69"><b data-source-node="n70">Functional Area</b>: The identifier for the functional area.</p>
            </li>
            <li data-source-node="n71">
                <p data-source-node="n72"><b data-source-node="n73">Description</b>: The description of the functional area.</p>
            </li>
        </ul>
        <p data-source-node="n74"> </p>
        <h5 data-source-node="n75">2. Status Flow</h5>
        <p data-source-node="n76"> </p>
        <p data-source-node="n77">The Status Flow screen displays the status records defined for the selected functional area.</p>
        <ul data-source-node="n78">
            <li data-source-node="n79">
                <p data-source-node="n80"><b data-source-node="n81">Functional Area</b>: Displays the selected functional area identifier (read-only).</p>
            </li>
            <li data-source-node="n82">
                <p data-source-node="n83"><b data-source-node="n84">Status</b>: The numeric status value.</p>
            </li>
            <li data-source-node="n85">
                <p data-source-node="n86"><b data-source-node="n87">Status Name</b>: The descriptive name for the status.</p>
            </li>
            <li data-source-node="n88">
                <p data-source-node="n89"><b data-source-node="n90">Related Status</b>: The numeric status that this status relates to in the flow.</p>
            </li>
            <li data-source-node="n91">
                <p data-source-node="n92"><b data-source-node="n93">Mandatory</b>: Indicates whether this status is required in the flow and cannot be skipped.</p>
            </li>
            <li data-source-node="n94">
                <p data-source-node="n95"><b data-source-node="n96">In Default Flow</b>: Indicates whether this status is included in the default processing flow.</p>
            </li>
            <li data-source-node="n97">
                <p data-source-node="n98"><b data-source-node="n99">Include In Interface Upload</b>: Indicates whether this status triggers an interface upload record.</p>
            </li>
            <li data-source-node="n100">
                <p data-source-node="n101"><b data-source-node="n102">Add New Status</b>: Create a new status record for this functional area.</p>
            </li>
            <li data-source-node="n103">
                <p data-source-node="n104"><b data-source-node="n105">Edit/Delete</b>: Update or remove the selected status record. Delete and edit are disabled for system-created records or records where changes are not allowed.</p>
            </li>
        </ul>
        <p data-source-node="n106"> </p>
        <h5 data-source-node="n107">A. Status Information</h5>
        <p data-source-node="n108"> </p>
        <p data-source-node="n109">Define the properties for a functional area status record.</p>
        <ul data-source-node="n110">
            <li data-source-node="n111">
                <p data-source-node="n112"><b data-source-node="n113">Functional Area</b>: Displays the functional area this status belongs to (read-only).</p>
            </li>
            <li data-source-node="n114">
                <p data-source-node="n115"><b data-source-node="n116">Status Name</b>: Enter the descriptive name for this status value.</p>
            </li>
            <li data-source-node="n117">
                <p data-source-node="n118"><b data-source-node="n119">Status Number</b>: Enter the numeric value that identifies this status.</p>
            </li>
            <li data-source-node="n120">
                <p data-source-node="n121"><b data-source-node="n122">Mandatory</b>: Enable this option if this status is required and cannot be bypassed during processing.</p>
            </li>
            <li data-source-node="n123">
                <p data-source-node="n124"><b data-source-node="n125">In Default Flow</b>: Enable this option to include this status in the default processing flow for the functional area.</p>
            </li>
            <li data-source-node="n126">
                <p data-source-node="n127"><b data-source-node="n128">Related Status</b>: Select the status value that this status is associated with in the flow.</p>
            </li>
            <li data-source-node="n129">
                <p data-source-node="n130"><b data-source-node="n131">System Status</b>: Select the system-level status that maps to this functional area status.</p>
            </li>
            <li data-source-node="n132">
                <p data-source-node="n133"><b data-source-node="n134">External Status</b>: Enter the external status value used when uploading status data to an external system.</p>
            </li>
            <li data-source-node="n135">
                <p data-source-node="n136"><b data-source-node="n137">Include In Interface Upload</b>: Enable this option to include this status in interface upload processing.</p>
            </li>
        </ul>
        <p data-source-node="n138"> </p>
        <p data-source-node="n139">Use Back, Save, Continue, and Finish to manage and complete Functional Area status flow configuration.</p>
