
        
        <h1 data-source-node="n57"><a name="kanchor2037" data-source-node="n58"></a>Immediate Reconcile of Bad Count Checkbox</h1>
        <p data-source-node="n59">This checkbox indicates if the user can immediately adjust the inventory 
 in this location as long as it's within the preference's positive and 
 negative tolerances.</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">If this checkbox is checked, 
 the user assigned to this preference can immediately adjust the inventory 
 in this location, as long as it's within the preference's positive and 
 negative tolerances.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li class="li_1" data-source-node="n64">If 
 this checkbox is not checked, the user assigned to this preference 
 can never adjust the inventory on his own. The system will place every 
 cycle count request that this user encounters (that is not equal to the 
 system quantity) into a "pending review" status. This request 
 then will have to be reviewed by someone authorized to perform cycle counts.</li>
        </ul>
