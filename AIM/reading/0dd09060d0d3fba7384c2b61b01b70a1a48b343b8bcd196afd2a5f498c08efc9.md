
        
        <h1 data-source-node="n56">Configurations Explorer Window</h1>
        <p data-source-node="n57">You will use this window to access the system configurations. All warehouse 
 specific data is setup and maintained in these configurations. The system 
 will use this data to manage all warehouse activity. The information defined 
 in these configurations is critical. We recommend limiting access to warehouse 
 supervisors and your IT department.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Using the Configuration Explorer Window...</h4>
        <ol data-source-node="n61">
            <li class="li_4" value="1" data-source-node="n62">
                <p class="p_12" data-source-node="n63">Access the Configurations Explorer Window.</p>
                <p data-source-node="n64"> </p>
            </li>
            <li value="2" data-source-node="n65">
                <p data-source-node="n66">Use the treeview or the find form 
 menu to locate the configuration window you want to use. If any 
 records exist for this configuration, the system will display them in 
 the records list (located on the right side of the explorer window).</p>
                <p data-source-node="n67"> </p>
            </li>
            <li value="3" data-source-node="n68">Select a configuration 
 record. The system will open the corresponding record in a configuration 
 window.</li>
        </ol>
