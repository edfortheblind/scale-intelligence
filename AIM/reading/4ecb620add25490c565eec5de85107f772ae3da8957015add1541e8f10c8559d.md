
        
        <h1 data-source-node="n56"><a name="kanchor1116" data-source-node="n57"></a>Lot / Lot ID Field</h1>
        <p data-source-node="n58">This field represents the lot ID associated with a product stored in your warehouse. A lot 
 ID represents a production run of one set of materials. You can require lot ID validation per item 
 on the Item Window. Lot IDs are identified during packing on the Item 
 Special Information Entry Window.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> If a single line represents multiple lots, this field will have the value “Multiple”.</p>
