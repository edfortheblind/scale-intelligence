Maximum Volume Field

On the Work Creation Master...

This field indicates the most volume that can be processed in a particular wave or work unit. The work creation process will start a new work unit when it senses that adding the next work instruction to the current work unit will exceed this maximum value. Note that if a single work instruction in and of itself exceeds this maximum, the instruction will be placed onto a work unit by itself. It will NOT be broken down into multiple work instructions.

 

The volume is always calculated as the base unit of measure quantity (example: eaches) multiplied by the length, width, and height of the item, regardless of whether the quantity is sufficient to make a higher unit of measure (such as a case or pallet) or not.

 

 

For example:

  • Suppose the Maximum Volume value is set to 100 cubic inches on the shipment allocation work creation master record.

  • The shipment has four details (item 1 = 60 cubic inches, item 2 = 40 cubic inches, item 3 =30 cubic inches, item 4 = 80 cubic inches).

  • The first item will get added to the first work unit (volume =60). The system will not break the detail.

  • The second item will get added to the second work unit (volume = 100). The system will not break the detail.

  • The third item will get added to the third work unit (volume=30). The system will not break the detail.

  • The fourth item will NOT get added to the third work unit, because it would exceed the maximum volume value (volume would equal 110). Therefore, the fourth item will get added to the fourth work unit.
