
        
        <h1 data-source-node="n56">Lookup Screen</h1>
        <p data-source-node="n57">You can use a Lookup Screen to search for a specific record in the system. 
 This is especially helpful when you do not know what a particular field 
 value should be. The system implements several search criteria when looking 
 for a record. Lookup Screens are located throughout the system, whenever 
 they are required. You can access them by pressing the small magnifying glass icon to the right of a field input box.</p>
        <h4 data-source-node="n58"> </h4>
        <h5 data-source-node="n59"> </h5>
        <h4 data-source-node="n60">Lookup Screen Fields...</h4>
        <ul data-source-node="n61">
            <li data-source-node="n62">The application uses several search criteria to 
 locate records in the system. The specific fields in each Lookup Screen 
 will depend on the type of record you are searching for.</li>
        </ul>
        <h4 data-source-node="n63"> </h4>
        <h4 data-source-node="n64">Procedures...</h4>
        <ol data-source-node="n65">
            <li value="1" data-source-node="n66">
                <p align="left" class="p_38" data-source-node="n67">Click on the magnifying glass icon (next to a field's input box), and the system will display a Lookup Screen. </p>
                <p align="left" class="p_38" data-source-node="n68"> </p>
            </li>
            <li align="left" class="li_11" value="2" data-source-node="n69">Enter 
 information for the search criteria fields (the fields displayed will depend on what type of field the lookup was accessed for). When entering data 
 in the search criteria fields, you can use this search syntax to help 
 narrow down your search:<br data-source-node="n70"> </li>
            <ul type="disc" class="ul_1" data-source-node="n71">
                <li data-source-node="n72">
                    <p align="left" class="p_38" data-source-node="n73">A% will 
 return all records that start with a capital "A"</p>
                    <p data-source-node="n74"> </p>
                </li>
                <li data-source-node="n75">
                    <p align="left" class="p_38" data-source-node="n76">%A will 
 return all records that end in a capital "A"</p>
                    <p align="left" class="p_38" data-source-node="n77"> </p>
                    <li data-source-node="n78">
                        <p align="left" class="p_38" data-source-node="n79">Search that starts with only a lower or upper case A will return all records that start with an "A".</p>
                    </li>
                    <p data-source-node="n80"> </p>
                </li>
                <li align="left" class="li_11" data-source-node="n81">%a% 
 will return all records that include a lowercase "a" anywhere 
 in the record name.</li>
            </ul>
            <p align="left" class="p_38" data-source-node="n82"> </p>
            <li value="3" data-source-node="n83">
                <p align="left" class="p_38" data-source-node="n84">Press the apply filter button.
 The system will display any records that have met your search criteria 
 in the record list.</p>
                <p align="left" class="p_38" data-source-node="n85"> </p>
            </li>
            <li align="left" class="li_11" value="4" data-source-node="n86">Choose 
 a record from the record list and press the Select button. The system will return to the original screen with the value populated into the appropriate field. <br data-source-node="n87"><br data-source-node="n88">NOTE: You can also clear the records from the Lookup Screen by pressing the Clear button (Clear filter for Insight/Transaction/Details screen). The filter button does not refresh the grid or start a search when clearing the filter criteria.  You will have to press the Apply filter button to start the search.</li>
        </ol>
