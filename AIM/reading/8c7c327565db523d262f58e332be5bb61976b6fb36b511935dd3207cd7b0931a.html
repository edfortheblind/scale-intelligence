Eligible Checkbox/Toggle

In Immediate Needs...

You can use this checkbox to activate immediate needs processing for a certain item.

 

 

In Inbound Quality Control...

You can use this checkbox to activate quality control validation for this item. If this is eligible, the system will, after an item is checked in, check to see if a portion of this item quantity should be routed to a QC location.

 

 

In Work Order Processing...

You can use this checkbox to indicate that this work order line qualifies for a quantity increase (over allocation) during work creation for work orders. You can define this over allocation on a work order's bill of materials detail record or on the work order line itself.
