Creating a Receipt and Receipt Line

Receipts can either be interfaced from the ERP or created in the system. All product introduced to the warehouse must be associated with a receipt record. The receipt record includes such values as address information, status, and other miscellaneous values. The receipt line record represents the actual item and quantity that you want to receive into your warehouse. All receipt lines are associated with a receipt record. You can also create receipts from shipments, using the Receipt From Shipment Screen (accessed via the Shipment Insight Screen).

Creating a Receipt...

The following information is a general description of each field section used in creating a receipt in SCALE. For specific definitions of a certain field, see the "Field Links" section of this topic, or type the field name into the help index.

 

- Access the Receipt Insight screen, and select the New action. The system will display the Receipt Screen in new mode.

 

Reference Info Fields

- You can use these fields to indicate the values of various fields associated with this receipt, including Receipt ID and Receipt ID Type.

 

- When finished, press the Save button, and the system will save the receipt.

 

Source Fields

- You can use these fields to provide the address information for the source entity of this receipt.

 

Ship From Fields

- You can use these fields to provide the address information for the ship from entity of this receipt.

 

Status Fields

- You can use these fields to view the statuses associated with this receipt.

 

Carrier Fields

- You can use these fields to indicate the carrier information for this receipt.

 

Dates Fields

- You can use these fields to assign various dates associated with this receipt.

 

Lines Fields

- You can use these fields to view the items associated with this receipt.

- Clicking on the New Line action will open the Receipt Line Screen in a new mode. Clicking on Save on that screen shows a success message and the screen gets refreshed so that you can enter another detail and so on.

- If you click on Cancel, the screen goes back to the Receipt Screen and then system will display all the new receipt lines that got added under the Lines section of the screen.

 

Totals Fields

- You can use these fields to view summary information associated with this receipt.

 

User Defined Fields

- You can use these fields to view the customized data.

 

 

 

Creating a Receipt Line...

The following information is a general description of each section used in creating a receipt line. For specific definitions of a certain field, see the "Field Links" section of this topic, or type the field name into the help index.

 

- Access the Receipt Line Insight Screen, and select the New action. The system will display the Receipt Line Screen in new mode.

 

Item Info Fields

- You can use these fields to indicate the item and lot that you want on this receipt line.

 

Quantity Info Fields

- You can use these fields to indicate the amount of the item that you want on this receipt line.

 

Item Dimensions Fields

- You can use these fields to define the physical attributes of the item included on this receipt line.

 

Item Characteristics Fields

- You can use these fields to define miscellaneous properties of the item included on this receipt line.

 

Processing Values Fields

- You can use these fields to indicate certain values that affect how the system will putaway this item quantity.

 

Reference Info Fields

- You can use these fields to view/indicate various receipt-related values.

 

Categories Fields

- You can use these fields to associate user-defined item categories to this receipt line.

 

- When finished, press the Save button, and the system will save the receipt line.

 

User Defined Fields

- You can use these fields to view the customized data.
