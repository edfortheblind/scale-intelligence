Apply At Container Contents Checkbox

This setting is typically used when packing hazardous items in containers.

 

 

Containers with one hazardous item...

Containers with one hazardous item do not require special formatting or special handling; the “flat” transmission approach can be used with the applicable accessorials. The Assign Accessorial Window will show the active records for the accessorial details.

 

 

Containers with 1-3 hazardous items...

In order to support multiple hazardous items packed into a single container, the external rating server accepts data values in a “complex type”, which is a data structure inside the transmission. If this "Apply at Container Contents" setting is active, then accessorial(s) are assigned in the following manner:

  1. The configuration manager would remove the “flat” accessorial details so that the “complex type” accessorial details will be shown during assignment.

  2. The user then would assign the accessorial to the container contents, populating the values that apply to the goods in the container. Other accessorials are assigned to the shipment or container and apply to all of the goods inside the container.

    - The Accessorial Assignment Window will only display “contents-level” accessorials when opened for container contents, and will show only “non-contents level” (“normal”) accessorials when opened for containers. It is not possible to assign these “contents level” accessorials at more than one level.

    - The Accessorial Assignment Window will display both types of accessorials when opened for full case containers.

  3. When accessorial values are gathered for transmission to the external rating server, the system sees that the assigned accessorial applies at the “contents” level and formats the accessorial values appropriately.

  4. The transmission is sent to the external rating server.

Important Note: Container contents records must exist for the system to assign accessorials in the manner described above; i.e., containers cannot be “created on the fly” since they would not have contents records to which an accessorial could be assigned.
