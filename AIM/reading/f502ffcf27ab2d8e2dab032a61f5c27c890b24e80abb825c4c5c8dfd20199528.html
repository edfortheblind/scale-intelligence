Lot Verification Required Checkbox (Outbound QC)

Outbound QC Inspection...

 

**This value is not used for RF Shipping Container QC**

 

This checkbox determines if the user will need to enter a lot value for lot-controlled items when performing inspection on a container, and how the lot field will appear on the inspection grid.

- If this checkbox is selected, the lot field will appear in the “scan item fields”, there will be a lot column in the inspection grid, and the inspection grid will display a separate grid row for each item/lot combination.

- If this checkbox is not selected, the lot field will not appear in the “scan item fields”, there will not be a lot column in the inspection grid, and the inspection grid will summarize all of an item's lot instances into a single grid row.

NOTE: It is recommended that you not turn off lot verification on a user's preferences while the user is currently performing QC inspection on containers. If this is done, the system might not have any information about which lot(s) failed QC, so therefore the grid would not be able to accurately display to the user the correct failed quantity against the right item/lot combination.
