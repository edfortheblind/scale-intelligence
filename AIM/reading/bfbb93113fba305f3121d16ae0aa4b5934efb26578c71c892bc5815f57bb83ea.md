
        
        <h1 data-source-node="n56"><a name="kanchor149" data-source-node="n57"></a>Configuring the SMTP Mail Server</h1>
        <p data-source-node="n58">You will need to configure a few technical settings in order for TPM email 
 alerts to work with your mail server. When mail comes to a mail server, 
 it needs to know how to deliver these messages. If your server cannot 
 deliver message(s), the following settings will indicate to the mail server 
 how to search for a server that does know how to deliver these messages. Some mail servers require 
 specialized settings to work with the system. If you experience problems 
 with email alerts after performing the following procedures, call support 
 for further assistance. Note that the following procedures 
 are performed outside of the SCALE application.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures...</h4>
        <p data-source-node="n62">You will perform this action on the Windows Internet Information Services 
 Manager.</p>
        <ol class="ol_1" data-source-node="n63">
            <li value="1" data-source-node="n64">Access the Internet 
 Information Services Manager on the application server (Start 
 | Programs | Administrative Tools). The system will open the Internet 
 Information Services Manager window.<br data-source-node="n65"> </li>
            <li value="2" data-source-node="n66">Locate the icon 
 that represents your application server (in the window's left pane). 
 <br data-source-node="n67"> </li>
            <li value="3" data-source-node="n68">Drill down to 
 the "Default SMTP Server" node. Right-click this node 
 and select Properties.<br data-source-node="n69"> </li>
            <li value="4" data-source-node="n70">On the Access 
 Tab, press the Relay Button. On the ensuing screen, select the 
 "<span class="span_2" style="font-weight: normal" data-source-node="n71">All except the list below</span>" 
 button.<br data-source-node="n72"> </li>
            <li value="5" data-source-node="n73">Also on this 
 window, select the " Allow 
 all computers which successfully authenticate to relay, regardless of 
 the list above" Check box.<br data-source-node="n74"> </li>
            <li value="6" data-source-node="n75">Press OK when 
 finished, and press OK again to save your changes. <br data-source-node="n76"> </li>
            <li value="7" data-source-node="n77">To apply these 
 setup settings, you will need to stop and restart the SMTP virtual 
 server. To do this, right-click the "Default SMTP Server" node, 
 and choose Stop and then Start.</li>
        </ol>
