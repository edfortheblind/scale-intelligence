
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor1976" data-source-node="n58"></a>Work Priority Escalation Criteria</h1>
        <p data-source-node="n59">Work Priority Escalation enables the system to automatically update the priority of work records (both header and detail) based on pre-defined criteria. This is done through a scheduled job that scans eligible work records and updates their priorities accordingly. This process ensures that high-priority work, such as urgent shipments, is executed ahead of others.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">The configuration involves two main steps:</p>
        <ul data-source-node="n62">
            <li data-source-node="n63">
                <p data-source-node="n64">Defining Eligibility Criteria – Determine which work records qualify for priority updates.</p>
            </li>
            <li data-source-node="n65">
                <p data-source-node="n66">Scheduling the Escalation Job – Specify the frequency and parameters of the job.</p>
            </li>
        </ul>
        <p data-source-node="n67">Criteria for eligibility.</p>
        <ul data-source-node="n68">
            <li data-source-node="n69">
                <p data-source-node="n70">Using the FilterBuilder: define criteria for selecting work records eligible for escalation. For example, if the filter includes a Work Type of “Shipment Work,” and your system has three types (Shipment Work, Receiving Work, and Work Order Work), the escalation job will only consider records with the “Shipment Work” type.</p>
            </li>
        </ul>
        <ul data-source-node="n71">
            <li data-source-node="n72">
                <p data-source-node="n73">On the Scheduled Job configuration Run From/Run At, you will first need to define the interval at which the work escalation priority job will run.</p>
            </li>
        </ul>
        <ul data-source-node="n74">
            <li data-source-node="n75">
                <p data-source-node="n76">On the Scheduled Job configuration Parameters section, you will next need to define the specific job settings for the work escalation priority job</p>
            </li>
        </ul>
