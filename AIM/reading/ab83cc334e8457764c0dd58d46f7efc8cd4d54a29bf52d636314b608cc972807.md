
        
        <h1 data-source-node="n56"><a name="kanchor1405" data-source-node="n57"></a>Requested Delivery Type Field</h1>
        <p data-source-node="n58">This field indicates the preferred delivery date option:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61"><i data-source-node="n62">Deliver On</i> - If this 
 is selected, the shipment should be delivered on the requested delivery 
 date.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li data-source-node="n64">
                <p data-source-node="n65"><i data-source-node="n66">Deliver By</i> - If this 
 is selected, the shipment should be delivered on or before the requested 
 delivery date.</p>
                <p data-source-node="n67"> </p>
            </li>
            <li data-source-node="n68">
                <p data-source-node="n69"><i data-source-node="n70">Deliver After</i> - If this 
 is selected, the shipment should be delivered after the requested 
 delivery date. It should not be delivered before or on this date.</p>
                <p data-source-node="n71"> </p>
            </li>
            <li data-source-node="n72"><i data-source-node="n73">None</i> - 
 If this is selected, the customer did not request a specific delivery 
 date. The system will default today's date.</li>
        </ul>
