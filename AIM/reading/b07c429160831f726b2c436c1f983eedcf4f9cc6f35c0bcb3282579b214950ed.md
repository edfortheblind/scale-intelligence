
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor265" data-source-node="n58"></a>Container Class</h1>
        <p data-source-node="n59">A container class groups together container types that share common characteristics, such as packaging category (e.g., carton, case, pallet). During carrier routing, the system references this record to determine the appropriate routing guide for a shipment line. Additionally, it helps associate a UCC code with a group of container types. By mapping container types to container classes, you reduce both configuration and processing time. The system includes common default container classes—such as pallet and carton—to support typical business operations.</p>
