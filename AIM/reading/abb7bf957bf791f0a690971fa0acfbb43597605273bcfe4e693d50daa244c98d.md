
        
        <h1 data-source-node="n56"><a name="kanchor318" data-source-node="n57"></a>Allow Multiple Containers Per Work ID Field</h1>
        <p data-source-node="n58">This field indicates whether the user is allowed to open a new container without closing the current container. When this field is set to No, the container currently open will be closed automatically when the user tries to open a new one.</p>
