Defining Warehouse Alerts

A warehouse alert can communicate to the user that a certain condition in the warehouse exists and needs attention. You can use warehouse alerts to learn what problem(s) exist in your warehouse and how to resolve them. When a defined alert action occurs, the system can generate a history record (displayed in the Warehouse Alert Viewer), an email message, or both. Also, the system allows you to configure when a warehouse alert should be sent, the email's structure and contents, who should receive it, and the priority that determines when the alert should be addressed (in relation to other alerts).

Note On Email Servers

The "Mail Server" registry value at HKEY_LOCAL_MACHINE \SOFTWARE\Manhattan Associates\ILS\ must be set to the name of the machine hosting the mail server software. If this value is empty or invalid, the system will throw an audit when trying to generate an alert.

 

 

Procedures...

 

Using the Header Fields
  1. Use the Alert Type Field to associate a warehouse process to this alert. Note that alert types are not configurable in the system. Ask a Manhattan representative if you want to add additional alert types.
     
  2. Use the Action Field to indicate what you want the system to generate when this alert is triggered.

    - Choose "Email" if you want the system to send an email to selected person(s) when this alert is triggered.

    - Choose "History" if you want the system to generate a history records when this alert is triggered. You can view this record in the Warehouse Alerts Viewer.

    - Choose "History and Email" if you want the system to generate both of these when this alert is triggered.

 

Using the General Tab
  1. Use the Priority Field to assign a priority to this alert. This value indicates what order the system will use to process this alert.
     
  2. Use the Description Field to provide a text description of this alert. This description will appear in this window's record list.
     
  3. Use the Message Field to provide the text of an alert, if an email template will not be used. The system uses this message as a default if the system process does not create its own message. Note that all alert processes create their own message except "Inbound Alert" and "Outbound Alert."
     
  4. Use the Email Title Field to indicate the text of the email's subject line.
     
  5. Use the Web Description Field to make this alert available for web users. You can use this value to make the description of this alert more understandable to clients using Trading Partner Management to define an alert.
     
  6. Use the Email Template Field to indicate a pre-made template that you want the system to use to format this email. The template defines the structure and contents of the alerts sent to the email address.

 

Using the Criteria Tab

You can use this tab's fields to provide additional criteria that a system record must meet before an alert is triggered. Depending on what alert type you choose, the system may or may not display fields on this tab. If this tab appears, you must provide a value in at least one of its fields.

 

 

Using the Interface Error Reference Fields Tab

You can use this tab's fields to view the values that are defined for the twenty interface error reference fields. When you select a different interface process from the Criteria Tab, the system will display the reference fields defined for that process. Note that you cannot change these values from this tab. For more information about interface validation warehouse alerts, see the topic Defining Warehouse Alerts.

 

 

Using the Email Addresses Tab

You will use this tab's fields to identify who should receive an email alert message, as well as the structure and contents of that email. This tab is displayed only if the alert generates emails. You can create multiple records on this tab if you want to send the alert to multiple email accounts.

  1. Right-click on the record list and choose New. The system will open the Warehouse Alert Address Window.
     
  2. Choose the email address you want to send the email message:

    - Select the Email Address Field to define the address that the system will send the alert to (for example, customer@store.com).

    For Inbound Alerts...
    - Select the Ship From Email Address Button to send the alert to the email address defined on the Ship From area of the Receipt Screen.

    - Select the Vendor Email Address Button to send the alert to the email address defined on the Source area of the Receipt Screen.

    For Outbound Alerts...
    - Select the Ship To Email Address Button to send the alert to the email address defined on the Ship To area of the Shipment Screen.

    - Select the Customer Email Address Button to send the alert to the email address defined on the Customer area of the Shipment Screen.

    - Select the Alternate Email Address Button to send the alert to the email address defined on the General area of the Shipment Screen.
     
  3. Use the Email Template Field to indicate a pre-made template that you want the system to use to format this email (if different than the template chosen above). The template defines the structure and contents of the alerts sent to the email address.
     
  4. Press OK. The system will display the email address in the record list.
