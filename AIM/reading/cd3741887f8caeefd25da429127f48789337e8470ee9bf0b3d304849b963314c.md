
        
        <h1 data-source-node="n56"><a name="kanchor258" data-source-node="n57"></a>Assigning/Unassigning A Work Unit To A Team/User</h1>
        <p data-source-node="n58">You can assign a work unit that is either open or in process. This is 
 especially helpful if you want to assign or 
 unassign a work unit to a user/team. Note that you cannot edit a closed 
 unit. The system will update the work unit to reflect the newly-assigned 
 user. If the unit's instruction(s) are to be processed from pick lists 
 (non-RF), you should reprint the pick lists and labels to ensure accuracy.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures...</h4>
        <ol data-source-node="n62">
            <li value="1" data-source-node="n63">
                <p data-source-node="n64">Open the Work Insight screen.</p>
                <p data-source-node="n65"> </p>
            </li>
            <li value="2" data-source-node="n66">
                <p data-source-node="n67">Access a work unit or multiple work units that 
 you want to assign/unassign. </p>
                <p data-source-node="n68"> </p>
            </li>
            <li value="3" data-source-node="n69">Select either 
 the Assign Team/User or Unassign action. <br data-source-node="n70"><br data-source-node="n71"><ul data-source-node="n72"><li data-source-node="n73"> The system will display the Assign Team/User Window for the Assign action. <br data-source-node="n74"><br data-source-node="n75"><ol data-source-node="n76"><li value="1" data-source-node="n77">Enter a work team or a username as applicable and press Save.<br data-source-node="n78"><br data-source-node="n79"></li><li value="2" data-source-node="n80"> If the user is not authorized for any work profile(s), you will be notified with an error message. Similarly, you will receive confirmation message if the user or team assignment is successful. <br data-source-node="n81"></li><br data-source-node="n82"></ol></li><li data-source-node="n83">The system will prompt yes/no confirmation for the Unassign action. If you click Yes, you will receive confirmation for successful unassignment.  <br data-source-node="n84"> </li><br data-source-node="n85"></ul></li>
        </ol>
