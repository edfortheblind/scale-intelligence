Lot Buttons

You can use these buttons to indicate how you want the system to allocate your lot-controlled items:

  • Any Lot (Multiple OK): Choose this option to have the system allocate items with any lot, where allocating multiple lots to satisfy the demand is acceptable. The system will use the allocation strategy and allocation location selection records to determine the order that the locations will be allocated from.
     
  • Any Lot (Single Only): Choose this option to have the system allocate any lot, but just a single lot. The system will use the allocation strategy and allocation location selection records to determine ordering (just like normal allocation). But once a lot is selected, it will be the only lot allocated. If the allocation demand cannot be met with this lot, the system will reject the rest of the quantity. If not enough quantity can be found for one lot, the system will allocate the largest quantity of one lot, and fail the rest of the quantity. Note that this single lot may exist in multiple locations.
     
  • Specified Lot (Single Only): Choose this option to have the system allocate only a specified lot. If the system cannot find the specified lot, allocation will fail. The system will only look for the lot specified (such as on the shipment or work order). It will not look for any other lots. Note that this single lot may exist in multiple locations. NOTE: If no lot is specified on the shipment line, then the system will not fail allocation, but will instead process as it would if using the "Any Lot (Multiple OK)" setting. When no lot is specified (as is often the case with replenishment which does not look at the lot on the shipment line), then allocation should not fail. Allocation will only fail in this scenario if no inventory/lot can be found which matches the specified allocation location selection criteria.
