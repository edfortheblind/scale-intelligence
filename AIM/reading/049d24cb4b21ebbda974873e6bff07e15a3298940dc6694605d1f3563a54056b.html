Replenishment Type Field

You will use this field to define when the system will attempt to replenish products:

  • Item Location Capacity: Use this type if you want to generate replenishment requests based on location need. This replenishment type is often used to replenish forward locations depleted during by an earlier work crew. Note that this replenishment type uses the "Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.

  • Top-Off Item Location Capacity: Use this type if you want to generate replenishment requests based on location need. Note that this replenishment type uses the "Top-Off Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.

  • Demand From Pool: Use this type if you want to generate replenishment requests for shipments in the pool. This type of replenishment allows you to prepare for upcoming demand. Note that this replenishment type uses the "Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.

  • Demand From Wave: Use this type if you want to generate replenishment requests for shipments in a wave. Note that you cannot choose this type if you plan to run manual replenishment. Note that this replenishment type uses the "Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.

  • Demand From RF Outbound Short Pick: Use this type if you want the system will run replenishment based on item demand from a location that has been short picked (if the user is configured to allow this via their work special handling settings). Note that this replenishment type does not allow you to configure for this master the Create Work Method (it is always set to automatic), the Replenishment Criteria (since the item and location are already known to the system), or the Replenishment Modes. Note that this replenishment type uses the "Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.
