        <h4 data-source-node="n184"><a name="SearchingBuildingAWave" data-source-node="n185"></a>Searching a Wave...</h4>
        <p data-source-node="n186">You can use the Wave Insight Screen to search for wave records for the shipment(s) in your warehouse. </p>
        <ol data-source-node="n187">
            <li value="1" data-source-node="n188">Open the Wave Insight Screen.<br data-source-node="n189"><br data-source-node="n190"></li>
            <li value="2" data-source-node="n191">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search. <br data-source-node="n192"><br data-source-node="n193"></li>
            <li value="3" data-source-node="n194">Press the Apply Filter button. The system will display all information regarding the resulting records in the List Pane.</li>
        </ol>
        <p data-source-node="n195">NOTE: You can select all the records from the first page of List Pane by checking the check box for selecting all records. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane. <br data-source-node="n196"><br data-source-node="n197"></p>
        <hr width="100%" align="center" data-source-node="n198">
        <p data-source-node="n199"> </p>
        <p data-source-node="n200"> </p>
        <h4 data-source-node="n201"><a name="Building" data-source-node="n202"></a>Building a Wave...</h4>
        <p data-source-node="n203">You can use the Wave Insight Screen to  build wave records for the shipment(s) in your warehouse. </p>
        <ol data-source-node="n204">
            <li value="1" data-source-node="n205">
                <p data-source-node="n206">Open the Wave insight screen.<br data-source-node="n207"><br data-source-node="n208"></p>
            </li>
            <li value="2" data-source-node="n209">Click on the Build action. The Build Wave screen opens. <br data-source-node="n210"><br data-source-node="n211"></li>
            <li value="3" data-source-node="n212">Specify the Warehouse and one or more Wave master(s) in the Build Wave screen and then click on the Build button. Only the authorized  wave masters  for the selected warehouse are displayed for selection. The system returns to the Wave Insight screen and displays a confirmation message stating that the build wave is successfully submitted. </li>
        </ol>
        <p data-source-node="n213">Note: In some scenarios, the wave will cause bad data, when waved shipments are distributed to an existing shipment with allocate complete checked. In such scenarios, user needs to check shipment has  allocation completion checked. This will ensure that no bad data is created on completion of wave.</p>

        <h4 data-source-node="n278"><a name="ScreenActions" data-source-node="n279"></a>Screen Actions</h4>
        <p data-source-node="n280">The following actions are accessible from the List Pane and/or Detail Pane:</p>
        <p data-source-node="n281"> </p>
        <p data-source-node="n282"> </p>
        <h5 data-source-node="n283">New</h5>
        <p data-source-node="n284">This action enables you to manually create a wave record from the Wave Insight screen. For more information on this topic, see the <a href="305222b4727196313e21c68fd4c60f3cf6fb17c46f785cd9bb01b21a25c118b1.html" data-source-node="n285">Creating a New Wave Record</a> topic. </p>
        <p data-source-node="n286"> </p>
        <p data-source-node="n287"> </p>
        <h5 data-source-node="n288">Edit/View</h5>
        <p data-source-node="n289">The Edit action is shown instead of the View action when you got the Edit security. The View action is displayed when you only have Display security for the screen.</p>
        <p data-source-node="n290"> </p>
        <p data-source-node="n291"> </p>
        <h5 data-source-node="n292">Delete</h5>
        <p data-source-node="n293">This action allows you to delete any selected wave that has not been run. When you delete a wave, all the shipments are returned to the pool and can be assigned to a new wave.</p>
        <p data-source-node="n294"> </p>
        <p data-source-node="n295"> </p>
        <h5 data-source-node="n296">Build</h5>
        <p data-source-node="n297">This action allows you to build wave(s) for a certain warehouse. During the wave building process, the system assigns pooled shipments 
 to the appropriate wave(s). </p>
        <p data-source-node="n298"> </p>
        <p data-source-node="n299"> </p>
        <h5 data-source-node="n300">Cancel</h5>
        <p data-source-node="n301">This action allows you to cancel any wave that has been run, as long as it has not been released. For more information on this topic, see the <a href="f95431ca9a42f8cc326def4b0c44563876797b45e44e9268cf9b9a4d634f5f9f.html" data-source-node="n302">Canceling a Wave</a> topic. </p>
        <p data-source-node="n303"> </p>
        <p data-source-node="n304"> </p>
        <h5 data-source-node="n305">Reprint Labels</h5>
        <p data-source-node="n306">This action enables you to manually select the printers that the system will use to print wave paperwork (documents and/or labels). These printers will override the print devices that were previously configured in your document routing/document master configuration records.  For more information on this topic, see the <a href="42af91a90fc9491ae664871eb3189b6e99db3122c0c63006e384f4b285ba1529.html" data-source-node="n307">Manually <a href="42af91a90fc9491ae664871eb3189b6e99db3122c0c63006e384f4b285ba1529.html" data-source-node="n308">S</a></a><a href="42af91a90fc9491ae664871eb3189b6e99db3122c0c63006e384f4b285ba1529.html" data-source-node="n309">electing Wave Printers/Reprinting Wave Paperwork</a> topic. </p>
        <p data-source-node="n310"> </p>
        <p data-source-node="n311"> </p>
        <h5 data-source-node="n312">Release</h5>
        <p data-source-node="n313">This action allows you to manually release it to the warehouse. When you release it, the work generated for this wave becomes available for processing. For more information on this topic, see the <a href="bdab4043ae299d4cf536764a37c115d67bdc18702d9c1764a41ef47b8f2abe13.html" data-source-node="n314">Processing a Wave</a> topic. </p>
        <p data-source-node="n315"> </p>
