
        
        <h1 data-source-node="n56"><a name="kanchor533" data-source-node="n57"></a>Immediate Needs Request Created Field</h1>
        <p data-source-node="n58">This field indicates whether there is any immediate needs request created for the receipt in the Receipt Insight screen's list pane grid fields or for the work orders in the Work Order Insight screen's list pane grid fields. This flag will be set as N when the request is fulfilled. </p>
