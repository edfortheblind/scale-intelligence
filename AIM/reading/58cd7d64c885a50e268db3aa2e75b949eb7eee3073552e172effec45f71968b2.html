Using World Ease Insight Screen

 

World Ease group consists of the container(s) whose final destination is the same intermediate consignee (Hub). A group is created when a shipping container is manifested. If a group already exists for a certain Hub destination, then the system will add the container to the existing group. You can view the containers assigned to a group from the World Ease Insight screen. When a group is closed, you will be able to print the appropriate World Ease documentation.

Search World Ease groups

Use the filter criteria to find and list the world ease groups. Follow the steps to perform a search

 

  • Navigate to Menu >> Shipping >> World Ease Insight screen.
  • In the filter section, enter the search criteria in World Ease ID, Container ID, Shipment ID, Warehouse. Also toggle the buttons to list the open and closed groups using the Include Open Groups and Show Closed Groups.
  • Optionally you can also use the Advanced Criteria to add search attributes.
  • Click Search to view the World Ease Groups listed based on search criteria.
  • The list has details such as World Ease ID and Status displayed for each Group.

 

Container Indicator Tile

This tile displays the number of containers that are associated with the selected World ease Group

Click on the Container tile to open Shipping Container insight screen.

 

Close World Ease Groups

The open World Ease Groups can be closed using the Close action button.

Note: For the World Ease Group documents to be printed, the system status should be in closed state.

 

  • Navigate to Menu >> Shipping >> World Ease Insight screen.
  • In the filter section, enter the search criteria and list the open Groups.
  • Select the required Group and click Actions >> Close
  • A success message is displayed.

Print UPS World Ease Documents

The closed World Ease Groups can be printed in the following way

 

  • Navigate to Menu >> Shipping >> World Ease Insight screen.
  • In the filter section, enter the search criteria and select ON to show the Closed Groups.
  • Select the required Group and Click Print >> Print Selected Doc or Print Default Docs
  • The Certificate of origin, Consolidated Invoice, Document Box Label and Master Invoice are printed for the selected World Ease ID.

Notes

  • You cannot associate additional containers to a closed group.
  • A closed group cannot be reopened.
  • If a group is open and you close the manifest associated with it, the system will automatically close the group as well.
  • The system does not generate paperwork automatically as part of the Close Group action. Instead, after you close a group, you will have to manually initiate printing via the Print Action. You will prepare the paperwork that goes in the Document Box after a group is closed. You can print the following documents from the insight screen: World Ease Certificate of Origin, World Ease Document Box Label, World Ease Consolidated Invoice, and World Ease Master Invoice.
  • If a shipment is on this group, but also has product that is not yet packed into a container, the system will associate this unpacked quantity with another group when it is manifested.
  • Once a group is closed, Progistics will start a new group for any new containers that are going to that particular Hub (along with new MSN numbers, etc).
