 to the system. You can use these operands to create comparisons in filter 
 data configuration windows. The system uses these operands to create an 
 SQL statement.</p>

        <h4 data-source-node="n83">Filter Operand Descriptions...</h4>
        <p data-source-node="n84"> </p>
        <p data-source-node="n85">!= (This operand indicates 
 that one value is   not equal to 
 another value).</p>
        <p data-source-node="n86"> </p>
        <p data-source-node="n87">&lt; (This operand indicates 
 that one value is   less than another 
 value).</p>
        <p data-source-node="n88"> </p>
        <p data-source-node="n89">&lt;= (This operand indicates 
 that one value is   less than or equal 
 to another value).</p>
        <p data-source-node="n90"> </p>
        <p data-source-node="n91">= (This operand indicates 
 that one value is   equal to another 
 value).</p>
        <p data-source-node="n92"> </p>
        <p data-source-node="n93">&gt; (This operand indicates 
 that one value is   greater than 
 another value).</p>
        <p data-source-node="n94"> </p>
        <p data-source-node="n95">&gt;= (This operand indicates 
 that one value is   greater than or equal 
 to another value).</p>
        <p data-source-node="n96"> </p>
        <p data-source-node="n97">IS NULL (This operand indicates 
 that a field has   no value at 
 all).<br data-source-node="n98"> </p>
        <p data-source-node="n99">IS NOT NULL (This operand 
 indicates that a field has a value).</p>
        <p data-source-node="n100"> </p>
        <p data-source-node="n101">LIKE (This operand indicates 
 that a value is similar to the one you enter. For example, if you enter 
 the value "PRO%" then the system will return all values that 
 begin with the prefix "PRO." If you enter the value "%PRO" 
 then the system will return all values that end with the suffix "PRO." 
 If you enter the value "%PRO%" then the system will return all 
 of the values that contain the letters "PRO."<br data-source-node="n102"> </p>
        <p data-source-node="n103">NOT LIKE (This operand 
 indicates that a value is not similar to the one you enter. For example, 
 if you enter the value "PRO%" then the system will not return 
 all values that begin with the prefix "PRO." If you enter the 
 value "%PRO" then the system will not return all values that 
 end with the suffix "PRO." If you enter the value "%PRO%" 
 then the system will not return all of the values that contain the letters 
 "PRO."</p>
