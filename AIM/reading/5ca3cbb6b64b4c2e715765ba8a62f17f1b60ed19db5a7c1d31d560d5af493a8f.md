
        
        <h1 data-source-node="n56"><a name="kanchor591" data-source-node="n57"></a>Using Inventory Attributes</h1>
        <p data-source-node="n58">You can add, edit, and/or delete inventory attributes from a location inventory record via the Inventory Insight Screen. After one of these actions is performed, the system will update the location inventory record, and generate a transaction history record documenting this change. If you want to read more general functional information about inventory attributes (including specifically where they are supported in SCALE), please see the topic <a href="c3f65ac4de2fc3dce97e4180f4db0eaaa010a10166193e50df4370c1ee3c7799.html" data-source-node="n59">Inventory Attributes - Introduction</a>.</p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Pre-Defined Attribute Values</h5>
        <p data-source-node="n62">You can create your own pre-defined inventory attribute values that the user can select from on views/gadgets. See <a href="3afe0a0e91c3be424098655a59ac0655672a919ff3ef1c0b6cfc3c6a56a8444d.html" data-source-node="n63">Creating Inventory Attribute Values</a> for more details.</p>

        <h4 data-source-node="n117"><a name="Adding" data-source-node="n118"></a>Adding Inventory Attributes...</h4>
        <ol data-source-node="n119">
            <li value="1" data-source-node="n120">Access the Inventory Insight screen and select a record that does not already have attributes associated with it.<br data-source-node="n121"><br data-source-node="n122"></li>
            <li value="2" data-source-node="n123">Select the Edit Inventory Attributes action. The system will display the Inventory Attributes Screen in new mode.<br data-source-node="n124"><br data-source-node="n125"></li>
            <li value="3" data-source-node="n126">Use the Attribute 1-20 Fields to provide the new attribute value(s) that you are adding to this inventory. Note that the system requires that you save at least one attribute field value (you cannot add zero attribute values).<br data-source-node="n127"><br data-source-node="n128"></li>
            <li value="4" data-source-node="n129">Press Save. The system will add the attribute value(s) to the inventory.</li>
        </ol>
        <p data-source-node="n130"> </p>

        <h4 data-source-node="n134"><a name="EditingDetails" data-source-node="n135"></a>Editing Inventory Attributes...</h4>
        <ol data-source-node="n136">
            <li value="1" data-source-node="n137">Access the Inventory Insight screen and select a record. <br data-source-node="n138"><br data-source-node="n139"></li>
            <li value="2" data-source-node="n140">In the Actions menu, the Edit Attributes action will get enabled. Click on the Edit attributes action. The system will open the Inventory Attributes screen in a new tab in edit mode.<br data-source-node="n141"><br data-source-node="n142"></li>
            <li value="3" data-source-node="n143">Use the Attribute 1-20 Fields to change the attribute value(s).<br data-source-node="n144"><br data-source-node="n145"></li>
            <li value="4" data-source-node="n146">Prees Save. The system will save the location inventory with the updated attribute value(s).  If no attributes exist yet for the record, they will be added.<br data-source-node="n147"><br data-source-node="n148"></li>
        </ol>

        <h4 data-source-node="n153"><a name="DeletingDetails" data-source-node="n154"></a>Deleting Inventory Attributes...</h4>
        <ol data-source-node="n155">
            <li value="1" data-source-node="n156">Access the Inventory Insight screen and search for a location inventory record which has an inventory attributes associated with it. <br data-source-node="n157"><br data-source-node="n158"></li>
            <li value="2" data-source-node="n159">Select that record. <br data-source-node="n160"><br data-source-node="n161"></li>
            <li value="3" data-source-node="n162">Click on the Delete attributes action. <br data-source-node="n163"><br data-source-node="n164"></li>
            <li value="4" data-source-node="n165">The system will ask you to confirm that you want to delete the attributes. <br data-source-node="n166"><br data-source-node="n167">- If you press Yes, the system will delete the link from the location inventory record and deletes the entire inventory attribute record from the database. A confirmation message appears that the record got deleted successfully.<br data-source-node="n168"><br data-source-node="n169">- If you press No, the system will not delete the attributes and will return to the Inventory Insight screen.<br data-source-node="n170"></li>
        </ol>
