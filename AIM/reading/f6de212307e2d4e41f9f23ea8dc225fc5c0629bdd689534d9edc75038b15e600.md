
        
        <h1 data-source-node="n56"><a name="kanchor293" data-source-node="n57"></a>Show Verification Screen Checkbox</h1>
        <p data-source-node="n58">This field indicates the system should display an extra screen during 
 RF GS1 check in processing, so that after a scan, the user will have to 
 verify that the data they scanned from a barcode was correct. This screen 
 will appear after all the barcodes for a template have been scanned.</p>
