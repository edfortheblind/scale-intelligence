
        
        <h1 data-source-node="n56"><a name="kanchor1148" data-source-node="n57"></a>Authorization Button(s)</h1>
        <p data-source-node="n58">You will use this button to provide authorization for an entity to particular 
 values. The entity is defined by its configuration. For example, if you 
 defining a work team. These buttons appear on many windows that allow 
 you to select multiple values. You can authorize an entity to have access 
 to either all values, no values or a list of values that you select.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">The valid values are:</p>
        <ul data-source-node="n62">
            <li data-source-node="n63"><i data-source-node="n64">All</i> - If this radio button is selected, the entity 
 will have access to all valid values. When new records are created, the 
 entity automatically has access to them.<br data-source-node="n65"><br data-source-node="n66"></li>
            <li data-source-node="n67"><i data-source-node="n68">None</i> - If this radio button is selected, the entity 
 will have access to no values.<br data-source-node="n69"><br data-source-node="n70"></li>
            <li data-source-node="n71"><i data-source-node="n72">List</i> - If this radio button is selected, the system 
 will allow you to select the appropriate values from the list. You can 
 select one or more values.</li>
        </ul>
