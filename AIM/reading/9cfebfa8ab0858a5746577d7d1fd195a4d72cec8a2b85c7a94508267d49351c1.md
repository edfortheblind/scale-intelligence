
        
        <h1 data-source-node="n56"><a name="kanchor216" data-source-node="n57"></a>Defining RF Screen Properties</h1>
        <p data-source-node="n58">The system allows you to modify the basic screen properties of an RF 
 device, such as font, screen size, or screen position. These settings 
 will determine how the system RF system is displayed on your RF devices. 
 You can modify these values by editing certain resource file keys, which 
 begin with the prefix RF_STD. You will perform this action on the System Text Editor Window.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures...</h4>
        <ol class="ol_1" data-source-node="n62">
            <li value="1" data-source-node="n63">Access the System 
 Text Editor Window.<br data-source-node="n64"> </li>
            <li value="2" data-source-node="n65">Choose "Text" 
 from the Group Field. <br data-source-node="n66"> </li>
            <li value="3" data-source-node="n67">Enter one of 
 the following values into the Key Field and press the Search Button. 
 The system will display the appropriate resource file key:<br data-source-node="n68"><br data-source-node="n69">- RF_PROCIMG:  This value determines the graphic that is displayed when the system 
 is busy processing on the RF system.       <br data-source-node="n70"><br data-source-node="n71">- RF_PROCIMGHEIGHT:  This value determines the height of 
 the RF system processing graphic.  <br data-source-node="n72"><br data-source-node="n73">- RF_PROCIMGWIDTH:  This value determines the width of the RF system processing graphic.  <br data-source-node="n74"><br data-source-node="n75">- RF_STDFONT: This value determines 
 the font that you want the system to use when displaying text on the RF.<br data-source-node="n76"><br data-source-node="n77">- RF_STDFONTSIZE: This value 
 determines the size of the font that you want the system to use when displaying 
 text on the RF.<br data-source-node="n78"><br data-source-node="n79">- RF_STDIMGLEFTPOS: This value 
 determines the position of the RF processing graphic from the left side 
 of the RF Screen in pixels. <br data-source-node="n80"><br data-source-node="n81">- RF_STDIMGTOPPOS: This value 
 determines the position of the RF processing graphic from the top of the 
 RF Screen in pixels.<br data-source-node="n82"><br data-source-node="n83">- RF_STDPAGEHEIGHT: This value 
 determines the RF screen's height in pixels.<br data-source-node="n84"><br data-source-node="n85">- RF_STDPAGEWIDTH: This value 
 determines the RF screen's width in pixels.<br data-source-node="n86"> </li>
            <li value="4" data-source-node="n87">When finished reviewing/editing these values, you will need to commit the resources.. See the 
 topic     <a href="fb8df1eb83ede1f4841c91bc83d8ba3b726c5647beaddda205d8618a19ac5efb.html" data-source-node="n88">Using the System 
 Text Editor</a> for information on these procedures. 
	
	<p data-source-node="n89"> </p></li>
        </ol>
