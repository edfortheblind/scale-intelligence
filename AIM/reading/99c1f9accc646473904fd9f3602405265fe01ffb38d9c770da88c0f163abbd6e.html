Activating Blind Receipt RF Header Fields

When checking in a receipt using the blind receiving method, users can have the option of entering certain header information into the RF device. You will use this configuration window to define the fields that the system will display on the receipt information entry screen when processing blind receipts. If you do not enter values for these RF fields, the system will fill these fields using the values as defined in the Receiving System Values Window.

 

NOTE: Using this window, the system allows you to add new header fields, and they will appear on the RF screen. However, they will not perform any function, and the system will not write anything to the database for these fields. Therefore, additional fields besides what is shipped with the system are not supported.
