
        
        <h1 data-source-node="n56"><a name="kanchor289" data-source-node="n57"></a>Defining Work Order Preferences</h1>
        <p data-source-node="n58">A work order preference record allows you to manage how a user or group 
 of users will process work orders. The default record should accommodate 
 the majority of employees. However, you can create specific preference 
 records for employees with unique processing needs.</p>

        <h4 data-source-node="n102">Procedures...</h4>
        <p data-source-node="n103"> </p>
        <h5 data-source-node="n104">General Tab</h5>
        <ol data-source-node="n105">
            <li value="1" data-source-node="n106">
                <p data-source-node="n107">Use the Default Build Location 
 Field to identify where the employee typically creates work units. 
 This value is displayed on the Work Order Window; the user can 
 override this value. It is also printed on the Work Order Component Pick 
 List to identify where components should be delivered for processing. 
 On the Work Order Finished Item Putaway List, this value identifies the 
 from location for the finished items.</p>
                <p data-source-node="n108"> </p>
            </li>
            <li value="2" data-source-node="n109">
                <p data-source-node="n110">Use the Default Storage Location 
 Field to identify the inventory location where the finished item 
 should be located. The system will default this location on the Work Order 
 Confirmation Window, but the user can select a different confirm location. 
 It is also printed on the Work Order Finished Item Putaway List to identify 
 where finished items should be putaway.</p>
                <p data-source-node="n111"> </p>
            </li>
            <li value="3" data-source-node="n112">
                <p data-source-node="n113">Use the Default Inventory Status 
 Field to define the status finished items are assigned when they're 
 confirmed. Generally, you should select an "available" status 
 if you want to allocate the product.</p>
                <p data-source-node="n114"> </p>
            </li>
            <li value="4" data-source-node="n115">
                <p data-source-node="n116">Use the License Plate Assignment Method 
 Radio Buttons to determine if the user will assign or verify license plate 
 IDs. A license plate ID identifies a finished item, or group of finished items, 
 for putaway.<br data-source-node="n117"> </p>
                <p data-source-node="n118">- If you select system, 
 the user never assigns a license plate ID; the system always assigns it.<br data-source-node="n119"><br data-source-node="n120">- If you select manual, the 
 user will assign the license plate ID.</p>
            </li>
            <p data-source-node="n121"> </p>
            <li value="5" data-source-node="n122">
                <p data-source-node="n123">Use the Create Work Checkbox 
 if you want the system to generate work instructions for the allocated 
 components and confirmed finished items.<br data-source-node="n124"><br data-source-node="n125">- If you select this checkbox, 
 the system will call work creation as soon as the component is allocated 
 or the finished item is confirmed.<br data-source-node="n126"><br data-source-node="n127">- If you do not select this checkbox, 
 the system will not create work for either allocated components or confirmed 
 finished items. Instead, it will automatically locate the quantity (either 
 component or finished item) and put its quantity as On Hand at the destination 
 location(s). Someone will need to ensure that the product is physically 
 delivered to that location(s).</p>
                <p data-source-node="n128"> </p>
            </li>
            <li value="6" data-source-node="n129">
                <p data-source-node="n130">Select the Generate Paperwork on 
 Release Checkbox if you want 
 the Work Order Component Pick List and/or the Work Order Assembly Instructions 
 printed when the work order is released. You can also print these documents 
 from the Work Order, as long as at least one component has been 
 allocated. To print automatically, this process must be set to Default 
 on the document type record.</p>
                <p data-source-node="n131"> </p>
            </li>
            <li value="7" data-source-node="n132">
                <p data-source-node="n133">Select the Generate Paperwork on 
 Confirm Checkbox if you want the Work Order Finished Item Putaway 
 List printed when the finished items are confirmed. You can also print 
 this document from the Work Order, as long as at least one finished 
 item has been confirmed.    To print automatically, 
 this process must be set to Default on the document type record.</p>
                <p data-source-node="n134"> </p>
            </li>
        </ol>
        <h5 data-source-node="n135">Assigned Users Tab</h5>
        <ol data-source-node="n136">
            <li value="1" data-source-node="n137">
                <p data-source-node="n138">Use the Assigned Users Tab to 
 associate user profile records with this preference record. When you create 
 the *Default record, the system will automatically select all user profile 
 records that are not already associated with a work order preference record. 
 New users are also automatically associated with the *Default record, 
 unless you associate them with a specific work order preference record.</p>
                <p data-source-node="n139"> </p>
                <p data-source-node="n140">NOTE: You can also assign 
 users from the User Profile Window.</p>
            </li>
        </ol>
