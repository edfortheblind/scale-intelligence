
        
        <h1 data-source-node="n56"><a name="kanchor1525" data-source-node="n57"></a>License Plate Putaway Verify Method Field</h1>
        <p data-source-node="n58">You can use this field to determine how the system will require you to enter license plate IDs during putaway:</p>
        <blockquote data-source-node="n59">
            <p data-source-node="n60">- If <i data-source-node="n61">Use Existing License Plate (No Override Allowed)</i>, the system will show the existing license plate ID in display mode, and not allow you to enter a new value.</p>
            <p data-source-node="n62"> </p>
            <p data-source-node="n63">- If <i data-source-node="n64">Verify Existing License Plate</i>, the system will require you to enter the existing license plate ID for confirmation. An error will occur if you enter a new value.</p>
            <p data-source-node="n65"> </p>
            <p data-source-node="n66">- If <i data-source-node="n67">Existing License Plate (Allow Override)</i>, the system will show the existing license plate, and you can either use the existing license plate or enter a new value.</p>
            <p data-source-node="n68"> </p>
            <p data-source-node="n69">- If <i data-source-node="n70">User Specified</i>, the system will not show the existing license plate. Therefore, you will have to enter a new value. </p>
        </blockquote>
