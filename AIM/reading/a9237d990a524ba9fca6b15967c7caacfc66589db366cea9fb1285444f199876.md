
        
        <h1 data-source-node="n57"><a name="kanchor1824" data-source-node="n58"></a>Location Status Field</h1>
        <p data-source-node="n59">This field indicates the status of a location. Location status are predefined. 
 The system will update a location's status if it changes during processing.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Below is a list of the system-defined location statuses:</p>
        <ul data-source-node="n62">
            <li data-source-node="n63">
                <p data-source-node="n64"><i data-source-node="n65">Empty</i> - There is no inventory 
 stored in this location. When you create a new location, you will assign 
 it this status, unless you assign it product immediately.</p>
                <p data-source-node="n66"> </p>
            </li>
            <li data-source-node="n67">
                <p data-source-node="n68"><i data-source-node="n69">Frozen</i> - There is no activity 
 allowed in this location. If product is stored in this location, it will 
 not be allocated. If this location is empty, the system will not assign 
 product to it. This status must be manually assigned to a location. You 
 may want to assign this status to locations that are temporarily unavailable.</p>
                <p data-source-node="n70"> </p>
            </li>
            <li data-source-node="n71">
                <p data-source-node="n72"><i data-source-node="n73">Storage</i> - When product is 
 allocated to a location and physically putaway, the system changes the 
 location's status from Empty to Storage. This status identifies that product 
 has been stored in the location, but no product has been picked yet. Note: 
 if the location has the status Picking, the system does not change it 
 to Storage.</p>
                <p data-source-node="n74"> </p>
            </li>
            <li class="li_1" data-source-node="n75"><i data-source-node="n76">Picking</i> 
 - When one or more units are physically picked from a location, 
 the system changes its status from Storage to Picking. The location will 
 remain in the Picking status until either its entire inventory is picked 
 or you manually change it to Frozen.</li>
        </ul>
