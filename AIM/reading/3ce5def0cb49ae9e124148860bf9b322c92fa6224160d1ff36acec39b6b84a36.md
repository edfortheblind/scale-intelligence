
        
        <h1 data-source-node="n56"><a name="kanchor1814" data-source-node="n57"></a>Pro Number Length Field</h1>
        <p data-source-node="n58">The number of digits in a carrier's pro numbers, excluding the prefix and
 suffix. Pro numbers are defined in ranges. If the 
 range's beginning and ending pro numbers are different lengths, the pro 
 number length is always equal to the longest number value. For example, 
 if the range is pro number range is 1 - 1000, the length value should 
 be '4'. </p>
