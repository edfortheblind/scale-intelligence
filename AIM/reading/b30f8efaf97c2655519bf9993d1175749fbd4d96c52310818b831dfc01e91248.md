
        
        <h1 data-source-node="n56"><a name="kanchor1637" data-source-node="n57"></a>Defining Container Classes</h1>
        <p data-source-node="n58">A container class allows you to link container types that share common 
 characteristics, such as package category (carton, case, pallet, etc). 
 The system will reference this record during carrier routing to help determine 
 which routing guide to apply to a shipment line. You can also use it 
 to identify the UCC Code associated with a group of container types. By 
 associating container types with their container classes, you can minimize 
 setup and processing time. The system is shipped with the most common 
 default container classes (pallet and carton), which should meet your 
 business needs.</p>

        <h4 data-source-node="n92">Procedures...</h4>
        <ol data-source-node="n93">
            <li value="1" data-source-node="n94">
                <p data-source-node="n95">Use the Container Class Field 
 to identify the container class. Provide a description.</p>
                <p data-source-node="n96"> </p>
            </li>
            <li value="2" data-source-node="n97">Use the UCC Code 
 Field to identify the UCC Code associated with this class' containers. 
 The system will assign this UCC Code to all containers associated with 
 this class.<br data-source-node="n98"> </li>
            <li value="3" data-source-node="n99">Use the EPC Filter 
 Value Field to identify the version/type of Electronic Product 
 Code (EPC) used for a particular container class. <br data-source-node="n100"> </li>
            <li value="4" data-source-node="n101">
                <p data-source-node="n102">Press OK. The system will 
 save your record.</p>
