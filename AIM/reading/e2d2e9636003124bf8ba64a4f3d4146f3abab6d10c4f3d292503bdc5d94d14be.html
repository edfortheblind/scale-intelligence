Using Billing Management With SCALE

Billing Management triggers that are configured to run "manually" must be activated via the Billing Management Manual Generation Window. In this window, you can select which triggers you want to run, and then submit them for processing. The trigger will then send the appropriate data to Billing Management. Note that you can directly access the Billing Management application via a link on the application desktop.

Procedures...

  1. Access the Billing Management Manual Generation Window from the desktop.
     
  2. Select the Billing Management triggers that you want to run. If you would like to run them all, select the Check All Button.
     
  3. Press OK, and the system will run the selected Billing Management trigger(s). The appropriate data resulting from the processing of the trigger will be sent to Billing Management.
