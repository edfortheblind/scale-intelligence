
        
        <h1 data-source-node="n56"><a name="kanchor346" data-source-node="n57"></a>Minimum Replenishment Threshold Field</h1>
        <p style="font-weight: bold" data-source-node="n58">** This field applies only to the following replenishment types: Demand From Pool, Demand From RF Outbound Short Pick Work, Demand From Wave, Item Location Capacity **</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">This field indicates the lowest possible percentage of product that 
 is acceptable for this location or location type. When the location's 
 quantity reaches this threshold, the system will automatically generate 
 a replenishment request (the next time replenishment is run). This value is expressed as a percentage. If 
 this minimum percentage is reached, the system will designate that location 
 for replenishment.</p>
