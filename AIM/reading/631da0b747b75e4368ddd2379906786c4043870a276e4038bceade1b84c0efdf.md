
        
        <h1 data-source-node="n56"><a name="kanchor694" data-source-node="n57"></a>External Status Field</h1>
        <p data-source-node="n58">This field allows you to give external web users a custom status message 
 about a container on the Order Status search screen. You can enter any 
 text value into this field, and the system will display this in a container’s 
 “Status” column. Note that this value only applies 
 to external web users, in the “Outbound” functional area. </p>
