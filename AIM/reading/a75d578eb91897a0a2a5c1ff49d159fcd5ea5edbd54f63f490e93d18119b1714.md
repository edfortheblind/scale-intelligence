        </h1>
        <h4 data-source-node="n59">Overview</h4>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Item Location Capacity configuration defines capacity limits and replenishment thresholds for item and location combinations. You can configure capacity by item or item class, then apply values by location type or specific location.</p>
        <h4 data-source-node="n62"> </h4>

        <h4 data-source-node="n68">Configure Item Location Capacity</h4>
        <p data-source-node="n69"> </p>
        <h5 data-source-node="n70">1. Select Item Location Capacity Type</h5>
        <p data-source-node="n71"> </p>
        <p data-source-node="n72">Choose how the capacity record is scoped.</p>
        <ul data-source-node="n73">
            <li data-source-node="n74">
                <p data-source-node="n75"><b data-source-node="n76">Item</b>: Select a specific item to configure capacity for that item only.</p>
            </li>
            <li data-source-node="n77">
                <p data-source-node="n78"><b data-source-node="n79">Item Class</b>: Select an item class to apply capacity settings to all applicable items in that class.</p>
            </li>
        </ul>
        <p data-source-node="n80"> </p>
        <h5 data-source-node="n81">2. Select Location Option</h5>
        <p data-source-node="n82"> </p>
        <p data-source-node="n83">Choose where the capacity definition is applied.</p>
        <ul data-source-node="n84">
            <li data-source-node="n85">
                <p data-source-node="n86"><b data-source-node="n87">Location Type</b>: Apply capacity settings to all locations matching the selected location type.</p>
            </li>
            <li data-source-node="n88">
                <p data-source-node="n89"><b data-source-node="n90">Location</b>: Apply capacity settings to a specific location record.</p>
            </li>
        </ul>
        <p data-source-node="n91"> </p>
        <h5 data-source-node="n92">3. Capacity Values</h5>
        <p data-source-node="n93"> </p>
        <p data-source-node="n94"><b data-source-node="n95">Maximum Quantity</b>: Enter the maximum quantity allowed for the selected scope.</p>
        <p data-source-node="n96"><b data-source-node="n97">Unit of Measure</b>: Select the unit of measure used for capacity quantity.</p>
        <p data-source-node="n98"><b data-source-node="n99">Minimum Replenishment Threshold Percent</b>: Enter the percentage that triggers replenishment activity.</p>
        <p data-source-node="n100"><b data-source-node="n101">Top Off Minimum Replenishment Threshold Percent</b>: Enter the threshold used for top-off replenishment behavior.</p>
        <p data-source-node="n102"><b data-source-node="n103">Maximum Replenishment Fill Percent</b>: Enter the maximum allowed fill percentage during replenishment.</p>
        <p data-source-node="n104"> </p>
        <p data-source-node="n105">Use Continue to move through each screen and Finish to save the item location capacity configuration.</p>
