Configuring a Scale

You will use this window to configure various settings that define how a scale and the system will communicate with each other. The application requires a separate scale for each packing station. This configuration applies to any user using the machine where the config file is installed. Note that you can use the Delete Configuration Values option (on the Actions Menu) to erase a user's previously-saved configuration values from the system.

Global Button Descriptions...

Apply Button: When the Generate config file setting is unchecked, it saves the data to the individual user’s user.config file (not the registry). When the setting is checked, it generates the config file.

 

OK Button: This button performs the same functions as the Apply Button, except that it will also exit the Scale Configuration Window (unless an error was found).

 

Cancel Button: This button will close the Scale Configuration Window, losing all user changes that were made in the current, unsaved session.

 

 

Setup Steps...

 

NOTE: When the workstation is configured to use RemoteApp or RDP to access a server and run the web browser from there (such as when using virtualization software), the scale must be set up to communicate to the screen via "wedge" software. This is software that takes the output of the device and sends it to the cursor on the screen, as if it were entered on the keyboard. In this situation, the user must have the cursor on the weight field at the time of placing the container on the scale. The Scale configuration is not used at all in this setup.

1. Windows Control Panel

The first step in scale setup is to attach the device to your machine. Most scales are attached to the serial (COM) port located at the back of your computer. You will need check to see if your machine's COM port is currently active. You can do this in the Windows Control Panel. See your Windows help system, your scale manual, or your system consultant for any specific questions on activating COM ports. After plugging in the device, the system will notify you about which COM port is used.

 

2. Connection Properties Tab

For the scale and computer to have a proper connection, you will need to define the scale's technical settings on the Connection Properties Tab.Most of the values you should enter in these fields are in your scale's instruction manual. Ask your system consultant if you have any further questions

  1. Access the Scale Configuration Window (accessed from the desktop), and click on the Connection Properties Tab.
     

  2. Use the COM Port Field to choose the serial port to which you are going to attach your scale.

     

  3. Use the Scale Connection Properties fields to define your serial connection:

     

    • Baud Rate: This field represents the connection speed.

       

    • Bits Per Byte: This field represents the number of bits used to represent the character being transmitted. The receiver (the system) and the transmitter (the scale) must agree on the number of data bits. Almost all devices transmit data using 7 or 8 bits. See the scale manual for the setting for your scale.

       

    • Parity: This field specifies the type of parity to be used on the port connection. Parity is used to detect data corruption during transmission.

       

    • Stop Bits: After a character has been transmitted (in the number of bits defined in the Bits Per Byte Field), a stop bit is sent to signal the end of a packet. This field specifies how many bits will be used to represent this signal.

       

    • EOF Byte: This field represents the character the scale sends at the end of the transmission. Enter the ASCII value of the character in this field.

       

    • Translation Parity: This field specifies the type of parity to be used on the data included in the transmission. While parity detects data corruption during transmission, translation parity converts the bytes read from the port in a useable form.

 

3. Command Strings Tab

Before you can use the scale to perform an action, the system has to tell it what action to perform. You can define this on the Command Strings Tab. Most of the values you should enter in these fields are in your scale's instruction manual. Ask your system consultant if you have any further questions.

  1. Access the Scale Configuration Window (accessed from the desktop), and click on the Command Strings Tab.
     

  2. Use the Command String Field to select which command string you want to define.

     

    • You can use the "Weight" command string to have the scale weigh an item/shipment.

       

    NOTE: The "Status" and "Zero" command strings are reserved for future use.

     

  3. Click the Add Button to append a byte to the end of the command string.

     

  4. Use the Integer Field to indicate the character you want to appear in that position in the command string. Use an ASCII value to represent each character. Each row in the grid represents a position in the command string.

     

    For example, suppose you want to create the following weight command string: W<carriage return>. You would enter the ASCII value 87 in the Integer Field. The system will display its corresponding character value in the Character Field (in this case, a W). Click the Add Button and the system will add another row to the grid. Now enter the value 13 (representing a carriage return) in the Integer Field. The system again displays its corresponding character value in the Character Field (in this case, it is a non-printable character, so it is represented by a generic symbol: a bar).

 

4. Response Strings Tab

This setting defines what information the scale will send back to the system. You can tell the system how and what part of the data string to process. You can define this on the Response Strings Tab. Most of the values you should enter in these fields are in your scale's instruction manual. Ask your system consultant if you have any further questions.

  1. Access the Scale Configuration Window (accessed from the desktop), and click on the Response Strings Tab.
     

  2. Use the Response String Field to select which response string you want to define.

     

    • The "Weight" response string defines the significant positions in the set of bytes in the string that the scale sends to the system.

       

    • The "Unknown" response string is a string that the scale will send to the system when it does not understand the command that the system sent to it.

       

      Use the Integer Field to indicate the character you want to appear in that position in the response string. Use an ASCII value to represent each character. Each row in the grid represents a position in the response string.

       

      For example, suppose you want to create the following response string:

       

      <lf >?<cr><etx>

       

      You would enter the ASCII value 10 in the Integer Field. The system will display its corresponding character value in the Character Field (in this case, it is a non-printable character, so it is represented by a generic symbol: a bar). Click the Add Button and the system will add another row to the grid. Now do the same with the remaining integers: 63, 13, and 3.

       

    NOTE: The "Status" and "Zero" response strings are reserved for future use.

     

  3. Use the Start Position Field and the End Position Field to indicate what characters in the response string the system will recognize as the data you are trying to capture.

     

    For example, when a scale weighs an item, the scale sends back a response string of 16 or more characters, such as the following:

     

    <lf>xxxx.xxuu<cr><lf>hh...<cr><etx>

     

    In the above example, <lf> represents a line feed, <cr> represents a carriage return, <etx> represents the end of transmission character, x represents the numbers of the weight, u represents the units of the weight, and h represents the status of the scale. In this example, the significant positions of the string are the numbers of the weight, so you would enter a "2" in the Start Position Field and an "8" in the End Position Field.

     

    So, if the scale sent back the following string,

     

    <lf>0002.34LB<cr><lf>00<cr><etx>

     

    then the system would recognize the weight in pounds as "2.34".

     

    NOTE: The system assumes that the unit of measure configured for use in the system is the same as the scale's unit of measure.

 

5. Scale Connection Test Tab

Once you are finished configuring your scale, you need to test the scale's settings before using it in production. You can perform this test on the Scale Connection Test Tab.You will need to save the configuration settings on this window before performing a test. Do this by pressing the Apply Button.

 

NOTE: Scale Connection Test Tab is only valid when the Generate config file setting is unchecked.

  1. Access the Scale Configuration Window (accessed from the desktop), and click on the Scale Connection Test Tab.
     

  2. Press the Test Button. The system will begin a test of the scale.

     

    • If the test was successful, the system will display the connection details used in the test and the item's weight in the Scale Connection Test Window. Your scale is now ready for use in production.

       

    • If the test was not successful, the system will display an error message. Review the test results to determine the error in the Scale Connection Test display. To correct the error, try checking your scale connection and the settings you defined in the previous steps. If that does not work, see your System consultant.

       

      WARNING:If there is a configuration problem with the scale, there is a slight possibility that the system might lock up during the test. If this occurs, restart the application and check the settings that you defined in the previous steps before repeating the test.
