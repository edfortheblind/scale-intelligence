
        
        <h1 data-source-node="n56">Warehouse Mobile - Conditional Screen Formatting</h1>
        <p data-source-node="n57">Warehouse Mobile now supports custom-conditioned color styling across all screens. This enhancement allows users to dynamically style visual components based on specific conditions—helping highlight critical information or guide user actions more effectively.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">Conditional screen formatting enables you to:</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">Alert users to important conditions, such as when handling hazardous materials.</p>
            </li>
        </ul>
        <ul data-source-node="n63">
            <li data-source-node="n64">
                <p data-source-node="n65">Emphasize specific screen sections, like changing the background color to red when picking a hazardous item.</p>
            </li>
        </ul>
        <p data-source-node="n66"> </p>
        <h5 data-source-node="n67">Custom Screen Options </h5>
        <p data-source-node="n68">You can apply conditional formatting at both the page level and the field level:</p>
        <p data-source-node="n69"> </p>
        <p data-source-node="n70">Page-Level Customizations</p>
        <ul data-source-node="n71">
            <li data-source-node="n72">
                <p data-source-node="n73">Title bar</p>
            </li>
        </ul>
        <ul data-source-node="n74">
            <li data-source-node="n75">
                <p data-source-node="n76">Verification highlights</p>
            </li>
        </ul>
        <p data-source-node="n77">Entire screen background</p>
        <ul data-source-node="n78">
            <li data-source-node="n79">
                <p data-source-node="n80">Field-Level Customizations</p>
            </li>
        </ul>
        <ul data-source-node="n81">
            <li data-source-node="n82">
                <p data-source-node="n83">Font color for text labels</p>
            </li>
        </ul>
        <ul data-source-node="n84">
            <li data-source-node="n85">
                <p data-source-node="n86">Background, input, and label colors for text boxes</p>
            </li>
        </ul>
        <p data-source-node="n87"> </p>
        <h5 data-source-node="n88">Customize method</h5>
        <p data-source-node="n89"> </p>
        <p data-source-node="n90">Conditional formatting is defined using handlebars within the screen's SRC file. These handlebars allow you to specify dynamic conditions that determine when and how visual changes should be applied.</p>
        <p data-source-node="n91"> </p>
        <p data-source-node="n92">Conditional styling can be applied to individual screenflow steps within a process. For example:</p>
        <ul data-source-node="n93">
            <li data-source-node="n94">
                <p data-source-node="n95">Location verification</p>
            </li>
            <li data-source-node="n96">
                <p data-source-node="n97">Item verification</p>
            </li>
            <li data-source-node="n98">
                <p data-source-node="n99">Quantity verification</p>
            </li>
        </ul>
        <p data-source-node="n100">Each step can have its own unique set of formatting conditions.</p>
        <p data-source-node="n101"> </p>
        <p data-source-node="n102">Note:</p>
        <p data-source-node="n103">The following components cannot be customized:</p>
        <ul data-source-node="n104">
            <li data-source-node="n105">
                <p data-source-node="n106">The bottom bar of the WM screen (where the GO button appears)</p>
            </li>
            <li data-source-node="n107">
                <p data-source-node="n108">The background color of dropdown menus (remains fixed in base light blue)</p>
            </li>
            <li data-source-node="n109">
                <p data-source-node="n110">Modal, popup, and message dialogs, such as:</p>
                <ul data-source-node="n111">
                    <li data-source-node="n112">
                        <p data-source-node="n113">Error messages</p>
                    </li>
                    <li data-source-node="n114">
                        <p data-source-node="n115">Actions menu</p>
                    </li>
                </ul>
            </li>
        </ul>
        <p data-source-node="n116">Note: Color customizations do not automatically adapt to Warehouse Mobile's light or dark themes. Users must manually test and validate your custom styling against each theme to ensure visual consistency and readability.</p>
