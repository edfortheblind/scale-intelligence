        <h4 data-source-node="n390"><a name="actions" data-source-node="n391"></a>Screen Actions (Inventory Insight)...</h4>
        <p data-source-node="n392">	Each of the actions listed can be done for multiple rows at the same time. The following actions are accessible from the List Pane:</p>
        <p data-source-node="n393"> </p>
        <p data-source-node="n394">NOTE: The options Edit, Adjust, Edit attributes, Delete attributes, Finished item breakdown, Immediate needs, and Transfer are not available when a line represents multiple license plates and/or attributes.</p>
        <p data-source-node="n395"> </p>
        <p data-source-node="n396">Notes:</p>
        <ul data-source-node="n397">
            <li data-source-node="n398">The status of allocated inventory can be changed in the shipping and receiving dock.</li>
            <li data-source-node="n399">From the Lot insight screen, user will not be able to perform inventory adjustment/status change/transfer when the updated inventory is linked with inventory attributes.</li>
            <li data-source-node="n400">While editing lot information, user will be able to change status/expiration date. This change will be updated across all inventory records for the item/company/lot in the system.</li>
            <li data-source-node="n401">When a lot controlled item status is changed to Unavailable, then the lot is not frozen when you select multiple lots for the same item. You can use the lot insight screen to freeze the lot.</li>
        </ul>
        <p data-source-node="n402"> </p>
        <h5 data-source-node="n403">Adjust</h5>
        <p data-source-node="n404">The Adjust action when highlighting a row  passes the item and location information into the Inventory adjustment screen. If the row is lot controlled and/or license plate tracked, that information is also passed. </p>
        <p data-source-node="n405"> </p>
        <h5 data-source-node="n406">Company Transfer</h5>
        <p data-source-node="n407">This action enables you to change the company of item from one to another. For more information read <a href="9a643fdf8dfce382a2bb33da573a5e4f12bc2435dd8ad092b52c3a7f8604ecd7.html" data-source-node="n408">Company Transfer</a>.</p>
        <p data-source-node="n409"> </p>
        <h5 data-source-node="n410">Create Count </h5>
        <p data-source-node="n411"> This action allows you to create a cycle count request for the selected row(s) based on the location/item/company/warehouse. If multiple rows are selected, a separate Cycle Count Quick Plan is created for each row selected. The cycle count will be added to a new plan named after the location of the selected row(s).  The “Create Activity Driven &amp; Quick Plan CC Work” cycle count system value setting will determine if the system will create cycle count work.  The system will display a success message to confirm that the cycle count request has been successfully submitted. The system will display an error message in case an error is encountered.</p>
        <p data-source-node="n412"> </p>
        <p data-source-node="n413"> </p>
        <h5 data-source-node="n414">Delete Attributes</h5>
        <p data-source-node="n415">This allows you to delete the Inventory attributes with the attribute ID. This is active if the selected line has existing inventory attributes.</p>
        <p data-source-node="n416"> </p>
        <p data-source-node="n417"> </p>
        <h5 data-source-node="n418">Delete Overrides</h5>
        <p data-source-node="n419">This action allows you to delete overrides for the selected location (s) when Location Unit of Measure overrides exist for the selected location inventory. Upon clicking Yes on the confirmation prompt, you can continue with the deletion process. </p>
        <p data-source-node="n420"> </p>
        <p data-source-node="n421"> </p>
        <h5 data-source-node="n422">Edit</h5>
        <p data-source-node="n423">This action allows you to display and edit the details of an inventory record.</p>
        <p data-source-node="n424"> </p>
        <p data-source-node="n425"> </p>
        <h5 data-source-node="n426">Edit Attributes</h5>
        <p data-source-node="n427">This allows you to display and edit the Inventory attributes with the attribute ID. This is active if the selected line has existing inventory attributes. You can save or cancel the modifications based on your requirement. </p>
        <p data-source-node="n428"> </p>
        <p data-source-node="n429"> </p>
        <h5 data-source-node="n430">Edit Overrides</h5>
        <p data-source-node="n431">This action allows you to create overrides for the selected location. Upon clicking Yes on the confirmation prompt, you can view the Location Unit of Measure screen. The <img src="../source/assets/425c106e7442bd138a4dff6fe676226fb3c48639d490e72a8962ca6484af34e6.png" style="width: 25;height: 25" loading="eager" data-source-node="n432"> icon in the Inventory Insight is displayed when override is created for the location.</p>
        <ul data-source-node="n433">
            <li data-source-node="n434">
                <p data-source-node="n435">If the item present in the location does not have any item unit of measure configured, the Location Unit of Measure defaults from the storage template linked to the item.<br data-source-node="n436"><br data-source-node="n437"></p>
            </li>
            <li data-source-node="n438">
                <p data-source-node="n439">If the item present in the location has an item unit of measure configured, the Location Unit of Measure defaults from the item unit of measure record.<br data-source-node="n440"><br data-source-node="n441"></p>
            </li>
            <li data-source-node="n442">
                <p data-source-node="n443">If the location already has an override based upon the storage template of the item and now the item is linked to a new storage template and item unit of measure is configured for the item,  system will delete the existing override while editing the override and will show the Location Unit of Measure based upon the new item unit of measure for the item.</p>
            </li>
        </ul>
        <p data-source-node="n444">For more information, refer to the topic <a href="960e3e76d1f58fe049ab2754babde577e7e33610f9bc5739836060725f04fcbf.html" data-source-node="n445">Editing/Deleting Location Unit of Measure Overrides</a>. </p>
        <p data-source-node="n446"> </p>
        <p data-source-node="n447"> </p>
        <h5 data-source-node="n448">Finished Item Breakdown</h5>
        <p data-source-node="n449">This action passes the item and location information into the Finished Item Breakdown screen. If the row is lot controlled and/or license plate tracked, that information is also passed. For more information on Finished Item Breakdown, see the <a href="b9ecb2d6cf1c6d3d40a421078c7aa0b4c520a0b00ff3c04caefa84269daa01d3.html" data-source-node="n450">Disassembling a Finished Item</a> topic.</p>
        <p data-source-node="n451"> </p>
        <p data-source-node="n452"> </p>
        <h5 data-source-node="n453">Freeze Lot </h5>
        <p data-source-node="n454"> This action allows you to freeze the specified lot when highlighting a row containing a lot controlled item, provided you have the required authorization to do so. If you select multiple rows and any of the rows does not have a lot controlled item, the action will be disabled. The system will display a success message to confirm that the freeze lot has been successfully submitted. The system will display an error message in case an error is encountered.</p>
        <p data-source-node="n455"> </p>
        <p data-source-node="n456"> </p>
        <h5 data-source-node="n457">Immediate Needs</h5>
        <p data-source-node="n458">This action allows you to select an immediate needs transaction for the Immediate Needs Insights screen. For more information on Immediate Needs, see the <a href="c3bf7cdf689326981fbe4a20a7d35e0dbba65a1ade6ba7ef9ed7316b1db4121d.html" data-source-node="n459">Researching a Warehouse's Immediate Needs</a> topic.</p>
        <p data-source-node="n460"> </p>
        <p data-source-node="n461"> </p>
        <h5 data-source-node="n462">Manual Replenishment</h5>
        <p data-source-node="n463">This action allows you to kick off the manual replenishment 
 process by selecting  which replenishment master(s) 
 you want to execute. For more information on Manual Replenishment, see the <a href="a8270619fa0a5e16d5c02c9e3547bbc106b879dc15a37b2ce23c7de96d18b9a6.html" data-source-node="n464">Manual Replenishment</a> topic.</p>
        <p data-source-node="n465"> </p>
        <p data-source-node="n466"> </p>
        <h5 data-source-node="n467">Mark for Replenishment</h5>
        <p data-source-node="n468">This action enables you to choose replenishment requests to be marked as eligible for replenishment. The system will then evaluate the location for replenishment the next time the real-time replenishment scheduled job runs. Note that this action is only enabled for locations eligible for real-time replenishment.   If you select multiple rows and any of the rows is not set up for real-time replenishment, the action will be disabled. </p>
        <p data-source-node="n469"> </p>
        <h5 data-source-node="n470">Status Change</h5>
        <p data-source-node="n471">This action enables you to change the  status of one or more inventory records. For more information on Status change, see the <a href="4ecf7f6c2c49c10dae6f034177793deac8c7a9f937bf165c81c9588dceae82b9.html" data-source-node="n472">Inventory status change</a>  topic.</p>
        <p data-source-node="n473"> </p>
        <h5 data-source-node="n474">Transfer</h5>
        <p data-source-node="n475">This action enables you to transfer one or more inventory records. The transfer of inventory records with lot controlled and/or license plate tracked information is also supported.</p>
        <h6 data-source-node="n476">Multi-select inventory record transfer</h6>
        <p data-source-node="n477">This action enables you to transfer multiple inventory records to a single location. The inventory transfer with or without work adjustment type is supported.</p>
        <p data-source-node="n478"> </p>
        <p data-source-node="n479">Follow the steps to perform Inventory transfer</p>
        <ul data-source-node="n480">
            <li data-source-node="n481">In the Inventory Insight screen, select multiple inventory records.</li>
            <li data-source-node="n482">Click <b data-source-node="n483">Actions &gt;&gt; Transfer </b> to view the <b data-source-node="n484">Inventory Transfer</b> screen</li>
            <li data-source-node="n485">Select the <b data-source-node="n486">Adjustment Type</b> from the drop down list.</li>
            <li data-source-node="n487">Enter the <b data-source-node="n488">To location</b>. Also you can use the search feature to find a location.</li>
            <li data-source-node="n489">Click <b data-source-node="n490">Transfer</b> and success message is displayed. Success and validation error message for all the inventory transfer is displayed in the screen.</li>
        </ul>
        <p data-source-node="n491">Also perform locate and inventory transfer in the <b data-source-node="n492">Inventory transfer</b> screen. User can select one or more records for inventory transfer in the <b data-source-node="n493">Inventory Insight</b> screen.</p>
        <ul data-source-node="n494">
            <li data-source-node="n495">Click <b data-source-node="n496">Actions &gt;&gt; Locate.</b></li>
            <li data-source-node="n497">In the <b data-source-node="n498">Select a locating rule</b> pop-up, enter the <b data-source-node="n499">locating rule</b> in the text box.</li>
            <li data-source-node="n500">Click <b data-source-node="n501">Locate</b>. The system will locate and transfer the selected records.</li>
        </ul>
        <p data-source-node="n502">Significance of color coded Validation messages</p>
        <ul data-source-node="n503">
            <li data-source-node="n504">When we have all the selected record is successful - Green</li>
            <li data-source-node="n505">When we have partial success in transfer of selected records. - Orange</li>
            <li data-source-node="n506">When all the selected records have failed - Red</li>
        </ul>
