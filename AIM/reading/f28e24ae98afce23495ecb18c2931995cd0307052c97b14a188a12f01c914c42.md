
        
        <h1 data-source-node="n56"><a name="kanchor1191" data-source-node="n57"></a>Device Name Field</h1>
        <p data-source-node="n58">The name of a print device record. This value 
 is defined on the Print Device Window. A print device record identifies 
 the printer that will produce documents for the system. Later, you will 
 associate the print device record with the appropriate documents on the 
 Document Routing Window.</p>
