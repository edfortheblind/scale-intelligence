
        
        <h1 data-source-node="n56"><a name="kanchor1003" data-source-node="n57"></a>Rendered Document PDF File Directory Field</h1>
        <p data-source-node="n58">This field indicates where you want SQL Server Reporting Services to place rendered (created).<i data-source-node="n59">pdf</i> files. Note that these .<i data-source-node="n60">pdf</i> files are not automatically deleted from this directory after they are printed by the default PDF reader application.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">This field is present in the Warehouse and Document Type Configurations. The appending of the Document Type path onto the Warehouse path determines the full path to the PDF file directory.  For example, if the warehouse path is \\Localhost\ILS\Reporting\SSRS and the document type path is Allocation Pick List, the full path used would be \\Localhost\ILS\Reporting\SSRS\Allocation Pick List when printing an Allocation Pick List.  </p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64">NOTE: A blank document type path prints the document using the warehouse path.  If the warehouse path is blank, then the document type has to be a valid path.</p>
