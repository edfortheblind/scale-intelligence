
        
        <h1 data-source-node="n56"><a name="kanchor448" data-source-node="n57"></a>License Plate Selection Method Buttons</h1>
        <h5 data-source-node="n58">On the Work Special Handling Window (Cycle Count Tab)</h5>
        <p data-source-node="n59">Use these buttons  to indicate how you want to initiate license plate cycle counts:</p>
        <blockquote data-source-node="n60">
            <p data-source-node="n61">- System Initiated: This indicates that the system will tell the user the order of the license plates that they are required to cycle count.</p>
            <p data-source-node="n62"> </p>
            <p data-source-node="n63">- User Initiated: This indicates that the user will be able to specify which license plate that they want to count.</p>
        </blockquote>
