
        
        <h1 data-source-node="n56"><a name="kanchor993" data-source-node="n57"></a>Treat As Loose In Container Creation Checkbox</h1>
        <p data-source-node="n58">This setting indicates that this unit of measure should be 
 treated as a "loose" piece. During container creation, the system 
 will check this setting to determine if this particular UM is a full container 
 unit of measure, or if it should be packed as a loose piece.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: The system will only use this value from the shipment line (in the manner described above) if no item unit of measure records for that item or item class exist. </p>
