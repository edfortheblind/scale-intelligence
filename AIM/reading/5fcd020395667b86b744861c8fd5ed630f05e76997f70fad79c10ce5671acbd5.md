
        
        <h1 data-source-node="n56">Shipment Selection Screen</h1>
        <p data-source-node="n57">The system displays this window during a transaction when you provide 
 a shipment ID that is associated with multiple shipments. You can use 
 the criteria provided on the window to identify which shipment you want 
 to use. The Shipment Selection Screen displays the list of all the shipments with the same shipment ID. This window can be accessed from the Transfer Container Screen.</p>
