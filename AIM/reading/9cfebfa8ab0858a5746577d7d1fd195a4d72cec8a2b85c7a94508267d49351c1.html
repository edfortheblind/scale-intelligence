Defining RF Screen Properties

The system allows you to modify the basic screen properties of an RF device, such as font, screen size, or screen position. These settings will determine how the system RF system is displayed on your RF devices. You can modify these values by editing certain resource file keys, which begin with the prefix RF_STD. You will perform this action on the System Text Editor Window.

 

 

Procedures...

  1. Access the System Text Editor Window.
     
  2. Choose "Text" from the Group Field.
     
  3. Enter one of the following values into the Key Field and press the Search Button. The system will display the appropriate resource file key:

    - RF_PROCIMG: This value determines the graphic that is displayed when the system is busy processing on the RF system.   

    - RF_PROCIMGHEIGHT: This value determines the height of the RF system processing graphic.  

    - RF_PROCIMGWIDTH: This value determines the width of the RF system processing graphic.

    - RF_STDFONT: This value determines the font that you want the system to use when displaying text on the RF.

    - RF_STDFONTSIZE: This value determines the size of the font that you want the system to use when displaying text on the RF.

    - RF_STDIMGLEFTPOS: This value determines the position of the RF processing graphic from the left side of the RF Screen in pixels.

    - RF_STDIMGTOPPOS: This value determines the position of the RF processing graphic from the top of the RF Screen in pixels.

    - RF_STDPAGEHEIGHT: This value determines the RF screen's height in pixels.

    - RF_STDPAGEWIDTH: This value determines the RF screen's width in pixels.
     
  4. When finished reviewing/editing these values, you will need to commit the resources.. See the topic Using the System Text Editor for information on these procedures.
