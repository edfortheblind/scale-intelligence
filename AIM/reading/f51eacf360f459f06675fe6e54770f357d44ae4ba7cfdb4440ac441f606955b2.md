
        
        <h1 data-source-node="n56"><a name="kanchor498" data-source-node="n57"></a>Original File Path Field</h1>
        <h5 data-source-node="n58">On the Interface Error Insight Screen / Interface Validation Warehouse Alerts...</h5>
        <p data-source-node="n59">This field indicates the directory path where the original data file that was interfaced from the ERP is now located. When a data validation error occurs with the download interface process, the system places this file (with its original file extension) in a subdirectory of the <i data-source-node="n60">Interface/Output</i> directory (as defined in the Interface System Values Window).</p>
