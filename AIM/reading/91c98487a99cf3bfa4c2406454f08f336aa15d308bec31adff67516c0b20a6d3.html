Searching/Viewing Work Order Records...

You can use the Work Order License Plate Insight Screen to search for and view work order records in your warehouse.

  1. Open the Work Order License Plate Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

  • The Work Order License Plate Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

The Work Order License Plate Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

The Detail Pane of Work Order License Plate Insight contains Indicator Tiles with counts of the other entities (i.e. open work, and transactions). If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following:

  1. Open Work

    1. Displays the number of open or in process work for the selected license plate.

    2. Clicking on this tile takes you to Work Insight filtering on the work order license plate and work order number for Work Order Putaway work.

     

  2. Transactions

    1. Displays the number of Pick & Put Confirmation transactions for the selected license plate.

    2. Clicking on this tile takes you to Transaction History Insight filtering on the license plate and item for the Pick & Put Confirmation transactions.


For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

Screen Actions

The following actions are accessible from the List Pane:

 

View/Edit

The View action allows you to open the Work Order License Plate Insight screen in the read-only mode and the Edit action allows you to open the Work Order Insight screen in the edit mode. So the View action only permits viewing the work order license plates, while the Edit action permits editing certain fields on the work order license plates.

 

 

Print Preview

This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to Printing Paperwork.

 

 

Print Default Docs

This action helps you to print the work order documents (Work Order Finished Items Putaway List) which are marked as default in the Document type.

 

 

Print Selected Docs

This action allows you to select or unselect the work order documents (Work Order Finished Items Putaway List) you want to print. If the document is checked as default in the Document type configuration, this document will also be checked in the Print selected window.
