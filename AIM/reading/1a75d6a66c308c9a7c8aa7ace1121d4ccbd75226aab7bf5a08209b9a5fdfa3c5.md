
        
        <h1 data-source-node="n56">Identifying Quality Measure Reason Codes</h1>
        <p data-source-node="n57">If a work instruction was not processed as anticipated, the system will 
 require you to associate a reason code with the instruction record. A 
 reason code identifies if an instruction was completed or why it was not 
 completed. Reason codes are commonly required when product is short picked, 
 the picking location is empty, or other circumstances inhibit you from 
 processing the work.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">WARNING: If you choose the wrong reason code, once you press OK, the system 
 will assign this code to the work instruction and write a history record.  You cannot undo this action. 
 However, processing of this instruction will not be adversely affected 
 by choosing the wrong reason code.</p>
