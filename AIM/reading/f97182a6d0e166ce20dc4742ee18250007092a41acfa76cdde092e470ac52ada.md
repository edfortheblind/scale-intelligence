
        
        <h1 data-source-node="n56"><a name="kanchor1549" data-source-node="n57"></a>Using the Quality History Insight Screen</h1>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">
            <p data-source-node="n60">You can use the Quality History Insight screen to search and manage quality records in your warehouse. If a record has not been processed as anticipated, the system will require you to associate a reason code with the record. A reason code identifies whether a task has been completed and reason for anomaly, if any. Examples of quality history reason codes are Region Does Not Exist, and Task Cannot Be Found. </p>
        </p>

        </ul>

        <h4 data-source-node="n182"><a name="Searching" data-source-node="n183"></a>Searching/Viewing Quality History Records...</h4>
        <p data-source-node="n184">You can use the Quality History Insight Screen to search for and view quality records in your warehouse. </p>
        <ol data-source-node="n185">
            <li value="1" data-source-node="n186">Open the Quality History Insight Screen.<br data-source-node="n187"><br data-source-node="n188"></li>
            <li value="2" data-source-node="n189">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n190"><br data-source-node="n191"></li>
            <li value="3" data-source-node="n192">Press the Apply Filter Button. The system will display  the resulting records in the List Pane.<br data-source-node="n193"> <br data-source-node="n194"></li>
            <li value="4" data-source-node="n195">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>

        <h4 data-source-node="n200"><a name="AboutList" data-source-node="n201"></a>About the List Pane</h4>
        <ul data-source-node="n202">
            <li data-source-node="n203">The Quality History Insight Screen's List Pane displays the results from a query performed in the Filter Pane.<br data-source-node="n204"><br data-source-node="n205"></li>
            <li data-source-node="n206">For more general information about the List Pane, see the topic <a href="444e9b8e14a977178c9ff48b972dd65c076a4adda44c3dfacddf94a4a6c24d22.html" data-source-node="n207">Introduction to Insight Screens</a>.</li>

        <h4 data-source-node="n212"><a name="AboutDetail" data-source-node="n213"></a>About the Details Pane...</h4>
        <ul data-source-node="n214">
            <li data-source-node="n215">The Quality History Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.<br data-source-node="n216"><br data-source-node="n217"></li>
            <li data-source-node="n218">The Detail Pane of Quality History Insight contains header fields comprising of Internal ID, Work Type, and Reason Code Description. You can click on the hyperlink of the Internal ID field to open the corresponding Quality History Details screen.<br data-source-node="n219"><br data-source-node="n220"></li>
            <li data-source-node="n221">For more general information about the Detail Pane, see the topic <a href="444e9b8e14a977178c9ff48b972dd65c076a4adda44c3dfacddf94a4a6c24d22.html" data-source-node="n222">Introduction to Insight Screens</a>.</li>
