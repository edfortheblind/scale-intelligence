Making an Item Eligible For Immediate Needs

For the system to alert the user of the immediate needs of a rejected entity (shipment, receipt, or work order), you must first activate the item(s) that you want the system to track immediate needs for. Note that components and finished items associated with the "Add BOM Component Lines" wave step are ineligible for immediate needs processing. You can complete this step on the Handling (1) Tab of the Item Window.

 

 

To Make an Item Eligible...

Access the Item Window. Open the item you wish to make eligible for immediate needs.

  1. Access the Handling (1) Tab.
     
  2. Use the Eligible Checkbox to indicate that you want this item to be made eligible for immediate needs processing.
     
  3. Use the Locating Rule Field to identify the rule you want the system to use when locating quantity of this item to fulfill immediate needs.
     
  4. Press OK. The system will save your changes.
