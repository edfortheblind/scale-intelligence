
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">Work Zone Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Work Zone configuration defines warehouse work zones used by work assignment and execution logic. You can create and maintain work zone records, then associate one or more work profiles to each zone.</p>
        <p data-source-node="n61"><b data-source-node="n62">Note</b>: This configuration is currently accessible only from the Location Configuration wizard and is not available as a standalone configuration outside the wizard.</p>
        <h4 data-source-node="n63"> </h4>
        <h4 data-source-node="n64">Configure Work Zone</h4>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">1. Work Zone</h5>
        <p data-source-node="n67"> </p>
        <p data-source-node="n68">Select or create a Work Zone record.</p>
        <ul data-source-node="n69">
            <li data-source-node="n70">
                <p data-source-node="n71"><b data-source-node="n72">Create New</b>: Create a new work zone record.</p>
            </li>
            <li data-source-node="n73">
                <p data-source-node="n74"><b data-source-node="n75">View All</b>: Review and select an existing work zone record.</p>
            </li>
            <li data-source-node="n76">
                <p data-source-node="n77"><b data-source-node="n78">Current Selection</b>: Displays the selected work zone record.</p>
            </li>
        </ul>
        <p data-source-node="n79"> </p>
        <h5 data-source-node="n80">A. Information</h5>
        <p data-source-node="n81"> </p>
        <p data-source-node="n82"><b data-source-node="n83">Zone</b>: Enter the work zone identifier.</p>
        <p data-source-node="n84"><b data-source-node="n85">Description</b>: Enter the work zone description.</p>
        <p data-source-node="n86"><b data-source-node="n87">Cart Building Work Sequence</b>: Enter the sequence value used for cart-building work processing.</p>
        <p data-source-node="n88"> </p>
        <h5 data-source-node="n89">B. Work Profiles</h5>
        <p data-source-node="n90"> </p>
        <p data-source-node="n91">Select one or more work profiles that will be applied to this work zone.</p>
        <ul data-source-node="n92">
            <li data-source-node="n93">
                <p data-source-node="n94"><b data-source-node="n95">All / None</b>: Select or clear all work profiles.</p>
            </li>
            <li data-source-node="n96">
                <p data-source-node="n97"><b data-source-node="n98">Show Selected</b>: Filter the list to selected profile values.</p>
            </li>
            <li data-source-node="n99">
                <p data-source-node="n100"><b data-source-node="n101">Search</b>: Find profiles by name before selection.</p>
            </li>
        </ul>
        <p data-source-node="n102"> </p>
        <p data-source-node="n103">Use Back, Save, Continue, and Finish to manage and complete Work Zone configuration.</p>
