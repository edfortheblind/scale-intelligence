        <h4 data-source-node="n63">Summary...</h4>
        <p data-source-node="n64">If you do not want to interface item records from your ERP system, you can define 
 them in SCALE. By defining an item in the system, you can manage how its 
 processed, what allocation and locating rules are applied to it, and what 
 handling controls (lot-controlled, serial number-tracked, etc) are required 
 during processing. Item setup is optional. If you do not want to create 
 records on the Item Window, the system will reference the item values 
 defined on the shipment line records. An item record identifies a product's 
 unique characteristics, such list price, department, style and size. If 
 your warehouse supports multi-company processing, you can identify the 
 company on each item record.</p>

        <h4 data-source-node="n77">Item Templates...</h4>
        <p style="font-size: 11pt" data-source-node="n78">The system supports item templates, which you can use to define the 
 structure of an item ID. An item template can also include a separator character. 
 </p>
        <p data-source-node="n79"> </p>
        <p data-source-node="n80"> </p>
        <p data-source-node="n81"> </p>
        <h4 data-source-node="n82">Item Unit of Measure...</h4>
        <p data-source-node="n83">An item's unit of measure (UM) identifies the storage container used 
 to move product through the warehouse. The system uses this information 
 to calculate how much product can fit in a location based on its UM breakdown. 
 Common examples of UMs include cases, pallets, eaches and inner packs. You can view the item's UM from the Movement Class Analysis Insight Screen and you can research on the movement class data (per item/company/location/warehouse) for each unit of measure for that item combination.</p>
        <p data-source-node="n84"> </p>

        <h4 data-source-node="n98">Alternate/Substitute Items...</h4>
        <p data-source-node="n99">You can associate alternate or substitute item(s) to an item master. 
 An alternate item is an item that the system will assign to an order if 
 the original item ordered is no longer available (because it is obsolete, 
 out of season, etc). A substitute item is an item that the system will 
 assign to an order if the original item ordered is no longer in stock 
 in the warehouse.</p>
        <p data-source-node="n100"> </p>

        <h4 data-source-node="n103">Item Cross References...</h4>
        <p data-source-node="n104">You can create an item cross-reference record for any item defined in 
 the application. A cross-reference number is established to identify an 
 item's UPC or EAN-14 number. A user processing an item can use either 
 the item number or the cross-reference number to identify it during SCALE processing.</p>
