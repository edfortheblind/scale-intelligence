FNC1 Separator Field

This field indicates what character you want the system to use to divide segments on a barcode. This separator can be any alphanumeric, ASCII, or non-printable character, and is required.

- The default/standard GS1 separator is ASCII value 29 (a non-printable character). This should be sufficient for most situations.

- Note that if you define a printable character as a separator, then it will appear in the human readable portion of the barcode/label.

- The FNC1 separator is only placed at the end of a variable length AI when it is not the last AI in the barcode.
