
        
        <h1 data-source-node="n57"><a name="kanchor601" data-source-node="n58"></a>Replenishment Type Field</h1>
        <p class="p_1" data-source-node="n59">You will use this field to define when 
 the system will attempt to replenish products:</p>
        <ul data-source-node="n60">
            <li data-source-node="n61"><i data-source-node="n62">Item Location Capacity</i>: Use this type if you want to generate replenishment 
 requests based on location need. This replenishment type is often used to replenish forward 
 locations depleted during by an earlier work crew. Note that this replenishment type uses the "Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.<br data-source-node="n63"><br data-source-node="n64"></li>
            <li data-source-node="n65"><i data-source-node="n66">Top-Off Item Location Capacity</i>: Use this type if you want to generate replenishment 
 requests based on location need. Note that this replenishment type uses the "Top-Off Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.<br data-source-node="n67"><br data-source-node="n68"></li>
            <li data-source-node="n69"><i data-source-node="n70">Demand From Pool</i>: Use this type if 
 you want to generate replenishment requests for shipments in the pool. This type of replenishment allows you to prepare for 
 upcoming demand. Note that this replenishment type uses the "Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.<br data-source-node="n71"><br data-source-node="n72"></li>
            <li data-source-node="n73"><i data-source-node="n74">Demand From Wave</i>: Use this type if you want to generate replenishment 
 requests for shipments in a wave.     Note that you cannot choose this type if you plan to run manual replenishment. Note that this replenishment type uses the "Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.<br data-source-node="n75"><br data-source-node="n76"></li>
            <li data-source-node="n77"><i data-source-node="n78">Demand From RF Outbound Short Pick</i>: Use this type if you want the system will run replenishment based on item demand from a location that has been short picked (if the user is configured to allow this via their work special handling settings). Note that this replenishment type does not allow you to configure for this master the Create Work Method (it is always set to automatic), the Replenishment Criteria (since the item and location are already known to the system), or the Replenishment Modes. Note that this replenishment type uses the "Minimum Replenishment Threshold" value (defined on the item location capacity record) during processing.</li>
        </ul>
