Using the Shipped Lot Insight Screen

You can use the Shipped Lot Insight Screen to identify where certain lots have been shipped from your warehouse. The system will retrieve this data from lots that are associated with shipping containers that have already been processed and sent to the customer (in other words, the shipment header's trailing status is greater than or equal to 900). The information gathered from this screen is helpful if, for example, you want to research lots that are part of product recalls. Note that the system will retrieve data for this window from both active and archived database tables.

Searching/Viewing Shipped Lot Records...

  1. Open the Shipped Lot Insight screen.

  2. Use the Basic Criteria fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Filter Button. The system will display the resulting records in the List Pane.

    - You can use the hyperlinks on the List Pane grid to access details about lot and related records.
