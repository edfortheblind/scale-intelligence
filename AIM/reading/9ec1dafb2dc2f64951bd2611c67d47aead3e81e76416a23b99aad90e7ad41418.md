
        
        <h1 data-source-node="n56"><a name="kanchor1180" data-source-node="n57"></a>Search Text Field</h1>
        <p data-source-node="n58">This field is displayed on the System Text 
 Editor Window. If you enter a value in this field, the system will display 
 only those base and custom values that contain this value. For example, 
 if you enter Item as your search text value, the window's record list 
 will only display those base and custom fields that contain the word Item.</p>
