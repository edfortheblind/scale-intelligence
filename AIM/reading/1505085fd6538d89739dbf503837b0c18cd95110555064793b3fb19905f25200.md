
        
        <h1 data-source-node="n56"><a name="kanchor643" data-source-node="n57"></a>Trigger Type Field</h1>
        <p data-source-node="n58">This field to indicate how a Billing Management trigger will be activated.</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60">When In-Line 
 is selected, the trigger will activate automatically when an event 
 (such as closing a shipping load) occurs in the system. In-line triggers 
 include events that are embedded in the system functional flow, such as 
 Packing or Receiving. To use this type of trigger, you first have to activate 
 it, and then when a particular event happens, the system will send the 
 data resulting from the trigger to Billing Management. No further user 
 intervention is required.<br data-source-node="n61"> </li>
            <li data-source-node="n62">When Manual is 
 selected, the user will have to manually activate a trigger via 
 the Billing Management Manual Generation Window. Manual triggers include 
 any events that are unrelated to a functional event, such as the storage 
 snapshot trigger. To use this type of trigger, you would access the Billing 
 Management Manual Generation Window and select the appropriate trigger. 
 The system will then send the data resulting from the trigger to Billing 
 Management.</li>
        </ul>
