
        
        <h1 data-source-node="n56"><a name="kanchor1636" data-source-node="n57"></a>Always Send Results Checkbox</h1>
        <h5 data-source-node="n58">For 
 Personal Alerts...</h5>
        <p data-source-node="n59">Select this checkbox if you want the system to send personal alert emails 
 regardless if a query's data has changed since the last scheduled job 
 was run. If this checkbox is not selected, the system will only send an 
 email when a query returns "new" results.</p>
