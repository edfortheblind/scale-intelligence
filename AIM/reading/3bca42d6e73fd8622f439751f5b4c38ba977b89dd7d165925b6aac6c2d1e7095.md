
        
        <h1 data-source-node="n56"><a name="kanchor1474" data-source-node="n57"></a>All Locations Checkbox</h1>
        <p data-source-node="n58">Select this checkbox if you want to apply a new inventory status to 
 all existing quantities of an item, including all location(s) in the warehouse 
 that contain this item. Note that you will also need to enter an "origin" 
 location to perform this action, which simply represents one location 
 that currently contains this item.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">When using this setting, all locations with the item/company/lot specified will be updated.  Note that you can only perform status changes on locations that do not have allocated quantities. In addition, status updates do not affect inventory at shipping dock locations.</p>
