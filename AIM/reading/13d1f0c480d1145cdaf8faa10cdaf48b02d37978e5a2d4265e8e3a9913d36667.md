        <p data-source-node="n58">The operand field defines the relationship 
 between an attribute and a value. They are primarily used to create rule sets on filter data
 configuration windows.</p>

Suppose then, using the anchoring processing, a container (associated with the carrier UPS) arrives at an empty dock area. Now, only containers that are associated with UPS can be anchored at that dock location. However, when those UPS containers are moved from the dock area (and it becomes empty), the dock area can accept any carrier's container (the "matches" anchoring would start again when a dock area houses its next container).</p>
