
        
        <h1 data-source-node="n56"><a name="kanchor239" data-source-node="n57"></a>Multi-Language Support Process Summary</h1>
        <p data-source-node="n58"><b data-source-node="n59">** Functionality **</b>
        </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h4 data-source-node="n62">Summary...</h4>
        <p data-source-node="n63">SCALE can support multiple languages other than the base language of English. This can be configured at the network user level so that each warehouse employee can work with the system in the language that they speak. </p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65"> </p>
        <p data-source-node="n66"> </p>

        <p data-source-node="n77">The following are key features of the multi-language support functional area:</p>
        <p data-source-node="n78"> </p>
        <h4 data-source-node="n79">Resource Files...</h4>
        <p data-source-node="n80">Resource files determine what text the system displays on application windows. In order to view the system in multiple languages, you first will need to acquire a translated version of the resource files (if they are not already available in the system). You will need to have these files (which use a *.trp extension) translated to the appropriate language in order for the system to display text in this language. You can use the System Text Editor's Translation Wizard to import/export resources values to/from the system, and then translate these resources yourself manually, or outsource them to a translation vendor.</p>
        <p data-source-node="n81"> </p>
        <p data-source-node="n82">The language that the system chooses to use is governed by a setting on the current user's Microsoft Windows operating system regional setting (in the Control Panel). SCALE will use the resource file for the language that the operating system is currently using to display text. </p>
        <p data-source-node="n83"> </p>
        <p data-source-node="n84"> </p>
        <p data-source-node="n85"> </p>
        <h4 data-source-node="n86">Language Change on Server-Client Machine...</h4>
        <p data-source-node="n87">When you implement a language change on a server or client machine, all screens accessed from the remote desktop system menu (such as configurations, etc) will display this new language in field names, window titles, system-supplied records, error messages, and any other text that the system generates. The language used by the application is determined by the Windows user's language setting, NOT by a setting in SCALE. Therefore, you can have users who speaking different languages using the same system application server. For all other screens, the language used by the application is determined by your internet browser's language. </p>
        <p data-source-node="n88"> </p>
        <p data-source-node="n89"> </p>
        <p data-source-node="n90"> </p>
        <h4 data-source-node="n91">Language Change on RF Devices...</h4>
        <p data-source-node="n92">When you implement a language change on an RF device, all the RF screens will display this new language in field names, window titles, error messages, and any other text that the system generates. You can change the language that the system uses to display text on the RF device on the device itself, regardless of what language setting is currently being used on the SCALE application server.</p>
        <p data-source-node="n93"> </p>
        <p data-source-node="n94"> </p>
        <p data-source-node="n95"> </p>
        <h4 data-source-node="n96">Language Change on TPM Website...</h4>
        <p data-source-node="n97">When you implement a language change on the TPM website, all web screens will display this new language in field names, window titles, error messages, and any other text that the system generates. A web user, however, cannot change the language that the system uses to display text on web screens. TPM uses the language setting that is defined on the server (via the Web User Window) which hosts the website.</p>
        <p data-source-node="n98"> </p>
        <p data-source-node="n99"> </p>
        <p data-source-node="n100"> </p>
        <h4 data-source-node="n101">Online Help System...</h4>
        <p data-source-node="n102">The application was built to allow you to use multiple versions of the help system as well. Currently, Manhattan ships the system with an English version of the help system. To obtain another language's version of the help (if not already available with the system), you must work with your consultant to get the help topics translated into your desired language. Usually this would be done by outsourcing this to an outside translation company.</p>
        <p data-source-node="n103"> </p>
        <p data-source-node="n104">When a user accesses the system online help, the system will check to see what language is defined on the regional settings of their Windows network user. It then checks to see if this user's defined language (say it is Spanish) has a help folder that corresponds with it. This Spanish help folder (located in the help directory on the system application server) would be titled with the Spanish language code ("es-MX"). If the system finds that folder, it will display the "Spanish-Mexico" translated help system. If it does not find this folder, the system will load the "base" help system files, which will typically be the English language files.</p>
        <p data-source-node="n105"> </p>
        <p data-source-node="n106"> </p>
        <p data-source-node="n107"> </p>
        <h4 data-source-node="n108">Translation Wizard...</h4>
        <p data-source-node="n109"><span style="font-size: 10pt" data-source-node="n110">You can use the Translation Wizard to assist you in implementing language translations with SCALE. The wizard's screens help you perform actions that are related to translating SCALE resources into different languages, such as export/import resource values to/from the SCALE database, and copy existing values to a spreadsheet in order to create a new language file. You can access the Translation Wizard from the System Text Editor Window.</span>
        </p>
