
        
        <h1 data-source-node="n56"><a name="kanchor1438" data-source-node="n57"></a>Reviewing Location Statuses</h1>
        <p data-source-node="n58">A location status identifies the state of a location to the system. 
 When you define a location, it should be assigned either the status empty 
 or frozen. The system uses location statuses during work creation to manage 
 the flow of goods through locations. The system will update a location's 
 status if it changes during processing.</p>

        <h4 data-source-node="n83">Default Location Statuses...<br data-source-node="n84"></h4>
        <p data-source-node="n85"> </p>
        <h5 data-source-node="n86">Empty</h5>
        <p data-source-node="n87">- There is no inventory 
 stored in this location. When you create a new location, you will assign 
 it this status, unless you assign it product immediately.</p>
        <p data-source-node="n88"> </p>
        <p data-source-node="n89"> </p>
        <h5 data-source-node="n90">Frozen</h5>
        <p data-source-node="n91">- The system will 
 not allocate or locate in this location.</p>
        <p data-source-node="n92">- This status must be manually 
 assigned from the Location Window.</p>
        <p data-source-node="n93">- You can perform Inventory 
 Management tasks to frozen inventory, if the Allow Frozen Checkbox on 
 the Adjustment Type Window is selected.</p>
        <p data-source-node="n94">- Note that manual actions (such as overriding locations) are allowed.</p>
        <p data-source-node="n95"> </p>
        <p data-source-node="n96"> </p>
        <h5 data-source-node="n97">Picking</h5>
        <p data-source-node="n98">- When one or more 
 units are physically picked from a location, the system changes its status 
 from Storage to Picking. The location will remain in the Picking status 
 until either its entire inventory is picked or you manually change it 
 to Frozen.</p>
        <p data-source-node="n99"> </p>
        <p data-source-node="n100"> </p>
        <h5 data-source-node="n101">Storage</h5>
        <p data-source-node="n102">- When product 
 is allocated to a location and physically putaway, the system changes 
 the location's status from Empty to Storage. This status identifies that 
 product has been stored in the location.</p>
