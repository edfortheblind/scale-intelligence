
        
        <h1 data-source-node="n56">Using Warehouse Mobile - Close Container</h1>
        <p data-source-node="n57">The Warehouse Mobile close container enables workers with hand held device to easily close containers on the shipping dock and quickly get them ready to be shipped from the warehouse. The close container process involves advancing a container’s status, as well as optionally (based on your packing preference settings) auto manifesting, auto printing, and assigning the container's shipment to a load. Basically, a closed container indicates that the packing process is complete. Also, a document/label will be printed upon closing the last container when the Close Last Container print procedure has been selected on the paperwork’s document type.</p>

        <h4 data-source-node="n80"><a name="Close" data-source-node="n81"></a>Close Container screen</h4>
        <p data-source-node="n82">Enables user to close containers on the shipping dock in the warehouse.  </p>
        <p data-source-node="n83"> </p>
        <h5 data-source-node="n84">Closing a container with the calculated weight</h5>
        <p data-source-node="n85">Follow the steps to close a container based on the weight calculated by the system.</p>
        <ol data-source-node="n86">
            <li value="1" data-source-node="n87">Tap <b data-source-node="n88">Close Container</b> to view <b data-source-node="n89">Close Container</b> screen.</li>
            <li value="2" data-source-node="n90">Enter or scan the <b data-source-node="n91">Container ID</b>.</li>
            <li value="3" data-source-node="n92">In close container screen, the <b data-source-node="n93">Container ID</b>, <b data-source-node="n94">System Weight</b> and <b data-source-node="n95">Actual Weight</b> information is populated.</li>
            <li value="4" data-source-node="n96">Tap <b data-source-node="n97">Go</b>. to view the confirmation message as  <b data-source-node="n98">Container is Closed</b>. No need to enter the actual weight value in this senario.</li>
        </ol>
        <h5 data-source-node="n99">Closing a container by entering the actual weight</h5>
        <p data-source-node="n100">Follow the steps to close a container based on the weight calculated by the system.</p>
        <ol data-source-node="n101">
            <li value="1" data-source-node="n102">Tap <b data-source-node="n103">Close Container</b> to view <b data-source-node="n104">Close Container</b> screen.</li>
            <li value="2" data-source-node="n105">Enter or scan the <b data-source-node="n106">Container ID</b>.</li>
            <li value="3" data-source-node="n107">In close container screen, the <b data-source-node="n108">Container ID</b>, <b data-source-node="n109">System Weight</b> and <b data-source-node="n110">Actual Weight</b> information is populated.</li>
            <li value="4" data-source-node="n111">You can enter the <b data-source-node="n112">Actual Weight</b> in the text box. On entering the Actual Weight value is displayed in Close Container screen.</li>
            <li value="5" data-source-node="n113">Tap <b data-source-node="n114">Go</b>. to view the confirmation message as  <b data-source-node="n115">Container is Closed</b>. </li>
        </ol>
        <h4 data-source-node="n116"><a name="Notes" data-source-node="n117"></a>Notes:</h4>
        <ul data-source-node="n118">
            <li data-source-node="n119">Entering a valid container ID system will retrieve the appropriate weight value and display it on the screen as System and Actual Weight values. In case the actual weight is different, enter the same in the Actual Weight text box</li>
            <li data-source-node="n120">Total weight for shipping is calculated as Weight of container type + Weight of Items in container.</li>
            <li data-source-node="n121">When you close the container, system will validate as to whether the container's weight is within the defined tolerance.</li>
            <li data-source-node="n122">If the weight is exceeding the tolerance limit, then it prompts the user to confirm the value to close the container.</li>
        </ul>
