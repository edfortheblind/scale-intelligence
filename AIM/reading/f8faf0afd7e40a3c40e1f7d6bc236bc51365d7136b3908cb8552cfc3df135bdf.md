
        
        <h1 data-source-node="n56"><a name="kanchor651" data-source-node="n57"></a>Packing Class Field</h1>
        <p data-source-node="n58">A packing class identifies which containers can be used to pack a particular 
 item for shipping. It also identifies which items can be packed together 
 in a shipping container. This field appears on the Item Window and 
 the Shipment Line screen. During the container creation wave step, the 
 system references this value when packing loose each records. </p>
