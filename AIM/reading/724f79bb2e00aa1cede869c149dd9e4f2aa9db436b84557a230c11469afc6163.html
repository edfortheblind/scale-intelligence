Printed As Buttons

When you define a document, you will need to identify what application generates it. Depending on which type of document you choose, the appropriate files will appear in the Document Template Field.

  • Reporting Services document - Choose this option if you want to generate a SQL Server Reporting Services (SSRS) document. The template file extension for SSRS documents is .rdl.

  • Progistics document - Choose this option if you want to generate a Progistics document.

  • Progistics label - Choose this option if you want to generate a Progistics shipping label.

  • SCALE label - Choose this option if you want to generate a SCALE vendor compliant label. The template file extension for SCALE labels is .lbl.

  • FedEx document/label - Choose this option if you want to generate a FedEx document/label.

  • Microsoft Word document -Choose this option if you want to generate a Microsoft Word document. The template file extension for Microsoft Word documents is .doc.

  • External Document/Label - Choose this option if you want to generate shipping labels or container manifests with an outside application that is not represented as an option on this field. When the application encounters a document of this type, it calls into the Rating Service Action of PrintLabel or PrintManifest.
