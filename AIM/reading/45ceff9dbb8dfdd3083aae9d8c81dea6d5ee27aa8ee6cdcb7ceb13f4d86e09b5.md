
        
        <h1 data-source-node="n56"><a name="kanchor910" data-source-node="n57"></a>Choosing the Default System Language</h1>
        <p data-source-node="n58">You can define which language that you want the system to use for certain 
 messages and text. For example, when someone is logging onto the RF and 
 Trading Partner Management, the system has not established who the user 
 is yet. Therefore, the system needs to choose a language to display these 
 windows, so it uses this value to decide which language to present these 
 windows with. Another example of the system using this value is to decide 
 which language to use when displaying an error message if a non-system 
 user attempted to start the system application.</p>

            <li value="3" data-source-node="n72">Use the System
