RF Consolidation

The consolidation process represents the step after picking/putaway, where the user will place a shipment's items/containers at a consolidation location (typically an area at or near the packing stations). Once one item/container of a shipment is assigned to a certain consolidation location, the system will assign all of its items/containers to that location. This ensures that all parts of a shipment will arrive at the same packing station, so that the items can be packed and/or the containers can be closed. Whether a detail/container is eligible for consolidation depends on its status. If the status is less than Staging Pending (and consolidation is active using the Consolidation After Putaway setting on the work profile), then the system will display the RF consolidation screen after the putaway action to the shipping dock. There, the user can assign the appropriate consolidation location, and take it to that location. Keep in mind that, if desired, you can also bypass the consolidation action altogether.

 

You can also manually initiate the consolidation process by choosing the Consolidation option from the RF Main Menu. The scenario where you would need to manually initiate consolidation is when you are picking items and automatic putaway is active on your work profile. Say, for example, your job is to pick items into a tote on a conveyor system. After the pick(s) are finished for a work unit, the system automatically puts away the tote and its contents, and the tote travels down the conveyor line. Since the workers will not have a chance to see the consolidation screen display after the putaway (since the system is performing putaway behind the scenes), then a worker at the end of the conveyor line will need to scan the tote from the consolidation screen (which is accessed from the RF main menu).

Procedures...

Log onto an RF Device.
  1. Execute the appropriate pick and putaway actions for a particular work unit, and then the system will automatically display the RF Consolidation screen.

    OR

    Manually initiate the consolidation process, choose the Consolidation option from the RF Main Menu. Scan in the container ID (typically a tote/transport container), and press OK. The system will then display the RF Consolidation screen.

  2. When consolidating one shipment's item(s), the system will display one RF screen for all the items you want to consolidate. The value ** All Quantity ** indicates that you are going to consolidate all of the items associated with a shipment. Also, the value directly under the shipment ID indicates the ship to address.

    When consolidating more than one shipment's item(s), the system will display an RF screen for each item/quantity. The ** All Quantity ** value would be replaced by a specific item and quantity, such as "AA001 Quantity 10."

    When consolidating shipping containers, the system will display one RF screen for each container that you want to consolidate. The value in the parentheses indicates that a container is the only container for the shipment. The value under the shipment ID indicates the ship to address.

  3. Use the Loc [Location] Field to enter the consolidation area and position where you want to place the item/container. Note that the system will default this value if a default consolidation area has been for this shipment's carrier, or if a consolidation has already been done for something associated with this shipment.

  4. Press OK. The system will consolidate your item/container, and navigate back to the Consolidation Screen. Note that if you try to consolidate a container to a consolidation location that does not support multiple shipments, and there is an open shipment currently assigned to that location, then the system will inform you that a shipment is already assigned to that location.
