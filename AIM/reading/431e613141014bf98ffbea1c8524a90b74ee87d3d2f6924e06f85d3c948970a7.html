Date/Time Stamp Field

On the DIF Inbound/Outbound Insight screen...

This field indicates the date and the time in which a DIF message is logged.

 

 

On the Interface Error Insight Screen... 

This field indicates the date and time in which a download interface error is logged.

 

 

On the Cycle Count Plan Screen...

This field indicates the date and time in which a cycle count master plan is logged.

 

 

On the Lot Screen...

This field indicates the date and time in which a lot record is logged.

 

 

On the Replenishment Request Screen...

This field indicates the date and time in which a replenishment request is logged.

 

 

On the Work Order Line Screen...

This field indicates the date and time in which a work order request is logged.

 

On the Tote Insight screen

This field indicates the date and time in which a Tote is created.
