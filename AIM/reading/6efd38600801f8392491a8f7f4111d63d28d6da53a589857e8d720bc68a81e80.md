
        
        <h1 data-source-node="n56"><a name="kanchor201" data-source-node="n57"></a>EPC Item Reference Field</h1>
        <p style="font-weight: normal" data-source-node="n58"> </p>
        <p style="font-weight: normal" data-source-node="n59">This field indicates an identifier that is given to an item and its 
 packing level (unit, inner-pack, case, or pallet). This value is used 
 when computing an Electronic Product Code (EPC) for the RFID process.</p>
