Defining the "Reporting" Link on the Web Main Menu

You can create a custom menu option for the Trading Partner Management Main Menu, which is represented by the "Reporting" link on the main menu. You could use this to display a custom web application, Internet web site, or other type of document. Note that both internal and external web users can view the "Reporting" link. You cannot change the name of this link. The system will always display this with the title of "Reporting."

 

WARNING: You cannot use the "Reporting" link to open an SSRS report.

 

 

Procedures...

Access the Web Screen Data Window. Open the "Reports" record.
  1. Use the URL To Call Field to indicate what you want displayed when a user selects the "Reporting" main menu option. Example values include Internet sites (http://www.manh.com) or other local/network files.

    2.  

  2. Use the Active Checkbox to indicate if the "Reporting" link will appear on the TPM main menu (the system default is to not make this record active).
     
  3. Press OK. The system will save your changes.
