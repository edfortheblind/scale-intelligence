        <h4 data-source-node="n106"><a name="Navigating" data-source-node="n107"></a>Navigating/Viewing the Receipt Monitoring Bar Chart</h4>
        <ol data-source-node="n108">
            <li value="1" data-source-node="n109">
                <p data-source-node="n110">Access the Receipt Monitoring screen.<br data-source-node="n111"><br data-source-node="n112"></p>
            </li>
            <li value="2" data-source-node="n113">
                <p data-source-node="n114">The system will display a chart on the first (highest) level which indicates the numbers of receipt headers in the user's default warehouse broken down by Receipt Dates as defined (Past Due, Today, Tomorrow, This Week, This Month, Future).<br data-source-node="n115"><br data-source-node="n116"></p>
            </li>
            <li value="3" data-source-node="n117">
                <p data-source-node="n118">Press on a Receipt Date data column, and the system will display the next level of the chart, Receipt Type. <br data-source-node="n119"><br data-source-node="n120"></p>
            </li>
            <li value="4" data-source-node="n121">
                <p data-source-node="n122">Press on a Receipt ID Type data column, and the system will then display the next level of the chart, Vendor Name. <br data-source-node="n123"><br data-source-node="n124"></p>
            </li>
            <li value="5" data-source-node="n125">Press on a Vendor Name data column, and the system will then display the last level of the chart, Purchase Order.<br data-source-node="n126"></li>
        </ol>
        <p data-source-node="n127"> </p>
        <p data-source-node="n128">NOTES: </p>
        <ul data-source-node="n129">
            <li data-source-node="n130">On any level of the chart, pressing Insight takes you to Receipt Insight with the receipts selected that match that graph.<br data-source-node="n131"><br data-source-node="n132"></li>
            <li data-source-node="n133">On each graph level, the totals at the top of the graph show number of receipts (headers), number of receipt lines, and total value (from receipt headers) pertaining to that graph.<br data-source-node="n134"><br data-source-node="n135"></li>
            <li data-source-node="n136">Changing warehouse at the top of the Monitoring screen displays the open receipts from the selected warehouse.</li>
        </ul>

        <h4 data-source-node="n141"><a name="Summary" data-source-node="n142"></a>Summary Data...</h4>
        <p data-source-node="n143">The following summary data totals are accessible from the Receipt Monitoring screen: </p>
        <p data-source-node="n144"> </p>
        <h5 data-source-node="n145">Total Receipts</h5>
        <p data-source-node="n146">This value indicates the number of receipts. </p>
        <p data-source-node="n147"> </p>
        <p data-source-node="n148"> </p>
        <h5 data-source-node="n149">Total Receipt Lines</h5>
        <p data-source-node="n150">This value indicates the number of unique receipt lines associated with the receipts being shown. </p>
        <p data-source-node="n151"> </p>
        <p data-source-node="n152"> </p>
        <h5 data-source-node="n153">Total Receipt Value</h5>
        <p data-source-node="n154">This value indicates the total value of receipts. </p>
        <p data-source-node="n155"> </p>
        <hr width="100%" align="center" data-source-node="n156">
        <p data-source-node="n157"> </p>

        <h4 data-source-node="n159"><a name="Indicator" data-source-node="n160"></a>Indicator Tiles</h4>
        <p data-source-node="n161">Indicator tiles display key warehouse data totals. Tapping on a tiles will navigate you to the appropriate insight screen that will load the data. The following indicator tiles are shipped with the system:</p>
        <p data-source-node="n162"> </p>
        <p data-source-node="n163"> </p>
        <h5 data-source-node="n164">Receipts over 24 hours old</h5>
        <p data-source-node="n165">This tile represents the summation of the number of receipts that have at least one item checked in greater than 24 hours ago and is not closed. </p>
        <p data-source-node="n166"> </p>
        <p data-source-node="n167"> </p>
        <h5 data-source-node="n168">Pending putaways over 4 hours old</h5>
        <p data-source-node="n169">This tile represents work instructions (with a "header" Instruction type and  "receipt" Internal Number Type along with the condition is not equal to closed) where the aging date time is greater than 4 hours since the current date/time.  Pressing on the tile takes the you to Work Insight with the selected instructions.</p>
        <p data-source-node="n170"> </p>
        <p data-source-node="n171"> </p>
        <h5 data-source-node="n172">Receipts with QC</h5>
        <p data-source-node="n173">This tile represents a count of the receipt headers where at least one receipt container has inbound quality control pending, and are not yet in a closed status. </p>
