
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">Equipment Type Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Equipment Type configuration defines the equipment categories used during work execution and work assignment logic. You can create equipment type records and maintain the related information used by work profiles and work teams.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62"><b data-source-node="n63">Note</b>: This configuration is currently accessible only from the Work Profile wizard and is not available as a standalone configuration outside the wizard.</p>
        <h4 data-source-node="n64"> </h4>
        <h4 data-source-node="n65">Configure Equipment Type</h4>
        <p data-source-node="n66"> </p>
        <h5 data-source-node="n67">1. Equipment Type</h5>
        <p data-source-node="n68"> </p>
        <p data-source-node="n69">Select or create an equipment type record.</p>
        <ul data-source-node="n70">
            <li data-source-node="n71">
                <p data-source-node="n72"><b data-source-node="n73">Create New</b>: Create a new equipment type record.</p>
            </li>
            <li data-source-node="n74">
                <p data-source-node="n75"><b data-source-node="n76">View All</b>: Review and select an existing equipment type record.</p>
            </li>
        </ul>
        <p data-source-node="n77"> </p>

        <p data-source-node="n82"><b data-source-node="n83">Description</b>: Enter the description for the equipment type record.</p>
        <p data-source-node="n84"> </p>
