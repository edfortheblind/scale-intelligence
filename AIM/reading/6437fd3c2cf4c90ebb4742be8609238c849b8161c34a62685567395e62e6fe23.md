
        
        <h1 data-source-node="n56"><a name="kanchor1498" data-source-node="n57"></a>Filter Field</h1>
        <p data-source-node="n58">This field is used on the Security Group Window. It is used to filter the users tied to a security group. You can type text into the edit box and the user names will automatically filter to your criteria. The percentage sign can also be used as a wildcard, for example, %smith.</p>
