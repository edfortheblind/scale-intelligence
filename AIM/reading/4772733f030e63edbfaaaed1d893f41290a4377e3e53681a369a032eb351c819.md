
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Labor Plan</h1>
        <p data-source-node="n58">A labor plan record specifies which labor group(s) should be processed during the labor plan execution wave step, as well as the order in which they are processed. Labor plans can be executed automatically within the wave.</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Create Labor Plan</h5>
        <ul data-source-node="n61">
            <li data-source-node="n62">
                <p data-source-node="n63"><b data-source-node="n64">Labor Plan</b> : Enter a unique name for your labor plan record.</p>
            </li>
        </ul>
        <ul data-source-node="n65">
            <li data-source-node="n66">
                <p data-source-node="n67"><b data-source-node="n68">Description</b>: Provide a brief explanation of the labor plan.</p>
            </li>
        </ul>
        <ul data-source-node="n69">
            <li data-source-node="n70">
                <p data-source-node="n71"><b data-source-node="n72">Sequence Number</b>: Define the order in which the labor groups assigned to this plan are processed during the wave execution.</p>
            </li>
        </ul>
        <h5 data-source-node="n73">Add New Sequence</h5>
        <ul data-source-node="n74">
            <li data-source-node="n75">
                <p data-source-node="n76"><b data-source-node="n77">Labor Group</b> - Select the labor group for which the wave step will generate estimated labor data. Note that only one detail record can be created per labor group within a single plan.</p>
            </li>
        </ul>
