        <h4 data-source-node="n91">Procedures...</h4>
        <ol class="ol_1" data-source-node="n92">
            <li value="1" data-source-node="n93">Use the Use LTL 
 Terms on BOL? Field to determine which VICS legal statement will 
 be printed on a bill of lading.<br data-source-node="n94"><br data-source-node="n95">	- If Yes, the system will 
 print the LTL legal statement on all bills of lading produced for this 
 carrier type.<br data-source-node="n96"><br data-source-node="n97">	- If No, the system will print 
 the TL legal statement on all bills of lading produced for this carrier 
 type.<br data-source-node="n98"> </li>
            <li value="2" data-source-node="n99">Use the One Pro 
 Number Per Load? Field to indicate if you want the system to assign 
 one pro number to represent all the shipments per shipping load. This 
 would commonly be used for loads that use the master BOL paperwork document.<br data-source-node="n100"> </li>
            <li value="3" data-source-node="n101">Press OK. 
 The system will save your record.</li>
        </ol>
