
        
        <h1 data-source-node="n56"><a name="kanchor1210" data-source-node="n57"></a>Using the Cycle Count Plan Insight Screen</h1>
        <p data-source-node="n58">You can use the Cycle Count Plan Insight Screen to search and manage cycle count plans in your warehouse. This helps you keep track of exactly how much inventory is present in your warehouse. There are two ways you can trigger cycle counts: by manually creating cycle count plans (called "plan-based"), or by having the system create cycle count work instructions automatically when a location is due for a cycle count (called "non-plan based" or "activity-driven"). This screen helps you to adopt the former method. </p>

        <h4 data-source-node="n190"><a name="Searching" data-source-node="n191"></a>Searching/Viewing Cycle Count Plan Records...</h4>
        <p data-source-node="n192">You can use the Cycle Count Plan Insight Screen to search for and view cycle count plan records in your warehouse. </p>
        <ol data-source-node="n193">
            <li value="1" data-source-node="n194">Open the Cycle Count Plan  Insight Screen.<br data-source-node="n195"><br data-source-node="n196"></li>
            <li value="2" data-source-node="n197">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n198"><br data-source-node="n199"></li>
            <li value="3" data-source-node="n200">Press the Search Button. The system will display  the resulting records in the List Pane. <br data-source-node="n201"><br data-source-node="n202"></li>
            <li value="4" data-source-node="n203">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>

        <h4 data-source-node="n224"><a name="AboutDPane" data-source-node="n225"></a>About the Detail Pane...</h4>
        <p data-source-node="n226">The Cycle Count Plan  Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.<br data-source-node="n227"><br data-source-node="n228"></p>
        <p data-source-node="n229">The Detail Pane of Cycle Count Plan  Insight contains Indicator Tiles with counts of the other entities (i.e. requests, open work, and transactions).  If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following: </p>
        <ol data-source-node="n230">
            <li value="1" data-source-node="n231">Requests<ol data-source-node="n232"><li value="1" data-source-node="n233">Displays the number of all the cycle count requests linked to the cycle count plan.</li><li value="2" data-source-node="n234"><p data-source-node="n235">Clicking on the Requests Indicator Tile takes you to the Cycle Count Request Insight screen filtering on the internal plan number. <br data-source-node="n236"><br data-source-node="n237"></p></li></ol></li>
            <li value="2" data-source-node="n238">Transactions<ol data-source-node="n239"><li value="1" data-source-node="n240">Displays the number of transaction history records for the cycle count plan.</li><li value="2" data-source-node="n241">Clicking on this tile takes you to Transaction History Insight filtering on the internal plan number and transaction type. <br data-source-node="n242"><br data-source-node="n243"></li></ol></li>
            <li value="3" data-source-node="n244">Open Work<ol data-source-node="n245"><li value="1" data-source-node="n246">Displays the  number of open and in process cycle count request work instruction details for the entire cycle count plan.</li><li value="2" data-source-node="n247">Clicking on the Open Work Indicator Tile takes you to Work Insight filtering on the internal plan number and internal number type.</li><li value="3" data-source-node="n248">The internal number type is Cycle Count.<br data-source-node="n249"></li></ol></li>
            <br data-source-node="n250">
            
        </ol>

        <h4 data-source-node="n258"><a name="Screen" data-source-node="n259"></a>Screen Actions</h4>
        <p data-source-node="n260">The following actions are accessible from the List Pane:</p>
        <p data-source-node="n261"> </p>
        <h5 data-source-node="n262">View</h5>
        <p data-source-node="n263">The View action allows you to open a specific cycle count plan against a selected record. Clicking on this action opens the Cycle Count Plan Details screen. </p>
        <p data-source-node="n264"> </p>
        <p data-source-node="n265"> </p>
        <h5 data-source-node="n266">Delete</h5>
        <p data-source-node="n267">The action allows to delete one or more cycle count plans. The system will prompt for a confirmation message after the delete action is performed. If there are multiple records selected for deletion with one or more requests that are already deleted, system will ignore the records that are already deleted and deletes all the other records which are eligible for deletion.</p>
        <p data-source-node="n268"> </p>
        <p data-source-node="n269"> </p>
        <h5 data-source-node="n270">Close</h5>
        <p data-source-node="n271">This action allows to manually close one or more cycle count plans. Selecting the record (s) and invoking the action will show a confirmation message and accepting a confirmation message will close the cycle count plan and a success message is shown once the plan is closed.</p>
        <p data-source-node="n272"> </p>
        <p data-source-node="n273"> </p>
        <h5 data-source-node="n274">Master Plan</h5>
        <p data-source-node="n275">The Master Plan action allows you to open the Cycle Count Master Plan screen. The warehouse defaulted on the Cycle Count Master Plan screen is based on the warehouse selected by user counter on the Cycle Count Plan Insight. Selecting a cycle count master and tapping/clicking on 'Save' will submit for cycle count plan creation. For more information on this, refer to the topic <a href="63ca81ffeb83c9db93ca5ad3d9373b618888c32081943359d9e605b8bfe949d8.html" data-source-node="n276">Using Cycle Count Plans</a>. </p>
        <p data-source-node="n277"> </p>
        <p data-source-node="n278"> </p>
        <h5 data-source-node="n279">Print Default</h5>
        <p data-source-node="n280">This action allows you to print all the default documents for a cycle count plan. This is useful when performing manual cycle counting for plans created outside of a master plan. If the plan is divided into multiple groups, a separate document will be printed per group. There is no option to preview the document before printing.</p>
        <p data-source-node="n281"> </p>
        <p data-source-node="n282"> </p>
        <h5 data-source-node="n283">Print Selected</h5>
        <p data-source-node="n284">This action allows you to select and print documents for a cycle count plan. If the plan is broken into multiple groups, a separate cycle count list will be printed for each group.    There is no option to preview the document before printing.</p>
        <p data-source-node="n285"> </p>
        <p data-source-node="n286"> </p>
        <h5 data-source-node="n287">Quick Plan</h5>
        <p data-source-node="n288">This action allows you to open the Cycle Count Quick Plan screen through which you can create a new cycle count plan. For more information, refer to the topic <a href="a2208ed6a36cd50ce453b926159af08f5c62b1519dbac2a8f2a3baae9d4dd92e.html" data-source-node="n289">Creating Cycle Count Quick Plans</a>. </p>
        <p data-source-node="n290"> </p>
        <p data-source-node="n291"> </p>
        <h5 data-source-node="n292">Release</h5>
        <p data-source-node="n293">This action enables you to release a single or multiple cycle count plans.  Selecting the record (s) and invoking the action will release the cycle count plan and a success message is shown after the plan is released. Refer to the topic <a href="63ca81ffeb83c9db93ca5ad3d9373b618888c32081943359d9e605b8bfe949d8.html" data-source-node="n294">Using Cycle Count Plans</a> for additional information on releasing the cycle count plans. </p>
