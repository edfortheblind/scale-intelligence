
        
        <h1 data-source-node="n56"><a name="kanchor1440" data-source-node="n57"></a>Item Selection Field</h1>
        <h5 data-source-node="n58">In Cycle Counting...</h5>
        <p class="p_1" data-source-node="n59">This field indicates the cycle count item 
 criteria record that will be associated with this cycle count master. 
 These selection records are used by the system to filter the number of 
 locations eligible for a cycle count.</p>
        <p class="p_1" data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"> </p>
        <h5 data-source-node="n62">In Order Entry...</h5>
        <p class="p_1" data-source-node="n63">You can use this field to load an order entry 
 item selection record, which contains the rules for selecting a series 
 of item(s) for your order.</p>
