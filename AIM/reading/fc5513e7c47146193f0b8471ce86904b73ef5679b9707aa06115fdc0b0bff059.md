
        
        <h1 data-source-node="n56"><a name="kanchor43" data-source-node="n57"></a>Total Container Value Field</h1>
        <p data-source-node="n58">This field indicates the total dollar value 
 of all containers packed within a certain date range. This is based 
 on the Item List Price value. So, if the item list price is 9.00, and 
 you have 100 units in the container, the total container value is 999.00</p>
