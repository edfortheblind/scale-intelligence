Searching/Viewing Background Job Queue Records...

You can use the Background Job Queue Insight Screen to search for and view background job queue records in your warehouse.

  1. Open the Background Job Queue Insight Screen.

  2. Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.

  3. Press the Search Button. The system will display the resulting records in the List Pane.

  4. If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.

 

 

 

About the List Pane...

  • The Background Job Queue Insight Screen's List Pane displays the results from a query performed in the Filter Pane.

  • For more general information about the List Pane, see the topic Introduction to Insight Screens.

 

 

 

About the Detail Pane...

  • The Background Job Queue Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.

  • The Detail Pane header consists of Process Status and Process Type.
  • For more general information about the Detail Pane, see the topic Introduction to Insight Screens.

 

 

Screen Actions

The following actions are accessible from the List Pane:

 

Reset

This action allows you to reset the Failed background job requests to the Ready status for reprocessing. Resetting failed requests will prompt for confirmation. Selecting Yes will continue with the reset, while selecting No will return to the Background job insight screen. Requests that are Ready or In Process cannot be reset.
