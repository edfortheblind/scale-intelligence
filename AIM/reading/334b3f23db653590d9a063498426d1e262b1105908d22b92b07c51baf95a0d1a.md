
        
        <h1 data-source-node="n56"><a name="kanchor1644" data-source-node="n57"></a>Data Source Field</h1>
        <h5 data-source-node="n58">For 
 Document Types...</h5>
        <p data-source-node="n59">This field identifies which data selection records can be linked with 
 a document type. A data selection record determines what criteria a record 
 in a wave must meet for the system to print paperwork for it. This value is displayed on the Document Type 
 Window. You cannot change this value on predefined document types. Note that this field is only applied for the wave print procedure.</p>
