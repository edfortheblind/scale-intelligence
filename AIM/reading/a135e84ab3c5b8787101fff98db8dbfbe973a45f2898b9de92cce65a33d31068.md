
        
        <h1 data-source-node="n56"><a name="kanchor300" data-source-node="n57"></a>Group Picks By Loc/LP Checkbox</h1>
        <p data-source-node="n58">This checkbox is used in RF picking, to indicate that if a work unit 
 has multiple picks for the same item at the same location, you want the 
 system to group this into one pick. For example, suppose a work unit has 
 2 instructions: (1) Item AAA, location 111, quantity 10 each, and (2) 
 Item AAA, location 111, quantity 5 each. With this flag on, you will see 
 a pick of 15 each from location 111 for item AAA. With this flag off, 
 you will see the two picks one for 10 the other for 5. Also note that if receipt containers/license plates for these items were created during a wave, 
 the system will group these as well. Suppose that 3 cases are ordered. 
 During the wave, the system allocates the cases from the same location, 
 and the system creates 3 full-case receipt containers/license plates. When a user performs the 
 work via RF, they will have to verify and confirm only one 
 time for all 3 cases combined.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Note About Loose Container Picks...</h5>
        <p data-source-node="n62">If this setting is activated, the work profile's <a href="8005235988cb299c6ecac104c143a042c0b7e9d4aae53756a5b5995dcbf1e6a0.html" data-source-node="n63">container picking method</a> is set to None, and if you are creating "loose" (a.k.a. not full unit of measure) containers out of the wave, the system will not group the resulting "loose" container picks.</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">Note About Parent/Child License Plates...</h5>
        <p data-source-node="n67">The following describes how to use this field to get one pick for parent license plate  or child license plate, when all the associated location inventory records are on same work instruction for the full amount:
 </p>
        <ul data-source-node="n68">
            <li data-source-node="n69">If this setting is not activated, the system will always process work instructions individually.<br data-source-node="n70"> </li>
            <li data-source-node="n71">If this setting is activated, the system will allow one pick of multi-item child license plate, if all items on child are on work unit and for entire amount. Otherwise, the user will have to do each pick individually.  The system allows one pick of parent license plate if all child license plates are on work instruction and are for full amount, otherwise user will have to do each picks individually.</li>
        </ul>
        <p data-source-node="n72"> </p>
        <h5 data-source-node="n73">Note About Labor Logging...</h5>
        <p data-source-node="n74">If this setting is activated, the system will still log five separate labor records when you perform picks.  However, the labor process type will be <i data-source-node="n75">GRP Pick Confirmation</i>.  When grouping, the system will spread the actual time for the labor across the grouped instructions.  In the same fashion, whenever putaways are grouped (there is no system setting for this as SCALE always attempts to group putaways when possible), then the labor process type will be <i data-source-node="n76">GRP Putaway Confirmation</i>. Also, the labor process type will be <i data-source-node="n77">GRP Pick Put Confirmation</i> whenever you are confirming more than a single instruction via RF and using automatic putaway.</p>
