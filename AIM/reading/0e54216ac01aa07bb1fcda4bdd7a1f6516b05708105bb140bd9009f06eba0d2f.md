
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Carrier EDI Reference</h1>
        <p data-source-node="n58">Carrier EDI reference records define the type of data that SCALE sends to your transportation system during the manifesting process. These records support customer-level EDI manifesting within the application.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">You can edit only the "Value" field of existing records. Creating new reference records or deleting existing ones is not allowed.</p>
