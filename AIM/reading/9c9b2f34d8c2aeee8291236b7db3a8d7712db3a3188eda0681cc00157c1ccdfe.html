Process Flows

 

 

 

Summary...

Inventory management refers to any adjustment to a location's inventory outside of a pick or a putaway. It allows the user to eliminate, in real-time, a deviation between his/her visual observation of a location's inventory and the system's inventory calculation. Adjustment types are associated with adjustment classes and are user-configurable. It is this class that determines how the system will process the adjustment type.

 

You may either initiate an inventory management request from an Insight screen or from an RF device. In either case, the inventory is moved within the system immediately as soon as you complete the transaction. You can also transfer or adjust at the license plate level. This allows you to process mixed product in one transaction. If the location supports license plate ID tracking, you can identify license plate information during the transactions.

 

You can use the Transaction History Insight Screen to research inventory transactions.

 

Notes:

  • The status of allocated inventory can be changed in the shipping and receiving dock.
  • From the Lot insight screen, user will not be able to perform inventory adjustment/status change/transfer when the updated inventory is linked with inventory attributes.
  • While editing lot information, user will be able to change status/expiration date. This change will be updated across all inventory records for the item/company/lot in the system.

The following are key features of the inventory management functional area:

 

Inventory Adjustment Types...

SCALE supports the inventory adjustment types listed below. You can create as many specialized adjustment types as you need. This allows you to use specific adjustment types for different kinds of inventory or locations. For example, you can create a negative adjustment that is only applied to items in a specific movement class.

 

For each adjustment type, you can also determine if can be applied to frozen locations. To minimize errors, you can set minimum and maximum quantity values per adjustment type.

  • Adjustment: Allows you to add or remove quantity (items, license plates) from a location.
     
  • Company Transfer: Allows you to change the company designation on an item in the warehouse.
     

  • Status Change: Allows you to change the status of product in a location.

     

  • Transfer: Allows you to move product from one location to another.
     
  • Warehouse Transfer: Allows you to change inventory from one warehouse to another.

 

Creating Work For Inventory Transactions...

You can define certain adjustment types to have the system generate work for the transactions, once they are performed. This allows inventory quantities to not show up as available in a location until the quantity is actually present in the location. When an adjustment is executed, the system will mark this quantity as in transit in the to location. For transfers, the system will mark this quantity as in transit in the to location, and allocated in the from location.

 

The adjustment types that the system can create work for are positive/negative adjustments, basic inventory transfers, and warehouse transfers. Note that this functionality can only be performed from the SCALE Inventory Adjustment and Inventory Transfer screens, not during RF inventory adjustments.

 

Catch Weight in Inventory Management

 

Catch weight is supported for inventory management transactions for items configured as catch weight items. During inventory processing, SCALE can capture, default, and update catch weight information based on the transaction type and quantity being processed.

Inventory Adjustments

Positive and negative inventory adjustments support catch weight handling.

  • For partial quantity adjustments, SCALE can default catch weight by using average catch weight at the location multiplied by the adjusted quantity. You can accept the default value or enter a different value.
  • For a negative adjustment of the entire quantity, SCALE does not prompt for catch weight. The system updates inventory and catch weight records automatically.
  • For adjustments created as work, SCALE does not prompt for catch weight during work creation. Catch weight is entered during work execution.
Inventory Transfers

 

Inventory transfers support catch weight handling.

  • For a partial transfer, SCALE can default catch weight by using average catch weight multiplied by the transferred quantity.
  • For a transfer of the entire quantity, SCALE does not prompt for catch weight and updates records automatically.
  • For transfers created as work, catch weight is entered during work execution instead of work creation.
Company Transfer and Status Change
  • Company transfer supports catch weight handling for catch weight items. During transfer, SCALE preserves catch weight information as inventory moves between companies and updates target inventory catch weight values as part of the transaction.
  • Status change does not prompt for catch weight information.
Update Catch Weight Without Changing Quantity

 

Use the Update Catch Weight action in Inventory Insight when quantity remains the same but weight changes (for example, sample removal or dehydration).

  1. Open Inventory Insight and locate the inventory record.
  2. Select the catch weight item record.
  3. Choose Update Catch Weight.
  4. Enter the new catch weight value.
  5. Save the change.
