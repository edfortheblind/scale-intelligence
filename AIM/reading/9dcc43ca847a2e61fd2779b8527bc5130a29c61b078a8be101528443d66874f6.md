
        
        <h1 data-source-node="n56"><a name="kanchor739" data-source-node="n57"></a>Available Quantity Field</h1>
        <h5 data-source-node="n58">When Picking...</h5>
        <p class="p_1" data-source-node="n59">This field indicates the item quantity available 
 for picking at a certain location. The system derives this number via 
 the following calculation: On Hand Quantity 
 - Allocated Quantity - Suspense Quantity = Available Quantity. 
  All "Inventory" 
 locations in the warehouse that contain the item/company are considered 
 for this calculation.</p>
        <p class="p_1" data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"> </p>
        <p style="font-weight: bold" data-source-node="n62">Calculation 
 Notes...</p>
        <ul type="disc" class="ul_1" data-source-node="n63">
            <li class="li_1" data-source-node="n64">If the "Allocate In Transit" setting (in the Location Window) is activated, the In Transit 
 Quantities will be added to the On Hand Quantity before the others 
 are subtracted.<br data-source-node="n65"> </li>
            <li class="li_1" data-source-node="n66">Available quantity does not 
 take location status into account, so Available/Unavailable/Damaged/Frozen 
 inventory is all considered "available quantity" here.<br data-source-node="n67"> </li>
            <li class="li_1" data-source-node="n68">If the "Should 
 in pool quantities count as allocated" setting (in the Order Entry 
 Values Window) is selected, the quantity required by shipments that are 
 "In Pool" will be subtracted from the calculated Available 
 Quantity value described above. <br data-source-node="n69"> </li>
            <li class="li_1" data-source-node="n70">NOTE: 
 When using unlimited allocation mode, the system allows the on hand quantity 
 calculation to return a negative available quantity value. However, the 
 system will display this negative amount as a     0. 
 For example, suppose the following for a certain location:<br data-source-node="n71"><br data-source-node="n72">	- On Hand quantity = -100<br data-source-node="n73"><br data-source-node="n74">- In Transit quantity = 0<br data-source-node="n75"><br data-source-node="n76">- Allocated quantity = 0<br data-source-node="n77"><br data-source-node="n78">- These values would yield an 
 Available Quantity of -100. The system, then, will display this quantity 
 to the user as a 0.</li>
        </ul>
        <p class="p_1" data-source-node="n79"> </p>
        <h5 data-source-node="n80">On the Receipt From Purchase Order Screen...</h5>
        <p data-source-node="n81">This field indicates the maximum quantity for which a receipt line can be created.
