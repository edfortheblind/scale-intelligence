
        
        <h1 data-source-node="n56"><a name="kanchor1874" data-source-node="n57"></a>Creating Cycle Count Quick Plans</h1>
        <p data-source-node="n58">A cycle count "quick plan" allows you to  choose plan variables at the time of plan creation, including the types of items/locations that will be counted, and the number of counts that the system will create from this plan. Note that quick plans differ from cycle count "master plans" because the quick plan settings are not stored as a configuration record for future use. Once a quick plan is created and released, the plan settings are not retained by the system. You can access the Cycle Count Quick Plan screen  from Cycle Count Plan Insight through the Quick Plan action.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">When creating a quick plan, you can define any setting available on the Cycle Count Master configuration. Additionally, some extra settings are provided, such as limiting locations counted to multi-item/permanent/LP-tracked locations, and limiting items counted to serial number-tracked items.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">You can manually create a cycle count quick plan from the Cycle Count Plan Insight screen. Note that once a quick plan is created, it functions in the same manner as a master plan (with regards to the release, close, and delete actions). See the topic <a href="63ca81ffeb83c9db93ca5ad3d9373b618888c32081943359d9e605b8bfe949d8.html" data-source-node="n63">Using Cycle Count Plans</a> for more information on these plan actions.</p>

        <h4 data-source-node="n183"><a name="manualCreate" data-source-node="n184"></a> Manually-Created Quick Plans...<br data-source-node="n185"></h4>
        <p data-source-node="n186">You can manually create a cycle count quick plan from the Cycle Count Plan Insight screen either by choosing the Quick Plan option from the Actions Menu, or by selecting this option from the right-click menu of the Active Plans Node. Note that you can enter any combination of values on the various criteria view pages. </p>
        <p data-source-node="n187"> </p>
        <p data-source-node="n188"> </p>
        <p data-source-node="n189"> </p>
        <h4 data-source-node="n190">Note On Wildcard Values...<br data-source-node="n191"></h4>
        <p data-source-node="n192">For several fields on this window, you can use a wildcard value (a percent sign) to indicate that you want the system to consider a range of a criteria field when creating a quick plan. For example, you could enter an Item value of <i data-source-node="n193">ITEM2%</i>, and the system would generate counts for all items that begin with the prefix <i data-source-node="n194">Item2</i>. Other fields you can perform wildcard searches on include Location and Lot (among others, including the non-numeric item user-defined fields).</p>
        <p data-source-node="n195"> </p>
        <p data-source-node="n196"> </p>
        <p data-source-node="n197"> </p>
        <h4 data-source-node="n198">Button Actions...<br data-source-node="n199"></h4>
        <p data-source-node="n200">- Use the Create Plan button or Create button (in the Cycle Count Quick Plan Screen) to have the system create your new quick plan. After pressing this button, the system will display a message that indicates how many cycle counts it will create for this quick plan, and ask you to confirm that you want to proceed with this quick plan creation. You can press Yes to create the plan, or Cancel to further modify your selection criteria.</p>
        <p data-source-node="n201"> </p>
        <p data-source-node="n202">- Use the Clear Button to restore the original field defaults and erase all the user-entered field values. This button is available only for the Windows version of the application. </p>
        <p data-source-node="n203"> </p>

        <h4 data-source-node="n205">Procedures: Plan Preferences Criteria View Fields...</h4>
        <ol data-source-node="n206">
            <li value="1" data-source-node="n207">Use the Description Field to provide a text description of the quick plan you want to create. The system will include this description with the quick plan's ID on the Cycle Count Plan Insight screen (this allows for easy identification of your quick plans).<br data-source-node="n208"><br data-source-node="n209"></li>
            <li value="2" data-source-node="n210">Use the Maximum Number of Counts Field to indicate the most cycle counts that the system can generate for your quick plan. If you do not provide a value, then the system will generate all counts that meet the quick plan's criteria.<br data-source-node="n211"><br data-source-node="n212"></li>
            <li value="3" data-source-node="n213">Use the Counts Per Group Field to indicate how many cycle count 
 requests you would like the system to group together during quick plan creation. Note that a zero or blank value indicates unlimited size. When you open the Cycle Count Quick Plan Window, the default value for this field is taken from the "Default Cycle Count Group Size" setting on the Cycle Count System Values Window.<br data-source-node="n214"><br data-source-node="n215"></li>
            <li value="4" data-source-node="n216">Use the Positive Adjustment Type Field to indicate the inventory adjustment type the system should use when performing positive inventory adjustments during the cycle counting process.  If this value is left blank, the system then will use the adjustment type value specified in the "Planned Count - Positive Adjustment" cycle count system value setting. The system will display the user and warehouse authorized adjustment types.<br data-source-node="n217"><br data-source-node="n218"></li>
            <li value="5" data-source-node="n219">Use the Negative Adjustment Type Field to indicate the inventory adjustment type the system should use when performing negative inventory adjustments during the cycle counting process.  If this value is left blank, the system then will use the adjustment type value specified in the "Planned Count - Negative Adjustment" cycle count system value setting. The system will display the user and warehouse authorized adjustment types.<br data-source-node="n220"><br data-source-node="n221"></li>
            <li value="6" data-source-node="n222">Use the Create Work Checkbox to indicate that you want the system to create work for each request that is generated from this quick plan. When you open the Cycle Count Quick Plan Window, whether or not this checkbox is selected by default is determined by the “Create Activity Driven and Quick Plan Cycle Count Work” setting on the Cycle Count System Values Window. <br data-source-node="n223"><br data-source-node="n224"></li>
            <li value="7" data-source-node="n225">Use the Update Cycle Count Work to Include All Items Checkbox to have the system create cycle count requests for all items currently at a multi-item location, as opposed to creating requests for just the item(s) at the location that match the cycle count item selection criteria.
 
Note that when a multi-item location is initially empty and then items are adjusted into it (prior to the cycle counting work being executed), the system will create a cycle count for every item adjusted into the location, regardless of whether this setting is on or off.<br data-source-node="n226"></li>
