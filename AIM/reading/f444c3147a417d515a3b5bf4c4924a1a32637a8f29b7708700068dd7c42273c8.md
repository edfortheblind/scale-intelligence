
        
        <h1 data-source-node="n56"><a name="kanchor635" data-source-node="n57"></a>Pick Prompt Field</h1>
        <p data-source-node="n58">This field indicates how the TalkMan gives the pick prompt to the user: </p>
        <blockquote data-source-node="n59">
            <p data-source-node="n60">- <i data-source-node="n61">Double Prompts </i>mean that the TalkMan speaks a location prompt, after which the user speaks the check digits, and a quantity-to-pick prompt. <br data-source-node="n62"><br data-source-node="n63">- <i data-source-node="n64">Always Single Prompt</i> means that the TalkMan speaks the location and quantity to pick (no matter how many items the user should pick), before waiting for the user to speak the check digits. <br data-source-node="n65"><br data-source-node="n66">-  <i data-source-node="n67">Single Prompt, Omit Quantity When = 1</i> means that the TalkMan gives the location and, if the user should pick more than one item, the quantity to pick. The prompt may include the work ID as well (depending upon the setting of Speak Work ID Field). The slot identifier may include the slot, description, or both (depending upon the setting of pick by Location/description).</p>
        </blockquote>
