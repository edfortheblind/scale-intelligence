Locating Rule Selection Screen

You can use this screen to have the system choose a "to location" to use for the putaway of a particular item. With this screen, the user can choose the locating rule that the system uses to determine this putaway location. You can access this screen from the Inventory Adjustments Screen, Inventory Transfers Screen, RF Inventory Management Screen, and the Work Order Confirmation Screen.

 

You can click on the Locate action to invoke locating. Note that the Locating rule value in the screen defaults to the locating rule defined on the item configuration. If none is configured there, the locating rule defaults to the Default rule.
