
        
        <h1 data-source-node="n56"><a name="kanchor785" data-source-node="n57"></a>Defining Wave Pick Location Groups</h1>
        <p data-source-node="n58">A wave pick location group record identifies the sequence rules that the 
 system will use when creating picking groups. Each sequence represents 
 a picking group and identifies the work zone(s) or location range where 
 it can be used. Later, you will associate the pick location group record 
 with a picking group record. The picking group record provides additional 
 parameters, such as how many containers can be included in the group.</p>

        <h4 data-source-node="n112">Procedures...</h4>
        <p class="p_15" data-source-node="n113"> </p>
        <h5 data-source-node="n114">Wave Pick Location Group Window</h5>
        <p data-source-node="n115">Provide a name for this pick location group and a description. Select 
 the Apply Button. Select the New Action. The system will display the Wave Pick 
 Location Group Detail Window. When you access this window, the Detail 
 Records Tab will not contain any values. After you define one or more 
 sequences on the detail window, this tab will display them. This allows 
 you to quickly review the order of the sequence records. You can perform 
 all eligible actions against a sequence from this tab, including opening 
 and deleting (to access the action list, right click or double-click on 
 the sequence).</p>
        <p data-source-node="n116"> </p>
        <p data-source-node="n117"> </p>
        <h5 data-source-node="n118">Wave Pick Location Group Detail 
 Window</h5>
        <ol data-source-node="n119">
            <li value="1" data-source-node="n120">
                <p data-source-node="n121">The Wave Pick Location Group Field will 
 default this record's name.</p>
                <p data-source-node="n122"> </p>
            </li>
            <li value="2" data-source-node="n123">
                <p data-source-node="n124">The Sequence Field will 
 contain the value 10. You can change the sequence number, but you cannot 
 use the same sequence number for multiple detail records. The sequence 
 number determines when this record will be used. The lower the sequence 
 number, the sooner it's processed. </p>
                <p data-source-node="n125"> </p>
            </li>
            <li value="3" data-source-node="n126">
                <p data-source-node="n127">Use the Warehouse Field to 
 identify the warehouse where this detail record can be applied.</p>
                <p data-source-node="n128"> </p>
            </li>
            <li value="4" data-source-node="n129">
                <p data-source-node="n130">Use either the Location Range Fields 
 or the Work Zone Check boxes to select the locations where this 
 picking group is used. You can select multiple locations or multiple work 
 zones, but you cannot create a detail record containing both locations 
 and zones. In the screen diagram above, the following work zones are selected: 
 Outside - Off Season and Outside Storage - Bulk. Therefore, when this 
 detail record is applied during a wave, the system will check to see if 
 all of the product in the container was allocated from one of these zones. 
 If all of the product was allocated from either zone, the system will 
 apply this detail record and create a picking group. If one or more items 
 was not allocated from either of these zones, the system cannot apply 
 this detail record and a new picking group is not created. In this case, 
 the system will check the next sequence. </p>
                <p data-source-node="n131"> </p>
            </li>
            <li value="5" data-source-node="n132">To define additional 
 sequence values, select the New Action. The Sequence Field will 
 contain the value 20. </li>
        </ol>
