
        
        <h1 data-source-node="n56"><a name="kanchor737" data-source-node="n57"></a>Rate Base Field</h1>
        <p data-source-node="n58">A rate base identifies which rate table is used    
based on a specific origin postal code and destination
postal code range and any other additional criteria which can be defined. Rate bases determine how much a carrier will charge for shipping product, based on specific parameters, such as weight, class and travel distance. Before the system can rate the LTL carrier's shipment, it must be linked to a valid rate base.                                   </p>
