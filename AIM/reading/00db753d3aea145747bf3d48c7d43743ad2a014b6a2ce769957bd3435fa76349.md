
        
        <h1 data-source-node="n56"><a name="kanchor966" data-source-node="n57"></a>Group Pallet Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates if you want containers that have the same type of item quantities on the same pallet (such as soda beverages and dairy products on a separate pallet).

</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Example:
</h5>
        <p data-source-node="n61">- If you wanted to group the containers by store on each pallet, then you would create a rule with "Mark For" as the attribute, and select the Group Pallet Checkbox.

</p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">- If you wanted to group the containers by type of item on each pallet, then you would create a rule with "NMFC Code" as the attribute, and select the Group Pallet Checkbox.
</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65">- If you wanted to make sure a heavy container is not set on a lighter container, you would choose the shipping container "Weight" as the attribute, and NOT select the Group Pallet Checkbox. If this checkbox had been selected, only containers that included items with the same weight would be placed on a pallet. With it not selected, the system can mix weights on the pallet.
</p>
