        <h4 data-source-node="n279"><a name="actions" data-source-node="n280"></a>Screen Actions...</h4>
        <p data-source-node="n281">The following actions are accessible from the Receipt Line Insight screen: </p>
        <p data-source-node="n282"> </p>
        <h5 data-source-node="n283">Edit/View</h5>
        <p data-source-node="n284">This action allows you to display and edit a receipt line’s information.</p>
        <p data-source-node="n285"> </p>
        <p data-source-node="n286"> </p>
        <h5 data-source-node="n287">Cancel Container</h5>
        <p data-source-node="n288">This action allows you to cancel the selected receipt container. This action is available only for receipt containers that have been downloaded or created using pre-check in containers prior to its check-in.  Canceling the receipt container marks it as closed and removes the inventory from the pre-receiving location.</p>
        <p data-source-node="n289"> </p>
        <p data-source-node="n290"> </p>
        <h5 data-source-node="n291">Delete Container</h5>
        <p data-source-node="n292">This action allows you to delete the selected receipt container.</p>
        <p data-source-node="n293"> </p>
        <p data-source-node="n294"> </p>
        <h5 data-source-node="n295">Immediate Needs</h5>
        <p data-source-node="n296">This action allows you to select an immediate needs transaction for the Immediate Needs Insights screen. For more information on Immediate Needs, see the Researching a Warehouse's Immediate Needs topic.</p>
        <p data-source-node="n297"> </p>
        <p data-source-node="n298"> </p>
        <h5 data-source-node="n299">Locate</h5>
        <p data-source-node="n300">This action enables you to locate a single or multiple receipt containers at a time. Invoking the action by selecting a receipt container will locate the receipt container using the locating rule and user assigned receiving preference (in User Profile) to the receipt container. In case the user profile does not have an assigned receiving preference then the default preference is used to locate. This action is enabled for a receipt container with status 'Locate pending'.  For more information on this topic, refer to <a href="a357eac1f7ebf1b8fcf6edee90c086783da65f07d18fbdcc06236891e314cebc.html" data-source-node="n301">Checking In and Locating Product</a>. </p>
        <p data-source-node="n302"> </p>
        <p data-source-node="n303"> </p>
        <h5 data-source-node="n304">Print Preview</h5>
        <p data-source-node="n305">This action allows you to generate and display a PDF version of the selected document type.         <h5 data-source-node="n322">Unlocate</h5>
        <p data-source-node="n323">User can unlocated one to many (multiple) eligible receipt containers. The process of unlocated is based on the receiving preference selected for the user. The default preference used in case there are no receiving preference is assigned.</p>
        <p data-source-node="n324"> </p>
        <p data-source-node="n325">Select the records and click <b data-source-node="n326">Actions &gt;&gt; Unlocate</b> and the system will prompt you to confirm with a Yes or No.</p>
        <p data-source-node="n327">When you selects Yes</p>
        <ul data-source-node="n328">
            <li data-source-node="n329">A successful message will be displayed. </li>
            <li data-source-node="n330">Error message will be displayed when all receipt containers fail to unlocate. </li>
            <li data-source-node="n331">Multiple errors will be displayed based on the records selected for unlocate. You can read each message to debug failures related to specific records. </li>
        </ul>
        <p data-source-node="n332">When user selects No, system will navigate back to the Insight screen.</p>
