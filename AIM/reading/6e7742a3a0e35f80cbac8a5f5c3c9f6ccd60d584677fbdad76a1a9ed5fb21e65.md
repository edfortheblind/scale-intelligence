
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">Cycle Count Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59">The purpose of a cycle count master record is to control what cycle count requests the system creates. Master records are only used in generating plan-based cycle count requests. These records are driven off of item and location criteria records.</p>

        <h4 data-source-node="n66">Configure Cycle Count Records</h4>
        <p data-source-node="n67"> </p>
        <h5 data-source-node="n68">1. Cycle Count Information </h5>
        <ul data-source-node="n69">
            <li data-source-node="n70">
                <p data-source-node="n71">Maximum number of counts (0=No maximum) - This indicates the maximum number of cycle count requests you want the system to generate from a particular cycle count plan. Note that if you put a "0" in this field, there will be no maximum limit of requests that the system will create.</p>
            </li>
        </ul>
        <p data-source-node="n72">Toggle Buttons</p>
        <ul data-source-node="n73">
            <li data-source-node="n74">
                <p data-source-node="n75">Create Work - indicate how the system should process cycle count plans.</p>
                <ul data-source-node="n76">
                    <li data-source-node="n77">
                        <p data-source-node="n78">If toggle is selected, the system will create work for this plan.</p>
                    </li>
                    <li data-source-node="n79">
                        <p data-source-node="n80">If toggle is not selected, the system will not create work for this plan. Instead, workers will execute this plan from a cycle count list paperwork document.</p>
                    </li>
                </ul>
            </li>
        </ul>
        <ul data-source-node="n81">
            <li data-source-node="n82">
                <p data-source-node="n83">Update cycle counts- the current count of containers that have matched this QC assignment criteria. The system will increment this count value up by one every time QC evaluation occurs and a matching container is found. Note that this field is never editable by the user.</p>
            </li>
        </ul>
        <p data-source-node="n84">Run with scheduled job - Indicate that you want the system to execute a cycle count plan (using this master) at a certain date/time via a system scheduled job.</p>
        <p data-source-node="n85"> </p>
        <p data-source-node="n86">Randomize number of counts - Indicate that you want the system to create cycle count requests from a random set of locations (based on the range as defined in your Cycle Count Location Selection record for this master).</p>
        <p data-source-node="n87"> </p>
        <h5 data-source-node="n88">2. Authorized Warehouses</h5>
        <p data-source-node="n89">Select the warehouses authorized for the cycle count.</p>
