
        
        <h1 data-source-node="n57"><a name="kanchor912" data-source-node="n58"></a>Carrier/Service Button</h1>
        <p data-source-node="n59">This button indicates if a routing guide record 
 is associated with a carrier/service.</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">If 
 this button contains a value, a carrier/service will transport 
 product when a routing guide is applied to a shipment.<br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64">If 
 this button does not contain a value, a carrier group is associated 
 with a routing guide. The system will select the appropriate carrier/service 
 from this carrier group.</li>
        </ul>
