
        
        <h1 data-source-node="n56"><a name="kanchor269" data-source-node="n57"></a>Container Contents Label</h1>
        <p data-source-node="n58">A container contents label identifies the items packed into a specific 
 container. This label also includes such data as the item location, quantity, 
 and basic shipment information. Container contents labels can be 
 automatically printed during the container creation wave step. You can 
 also manually print this label in the Shipping Container Insight (once the container 
 has been packed). </p>
