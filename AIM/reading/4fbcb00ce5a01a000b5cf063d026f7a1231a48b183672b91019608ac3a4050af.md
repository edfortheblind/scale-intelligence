        <h4 data-source-node="n239"><a name="Searching" data-source-node="n240"></a>Searching/Viewing Shipment Records...</h4>
        <p data-source-node="n241">You can use the Shipment Insight Screen to search for and view shipment records in your warehouse. </p>
        <ol data-source-node="n242">
            <li value="1" data-source-node="n243">Open the Shipment Insight Screen.<br data-source-node="n244"><br data-source-node="n245"></li>
            <li value="2" data-source-node="n246">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n247"><br data-source-node="n248"></li>
            <li value="3" data-source-node="n249">Press the Search Button. The system will display  the resulting records in the List Pane. <br data-source-node="n250"><br data-source-node="n251"></li>
            <li value="4" data-source-node="n252">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>

        <h4 data-source-node="n256"><a name="Invoke" data-source-node="n257"></a>Invoke Shipment Insight from Shipping 
 Load Insight...</h4>
        <p data-source-node="n258">If you want to invoke Shipment Insight from Shipping Load Insight, complete the procedures below: </p>
        <p data-source-node="n259"> </p>
        <ol data-source-node="n260">
            <li value="1" data-source-node="n261">
                <p data-source-node="n262">Select a record from the List Pane of Shipping Load Insight and tap on the Shipment Indicator Tiles to open the Shipment Insight screen.</p>
                <p data-source-node="n263"> </p>
            </li>
            <li value="2" data-source-node="n264">
                <p data-source-node="n265">The Shipment Insight screen should open with these predefined search criteria - Shipping Load. All the shipments tied to that shipping load should get displayed accordingly in the list pane. </p>
                <p data-source-node="n266"> </p>
            </li>
            <li class="li_7" value="3" data-source-node="n267">	Hyperlink does not appear if you do not have the required security permission for accessing the Shipment Insight screen. </li>
        </ol>

        <h4 data-source-node="n316"><a name="DetailsPane" data-source-node="n317"></a>About the Detail Pane...</h4>
        <p data-source-node="n318">The Shipment Insight Screen's Detail Pane displays the specific field values associated with a selected record in the List Pane.<br data-source-node="n319"><br data-source-node="n320"></p>
        <p data-source-node="n321">The Detail Pane of Shipment Insight contains Indicator Tiles with counts of the other entities (i.e. shipment lines and shipping containers).  If you click/tap on those indicator tiles, it will take you to the appropriate screen showing the selected data provided you have the required security to access those called screens. Here Indicator Tiles are added for the following: </p>
        <ol data-source-node="n322">
            <li value="1" data-source-node="n323">Lines<br data-source-node="n324"><br data-source-node="n325"><ol data-source-node="n326"><li value="1" data-source-node="n327">Displays the number of shipment line records on the load.<br data-source-node="n328"><br data-source-node="n329"></li><li value="2" data-source-node="n330"><p data-source-node="n331">Clicking on this tile takes you to Shipment Line Insight web screen filtering on the given load number.<br data-source-node="n332"><br data-source-node="n333"></p></li></ol></li>
            <li value="2" data-source-node="n334">Containers<br data-source-node="n335"><br data-source-node="n336"><ol data-source-node="n337"><li value="1" data-source-node="n338"><p data-source-node="n339">Displays total number of containers on the load.<br data-source-node="n340"><br data-source-node="n341"></p></li><li value="2" data-source-node="n342"><p data-source-node="n343">Clicking on this tile takes you to Shipping Container Insight filtering on the given load number. <br data-source-node="n344"></p></li></ol></li>
            <br data-source-node="n345">
        </ol>

        <h4 data-source-node="n355"><a name="Actions" data-source-node="n356"></a>Screen Actions...</h4>
        <p data-source-node="n357">The following actions are accessible from the List Pane:</p>
        <p data-source-node="n358"> </p>
        <p data-source-node="n359"> </p>
        <h5 data-source-node="n360">New</h5>
        <p data-source-node="n361">This action enables you to manually create a new shipment from the Shipment Insight screen. When this action is selected, the system will open the Shipment screen in new mode.  The shipment will be created at the status configured in the “Default Status When Added from shipping” Outbound Status Action.  For more information on creating shipments, see the <a href="9d7b6f8eb86f821e91644205e500f232cd099762c4e804be2fb56a39a81dcff5.html" data-source-node="n362">Creating/Editing a Shipment</a> topic.</p>
        <p data-source-node="n363"> </p>
        <p data-source-node="n364"> </p>
        <h5 data-source-node="n365">Copy</h5>
        <p data-source-node="n366">This action allows you to copy the selected shipment from the List Pane of Shipment Insight into the Shipment screen. When this action is selected, the system will open the Shipment screen in new mode. You may edit the fields also in the shipment if required. The shipment will be created at the status configured in the “Default Status When Added from shipping” Outbound Status Action.  </p>
        <p data-source-node="n367"> </p>
        <p data-source-node="n368"> </p>
        <h5 data-source-node="n369">Edit</h5>
        <p data-source-node="n370">This action allows you to change field values on the shipment. When this action is selected, the system will open the Shipment screen in edit mode. </p>
        <p data-source-node="n371"> </p>
        <p data-source-node="n372"> </p>
        <h5 data-source-node="n373">Delete</h5>
        <p data-source-node="n374">This action allows you to delete a shipment or multiple shipments when there is no active work associated with the shipment(s). Note that this action is disabled when the trailing status of the shipment is less than Picking Pending and the leading status is greater than or equal to Load Confirm Pending. For more information on deleting shipments, see the <a href="b8cac7af3607a14a426e1d6a3d5e77e50dacdb7dc06933dc6737652d5d59d465.html" data-source-node="n375">Shipment Processing</a> topic.</p>
        <p data-source-node="n376"> </p>
        <p data-source-node="n377"> </p>
        <h5 data-source-node="n378">New Line</h5>
        <p data-source-node="n379">This action allows you to create a new shipment line and redirects you to the Shipment Line screen in the new mode. The action is not available if the shipment is in cancellation or the shipment is being deleted or the shipment is in load confirmation or if the shipment's trailing status is greater than or equal to Load Confirm Pending. </p>
        <p data-source-node="n380"> </p>
        <p data-source-node="n381"> </p>
        <h5 data-source-node="n382">View/Edit Accessorials</h5>
        <p data-source-node="n383">This action enables you to ship an order with the appropriate accessorials. Selecting a Shipment ID and clicking on this opens the Accessorial Assignment screen. Refer to the topic <a href="20ae483e95cd8c4155eef53cafcca4eaa8681885f39691a08a794a733dcc116a.html" data-source-node="n384">Assigning Accessorials</a> for additional information. </p>
        <p data-source-node="n385"> </p>
        <p data-source-node="n386"> </p>
        <h5 data-source-node="n387">Cancel</h5>
        <p data-source-node="n388">This action allows you to cancel a shipment or multiple shipments, as long as the leading status of the shipment(s) falls within Packing Pending and Ship Confirm Pending. For more information on canceling shipments, see the <a href="b8cac7af3607a14a426e1d6a3d5e77e50dacdb7dc06933dc6737652d5d59d465.html" data-source-node="n389">Shipment Processing</a> topic.</p>
        <p data-source-node="n390"> </p>
        <p data-source-node="n391"> </p>
        <h5 data-source-node="n392">Confirm</h5>
        <p data-source-node="n393">This action allows you to confirm one or more shipment, as long as the shipment is on a shipping load and the status is greater than or equal to Picking Pending and less than Load Confirm Pending.  The Confirm Shipment action is not available when the shipment is on an unreleased wave, or when it is canceled or deleted, or the shipment is transferred or unassigned from a shipping load.  For more information on confirming shipments, see the <a href="b8cac7af3607a14a426e1d6a3d5e77e50dacdb7dc06933dc6737652d5d59d465.html" data-source-node="n394">Shipment Processing</a> topic. </p>
        <p data-source-node="n395"> </p>
        <p data-source-node="n396"> </p>
        <h5 data-source-node="n397">Consolidate</h5>
        <p data-source-node="n398">This action enables you to consolidate all the shipments with the one that you selected from the List Pane of Shipment Insight. It opens the Shipment Consolidation Screen. For more general information on shipment consolidation, see the <a href="990cca6e65bb09d27235649580d624d864065d9921bc602524e3ba41f75ce66e.html" data-source-node="n399">Shipment Consolidation Window</a> topic.</p>
        <p data-source-node="n400"> </p>
        <p data-source-node="n401"> </p>
        <h5 data-source-node="n402">Immediate Needs</h5>
        <p data-source-node="n403">This action allows you access the Immediate Needs Insight screen from Shipment Insight. The Immediate Needs Insight action is enabled if the shipment line has at least one immediate needs item and there is an immediate needs request created for the item. If the immediate needs request is fulfilled, this action will not be available while selecting the shipment from List Pane. Pressing on the Immediate Needs action will open the Immediate Needs Insight screen using the reference ID (Shipment ID) and the warehouse as predefined search criteria. </p>
        <p data-source-node="n404"> </p>
        <p data-source-node="n405"> </p>
        <h5 data-source-node="n406">Manifest at Shipment Level</h5>
        <p data-source-node="n407">This action enables you to manually manifest a selected shipment, if the shipment is in a proper state to allow manifesting. For more information on manifesting containers, see the topic <a href="e545773cb9f1eea00e8cc790d8f07163d4368a9a92034238b27c12a021ec1d2c.html" data-source-node="n408">Manifesting a Container/Shipment</a>.</p>
        <p data-source-node="n409"> </p>
        <p data-source-node="n410"> </p>
        <h5 data-source-node="n411">Pack</h5>
        <p data-source-node="n412">This action allows you to pack shipment lines into shipping containers.  Selecting the action will open the Packing screen.</p>
        <p data-source-node="n413"> </p>
        <p data-source-node="n414"> </p>
        <h5 data-source-node="n415">Print Preview</h5>
        <p data-source-node="n416">This action allows you to generate and display a PDF version of the selected document type. For more information on this topic, refer to <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n417">Printing Paperwork</a>. </p>
        <p data-source-node="n418"> </p>
        <p data-source-node="n419"> </p>
        <h5 data-source-node="n420">Print Default Docs</h5>
        <p data-source-node="n421">This action allows you to print the default shipping documents that have both the print procedure for "shipment" setting and the default setting selected on the document’s Document Type record. </p>
        <p data-source-node="n422"> </p>
        <p data-source-node="n423"> </p>
        <h5 data-source-node="n424">Print Selected Docs</h5>
        <p data-source-node="n425">This action allows you to print all the selected documents.  For more information on printing topic, see the <a href="9e44fc4a2818a3126ea3add44e9b0cd8b6f99b7068fae02daff83da4050968b9.html" data-source-node="n426">Printing Paperwork</a> topic. </p>
        <p data-source-node="n427"> </p>
        <p data-source-node="n428"> </p>
        <h5 data-source-node="n429">Receipt from Shipment</h5>
        <p data-source-node="n430">This action allows you to open the Receipt from Shipment screen with all the selected shipment-related data populated on the screen. Users can create receipt from shipment for a shipment with single as well as multiple details. System will use the returned quantity entered for each detail and create receipt with all the details based on the inputs. Refer to the topic <a href="839bcd97b359849b55cefbf2a3536c3e9dadcb33d7fb01b8899309b188e40627.html" data-source-node="n431">Creating a Receipt From a Shipment</a> for additional information. </p>
        <p data-source-node="n432"> </p>
        <p data-source-node="n433"> </p>
        <h5 data-source-node="n434">Remove from Load</h5>
        <p data-source-node="n435">This action allows you to remove the selected shipments from the assigned shipping load.</p>
        <p data-source-node="n436"> </p>
        <p data-source-node="n437"> </p>
        <h5 data-source-node="n438">Route</h5>
        <p data-source-node="n439">This action enables you to route a shipment from the Shipment Insight. This is especially helpful if you change something about the shipment (e.g. weight, destination) and need to route it with its new properties. For more information on routing, see the topic <a href="d2e0349e69309ddf097172d98a477fdf863f8b3e3e8cc8ccb0a3008807043101.html" data-source-node="n440">Rating/Routing Shipments</a>.</p>
        <p data-source-node="n441"> </p>
        <p data-source-node="n442"> </p>
        <h5 data-source-node="n443">Transfer Shipment</h5>
        <p data-source-node="n444">This action allows you to transfer a shipment to a new shipping load.</p>
        <p data-source-node="n445"> </p>
        <p data-source-node="n446"> </p>
        <h5 data-source-node="n447">Split Shipment</h5>
        <p data-source-node="n448">You can manually assign the shipments after they have been run through different waves by splitting it. To split multiple shipment lines to a new shipment, select the multiple rows by clicking on the respective checkboxes and then select the Split Shipment action. </p>
        <p data-source-node="n449"> </p>
        <p data-source-node="n450"> </p>
        <h5 data-source-node="n451">VAS Activity</h5>
        <p data-source-node="n452">This action can be used to search VAS activities associated with all the containers for a particular shipment. On selecting this action, system redirects the user to the VAS Insight screen and the shipment ID will get defaulted to the Shipment Id field of the Filter Pane of VAS Insight. The related results get displayed on the list pane. A row in the List Pane of Shipment Insight needs to be selected for using this action.</p>
