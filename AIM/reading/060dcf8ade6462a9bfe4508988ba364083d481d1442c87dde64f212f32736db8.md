        <ol class="ol_1" data-source-node="n118">
            <li value="1" data-source-node="n119">Take the numbers from the odd positions and multiple 
 that number by 2: 02568 X 2 = 05136<br data-source-node="n120"> </li>
            <li value="2" data-source-node="n121">Take the results and add its individual numbers: 
 0 + 5 + 1 + 3 + 6 = 15<br data-source-node="n122"> </li>
            <li value="3" data-source-node="n123">Add the numbers from the even positions: 0 + 1 
 + 0 + 1 = 2<br data-source-node="n124"> </li>
            <li value="4" data-source-node="n125">Add the results from steps b and c: 
 15 + 2 = 17<br data-source-node="n126"> </li>
            <li value="5" data-source-node="n127">Subtract the result in step d from 100: 100 – 
 17 = 83<br data-source-node="n128"> </li>
            <li value="6" data-source-node="n129">Add two to the result from the last digit in step 
 e:  3 + 
 2 = 5 (If this number is larger than 9 drop the first digit; for example, 
 10 would become 0)<br data-source-node="n130"> </li>
            <li value="7" data-source-node="n131">Multiple the base pro number by 10: 002150618 
 * 10 = 0021506180<br data-source-node="n132"> </li>
            <li value="8" data-source-node="n133">Add the result of step f to the result of step 
 g: 0021506180 + 5 = 021506185</li>
