
        
        <h1 data-source-node="n56"><a name="kanchor1844" data-source-node="n57"></a>Reviewing Application Identifiers</h1>
        <p data-source-node="n58">An application identifier is a segment of a GS1 barcode that represents 
 the data that the barcode section contains. The identifiers provided with 
 SCALE are standard for GS1 processing, and typically should not be edited. 
 The application identifiers defined in this window mimic the requirements 
 set by the GS1 standards association.</p>

        <h4 data-source-node="n192">Procedures...</h4>
        <ol class="ol_1" data-source-node="n193">
            <li value="1" data-source-node="n194">The Application 
 Identifier Field indicates the name of the AI. These are standard 
 identifiers that cannot be changed.<br data-source-node="n195"> </li>
            <li value="2" data-source-node="n196">The Default SCALE 
 Mapped Field indicates the value in the system that this AI will 
 represent. For example, the GTIN application identifier maps to SCALE's 
 "Item" field. This field allows the user to change the Default SCALE Mapped Field between the Item and Item Cross Reference fields for the 01 and 02 identifiers only.  Note that none of the other AIs use this field.  <br data-source-node="n197"> </li>
            <li value="3" data-source-node="n198">The GS1 Title 
 Field indicates the name provided for this AI by the GS1 standards 
 association. This value is not used in SCALE GS1 processing. <br data-source-node="n199"> </li>
            <li value="4" data-source-node="n200">The String Format 
 Type Field indicates if this AI will have numeric or alphanumeric 
 values.<br data-source-node="n201"> </li>
            <li value="5" data-source-node="n202">The String Length 
 Field indicates the character length of this AI's value.<br data-source-node="n203"> </li>
            <li value="6" data-source-node="n204">The String Length 
 Type Field indicates how SCALE will expect GS1 data to enter the 
 system when scanned:<br data-source-node="n205"><br data-source-node="n206">- Fixed Length: The data value 
 has to be of a certain size, or the system will return an error when the 
 AI is scanned. For example, if the value is set at a length of three 
 characters, then every value for this AI must be three digits (such as 
 002, 012, 124). <br data-source-node="n207"><br data-source-node="n208">- Variable Length: The data 
 value can be of any size. <br data-source-node="n209"> </li>
            <li value="7" data-source-node="n210">The Decimal Indicator 
 Checkbox is not used at this time.<br data-source-node="n211"> </li>
            <li value="8" data-source-node="n212">Press OK.</li>
        </ol>
