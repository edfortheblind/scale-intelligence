Assigning Accessorials

An accessorial is an additional cost levied to cover special processing for a parcel. Examples of accessorials include Cash On Delivery (COD), Delivery Confirmation, or Saturday Delivery. For an accessorial to take effect, it must be applied before you manifest a container. If you assign an accessorial after a container is manifested, you must re-manifest the container in the Shipping Container Insight screen for the accessorial to take effect. When a container is manifested, the shipping cost is based on the carrier's shipping rate + any accessorial(s).

Procedures...

  1. Access the Accessorial Assignment screen from one of the following places:

    - Shipping Container Insight Screen: From the Actions Menu, select Edit Accessorials.  These are assigned at the container or container contents level.

    - Shipment Insight Screen: From the Actions Menu, select Edit Accessorials. These are assigned at the shipment level.
     
  2. Choose the accessorial(s) you want to assign to this container. An Edit accessorial screen will open with a list of accessorial types.

    NOTE: The grid on the Accessorial Assignment screen will be empty when first assigning accessorials. This grid will only display the assigned accessorials.
     

  3. Select an accessorial type from the list. This will display all the accessorial details for the accessorial type.

  4. Enter values for the desired accessorials and select Save. The selected accessorials will be added to the grid on the Accessorial Assignment screen.

  5. Select Save on the Accessorial assignment screen to save the edited accessorials.

NOTE: You can delete the accessorials by selecting the row in the accessorial grid and pressing the Delete button.

Note On RMA Numbers and FedEx Returns...

It is important to note that all containers on the same shipment must have the same Return Shipment Indicator (RMA) number for FedEx returns. For shipments that proactively allow for returns (e.g. including a returns label in the original container to make it easy to return the product), then they need to have the RMA marked on each container where SCALE is going to generate a return label. For each of these containers on a given shipment, there is another detail record under the accessorial for the RMA number. This RMA number must be the same for each container on the shipment, but keep in mind that the system does not validate this. FSMS will print the first RMA number that it sees for the shipment on all return labels for that shipment regardless.
