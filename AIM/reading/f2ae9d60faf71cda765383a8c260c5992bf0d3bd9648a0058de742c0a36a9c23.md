
        
        <h1 data-source-node="n56"><a name="kanchor357" data-source-node="n57"></a>Cycle Count List</h1>
        <p data-source-node="n58">A cycle count list represents all of the open cycle count requests that 
 are contained on a certain cycle count plan. This document identifies 
 the location and item that needs cycle counted, as well as the expected 
 quantity of an item in that location. When you perform a cycle count, 
 you can indicate the number of items actually present in a location in 
 the Actual Quantity Field. </p>
