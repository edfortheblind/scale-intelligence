
        
        <h1 data-source-node="n56">Color Field</h1>
        <p data-source-node="n57">This field indicates the color of a certain item. This value is typically used for retail products (such as clothing).</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">On Viewers Configuration Window...</h5>
        <p data-source-node="n61">You can use this field to choose a color that you want to assign to 
 certain records that will display on the results screen of a custom viewer. 
 The system will use the rules defined in this window to determine what 
 records it shades using this color. If you do not assign any rules to 
 this color record, the system will shade all results row(s) using this 
 color. </p>
