Reviewing Transmit Status Values

A transmit status indicates whether the Manifests have been transmitted to the appropriate carrier or not. There are two Transmit statuses- Transmitted and Not transmitted. Transmitted status indicates an EDI (Electronic Data Interchange) file with manifest data has been transmitted for the carrier associated with the manifest. Not transmitted status suggests that the manifest was not transmitted when the manifest was closed. Refer to the Using the Manifest Insight Screen topic for more information.
