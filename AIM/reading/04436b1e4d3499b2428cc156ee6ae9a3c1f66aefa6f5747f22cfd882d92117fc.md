
        
        <h1 data-source-node="n56"><a name="kanchor1828" data-source-node="n57"></a>Zones Away Field</h1>
        <p data-source-node="n58">This field indicates which zone contains items that are currently ready 
 to be picked into a container.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Below are some example values:</p>
        <ul data-source-node="n61">
            <li data-source-node="n62">
                <p data-source-node="n63">Equals "0" for a particular 
 zone: this zone has item(s) ready to be picked.</p>
                <p data-source-node="n64"> </p>
            </li>
            <li data-source-node="n65">Equals "2" 
 for a particular zone: before this zone is ready to be picked, 
 there are 2 other zones that have to be picked from.</li>
        </ul>
