
        
        <h1 data-source-node="n56"><a name="UsingTheDocumentRoutingViewer" data-source-node="n57"></a>Using the Document Routing Viewer</h1>
        <p data-source-node="n58">You can use the viewer to edit, copy, and delete multiple document routing records.  From the Configuration Explorer window you can edit, copy, or delete a single record.  The Document Routing Viewer allows the selection of multiple records to perform the same actions. You can also select multiple records with different document types and customize the document routing viewer from the Actions menu. </p>

        <h4 data-source-node="n133"><a name="SearchingDocumentRouting" data-source-node="n134"></a>Searching Document Routing Records...</h4>
        <p data-source-node="n135">You can use the Document Routing Viewer to perform searches for document routing records.</p>
        <p data-source-node="n136"> </p>
        <ul data-source-node="n137">
            <li data-source-node="n138">
                <p data-source-node="n139">Enter the criteria that you want to use to define your search.<br data-source-node="n140"><br data-source-node="n141"></p>
            </li>
            <li data-source-node="n142">
                <p data-source-node="n143">Press Search. The system will display the resulting records from your search in the Results Tab.</p>
            </li>
        </ul>
        <p data-source-node="n144"> </p>
        <hr width="100%" align="center" data-source-node="n145">

        <h4 data-source-node="n148"><a name="EditingDocumentRouting" data-source-node="n149"></a>Editing Single Document Routing Record...</h4>
        <p data-source-node="n150">You can edit a single record from the Configuration Explorer as well as from  the Document Routing Viewer Window. This is helpful  when the data on a record does not reflect the desired details. </p>
        <ul data-source-node="n151">
            <li data-source-node="n152">
                <p data-source-node="n153">Double-click to open the specific record under Document Routing window from the Configuration Explorer. The Routing criteria tab is opened by default. </p>
                <p data-source-node="n154">
                    <br data-source-node="n155">
                </p>
            </li>
            <li data-source-node="n156">Modify the existing record and click OK. </li>
        </ul>
        <p data-source-node="n157">Alternatively, you can also open the  Document Routing Viewer Window and search for the record you want to modify. Under the Results tab, the record will be displayed. You can right-click on that specific record and press Edit. </p>
        <p data-source-node="n158"> </p>
        <hr width="100%" align="center" data-source-node="n159">
        
        <p data-source-node="n160"> </p>
        <p data-source-node="n161"> </p>
        <h4 data-source-node="n162"><a name="EditingMultipleDocumentRouting" data-source-node="n163"></a>Editing Multiple Document Routing Records...</h4>
        <p data-source-node="n164">You can edit multiple records from the Document Routing Viewer Window. </p>
        <p data-source-node="n165"> </p>
        <ul data-source-node="n166">
            <li data-source-node="n167">
                <p data-source-node="n168">Select multiple records from the Document Routing Viewer Window. </p>
                <p data-source-node="n169">
                    <br data-source-node="n170">
                </p>
            </li>
            <li data-source-node="n171">Right-click and press Edit. </li>
        </ul>
        <p data-source-node="n172">This opens the Document routing window  with fields and the corresponding check-boxes. This checkboxes will be enabled based on the document type being edited. </p>
        <p data-source-node="n173"> </p>
        <p data-source-node="n174">NOTE: If multiple document types have been selected, then only the username, warehouse, number of copies, machine name, and device name are editable.  All fields will be disabled until the user checks one of the enabled checkboxes.  So the field can be edited only after the checkbox is enabled.  If multiple records have been selected and there are multiple values for a field, then the field will show multiple.  These fields can also be updated to a single value.</p>
        <p data-source-node="n175"> </p>

        <h4 data-source-node="n179"><a name="DeletingDocumentRouting" data-source-node="n180"></a>Deleting Single Document Routing Record...</h4>
        <p data-source-node="n181">You can delete a single record from the Configuration Explorer as well as from  the Document Routing Viewer Window. Right-click on the selected record and press Delete to delete the specific record. </p>
        <p data-source-node="n182"> </p>
        <hr width="100%" align="center" data-source-node="n183">
        
        <p data-source-node="n184"> </p>
        <p data-source-node="n185"> </p>
        <h4 data-source-node="n186"><a name="DeletingMultipleDocumentRouting" data-source-node="n187"></a>Deleting Multiple Document Routing Records...</h4>
        <p data-source-node="n188">You can delete multiple records from the Document Routing Viewer Window. </p>
        <ul data-source-node="n189">
            <li data-source-node="n190">
                <p data-source-node="n191">Select multiple records from the Document Routing Viewer Window.</p>
                <p data-source-node="n192">
                    <br data-source-node="n193">
                </p>
            </li>
            <li data-source-node="n194">Right-click and press Delete. </li>
        </ul>
        <p data-source-node="n195">This opens a confirmation window. Click Yes if you confirm the delete action. </p>
        <p data-source-node="n196"> </p>
        <p data-source-node="n197"> </p>
        <h4 data-source-node="n198"><a name="CopyingDocumentRouting" data-source-node="n199"></a>Copying Single Document Routing Record...</h4>
        <p data-source-node="n200">You can copy a single record from the Configuration Explorer as well as from  the Document Routing Viewer Window. Right-click on the selected record and press Copy to copy the specific record. This opens the Document Routing - Create New dialog box in the copy mode. If the document routing records get successfully updated, you will receive a confirmation message. </p>
        <p data-source-node="n201"> </p>
        <hr width="100%" align="center" data-source-node="n202">
        
        <p data-source-node="n203"> </p>
        <p data-source-node="n204"> </p>
        <h4 data-source-node="n205"><a name="CopyingMultipleDocumentRoutingViewer" data-source-node="n206"></a>Copying Multiple Document Routing Records...</h4>
        <p data-source-node="n207">You can copy multiple records from the Document Routing Viewer Window. </p>
        <ul data-source-node="n208">
            <li data-source-node="n209">
                <p data-source-node="n210">Select multiple records from the Document Routing Viewer Window.</p>
                <p data-source-node="n211">
                    <br data-source-node="n212">
                </p>
            </li>
            <li data-source-node="n213">Right-click and press Copy. </li>
        </ul>
        <p data-source-node="n214">This opens the Document Routing - Create New dialog box in the copy mode. Multiple is shown for all the fields with multiple document routing records. You will be prompted to continue with the copy action after selecting multiple records from the Document Routing Viewer and clicking OK in the Document Routing - Create New dialog box. The message also will display the number of records being copied. If you continue and the document routing records get successfully created, you will receive a confirmation message. </p>
        <p data-source-node="n215"> </p>
        <p data-source-node="n216">NOTE: The system will automatically Refresh document routing records in the viewer after the completion of edit/deletion/copy action. </p>
