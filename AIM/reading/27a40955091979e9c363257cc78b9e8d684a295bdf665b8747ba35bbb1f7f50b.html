Reviewing Work System Values

These system-defined values accommodate specific events that may occur during the work process. When the system encounters an unexpected experience during work creation or work execution, it will display the appropriate system defined values. You should not need to create unique values on this window.

Value Key

 

Value Description

 

10 - Max Work records retrieved in System Directed Work

 

This value indicates the maximum number of work instructions that will be displayed to the user from a particular work unit. The system honors this value only during system-directed work.

 

20 - Number of Locations To Display On Override Pick

 

This value determines how many locations the system will display on the RF Override Pick screen (when the user presses the Location Lookup Button).

 

30 - Hide Non-Significant Dec Positions on RF Picking?

 

This value determines how decimal positions are displayed on the RF device when performing picking. If this value is set to 'N' then the system displays the number of decimal positions that is defined in the Decimal Positions configuration 'Quantity' setting. If this value is 'Y' then the system will only display the decimal positions up to the last non-zero value (for example, 11.48 vs 11.4800).

 

40 - Priority For Work In Transit to Short Pick Loc

 

This value determines the priority the system will assign to a work instruction that has in transit quantity to meet a short-picked location's demand replenishment need. This value is only used when, during RF work execution, the system invokes the "Demand From RF Outbound Short Pick" replenishment type.

 

50 - Remove Container from cart when work is passed?

 

This value determines if the system will remove all the containers from the cart picking when the user elects to pass work during group user work execution:

  • No: The system will not remove the containers.

  • Warn: The system will display a confirmation message, and the user can then decide whether or not to remove the containers (on the message, the user would press "OK" to remove, press "Cancel" to pass the work without removing).

  • Yes: The system will remove the containers

 

 

60 - Number of instructions

per RF Pick screen page

 

This value determines the number of work instructions displayed per page when the user selects "View Picks" for RF shipment work.

 

 

Compute Zones Away

This value determines if you want the system to calculate "zones away" data in the Picking Management Window.

 

Container Prefix

This value identifies the prefix that the system will use when validating a Container ID value for a container that is created "on the fly" during work execution. If a value is defined here, the system will return an error if a container is created "on the fly" with an ID that does not match this prefix.

 

Display RF Work Comments

This value determines whether or not the system will display comments during the RF picking process. These comments are defined on the Comment Type Window. Note that displaying these comments can slow down RF performance.

 

100 - Display Warehouse Mobile Work Text Messages

This value determines whether or not the system will display text messages during the RF and Warehouse Mobile picking process. These messages are defined on the Text Message Window. Note that displaying these messages can slow down RF performance.

 

New Work Delimiter

This value identifies the delimiter character you want to use to ensure that each work unit in the system is unique.

 

Also, the system uses this value to assign container IDs if, while in manual container assignment mode, the user splits a receiving container during locating. The system will use the character you provide for this value and append it to the existing container ID. Therefore, if container A was split into two containers, the resulting two containers would have the ID's of A#000001 and A#000002.

 

Pick All Quantity Text

This value identifies the text message that the system will display if the current pick will empty a location.

 

RF Session Timeout

This value identifies how many minutes the system will wait before timing out an RF device. This time span resets to zero minutes after each RF action (such as performing a pick or a putaway).

 

Unassigned Equipment Type

This value identifies the equipment type that will be used in Labor Management if you did not identify equipment types.

 

Unassigned Work Team

This value identifies the work team that will be used in Labor Management if you did not identify work teams.

 

90- Un-assign work on logout from RF?

This value will determine if the system will un assign the un-assign user from work in case of log out due to new session. By default it is Y and will un-assign the user.

If set to N, then will retain the assigned user even on log out due to new session.

User Name Defaulted

This value indicates that the system would default the user name value when using the picking management module. When this value is active, the user name on the pick management assignment screen defaults from the user who is signed in to the system. When this value is inactive, the user name defaults to blank.

 

Wave Hold

This value identifies the hold code. All work is held after the wave is run, unless the wave is set to automatically release.

 

Wave Replen Work Type

This value allows the work type that is specified to be applied to any replenishment work created in a wave. The system will assign this work type (and its priority) to the wave-generate replenishment work. This is helpful when wanting to distinguish between replenishment work created by the wave and replenishment work created manually.

 

Work Unit

 

This value identifies the value assigned to a work unit during work creation.

WM Session Timeout - Warehouse Mobile Session Timeout value (in minutes)

 

The warehouse mobile will log out for the user when it is inactive more than the set time limit. A message Your session has ended and you have been signed off. Please sign onto the system again is displayed to the user.
