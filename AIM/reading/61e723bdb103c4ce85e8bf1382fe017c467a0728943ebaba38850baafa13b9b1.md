
        
        <h1 data-source-node="n56">Using the Metadata Database Table View Window</h1>
        <p data-source-node="n57">The Metadata Database Table View Window enables the user to add a column of the table to the insight screen.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59">The Metadata Screen Control Grid Columns Window defines the grid column type of User Interface (UI) element that will be included in the Insight screen.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">Steps to add column in the grid.</p>
        <p data-source-node="n62"> </p>
        <ul data-source-node="n63">
            <li data-source-node="n64">
                <p data-source-node="n65">Navigate to <b data-source-node="n66">ListPaneDataGrid &gt;&gt; Screen Control grid Column</b> accordion.</p>
            </li>
            <li data-source-node="n67">
                <p data-source-node="n68">Click <b data-source-node="n69">Add</b> button to view <b data-source-node="n70">Database Table View</b> screen.</p>
            </li>
            <li data-source-node="n71">
                <p data-source-node="n72">Select the column name and Click <b data-source-node="n73">Add</b> button.</p>
            </li>
            <li data-source-node="n74">
                <p data-source-node="n75">Details screen will enable user to define the properties for the column selected.</p>
            </li>
            <li data-source-node="n76">
                <p data-source-node="n77">Click <b data-source-node="n78">Save</b>. View the insight screen to view the new column added in the grid.</p>
            </li>
        </ul>
        <p data-source-node="n79">Read Developer Hub for more information.</p>
