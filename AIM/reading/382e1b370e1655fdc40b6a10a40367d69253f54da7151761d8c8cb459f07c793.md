        <p data-source-node="n58">If you manually create a wave, you must manually add shipments to it. 
 You can also manually add shipments to existing waves. You can add or 
 transfer a shipment to a wave if the wave is neither closed nor released.</p>

        <h4 data-source-node="n112"><a name="addShipMobile" data-source-node="n113"></a>Adding a Shipment to a Wave...</h4>
        <ol data-source-node="n114">
            <li value="1" data-source-node="n115">
                <p data-source-node="n116">Access the Planned Shipment Insight screen.<br data-source-node="n117"><br data-source-node="n118"></p>
            </li>
            <li value="2" data-source-node="n119">
                <p data-source-node="n120">Select a shipment that is in the pool.<br data-source-node="n121"><br data-source-node="n122"></p>
            </li>
            <li value="3" data-source-node="n123">
                <p data-source-node="n124">Open the Actions menu and tap on Add shipment to wave or Transfer to another wave.  This opens the Add Shipment to Wave screen.<br data-source-node="n125"><br data-source-node="n126"></p>
                <p data-source-node="n127">NOTE: If you select the Transfer to another wave action, the Add Shipment to Wave screen opens with the list of existing waves and an option to transfer to a new wave. This action is enabled only when the  leading and trailing status of the shipment is 'Wave Pending' and the shipment is on a wave.<br data-source-node="n128"><br data-source-node="n129"></p>
            </li>
            <li value="4" data-source-node="n130">
                <p data-source-node="n131"> You can assign this record to either a 
 new or existing wave.</p>
                <p data-source-node="n132">
                </p>
                <p data-source-node="n133">- To assign this shipment to a 
 new wave, select the New Wave Button. The system will display the New 
 Wave Window. Select this new wave record and press Save. The system will navigate 
 back to the Planned Shipment Insight screen after displaying a success message indicating that the shipment(s) were successfully added to the wave. The wave that you have added will 
 be highlighted; the system will generate a wave number for it.<br data-source-node="n134"><br data-source-node="n135">	- To assign this shipment to an existing 
 wave, select the appropriate record from the Existing Wave 
 Field and press Save.</p>
                <p data-source-node="n136"> </p>
                <p data-source-node="n137">This will add shipments selected from the Planned Shipment Insight to the wave.   <br data-source-node="n138"></p>
                <p data-source-node="n139"> </p>
            </li>
        </ol>

        <h4 data-source-node="n144"><a name="addAllShipsMobile" data-source-node="n145"></a>Adding All Filtered Shipment(s) to a Wave...</h4>
        <ol data-source-node="n146">
            <li value="1" data-source-node="n147">
                <p data-source-node="n148">Access the Planned Shipment Insight screen.<br data-source-node="n149"><br data-source-node="n150"></p>
            </li>
            <li value="2" data-source-node="n151">
                <p data-source-node="n152">Select a shipment that is in the pool.<br data-source-node="n153"><br data-source-node="n154"></p>
            </li>
            <li value="3" data-source-node="n155">
                <p data-source-node="n156">Open the Actions menu and tap on Add all filtered shipments to wave.  This opens the Add Shipment to Wave screen. The system will add all the shipments that are returned out of search criteria.  <br data-source-node="n157"><br data-source-node="n158"></p>
            </li>
            <li value="4" data-source-node="n159">
                <p data-source-node="n160"> You can assign this record to either a 
 new or existing wave.</p>
                <p data-source-node="n161"> </p>
                <p data-source-node="n162">- To assign this shipment to a 
 new wave, select the New Wave Button. The system will display the New 
 Wave Window. Select this new wave record and press Save. The system will navigate 
 back to the Planned Shipment Insight screen after displaying a success message indicating that the shipment(s) were successfully added to the wave. The wave that you have added will 
 be highlighted.<br data-source-node="n163"><br data-source-node="n164">	- To assign this shipment to an existing 
 wave, select the appropriate record from the Existing Wave 
 Field and press Save.</p>
                <p data-source-node="n165"> </p>
                <p data-source-node="n166">This will add shipments selected from the Planned Shipment Insight to the wave.   <br data-source-node="n167"></p>
