Order Ship To Selection

These selection records provide a means for the user to define often used batches of ship to names in the system order entry system. These are useful if you have orders (containing the same items/ship to names) that are shipped on a infrequent, yet regular, basis.

 

Add New Record

  • Add Filter Name and Description.

  • Filter Builder section: You can use this tab to identify which ship to names the system will add to the batch. NOTE: To add more than one ship to name to a batch, select the Or Button each time you add a name.

  • Order By Builder: You do not need to address this tab when creating order ship to selection records. However, if you define a display order for the names using this tab, the system will honor it.
