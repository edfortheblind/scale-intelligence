
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><a name="kanchor1091" data-source-node="n58"></a>Putaway Location Group</h1>
        <p data-source-node="n59">A Putaway Location Group enables received items to be grouped together and put away as a unit. The configuration settings define how these groups function. When the first putaway group is created—either using a location range or a locating zone—all subsequent groups must follow the same method (either all range-based or all zone-based).</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">During the locating process, the system attempts to assign items to a location that belongs to an existing Putaway Group. It associates the receipt container with this group. If no group exists for the target location, the system will either:</p>
        <ul data-source-node="n62">
            <li data-source-node="n63">
                <p data-source-node="n64">Create a new Putaway Group automatically using a system-generated ID, or</p>
            </li>
            <li data-source-node="n65">
                <p data-source-node="n66">Prompt the user to assign a Putaway Group ID manually.</p>
            </li>
        </ul>
        <p data-source-node="n67">Once assigned, the system updates the Parent License Plate of the received inventory with the Putaway Group ID.</p>
        <p data-source-node="n68">When executing putaway work, tasks are generated at the group level—meaning all items in the group are handled together.</p>
        <p data-source-node="n69"> </p>
        <p data-source-node="n70">You can use putaway groups to manage returned items by placing them in a designated receiving dock area. From there, they can either be returned to their original inventory locations or moved to a special returns or repair zone.</p>
        <p data-source-node="n71"> </p>
        <h4 data-source-node="n72">Create a Putaway Group Location</h4>
        <p data-source-node="n73"> </p>
        <ul data-source-node="n74">
            <li data-source-node="n75">
                <p data-source-node="n76"><b data-source-node="n77">Warehouse</b>: Select the warehouse where the putaway group will reside.</p>
            </li>
        </ul>
        <ul data-source-node="n78">
            <li data-source-node="n79">
                <p data-source-node="n80"><b data-source-node="n81">Location Range</b>: Specify the range of locations included in the group.</p>
            </li>
        </ul>
        <ul data-source-node="n82">
            <li data-source-node="n83">
                <p data-source-node="n84"><b data-source-node="n85">Locating Zone</b>: Identify the zone of locations that define the putaway group.</p>
            </li>
        </ul>
        <ul data-source-node="n86">
            <li data-source-node="n87">
                <p data-source-node="n88"><b data-source-node="n89">Group Assignment Method</b>: Choose whether Group IDs should be manually assigned by the user or automatically generated by the system.</p>
            </li>
        </ul>
        <ul data-source-node="n90">
            <li data-source-node="n91">
                <p data-source-node="n92"><b data-source-node="n93">Maximum Units</b>: Set the maximum number of items allowed in a group. Once reached, the system closes the group and creates a new one using the same settings.</p>
            </li>
        </ul>
        <p data-source-node="n94"> </p>
        <p data-source-node="n95">Toggle Buttons</p>
        <ul data-source-node="n96">
            <li data-source-node="n97">
                <p data-source-node="n98"><b data-source-node="n99">One Per User</b>: Enable this to ensure each user processing returns is assigned a separate group, preventing overlap.</p>
            </li>
        </ul>
        <ul data-source-node="n100">
            <li data-source-node="n101">
                <p data-source-node="n102"><b data-source-node="n103">Verify Group ID</b>: When enabled, the system requires users to manually enter an existing Putaway Group ID during check-in.</p>
            </li>
        </ul>
