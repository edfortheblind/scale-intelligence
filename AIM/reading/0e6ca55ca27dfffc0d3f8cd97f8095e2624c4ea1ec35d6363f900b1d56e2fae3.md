
        
        <h1 data-source-node="n56"><a name="kanchor1259" data-source-node="n57"></a>NMFC Code Field</h1>
        <p data-source-node="n58">The NMFC code links an item to a class for 
 freight rating purposes. Each NMFC value is a sequence of letters and/or 
 numbers representing a group of like items with similar characteristics. 
 It is used primarily by LTL carriers. These codes are specified by the Interstate 
 Commerce Commission. The NMFC Field in the system is 25 characters long, 
 which will support your codes and subcodes</p>
