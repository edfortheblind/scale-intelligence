
        
        <h1 data-source-node="n56"><a name="kanchor2085" data-source-node="n57"></a>Order Processing Field</h1>
        <p data-source-node="n58">This field indicates how you want the system to handle orders that are 
 entered via Trading Partner Management.</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60"><i data-source-node="n61">Automatic</i>: 
 If you choose this method, the system will automatically create the orders 
 for this user through TPM. No additional user intervention is required.<br data-source-node="n62"> </li>
            <li data-source-node="n63"><i data-source-node="n64">Manual</i>: 
 If you choose this method, the system will save web orders as an XML file. 
 You must then later enter these XML order files into the application's 
 full screen Order Entry module.</li>
        </ul>
