
        
        <h1 data-source-node="n56"><a name="kanchor2096" data-source-node="n57"></a>Weight Tolerance Field</h1>
        <p data-source-node="n58">This field is defined on the Container Type Window. It determines how 
 much of a deviation can exist between a container's actual weight and 
 how much the system believes that it weighs. The system estimates how much a container 
 weighs during the wave and during manual packing. When it closes this 
 container, it checks the actual weight of the container and compares it 
 to the estimate. If there is a weight deviation above or below the weight 
 tolerance, the system displays an alert message. You can override this 
 value or research the weight difference.</p>
