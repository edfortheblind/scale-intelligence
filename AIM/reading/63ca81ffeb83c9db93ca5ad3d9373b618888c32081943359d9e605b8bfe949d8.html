Using Cycle Count Plans

Cycle counting is the physical verification that the inventory actually present in a location matches what the system believes is in the location. This helps you keep track of exactly how much inventory is present in your warehouse. One method you can use to trigger cycle counts is by manually creating cycle count plans (called "plan-based"). These plans include information on which item(s) and location(s) are to be counted. Cycle count plans can either be generated from a predefined "master" configuration record, or dynamically via a "quick plan" option (which allows you to choose the plan settings at the time of plan creation). You can confirm/reconcile these cycle counting requests using an RF device, Work Insight Screen, and the Cycle Count Plan Insight.

 

This topic discusses how to create and manage cycle count plans. See the topic Confirming Cycle Counts to view the procedures on how to actually execute cycle count work/confirm cycle count requests from an RF device or the Cycle Count Plan Insight.

Creating a Cycle Count Master Plan...

Cycle count master plans indicate how a worker will execute a group of requests. These plans are based off of "master" records, which are defined in the on the Cycle Count Master configuration window. You can create a cycle count plan using the "master" settings from the Cycle Count Plan Insight screen. Note that if there is already a pending request (Open status) for an item/location combination, then the system will not create a new cycle count request. For example, suppose you create a cycle count plan with a large number of requests. Soon after, some workers execute picks on locations that should trigger the creation of activity-driven requests; however, none of the workers will see cycle count requests when doing that work. This is because your original cycle count plan already created a pending request for that location. Therefore, a new request was not created.

 

PAPERWORK NOTE: When a cycle count plan contains requests that share a single company, the system will honor the document routing record with that company specified. When the plan has multiple companies specified for its requests, the system will honor the document routing record with no company specified.

 

Procedures

  1. Access the Cycle Count Plan Insight screen.   

     

  2. Click on the New Master Plan action to create a new Master Plan. The system will display the Cycle Count Master Plan screen.

     

  3. Choose a cycle count master record in which to base your plan on. These records control what cycle count requests the system will create, using the user-defined item and location selection criteria.

    NOTE: The warehouse defaulted on the cycle count master plan screen will be based on the warehouse selected by user counter on the Cycle Count Plan Insight.

     

  4. Indicate how many cycle count requests you want to assign per worker. When a plan is created, the system groups the requests. This could be especially helpful if you have 10 people out on the floor and there is a plan that has 500 requests. Counts per Group field allows you to group the requests so that they are evenly divided between workers. When printing cycle count lists, each group is printed separately.

     

  5. Select the Auto Print Cycle Count List Toggle if you want the system to generate this document after you create this plan. You can also print this document from the Cycle Count Plan Insight.

     

  6. Select the Auto Release Plan Toggle if you want the system to release this plan as soon as it is created. If you create work, releasing the plan immediately will release the work and allow RF users to start seeing the cycle count requests. This is helpful if you want to review some of the requests created before releasing the work to be done.

     

  7. Tap or click on 'Save' will submit for cycle count plan creation. Success message is shown on submitting cycle count plan for creation.

 

 

 

Creating a Cycle Count Quick Plan...

From the Cycle Count Plan Insight screen, you can create a cycle count plan dynamically by using the "quick plan" option (accessed via the Actions menu or the right-click menu of the Active Plans Node). The difference between a "master" plan and a "quick plan" is that a master plan is generated off of a predefined configuration record, while the quick plan is generated using settings defined "on the fly" using the Cycle Count Quick Plan Window. For detailed procedures on how to create quick plans, see Creating Cycle Count Quick Plans. Note that once a quick plan is created, it functions in the same manner as a master plan. Therefore, the remaining subjects discussed in this topic below (regarding the releasing, closing, and deleting of plans) refer to both master and quick plans.

 

 

 

 

Releasing a Cycle Count Plan...

When a cycle count plan is created, you cannot perform any actions to it until it is released. If work was created for the plan, when the plan is released, the work is also released and the work can then be executed. You can manually release a plan in the Cycle Count Plan Insight, or have the system automatically release it on the Cycle Count Master Plan screen. The procedures below will describe how to manually release a plan.

 

NOTE: The procedures below assume that the cycle count plan was not set to release automatically on the Cycle Count Master Plan screen.

 

Procedures

  1. Access the Cycle Count Plan Insight screen.

     

  2. Locate the cycle count plan(s) that you want to release by turning the Show Active Plans toggle ON.

     

  3. Select the Release Action. The system will release the cycle count plan(s).

 

 

 

Closing a Cycle Count Plan...

When all the requests for a cycle count plan have been confirmed/reconciled, the system will close the plan automatically. This action indicates that all the counts for a certain plan have been completed. After a plan is closed, the system moves it from the Active Plans Node to the Completed Plans Node in the Cycle Count Plan Insight. If for some reason you need to close a plan manually, access the Show Active Plans toggle from the Cycle Count Plan Insight screen. Right-click a cycle count plan and choose Close from the Action. The system will close the plan, and move it into the Completed Plans Node. If you close a plan before all cycle counts are executed, the system closes the requests and deletes any work associated with them.

 

 

 

 

Deleting a Cycle Count Plan/Request...

You may need to delete a cycle count plan or request if, for example, one was created for the wrong location. Deleted plans/requests are completely removed from the system. You can perform this action in the Cycle Count Plan Insight screen. When deleting request that created work, the work corresponding to the requests will also be deleted.

 

Restrictions

  • You cannot delete a plan that has been released or has a status of "in-creation."

     

  • You cannot delete requests that are in a "pending review" status.

 

Procedures

  1. Access the Cycle Count Plan Insight screen.

     

  2. Locate the cycle count plan/request you want to delete in one of the plan nodes.

     

  3. Select a plan/request and select the Delete Action.

     

  4. The system will display a confirmation window. Verify that you want to delete this plan/request.

     

  5. Press OK. The system will delete the plan and navigate back to the insight screen.
