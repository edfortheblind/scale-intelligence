        <h4 data-source-node="n74">Step 1: Defining a Text Message...</h4>
        <p class="p_21" data-source-node="n75">Performed on the Text Messages window</p>
        <ul type="disc" class="ul_1" data-source-node="n76">
            <li data-source-node="n77">You will need to create a text message record to indicate when you want the system to display the text message (before or after a picking action). <br data-source-node="n78"><br data-source-node="n79">See the topic <a href="66f46b0b0708eb6addc55bbe73b34944df06abb4621271e45a2787933d1450cc.html" data-source-node="n80">Defining Text Messages</a> for more detailed information on using this window.</li>
        </ul>
        <p data-source-node="n81"> </p>
        <p data-source-node="n82"> </p>
        <h4 data-source-node="n83">Step 2: Associating the Text Message with an Item, Company, or Account...</h4>
        <p class="p_21" data-source-node="n84">Performed on the Performed on the Text Message Assignment window</p>
        <ul type="disc" class="ul_1" data-source-node="n85">
            <li data-source-node="n86">You will need to associate the message ID you created 
 in step 1 with the item, company, or account. Once this 
 is done, the system will display the appropriate text messages on 
 the RF or Warehouse Mobile devices.<br data-source-node="n87"><br data-source-node="n88">See the topic <a href="1f4163d280f20bc685a3d07d03b592416361bed4f6b841902a9a9dda7b4f8fb3.html" data-source-node="n89">Associating Text Messages</a> for more detailed information 
 on using this window.</li>
        </ul>
        <p data-source-node="n90"> </p>
        <p data-source-node="n91"> </p>
        <h4 data-source-node="n92">Step 3: Activating Work Text Messages...</h4>
        <p data-source-node="n93">Performed on the Work System Values Window</p>
        <ul data-source-node="n94">
            <li data-source-node="n95">The work system value "Display Warehouse Mobile Text Messages ?" must be set to yes for these text messages to appear on the RF and Warehouse Mobile devices.</li>
        </ul>
