
        
        <h1 data-source-node="n56"><a name="kanchor541" data-source-node="n57"></a>Default Shipper Checkbox</h1>
        <p data-source-node="n58">
            <p data-source-node="n59">You can use the Default Shipper Checkbox to indicate a particular cross reference record is to be used as the "default" shipper code. When a "default" cross reference record's warehouse/company combination is indicated on the Shipment Screen or Rate Shopping Window,  then the system will rate as per the configured default shipper code.<br data-source-node="n60"><br data-source-node="n61">The following are a few things to consider when using this setting:<br data-source-node="n62">- There can only be one default shipper cross reference record for a certain warehouse/company or warehouse/(blank company) combination.
<br data-source-node="n63"><br data-source-node="n64">- The first cross reference record you create for a warehouse/company combination is automatically set as the default shipper. You cannot change this setting on this initial record until subsequent records are created for this warehouse/company combination. <br data-source-node="n65"><br data-source-node="n66">- If you choose to designate a cross reference record as the default shipper record (and there is an existing default record), then the system will make the current record the default, and unselect this setting from the previous default record.<br data-source-node="n67"><br data-source-node="n68">- If multiple records  for a warehouse/company combination exist, the system will not allow you to delete a default shipper record.</p>
