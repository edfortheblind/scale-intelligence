Default Shipper Checkbox

You can use the Default Shipper Checkbox to indicate a particular cross reference record is to be used as the "default" shipper code. When a "default" cross reference record's warehouse/company combination is indicated on the Shipment Screen or Rate Shopping Window, then the system will rate as per the configured default shipper code.

The following are a few things to consider when using this setting:
- There can only be one default shipper cross reference record for a certain warehouse/company or warehouse/(blank company) combination.

- The first cross reference record you create for a warehouse/company combination is automatically set as the default shipper. You cannot change this setting on this initial record until subsequent records are created for this warehouse/company combination.

- If you choose to designate a cross reference record as the default shipper record (and there is an existing default record), then the system will make the current record the default, and unselect this setting from the previous default record.

- If multiple records for a warehouse/company combination exist, the system will not allow you to delete a default shipper record.
