Choosing a System Display Language

You can define which language that you want the system to display text for the system, RF, Insight Screens, and Trading Partner Management windows. This setting is made at the network user level. The system uses the language setting in the Windows Control Panel to govern in what language the system displays text. This is helpful if you have different users whom require different language configurations. For instance, when you change the Windows language setting during a Remote Desktop Services client session, you can log onto SCALE using any machine, and the language setting will "travel" with you. You can perform this action on the Windows Control Panel (Regional and Language Options) Window or the Web User Window.

 

NOTE: In this topic, the term "user profile" refers to the Windows network user that an employee is signed onto via Remote Desktop Services. This does not refer to a SCALE user profile.

Choosing a Display Language For SCALE Application Windows and RF Screens...

When you implement a language change, all SCALE windows will display this new language in field names, window titles, system-supplied records, error messages, and any other text that the system generates. See the SDK topic "Choosing a Display Language For RF Screens" for more details.

  1. Access the Windows Control Panel (Start | Control Panel).
     
  2. Access the Regional and Language Options screen.
     
  3. On the Regional Options Tab, select a language and press OK.

    IMPORTANT: For your changes to take effect, you need to exit and restart the system/RF module. The system will use the new language to display windows when accessed only by the user whose profile you are changing with this procedure. All other users will see the language that is defined on their Windows' profile records.

 

 

 

Additional Step For RF Devices:

You will need to perform the following step to complete the implementation of a new language on your RF devices. The system will reference a setting on your web browser to display the correct language on the RF.

  1. Open the Internet Explorer web browser.
     
  2. Go to the option Tools | Internet Options, and press the Languages Button.
     
  3. Press the Add Button, choose the language you would like to add, and press OK. The system will add your new selection to the "language preference" list.
     
  4. Move your new language to be the first in the "language preference" list, and press OK. The system will save your changes, and the RF device will now display this new language.

 

 

 

Choosing a Display Language for Web Screens...

When you implement this language change, all web screens will display this new language in field names, window titles, error messages, and any other text that the system generates. However, the main log on page will always use the application server's language, regardless of a specific web user's language preference.

  1. Open the Configurations Explorer, and access the Web User Window.
     
  2. Open the web user profile record that you want to select a language for, and select the General Tab.
     
  3. Use the Language Selection Field to indicate which language you want the system to use when displaying text on the web windows.
     
  4. Press OK. The system will save the record.

    IMPORTANT: For your changes to take effect, you need to exit and restart the Internet Explorer browser. The system will use the new language to display windows when accessed only by the user whose profile you are changing with this procedure. All other users will see the language that is defined on their profile records.

 

 

 

Choosing a Display Language for Insight Screens...

When you implement a language change, all Insight screens will display this new language in field names, window titles, error messages, and any other text that the system generates. This can be achieved by changing the browser language setting, or by changing the operating system’s language and region settings. These settings vary, depending on device type and operating system version.

  1. With the Insight screens, multiple browsers and devices are supported. It should be noted, however, that certain languages/regions are not necessarily implemented on all supported browsers. Additionally, if there are fields on the web screens that are not translated, some may still display in the application server’s language.

  2. Changing the language selection on a desktop browser (e.g., Internet Explorer) usually includes the localization formatting for date-time and decimal separators. For example, if the languages of "Spanish (Mexico)" and "Spanish (Spain)" are listed, they each have different corresponding locale settings. However, on many tablets and mobile devices (e.g., iPad), there is a region setting which is separate from the language setting. Please consult your manufacturer’s device manual or specific browser for detailed information on how to properly set the language region.

 

 

 

Choosing a Display Language For History and Server-Side Processing...

Additionally, if you want history and server-side processing to be reflected in a different language, you will need to make these additional changes:

  • Select the desired language (for the ILSSRV user) in the Windows Regional and Language Options.

  • Change the "Default System Language" in the SCALE Technical Values Window to the desired language.

 

 

 

Miscellaneous Display Language Notes...

  • Since the client machine installer runs before the Database Environment selection, the system will retrieve error messages during the client machine install from the "Default" database configured in the WMFW.config file (based on the Windows user's culture). The "Default" database may not contain the same language translations as the other database environments. If you want to be able to view messages in the languages found in each database environment, then you will need to import these languages into the "Default" database configured in the WMFW.config file.
