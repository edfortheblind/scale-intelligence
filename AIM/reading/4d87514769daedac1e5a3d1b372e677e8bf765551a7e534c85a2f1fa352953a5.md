
        
        <h1 data-source-node="n56"><a name="kanchor1151" data-source-node="n57"></a>Allow VAS Override At Close Container And Load Confirm Checkbox</h1>
        <p data-source-node="n58"> This field indicates the system's behavior when a container has pending VAS at the time of close container and shipping load confirmation:</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60"><b style="color: #000080;text-decoration: none" data-source-node="n61">At Close Container...</b>
        </h5>
        <blockquote data-source-node="n62">
            <p data-source-node="n63">- <i data-source-node="n64">When this setting IS NOT selected and a container has pending VAS</i>, the system will display a message indicating that the container cannot be closed because it has pending VAS activity(s).</p>
            <p data-source-node="n65"> </p>
            <p data-source-node="n66">- <i data-source-node="n67">When this setting IS selected and a container has pending VAS</i>, the system will display a message indicating that the container has a pending VAS activity, and you can choose whether to allow the container to close or hold it up because of the pending VAS. </p>
            <p data-source-node="n68"> </p>
        </blockquote>
        <p data-source-node="n69"> </p>
        <h5 data-source-node="n70"><b style="color: #000080;text-decoration: none" data-source-node="n71">At Load Confirm...</b>
        </h5>
        <blockquote data-source-node="n72">
            <p data-source-node="n73">- <i data-source-node="n74">When this setting IS NOT selected and a container has pending VAS</i>, the system will display a message indicating that the container has a pending VAS activity, and will not confirm the load. </p>
            <p data-source-node="n75"> </p>
            <p data-source-node="n76">- <i data-source-node="n77">When this setting IS selected and a container has pending VAS</i>, the system will ignore the pending VAS and will confirm the load. Note that the system will still label the container as "VAS Pending" after the load has been confirmed.</p>
        </blockquote>
