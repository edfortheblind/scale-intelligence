Disposition Code Record

When receiving items, you can require workers to scan a disposition code for each container. These codes reflect the condition or status of the inventory in the container—such as good, damaged, or broken. Disposition codes are especially useful for processing returns. Additionally, since each code is tied to a specific locating rule, the system can determine storage locations based on the item's condition.

 

Create a disposition code

 

  • Click Add New Record button.

  • Enter Identifier and Description.

System Defined Values

  • Locating Rule drop-down, select the rule that determines where the system should place containers associated with this code.

  • Use the Inventory Status drop-down to define the condition of the container you're assigning the disposition code to.

  • Use the Require Image Capture drop down to Yes or No, to indicate where disposition code is required or not during image capture.
