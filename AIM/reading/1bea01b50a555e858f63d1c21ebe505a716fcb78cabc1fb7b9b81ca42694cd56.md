
        
        <h1 data-source-node="n56">Choosing Rules on the Item Master</h1>
        <p data-source-node="n57">In order for the system to use advanced rule set assignment for an item, 
 you first need to indicate on the item master that you want to use rule 
 set assignment for this item, by choosing a blank or default allocating/locating 
 rule. This allows the system to choose an appropriate allocating/locating 
 rule using the rule set criteria that you define. You will indicate this 
 setting on the Item Window.</p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">Procedures...</h4>
        <ol class="ol_2" data-source-node="n61">
            <li value="1" data-source-node="n62">Access the Item 
 Window from the Configurations Explorer, and open/create an item 
 record.<br data-source-node="n63"> </li>
            <li value="2" data-source-node="n64"><i data-source-node="n65">For Inbound Processing</i>: In the Locating Rule Field, 
 choose the *Default value or leave the field blank.<br data-source-node="n66"><br data-source-node="n67"><i data-source-node="n68">For Outbound Processing</i>: In the Allocation Rule Field, 
 choose the   *Default value or 
 leave the field blank.<br data-source-node="n69"> </li>
            <li value="3" data-source-node="n70">For information 
 on other fields in this window, see the topic  <a href="505c5c4630e085fc146ea8699fd6ca8b29c4f269b413b1ce93e0e981d01241b2.html" data-source-node="n71">Defining 
 Items in the System</a>.<br data-source-node="n72"> </li>
            <li value="4" data-source-node="n73">Press OK. 
 The system will save your changes.</li>
        </ol>
