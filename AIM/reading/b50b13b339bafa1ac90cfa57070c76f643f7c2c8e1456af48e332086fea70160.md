
        
        <h1 data-source-node="n56"><a name="kanchor167" data-source-node="n57"></a>Destination Postal Code Field</h1>
        <p data-source-node="n58">The destination postal code, or postal code 
 range. This field is obtained from the Ship To postal code on the shipment. The range includes two postal codes: the 
 beginning postal code and the ending postal code.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The carrier supports 
 the beginning postal code, the ending postal code and all the postal codes 
 between them.</p>
        <p data-source-node="n61"> </p>
        <p class="p_1" data-source-node="n62">During LTL internal rating, the system does a match of this postal code range to the Ship To postal code on the shipment when determining which rate base to use.</p>
