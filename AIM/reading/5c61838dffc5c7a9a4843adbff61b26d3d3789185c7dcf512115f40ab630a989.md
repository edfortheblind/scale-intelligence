
        
        <h1 data-source-node="n56">Creating Receiving Interface Upload Criteria Records</h1>
        <p data-source-node="n57">You can use the Receiving Interface Upload Criteria to filter the receiving records to be uploaded for the specified upload process detail.  Different filter criteria can be set on each receiving process detail.  The system will place the records in the upload directory defined on the interface process detail. </p>
        <p data-source-node="n58">The filter search value will list the statuses for the Leading status and Trailing status Attribute fields which will include both inbound and outbound statuses for selection.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">If the process detail’s directory is blank, then the upload directory of the interface system value  will be used.    The receiving data should satisfy the conditions set by the receiving interface system values.</p>
