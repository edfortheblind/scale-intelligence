
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">Interface Data Map Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Interface Data Map configuration defines the field mappings used when interfacing data between SCALE and an external system. You can create maps for delimited or fixed-length file formats and define the sequence and properties of each mapped field.</p>
        <h4 data-source-node="n61"> </h4>
        <h4 data-source-node="n62">Configure Interface Data Map</h4>
        <p data-source-node="n63"> </p>
        <h5 data-source-node="n64">1. Interface Data Map</h5>
        <p data-source-node="n65"> </p>
        <p data-source-node="n66">The Review Interface Data Maps screen displays existing records and allows record maintenance.</p>
        <ul data-source-node="n67">
            <li data-source-node="n68">
                <p data-source-node="n69"><b data-source-node="n70">Review Interface Data Maps</b>: View existing maps with Name, Mode, Record Type, Action, and Direction columns.</p>
            </li>
            <li data-source-node="n71">
                <p data-source-node="n72"><b data-source-node="n73">Add New Interface Data Map</b>: Create a new data map record.</p>
            </li>
            <li data-source-node="n74">
                <p data-source-node="n75"><b data-source-node="n76">Delete</b>: Remove the selected data map record.</p>
            </li>
        </ul>
        <p data-source-node="n77"> </p>
        <h5 data-source-node="n78">A. Information</h5>
        <p data-source-node="n79"> </p>
        <p data-source-node="n80">Enter the general data map details.</p>
        <ul data-source-node="n81">
            <li data-source-node="n82">
                <p data-source-node="n83"><b data-source-node="n84">Name</b>: Enter the unique identifier for the data map. This value is required and cannot be changed after creation.</p>
            </li>
            <li data-source-node="n85">
                <p data-source-node="n86"><b data-source-node="n87">Record Type</b>: Select the type of data record this map applies to. This value is required and determines the available Interface Actions.</p>
            </li>
            <li data-source-node="n88">
                <p data-source-node="n89"><b data-source-node="n90">Interface Action</b>: Select the interface action associated with the chosen Record Type. This field is enabled only after a Record Type is selected.</p>
            </li>
            <li data-source-node="n91">
                <p data-source-node="n92"><b data-source-node="n93">Mode</b>: Select the interface file format. Choose <b data-source-node="n94">Delimited</b> for delimiter-separated files or <b data-source-node="n95">Fixed Length</b> for positional fixed-width files. This value is required and cannot be changed after creation.</p>
            </li>
        </ul>
        <p data-source-node="n96"> </p>
        <h5 data-source-node="n97">2. Map Fields</h5>
        <p data-source-node="n98"> </p>
        <p data-source-node="n99">The Map Fields screen displays the ordered list of fields defined for this data map.</p>
        <ul data-source-node="n100">
            <li data-source-node="n101">
                <p data-source-node="n102"><b data-source-node="n103">Position</b>: The sequence position of the field in the map.</p>
            </li>
            <li data-source-node="n104">
                <p data-source-node="n105"><b data-source-node="n106">Field</b>: The name of the mapped data field.</p>
            </li>
            <li data-source-node="n107">
                <p data-source-node="n108"><b data-source-node="n109">Required</b>: Indicates whether the field is required. Required fields cannot be deleted.</p>
            </li>
            <li data-source-node="n110">
                <p data-source-node="n111"><b data-source-node="n112">Length</b> (Fixed Length mode only): The character width allocated to the field.</p>
            </li>
            <li data-source-node="n113">
                <p data-source-node="n114"><b data-source-node="n115">Pad Character</b> (Fixed Length mode only): The character used to pad the field to its defined length.</p>
            </li>
            <li data-source-node="n116">
                <p data-source-node="n117"><b data-source-node="n118">Pad From</b> (Fixed Length mode only): Indicates whether padding is applied from the left or right of the field value.</p>
            </li>
            <li data-source-node="n119">
                <p data-source-node="n120"><b data-source-node="n121">Add New Field</b>: Add a new field entry to the map. Fields can be reordered by dragging rows.</p>
            </li>
            <li data-source-node="n122">
                <p data-source-node="n123"><b data-source-node="n124">Edit/Delete</b>: Update or remove the selected field. Delete is disabled for required fields.</p>
            </li>
        </ul>
        <p data-source-node="n125"> </p>
        <h5 data-source-node="n126">A. Field Properties</h5>
        <p data-source-node="n127"> </p>
        <p data-source-node="n128">Define the properties for a data map field.</p>
        <ul data-source-node="n129">
            <li data-source-node="n130">
                <p data-source-node="n131"><b data-source-node="n132">Field</b>: Select the field from the list of available fields for the data map (New mode), or view the read-only field name (Change mode).</p>
            </li>
            <li data-source-node="n133">
                <p data-source-node="n134"><b data-source-node="n135">Length</b> (Fixed Length mode only): Enter the number of characters allocated to this field in the fixed-length record.</p>
            </li>
            <li data-source-node="n136">
                <p data-source-node="n137"><b data-source-node="n138">Pad Character</b> (Fixed Length mode only, not applicable to first field): Enter the character used to pad this field when the value is shorter than the defined length.</p>
            </li>
            <li data-source-node="n139">
                <p data-source-node="n140"><b data-source-node="n141">Pad From</b> (Fixed Length mode only, not applicable to first field): Select whether padding is applied from the <b data-source-node="n142">Left</b> or <b data-source-node="n143">Right</b> side of the field value. Defaults to Right.</p>
            </li>
        </ul>
        <p data-source-node="n144"> </p>
        <p data-source-node="n145">Use Back, Save, Continue, and Finish to manage and complete Interface Data Map configuration.</p>
