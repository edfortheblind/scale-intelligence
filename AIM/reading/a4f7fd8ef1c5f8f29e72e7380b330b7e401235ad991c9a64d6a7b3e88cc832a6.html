Group Number Field

In Picking... 

When the system creates a pick group, it assigns it a group number. The group number identifies all of the containers in the picking group. Picking groups are created during the pick group creation wave step and during group user work initiation. You can view the group number in the following places: Putaway Group Insight Screen, Work Instruction screen, and the Picking Group Pick List paperwork document.

 

 

In Cycle Counting...

This field indicates the number of a cycle count request group. The size of these groups are defined on the Cycle Count Plan Creation screen. For example, if there are 100 requests to execute, and you indicate that you want to distribute these requests in groups of 50, then there would be a group "1" and a group "2."
