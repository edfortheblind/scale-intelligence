Creating a Dock Area Carrier Assignment Record

The system uses these records to help ensure that all of a shipment's containers/details are assigned to the carrier's appropriate dock location area (staging or dock door). The system references this record when using the dock location selection strategy. Note that these records are optional, and if they do not exist, the dock assignment process will assign the default dock locations as defined on the dock management flow header or detail.

Procedures: Header Fields...

  1. Use the Warehouse Field to indicate the warehouse where a carrier's dock location area resides.

  2. Use the Dock Area Field to indicate the dock location area that you want the system to assign when a container is associated to a specific carrier.

 

Procedures: General Tab Fields...

  1. Use the Carrier Assignment Field to indicate that you want to filter eligible containers by carrier/carrier service, carrier group, or none.

    Notes On "None" Records:
    - It is helpful to create a "none" record for a dock location area so that if the system cannot find an empty spot in the carrier's dock location area, then the container will be assigned to the overflow location (represented by the "none" record).

    - If no "none" records are defined, then the system will assign the last dock location evaluated (regardless of its current open capacity).

  2. Press OK. The system will save your record.
