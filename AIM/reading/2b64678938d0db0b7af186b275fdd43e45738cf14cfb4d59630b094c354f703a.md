
        
        <h1 data-source-node="n56"><a name="kanchor59" data-source-node="n57"></a>Template Field</h1>
        <h5 data-source-node="n58">Using the Interface...</h5>
        <p data-source-node="n59">This field identifies the XML schema that you want this trigger header 
 record to use when processing the system data. The system Template values 
 represent a list of the available schemas that the user can choose from 
 to use for their mapping. The system uses this template to grab each of 
 the attributes from that template and place them in the Billing Management 
 list.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">On the Item Window...</h5>
        <p class="p_30" data-source-node="n63">Use this field to select 
 a template that the system will use to validate an entered serial number. 
 You can also choose to not select a template, and then the user will be 
 able to enter any combination of characters for a serial number.</p>
        <p class="p_30" data-source-node="n64"> </p>
        <p class="p_30" data-source-node="n65"> </p>
        <h5 data-source-node="n66">On the Notification Window...</h5>
        <p class="p_30" data-source-node="n67">This field  indicates the template that the system will use to generate a notification. The following template formats are supported: XML, HTML, plain text, and rich text. Inside the template, such things as links to Insight screens, links per data row returned in .csv file, and header/footer data. See the <a href="81d022a2ab379af5c9e945433d1bd3f6e09728fcfd355546989e79b3a0ecfa54.html" data-source-node="n68">SDK</a> for more information/examples on notification templates.</p>
