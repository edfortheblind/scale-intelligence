
        
        <h1 data-source-node="n56"><a name="kanchor870" data-source-node="n57"></a>Creating Document Criteria Records</h1>
        <p data-source-node="n58">Document criteria records allow the user to select and sort the detail 
 data on particular document types. This is done by first creating a criteria 
 record for a document (in one of the four Document Criteria Windows), 
 and then assigning it to a document (in the Document Window).</p>

        <h4 data-source-node="n168"><a name="Acreating" data-source-node="n169"></a>Step 1: Creating the Criteria Record...</h4>
        <p data-source-node="n170">Choose one of the four document criteria windows from the Configurations 
 Explorer, and create a new record.</p>
        <ol class="ol_1" data-source-node="n171">
            <li class="li_10" value="1" data-source-node="n172">Using the Filter Data Tab: You can use 
 this tab to indicate what field(s) that you want to filter out of your 
 paperwork document. For example, if you do not want to print the component 
 items on that Shipment Pack List with BOM Components, you could enter 
 the following filter data rule:   RELATED_LINE_NUM 
 = 0. 	The system then would only print the non-component detail lines on 
 the document. <br data-source-node="n173"> </li>
            <li class="li_10" value="2" data-source-node="n174">Using the Order By Tab: You can use 
 this tab to sort the detail lines of a document in a different way than 
 the system does by default. For example, on a Shipment Pack List with 
 Containers, suppose you want to sort the details by order line number 
 in an ascending order. You would enter the following attribute:   SHIPMENT_DETAIL.ERP_ORDER_LINE_NUM 
 /   Ascending. 	The system then would print the shipment lines on this document in 
 an ascending order.<br data-source-node="n175"> </li>
            <li class="li_10" value="3" data-source-node="n176">When finished, press OK. The system 
 will save your document filter record.</li>
        </ol>
        <p data-source-node="n177"> </p>
        <h4 data-source-node="n178"><a name="Bassoc" data-source-node="n179"></a>Step 2: Associating a Filter Record with 
 a Document...</h4>
        <p data-source-node="n180">Access the Document Window from the Configurations Explorer. Open the 
 record of the document you want to assign a filter to.</p>
        <ol class="ol_1" data-source-node="n181">
            <li value="1" data-source-node="n182">Use the Document 
 Criteria Field to assign a document filter to this document. Now, 
 when the system generates this paperwork, it will use this filter record 
 to display the values on the document. Choose no value in this field if 
 you want the system to use the default layout for a document.<br data-source-node="n183"> </li>
            <li value="2" data-source-node="n184">Press OK. 
 The system will save your changes. </li>
        </ol>
