Field / Field Name

In Packing...

This represents the field value that a detail line must have for the system to pack it into a particular container. Note that only items whose shipment line values match ALL of the fields (as defined on the packing criteria record) will be packed together. You would receive a warning message since the field does not match. For example, suppose that "Mark For" is a field defined on the packing criteria record. The detail line item being packed, however, has a different "Mark For" value than an item already in the container. The system, then, cannot pack this item into the container, because the "Mark For" values do not match up. The system will then need to look for another container to pack this item into.

 

 

On the Viewers Window...

On the Colors/Icons Tabs, this field indicates what field the system will use to determine whether or not to display a certain color or icon with a data record.

 

 

On Custom Search Criteria Window...

This field indicates a field that you can add as additional search criteria.

 

 

On the Carrier EDI Reference Window...

This field indicates the text name of an EDI reference field that you want to send to the transportation system.

 

 

On the Interface Error Reference Field Configuration Windows...

This field indicates the path (i.e., the location of the value within the XML nodes, expressed using xpath) of a value that you want to use as a reference field for a specific interface process. For examples of how to express these values, see the topic Defining Interface Validation Error Reference Fields.
