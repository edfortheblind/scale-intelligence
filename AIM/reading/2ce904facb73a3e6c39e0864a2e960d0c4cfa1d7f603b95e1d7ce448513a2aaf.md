
        
        <h1 data-source-node="n56"><a name="kanchor1185" data-source-node="n57"></a>Pro Number / Pro Number Range Field</h1>
        <p data-source-node="n58">A pro number 
 identifies a shipment or shipping load for a particular LTL or TL carrier. 
 It is generated manually by the user or automatically by the system, and 
 is displayed on the bill of lading or master bill of lading. Pro numbers 
 are required for LTL or TL carriers only: parcel carriers do not use pro 
 numbers. You must obtain pro numbers from the carrier.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Pro numbers can be assigned by the system either at the load level, 
 or one per individual shipment. You can define this setting on the Carrier 
 Type Window.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">Each LTL and TL carrier will provide you with a pro 
 number range for each warehouse, along with information about the 
 pro number's structure. You will identify this information on the Pro 
 Number Window. After you define a carrier's pro number range, the system 
 will sequentially assign the pro numbers to each bill of lading that it 
 produces for the carrier. When the system assigns the last pro number 
 in the range, it will send negative numbers, such as -1, -2, -3, until 
 you provide a new pro number range.     </p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64">Note that you can set up a warehouse alert to generate a history record and/or email message that will notify the user  if a pro number range is close to running out of numbers (a configured percentage set in the Rating System Values Window).</p>
