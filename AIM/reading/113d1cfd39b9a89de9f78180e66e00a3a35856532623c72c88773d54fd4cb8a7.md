
        
        <h1 data-source-node="n56"><a name="kanchor670" data-source-node="n57"></a>Creating Inbound Quality Control Locations</h1>
        <p data-source-node="n58">Below are some tips on creating inbound quality control locations. It is helpful 
 to differentiate these locations from regular inventory locations, so 
 you can easily sort and maintain them via the Inventory Insight screen.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures...</h4>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">Access the Location Window.</p>
        <ol class="ol_1" data-source-node="n64">
            <li value="1" data-source-node="n65">Create a new location 
 record.  <br data-source-node="n66"><br data-source-node="n67">- Make sure that the location you 
 are creating is an inventory storage location. This gives you the 
 ability to directly allocate from an inbound QC location, if necessary. <br data-source-node="n68"><br data-source-node="n69">Use a naming convention for your 
 inbound QC locations that clearly designate them as being used for quality control.This will help you be able to quickly find your locations in the Inventory Insight. Also, you can use this convention to easily 
 set up your allocation rules to skip quality control locations.<br data-source-node="n70"><br data-source-node="n71">See the topic <a href="0647e4eabceb836507240391e04a1529a5bb19faf3c5adf6ea08c38524dbfc8b.html" data-source-node="n72">Creating Locations</a> 
 for more information on using this window's fields.</li>
        </ol>
