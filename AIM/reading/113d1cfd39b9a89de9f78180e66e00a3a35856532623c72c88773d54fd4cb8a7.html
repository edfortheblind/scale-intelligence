Creating Inbound Quality Control Locations

Below are some tips on creating inbound quality control locations. It is helpful to differentiate these locations from regular inventory locations, so you can easily sort and maintain them via the Inventory Insight screen.

 

 

Procedures...

 

Access the Location Window.

  1. Create a new location record.

    - Make sure that the location you are creating is an inventory storage location. This gives you the ability to directly allocate from an inbound QC location, if necessary.

    Use a naming convention for your inbound QC locations that clearly designate them as being used for quality control.This will help you be able to quickly find your locations in the Inventory Insight. Also, you can use this convention to easily set up your allocation rules to skip quality control locations.

    See the topic Creating Locations for more information on using this window's fields.
