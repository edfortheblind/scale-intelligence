Printing Paperwork

You can print customizable SCALE documents from dozens of areas of the application. The system allows you to either manually select the documents you want to print, or to predefine the documents that you want automatically printed in a certain functional situation. The procedures included in this topic outline how you can use the Print Documents Window to generate documents, as well as the various printing actions available in SCALE windows.

Printing from a SCALE Screen... 

 

Screens

You can print different types of documents using the various insight screens available. A document is linked to a process via its document type.

  1. Access the specific insight screen as required and select the appropriate record. 

  2. Select the required Print Action: "Print Default Docs" or "Print Selected Docs".

  3. Select the document types as preferred:

  • If you select "Print Default Docs", the system will print all paperwork associated with document types that were defaulted to print for this function. A document type is defaulted to print automatically when the Default checkbox for this print procedure is selected on the Document Type Window.

  • If you select "Print Selected Docs", the system will display the Print Documents Window. You can select or deselect any document displayed on this window. Documents will appear in this window if their document type is associated with the print procedure associated with this window. Also note that documents are preselected if the print procedure's Default checkbox is selected for the document type associated with this paperwork. 

NOTE: Choosing a label or document printer when printing a selected document will override the document routing printer for all the selected document types. The selected printer also overrides the default printer set on the user profile. Printing will use the document routing printer for each document type when the “Use document routing” toggle is set to Yes. These toggles will be defaulted to Yes and the printer selection will be disabled when the user profile’s default printer is blank. If the user profile’s default printer is filled, then the toggles will be set to No with the user profile’s printer defaulted and the printer selection enabled.

 

The "Default" value set for All Bills of Lading option when using the Print Selected Documents functions as below

  • When the Bill of lading type on the shipping load is None, then system will prints just the bills of lading for all of the shipments on the load.
  • When the Bill of lading type on the shipping load is Consolidator or Multi stop truck load, then system will print the Master bill of lading for the load as well as all bills of lading for the shipments on the load.

  1. Press Submit. The system sends the print requests to batch queue for printing.

NOTE: Printing requires a document routing record that matches the document routing criteria from the submitted print request.

 

 

Print Previewing Documents... 

You can preview the layout/content of a document before you print it. Note that there are a few system windows that do not support print preview. You can only preview paperwork if the Allow Print Preview Checkbox is selected for the document type linked to the document that you want to view. Note that for print previewing any labels/documents, the document being generated must be configured as a Reporting Services Document in the Document configuration. These are the only documents that can be print previewed, unless the exit point “Print Preview – Override” is enabled and there is custom code created to generate PDFs for other documents.

 

Procedures
  1. Access the screen that you want to view a document from.
     

  2. Select the record you want to print preview from and select the Print Preview Action. The system will display a popup window from which you can select the document for previewing,

     

  3. Select the document that you want to view and click/tap the Preview button. The system generates a PDF of the document and displays it on a new tab in the browser. You can choose to print from here, save or download the document, or perform any action permissible by a standard PDF format.

NOTE: You must have pop ups enabled for the document to appear.

 

 

Printing Documents Automatically... 

The system can automatically generate paperwork when particular events occur (such as at container close). See the setup overview topic for the appropriate functional area for more information on automatic paperwork.

 

 

Changing a Printer's Share Name... 

To minimize printer configuration maintenance, Manhattan strongly recommends that you do not change the printer's share name to be different than its actual name. Progistics uses this value when generating labels if it differs from the printer's network name. If you do decide to change the printer's share name, complete the following activities after the name change:

  • Open the Print Device Window for this printer record. Press OK and close the window. Open the window again. Press OK again and close this window. This updates the record twice in a row, which is required to circumvent a known Windows error regarding share names.

  • Print a test label to verify that Progistics accepted the name change.
