
        
        <h1 data-source-node="n56"><a name="kanchor515" data-source-node="n57"></a>Enable RF and Warehouse Mobile Success Text Checkbox</h1>
        <p data-source-node="n58">Select this checkbox to indicate that you want the system to display a text message after each successful RF or Warehouse Mobile pick or putaway. The message will appear at the appropriate RF or Warehouse Mobile screen. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">For example, you could have the system tell the user the last item that they picked, or the ID of the last container they picked into. However, if the RF user goes on to execute another work unit immediately after executing a work unit, the system will display the RF Success Text on the Work Unit Entry screen for that work unit.
</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62">Note that this message will appear after the first successful pick/putaway, not on the first picking/putaway screen. Also, if the current executed pick was the last pick on the work unit, the system will display the message on the putaway confirmation screen. </p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64">In addition to displaying either the "success display" or "success message" field, you could have the system display both values to the user, For example, you could have the system show the text<i data-source-node="n65"> Last Item Picked: NOR0001</i>, where "Last Item Picked:" is the success message, and "NOR0001" is the success display field.</p>
