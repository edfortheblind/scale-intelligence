
        
        <h1 data-source-node="n56"><a name="kanchor2007" data-source-node="n57"></a>Carrier Symbol Field</h1>
        <p data-source-node="n58">This field indicates the symbol identifying a carrier. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Using Progistics...</h5>
        <p data-source-node="n62">This value is defined 
 by Progistics. Note that only a certified system 
 consultant is authorized to identify Progistics carrier symbols.</p>
        <p data-source-node="n63"> </p>
        <p data-source-node="n64"> </p>
        <h5 data-source-node="n65">Using Internal Less Than Truckload Rating...</h5>
        <p data-source-node="n66">When internally rating an LTL carrier, this symbol must be defined as 'ILS.LTL'. This value is defined on the Rating ID Carrier Symbols Configuration.</p>
