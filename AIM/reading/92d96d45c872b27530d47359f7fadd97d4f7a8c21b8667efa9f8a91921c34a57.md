
        
        <h1 data-source-node="n56"><a name="kanchor1822" data-source-node="n57"></a>Using the Consolidated Container Location Viewer</h1>
        <p data-source-node="n58">You can use this viewer to find the deconsolidated shipments for an ERP order and the locations of the shipping containers for those orders on the shipping dock.  The viewer groups the search results by ERP order.  Under this grouping the ERP orders will have a header row for each unique order and shipment combination found for the ERP order.  Each header row has details underneath showing the location on the shipping dock of the shipping containers for the order.</p>

        <h4 data-source-node="n120"><a name="SearchERPOrder" data-source-node="n121"></a>Searching for ERP Order Records</h4>
        <p data-source-node="n122"> </p>
        <ol data-source-node="n123">
            <li value="1" data-source-node="n124">Access the Consolidated Container Location Viewer. <br data-source-node="n125"><br data-source-node="n126"></li>
            <li value="2" data-source-node="n127">
                <p data-source-node="n128">Use the fields on the Criteria Tab to enter the value(s) that you want to use to find the ERP orders to deconsolidate and the locations of the shipping containers on the shipping dock.</p>
                <p data-source-node="n129"> </p>
            </li>
            <li value="3" data-source-node="n130">
                <p data-source-node="n131"> Press Search.  The system will display the results on the Results Tab.</p>
            </li>
        </ol>

        <h4 data-source-node="n134"><a name="DeconsolidatingERPOrder" data-source-node="n135"></a>Deconsolidating an ERP Order from a Shipment</h4>
        <p data-source-node="n136"> </p>
        <ol data-source-node="n137">
            <li value="1" data-source-node="n138">Access the Consolidated Container Location Viewer.<br data-source-node="n139"><br data-source-node="n140"></li>
            <li value="2" data-source-node="n141">
                <p data-source-node="n142">Perform a search for the ERP order records. Refer to the Searching for ERP Order Records topic (illustrated above). </p>
                <p data-source-node="n143"> </p>
            </li>
            <li value="3" data-source-node="n144">
                <p data-source-node="n145">Right-click on one or more ERP order “header” records and select the Deconsolidate action.  The system will request confirmation on whether you want to continue with deconsolidating the ERP orders from the shipment.<br data-source-node="n146"><br data-source-node="n147"></p>
                <ol data-source-node="n148">
                    <li value="1" data-source-node="n149">If you click OK to continue, it will submit the ERP order for the shipment to deconsolidation.  A message will be displayed indicating that the ERP order has been successfully submitted for deconsolidation.<br data-source-node="n150"><br data-source-node="n151"></li>
                    <li value="2" data-source-node="n152">If you click Cancel, it will navigate back to the selected record. <br data-source-node="n153"><br data-source-node="n154"></li>
                </ol>
                <p data-source-node="n155">NOTE: The system will deconsolidate the selected order’s shipment lines from the original shipment and transfer to a new shipment.<br data-source-node="n156"><br data-source-node="n157"></p>
            </li>
        </ol>
