High Ship Confirm Status Field

The most advanced status that can be ship confirmed. A shipment with this status can be ship confirmed. The system uses this field in conjunction with the Low Ship Confirm Status Field to determine the status range eligible for ship confirmation.

 

 

Defining Only One Eligible Status...

To define only one eligible ship confirm status, enter that value in both the Low Ship Confirm Status Field and the High Ship Confirm Status Field. The system will only ship confirm shipments with the status that you defined.
