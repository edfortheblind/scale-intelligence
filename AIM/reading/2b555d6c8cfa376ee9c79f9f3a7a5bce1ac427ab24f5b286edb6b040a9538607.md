
        
        <h1 data-source-node="n56"><a name="kanchor781" data-source-node="n57"></a>Clear Location Checkbox/Toggle</h1>
        <p data-source-node="n58">If this setting is active, the system will allocate from a location inventory record (not the location as a whole) only if the location can be “emptied” without exceeding the demand quantity or the forward location capacity. Also, the system will filter out any location inventory records which has quantity more than the demand or the location capacity. Keep in mind that this setting applies to all types of allocation (shipment, replenishment, work order).  </p>
        <p data-source-node="n59">  </p>
        <p data-source-node="n60"> </p>
        <h5 data-source-node="n61">Examples...</h5>
        <p data-source-node="n62">Suppose Location A has two lots (lot-1 =150 EA, and lot-2=70 EA).</p>
        <ul data-source-node="n63">
            <li data-source-node="n64"><i data-source-node="n65">Replenishment Allocation</i>: IF forward location capacity is only 100 EA, the system ignores the location inventory record with 150 EA, and allocates 70 EA of lot-2. Similarly, in the case of demand replenishment, if the demand is for 100 EA, the system ignores the location inventory record with 150 EA, and allocates 70 EA of lot-2.<br data-source-node="n66"><br data-source-node="n67"></li>
            <li data-source-node="n68"><i data-source-node="n69">Shipment Allocation</i>: If the demand for the shipment is for 100 EA, the system ignores the location inventory record with 150 EA, and allocates 70 EA of lot-2.<br data-source-node="n70"><br data-source-node="n71"></li>
            <li data-source-node="n72"><i data-source-node="n73">Work Order Allocation</i>: If the demand is for 100 EA of a component item, the system ignores the location inventory record with 150 EA, and allocates 70 EA of lot-2.</li>
        </ul>
        <h5 data-source-node="n74"> </h5>
        <h5 data-source-node="n75">Advanced Allocation Note...</h5>
        <p data-source-node="n76"> If a shipment is using the Advanced Allocation functionality, then this will take precedence over the Clear Location During Allocation setting.</p>
