
        
        <h1 data-source-node="n56"><a name="kanchor1372" data-source-node="n57"></a>Allow Renaming Of Existing Work Unit Checkbox</h1>
        <p data-source-node="n58">You can use this checkbox to determine whether or not the system will display the Rename Work Unit Field on the RF system directed work initiation screen. </p>
        <ul data-source-node="n59">
            <li data-source-node="n60">If this checkbox is selected, the system will display the Rename Work Unit field on the screen. Keep in mind that the user will be required to enter a value into this field.<br data-source-node="n61"><br data-source-node="n62"></li>
            <li data-source-node="n63">If it is not, then the system will only display the Location Field on the screen.</li>
        </ul>
