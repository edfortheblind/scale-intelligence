
        
        <h1 data-source-node="n56"><a name="kanchor83" data-source-node="n57"></a>Picking Group Pick List</h1>
        <p data-source-node="n58">A picking group pick list defines how a pick group should be structured 
 and its contents. This document identifies the items in each container, 
 each container's position in the group, the locations that you need to 
 visit, etc. Picking group pick lists can be automatically generated during 
 the paperwork wave step if the pick group creation wave step previously 
 ran. You can also print this document from any container in the group.</p>
