
        
        <h1 data-source-node="n56">Show Only Top Level Toggle</h1>
        <p data-source-node="n57">If this toggle is turned on in the filter pane of the Shipping Container Insight screen, only the top-level shipping containers will be displayed in the search results.  A top-level container is a container that doesn’t have a parent container. If the Shipping Container Insight screen is accessed from the Containers tile on the Shipment Insight screen, the toggle is turned on by default.  The toggle is turned off when the Shipping Container Insight screen is accessed from the System menu.</p>
