
        
        <h1 data-source-node="n56">Pass Unit Of Measure Field</h1>
        <p data-source-node="n57">This field indicates  what unit of measure you want to use while picking. When this field is set to <i data-source-node="n58"><a name="kanchor1624" data-source-node="n59"></a>Lowest</i>, the TalkMan will always use the lowest UM (such as Each).  When it is set to <i data-source-node="n60">Highest</i>, the TalkMan will use the highest UM the system can convert the work detail to, for each Case, Pallet, etc.</p>
