
        
        <h1 data-source-node="n56"><a name="kanchor711" data-source-node="n57"></a>Destination Field</h1>
        <h5 data-source-node="n58">On the Receipt Workbench...</h5>
        <p data-source-node="n59">This field indicates the following, depending on the status of the receipt container:</p>
        <ul data-source-node="n60">
            <li data-source-node="n61"><i data-source-node="n62">Check In Pending</i>: If the pre-check in receipt container is at this status, the Destination field value represents the locating rule assigned to the receipt line.<br data-source-node="n63"><br data-source-node="n64"></li>
            <li data-source-node="n65"><i data-source-node="n66">Locate Pending</i>: If the receipt container is at this status, the Destination field value represents the locating rule assigned to the receipt line.<br data-source-node="n67"><br data-source-node="n68"></li>
            <li data-source-node="n69"><i data-source-node="n70">Putaway Pending</i>: If the receipt container is at this status, the Destination field value represents the actual putaway location for this receipt line.</li>
        </ul>
        <p data-source-node="n71">NOTE: If the system encounters an error during the locating process, the system will display the value "failed" in the Destination field.</p>
