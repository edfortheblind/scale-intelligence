
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Consolidation Criteria</h1>
        <p data-source-node="n58">A consolidation criteria record specifies a single attribute that two shipments must have in common for consolidation to take place. If more than one criterion is defined, the system will only consolidate shipments that meet all of the specified criteria. Typical criteria include Ship To, Company, and Warehouse.</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Add New Criteria</h5>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62"><b data-source-node="n63">Table Field</b>: Select the shipment attribute to be used as a consolidation criterion. Common fields include Ship To, Carrier, and Requested Delivery Date.</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65">Toggle Button</p>
        <p data-source-node="n66"> <b data-source-node="n67">Required</b> - this value is required for manual consolidation.</p>
        <ul data-source-node="n68">
            <li data-source-node="n69">

            </li>
            <li data-source-node="n71">
