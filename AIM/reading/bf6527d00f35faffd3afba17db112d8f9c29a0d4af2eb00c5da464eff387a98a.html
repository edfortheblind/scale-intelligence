Defining Dock Area Anchor Criteria Records

Dock area anchor criteria records determine which dock area(s) are eligible for container assignment when anchoring shipping containers (using the Anchor Dock Area Using Shipment selection strategy). This eligibility selection is based on this record's filter criteria and the shipping container’s shipment information. Note that the system will add all dock areas to the eligible list that match the above-mentioned criteria.

 

 

"Matches" Operand

This filter data configuration window uses a special operand when creating criteria rules: the matches operand. For more information on how this operand works, please see the Operand Field topic.
