
        
        <h1 data-source-node="n56"><a name="kanchor361" data-source-node="n57"></a>Empty Location Criteria Field</h1>
        <p data-source-node="n58">During replenishment, this record determines where the system will attempt 
 to replenish product, if the following situations occur:</p>
        <ul data-source-node="n59">
            <li data-source-node="n60">
                <p data-source-node="n61">The amount of product that you have to replenish exceeds the locations 
 available for replenishment. After the system replenishes to all of the locations that currently contain the product, this field identifies the 
 next location(s) that it can replenish to.</p>
                <p data-source-node="n62"> </p>
                <p data-source-node="n63">OR</p>
                <p data-source-node="n64"> </p>
            </li>
            <li data-source-node="n65">No locations currently contain the item that you 
 need to replenish. In this case, you will use this field to determine 
 where to start replenishing.</li>
        </ul>
        <p class="p_1" data-source-node="n66">This record must be associated with a replenishment 
 master record.</p>
