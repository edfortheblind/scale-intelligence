Work Priority Escalation Criteria

Work Priority Escalation enables the system to automatically update the priority of work records (both header and detail) based on pre-defined criteria. This is done through a scheduled job that scans eligible work records and updates their priorities accordingly. This process ensures that high-priority work, such as urgent shipments, is executed ahead of others.

 

The configuration involves two main steps:

  • Defining Eligibility Criteria – Determine which work records qualify for priority updates.

  • Scheduling the Escalation Job – Specify the frequency and parameters of the job.

Criteria for eligibility.

  • Using the FilterBuilder: define criteria for selecting work records eligible for escalation. For example, if the filter includes a Work Type of “Shipment Work,” and your system has three types (Shipment Work, Receiving Work, and Work Order Work), the escalation job will only consider records with the “Shipment Work” type.

  • On the Scheduled Job configuration Run From/Run At, you will first need to define the interval at which the work escalation priority job will run.

  • On the Scheduled Job configuration Parameters section, you will next need to define the specific job settings for the work escalation priority job
