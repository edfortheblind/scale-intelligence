
        
        <h1 data-source-node="n56"><a name="kanchor580" data-source-node="n57"></a>Include in Interface Upload Checkbox/Field</h1>
        <h5 data-source-node="n58">On the Adjustment Type Window...</h5>
        <p class="p_1" data-source-node="n59">This checkbox determines if the system will generate an interface upload record when a particular adjustment type is performed. </p>
        <p class="p_1" data-source-node="n60"> </p>
        <p class="p_1" data-source-node="n61"> </p>
        <h5 data-source-node="n62">On 
 the History Transaction Types Window...</h5>
        <p class="p_1" data-source-node="n63">This field indicates if you want this type 
 of history record included in interface uploads.</p>
        <p class="p_1" data-source-node="n64"> </p>
        <p class="p_1" data-source-node="n65"> </p>
        <h5 data-source-node="n66">On the Functional Area Status Window...</h5>
        <p class="p_1" data-source-node="n67">This checkbox determines if the system will generate an interface upload record when an entity's trailing status reaches a particular status. Note that this functionality is for outbound functional area statuses only. Also, the system will not allow shipments to be uploaded multiple times for the same trailing status change. </p>
