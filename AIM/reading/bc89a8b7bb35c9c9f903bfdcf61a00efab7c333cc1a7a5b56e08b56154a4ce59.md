
        
        <h1 data-source-node="n56"><a name="kanchor125" data-source-node="n57"></a>Item Template Field</h1>
        <p data-source-node="n58">The item template associated with a specific item. An item template 
 identifies separator characters that should be added to an item number 
 at specific intervals. For example, the American Social Security Number 
 includes two dashes, which are separator characters that occur at specific 
 intervals: ### - 
 ## - ####. When the system stores the item number, it will include the separators. 
 The configuration for items will insert the separators if they are not 
 included in the number.</p>
