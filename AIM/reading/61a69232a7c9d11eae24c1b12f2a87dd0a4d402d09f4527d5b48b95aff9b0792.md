
        
        <h1 data-source-node="n57"><a name="kanchor1759" data-source-node="n58"></a>Split Quantity? Checkbox</h1>
        <p data-source-node="n59">This checkbox indicates if you want to completely fill a location and 
 split off any remaining item quantity to be located in a different location 
 (using the locating rules). Note that the system 
 cannot split a container that has serial numbers tied to it. If this checkbox is checked, 
 the system will try to meet the requirements of the first locating rule. 
 If it cannot, then the system will split off the remaining quantity and 
 create a new container, using the same values (such as unit of 
 measure, dimensions, etc). The system will then try to locate the remaining 
 quantity using the second locating rule. This will continue until all 
 the product is located, or locating fails because all of the existing 
 locating rules cannot be met. If 
 this checkbox is not checked, the system will try to meet the requirements 
 of the locating rule(s). If it cannot, then locating will fail.</p>
