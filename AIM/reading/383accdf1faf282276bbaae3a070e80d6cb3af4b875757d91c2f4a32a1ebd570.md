
        
        <h1 data-source-node="n56"><a name="kanchor1204" data-source-node="n57"></a>Activating Inventory Tracking</h1>
        <p data-source-node="n58">Inventory management allows you to control and adjust product at the 
 location level. The system will update its inventory history of the product 
 based on these inventory management activities. Therefore, the system 
 must perform inventory tracking on the item if you want to adjust it. 
 If the system does not track the item, it will have no inventory count 
 for the product and no inventory records for the item/location. You will need to activate inventory tracking in one of two places, depending 
 on the item you are trying to track. If the item you are trying to track 
 is defined in the system, you will have to activate a setting in the Item 
 Window. If the item you are trying to track is not defined in the system, 
 you will have to activate a setting in the Inventory Control Values Window.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h4 data-source-node="n62">Procedures: An Item Defined in the System</h4>
        <p data-source-node="n63">Access the Item Window. Open an item record.</p>
        <ul data-source-node="n64">
            <li data-source-node="n65">
                <p data-source-node="n66">To activate inventory tracking 
 for an item defined in the system, select the Inventory Tracking 
 Checkbox. The system will now allow Inventory adjustments on this item.    NOTE: This setting takes precedence 
 over the system value (when configured to "No" in the procedure 
 below).</p>
                <p data-source-node="n67"> </p>
            </li>
        </ul>
        <p data-source-node="n68"> </p>
        <h4 data-source-node="n69">Procedures: An Item NOT Defined in the System</h4>
        <p data-source-node="n70">Access the Inventory Control Values Window. Select the Inventory Tracking 
 record.</p>
        <ul data-source-node="n71">
            <li data-source-node="n72">To activate inventory 
 tracking for items not defined in the system, select the value 
 "Yes" in the Inventory Tracking Field. The system will now allow 
 adjustments for any item that is not defined in the system.    NOTE: 
 If you select the value "No," then the system will not 
 allow adjustments to    any item 
 not already defined in the system.</li>
        </ul>
