
        
        <h1 data-source-node="n56"><a name="kanchor413" data-source-node="n57"></a>Allow Container Creation During Close Checkbox</h1>
        <p data-source-node="n58">You can use this checkbox if you want to be able to create containers without 
 identifying their contents. This allows then to create containers "on 
 the fly" on the Close Container screen (outside of the packing process). 
 The user identifies the shipment associated with the container, but 
 never links it to particular shipment lines. Because the shipment line  is not identified, the system cannot verify accuracy of contents, or track 
 the contents through the system.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: This setting only applies to the Close Container Window that is accessed from the remote desktop system menu.</p>
