
        
        <h1 data-source-node="n57"><a name="kanchor1454" data-source-node="n58"></a>Parent Field</h1>
        <p data-source-node="n59">This field indicates the top-level accessorial detail that the accessorial detail you are configuring is subordinate to. This allows you the ability to create a parent/child relationship between accessorial details of the <i data-source-node="n60">Address</i> value type.  This is helpful when Progistics expects full address values to be passed for a particular accessorial detail. 

 Note that while only a value type of <i data-source-node="n61">Address</i> can be a parent accessorial detail, any value type can be a child accessorial detail. </p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">When using Progistics, in order to pass a new address as the “Ship From” on a label, a subcode needs to be created with the external symbol of RETURN_ADDRESS. Then, each of the “child” subcodes will need to have the external symbols listed below (case sensitive):</p>
        <blockquote data-source-node="n64">
            <p data-source-node="n65">Company</p>
            <p data-source-node="n66">Address1</p>
            <p data-source-node="n67">Address2</p>
            <p data-source-node="n68">Address3</p>
            <p data-source-node="n69">City</p>
            <p data-source-node="n70">StateProvince</p>
            <p data-source-node="n71">PostalCode</p>
            <p data-source-node="n72">CountrySymbol</p>
            <p data-source-node="n73">Contact</p>
            <p data-source-node="n74">Phone</p>
            <p data-source-node="n75">Fax</p>
        </blockquote>
