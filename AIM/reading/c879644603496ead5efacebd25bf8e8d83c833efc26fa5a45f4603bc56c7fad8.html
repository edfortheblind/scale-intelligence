Prerequisites/Requirements When Using UPS World Ease

Below are some prerequisites and requirements that you will have to address when using the UPS World Ease carrier service:

  • You will need to get clearance from UPS to use the World Ease service.
     
  • World Ease requires its own account number, separate from the account number used for regular UPS shipments. Therefore, you will need to acquire new account number(s), as they need to be set up as consignee account numbers and defined as intermediate consignees on shipments. Obtain this intermediate consignee information from your UPS representative.

  • You will need to establish a separate shipper code for the World Ease shipments.
     
  • World Ease is an accessorial. The accessorial header should have the Apply Per Container and the Always Apply checkboxes selected. This is done so that whenever you interface a World Ease shipment, the accessorial is always applied. The World Ease accessorial must be applied to all containers of a shipment.
     
  • Because World Ease has its own accessorial fee, and because it directs a container to a hub (not directly to the end customer), it should not be used with "generic" international services offered by UPS. Therefore, you will need to create one World Ease carrier service for every UPS service that you support. In other words, the World Ease carrier service gets the World Ease accessorial; not the "generic" international service.

  • To associate a container with a World Ease Group during a wave, you will need to run the "Paperwork – Labels" wave step (as it includes the manifesting process).
     
  • Note that the "IMPORTER_OF_RECORD" accessorial external symbol means "Intermediate Consignee Address" (the intermediate consignee is also referred to as a Hub or Port of Entry); the "IMPORTER_OF_RECORD_ACCOUNT" accessorial external symbol means "Consignee Account Number."
     
  • A shipper can only use World Ease when the "Allow World Ease Shipments" checkbox is selected in the Progistics configuration for the UPS carrier.

  • The UPS World Ease license option needs to be added to the current license. You do not need a new license, as your existing Progistics license would be enabled for World Ease. There is another way of setting up World Ease where you need a separate UPS account number, but the help addresses setup of World Ease with a single account number.

  • Obtain a POE file (a.k.a. Port of Entry file). This is a csv file provided by your UPS representative. It contains the details of the POE and states the minimum and maximum zip code supported (such as 30080 to 30090). All the zip codes that lie in the range of 30080 to 30090 would be supported by this POE.

  • Obtain the special kind of thermal label from UPS. It will have a code of either 01863201 or 01863202.

  • Since the World Ease labels are of a different size and structure, a dedicated label printer to print these labels is required.
