Disassembling a Finished Item

Occasionally, you may need to disassemble a finished item. You can perform this action from the Inventory Insight screen. You can only disassemble a finished item if it is associated with a bill of materials record.

Procedures...

 

Disassembling from Inventory Insight at Inventory Location:
  • Access the Inventory Insight screen.

  • Find the location where the finished item is stored. Use the Basic Criteria Fields located on the Filter Pane to indicate the values for your primary search.

  • Press the Search Button. The system will display the resulting records in the List Pane.

  • Select the finished item from the grid. Select the Finished Item Breakdown action from the Actions menu. If disassembling a finished item at an LP tracked location, then the "Show all LPs and attributes" toggle should be turned on.

  • Verify that the Quantity Field contains the number of finished items that you want to disassemble. If appropriate, you can change this value. The Available Quantity field must represent a positive value.

  • Verify that the Transfer to Build Location Field represents the location where you want the component items returned.

  • Review the list of components displayed in the Components list. Please note that the value in the component's Quantity needed per item Field identifies how many units were required to make one finished item. For example, if you are disassembling 10 finished item units and 2 units of component A are used to build each finished item, you will return 20 units of component A.

  • Press Save. The system will perform an inventory transfer to locate the component items back to the build location identified in the Transfer to Build Location Field.

For Lot Controlled Component Items:
  1. The system will prompt for Lot Information after pressing Save. The screen will prompt for the lot ID and breakdown quantity. The total breakdown quantity will be defaulted from the Finished Item Breakdown screen. If the component item exists with one or more lot IDs at the build location, then these lot IDs will be defaulted in the lot ID drop down.

  2. Press Save.

    • If the lot ID already exists at the build location for the component item, then the system adds the component item quantity for the lot ID to the build location.

    • If the lot ID does not exist at the build location for the component item, then the system prompts for the new lot ID, inventory status, expiration date, and whether to freeze the lot from the Lot screen. The lot ID is defaulted from the Lot Information screen and the inventory status is defaulted from the Finished Item Breakdown screen. Note that setting the Frozen toggle to Yes will change the inventory status to the “Inventory status for frozen lots” Inventory Control Value.

    • Press Save. The system adds the component item quantity for the new lot ID at the build location with the inventory status and expiration date set on the Lot screen.

 

 

 

Disassemble Finished Item at Work Order Build Location from Inventory Insight when Locate and Create Work are turned on:
  • Access the Inventory Insight screen.

  • Find the location for the finished item to break down using the Basic Criteria Fields located on the Filter Pane to indicate the values for your primary search.

  • Press the Search Button. The system will display the resulting records in the List Pane.

  • Transfer the finished item from the inventory location to a work order build location using an inventory transfer.

  • Find the finished item at the work order build location.

  • Select the finished item from the grid. Select the Finished Item Breakdown action from the Actions menu.

  • Turn the Locate and Create Work flag On.

  • Verify that the Quantity Field contains the number of finished items that you want to disassemble. If appropriate, you can change this value. The Available Quantity field must represent a positive value.

  • Review the component items. Each of the component items will have a locating rule and inventory status:

    1. The locating rule will be the component item’s locating rule from the item master. The locating rule can be changed to any active locating rule.

    2. The inventory status will be the set to the “Default inventory status for adjustments” inventory control value. The status per component item can be changed to any active inventory status.

  • Press Save. Each component item will be located to an inventory location based on the item’s locating rule. Inventory transfer work will be created to the inventory location. The work creation master set on the “Adjustment type for component item transfer” work order system value will determine what work creation master is used. The system will remove the disassemble quantity of the finished item from the build location and add the component items to the build location. The inventory status for those items will be based on the value set on each component item. Each component item will have allocated quantity at the build location and in transit at the inventory location.

Note that if a component item already exists at the build location, then the component item’s inventory status remains disabled regardless the value set on the component item.

 

For Lot Controlled Component Items:
  1. The system will prompt for Lot Information after pressing Save. The screen will prompt for the lot ID and breakdown quantity. The total breakdown quantity will be defaulted from the Finished Item Breakdown screen. If the component item exists with one or more lot IDs at the build location, then these lot IDs will be defaulted in the lot ID drop down.

  2. Press Save.

    • If the lot ID already exists at the build location for the component item, then the system adds the component item quantity for the lot ID to the build location.

    • If the lot ID does not exist at the build location for the component item, then the system prompts for the new lot ID, inventory status, expiration date, and whether to freeze the lot from the Lot screen. The lot ID is defaulted from the Lot Information screen and the inventory status is defaulted from the Finished Item Breakdown screen. Note that setting the Frozen toggle to Yes will change the inventory status to the “Inventory status for frozen lots” Inventory Control Value.

    • Press Save. The system adds the component item quantity for the new lot ID at the build location with the inventory status and expiration date set on the Lot screen.

     

    NOTE: 

    • Locating failure leaves the component items that fail on hand at the build location. Component items that locate successfully remain located as long as work creation is successful.

    • Work creation failure rolls back only the work for the component items that fail. This “unlocates” the component items that fail and leaves them on hand at the build location.

    • Locating or work creation failure requires the user to fix the cause of failure (locating rule or work creation criteria) and use an inventory transfer to move the component out of the work order build location.

    • Deleting the inventory transfer work for the component item will unlocate the component item(s). The component items will remain on hand at the build location.

    • Locating and creating work is done per component item, which means a work unit is created for each component item.

Disassembling a Finished Item with Serial Number Tracked Finished or Component Items:
  • Access the Inventory Insight screen.

  • Find the location where the finished item is stored. Use the Basic Criteria Fields located on the Filter Pane to indicate the values for your primary search.

  • Press the Search Button. The system will display the resulting records in the List Pane.

  • Select the finished item from the grid. Select the Finished Item Breakdown action from the Actions menu. If disassembling a finished item at an LP tracked location, then the "Show all LPs and attributes" toggle should be turned on.

  • Verify that the Quantity Field contains the number of finished items that you want to disassemble. If appropriate, you can change this value. The Available Quantity field must represent a positive value.

  • Verify that the Transfer to Build Location Field represents the location where you want the component items returned. The Transfer to Build Location field is only required when the finished item is at an inventory location. If the finished item is at a work order build location, then the field is disabled.

  • Review the list of components displayed in the Components list. Please note that the value in the component's Quantity needed per item Field identifies how many units were required to make one finished item. For example, if you are disassembling 10 finished item units and 2 units of component A are used to build each finished item, you will return 20 units of component A.

  • Press Save. The system will perform an inventory transfer to locate the component items back to the build location identified in the Transfer to Build Location Field.

  • Press Save on the Finished Item Breakdown screen. The system will prompt to enter/select a serial number for each unit of the finished item being disassembled.

  • Press Save on the Serial Number Entry screen. The system will prompt to enter a new serial number for each unit of the component item that is being added to inventory at the build location.

NOTE: The Serial Number Entry screen will only prompt for items that are serial number tracked in inventory when breaking down a finished item.
