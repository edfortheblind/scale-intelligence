
        
        <h1 data-source-node="n56"><a name="kanchor2087" data-source-node="n57"></a>Activating a Work Type for Pick Management</h1>
        <p data-source-node="n58">You must activate picking management for a specific work type if you 
 want the system to display work unit(s) with this type in the picking 
 management windows. Note that this topic discusses only 
 the steps needed to activate picking management for a specific work type. 
 For more information on creating work types in general, see the topic <a href="41c42a03d5dce72b3adc9e4eeaed9c61eece8b634fd3fa2dddcdc61685f892b3.html" data-source-node="n59">Defining Work Types</a>. You will activate a work type on the Work Type Window.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h4 data-source-node="n62">Using the Pick Management Active Checkbox...</h4>
        <p data-source-node="n63">Access the Work Type Window. Open or create a new work type record.</p>
        <ol data-source-node="n64">
            <li value="1" data-source-node="n65">Use the Pick 
 Management Active Checkbox to indicate if you want work units with 
 this work type to appear in picking management.<br data-source-node="n66"> </li>
            <ul type="disc" class="ul_1" data-source-node="n67">
                <li data-source-node="n68">
                    <p data-source-node="n69">If this checkbox is checked, 
 the system will display work units with this work type in picking management 
 windows, such as the Picking Selection Window or the Picking Management 
 Explorer.</p>
                    <p data-source-node="n70"> </p>
                </li>
                <li data-source-node="n71">If this 
 checkbox is not checked, the system will not display work units 
 with this work type in picking management windows.</li>
            </ul>
        </ol>
