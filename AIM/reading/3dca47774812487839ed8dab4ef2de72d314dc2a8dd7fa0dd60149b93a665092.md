
        
        <h1 data-source-node="n56"><a name="kanchor1753" data-source-node="n57"></a>ERP Order Number Field</h1>
        <p data-source-node="n58">This field represents the ERP order number associated with a specific 
 order request. All shipments are associated with an order. Order numbers originate in the ERP. When interfacing 
 an order, the system assigns it a shipment ID number. All activity in 
 the system is committed against the shipment ID number, not the order 
 number. The system transmits status updates to the interface.</p>
