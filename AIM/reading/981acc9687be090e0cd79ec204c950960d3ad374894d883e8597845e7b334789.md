
        
        <h1 data-source-node="n56">Using Warehouse Mobile - Shipping Container Nesting</h1>
        <p data-source-node="n57">The Warehouse Mobile shipping container nesting enables workers with the mobile device to pack one small (child) container into another large (parent) container. This is used for orders that have prepacked cases and few loose items. Using nesting the case can be packed into a large container that also has the loose items.</p>
        <p data-source-node="n58">When you performs nesting, the system associates the nested container ID and its items with the container that you have nested into.</p>
        <p data-source-node="n59">Using this screen, shipping container can also be removed from pallets.</p>
        <p data-source-node="n60">Note: Containers on shipment can only be nested. will be done for containers. Also, the container types available for nesting can be authorized by company and warehouse. See the Defining Container Types for more details.</p>

        <h4 data-source-node="n93"><a name="Nest" data-source-node="n94"></a>Nest Container screen</h4>
        <p data-source-node="n95"> </p>
        <p data-source-node="n96">Enables user to nest containers on the shipping dock in the warehouse.</p>
        <p data-source-node="n97"> </p>
        <ol data-source-node="n98">
            <li value="1" data-source-node="n99">Tap <b data-source-node="n100">Shipping Container Nesting</b> to view the Select Nesting Type screen.</li>
            <li value="2" data-source-node="n101">
                <p data-source-node="n102">Tap Nest.</p>
            </li>
            <li value="3" data-source-node="n103">Enter or scan the <b data-source-node="n104">Container ID</b> and Tap <b data-source-node="n105">Go</b>.</li>
            <li value="4" data-source-node="n106">The entered <b data-source-node="n107">Container ID</b> is displayed as <b data-source-node="n108">From Container</b>. Click information to view the details of the container.</li>
            <li value="5" data-source-node="n109">Enter the <b data-source-node="n110">To Container</b> to nest. Tap <b data-source-node="n111">Go</b>.</li>
            <li value="6" data-source-node="n112">In case its a new container created, select the <b data-source-node="n113">Container Type</b> from the list.</li>
            <li value="7" data-source-node="n114">Tap <b data-source-node="n115">Go</b> to complete nesting the containers.</li>
        </ol>
        <h4 data-source-node="n116">Nesting Containers Onto Multiple Order Pallets</h4>
        <p data-source-node="n117"> </p>
        <p data-source-node="n118">User can nest shipping containers onto multiple order pallets. A multiple order pallet is a single shipping pallet that has different shipments (for different ship to addresses) placed on it. Also, you may remove container(s) from a multiple order pallet using this screen.</p>
        <p data-source-node="n119"> </p>
        <p data-source-node="n120">
            <h4 data-source-node="n121">Remove Shipping Container screen</h4>
            <p data-source-node="n122"> </p>
        </p>
        <p data-source-node="n123">The Remove Shipping Container screen prompts for a Container ID. The Warehouse Mobile screen is titled Shipping Container Remove Nesting and uses the Container ID field to start the remove flow.</p>
        <p data-source-node="n124">If you enter a nested container, the system removes a single container from the pallet. If you enter a parent container, the system prompts you to confirm whether to remove all nested containers from the pallet.</p>
        <p data-source-node="n125"> </p>
        <p data-source-node="n126">
            <h4 data-source-node="n127">Remove a single container from a pallet</h4>
            <p data-source-node="n128"> </p>
        </p>
        <p data-source-node="n129">Use this flow when you want to remove one nested shipping container from a pallet.</p>
        <p data-source-node="n130"> </p>
        <ol data-source-node="n131">
            <li value="1" data-source-node="n132">Select Remove from the Select Nesting Type screen.</li>
            <li value="2" data-source-node="n133">Enter or scan the nested container in the Container ID field.</li>
            <li value="3" data-source-node="n134">Confirm the removal when prompted.</li>
            <li value="4" data-source-node="n135">The system removes the container from the pallet.</li>
            <li value="5" data-source-node="n136">The system notifies the user that the container was successfully removed from the pallet.</li>
        </ol>
        <p data-source-node="n137"> </p>
        <p data-source-node="n138">
            <h4 data-source-node="n139">Remove all containers from a pallet</h4>
            <p data-source-node="n140"> </p>
        </p>
        <p data-source-node="n141">Use this flow when you want to remove all nested shipping containers from a parent pallet.</p>
        <p data-source-node="n142"> </p>
        <ol data-source-node="n143">
            <li value="1" data-source-node="n144">Select Remove from the Select Nesting Type screen.</li>
            <li value="2" data-source-node="n145">Enter or scan the parent container in the Container ID field.</li>
            <li value="3" data-source-node="n146">When the confirmation prompt appears, select Yes to remove all nested containers from the pallet.</li>
            <li value="4" data-source-node="n147">Select No to return to the Container ID screen without removing containers.</li>
        </ol>
        <p data-source-node="n148">
            <h4 data-source-node="n149"><a name="Notes" data-source-node="n150"></a>Notes</h4>
        </p>
        <ul data-source-node="n151">
            <li data-source-node="n152">A new system created container or manually added container nesting will be done based on the packing reference configuration</li>
            <li data-source-node="n153">The container type listed will be based on the configuration in the company and user authorization.</li>
            <li data-source-node="n154">When nesting is done to an existing container, system will not prompt container type selection.</li>
            <li data-source-node="n155">Nesting cannot be done for a container in different location.</li>
            <li data-source-node="n156">When a wave is not in Released state, then nesting will fail.</li>
            <li data-source-node="n157">Asynchronous validation is enabled, and system displays appropriate error message.</li>
        </ul>
