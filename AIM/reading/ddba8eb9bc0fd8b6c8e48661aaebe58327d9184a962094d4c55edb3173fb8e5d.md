
        
        <h1 data-source-node="n56"><a name="kanchor952" data-source-node="n57"></a>Wave ID / Wave Number Field</h1>
        <p data-source-node="n58">A system assigned number that represents a specific wave. This ID is 
 associated with all shipments included in a wave. The wave that generated 
 a particular work instruction. Note: on the Work Instruction screen, this 
 field can refer to a locating group if the following conditions exist: 
 the work instruction is a putaway generated by the Inbound processing 
 module. In this case, a wave number does not literally apply because the 
 work is created outside of a wave. A locating group includes all checked 
 in containers that were located when the user selected Locate All or Locate 
 on the Receipt Workbench. If the user selected Locate (not Locate 
 All), the group will include only 1 container. </p>
