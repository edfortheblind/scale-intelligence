                <td class="td_15" data-source-node="n195">
                    <p data-source-node="n196">Delimiter Token: This value 
 indicates which character you want to use to separate fields on a Delimited/Fixed 
 Length text file. Common delimiter tokens include such characters as: 
 +, |, #. <br data-source-node="n197"><br data-source-node="n198">This delimiter token must be a 
 one character value. The token cannot be a letter, number or any symbol 
 that you might include as data. For example, if some addresses use # sign 
 for apartments, do not select this symbol as the delimiter token. The 
 system cannot discern between data and token signs and will not parse 
 the data correctly.<br data-source-node="n199"><br data-source-node="n200">You can use ASCII values to specify a character that cannot be accessed 
 by the keyboard. This is an additional safeguard to ensure that a value 
 is not used as both the token and a value. For example, you could enter 
 the ASCII value 124 to represent | (the pipe bar).<br data-source-node="n201"><br data-source-node="n202">NOTE: Windows considers an asterisk a "wildcard" character 
 (used for general searches), so the system will not allow you enter an 
 asterisk into the System Value Field.</p>
