
        
        <h1 data-source-node="n56"><a name="kanchor1573" data-source-node="n57"></a>Before You Begin: Web Statistics Setup Prerequisites</h1>
        <p data-source-node="n58">You must address the following items in order for the system to correctly 
 generate web statistics. If you have any further questions about these 
 prerequisites, see your Manhattan consultant:</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Inbound 
 Statistics...</h4>
        <p data-source-node="n62">- Based on container status &gt;= 900</p>
        <p data-source-node="n63">- Company present on the detail</p>
        <p data-source-node="n64">- Transaction history created for locating</p>
        <p data-source-node="n65">- Date based on receipt container's date time stamp</p>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67"> </p>
        <h4 data-source-node="n68">Outbound 
 Statistics...</h4>
        <p data-source-node="n69">- Must perform picking work</p>
        <p data-source-node="n70">- Detail status &gt; 800</p>
        <p data-source-node="n71">- Company present on the detail</p>
        <p data-source-node="n72">- Transaction history created for load confirmation</p>
        <p data-source-node="n73">- System goes off of the load confirmation activity date time stamp.</p>
        <p data-source-node="n74"> </p>
        <p data-source-node="n75"> </p>
        <h4 data-source-node="n76">Item 
 Statistics...</h4>
        <p data-source-node="n77">- System gets all item, company, and inventory status records</p>
        <p data-source-node="n78">- Updates based on inbound and outbound statistics</p>
        <p data-source-node="n79">- System takes current inventory snapshot (If you re-generate the statistics 
 on a different day, the current inventory records will be updated)</p>
