
        
        <h1 data-source-node="n56">One Pro Number Per Load? Field</h1>
        <p data-source-node="n57">This field indicates if you want the system to assign one pro number 
 to represent all the shipments per shipping load. This would commonly 
 be used for loads that use the master BOL paperwork document.</p>
