
        
        <h1 data-source-node="n56"><a name="kanchor765" data-source-node="n57"></a>Store Distribution Field</h1>
        <p data-source-node="n58">This field is an identifier that represents the store order/distro that was interfaced into the system. The purpose of this value is so a shipment's individual store details can be linked back to the original store order (after the details have been assigned to new individual shipments). These shipments, then, would be shipped to the store.</p>
