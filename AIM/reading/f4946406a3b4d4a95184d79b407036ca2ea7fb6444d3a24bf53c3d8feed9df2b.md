
        
        <h1 data-source-node="n56"><a name="kanchor1345" data-source-node="n57"></a>Activating Real Time Replenishment for a Location</h1>
        <p data-source-node="n58">For the system to consider a location for real time replenishment, it 
 first has to be labeled as a "real time" location. You can 
 activate this setting on the Location Window. Note that only "inventory 
 storage" locations can be made eligible for real time replenishment. You can activate this setting on the Location Window.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Procedures...</h4>
        <ol class="ol_2" data-source-node="n62">
            <li value="1" data-source-node="n63">Access the Location 
 Window, and open a location record or create a new location.<br data-source-node="n64"> </li>
            <li value="2" data-source-node="n65">Use the Real 
 Time Replenishment Checkbox to make this location eligible for 
 real time replenishment. For more details, see the <a href="5cd4fd4791e17a8dcbfcd241048f239594fb6f06869b157c8979e992722cd536.html" data-source-node="n66">field topic</a>.<br data-source-node="n67"> </li>
            <li value="3" data-source-node="n68">For information 
 on the other fields in this window, see the topic "Creating 
 Locations."<br data-source-node="n69"> </li>
            <li value="4" data-source-node="n70">Press OK 
 when finished.</li>
        </ol>
