
        
        <h1 data-source-node="n56"><a name="kanchor1265" data-source-node="n57"></a>Creating a Dock Area Carrier Assignment Record</h1>
        <p data-source-node="n58">The system uses these records to help ensure that all of a shipment's containers/details are assigned to the carrier's appropriate dock location area (staging or dock door). The system references this record when using the dock location selection strategy. Note that these records are optional, and if they do not exist, the dock assignment process will assign the default dock locations as defined on the dock management flow header or detail. </p>

        <h4 data-source-node="n86">Procedures: Header Fields...</h4>
        <ol data-source-node="n87">
            <li value="1" data-source-node="n88">Use the Warehouse Field to indicate the warehouse where a carrier's dock location area resides.<br data-source-node="n89"><br data-source-node="n90"></li>
            <li value="2" data-source-node="n91">Use the Dock Area Field to indicate the dock location area that you want the system to assign when a container is associated to a specific carrier.</li>
        </ol>
        <p data-source-node="n92"> </p>
        <h4 data-source-node="n93">Procedures: General Tab Fields...</h4>
        <ol data-source-node="n94">
            <li value="1" data-source-node="n95">Use the Carrier Assignment Field to indicate that you want to filter eligible containers by carrier/carrier service, carrier group, or none. <br data-source-node="n96"><br data-source-node="n97"><i data-source-node="n98">Notes On "None" Records</i>:<br data-source-node="n99">- It is helpful to create a "none" record for a dock location area so that if the system cannot find an empty spot in the carrier's dock location area, then the container will be assigned to the overflow location (represented by the "none" record). <br data-source-node="n100"><br data-source-node="n101">- If no "none" records are defined, then the system will assign the last dock location evaluated (regardless of its current open capacity).<br data-source-node="n102"><br data-source-node="n103"></li>
            <li value="2" data-source-node="n104">Press OK. The system will save your record.</li>
        </ol>
