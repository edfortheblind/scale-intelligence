
        
        <h1 data-source-node="n56"><a name="kanchor584" data-source-node="n57"></a>Update Cycle Count Work To Include All Items Checkbox/Toggle</h1>
        <p data-source-node="n58">If this checkbox/toggle is selected, then the system will create cycle count requests for all items currently at a multi-item location, as opposed to creating requests for just the item(s) at the location that match the cycle count item selection criteria.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">NOTE: When a multi-item location is initially empty and then items are adjusted into it (prior to the cycle counting work being executed), the system will create a cycle count for every item adjusted into the location, regardless of whether this setting is on or off.</p>
