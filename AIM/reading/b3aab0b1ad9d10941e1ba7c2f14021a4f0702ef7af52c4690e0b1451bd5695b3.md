
        
        <h1 data-source-node="n56"><a name="kanchor1569" data-source-node="n57"></a>Image Resource Key Field</h1>
        <h5 data-source-node="n58">On 
 Viewer Windows...</h5>
        <p data-source-node="n59">This field indicates the icon that 
 will appear to the left of certain records on the results grid of custom 
 viewers. The system will use the rules defined in this window to determine 
 what records it will display this icon for. If you do not assign any rules 
 to this icon record, the system will display this icon for all results 
 row(s).  </p>
