
        
        <h1 data-source-node="n56"><a name="kanchor751" data-source-node="n57"></a>SCAC Code Field</h1>
        <p data-source-node="n58">The Standard Carrier Alpha Code. The SCAC 
 Code is a unique identifier for a particular carrier. The carrier will 
 provide its SCAC Code. The SCAC Code is printed on the carrier's 
 Bill of Lading. The system does not use it for processing. This field is also part of the interface upload 
 process for shipments.</p>
