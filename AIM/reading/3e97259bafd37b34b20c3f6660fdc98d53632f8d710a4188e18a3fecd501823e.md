
        
        <h1 data-source-node="n56"><a name="kanchor1605" data-source-node="n57"></a>Next Number Field</h1>
        <p data-source-node="n58">The next number that the system will assign 
 to a key number. A key number uniquely identifies a specific object/number. 
 Examples include parcel number, container ID/license plate ID, wave number and shipment 
 number. The system assigns these numbers each time a new one is needed. The system usually assigns these when a wave 
 is initiated.</p>
