Creating Security Permissions

You can create user security records on the Security Permissions Window. When a user attempts to access a SCALE window, the system determines if they have any user-level security records. If an employee has a user-level record, the system will apply that record each time the employee attempts to access the window. User-level security limits a single employee's ability to access and/or perform actions on a specific window. Or, the Security Permissions Window can be used to define the security rights of a specific security group. Processing and/or configurations are defined for the security group and what security checkpoints can be used for the group. These are all defined using the Security Permissions Window.
 

Mass security changes are also allowed using this window. The system allows you to select the processing or configuration windows and assigning security to them. All of the selected forms (windows) will be assigned the selected security levels and actions.

 

This window allows you to grant security permissions by a specific processing function or by a specific configuration.

Using Security Permissions...

Open the Security Permissions Window. The upper half of this window displays the system windows that you can create security records for.

  1. Access a specific window's settings by selecting it from the list.

     

  2. When you select a record from the list, the system displays all security records defined for this window.
     
  3. To create a new record, select the New Action from the record list.
     
  4. Use the Security Level Field to indicate if you want to create a user, group or system-level security record.
     
  5. Use the User Name Field to select the user that you are creating the security record for. When you create a system-level record, this field is deactivated.
    Or,
    Use the Group Name Field to select the group you are creating the security record for.
     
  6. Use the checkboxes on the General Tab to assign permission to this user for basic window functions, such as run, copy or delete. Note that to allow a user to open a window, you must select the action "Run."
     
  7. Use the checkboxes on the Form Specific Tab to select the specific advanced action(s) that you want to allow this user to perform on this window. Note that not all windows will have form-specific tabs.
     
  8. When finished, click OK. The system will save your record. You will have to perform a session refresh in order for security settings to take effect.

 

 

Performing a Mass Security Change...

A mass security change lets you define user, group or system-level security that affects all system windows in one step. This is especially helpful if you want to create a system-level record for all windows, or grant a user access to all windows. If you want to perform a mass change to the Security Permissions Window, create a user-level record that can access both this window and the Configurations Explorer. The system will not allow you to deny access to the Security Window in a mass change unless one record exists that can open it. This safeguard ensures you are not locked out the Security Window.

  1. Access the Security Permissions Window.

  2. Manually select the windows you want to set security for. You may select All, Processing or Configurations windows to be displayed.

    OR

    Choose the Select All option from the Actions Menu. The system will select all the windows from the forms list.
     

  3. Use the Security Level Field to indicate if you want to create a user-level, group level, or system-level security record. If you create a user-level record, use the User Name Field to select the user that you are creating the security record for. If you select Group level, enter or select the group.

     

  4. Use the Checkpoints Checkboxes to select the actions that you want to allow the user to perform on these windows.

     

  5. Click OK. The system will create security records for the windows you selected. You will have to perform a session refresh in order for security settings to take effect.

 

 

 Copying a User Profile to a Security Permissions Group or User...

  1. Access the User Profile Window.

  2. Select the user being copied.

  3. Click OK. The user profile is displayed.

  4. From the Actions Menu, select either Copy user Security Permissions 'To Group' or 'To User; Option.

  5. From the Copy Permissions To Window, select the destination group or user.

  6. Click OK to update and copy.
