
        
        <h1 data-source-node="n56"><a name="kanchor156" data-source-node="n57"></a>Parent Dock Area Field</h1>
        <p data-source-node="n58">Use this field to create a relationship between a dock position (the child) and a dock area (the parent). The system uses this link to group dock position(s) into the correct dock area on the Dock Manager Window. Note that these links are optional and are not required to use the dock management process. Also, a dock area and dock position do not need the same location template structure to be linked.</p>
