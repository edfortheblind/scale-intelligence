
        
        <h1 data-source-node="n56"><a name="kanchor1077" data-source-node="n57"></a>Work Type Field</h1>
        <p data-source-node="n58">This field identifies a specific type of work, such as order picking. 
 You will define your warehouse's work types on the Work Type Window. Later, 
 you will associate the work type with work creation records and work profiles. 
 All work created in the system is assigned a work type. In addition, the 
 system generates labor management records based on work type. In the Labor Monitoring Screen, when drilling into a labor group, this field shows the estimated time broken down by work type.</p>
