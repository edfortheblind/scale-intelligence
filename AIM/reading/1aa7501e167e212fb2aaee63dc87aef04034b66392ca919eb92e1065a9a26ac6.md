
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">Locating Zone Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">Locating Zone configuration defines grouping values used by location determination and putaway logic. You can create and maintain locating zone records and assign them to locations.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62"><b data-source-node="n63">Note</b>: This configuration is currently accessible only from the Location Configuration wizard and is not available as a standalone configuration outside the wizard.</p>
        <h4 data-source-node="n64"> </h4>
        <h4 data-source-node="n65">Configure Locating Zone</h4>
        <p data-source-node="n66"> </p>
        <h5 data-source-node="n67">1. Locating Zone</h5>
        <p data-source-node="n68"> </p>
        <p data-source-node="n69">Select or create a Locating Zone record.</p>
        <ul data-source-node="n70">
            <li data-source-node="n71">
                <p data-source-node="n72"><b data-source-node="n73">Create New</b>: Create a new locating zone record.</p>
            </li>
            <li data-source-node="n74">
                <p data-source-node="n75"><b data-source-node="n76">View All</b>: Review and select an existing locating zone record.</p>
            </li>
            <li data-source-node="n77">
                <p data-source-node="n78"><b data-source-node="n79">Current Selection</b>: Displays the selected locating zone record.</p>
            </li>
        </ul>
        <p data-source-node="n80"> </p>
        <h5 data-source-node="n81">A. Information</h5>
        <p data-source-node="n82"> </p>
        <p data-source-node="n83"><b data-source-node="n84">Zone</b>: Enter the locating zone identifier.</p>
        <p data-source-node="n85"><b data-source-node="n86">Description</b>: Enter the locating zone description.</p>
        <p data-source-node="n87"> </p>
        <p data-source-node="n88">Use Back, Save, Continue, and Finish to manage and complete Locating Zone configuration.</p>
