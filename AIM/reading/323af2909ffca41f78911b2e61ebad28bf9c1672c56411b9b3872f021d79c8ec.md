
        
        <h1 data-source-node="n56"><a name="kanchor1466" data-source-node="n57"></a>Test Data Field</h1>
        <p data-source-node="n58">This field is used to enter a sample serial number that you believe 
 matches the structure of a serial number template. You will need to press 
 the Test Button to have the system analyze this "test data" 
 and decide if it matches the serial number template. A message will be 
 displayed with the results.</p>
