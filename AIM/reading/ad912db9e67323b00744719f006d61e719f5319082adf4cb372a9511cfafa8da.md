
        
        <h1 data-source-node="n56"><a name="kanchor416" data-source-node="n57"></a>Compute Qty As Buttons</h1>
        <h5 data-source-node="n58">For Quality Control...</h5>
        <p data-source-node="n59">Use these buttons to indicate how the system will compute how many items 
 that will be routed to quality control: by Amount or by Percentage. </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">For Work Order Processing...</h5>
        <p data-source-node="n63">Use these buttons to tell the system how you want to indicate the amount 
 of extra allocation for a certain work order component:</p>
        <ul type="disc" class="ul_1" data-source-node="n64">
            <li data-source-node="n65">If "amount" 
 is chosen, then the Increase Qty Field defines a hard quantity 
 for the additional quantity that the system will allocate. Suppose the 
 quantity of the component needed on a work order was 50, and the increase 
 quantity was 10; the system in this case would allocate 60.<br data-source-node="n66"> </li>
            <li data-source-node="n67">If "percentage" 
 is chosen, then the Increase Qty Field defines a percentage increase 
 for the additional quantity that the system will allocate. For example, 
 if the quantity of the component needed on a work order was 50, and the 
 increase quantity was 10; the system in this case would allocate 55.</li>
        </ul>
        <p data-source-node="n68">NOTE: You can only edit this 
 setting prior to the first time allocation is attempted on the work order.</p>
