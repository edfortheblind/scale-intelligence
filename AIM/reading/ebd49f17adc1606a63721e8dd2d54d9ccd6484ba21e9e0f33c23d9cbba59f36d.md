
        
        <h1 data-source-node="n57"><a name="kanchor970" data-source-node="n58"></a>From Quantity Field</h1>
        <p data-source-node="n59">The value in this field is dependent on the status of the instruction:</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">If the instruction has not been 
 completed, this field will contain the value generated during the 
 work creation process. </p>
                <p data-source-node="n63"> </p>
            </li>
            <li data-source-node="n64">
                <p data-source-node="n65">If the instruction is currently 
 being processed, this field will contain the amount of product 
 not yet obtained from the location.</p>
                <p data-source-node="n66"> </p>
            </li>
            <li class="li_1" data-source-node="n67">If 
 the instruction has been confirmed, this field will contain the 
 value '0'.</li>
        </ul>
        <p data-source-node="n68">This field identifies the quantity that should 
 be removed from the from location. It appears on the Work Instruction 
 Window.</p>
