
        
        <h1 data-source-node="n56"><a name="kanchor1574" data-source-node="n57"></a>Positive Tolerance Field</h1>
        <p data-source-node="n58">This field indicates the number of units above the number the system 
 thinks is contained in a location that the system will allow the user 
 to perform an adjustment to the location. For example, suppose the value in this field 
 is "5". Then, you are presented with a cycle count request that 
 indicates that there should be 20 units of an item in a particular location. 
 You count the units in the location, and there are 35. The system then 
 will compare this number to the positive tolerance value defined in this 
 window. This will determine if the user is allowed to make an adjustment. 
 Since the item quantity in this location is 15 units over the tolerance, 
 the system will put this request in a pending review status, and you will 
 not be able to execute the cycle count. Once the cycle count is in the 
 pending review status, it must be reviewed from the Cycle Count Request Insight screen 
 by a supervisor.</p>
