Processing UPS World Ease Groups

A UPS World Ease group consists of the container(s) whose final destination is the same intermediate consignee (Hub). A group is created when a shipping container is manifested. If a group already exists for a certain Hub destination, then the system will add the container to the existing group. You can view the containers assigned to a group from the World Ease Insight. When a group is closed, you will be able to print the appropriate World Ease documentation.

Required World Ease Manifesting Values...

The following values need to be provided on shipments that you want to manifest using UPS World Ease:

  • World Ease Flag Accessorial on the Shipping Container: This is setup to always apply to every container that uses UPS World Ease.
     
  • Intermediate Consignee Account Number on the Shipment: This is a nine-digit code supplied by UPS. This code represents a hub's address and the postal code range that the hub supports.

 

 

Procedures: Searching for Groups...

Access the World Ease Insight.

  1. Enter a value into the search criteria field(s).
     
  2. Press Search. The system will display in the Results Tab the World Ease group(s) that match your criteria. Each group will have either an Open or Closed status. An Open group can still have containers associated with it. For more information on Closed groups, see the section on closing groups below.

 

 

Procedures: Closing Groups...

Access the World Ease Insight. Perform a search for the appropriate World Ease group. To close a group, right-click a group and choose the Close Group option:

  • You cannot associate additional containers to a closed group.
     
  • A closed group cannot be reopened.
     
  • If a group is open and you close the manifest associated with it, the system will automatically close the group as well.
     
  • The system does not generate paperwork automatically as part of the Close Group action. Instead, after you close a group, you will have to manually initiate printing via the Print Action. You will prepare the paperwork that goes in the Document Box after a group is closed. You can print the following documents from the insight screen: World Ease Certificate of Origin, World Ease Document Box Label, World Ease Consolidated Invoice, and World Ease Master Invoice.
     
  • If a shipment is on this group, but also has product that is not yet packed into a container, the system will associate this unpacked quantity with another group when it is manifested.
     
  • Once a group is closed, Progistics will start a new group for any new containers that are going to that particular Hub (along with new MSN numbers, etc).
