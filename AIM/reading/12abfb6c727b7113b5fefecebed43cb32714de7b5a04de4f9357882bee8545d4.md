
        
        <h1 data-source-node="n56"><a name="kanchor1764" data-source-node="n57"></a>Status Range Fields</h1>
        <p data-source-node="n58">This field range identifies when a particular 
 action can be performed. The system supports status ranges for the following 
 functions: packing and ship confirmation. Regardless of the function, status ranges 
 always determine when a shipment can be processed, based on status. When you define a status range, use the second 
 status field to define the most advanced status. All statuses within this 
 range can be processed. Generally, more expansive status ranges are 
 assigned to managers and supervisors. This increases their ability to 
 respond to rush orders and other unexpected situations. For example, if 
 a status range allows someone to pack any item between In Picking and 
 Ready for Packing, he/she can rush an order through. More conservative 
 status ranges identify when the process typically occurs. For example, 
 the status range 'Ready for Packing to Ready for Packing' can be used 
 to process the majority of shipments in a stable warehouse. This status 
 range would be generally assigned to most employees performing the task.</p>

        <h5 data-source-node="n65">Defining Only One Eligible Status...</h5>
        <p data-source-node="n66">To define only one eligible status, enter that

 preference record will only be able to pack/confirm shipments in this
