Warehouse Mobile - Shipping Nest Container onto Multiple Order Pallets (MOP)

The Warehouse Mobile shipping container onto Multiple Order Pallets to nest shipping containers onto multiple order pallets. A multiple order pallet is a single shipping pallet that has different shipments (for different ship to addresses) placed on it. Also, you may remove container(s) from a multiple order pallet using this screen.

Nest Container onto a Multiple Order Pallet (MOP)

Enables user to nest container.

 

  1. Tap MOP Shipping Container Nesting to view the Select nesting type screen.
  2. Select Nest or Remove. Tap Nest to view Multiple Order pallet nesting screen.
  3. Enter or scan the Container ID that you want to nest the container onto Tap Go. Whether the new multiple order pallet ID is manually or system generated is based on the user's Container Assignment Method setting in packing preferences.
  4. Tap Go. The system will nest the container onto the multiple order pallet. You can continue to nest containers, or exit the screen by pressing the Cancel button.
  5. Also, in step 2 if you select Remove,then the Multiple Order pallet remove nesting screen is displayed. Repeat steps 3 and 4 to complete removing the container from nesting.

,

Nesting Validations

  • The “from” shipping container must be at the same dock location as the shipping container(s) already nested on the multiple order pallet.
  • The new multiple pallet ID must be unique in the system; it cannot be a currently-existing shipping container or multiple order pallet.
  • A shipping container
    • must be the “top-level” container to be eligible for nesting onto a multiple order pallet. Child shipping containers are NOT eligible for nesting.
    • must have a status greater than In Packing and less than or equal to Ship Confirm Pending to be eligible for nesting.
    • cannot be assigned to different carrier from the container(s) on the multiple order pallet.
    • cannot be assigned to a load different from the container(s) on the multiple order pallet.
    • cannot be assigned when the shipment(s) on the multiple order pallet are assigned to a closed shipping load.
    • cannot be nested onto the multiple order pallet if its wave has not been released.
    • cannot be nested onto the multiple order pallet if it has pending shipment work.
    • cannot be nested onto the multiple order pallet if it has pending or active dock management work.
  • As a result of the nesting action, the system will not change the manifest state on any of the shipping container(s) that are being nested or are already nested on the multiple order pallet already be assigned to a multiple order pallet.
