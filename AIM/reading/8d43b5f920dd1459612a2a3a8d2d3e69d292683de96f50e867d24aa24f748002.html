Customer Category

Customer categories are used in the order entry module to indicate such custom values as value-added inserts (catalogs, promotional gifts, etc.), special handling instructions, pay terms, or any other user-defined message/label. Note that you can define any value for these categories, as these categories do not affect system processing of orders. Also, you can indicate whether you want to have a category be inherited or not in the Customer configuration.

 

Requiring and Validating Customer Categories

Requiring Values: Refer to the "Reviewing Customer Category System Values" topic to enforce required input for each category.

 

Validation Settings: By default, customer category fields are validated against pre-defined values in the Customer Category 1–10 window.

You can disable validation by updating system text keys:

  • Each category uses a key in the format CUSTOMERCATEGORYxCFVV (e.g., CUSTOMERCATEGORY7CFVV).

  • A value of "N" enforces validation (default).

  • Change to "Y" to allow free-text entry, bypassing the predefined list.

 

Create Customer Category

 

Use the Identifier and Description Fields to indicate the name of the category. The system will use the values you enter in the Identifier Field to populate the Category (1-10) Field on the Order Entry Window. In the Order Entry Window, you can associate category(s) to an order.
