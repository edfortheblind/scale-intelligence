Activating History Generation

You will determine if the system will generate history records for most warehouse operations. Each operation is associated with a particular history type. The system activates most types of history record generation by default.

 

The following history types are tracked in SCALE:

  • Transaction History: Any time inventory is impacted by either system or user activity, The system writes a transaction record identifying what happened. Examples of transaction types are shipment allocation and short pick adjustment.

     

  • Process History: Any time the system either makes a decision or performs a transaction without user assistance, the it writes a process record identifying what happened. Examples of processes are carrier assignment and shipment processing.

     

  • Quality History: Any time an employee provides a reason code to explain a discrepancy during processing, the system writes a quality record identifying what happened. Examples of quality history are selecting the wrong item.

     

  • Receipt Quality History: Any time that an employee checks in a license plate on a new receipt, closes a receipt, or reopens a closed receipt, the system writes a quality record. Examples of receipt quality history are items not received and missed expected receipt date.

Procedures...

  1. Use the Create History? Field to identify whether or not you want the system to generate history for this operation:
     

    • To generate history for this operation, choose Yes. Note that you will need to perform a reset in order for the system to start recording this type of history.

       

    • To not generate history for this operation, choose No. Note that you will need to perform a reset in order for the system to stop recording this type of history.

     

  2. For transaction history, you will need to also determine if this type of history will be included in inventory transaction interface uploads.

    For quality history, you will need to choose a process and/or disposition code that is associated with this type of history.
     
  3. Press OK. The system will save your changes.
