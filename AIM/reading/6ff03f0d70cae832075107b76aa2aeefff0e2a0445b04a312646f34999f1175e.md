
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">Rating Service Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59">A rating service specifies a carrier and service combination. Progistics uses this information to determine the appropriate rate based on the selected carrier and service. For SCALE Less Than Truckload (LTL) internal rating, this configuration displays the rating ID and server symbol being used. Note that rating services are not required for internal LTL rating.</p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">Configure Rating Service</h4>
        <ul data-source-node="n62">
            <li data-source-node="n63">
                <p data-source-node="n64"><b data-source-node="n65">Rating Service</b>  - Select to identify the service. To minimize confusion, be sure to include the carrier's name in this field, because several carriers may have the same names for certain services they offer.</p>
            </li>
        </ul>
        <ul data-source-node="n66">
            <li data-source-node="n67">
                <p data-source-node="n68">Use the <b data-source-node="n69">Rating ID</b> to identify the carrier who offers this service..</p>
            </li>
        </ul>
        <ul data-source-node="n70">
            <li data-source-node="n71">
                <p data-source-node="n72">Use the <b data-source-node="n73">Service Symbol</b> to identify this carrier/service combination.</p>
            </li>
        </ul>
