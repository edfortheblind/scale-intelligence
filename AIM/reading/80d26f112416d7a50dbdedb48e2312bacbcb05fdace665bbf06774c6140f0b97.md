        <p data-source-node="n58">This field indicates if the data contained in files using this map will 
 be provided as delimited data or as fixed length data. If you choose fixed 
 length<span class="span_1" data-source-node="n59"> </span>mode, the system will 
 require that each field defined for this data map be given a specific 
 length.</p>
