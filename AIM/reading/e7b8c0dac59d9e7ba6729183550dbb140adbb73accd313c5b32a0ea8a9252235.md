        <h4 data-source-node="n89"><a name="Searching" data-source-node="n90"></a>Searching/Viewing Warehouse Mobile menu Records</h4>
        <p data-source-node="n91"> </p>
        <p data-source-node="n92">You can use the <b data-source-node="n93">Warehouse Mobile Menu Insight</b> screen to search for and view SRC records.</p>
        <ol data-source-node="n94">
            <li value="1" data-source-node="n95">Navigate to <b data-source-node="n96">Menu</b> &gt;&gt; <b data-source-node="n97">System Management</b> &gt;&gt; <b data-source-node="n98">Activity Architect.</b> . Click <b data-source-node="n99">Configure Menu</b> to open the <b data-source-node="n100">Warehouse Mobile Menu Insight</b> screen.<br data-source-node="n101"><br data-source-node="n102"></li>
            <li value="2" data-source-node="n103">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search. Optionally you can use the <b data-source-node="n104">Advanced Criteria</b> to enhance the search criteria.<br data-source-node="n105"><br data-source-node="n106"></li>
            <li value="3" data-source-node="n107">Click Search and system will display  the resulting records in the List Pane. <br data-source-node="n108"><br data-source-node="n109"></li>
            <li value="4" data-source-node="n110">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>
        <h4 data-source-node="n111"><a name="About" data-source-node="n112"></a>About the List Pane</h4>
        <p data-source-node="n113"> </p>
        <p data-source-node="n114">The list pane displays the list of menu records. </p>
        <p data-source-node="n115"> </p>
        <ul data-source-node="n116">
            <li data-source-node="n117">The <b data-source-node="n118">Warehouse Mobile Menu Insight</b> screen's List Pane displays the results from a query performed in the Filter Pane.<br data-source-node="n119"><br data-source-node="n120"></li>
            <li data-source-node="n121">For more general information about the List Pane, see the topic <a href="444e9b8e14a977178c9ff48b972dd65c076a4adda44c3dfacddf94a4a6c24d22.html" data-source-node="n122">Introduction to Insight Screens</a>.<br data-source-node="n123"></li>
        </ul>

        <h4 data-source-node="n125"><a name="Actions" data-source-node="n126"></a>Screen Actions...</h4>
        <p data-source-node="n127">The following actions are accessible from the <b data-source-node="n128">Warehouse Mobile Menu Insight</b> screen:</p>
        <p data-source-node="n129"> </p>
        <h5 data-source-node="n130">New</h5>
        <p data-source-node="n131">This action enables you to create a new warehouse mobile menu. Click <b data-source-node="n132">New</b> to create a new warehouse mobile menu. For more information on this topic, see <a href="bc118f0180b3eb741dad885447fb915566562640bf912e54d2baa88cff260e05.html" data-source-node="n133">Creating Warehouse Mobile menu.</a></p>
        <p data-source-node="n134"> </p>
        <h5 data-source-node="n135">Edit</h5>
        <p data-source-node="n136">This action allows edit the existing warehouse mobile menu record. Click <b data-source-node="n137">Edit</b> and view the warehouse mobile menu screen in edit mode. For more information on this topic, see <a href="bc118f0180b3eb741dad885447fb915566562640bf912e54d2baa88cff260e05.html" data-source-node="n138">Creating Warehouse Mobile menu.</a></p>
        <p data-source-node="n139"> </p>
        <h5 data-source-node="n140">Delete</h5>
        <p data-source-node="n141">This action allows you to delete single or multiple warehouse mobile menu records at a time.</p>
