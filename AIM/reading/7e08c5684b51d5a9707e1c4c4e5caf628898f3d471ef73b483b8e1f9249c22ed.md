
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Comment Type</h1>
        <p data-source-node="n58">A comment type determines when a specific message should be included on documents associated with a particular document type, effectively linking messages to documents. Each comment type must be defined in both the ERP and the system. When setting up a comment type in this screen, ensure it matches exactly with the one defined in the ERP—any mismatch will prevent the system from printing the correct comment on the document. Once the comment type is defined, you will associate it with the relevant document types for printing.</p>
        <p data-source-node="n59"> </p>
        <h5 data-source-node="n60">Create Comment Type record</h5>
        <ul data-source-node="n61">
            <li data-source-node="n62">
                <p data-source-node="n63"><b data-source-node="n64">Comment Type</b> - Enter the name of the comment type. This value must exactly match the corresponding comment type defined in the ERP. When used in a shipment, shipment line, or work instruction, the system will refer back to the ERP to retrieve the related message.</p>
            </li>
        </ul>
        <ul data-source-node="n65">
            <li data-source-node="n66">
                <p data-source-node="n67"><b data-source-node="n68">Description</b> - Provide a description of the comment type. This is for reference only and does not need to match any ERP value.</p>
            </li>
        </ul>
        <ul data-source-node="n69">
            <li data-source-node="n70">
                <p data-source-node="n71"><b data-source-node="n72">Communication Method Buttons</b>: Specify when the comment will appear on an  device. Note: The system does not consider the "before/after" timing for printed documents like pick lists.</p>
                <ul data-source-node="n73">
                    <li data-source-node="n74">
                        <p data-source-node="n75"><b data-source-node="n76">Before</b>: Displays the comment before the associated work instruction.</p>
                    </li>
                    <li data-source-node="n77">
                        <p data-source-node="n78"><b data-source-node="n79">After</b>: Displays the comment after the work instruction is completed.</p>
                    </li>
                </ul>
            </li>
        </ul>
