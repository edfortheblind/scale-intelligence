
        
        <h1 data-source-node="n56"><a name="kanchor792" data-source-node="n57"></a>Availability Checking Checkbox</h1>
        <p data-source-node="n58">This setting indicates that you want the system to verify 
 if the warehouse contains enough quantity to satisfy a new shipment/order's 
 demand. The system performs this validation when an order is created via 
 order entry, or a new shipment line is entered. The system will alert 
 the user if enough inventory does not exist to meet this demand.</p>
