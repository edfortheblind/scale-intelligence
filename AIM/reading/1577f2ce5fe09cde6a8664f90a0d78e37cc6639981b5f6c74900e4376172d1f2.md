
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n56"><span style="font-size: 18pt" data-source-node="n57">Work Order Preference Configuration</span>
        </h1>
        <h4 data-source-node="n58">Overview</h4>
        <p data-source-node="n59">A work order preference record allows you to manage how a user or group of users will process work orders. The default record should accommodate the majority of employees. However, you can create specific preference records for employees with unique processing needs.</p>
        <p data-source-node="n60"> </p>
        <h4 data-source-node="n61">General Information</h4>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">Enter Preference Name and Description</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65">Default Build Location</p>
        <ul data-source-node="n66">
            <li data-source-node="n67">
                <p data-source-node="n68">Select the Default Build Location Field to identify where the employee typically creates work units. This value is displayed on the Work Order Window; the user can override this value. It is also printed on the Work Order Component Pick List to identify where components should be delivered for processing. On the Work Order Finished Item Putaway List, this value identifies the from location for the finished items.</p>
            </li>
        </ul>
        <p data-source-node="n69">Default Storage Location</p>
        <ul data-source-node="n70">
            <li data-source-node="n71">
                <p data-source-node="n72">Select the Default Storage Location Field to identify the inventory location where the finished item should be located. The system will default this location on the Work Order Confirmation Window, but the user can select a different confirm location. It is also printed on the Work Order Finished Item Putaway List to identify where finished items should be putaway.</p>
            </li>
        </ul>
        <p data-source-node="n73">Default Inventory Status</p>
        <ul data-source-node="n74">
            <li data-source-node="n75">
                <p data-source-node="n76">Select the Default Inventory Status Field to define the status finished items are assigned when they're confirmed. Generally, you should select an "available" status if you want to allocate the product.</p>
            </li>
        </ul>
        <p data-source-node="n77"> </p>
        <h4 data-source-node="n78">Processing</h4>
        <p data-source-node="n79"> </p>
        <p data-source-node="n80">Create Work</p>
        <p data-source-node="n81">Use the Create Work Checkbox if you want the system to generate work instructions for the allocated components and confirmed finished items.</p>
        <ul data-source-node="n82">
            <li data-source-node="n83">
                <p data-source-node="n84">If you select this checkbox, the system will call work creation as soon as the component is allocated or the finished item is confirmed.</p>
            </li>
        </ul>
        <ul data-source-node="n85">
            <li data-source-node="n86">
                <p data-source-node="n87">If you do not select this checkbox, the system will not create work for either allocated components or confirmed finished items. Instead, it will automatically locate the quantity (either component or finished item) and put its quantity as On Hand at the destination location(s). Someone will need to ensure that the product is physically delivered to that location(s).</p>
            </li>
        </ul>
        <p data-source-node="n88">Generate paperwork on release</p>
        <ul data-source-node="n89">
            <li data-source-node="n90">
                <p data-source-node="n91">Select the Generate Paperwork on Release option if you want the Work Order Component Pick List and/or the Work Order Assembly Instructions printed when the work order is released. You can also print these documents from the Work Order, as long as at least one component has been allocated. To print automatically, this process must be set to Default on the document type record.</p>
            </li>
        </ul>
        <p data-source-node="n92">Generate paperwork on confirm</p>
        <ul data-source-node="n93">
            <li data-source-node="n94">
                <p data-source-node="n95">Select the Generate Paperwork on Confirm option if you want the Work Order Finished Item Putaway List printed when the finished items are confirmed. You can also print this document from the Work Order, as long as at least one finished item has been confirmed. To print automatically, this process must be set to Default on the document type record.</p>
            </li>
        </ul>
        <p data-source-node="n96">Logistics unit assignment method</p>
        <p data-source-node="n97">Select the License Plate Assignment Method  Buttons to determine if the user will assign or verify license plate IDs. A license plate ID identifies a finished item, or group of finished items, for putaway.</p>
        <ul data-source-node="n98">
            <li data-source-node="n99">
                <p data-source-node="n100">System: If you select system, the user never assigns a license plate ID; the system always assigns it.</p>
            </li>
        </ul>
        <ul data-source-node="n101">
            <li data-source-node="n102">
                <p data-source-node="n103">Manual : If you select manual, the user will assign the license plate ID.</p>
            </li>
        </ul>
