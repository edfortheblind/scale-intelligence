
        
        <h1 data-source-node="n56"><a name="kanchor1475" data-source-node="n57"></a>Document Printer Field</h1>
        <h5 data-source-node="n58">On the Select Wave Printers Window...<a name="kanchor1476" data-source-node="n59"></a></h5>
        <p data-source-node="n60">This field indicates the printer that you want the system to use when printing wave paperwork that is classified as documents in the Document Type Window. Note that this field lists all of the print devices that are currently configured in the system.</p>
        <p data-source-node="n61"> </p>
        <p data-source-node="n62"> </p>
        <h5 data-source-node="n63">On the Reprint Wave Documents Window...</h5>
        <p data-source-node="n64">This field indicates the printer that you want the system to use for the reprint action. Note  that this field lists all print devices currently configured in the system.</p>
        <p data-source-node="n65"> </p>
        <p data-source-node="n66"> </p>
        <h5 data-source-node="n67">On the User Profile Default Printers Window...</h5>
        <p data-source-node="n68">This field indicates a list of all the document printers in the print device configuration.  The default printer on the user profile overrides document routing printer configured for the document type.  Selecting a printer when printing selected documents will override the default printer.  </p>
        <p data-source-node="n69">NOTE: Printing still requires a document routing record that matches the document routing criteria for the user submitting the print request.</p>
        <p data-source-node="n70"> </p>
