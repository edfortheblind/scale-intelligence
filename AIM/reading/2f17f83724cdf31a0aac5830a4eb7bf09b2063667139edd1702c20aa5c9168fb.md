
        
        <h1 data-source-node="n56"><a name="kanchor1490" data-source-node="n57"></a>Defining Viewer Icons</h1>
        <p data-source-node="n58">You can define the icons that appear 
 to the left of certain sets of records that display after a search query on the results grid 
of a SCALE viewer window. To add a custom icon to a viewer, add your graphic 
 file to the following directory: \\ILS\ResourceImages\. For example, suppose you want the system to display an icon next to all the data records for a specific carrier. You would then need to create a record in the Viewer Icon Editor that defines which icon the system should display with the record(s) associated with a specific carrier. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"> Important: Read the <a href="a2be91555d338145450001160e7b087ad9a5e585369ec12e988059d1d9bf481a.html" data-source-node="n61">Notes on Viewer Setup</a> before adding icons.</p>

        <h4 data-source-node="n95">Procedures...</h4>
        <p data-source-node="n96">Open your custom viewer record on the Viewers Window. Press the Fields 
 Button, and select the Icons Tab on the Customize Viewer Window. Open 
 an existing icon record, or right-click the list and select New Item. 
 The system will display the Viewer Icon Editor Window.</p>
        <ol class="ol_1" data-source-node="n97">
            <li value="1" data-source-node="n98">Use the Image 
 Resource Key Field to indicate the icon that will appear to the 
 left of certain records on the results grid. The system will use the rules 
 defined in this window to determine what records it will display this 
 icon for. If you do not assign any rules to this icon record, the system 
 will display this icon for all results row(s). </li>
        </ol>
        <p data-source-node="n99"> </p>
        <h4 data-source-node="n100">Establishing 
 Rules for Icons...</h4>
        <ol class="ol_1" data-source-node="n101">
            <li value="1" data-source-node="n102">You will use 
 the Field Name, Operand, and Value fields to define rules. Note 
 that you will only be able to choose fields that are a part of the database 
 table that the viewer is associated with.<br data-source-node="n103"><br data-source-node="n104">For example, suppose you have a viewer that displays shipment 
 records. You could assign a separate icon the system could use to display 
 for different carrier records. So, when the system displays results from 
 a query, shipments with different carriers are represented by different 
 icons.  <br data-source-node="n105"> </li>
            <li value="2" data-source-node="n106">Or 
 Checkbox: See the <a href="7efb2692896288886d6900f2a3f3f3ce8d6df6580dc8364bd8ba789132ee6e43.html" data-source-node="n107">field topic</a> for a description.<br data-source-node="n108"> </li>
            <li value="3" data-source-node="n109">You can then 
 create more rules, or press OK to save your icon record. </li>
        </ol>
