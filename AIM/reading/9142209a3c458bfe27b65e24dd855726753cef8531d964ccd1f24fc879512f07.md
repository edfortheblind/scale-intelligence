
        
        <h1 data-source-node="n56"><a name="kanchor1962" data-source-node="n57"></a>Configuring DIF File Protocol Properties</h1>
        <p data-source-node="n58">To setup the SCALE Device Integration Framework (DIF), you will need to address some configuration values in the application's database. The third step in this process is to configure the DIF protocol properties. A protocol property record contains the specific file transfer data that is used to define the properties of a DIF endpoint. Note that there is no configuration screen to define protocols in the SCALE Configurations Explorer. You will need to configure these values directly in the application database's FILE_PROTOCOL_PROPERTIES table.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">IMPORTANT: In order for changes to the FILE_PROTOCOL_PROPERTIES table to be reflected, you will need restart the DIF Processing Service. </p>

        <h4 data-source-node="n81">Procedures...</h4>
        <ol data-source-node="n82">
            <li value="1" data-source-node="n83">Access your application database using a database editing tool such as SQL Server Management Studio.<br data-source-node="n84"><br data-source-node="n85"></li>
            <li value="2" data-source-node="n86">Access the FILE_PROTOCOL_PROPERTIES database table. Each database row represents the properties of a separate DIF endpoint.<br data-source-node="n87"><br data-source-node="n88"></li>
            <li value="3" data-source-node="n89">Define values for the following database fields:<br data-source-node="n90"><br data-source-node="n91">Object_ID (numeric 9,0): Represents the unique protocol identifier. This is a required field.<br data-source-node="n92"><br data-source-node="n93">Endpoint_ID (numeric 9,0): Represents the endpoint tied to this protocol. This is a required field.<br data-source-node="n94"><br data-source-node="n95">From_Directory (alpha-numeric 255): Represents the file directory records are originally placed in to be processed.<br data-source-node="n96"><br data-source-node="n97">From_Ext (alpha-numeric 25): Represents the file extension the records must have to be eligible for processing.<br data-source-node="n98"><br data-source-node="n99">To_Directory (alpha-numeric 255): Represents the file directory records are placed into after processing.<br data-source-node="n100"><br data-source-node="n101">To_Ext (alpha-numeric 25): Represents the file extension the records are marked as after processing.<br data-source-node="n102"><br data-source-node="n103">Insert_Message (alpha 1): Represents whether or not a message will be inserted into the incoming DIF Message table. Supported values are Y or N.<br data-source-node="n104"><br data-source-node="n105">Sleep_Time (numeric 9,0): Represents the amount of time the system waits between processing records.<br data-source-node="n106"><br data-source-node="n107">USER_DEF1 - USER_DEF6 (alpha-numeric 25): Represents user identified values, similar to other places in the system.<br data-source-node="n108"><br data-source-node="n109">USER_DEF7 - USER_DEF8 (numeric 14,5): Represents user identified values, similar to other places in the system.<br data-source-node="n110"><br data-source-node="n111"></li>
            <li value="4" data-source-node="n112">When finished entering values, commit the changes to the database and exit your database editing tool.</li>
        </ol>
