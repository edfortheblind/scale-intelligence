Reviewing Weight Break

Use this window to identify what weight breaks are used by the rate base. This window establishes the maximum weight allowed when defining weight breaks on the Rate Base configuration. The SCALE system is shipped with a default weight break configuration record. The last detail record must contain the maximum value that is allowed in the 'Maximum Weight' field. For example, 999999999999999.9999.
