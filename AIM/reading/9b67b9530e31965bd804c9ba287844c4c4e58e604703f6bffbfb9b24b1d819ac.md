        <h4 data-source-node="n134"><a name="displayNotes" data-source-node="n135"></a>Reference Messages...</h4>
        <p width="100%" style="font-style: normal" data-source-node="n136">The system displays one or more of the following reference messages, depending on the condition of the container that you are currently packing. These messages appear in the Status Info accordion of the Packing Screen.</p>
        <ul data-source-node="n137">
            <li width="100%" data-source-node="n138">Not Completely Picked: This message indicates that there are line(s) on this shipment that have yet to be picked. Any line(s) that have not been picked cannot be packed.<br data-source-node="n139"><br data-source-node="n140"></li>
            <li width="100%" data-source-node="n141">Completely Picked: This message indicates that all line(s) for this shipment have been picked, and are available to be packed.<br data-source-node="n142"><br data-source-node="n143"></li>
            <li width="100%" data-source-node="n144">VAS Required: This message indicates that the container you are packing into requires value added services.<br data-source-node="n145"><br data-source-node="n146"></li>
            <li width="100%" data-source-node="n147">QC Required: This message indicates that the container you are packing into requires QC.<br data-source-node="n148"><br data-source-node="n149"></li>
            <li width="100%" data-source-node="n150">Awaiting Immediate Needs: This message indicates that the shipment has been completely 
 picked, but has immediate needs pending. </li>
        </ul>

        <h4 data-source-node="n155"><a name="PackingDCinsight" data-source-node="n156"></a>Packing 
 a Container...</h4>
        <ol data-source-node="n157">
            <li value="1" data-source-node="n158">Access the Packing 
 Screen. 
 <br data-source-node="n159"></li>
            <p data-source-node="n160"> </p>
            <li value="2" data-source-node="n161">Identify the 
 shipment in the Shipment ID field. Note that the default value for this field is the shipment number. You 
 can configure the system to prompt for a different field when initiating a packing 
 action using the "Initiation Field" setting on the Packing Preferences configuration.<br data-source-node="n162"></li>
            <p data-source-node="n163"> </p>
            <li value="3" data-source-node="n164">Select 
 a value in the Team field to indicate that you want to sign onto a packing team. If you are associated with a work team, the 
 system will track your activity on the Labor Activity Insight Screen. Note that this field is optional.<br data-source-node="n165"><br data-source-node="n166"></li>
            <li value="4" data-source-node="n167">Press the initiation (arrow) button. 
  The Packing Screen will then display all of the open lines for the initiated entity (e.g., a shipment). Note that if you enter an initiation criteria that does not have any items left to pack, the system will display an error message indicating that there are no lines available to pack.<br data-source-node="n168"> </li>
            <li value="5" data-source-node="n169">Use the Container ID Field to select a container ID to assign to this package: <br data-source-node="n170"><br data-source-node="n171">- <i data-source-node="n172">Use an Existing Container</i>: By pressing the Existing container button, you can pack items into an existing container. The system will populate the drop-down field with all the container(s) that are associated with this entity. If you have not yet packed any containers for this entity, the system will not display any container IDs in this field. <br data-source-node="n173"><br data-source-node="n174">- <i data-source-node="n175">Use a New Container</i>: By pressing the New container button, you can pack items into a new container. The container will become a free-entry field where you can indicate the new container ID (if container assignment is defined as manual in your packing preferences). Note that if you are using system container assignment, the system will disable this field and contain a value that says "System created".<br data-source-node="n176"><br data-source-node="n177"></li>
            <li value="6" data-source-node="n178">Use the Container Type Field 
 to identify what type of container you are packing into. If you assigned 
 an existing container ID, you cannot change this value since the container type 
 has previously been defined. The container types available for packing can be authorized by company and warehouse. See the <a href="b8520236e77bf1d9729a56d56a398123183351403f9a3eff7e86595795483b9e.html" data-source-node="n179">Defining Container Types</a> for more details.<br data-source-node="n180"><br data-source-node="n181"></li>
            <li value="7" data-source-node="n182">Next, identify the 
 item that you want to pack:</li>
            <ul type="disc" class="ul_1" data-source-node="n183">
                <p data-source-node="n184"> </p>
                <li data-source-node="n185">
                    <p data-source-node="n186">If item validation is active (via packing preferences), you will need to scan/enter the 
 item/item cross reference that you want to pack. </p>
                    <p data-source-node="n187"> </p>
                </li>
                <li data-source-node="n188">If item validation is not active (via packing preferences), you can select a grid row of the item you want to pack. The system will then auto-populate the ID into the Item field.</li>
            </ul>
            <p data-source-node="n189"> </p>
            <p data-source-node="n190">Packing Instructions - On selecting an item,</p>
            <ul data-source-node="n191">
                <li data-source-node="n192">
                    <p data-source-node="n193"> if packing instructions are defined at shipment header level, then it will be displayed in the Packing Instruction accordion.</p>
                </li>
                <li data-source-node="n194">
                    <p data-source-node="n195">If packing instruction are defined at shipment line level, then a pop-up notification will be displayed.</p>
                </li>
            </ul>
            <p data-source-node="n196">
                <br data-source-node="n197">
            </p>
            <li value="8" data-source-node="n198">Enter the quantity you want to pack using the plus and minus buttons on the quantity ticker. You may also enter the number value directly into the quantity text box. Note that if item verify is off, the system defaults the total packed quantity into the quantity ticker when you select an item's grid row. <br data-source-node="n199"></li>
            <p data-source-node="n200"> </p>
            <li value="9" data-source-node="n201">
                <p data-source-node="n202">Select the Pack Button. 
 The system will pack the shipment line into the container. If you have packed the full quantity of the line into the container, then the item's grid row will disappear from the grid. The system will also update the Total Quantity and Total Weight values in the Container Summary accordion. <br data-source-node="n203"><br data-source-node="n204">Note that you could also press the Pack All Button, which would pack ALL of the remaining item quantities into the container. Also, packing will prompt for serial number entry when the item has been set up to track serial numbers in the outbound or inventory flows.</p>
                <p data-source-node="n205"> </p>
                <p data-source-node="n206">Note: You will need to provide catch weight for catch weight-tracked items.</p>
                <p data-source-node="n207">
                    <br data-source-node="n208">
                </p>
            </li>
            <p data-source-node="n209"> </p>
            <li value="10" data-source-node="n210">When you pack an item and item validation mode is on, the system will display the following in the "Last Item Packed" section on the right pane of the screen: the item's ID, description, quantity packed. <br data-source-node="n211"><br data-source-node="n212"></li>
            <li value="11" data-source-node="n213">You can now pack additional items into this existing container, or into a brand new container. Or, you could close the container by pressing the Close button (the system will display the Close Container Screen loaded with the container that you just packed).
  </li>
        </ol>
        <p data-source-node="n214"> </p>
        <h5 data-source-node="n215">Packing Error Note:</h5>
        <p data-source-node="n216">- If the system encounters an error when packing an item, the system will display a checkbox in the "Error" grid column. You can then press the row's checkbox to view the specific error that occurred.</p>

        <h4 data-source-node="n222"><a name="Overpacking" data-source-node="n223"></a>Overpacking a Container...</h4>
        <p class="p_14" data-source-node="n224">When you pack a container in the system, you 
 typically cannot pack an amount that is greater than the quantity available 
 on the shipment line. However, the system does allow overpacking if your packing preferences are defined accordingly.</p>
        <ol data-source-node="n225">
            <li value="1" data-source-node="n226">
                <p data-source-node="n227">Indicate the quantity of the item you want to over pack.<br data-source-node="n228"><br data-source-node="n229"></p>
            </li>
            <li value="2" data-source-node="n230">
                <p data-source-node="n231">Select the Pack Action. The system 
 will then display the Over Packing Verification Screen.</p>
                <p data-source-node="n232"> </p>
            </li>
            <li value="3" data-source-node="n233">Use the Reason 
 Code Field to enter an explanation for the overpacking action.<br data-source-node="n234"><br data-source-node="n235"></li>
            <li value="4" data-source-node="n236">Press Save when 
 finished. The system will pack the item into the container.</li>
        </ol>
