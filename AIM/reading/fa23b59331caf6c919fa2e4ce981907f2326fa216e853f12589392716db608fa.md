
        
        <h1 data-source-node="n56"><a name="kanchor988" data-source-node="n57"></a>Vendor Compliant Label</h1>
        <p data-source-node="n58">A vendor compliant label is a container identification label that is 
 compliant with the ship to's specifications. If you want to include a UCC-128 barcode on the label, see <a href="6ef0a948ccfdfa8010ca699f397154c15983ded4d8123d43cc6afacb5debefb0.html" data-source-node="n59">UCC 
 Code Field</a> to review where the system retrieves its values from. Vendor compliant labels must be printed on a specific type of thermal 
 printer, such as a Zebra. They must also be written in a programming language 
 acceptable to the specified printer. </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">General Notes</h5>
        <p data-source-node="n63">- If you would like to 
 print both a container contents label       and 
 a vendor compliant label from the wave, see the topic Container Contents 
 &amp; Vendor Labels.</p>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65"> </p>
        <h5 data-source-node="n66">Technical Notes</h5>
        <p data-source-node="n67">- Printers producing vendor compliant labels must be  accessible through a network share. Please refer to the Printer Configuration  Guide for more information. </p>
        <p data-source-node="n68"> </p>
        <p data-source-node="n69">- Also, make sure that the printer 
 used by the application server    and 
 hosted on the application server are shared with the same name as they 
 were created as. For example, if your printer's name is "VCL1", 
 you must share it as "VCL1".</p>
