
        
        <h1 data-source-node="n56"><a name="kanchor1999" data-source-node="n57"></a>Using the Work Monitoring: Customer Screen</h1>
        <p data-source-node="n58">You can use the Work Monitoring: Customer screen to research and manage employee workloads in your warehouse.  It is accessible from the SCALE Desktop menu, as well as a tablet device. This allows you to be able to interact with the system from literally anywhere. The system uses a configurable framework called metadata to display this screen's components, which allows you the ability to customize certain parts on the screen. </p>
        <p data-source-node="n59"> </p>

        <h4 data-source-node="n102"> <a name="NavigatingChart" data-source-node="n103"></a>Navigating the Work Monitoring: Customer Chart</h4>
        <p data-source-node="n104"> </p>
        <ol data-source-node="n105">
            <li value="1" data-source-node="n106">Open the Work Monitoring: Customer screen.<br data-source-node="n107"><br data-source-node="n108"></li>
            <li value="2" data-source-node="n109">The system will display the monitoring screen, with the chart on the first (highest) level, <i data-source-node="n110">customer category 1</i>.<br data-source-node="n111"><br data-source-node="n112"></li>
            <li value="3" data-source-node="n113">Next, click/tap on a customer category 1 data column, and the system will then display the next level of the chart, <i data-source-node="n114">customer name</i>.<br data-source-node="n115"><br data-source-node="n116"></li>
            <li value="4" data-source-node="n117">Next, click/tap on a customer name data column, and the system will then display the next level of the chart, <i data-source-node="n118">ship to name</i>.<br data-source-node="n119"><br data-source-node="n120"></li>
            <li value="5" data-source-node="n121">Next, click/tap on a ship to name data column, and the system will then display the next level of the chart, <i data-source-node="n122">work group</i><br data-source-node="n123"><br data-source-node="n124"></li>
            <li value="6" data-source-node="n125">Again, click/tap on a work group data column, and the system will then display the final level of the chart, <i data-source-node="n126">work type</i>.<br data-source-node="n127"><br data-source-node="n128"></li>
            <li value="7" data-source-node="n129">Finally, when you click on a work type data column, the system will open the Work Insight screen (in a separate browser window), with all the record(s) that meet the criteria you have chosen on the chart displayed on the insight's data grid.</li>
        </ol>
