
        
        <h1 data-source-node="n56"><a name="kanchor1451" data-source-node="n57"></a>Work Criteria Field</h1>
        <p data-source-node="n58">This 
 field associates a work criteria record with a work creation master record. 
 A work criteria record determines how work will be generated and processed 
 for an entity. It 
 will also define the header and summary levels for a work instruction 
 record.</p>
