        <h4 data-source-node="n123"><a name="Searching" data-source-node="n124"></a>Searching/Viewing Work Records...</h4>
        <p data-source-node="n125">You can use the Tote Insight Screen to search for and view work records in your warehouse. </p>
        <ol data-source-node="n126">
            <li value="1" data-source-node="n127">Open the Tote Insight Screen.<br data-source-node="n128"><br data-source-node="n129"></li>
            <li value="2" data-source-node="n130">Use the Basic Criteria Fields (located on the Filter Pane) to indicate the values for your primary search.<br data-source-node="n131"><br data-source-node="n132"></li>
            <li value="3" data-source-node="n133">Press the Apply Filter Button. The system will display the resulting records in the List Pane. <br data-source-node="n134"><br data-source-node="n135"></li>
            <li value="4" data-source-node="n136">If you select one of the result records from the List Pane, then the system will display its information in the Detail Pane.</li>
        </ol>

        <h4 data-source-node="n162"><a name="ScreenActions" data-source-node="n163"></a>Screen Actions...</h4>
        <p data-source-node="n164">The following actions are accessible from the List Pane:</p>
        <p data-source-node="n165"> </p>
        <h5 data-source-node="n166">Unassign</h5>
        <p data-source-node="n167">This action allows you to unassign the user from the selected tote. The system will remove the assigned user from the tote. </p>
        <p data-source-node="n168"> </p>
        <p data-source-node="n169"><b data-source-node="n170">Procedure</b>
        </p>
        <ul data-source-node="n171">
            <li data-source-node="n172">Navigate to the Putwall Insight screen</li>
            <li data-source-node="n173">Select a tote record and <b data-source-node="n174">Actions</b> &gt;&gt; <b data-source-node="n175">Unassign</b>.</li>
            <li data-source-node="n176">System will prompt user with confirmation message. Click <b data-source-node="n177">Yes</b>.</li>
            <li data-source-node="n178">A successful message indicating the user has been unassigned form the tote is displayed.</li>
        </ul>
