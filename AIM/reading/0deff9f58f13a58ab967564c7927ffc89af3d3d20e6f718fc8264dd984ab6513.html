Parent Container / Parent Container ID Field

On the Shipping Container Insight Screen...

The Parent field is an internal number that can be filled on item contents or parent containers that are nested onto another parent. A parent container or full unit of measure container (e.g., full case or full pallet) will be devoid of parent unless it is nested onto another parent. Items packed into a container will have a parent. On the Shipping Container Insight Screen, by default, you will only see parent containers. You have to turn ON the Show container contents toggle to see the items packed into the container.

 

 

On the Receipt Workbench...

This field represents a parent receipt container. Using this field, you can enter a new parent container to nest children into, or select an existing parent container (if any receipt containers have been created for this receipt).
