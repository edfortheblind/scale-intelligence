
        
        <h1 data-source-node="n56"><a name="kanchor462" data-source-node="n57"></a>Instruction Type Field</h1>
        <p data-source-node="n58">This field identifies a type of work instruction. Instruction types are generated during work 
 creation. </p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">The system supports 
 the following instruction types:</p>
        <blockquote data-source-node="n61">
            <p data-source-node="n62"><i data-source-node="n63">Header</i> - The header level represents 
 the work unit. It groups detail lines together for processing. It is defined 
 on the Work Criteria Window by selecting the Work Unit Checkbox.</p>
            <p data-source-node="n64"> </p>
            <p class="p_1" data-source-node="n65"><i data-source-node="n66">Detail</i> 
 - The detail level represents a single work instruction.</p>
        </blockquote>
