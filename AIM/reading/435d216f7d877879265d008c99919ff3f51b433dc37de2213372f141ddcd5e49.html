Labor

Labor records are used to define and manage parameters specific to a warehouse. These settings help accurately record and monitor worker shifts within the designated warehouse environment.

 

Configuration Navigation

 

Required Setup >> Warehouse >> Labor section.

 

  • Threshold Throughput % - Represents the minimum acceptable throughput % for employees.

  • Threshold Throughput (handling Units/Hour)- Specifies the minimum acceptable throughput for employees.

  • Threshold Utilization- Represents the minimum acceptable Utilization % for employees.

  • Upcoming Shift Assignment Window (In minutes) - A defined time period before a shift starts during which an arriving user is assigned to that upcoming shift instead of the current one.
