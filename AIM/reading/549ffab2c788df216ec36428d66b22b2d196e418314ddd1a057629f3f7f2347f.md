
        
        <h1 data-source-node="n56"><a name="kanchor1872" data-source-node="n57"></a>Parent Screen Field</h1>
        <p data-source-node="n58">This field indicates the current screen's parent. For example, in the 
 Web Screen Data Window, the InventoryStatusResults screen's parent is 
 the InventoryStatusInquiry screen. If a screen does not have a parent, 
 this field will not have a value.</p>
