Pattern Field

On the Serial Number Template Window...

This field displays the code that represents the segments that are defined for a serial number template. The system uses this string to "compute" a serial number according to the parameters in a template.

 

 

On the Lot Template Window...

This field allows you to define the date format string if you want the system to auto-fill the date field.

 

If you select the Custom button, you can enter in your own date format string, The following date formats are pre-defined:

  • MMddyyyy (two-digit month, two-digit day, four-digit year)

  • ddMMyyyy (two-digit day, two-digit month, four-digit year)

  • yyyyMMdd (four-digit year, two-digit month, two-digit day)

 

Also, there are a number of additional valid characters that are supported to create date format strings. See the Microsoft website linked below for more information:
