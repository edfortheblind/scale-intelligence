
        
        <h1 data-source-node="n56"><a name="kanchor850" data-source-node="n57"></a>Show all LPs and Attributes Toggle</h1>
        <p data-source-node="n58">You would use this toggle to indicate that you want the system to display all the license plates (whether parent or child) that are associated with a location as separate result records. Also, if selected, the system will display any instances of inventory that have attributes associated with them as separate result records.</p>
