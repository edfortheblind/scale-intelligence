
        
        <h1 data-source-node="n56"><a name="kanchor1996" data-source-node="n57"></a>Identifying NMFC Codes</h1>
        <p data-source-node="n58">An NMFC Code 
 identifies LTL 
 class for product and determines the description on the BOL. 
 You will need to define the NMFC 
 Codes associated with all product in your warehouse. If items with different 
 NMFC codes 
 are packed in the same container, the system will display the code with 
 the highest class in the carrier information section of the Bill of Lading. 
 Note that you should be sure to complete this procedure if you ship using 
 LTL carriers.</p>

        <h4 data-source-node="n91">Procedures...</h4>
        <ol data-source-node="n92">
            <li value="1" data-source-node="n93">Access the National 
 Motor Freight Classifications Window. Select the New Action. Name 
 the record, and provide a description.<br data-source-node="n94"><br data-source-node="n95"></li>
            <li value="2" data-source-node="n96">Define the LTL 
 Class associated with the NMFC 
 Code. The system will use 
 this field during carrier rating for LTL 
 carriers.<br data-source-node="n97"><br data-source-node="n98"></li>
            <li value="3" data-source-node="n99">Use 
 the Hazardous Code Field to 
 identify an item that uses this particular NMFC Code as being 
 a hazardous material. The system will display this code on a shipment's 
 bill of lading document (in the "H.M." field).<br data-source-node="n100"><br data-source-node="n101"></li>
            <li value="4" data-source-node="n102">Press OK. 
 The system will add the record.</li>
        </ol>
