Decimal Position Field / Decimal Positions Field

On the System Text Editor Detail Window...

This field indicates the location of a decimal point in a field value. You can only modify the decimal position of a custom text value; you cannot edit a base text value.

 

 

On the Customize Viewer Window...

This field represents how the system will display decimal positions for field values on your viewer's results tab. You can select from value categories that are defined on the Decimal Positions Window.

 

On Warehouse Dashboard

The decimal position on the warehouse dashboard is configured using the Dashboard record from the Decimal Positions configuration.

 

Note About Keeping 14 Digits To the Left of the Decimal...

Below are the settings that are allowed for numeric fields in the System Text Editor if you want to keep 14 digits to the left of the decimal. This is applicable for any numeric fields throughout the system which have a maximum field length of 19,5:

 

[field length, decimal position]

  1. 14,0
  2. 15,1
  3. 16,2
  4. 17,3
  5. 18,4
  6. 19,5

Note that anything having more than 14 digits to the left of the decimal would be an invalid setting.
