
        
        <h1 data-source-node="n56"><a name="kanchor479" data-source-node="n57"></a>Lot Verification Required Checkbox (Outbound QC)</h1>
        <h5 data-source-node="n58">Outbound QC Inspection...</h5>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60"><i data-source-node="n61">**This value is not used for RF Shipping Container QC**</i>
        </p>
        <p data-source-node="n62"> </p>
        <p data-source-node="n63">This checkbox determines if the user will need to enter a lot value for lot-controlled items when performing inspection on a container, and how the lot field will appear on the inspection grid. </p>
        <blockquote data-source-node="n64">
            <p data-source-node="n65">- <i data-source-node="n66">If this checkbox is selected</i>, the lot field will appear in the “scan item fields”, there will be a lot column in the inspection grid, and the inspection grid will display a separate grid row for each item/lot combination. <br data-source-node="n67"><br data-source-node="n68">- <i data-source-node="n69">If this checkbox is not selected</i>, the lot field will not appear in the “scan item fields”, there will not be a lot column in the inspection grid, and the inspection grid will summarize all of an item's lot instances into a single grid row.</p>
        </blockquote>
        <p data-source-node="n70">NOTE: It is recommended that you not turn off lot verification on a user's preferences while the user is currently performing QC inspection on containers. If this is done, the system might not  have any information about which lot(s) failed QC, so therefore the grid would not be able to accurately display to the user the correct failed quantity against the right item/lot combination.</p>
