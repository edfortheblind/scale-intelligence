
        
        <h1 data-source-node="n56"><a name="kanchor1447" data-source-node="n57"></a>Using Gadgets</h1>
        <p data-source-node="n58">In general, gadgets are defined as small specialized applications that are designed to do simple tasks (such as clocks, calendars, RSS readers, or search tools). On the SCALE Desktop, gadgets also allow you to run small pieces of functionality, whether it originates from SCALE or an external application. You can have any number of gadgets displaying at any time on the Desktop. When you exit and re-enter the application, the gadgets will be in the same position and be the same size as they were when you exited the application.</p>
        <p data-source-node="n59"> </p>
        <p data-source-node="n60">There are two types of gadgets, Single User Gadgets and Global Gadgets. Note that gadgets are sorted by type in the gadget library window.</p>
        <ul data-source-node="n61">
            <li data-source-node="n62">Single User Gadgets: When you create a single user gadget on your Desktop, they are not viewable by any user other than yourself. Note that gadgets are created by default as single user gadgets. Single user gadgets are listed under the "My Gadgets" section of the gadget library.<br data-source-node="n63"><br data-source-node="n64"></li>
            <li data-source-node="n65">Global Gadgets: These gadgets can be viewed by more than one user (i.e. all users, a subset of users, or a security group). Global gadgets are listed under the "Global Gadgets" section of the gadget library.</li>
        </ul>

        <h5 data-source-node="n177">Creating a Global Gadget</h5>
        <p data-source-node="n178"> </p>
        <p data-source-node="n179">1. After <a href="#addingGadgets" data-source-node="n180">adding a gadget</a> to the desktop, you can choose to designate it as a global gadget.</p>
        <p data-source-node="n181"> </p>
        <p data-source-node="n182">2. Open the <a href="#gadgetConfigSettings" data-source-node="n183">settings</a> window of your gadget.</p>
        <p data-source-node="n184"> </p>
        <p data-source-node="n185">
            <img loading="eager" data-source-node="n186">
        </p>
        <p data-source-node="n187"> </p>
        <p data-source-node="n188"> </p>
        <p data-source-node="n189">3. Select the Global Gadget Checkbox to indicate that you want users other than yourself to have access to this gadget. </p>
        <p data-source-node="n190"> </p>
        <p data-source-node="n191">
            <img loading="eager" data-source-node="n192">
        </p>

        <p data-source-node="n194"> </p>
        <p data-source-node="n195">4. Press the Apply Button. The system will designate this gadget a global gadget, and the Configure Security Permissions link will activate.</p>

Select the Configure Security Permissions link to grant permission to the user(s) that you want to grant access to this gadget (all users, a subset of users, or a security group). The system will open the <a href="7455e0507949c7f8485e8beb4cca47f7576e8f57283c073b96738a810f6a52f7.html" data-source-node="n198">Security Permissions Window</a>.</p>

        <h5 data-source-node="n207">Global and Local Gadgets With the Same Name</h5>
        <p style="color: #000000" data-source-node="n208">There is a scenario where a user can have a single user gadget and global gadget that have the same name. In this scenario, if the user wished to make their single user gadget a global gadget, they would have to rename it. The scenario is the following: Suppose you create a single user gadget called My Gadget. Also, suppose another user creates a single user gadget with the same name (My Gadget). Then, if the first user decides to make their gadget a global gadget, the system allows this. The second user now has a global gadget and a single user gadget with the same name. When the second user attempts to make their single user gadget a global gadget, the system gives them an error indicating the name must be unique.</p>

        <h4 data-source-node="n217">Gadget Security...</h4>
        <p data-source-node="n218"> When you create a gadget, the system creates the a security permissions record for this gadget. This allows you to manage the security for users/groups in the same way as other SCALE windows. You can choose to add security records for users/groups at the time of global gadget creation, or at a later time. In addition, a user with the proper security authority can change a gadget from being a global gadget to a single user gadget (or vice versa).  When you do this, the system will remove/add the proper security records so that the various Desktops this change affects can manage this change.  Also note that if a user has permission to access a global gadget, but that permission is taken away, the next time they open SCALE, the system will not display that gadget.</p>
        <p data-source-node="n219"> </p>
        <p data-source-node="n220"> </p>
        <p data-source-node="n221">Below are descriptions of the available gadget security checkpoints:</p>
        <ul data-source-node="n222">
            <li data-source-node="n223">Add Gadget to Desktop: Determines if you can add a gadget to the Desktop from the gadget library. <br data-source-node="n224"><br data-source-node="n225"></li>
            <li data-source-node="n226">Add New Gadget: Determines if you can add a gadget into the gadget library.<br data-source-node="n227"><br data-source-node="n228"></li>
            <li data-source-node="n229">Administer Gadget Settings: Determines if you can access the Gadget Settings screen.<br data-source-node="n230"><br data-source-node="n231"></li>
            <li data-source-node="n232">Administer Global Gadgets: This setting determines the following:<br data-source-node="n233"><br data-source-node="n234">- Whether you can make a single user gadget into a global gadget.<br data-source-node="n235"><br data-source-node="n236">- Whether you can configure settings on global gadgets.<br data-source-node="n237"><br data-source-node="n238">- Whether you can uninstall global gadgets.<br data-source-node="n239"><br data-source-node="n240">- Whether you can copy global gadgets (if you do not have this security, then you can copy a global gadget, but it will become a single user gadget).<br data-source-node="n241"><br data-source-node="n242"></li>
            <li data-source-node="n243">Copy Gadget: Determines if you can copy a gadget, whether it is a single user or global gadget.<br data-source-node="n244"><br data-source-node="n245"></li>
            <li data-source-node="n246">Remove Gadget from Desktop: Determines if you can close a gadget that is being displayed on the Desktop.<br data-source-node="n247"><br data-source-node="n248"></li>
            <li data-source-node="n249">Uninstall Gadget: Determines if you can remove a gadget from the gadget library.</li>
        </ul>

        <h4 data-source-node="n416"><a name="copyingGadget" data-source-node="n417"></a>Copying Gadgets...</h4>
        <p data-source-node="n418">You can copy an existing gadget and save a new version of this gadget with a different name. Note that you need to have the appropriate <a href="#gadgetSecurity" data-source-node="n419">security permissions</a> in order to perform this action. </p>
        <p data-source-node="n420"> </p>
        <p data-source-node="n421"> </p>
        <p data-source-node="n422">The following steps describe how to copy a gadget:</p>
        <p data-source-node="n423"> </p>
        <p data-source-node="n424">1. Open the Desktop Gadget - Library Window.</p>
        <p data-source-node="n425"> </p>
        <p data-source-node="n426">2. Right-click the gadget you want to copy, and select the Copy action:</p>
        <p data-source-node="n427"> </p>
        <p data-source-node="n428">
            <img loading="eager" data-source-node="n429">
        </p>
        <p data-source-node="n430"> </p>
        <p data-source-node="n431"> </p>
        <p style="font-weight: normal" data-source-node="n432">3. The system will open the Desktop Gadget - Copy window: </p>
        <p data-source-node="n433"> </p>
        <p data-source-node="n434">
            <img loading="eager" data-source-node="n435">
        </p>
        <p data-source-node="n436"> </p>
        <p data-source-node="n437"> </p>
        <p style="font-weight: normal" data-source-node="n438">4. Enter a new name for this gadget, and press OK. This name must be unique among gadgets.</p>
        <p data-source-node="n439"> </p>
        <p style="font-weight: normal" data-source-node="n440">5. The system will save your new gadget, and display it in the Desktop Gadget - Library. You can now add this gadget to the Desktop and configure its settings.</p>

        <h4 data-source-node="n447"><a name="removingGadgets" data-source-node="n448"></a>Removing Gadgets from the Desktop...</h4>
        <p data-source-node="n449">When you press the "X" button on a gadget's Toolbar, the system will remove the gadget from the Desktop. Note that this gadget will still remain present in the library, so you can add it again to the Desktop later if you choose. Note that there is a security checkpoint that governs whether or not a user will be able to remove gadgets from the Desktop.</p>

        <h4 data-source-node="n458"><a name="uninstallingGadgets" data-source-node="n459"></a>Uninstalling Gadgets...</h4>
        <p data-source-node="n460">This option allows the user to remove a gadget from being listed in the gadget library. This will prevent users from viewing this gadget on the Desktop, unless it is first reloaded into the library. There is a security checkpoint that governs whether or not a user will be able to uninstall gadgets from the library. Note that if a global gadget is uninstalled, then that gadget will not be available to any users the next time that they log into the application.</p>
        <p data-source-node="n461"> </p>
        <p data-source-node="n462">1. Access the Desktop's gadget library.</p>
        <p data-source-node="n463"> </p>
        <p data-source-node="n464">2. Right-click the gadget that you want to remove and choose the Uninstall option:</p>
        <p data-source-node="n465"> </p>
        <p data-source-node="n466">
            <img loading="eager" data-source-node="n467">
        </p>
        <p data-source-node="n468"> </p>
        <p data-source-node="n469"> </p>
        <p data-source-node="n470">3. The system will remove the listing from the gadget library, as well as the gadget itself from the Desktop (if the gadget was currently being displayed there).</p>
        <p data-source-node="n471"> </p>

            <h5 data-source-node="n481"><a name="counterGadget" data-source-node="n482"></a>COUNTER GADGET</h5>
            <p data-source-node="n483">This gadget identifies the number of records that have met specific data criteria. For example, you might want to define this gadget to identify how many shipments have been confirmed. The counter number would then tick upwards by one digit each time a shipment is confirmed (see the example below). Note that the data displayed by the Counter gadget is defined using either a custom SQL statement or stored procedure. This query/stored procedure should return a single count value that will be bound to the gadget.</p>

            <h5 data-source-node="n498"><a name="feedGadget" data-source-node="n499"></a>FEED GADGET</h5>

When the gadget is displayed on the Desktop, it will display headlines from the RSS feed that was configured. Note that feeds that require a username/password (other than your Windows login) are not supported with this gadget.</p>

            <h5 data-source-node="n506"><a name="gaugeGadget" data-source-node="n507"></a>GAUGE GADGET</h5>
            <p data-source-node="n508">This gadget communicates the percent of records that have met a specific data criteria. For example, you could use a gauge gadget to show the percentage of today’s shipments that have been ship confirmed; or, the percent of permanent locations that are currently empty.
 Gauge data is defined  using either a custom SQL statement or stored procedure, and the gauge will provide reliable percents based on the data returned from the database.  This query/stored procedure should return a single percentage value that will be bound to the gadget.</p>

            <h5 data-source-node="n514"><a name="warehouseAlertsGadget" data-source-node="n515"></a>WAREHOUSE ALERTS GADGET</h5>
            <p data-source-node="n516">This gadget displays alert(s) that meet the data criteria of a warehouse alert record. A warehouse alert is an immediate update or warning on a situation the warehouse manager needs to address. The alert gadget can display this information directly on the Desktop.
 You can also export the grid data to an Excel spreadsheet by pressing the Excel button on the gadget's toolbar.
 Note that this gadget only includes those alerts that are defined to generate history. Therefore, alerts that only generate emails cannot be displayed using this gadget.
