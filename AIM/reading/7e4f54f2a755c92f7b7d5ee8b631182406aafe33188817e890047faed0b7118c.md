
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57"><span style="font-size: 18pt" data-source-node="n58">Item Location Assignment</span>
        </h1>
        <h4 data-source-node="n59">Overview</h4>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61">The Item Location Assignment process allows you to assign items to specific locations within a warehouse. This is a single-step configuration where you enter the necessary item and location information.</p>
        <p data-source-node="n62"> </p>
        <h4 data-source-node="n63">Enter Item and Location Information</h4>
        <p data-source-node="n64"> </p>
        <p data-source-node="n65">Complete the following fields to assign an item to a location:</p>
        <p data-source-node="n66"> </p>
        <p data-source-node="n67"><strong data-source-node="n68">Item</strong> – Enter the item number or code. This field is required. The system will validate that the item exists in the system.</p>
        <p data-source-node="n69"><strong data-source-node="n70">Company</strong> – Select the company associated with this item location assignment. This field is typically pre-populated based on your user context.</p>
        <p data-source-node="n71"><strong data-source-node="n72">Permanent Location</strong> – Enter the permanent storage location code for the item. This field is required. This location code should match a valid location defined in your warehouse configuration.</p>
        <p data-source-node="n73"><strong data-source-node="n74">Warehouse</strong> – Select the warehouse where the item location is being assigned. This field is required. The warehouse determines which location codes are available for assignment.</p>
        <p data-source-node="n75"><strong data-source-node="n76">Quantity UM</strong> – Select the unit of measure for the quantity associated with this item location assignment. This field is optional and depends on your warehouse configuration.</p>
        <p data-source-node="n77"> </p>
        <h4 data-source-node="n78">Completing the Assignment</h4>
        <p data-source-node="n79"> </p>
        <p data-source-node="n80">After entering all required information, you have the following options:</p>
        <ul data-source-node="n81">
            <li data-source-node="n82"><strong data-source-node="n83">BACK</strong> – Return to the previous screen without saving changes.</li>
            <li data-source-node="n84"><strong data-source-node="n85">EDIT USER DEFINED FIELDS</strong> – Add or modify custom fields that may be required for your organization's specific needs.</li>
            <li data-source-node="n86"><strong data-source-node="n87">FINISH</strong> – Save the item location assignment and complete the process.</li>
        </ul>
        <p data-source-node="n88">Once you click FINISH, the item location assignment will be saved to the system and the item will be associated with the specified location in the selected warehouse.</p>
