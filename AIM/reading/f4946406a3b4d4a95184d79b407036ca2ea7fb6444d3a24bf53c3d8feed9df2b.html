Activating Real Time Replenishment for a Location

For the system to consider a location for real time replenishment, it first has to be labeled as a "real time" location. You can activate this setting on the Location Window. Note that only "inventory storage" locations can be made eligible for real time replenishment. You can activate this setting on the Location Window.

 

 

Procedures...

  1. Access the Location Window, and open a location record or create a new location.
     
  2. Use the Real Time Replenishment Checkbox to make this location eligible for real time replenishment. For more details, see the field topic.
     
  3. For information on the other fields in this window, see the topic "Creating Locations."
     
  4. Press OK when finished.
