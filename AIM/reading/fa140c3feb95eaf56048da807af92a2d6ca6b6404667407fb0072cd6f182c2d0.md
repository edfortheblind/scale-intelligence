
        
        <h1 data-source-node="n56"><a name="kanchor862" data-source-node="n57"></a>Screen Framework Discussion</h1>
        <p data-source-node="n58">The Screen Framework provides the infrastructure to configure a web interface (screen) using three basic User Interface (UI) elements: screen part, screen group and screen control.  Each of these elements uses metadata to dynamically render the parts, groups and controls on a screen.  A screen can have one to many screen parts.  A screen part can have one to many screen groups, while a screen group can have one to many screen controls. A screen part is not much more than a panel with a title.  Common screen groups include horizontal tabs, vertical tabs and accordions.  A text editor is an example of a screen control used for entering data.  </p>
