
        
        <h1 data-source-node="n56">Warehouse Mobile - Pick to Tote</h1>
        <p data-source-node="n57">The process involves the  user/system picking the items to  transport containers which are also called  a Tote. The pick to tote can be performed with user or system directed work initiation.</p>
        <p data-source-node="n58">All tote related information is recorded in the <i data-source-node="n59">tote_header</i> and <i data-source-node="n60">tote_details</i> table after a putaway or automatic putaway is completed. Read <a href="8ac01fd8fcb46e10f338d1a8ad6bcf37173fa01d75b5ab4c6a631eb2da172833.html" data-source-node="n61">Tote Insight</a> and <a href="ab3e731efc30c514ad10ed2774c3555e56c2a6c6ab49ea8b2d24604226ee1fa8.html" data-source-node="n62">Tote Details Insight</a> screen for more information</p>
        <p data-source-node="n63">User can pick shipment allocation and shipment container work into a tote.</p>

        <h4 data-source-node="n101"><a name="User" data-source-node="n102"></a>User Directed pick to tote work execution</h4>
        <p data-source-node="n103">Perform a user directed pick to tote. </p>
        <ol data-source-node="n104">
            <li value="1" data-source-node="n105">Log in to the Warehouse Mobile application.</li>
            <li value="2" data-source-node="n106">Select the <b data-source-node="n107">Work Execution</b> option from the Warehouse Mobile Main Menu.</li>
            <li value="3" data-source-node="n108">Select the Work Profile and enter or scan the <b data-source-node="n109">Work Unit or Tote ID</b>. </li>
            <li value="4" data-source-node="n110">Tap <b data-source-node="n111">Go</b> to view the <b data-source-node="n112">Pick Confirmation</b> screen. </li>
            <li value="5" data-source-node="n113">Enter the Tote ID and Tap <b data-source-node="n114">Go</b>. Pick Successful message is displayed, and the system will navigate to the putaway confirmation screen after all the picks are completed.</li>
            <li value="6" data-source-node="n115">Tap <b data-source-node="n116">Go</b>.</li>
        </ol>
