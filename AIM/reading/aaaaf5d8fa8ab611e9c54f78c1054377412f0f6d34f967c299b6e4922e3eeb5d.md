
        
        <h1 data-source-node="n56"><a name="kanchor582" data-source-node="n57"></a>Work Pick List</h1>
        <p data-source-node="n58">The work pick list is a general term for two documents: a Batch Pick List and an Order Pick List:</p>
        <ul type="disc" class="ul_1" data-source-node="n59">
            <li data-source-node="n60"><i data-source-node="n61">Batch Pick List</i>: 
 This represents a list of work instructions for multiple orders. Generally, 
 a batch pick groups together multiple details requesting either the same 
 item or the same location. It identifies what item(s) to pick, where to 
 pick, and how much to pick for all shipments requiring an item be picked 
 from a location. You can manually 
 generate a batch pick list in the Work Insight Screen.<br data-source-node="n62"> </li>
            <li data-source-node="n63"><i data-source-node="n64">Order Pick List:</i> 
 This represents the shipments to be picked for a complete order. These 
 are used when you are only picking product from a single ship to. This 
 document tells a picker what to pick, where to pick it from, and how much 
 to pick. You can manually generate 
 an order pick list in the Work Insight Screen.</li>
        </ul>
