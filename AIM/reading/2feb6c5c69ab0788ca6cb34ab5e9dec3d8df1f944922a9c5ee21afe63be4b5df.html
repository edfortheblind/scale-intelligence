Setup Overviews: Trading Partner Management

Below are lists of the setup procedures required to use the Trading Partner Management functional areas.

 

NOTE: Actions without hyperlinks can be performed by your Manhattan Associates representative.

 

 

Email Alerts (TPM)

  1. Configure the SMTP Mail Server
  2. Create a custom email template
  3. Define a TPM email alert
  4. Review the TPM email alert-related web system values

 

 

Web Inventory Management

  1. Define the web screen data values

 

 

Web Order Management

  1. Review order management-related web system values
  2. Define the web screen data values
  3. Activate item and carrier records for web order entry

 

 

Web Purchase Order Management

  1. Review purchase order management-related web system values

 

 

Initial Setup

  1. Create new web users
  2. Create a customer group selection record
  3. Review general web system values
  4. Define the web screen data values
  5. Define the "Reporting" link

 

 

Web Statistics

  1. Review the web statistics-related web system values
  2. Define the web screen data values
