
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n58">Inventory Control Values</h1>
        <p data-source-node="n59">Inventory control values help determine some miscellaneous technical 
 values that are related to managing inventory. These values should only 
 be reviewed or edited by a member of your IT staff or a system consultant. 
 The system is shipped with the most common default values which should 
 meet your business needs.</p>

 allocation requests table. These records are subsequently used by the 
 container creation wave step.<br data-source-node="n109"><br data-source-node="n110">The default dimensions and weight for an item are defined in the Item Unit 
 of Measure Window, and that is what container creation wave step uses 
 to calculate a container’s dimensions. However, an individual instance 
 of an item can be overridden to have different dimensions; when this happens, 
 these override dimensions are stored with the product itself, specifically 
 in the Location Unit of Measure table.<br data-source-node="n111"><br data-source-node="n112">- If this 
 value is Y, the allocation/container 
 creation wave step will look at the Location unit of measure table first

 specific unique dimensions). Note that the allocation process will run 
 slower as a result of this extra calculation.<br data-source-node="n113"><br data-source-node="n114">- If this 
 value is N, the allocation/container 
 creation wave step will use the dimensions as configured in the Item Unit 
 of Measure Window. Thus, the allocation process will run “normally” (i.e., 
 not checking the location unit of measure table for dimensions).</p>

 This value determines how the system will handle the remaining inventory

 or not you want the system to suspend the remaining quantity, and if you

 balance of inventory. Note that this value does not apply to shipping dock locations (for these, the system always uses the "No count, remove transaction quantity" action since cycle counts are not supported there):</p>

 unallocated on hand quantity from inventory using a short pick adjustment.<br data-source-node="n149"> </li>

 transaction quantity: The system will subtract all the transaction's 
 quantity from inventory using a short pick adjustment.<br data-source-node="n151"> </li>

 all unallocated on hand quantity: The system will move all unallocated 
 on hand quantity  to the Suspense 
 Quantity Field, and generate a cycle count request. <br data-source-node="n153"> </li>
                        <li data-source-node="n154">Count, suspend 
 transaction quantity: The system will move all the transaction's 
 quantity  to the Suspense Quantity
