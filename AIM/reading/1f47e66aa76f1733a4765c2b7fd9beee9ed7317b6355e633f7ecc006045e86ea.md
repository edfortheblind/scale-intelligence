        <p data-source-node="n58">This field identifies the description for the activity code of this 
 Billing Management trigger header record. This text description can be 
 any value you choose, as long as it corresponds to this value in Billing 
 Management. This value corresponds to Billing Management's <i style="font-style: italic" data-source-node="n59">Activity Code</i> field.</p>
