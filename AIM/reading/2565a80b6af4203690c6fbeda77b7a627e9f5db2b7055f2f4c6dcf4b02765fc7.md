
        
        <h1 data-source-node="n56"><a name="kanchor572" data-source-node="n57"></a>Location Selection Field</h1>
        <h5 data-source-node="n58">In Locating...</h5>
        <p data-source-node="n59">This field is used during locating, along with the Strategy Field, to 
 subset the number of possible locations where checked in product can be 
 located. This field also determines how the selected locations will be 
 organized. It is defined on a locating rule record.</p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">In Cycle Counting...</h5>
        <p class="p_1" data-source-node="n63">This field indicates the cycle count location 
 criteria record that will be associated with this cycle count master. 
 These selection records are used by the system to filter the number of 
 locations eligible for a cycle count.</p>
