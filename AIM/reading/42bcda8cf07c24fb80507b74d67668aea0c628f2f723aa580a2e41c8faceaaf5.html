Mod 11 V2

This algorithm is used by some LTL/TL carriers, including Southeastern Freight Lines.

 

 

Calculation...

The check digit is generated by a short string of numeric processes performed on specific digits of the next Pro Number. It is a single digit that the system calculates and appends to the next Pro Number. Below is the calculation that the system uses for algorithm Mod 11 V2:

  1. The system takes the next Pro Number and multiplies the 1st position value by 9. The 2nd position value is multiplied by 8.

     

  2. The 3rd position value is multiplied by 7. The 4th position value is multiplied by 6.

     

  3. The 5th position value is multiplied by 5. The 6th position value is multiplied by 4.

     

  4. The 7th position value is multiplied by 3. The 8th position value is multiplied by 2.

     

  5. The sums from Steps 1 - 4 are added together and divided by 11.

     

  6. The result of Step 5 is multiplied by 11, then subtracted from the sums of Steps 1 - 4.

     

  7.  

  8. The finished Pro Number is PPPNNNNNNNNNNSSSC.

a. Take the value in the first position multiply it by 9. Take the value in the 2nd position and multiply it by 8, etc. Add the results together. 0 * 9 + 2 * 8 + 1 * 7 + 5 * 6 + 0 * 5 + 6 * 4 + 1 * 3 + 8 * 2 = 0 + 16 + 7 + 30 + 0 + 24 + 3 + 16 = 96

 

b. Divide the above result by 11. 96 / 11 = 8

 

c. Multiply the above result by 11. 11 * 8 = 88

 

d. Subtract the above result from the sum in step a. 96 – 88 = 8
