
        
        <h1 style="text-align: left;font-size: 12pt" data-source-node="n57">Shipment Process Type</h1>
        <p data-source-node="n58">Shipment process types offer an additional method for classifying orders or shipments. For instance, this field can specify the required shipping method (e.g., rush order, international) or the type of payment processing needed (e.g., cash, credit card). To enable the system to use this value effectively, you must configure a corresponding criteria rule based on the related process.</p>
