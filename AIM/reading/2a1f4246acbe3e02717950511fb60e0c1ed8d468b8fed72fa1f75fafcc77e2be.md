
        
        <h1 data-source-node="n56">Accessing the Help System</h1>
        <p data-source-node="n57">When you are using the application, the online help system is always 
 just a click away. </p>
        <p data-source-node="n58"> </p>
        <p data-source-node="n59"> </p>
        <h4 data-source-node="n60">To access the complete help system:</h4>
        <ul data-source-node="n61">
            <li type="disc" class="li_2" data-source-node="n62">Select the Contents and Index option from the 
 "Help" menu bar option from any window.<br data-source-node="n63"></li>
        </ul>
        <p data-source-node="n64"> </p>
        <h4 data-source-node="n65">To access the help for a specific window's 
 topic:</h4>
        <ul type="disc" class="ul_1" data-source-node="n66">
            <li data-source-node="n67">Select the "On  [Window Name]" option 
 from any window's help menu.</li>
        </ul>
