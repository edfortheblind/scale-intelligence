
        
        <h1 data-source-node="n57"><a name="kanchor1626" data-source-node="n58"></a>Inventory Tracking Checkbox/Toggle</h1>
        <p data-source-node="n59">This checkbox/toggle appears on the Item Window/Item Info Accordion.</p>
        <ul data-source-node="n60">
            <li data-source-node="n61">
                <p data-source-node="n62">If the checkbox/toggle is selected, 
 the system will track which locations an item is stored in and how many 
 units are associated with each location. It will use this information 
 to perform allocations and replenishments.</p>
                <p data-source-node="n63"> </p>
            </li>
            <li class="li_1" data-source-node="n64">If 
 the checkbox/toggle is not selected, the system will     not 
 track which locations an item is stored in or how many units are associated 
 with each location. The system will only perform allocations/locating for a non-tracked 
 item if it is associated with a permanent location.</li>
        </ul>
        <p class="p_1" data-source-node="n65">  NOTE: For Work Order Line Details screen, Inventory Tracked toggle is applicable for composite items. </p>
