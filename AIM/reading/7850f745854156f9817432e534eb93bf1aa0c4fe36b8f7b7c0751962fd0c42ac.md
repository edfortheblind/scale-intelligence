
        
        <h1 data-source-node="n56">Using Warehouse Mobile - Shipping Container QC</h1>
        <p data-source-node="n57">The Warehouse Mobile- Shipping Container QC enables workers with hand held device to easily manually mark a shipping container for QC. Based on the <b data-source-node="n58">Quality Control</b> option selected in the <b data-source-node="n59">Packing preference</b>, the system can perform Shipping container QC in Grocery Store and Total Quantity modes.</p>

        <h4 data-source-node="n74"><a name="Manually" data-source-node="n75"></a>Manually Mark a shipping container for QC</h4>
        <p data-source-node="n76">Follow the steps to mark a shipping container QC</p>
        <ol data-source-node="n77">
            <li value="1" data-source-node="n78">Tap <b data-source-node="n79">Shipping Container QC</b>  screen.</li>
            <li value="2" data-source-node="n80">Enter or scan the <b data-source-node="n81">Container ID </b> and Tap <b data-source-node="n82">Go</b>.</li>
            <li value="3" data-source-node="n83">System prompts user to mark the entered container for QC or not. Select Yes.</li>
            <li value="4" data-source-node="n84">Container is marked for QC successful message is displayed.</li>
        </ol>
        <h4 data-source-node="n85"><a name="Grocery" data-source-node="n86"></a>Perform Shipping container QC - Grocery Store mode.</h4>
        <p data-source-node="n87">Follow the steps to process the shipping container QC in Grocery Store mode. </p>
        <p data-source-node="n88"> </p>
        <p data-source-node="n89">Configuration Required</p>
        <ul data-source-node="n90">
            <li data-source-node="n91">
                <p data-source-node="n92">Select the <b data-source-node="n93">Grocery Store</b> option under <b data-source-node="n94">Packing Preference &gt;&gt; Quality Control</b>  in User Profile configuration</p>
            </li>
        </ul>
        <p data-source-node="n95">Follow the steps</p>
        <ol data-source-node="n96">
            <li value="1" data-source-node="n97">Tap <b data-source-node="n98"><b data-source-node="n99">Shipping Container QC</b></b></li>
            <li value="2" data-source-node="n100">Enter or scan the <b data-source-node="n101">Container ID</b>and Tap <b data-source-node="n102">Go</b></li>
            <li value="3" data-source-node="n103">Enter the item name in Item field and Tap <b data-source-node="n104">Go</b>. System will display a success message with Item name and quantity count value.</li>
            <li value="4" data-source-node="n105">Select <b data-source-node="n106">Actions &gt;&gt; Complete</b>. The system will validate if the item count matches with the system count. If yes, then <b data-source-node="n107">QC successful</b> message is displayed.</li>
        </ol>
        <p data-source-node="n108"> </p>
        <h4 data-source-node="n109"><a name="Total" data-source-node="n110"></a>Perform Shipping container QC - Total Quantity mode.</h4>
        <p data-source-node="n111">Follow the steps to process the shipping container QC in Total Quantity mode. </p>
        <p data-source-node="n112"> </p>
        <p data-source-node="n113">Configuration Required</p>
        <ul data-source-node="n114">
            <li data-source-node="n115">
                <p data-source-node="n116">Select the <b data-source-node="n117">Total Quantity</b> option under <b data-source-node="n118">Packing Preference &gt;&gt; Quality Control</b> in User Profile configuration</p>
            </li>
        </ul>
        <p data-source-node="n119">Follow the steps</p>
        <ol data-source-node="n120">
            <li value="1" data-source-node="n121">Tap <b data-source-node="n122"><b data-source-node="n123">Shipping Container QC</b></b></li>
            <li value="2" data-source-node="n124">Enter or scan the <b data-source-node="n125">Container ID</b>and Tap <b data-source-node="n126">Go</b></li>
            <li value="3" data-source-node="n127">Enter the item name in Item field and Tap <b data-source-node="n128">Go</b>. System will prompt user to enter the Item quantity count.</li>
            <li value="4" data-source-node="n129">Enter value in Quantity Field and Tap Go. System will display a success message with Item name and quantity count value.</li>
            <li value="5" data-source-node="n130">Select <b data-source-node="n131">Actions &gt;&gt; Complete</b>. The system will validate if the item count matches with the system count. If yes, then <b data-source-node="n132">QC successful</b> message is displayed.</li>
        </ol>
        <p data-source-node="n133"> </p>
        <p data-source-node="n134"><b data-source-node="n135">Note:</b>
        </p>
        <ul data-source-node="n136">
            <li data-source-node="n137">If the count does not match, the system will display QC failed message and prompts user to rescan item when <b data-source-node="n138">Actions &gt;&gt;Complete</b> action is performed. <ul data-source-node="n139"><li data-source-node="n140">Tap Yes, and user can rescan the items to count.</li><li data-source-node="n141">Tap No, and system redirects to the Container ID entry screen.</li></ul></li>
        </ul>
