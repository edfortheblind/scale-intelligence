
        
        <h1 data-source-node="n56"><a name="kanchor563" data-source-node="n57"></a>Default Receiving Dock Field</h1>
        <p class="p_1" data-source-node="n58">This field identifies where the employee typically 
 receives product. When this product is putaway via an RF, the value will 
 appear in the From Loc Field. Note that for new installations, this field is filled initially with a dummy receiving location. This field needs to be updated with a valid receiving location. Otherwise, anyone using the 'default receiving dock - receiving preference', will get an error stating the receiving location does not exist.</p>
