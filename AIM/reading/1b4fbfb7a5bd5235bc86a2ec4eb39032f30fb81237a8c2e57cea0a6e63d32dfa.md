
        
        <h1 data-source-node="n56"><a name="kanchor1655" data-source-node="n57"></a>Picking Sequence Field</h1>
        <p data-source-node="n58">This field identifies the picking sequence number assigned to a location. 
 Picking sequences allow you to redefine how the system orders picking 
 work instructions.Later, you would define this sequence value as the Order 
 By attribute on the Allocation Location Selection Window. Picking sequences are optional, not required.</p>
