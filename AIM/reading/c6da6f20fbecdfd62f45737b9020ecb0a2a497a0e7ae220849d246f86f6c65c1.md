
        
        <h1 data-source-node="n56"><a name="kanchor1262" data-source-node="n57"></a>Defining Estimated Work Rates</h1>
        <p data-source-node="n58">You can create an estimated work rate record for a specific work type/work 
 zone. When the system creates a work instruction for this work type/work 
 zone, it will calculate the time required to complete the instruction 
 based on this record. Later, it will display this information on the Work 
 Insight Screen. A manager can review the estimates to determine approximately 
 how much work is available for employees to process.</p>

        <h4 data-source-node="n92">Procedures...</h4>
        <ol data-source-node="n93">
            <li value="1" data-source-node="n94">
                <p data-source-node="n95">Use the Work Type and Work Zone 
 Fields to define which work units that you want to estimate. The 
 system will only apply the estimate when the values that your defined 
 here are met. You can define values in both fields, or leave one blank.</p>
                <p data-source-node="n96"> </p>
            </li>
            <li value="2" data-source-node="n97">
                <p data-source-node="n98">Use the Measurement Choices Buttons 
 to define what type of measurements you want to use: measurements per 
 hour or unit of measure. You can only select one of these buttons. If 
 you select the   Measurements Per Hour 
 Button, the system will measure one of the following variables: 
 labor costs, work units, instructions, by weight or by volume. If you 
 select the   Unit Of Measure Button, 
 the system will measure a quantity unit of measure, such as a case or 
 a pallet.</p>
                <p data-source-node="n99"> </p>
            </li>
            <li value="3" data-source-node="n100">
                <p data-source-node="n101">Use the General Tab Fields to 
 define what values the system will track for this estimate. The system 
 will display different values on the tab, based on the Measurement Choice 
 Button that you selected.</p>
                <p data-source-node="n102"> </p>
            </li>
            <ul type="disc" class="ul_1" data-source-node="n103">
                <li data-source-node="n104">
                    <p data-source-node="n105">If 
 you selected the Measurements Per Hour Buttonthe system 
 will display the Measurement Per Hour Field and a corresponding Hourly 
 Rate Field. You can define one of measurements identified during Step 
 2 (labor costs, work units, etc).</p>
                    <p data-source-node="n106"> </p>
                </li>
                <li data-source-node="n107">If you selected 
 the Unit of Measure Button  the 
 system will display the Unit of Measure Pull Down Menus and corresponding 
 Hourly Rate Fields. You can define up to 8 unit of measure records here.<br data-source-node="n108"> </li>
            </ul>
            <li value="4" data-source-node="n109">Press OK. 
 The system will save your record.</li>
        </ol>
