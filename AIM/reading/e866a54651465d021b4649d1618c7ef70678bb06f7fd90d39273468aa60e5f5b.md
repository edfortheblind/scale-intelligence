
        
        <h1 data-source-node="n56"><a name="kanchor1827" data-source-node="n57"></a>Allow Duplicates Checkbox</h1>
        <p data-source-node="n58">Select this checkbox to determine whether the system will allow users 
 to enter the same serial number for multiple items. Note that this checkbox 
 will be active only if the "Allow Duplicate Serial Numbers" 
 flag in the Inventory Control Values is set at "Y." Be sure 
 to only use this setting if your business process is not affected by having 
 multiple items with the same serial number. </p>
        <ul data-source-node="n59">
            <li data-source-node="n60"><span class="span_1" data-source-node="n61">If unchecked</span>, indicates that 
 you want to prevent duplicate serial numbers from being entered for an 
 individual item. <br data-source-node="n62"><br data-source-node="n63"></li>
            <li data-source-node="n64"><span class="span_1" data-source-node="n65">If checked</span>, the system will 
 allow duplicate serial numbers across items. The system will only allow 
 duplicate serial numbers to be added to items that are associated with 
 a serial number template.</li>
        </ul>
