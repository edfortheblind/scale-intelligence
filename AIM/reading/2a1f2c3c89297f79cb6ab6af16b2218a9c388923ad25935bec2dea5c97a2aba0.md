
        
        <h1 data-source-node="n56"><a name="kanchor1855" data-source-node="n57"></a>Receipt Date Field</h1>
        <p class="p_1" data-source-node="n58">The date that a receipt is interfaced to the system. If the receipt is manually created in the 
 system, this is the date that it was created. When you create a receipt, 
 the system always defaults today's date, but you can change it.</p>
