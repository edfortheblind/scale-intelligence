        <p data-source-node="n73"> </p>
        <p data-source-node="n74">An RF device provides a portable method for warehouse work to be executed. Via RF, 
 you can have the system drive the picking (system-directed work) or have 
 the user scan/enter the work units that they would like to work on (user-directed 
 work). Other flavors of picking that are supported via RF are group-user picking (assigning several work units to a transport container and picking them into it), or user directed picking directly into a shipping container. How you initiate your work depends on how you define your work profile. </p>

        <h4 data-source-node="n132"><a name="generalNotes" data-source-node="n133"></a>Screen Display Notes...</h4>
        <p data-source-node="n134">The following items apply to the various RF work initiation/confirmation screens.</p>
        <ul data-source-node="n135">
            <li data-source-node="n136"> The number of decimal positions that the system displays on these screens is controlled by the Suppress Non-Significant Decimal Positions On RF Picking Screen setting on the Work System Values Window.<br data-source-node="n137"><br data-source-node="n138"></li>
            <li data-source-node="n139">At the top of the Pick Confirmation screen, the system displays the following reference values/messages: <br data-source-node="n140"><br data-source-node="n141">- OH (On Hand quantity): This value represents the on hand quantity based upon the item/company/lot/LP at a location. Note that this value will not be displayed on the screen when executing dock management work.<br data-source-node="n142"><br data-source-node="n143">- ATP (Available To Pick quantity): This value is calculated by (available quantity) + (quantity on current work instruction), based upon the item/company/lot/LP uniqueness at the location. Note that this value will not exceed the "on hand" quantity value. Note that this value will not be displayed on the screen when executing dock management work.<br data-source-node="n144"><br data-source-node="n145">- VAS Required: This message indicates that the container that you are picking into has value added services associated with it. <br data-source-node="n146"><br data-source-node="n147">- QC Required: This message indicates that the container that you are picking into has QC associated with it. Note that if this container also has VAS associated with it, the system will not display this message.<br data-source-node="n148"><br data-source-node="n149"></li>
            <li data-source-node="n150">If a current pick will empty a location of a particular item, the system 
 will display an alert. This message is configurable in the Work 
 System Values Window.<br data-source-node="n151"><br data-source-node="n152"></li>
            <li data-source-node="n153">You can have the system default a pick location's license plate ID as the container ID of the shipping container that you are picking the quantity into. This option (Default LP ID As Container ID On Full Picks) is a setting on the Work Profile Window. For more details, see the topic <a href="671ff642f3216ae5a948a064d208b7b4bf66e0f9e75327a7802cd2f83a97d544.html" data-source-node="n154">Creating Work Profiles</a>.<br data-source-node="n155"><br data-source-node="n156"></li>
            <li data-source-node="n157">You can have the system-directed work initiation screen display either the Location and Rename Work Unit Fields, or just the Location Field. See the System Directed Work Additional Options section of <a href="671ff642f3216ae5a948a064d208b7b4bf66e0f9e75327a7802cd2f83a97d544.html" data-source-node="n158">Creating Work Profiles</a> for more information.<br data-source-node="n159"><br data-source-node="n160"></li>
            <li data-source-node="n161">After you perform a partial pick, and the system refreshes the screen, the partial quantity you just picked will display in the Quantity field, NOT the remaining quantity to pick for that instruction. This will speed up the picking process when picking to multiple containers (since it is likely that the same quantity will fit into each container).  Also, if there is less remaining quantity than the last quantity picked, the screen will default the remaining quantity into the Quantity field.<br data-source-node="n162"><br data-source-node="n163"></li>
            <li data-source-node="n164">You can view the lot's expiration date during RF pick confirmation. This expiration date format is dependent on user's local/regional date setting. However, if no expiration date has been captured or the maximum database value for this field has been assigned, the system will not display the expiration date.<br data-source-node="n165"><br data-source-node="n166"></li>
            <li data-source-node="n167">The system places the cursor focus in certain fields in the following situations:<br data-source-node="n168"><br data-source-node="n169">** The list below is in priority sequence (as soon as the first condition listed is met, that is where the system places the cursor).<br data-source-node="n170">- If the "location verify" setting is enabled, the system places cursor focus on the Location field.<br data-source-node="n171"><br data-source-node="n172">- If the "item verify" setting is enabled, the system places the focus on the Item field.<br data-source-node="n173">- If the "quantity verify" setting is enabled, the system places the focus on the Quantity field.<br data-source-node="n174">- If the "put into shipping container" setting is enabled, then the system places focus on the Container ID field.<br data-source-node="n175">- If the "put into shipping container" setting is enabled and a short putaway occurds, then the system places the focus on the Quantity field.<br data-source-node="n176">- If the "container verify" setting is enabled and you are executing dock management work, then the system places focus on the Pallet field.<br data-source-node="n177">- In all other situations, the system places focus on the upper-leftmost, input-capable field.<br data-source-node="n178"></li>
        </ul>

        <h4 data-source-node="n589"><a name="pickingNotes" data-source-node="n590"></a>Picking Notes...</h4>
        <ul data-source-node="n591">
            <li data-source-node="n592">If executing a partial pick, the system will delete the remaining 
 quantity from the work instruction (and close it) if the "Close After 
 Partial Pick" check box (in Work Special Handling Window) is selected. 
 If not, the system would keep the instruction open so the remainder could 
 be picked later. Note that the "partial pick and close" action 
 is only available for RF replenishment and work order picks, if it is defined 
 to do so in the Work Special Handling Window.<br data-source-node="n593"><br data-source-node="n594"></li>
            <li data-source-node="n595">You cannot perform a partial pick on a full container, full containers being containers created in the wave where the quantity allocated matches the quantity on that unit of measure for the item.  In this case the system creates a single shipping container record that cannot be broken down further. <br data-source-node="n596"><br data-source-node="n597"></li>
            <li data-source-node="n598">If you are executing a pick with the "Allow Over Picking" work special handling setting active, the system will allow the user to pick more quantity than 
 exists on a work instruction, as long as this quantity is within the location's 
 available quantity. When an over pick is performed, the system will increment 
 the transaction quantity, and process the pick as a complete/normal pick. 
 This option is only available for RF replenishment and work order picking. 
 For example, suppose a work order component work instruction calls for 
 980 eaches of an item. It may be easier physically, then, for the worker 
 to pick two cases of 500 (for a total of 1,000 eaches) rather than breaking 
 one case open and leaving 20 eaches loose at the location. If this check box 
 is checked, the system will increment the instruction by 20 eaches, and 
 process the pick as normal.<br data-source-node="n599"><br data-source-node="n600"></li>
            <li data-source-node="n601">If you are executing a pick with the "Allow Pick In Transit" work special handling setting active, the system will allow the user to pick quantities that are labeled as "in transit". Therefore, if there is not enough quantity in the location to be picked, but there is additional inventory that is on the way to the location, the user will be able to pick from that in transit quantity. Important: If the user picks this inventory, the on hand inventory at the location will show a negative quantity until that quantity is rectified by something such as a replenishment or an inventory transfer.<br data-source-node="n602"><br data-source-node="n603"></li>
            <li data-source-node="n604">If you are executing a pick with the "Use Converted Quantity" work special handling setting active, the system will allow the user to pick quantities in the converted UM. If item has UM greater than base UM and pick quantity is a multiple of that converted quantity, the system uses converted UM as pick quantity when "Use converted quantity" checkbox is enabled. If the item only has base UM configured, the system uses base UM as pick quantity when "Use converted quantity" is enabled. If the item has UM greater than base UM but pick quantity is not a multiple of converted quantity UM, the system uses base UM as pick quantity when "Use converted quantity" is enabled. User cannot enter a decimal quantity for converted quantity to a partial/short pick.<br data-source-node="n605"><br data-source-node="n606"></li>
            <li data-source-node="n607">If the item quantity being picked is catch weight and/or serial number tracked, the system will display an entry screen for each item being picked. Note that if the item you are picking is configured for serial number range entry, then the system will display a special screen that allows you to enter the first and last serial number in the range of numbers that is on the quantity that you are picking. You can also press the Skip button to return to the regular serial number entry screen (so you can manually enter each number as opposed to providing the range).<br data-source-node="n608"><br data-source-node="n609"></li>
            <li data-source-node="n610">Note on Pallet Building (Picking Into Shipping Container mode): If you are picking product using the Pallet Building functionality, the system will display the Pallet ID and Pallet Container Type fields on this screen. Note that these fields will only appear if the shipping container you are working with has a parent container. Also, if defined in the work special handling configuration, you can have the user verify the Pallet ID for each pick.<br data-source-node="n611"><br data-source-node="n612"></li>
            <li data-source-node="n613">If you are picking a full UM container (created out of the wave) that has serial number tracked items, then the system will not prompt the user to enter serial numbers.<br data-source-node="n614"><br data-source-node="n615"></li>
            <li data-source-node="n616">It is highly recommended that you do not confirm decimal quantities of serial number tracked items when picking.<br data-source-node="n617"><br data-source-node="n618"></li>
            <li data-source-node="n619">
                <p data-source-node="n620">When short picking an inventory serial number tracked item when the for "Short Pick Inventory Action" inventory control value  is set to "No count,remove all unallocated on hand quantity" or "No count, remove transaction quantity", the system will remove serial numbers to match the quantity being removed from the location.  Note that it will NOT prompt the user for which serial numbers are to be removed, it will simply just choose them.  allows this). If you choose this option, the system will display a nesting 
 RF screen after you have putaway your shipping containers. If you specify 
 a container, the picked containers are then nested under it. This allows 
 you to do is pick into shipping containers, and then place those shipping 
 containers on a pallet for shipping.<br data-source-node="n754"><br data-source-node="n755"></li>
