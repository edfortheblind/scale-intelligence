Container Creation System Values

These values manage certain settings that will affect the execution of the container creation wave step.

 

 

Value Key

 

Value Description

 

30

3D Cubing Default Stabilization Code: This value indicates the stabilization code that you want the system to assign to items. If you are not purposely assigning a code via the stabilization amount exit point, this system value represents the code that the 3D cubing strategy will reference during its execution. For specific details on how the 3D cubing strategy uses these stabilization codes, please reference the Container Creation in the Wave process flow topic.
