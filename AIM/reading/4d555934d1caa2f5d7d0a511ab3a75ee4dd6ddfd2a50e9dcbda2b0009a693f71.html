Consolidation Location

You can use this configuration to set up consolidation locations, which are non-inventory-tracked areas consisting of one or more positions. These typically represent a physical packing station or a designated area near a packing station.

When you assign a detail or container from a shipment to a consolidation location, the system automatically assigns all related details or containers from that shipment to the same location.

 

Create Consolidation Location record.

  • Warehouse - Select the warehouse where the new location will be created.

  • Location Area - Choose the area within the warehouse where this location should be placed.

  • Position Range - Define the position(s) for the location

    • To create a single position, enter the same position name in both fields.

    • To create a range of positions, enter the first and last positions in the respective fields.

  • Note: Each location must have at least one position.

  • Check Digit - Enter the check digit workers must input to confirm they are at the correct location.

 

Toggle Buttons

  • Generate Check Digit indicate that you want the system to automatically generate check digits for this location.

  • Multi Shipment - indicate that you can have more than one shipment residing in a particular consolidation location.
