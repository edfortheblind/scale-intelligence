
        
        <h1 data-source-node="n56"><a name="kanchor449" data-source-node="n57"></a>External Rating Symbol Field</h1>
        <h5 data-source-node="n58">On 
 the Dimension UM Window...</h5>
        <p data-source-node="n59">This field identifies the value (which corresponds to the Dimension 
 UM) that is sent by the system to the transportation engine, either FSMS 
 or Progistics. Valid values for this field are "I" (for inches) 
 and "C" (for centimeters). </p>
        <p data-source-node="n60"> </p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">On 
 the Freight Terms Window...</h5>
        <p data-source-node="n63">This field indicates the Progistics name for a freight term. The system 
 passes this symbol to Progistics when the system requests a rate.</p>
