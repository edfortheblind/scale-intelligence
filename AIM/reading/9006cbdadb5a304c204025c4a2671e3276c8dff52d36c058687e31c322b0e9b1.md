
        
        <h1 data-source-node="n56"><a name="kanchor1742" data-source-node="n57"></a>Maximum Lines Field</h1>
        <p data-source-node="n58">This field represents the most shipment lines that can be 
 processed in a particular wave.</p>
        <p class="p_1" data-source-node="n59">  </p>
        <p data-source-node="n60">The system supports the following wave maximums:</p>
        <ul data-source-node="n61">
            <li data-source-node="n62">Maximum lines</li>
            <li data-source-node="n63">Maximum quantity</li>
            <li data-source-node="n64">Maximum shipments</li>
            <li data-source-node="n65">Maximum value</li>
            <li data-source-node="n66">Maximum volume</li>
            <li data-source-node="n67">Maximum weight</li>
        </ul>
        <p class="p_1" data-source-node="n68">If more than one maximum applies to a wave 
 record, the system will close a wave when it reaches one of the maximums. 
 This allows you to manage the waves at multiple levels.</p>
