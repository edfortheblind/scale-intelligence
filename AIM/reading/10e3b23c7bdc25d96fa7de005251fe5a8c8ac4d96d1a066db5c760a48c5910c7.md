
        
        <h1 data-source-node="n56"><a name="kanchor458" data-source-node="n57"></a>Save As Template Checkbox</h1>
        <p data-source-node="n58">This checkbox indicates if you want to save the current order as a template. If this checkbox is checked, 
 the flow of screens in the current order entry session will be saved as 
 a template. You can then load this template in future sessions using the 
 Use Template Button on the first screen of the Order Entry Window. If this checkbox 
 is not checked, the system will process the order without saving 
 it as a template.</p>
