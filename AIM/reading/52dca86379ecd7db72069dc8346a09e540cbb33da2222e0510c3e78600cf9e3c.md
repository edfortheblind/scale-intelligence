
        
        <h1 data-source-node="n56"><a name="kanchor1951" data-source-node="n57"></a>Reviewing Container Shapes</h1>
        <p data-source-node="n58">A container shape indicates the physical shape of a shipping container. 
 Examples include such shape descriptions as <i data-source-node="n59">standard</i> or <i data-source-node="n60">irregular</i>. 
 During the wave's container creation process, the system attempts to put 
 an entire item quantity into the next container type in the container 
 group, and keeps trying until the items will not fit; therefore, putting 
 it in the smallest possible container type. Note that the system will 
 only downsize into sequences that have the same container shape as the 
 container it started with. For example, if the first container the system 
 packs a quantity into was <i data-source-node="n61">irregular</i>, then the system will attempt 
 to downsize into the following sequences until it finds one that has a 
 value different than <i data-source-node="n62">irregular</i>.</p>
