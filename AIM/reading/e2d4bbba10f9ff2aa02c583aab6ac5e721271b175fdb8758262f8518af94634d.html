Performing User OR System-Directed Work... 

 

1. Log on to your RF Device and select the Work function. The system will display the Work Profile selection screen.

 

 

2. If you have a default work profile defined for your user profile, the system will automatically choose this profile and direct you to the appropriate work screen. Otherwise, you will need to manually choose a work profile.

 

 

3. Scan the work initiation value and press OK:

  • NOTE: Work units for receipt containers with delayed locating will relocate from the receiving pre-locate location to an inventory location when starting work.

 

For User-Directed:

 

WHAT TO SCAN?

 

IN WHAT SITUATION?

 

Work Unit

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

You will scan a work unit ID when initiating user-directed work.

  • If the scanned work unit was created as part of “delayed locating”, then the system will relocate the receipt container(s) associated with that work unit after passing start work validation.

    - If relocating and start work validation to the new location succeeds, then the system displays the Pick Confirmation screen.

    • - If relocating or start work validation fails, then the system displays the error and the User Directed screen. The user would need to investigate the failure or enter a different work unit. The work unit’s for failed receipt containers will remain located to the receiving pre-locate location.

  • Relocating is delayed until starting work for the P&D pick when the receiving dock has an outgoing P&D location.

 

 

 

For System-Directed:

 

WHAT TO SCAN?

 

IN WHAT SITUATION?

 

Location only

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

You will scan a location ID to initiate system-directed work.

  • The system will look at the from location assignment method in the work profile to determine what work to assign to a user. For example, suppose that your assignment method is location/priority/FIFO. The system would first take into consideration where you are in the warehouse when deciding which work unit to assign to you. For example, if you were currently standing in the bulk locations area, you would want the system to send you work that is located near this area. You could scan the location nearest to you so the system would send you work that was nearest your new location. If more than one available work unit is present at that location, the system will next look at the priority value of the work units. If that is the same, the system then would assign the work unit based on a first in, first out (FIFO) basis.

    •  

  • If the scanned work unit was created as part of “delayed locating”, then the system will relocate the receipt container(s) associated with that work unit after passing start work validation.

    - If relocating and start work validation to the new location succeeds, then the system displays the Pick Confirmation screen.

    • - If relocating or start work validation fails, then the system displays the error and the User Directed screen. The user would need to investigate the failure or enter a different work unit. The work unit’s for failed receipt containers will remain located to the receiving pre-locate location.

  • Relocating is delayed until starting work for the P&D pick when the receiving dock has an outgoing P&D location.

 

Rename Work Unit only

 

 

 

 

 

 

 

 

 

 

 

 

 

 

You will enter a new work unit ID if you want to rename the next work unit that the system assigns to you.

 

For example, suppose you are a picker whose job it is to pick items from an aisle location and place them in a P&D location at the end of the aisle. It is then another worker's job to continue processing on a work unit from that P&D location. So, you would have a roll of barcode stickers, where each sticker has a new work unit number on it. You would then scan a barcode into the Rename Work Unit Field, and press OK. The system will rename the next work unit it sends you as the value that you scanned into this field. The worker whose job it is to putaway from the P&D location then could just scan the barcode (with the new work unit ID on it) and continue the processing work that you started.

 

Notes:

- The system-directed work unit selection screen functionality (described below) is not available when renaming a work unit.

- You cannot leave this field blank.

 

Location AND Rename Work Unit

 

 

 

 

 

 

 

You would enter a location AND a new work unit if you want to tell the system what location you are currently at, and also want to rename the work unit that the system sends to you.

 

Notes:

- The system-directed work unit selection screen functionality (described below) is not available when renaming a work unit.

- You cannot leave this field blank.

 

No Location

 

 

You would not enter a location value if you do not care where in the warehouse that the next work unit will come from. You would do this if your job was to pick/putaway from all areas of the warehouse.

 

System-Directed

Work Unit Selection

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

If the From Location (where the system assigned you a work unit) is eligible for system-directed work unit selection, then the system will display an additional initiation screen. This allows you to choose the work unit you wish to execute:

  • If you scan a work unit and press OK, the system will then display the first instruction in the Pick Confirmation screen. The system will not allow you to move forward in the picking process without first scanning a work unit.

  • If you press Cancel, the system will return you to the initial system-directed work initiation screen.
Notes:

 

- That all the work unit validations for the system-directed work unit selection screen are identical to the validations that the system performs when initiating work with the user-directed initiation screen (such as the work unit cannot be closed, cannot be active, etc).

 

- That you are required to scan a work unit from the current location (as displayed on the Work Unit Selection screen). You cannot scan a work unit from a different location.

 

- This system-directed work unit selection screen functionality is not available when renaming a work unit.

 

Multiple Work Unit Assignment

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

If the From Location (where the system assigned you a work unit) is eligible for system-directed multiple work unit assignment, then the system will display an additional initiation screen. This allows you to assign more than one work unit to execute during a picking session:

  • If you scan a work unit and press Assign, the system will generate a group ID (after the first assignment), and assign the work unit to this group. All subsequent work unit(s) assigned during this session will be associated with this group ID.

  • If you press Begin Picks, the system will display the Pick Confirmation screen:

    - If the “Group by Loc/LP” work profile setting is enabled, the system will display a single pick for all work units and instructions.

    - If the “Group by Loc/LP” work profile setting is NOT enabled, the system will required you to do individual picks for all instructions on all work units.

    - If you press the Pass or Full button on the Pick Confirmation screen, the system will unassign all work from the group (after displaying a warning prompt).

    - If you press the Skip button, the system will move to next work instruction (if there are multiple picks assigned to this group).

  • If you press Cancel, the system will ungroup any assigned work units, and return you to the initial system-directed work initiation screen.
Notes:

 

- There is no limit to the work unit(s) that you can assign to a picking session.

 

- If you press the Pass button on the putaway action, the system will unassign all work units from the group (after displaying a warning prompt).

 

- If you press the Skip button on the putaway action, the system will cycle to the next work unit/detail if those exist.

 

- If you putaway to a P&D location, the system will automatically remove the work unit from the group without displaying a warning prompt.

 

-If the scanned work unit was created as part of “delayed locating”, then the system will relocate the receipt container(s) associated with that work unit before assigning to the group of work units to execute.

  • If relocating when assigning the work unit and start work validation when beginning picks succeeds, then the system displays the Pick Confirmation screen.

  • If relocating the work unit from “delayed locating” fails, then an error is displayed and the work unit is not assigned to the group of work units to execute. The work unit’s for the failed receipt containers will remain located to the receiving pre-locate location.

  • If relocating succeeds and start work validation when beginning picks fails, then the System Directed screen is displayed and the work units are ungrouped.

-Relocating is delayed until starting work for the P&D pick when the receiving dock has an outgoing P&D location.
