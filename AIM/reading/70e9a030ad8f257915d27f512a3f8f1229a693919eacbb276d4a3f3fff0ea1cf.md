
        
        <h1 data-source-node="n56"><a name="ContainersActionTiles" data-source-node="n57"></a><a name="kanchor1496" data-source-node="n58"></a>Containers Indicator Tile</h1>
        <h5 data-source-node="n59">Shipment Insight Screen</h5>
        <p data-source-node="n60">This tile displays the total number of parent shipping containers.  Pressing on this tile takes you to the Shipping Container Insight screen, filtering the results by specific parameters depending on from which screen it has been accessed.</p>
        <p data-source-node="n61"> </p>
        <h5 data-source-node="n62">Shipping Container Insight Screen</h5>
        <p data-source-node="n63">This tile displays the total number of shipping containers at the subsequent level.  Pressing the tile takes you to the Shipping Container Insight to display the  containers at the subsequent level.</p>
        <p data-source-node="n64"> </p>
        <h5 data-source-node="n65">Wave Insight Screen</h5>
        <p data-source-node="n66">This tile displays the number of containers after the wave has been run, when containers are created in the wave.  Note that if shipping containers are interfaced into the system with the shipment, this tile could have quantity prior to the wave being run.</p>
        <p data-source-node="n67"> </p>
        <h5 data-source-node="n68">Receipt Line Insight Screen</h5>
        <p data-source-node="n69">This tile displays the number of receipt containers associated with a receipt line. Pressing on this tile takes you the Receipt Container Insight screen, filtering the results by the internal receipt line number.</p>
        <p data-source-node="n70"> </p>
        <h5 data-source-node="n71">Putaway Group Insight Screen</h5>
        <p data-source-node="n72">This tile displays the number of receipt containers that are associated with the selected putaway group. When you tap/click on this tile, the system will open the Receipt Container Insight Screen and shows only the containers that are associated to the selected putaway group.</p>
