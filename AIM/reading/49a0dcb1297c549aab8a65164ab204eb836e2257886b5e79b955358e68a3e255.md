
        
        <h1 data-source-node="n56">Document Print Break Window</h1>
        <p data-source-node="n57">You will use this window to identify the printers that paperwork will 
 be routed to during a wave. You will also define how many pieces of paperwork 
 can be associated with a particular printer. Once the system reaches this 
 maximum, it will route the remaining documents to the next printer identified 
 on this window. If the system uses the last printer and more documents 
 remain, it will return to the first printer defined and route the paperwork 
 to it. This window applies only to documents generated during a wave (not 
 labels). You can only access this window from the Document Master Window. 
 </p>
